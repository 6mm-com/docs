> **Nota**
>
> Endpoints de posição exigem permissão comercial.

<h2 id="set-leverage">Alavancagem de Conjunto</h2>

```http
POST /v1/private/position/leverage
Content-Type: application/json
```

Órgão do pedido:

```json
{
  "symbol": "BTCUSDT",
  "leverage": 20
}
```

Campos de resposta:

| Campo       | Tipo   | Descrição |
| ----------- | ------ | ----------- |
| `symbol`    | string | Símbolo      |
| `leverage`  | int32  | Alavancagem    |
| `timestamp` | int64  | Carimbo de data e hora   |

<h2 id="set-margin-mode">Definir Modo Margem</h2>

```http
POST /v1/private/position/margin-mode
Content-Type: application/json
```

Órgão do pedido:

```json
{
  "symbol": "BTCUSDT",
  "marginMode": 1
}
```

`marginMode`: `1` cruzar, `2` isolado.

<h2 id="position-settings">Configurações de Posição</h2>

```http
GET /v1/private/position/settings?symbol=BTCUSDT
```

Campos de resposta:

| Campo        | Tipo   | Descrição             |
| ------------ | ------ | ----------------------- |
| `symbol`     | string | Símbolo                  |
| `marginMode` | int32  | `1` cruzar, `2` isolado |
| `leverage`   | int32  | Alavancagem                |

<h2 id="current-positions">Cargos Atuais</h2>

```http
GET /v1/private/position/positions?symbol=BTCUSDT
```

Parâmetros da solicitação:

| Parâmetro | Tipo   | Obrigatório | Descrição |
| --------- | ------ | -------- | ----------- |
| `symbol`  | string | Não       | Símbolo      |

Campos de resposta:

| Campo                         | Tipo   | Descrição                |
| ----------------------------- | ------ | -------------------------- |
| `positions[].symbol`          | string | Símbolo                     |
| `positions[].marginMode`      | string | Modo margem                |
| `positions[].positionSide`    | string | Lado da posição              |
| `positions[].leverage`        | int32  | Alavancagem                   |
| `positions[].quantity`        | string | Quantidade de posição          |
| `positions[].entryPrice`      | string | Preço de entrada                |
| `positions[].breakEvenPrice`  | string | Preço de equilíbrio           |
| `positions[].liqPrice`        | string | Preço de liquidação          |
| `positions[].marginRatio`     | string | Razão de margem               |
| `positions[].unrealizedPnl`   | string | PnL não realizado             |
| `positions[].roe`             | string | Retorno sobre o patrimônio líquido           |
| `positions[].nextFundingFee`  | string | Próxima taxa estimada de financiamento |
| `positions[].fundingFeeAccum` | string | Taxa acumulada de financiamento    |
| `positions[].tpPrice`         | string | Preço de lucro          |
| `positions[].slPrice`         | string | Preço de stop-loss            |

<h2 id="position-history">Histórico da Posição</h2>

```http
GET /v1/private/position/history?symbol=BTCUSDT&page=1&pageSize=20
```

Parâmetros da solicitação:

| Parâmetro   | Tipo   | Obrigatório | Descrição                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Não       | Símbolo                       |
| `side`      | string | Não       | `long` / `short`             |
| `startTime` | int64  | Não       | Horário de início                   |
| `endTime`   | int64  | Não       | Fim dos tempos                     |
| `page`      | int64  | Não       | Número da página, `1` padrão     |
| `pageSize`  | int64  | Não       | Itens por página, padrão `20` |

Campos de resposta:

| Campo                    | Tipo   | Descrição               |
| ------------------------ | ------ | ------------------------- |
| `list[].symbol`          | string | Símbolo                    |
| `list[].positionSide`    | string | Lado da posição             |
| `list[].leverage`        | int32  | Alavancagem                  |
| `list[].maxQuantity`     | string | Quantidade máxima de posição |
| `list[].entryPrice`      | string | Preço de entrada               |
| `list[].closePrice`      | string | Preço fechado               |
| `list[].pnl`             | string | PnL realizado              |
| `list[].roe`             | string | Retorno sobre o patrimônio líquido          |
| `list[].marginMode`      | string | Modo margem               |
| `list[].triggerMode`     | int32  | Modo de gatilho fechado        |
| `list[].fundingFeeAccum` | string | Taxa acumulada de financiamento   |
| `list[].openedAt`        | int64  | Horário aberto                 |
| `list[].closedAt`        | int64  | Tempo de fechamento                |
| `total`                  | int64  | Contagem total               |
