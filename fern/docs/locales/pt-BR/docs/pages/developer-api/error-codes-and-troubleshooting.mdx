<h2 id="error-response-format">Formato de Resposta de Erro</h2>

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Erros de negócio geralmente ainda retornam a estrutura unificada de JSON . Integradores devem verificar `code` primeiro. Falhas de autenticação podem retornar HTTP `401`; limitação de taxa pode retornar HTTP `429`.

<h2 id="common-error-codes">Códigos de Erro Comuns</h2>

| Código de erro      | Descrição                                  |
| --------------- | -------------------------------------------- |
| `0`             | Sucesso                                      |
| `1001`          | Nenhuma informação válida de autenticação fornecida |
| `1002`          | Token expirado                                |
| `1003`          | Token inválido, API Keyou assinatura         |
| `1004`          | Token revogado                                |
| `1006`          | Fonte IP descompasso                           |
| `2001`          | Parâmetro exigido ausente                   |
| `2002`          | Valor inválido do parâmetro                      |
| `2003`          | Parâmetro fora do alcance                       |
| `3001`          | Equilíbrio insuficiente                         |
| `3003`          | Ordem não encontrada                              |
| `3004`          | Solicitação duplicada                            |
| `3005`          | Pedido não pode ser cancelado                     |
| `3006`          | Permissão negada                            |
| `3100` - `3112` | Erro de validação do parâmetro de ordem da condição   |
| `5001`          | Erro interno do servidor                        |
| `5002`          | Serviço temporariamente indisponível              |
| `5003`          | Limite de taxa acionado                         |

<h2 id="troubleshooting">Solução de problemas</h2>

| Problema                                     | Recomendação                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` nenhuma informação válida de autenticação  | Verifique se `Authorization: Bearer <accessToken>` ou `X-API-KEY` está incluído.                  |
| `1002` Token expirado                        | Atualize o Token ou faça login novamente antes de tentar novamente.                                                   |
| `1003` Token, API Keyou assinatura inválidas | Verifique API Key, carga útil de assinatura, corpo JSON string de solicitação e ordem dos parâmetros de consulta.           |
| `1006` fonte IP descompasso                   | Verifique a configuração da lista branca API Key IP .                                                    |
| `3004` pedido de duplicação                    | Não reutilize a mesma assinatura para caminhos relacionados à ordem. Regenerar `timestamp` e `signature`. |
| `5003` limite de taxa acionado                 | Reduza a frequência dos pedidos e use um backoff exponencial se tentar novamente.                                |
| `Timestamp outside of tolerance window`     | Ligue para `/v1/time` calibrar o desfasamento temporal e assine o pedido novamente.                             |
