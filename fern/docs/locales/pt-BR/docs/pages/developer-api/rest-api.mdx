<h2 id="public-endpoints">Pontos Finais Públicos</h2>

| Endpoint                   | Método | Caminho                                        | Descrição                                                    |
| -------------------------- | ------ | ------------------------------------------- | -------------------------------------------------------------- |
| Versão de serviço            | GET    | `/v1/version`                               | Obtenha informações sobre a versão do serviço                                |
| Tempo do servidor                | GET    | `/v1/time`                                  | Tenha tempo no servidor                                                |
| Login do usuário                 | POST   | `/v1/public/user/login`                     | Use nome de usuário e senha para obter `accessToken`              |
| Token de Atualização              | POST   | `/v1/public/user/refresh-token`             | Atualizar o estado de login via Cookie                                 |
| Troca de ingressos para agente      | POST   | `/v1/public/agent-sso/exchange-ticket`      | Troque um ticket de entrada de agente pelo estado de login              |
| Troca de Token de Incorporação de Agente | POST   | `/v1/public/agent-sso/exchange-embed-token` | Troque um token de negociação embutido de curta duração por um estado de login |
| Configuração de símbolos       | GET    | `/v1/public/market/symbols`                 | Obtenha símbolos, regras de negociação e configuração de níveis de taxas         |
| Configuração das taxas de financiamento | GET    | `/v1/public/market/funding-rate`            | Consulta à configuração da taxa de financiamento                               |
| Taxa atual de financiamento       | GET    | `/v1/public/market/funding-rate/current`    | Paginar as taxas atuais de financiamento                                 |
| Histórico das taxas de financiamento       | GET    | `/v1/public/market/funding-rate/history`    | Consultar histórico de taxas de financiamento                                     |
| Klines                     | GET    | `/v1/public/market/klines`                  | Consultar preço de negociação, preço de índice ou marcar preço Klines           |
| Tabela de líderes da PnL            | GET    | `/v1/public/leaderboard/pnl`                | Consulta tabela de classificação PnL de 7 / 30 / 90 dias                          |

<h2 id="private-user-endpoints">Endpoints de Usuários Privados</h2>

A menos que especificado de outra forma, os seguintes endpoints podem usar JWT ou API Key assinatura.

| Endpoint                 | Método | Caminho                                      | Permissão   | Descrição                                 |
| ------------------------ | ------ | ----------------------------------------- | ------------ | ------------------------------------------- |
| Informações do usuário                | GET    | `/v1/private/user/info`                   | Leia         | Consultar o perfil atual do usuário                  |
| Ativos do usuário              | GET    | `/v1/private/user/asset`                  | Leia         | Consultar saldo da carteira e uso da margem       |
| Crie listenKey         | POST   | `/v1/private/user/listen-key`             | Leia         | Criar chave de autenticação WebSocket privada |
| Renovar listenKey          | PUT    | `/v1/private/user/listen-key`             | Leia         | Estenda listenKey validade                   |
| Fechar listenKey          | DELETE | `/v1/private/user/listen-key`             | Leia         | Fechar listenKey                             |
| Registros de alteração de conta      | GET    | `/v1/private/user/account-change-log`     | Leia         | Consultar registros de movimento de fundos                 |
| Estatísticas de volume em 30 dias | GET    | `/v1/private/user/volume-stats`           | Leia         | Consultar o volume e as taxas de negociação recentes de 30 dias |
| Histórico do balanço          | GET    | `/v1/private/user/balance-history`        | Leia         | Histórico de balanceamento de consultas                       |
| Visão geral do comércio           | GET    | `/v1/private/user/trade-overview`         | Leia         | Consultar PnL, volume e tendência de ativos          |
| Resumo da visão geral dos ativos   | GET    | `/v1/private/user/asset/overview/summary` | Leia         | Consultar métricas de resumo de ativos                 |
| Tendência geral dos ativos     | GET    | `/v1/private/user/asset/overview/trend`   | Leia         | Consultar tendência de ativos                           |
| Salvar símbolos favoritos    | POST   | `/v1/private/user/favorite-symbols`       | Leia         | Sobrescrever símbolos favoritos                  |
| Obtenha símbolos favoritos     | GET    | `/v1/private/user/favorite-symbols`       | Leia         | Consultar símbolos favoritos                      |
| Desconectar                   | POST   | `/v1/private/user/logout`                 | JWT + Cookie | Limpar estado de login                           |

<h2 id="api-key-management-endpoints">API Key Endpoints de Gerenciamento</h2>

API Key endpoints de gerenciamento aceitam apenas JWT.

| Endpoint            | Método | Caminho                                  | Descrição                                         |
| ------------------- | ------ | ------------------------------------- | --------------------------------------------------- |
| Crie API Key      | POST   | `/v1/private/user/api-key/create`     | Crie API Key; `apiSecret` é retornado apenas uma vez   |
| API Key lista        | GET    | `/v1/private/user/api-key/list`       | Consultar as chaves de API do usuário atual                       |
| Atualização API Key      | PUT    | `/v1/private/user/api-key/update`     | Atualize o rotulo, permissões, IP lista branca e status |
| Exclua API Key      | POST   | `/v1/private/user/api-key/delete`     | Exclua um API Key especificado                          |
| Exclua todas as API Chaves | POST   | `/v1/private/user/api-key/delete-all` | Exclua todas as API Chaves do usuário atual             |

<h2 id="order-endpoints">Ordem Extremos</h2>

Endpoints de ordens exigem permissão de troca.

| Endpoint                    | Método | Caminho                                  | Descrição                                                       |
| --------------------------- | ------ | ------------------------------------- | ----------------------------------------------------------------- |
| Consulta em ordem única          | GET    | `/v1/private/order`                   | Consulta exata por `symbol + orderId/clientOrderId`                   |
| Ordem de colocação                 | POST   | `/v1/private/order/place`             | Ordem limite ou de mercado                                             |
| Ordem de condição de lugar       | POST   | `/v1/private/order/place-condition`   | Stop loss, take profit, trailing stop e outras ordens de condição |
| Coloque a ordem da estratégia        | POST   | `/v1/private/order/place-strategy`    | OTO / OCO / OTOCO ordem de estratégia                                  |
| Faça pedidos em lote          | POST   | `/v1/private/order/batch-place`       | Envie múltiplos pedidos normais                                     |
| Cancelar pedido                | POST   | `/v1/private/order/cancel`            | Cancelar uma ordem normal especificada                                   |
| Ordem de alteração                 | POST   | `/v1/private/order/move`              | Modificar o preço e a quantidade normais de ordem pendente                    |
| Ordens de retificação em lote          | POST   | `/v1/private/order/batch-move`        | Modificação em lote de ordens normais pendentes para o mesmo símbolo            |
| Pedidos de cancelamento por lote         | POST   | `/v1/private/order/batch-cancel`      | Cancelar pedidos normais em lote                                        |
| Cancelar tudo                  | POST   | `/v1/private/order/batch-cancel-all`  | Cancelamento de pedidos em lote por tipo                                       |
| Ordem de cancelar condição      | POST   | `/v1/private/order/cancel-condition`  | Cancelar uma ordem de condição especificada                                |
| Ordens normais atuais       | GET    | `/v1/private/order/current`           | Consultar ordens normais pendentes atuais                               |
| Ordens de condição atual    | GET    | `/v1/private/order/current-condition` | Consultar ordens de condição não acionadas atuais                        |
| Ordens normais históricas    | GET    | `/v1/private/order/history`           | Paginar ordens normais históricas                                 |
| Ordens de condição histórica | GET    | `/v1/private/order/history-condition` | Paginar ordens de condição histórica                              |
| Recordes de trocas               | GET    | `/v1/private/order/trades`            | Paginar registros de troca                                            |
| Detalhe da ordem da estratégia       | GET    | `/v1/private/order/strategy`          | Ordem da estratégia de consulta e subordens                               |

<h2 id="position-endpoints">Pontos de Ponta de Posição</h2>

Os endpoints de posição exigem permissão de troca.

| Endpoint          | Método | Caminho                               | Descrição                                  |
| ----------------- | ------ | ---------------------------------- | -------------------------------------------- |
| Definir modo margem   | POST   | `/v1/private/position/margin-mode` | Interruptor isolado / margem cruzada               |
| Alavancagem de conjunto      | POST   | `/v1/private/position/leverage`    | Alavancagem de símbolo de conjunto                          |
| Configurações de posição | GET    | `/v1/private/position/settings`    | Alavancagem de consulta e modo margem para um símbolo  |
| Cargos atuais | GET    | `/v1/private/position/positions`   | Consultar posições atuais                      |
| Histórico da posição  | GET    | `/v1/private/position/history`     | Consultar posições históricas e fechar registros |
