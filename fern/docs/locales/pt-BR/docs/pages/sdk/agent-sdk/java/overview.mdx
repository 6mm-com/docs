<h2 id="runtime">Duração</h2>

| Item | Valor |
| --- | --- |
| Versão mínima Java | Java 8+ |
| Ferramenta recomendada de construção | Maven 3.9+ |
| Grupo Maven | `com.sixmm.exchange.sdk` |
| Artefato Maven | `agent` |
| Etiqueta de fonte documentada | `v0.1.1` |

O repositório público do GitHub é hospedagem de código-fonte, não um repositório de dependência do Maven. Construa e instale o código-fonte marcado localmente ou publique o artefato aprovado no repositório privado do Maven da sua organização antes de usá-lo em builds de equipe.

<h2 id="typical-backend-responsibilities">Responsabilidades típicas de backend</h2>

- Validar a sessão do usuário parceiro.
- Mapear o usuário parceiro para agentUserId.
- Vinculação de chamadas antes da primeira negociação ou transferência.
- Ligue createEntryUrl para um SSOcompleto único de .
- Chame createEmbedToken para Trading Widget modo de tokens de parceiro.
- Verificar webhooks de transferência e processá-los idempotentemente.

<h2 id="security-and-operational-rules">Regras de segurança e operacionais</h2>

- Armazenar `apiSecret` apenas em um gerenciador de segredos backend ou variável de ambiente protegido.
- Mantenha o tempo do servidor sincronizado porque as requisições assinadas contêm carimbos de data.
- Trate `agentOrderNo` como uma chave de idempotência durável e mantenha-a globalmente única.
- Armazenar `platformUserId` como uma cadeia e persistir sua relação com `agentUserId`.
- Consultar a transferência original antes de tentar novamente após um timeout ou resultado de rede incerto.
