<h2 id="sdk-call">SDK chamada</h2>

Crie tokens de embed a partir do seu backend após validar a sessão do usuário parceiro. O navegador deve chamar seu endpoint, e seu endpoint deve chamar 6MM pelo Agent SDK.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Credencial única**
>
> embedToken é de curta duração e de uso único. Não coloque isso em uma URL string de consulta.

<h2 id="backend-endpoint-example">Exemplo de endpoint backend</h2>

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Devolva apenas os campos necessários pelo fornecedor de tokens Trading Widget . Não retorne apiSecret, campos de assinatura bruta ou configuração interna do serviço.

<h2 id="failure-handling">Manuseio de falhas</h2>

| Condição | Manuseio recomendado |
| --- | --- |
| A sessão do usuário está ausente ou expirada | Devolva o 401 do endpoint parceiro e peça para o usuário fazer login novamente. |
| O usuário agente não está vinculado | Atribua primeiro o usuário, depois tente novamente a criação do token. |
| 6MM retorna um erro temporário | Devolva um erro retentável para o frontend e registre requestId para suporte. |
| channelId não corresponde à instância do widget | Rejeite o pedido e recrie a sessão do widget. |
