<h2 id="install">Instalação</h2>

A fonte pública SDK atualmente documenta `v0.1.1` de etiquetas com estas coordenadas Maven:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

O GitHub não funciona como um repositório de dependência do Maven. Instale o código-fonte marcado localmente antes de resolver a dependência:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Equipes de construção**
>
> Publique o artefato aprovado no repositório Maven da sua organização para CI, testes e builds de produção. Confirme a versão aprovada com 6MM antes da implantação em produção.

Exemplos de código-fonte e uso estão disponíveis no repositório oficial Java SDK :

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

<h2 id="before-you-start">Antes de começar</h2>

- Confirme seu agente de produção API URL base com a equipe 6MM .
- Armazene apiSecret apenas no gerenciamento de segredos do backend.
- Prepare um mapeamento estável entre platformUserId e agentUserId.
- Habilitar logs estruturados em torno dos fluxos bind, transfer, order e webhook.

<h2 id="initialize-client">Inicializar cliente</h2>

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Apenas backend**
>
> Não inicialize o Agent SDK a partir do código cliente do navegador, celular ou desktop. O SDK assina solicitações privilegiadas do Agente API .

<h2 id="example-transfer-funds-in">Exemplo: transferir fundos para</h2>

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Use um número de pedido único do lado do parceiro para cada solicitação de transferência. Se uma solicitação expirar, consulte a ordem original antes de criar uma nova.
