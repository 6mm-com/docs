<h2 id="which-path-should-i-choose">Qual caminho devo escolher?</h2>

| Objetivo comercial | Solução recomendada | Médicos primários |
| --- | --- | --- |
| Adicionar o trading a um produto já existente | Embedded API / SDK Sistema de Negociação | SDKs, Desenvolvedores |
| Melhorar a profundidade do mercado e a qualidade da execução | Soluções Institucionais de Liquidez | Trading, Desenvolvedores |
| Lance rapidamente uma bolsa de marca | Sistema de Troca de Marca Branca | Soluções, Recursos |
| Prepare-se para operações reguladas | Licenciamento de Conformidade e Consultoria | Segurança e Conformidade |

<h2 id="how-the-solutions-connect">Como as soluções se conectam</h2>

A maioria das implementações de parceiros combina mais de uma capacidade 6MM . Uma exchange white-label pode usar liquidez institucional, suporte à conformidade e integrações API . Um parceiro comercial embarcado pode começar com o Trading Widget SDK e depois adicionar fluxos de Agent SDK backend, processamento de webhooks e recursos operacionais.
