Esta seção foi escrita para produto, operações, suporte e educação para usuários finais. Para campos API , sinais e detalhes de integração no backend, use as seções Desenvolvedores e SDK .

<h2 id="before-trading">Antes das negociações</h2>

- Confirmar que o usuário entra por meio de um parceiro autorizado ou 6MM entrada incorporada.
- Certifique-se de que os fundos estejam disponíveis na conta correta antes de fazer pedidos.
- Compreender o comportamento de alavancagem, margem, liquidação e taxas de investimento.
- Comece com posições pequenas ao aprender um novo mercado ou modo de negociação.
- Usar TP / SL e ordens apenas de redução quando apropriado para controle de risco.
