Use este modelo ao preparar uma nova integração ou ao mover uma integração existente para produção.

<h2 id="partner-information">Informações sobre parceiros</h2>

| Campo | Descrição |
| --- | --- |
| Nome do parceiro | Nome legal ou de projeto usado para a integração. |
| Tipo de produto | App, carteira, portal de corretores, exchange white-label, plataforma institucional ou outra. |
| Contatos primários | Contatos de negócios, técnicos, operações e emergências. |
| Regiões de lançamento | Países ou regiões onde a integração será exposta. |

<h2 id="technical-information">Informações técnicas</h2>

| Campo | Descrição |
| --- | --- |
| Domínios frontend | Domínios que carregam o widget ou as páginas de entrada. |
| Domínios backend | Domínios de servidor usados para chamadas Agent SDK ou API . |
| Webhook URL | Endpoint de webhook de produção e requisitos esperados IP lista de permissões. |
| Escopo de integração | Trading Widget, Agent SDK, REST API, WebSocket, sistema white label ou integração de liquidez. |

<h2 id="operational-information">Informações operacionais</h2>

- Data prevista de lançamento.
- Tráfego esperado ou faixa de usuários ativos.
- Responsável pelo horário de suporte e escalonamento.
- Monitorar o proprietário e o contato do incidente.

<h2 id="security-and-review-information">Informações de segurança e revisão</h2>

- Método de autenticação e escopo de permissões API Key .
- Armazenamento secreto, proprietário da rotação e IPs de fonte aprovados.
- Verificação de assinatura de Webhook e design de idempotência.
- Proprietários de registro, monitoramento, reconciliação, rollback e resposta a incidentes.
- Mercados-alvo, tipo de usuário, modelo de custódia e a entidade responsável pelas obrigações voltadas ao usuário.

Não inclua segredos de produção, tokens de acesso completo, chaves privadas ou dados de usuário não censurados neste modelo.

Use a [checklist de lançamento em produção](/pt-BR/resources/production-launch-checklist) para aprovação final e o [template de solicitação de suporte](/pt-BR/resources/support-request-template) para escalonamento de problemas.
