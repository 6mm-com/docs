<h2 id="service-endpoints">Xizmat nuqtalari</h2>

| Turi      | Oxirgi nuqta              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="time-and-numeric-values">Vaqt va son qiymatlari</h2>

* Agar boshqacha ko'rsatilmagan bo'lsa, vaqt maydonlari Unix millisekund vaqt tamg'asidir.
* Kunlik statistika, balans snapshotlari va savdo hajmi statistikasi standart ravishda UTC kun chegaralaridan foydalanadi.
* Miqdori, narxi, miqdori va tezligi kabi aniqlikka sezgir maydonlar string shaklida uzatiladi.
* `orderId`, `conditionId`va `strategyId` kabi katta butun sonli identifikatorlar JSONda satrlar sifatida qaytariladi.

<h2 id="response-format">Javob formati</h2>

Muvaffaqiyatli javob:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Xatolik javobi:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Izohlar:

* Biznes xatolari odatda yagona JSON tuzilmasini qaytaradi. Integratorlar avval `code` tekshirishi kerak.
* Autentifikatsiyadagi xatoliklar HTTP `401`qaytishi mumkin ; Tezlik cheklovi HTTP `429`qaytishi mumkin.
* So'rov sarlavhasiga `X-Request-ID` yuborishingiz mumkin. Server uni javobda `requestId` sifatida qaytaradi.
