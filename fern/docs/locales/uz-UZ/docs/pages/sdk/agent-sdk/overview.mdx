Bu 6MM Agent SDK hamkor orqa tomon xizmatlari uchun mo'ljallangan, ular imzolash va so'rovlarni noldan boshqarishni amalga oshirmasdan imzolangan Agent APIs chaqirishi kerak. U brauzer, mobil yoki ommaviy ish stoli kodida ishlamasligi kerak, chunki integratsiyada hamkor API maxfiy ishlatiladi.

<h2 id="when-to-use-the-agent-sdk">Qachon Agent SDK</h2>

Backendingiz hamkor foydalanuvchini bog'lash, aktivlarni tasdiqlangan ish jarayonidan o'tkazish, savdo yozuvlarini so'rov qilish, o'rnatilgan savdo yozuvini yaratish yoki webhook bildirishnomalarini tekshirish URLkerak bo'lganda Agent SDK foydalaning. [Trading Widget SDK](/uz/sdk/trading-widget/overview) ni alohida ishlating, agar hamkor frontend savdo interfeysini ko'rsatishi kerak bo'lsa.

<h2 id="common-configuration">Umumiy konfiguratsiya</h2>

| Kalit | Misol | Tavsif |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Agent API xizmat URL orqada slashsiz. |
| agentCode | AGENT001 | Hamkor agent kodi. |
| apiSecret | sizning-api-siringiz- | API imzo sirini faqat orqa fonda saqlaydi. |
| defaultCurrency | USDT | Transfer va hisob uchun standart valyuta APIs. |
| webhookUrl | https://partner.example.com/6mm/webhook | Webhook bildirishnomalari uchun hamkor endpoint 6MM . |

<h2 id="typical-integration-flow">Oddiy integratsiya oqimi</h2>

1. Hamkor frontendi foydalanuvchini sherikning o'z hisob tizimi orqali autentifikatsiya qiladi.
2. Hamkor orqa tizimi foydalanuvchini barqaror hamkor tomonidagi identifikatorga xaritalaydi.
3. Orqa tizim Agent SDK `agentCode` va himoyalangan API sirini chaqiradi.
4. SDK imzo qo'yib, Agentga so'rov yuboradi API .
5. Orqa fond qaytarilgan biznes identifikatorini saqlaydi va keyingi webhooklarni idempot tarzda qayta ishlaydi.
6. Frontend faqat qisqa muddatli natija yoki kirish ma'lumotlarini oladi.

<h2 id="production-checklist">Ishlab chiqarish ro'yxati</h2>

- `apiSecret` manba kodidan emas, backend maxfiy menejerdan yuklanadi.
- Rivojlanish, sahnalashtirish va ishlab chiqarish qobiliyatlarini alohida saqlash.
- Barqaror hamkor foydalanuvchi xaritasi va noyob biznes buyurtma identifikatorlaridan foydalanish.
- Vaqt tugagan so'rov holatini tekshirayotganda asl identifikatorni saqlang.
- Webhook imzolarini tekshirish va qayta ishlangan hodisa identifikatorlarini saqlash.
- Loglardan sirlar va imzolarni yashirish, lekin qo'llab-quvvatlash uchun so'rov IDlarini saqlab qolish.
