<h2 id="request-format">Sorğu Formatı</h2>

| Yerləşmə | Sahə       | Tələb olunur            | Təsvir                                   |
| -------- | ----------- | ------------------- | --------------------------------------------- |
| Başlıq   | `X-API-KEY` | Bəli                 | `apiKey` API Key yaradıldıqda geri qaytarılır |
| Sorğu    | `timestamp` | Bəli                 | Unix millisekund zaman möhürü                    |
| Sorğu    | `signature` | Bəli                 | HMAC-SHA256 imzası, kiçik hərfli altıbucaqlı sim   |
| Kuzov     | JSON        | Son nöqtədən asılıdır | POST / PUT / DELETE tələb bədəni              |

<h2 id="signature-payload">İmza Yükü</h2>

```
payload = queryStringWithoutSignature + requestBody
signature = HMAC-SHA256(apiSecret, payload)
```

Əsas qaydalar:

* `timestamp` Unix millisekund zaman möhürü olmalıdır. Server tolerantlıq pəncərəsi ±10 saniyədir.
* `signature` URL sorğu sətirinə yerləşdirilir, lakin imza yükünə daxil edilmir.
* Server orijinal sorğu sətirini yoxlayır `signature`; sorğu parametrlərini yenidən sıralamır.
* İmzalama üçün istifadə olunan sorğu parametr sırası faktiki sorğu ilə uyğun gəlməlidir URL.
* Əgər sorğu bədəni mövcuddursa, imzalamaq üçün istifadə olunan JSON sətiri faktiki ötürülən bədənlə tam uyğun gəlməlidir.
* Sifarişlə bağlı yollar imza təkrar yoxlamaları aparır. Eyni imzanı qısa müddət ərzində təkrar istifadə etmək `Signature replay detected`qaytarır.

<h2 id="server-time">Server Vaxtı</h2>

```http
GET /v1/time
```

Cavab nümunəsi:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "timestamp": 1780473256,
    "timestampMs": 1780473256708,
    "iso": "2026-06-03T07:54:16Z",
    "timezone": "UTC"
  },
  "requestId": "req-7cad3113"
}
```

Müştərilər `timeOffsetMs = serverTimestampMs - localTimestampMs`hesablamalıdır, sonra sonrakı imzalanmış sorğular üçün `timestamp = nowMs + timeOffsetMs` istifadə etməlidirlər. Server `Timestamp outside of tolerance window`qaytararsa, dərhal vaxtı yenidən sinxronizasiya edib imzanı yenidən yaratmalıdır.

<h2 id="python-signing-example">Python İmzalama Nümunəsi</h2>

```python
import hashlib
import hmac
import json
import time
from urllib.parse import urlencode

import requests

BASE_URL = "https://api.6mm.com"
API_KEY = "YOUR_API_KEY"
API_SECRET = "YOUR_API_SECRET"
TIME_OFFSET_MS = 0

def sign(payload: str) -> str:
    return hmac.new(
        API_SECRET.encode("utf-8"),
        payload.encode("utf-8"),
        hashlib.sha256,
    ).hexdigest()

def sync_time_offset():
    global TIME_OFFSET_MS
    before = int(time.time() * 1000)
    resp = requests.get(f"{BASE_URL}/v1/time", timeout=5)
    after = int(time.time() * 1000)
    resp.raise_for_status()

    server_ts = int(resp.json()["data"]["timestampMs"])
    local_midpoint = (before + after) // 2
    TIME_OFFSET_MS = server_ts - local_midpoint

def signed_request(method: str, path: str, params=None, body=None):
    params = dict(params or {})
    params["timestamp"] = str(int(time.time() * 1000) + TIME_OFFSET_MS)

    query_string = urlencode(params)
    body_string = ""
    if body is not None:
        body_string = json.dumps(body, separators=(",", ":"), ensure_ascii=False)

    signature = sign(query_string + body_string)
    url = f"{BASE_URL}{path}?{query_string}&signature={signature}"
    headers = {
        "X-API-KEY": API_KEY,
        "Content-Type": "application/json",
    }
    resp = requests.request(method, url, headers=headers, data=body_string if body is not None else None, timeout=10)
    resp.raise_for_status()
    return resp.json()

sync_time_offset()
print(signed_request("GET", "/v1/private/order/current", {"symbol": "BTCUSDT"}))
```
