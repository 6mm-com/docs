<h2 id="install">I-install</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Pag-access sa pakete**
>
> 6MM nagbibigay ng aprubadong pangalan ng Composer package, repository, at bersyon sa panahon ng partner onboarding. Hindi dapat ipalagay na umiiral ang package sa public Packagist.

<h2 id="before-you-start">Bago ka magsimula</h2>

- Kumpirmahin ang Agent API base URL gamit ang 6MM.
- I-load ang apiSecret mula sa mga environment variable o secret management.
- Panatilihin SDK paggamit sa loob lamang ng backend services.
- Ihanda ang idempotent handling para sa transfer at webhook flows.

<h2 id="initialize-client">I-initialize ang kliyente</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Backend lamang**
>
> Ang PHP SDK ay pumipirma ng Agent API requests at hindi dapat ma-expose sa pamamagitan ng public source code o frontend runtime environments.

<h2 id="example-transfer-funds-in">Halimbawa: maglipat ng pondo sa</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Gamitin ang decimal strings para sa mga halaga at panatilihin ang orihinal na agentOrderNo kapag muling sinusubukan o tinatanong ang transfer status.
