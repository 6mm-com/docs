<h2 id="method-summary">Buod ng Paraan</h2>

| Pamamaraan | Layunin |
| --- | --- |
| destroy() | Alisin ang iframe at i-release event listeners. |
| getState() | Basahin ang kasalukuyang estado ng SDK lifecycle. |
| whenReady() | Maghintay hanggang matapos ang initialization ng iframe. |
| setSymbol(simbolo) | Palitan ang trading pair sa loob ng iframe. |
| setTheme(tema) | I-update ang iframe theme parameter. |
| setLocale(lokasyon) | Palitan ang wika ng iframe. |
| setSize(lapad, taas) | I-update ang sukat ng iframe. |
| reload() | I-reload ang kasalukuyang iframe. |
| refreshAuth(dahilan) | I-trigger ang widget auth refresh flow. |
| setTokenProvider(tagapagbigay) | Palitan ang provider na ginagamit ng partner-token mode. |
| on(event, handler) | Mag-subscribe sa runtime events at makatanggap ng unsubscribe function. |

<h2 id="destroy">destroy()</h2>

Tanggalin ang iframe, linisin ang mga listener, at mag-emit ng destroyed nang isang beses para sa kasalukuyang instance.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Basahin ang kasalukuyang lifecycle state ng widget instance.

```js
const state = widget.getState()
```

Kasama sa mga return value ang loading, authentication, ready, error, at destroyed.

<h2 id="whenready">whenReady()</h2>

Hintayin na matapos ang initialization ng iframe bago patakbuhin ang dependent UI logic.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(simbolo)</h2>

Ilipat ang trading pair sa loob ng iframe. Kung ang iframe ay nag-i-initialize pa, ang SDK ay mag-queue ng command at ipapadala ito kapag handa na.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(tema)</h2>

I-update ang theme parameter na ginagamit ng embedded trading iframe.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(lokasyon)</h2>

Palitan ang wika ng iframe. Ang mga suportadong halaga ay en, en-US, at zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(lapad, taas)</h2>

I-update ang iframe DOM size at abisuhan ang iframe tungkol sa bagong outer size. Ang mga numeric na halaga ay kino-convert sa px.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">reload()</h2>

I-reload ang kasalukuyang iframe at hintayin itong mag-initialize muli.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(dahilan)</h2>

Hilingin sa iframe na i-refresh ang kasalukuyang authentication flow. Ang opsyonal na reason value ay ipinapasa para sa logging at flow control.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(tagapagbigay)</h2>

Palitan ang tokenProvider na ginagamit ng partner-token mode. Tatawagan ng SDK ang provider kapag humiling ang iframe ng bagong embed token.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">on(event, handler)</h2>

Mag-subscribe sa runtime event. Ang returned function ay nag-aalis ng listener.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
