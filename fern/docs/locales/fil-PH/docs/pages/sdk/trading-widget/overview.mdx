<h2 id="responsibility-split">Hati ng Responsibilidad</h2>

| Lugar | May-ari | Mga Tala |
| --- | --- | --- |
| Paglikha ng lalagyan | Frontend ng partner | Magbigay ng nakikitang elemento na may tahasang lapad at taas. |
| Paglikha ng iframe | Trading Widget SDK | Ang SDK ang lumilikha at namamahala sa iframe. |
| Trading UI | 6MM iframe | K-line, order book, order form, posisyon, order, at account data na tumatakbo sa loob ng iframe. |
| Mga kontrol sa pagpapakita | Trading Widget SDK + 6MM iframe | Ang PC embed header at bottom ticker ay nakatago bilang default. Maaaring gamitin ng mga kasosyo ang `display` upang ipakita ang mga shell area o itago ang mga high-level trading container. |
| Tseke sa pag-login ng partner | Partner backend | I-validate ang partner user session bago magbigay ng auth credentials. |
| Pag-isyu ng Embed token | Partner backend + Agent API | Inirerekomenda para sa partner-token mode. |

<h2 id="versioning">Pag-aayos ng Bersyon</h2>

Nanatiling matatag ang public integration path sa ilalim ng v1 script URL. Kasama sa kasalukuyang v1 capability set ang partner-token, tokenProvider, entryUrlProvider, display controls, lifecycle events, instance methods, at order events.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Kailan gagamitin ang widget</h2>

Pumili Trading Widget kapag kailangan ng partner ng kumpletong trading interface sa loob ng umiiral na web product. Gamitin ang REST API at WebSocket documentation kapag gumagawa at nagpapanatili ng fully custom trading interface.

<h2 id="implementation-path">Landas ng Implementasyon</h2>

1. Sundin ang [Trading Widget Quick Start](/fil/sdk/trading-widget/quick-start) upang i-load ang script at gumawa ng nakikitang lalagyan.
2. I-configure ang [partner-token authentication](/fil/sdk/trading-widget/authentication) sa pamamagitan ng partner backend.
3. Idagdag ang kinakailangang [options and events](/fil/sdk/trading-widget/options-events).
4. Gamitin ang [instance methods](/fil/sdk/trading-widget/instance-methods) para sa lifecycle at runtime controls.
