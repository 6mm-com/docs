Ang kalidad ng likwididad ay nakikita ng mga gumagamit sa pamamagitan ng lalim, spread, bilis ng pagpapatupad, at pagiging maaasahan ng order. Para sa mga partner platform, madalas na tinutukoy ng mga indicator na ito kung sapat ang tiwala ng mga gumagamit sa isang merkado upang mag-trade nang paulit-ulit.

<h2 id="what-to-evaluate">Ano ang dapat suriin</h2>

| Tagapagpahiwatig | Bakit ito mahalaga |
| --- | --- |
| Lalim ng pag-order ng libro | Tumutulong sa mas malalaking order na maisagawa nang mas kaunti ang epekto sa presyo. |
| Bid-ask spread | Nakakaapekto sa nakikitang trading cost bago maglagay ng order. |
| Maaasahan ng fill | Tinutukoy kung ang mga order ng user ay natatapos nang predictable habang aktibo ang mga merkado. |
| Paghawak ng Volatility | Pinapanatili ang matatag na pag-uugali sa pangangalakal sa mabilis na paggalaw ng merkado. |

<h2 id="how-6mm-supports-liquidity-quality">Paano sinusuportahan ng 6MM ang kalidad ng likwididad</h2>

- Pinagsasama-sama ang mga pinagkukunan ng likwididad at ipinapamahagi ang lalim ng merkado sa mga senaryo ng kasosyo.
- Sinusuportahan ang awtomatikong liquidity provision para sa mga suportadong trading market.
- Tumutulong bawasan ang pira-pirasong pag-uugali sa merkado sa panahon ng paglulunsad, paglago, at mataas na volume.
- Gumagamit ng risk controls kaya ang kalidad ng pag-quote ay hindi kapalit ng operational stability.

<h2 id="operational-focus">Pokus sa operasyon</h2>

Subaybayan ang kalidad ng likwididad kasama ang pag-uugali ng mga gumagamit. Ang mataas na page views nang walang order ay maaaring magpahiwatig ng mga isyu sa tiwala o pagkalat ng mga isyu. Ang mga pagtatangka sa mataas na order na mababa ang pagkumpleto ay maaaring magpahiwatig ng lalim ng merkado, panganib, o mga isyu sa workflow ng account.
