<h2 id="public-endpoints">Mga Pampublikong Endpoint</h2>

| Endpoint                   | Pamamaraan | Landas                                        | Paglalarawan                                                    |
| -------------------------- | ------ | ------------------------------------------- | -------------------------------------------------------------- |
| Bersyon ng Serbisyo            | GET    | `/v1/version`                               | Kunin ang impormasyon tungkol sa bersyon ng serbisyo                                |
| Oras ng server                | GET    | `/v1/time`                                  | Kumuha ng oras sa server                                                |
| Pag-login ng user                 | POST   | `/v1/public/user/login`                     | Gamitin ang username at password upang makuha ang `accessToken`              |
| I-refresh ang token              | POST   | `/v1/public/user/refresh-token`             | I-refresh ang estado ng pag-login gamit ang Cookie                                 |
| Agent Ticket exchange      | POST   | `/v1/public/agent-sso/exchange-ticket`      | Ipagpalit ang tiket ng pagpasok ng ahente para sa estado ng pag-login              |
| Agent Embed Token exchange | POST   | `/v1/public/agent-sso/exchange-embed-token` | Magpalit ng embedded trading short-lived token para sa login state |
| Konfigurasyon ng simbolo       | GET    | `/v1/public/market/symbols`                 | Kumuha ng mga simbolo, mga patakaran sa kalakalan, at configuration ng fee tier         |
| Konfigurasyon ng rate ng pondo | GET    | `/v1/public/market/funding-rate`            | Query na konfigurasyon ng rate ng pondo                               |
| Kasalukuyang antas ng pondo       | GET    | `/v1/public/market/funding-rate/current`    | I-paginate ang kasalukuyang mga rate ng pondo                                 |
| Kasaysayan ng rate ng pondo       | GET    | `/v1/public/market/funding-rate/history`    | Kasaysayan ng query funding rate                                     |
| Klines                     | GET    | `/v1/public/market/klines`                  | I-query ang presyo ng kalakalan, presyo ng index, o presyo ng marka Klines           |
| PnL leaderboard            | GET    | `/v1/public/leaderboard/pnl`                | Query 7 / 30 / 90 araw PnL leaderboard                          |

<h2 id="private-user-endpoints">Mga Pribadong User Endpoint</h2>

Maliban kung may ibang tinukoy, ang mga sumusunod na endpoint ay maaaring gumamit ng JWT o API Key signing.

| Endpoint                 | Pamamaraan | Landas                                      | Pahintulot   | Paglalarawan                                 |
| ------------------------ | ------ | ----------------------------------------- | ------------ | ------------------------------------------- |
| Impormasyon ng user                | GET    | `/v1/private/user/info`                   | Basahin         | I-query ang kasalukuyang user profile                  |
| Mga asset ng user              | GET    | `/v1/private/user/asset`                  | Basahin         | Query wallet balance at paggamit ng margin       |
| Gumawa ng listenKey         | POST   | `/v1/private/user/listen-key`             | Basahin         | Gumawa ng pribadong WebSocket authentication key |
| I-renew listenKey          | PUT    | `/v1/private/user/listen-key`             | Basahin         | Palawigin ang bisa listenKey                   |
| Isara listenKey          | DELETE | `/v1/private/user/listen-key`             | Basahin         | Isara listenKey                             |
| Mga log ng pagbabago sa account      | GET    | `/v1/private/user/account-change-log`     | Basahin         | Mga tala ng paggalaw ng pondo sa query                 |
| 30-araw na estadistika ng dami | GET    | `/v1/private/user/volume-stats`           | Basahin         | I-query ang kamakailang 30-araw na trading volume at mga bayarin |
| Kasaysayan ng Balanse          | GET    | `/v1/private/user/balance-history`        | Basahin         | Kasaysayan ng query balance                       |
| Pangkalahatang-ideya ng kalakalan           | GET    | `/v1/private/user/trade-overview`         | Basahin         | I-query ang PnL, volume, at trend ng asset          |
| Buod ng pangkalahatang-ideya ng asset   | GET    | `/v1/private/user/asset/overview/summary` | Basahin         | I-query ang mga metrics ng buod ng asset                 |
| Pangkalahatang-ideya ng trend ng asset     | GET    | `/v1/private/user/asset/overview/trend`   | Basahin         | Trend ng query asset                           |
| I-save ang mga paboritong simbolo    | POST   | `/v1/private/user/favorite-symbols`       | Basahin         | I-overwrite ang mga paboritong simbolo                  |
| Kumuha ng mga paboritong simbolo     | GET    | `/v1/private/user/favorite-symbols`       | Basahin         | I-query ang mga paboritong simbolo                      |
| Pag-log out                   | POST   | `/v1/private/user/logout`                 | JWT + Cookie | Linisin ang estado ng pag-login                           |

<h2 id="api-key-management-endpoints">API Key Mga Endpoint ng Pamamahala</h2>

API Key management endpoints ay tumatanggap lamang ng JWT.

| Endpoint            | Pamamaraan | Landas                                  | Paglalarawan                                         |
| ------------------- | ------ | ------------------------------------- | --------------------------------------------------- |
| Gumawa ng API Key      | POST   | `/v1/private/user/api-key/create`     | Gumawa ng API Key; `apiSecret` ibinalik lamang nang isang beses   |
| listahan ng API Key        | GET    | `/v1/private/user/api-key/list`       | I-query ang API Keys ng kasalukuyang user                       |
| Update API Key      | PUT    | `/v1/private/user/api-key/update`     | I-update ang label, mga permiso, IP whitelist, at status |
| Burahin API Key      | POST   | `/v1/private/user/api-key/delete`     | Tanggalin ang tinukoy na API Key                          |
| Tanggalin ang lahat ng API Keys | POST   | `/v1/private/user/api-key/delete-all` | Tanggalin ang lahat ng API Keys ng kasalukuyang user             |

<h2 id="order-endpoints">Order Endpoints</h2>

Ang mga order endpoint ay nangangailangan ng trade permission.

| Endpoint                    | Pamamaraan | Landas                                  | Paglalarawan                                                       |
| --------------------------- | ------ | ------------------------------------- | ----------------------------------------------------------------- |
| Mag-query ng single order          | GET    | `/v1/private/order`                   | Eksaktong query ayon sa `symbol + orderId/clientOrderId`                   |
| Mag-order                 | POST   | `/v1/private/order/place`             | Limitasyon o order sa merkado                                             |
| Maglagay ng order ng kondisyon       | POST   | `/v1/private/order/place-condition`   | Stop loss, take profit, trailing stop, at iba pang mga order ng kondisyon |
| Maglagay ng order ng estratehiya        | POST   | `/v1/private/order/place-strategy`    | OTO / OCO / OTOCO strategy order                                  |
| Maglagay ng batch ng order          | POST   | `/v1/private/order/batch-place`       | Magsumite ng maraming normal na order                                     |
| Kanselahin ang order                | POST   | `/v1/private/order/cancel`            | Kanselahin ang tinukoy na normal order                                   |
| Ayusin ang pag-amyenda                 | POST   | `/v1/private/order/move`              | Baguhin ang normal na presyo at dami ng pending order                    |
| I-edit ang mga order          | POST   | `/v1/private/order/batch-move`        | I-batch na baguhin ang normal na pending orders para sa parehong simbolo            |
| I-batch ang mga order na kanselahin         | POST   | `/v1/private/order/batch-cancel`      | I-batch na kanselahin ang normal na mga order                                        |
| Kanselahin lahat                  | POST   | `/v1/private/order/batch-cancel-all`  | I-batch na kanselahin ang mga order ayon sa uri                                       |
| Kanselahin ang order ng kondisyon      | POST   | `/v1/private/order/cancel-condition`  | Kanselahin ang tinukoy na order ng kondisyon                                |
| Kasalukuyang normal na order       | GET    | `/v1/private/order/current`           | I-query ang kasalukuyang normal na pending orders                               |
| Mga order sa kasalukuyang kondisyon    | GET    | `/v1/private/order/current-condition` | I-query ang kasalukuyang untriggered condition orders                        |
| Mga makasaysayang normal na orden    | GET    | `/v1/private/order/history`           | Pag-paginate ng makasaysayang normal na ayos                                 |
| Mga makasaysayang kalagayan | GET    | `/v1/private/order/history-condition` | Pag-paginate ng mga makasaysayang ayos ng kondisyon                              |
| Mga rekord sa kalakalan               | GET    | `/v1/private/order/trades`            | Mga rekord ng kalakalan na may pahina                                            |
| Detalye ng order ng estratehiya       | GET    | `/v1/private/order/strategy`          | I-query ang order ng estratehiya at mga sub-order                               |

<h2 id="position-endpoints">Ilagay ang mga Endpoint</h2>

Ang mga endpoint ng posisyon ay nangangailangan ng trade permission.

| Endpoint          | Pamamaraan | Landas                               | Paglalarawan                                  |
| ----------------- | ------ | ---------------------------------- | -------------------------------------------- |
| Itakda ang margin mode   | POST   | `/v1/private/position/margin-mode` | Switch isolated / cross margin               |
| Magtakda ng leverage      | POST   | `/v1/private/position/leverage`    | Itakda ang simbolo ng leverage                          |
| Mga setting ng posisyon | GET    | `/v1/private/position/settings`    | Query leverage at margin mode para sa isang simbolo  |
| Kasalukuyang mga posisyon | GET    | `/v1/private/position/positions`   | I-query ang kasalukuyang posisyon                      |
| Kasaysayan ng posisyon  | GET    | `/v1/private/position/history`     | Mag-query ng mga makasaysayang posisyon at isara ang mga rekord |
