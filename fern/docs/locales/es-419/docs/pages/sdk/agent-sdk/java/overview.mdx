<h2 id="runtime">Duración</h2>

| Ítem | Valor |
| --- | --- |
| Versión mínima Java | Java 8+ |
| Herramienta de construcción recomendada | Maven 3.9+ |
| Grupo Maven | `com.sixmm.exchange.sdk` |
| Artefacto Maven | `agent` |
| Etiqueta de fuente documentada | `v0.1.1` |

El repositorio público de GitHub es alojamiento fuente, no un repositorio de dependencias de Maven. Compila e instala el código fuente etiquetado localmente o publica el artefacto aprobado en el repositorio privado de Maven de tu organización antes de usarlo en compilaciones de equipos.

<h2 id="typical-backend-responsibilities">Responsabilidades típicas de backend</h2>

- Validar la sesión de usuario asociada.
- Mapear al usuario socio a agentUserId.
- Vinculación de llamadas antes de los flujos de primera operación o transferencia.
- Llama a createEntryUrl para un SSOcompleto único en el sitio .
- Llamar createEmbedToken para Trading Widget modo de token de compañero.
- Verificar los webhooks de transferencia y procesarlos idempotentemente.

<h2 id="security-and-operational-rules">Reglas de seguridad y operativas</h2>

- Almacenar `apiSecret` solo en un gestor de secretos de backend o en una variable de entorno protegido.
- Mantener sincronizada la hora del servidor porque las solicitudes firmadas contienen marcas de tiempo.
- Tratar `agentOrderNo` como una clave de idempotencia duradera y mantenerla única a nivel global.
- Almacenar `platformUserId` como una cadena y persistir su relación con `agentUserId`.
- Consulta la transferencia original antes de intentarlo de nuevo después de un tiempo de espera o un resultado de red incierto.
