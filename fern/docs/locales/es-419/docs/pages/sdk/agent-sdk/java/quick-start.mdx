<h2 id="install">Instalación</h2>

La fuente pública SDK actualmente documenta `v0.1.1` de etiquetas con estas coordenadas de Maven:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

GitHub no actúa como un repositorio de dependencias de Maven. Instala el código fuente etiquetado localmente antes de resolver la dependencia:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Formaciones de equipo**
>
> Publica el artefacto aprobado en el repositorio Maven de tu organización para CI, pruebas y compilaciones de producción. Confirma la versión aprobada con 6MM antes del despliegue en producción.

Ejemplos de código fuente y uso están disponibles en el repositorio oficial de Java SDK :

[6mm-com/agent-java-sdk](https://github.com/6mm-com/agent-java-sdk)

<h2 id="before-you-start">Antes de que empieces</h2>

- Confirma tu agente de producción API URL base con el equipo 6MM .
- Almacenar apiSecret solo en la gestión de secretos del backend.
- Preparar un mapeo estable entre platformUserId y agentUserId.
- Habilitar registros estructurados alrededor de flujos de enlace, transferencia, orden y webhook.

<h2 id="initialize-client">Inicializar cliente</h2>

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Solo backend**
>
> No inicialices el Agent SDK desde el código del cliente del navegador, móvil o escritorio. El SDK firma solicitudes privilegiadas del Agente API .

<h2 id="example-transfer-funds-in">Ejemplo: transferir fondos en</h2>

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Usa un número de pedido único del lado del socio para cada solicitud de transferencia. Si una solicitud expira, consulta el pedido original antes de crear uno nuevo.
