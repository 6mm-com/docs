Yeni inteqrasiyanı hazırlayarkən və ya mövcud inteqrasiyanı istehsala köçürərkən bu şablondan istifadə edin.

<h2 id="partner-information">Tərəfdaş məlumatları</h2>

| Sahə | Təsvir |
| --- | --- |
| Tərəfdaş adı | İnteqrasiya üçün istifadə olunan hüquqi və ya layihə adı. |
| Məhsul növü | Tətbiq, cüzdan, broker portalı, ağ etiketli birja, institusional platforma və ya digər. |
| Əsas əlaqələr | Biznes, texniki, əməliyyat və təcili əlaqə şəxsləri. |
| Buraxılış bölgələri | İnteqrasiyanın açıq olacağı ölkələr və regionlar. |

<h2 id="technical-information">Texniki məlumat</h2>

| Sahə | Təsvir |
| --- | --- |
| Ön tərəf domenləri | Widget və ya giriş səhifələrini yükləyəcək domenlər. |
| Arxa tərəf domenləri | Server domenləri Agent SDK və ya API zənglər üçün istifadə olunur. |
| Webhook URL | İstehsalat webhook son nöqtəsi və gözlənilən IP icazə siyahısı tələbləri. |
| İnteqrasiya əhatə dairəsi | Trading Widget, Agent SDK, REST API, WebSocket, ağ etiket sistemi və ya likvidlik inteqrasiyası. |

<h2 id="operational-information">Əməliyyat məlumatları</h2>

- Gözlənilən buraxılış tarixi.
- Gözlənilən trafik və ya aktiv istifadəçi diapazonu.
- Dəstək saatları və eskalasiya sahibi.
- Sahibi və hadisə əlaqəsini izləmək.

<h2 id="security-and-review-information">Təhlükəsizlik və baxış məlumatları</h2>

- Autentifikasiya metodu və API Key icazə sahəsi.
- Gizli yaddaş, rotasiya sahibi və təsdiqlənmiş mənbə IP-ləri.
- Webhook imza təsdiqi və idempotensiya dizaynı.
- Qeydiyyat, monitorinq, uzlaşdırma, geri qaytarma və insidentə cavab sahibləri.
- Hədəf bazarlar, istifadəçi növü, saxlanma modeli və istifadəçiyə qarşı öhdəliklərə cavabdeh qurum.

Bu şablonda istehsal sirləri, tam giriş tokenləri, özəl açarlar və ya redaktə olunmamış istifadəçi məlumatları daxil edilməməlidir.

Son təsdiq üçün [istehsalın işə salınma yoxlama siyahısı](/az/resources/production-launch-checklist) və məsələnin eskalasiyası üçün [dəstək sorğusu şablonu](/az/resources/support-request-template) istifadə edin.
