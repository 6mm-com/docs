Qo'llab-quvvatlash bilan bog'lanayotganda, mavjud bo'lsa, quyidagi ma'lumotlarni kiriting.

<h2 id="required-context">Majburiy kontekst</h2>

| Maydon | Misol |
| --- | --- |
| Atrof-muhit | Ishlab chiqarish yoki sahnalashtirish |
| Ta'sirlangan modul | Trading Widget, Agent SDK, REST API, WebSocket, webhook, oq yorliq tizimi |
| Vaqt oralig'i | UTC chiqarilgan vaqt oralig'i |
| Hamkor foydalanuvchi ID | Agar tegishli bo'lsa, hamkor tomonidagi foydalanuvchi identifikatori |
| 6MM xaritalash identifikatori | agentUserId, order ID, request ID yoki webhook event ID |
| Biznesga ta'siri | Ta'sirlangan foydalanuvchilar yoki operatsiyalar soni va muammo davom etayotganmi? |

<h2 id="description-format">Tavsif formati</h2>

-Nima bo'ldi?
- Nima bo'lishini kutganding?
- Uni ko'paytirish mumkinmi?
- So'nggi paytlarda nima o'zgardi?
- Muammo hali ham davom etyaptimi?

<h2 id="attachments">Ilovalar</h2>

- Tegishli so'rov va javob jurnallari.
- Skrinshotlar yoki ekran yozuvlari.
- Webhook yuklamasi va imzo sarlavhalari.
- Trading Widget muammolar uchun brauzer konsolidagi xatolar.

<h2 id="copyable-template">Nusxa ko'chiriladigan shablon</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Tegishli bo'lmagan maydonlarni olib tashlang, lekin imkon qadar UTC vaqt oralig'ini va kamida bitta qidiruv mumkin bo'lgan so'rov yoki biznes identifikatorini saqlang.

<h2 id="redact-sensitive-data">Maxfiy ma'lumotlarni yashirish</h2>

Yubormang:

- Parollar yoki to'liq kirish tokenlari
- API sirlar, shaxsiy kalitlar yoki to'liq imzolar
- Sessiya cookie-fayllari
- To'liq to'lov, shaxs yoki boshqa keraksiz shaxsiy ma'lumotlar

Maydon nomi va qisqa prefiks yoki qo'shimchani faqat support tozalangan qiymatlarni ajratishi kerak bo'lganda saqlang.
