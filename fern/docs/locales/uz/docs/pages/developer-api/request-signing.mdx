<h2 id="request-format">So'rov formati</h2>

| Joylashuvi | Maydon       | Majburiy            | Tavsif                                   |
| -------- | ----------- | ------------------- | --------------------------------------------- |
| Sarlavha   | `X-API-KEY` | Ha                 | `apiKey` API Key yaratilganda qaytarildi |
| So'rov    | `timestamp` | Ha                 | Unix millisekund vaqt tamg'asi                    |
| So'rov    | `signature` | Ha                 | HMAC-SHA256 imzosi, kichik harflar bilan yozilgan olti harfli string   |
| Kuzov     | JSON        | Oxirgi nuqtaga bog'liq | POST / PUT / DELETE so'rov tanasi              |

<h2 id="signature-payload">Imzo yuklamasi</h2>

```
payload = queryStringWithoutSignature + requestBody
signature = HMAC-SHA256(apiSecret, payload)
```

Asosiy qoidalar:

* `timestamp` Unix millisekund vaqt tamg'asi bo'lishi kerak. Server chidamlilik oynasi ±10 soniya.
* `signature` URL so'rov qatoriga joylashtiriladi, lekin imzo yuklamasiga kiritilmaydi.
* Server asl so'rov qatorini olib tashlagandan so'ng tekshiradi `signature`; u so'rov parametrlarini qayta tartiblamaydi.
* Imzolash uchun ishlatiladigan so'rov parametr tartibi haqiqiy so'rov URLmos kelishi kerak.
* Agar so'rov tanasi mavjud bo'lsa, imzolash uchun ishlatiladigan JSON satr haqiqiy uzatilgan tanaga aniq mos kelishi kerak.
* Tartibga bog'liq yo'llar imzo qayta ko'rish tekshiruvlarini bajaradi. Bir xil imzoni qisqa vaqt ichida qayta ishlatish natijani `Signature replay detected`beradi.

<h2 id="server-time">Server vaqti</h2>

```http
GET /v1/time
```

Javob misoli:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "timestamp": 1780473256,
    "timestampMs": 1780473256708,
    "iso": "2026-06-03T07:54:16Z",
    "timezone": "UTC"
  },
  "requestId": "req-7cad3113"
}
```

Mijozlar `timeOffsetMs = serverTimestampMs - localTimestampMs`hisoblashlari, so'ngra keyingi imzolangan so'rovlar uchun `timestamp = nowMs + timeOffsetMs` ishlatishlari kerak. Agar server `Timestamp outside of tolerance window`qaytarsa, darhol vaqtni qayta sinxronlashtiring va imzoni tiklang.

<h2 id="get-signing-example">GET Imzolash misoli</h2>


Imzo yuklamasi:

```
symbol=BTCUSDT&timestamp=1772710377808
```

<h2 id="python-signing-example">Python imzolash misoli</h2>

```python
import hashlib
import hmac
import json
import time
from urllib.parse import urlencode

import requests

BASE_URL = "https://api.6mm.com"
API_KEY = "YOUR_API_KEY"
API_SECRET = "YOUR_API_SECRET"
TIME_OFFSET_MS = 0

def sign(payload: str) -> str:
    return hmac.new(
        API_SECRET.encode("utf-8"),
        payload.encode("utf-8"),
        hashlib.sha256,
    ).hexdigest()

def sync_time_offset():
    global TIME_OFFSET_MS
    before = int(time.time() * 1000)
    resp = requests.get(f"{BASE_URL}/v1/time", timeout=5)
    after = int(time.time() * 1000)
    resp.raise_for_status()

    server_ts = int(resp.json()["data"]["timestampMs"])
    local_midpoint = (before + after) // 2
    TIME_OFFSET_MS = server_ts - local_midpoint

def signed_request(method: str, path: str, params=None, body=None):
    params = dict(params or {})
    params["timestamp"] = str(int(time.time() * 1000) + TIME_OFFSET_MS)

    query_string = urlencode(params)
    body_string = ""
    if body is not None:
        body_string = json.dumps(body, separators=(",", ":"), ensure_ascii=False)

    signature = sign(query_string + body_string)
    url = f"{BASE_URL}{path}?{query_string}&signature={signature}"
    headers = {
        "X-API-KEY": API_KEY,
        "Content-Type": "application/json",
    }
    resp = requests.request(method, url, headers=headers, data=body_string if body is not None else None, timeout=10)
    resp.raise_for_status()
    return resp.json()

sync_time_offset()
print(signed_request("GET", "/v1/private/order/current", {"symbol": "BTCUSDT"}))
```
