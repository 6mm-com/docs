Savdo qo'llanmasi foydalanuvchilarning kirish va moliyalashtirishdan doimiy shartnoma savdosiga qanday o'tishini, shuningdek, asosiy savdo qoidalari buyruqlar, pozitsiyalar, to'lovlar va likvidatsiya xavfiga qanday ta'sir qilishini tushuntiradi.

Ushbu bo'lim mahsulot, operatsiyalar, qo'llab-quvvatlash va yakuniy foydalanuvchi ta'limi uchun yozilgan. API maydonlar, imzolash va backend integratsiyasi tafsilotlari uchun Developers va SDK bo'limlaridan foydalaning.

<h2 id="before-trading">Savdodan oldin</h2>

- Foydalanuvchi ruxsat etilgan hamkor yoki o'rnatilgan 6MM orqali kirishini tasdiqlash.
- Buyurtma berishdan oldin mablag'lar to'g'ri hisobda ekanligiga ishonch hosil qiling.
- Leverage, marja, likvidatsiya va moliyalashtirish to'lovlari xulq-atvorini tushunish.
- Yangi bozor yoki savdo rejimini o'rganayotganda kichik pozitsiya o'lchamlaridan boshlang.
- TP / SL dan foydalaning va xavfni nazorat qilish uchun zarur bo'lsa, faqat qisqartirish buyruqlari.
