La Guía de Trading explica cómo los usuarios pasan de acceder y financiar a la negociación con contratos perpetuos, y cómo las reglas básicas de trading afectan a órdenes, posiciones, comisiones y riesgo de liquidación.

Esta sección está escrita para producto, operaciones, soporte y educación para el usuario final. Para API campos, firmas y detalles de integración backend, utilice las secciones Desarrolladores y SDK .

<h2 id="before-trading">Antes de operar</h2>

- Confirmar que el usuario accede a través de un socio autorizado o 6MM entrada integrada.
- Asegurarse de que los fondos estén disponibles en la cuenta correcta antes de realizar pedidos.
- Comprender el apalancamiento, el margen, la liquidación y el comportamiento de las comisiones de financiación.
- Comienza con tamaños de posición pequeños al aprender un nuevo mercado o modo de trading.
- Utilizar TP / SL y órdenes solo de reducción cuando sea apropiado para el control de riesgos.
