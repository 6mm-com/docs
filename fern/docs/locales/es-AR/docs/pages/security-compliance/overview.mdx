La documentación de seguridad y cumplimiento está redactada para equipos socios que preparan el uso en producción de la infraestructura de 6MM trading. Conecta la arquitectura de seguridad, controles de API/SDK , preparación de cumplimiento, límites legales y preparación para el lanzamiento en un único camino de revisión.

<h2 id="documentation-map">Mapa de documentación</h2>

| Área | Propósito |
| --- | --- |
| Arquitectura de seguridad | Entiende cómo se protege la infraestructura de trading, el acceso APISDK y las operaciones de los socios. |
| API y seguridad de webhooks | Proteger las integraciones backend mediante firmas, almacenamiento secreto y procesamiento de idempotentes. |
| Preparación para el cumplimiento | Preparar el contexto de soporte de licencias, las comprobaciones de lanzamiento y los controles operativos del lado del socio. |
| Documentos legales | Revisa los términos, la privacidad y los límites de responsabilidad antes del lanzamiento en producción. |

<h2 id="recommended-reading-order">Orden de lectura recomendada</h2>

1. Comienza con la Arquitectura de Seguridad y el Límite de Responsabilidad del Socio.
2. Revisar la gestión API Key , la firma de solicitudes y la idempotencia de Webhook antes de la integración backend.
3. Revisar la Visión General de Cumplimiento y el Soporte de Licencias antes de la preparación para el lanzamiento regional.
4. Revisa las páginas legales y la lista de comprobación de lanzamiento antes de exponer la funcionalidad de trading a los usuarios.
