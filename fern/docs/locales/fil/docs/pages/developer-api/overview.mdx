<h2 id="documentation-areas">Mga Lugar ng Dokumentasyon</h2>

| Lugar | Ano ang saklaw nito |
| --- | --- |
| Pagsasaayos ng integrasyon | Mga address ng serbisyo, mga convention ng kahilingan, hugis ng tugon, at mga mode ng pag-access. |
| Pagpapatunay at seguridad | JWT, API Key permissions, HMAC signing, proteksyon sa replay, at time sync. |
| REST API | Mga pampublikong endpoint, datos ng user/account, mga order, posisyon, at datos sa merkado. |
| WebSocket | Lifecycle ng koneksyon, mga stream ng pampublikong merkado, at mga stream ng pribadong gumagamit. |
| Sanggunian at pag-troubleshoot | Enums, error codes, at mga praktikal na rekomendasyon sa integrasyon. |

<h2 id="production-checklist">Listahan ng produksyon</h2>

- Itago ang API mga sikreto sa backend lang.
- I-sync ang oras ng server bago ang mga signed request.
- Ituring ang lahat ng numeric precision fields bilang mga string maliban kung tahasang sinasabi ng pahina ang kabaligtaran.
- Gamitin ang idempotency, request IDs, at structured logs sa paligid ng order flows.
- Mag-subscribe sa WebSocket streams para sa mga estado na kailangang manatiling napapanahon sa mga operational system.
- Suriin ang mga error code at subukang muli ang pag-uugali bago ilunsad.
