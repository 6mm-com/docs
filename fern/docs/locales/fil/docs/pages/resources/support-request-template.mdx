Kapag nakikipag-ugnayan sa suporta, isama ang impormasyong nasa ibaba kapag available.

<h2 id="required-context">Kinakailangang konteksto</h2>

| Larangan | Halimbawa |
| --- | --- |
| Kapaligiran | Produksyon o pagtatanghal |
| Apektadong module | Trading Widget, Agent SDK, REST API, WebSocket, webhook, white-label system |
| Saklaw ng Panahon | UTC saklaw ng timestamp nang mangyari ang isyu |
| Partner user ID | Partner-side user identifier, kung mahalaga |
| 6MM mapping ID | agentUserId, order ID, request ID, o webhook event ID |
| Epekto sa Negosyo | Bilang ng mga apektadong user o operasyon at kung patuloy pa ang isyu |

<h2 id="description-format">Format ng paglalarawan</h2>

-Anong nangyari?
- Ano ang inaasahan mong mangyayari?
- Pwede ba itong ulitin?
- Ano ang nagbago kamakailan?
- Nangyayari pa ba ang isyu?

<h2 id="attachments">Mga Kalakip</h2>

- Kaugnay na mga log ng kahilingan at tugon.
- Mga screenshot o screen recording.
- Webhook payload at signature headers.
- Mga error sa browser console para sa Trading Widget isyu.

<h2 id="copyable-template">Maaaring kopyahin na template</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Tanggalin ang mga field na hindi mahalaga, ngunit panatilihin ang UTC time range at kahit isang searchable request o business identifier hangga't maaari.

<h2 id="redact-sensitive-data">I-redact ang sensitibong datos</h2>

Huwag magpadala:

- Mga password o full access tokens
- API mga lihim, pribadong susi, o kumpletong pirma
- Session cookies
- Buong bayad, pagkakakilanlan, o iba pang hindi kinakailangang personal na datos

Panatilihin ang pangalan ng field at maikling prefix o suffix lamang kapag kailangang pag-ibahin ng suporta ang mga sanitized na halaga.
