<h2 id="recommended-mode-partner-token">Inirerekomendang mode: partner-token</h2>

Iniiwasan ng partner-token ang paglalagay ng maiikling token sa mga URL at pinananatili ang apiSecret sa backend ng partner.

```js
const widget = TradingWidget.create('#trading-widget', {
  baseUrl: 'https://app.6mm.com',
  auth: {
    mode: 'partner-token',
    tokenProvider: async ({ channelId, symbol, reason }) => {
      const resp = await fetch('/api/trading/embed-token', {
        method: 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ channelId, symbol, reason }),
      })

      if (!resp.ok) {
        throw new Error('Failed to request embed token')
      }

      return resp.json()
    },
  },
})
```

<h2 id="backend-flow">Daloy ng backend</h2>

```text
1. Partner frontend receives auth_request from the iframe.
2. SDK calls tokenProvider.
3. Partner frontend calls its own backend.
4. Partner backend validates the partner session.
5. Partner backend calls 6MM Agent API or Java SDK createEmbedToken.
6. SDK sends embedToken to the iframe through postMessage.
7. iframe exchanges embedToken for a 6MM access token.
8. iframe continues initialization and emits ready.
```

<h2 id="tokenprovider-contract">kontrata ng tokenProvider</h2>

| Larangan | Direksyon | Paglalarawan |
| --- | --- | --- |
| channelId | SDK -> Partner backend | Natatanging widget session identifier. Dapat ipasa ito ng backend sa createEmbedToken. |
| simbolo | SDK -> Partner backend | Kasalukuyang hinihiling na simbolo ng kalakalan. Gamitin ito upang i-scope ang token kapag kinakailangan. |
| dahilan | SDK -> Partner backend | Bakit humihiling ang SDK ng token, tulad ng initial load o refresh. |
| embedToken | Partner backend -> SDK | Panandaliang token na nilikha ng Agent SDK o Agent API. |
| expireAt | Partner backend -> SDK | Token expiration timestamp na ibinalik ng 6MM. |

<h2 id="failure-handling">Paghawak ng Pagkabigo</h2>

| Kondisyon | Inirerekomendang paghawak |
| --- | --- |
| Nag-expire ang partner session | Ibalik ang 401 mula sa partner endpoint at hilingin sa user na mag-sign in muli. |
| Pansamantalang nabigo ang paglikha ng token | Maglagay ng error sa tokenProvider at hayaang lumabas ang widget ng authentication error. |
| channelId hindi pagkakatugma | Tanggihan ang kahilingan at muling likhain ang widget instance. |
| Hindi pinapayagan ang user na mag-trade | Ibalik ang partner-controlled error at huwag gumawa ng embed token. |

<h2 id="compatibility-mode-agent-sso">Compatibility mode: agent-sso</h2>

Pinananatili ng agent-sso ang lumang /agent-entry ticket flow. Mas gusto ang partner-token para sa mga bagong integrasyon.

```js
const widget = TradingWidget.create('#trading-widget', {
  baseUrl: 'https://app.6mm.com',
  auth: {
    mode: 'agent-sso',
    entryUrlProvider: async ({ redirectPath }) => {
      const resp = await fetch('/api/trading-entry', {
        method: 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ redirectPath }),
      })
      const data = await resp.json()
      return data.webUrl
    },
  },
})
```
