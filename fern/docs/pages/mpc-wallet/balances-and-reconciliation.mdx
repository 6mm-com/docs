Use the balance view to see the current funds position and transaction views to explain how it changed. Enterprise workspaces can expose several views, depending on product and role.

<span data-sixmm-canonical-anchor="use-the-right-record-for-each-question" aria-hidden="true"></span>

## Use the right record for each question

| Question | Where to look |
| --- | --- |
| What amount can be used for payment? | Check the available balance for the intended wallet and asset. Review amounts held or frozen separately. |
| Did an incoming payment receive credit? | Check the deposit record and match the network, asset, amount, and receiving details. |
| Has an outgoing payment reached a known result? | Check the withdrawal record and its chain confirmation where available. |
| Which entries affected the business balance? | Use the ledger view if the workspace provides it. Check the chain activity view for the on-chain movement. |

<span data-sixmm-canonical-anchor="reconcile-a-payment-period" aria-hidden="true"></span>

## Reconcile a payment period

1. Identify the workspace, network, asset and business period you are checking.
2. Match deposit and withdrawal records to the business order or payment reference you kept.
3. Account for fees and internal collection separately. Record any balance held for a pending request separately from a completed transfer.
4. Investigate unmatched entries using the transaction reference and latest status. Keep a pending item open until the result is established.

For example, if an outgoing transaction appears on-chain while the withdrawal record is still waiting for confirmation, keep the original business request open and follow that record. Use the final status and the corresponding amounts to close reconciliation.
