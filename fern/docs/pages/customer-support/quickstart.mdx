## Prepare your workspace

Open [the console](https://csadmin.6mm.com/) with the account provided for your tenant. Complete the sign-in and security setup requested by the login screen. If you cannot access a menu, ask your tenant administrator to check the role.

1. **Set up the team.** In Agent Management, create the required roles and agent accounts. Check who may view conversations, edit content and manage settings.
2. **Prepare business knowledge.** In Content Management, create categories and articles for account access, deposit and withdrawal procedures, trading rules, fees and support escalation. Review and publish the material users should see.
3. **Configure automation.** Enable the required intelligent services in System Settings. In Bot Configuration, review FAQ, vector matching, AI replies and identity responses.
4. **Prepare languages.** Choose the main and default languages, translate the help content and review terminology, numbers and links.
5. **Connect your website.** Add the site to Website Integration and copy the tenant's generated embed code. Use your own App Key.
6. **Test before launch.** Use Bot Configuration's flow test and then the real visitor entry. Check known questions, follow-ups, another language, human support and ticket submission.

## Launch acceptance

| Test | Expected result |
| --- | --- |
| A documented trading rule | The reply preserves conditions, numbers and exceptions |
| An unknown account-specific issue | No invented balance or transaction result; the user gets an appropriate next step |
| A foreign-language question | A suitable reply or agent translation in the enabled language |
| Human support unavailable | The configured alternative, such as a ticket, is available |
| Restricted agent account | Only permitted menus and records are accessible |
| Service usage | The relevant call appears in Usage and Billing |

Connect MCP after the basic workflow works. Start with a read-only query, then a test draft, before using writes on business content.
