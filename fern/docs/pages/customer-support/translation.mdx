## Serve users across languages

6MM AI Customer Support combines multilingual AI replies, conversation translation and translated help content. These are separate capabilities with their own settings; switching the console language does not translate every article or message.

| Capability | What changes |
| --- | --- |
| Console language | Menus and interface text seen by your agents |
| Help-content translation | Localized articles, questions and other supported content |
| AI reply language | The language used by the model for the visitor's question |
| Conversation translation | Translated messages that help agents understand and respond across languages |

Content language codes currently include English and regional English; Simplified and Traditional Chinese; Japanese; Russian; Spanish and regional variants; Italian; French; German; Portuguese and regional variants; Indonesian; Polish; Vietnamese; Ukrainian; Uzbek; Arabic; Filipino; and Azerbaijani. The exact selectable list depends on the feature. Documentation-site languages and support-product languages are not identical.

## Manage translated content

Open **Language Translation**. Select the source content and target language, review existing translations and completion status, then translate or edit and save. Configure main and default languages in the available settings. Review numbers, currencies, network names, links and exceptions before publishing customer-facing text.

Automatic translation requires an available service and may incur usage charges. A missing translation does not mean the source is missing; inspect the target language and fallback behavior separately.

## Use your connected AI to translate

With [MCP](/customer-support/mcp-connect), an external AI can read the source, create or polish translations and save them with the permitted write tools. Alternatively, it can invoke the platform's automatic-translation tool. The first uses the connected AI for translation; the second uses the platform translation service and its billing rules. Both preserve account permissions and any required confirmation.

Example request: translate a withdrawal guide into Japanese, preserve URLs and numeric limits, and show the proposed translation before saving. Do not claim a successful save until the tool reports completion.
