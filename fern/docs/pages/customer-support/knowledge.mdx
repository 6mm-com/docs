## Choose the right content type

Open **Content Management**. Knowledge categories organize articles; the other content types provide concise answers, navigation and service entry points.

| Content | Typical use |
| --- | --- |
| Knowledge articles and categories | Detailed guides for onboarding, transfers, trading rules and troubleshooting |
| Hot questions | Short answers to frequently asked questions |
| Question categories and feature cards | Group topics and guide users to relevant information |
| Announcements | Publish customer-facing notices |
| Self-service entries | Direct users to available support actions or resources |

<span data-sixmm-canonical-anchor="create-and-maintain-knowledge" aria-hidden="true"></span>

## Create and maintain knowledge

1. Create or select the appropriate category. Complete required fields, including the category when creating an article.
2. Write the title and body, including scope, conditions, steps and exceptions. Use actual business rules rather than assumed exchange behavior.
3. Save and review the draft. Publish when ready for users; unpublish outdated material when appropriate.
4. Maintain translations and check retrieval/index status after changes. Test the question in the bot flow and visitor chat.

For example, a withdrawal guide should explain which network the user must choose, where they obtain the address, any applicable business restrictions and how to contact support. Do not invent processing times or fees.

<span data-sixmm-canonical-anchor="keep-content-consistent" aria-hidden="true"></span>

## Keep content consistent

Updating the source does not prove every translation is current. Review affected translations and related FAQ answers. A published article, a hot-question answer and an announcement should not describe incompatible rules. Before deletion, check whether the content is still needed for user navigation or answers. MCP supports the same permitted content operations; see [MCP tools](/customer-support/mcp-tools).
