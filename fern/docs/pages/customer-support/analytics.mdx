## Understand support activity

Open **Statistics** and choose the relevant time range and available filters. Review real-time overview, conversations, tickets, satisfaction, messages, agents, feedback and knowledge statistics.

Use several metrics together. Conversation volume shows demand, ticket status shows follow-up work, and ratings provide feedback on individual experiences. A high knowledge view count alone does not prove an issue was resolved.

<span data-sixmm-canonical-anchor="compare-like-for-like-data" aria-hidden="true"></span>

## Compare like-for-like data

Keep the same time range, timezone, filters and module scope when comparing results. Check the field labels rather than assuming all numbers count unique people. If a value differs from another screen, compare its definition and filtering first.

MCP can query statistics and help summarize trends. It cannot modify statistical records through the read-only statistics tools. Ask it to include the queried period and source metrics in the summary so the result can be checked in the console.
