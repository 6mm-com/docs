## Available tools follow your role

The table describes the maximum supported scope. Your AI application receives only tools allowed for the authorizing account. Use the live tool list and its parameter schema as the contract; a new console feature is not automatically an MCP tool.

| Console module | Supported operations |
| --- | --- |
| Online conversations | Read sessions, messages and queue information; assign, join, take over and transfer; send messages; invite ratings; manage upload permission; recognize/translate messages; upload supported files |
| Tickets and feedback | Query, assign, update status and delete user tickets and feedback; create, read, update, assign and delete agent tickets |
| Conversation history | Query sessions and messages; delete a single session or multiple sessions |
| Content management | Read and maintain categories, articles, hot questions, question categories, feature cards, announcements and self-service entries; publish/unpublish articles |
| Language translation | Read sources, translations and completion status; save or clear supported translations; invoke automatic translation; manage supported language settings |
| Bot configuration | Read supported settings and FAQs, maintain similar questions, test replies, inspect retrieval status, update indexes and rebuild vectors |
| Agent management | Maintain supported agents, roles and quick replies |
| System settings | Read/write allowed appearance, copy, conversation, visitor-entry, intelligent-service and website allowlist fields |
| Statistics | Read-only overview and supported statistical queries |
| Usage and billing | Read-only balance, usage, transactions and prices |
| Operation logs | Read-only operation list and details |

## Writes and confirmation

Deleting, publishing/unpublishing, editing published articles, sending messages, role/account management, website allowlist changes, vector rebuilds and platform automatic translation require backend confirmation where specified by the tool. A write without confirmation can still change data immediately; review the intended scope before asking the AI to execute it.

MCP does not provide platform administration, tenant closure/deletion, balance recharge, billing edits or provider-secret access. File tools enforce format checks and the deployed size limit; the current implementation supports a single file up to 10 MB via Base64. Use the console for larger files where its own limits permit.

## Example tasks

- List missing translations and draft Japanese versions while preserving links and amounts.
- Find unresolved user tickets and propose assignments without applying them yet.
- Create a knowledge article draft in an existing category, then show its title and ID.
- Summarize recent support statistics with the exact date range.

Platform AI, automatic translation and vector operations can incur existing service charges. The connected AI provider's own usage is separate.
