Before placing an order, make sure prediction is enabled for your account and that you can identify the game's result condition.

## Prepare your account

Access prediction through your partner platform. Check the funding account's available balance, the settlement currency, and any participation restrictions. A balance held in another account is not automatically available for prediction.

## Select an order

| Game | Check before entering an amount |
| --- | --- |
| Up/Down Prediction | Symbol, round number, direction, betting close time, and result-evaluation time |
| Custom Prediction | Symbol, direction, selected duration, and the order's time conditions |
| Prediction Grid | Symbol, price lower and upper bounds, and valid start and end times |

## Review and submit

1. Enter an amount within the displayed single-order limits.
2. Review the current quote and expected payout. A quote can change before acceptance.
3. Read the result rule, any fee disclosure, and the relevant cutoff time.
4. Submit once, then check that an order number and accepted terms are available.

> **An uncertain response is not a failed order.**
> If the page times out, check current orders and account transactions before submitting again. Repeated clicks can create separate orders.

## Check the result

Follow the order through current and historical records. Use the actual payout and settlement transaction to reconcile funds; the expected payout shown before settlement is not an available balance.
