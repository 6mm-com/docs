This guide targets **Agent Java SDK `v0.3.0`**, Java 8+, and the tagged public contract. Examples run in a partner backend after initializing `client` in [Quick Start](/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Six perpetual queries: current orders, order history, fills, current positions, position history, and account ledger.
- Funding balances, transfers, recovery queries, and Funding/Contract transfers.
- Explicit production/simulated selection for supported funds requests.
- Seconds trading redirect and embedding guides, response-field reference, and migration instructions.

Java SDK and Trading Widget SDK have independent versions. The `v1` Widget URL is not Java SDK version `0.3.0`.

<span data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Existing integrations

Preserve user mappings, original orders, and credentials. Omitted environment fields retain existing production behavior. Funding, explicit simulated funds, and six perpetual queries require the corresponding new models and methods. Review [Upgrade guide](/sdk/agent-sdk/java/upgrade) before changing an existing integration.
