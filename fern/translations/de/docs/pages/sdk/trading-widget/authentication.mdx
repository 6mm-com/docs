## Empfohlener Modus: Partner-Token

Partner-Token vermeidet das Einfügen kurzer Token in URLs und behält apiSecret im Partner-Backend.

```js
const widget = TradingWidget.create('#trading-widget', {
  baseUrl: 'https://app.6mm.com',
  auth: {
    mode: 'partner-token',
    tokenProvider: async ({ channelId, symbol, reason }) => {
      const resp = await fetch('/api/trading/embed-token', {
        method: 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ channelId, symbol, reason }),
      })

      if (!resp.ok) {
        throw new Error('Failed to request embed token')
      }

      return resp.json()
    },
  },
})
```

## Backend-Flow

```text
1. Partner frontend receives auth_request from the iframe.
2. SDK calls tokenProvider.
3. Partner frontend calls its own backend.
4. Partner backend validates the partner session.
5. Partner backend calls 6MM Agent API or Java SDK createEmbedToken.
6. SDK sends embedToken to the iframe through postMessage.
7. iframe exchanges embedToken for a 6MM access token.
8. iframe continues initialization and emits ready.
```

<span id="tokenprovider-contract" data-sixmm-canonical-anchor="tokenprovider-contract" aria-hidden="true"></span>

## tokenProvider Vertrag

| Feld | Richtung | Beschreibung |
| --- | --- | --- |
| channelId | SDK -> Partner-Backend | Eindeutige Widget-Sitzungskennung. Das Backend sollte es an createEmbedToken weiterleiten. |
| Symbol | SDK -> Partner-Backend | Aktuelles oder anfängliches Handelssymbol, das als Integrationskontext übergeben wurde; Es handelt sich nicht um eine Berechtigungsbeschränkung für Token-Handelspaare. |
| Grund | SDK -> Partner-Backend | Warum SDK ein Token anfordert, z. B. Erstladevorgang oder Aktualisierung. |
| embedToken | Partner-Backend -> SDK | Kurzlebiges Token, das vom Agent SDK oder dem Agenten API erstellt wurde. |
| expireAt | Partner-Backend -> SDK | Zeitstempel des Token-Ablaufs, zurückgegeben von 6MM. |

<span id="failure-handling" data-sixmm-canonical-anchor="failure-handling" aria-hidden="true"></span>

## Fehlerbehandlung

| Zustand | Empfohlene Handhabung |
| --- | --- |
| Partnersitzung abgelaufen | Geben Sie 401 vom Partnerendpunkt zurück und bitten Sie den Benutzer, sich erneut anzumelden. |
| Die Tokenerstellung ist vorübergehend fehlgeschlagen | Geben Sie einen Fehler in tokenProvider aus und lassen Sie zu, dass das Widget einen Authentifizierungsfehler anzeigt. |
| channelId Nichtübereinstimmung | Lehnen Sie die Anfrage ab und erstellen Sie die Widget-Instanz neu. |
| Der Benutzer darf nicht handeln | Geben Sie einen vom Partner gesteuerten Fehler zurück und erstellen Sie kein Einbettungstoken. |

## Kompatibilitätsmodus: agent-sso

agent-sso behält den älteren /agent-entry-Ticketfluss bei. Bevorzugen Sie Partner-Token für neue Integrationen.

```js
const widget = TradingWidget.create('#trading-widget', {
  baseUrl: 'https://app.6mm.com',
  auth: {
    mode: 'agent-sso',
    entryUrlProvider: async ({ redirectPath }) => {
      const resp = await fetch('/api/trading-entry', {
        method: 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ redirectPath }),
      })
      const data = await resp.json()
      return data.webUrl
    },
  },
})
```

<span id="seconds-trading-and-environment-rules" data-sixmm-canonical-anchor="seconds-trading-and-environment-rules" aria-hidden="true"></span>

## Sekundenhandel und Umweltregeln

Verwenden Sie für Sekundenseiten dieselbe `partner-token`-Authentifizierung mit `page` und `tradingMode`, die im Widget konfiguriert sind. Es gibt kein separates Vorhersage-Token. Jeder tokenProvider-Aufruf muss ein neues einmaliges Token von Ihrem Backend erhalten.

Geben Sie `embedToken`, `expireAt` in Unix-Sekunden und das Original `channelId` als Objekt der obersten Ebene zurück. Die Agent SDK-Token-Antwort enthält nicht `channelId`; Ihr Backend spiegelt den aktuellen Widget-Kanal wider. Wenn Ihr Endpunkt Antworten in `data` umschließt, entpacken Sie sie, bevor Sie von tokenProvider zurückkehren.
