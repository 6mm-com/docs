## Optionen

| Feld | Typ | Standard | Notizen |
| --- | --- | --- | --- |
| baseUrl | string | SDK Skriptursprung | iframe-Domäne. Explizit auf Partnerseiten übergeben. |
| Symbol | string | BTCUSDT | Normalisiert auf Großbuchstaben und Streifen - / _. |
| Thema | dunkel \| Licht | dunkel | Anfänglicher Theme-Parameter. |
| Gebietsschema | de \| en-US \| zh-CN | Browser/Standard | Englisch und vereinfachtes Chinesisch werden unterstützt. |
| Layout | Standard \| kompakt | Standard | Reservierte Layoutoption. |
| Anzeige | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Steuert Einbettungsbereiche und hochrangige Handelscontainer. |
| Autor | object | keiner | Verwenden Sie Partner-Token für neue SSO-Integrationen. |

## Anzeigesteuerung

`display` steuert die eingebettete Handelsseiten-Shell und High-Level-Container. Bei Partner-Einbettungen sind der PC-Header und der Ticker für den unteren Markt standardmäßig ausgeblendet.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Feld | Typ | Standard | Notizen |
| --- | --- | --- | --- |
| showHeader | boolean | FALSCH | Ob der PC-Einbettungsheader im Iframe angezeigt werden soll. |
| showTicker | boolean | FALSCH | Ob der Ticker des unteren Marktes in der Einbettungsschale angezeigt werden soll. |
| versteckt | string[] | [] | Versteckt hochrangige Container auf der Handelsseite. |

Unterstützte `display.hidden`-Werte:

| Wert | Container |
| --- | --- |
| Diagramm | Diagrammcontainer |
| orderBook | Orderbuchcontainer |
| orderForm | Orderformular-Panel |
| Positionen | Bedienfeld für untere Positionen und offene Orders |
| Konto | Container für Kontovermögen |

`display.hidden` verbirgt nur ganze Container. Es werden keine einzelnen Schaltflächen, Felder oder Werkzeuge innerhalb eines Containers ausgeblendet. Werte, die nicht dem aktuellen Ansichtsfenster zugeordnet sind, werden ignoriert.

## Ereignisse

| Ereignis | Auslösen |
| --- | --- |
| bereit | Iframe-Initialisierung abgeschlossen. |
| Fehler | SDK, Iframe oder Authentifizierungsfehler. |
| state_changed | SDK Lebenszyklusstatus geändert. |
| auth_state_changed | Partner-Token-Authentifizierungsstatus geändert. |
| symbol_geändert | Das tatsächliche Iframe-Symbol wurde geändert. |
| locale_changed | Das tatsächliche Iframe-Gebietsschema wurde geändert. |
| order_created | Der Benutzer hat im Iframe eine Order erstellt. |
| order_failed | Das Absenden der Order ist fehlgeschlagen. |
| zerstört | SDK Instanz zerstört. |

## Produktseiten und Handelsmodus

Java Agent SDK und Browser Trading Widget SDK werden unabhängig voneinander versioniert. Nutzen Sie für den Sekundenhandel die aktuellen Widget-Funktionen und wählen Sie explizit sowohl die Seite als auch den Handelsmodus aus.

| Option | Werte | Bedeutung |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Produktseite für Sekundenhandel. |
| `tradingMode` | `real`, `demo` | Standardmäßig ist `real`; explizit mit der Backend-Finanzierungsumgebung übereinstimmen. |

Überprüfen Sie `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` und `TradingWidget.capabilities.partnerToken` vor der Initialisierung. Bei der Tokenerstellung wird keine Fondsumgebung ausgewählt. Um Benutzer oder den Echt-/Demomodus zu ändern, zerstören Sie die alte Instanz und erstellen Sie eine neue.

Sehen [Beispiel für den Handel mit vollständigen Sekunden](/de/sdk/agent-sdk/java/seconds-trading) Und [Produktions-/simulierte Konfiguration](/de/sdk/agent-sdk/java/environments).

## Zusätzliche Anzeigeziele und Ereignisse

Die aktuelle Laufzeit akzeptiert auch `symbolFavorites` und `symbolTicker` in `display.hidden`. Überprüfen Sie immer `TradingWidget.capabilities.displayTargets`; Ein Ziel steuert einen Container auf hoher Ebene und ist keine Berechtigungseinstellung auf Feldebene.

| Ereignis | Bedeutung |
| --- | --- |
| `rendered` | Der Iframe sendet seine gerenderte Benachrichtigung. |
| `theme_changed` | Der Iframe meldet sein eigentliches Thema. |
| `page_changed` | Der Iframe meldet seine eigentliche Produktseite. |

Verwenden Sie `onRendered` oder `widget.on('rendered', handler)`, um das Rendern getrennt von der Initialisierung durchzuführen. Derzeit unterstützte Seiten werden in `TradingWidget.capabilities.pages` veröffentlicht. Validieren Sie die angeforderte Seite, anstatt einen Pfad zu erraten.
