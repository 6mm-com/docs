<h2 id="responsibility-split">Verantwortlichkeitsaufteilung</h2>

| Gebiet | Besitzer | Anmerkungen |
| --- | --- | --- |
| Erstellung von Behältern | Partner-Frontend | Stellen Sie ein sichtbares Element mit expliziter Breite und Höhe bereit. |
| iframe-Erstellung | Trading Widget SDK | Das SDK erstellt und verwaltet das iframe. |
| Handels-UI | 6MM iframe | K-Line, Auftragsbuch, Auftragsformular, Positionen, Orders und Kontendaten werden im iframe ausgeführt. |
| Display-Steuerungen | Trading Widget SDK + 6MM iframe | Der PC-Embed-Header und der untere Ticker sind standardmäßig versteckt. Partner können `display` nutzen, um Shell-Bereiche anzuzeigen oder hochstufige Handelscontainer auszublenden. |
| Partner-Login-Check | Partner-Backend | Überprüfen Sie die Partnerbenutzersitzung, bevor Sie Authentifizierungsdaten ausgeben. |
| Einbetting-Token-Ausgabe | Partner-Backend + Agent API | Empfohlen für den Partner-Token-Modus. |

<h2 id="versioning">Versionierung</h2>

Die öffentliche Integrations-URL bleibt unter dem v1-Skriptpfad stabil. Das aktuelle v1-Fähigkeitsset umfasst Partner-Token, tokenProvider, entryUrlProvider, Anzeigesteuerungen, Lebenszyklusereignisse, Instanzmethoden und Auftragsereignisse.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Wann man das Widget verwenden sollte</h2>

Wählen Sie Trading Widget , wann ein Partner eine vollständige Handelsoberfläche innerhalb eines bestehenden Webprodukts benötigt. Verwenden Sie stattdessen die REST API und WebSocket Dokumentation, wenn Sie eine vollständig individuelle Handelsoberfläche erstellen und pflegen.

<h2 id="implementation-path">Implementierungsweg</h2>

1. Folgen Sie dem [Trading Widget Schneller Start](/de/sdk/trading-widget/quick-start) um das Skript zu laden und einen sichtbaren Container zu erstellen.
2. Konfigurieren [Partner-Token-Authentifizierung](/de/sdk/trading-widget/authentication) Über ein Partner-Backend.
3. Fügen Sie die erforderlichen Zahlen hinzu [Optionen und Ereignisse](/de/sdk/trading-widget/options-events).
4. Nutzung [Instanzmethoden](/de/sdk/trading-widget/instance-methods) Für Lebenszyklus- und Laufzeitkontrollen.
