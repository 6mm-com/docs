## Verantwortungsteilung

| Bereich | Eigentümer | Notizen |
| --- | --- | --- |
| Containererstellung | Partner-Frontend | Stellen Sie ein sichtbares Element mit expliziter Breite und Höhe bereit. |
| Iframe-Erstellung | Trading Widget SDK | Der SDK erstellt und verwaltet den Iframe. |
| Handelsoberfläche | 6MM Iframe | K-Line, Orderbuch, Orderformular, Positionen, Orders und Kontodaten laufen im Iframe. |
| Anzeigesteuerung | Trading Widget SDK + 6MM Iframe | Die PC-Einbettungskopfzeile und der untere Ticker sind standardmäßig ausgeblendet. Partner können `display` verwenden, um Shell-Bereiche anzuzeigen oder hochrangige Handelscontainer zu verbergen. |
| Partner-Login-Prüfung | Partner-Backend | Validieren Sie die Partnerbenutzersitzung, bevor Sie Authentifizierungsdaten ausgeben. |
| Einbetten der Token-Ausgabe | Partner-Backend + Agent API | Empfohlen für den Partner-Token-Modus. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Versionierung

Die öffentliche Integrations-URL bleibt unter dem v1-Skriptpfad stabil. Der aktuelle v1-Funktionssatz umfasst Partner-Token, tokenProvider, entryUrlProvider, Anzeigesteuerelemente, Lebenszyklusereignisse, Instanzmethoden und Orderereignisse.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Wann das Widget verwendet werden soll

Wählen Sie Trading Widget, wenn ein Partner eine vollständige Handelsschnittstelle innerhalb eines vorhandenen Webprodukts benötigt. Verwenden Sie stattdessen die Dokumentation REST API und WebSocket, wenn Sie eine vollständig benutzerdefinierte Handelsschnittstelle erstellen und pflegen.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Implementierungspfad

1. Folgen Sie dem [Trading Widget Schnellstart](/de/sdk/trading-widget/quick-start) um das Skript zu laden und einen sichtbaren Container zu erstellen.
2. Konfigurieren [Partner-Token-Authentifizierung](/de/sdk/trading-widget/authentication) über ein Partner-Backend.
3. Fügen Sie das Erforderliche hinzu [Optionen und Ereignisse](/de/sdk/trading-widget/options-events).
4. Verwenden [Instanzmethoden](/de/sdk/trading-widget/instance-methods) für Lebenszyklus- und Laufzeitkontrollen.

## Verifizierte öffentliche Laufzeit

Das öffentliche `v1`-Skript meldet die Version `1.8.0` vom 10.10.2026. Dieser URL ist ein stabiler Einstiegspunkt für die Hauptversion, kein angehefteter Build. Lesen Sie `TradingWidget.version` und `TradingWidget.capabilities` in Ihrer geladenen Laufzeit, bevor Sie optionale Funktionen verwenden. Java Agent SDK `v0.3.0` ist ein separates Backend-Paket.

Die Laufzeit unterstützt eine einzelne aktive Instanz (`multiInstance=false`); Durch das Erstellen eines weiteren Widgets wird die vorherige Instanz zerstört. Die unterstützten Gebietsschemas sind `en`, `en-US` und `zh-CN`, unabhängig von den 20 Dokumentationssprachen.
