## Methodenzusammenfassung

| Methode | Zweck |
| --- | --- |
| destroy() | Entferne das iframe und lasse die Event-Listener frei. |
| getState() | Lesen Sie den aktuellen Lebenszykluszustand SDK . |
| whenReady() | Warte, bis der iframe die Initialisierung abgeschlossen hat. |
| setSymbol(Symbol) | Tausche das Handelspaar innerhalb des iframes. |
| setTheme(Thema) | Aktualisiere den iframe-Theme-Parameter. |
| setLocale(Ort) | Wechsel die iframe-Sprache. |
| setSize(Breite, Höhe) | Aktualisiere die iframe-Maße. |
| Reload() | Lade den aktuellen iframe neu. |
| refreshAuth(Grund) | Löse den Widget-Auth-Refresh-Flow aus. |
| setTokenProvider(Anbieter) | Ersetzen Sie den Anbieter, der im Partner-Token-Modus verwendet wird. |
| on(Event, Handler) | Abonnieren Sie Laufzeitereignisse und erhalten Sie eine Abmeldungsfunktion. |

<span data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## destroy()

Entferne das iframe, lösche die Hörer und emittiere einmal deaktiviert für die aktuelle Instanz.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Lesen Sie den aktuellen Lebenszykluszustand der Widget-Instanz.

```js
const state = widget.getState()
```

Rückgabewerte umfassen Laden, Authentifizierung, Bereitschaft, Fehler und Zerstörung.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Warte, bis der iFrame die Initialisierung abgeschlossen hat, bevor du abhängige UI-Logik ausführst.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(Symbol)

Tausche das Handelspaar innerhalb des iframes. Wenn der iframe noch initialisiert, stellt der SDK den Befehl in die Warteschlange und sendet ihn nach Ready.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(Thema)

Aktualisieren Sie den Theme-Parameter, der vom eingebetteten Handels-iframe verwendet wird.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(Ort)

Wechsel die iframe-Sprache. Unterstützte Werte sind en, en-US und zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(Breite, Höhe)

Aktualisieren Sie die Größe DOM iframe und informieren Sie den iframe über die neue äußere Größe. Numerische Werte werden in px umgewandelt.

```js
widget.setSize('100%', 720)
```

<span data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## Reload()

Lade den aktuellen iFrame neu und warte, bis er erneut initialisiert.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(Grund)

Bitten Sie den iframe, den aktuellen Authentifizierungsfluss zu aktualisieren. Der optionale Begründungswert wird für Logging und Flusskontrolle weitergeleitet.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(Anbieter)

Ersetzen Sie die tokenProvider im Partner-Token-Modus. Der SDK ruft den Anbieter auf, wenn der iframe ein frisches Einbettungstoken anfordert.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(Event, Handler)

Abonnieren Sie ein Runtime-Event. Die zurückgegebene Funktion entfernt den Listener.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
