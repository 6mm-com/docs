## Zusammenfassung der Methode

| Verfahren | Zweck |
| --- | --- |
| zerstören() | Entfernen Sie den Iframe und geben Sie Ereignis-Listener frei. |
| getState() | Lesen Sie den aktuellen Lebenszyklusstatus SDK. |
| whenReady() | Warten Sie, bis der Iframe die Initialisierung abgeschlossen hat. |
| setSymbol(Symbol) | Tauschen Sie das Handelspaar innerhalb des Iframes. |
| setTheme(Thema) | Aktualisieren Sie den Iframe-Designparameter. |
| setLocale(Gebietsschema) | Wechseln Sie die Iframe-Sprache. |
| setSize(Breite, Höhe) | Iframe-Abmessungen aktualisieren. |
| neu laden() | Laden Sie den aktuellen Iframe neu. |
| refreshAuth(Grund) | Lösen Sie den Aktualisierungsfluss für die Widget-Authentifizierung aus. |
| setTokenProvider(Anbieter) | Ersetzen Sie den verwendeten Anbieter durch den Partner-Token-Modus. |
| on(Ereignis, Handler) | Abonnieren Sie Laufzeitereignisse und erhalten Sie eine Abmeldefunktion. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## zerstören()

Entfernen Sie den Iframe, löschen Sie die Listener und geben Sie die Funktion „zerstört“ einmal für die aktuelle Instanz aus.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Lesen Sie den aktuellen Lebenszyklusstatus der Widget-Instanz.

```js
const state = widget.getState()
```

Zu den Rückgabewerten gehören „Laden“, „Authentifizierung“, „Bereit“, „Fehler“ und „Zerstört“.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Warten Sie, bis der Iframe die Initialisierung abgeschlossen hat, bevor Sie die abhängige UI-Logik ausführen.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(Symbol)

Tauschen Sie das Handelspaar innerhalb des Iframes. Wenn der Iframe noch initialisiert wird, stellt SDK den Befehl in die Warteschlange und sendet ihn nach der Fertigstellung.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(Thema)

Aktualisieren Sie den Theme-Parameter, der vom eingebetteten Handels-Iframe verwendet wird.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(Gebietsschema)

Wechseln Sie die Iframe-Sprache. Unterstützte Werte sind en, en-US und zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(Breite, Höhe)

Aktualisieren Sie die Iframe-Größe DOM und benachrichtigen Sie den Iframe über die neue äußere Größe. Numerische Werte werden in px umgewandelt.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## neu laden()

Laden Sie den aktuellen Iframe neu und warten Sie, bis er erneut initialisiert wird.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(Grund)

Bitten Sie den Iframe, den aktuellen Authentifizierungsfluss zu aktualisieren. Der optionale Grundwert wird zur Protokollierung und Flusskontrolle weitergeleitet.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(Anbieter)

Ersetzen Sie das vom Partner-Token-Modus verwendete tokenProvider. Der SDK ruft den Anbieter auf, wenn der Iframe ein neues Einbettungstoken anfordert.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(Ereignis, Handler)

Abonnieren Sie ein Laufzeitereignis. Die zurückgegebene Funktion entfernt den Listener.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Zusätzliche Methoden in der aktuellen v1-Laufzeit

| Verfahren | Zweck |
| --- | --- |
| `whenRendered()` | Warten Sie auf die gerenderte Benachrichtigung des Iframes. Dies ist von „ready“ zu unterscheiden. |
| `setPage(page)` | Fordern Sie in der aktuellen Instanz eine unterstützte Produktseite an. Es ändert nichts an der Fondsumgebung. |
| `prepareForRecreate()` | Bitten Sie einen fertigen Iframe, den Austausch vorzubereiten. gibt ein Versprechen zurück und kann es ablehnen, wenn es nicht verfügbar, ausgelastet oder abgelaufen ist. |
| `cancelRecreate()` | Brechen Sie einen ausstehenden/vorbereiteten Ersatzfluss ab. |
| `TradingWidget.validateOptions(options)` | Überprüfen Sie die Initialisierungsoptionen, bevor Sie eine Instanz erstellen. |

Bei einer Änderung des Benutzers oder der realen/Demo-Umgebung zerstören Sie die alte Instanz und erstellen Sie eine neue mit der Zielauthentifizierung und dem Zielmodus. Verwenden Sie `setPage` nicht als Umgebungsschalter. Überprüfen Sie die Fähigkeiten, bevor Sie optionale Methoden verwenden.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
