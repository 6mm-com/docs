## Laufzeit

| Gegenstand | Wert |
| --- | --- |
| Paket | sixmm/agent-SDK |
| Minimum PHP Version | PHP 7,4+ |
| Empfohlene PHP Version | PHP 8.1+ oder aktuell unterstützte Versionen |
| Erforderliche Erweiterungen | ext-json, ext-curl |

Die PHP SDK Paketquelle und die genehmigte Version werden beim Partner-Onboarding bereitgestellt. Nehmen Sie nicht an, dass das Paket über den öffentlichen Packagist verfügbar ist; konfigurieren Sie das für Ihre Organisation bereitgestellte Composer-Repository.

<span id="backend-integration-rules" data-sixmm-canonical-anchor="backend-integration-rules" aria-hidden="true"></span>

## Backend-Integrationsregeln

- Laden `apiSecret` aus einem Secret-Manager oder einer geschützten Umgebungsvariable.
- Benutzerbindung, Übertragung, Signierung und Webhook-Logik aus dem Browsercode heraushalten.
- Verwenden Sie Dezimalstrings für Asset-Beträge, um Gleitkomma-Rundungen zu vermeiden.
- Verwenden Sie die ursprüngliche `agentOrderNo` bei der Abfrage eines unsicheren Übertragungsergebnisses.
- Verifizieren Sie Webhook-Signaturen mit dem Rohanfrage-Body vor der Entschlüsselung oder Änderung dieser Anfrage.
