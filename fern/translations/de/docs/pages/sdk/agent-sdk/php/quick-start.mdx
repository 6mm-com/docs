## Installation

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Paketzugriff**
>
> 6MM stellt den Namen des genehmigten Composer-Pakets, das Repository und die Version während des Partner-Onboardings bereit. Das Paket sollte nicht als Existenz auf dem öffentlichen Packagist angenommen werden.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Bevor du anfängst

- Bestätigen Sie den Agenten API Basis URL mit 6MM.
- Laden apiSecret aus Umgebungsvariablen oder Geheimnisverwaltung.
- Halten Sie SDK Nutzung nur innerhalb von Backend-Diensten.
- Bereite idempotente Handhabung für Transfer- und Webhook-Flows vor.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Client initialisieren

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Nur Backend**
>
> Die PHP SDK signiert Agent- API -Anfragen und darf nicht über öffentlichen Quellcode oder Frontend-Laufzeitumgebungen freigegeben werden.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Beispiel: Gelder überweisen

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Verwenden Sie Dezimalzeichenketten für Beträge und bewahren Sie die ursprüngliche agentOrderNo beim erneuten Versuch oder Abfrage des Übertragungsstatus.
