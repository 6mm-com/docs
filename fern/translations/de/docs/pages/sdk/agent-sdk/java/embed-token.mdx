## Trading Widget Token einbetten

Das Einbettungstoken gilt für den Modus Trading Widget SDK `partner-token + tokenProvider`. Der
Der Browser ruft das Partner-Backend auf, und das Partner-Backend ruft Folgendes auf: Java SDK
um ein `embedToken` zu erstellen.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Integrationsvoraussetzungen:

- `channelId` muss den von Trading Widget SDK übergebenen Wert verwenden.
- `symbol` ist optional und kann das aktuelle Anfangssymbol tragen. Es handelt sich nicht um eine Berechtigungsbeschränkung für Token-Handelspaare.
- `embedToken` ist kurzlebig und einmalig. Fügen Sie es nicht in URL-Abfragezeichenfolgen ein.
- Das Partner-Frontend darf niemals `apiSecret` enthalten.
- `expireAt` ist ein Unix-Zeitstempel in Sekunden, kein TTL.

Beispiel für einen Partner-Backend-Endpunkt:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Partnerendpunktvertrag

Authentifizieren Sie die Partnersitzung und leiten Sie `agentUserId` serverseitig ab. Akzeptieren Sie das aktuelle Widget `channelId`; Rückgabe der obersten Ebene `embedToken`, `expireAt` (Unix-Sekunden) und dasselbe `channelId`. Agentenantworten liefern nicht `channelId`: Ihr Backend gibt es zurück. Rufen Sie bei der Initialisierung und Erneuerung ein neues Token ab. Verwenden Sie es niemals wieder. Bei der Token-Erstellung werden weder Gelder übertragen noch die Wallet-Umgebung ausgewählt.

Sehen [Sekundenhandel](/de/sdk/agent-sdk/java/seconds-trading) für den kompletten Frontend-/Backend-Flow.
