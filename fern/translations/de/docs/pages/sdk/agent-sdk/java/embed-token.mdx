## SDK Ruf

Erstellen Sie nach der Validierung der Partnerbenutzersitzung Embed-Token aus Ihrem Backend. Der Browser sollte Ihren Endpunkt aufrufen, und Ihr Endpunkt sollte 6MM über die Agent SDK aufrufen.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Einmaliges Zertifikat**
>
> embedToken ist nur von kurzer Dauer und einmaliger Gebrauch. Platzieren Sie es nicht in eine URL Abfrage-Zeichenkette.

<span id="backend-endpoint-example" data-sixmm-canonical-anchor="backend-endpoint-example" aria-hidden="true"></span>

## Beispiel für einen Backend-Endpunkt

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Geben Sie nur die vom Trading Widget Token-Anbieter benötigten Felder zurück. Geben Sie keine apiSecret, Rohsignaturfelder oder interne Service-Konfigurationen zurück.

<span id="failure-handling" data-sixmm-canonical-anchor="failure-handling" aria-hidden="true"></span>

## Fehlerhandhabung

| Zustand | Empfohlenes Handling |
| --- | --- |
| Die Benutzersitzung fehlt oder ist abgelaufen | Geben Sie 401 vom Partnerendpunkt zurück und bitten Sie den Benutzer, sich erneut anzumelden. |
| Der Agent-Nutzer ist nicht gebunden | Binde zuerst den Benutzer und versuche dann erneut die Token-Erstellung. |
| 6MM gibt einen temporären Fehler zurück | Gib einen wiederholbaren Fehler an das Frontend zurück und logge requestId zur Unterstützung. |
| channelId passt nicht zur Widget-Instanz | Lehne die Anfrage ab und erstelle die Widget-Sitzung erneut. |
