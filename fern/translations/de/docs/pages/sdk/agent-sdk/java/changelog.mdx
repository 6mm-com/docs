Dieser Leitfaden richtet sich an **Agent Java SDK `v0.3.0`**, Java 8+ und den getaggten öffentlichen Auftrag. Beispiele werden nach der Initialisierung von `client` in einem Partner-Backend ausgeführt [Schnellstart](/de/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Sechs fortlaufende Abfragen: aktuelle Bestellungen, Bestellhistorie, Ausführungen, aktuelle Positionen, Positionshistorie und Kontobuch.
- Finanzierungssalden, Überweisungen, Rückforderungsanfragen und Finanzierungs-/Vertragsübertragungen.
- Explizite Produktion/simulierte Auswahl für unterstützte Mittelanfragen.
- Seconds Trading-Umleitungs- und Einbettungsleitfäden, Antwortfeldreferenzen und Migrationsanweisungen.

Java SDK und Trading Widget SDK haben unabhängige Versionen. Das `v1` Widget URL ist nicht die Java SDK Version `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Bestehende Integrationen

Behalten Sie Benutzerzuordnungen, ursprüngliche Bestellungen und Anmeldeinformationen bei. Ausgelassene Umgebungsfelder behalten das bestehende Produktionsverhalten bei. Finanzierung, explizit simulierte Fonds und sechs ewige Abfragen erfordern die entsprechenden neuen Modelle und Methoden. Rezension [Upgrade-Anleitung](/de/sdk/agent-sdk/java/upgrade) bevor Sie eine bestehende Integration ändern.
