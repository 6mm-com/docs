## Maven-Koordinaten

Aktuelle Quellkoordinaten:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.3.0</version>
</dependency>
```

GitHub ist Quellhosting, kein Maven-Abhängigkeits-Repository. Wenn der SDK nicht vorhanden ist
bereits in einem Maven-Repository veröffentlicht wurde, installieren Sie es in Ihrem lokalen Maven
Repository zuerst:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.3.0
mvn install
```

Nach der lokalen Installation kann Ihr Geschäftsprojekt gelöst werden
`com.sixmm.exchange.sdk:agent:0.3.0` aus dem lokalen Maven-Repository.

Für Team-Builds und Testumgebungen veröffentlichen Sie SDK in einem Maven-Repository
wie Nexus, Artifactory, GitHub Packages, Maven Central, oder verwenden Sie einen GitHub
basierten Build-Service wie JitPack.

Informationen zu einer vorhandenen Integration finden Sie im [SDK Upgrade-Anleitung](https://github.com/6mm-com/agent-java-sdk/blob/v0.3.0/docs/merchant-integration.md#8-旧-sdk-升级). Verwenden Sie das stabile Quell-Tag `v0.3.0`, um SDK zu installieren und die entsprechende Integrationsdokumentation zu lesen.

## Client-Initialisierung

<span id="plain-java" data-sixmm-canonical-anchor="plain-java" aria-hidden="true"></span>

### Einfach Java

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

<span id="spring-boot" data-sixmm-canonical-anchor="spring-boot" aria-hidden="true"></span>

### Frühlingsstiefel

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;
import java.time.Duration;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class AgentSdkConfig {

    @Bean
    public AgentClient agentClient(AgentSdkProperties props) {
        return new AgentClient(AgentClientConfig.builder()
                .baseUrl(props.getBaseUrl())
                .agentCode(props.getAgentCode())
                .apiSecret(props.getApiSecret())
                .defaultCurrency("USDT")
                .timeout(Duration.ofSeconds(10))
                .build());
    }
}
```

Beispielhafte Anwendungseigenschaften:

```properties
agent.sdk.base-url=https://agent-api.6mm.com
agent.sdk.agent-code=AGENT001
agent.sdk.api-secret=${AGENT_API_SECRET}
```

## Benutzer binden

Bind erstellt oder ruft die Beziehung zwischen einem Partnerbenutzer und einem 6MM ab.
Plattformbenutzer. Rufen Sie es auf, wenn ein Benutzer zum ersten Mal in den Handelsfluss eintritt oder bevor
Erster Transfer nach 6MM.

```java
import com.sixmm.agent.model.BindRequest;
import com.sixmm.agent.model.BindResponse;

BindResponse resp = client.bind(
        BindRequest.of("agent-user-001")
                .withUsername("alice")
                .withExt("{\"source\":\"web\"}"));

System.out.println(resp.platformUserId);
System.out.println(resp.bindStatus);
System.out.println(resp.isSimulatedUser);
```

Anfragefelder:

| Feld | Typ | Erforderlich | Beschreibung |
| --- | --- | --- | --- |
| `agentUserId` | string | Ja | Eindeutige Partner-Benutzer-ID |
| `username` | string | NEIN | Partnerseitiger Anzeigename, der als Spitzname des Plattformbenutzers verwendet wird |
| `ext` | string | NEIN | Erweiterungsfeld. Die Zeichenfolge JSON wird empfohlen |

Antwortfelder:

| Feld | Typ | Beschreibung |
| --- | --- | --- |
| `platformUserId` | string | 6MM externe Benutzer-ID |
| `bindStatus` | string | Normalerweise `BOUND` |
| `isSimulatedUser` | boolean | Ob es sich um einen simulierten Benutzer handelt |

## Empfohlene Geschäftsabläufe

<span id="first-trading-entry" data-sixmm-canonical-anchor="first-trading-entry" aria-hidden="true"></span>

### Erster Handelseintrag

```text
1. User logs in to the partner site.
2. Partner backend calls bind with agentUserId.
3. Partner stores the agentUserId and platformUserId relationship.
4. User clicks the trading entry.
5. Redirect mode: call createEntryUrl and open webUrl in the browser.
6. Embed mode: Trading Widget calls tokenProvider, and partner backend calls createEmbedToken.
```

<span id="deposit-into-6mm" data-sixmm-canonical-anchor="deposit-into-6mm" aria-hidden="true"></span>

### Einzahlung in 6MM

```text
1. Partner creates a unique agentOrderNo.
2. Partner calls transfer(Direction.IN).
3. If SUCCESS is returned, mark the local order as successful.
4. If PROCESSING is returned, wait for webhook or poll queryOrder.
5. If FAILED is returned or AgentApiException is thrown, handle it as failed.
```

<span id="withdraw-back-to-partner" data-sixmm-canonical-anchor="withdraw-back-to-partner" aria-hidden="true"></span>

### Zurückziehen zum Partner

```text
1. Partner creates a unique agentOrderNo.
2. Fixed amount withdraw: call transfer(Direction.OUT).
3. Full withdraw: call transferAllOut.
4. Confirm the final result by orderStatus, webhook, or queryOrder.
```

## Fehlerbehandlung

SDK Ausnahmen sind in zwei Kategorien unterteilt:

| Ausnahme | Szenario | Empfohlene Handhabung |
| --- | --- | --- |
| `AgentApiException` | HTTP Status ist nicht 2xx oder Agentenantwort `code != 0` | Lesen Sie `getHttpStatus()`, `getCode()` und `getResponseBody()` und behandeln Sie es als geschäftlichen/API Misserfolg |
| `AgentSdkException` | Netzwerk-, Serialisierungs-, Konfigurations- oder Signaturfehler | Protokollieren Sie es und behandeln Sie es als Systemausnahme |

Beispiel:

```java
import com.sixmm.agent.AgentApiException;
import com.sixmm.agent.AgentSdkException;

try {
    TransferResponse resp = client.transfer(TransferRequest.fixed(
            "AGT-ORDER-1001", "agent-user-001", Direction.IN, "USDT", "10.00"));
    // Update the local order according to resp.orderStatus.
} catch (AgentApiException e) {
    // Business rejection or HTTP error.
    log.warn("6mm agent api rejected request, httpStatus={}, code={}, body={}",
            e.getHttpStatus(), e.getCode(), e.getResponseBody());
} catch (AgentSdkException e) {
    // Local SDK error or network error.
    log.error("6mm agent sdk request failed", e);
}
```
