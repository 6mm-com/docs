## Installation

Die öffentliche SDK Quelle dokumentiert derzeit `v0.1.1` mit diesen Maven-Koordinaten:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

GitHub fungiert nicht als Maven-Abhängigkeitsrepository. Installieren Sie den markierten Quellcode lokal, bevor Sie die Abhängigkeit beheben:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Team baut**
>
> Veröffentlichen Sie das genehmigte Artefakt im Maven-Repository Ihrer Organisation für CI-, Test- und Produktionsbuilds. Bestätigen Sie die genehmigte Version mit 6MM vor der Produktionsbereitstellung.

Quellcode und Anwendungsbeispiele sind im offiziellen Java SDK -Repository verfügbar:

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Bevor du anfängst

- Bestätigen Sie, dass Ihr Produktionsagent API Basis URL mit dem 6MM Team ist.
- Speichern apiSecret nur im Backend-Secret-Management.
- Bereite eine stabile Abbildung zwischen platformUserId und agentUserIdvor.
- Ermöglicht strukturierte Logs rund um Bind-, Transfer-, Order- und Webhook-Flows.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Client initialisieren

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Nur Backend**
>
> Initialisieren Sie die Agent SDK nicht aus Browser-, Mobil- oder Desktop-Client-Code. Die SDK signiert privilegierte Agenten API Anfragen.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Beispiel: Gelder überweisen

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Verwenden Sie für jede Übertragungsanfrage eine eindeutige Partner-Ordernummer. Wenn eine Anfrage abläuft, fragen Sie vor der Erstellung einer neuen die ursprüngliche Bestellung ab.
