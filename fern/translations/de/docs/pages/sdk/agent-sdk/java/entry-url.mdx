## Direkteintrag URL

Der Direkteintrag URL ist für den Umleitungsmodus vorgesehen. Ein Partnerbenutzer klickt auf eine Schaltfläche
Partnerseite, öffnet das Frontend 6MM und wird automatisch angemeldet.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/en/futures/BTCUSDT?tradingMode=real")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Feldregeln:

| Feld | Beschreibung |
| --- | --- |
| `redirectPath` | 6MM relativer Frontend-Pfad. Es muss mit `/` beginnen, zum Beispiel `/en/futures/BTCUSDT?tradingMode=real` |
| `returnUrl` | Absoluter Partner URL, der verwendet wird, wenn der Benutzer das 6MM-Frontend verlässt. Nur `http` und `https` sind zulässig |
| `expireAt` | Ablaufzeit der Eintrittskarte als Unix-Zeitstempel in Sekunden |

Das Beispiel eröffnet Perpetual Futures im Real-Modus. Für simulierten Handel verwenden Sie `tradingMode=demo` im Frontend und übergeben Sie explizit `environment=SIMULATED` in den entsprechenden Back-End-Wallet-Anfragen. Frontend `tradingMode` und Backend-Fonds `environment` werden separat konfiguriert. Durch das Erstellen eines Eintrags URL wird der Benutzer authentifiziert; Es werden weder Gelder überwiesen noch eine Wallet-Umgebung ausgewählt.

Sicherheitsanforderungen:

- `webUrl` enthält ein einmaliges Ticket. Benutzen Sie es sofort und lagern Sie es nicht über einen längeren Zeitraum.
- Wenn der Eintrag URL abläuft oder verwendet wurde, generieren Sie auf der Partnerseite einen neuen.
- `returnUrl` darf nicht `javascript:`, ein relativer Pfad oder ein URL mit Benutzerinformationen sein.

## Produkt- und Modusauswahl

Verwenden Sie die aktuelle Frontend-Route, die von 6MM bereitgestellt wird. Zum Beispiel `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` oder `/zh-CN/futures/BTCUSDT?tradingMode=real`. Das Ticket authentifiziert den Benutzer; Es wählt keine Finanzierungsumgebung aus und bewegt keine Gelder.

Sehen [Sekundenhandel](/de/sdk/agent-sdk/java/seconds-trading) für Weiterleitungs- und eingebettete Beispiele.
