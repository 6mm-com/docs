Verwenden Sie die Saldenansicht, um den aktuellen Kontostand anzuzeigen, und die Transaktionsansichten, um zu erklären, wie sich dieser geändert hat. Unternehmensarbeitsbereiche können je nach Produkt und Rolle mehrere Ansichten verfügbar machen.

<span id="use-the-right-record-for-each-question" data-sixmm-canonical-anchor="use-the-right-record-for-each-question" aria-hidden="true"></span>

## Verwenden Sie für jede Frage den richtigen Datensatz

| Frage | Wo suchen |
| --- | --- |
| Mit welchem ​​Betrag kann bezahlt werden? | Überprüfen Sie das verfügbare Guthaben für die gewünschte Wallet und den gewünschten Vermögenswert. Überprüfen Sie die gehaltenen oder eingefrorenen Beträge separat. |
| Wurde eine eingehende Zahlung gutgeschrieben? | Überprüfen Sie den Einzahlungsdatensatz und gleichen Sie das Netzwerk, den Vermögenswert, den Betrag und die Empfangsdetails ab. |
| Hat eine Ausgangszahlung ein bekanntes Ergebnis erreicht? | Überprüfen Sie den Auszahlungsdatensatz und die Kettenbestätigung, sofern verfügbar. |
| Welche Buchungen beeinflussten die Geschäftsbilanz? | Verwenden Sie die Hauptbuchansicht, sofern der Arbeitsbereich diese bereitstellt. Überprüfen Sie die Kettenaktivitätsansicht auf die Bewegung in der Kette. |

<span id="reconcile-a-payment-period" data-sixmm-canonical-anchor="reconcile-a-payment-period" aria-hidden="true"></span>

## Gleichen Sie einen Zahlungszeitraum ab

1. Identifizieren Sie den Arbeitsbereich, das Netzwerk, das Asset und den Geschäftszeitraum, den Sie überprüfen.
2. Ordnen Sie die Einzahlungs- und Auszahlungsunterlagen der von Ihnen geführten Geschäftsbestellung oder Zahlungsreferenz zu.
3. Abrechnung von Gebühren und internem Inkasso getrennt. Erfassen Sie den für eine ausstehende Anfrage gehaltenen Saldo getrennt von einer abgeschlossenen Überweisung.
4. Untersuchen Sie nicht übereinstimmende Einträge anhand der Transaktionsreferenz und des aktuellen Status. Lassen Sie ein ausstehendes Element geöffnet, bis das Ergebnis feststeht.

Wenn beispielsweise eine ausgehende Transaktion in der Kette erscheint, während der Auszahlungsdatensatz noch auf eine Bestätigung wartet, lassen Sie die ursprüngliche Geschäftsanfrage offen und folgen Sie diesem Datensatz. Verwenden Sie den Endstatus und die entsprechenden Beträge, um die Abstimmung abzuschließen.
