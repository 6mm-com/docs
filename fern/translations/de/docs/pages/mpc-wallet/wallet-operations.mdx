Verwenden Sie die Menüs und Berechtigungen des ausgewählten Arbeitsbereichs als Ausgangspunkt. Persönliche und Team-Wallets legen Wert auf Wallet-Assets und Gerätesignaturen. Unternehmensarbeitsbereiche bieten auch geschäftliche Genehmigungen und betriebliche Ansichten.

<span id="receive-assets" data-sixmm-canonical-anchor="receive-assets" aria-hidden="true"></span>

## Erhalten Sie Vermögenswerte

Wählen Sie das gewünschte Netzwerk und Asset aus und verwenden Sie dann die für dieses Wallet oder diesen Geschäftsbenutzer bereitgestellten Empfangsdetails. Einige Netzwerke erfordern zusätzlich zu einer Adresse ein Memo oder einen Tag. Bewahren Sie diese Angaben auf und überprüfen Sie sie vor dem Absenden.

Die Zuweisung einer Adresse bedeutet nicht, dass eine Anzahlung eingegangen ist. Verfolgen Sie den Einzahlungsbeleg, die Kettenbestätigungen und etwaige Risikoeinbehaltungen separat. Eine Reihentransaktion kann sichtbar sein, bevor Gelder auf dem Geschäftskonto verfügbar sind.

<span id="transfer-assets" data-sixmm-canonical-anchor="transfer-assets" aria-hidden="true"></span>

## Vermögenswerte übertragen

1. Wählen Sie das Quell-Wallet oder Guthaben aus und geben Sie das Ziel, den Betrag und die erforderliche Notiz ein.
2. Sehen Sie sich die Vorschau, Gebühreninformationen und Zielprüfungen an. Stellen Sie sicher, dass das entsprechende Gebührenguthaben dort verfügbar ist, wo das Wallet-Modell es erfordert.
3. Einmal absenden und die Anforderungskennung behalten. Füllen Sie die vom Produkt vorgelegten Zulassungen bzw. Gerätebestätigungen aus.
4. Folgen Sie der Unterzeichnung, der Übertragung und der Kettenbestätigung, bis das Endergebnis feststeht.

Die Genehmigung bedeutet nicht, dass die Transaktion unterzeichnet ist, und die Veröffentlichung bedeutet nicht, dass sie bestätigt wird. Es sollte nicht davon ausgegangen werden, dass bei persönlichen und Teamabhebungen derselbe Webgenehmigungsprozess wie bei Unternehmensabhebungen verwendet wird.

<span id="understand-enterprise-wallet-roles" data-sixmm-canonical-anchor="understand-enterprise-wallet-roles" aria-hidden="true"></span>

## Verstehen Sie die Rollen von Unternehmens-Wallets

| Rolle | Zweck |
| --- | --- |
| Einzahlungsgeldbörse | Empfangen Sie eingehende Assets und unterstützen Sie Inkasso-Workflows |
| Hot- oder Auszahlungsbrieftasche | Abwicklung operativer ausgehender Überweisungen |
| Transit-Geldbörse | Verschieben Sie Vermögenswerte zwischen Betriebs- und Reservevereinbarungen |
| Geldbörse reservieren | Halten Sie Vermögenswerte im Rahmen einer Vertragsvereinbarung, die zur Reservenutzung geeignet ist |

Bei manchen Produkten wird auch zwischen Gebührenfinanzierung oder Einzelfonds unterschieden. Dabei handelt es sich um operative Rollen, nicht um das Versprechen, dass jedes Produkt jeden Wallet-Typ offenlegt. Ein Reserve-Label allein beweist nicht, dass Geräte offline sind.

<span id="reconcile-uncertain-results" data-sixmm-canonical-anchor="reconcile-uncertain-results" aria-hidden="true"></span>

## Vereinbaren Sie unsichere Ergebnisse

Vergleichen Sie die Geschäftsanfrage, den Wallet-Datensatz und die Kettentransaktion. Halten Sie verfügbare Salden, eingefrorene Salden, Hauptbucheinträge und Kettenbeobachtungen getrennt.

Wenn bei einer Anfrage eine Zeitüberschreitung auftritt oder die Überprüfung noch nicht abgeschlossen ist, fragen Sie den vorhandenen Datensatz ab. Erstellen Sie keine weitere Überweisung, nur weil ein Erfolgsbildschirm oder eine Benachrichtigung fehlt. Voraussetzung für die Stornierung ist der tatsächliche Unterzeichnungsstatus; Eine eingereichte Stornierung ist kein Beweis dafür, dass Gelder nicht verschoben werden können. Entwickler sollten folgen [Transaktionen und Wiederholungsversuche](/de/mpc-wallet/transactions).
