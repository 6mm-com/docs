An Unternehmenszahlungen können Personen mit unterschiedlichen Rollen beteiligt sein. Der Betreiber bereitet die Überweisung vor, ein autorisierter Prüfer kümmert sich bei Bedarf um die Genehmigung und die unterzeichnenden Teilnehmer fertigen die Transaktionsunterschrift an.

<span id="prepare-the-payment" data-sixmm-canonical-anchor="prepare-the-payment" aria-hidden="true"></span>

## Bereiten Sie die Zahlung vor

Wählen Sie das Quell-Wallet, das Netzwerk und das Asset aus. Geben Sie die Empfängeradresse, den Betrag und eine eventuell erforderliche Zielnotiz ein. Sehen Sie sich die Vorschau und die Gebühren an. Wenn der ausgewählte Workflow das Ziel anhand einer Zulassungsliste prüft, lösen Sie alle Einschränkungen mithilfe des autorisierten Adressverwaltungsprozesses auf.

<span id="review-and-track-progress" data-sixmm-canonical-anchor="review-and-track-progress" aria-hidden="true"></span>

## Überprüfen und verfolgen Sie den Fortschritt

Wenn eine Genehmigung erforderlich ist, kann ein Prüfer die Zahlungsdetails in der Enterprise-Aufgabenliste überprüfen und im Rahmen seiner Berechtigungen handeln. Anfragen, die eine Plattformrisikoprüfung erfordern, können dort warten, bevor sie unterzeichnet werden. Überprüfen Sie nach der Genehmigung die Zahlungsaufzeichnung auf Signierung, Übertragung und Kettenbestätigung.

| Was Sie sehen | Wie man es interpretiert |
| --- | --- |
| Warten auf Genehmigung oder Überprüfung | Ein Prüfschritt ist noch offen. Überprüfen Sie den zugewiesenen Prozess. |
| Genehmigt oder wartet auf Unterzeichnung | Die Anfrage kann sich entlang des Signatur-Workflows bewegen. Folgen Sie dem vorhandenen Datensatz. |
| Senden oder auf Bestätigung warten | Das Ergebnis der Kette ist noch in Bearbeitung. Verwenden Sie die Transaktionsreferenz, sofern verfügbar. |
| Ergebnis wird überprüft | Überwachen Sie weiterhin dieselbe Anfrage, bis das Ergebnis bekannt ist. |
| Bestätigt | Der Datensatz hat ein Kettenergebnis, das abgeglichen werden kann. |

Wenn sich ein Ergebnis verzögert, überprüfen Sie die ursprüngliche Anfrage, bevor Sie eine andere Maßnahme ergreifen. Die Kündigungsberechtigung hängt vom tatsächlichen Unterzeichnungsstadium ab. Zur Systemintegration siehe [Transaktionen und Wiederholungsversuche](/de/mpc-wallet/transactions).
