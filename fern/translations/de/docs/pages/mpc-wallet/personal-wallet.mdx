Das persönliche Wallet ist für jemanden gedacht, der seine eigenen digitalen Vermögenswerte verwaltet und die Teilnahme an der Unterzeichnung auf die Geräte oder Knoten in seinem Wallet-Plan verteilen möchte. In einem Arbeitsbereich können Sie Assets anzeigen, Empfangsdetails abrufen, den Übertragungsfortschritt verfolgen und Geräte verwalten.

<span id="set-up-the-wallet-and-devices" data-sixmm-canonical-anchor="set-up-the-wallet-and-devices" aria-hidden="true"></span>

## Richten Sie das Wallet und die Geräte ein

Wählen Sie den persönlichen Arbeitsbereich aus und überprüfen Sie die verfügbaren Schlüsselverwahrungsoptionen. Bei der Selbstverwahrung bleiben die Schlüsselfragmente des Wallets beim Kunden. Das gemeinsame Schlüsselverwahrung überträgt einen Teil des Unterschriftenmaterials auf die Plattform. Auf dem Setup-Bildschirm werden die erforderlichen Teilnehmer für die von Ihnen gewählte Option angezeigt.

Schließen Sie die Geräteregistrierung und Wallet-Initialisierung ab, bevor Sie das Wallet aufladen. Überprüfen Sie das Wiederherstellungsmaterial und das Verfahren zum Geräteaustausch für den ausgewählten Plan. Sehen [Schlüsselverwahrungsmodelle](/de/mpc-wallet/custody-models) Und [Sicherheit und Erholung](/de/mpc-wallet/security-and-recovery).

<span id="receive-and-send-assets" data-sixmm-canonical-anchor="receive-and-send-assets" aria-hidden="true"></span>

## Assets empfangen und senden

1. Öffnen Sie die Asset-Ansicht des Wallets und wählen Sie das Netzwerk für die eingehende Überweisung aus. Kopieren Sie die Empfangsadresse und alle erforderlichen Notizen oder Tags zusammen.
2. Überprüfen Sie den Transaktionsverlauf, nachdem Sie Geld gesendet haben. Vergleichen Sie Netzwerk, Vermögenswert und Betrag mit der erwarteten Übertragung.
3. Überprüfen Sie bei einer ausgehenden Überweisung das Ziel, den Betrag und die Gebühr im Überweisungsablauf. Folgen Sie der Signaturaufgabe auf den erforderlichen Geräten und warten Sie auf das endgültige Transaktionsergebnis.

<span id="example-of-moving-funds-between-your-wallets" data-sixmm-canonical-anchor="example-of-moving-funds-between-your-wallets" aria-hidden="true"></span>

## Beispiel für den Geldtransfer zwischen Ihren Wallets

Angenommen, Sie möchten Vermögenswerte von einer anderen Wallet nach bitMPC verschieben. Erhalten Sie die Empfangsdaten für das gewünschte Netzwerk, überprüfen Sie diese in beiden Wallets und senden Sie einen kleinen Testbetrag, wenn Sie Testzugang haben. Bewahren Sie die Transaktionsreferenz auf, damit Sie den Datensatz später wiederfinden können. Überprüfen Sie beim Versenden von Geldern, ob die unterzeichnenden Teilnehmer für Ihren Plan verfügbar sind.
