Verwandeln Sie Gespräche, Tickets und Wissensaktivitäten in Fragen, auf die Ihr Team reagieren kann. Beginnen Sie mit einem definierten Berichtszeitraum und untersuchen Sie dann die Aufzeichnungen, die einer Änderung der Zahlen zugrunde liegen.

<div className="sixmm-support-flow">

1. **Legen Sie den Zeitraum fest** – Halten Sie Daten und Filter konsistent.
2. **Indikatoren vergleichen** – Sehen Sie sich Lautstärke, Handhabung und Feedback gemeinsam an.
3. **Untersuchen Sie die Aufzeichnungen** – Finden Sie Beispiele und wählen Sie eine konkrete Verbesserung aus.

</div>


<span id="understand-support-activity" data-sixmm-canonical-anchor="understand-support-activity" aria-hidden="true"></span>

## Supportaktivitäten verstehen

Öffnen Sie **Statistik** und wählen Sie den relevanten Zeitraum und die verfügbaren Filter aus. Sehen Sie sich Echtzeitübersichten, Gespräche, Tickets, Zufriedenheit, Nachrichten, Agenten, Feedback und Wissensstatistiken an.

Verwenden Sie mehrere Metriken zusammen. Das Gesprächsvolumen zeigt die Nachfrage, der Ticketstatus zeigt die Nacharbeit und Bewertungen geben Feedback zu individuellen Erlebnissen. Eine hohe Anzahl an Wissensaufrufen allein beweist nicht, dass ein Problem gelöst wurde.

<span id="compare-like-for-like-data" data-sixmm-canonical-anchor="compare-like-for-like-data" aria-hidden="true"></span>

## Vergleichen Sie vergleichbare Daten

Behalten Sie beim Vergleich der Ergebnisse den gleichen Zeitraum, die gleiche Zeitzone, die gleichen Filter und den gleichen Modulumfang bei. Überprüfen Sie die Feldbeschriftungen, anstatt davon auszugehen, dass alle Zahlen einzelne Personen zählen. Wenn sich ein Wert von einem anderen Bildschirm unterscheidet, vergleichen Sie zunächst seine Definition und Filterung.

MCP kann Statistiken abfragen und dabei helfen, Trends zusammenzufassen. Statistikdatensätze können nicht über die schreibgeschützten Statistiktools geändert werden. Bitten Sie darum, den abgefragten Zeitraum und die Quellmetriken in die Zusammenfassung aufzunehmen, damit das Ergebnis in der Konsole überprüft werden kann.


<span id="choose-a-view-for-the-question" data-sixmm-canonical-anchor="choose-a-view-for-the-question" aria-hidden="true"></span>

## Wählen Sie eine Ansicht für die Frage

| Frage | Nützliche Ansichten |
| --- | --- |
| Was hat sich an der Supportnachfrage geändert? | Nachrichten, menschliche Gespräche, Bot-Aktivität und Länderverteilung. |
| Hält sich die Nacharbeit an? | Tickets und Feedback mit demselben Berichtszeitraum. |
| Wie bewerten Besucher den Service? | Zufriedenheit, gefolgt von einem Rückblick auf die zugrunde liegenden Gespräche. |
| Welcher Hilfeinhalt benötigt Aufmerksamkeit? | FAQ und Wissensstatistiken, verglichen mit wiederholten Fragen aus echten Sitzungen. |

<span id="example-prepare-a-weekly-review" data-sixmm-canonical-anchor="example-prepare-a-weekly-review" aria-hidden="true"></span>

### Beispiel: Bereiten Sie einen wöchentlichen Rückblick vor

1. Wählen Sie die vereinbarte Woche aus und erfassen Sie den Datumsbereich und die aktiven Filter in der Überprüfung.
2. Fassen Sie Nachfrage, unfertige Arbeiten und Besucherfeedback separat zusammen. Addieren Sie keine ungleichen Kennzahlen.
3. Öffnen Sie eine kleine Reihe relevanter Gespräche oder Tickets, um die Gründe für die Änderung zu verstehen.
4. Wählen Sie eine konkrete Aktion: Überarbeiten Sie einen unklaren Artikel, aktualisieren Sie eine schnelle Antwort oder überprüfen Sie die Teamabwicklung. Vergleichen Sie den nächsten Zeitraum mit denselben Definitionen.

Sie können eine mit MCP-vernetzte KI bitten, die ausgewählten Statistiken zusammenzufassen und zu untersuchende Fragen zu identifizieren. Fordern Sie es auf, den Zeitraum zu benennen und beobachtete Zahlen von vorgeschlagenen Erklärungen zu unterscheiden.

## Häufige Fragen

<AccordionGroup>

<Accordion title="Bedeutet ein beliebter Artikel, dass er die meisten Fragen beantwortet?">
Ansichten und Interaktionen beschreiben Aktivitäten, keine garantierte Auflösung. Lesen Sie die Fragen und Ergebnisse der Besucher, bevor Sie eine Schlussfolgerung ziehen.
</Accordion>

<Accordion title="Warum zeigen zwei Berichte unterschiedliche Gesamtsummen an?">
Vergleichen Sie zunächst die Zeitbasis, Filter und Metrikdefinition. Sitzungszahlen, Nachrichten und einzelne Besucher sind unterschiedliche Größen.
</Accordion>

</AccordionGroup>
