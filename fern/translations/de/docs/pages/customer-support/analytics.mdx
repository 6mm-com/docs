## Supportaktivitäten verstehen

Öffnen Sie **Statistik** und wählen Sie den relevanten Zeitraum und die verfügbaren Filter aus. Sehen Sie sich Echtzeitübersichten, Gespräche, Tickets, Zufriedenheit, Nachrichten, Agenten, Feedback und Wissensstatistiken an.

Verwenden Sie mehrere Metriken zusammen. Das Gesprächsvolumen zeigt die Nachfrage, der Ticketstatus zeigt die Nacharbeit und Bewertungen geben Feedback zu individuellen Erlebnissen. Eine hohe Anzahl an Wissensaufrufen allein beweist nicht, dass ein Problem gelöst wurde.

<span id="compare-like-for-like-data" data-sixmm-canonical-anchor="compare-like-for-like-data" aria-hidden="true"></span>

## Vergleichen Sie vergleichbare Daten

Behalten Sie beim Vergleich der Ergebnisse den gleichen Zeitraum, die gleiche Zeitzone, die gleichen Filter und den gleichen Modulumfang bei. Überprüfen Sie die Feldbeschriftungen, anstatt davon auszugehen, dass alle Zahlen einzelne Personen zählen. Wenn sich ein Wert von einem anderen Bildschirm unterscheidet, vergleichen Sie zunächst seine Definition und Filterung.

MCP kann Statistiken abfragen und dabei helfen, Trends zusammenzufassen. Statistikdatensätze können nicht über die schreibgeschützten Statistiktools geändert werden. Bitten Sie darum, den abgefragten Zeitraum und die Quellmetriken in die Zusammenfassung aufzunehmen, damit das Ergebnis in der Konsole überprüft werden kann.
