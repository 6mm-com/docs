## Wählen Sie den richtigen Inhaltstyp

Öffnen Sie **Content Management**. Wissenskategorien organisieren Artikel; Die anderen Inhaltstypen bieten prägnante Antworten, Navigation und Service-Einstiegspunkte.

| Inhalt | Typische Verwendung |
| --- | --- |
| Wissensartikel und Kategorien | Detaillierte Anleitungen für Onboarding, Transfers, Handelsregeln und Fehlerbehebung |
| Heiße Fragen | Kurze Antworten auf häufig gestellte Fragen |
| Fragenkategorien und Funktionskarten | Gruppieren Sie Themen und leiten Sie Benutzer zu relevanten Informationen |
| Ankündigungen | Veröffentlichen Sie kundenorientierte Mitteilungen |
| Self-Service-Einträge | Leiten Sie Benutzer zu verfügbaren Supportaktionen oder Ressourcen weiter |

<span id="create-and-maintain-knowledge" data-sixmm-canonical-anchor="create-and-maintain-knowledge" aria-hidden="true"></span>

## Wissen schaffen und pflegen

1. Erstellen oder wählen Sie die entsprechende Kategorie aus. Füllen Sie beim Erstellen eines Artikels die erforderlichen Felder aus, einschließlich der Kategorie.
2. Schreiben Sie den Titel und den Text, einschließlich Umfang, Bedingungen, Schritte und Ausnahmen. Nutzen Sie tatsächliche Geschäftsregeln statt angenommenem Austauschverhalten.
3. Speichern und überprüfen Sie den Entwurf. Veröffentlichen Sie, wenn es für Benutzer bereit ist. Veröffentlichen Sie gegebenenfalls veraltetes Material.
4. Pflegen Sie Übersetzungen und überprüfen Sie den Abruf-/Indexstatus nach Änderungen. Testen Sie die Frage im Bot-Flow und Besucher-Chat.

Beispielsweise sollte in einem Auszahlungsleitfaden erklärt werden, welches Netzwerk der Benutzer wählen muss, wo er die Adresse erhält, welche Geschäftsbeschränkungen gelten und wie er den Support kontaktieren kann. Erfinden Sie keine Bearbeitungszeiten oder Gebühren.

<span id="keep-content-consistent" data-sixmm-canonical-anchor="keep-content-consistent" aria-hidden="true"></span>

## Halten Sie den Inhalt konsistent

Die Aktualisierung der Quelle beweist nicht, dass jede Übersetzung aktuell ist. Überprüfen Sie die betroffenen Übersetzungen und die zugehörigen FAQ-Antworten. Ein veröffentlichter Artikel, eine Antwort auf eine heiße Frage und eine Ankündigung sollten keine inkompatiblen Regeln beschreiben. Prüfen Sie vor dem Löschen, ob der Inhalt noch für die Nutzernavigation oder Antworten benötigt wird. MCP unterstützt dieselben zulässigen Inhaltsvorgänge; sehen [MCP Werkzeuge](/de/customer-support/mcp-tools).
