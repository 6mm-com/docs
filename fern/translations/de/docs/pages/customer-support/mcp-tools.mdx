## Die verfügbaren Tools folgen Ihrer Rolle

Die Tabelle beschreibt den maximal unterstützten Bereich. Ihre KI-Anwendung erhält nur Tools, die für das Autorisierungskonto zulässig sind. Verwenden Sie die Live-Tool-Liste und ihr Parameterschema als Vertrag. Eine neue Konsolenfunktion ist nicht automatisch ein MCP-Tool.

| Konsolenmodul | Unterstützte Operationen |
| --- | --- |
| Online-Gespräche | Lesen Sie Sitzungen, Nachrichten und Warteschlangeninformationen. zuweisen, beitreten, übernehmen und übertragen; Nachrichten senden; Bewertungen einladen; Upload-Berechtigung verwalten; Nachrichten erkennen/übersetzen; Laden Sie unterstützte Dateien hoch |
| Tickets und Feedback | Benutzertickets und Feedback abfragen, zuweisen, Status aktualisieren und löschen; Agententickets erstellen, lesen, aktualisieren, zuweisen und löschen |
| Gesprächsgeschichte | Abfragesitzungen und Nachrichten; Löschen Sie eine einzelne Sitzung oder mehrere Sitzungen |
| Content-Management | Lesen und pflegen Sie Kategorien, Artikel, aktuelle Fragen, Fragekategorien, Funktionskarten, Ankündigungen und Self-Service-Einträge; Artikel veröffentlichen/veröffentlichen |
| Sprachübersetzung | Quellen, Übersetzungen und Fertigstellungsstatus lesen; unterstützte Übersetzungen speichern oder löschen; automatische Übersetzung aufrufen; Verwalten Sie unterstützte Spracheinstellungen |
| Bot-Konfiguration | Lesen Sie unterstützte Einstellungen und FAQs, verwalten Sie ähnliche Fragen, testen Sie Antworten, überprüfen Sie den Abrufstatus, aktualisieren Sie Indizes und erstellen Sie Vektoren neu |
| Agentenverwaltung | Behalten Sie unterstützte Agenten, Rollen und Schnellantworten bei |
| Systemeinstellungen | Lese-/Schreibzugriff auf die Felder „Darstellung“, „Kopieren“, „Konversation“, „Besuchereingabe“, „Intelligenter Service“ und „Website-Zulassungsliste“. |
| Statistiken | Schreibgeschützte Übersicht und unterstützte statistische Abfragen |
| Nutzung und Abrechnung | Nur lesbarer Kontostand, Nutzung, Transaktionen und Preise |
| Betriebsprotokolle | Schreibgeschützte Vorgangsliste und Details |

## Schreibt und Bestätigung

Das Löschen, Veröffentlichen/Aufheben der Veröffentlichung, Bearbeiten veröffentlichter Artikel, Senden von Nachrichten, Rollen-/Kontoverwaltung, Änderungen der Website-Zulassungsliste, Vektorerneuerungen und die automatische Übersetzung der Plattform erfordern eine Backend-Bestätigung, sofern vom Tool angegeben. Ein Schreibvorgang ohne Bestätigung kann dennoch Daten sofort ändern; Überprüfen Sie den beabsichtigten Umfang, bevor Sie die KI mit der Ausführung beauftragen.

MCP bietet keine Plattformverwaltung, Mieterschließung/-löschung, Guthabenaufladung, Rechnungsbearbeitung oder Zugang zum Anbietergeheimnis. Dateitools erzwingen Formatprüfungen und die bereitgestellte Größenbeschränkung; Die aktuelle Implementierung unterstützt eine einzelne Datei bis zu 10 MB über Base64. Verwenden Sie die Konsole für größere Dateien, wenn die eigenen Grenzen dies zulassen.

## Beispielaufgaben

- Listen Sie fehlende Übersetzungen auf und entwerfen Sie japanische Versionen unter Beibehaltung von Links und Beträgen.
- Finden Sie ungelöste Benutzertickets und schlagen Sie Aufgaben vor, ohne sie noch anzuwenden.
- Erstellen Sie einen Wissensartikelentwurf in einer vorhandenen Kategorie und zeigen Sie dann dessen Titel und ID an.
- Fassen Sie aktuelle Supportstatistiken mit dem genauen Datumsbereich zusammen.

Für Plattform-KI, automatische Übersetzung und Vektoroperationen können bestehende Servicegebühren anfallen. Die Eigennutzung des angeschlossenen KI-Anbieters ist davon getrennt.
