Nutzen Sie den Gesprächsverlauf, um den Kontext wiederherzustellen, die Servicequalität zu überprüfen und eine bestimmte Beratung zu untersuchen. Beginnen Sie mit einer Konversationsnummer oder einem engen Zeitbereich, anstatt jeden Datensatz zu durchsuchen.

<div className="sixmm-support-flow">

1. **Suchen Sie die Sitzung** – Wählen Sie Filter und die richtige Datumsbasis.
2. **Lesen Sie den vollständigen Kontext** – Überprüfen Sie Nachrichten, Agenten- und Besucherdetails.
3. **Nachverfolgung** – Verbessern Sie eine Antwort oder setzen Sie den ungelösten Fall fort.

</div>


<span id="find-an-earlier-conversation" data-sixmm-canonical-anchor="find-an-earlier-conversation" aria-hidden="true"></span>

## Suchen Sie nach einem früheren Gespräch

Öffnen Sie **Konversationsverlauf**. Nutzen Sie die verfügbaren Filter für Benutzer-/Sitzungssuche, Konversationstyp, Bewertung, Agent, Kategorie, Sprache und Zeit. Öffnen Sie die Details, um die Nachrichten und Sitzungsinformationen zu lesen.

Die Spalte „Benutzer-E-Mail-Liste“ bevorzugt die Kontakt-E-Mail und verwendet ansonsten die Besucher-E-Mail. Die Detailansicht behält beide Felder bei, sodass Agenten ihre Quellen unterscheiden können. Ein leerer Wert bedeutet, dass das Feld nicht erfasst wurde; es beweist nicht, dass ein Kunde kein E-Mail-Konto hat.

<span id="review-service-quality" data-sixmm-canonical-anchor="review-service-quality" aria-hidden="true"></span>

## Überprüfen Sie die Servicequalität

Nutzen Sie das Gespräch, den Agenten und die Bewertung zusammen, um den Fall zu verstehen. Eine als KI-Nachricht angezeigte Antwort kann aus einer konfigurierten Antwort- oder Matching-Phase und nicht aus einem Anruf mit großem Modell stammen. Vergleichen Sie den Inhalt mit dem aktuellen Wissensstand und nutzen Sie einen Flow-Test, um das Antwortverhalten zu untersuchen.

Das Löschen ist nur mit den entsprechenden Berechtigungen möglich. Lesen Sie die Bestätigung, bevor Sie einen oder mehrere Datensätze löschen. MCP Verlaufsabfragen verwenden den autorisierten Bereich und das Löschen erfordert eine Bestätigung; Gehen Sie nicht davon aus, dass jeder Agent über die vollständige Mandantenhistorie verfügt.


<span id="read-the-fields-without-mixing-identities" data-sixmm-canonical-anchor="read-the-fields-without-mixing-identities" aria-hidden="true"></span>

## Lesen Sie die Felder, ohne Identitäten zu vermischen

| Feld | Interpretation |
| --- | --- |
| Gesprächsnummer | Identifiziert die Konsultation, die Sie überprüfen. Verwenden Sie es, um eine Verwechslung einzelner Sitzungen zu vermeiden. |
| Besuchername | Ein lesbares Anzeigeetikett, kein Beweis für ein verifiziertes Exchange-Konto. |
| Eintragstyp und Benutzer-ID | Helfen Sie dabei, anonymen Zugriff von einer integrierten Anmeldeidentität zu unterscheiden. Fehlende Identitätsdaten sollten nicht erraten werden. |
| Benutzer-E-Mail | Verwendet zuerst die Kontakt-E-Mail und dann die Besucher-E-Mail. Details halten die beiden Quellen getrennt. |
| Sprache und IP Standort | Nützlicher Kontext für den Support, kein Nachweis der Identität des Benutzers oder des genauen physischen Standorts. |
| Bewertung | Feedback, das für diese Sitzung vorhanden ist. Keine Bewertung ist nicht gleichbedeutend mit einer negativen Bewertung. |

<span id="example-review-a-low-rated-consultation" data-sixmm-canonical-anchor="example-review-a-low-rated-consultation" aria-hidden="true"></span>

### Beispiel: Überprüfen Sie eine schlecht bewertete Beratung

1. Filtern Sie nach Bedarf nach Datum, Agent und Bewertung und öffnen Sie dann den vollständigen Datensatz.
2. Lesen Sie, was der Besucher gefragt hat, bevor Sie die Antwort bewerten. Überprüfen Sie, ob eine Übergabe oder ein sprachliches Missverständnis das Gespräch beeinflusst hat.
3. Wenn die Antwort unvollständig war, überprüfen Sie den entsprechenden Wissensinhalt und die Bot-Konfiguration. Ein schlechtes Ergebnis bedeutet nicht immer, dass das Modell selbst gescheitert ist.
4. Bewahren Sie die Sitzungsnummer bei Ihrer internen Nachverfolgung auf, damit das Team auf die gleichen Beweise zurückgreifen kann.

## Häufige Fragen

<AccordionGroup>

<Accordion title="Warum ist die E-Mail leer?">
Die Sitzung hat möglicherweise keine Kontakt-E-Mail erfasst oder keine E-Mail von der Eintragsintegration erhalten. Überprüfen Sie beide Felder im Detail, bevor Sie zu dem Schluss kommen, dass Daten unerwartet fehlen.
</Accordion>

<Accordion title="Warum verändern sich die Ergebnisse durch eine Änderung des Datumsfilters?">
Die Seite kann nach Startzeit oder Schließzeit gefiltert werden. Ein Gespräch, das an einem Tag beginnt und an einem anderen endet, führt bei diesen beiden Optionen zu unterschiedlichen Ergebnissen.
</Accordion>

</AccordionGroup>
