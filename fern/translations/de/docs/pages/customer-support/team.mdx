Geben Sie jedem Agenten ein individuelles Konto, wählen Sie eine Rolle und bereiten Sie überprüfte Schnellantworten vor. Organisieren Sie den Zugriff rund um die Arbeit, die jede Person ausführt, und überprüfen Sie ihn dann mit diesem Konto.

<div className="sixmm-support-flow">

1. **Konto erstellen** – Identifizieren Sie den Agenten und den Kontostatus.
2. **Rolle zuweisen** – Gewähren Sie die für den Job erforderlichen Module und Aktionen.
3. **Überprüfen Sie den Workflow** – Testen Sie den Zugriff und bereiten Sie schnelle Antworten vor.

</div>


<span id="organize-the-support-team" data-sixmm-canonical-anchor="organize-the-support-team" aria-hidden="true"></span>

## Organisieren Sie das Support-Team

Verwenden Sie **Agent Management**, um Agentenkonten, Rollen und Schnellantworten zu verwalten. Weisen Sie Rollen basierend auf den Modulen und Aktionen zu, die jede Person tatsächlich benötigt. Behalten Sie die persönlichen Anmeldeinformationen Ihres Kontos bei, anstatt ein einziges Administrator-Login im gesamten Team zu teilen.

Nachdem Sie eine Rolle geändert haben, überprüfen Sie diese mit dem betroffenen Konto: Sichtbare Menüs, Konversationsüberwachung, Inhaltsbearbeitung und Einstellungszugriff können unterschiedlich sein. Kontostatus-, Sitzungsbesitz- und Feldebenenprüfungen gelten auch über das Vorhandensein eines Menüs hinaus.

<span id="mcp-inherits-the-same-identity" data-sixmm-canonical-anchor="mcp-inherits-the-same-identity" aria-hidden="true"></span>

## MCP erbt dieselbe Identität

Eine MCP-Verbindung ist an das autorisierende Mandanten- und Agentenkonto gebunden. AI erhält keine separate Administratorrolle. Der Dienst bewertet die Kontoberechtigungen bei Anrufen neu. Ein nicht verfügbares Tool kann nicht aktiviert werden, indem man seinen Namen errät oder eine andere Mandanten-ID angibt.

Verwalten Sie verbundene Anwendungen in **Systemeinstellungen → MCP Verbindung**. Nicht mehr benötigte Verbindungen widerrufen. Durch das Abmelden vom Browser wird die Autorisierung einer externen KI-Anwendung nicht automatisch widerrufen.

Rollen- und Agentenkontoänderungen bis MCP erfordern eine Bestätigung. Beim Erstellen eines Agenten über MCP wird das anfängliche Passwort vom Benutzer auf der Backend-Bestätigungsseite eingegeben und nicht an die KI zurückgegeben.


<span id="understand-the-three-management-areas" data-sixmm-canonical-anchor="understand-the-three-management-areas" aria-hidden="true"></span>

## Verstehen Sie die drei Managementbereiche

| Bereich | Was zu pflegen ist |
| --- | --- |
| Agentenkonten | Namen, Anmelde-E-Mails, Rollen, aktivierter Status und die von der Seite bereitgestellten Empfangskontrollen. |
| Rollenmanagement | Die zulässigen Module und Aktionen für eine Gruppe von Agenten. Überprüfen Sie die Auswirkungen auf vorhandene Mitglieder, bevor Sie Änderungen speichern. |
| Schnelle Antworten | Wiederverwendbare Antworttitel, Inhalt, Reihenfolge und aktivierter Status. Überprüfen Sie Übersetzungen, sofern die Funktion verfügbar ist. |

<span id="prepare-an-agent-for-their-first-shift" data-sixmm-canonical-anchor="prepare-an-agent-for-their-first-shift" aria-hidden="true"></span>

### Bereiten Sie einen Agenten auf seine erste Schicht vor

1. Bestätigen Sie die Anmelde-E-Mail-Adresse und die vorgesehene Rolle. Behandeln Sie Kontoverfügbarkeit, Anmeldestatus und Arbeitsstatus nicht als dasselbe.
2. Überprüfen Sie den Überwachungszugriff, die Empfangspriorität und die maximale Anzahl gleichzeitiger Sitzungen, sofern konfiguriert. Diese Steuerelemente ergänzen Rollenberechtigungen.
3. Bitten Sie den Agenten, sich anzumelden und die für seine Arbeit erforderlichen Menüs und Bearbeitungsaktionen zu überprüfen.
4. Bereiten Sie schnelle Antworten auf häufig gestellte Fragen vor und prüfen Sie dann, ob diese aktuelle Links und keine besucherspezifischen Informationen enthalten.

**Übergaberoutine:** Überprüfen Sie offene Verantwortlichkeiten, bevor Sie den Zugriff eines Agenten ändern. Überprüfen Sie nach einer Rollen- oder Kontoänderung die wirksamen Berechtigungen, anstatt sich nur auf den Rollennamen zu verlassen.

## Häufige Fragen

<AccordionGroup>

<Accordion title="Fungiert eine vom Administrator autorisierte KI als gewöhnlicher Agent?">
Nein. Eine MCP-Verbindung verwendet das Konto, das sie autorisiert hat. Verbinden Sie sich mit dem Konto, dessen Zugriff für die beabsichtigte Arbeit geeignet ist.
</Accordion>

<Accordion title="Wird durch das Abmelden die externe KI getrennt?">
Das Abmelden von der Konsole ist unabhängig vom Widerrufen einer MCP-Verbindung. Verwenden Sie die Verbindung Systemeinstellungen → MCP, um einen Antrag zu widerrufen.
</Accordion>

</AccordionGroup>
