Richten Sie ein, wie Besucher den Support betreten, was sie sehen und welche intelligenten Dienste verfügbar sind. Behandeln Sie eine Einstellungsänderung wie eine kleine Freigabe: Speichern Sie sie, testen Sie die tatsächliche Eingabe und überprüfen Sie das Ergebnis.

<div className="sixmm-support-flow">

1. **Wählen Sie die Einstellung** – Suchen Sie die Registerkarte für das Verhalten, das Sie ändern möchten.
2. **Änderung speichern** – Überprüfen Sie den betroffenen Eintrag oder Dienst.
3. **Als Besucher testen** – Öffnen Sie die echte Website und überprüfen Sie das Ergebnis.

</div>


<span id="configure-the-visitor-experience" data-sixmm-canonical-anchor="configure-the-visitor-experience" aria-hidden="true"></span>

## Konfigurieren Sie das Besuchererlebnis

Öffnen Sie **Systemeinstellungen**. Die verfügbaren Steuerelemente hängen von Ihrer Rolle und den aktivierten Mandantendiensten ab.

| Tab | Was zu konfigurieren ist |
| --- | --- |
| Aussehen und Integration | Die verfügbaren visuellen und Eingabeeinstellungen |
| Homepage und Kopie | Kundenorientierter Homepage-Text und Anleitung |
| Gespräch und Auszeit | Konversationsverhalten und Timeout-Kontrollen |
| Besucherdialoge | Die beim Besuchereintritt gesammelten Informationen und Eingabeaufforderungen |
| Intelligente Dienste | Dem Mieter werden KI-, Abruf- und Übersetzungsfunktionen zur Verfügung gestellt |
| Website-Integration | Domain-Zulassungsliste, Einbettungscode, signierte Identität und Sprach-/Themenintegration |
| MCP Verbindung | Serviceadresse, Antrags- und Widerrufsberechtigung |

Speichern Sie die Einstellungen und überprüfen Sie sie dann im Besuchereintrag. Eine Vorschau oder ein erfolgreiches Speichern beweist nicht, dass eine separat eingebettete Website bereits die neuesten Einstellungen verwendet.

<span id="keep-boundaries-clear" data-sixmm-canonical-anchor="keep-boundaries-clear" aria-hidden="true"></span>

## Halten Sie die Grenzen klar

Mandanteneinstellungen konfigurieren den Kundensupport des Mandanten. Sie gewähren keinen Zugriff auf plattformweite Anbieterschlüssel, andere Mieter, Aufladevorgänge oder Börsenhandelskonten. MCP macht nur die unterstützten Konfigurationsfelder verfügbar, die von der aktuellen Rolle zugelassen werden. Änderungen der Domain-Zulassungsliste bis MCP erfordern eine Bestätigung.


<span id="plan-the-initial-setup" data-sixmm-canonical-anchor="plan-the-initial-setup" aria-hidden="true"></span>

## Planen Sie die Ersteinrichtung

1. **Erscheinungsbild und Text:** Überprüfen Sie die sichtbare Marke, die Homepage-Anleitung und den unterstützenden Wortlaut. Sorgen Sie dafür, dass die Beschreibungen mit dem von Ihnen tatsächlich angebotenen Austauschdienst übereinstimmen.
2. **Besuchereintrag:** Entscheiden Sie, welche Informationen gesammelt werden sollen, und überprüfen Sie das verfügbare Eingabeaufforderungsverhalten. Testen Sie ggf. sowohl einen neuen als auch einen wiederkehrenden Besuch.
3. **Empfangsverhalten:** Überprüfen Sie die Sitzungs- und Zeitüberschreitungskontrollen mit dem Team, das Live-Gespräche abwickelt.
4. **Intelligente Dienste:** Überprüfen Sie die aktivierten Mandantenfunktionen und testen Sie dann eine repräsentative Frage oder Übersetzung. Ein konfigurierter Switch allein beweist nicht, dass eine Upstream-Anfrage erfolgreich ist.
5. **Website-Integration:** Überprüfen Sie die zulässige Website-Domain und verwenden Sie den Integrationsleitfaden für Einbettungscode, Anmeldeidentität, Sprache und Thema.
6. **MCP:** Verbinden Sie eine externe KI erst, nachdem Sie das Autorisierungskonto und die verfügbaren Berechtigungen überprüft haben.

<span id="example-a-saved-change-is-not-visible-on-your-website" data-sixmm-canonical-anchor="example-a-saved-change-is-not-visible-on-your-website" aria-hidden="true"></span>

### Beispiel: Eine gespeicherte Änderung ist auf Ihrer Website nicht sichtbar

Überprüfen Sie zunächst den zu testenden Mieter- und Besucherzugang. Laden Sie diesen Eintrag erneut, prüfen Sie, ob die einbettende Website eine eigene Sprache oder ein eigenes Thema übergibt, und bestätigen Sie, dass die beabsichtigte Konfiguration gespeichert wurde. Überprüfen Sie bei Zugriffsfehlern die zulässige Domäne und die Integrationskonfiguration, bevor Sie wiederholt unabhängige Einstellungen ändern.

## Häufige Fragen

<AccordionGroup>

<Accordion title="Warum kann ich die Registerkarte „Einstellungen“ nicht sehen?">
Kontoberechtigungen und aktivierte Mandantendienste bestimmen, was verfügbar ist. Bitten Sie den Mandantenadministrator, den entsprechenden Zugriff zu überprüfen, anstatt einen anderen Mandanten oder ein anderes Konto zu ändern.
</Accordion>

<Accordion title="Wo werden Modellberechtigungen und Aufladungen verwaltet?">
Anbieteranmeldeinformationen und Anpassungen des Plattformgleichgewichts erfolgen außerhalb der Mandanteneinstellungen. Nutzen Sie die mit dem Plattformbetreiber vereinbarten Servicevereinbarungen.
</Accordion>

</AccordionGroup>
