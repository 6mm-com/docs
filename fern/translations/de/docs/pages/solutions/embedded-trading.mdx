Das Embedded API / SDK Trading System ist für Partner konzipiert, die bereits Traffic, Nutzer oder Geschäftsabläufe besitzen und Trading hinzufügen möchten, ohne eine vollständige Börse von Grund auf aufbauen zu müssen.

<h2 id="what-it-provides">Was es bietet</h2>

- Eingebettetes Handelsterminal über die Trading Widget SDK
- Partner-Backend-Integration über Agent SDK
- Benutzer-Identitätsbindungs- und Entry-Token-Flows
- Vermögensübertragung, Bestellung, Position und Kontozugriff API
- Event-, Webhook- und Lebenszyklusintegration für operative Systeme

<h2 id="recommended-architecture">Empfohlene Architektur</h2>

| Schicht | Verantwortung |
| --- | --- |
| Partner-Frontend | Hostet den Einstiegspunkt und integriert die 6MM Handelsoberfläche. |
| Partner-Backend | Bewahrt API Geheimnisse, validiert Nutzer, gibt Einbettungstoken aus und verarbeitet Webhooks. |
| 6MM Handelsinfrastruktur | Verwaltet Handels-UI, Matching, Risiko, Liquidität, Kontostatus und Handelslebenszyklus. |

<h2 id="choose-an-integration-path">Wählen Sie einen Integrationspfad</h2>

| Anforderung | Empfohlener Weg |
| --- | --- |
| Vollständige Handelsoberfläche mit der schnellsten Webintegration | Trading Widget |
| Backend-Benutzerbindung, Übertragung, Eingabe URL und Webhook-Handling | Agent SDK |
| Vollständig individuelle Produkt- und Bestellworkflows | REST API + WebSocket |
| Branded-Exchange-Erfahrung mit einem breiteren operativen Umfang | White-Label-Börse |

Das endgültige Design kann diese Wege kombinieren. Bestätigen Sie die Authentifizierung, den Eigentum an Vermögenswerte, Verantwortungsgrenzen, Überwachung und Produktionsunterstützung, bevor die Implementierung beginnt.
