> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


Agentic Skills sind übergeordnete Workflow-Vorlagen, die auf den Tools CLI und MCP basieren.

Sie definieren, wann ein Agent Tools verwenden soll, welche Aktionen verboten sind, welches Ausgabeformat erstellt werden soll und welche Risikoprüfungen erforderlich sind.

## Empfohlene Fähigkeiten

| Fähigkeit | Zweck | Standardmodus |
| --- | --- | --- |
| 6mm-Marktanalyst | Analysieren Sie Marktzustand, Liquidität, Volatilität und Finanzierung. | Schreibgeschützt |
| 6mm-Portfolio-Risikomanager | Überprüfen Sie die Gefährdung und Risikokonzentration des Kontos. | Konto gelesen |
| 6mm-Finanzierungs-Arbitrage-Forscher | Vergleichen Sie Fördersätze und Forschungsmöglichkeiten. | Schreibgeschützt |
| 6mm-Liquidationsschutz-Assistent | Identifizieren Sie Liquidationsrisiken und Optionen zur Risikominderung. | Konto gelesen |
| 6mm-Auftragsausführungsplaner | Auftragsparameter und Ausführungsansatz planen. | Nur Vorschau |
| 6mm-Trading-Journal-Analyst | Fassen Sie Hinweise zu Füllungen, Verhalten und Risiken zusammen. | Konto gelesen |

<span id="what-each-skill-should-include" data-sixmm-canonical-anchor="what-each-skill-should-include" aria-hidden="true"></span>

## Was jede Fähigkeit beinhalten sollte

- Beabsichtigtes Benutzerszenario.
- Erforderliche CLI- oder MCP-Tools.
- Erlaubte und verbotene Aktionen.
- Erforderliche Berechtigungsstufe.
- Ob der Handel erlaubt ist.
- Ob eine Vorschau obligatorisch ist.
- Ausgabeformat.
- Risikowarnverhalten.
- Beispiel-Benutzeraufforderungen.

## Empfohlene Erstveröffentlichung

Veröffentlichen Sie Fertigkeiten zunächst als Dokumentationsvorlagen. Konvertieren Sie sie erst dann in installierbare Pakete, wenn die zugrunde liegenden Tools und Berechtigungsbereiche stabil sind.
