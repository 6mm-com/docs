> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


Wählen Sie ein Setup basierend auf zwei Fragen:

1. Welchen KI-Client möchten Sie verwenden?
2. Benötigen Sie nur öffentliche Daten, Zugang zu Privatkonten oder Handelsabläufe?

Wenn Sie sich nicht sicher sind, beginnen Sie mit Hosted MCP für öffentliche Daten oder Local MCP für private Konto-Workflows.

## Wählen Sie nach Anwendungsfall

<CardGroup cols={2}>
<Card title="Ich benötige nur öffentliche Marktdaten" icon="fa-duotone fa-cloud" href="/de/ai-hub/hosted-mcp">

## Schnelle Entscheidungstabelle

| Ziel | Empfohlenes Setup | Warum |
| --- | --- | --- |
| Bitten Sie einen KI-Kunden um öffentliche Marktdaten | Gehostet MCP | Keine lokale Installation und kein API-Schlüssel erforderlich. |
| Lassen Sie Claude Desktop, Cursor oder ChatGPT Desktop 6MM-Tools aufrufen | Lokal MCP | KI ruft Tools über einen vom Benutzer kontrollierten lokalen Server auf. |
| Lassen Sie Codex, Claude Code, Gemini CLI oder Skripte 6MM aufrufen | CLI | Die Befehlsausgabe kann JSON sein und für Agenten leicht zu analysieren sein. |
| Stellen Sie einen vom Unternehmen verwalteten MCP-Endpunkt bereit | Fernbedienung MCP | Die Institution kontrolliert Hosting, Anmeldeinformationen, Zugriff und Protokolle. |
| Standardisieren Sie wiederholte Analyse- oder Risikoabläufe | Agentenfähigkeiten | Vorlagen definieren die Werkzeugnutzung, Leitplanken und das Ausgabeformat. |

## Wählen Sie nach Setup-Pfad

| Aufstellen | Installation | API Schlüsselposition | Bester anfänglicher Umfang | Konto- und Handelsumfang |
| --- | --- | --- | --- | --- |
| Gehostet MCP | Keiner | Kein Benutzerschlüssel API für öffentliche Daten | Öffentliche Marktdaten | Nicht für die Erstveröffentlichung empfohlen |
| Lokal MCP | Der Benutzer installiert das Paket | Benutzermaschine | Öffentliche Daten und Account-Lesen | Empfohlener Weg für den zukünftigen Handel |
| CLI | Der Benutzer installiert das Paket | Benutzermaschine | Öffentliche Daten und Skripte | Nützlich für Vorschau und Automatisierung |
| Fernbedienung MCP | Der Benutzer stellt den Server bereit | Benutzer-Cloud oder Institutions-Cloud | Öffentliche Daten oder Account-Lesen | Möglich, wenn der Benutzer die Bereitstellung steuert |
| Fähigkeiten | Dokumente oder installierbare Vorlagen | Hängt von den zugrunde liegenden Tools ab | Analyse-Workflows | Muss den Werkzeugberechtigungen folgen |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## Faustregel für die Sicherheit

Verwenden Sie das Setup mit dem geringsten Risiko, das die Aufgabe unterstützt:

- Öffentliche Marktdaten: Gehostete MCP ist ausreichend.
- Private Kontodaten: Lokal MCP oder benutzerverwaltet Remote MCP.
- Handelsvorschau: Lokal MCP oder CLI, vorzugsweise zuerst Testnet.
- Echter Handel: nur nach ausdrücklicher Genehmigung, Vorschau, Bestätigung, Limits und Prüfprotokollen.
