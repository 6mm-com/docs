> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


Remote MCP ist für Benutzer oder Institutionen gedacht, die einen langlebigen MCP-Endpunkt unter ihrer eigenen Kontrolle haben möchten.

Im Gegensatz zu Hosted MCP wird Remote MCP nicht von 6MM für den Benutzer betrieben. 6MM stellt Code, Bilder, Vorlagen und Dokumentation bereit; Der Benutzer kontrolliert Hosting und Anmeldeinformationen.

<span id="architecture" data-sixmm-canonical-anchor="architecture" aria-hidden="true"></span>

## Architektur

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<span id="deployment-targets" data-sixmm-canonical-anchor="deployment-targets" aria-hidden="true"></span>

## Bereitstellungsziele

- Docker oder Docker Compose.
- VPS mit einem Reverse-Proxy.
- Eisenbahn.
- Machen.
- Fly.io.
- AWS ECS oder Lambda.
- Internes Kubernetes.

<span id="required-files" data-sixmm-canonical-anchor="required-files" aria-hidden="true"></span>

## Erforderliche Dateien

- Docker-Datei.
- docker-compose.yml.
- .env.template.
- HTTP Transportmodus.
- /mcp-Endpunkt.
- /health-Endpunkt.
- Reverse-Proxy- und TLS-Notizen.

<span id="credential-model" data-sixmm-canonical-anchor="credential-model" aria-hidden="true"></span>

## Berechtigungsmodell

Anmeldeinformationen sollten in der benutzerverwalteten Umgebung gespeichert werden, nicht in der AI-Client-Eingabeaufforderung. Beschränken Sie bei von Institutionen verwalteten Bereitstellungen den Zugriff auf genehmigte Clients und Netzwerke.

<span id="recommended-first-release" data-sixmm-canonical-anchor="recommended-first-release" aria-hidden="true"></span>

## Empfohlene Erstveröffentlichung

Beginnen Sie mit öffentlichen Marktdaten. Fügen Sie ein schreibgeschütztes Konto hinzu, nachdem Authentifizierung, Schlüsselbereichsbestimmung, Protokolle und Zugriffskontrollen verfügbar sind. Der Handel sollte deaktiviert bleiben, bis die Anforderungen für den kontrollierten Handel erfüllt sind.
