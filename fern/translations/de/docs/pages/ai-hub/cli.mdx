6MM CLI ist der Befehlszeilen-Einstiegspunkt für Benutzer, Skripte und KI-Agenten, die Shell-Befehle ausführen können.

Verwenden Sie CLI, wenn die KI-Umgebung Terminalbefehle direkt ausführen kann. Dies ist oft der einfachste Weg für Codierungsagenten, da kein separater MCP-Server erforderlich ist. Das CLI sollte standardmäßig stabiles JSON zurückgeben, damit Agenten Ergebnisse analysieren können, ohne auf die Terminalformatierung angewiesen zu sein.

<span id="what-the-cli-is-good-for" data-sixmm-canonical-anchor="what-the-cli-is-good-for" aria-hidden="true"></span>

## Wofür der CLI gut ist

- Schnelle Abfrage von Marktdaten über ein Terminal.
- Agentengesteuerte Analyse in Codex, Claude Code, Gemini CLI oder ähnlichen Tools.
- CI oder geplante Skripte, die 6MM Daten benötigen.
- Kontoleseprüfungen, wenn lokale Anmeldeinformationen konfiguriert sind.
- Bestellvorschau-Abläufe, bei denen der Agent Parameter vorbereitet, aber keine Bestellung aufgibt.

<span id="example-commands" data-sixmm-canonical-anchor="example-commands" aria-hidden="true"></span>

## Beispielbefehle

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

<span id="output-modes" data-sixmm-canonical-anchor="output-modes" aria-hidden="true"></span>

## Ausgabemodi

| Modus | Anwendungsfall |
| --- | --- |
| JSON | Standard für KI-Agenten, Skripte und Automatisierung. |
| Tisch | Überprüfung des für Menschen lesbaren Terminals. |
| Roh | Debugging- und Integrationstests. |

<span id="recommended-safety-defaults" data-sixmm-canonical-anchor="recommended-safety-defaults" aria-hidden="true"></span>

## Empfohlene Sicherheitsvorgaben

- Die Standardumgebung ist testnet.
- Die Standardausgabe ist JSON.
- Handelsbefehle erfordern eine ausdrückliche Einwilligung.
- Die Erstellung einer Mainnet-Bestellung erfordert eine Bestätigung.
- Vor dem Erstellen ist der Vorschaumodus verfügbar.
- Zu den Fehlern gehören stabile Codes und klare Nachrichten.

<span id="agent-usage" data-sixmm-canonical-anchor="agent-usage" aria-hidden="true"></span>

## Agentennutzung

KI-Agenten sollten schreibgeschützte Befehle bevorzugen, es sei denn, der Benutzer fordert ausdrücklich eine Vorschau oder Handelsaktionen an.

Beispielaufforderung:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
