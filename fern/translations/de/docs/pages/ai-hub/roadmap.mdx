> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


AI Hub sollte schrittweise veröffentlicht werden, damit Benutzer frühzeitig einen Mehrwert erhalten und gleichzeitig sensible Handelsfunktionen geschützt bleiben.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## Phase 1: Zugang zu KI auf dem öffentlichen Markt

Ziel: jedem unterstützten KI-Client das Lesen offizieller 6MM-Marktdaten ermöglichen.

Leistungen:

- Freigegebener SDK/API-Client.
- CLI öffentliche Marktbefehle.
- Lokale MCP öffentliche Marktinstrumente.
- Gehostete MCP öffentliche Markttools.
- Ressourcen für Märkte, Gebühren, Risikoregeln und Systemstatus.
- Client-Installationshandbücher.

Nicht enthalten:

- Kontoanfragen.
- Echter Handel.
- API Schlüsselhosting.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Phase 2: Konto lesen

Ziel: Benutzern die sichere Einsicht in den eigenen Kontokontext ermöglichen.

Leistungen:

- Schreibgeschützter API-Schlüsselbereich.
- Kontozusammenfassung.
- Salden.
- Positionen.
- Offene Bestellungen.
- Füllt.
- Förderzahlungen.
- Aufforderung zum Portfoliorisiko.

Bevorzugte Bereitstellung:

- Lokal MCP.
- CLI.
- Remote MCP selbst gehostet.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Phase 3: Handelsvorschau

Ziel: KI bei der Generierung von Aufträgen helfen lassen, ohne sie auszuführen.

Leistungen:

- `preview_order`.
- Risikoprüfungen.
- Auswirkungen auf die Marge.
- Kostenvoranschlag.
- Auswirkungen auf die Liquidation.
- Aufforderung zur Ausführungsplanung.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Phase 4: Kontrollierter Handel

Ziel: Echten Handel nur mit starken Leitplanken unterstützen.

Leistungen:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- Idempotenz.
- maximale fiktive Grenzen.
- ausdrückliche Bestätigung.
- Audit-Protokolle.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Phase 5: Agentenfähigkeiten

Ziel: gemeinsame Marktanalysen und Risiko-Workflows produzieren.

Leistungen:

- Fähigkeiten als Marktanalyst.
- Fähigkeit zum Portfoliorisiko.
- Forschungskompetenz finanzieren.
- Fähigkeit zum Liquidationsschutz.
- Fähigkeit zur Ausführungsplanung.
- Beispiel-Aufgabenbibliothek.
