> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


VS Code und GitHub Copilot sind nützlich für die SDK-Implementierung, die API-Signierung und die Partner-Backend-Integration.

<h2 id="recommended-setup">Empfohlenes Setup</h2>

| Brauchen | Aufstellen |
| --- | --- |
| Editorintegrierter Kontext | Lokal MCP, sofern unterstützt |
| Terminalüberprüfung | 6MM CLI |
| Team-Workflow-Vorlagen | Agentenfähigkeiten |

<h2 id="security-notes">Sicherheitshinweise</h2>

Platzieren Sie keine API-Geheimnisse in Frontend-Code, an die Quellcodeverwaltung übergebenen Erweiterungseinstellungen oder freigegebenen Arbeitsbereichsdateien.
