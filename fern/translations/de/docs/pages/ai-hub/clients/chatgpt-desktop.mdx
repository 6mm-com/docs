> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


ChatGPT Desktop ist ein vertrauter Einstiegspunkt für Benutzer, die Marktfragen in natürlicher Sprache stellen möchten.

Verwenden Sie diesen Pfad, wenn der Benutzer eine Konversationsschnittstelle für öffentliche Marktdaten, Kontozusammenfassungen, Positionserklärungen und den Kontext von Handelsregeln wünscht.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Empfohlenes Setup

| Brauchen | Aufstellen |
| --- | --- |
| Öffentliche Marktdaten | Gehostet MCP |
| Kontext des privaten Kontos | Lokal MCP |
| Wiederholbare Analyseaufforderungen | Agentenfähigkeiten |
| Terminalbasierte Arbeitsabläufe | 6MM CLI |

<span id="what-users-can-ask" data-sixmm-canonical-anchor="what-users-can-ask" aria-hidden="true"></span>

## Was Benutzer fragen können

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<span id="safety-defaults" data-sixmm-canonical-anchor="safety-defaults" aria-hidden="true"></span>

## Sicherheitsvorgaben

- Beginnen Sie mit öffentlichen Marktdaten.
- Verwenden Sie Local MCP, wenn Kontoanmeldeinformationen erforderlich sind.
- Behalten Sie private API-Schlüssel auf dem Computer des Benutzers.
- Vor jeder zukünftigen Handelsaktion sind eine Vorschau und eine ausdrückliche Bestätigung erforderlich.
