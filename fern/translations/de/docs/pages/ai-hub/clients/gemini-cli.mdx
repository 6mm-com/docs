Gemini CLI funktioniert am besten mit Befehlszeilenausgaben, die überprüft, zusammengefasst und an Folgeaufgaben übergeben werden können.

<h2 id="recommended-setup">Empfohlenes Setup</h2>

| Brauchen | Aufstellen |
| --- | --- |
| Öffentliche Marktkontrollen | 6MM CLI |
| Geskriptete Recherche | 6MM CLI |
| Kontext des privaten Kontos | Lokal MCP oder CLI mit lokalen Anmeldeinformationen |

<h2 id="example-prompts">Beispielaufforderungen</h2>

```text
Use 6MM CLI to fetch market metadata and summarize tradable pairs.
```

```text
Use 6MM to compare fee and margin rules for two symbols.
```

<h2 id="output-format">Ausgabeformat</h2>

Bevorzugen Sie strukturierte Ausgaben wie JSON oder Markdown-Tabellen, damit der KI-Client über das Ergebnis nachdenken kann, ohne an Präzision zu verlieren.
