> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


MCP Tools sind Aktionen, die ein KI-Client aufrufen kann. Jedes Tool sollte eine klare Beschreibung, ein JSON-Schema, eine Berechtigungsanforderung, ein stabiles Antwortformat und ein Fehlermodell haben.

## Phase 1: Instrumente des öffentlichen Marktes

| Werkzeug | Zweck |
| --- | --- |
| 6mm_system_status | Prüfen Sie Service und Marktverfügbarkeit. |
| 6mm_Märkte | Listen Sie verfügbare Märkte und grundlegende Metadaten auf. |
| 6mm_market_summary | Fassen Sie den Marktzustand für ein oder mehrere Symbole zusammen. |
| 6mm_Ticker | Gibt die neuesten Tickerdaten zurück. |
| 6mm_Bestellbuch | Tiefe des Retouren-Orderbuchs. |
| 6mm_Klines | Geben Sie historische Kerzen zurück. |
| 6mm_trades | Geben Sie die letzten öffentlichen Trades zurück. |
| 6mm_funding_rates | Geben Sie aktuelle und historische Finanzierungsraten zurück. |

| Werkzeug | Zweck |
| --- | --- |

<span id="tool-requirements" data-sixmm-canonical-anchor="tool-requirements" aria-hidden="true"></span>

## Werkzeuganforderungen

Jedes Tool sollte Folgendes definieren:

- Beschreibung für das KI-Modell.
- Geben Sie das Schema JSON ein.
- Berechtigungsbereich.
- Umweltunterstützung.
- Ratengrenzverhalten.
- Stabile Antwortfelder.
- Fehlercodes.
- Audit-Log-Felder.
