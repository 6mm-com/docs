> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


MCP Ressourcen sind schreibgeschützter Kontext, den KI-Clients prüfen können, bevor sie Tools aufrufen.

Ressourcen reduzieren Halluzinationen, indem sie dem Modell stabile, strukturierte Informationen über 6MM liefern.

<h2 id="recommended-resource-uris">Empfohlene Ressourcen-URIs</h2>

| Ressource | Zweck |
| --- | --- |
| 6mm://system/config | Umgebungs- und Leistungskonfiguration. |
| 6mm://system/status | Aktueller System- und Marktstatus. |
| 6mm://Märkte | Verfügbare Märkte. |
| 6mm://market/{symbol} | Vertragsspezifikationen und Metadaten auf Marktebene. |
| 6mm://Gebühren | Gebührenordnung. |
| 6mm://risiko/regeln | Zusammenfassung der Handels- und Risikoregeln. |
| 6mm://Risiko/Marge | Margin- und Liquidationskontext. |
| 6mm://Finanzierung/Regeln | Regeln für die Finanzierungsrate. |
| 6mm://api/docs | API Referenzzusammenfassung oder Links. |

<h2 id="resource-design-rules">Regeln für das Ressourcendesign</h2>

- Halten Sie Ressourcen schreibgeschützt.
- Verwenden Sie stabile Schemata.
- Fügen Sie Zeitstempel und Umgebungsnamen hinzu.
- Vermeiden Sie es, Geheimnisse preiszugeben.
- Bevorzugen Sie prägnante strukturierte Daten gegenüber langer Prosa.
- Link zur kanonischen Dokumentation, wenn die Details zu lang sind.
