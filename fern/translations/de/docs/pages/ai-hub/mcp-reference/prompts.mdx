> **Geplant – noch nicht gestartet**
> AI Hub ist eine geplante Funktion. Die Funktionen, Endpunkte, Befehle und Clientkonfigurationen auf dieser Seite beschreiben das vorgeschlagene Design und sind derzeit nicht verfügbar. Die endgültige Verfügbarkeit und Einrichtungsanweisungen werden beim Start bekannt gegeben.


MCP-Eingabeaufforderungen sind wiederverwendbare Workflows, die vom MCP-Server bereitgestellt werden. Sie helfen Benutzern, konsistente Fragen zu stellen und KI-Kunden dabei zu helfen, die richtigen Tools zu verwenden.

<h2 id="recommended-prompts">Empfohlene Eingabeaufforderungen</h2>

| Prompt | Zweck |
| --- | --- |
| Marktübersicht | Fassen Sie den Marktzustand für ausgewählte Symbole zusammen. |
| Markt_Mikrostruktur_Analyse | Analysieren Sie Spread, Tiefe, aktuelle Trades und Liquiditätsbedingungen. |
| portfolio_risk_assessment | Überprüfen Sie Positionen, Engagement, Marge und Liquidationsrisiko. |
| position_management | Helfen Sie Benutzern, den Positionsstatus und mögliche Aktionen zu verstehen. |
| liquidation_protection | Identifizieren Sie Liquidationsrisiken und Optionen zur Risikominderung. |
| Finanzierungsrate_Opportunity | Vergleichen Sie Fördersätze und mögliche Möglichkeiten. |
| create_optimal_order | Bestellparameter vor der Vorschau planen. |
| hedging_strategy | Erkunden Sie Absicherungsmöglichkeiten für bestehende Risiken. |
| Trading_Beratung | Erstellen Sie eine strukturierte Handelsanalyse, ohne Aufträge auszuführen. |

<h2 id="prompt-safety-rules">Sofortige Sicherheitsregeln</h2>

- Behandeln Sie schnelle Ergebnisse nicht als Finanzberatung.
- Führen Sie keine Handelstools aus, es sei denn, der Benutzer fordert ausdrücklich dazu auf.
- Verwenden Sie vor dem Erstellen die Vorschau.
- Erläutern Sie Annahmen und Datenquellen.
- Bevorzugen Sie Testnet-Beispiele in der öffentlichen Dokumentation.
