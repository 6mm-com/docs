Ein angebotenes Spiel oder Angebot garantiert nicht, dass jede vorgeschlagene Bestellung angenommen werden kann. Verfügbare Mittel, Produktkonfiguration und Risikokontrollen wirken sich alle auf die Akzeptanz aus.

<span id="allgemeine-einschränkungen" data-sixmm-anchor-target="common-restrictions" aria-hidden="true"></span>
<h2 id="common-restrictions">Allgemeine Einschränkungen</h2>

| Beschränkung | Wirkung |
| --- | --- |
| Spiel oder Symbol deaktiviert | Das ausgewählte Produkt ist für neue Bestellungen nicht verfügbar |
| Zeitraum nicht aktiviert | Diese Dauer kann für das Symbol nicht ausgewählt werden |
| Mindest-/Höchstwert einer Einzelbestellung | Der Einsatz muss innerhalb des angezeigten zulässigen Bereichs liegen |
| Kumulative Beteiligungs- oder Exposure-Kontrolle | Auch bei Gültigkeit des Einzeleinsatzes können weitere Bestellungen eingeschränkt werden |
| Kontrolle der Quotenabweichung | Für ein Angebot kann eine Überprüfung erforderlich sein oder die Eingabe von Vorhersagen kann eingeschränkt sein |
| Grid-Zitat über dem Maximum | Die Zelle ist gemäß der Rasterpreisregel nicht verfügbar |
| Geschlossenes Wettfenster | Eine neue Bestellung kann im geschlossenen Fenster nicht angenommen werden |

Das Verwaltungsmodell umfasst Warnungen, Überprüfungen, Vorhersagebeschränkungen und verzögerte Auftragsabwicklung. Die tatsächliche Reaktion hängt von der ausgelösten Regel ab; Gehen Sie nicht davon aus, dass jede Grenze zum gleichen Ergebnis führt.

<span id="einsatz--und-modellrisiko" data-sixmm-anchor-target="stake-and-model-risk" aria-hidden="true"></span>
<h2 id="stake-and-model-risk">Einsatz- und Modellrisiko</h2>

Eine verlorene Order ohne Auszahlung verliert ihren Einsatz. Höhere Quoten sind kein Beweis für eine bessere Chance: Sie können eine geringere geschätzte Trefferwahrscheinlichkeit widerspiegeln. Ein Zielrenditeparameter garantiert nicht die Rendite einer Person.

<span id="konfigurationsänderungen" data-sixmm-anchor-target="configuration-changes" aria-hidden="true"></span>
<h2 id="configuration-changes">Konfigurationsänderungen</h2>

Überprüfen Sie vor einer neuen Bestellung die aktuellen Produkteinstellungen. Bei akzeptierten benutzerdefinierten und Rasterbestellungen verhindern beibehaltene Quoten und relevante Bestellschnappschüsse, dass eine spätere Bildschirmaktualisierung die akzeptierten Bedingungen neu definiert.

<span id="wenn-eine-bestellung-nicht-verfügbar-ist" data-sixmm-anchor-target="when-an-order-is-unavailable" aria-hidden="true"></span>
<h2 id="when-an-order-is-unavailable">Wenn eine Bestellung nicht verfügbar ist</h2>

Überprüfen Sie den Produktwechsel, das verfügbare Guthaben, die Limits, das Angebot und den Zeitpunkt. Übermitteln Sie nicht wiederholt erneut, um eine Einschränkung zu umgehen. Behalten Sie die Antwort- und Bestellkennung bei, falls eine solche erstellt wurde.
