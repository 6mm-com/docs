Jeder akzeptierte Vorhersageauftrag hat eine eigene Auftragsnummer. Auf-/Ab-Befehle beziehen sich ebenfalls auf eine Runde; Für kundenspezifische und Grid-Bestellungen ist keine gemeinsame Runde erforderlich.

<span id="aktuelle-und-historische-aufzeichnungen" data-sixmm-anchor-target="current-and-historical-records" aria-hidden="true"></span>
<h2 id="current-and-historical-records">Aktuelle und historische Aufzeichnungen</h2>

| Angezeigter Status | Wie man es liest |
| --- | --- |
| Warten auf Ergebnis | Es liegt noch kein endgültiges Ergebnis vor |
| Wetten geschlossen | Die angezeigte Wettphase ist geschlossen; Dies ist kein Gewinn/Verlust-Ergebnis |
| Won | Die Bestellung wird als erfolgreiches Ergebnis erfasst |
| Verloren | Die Bestellung wird als Verlustergebnis erfasst |
| Erstattet | Die Rückerstattungsbearbeitung spiegelt sich im Bestellstatus wider; die tatsächliche Transaktion abgleichen |
| Entwertet | Die Bestellung wird ungültig; Überprüfen Sie den Grund und die damit verbundene Mittelbehandlung |

Nicht jedes Spiel nutzt jeden Zwischenstatus auf die gleiche Weise. Eine Statusanzeige allein beweist nicht, dass die Kontogutschrift abgeschlossen ist.

<span id="zu-überprüfende-felder" data-sixmm-anchor-target="fields-to-check" aria-hidden="true"></span>
<h2 id="fields-to-check">Zu überprüfende Felder</h2>

Bei allen Spielen werden die Bestellnummer, der Benutzerbesitz, das Symbol, der Einsatz, die Gewinnchancen, die Bestellzeit und der Status angezeigt. Zu den historischen Aufzeichnungen gehören die tatsächliche Auszahlung, Ergebnisinformationen, Abwicklungszeit und Abwicklungstransaktionsnummer.

- Auf/Ab fügt die Rundenzahl und die vorhergesagte/tatsächliche Richtung hinzu.
- Benutzerdefiniert fügt feste Quoten und den unabhängigen Ablauf hinzu.
- Raster fügt die ausgewählte Zelle und das Preisintervall hinzu; Interpretieren Sie Ergebnisfelder mithilfe der Zeitfenster-Berührungsregel.

<span id="änderungen-und-doppelte-einreichungen" data-sixmm-anchor-target="changes-and-duplicate-submissions" aria-hidden="true"></span>
<h2 id="changes-and-duplicate-submissions">Änderungen und doppelte Einreichungen</h2>

Gehen Sie nicht davon aus, dass eine Prediction Order wie eine Perpetual Limit Order geändert oder storniert werden kann. Befolgen Sie die für das akzeptierte Produkt verfügbaren Aktionen und Regeln. Wenn eine Übermittlungsantwort unsicher ist, fragen Sie die ursprüngliche Bestellung ab, bevor Sie einen weiteren Einsatz platzieren.
