Ausnahmen können Preisunterbrechungen, inkonsistente Preisnachweise, Quotenunterschiede oder eine fehlgeschlagene Abwicklungsverarbeitung sein. Eine Ausnahme erfordert eine aufgezeichnete Lösung; es ist nicht automatisch ein Verlustergebnis.

<span id="common-situations" data-sixmm-canonical-anchor="common-situations" aria-hidden="true"></span>

## Häufige Situationen

| Situation | Was zu tun |
| --- | --- |
| Während des gültigen Fensters fehlt die Netzeinspeisung | Ausnahme-/Rückerstattungsbearbeitung prüfen; Eine fehlende Probe kann keinen Beweis für ein Versehen darstellen |
| Zeitüberschreitung bei der Bestellantwort | Sehen Sie sich die ursprüngliche Bestellung und Reservierung an, bevor Sie sie erneut absenden |
| Anzeige und aufgezeichnetes Ergebnis stimmen nicht überein | Vergleichen Sie Preisquelle, Zeitstempel, akzeptierte Bedingungen und Ergebnisnachweise |
| Die Abwicklung scheint verzögert zu sein | Überprüfen Sie den Endstatus und die Transaktion separat |
| Zurückerstatteter oder ungültiger Datensatz | Überprüfen Sie den Grund, die tatsächliche Geldbewegung und die verbleibende Reservierung |

<span id="refund-and-void-are-distinct" data-sixmm-canonical-anchor="refund-and-void-are-distinct" aria-hidden="true"></span>

## Rückerstattung und Nichtigkeit sind unterschiedlich

Eine Rückerstattung beschreibt die Fondsbehandlung. Eine Annullierung beschreibt die Ungültigkeit einer Bestellung. Den genauen Rückerstattungsbetrag oder die Bearbeitungsfrist können Sie nicht allein aus dem Etikett ableiten; Verwenden Sie die aufgezeichneten Auflösungen und Transaktionen.

Erstattete und stornierte Bestellungen sind von der gültigen Teilnahme an der Berichterstattung ausgeschlossen. Rückerstattungen sollten bei der Beurteilung der Spielleistung nicht als Gewinne gewertet werden.

<span id="support-evidence" data-sixmm-canonical-anchor="support-evidence" aria-hidden="true"></span>

## Belege unterstützen

Geben Sie die Bestellnummer, gegebenenfalls die runde Zahl, das Symbol, relevante Zeitstempel, den aufgezeichneten Auszahlungsmultiplikator, das Ergebnis/den Status und die Abrechnungstransaktionsnummer an. Geben Sie bei Netzstreitigkeiten das akzeptierte Preisintervall und das gültige Zeitfenster an. Geben Sie niemals Passwörter, API Geheimnisse oder Vollzugriffstoken an.

Verwenden [Partnerunterstützung](/de/resources/contact/support) für den Supportweg und [Überweisungen und Transaktionen](/de/prediction/transfers-ledger) zur Versöhnung.
