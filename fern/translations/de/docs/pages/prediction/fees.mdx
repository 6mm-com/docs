Die Prognosegebühren müssen zusammen mit den Quoten der angenommenen Bestellung und der von Ihrer Partnerplattform veröffentlichten Gebührentabelle gelesen werden. In diesem Leitfaden wird kein allgemeingültiger Gebührensatz festgelegt.

<span id="unterscheiden-sie-die-beträge" data-sixmm-anchor-target="distinguish-the-amounts" aria-hidden="true"></span>
<h2 id="distinguish-the-amounts">Unterscheiden Sie die Beträge</h2>

| Artikel | Bedeutung |
| --- | --- |
| Quotenmultiplikator | Bestimmt die Bruttogewinnrendite gemäß den Bestellbedingungen |
| Zielrückgabeparameter | Eine Preismodelleingabe; keine eigenständige Gebührentransaktion |
| Separat ausgewiesene Servicegebühr | Eine Gebühr zum Abgleich, sofern sie für das Produkt/die Bestellung gilt |
| Abrechnung der Partnereinnahmen | Eine Zuteilung auf Unternehmensebene, nicht automatisch eine weitere Benutzerbestellgebühr |

Das Betriebsmodell umfasst als Gebührenkategorie die Servicegebühren für Prognoseplattformen. Das Vorhandensein dieser Kategorie legt keinen Tarif, keinen Abrechnungszeitpunkt oder die Frage fest, ob eine bestimmte Bestellung separat berechnet wird.

<span id="vor-dem-absenden-prüfen" data-sixmm-anchor-target="check-before-submitting" aria-hidden="true"></span>
<h2 id="check-before-submitting">Vor dem Absenden prüfen</h2>

- Ob für das ausgewählte Spiel und Konto eine Gebühr anfällt.
- Die Gebührenbasis und -höhe sowie der Zeitpunkt der Erhebung.
- Ob die angezeigte Rücksendung vor oder nach einer gesondert erhobenen Gebühr erfolgt.
- Wie Gebühren für erstattete oder stornierte Bestellungen behandelt werden.

Wenn diese Bedingungen unklar sind, fordern Sie den entsprechenden Zeitplan an [Partnerunterstützung](/de/resources/contact/support) vor dem Handel.

<span id="abgleichen-ohne-doppelten-abzug" data-sixmm-anchor-target="reconcile-without-deducting-twice" aria-hidden="true"></span>
<h2 id="reconcile-without-deducting-twice">Abgleichen ohne doppelten Abzug</h2>

Ein Quotenparameter und eine separate Gebühr sind unterschiedliche Datensätze. Ziehen Sie keinen abgeleiteten Prozentsatz von einer Auszahlung ab, der bereits die akzeptierten Quoten widerspiegelt. Gleichen Sie nur die tatsächlich offengelegten Gebühren und Transaktionen ab.

Sehen [Auszahlungen und PnL](/de/prediction/returns-pnl) Und [Überweisungen und Transaktionen](/de/prediction/transfers-ledger).
