Die Up/Down-Vorhersage gruppiert Bestellungen in geplante Runden. Benutzer wählen aus, ob der Abrechnungspreis höher oder niedriger als der Eröffnungspreis der Runde sein soll.

<span id="so-nehmen-sie-teil" data-sixmm-anchor-target="how-to-participate" aria-hidden="true"></span>
<h2 id="how-to-participate">So nehmen Sie teil</h2>

1. Wählen Sie ein aktiviertes Symbol und einen aktivierten Punkt aus.
2. Überprüfen Sie die Rundenzahl, den Eröffnungspreis, das Wettfenster und die Zeit für die Ergebnisauswertung.
3. Wählen Sie „Nach oben“ oder „Nach unten“ und geben Sie den Einsatz ein.
4. Überprüfen Sie die angebotenen Quoten und die erwartete Auszahlung und senden Sie sie dann ab, während die Wette geöffnet ist.
5. Verfolgen Sie die Bestellung in ihrer Runde, überprüfen Sie das Endergebnis und senden Sie sie zurück.

<span id="rundenzeiten" data-sixmm-anchor-target="round-times" aria-hidden="true"></span>
<h2 id="round-times">Rundenzeiten</h2>

| Zeit | Bedeutung |
| --- | --- |
| Wettstart | Die Runde beginnt mit der Annahme von Befehlen |
| Wetten knapp | Neue Wetten für diese Runde werden nicht mehr akzeptiert |
| Ergebnisauswertungszeit | Die geplante Ergebnisauswertungszeit |
| Abschluss der Siedlung | Der aufgezeichnete Abschluss der Abrechnungsverarbeitung |

Die Dauer einer Runde und ihr Einsatzfenster sind unterschiedliche Einstellungen. Verwenden Sie die angezeigten Zeitstempel, anstatt davon auszugehen, dass die Wetten für den gesamten Zeitraum offen bleiben.

<span id="richtungsergebnis" data-sixmm-anchor-target="direction-result" aria-hidden="true"></span>
<h2 id="direction-result">Richtungsergebnis</h2>

| Preisvergleich | Richtung |
| --- | --- |
| Der Abrechnungspreis ist höher als der Eröffnungspreis | Hoch |
| Der Abrechnungspreis ist niedriger als der Eröffnungspreis | Runter |

Ein gleicher Preis legt keine Richtung fest. Überprüfen Sie die Gleichpreisregel der jeweiligen Runde. Behandeln Sie Gleichheit nicht als automatischen Verlust oder Rückerstattung.

<span id="quoten-und-beispiel" data-sixmm-anchor-target="odds-and-example" aria-hidden="true"></span>
<h2 id="odds-and-example">Quoten und Beispiel</h2>

Die angebotenen Quoten ändern sich mit den Up- und Down-Pools und dem vorgeschlagenen Einsatz, vorbehaltlich konfigurierter Limits. Ein späteres Pool-Angebot allein identifiziert nicht die Abwicklungsbedingungen einer früheren Order; Verwenden Sie die aufgezeichneten Bedingungen dieser Bestellung.

Wenn der Eröffnungspreis beispielsweise 65.000 und der Abrechnungspreis 65.100 beträgt, ist die Richtung Aufwärts. Ein akzeptierter Gewinneinsatz von 100 USDT bei einem aufgezeichneten Auszahlungsmultiplikator von 1,85x hat eine Bruttoauszahlung von 185 USDT vor einer separat ausgewiesenen Gebühr. Diese Zahlen veranschaulichen die Berechnung, kein Produktionsangebot.
