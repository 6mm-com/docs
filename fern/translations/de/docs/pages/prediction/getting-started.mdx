Bevor Sie eine Bestellung aufgeben, stellen Sie sicher, dass die Vorhersage für Ihr Konto aktiviert ist und Sie den Ergebniszustand des Spiels erkennen können.

<span id="bereiten-sie-ihr-konto-vor" data-sixmm-anchor-target="prepare-your-account" aria-hidden="true"></span>
<h2 id="prepare-your-account">Bereiten Sie Ihr Konto vor</h2>

Greifen Sie über Ihre Partnerplattform auf Vorhersagen zu. Überprüfen Sie den verfügbaren Saldo des Finanzierungskontos, die Abrechnungswährung und etwaige Teilnahmebeschränkungen. Ein Guthaben auf einem anderen Konto ist nicht automatisch für die Vorhersage verfügbar.

<span id="wählen-sie-eine-bestellung-aus" data-sixmm-anchor-target="select-an-order" aria-hidden="true"></span>
<h2 id="select-an-order">Wählen Sie eine Bestellung aus</h2>

| Spiel | Überprüfen Sie dies, bevor Sie einen Betrag eingeben |
| --- | --- |
| Up/Down-Vorhersage | Symbol, Rundenzahl, Richtung, Wettabschlusszeit und Ergebnisauswertungszeit |
| Benutzerdefinierte Vorhersage | Symbol, Richtung, ausgewählte Dauer und die Zeitbedingungen des Auftrags |
| Vorhersageraster | Symbol, Preisunter- und -obergrenzen sowie gültige Start- und Endzeiten |

<span id="überprüfen-und-abschicken" data-sixmm-anchor-target="review-and-submit" aria-hidden="true"></span>
<h2 id="review-and-submit">Überprüfen und abschicken</h2>

1. Geben Sie einen Betrag innerhalb der angezeigten Einzelbestellgrenzen ein.
2. Überprüfen Sie das aktuelle Angebot und die erwartete Auszahlung. Ein Angebot kann sich vor der Annahme ändern.
3. Lesen Sie die Ergebnisregel, etwaige Gebührenoffenlegungen und die relevante Annahmeschlusszeit.
4. Senden Sie es einmal ab und prüfen Sie dann, ob eine Bestellnummer und akzeptierte Bedingungen verfügbar sind.

> **Eine unsichere Antwort ist keine fehlgeschlagene Bestellung.**
> Wenn die Seite eine Zeitüberschreitung erfährt, überprüfen Sie die aktuellen Bestellungen und Kontotransaktionen, bevor Sie sie erneut übermitteln. Durch wiederholtes Klicken können separate Bestellungen erstellt werden.

<span id="überprüfen-sie-das-ergebnis" data-sixmm-anchor-target="check-the-result" aria-hidden="true"></span>
<h2 id="check-the-result">Überprüfen Sie das Ergebnis</h2>

Verfolgen Sie die Reihenfolge anhand aktueller und historischer Aufzeichnungen. Nutzen Sie die tatsächliche Auszahlungs- und Abrechnungstransaktion, um die Mittel abzugleichen. Bei der vor der Abrechnung angezeigten erwarteten Auszahlung handelt es sich nicht um einen verfügbaren Saldo.
