Sicherheits- und Compliance-Dokumentation wird für Partnerteams erstellt, die die Produktionsnutzung 6MM Handelsinfrastruktur vorbereiten. Sie verbindet Sicherheitsarchitektur, API/SDK Kontrollen, Compliance-Vorbereitung, rechtliche Grenzen und Startbereitschaft in einem Prüfpfad.

<h2 id="documentation-map">Dokumentationskarte</h2>

| Gebiet | Zweck |
| --- | --- |
| Sicherheitsarchitektur | Verstehen Sie, wie Handelsinfrastruktur, API/SDK Zugang sowie Partneraktivitäten geschützt sind. |
| API und Webhook-Sicherheit | Schützen Sie Backend-Integrationen durch Signing, geheime Speicherung und Idempotent-Verarbeitung. |
| Compliance-Bereitschaft | Bereiten Sie den Lizenzsupport-Kontext, Startprüfungen und Partner-seitigen operativen Kontrollen vor. |
| Rechtsdokumente | Überprüfen Sie die Bedingungen, Datenschutz- und Verantwortungsgrenzen vor dem Produktionsstart. |

<h2 id="recommended-reading-order">Empfohlene Lesereihenfolge</h2>

1. Beginnen Sie mit Sicherheitsarchitektur und Partnerverantwortungsgrenze.
2. Überprüfung API Key Management, Request Signing und Webhook-Idempotenz vor der Backend-Integration.
3. Überprüfen Sie die Compliance-Übersicht und die Lizenzunterstützung vor der Vorbereitung auf den regionalen Start.
4. Überprüfen Sie die rechtlichen Seiten und die Startcheckliste, bevor Sie die Handelsfunktionen den Nutzern offenstellen.
