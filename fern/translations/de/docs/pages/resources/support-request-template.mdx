Wenn Sie den Support kontaktieren, geben Sie die untenstehenden Informationen an, wann immer verfügbar.

<span id="required-context" data-sixmm-canonical-anchor="required-context" aria-hidden="true"></span>

## Erforderlicher Kontext

| Spielfeld | Beispiel |
| --- | --- |
| Umwelt | Produktion oder Inszenierung |
| Betroffenes Modul | Trading Widget, Agent SDK, REST API, WebSocket, Webhook, White-Label-System |
| Zeitspanne | UTC Zeitstempelbereich, in dem das Problem aufgetreten ist |
| Partner-Benutzer-ID | Partnerseitige Benutzerkennung, falls relevant |
| 6MM Kartierungs-ID | agentUserId, Bestell-ID, Anfrage-ID oder Webhook-Event-ID |
| Wirtschaftliche Auswirkungen | Anzahl der betroffenen Nutzer oder Operationen und ob das Problem weiterhin existiert |

<span id="description-format" data-sixmm-canonical-anchor="description-format" aria-hidden="true"></span>

## Beschreibungsformat

- Was ist passiert?
- Was hast du erwartet?
- Kann es reproduziert werden?
- Was hat sich kürzlich geändert?
- Gibt es das Problem immer noch?

<span id="attachments" data-sixmm-canonical-anchor="attachments" aria-hidden="true"></span>

## Anhänge

- Relevante Anfrage- und Antwortprotokolle.
- Screenshots oder Bildschirmaufnahmen.
- Webhook-Payload und Signatur-Header.
- Fehler in der Browser-Konsole für Trading Widget Probleme.

<span id="copyable-template" data-sixmm-canonical-anchor="copyable-template" aria-hidden="true"></span>

## Kopierbare Vorlage

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Entfernen Sie Felder, die nicht relevant sind, behalten Sie aber den UTC Zeitrahmen und mindestens eine durchsuchbare Anfrage oder Geschäftskennung wann immer möglich bei.

<span id="redact-sensitive-data" data-sixmm-canonical-anchor="redact-sensitive-data" aria-hidden="true"></span>

## Sensible Daten schwärzen

Nicht senden:

- Passwörter oder Vollzugriffstoken
- API Geheimnisse, private Schlüssel oder vollständige Unterschriften
- Session-Cookies
- Vollständige Zahlung, Identität oder andere unnötige personenbezogene Daten

Behalten Sie den Feldnamen und ein kurzes Präfix oder Suffix nur dann auf, wenn der Support zwischen beeinsichtigten Werten unterscheiden muss.

<span id="choose-the-right-channel" data-sixmm-canonical-anchor="choose-the-right-channel" aria-hidden="true"></span>
