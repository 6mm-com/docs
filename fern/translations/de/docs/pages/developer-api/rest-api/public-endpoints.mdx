## Basis URL

```
https://api.6mm.com
```

<span id="service-version" data-sixmm-canonical-anchor="service-version" aria-hidden="true"></span>

## Dienstversion

```http
GET /v1/version
```

Holen Sie sich Informationen zur Serviceversion.

<span id="server-time" data-sixmm-canonical-anchor="server-time" aria-hidden="true"></span>

## Serverzeit

```http
GET /v1/time
```

Erhalten Sie Serverzeit. Dieser Endpunkt kann verwendet werden, um die Client-Zeit vor dem API Key Signieren zu kalibrieren.

<span id="user-login" data-sixmm-canonical-anchor="user-login" aria-hidden="true"></span>

## Benutzeranmeldung

```http
POST /v1/public/user/login
```

Anfrageparameter:

| Parameter    | Typ   | Erforderlich | Beschreibung                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | Ja      | Benutzername, Länge 3 - 32                 |
| `password`   | string | Ja      | Passwort, Länge 1 - 64                 |
| `deviceId`   | string | Nein       | Geräte-Fingerabdruck, bis zu 64 Zeichen |
| `deviceName` | string | Nein       | Gerätname, bis zu 128 Zeichen       |

Beispiel für eine Anfrage:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

Antwortbeispiel:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<span data-sixmm-canonical-anchor="refresh-token" aria-hidden="true"></span>

## Refresh Token

```http
POST /v1/public/user/refresh-token
```

In normalen Integrationsszenarien wird der Login-Status per Cookie aktualisiert. Behalten Sie das Cookie durch die Login-Antwort zurück.

Antwortfelder:

| Spielfeld          | Typ   | Beschreibung              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | New access Token         |
| `accessExpire` | int64  | Ablaufzeit des Access Tokens |

<span data-sixmm-canonical-anchor="agent-sso" aria-hidden="true"></span>

## Agent SSO

<span id="ticket-exchange" data-sixmm-canonical-anchor="ticket-exchange" aria-hidden="true"></span>

## Fahrkartenaustausch

```http
POST /v1/public/agent-sso/exchange-ticket
```

Anfrageparameter:

| Parameter  | Typ   | Erforderlich | Beschreibung                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | Ja      | Einmaliges Ticket vom Agentenservice ausgestellt |
| `deviceId` | string | Nein       | Geräte-Fingerabdruck, bis zu 64 Zeichen     |

Antwortfelder:

| Spielfeld          | Typ   | Beschreibung              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Zugangstoken             |
| `accessExpire` | int64  | Ablaufzeit des Access Tokens |
| `redirectPath` | string | Vorgeschlagener Umleitungspfad  |

<span id="embed-token-exchange" data-sixmm-canonical-anchor="embed-token-exchange" aria-hidden="true"></span>

## Embed-Token-Börse

```http
POST /v1/public/agent-sso/exchange-embed-token
```

Anfrageparameter:

| Parameter    | Typ   | Erforderlich | Beschreibung                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | Ja      | Kurzlebiger von dem Agentendienst ausgegebener eingebetteter Handelstoken |
| `channelId`  | string | Ja      | Eingebettete iframe-Kanal-ID, bis zu 128 Zeichen               |
| `deviceId`   | string | Nein       | Geräte-Fingerabdruck, bis zu 64 Zeichen                        |

Antwortfelder:

| Spielfeld          | Typ   | Beschreibung              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Zugangstoken             |
| `accessExpire` | int64  | Ablaufzeit des Access Tokens |

<span id="pnl-leaderboard" data-sixmm-canonical-anchor="pnl-leaderboard" aria-hidden="true"></span>

## PnL-Bestenliste

```http
GET /v1/public/leaderboard/pnl?period=30d
```

Anfrageparameter:

| Parameter | Typ   | Erforderlich | Beschreibung          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | Ja      | `7d` / `30d` / `90d` |

Antwortfelder:

| Spielfeld              | Typ   | Beschreibung                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | Rang                                                              |
| `list[].userId`    | string | Externe Benutzer-ID                                                  |
| `list[].trader`    | string | Name maskierter Händler                                                |
| `list[].volume`    | string | Handelsvolumen im Fenster                                      |
| `list[].pnlAmount` | string | PnL im Fenster realisiert                                        |
| `list[].pnlPct`    | string | PnL-Verhältnis, dezimal von `0` bis `1`                                |
| `myRank`           | int32  | Der Rang des aktuellen Nutzers. Wird `0` zurückgegeben, wenn er nicht authentifiziert oder nicht gerankt ist |
