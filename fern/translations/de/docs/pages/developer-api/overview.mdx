<h2 id="production-checklist">Produktionscheckliste</h2>

- Speichere API Geheimnisse nur im Backend.
- Serverzeit vor signierten Anfragen synchronisieren.
- Behandle alle numerisch präzisen Felder als Zeichenketten, sofern nicht ausdrücklich etwas anderes auf einer Seite steht.
- Verwenden Sie Idempotenz, Anfrage-IDs und strukturierte Logs rund um Orderflüsse.
- Abonnieren Sie WebSocket Streams für Zustände, die in den Betriebssystemen aktuell bleiben müssen.
- Überprüfen Sie Fehlercodes und Wiederholungsverhalten vor dem Start.
