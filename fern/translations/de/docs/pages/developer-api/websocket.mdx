<h2 id="service-endpoint">Service Endpoint</h2>

```
wss://ws.6mm.com/ws
```

WebSocket Kanäle sind in öffentliche und private Kanäle unterteilt:

| Typ             | Authentifizierung              | Beschreibung                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Öffentliche Kanäle  | Nicht erforderlich                | Marktdaten wie Tiefe, Trades, Klines und Ticker |
| Private Kanäle | `listenKey` oder JWT erforderlich | Nutzerbestellungen, Konten und Positionsströme              |

<h2 id="public-channels">Öffentliche Kanäle</h2>

Öffentliche WebSocket erfordert keine Authentifizierung. Nach der Verbindung senden Sie eine `subscribe` Anfrage, um Marktkanäle zu abonnieren.

Häufige Kanäle:

| Kanal                            | Beschreibung                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Bestelle Buchtiefe. Es wird zuerst ein Snapshot gesendet, dann inkrementelle Updates |
| `market.trade.{symbol}`            | Neueste Trades                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Einzelsymbol-Ticker-Zusammenfassung                                       |
| `market.tickers`                   | Zusammenfassung des All-Symbol-Tickers                                          |

<h2 id="private-channels">Private Kanäle</h2>

<h2 id="listenkey">listenKey</h2>
Für private WebSocket -Streams erstellen Sie zuerst ein `listenKey` durch die REST API und verbinden Sie sich dann mit:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
Kompatible JWT Verbindungsmethode:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Nach erfolgreicher Authentifizierung abonniert der Server automatisch die Verbindung auf den privaten Kanal des aktuellen Nutzers. Ein manuelles Abonnement ist nicht erforderlich.
