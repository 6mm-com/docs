In diesem Leitfaden wird der Finanzierungsweg für den Handel mit unbefristeten Verträgen erläutert. Auf dem Finanzierungskonto stehen Mittel zur Zuweisung zur Verfügung; Das unbefristete Konto enthält Vertragsmargen und Abrechnungssalden. Für diese Route ist kein Spotkonto erforderlich.

<span id="partner-managed-deposits-and-withdrawals" data-sixmm-canonical-anchor="partner-managed-deposits-and-withdrawals" aria-hidden="true"></span>

## Finanzierung über Ihre Plattform

Befolgen Sie für Partner-Integrationen API / SDK den Guthabenzuweisungs- und Finanzierungsprozess der Partnerplattform. Bei White-Label-Bereitstellungen folgen Ein- und Auszahlungen dem konfigurierten Wallet-Anbieter-Prozess der Plattform; Bestätigte Einzahlungen werden dem Finanzierungskonto gutgeschrieben und Auszahlungen über dieses Konto.

Überprüfen Sie die verfügbare Finanzierungsmethode auf Ihrer Plattform. Eine interne Kontoübertragung ist von einer Ein- oder Auszahlung getrennt.

<span id="account-structure-within-6mm" data-sixmm-canonical-anchor="account-structure-within-6mm" aria-hidden="true"></span>

## Konten, die für den ewigen Handel genutzt werden

| Konto | Zweck |
| --- | --- |
| <span style={{ whiteSpace: "nowrap" }}>Finanzierungskonto</span> | Hält Gelder zur Zuweisung bereit und erhält Gelder, die vom Dauerkonto zurücküberwiesen werden. Nutzen Sie das verfügbare Guthaben, wenn Sie eine Überweisung vorbereiten. |
| <span style={{ whiteSpace: "nowrap" }}>Unbefristetes Konto</span> | Enthält Gelder, die für die Vertragsmarge und die Abrechnung verwendet werden. Überprüfen Sie das Kontoguthaben, die Margin-Nutzung sowie nicht realisierte Gewinne und Verluste, bevor Sie handeln oder eine Überweisung tätigen. |

<span id="automated-balance-transfer-to-6mm" data-sixmm-canonical-anchor="automated-balance-transfer-to-6mm" aria-hidden="true"></span>

## Bereiten Sie eine Überweisung vor

1. Bestätigen Sie den Benutzer, das Asset und die Übertragungsrichtung.
2. Überprüfen Sie das verfügbare Guthaben des Quellkontos und etwaige Kontobeschränkungen.
3. Übermitteln Sie es über den von der Plattform unterstützten Transfereintrag oder die autorisierte Integration.
4. Bestätigen Sie das Überweisungsergebnis und den Zielsaldo, bevor Sie eine Bestellung aufgeben.

<span id="internal-transfers-between-accounts" data-sixmm-canonical-anchor="internal-transfers-between-accounts" aria-hidden="true"></span>

## Übertragung zwischen Finanzierungs- und Dauerkonten

- Vor dem Handel: Übertragen Sie das erforderliche Abrechnungsguthaben vom Finanzierungskonto auf das Dauerkonto.
- Nach der Abrechnung: Überweisen Sie den zur Abhebung verfügbaren Betrag vom Dauerkonto zurück auf das Finanzierungskonto.
- Kontoübertragungen sind interne Saldobewegungen, keine On-Chain-Transaktionen.
- Die Verwendung von Margen, offene Aufträge, Positionen und Kontobeschränkungen können sich auf den für die Überweisung verfügbaren Betrag auswirken. Verwenden Sie den von der Plattform angezeigten Betrag und das Ergebnis.

<span id="design-principles" data-sixmm-canonical-anchor="design-principles" aria-hidden="true"></span>

## Überprüfen Sie den Status und gleichen Sie die Salden ab

Eine eingereichte Anfrage allein bestätigt nicht den Abschluss. Überprüfen Sie die Überweisungs-ID, den Status, das Guthaben, den Betrag, das Quellkonto und das Zielkonto. Wenn die Verarbeitung fehlschlägt oder ungelöst bleibt, überprüfen Sie die Kontostandaufzeichnungen und wenden Sie sich an den Plattform-Support, bevor Sie eine weitere Anfrage einreichen.

Gehen Sie nicht davon aus, dass alle Guthaben frei übertragen werden können oder dass jede Überweisung sofort oder gebührenfrei erfolgt. Befolgen Sie die auf der Plattform angezeigten Bedingungen und das endgültige Verarbeitungsergebnis.
