La Guía de Trading explica cómo los usuarios pasan del acceso y financiamiento al trading de contratos perpetuos, y cómo las reglas centrales de trading afectan órdenes, posiciones, comisiones y riesgo de liquidación.

Esta sección está escrita para producto, operaciones, soporte y educación para usuarios finales. Para API campos, firmas y detalles de integración de backend, usa las secciones de Desarrolladores y SDK .

<h2 id="before-trading">Antes de operar</h2>

- Confirmar que el usuario ingresa a través de un socio autorizado o incrustado 6MM entrada.
- Asegurarse de que los fondos estén disponibles en la cuenta correcta antes de realizar pedidos.
- Entender el apalancamiento, el margen, la liquidación y el comportamiento de las comisiones de financiamiento.
- Comenzar con posiciones pequeñas al aprender un nuevo mercado o modo de negociación.
- Usar TP / SL y órdenes solo de reducción cuando sea apropiado para el control de riesgos.
