La planificación de licencias es parte de un plan de lanzamiento más amplio. El camino correcto depende de los mercados objetivo, tipo de usuario, alcance del producto, modelo de custodia y las responsabilidades operativas de cada parte.

<h2 id="planning-inputs">Insumos de planificación</h2>

| Entrada | Por qué importa |
| --- | --- |
| Jurisdicción objetivo | Determina las expectativas regulatorias y la revisión local requerida. |
| Tipo de usuario | Los usuarios minoristas, profesionales, institucionales o distribuidos por socios pueden requerir controles diferentes. |
| Alcance del producto | Las funciones de spot, derivados, cartera, custodia y corretaje pueden cambiar el modelo de cumplimiento. |
| Modelo operativo | Los modelos de marca blanca, embebidos, corredores e institucionales tienen diferentes límites de responsabilidad. |

<h2 id="how-to-use-this-documentation">Cómo usar esta documentación</h2>

Usa estos documentos para alinear los requisitos técnicos y operativos antes de la revisión legal. La documentación puede ayudar a los equipos a describir la arquitectura, el flujo de datos, la firma, la seguridad, el movimiento de activos y las responsabilidades del ciclo de vida del trading.

> **Importante**
>
> Las decisiones de licenciamiento deben ser revisadas con asesores legales y de cumplimiento calificados para la jurisdicción correspondiente.
