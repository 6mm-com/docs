Al contactar al soporte, incluye la información a continuación siempre que esté disponible.

<span id="required-context" data-sixmm-canonical-anchor="required-context" aria-hidden="true"></span>

## Contexto requerido

| Campo | Ejemplo |
| --- | --- |
| Medio ambiente | Producción o puesta en escena |
| Módulo afectado | Trading Widget, Agent SDK, REST API, WebSocket, webhook, sistema de marca blanca |
| Intervalo de tiempo | UTC rango de marca de tiempo cuando ocurrió el problema |
| ID de usuario del socio | Identificador de usuario del lado del socio, si es relevante |
| ID de mapeo 6MM | agentUserId, ID de orden, ID de solicitud o ID de evento de webhook |
| Impacto en el negocio | Número de usuarios o operaciones afectadas y si el problema sigue en curso |

<span id="description-format" data-sixmm-canonical-anchor="description-format" aria-hidden="true"></span>

## Formato de la descripción

- ¿Qué pasó?
- ¿Qué esperabas que pasara?
- ¿Se puede reproducir?
- ¿Qué cambió recientemente?
- ¿El problema sigue ocurriendo?

<span id="attachments" data-sixmm-canonical-anchor="attachments" aria-hidden="true"></span>

## Adjuntos

- Registros relevantes de solicitudes y respuestas.
- Capturas de pantalla o grabaciones de pantalla.
- Encabezados de carga útil y firma Webhook.
- Errores en la consola del navegador por Trading Widget problemas.

<span id="copyable-template" data-sixmm-canonical-anchor="copyable-template" aria-hidden="true"></span>

## Plantilla copiable

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Elimina los campos que no sean relevantes, pero mantén el rango de tiempo UTC y al menos una solicitud o identificador de negocio buscable siempre que sea posible.

<span id="redact-sensitive-data" data-sixmm-canonical-anchor="redact-sensitive-data" aria-hidden="true"></span>

## Redactar datos sensibles

No envíes:

- Contraseñas o tokens de acceso completo
- API secretos, claves privadas o firmas completas
- Cookies de sesión
- Pago completo, identidad u otros datos personales innecesarios

Mantén el nombre del campo y un prefijo o sufijo corto solo cuando soporte necesite distinguir entre valores sanitizados.
