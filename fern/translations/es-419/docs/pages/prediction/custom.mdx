La predicción personalizada permite a los usuarios iniciar pedidos independientes eligiendo Arriba o Abajo y una duración disponible. No es necesario unirse a la siguiente ronda arriba/abajo programada.

## Cómo participar

1. Elija un símbolo y una de sus duraciones habilitadas.
2. Seleccione Arriba o Abajo e ingrese una apuesta permitida.
3. Revise las probabilidades fijas para esa duración y el pago esperado.
4. Después de la aceptación, verifique el precio de apertura registrado, el tiempo de la orden, el vencimiento y las probabilidades.
5. Al vencimiento, siga el resultado de la liquidación en el historial de pedidos.

## Cada pedido tiene sus propios términos

| Término registrado | Objetivo |
| --- | --- |
| Símbolo y dirección | Identifica la serie de precios y el resultado seleccionado. |
| Precio de apertura | La base de comparación para este pedido. |
| Duración y caducidad | Define cuándo vence esta orden |
| Apuestas y probabilidades fijas | Define el monto aceptado y el multiplicador de devolución. |
| Precio de liquidación y resultado | Registra el resultado |

Las cuotas fijas configuradas para un período se aplican en ambas direcciones. Una vez aceptada, la orden almacena una instantánea de las probabilidades; cambios de configuración posteriores no lo reemplazan.

## Resultado y ejemplo

Un precio de liquidación mayor corresponde a Up y un precio menor a Down. La manipulación de precios iguales debe seguir la regla de producto aplicable.

Para una orden Down ilustrativa con un precio de apertura de 3000 y un precio de liquidación de 2990, gana la dirección seleccionada. Una apuesta de 100 USDT con probabilidades fijas de 1,85x devuelve 185 USDT antes de las tarifas reveladas por separado, incluida la apuesta; el beneficio neto bruto es 85 USDT.

## Cosas que comprobar

- Dos órdenes realizadas en momentos diferentes pueden tener precios de apertura y resultados diferentes.
- Utilice el tiempo de caducidad aceptado, no una cuenta atrás del navegador, al comprobar un resultado.
- No es necesario que una duración habilitada o un valor de probabilidades fijas para un símbolo se apliquen a otro.
