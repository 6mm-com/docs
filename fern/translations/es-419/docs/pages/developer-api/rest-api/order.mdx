> los endpoints de órdenes requieren permiso comercial.

<h2 id="place-order">Orden de lugares</h2>

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Parámetros de solicitud:**

| Parámetro       | Tipo   | Obligatorio               | Descripción                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Sí                    | Símbolo                                                                                                                        |
| `type`          | string | Sí                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Sí                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | No                     | `BOTH` / `LONG` / `SHORT`, por defecto `BOTH`                                                                                     |
| `price`         | string | Requerido condicionalmente | Requerida para órdenes límite                                                                                                     |
| `quantity`      | string | Requerido condicionalmente | Cantidad. Se puede omitir cuando `closePosition=true`                                                                            |
| `timeInForce`   | string | No                     | `GTC` / `IOC` / `FOK`, por defecto `GTC`                                                                                          |
| `reduceOnly`    | bool   | No                     | Solo reducir, por defecto `false`                                                                                                  |
| `makerOnly`     | bool   | No                     | Solo para creadores, `false` predeterminada                                                                                                   |
| `closePosition` | bool   | No                     | Cierra toda la posición, por defecto `false`                                                                                    |
| `clientOrderId` | string | No                     | ID de orden definido por el cliente                                                                                                       |
| `placeType`     | string | No                     | Marcador de tipo de colocación de orden                                                                                                   |
| `priceType`     | int32  | No                     | BBO tipo de precio: `0` precio especificado, `1` precio del oponente 1, `2` precio del oponente 5, `3` precio del mismo lado 1, `4` precio del mismo lado 5 |

**Solicito ejemplo:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Campos de respuesta:**

| Campo           | Tipo   | Descripción             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | ID de orden del servidor         |
| `clientOrderId` | string | ID de orden definido por el cliente |
| `status`        | string | Estado de la orden            |
| `timestamp`     | int64  | Marca de tiempo               |

<h2 id="batch-place-orders">Pedidos por lotes</h2>

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Solicito cuerpo:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Campos de respuesta:**

| Campo          | Tipo  | Descripción                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Número de órdenes exitosas |
| `failedCount`  | int32 | Número de órdenes fallidas     |
| `results[]`    | array | Resultado para cada orden       |

<h2 id="place-condition-order">Orden de Condición de Lugar</h2>

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Parámetros de solicitud:**

| Parámetro       | Tipo   | Obligatorio               | Descripción                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Sí                    | Símbolo                                                                                      |
| `type`          | string | Sí                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Sí                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | No                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Requerido condicionalmente | Obligatorio para `STOP_LIMIT` / `TAKE_PROFIT_LIMIT`                                             |
| `quantity`      | string | Requerido condicionalmente | Cantidad. Se puede omitir cuando `closePosition=true`                                          |
| `timeInForce`   | string | No                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | No                     | Solo reducir                                                                                 |
| `clientOrderId` | string | No                     | ID de orden definido por el cliente                                                                     |
| `stopPrice`     | string | Requerido condicionalmente | Precio de disparo                                                                               |
| `workingType`   | string | No                     | `MARK_PRICE` / `CONTRACT_PRICE`, por defecto `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | No                     | Si la protección de precios está habilitada                                                         |
| `activatePrice` | string | Requerido condicionalmente | Precio de activación de órdenes posteriores                                                             |
| `callbackRate`  | string | Requerido condicionalmente | Tasa de callback en el orden final                                                                |
| `closePosition` | bool   | No                     | Cierra toda la posición                                                                   |

**Campos de respuesta:**

| Campo             | Tipo   | Descripción            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | ID de orden de condición     |
| `conditionStatus` | string | Estado del orden de condición |
| `timestamp`       | int64  | Marca de tiempo              |

<h2 id="place-strategy-order">Lugar Orden de Estrategia</h2>

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Parámetros de solicitud:**

| Parámetro      | Tipo   | Obligatorio | Descripción             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Sí      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Sí      | Lista de subórdenes          |

Los campos en `subOrderList[]` son en su mayoría iguales a los órdenes normales y los órdenes de condición, con campos de dependencia adicionales:

| Parámetro        | Tipo   | Descripción                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | ID de suborden                                    |
| `firstDrivenId`  | int64  | Primer ID de orden de manejo. `0` significa sin dependencia |
| `firstDrivenOn`  | string | Primera condición detonante                         |
| `firstTrigger`   | string | Primera acción de disparo                            |
| `secondDrivenId` | int64  | Segunda identificación de orden de conducción                         |
| `secondDrivenOn` | string | Segunda condición desencadenante                        |
| `secondTrigger`  | string | Segunda acción de gatillo                           |

**Campos de respuesta:**

| Campo            | Tipo   | Descripción     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | ID de estrategia     |
| `strategyStatus` | string | Estado de la estrategia |
| `timestamp`      | int64  | Marca de tiempo       |

<h2 id="query-single-order">Consulta en un solo orden</h2>

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Parámetros de solicitud:**

| Parámetro       | Tipo   | Obligatorio | Descripción             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Sí      | Símbolo                  |
| `orderId`       | string | No       | ID de orden del servidor         |
| `clientOrderId` | string | No       | ID de orden definido por el cliente |

Al menos uno de `orderId` y `clientOrderId` debe ser proporcionado. Si ambos se proporcionan, el servidor realiza una coincidencia exacta en ambas condiciones.


<h2 id="cancel-all">Cancelar todo</h2>

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Parámetros de solicitud:**

| Parámetro    | Tipo   | Obligatorio | Descripción                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | No       | Símbolo                                                                              |
| `cancelType` | int32  | No       | `0` todas las órdenes normales, `1` solo órdenes límite, `2` todas las órdenes de condición. Default `0` |

La cancelación total para órdenes normales se acepta de manera asíncrona. El estado final debe ser determinado por WebSocket `ORDER_TRADE_UPDATE` o por los endpoints de consulta.
