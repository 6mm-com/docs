A menos que se especifique lo contrario, los siguientes puntos finales pueden usar JWT o API Key firma.

<h2 id="user-info">Información de usuario</h2>

```http
GET /v1/private/user/info
```

Campos de respuesta:

| Campo                  | Tipo   | Descripción      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | ID de usuario externo |
| `userInfo.username`    | string | Nombre de usuario         |
| `userInfo.agentId`     | int64  | ID de agente         |
| `userInfo.vipLevel`    | int64  | VIP nivel        |
| `userInfo.lastLoginAt` | int64  | Última hora de inicio de sesión  |
| `userInfo.lastLoginIp` | string | Último inicio de sesión IP    |

<h2 id="user-assets">Activos de usuario</h2>

```http
GET /v1/private/user/asset
```

Campos de respuesta:

| Campo                     | Tipo   | Descripción                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | ID de usuario externo                |
| `userAsset.assetType`     | string | Tipo de activo                      |
| `userAsset.walletBalance` | string | Saldo de cartera                  |
| `userAsset.frozenMargin`  | string | Margen congelado por órdenes pendientes |
| `userAsset.usedMargin`    | string | Margen utilizado por posiciones        |

<h2 id="create-listenkey">Crea listenKey</h2>

```http
POST /v1/private/user/listen-key
```

Crea una clave de autenticación para flujos de WebSocket privados.

<h2 id="renew-listenkey">Renovar listenKey</h2>

```http
PUT /v1/private/user/listen-key
```

Extiende listenKey validez.

<h2 id="close-listenkey">Cierra listenKey</h2>

```http
DELETE /v1/private/user/listen-key
```

Cierra la listenKeyespecificada.

<h2 id="account-change-logs">Registros de Cambios de Cuenta</h2>

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Parámetros de la solicitud:

| Parámetro    | Tipo   | Obligatorio | Descripción                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | No       | Tipo de activo, como `USDT`   |
| `changeType` | string | No       | Cambio de tipo                  |
| `startTime`  | int64  | No       | Hora de inicio                   |
| `endTime`    | int64  | No       | Fin del tiempo                     |
| `page`       | int32  | No       | Número de página, `1` predeterminado     |
| `pageSize`   | int32  | No       | Elementos por página, `20` predeterminado |

Campos de respuesta:

| Campo                        | Tipo   | Descripción                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Tipo de activo                   |
| `list[].amount`              | string | Cantidad cambiada               |
| `list[].walletBalanceBefore` | string | Saldo de la cartera antes del cambio |
| `list[].walletBalanceAfter`  | string | Saldo de la cartera después del cambio  |
| `list[].frozenBalanceBefore` | string | Saldo congelado antes del cambio |
| `list[].frozenBalanceAfter`  | string | Saldo congelado después del cambio  |
| `list[].changeType`          | string | Cambio de tipo                  |
| `list[].referenceId`         | string | ID de negocio relacionado          |
| `list[].createdAt`           | int64  | Tiempo de creación                |
| `total`                      | int64  | Conteo total                  |

<h2 id="30-day-volume-statistics">Estadísticas de Volumen a 30 Días</h2>

```http
GET /v1/private/user/volume-stats
```

Campos de respuesta:

| Campo         | Tipo   | Descripción                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Volumen acumulado de operaciones en los últimos 30 días |
| `feeTotal30d` | string | Cuotas acumuladas en los últimos 30 días           |

<h2 id="balance-history">Historial de Balance</h2>

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Parámetros de la solicitud:

| Parámetro | Tipo   | Obligatorio | Descripción                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Sí      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | No       | Número de elementos devueltos, `30` predeterminado |

Campos de respuesta:

| Campo             | Tipo   | Descripción                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Fecha de agregación            |
| `items[].balance` | string | Saldo de cartera              |
| `items[].pnl`     | string | PnL realizado para ese periodo |

<h2 id="trade-overview">Resumen del comercio</h2>

```http
GET /v1/private/user/trade-overview?type=1M
```

Parámetros de la solicitud:

| Parámetro | Tipo   | Obligatorio | Descripción                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Sí      | Rango de tendencias: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Campos de respuesta:

| Campo                | Tipo   | Descripción                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | El PnL realizado hoy                                                 |
| `todayVolume`        | string | Volumen de negociación de contratos hoy                                      |
| `totalVolume`        | string | Volumen acumulativo de operaciones de contratos                                   |
| `totalPnl`           | string | PnL acumulado realizado                                              |
| `maxDrawdown30d`     | string | Cantidad máxima de reducción en los últimos 30 días                        |
| `maxDrawdown30dRate` | string | Tasa máxima de reducción en los últimos 30 días, decimal de `0` a `1` |
| `transferIn`         | string | Fondos acumulados transferidos                                      |
| `transferOut`        | string | Fondos transferidos acumulados                                     |
| `items[]`            | array  | Datos de tendencias de activos                                                     |

<h2 id="asset-overview-summary">Resumen del Activo</h2>

```http
GET /v1/private/user/asset/overview/summary
```

Los campos de respuesta son los mismos que los campos de resumen de la visión general del comercio, excluyendo `items[]`.

<h2 id="asset-overview-trend">Tendencia de Resumen de Activos</h2>

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Parámetros de la solicitud:

| Parámetro | Tipo   | Obligatorio | Descripción                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Sí      | Rango de tendencias: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Campos de respuesta:

| Campo                  | Tipo   | Descripción                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Tiempo de instantánea                   |
| `items[].balance`      | string | Saldo de cuenta corriente         |
| `items[].pnl`          | string | PnL para el periodo actual      |
| `items[].pnlRate`      | string | Tasa PnL para el periodo actual |
| `items[].totalPnl`     | string | PnL acumulado                  |

<h2 id="favorite-symbols">Símbolos favoritos</h2>

<h2 id="save">Salvar</h2>

```http
POST /v1/private/user/favorite-symbols
Content-Type: application/json
```

Cuerpo de la solicitud:

```json
{
  "symbols": ["BTCUSDT", "ETHUSDT"]
}
```

<h2 id="query">Consulta</h2>

```http
GET /v1/private/user/favorite-symbols
```

Campos de respuesta:

| Campo     | Tipo      | Descripción          |
| --------- | --------- | -------------------- |
| `symbols` | cuerda\[] | Lista de símbolos favoritos |
