<h2 id="error-response-format">Formato de respuesta a errores</h2>

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Los errores de negocio usualmente aún devolven la estructura unificada de JSON . Los integradores deberían revisar `code` primero. Las fallas de autenticación pueden devolver HTTP `401`; La limitación de velocidad puede regresar HTTP `429`.

<h2 id="common-error-codes">Códigos de error comunes</h2>

| Código de error      | Descripción                                  |
| --------------- | -------------------------------------------- |
| `0`             | Éxito                                      |
| `1001`          | No se proporciona información válida de autenticación |
| `1002`          | Token expirado                                |
| `1003`          | Token inválido, API Keyo firma         |
| `1004`          | Token revocado                                |
| `1006`          | Fuente IP desajuste                           |
| `2001`          | Parámetro requerido faltante                   |
| `2002`          | Valor de parámetro inválido                      |
| `2003`          | Parámetro fuera de rango                       |
| `3001`          | Equilibrio insuficiente                         |
| `3003`          | Orden no encontrada                              |
| `3004`          | Solicitud duplicada                            |
| `3005`          | El pedido no puede ser cancelado                     |
| `3006`          | Permiso denegado                            |
| `3100` - `3112` | Error de validación de parámetros de orden de condición   |
| `5001`          | Error interno del servidor                        |
| `5002`          | Servicio temporalmente no disponible              |
| `5003`          | Límite de tasa activado                         |

<h2 id="troubleshooting">Solución de problemas</h2>

| Problema                                     | Recomendación                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` no hay información válida de autenticación  | Revisa si `Authorization: Bearer <accessToken>` o `X-API-KEY` está incluido.                  |
| `1002` Token expirado                        | Actualizar el Token o iniciar sesión de nuevo antes de intentarlo de nuevo.                                                   |
| `1003` Token, API Keyo firma inválida | Revisa API Key, carga útil de firma, cuerpo de solicitud JSON cadena y orden de los parámetros de consulta.           |
| `1006` fuente IP desajuste                   | Revisa la configuración API Key IP lista blanca.                                                    |
| `3004` solicitud de duplicado                    | No reutilices la misma firma para rutas relacionadas con el orden. Regenerar `timestamp` y `signature`. |
| `5003` límite de tasa activado                 | Reduce la frecuencia de solicitudes y usa retroceso exponencial si vuelves a intentarlo.                                |
| `Timestamp outside of tolerance window`     | Llama a `/v1/time` para calibrar el offset de tiempo y firma la solicitud de nuevo.                             |
