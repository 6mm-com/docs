> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


6MM Agentic AI Hub es la AI-interfaz nativa para 6MM datos de mercado, flujos de trabajo de cuentas y futuras operaciones comerciales controladas.

En lugar de cambiar entre paneles, API documentos y scripts, los usuarios pueden pedirle a un cliente de IA que consulte 6MM, explique las condiciones del mercado, revise el riesgo de la cuenta o prepare una vista previa de la orden. El cliente AI no reemplaza el modelo de seguridad 6MM API; llama a herramientas 6MM estructuradas a través de CLI, MCP o plantillas de flujo de trabajo.

<h2 id="what-you-can-ask-an-ai-client">Qué puedes preguntarle a un cliente de IA</h2>

Utilice AI Hub cuando desee hacer preguntas como:

```text
Show me the BTC-USDT-PERP order book and explain current liquidity.
```

```text
Compare BTC and ETH funding rates over the last 24 hours.
```

```text
Check my testnet positions and explain liquidation risk. Do not place orders.
```

```text
Preview a small BTC long order and explain fees, margin impact, and risk checks.
```

<h2 id="why-ai-agents-need-a-dedicated-access-layer">Por qué los agentes de IA necesitan una capa de acceso dedicada</h2>

Los agentes de IA funcionan mejor cuando tienen herramientas estructuradas en lugar de páginas web sin formato o texto copiado no estructurado. AI Hub les ofrece:

| Requisito | 6MM enfoque |
| --- | --- |
| Contexto del mercado en vivo | Herramientas y recursos públicos de datos de mercado para símbolos, libros de pedidos, operaciones, financiación, tarifas y reglas. |
| Borrar permisos | Separe los ámbitos comerciales controlados, de lectura de cuenta, de vista previa y de datos públicos. |
| Ejecución más segura | Vista previa del flujo de primer pedido, confirmación explícita, idempotencia, límites y registros de auditoría. |
| Flexibilidad del cliente | MCP alojado, MCP local, CLI, MCP remoto y Agentic Skills para diferentes entornos de IA. |

<h2 id="setup-paths">Rutas de configuración</h2>

| Camino | Lo mejor para | El usuario debe saber |
| --- | --- | --- |
| Alojado MCP | Acceso rápido a datos de mercado públicos | Sin instalación ni clave de usuario API para datos públicos. El comercio no es el objetivo del primer lanzamiento. |
| Locales MCP | Clientes de IA que necesitan contexto de cuenta privada | El servidor MCP se ejecuta localmente y las credenciales permanecen en la máquina del usuario. |
| CLI | Agentes de codificación, scripts y usuarios de terminales. | Produce una salida de comando amigable para el agente y se puede usar sin un servidor MCP. |
| Remoto MCP | Instituciones y equipos que quieren su propio punto final | El usuario o la institución controla el alojamiento, las credenciales, el acceso a la red y los registros. |
| Habilidades de agente | Flujos de trabajo repetibles | Las habilidades guían a la IA a través del análisis y los pasos de riesgo utilizando herramientas aprobadas. |

<h2 id="what-is-available-first">¿Qué está disponible primero?</h2>

AI Hub debería comenzar con datos públicos del mercado y recursos de reglas comerciales:

- Mercados.
- Tickers.
- Ordenar libros.
- Vientos alisios.
- Kline.
- Tasas de financiación.
- Estado del sistema.
- Tarifas, especificaciones de contrato, reglas de margen y recursos de reglas de riesgo.

El acceso a cuentas privadas y el comercio deben realizarse de la siguiente manera:

- Las herramientas de lectura de cuentas requieren credenciales explícitas de solo lectura.
- La vista previa del pedido debe aparecer antes de cualquier creación de pedido real.
- El comercio controlado requiere alcances de permisos, comprobaciones de riesgos del lado del servicio, confirmación del usuario, idempotencia y registros de auditoría.
