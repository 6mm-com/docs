> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


MCP remoto es para usuarios o instituciones que desean un punto final MCP de larga duración bajo su propio control.

A diferencia del MCP alojado, el MCP remoto no es operado por 6MM para el usuario. 6MM proporciona código, imágenes, plantillas y documentación; el usuario controla el hosting y las credenciales.

<span id="architecture" data-sixmm-canonical-anchor="architecture" aria-hidden="true"></span>

## Arquitectura

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<span id="deployment-targets" data-sixmm-canonical-anchor="deployment-targets" aria-hidden="true"></span>

## Objetivos de implementación

- Docker o Docker Compose.
- VPS con un proxy inverso.
- Ferrocarril.
- Prestar.
- Volar.io.
- AWS ECS o Lambda.
- Kubernetes internos.

<span id="required-files" data-sixmm-canonical-anchor="required-files" aria-hidden="true"></span>

## Archivos requeridos

- Archivo Docker.
- docker-compose.yml.
- .env.plantilla.
- HTTP modo de transporte.
- /mcp punto final.
- /punto final de salud.
- Proxy inverso y notas TLS.

<span id="credential-model" data-sixmm-canonical-anchor="credential-model" aria-hidden="true"></span>

## Modelo de credencial

Las credenciales deben almacenarse en el entorno administrado por el usuario, no en el indicador del cliente de IA. Para implementaciones administradas por la institución, restrinja el acceso a clientes y redes aprobados.

<span id="recommended-first-release" data-sixmm-canonical-anchor="recommended-first-release" aria-hidden="true"></span>

## Primera versión recomendada

Comience con los datos del mercado público. Agregue cuenta de solo lectura después de que la autenticación, el alcance de las claves, los registros y los controles de acceso estén disponibles. El comercio debe permanecer inhabilitado hasta que se cumplan los requisitos comerciales controlados.
