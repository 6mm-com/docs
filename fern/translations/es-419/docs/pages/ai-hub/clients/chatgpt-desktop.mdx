> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


ChatGPT Desktop es un punto de entrada familiar para los usuarios que desean hacer preguntas sobre el mercado en lenguaje natural.

Utilice esta ruta cuando el usuario desee una interfaz conversacional para datos del mercado público, resúmenes de cuentas, explicaciones de posiciones y contexto de reglas comerciales.

<h2 id="recommended-setup">Configuración recomendada</h2>

| Necesidad | Configuración |
| --- | --- |
| Datos del mercado público | Alojado MCP |
| Contexto de cuenta privada | Locales MCP |
| Indicaciones de análisis repetibles | Habilidades de agente |
| Flujos de trabajo basados ​​en terminales | 6MM CLI |

<h2 id="what-users-can-ask">Qué pueden preguntar los usuarios</h2>

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<h2 id="safety-defaults">Valores predeterminados de seguridad</h2>

- Comience con los datos del mercado público.
- Utilice Local MCP cuando se necesiten credenciales de cuenta.
- Mantenga claves privadas API en la máquina del usuario.
- Requerir vista previa y confirmación explícita antes de cualquier acción comercial futura.
