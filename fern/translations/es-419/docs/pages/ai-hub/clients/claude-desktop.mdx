> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


Claude Desktop es una buena opción para la investigación basada en MCP-, la revisión de cuentas y el análisis operativo.

<h2 id="recommended-setup">Configuración recomendada</h2>

| Necesidad | Configuración |
| --- | --- |
| Investigación de mercado público | Alojado MCP |
| Análisis consciente de la cuenta | Locales MCP |
| Punto final del equipo interno | Remoto MCP |

<h2 id="example-prompts">Indicaciones de ejemplo</h2>

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<h2 id="notes">Notas</h2>

Se prefiere el MCP local siempre que se trate de datos de cuentas privadas porque el servidor MCP se ejecuta en la máquina del usuario y no es necesario enviar las credenciales a un punto final de AI alojado en 6MM.
