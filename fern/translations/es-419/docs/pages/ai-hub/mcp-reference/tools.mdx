> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


Las herramientas MCP son ​​acciones que un cliente de IA puede invocar. Cada herramienta debe tener una descripción clara, un esquema JSON, un requisito de permiso, un formato de respuesta estable y un modelo de error.

## Fase 1: herramientas del mercado público

| Herramienta | Objetivo |
| --- | --- |
| 6mm_estado_del_sistema | Consultar servicio y disponibilidad en el mercado. |
| 6mm_mercados | Enumere los mercados disponibles y los metadatos básicos. |
| 6mm_market_summary | Resuma el estado del mercado para uno o más símbolos. |
| 6mm_ticker | Devuelve los últimos datos del ticker. |
| libro de pedidos de 6 mm | Profundidad del libro de pedidos de devolución. |
| 6mm_klines | Devolver velas históricas. |
| 6mm_comercios | Devolver operaciones públicas recientes. |
| 6mm_tasas_de_financiación | Devolver las tasas de financiación actuales e históricas. |

## Requisitos de herramientas

Cada herramienta debe definir:

- Descripción del modelo de IA.
- Ingrese el esquema JSON.
- Alcance del permiso.
- Apoyo al medio ambiente.
- Comportamiento de límite de velocidad.
- Campos de respuesta estables.
- Códigos de error.
- Campos del registro de auditoría.
