<h2 id="which-path-should-i-choose">¿Qué camino debería elegir?</h2>

<h2 id="how-the-solutions-connect">Cómo se conectan las soluciones</h2>

La mayoría de las implementaciones de socios combinan más de una capacidad de 6MM . Una bolsa de marca blanca puede usar liquidez institucional, soporte para cumplimiento y API integraciones. Un socio comercial embebido puede comenzar con el Trading Widget SDK y luego agregar flujos de Agent SDK backend, procesamiento de webhooks y recursos operativos.
