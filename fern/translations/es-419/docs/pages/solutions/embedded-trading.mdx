El Embedded API / SDK Trading System está diseñado para socios que ya poseen tráfico, usuarios o flujos de trabajo empresariales y que quieren agregar trading sin construir una bolsa completa desde cero.

<h2 id="what-it-provides">Lo que ofrece</h2>

- Terminal de negociación integrado a través del Trading Widget SDK
- Integración de backend de socios a través de Agent SDKs
- Enlaces de identidad del usuario y flujos de token de entrada
- Transferencia de activos, órdenes, posiciones y acceso API cuenta
- Integración de eventos, webhooks y ciclos de vida para sistemas operativos

<h2 id="recommended-architecture">Arquitectura recomendada</h2>

| Capa | Responsabilidad |
| --- | --- |
| Frontend asociado | Aloja el punto de entrada e integra la interfaz 6MM de trading. |
| Backend del socio | Guarda API secretos, valida a los usuarios, emite tokens integrados y procesa webhooks. |
| 6MM infraestructura comercial | Se encarga de la interfaz de trading, emparejamiento, riesgo, liquidez, estado de la cuenta y ciclo de vida del trading. |

<h2 id="choose-an-integration-path">Elige una ruta de integración</h2>

| Requisito | Ruta recomendada |
| --- | --- |
| Interfaz de trading completa con la integración web más rápida | Trading Widget |
| Enlace de usuario backend, transferencia, URLde entrada y manejo de webhook | Agent SDK |
| Flujos de trabajo totalmente personalizados de productos y pedidos | REST API + WebSocket |
| Experiencia en intercambios de marca con un alcance operativo más amplio | Intercambio de marca blanca |

El diseño final puede combinar estos caminos. Confirma la autenticación, la propiedad de activos, los límites de responsabilidad, el monitoreo y el soporte en producción antes de que comience la implementación.
