<h2 id="options">Opciones</h2>

| Campo | Tipo | Predeterminado | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origen de la escritura | Dominio iframe. Pasa explícitamente en las páginas de compañeros. |
| Símbolo | string | BTCUSDT | Normalizado a mayúsculas y tiras - / _. |
| Tema | oscuro \| Luz | oscuro | Parámetro inicial del tema. |
| Ubicación | en \| en-US \| zh-CN | Navegador/predeterminado | Se admiten inglés y chino simplificado. |
| Distribución | por defecto \| compacto | Por defecto | Opción de distribución reservada. |
| Pantalla | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Controla las áreas de concha y contenedores de comercio de alto nivel. |
| Auth | object | ninguno | Usa partner-token para nuevas integraciones SSO . |

<h2 id="display-controls">Controles de pantalla</h2>

`display` controla el shell incrustado de la página de trading y los contenedores de alto nivel. En los embebidos de socios, el encabezado de PC y el ticker de mercado más bajo están ocultos por defecto.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Predeterminado | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | falso | Si mostrar el encabezado embebido de la PC dentro del iframe. |
| showTicker | boolean | falso | Si mostrar el ticker inferior del mercado en la cáscara embed. |
| Oculto | cuerda[] | [] | Esconde contenedores de alto nivel en la página de intercambio. |

Valores `display.hidden` apoyados:

| Valor | Contenedor |
| --- | --- |
| Lista | Contenedor de cartas |
| orderBook | Contenedor de libro de pedidos |
| orderForm | Panel de formularios de pedido |
| Cargos | Posiciones más bajas y panel de órdenes abiertas |
| cuenta | Contenedor de activos de la cuenta |

`display.hidden` solo esconde contenedores enteros. No oculta botones, campos o herramientas individuales dentro de un contenedor. Se ignoran los valores que no corresponden al viewport actual.

<h2 id="events">Eventos</h2>

| Evento | Disparador |
| --- | --- |
| Listo | Inicialización del iframe terminada. |
| error | SDK, iframe o error de autenticación. |
| state_changed | SDK estado del ciclo de vida cambió. |
| auth_state_changed | El estado de autenticación del token de socio cambió. |
| symbol_changed | El símbolo real del iframe cambió. |
| locale_changed | La ubicación real del iframe cambió. |
| order_created | El usuario creó una orden dentro del iframe. |
| order_failed | Envío de pedido fallido. |
| destruido | SDK instancia destruida. |
