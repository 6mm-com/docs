## Opciones

| Campo | Tipo | Por defecto | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origen del script | Dominio de marco flotante. Pase explícitamente en las páginas de socios. |
| símbolo | string | BTCUSDT | Normalizado a mayúsculas y tiras - / _. |
| tema | oscuro \| luz | oscuro | Parámetro del tema inicial. |
| lugar | es \| es-US \| zh-CN | Navegador/predeterminado | Se admiten inglés y chino simplificado. |
| disposición | por defecto \| compacto | por defecto | Opción de diseño reservado. |
| mostrar | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Los controles incorporan áreas de estructura y contenedores comerciales de alto nivel. |
| autenticación | object | ninguno | Utilice el token de socio para nuevas integraciones SSO. |

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Controles de pantalla

`display` controla el shell de la página comercial integrada y los contenedores de alto nivel. En las inserciones de socios, el encabezado de la PC y el ticker de mercado inferior están ocultos de forma predeterminada.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Por defecto | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | FALSO | Si se debe mostrar el encabezado incrustado de la PC dentro del iframe. |
| showTicker | boolean | FALSO | Si se debe mostrar el ticker inferior del mercado en el shell de inserción. |
| oculto | cadena[] | [] | Oculta contenedores de alto nivel en la página comercial. |

Valores `display.hidden` admitidos:

| Valor | Recipiente |
| --- | --- |
| cuadro | Contenedor de gráficos |
| orderBook | Contenedor de libro de pedidos |
| orderForm | Panel de formulario de pedido |
| posiciones | Panel de posiciones inferiores y órdenes abiertas |
| cuenta | Contenedor de activos de la cuenta |

`display.hidden` oculta solo contenedores completos. No oculta botones, campos o herramientas individuales dentro de un contenedor. Los valores que no se asignan a la ventana gráfica actual se ignoran.

## Eventos

| Evento | Desencadenar |
| --- | --- |
| listo | La inicialización del iframe finalizó. |
| error | SDK, iframe o error de autenticación. |
| estado_cambiado | SDK el estado del ciclo de vida cambió. |
| auth_state_changed | El estado de autenticación del token de socio cambió. |
| símbolo_cambiado | El símbolo de iframe real cambió. |
| locale_changed | La configuración regional real del iframe cambió. |
| pedido_creado | El usuario creó un pedido dentro del iframe. |
| pedido_fallido | El envío del pedido falló. |
| destruido | SDK instancia destruida. |

## Páginas de productos y modo de negociación.

Java Agent SDK y el navegador Trading Widget SDK tienen versiones independientes. Para operar en segundos, utilice las capacidades actuales del widget y seleccione explícitamente tanto la página como el modo de comercio.

| Opción | Valores | Significado |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Página de producto para el comercio de segundos. |
| `tradingMode` | `real`, `demo` | El valor predeterminado es `real`; coincidir explícitamente con el entorno de financiación backend. |

Verifique `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` y `TradingWidget.capabilities.partnerToken` antes de la inicialización. La creación de tokens no selecciona un entorno de fondos. Para cambiar de usuario o modo real/demo, destruya la instancia anterior y cree una nueva.

Ver [ejemplo completo de comercio de segundos](/es-419/sdk/agent-sdk/java/seconds-trading) y [producción/configuración simulada](/es-419/sdk/agent-sdk/java/environments).

## Eventos y objetivos de visualización adicionales

El tiempo de ejecución actual también acepta `symbolFavorites` y `symbolTicker` en `display.hidden`. Siempre marque `TradingWidget.capabilities.displayTargets`; un objetivo controla un contenedor de alto nivel y no es una configuración de permiso a nivel de campo.

| Evento | Significado |
| --- | --- |
| `rendered` | El iframe envía su notificación renderizada. |
| `theme_changed` | El iframe informa su tema real. |
| `page_changed` | El iframe informa su página de producto real. |

Utilice `onRendered` o `widget.on('rendered', handler)` para manejar la representación por separado de la inicialización. Las páginas admitidas actualmente se publican en `TradingWidget.capabilities.pages`; valide la página solicitada en lugar de adivinar una ruta.
