<h2 id="responsibility-split">División de responsabilidades</h2>

| Área | Propietario | Notas |
| --- | --- | --- |
| Creación de contenedores | Frontend asociado | Proporciona un elemento visible con ancho y altura explícitos. |
| Creación de iframe | Trading Widget SDK | El SDK crea y administra el iframe. |
| Interfaz de Comercio | 6MM iframe | K-line, libro de pedidos, formulario de pedido, posiciones, órdenes y datos de cuenta se ejecutan dentro del iframe. |
| Controles de pantalla | Trading Widget SDK + 6MM iframe | El encabezado y el ticker inferior del embed de la PC están ocultos por defecto. Los socios pueden usar `display` para mostrar áreas de conchas o ocultar contenedores de comercio de alto nivel. |
| Verificación de inicio de sesión de socios | Backend del socio | Valida la sesión de usuario del socio antes de emitir credenciales de autenticación. |
| Emisión de tokens embebidos | Backend de socios + Agente API | Recomendado para el modo token-partner. |

<h2 id="versioning">Versión</h2>

La ruta de integración pública permanece estable bajo el script v1 URL. El conjunto actual de capacidades v1 incluye partner-token, tokenProvider, entryUrlProvider, controles de visualización, eventos del ciclo de vida, métodos de instancia y eventos de orden.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Cuándo usar el widget</h2>

Elige Trading Widget cuando un socio necesita una interfaz de trading completa dentro de un producto web existente. Usa la documentación REST API y WebSocket al construir y mantener una interfaz de trading completamente personalizada.

<h2 id="implementation-path">Ruta de implementación</h2>

1. Sigue el [Trading Widget Quick Start](/es-419/sdk/trading-widget/quick-start) para cargar el script y crear un contenedor visible.
2. Configurar [autenticación de token de socio](/es-419/sdk/trading-widget/authentication) a través de un backend de socio.
3. Agregar las [opciones y eventos](/es-419/sdk/trading-widget/options-events).
4. Usar [métodos de instancia](/es-419/sdk/trading-widget/instance-methods) para controles de ciclo de vida y tiempo de ejecución.
