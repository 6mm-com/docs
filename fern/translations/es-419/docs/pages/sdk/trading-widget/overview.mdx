## División de responsabilidad

| Área | Dueño | Notas |
| --- | --- | --- |
| Creación de contenedores | Interfaz de socio | Proporcione un elemento visible con ancho y alto explícitos. |
| creación de iframe | Trading Widget SDK | El SDK crea y administra el iframe. |
| Interfaz de usuario comercial | 6MM marco flotante | La línea K, el libro de pedidos, el formulario de pedidos, las posiciones, los pedidos y los datos de la cuenta se ejecutan dentro del iframe. |
| Controles de pantalla | Trading Widget SDK + 6MM marco flotante | El encabezado de inserción de PC y el ticker inferior están ocultos de forma predeterminada. Los socios pueden usar `display` para mostrar áreas de estructura u ocultar contenedores comerciales de alto nivel. |
| Verificación de inicio de sesión de socio | backend del socio | Valide la sesión del usuario asociado antes de emitir las credenciales de autenticación. |
| Insertar emisión de tokens | Backend de socio + Agente API | Recomendado para el modo token de socio. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Versionado

La ruta de integración pública permanece estable bajo el script v1 URL. El conjunto de capacidades v1 actual incluye token de socio, tokenProvider, entryUrlProvider, controles de visualización, eventos de ciclo de vida, métodos de instancia y eventos de orden.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Cuándo usar el widget

Elija Trading Widget cuando un socio necesite una interfaz comercial completa dentro de un producto web existente. Utilice la documentación REST API y WebSocket cuando cree y mantenga una interfaz comercial totalmente personalizada.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Ruta de implementación

1. Sigue el [Trading Widget Inicio rápido](/es-419/sdk/trading-widget/quick-start) para cargar el script y crear un contenedor visible.
2. Configurar [autenticación de token de socio](/es-419/sdk/trading-widget/authentication) a través de un backend asociado.
3. Agregue lo requerido [opciones y eventos](/es-419/sdk/trading-widget/options-events).
4. Usar [métodos de instancia](/es-419/sdk/trading-widget/instance-methods) para controles de ciclo de vida y tiempo de ejecución.

<span id="verified-public-runtime" data-sixmm-canonical-anchor="verified-public-runtime" aria-hidden="true"></span>

## Tiempo de ejecución público verificado

El script público `v1` informa la versión `1.8.0` a partir del 2026-10-10. Este URL es un punto de entrada estable de la versión principal, no una compilación fijada. Lea `TradingWidget.version` y `TradingWidget.capabilities` en su tiempo de ejecución cargado antes de usar funciones opcionales. Java Agent SDK `v0.3.0` es un paquete de backend independiente.

El tiempo de ejecución admite una única instancia activa (`multiInstance=false`); La creación de otro widget destruye la instancia anterior. Sus configuraciones regionales admitidas son `en`, `en-US` y `zh-CN`, independientemente de los 20 idiomas de documentación.
