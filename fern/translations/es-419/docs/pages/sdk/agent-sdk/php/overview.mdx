## Duración

| Ítem | Valor |
| --- | --- |
| Paquete | Sixmm/agente-SDK |
| Versión mínima PHP | PHP 7.4+ |
| Versión recomendada PHP | PHP 8.1+ o versiones actualmente compatibles |
| Extensiones requeridas | ext-json, ext-curl |

La fuente del paquete PHP SDK y la versión aprobada se proporcionan durante la incorporación del socio. No asumas que el paquete está disponible en Packagist público; Configura el repositorio Composer proporcionado para tu organización.

## Escenarios soportados

| Escenario | SDK método |
| --- | --- |
| Bind user | atar |
| Transferencia de cantidad fija | Transferencia |
| Transfiere todo fuera | transferAllOut |
| Transferencia inversa | Reversa |
| Orden de consulta | queryOrder |
| Crear URL | createEntryUrl |
| Verificación de Webhook | WebhookVerifier::verify |

<span id="backend-integration-rules" data-sixmm-canonical-anchor="backend-integration-rules" aria-hidden="true"></span>

## Reglas de integración de backend

- Cargar `apiSecret` desde un administrador secreto o variable de entorno protegido.
- Mantener la vinculación del usuario, transferencia, firma y lógica de webhook fuera del código del navegador.
- Usar cadenas decimales para los montos de activos para evitar redondeos en punto flotante.
- Reutilizar el `agentOrderNo` original al consultar un resultado de transferencia incierto.
- Verificar las firmas del webhook contra el cuerpo de la solicitud en bruto antes de decodificarlo o cambiarlo.
