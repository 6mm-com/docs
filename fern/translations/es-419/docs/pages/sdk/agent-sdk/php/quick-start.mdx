## Instalación

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Acceso al paquete**
>
> 6MM proporciona el nombre aprobado del paquete Composer, el repositorio y la versión durante la incorporación del socio. No se debe asumir que el paquete existe en Packagist público.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Antes de que empieces

- Confirma que el Agente API base URL con 6MM.
- Cargar apiSecret desde variables de entorno o gestión de secretos.
- Mantener SDK uso solo dentro de los servicios backend.
- Preparar el manejo de idempotentes para transferencias y flujos de webhook.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Inicializar cliente

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Solo backend**
>
> El PHP SDK firma las solicitudes del Agente API y no debe ser expuesto a través de código fuente público o entornos de ejecución frontend.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Ejemplo: transferir fondos en

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Usa cadenas decimales para los montos y conserva el agentOrderNo original al volver a intentar o consultar el estado de la transferencia.
