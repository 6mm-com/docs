## Entrada directa URL

La entrada directa URL es para el modo de redirección. Un usuario asociado hace clic en un botón en la
sitio asociado, abre la interfaz 6MM y se inicia sesión automáticamente.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Reglas de campo:

| Campo | Descripción |
| --- | --- |
| `redirectPath` | 6MM ruta relativa de la interfaz. Debe comenzar con `/`, por ejemplo `/trade/BTCUSDT` |
| `returnUrl` | Socio absoluto URL utilizado cuando el usuario sale de la interfaz 6MM. Sólo se permiten `http` y `https` |
| `expireAt` | Tiempo de vencimiento del ticket de entrada como marca de tiempo Unix en segundos |

Requisitos de seguridad:

- `webUrl` contiene un ticket único. Úselo inmediatamente y no lo almacene a largo plazo.
- Si la entrada URL caduca o ha sido utilizada, genere una nueva desde el sitio asociado.
- `returnUrl` no debe ser `javascript:`, una ruta relativa o un URL con información de usuario.


<span id="product-and-mode-selection" data-sixmm-canonical-anchor="product-and-mode-selection" aria-hidden="true"></span>

## Selección de producto y modo.

Utilice la ruta de interfaz actual proporcionada por 6MM. Por ejemplo `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` o `/zh-CN/futures/BTCUSDT?tradingMode=real`. El ticket autentifica al usuario; no selecciona un entorno de financiación ni mueve fondos.

Ver [Comercio de segundos](/es-419/sdk/agent-sdk/java/seconds-trading) para redireccionamiento y ejemplos integrados.
