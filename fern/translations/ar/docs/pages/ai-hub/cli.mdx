> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


6MM CLI هي نقطة دخول سطر الأوامر للمستخدمين والبرامج النصية ووكلاء الذكاء الاصطناعي الذين يمكنهم تنفيذ أوامر shell.

استخدم CLI عندما تتمكن بيئة الذكاء الاصطناعي من تشغيل الأوامر الطرفية مباشرة. غالبًا ما يكون هذا هو أبسط مسار لوكلاء الترميز لأنه لا يلزم وجود خادم MCP منفصل. يجب أن يُرجع CLI مستقرًا JSON افتراضيًا حتى يتمكن الوكلاء من تحليل النتائج دون الاعتماد على التنسيق الطرفي.

<h2 id="what-the-cli-is-good-for">ما فائدة CLI من أجله</h2>

- استعلامات سريعة عن بيانات السوق من المحطة.
- التحليل القائم على الوكيل في Codex أو Claude Code أو Gemini CLI أو أدوات مماثلة.
- CI أو البرامج النصية المجدولة التي تحتاج إلى بيانات 6MM.
- التحقق من قراءة الحساب عند تكوين بيانات الاعتماد المحلية.
- تتدفق معاينة الطلب حيث يقوم الوكيل بإعداد المعلمات ولكن لا يقدم طلبًا.

<h2 id="example-commands">أوامر المثال</h2>

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

<h2 id="output-modes">أوضاع الإخراج</h2>

| وضع | حالة الاستخدام |
| --- | --- |
| JSON | الإعداد الافتراضي لوكلاء الذكاء الاصطناعي والبرامج النصية والأتمتة. |
| طاولة | مراجعة المحطة الطرفية التي يمكن قراءتها بواسطة الإنسان. |
| خام | اختبارات التصحيح والتكامل. |

<h2 id="recommended-safety-defaults">افتراضيات السلامة الموصى بها</h2>

- البيئة الافتراضية هي testnet.
- الإخراج الافتراضي هو JSON.
- تتطلب أوامر التداول الاشتراك الصريح.
- يتطلب إنشاء أمر الشبكة الرئيسية تأكيدًا.
- وضع المعاينة متاح قبل الإنشاء.
- تتضمن الأخطاء رموزًا مستقرة ورسائل واضحة.

<h2 id="agent-usage">استخدام الوكيل</h2>

يجب على وكلاء الذكاء الاصطناعي تفضيل أوامر القراءة فقط ما لم يطلب المستخدم صراحةً إجراءات المعاينة أو التداول.

مثال موجه:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
