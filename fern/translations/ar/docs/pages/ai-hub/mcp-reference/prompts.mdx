> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


المطالبات MCP هي عمليات سير عمل قابلة لإعادة الاستخدام يتم كشفها بواسطة خادم MCP. إنها تساعد المستخدمين على طرح أسئلة متسقة وتساعد عملاء الذكاء الاصطناعي على استخدام الأدوات المناسبة.

## المطالبات الموصى بها

| اِسْتَدْعَى | غاية |
| --- | --- |
| Market_overview | تلخيص حالة السوق عبر الرموز المحددة. |
| تحليل_البنية_السوقية_السوقية | تحليل الانتشار والعمق والتداولات الأخيرة وظروف السيولة. |
| Portfolio_risk_assessment | مراجعة المراكز والتعرض والهامش ومخاطر التصفية. |
| Position_management | ساعد المستخدمين على فهم حالة الموقف والإجراءات الممكنة. |
| Liquidation_protection | تحديد مخاطر التصفية وخيارات الحد من المخاطر. |
| معدل_التمويل_الفرصة | قارن معدلات التمويل والفرص الممكنة. |
| create_optimal_order | معلمات ترتيب الخطة قبل المعاينة. |
| Hedging_strategy | استكشف خيارات التحوط للتعرض الحالي. |
| Trading_consultation | قم بإعداد تحليل تداول منظم دون تنفيذ الأوامر. |

## قواعد السلامة السريعة

- لا تعامل الإخراج الفوري على أنه نصيحة مالية.
- لا تقم بتنفيذ أدوات التداول إلا إذا طلب المستخدم ذلك صراحةً.
- استخدم المعاينة قبل الإنشاء.
- شرح الافتراضات ومصادر البيانات.
- تفضل أمثلة testnet في الوثائق العامة.
