> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


أدوات MCP هي إجراءات يمكن لعميل الذكاء الاصطناعي الاتصال بها. يجب أن تحتوي كل أداة على وصف واضح، ومخطط JSON، ومتطلبات الإذن، وتنسيق الاستجابة المستقر، ونموذج الخطأ.

<h2 id="phase-1-public-market-tools">المرحلة الأولى: أدوات السوق العامة</h2>

| أداة | غاية |
| --- | --- |
| 6mm_system_status | التحقق من الخدمة وتوافر السوق. |
| 6mm_markets | قائمة الأسواق المتاحة والبيانات الوصفية الأساسية. |
| 6mm_market_summary | تلخيص حالة السوق لرمز واحد أو أكثر. |
| 6mm_ticker | إرجاع أحدث بيانات المؤشر. |
| 6mm_orderbook | عمق دفتر أوامر الإرجاع. |
| 6mm_klines | عودة الشموع التاريخية. |
| 6mm_trades | إرجاع الصفقات العامة الأخيرة. |
| 6mm_funding_rates | إرجاع معدلات التمويل الحالية والتاريخية. |

<h2 id="phase-2-account-read-tools">المرحلة الثانية: أدوات قراءة الحساب</h2>

| أداة | غاية |
| --- | --- |
| 6mm_account_summary | تلخيص حالة الحساب. |
| 6mm_أرصدة | قراءة الموازنات. |
| 6mm_positions | قراءة المواقف. |
| 6mm_open_orders | قراءة الأوامر المفتوحة. |
| 6mm_order_history | قراءة الأوامر التاريخية. |
| 6mm_fills | قراءة يملأ. |
| 6mm_funding_المدفوعات | قراءة مدفوعات التمويل. |

<h2 id="phase-3-and-later-trading-tools">المرحلة 3 وما بعدها: أدوات التداول</h2>

| أداة | غاية |
| --- | --- |
| 6mm_preview_order | التحقق من صحة الأمر دون تقديمه. |
| 6mm_create_order | قم بإنشاء طلب بعد التأكيد وفحص المخاطر. |
| 6mm_cancel_order | إلغاء طلب واحد. |
| 6mm_cancel_all_orders | قم بإلغاء جميع الطلبات المفتوحة المؤهلة. |
| 6mm_amend_order | تعديل أمر موجود. |
| 6mm_order_status | قراءة الحالة لطلب معين. |

<h2 id="tool-requirements">متطلبات الأداة</h2>

يجب أن تحدد كل أداة:

- وصف لنموذج الذكاء الاصطناعي.
- أدخل مخطط JSON.
- نطاق الإذن.
- دعم البيئة.
- سلوك حد المعدل.
- مجالات الاستجابة مستقرة.
- رموز الخطأ.
- حقول سجل التدقيق.
