> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


MCP الموارد هي سياق للقراءة فقط يمكن لعملاء الذكاء الاصطناعي فحصه قبل استدعاء الأدوات.

تقلل الموارد من الهلوسة من خلال إعطاء النموذج معلومات مستقرة ومنظمة حول 6MM.

<h2 id="recommended-resource-uris">عناوين URI للمورد الموصى بها</h2>

| الموارد | غاية |
| --- | --- |
| 6 ملم: // النظام / التكوين | تكوين البيئة والقدرة. |
| 6 ملم: // النظام/الحالة | النظام الحالي وحالة السوق. |
| 6 ملم: // الأسواق | الأسواق المتاحة. |
| 6mm://market/{symbol} | مواصفات العقد والبيانات الوصفية على مستوى السوق. |
| 6 ملم: // الرسوم | قواعد الرسوم. |
| 6 ملم: // المخاطرة / القواعد | ملخص قواعد التداول والمخاطر. |
| 6 ملم: // المخاطرة / الهامش | سياق الهامش والتصفية. |
| 6mm://funding/rules | قواعد معدل التمويل. |
| 6 ملم: //api/docs | API ملخص مرجعي أو روابط. |

<h2 id="resource-design-rules">قواعد تصميم الموارد</h2>

- احتفظ بالموارد للقراءة فقط.
- استخدم مخططات مستقرة.
- قم بتضمين الطوابع الزمنية وأسماء البيئة.
- تجنب كشف الأسرار.
- تفضل البيانات المنظمة المختصرة على النثر الطويل.
- قم بالارتباط بالوثائق الأساسية عندما تكون التفاصيل طويلة جدًا.
