> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


تُعد استضافة MCP أبسط طريقة لبدء استخدام 6MM AI Hub.

قم بتوصيل عميل الذكاء الاصطناعي بنقطة النهاية 6MM المستضافة MCP واطرح أسئلة حول بيانات السوق العامة. لا يوجد خادم محلي للتثبيت، ولا يوجد نشر سحابي للصيانة، ولا يلزم وجود مفتاح مستخدم API للبيانات العامة.

<h2 id="what-you-can-do">ما يمكنك القيام به</h2>

- الاستعلام عن بيانات السوق الحية والتاريخية.
- تصفح الأسواق الدائمة المتاحة.
- تحقق من عمق دفتر الطلبات والصفقات الأخيرة.
- مقارنة معدلات التمويل.
- اقرأ الرسوم والعقد والهامش وسياق قاعدة المخاطر.

يُعد MCP المستضاف هو الأفضل للبحث واستكشاف المنتجات وتحليل السوق العامة. إنه ليس الإعداد الأول الصحيح للوصول إلى الحساب الخاص أو التداول.

<h2 id="endpoint">نقطة النهاية</h2>

```text
https://mcp.6mm.com/mcp
```

فحص الصحة:

```text
https://mcp.6mm.com/health
```

<h2 id="recommended-first-release-scope">نطاق الإصدار الأول الموصى به</h2>

يجب أن يعرض MCP المستضاف المعلومات العامة ومعلومات القراءة فقط في الإصدار الأول فقط:

- الأسواق.
- أشرطة.
- طلب الكتب.
- الصفقات الأخيرة.
- كلاينز.
- معدلات التمويل.
- حالة النظام.
- رسوم التداول.
- مواصفات العقد.
- موارد قاعدة المخاطر والهامش.

<h2 id="not-supported-in-the-first-release">غير مدعوم في الإصدار الأول</h2>

لا ينبغي أن يكون المستضاف MCP هو المكان الأول الذي يتم الكشف فيه عن:

- أرصدة الحسابات.
- المواقف.
- أوامر مفتوحة.
- إنشاء الطلب.
- إلغاء الطلب.
- التحويلات أو السحوبات.
- تخزين مفتاح المستخدم API.

<h2 id="why-public-data-first">لماذا البيانات العامة أولا</h2>

يتم تشغيل MCP المستضاف بواسطة 6MM ويمكن الوصول إليه عبر الشبكة. إنه ملائم، لكن لا ينبغي أن يصبح المكان الافتراضي الذي يرسل فيه المستخدمون مفاتيح API الخاصة. يجب أن تبدأ عمليات سير عمل الحساب والتداول الحساسة بالـ MCP، أو CLI، أو جهاز التحكم عن بعد الذي يديره المستخدم MCP.

<h2 id="example-user-prompt">مثال لمطالبة المستخدم</h2>

```text
Use 6MM to check BTC-USDT-PERP orderbook depth and summarize liquidity.
```

<h2 id="operational-requirements">المتطلبات التشغيلية</h2>

- TLS على جميع نقاط النهاية.
- حدود معدل الطلب.
- الحماية من إساءة الاستخدام.
- السجلات والمقاييس المنظمة.
- الفحوصات الصحية.
- مسح أوصاف ومخططات الأداة.
- استجابات الأخطاء الثابتة لعملاء الذكاء الاصطناعي.
