> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


اختر الإعداد بناءً على سؤالين:

1. ما هو عميل الذكاء الاصطناعي الذي تريد استخدامه؟
2. هل تحتاج إلى بيانات عامة فقط، أو الوصول إلى الحساب الخاص، أو سير عمل التداول؟

إذا لم تكن متأكدًا، فابدأ بالـ MCP المستضاف للبيانات العامة أو المحلي MCP لسير عمل الحساب الخاص.

## جدول القرار السريع

| هدف | الإعداد الموصى به | لماذا |
| --- | --- | --- |
| اطلب من عميل الذكاء الاصطناعي الحصول على بيانات السوق العامة | مستضاف MCP | لا يوجد تثبيت محلي ولا يلزم وجود مفتاح API. |
| السماح لـ Claude Desktop أو Cursor أو ChatGPT Desktop باستدعاء أدوات 6MM | محلي MCP | يستدعي الذكاء الاصطناعي الأدوات من خلال خادم محلي يتحكم فيه المستخدم. |
| اسمح لـ Codex أو Claude Code أو Gemini CLI أو البرامج النصية باستدعاء 6MM | CLI | يمكن أن يكون مخرج الأمر JSON ويسهل على الوكلاء تحليله. |
| توفير نقطة نهاية MCP تديرها الشركة | البعيد MCP | تتحكم المؤسسة في الاستضافة وبيانات الاعتماد والوصول والسجلات. |
| توحيد التحليل المتكرر أو سير عمل المخاطر | مهارات الوكيل | تحدد القوالب استخدام الأداة، وحواجز الحماية، وتنسيق الإخراج. |

## اختر من قبل عميل الذكاء الاصطناعي

| عميل الذكاء الاصطناعي | مستضاف MCP | محلي MCP | CLI | ملحوظات |
| --- | --- | --- | --- | --- |
| كلود سطح المكتب | ممكن | مُستَحسَن | ممكن | استخدم MCP المحلي عند الحاجة إلى سياق الحساب. |
| كلود.اي ويب | يوصى به عند دعمه | لا ينطبق | لا ينطبق | الأفضل لبيانات السوق العامة فقط. |
| سطح المكتب ChatGPT | ممكن | مُستَحسَن | ممكن | يُفضل MCP المحلي لأدوات الحساب الخاص. |
| المؤشر | ممكن | مُستَحسَن | ممكن | يعمل MCP المحلي بشكل جيد مع سير عمل الترميز. |
| المخطوطة CLI | ممكن | ممكن | مُستَحسَن | CLI عادة ما يكون المسار الأكثر مباشرة. |
| كلود كود CLI | ممكن | ممكن | مُستَحسَن | CLI أو محلي MCP حسب سير العمل. |
| رمز VS/مساعد الطيار | ممكن | مُستَحسَن | ممكن | يعتمد على MCP والدعم الطرفي. |
| الجوزاء CLI | ممكن | ممكن | مُستَحسَن | CLI هو الإعداد الأول الأبسط. |
| ركوب الأمواج | ممكن | مُستَحسَن | ممكن | يُفضل استخدام MCP محليًا. |

## اختر حسب مسار الإعداد

| يثبت | تثبيت | API موقع المفتاح | أفضل نطاق أولي | نطاق الحساب والتداول |
| --- | --- | --- | --- | --- |
| مستضاف MCP | لا أحد | لا يوجد مفتاح مستخدم API للبيانات العامة | بيانات السوق العامة | لا ينصح به للإصدار الأول |
| محلي MCP | حزمة تثبيت المستخدم | آلة المستخدم | البيانات العامة وقراءة الحساب | المسار الموصى به للتداول في المستقبل |
| CLI | حزمة تثبيت المستخدم | آلة المستخدم | البيانات العامة والبرامج النصية | مفيدة للمعاينة والأتمتة |
| البعيد MCP | يقوم المستخدم بنشر الخادم | سحابة المستخدم أو سحابة المؤسسة | البيانات العامة أو قراءة الحساب | ممكن عندما يتحكم المستخدم في النشر |
| مهارات | المستندات أو القوالب القابلة للتثبيت | يعتمد على الأدوات الأساسية | سير عمل التحليل | يجب أن تتبع أذونات الأداة |

## القاعدة الأمنية الأساسية

استخدم الإعداد الأقل خطورة الذي يدعم المهمة:

- بيانات السوق العامة: المستضافة MCP كافية.
- بيانات الحساب الخاص: محلي MCP أو بعيد يديره المستخدم MCP.
- معاينة التداول: محلي MCP أو CLI، ويفضل استخدام testnet أولاً.
- التداول الحقيقي: فقط بعد الحصول على إذن صريح ومعاينة وتأكيد وحدود وسجلات التدقيق.
