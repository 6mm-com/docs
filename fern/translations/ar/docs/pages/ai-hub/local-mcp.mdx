> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


المحلي MCP هو الإعداد الموصى به عندما يحتاج عميل الذكاء الاصطناعي إلى سياق حساب خاص أو أدوات تداول يتم التحكم فيها في المستقبل.

يعمل الخادم MCP على جهاز المستخدم. يستدعي عميل الذكاء الاصطناعي أدوات 6MM المحلية، ويتواصل الخادم المحلي مع 6MM APIs باستخدام بيانات الاعتماد التي قام المستخدم بتكوينها.

<h2 id="what-your-ai-client-can-do">ما يمكن لعميل الذكاء الاصطناعي الخاص بك فعله</h2>

باستخدام MCP المحلي، يمكن لعميل الذكاء الاصطناعي استخدام أدوات 6MM بطريقة يمكن التحكم فيها:

- جلب بيانات السوق الحية والتاريخية.
- اقرأ أرصدة الحسابات، والمواقف، والأوامر المفتوحة، وعمليات التعبئة، وسجلات التمويل عند تمكين بيانات الاعتماد للقراءة فقط.
- شرح تعرض المحفظة واستخدام الهامش ومخاطر التصفية.
- معاينة الطلبات قبل تقديم أي طلب حقيقي.
- في مراحل التداول الخاضعة للرقابة اللاحقة، لا تقم بإنشاء أو إلغاء الأوامر إلا بعد الحصول على إذن صريح والتحقق من المخاطر.

استخدم MCP المحلي عندما يجب أن تظل بيانات الاعتماد على جهاز المستخدم.

<h2 id="architecture">بنيان</h2>

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

<h2 id="example-configuration">تكوين المثال</h2>

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

<h2 id="recommended-permission-tiers">مستويات الأذونات الموصى بها</h2>

| الطبقة | أدوات | ملحوظات |
| --- | --- | --- |
| البيانات العامة | الأسواق، المؤشر، دفتر الطلبات، كلاينز، الصفقات، التمويل | لا يوجد وصول إلى الحساب الخاص. |
| قراءة الحساب | الأرصدة، المراكز، الأوامر المفتوحة، عمليات التعبئة | يتطلب نطاق المفتاح API للقراءة فقط. |
| معاينة التداول | معاينة الطلب وتأثير الهامش وتقدير الرسوم | لا يضع أوامر. |
| التداول الخاضع للرقابة | إنشاء وإلغاء وتعديل الأوامر | يتطلب إذنًا صريحًا وتأكيدًا وضوابط للمخاطر. |

<h2 id="first-setup-checklist">قائمة التحقق الأولى للإعداد</h2>

1. قم بتثبيت الحزمة MCP.
2. قم بإنشاء أو تكوين مفتاح API للقراءة فقط.
3. ابدأ في testnet.
4. أضف خادم MCP إلى تكوين عميل الذكاء الاصطناعي.
5. اطلب من العميل إدراج أدوات 6MM المتاحة.
6. قم بتشغيل استعلام بيانات السوق العامة.
7. عندها فقط أضف بيانات اعتماد قراءة الحساب إذا لزم الأمر.

<h2 id="security-notes">ملاحظات أمنية</h2>

المحلي MCP يجب أن يكون افتراضيًا للقراءة فقط وtestnet. يجب أن تتطلب أدوات التداول المعاينة، وتأكيد المستخدم، ومفاتيح العجز، والحدود النظرية، وفحوصات المخاطر من جانب الخدمة.
