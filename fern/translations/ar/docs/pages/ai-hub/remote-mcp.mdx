> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


جهاز التحكم عن بعد MCP مخصص للمستخدمين أو المؤسسات التي تريد نقطة نهاية MCP طويلة الأمد تحت سيطرتها الخاصة.

على عكس المستضاف MCP، لا يتم تشغيل جهاز التحكم عن بعد MCP بواسطة 6MM للمستخدم. 6MM يوفر التعليمات البرمجية والصور والقوالب والوثائق؛ يتحكم المستخدم في الاستضافة وبيانات الاعتماد.

<h2 id="architecture">بنيان</h2>

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<h2 id="deployment-targets">أهداف النشر</h2>

- عامل ميناء أو عامل ميناء يؤلف.
- VPS مع وكيل عكسي.
- السكك الحديدية.
- يجعل.
- Fly.io.
- AWS ECS أو لامدا.
- كوبيرنيت الداخلية.

<h2 id="required-files">الملفات المطلوبة</h2>

- ملف الإرساء.
- docker-compose.yml.
- .env.template.
- HTTP وضع النقل.
- /mcp نقطة النهاية.
- / نقطة النهاية الصحية.
- عكس الوكيل وTLS الملاحظات.

<h2 id="credential-model">نموذج الاعتماد</h2>

يجب تخزين بيانات الاعتماد في البيئة التي يديرها المستخدم، وليس في موجه عميل الذكاء الاصطناعي. بالنسبة لعمليات النشر التي تديرها المؤسسة، قم بتقييد الوصول إلى العملاء والشبكات المعتمدة.

<h2 id="recommended-first-release">يوصى بالإصدار الأول</h2>

ابدأ ببيانات السوق العامة. أضف قراءة الحساب فقط بعد توفر المصادقة ونطاق المفاتيح والسجلات وعناصر التحكم في الوصول. يجب أن يظل التداول معطلاً حتى يتم استيفاء متطلبات التداول الخاضعة للرقابة.
