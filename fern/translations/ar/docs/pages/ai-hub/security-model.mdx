> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


يجب أن يكون الوصول إلى التداول بمساعدة الذكاء الاصطناعي أكثر أمانًا من الأتمتة العادية لأنه يتم التعبير عن نية المستخدم باللغة الطبيعية.

<h2 id="required-permission-scopes">نطاقات الأذونات المطلوبة</h2>

| نِطَاق | يسمح |
| --- | --- |
| السوق: قراءة | بيانات السوق العامة وموارد القاعدة. |
| الحساب: إقرأ | الأرصدة والصفقات والأوامر المفتوحة وعمليات التعبئة وملخصات الحساب. |
| النظام: الكتابة | إنشاء الأمر وتعديله وإلغاؤه. |

<h2 id="default-safety-posture">وضعية السلامة الافتراضية</h2>

- الافتراضي للقراءة فقط.
- الافتراضي إلى testnet.
- لا تكشف عن عمليات السحب أو التحويلات من خلال أدوات الذكاء الاصطناعي.
- تتطلب المعاينة قبل الإنشاء.
- تتطلب تأكيدًا صريحًا قبل التداول على الشبكة الرئيسية.
- استخدم مفاتيح العجز لإجراءات التداول.
- تطبيق الحد الأقصى للحدود النظرية والرافعة المالية.
- احتفظ بسجلات التدقيق الكاملة.

<h2 id="controlled-trading-flow">تدفق التداول الخاضع للرقابة</h2>

```text
User natural language intent
  -> AI maps intent to tool parameters
  -> 6mm_preview_order validates the order
  -> service returns risk checks and margin impact
  -> user explicitly confirms
  -> 6mm_create_order submits the order
  -> audit log records the full flow
```

<h2 id="prompt-injection-protection">حماية الحقن الفوري</h2>

يجب على عملاء الذكاء الاصطناعي وخوادم MCP التعامل مع المحتوى الخارجي على أنه غير موثوق به. يجب ألا تتجاوز صفحات السوق والنصوص المنسوخة والمستندات ومحتوى الويب أذونات الأداة أو قواعد التأكيد أو حدود التداول.
