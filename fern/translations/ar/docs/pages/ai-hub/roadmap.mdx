> ** مخطط له - لم يتم إطلاقه بعد **
> AI Hub هي ميزة مخططة. تصف القدرات ونقاط النهاية والأوامر وتكوينات العميل الموجودة في هذه الصفحة التصميم المقترح وهي غير متوفرة حاليًا. سيتم الإعلان عن تعليمات التوفر والإعداد النهائية عند الإطلاق.


يجب إطلاق AI Hub على مراحل حتى يحصل المستخدمون على القيمة مبكرًا بينما تظل قدرات التداول الحساسة محمية.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## المرحلة الأولى: الوصول إلى السوق العامة باستخدام الذكاء الاصطناعي

الهدف: السماح لأي عميل مدعوم بتقنية الذكاء الاصطناعي بقراءة بيانات السوق الرسمية 6MM.

التسليمات:

- مشترك SDK / API العميل.
- CLI أوامر السوق العامة.
- أدوات السوق العامة المحلية MCP.
- استضافة MCP أدوات السوق العامة.
- موارد للأسواق والرسوم وقواعد المخاطر وحالة النظام.
- أدلة تثبيت العميل.

غير متضمنة:

- استعلامات الحساب.
- التداول الحقيقي.
- API استضافة المفتاح.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## المرحلة الثانية: قراءة الحساب

الهدف: السماح للمستخدمين بفحص سياق حساباتهم بأمان.

التسليمات:

- للقراءة فقط API نطاق المفتاح.
- ملخص الحساب.
- أرصدة.
- المواقف.
- أوامر مفتوحة.
- يملأ.
- مدفوعات التمويل.
- موجه مخاطر المحفظة.

النشر المفضل:

- محلي MCP.
- CLI.
- عن بعد MCP مستضاف ذاتيًا.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## المرحلة 3: معاينة التداول

الهدف: السماح للذكاء الاصطناعي بالمساعدة في إنشاء الأوامر دون تنفيذها.

التسليمات:

- `preview_order`.
- فحوصات المخاطر.
- تأثير الهامش.
- تقدير الرسوم.
- تأثير التصفية.
- موجه تخطيط التنفيذ.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## المرحلة الرابعة: التداول الخاضع للرقابة

الهدف: دعم التداول الحقيقي فقط من خلال حواجز حماية قوية.

التسليمات:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- العجز الجنسي.
- الحد الأقصى للحدود النظرية
- تأكيد صريح.
- سجلات التدقيق.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## المرحلة الخامسة: المهارات الوكيلة

الهدف: إنتاج تحليل السوق المشترك وسير عمل المخاطر.

التسليمات:

- مهارة محلل السوق.
- مهارة مخاطر المحفظة.
- مهارة تمويل الأبحاث.
- مهارة الحماية من التصفية.
- مهارة تخطيط التنفيذ.
- مكتبة المهام النموذجية.
