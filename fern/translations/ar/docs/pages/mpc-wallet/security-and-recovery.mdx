يبدأ الإعداد الأمني ​​بترتيبات الحفظ المفاتيح المختارة. تخدم حماية الحساب والموافقة على المعاملة وMPC المشاركة ومواد الاسترداد أغراضًا مختلفة.

<span id="assign-responsibilities" data-sixmm-canonical-anchor="assign-responsibilities" aria-hidden="true"></span>

## تعيين المسؤوليات

عرض روتيني منفصل، وبدء النقل، والموافقة، وإدارة الأعضاء، وإدارة بيانات اعتماد المطور حيث يسمح المنتج بذلك. التحقق من الأذونات في مساحة العمل المقصودة؛ الوصول إلى مساحة عمل واحدة لا ينشئ سلطة على أخرى.

بالنسبة لعمليات سير العمل في المؤسسة، قم بالموافقة على من يقوم بمراجعة تغييرات الوجهة والطلبات الصادرة. بالنسبة لتوقيع الجهاز، يجب على المشارك فحص الشبكة المعروضة والأصول والمبلغ والوجهة والسياق قبل القبول. لا ينبغي التعامل مع تأكيد الجهاز باعتباره مطالبة بالموافقة العمياء.

<span id="keep-credentials-distinct" data-sixmm-canonical-anchor="keep-credentials-distinct" aria-hidden="true"></span>

## حافظ على بيانات الاعتماد مميزة

| مادة | غاية |
| --- | --- |
| مصادقة الحساب | الوصول إلى تطبيق المستخدم |
| API المفتاح والسر | مصادقة طلبات الواجهة الخلفية API |
| مفتاح تفويض العميل | تفويض محتويات API الانسحاب عند الاقتضاء |
| MPC المشاركة الرئيسية | شارك في عملية التوقيع الموزعة للمحفظة |
| مواد النسخ الاحتياطي والاسترداد | استعادة المشاركة أو تنفيذ إجراء الاسترداد المدعوم |

تخزينها وفقا لمسؤولياتهم الخاصة. مفتاح API ليس مشاركة MPC؛ إن إعادة تعيين كلمة مرور الحساب ليست عملية استرداد للمحفظة. قم بتحميل المفاتيح العامة فقط من خلال تدفق التسجيل ذي الصلة، وليس المفاتيح الخاصة المقابلة لها مطلقًا.

## تحضير الانتعاش قبل الاستخدام

قم بتسجيل المشاركين المطلوبين وأصحاب النسخ الاحتياطية وخطوات الاسترداد أثناء الإعداد. احتفظ بالنسخ الاحتياطية في مواقع مناسبة منفصلة واختبر إجراء الاسترداد المدعوم في بيئة خاضعة للرقابة. ضع في اعتبارك فقدان الجهاز وانقطاع خدمة النظام الأساسي.

لا تسمح الحراسة الذاتية للمنصة بإعادة إنشاء مشاركات العملاء المفقودة. إذا بقي عدد قليل جدًا من المشاركين والنسخ الاحتياطية القابلة للاستخدام لتلبية متطلبات المحفظة، فقد يتم فقدان الوصول إلى الأصول. تحتاج الحفظ المشترك للمفاتيح أيضًا إلى ترتيبات استرداد موثقة؛ لا تفترض أن المشاركة في المنصة تضمن التعافي.

<span id="handle-an-unavailable-participant" data-sixmm-canonical-anchor="handle-an-unavailable-participant" aria-hidden="true"></span>

## التعامل مع مشارك غير متوفر

قم أولاً بالتمييز بين مشكلة الاتصال المؤقتة والجهاز غير المتاح ومواد التوقيع المفقودة. قم بمراجعة الجلسة وحالة الجهاز، ثم استخدم عملية الاسترداد أو الاستبدال المدعومة. لا تقم بمسح جهاز أو تغيير هوية توقيع التطبيق الخاص به أو افتراض إمكانية نقل المشاركات قبل التحقق من متطلبات الاسترداد.

إن توفر النسخة الاحتياطية ليس دليلاً على اكتمال اختبار الاسترداد. تأكد من الإجراءات والأدوات المضمنة في إصدارك قبل الاعتماد عليها.
