تصف أدلة المطورين سطح تكامل محفظة المؤسسة الحالي. MPC لم يتم إطلاق المحفظة: أمثلة نقاط النهاية هي مراجع التنفيذ، وليست وعدًا بخدمة متاحة للجمهور أو عقد API مجمد.

<span id="obtain-integration-information" data-sixmm-canonical-anchor="obtain-integration-information" aria-hidden="true"></span>

## الحصول على معلومات التكامل

قم بتأكيد قاعدة الاختبار URL، إصدار API، وهوية مساحة العمل، ونموذج الحفظ المفاتيح، والشبكات والأصول الممكّنة، وأذونات API، ومتطلبات ترخيص العميل وإعداد webhook. تأتي معرفات الشبكة والأصول من البيئة المتفق عليها؛ لا تفترض أنها تساوي معرفات السلسلة العامة.

احتفظ ببيانات اعتماد تكامل المحفظة منفصلة عن بيانات اعتماد التداول API. لا يجعل موقع التوثيق المشترك الخدمات أو نماذج الحسابات قابلة للتبديل.

<span id="connect-the-business-flow" data-sixmm-canonical-anchor="connect-the-business-flow" aria-hidden="true"></span>

## ربط تدفق الأعمال

1. قم بإنشاء مفتاح API ذو الامتيازات الأقل لمساحة عمل المؤسسة المقصودة واحتفظ بسره على الواجهة الخلفية لديك.
2. التحقق من صحة الطلب الموقع للقراءة فقط ومعالجة الأخطاء قبل تقديم عمليات النقل.
3. قم بتخصيص عنوان استلام لمعرف مستخدم تجاري ثابت، ثم تحقق من العنوان الذي تم إرجاعه وأي مذكرة.
4. تلقي أحداث الإيداع وتسويتها مع API الاستعلامات والسجلات الخاصة بك.
5. أضف ترخيص السحب ومعرفات طلبات الأعمال الثابتة وتتبع النتائج.

<span id="core-api-areas" data-sixmm-canonical-anchor="core-api-areas" aria-hidden="true"></span>

## المناطق الأساسية API

| منطقة | أمثلة على الطريق الحالي | غاية |
| --- | --- | --- |
| تلقي العناوين | `POST /api/v1/addresses`، `GET /api/v1/addresses` | تخصيص العناوين والاستعلام عنها |
| الودائع | `GET /api/v1/deposits`، `GET /api/v1/deposits/{id}` | متابعة التحويلات الواردة |
| عمليات السحب | `POST /api/v1/withdrawals`، `GET /api/v1/withdrawals/{id}` | تقديم طلب والاستعلام عن نتيجته |
| طلب البحث | `GET /api/v1/withdrawals/by-request` | التوفيق بين الطلب بعد استجابة غير مؤكدة |
| أرصدة | `GET /api/v1/balances` | الاستعلام عن أرصدة الأعمال في النطاق المعتمد |

لا يعني تسجيل المسار أن كل مفتاح API يمكنه استدعاء كل عملية. يمكن أن يؤثر الوصول إلى المنتج وأذونات مساحة العمل ووضع الحفظ المفاتيح والتهيئة على التوفر. تقع واجهات الأجهزة الإدارية والشخصية خارج تدفق البدء السريع للمؤسسة.

## التحقق من عناوين الاستلام

يدعم تطبيق SDK المتوفر شهادات العناوين الموقعة. قم بتكوين الأعضاء الموثوق بهم أو مادة الثقة المحددة بواسطة حزمة التكامل، وقم بشكل مستقل بتوفير معلومات مساحة العمل والسلسلة ومجموعة المفاتيح المتوقعة عند الحاجة. لا تستمد كل توقعات الثقة من نفس الاستجابة التي تتحقق منها.

بالنسبة لعناوين المجمع المُدارة بالكامل، يمكن للشهادة تحديد عنوان مملوك للنظام الأساسي بينما يظل تعيينه للعميل عبارة عن بيان من جانب الخادم. لا تصف هذا التعيين كدليل مشفر على ملكية العميل.
