6MM الدعم مصمم للشركاء المصرح لهم، والتكاملات النشطة، وعمليات الإنتاج. يبقى دعم المستخدم النهائي مسؤولية منصة الشريك ما لم يتم الاتفاق بشكل منفصل.

<h2 id="choose-the-right-path">اختر الطريق الصحيح</h2>

| الوضع | المسار الموصى به | تشمل |
| --- | --- | --- |
| شراكة جديدة أو تقييم حلول | مسار انضمام الشركاء | نوع المنتج، المنطقة المستهدفة، الجدول الزمني للإطلاق، نموذج التكامل المتوقع. |
| SDK، API، webhook أو سؤال حول البيئة | مسار الدعم الفني | نقطة النهاية، النسخة SDK ، معرف الطلب، خطوات الإنتاج، السجلات. |
| حادث الإنتاج أو تدهور تدفق التداول | مسار تصعيد الحادث | نطاق التأثير، وقت البدء، المستخدمين المتأثرين، معرفات الطلبات، التخفيف الحالي. |
| تغيير المواد في الأصول أو النسخ أو الإطلاق | مسار دعم العمليات | الصفحة، اللغة، التغيير المطلوب، تاريخ الإطلاق، موافقة المالك. |
| الضعف أو الاشتباه في الإساءة | مسار تقارير الأمان | التفاصيل التقنية، نقطة النهاية المتأثرة، الأدلة، الإلحاح، وما إذا كانت المشكلة نشطة. |

<h2 id="severity-guide">دليل الشدة</h2>

| الشدة | مثال |
| --- | --- |
| حرج | التداول الإنتاجي، أو المصادقة، أو إصدار الرموز، أو تدفقات الأموال غير متاحة. |
| عالي | تدفق الشركاء الرئيسي يتدهور، لكن هناك حل بديل. |
| عادي | سؤال عن التكامل، طلب التكوين، مشكلة في الوثائق، أو دعم الإطلاق المخطط له. |

<h2 id="before-contacting-support">قبل التواصل مع الدعم</h2>

- تأكيد المنطقة والبيئة المتأثرة بالمنتج.
- جمع معرفات الطلبات، معرفات الطلبات، الطوابع الزمنية، معرفات تعيين المستخدمين، معرفات أحداث الويبهوك، والسجلات.
- استخدم قالب طلب الدعم لمشاكل الإنتاج.
