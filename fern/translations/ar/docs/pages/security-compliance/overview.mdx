تكتب وثائق الأمن والامتثال لفرق الشركاء التي تجهز استخدام الإنتاج لبنية 6MM التداول. تربط بنية الأمان، وضوابط API/SDK ، والتحضير للامتثال، والحدود القانونية، وجاهزية الإطلاق في مسار مراجعة واحد.

<h2 id="documentation-map">خريطة التوثيق</h2>

| المنطقة | الغرض |
| --- | --- |
| بنية الأمان | فهم كيفية حماية بنية التداول، والوصول إلى API/SDK ، وعمليات الشركاء. |
| API وأمان webhook | حماية تكاملات الخلفية من خلال التوقيع، والتخزين السري، والمعالجة الذاتية. |
| جاهزية الامتثال | جهز سياق دعم الرخصة، وفحوصات الإطلاق، والضوابط التشغيلية من جانب الشريك. |
| الوثائق القانونية | راجع الشروط والخصوصية وحدود المسؤولية قبل بدء الإنتاج. |

<h2 id="recommended-reading-order">ترتيب القراءة الموصى به</h2>

1. ابدأ بهيكل الأمن وحدود مسؤولية الشركاء.
2. مراجعة إدارة API Key ، توقيع الطلبات، وميزة Webhook قبل دمج الواجهة الخلفية.
3. مراجعة نظرة عامة على الامتثال ودعم الترخيص قبل التحضير للإطلاق الإقليمي.
4. راجع الصفحات القانونية وقائمة التحقق من الإطلاق قبل عرض وظائف التداول للمستخدمين.
