نموذج المسؤولية الواضح يقلل من المخاطر التشغيلية ويساعد فرق الدعم على الاستجابة بشكل أسرع.

<h2 id="responsibility-split">تقسيم المسؤولية</h2>

| المنطقة | 6MM | شريك |
| --- | --- | --- |
| البنية التحتية للتجارة | قدرات المطابقة، والمخاطرة، ومحرك التداول، وقدرات API وSDK | التكامل الصحيح ومراقبة الإنتاج |
| علاقة المستخدم النهائي | لا توجد علاقة مباشرة مع العميل إلا إذا تم الاتفاق بشكل منفصل | عملية انضمام المستخدم، الدعم، الإفصاحات، ودورة حياة الحساب |
| الأسرار والمؤهلات | يوفر نموذج الاعتماد ومتطلبات التوقيع | يخزن الأسرار بشكل آمن ويقيد الوصول الداخلي |
| ويبهوكس | إرسال أحداث دورة حياة موقعة | يتحقق من التواقيع ويعالج الأحداث بشكل متكامل |
| عمليات الامتثال | يوفر تقنيات ومواد دعم موجهة للامتثال | تأكيد الالتزامات المحلية والمتطلبات الموجهة للمستخدمين |
| إصدارات التكامل | يحافظ على قدرات المنصة والتكامل الموثقة | اختبار كود الشريك، والتكوين، ورحلات المستخدم قبل الإصدار |
| التعامل مع الحوادث | يحقق في البنية التحتية 6MM ذات الصلة ويوفر قنوات دعم للشركاء | يكتشف التأثير المواجه للمستخدم، ويحافظ على الأدلة، ويحتوي على أنظمة الشركاء، ويتصعد الأمور |

<h2 id="responsibilities-by-lifecycle">المسؤوليات حسب دورة الحياة</h2>

| المسرح | عمل الشريك |
| --- | --- |
| التصميم | حدد ملكية المستخدم، تدفق الأصول، تدفق البيانات، نموذج الدعم، والجهات المستهدفة. |
| البناء | احتفظ بالأسرار في الخلفية، ونفذ المصادقة المدعومة، وحافظ على معرفات الأعمال. |
| اختبار | قم بممارسة مهلة الاستراحة، وإعادة المحاولة، وتكرار webhook، ورمز منتهية الصلاحية، وسيناريوهات الفشل. |
| الإطلاق | مراجعة الجاهزية الكاملة، وإنشاء المراقبة، وتصعيد الدعم الوثائقي. |
| التشغيل | مراجعة التنبيهات، وتوفيق العمليات غير الطبيعية، وتدوير بيانات التوثيق، والحفاظ على أدلة التدقيق. |
| الحادث | احتواء على أنظمة يتحكم بها الشركاء، وحماية بيانات الاعتماد، والحفاظ على الجداول UTC ، والاتصال بالقناة 6MM الصحيحة. |

<h2 id="handoff-checklist">قائمة التحقق للتسليم التشغيلي</h2>

- تعيين المالك للصحة والسلامة والامتثال ودعم المستخدم النهائي في التكامل.
- عناوين URL لقاعدة إنتاج الوثائق، ومالكي بيانات الاعتماد، وإجراءات التناوب.
- تأكيد لوحات المعلومات والتنبيهات لفشل المصادقة، والطلب، والنقل، وفشل webhook.
- تخزين معرفات طلبات، أرقام أوامر الشركاء، ومعرفات الأحداث في سجلات قابلة للبحث.
- تحديد الأحداث التي تتطلب تصعيدا فوريا.
- إبقاء [نموذج طلب الدعم](/ar/resources/support-request-template) متاحا لفريق العمليات.
