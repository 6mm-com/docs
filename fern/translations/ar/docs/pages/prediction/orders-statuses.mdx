كل أمر تنبؤ مقبول له رقم الطلب الخاص به. تشير الأوامر لأعلى/لأسفل أيضًا إلى جولة؛ لا تتطلب الطلبات المخصصة والشبكة جولة مشتركة.

<span id="current-and-historical-records" data-sixmm-canonical-anchor="current-and-historical-records" aria-hidden="true"></span>

## السجلات الحالية والتاريخية

| الحالة المعروضة | كيفية قراءتها |
| --- | --- |
| في انتظار النتيجة | ولم يتم تسجيل النتيجة النهائية بعد |
| الرهان مغلق | مرحلة الرهان المعروضة مغلقة؛ هذه ليست نتيجة الفوز/الخسارة |
| فاز | يتم تسجيل الأمر كنتيجة فائزة |
| ضائع | يتم تسجيل الأمر كنتيجة خاسرة |
| ردها | تنعكس معالجة استرداد الأموال في حالة الطلب؛ التوفيق بين الصفقة الفعلية |
| باطل | تم إبطال الأمر؛ تحقق من السبب ومعالجة الأموال ذات الصلة |

لا تستخدم كل لعبة كل حالة متوسطة بنفس الطريقة. لا تثبت تسمية الحالة وحدها أن رصيد الحساب قد اكتمل.

<span id="fields-to-check" data-sixmm-canonical-anchor="fields-to-check" aria-hidden="true"></span>

## الحقول للتحقق

تعرض جميع الألعاب رقم الطلب، وملكية المستخدم، والرمز، والرهان، والاحتمالات، ووقت الطلب، والحالة. تضيف السجلات التاريخية الدفع الفعلي ومعلومات النتيجة ووقت التسوية ورقم معاملة التسوية.

- لأعلى/لأسفل يضيف الرقم الدائري والاتجاه المتوقع/الفعلي.
- يضيف المخصص مضاعفات عائد ثابتة وانتهاء الصلاحية المستقل.
- تضيف الشبكة الخلية المحددة والفاصل الزمني للسعر؛ تفسير حقول النتائج باستخدام قاعدة لمس النافذة الزمنية.

## التغييرات والتقديمات المكررة

لا تفترض أنه يمكن تعديل أو إلغاء أمر التنبؤ مثل أمر الحد الدائم. اتبع الإجراءات والقواعد المتاحة للمنتج المقبول. عندما تكون استجابة الإرسال غير مؤكدة، استفسر عن الطلب الأصلي قبل وضع حصة أخرى.
