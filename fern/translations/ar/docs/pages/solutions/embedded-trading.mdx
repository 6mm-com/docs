تم تصميم نظام التداول Embedded API / SDK للشركاء الذين يمتلكون بالفعل حركة مرور أو مستخدمين أو سير عمل أعمال ويرغبون في إضافة التداول دون بناء بورصة كاملة من الصفر.

<h2 id="what-it-provides">ما الذي تقدمه</h2>

- محطة تداول مدمجة عبر Trading Widget SDK
- دمج الشركاء في الواجهة الخلفية من خلال Agent SDK
- ربط هوية المستخدم وتدفقات رموز الإدخال
- نقل الأصول، والطلب، والموقع، والوصول إلى API الحساب
- تكامل الأحداث، الويبهوك، ودورة الحياة للأنظمة التشغيلية

<h2 id="recommended-architecture">الهندسة المعمارية الموصى بها</h2>

| الطبقة | المسؤولية |
| --- | --- |
| واجهة الشريك الأمامية | تستضيف نقطة الدخول وتدمج واجهة التداول 6MM . |
| خلفية الشريك | يحتفظ API الأسرار، ويتحقق من صحة المستخدمين، ويصدر رموز مدمجة، ويعالج webhooks. |
| 6MM البنية التحتية للتجارة | يتعامل مع واجهة التداول، المطابقة، المخاطر، السيولة، حالة الحساب، ودورة حياة التداول. |

<h2 id="choose-an-integration-path">اختر مسار تكامل</h2>

| المتطلب | المسار الموصى به |
| --- | --- |
| واجهة تداول كاملة مع أسرع تكامل ويب | Trading Widget |
| ربط المستخدمين في الخلفية، والنقل، و URL الإدخال، والتعامل مع webhook | Agent SDK |
| سير عمل المنتجات والطلبات المخصص بالكامل | REST API + WebSocket |
| خبرة في تبادل العلامات التجارية مع نطاق تشغيلي أوسع | تبادل العلامة البيضاء |

قد يجمع التصميم النهائي بين هذين المسارين. تأكد من المصادقة، ملكية الأصول، حدود المسؤولية، المراقبة، ودعم الإنتاج قبل بدء التنفيذ.
