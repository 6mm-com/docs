استخدم هذه القائمة قبل عرض تدفقات التداول المدعومة 6MMللمستخدمين الإنتاجيين. تم تصميمها ليقوم فرق المنتج والهندسة والعمليات والمخاطرة والدعم بمراجعتها معا.

<span id="launch-checklist" data-sixmm-canonical-anchor="launch-checklist" aria-hidden="true"></span>

## قائمة التحقق من الإطلاق

| المنطقة | قائمة التحقق |
| --- | --- |
| المنتج | نقاط الدخول، ونص المستخدم، ومحفزات المخاطر، وتغطية اللغة، ومسارات الدعم جاهزة. |
| الخلفية | API بيانات الاعتماد، والتوقيع، وإصدار الرموز، والويبهوكس، والمحاولات، والتسجيل. |
| التجارة | تمت مراجعة أوامر الطلب، والتحويل، والموقع، والهامش، والأتعاب، وسلوك التصفية. |
| الأمن | يتم إعداد سجلات الأسرار، وأدوار الوصول، والمراقبة، والاستجابة للحوادث، وسجلات التدقيق. |
| العمليات | يتم تعيين سير عمل الدعم، ومسارات التصعيد، والمصالحة، والمراقبة اليومية. |

<span id="recommended-sequence" data-sixmm-canonical-anchor="recommended-sequence" aria-hidden="true"></span>

## التسلسل الموصى به

1. التحقق الكامل من بيئة الرمل أو البيئة الداخلية.
2. تشغيل رحلات مستخدم من طرف إلى طرف لتسجيل الدخول، الدخول، النقل، التداول، والدعم.
3. تأكيد ملكية المراقبة والاستجابة للحوادث.
4. الموافقة على النسخ العامة، والأصول المحلية، وتنزيلات الموارد.
5. ابدأ بنافذة إطلاق محكمة قبل الترويج الشامل.

<span id="after-launch" data-sixmm-canonical-anchor="after-launch" aria-hidden="true"></span>

## بعد الإطلاق

راجع النشاط يوميا خلال فترة الإطلاق الأولية. شاهد تحويل الإدخال، فشل إصدار الرموز، أخطاء الطلب، جودة الانتشار، إكمال النقل، محاولات المحاولات عبر الويبهوك، وتذاكر الدعم معا.
