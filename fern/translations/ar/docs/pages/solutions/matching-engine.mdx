التبادل ذو العلامة البيضاء يتطلب أكثر من مجرد غلاف واجهة أمامية. تعتمد تجربة المستخدم على وحدات أساسية موثوقة وراء التداول، والحسابات، والمخاطر، والتسوية.

<h2 id="core-modules">الوحدات الأساسية</h2>

| الوحدة | الدور |
| --- | --- |
| المطابقة ودورة حياة الترتيب | يتعامل مع سجلات تقديم الأوامر، والحالة المطابقة، والإلغاء، والتنفيذ. |
| نظام الحسابات والمراكز | يحافظ على الأرصدة، وحالة الهامش، والمراكز، وتوفر التداول. |
| ضوابط المخاطر | ينسق الرافعة المالية، والهامش، والتصفية، والسلوك غير الطبيعي في السوق. |
| بيانات السوق | توزع بيانات الأسعار، العمق، التداولات، والرسوم البيانية على واجهات التداول. |
| الاستيطان والسجلات | يحافظ على سجل التداول، تغييرات التوازن، والسجلات التشغيلية متوافقة. |

<h2 id="implementation-questions">أسئلة التنفيذ</h2>

- أي أنواع الترتيب وترتيب الحالة تعرض للمستخدمين؟
- أي خدمة تملك قواعد الرموز، والتحقق الدقيق، وتوفر التداول؟
- كيف يتم التوفيق بين سجلات النظام والتجارة والمواقف والتوازن والتسوية؟
- أي المعرفات تبقى مستقرة عبر REST الردود، والأحداث WebSocket ، وسجلات الشركاء؟
- ما هو مسار المراقبة والتراجع عندما تصبح بيانات المطابقة أو المخاطر أو السوق غير متوفرة؟

أجب على هذه الأسئلة قبل تطوير الواجهة الأمامية حتى يستخدم سلوك المنتج، والتعامل API ، والعمليات، والدعم نفس نموذج التداول.
