<h2 id="how-the-solutions-connect">كيف ترتبط الحلول</h2>

تجمع معظم تطبيقات الشركاء بين أكثر من قدرة 6MM واحدة. قد تستخدم البورصة ذات العلامة البيضاء السيولة المؤسسية، ودعم الامتثال، وتكاملات API . قد يبدأ الشريك التجاري المدمج من Trading Widget SDK ثم يضيف لاحقا تدفقات Agent SDK خلفية، ومعالجة webhook، وموارد تشغيلية.
