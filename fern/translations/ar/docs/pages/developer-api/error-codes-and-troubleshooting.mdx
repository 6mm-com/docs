<h2 id="error-response-format">صيغة الاستجابة للخطأ</h2>

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

عادة ما تعيد أخطاء الأعمال هيكل JSON الموحد. يجب على المدمجين التحقق من `code` أولا. قد تعيد حالات فشل المصادقة HTTP `401`؛ قد تعيد حدود المعدل HTTP `429`.

<h2 id="common-error-codes">رموز الأخطاء الشائعة</h2>

| رمز الخطأ      | الوصف                                  |
| --------------- | -------------------------------------------- |
| `0`             | النجاح                                      |
| `1001`          | لم يتم تقديم معلومات مصادقة صحيحة |
| `1002`          | الرمز منتهية صلاحيته                                |
| `1003`          | رمز غير صالح، API Keyأو توقيع         |
| `1004`          | تم سحب الرمز                                |
| `1006`          | المصدر IP عدم التطابق                           |
| `2001`          | المعلمة المطلوبة مفقودة                   |
| `2002`          | قيمة المعلمة غير صالحة                      |
| `2003`          | المعامل خارج النطاق                       |
| `3001`          | التوازن غير الكافي                         |
| `3003`          | لم يتم العثور على الترتيب                              |
| `3004`          | طلب مكرر                            |
| `3005`          | لا يمكن إلغاء الطلب                     |
| `3006`          | تم رفض الإذن                            |
| `3100` - `3112` | خطأ التحقق من صحة معلمات ترتيب الشروط   |
| `5001`          | خطأ داخلي في الخادم                        |
| `5002`          | الخدمة غير متاحة مؤقتا              |
| `5003`          | تفعيل حد السعر                         |

<h2 id="troubleshooting">استكشاف الأخطاء</h2>

| المشكلة                                     | التوصية                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` لا توجد معلومات مصادقة صالحة  | تحقق مما إذا كان `Authorization: Bearer <accessToken>` أو `X-API-KEY` متضمن.                  |
| `1002` الرمز منتهي صلاحيته                        | قم بتحديث الرمز أو تسجيل الدخول مرة أخرى قبل إعادة المحاولة.                                                   |
| `1003` رمز غير صالح أو API Keyأو توقيع | تحقق من API Key، حمولة التوقيع، نص JSON نص الطلب، وترتيب معلمات الاستعلام.           |
| المصدر `1006` IP عدم تطابق                   | تحقق من إعدادات القائمة البيضاء API Key IP .                                                    |
| `3004` طلب مكرر                    | لا تعيد استخدام نفس التوقيع في المسارات المتعلقة بالترتيب. أعد توليد `timestamp` `signature`. |
| `5003` حد السعر تم تفعيله                 | قلل من تكرار الطلبات واستخدم التراجع الأسي عند إعادة المحاولة.                                |
| `Timestamp outside of tolerance window`     | اتصل `/v1/time` لمعايرة تعويض الوقت وتوقيع الطلب مرة أخرى.                             |
