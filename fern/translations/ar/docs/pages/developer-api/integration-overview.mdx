> REST URL القاعدة : `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

هذه الوثائق مخصصة للأنظمة الخارجية التي تتكامل مع خدمة 6MM API . يغطي تسجيل الدخول، المصادقة JWT ، إدارة API Key ، توقيع API Key HMAC ، استفسارات الحسابات، الطلبات، المراكز، بيانات السوق، وتدفقات WebSocket .

يتم التعامل مع توفير الحسابات وإعداد التمويل من خلال عمليات على المنصة. تصف هذه التوثيق فقط نقاط نهاية الخدمة API القابلة للاستدعاء خارجيا.

<span id="service-endpoints" data-sixmm-canonical-anchor="service-endpoints" aria-hidden="true"></span>

## نقاط نهاية الخدمة

| النوع      | نقطة النهاية              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## تدفق التكامل

تسلسل التكامل الموصى به:

1. سجل الدخول بالحساب الذي توفره المنصة واحصل على `accessToken`.
2. للوصول البرمجي على جانب الخادم، أنشئ API Key مع JWT أولا، وقم بتخزين `apiSecret`المرتجعة مرة واحدة بأمان.
3. يمكن استدعاء الاستعلامات الخاصة ونقاط نهاية الأوامر والمراكز باستخدام إما `Authorization: Bearer <accessToken>` أو توقيع API Key.
4. بالنسبة للبثوث الخاصة WebSocket ، أنشئ `listenKey` أولا، ثم اتصل ب `wss://ws.6mm.com/ws?listenKey=...`.
5. بيانات السوق REST نقاط النهاية وقنوات WebSocket العامة لا تتطلب المصادقة.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## اختيار المصادقة

| السيناريو                               | الطريقة الموصى بها         |
| -------------------------------------- | -------------------------- |
| إجراءات مستخدم الواجهة الأمامية                  | JWT                        |
| المكالمات البرمجية على جانب الخادم         | توقيع API Key + HMAC   |
| API Key إنشاء وتحديث وحذف | JWT                        |
| REST السوق العامة / WebSocket العام  | لا حاجة للمصادقة |
