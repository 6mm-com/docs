<h2 id="orders">الأوامر</h2>

| إينوم                 | القيم                                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| جانب الأمر           | `BUY` / `SELL`                                                                                            |
| جانب المركز        | `BOTH` / `LONG` / `SHORT`                                                                                 |
| نوع الأمر الطبيعي    | `LIMIT` / `MARKET`                                                                                        |
| نوع ترتيب الحالة | `STOP_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_MARKET` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP`               |
| الزمن القائم        | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                                         |
| نوع سعر الزناد   | `MARK_PRICE` / `CONTRACT_PRICE`                                                                           |
| حالة الأمر         | `NEW` / `PENDING` / `PARTIALLY_FILLED` / `FILLED` / `CANCELED` / `REJECTED` / `PARTIALLY_FILLED_CANCELED` |

`NEW` يعني أن طلب الطلب تم قبوله وإعادته. `PENDING` يعني أن الأمر دخل في حالة الطلب المعلق أو المفتوح.

<h2 id="positions">المناصب</h2>

| إينوم                      | القيم                                                      |
| ------------------------- | ----------------------------------------------------------- |
| قيمة طلب وضع الهامش | `1` التقاطع `2` معزول                                     |
| سلسلة وضع الهامش        | `ISOLATED` / `CROSS`                                        |
| وضع الزناد المغلق        | `1` الدليل `2` يأخذ الأرباح، `3` وقف الخسارة، `4` التصفية |

<h2 id="integration-rules">قواعد التكامل</h2>

- عامل قيم العدد كقيم أسلاك حساسة للحرف.
- الحفاظ على القيم غير المعروفة في السجلات والفشل بأمان بدلا من مطابقتها بصمت إلى حالة معروفة.
- لا تستنتج أن كل حالة من الحالات غير النهائية آمنة لإعادة التجربة. استفسر عن الأمر أو توفقه مع حدث WebSocket خاص.
- تخزين كل من قيمة API الأصلية وملصق العرض المواجه للشريك حتى يمكن دعم القيم الجديدة دون تغيير السجلات التاريخية.

<h2 id="order-state-handling">التعامل مع الحالة في الأمر</h2>

| مجموعة الولايات | القيم | التعامل الموصى به |
| --- | --- | --- |
| مقبولة أو مفتوحة | `NEW`، `PENDING`، `PARTIALLY_FILLED` | حافظ على النظام نشطا ووافقت على WebSocket أو REST التحديثات. |
| اكتمل | `FILLED` | طبق الكمية النهائية وسجلات التنفيذ. |
| مغلق بدون تعبئة كاملة | `CANCELED`، `REJECTED`، `PARTIALLY_FILLED_CANCELED` | أوقف المعالجة النشطة وحافظ على السبب وأي كمية تم تنفيذها. |
