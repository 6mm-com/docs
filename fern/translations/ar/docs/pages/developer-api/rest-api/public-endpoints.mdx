## URL القاعدة

```
https://api.6mm.com
```

<span id="service-version" data-sixmm-canonical-anchor="service-version" aria-hidden="true"></span>

## نسخة الخدمة

```http
GET /v1/version
```

احصل على معلومات عن إصدار الخدمة.

<span id="server-time" data-sixmm-canonical-anchor="server-time" aria-hidden="true"></span>

## وقت الخادم

```http
GET /v1/time
```

احصل على وقت الخادم. يمكن استخدام هذه النقطة النهائية لمعايرة وقت العميل قبل توقيع API Key .

<span id="user-login" data-sixmm-canonical-anchor="user-login" aria-hidden="true"></span>

## تسجيل دخول المستخدم

```http
POST /v1/public/user/login
```

معايير الطلب:

| المعلمة    | النوع   | مطلوب | الوصف                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | نعم      | اسم المستخدم، الطول من 3 إلى 32                 |
| `password`   | string | نعم      | كلمة السر، الطول 1 - 64                 |
| `deviceId`   | string | لا       | بصمة الجهاز، حتى 64 حرفا |
| `deviceName` | string | لا       | اسم الجهاز، حتى 128 حرفا       |

مثال على الطلب:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

مثال على الرد:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<span id="refresh-token" data-sixmm-canonical-anchor="refresh-token" aria-hidden="true"></span>

## رمز تحديث

```http
POST /v1/public/user/refresh-token
```

في سيناريوهات التكامل العادية، يتم تحديث حالة تسجيل الدخول عبر كوكي. احتفظ بالكوكي الذي أعادته عبر رد تسجيل الدخول.

حقول الاستجابة:

| الميدان          | النوع   | الوصف              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | رمز الوصول الجديد         |
| `accessExpire` | int64  | وقت انتهاء صلاحية رمز الوصول |

<span id="agent-sso" data-sixmm-canonical-anchor="agent-sso" aria-hidden="true"></span>

## العميل SSO

<span id="ticket-exchange" data-sixmm-canonical-anchor="ticket-exchange" aria-hidden="true"></span>

## تبادل التذاكر

```http
POST /v1/public/agent-sso/exchange-ticket
```

معايير الطلب:

| المعلمة  | النوع   | مطلوب | الوصف                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | نعم      | تذكرة لمرة واحدة صادرة من خدمة الوكيل |
| `deviceId` | string | لا       | بصمة الجهاز، حتى 64 حرفا     |

حقول الاستجابة:

| الميدان          | النوع   | الوصف              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | رمز الوصول             |
| `accessExpire` | int64  | وقت انتهاء صلاحية رمز الوصول |
| `redirectPath` | string | مسار إعادة التوجيه المقترح  |

<span id="embed-token-exchange" data-sixmm-canonical-anchor="embed-token-exchange" aria-hidden="true"></span>

## تبادل الرموز المضمنة

```http
POST /v1/public/agent-sso/exchange-embed-token
```

معايير الطلب:

| المعلمة    | النوع   | مطلوب | الوصف                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | نعم      | رمز تداول مدمج قصير العمر يصدره خدمة الوكلاء |
| `channelId`  | string | نعم      | معرف قناة iframe مدمج، حتى 128 حرفا               |
| `deviceId`   | string | لا       | بصمة الجهاز، حتى 64 حرفا                        |

حقول الاستجابة:

| الميدان          | النوع   | الوصف              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | رمز الوصول             |
| `accessExpire` | int64  | وقت انتهاء صلاحية رمز الوصول |

<span id="pnl-leaderboard" data-sixmm-canonical-anchor="pnl-leaderboard" aria-hidden="true"></span>

## لوحة المتصدرين في PnL

```http
GET /v1/public/leaderboard/pnl?period=30d
```

معايير الطلب:

| المعلمة | النوع   | مطلوب | الوصف          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | نعم      | `7d` / `30d` / `90d` |

حقول الاستجابة:

| الميدان              | النوع   | الوصف                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | الرتبة                                                              |
| `list[].userId`    | string | معرف المستخدم الخارجي                                                  |
| `list[].trader`    | string | اسم تاجر مقنع                                                |
| `list[].volume`    | string | حجم التداول في النافذة                                      |
| `list[].pnlAmount` | string | تم تحقيق PnL في النافذة                                        |
| `list[].pnlPct`    | string | نسبة PnL، عشرية من `0` إلى `1`                                |
| `myRank`           | int32  | ترتيب المستخدم الحالي. يعيد `0` إذا لم يتم التحقق منه أو لم يتم تصنيفه |
