<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## معلومات المستخدم

```http
GET /v1/private/user/info
```

حقول الاستجابة:

| الميدان                  | النوع   | الوصف      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | معرف المستخدم الخارجي |
| `userInfo.username`    | string | اسم المستخدم         |
| `userInfo.agentId`     | int64  | معرف الوكيل         |
| `userInfo.vipLevel`    | int64  | VIP المستوى        |
| `userInfo.lastLoginAt` | int64  | آخر وقت تسجيل دخول  |
| `userInfo.lastLoginIp` | string | آخر تسجيل IP    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## أصول المستخدمين

```http
GET /v1/private/user/asset
```

حقول الاستجابة:

| الميدان                     | النوع   | الوصف                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | معرف المستخدم الخارجي                |
| `userAsset.assetType`     | string | نوع الأصل                      |
| `userAsset.walletBalance` | string | رصيد المحفظة                  |
| `userAsset.frozenMargin`  | string | الهامش مجمد بسبب الأوامر المعلقة |
| `userAsset.usedMargin`    | string | الهامش المستخدم من قبل المراكز        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## أنشئ listenKey

```http
POST /v1/private/user/listen-key
```

ينشئ مفتاح مصادقة لتدفقات WebSocket الخاصة.

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## تجديد listenKey

```http
PUT /v1/private/user/listen-key
```

يمدد صلاحية listenKey .

<span id="close-listenkey" data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## إغلاق listenKey

```http
DELETE /v1/private/user/listen-key
```

يغلق listenKeyالمحدد.

## سجلات تغيير الحساب

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

معايير الطلب:

| المعلمة    | النوع   | مطلوب | الوصف                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | لا       | نوع الأصل، مثل `USDT`   |
| `changeType` | string | لا       | تغيير النوع                  |
| `startTime`  | int64  | لا       | وقت البدء                   |
| `endTime`    | int64  | لا       | نهاية الزمن                     |
| `page`       | int32  | لا       | رقم الصفحة، `1` الافتراضي     |
| `pageSize`   | int32  | لا       | العناصر في كل صفحة، `20` الافتراضي |

حقول الاستجابة:

| الميدان                        | النوع   | الوصف                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | نوع الأصل                   |
| `list[].amount`              | string | المبلغ المتغير               |
| `list[].walletBalanceBefore` | string | رصيد المحفظة قبل التغيير |
| `list[].walletBalanceAfter`  | string | رصيد المحفظة بعد التغيير  |
| `list[].frozenBalanceBefore` | string | تجمد التوازن قبل التغيير |
| `list[].frozenBalanceAfter`  | string | توازن متجمد بعد التغيير  |
| `list[].changeType`          | string | تغيير النوع                  |
| `list[].referenceId`         | string | معرف الأعمال ذات الصلة          |
| `list[].createdAt`           | int64  | زمن الخلق                |
| `total`                      | int64  | إجمالي العدد                  |

## إحصائيات حجم الثلاثين يوما

```http
GET /v1/private/user/volume-stats
```

حقول الاستجابة:

| الميدان         | النوع   | الوصف                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | حجم التداول التراكمي خلال الثلاثين يوما الماضية |
| `feeTotal30d` | string | الرسوم التراكمية خلال آخر 30 يوما           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## تاريخ التوازن

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

معايير الطلب:

| المعلمة | النوع   | مطلوب | الوصف                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | نعم      | `1D` / `1W` / `1M`                     |
| `limit`   | الاستخبارات    | لا       | عدد العناصر التي تم إرجاعها، `30` الافتراضي |

حقول الاستجابة:

| الميدان             | النوع   | الوصف                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | تاريخ التجميع            |
| `items[].balance` | string | رصيد المحفظة              |
| `items[].pnl`     | string | تم تحقيق PnL لتلك الفترة |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## نظرة عامة على التجارة

```http
GET /v1/private/user/trade-overview?type=1M
```

معايير الطلب:

| المعلمة | النوع   | مطلوب | الوصف                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | نعم      | نطاق الاتجاهات: `1D`، `1W`، `1M`، `3M`، `6M`، `1Y` |

حقول الاستجابة:

| الميدان                | النوع   | الوصف                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | PnL الذي تم تحقيقه اليوم                                                 |
| `todayVolume`        | string | حجم تداول العقود اليوم                                      |
| `totalVolume`        | string | حجم تداول العقود التراكمي                                   |
| `totalPnl`           | string | الأرباح التراكمية المحققة                                              |
| `maxDrawdown30d`     | string | أقصى مبلغ سحب خلال آخر 30 يوما                        |
| `maxDrawdown30dRate` | string | أقصى معدل سحب خلال آخر 30 يوما، عشري من `0` إلى `1` |
| `transferIn`         | string | الأموال المحولة التراكمية                                      |
| `transferOut`        | string | الأموال المحولة التراكمية                                     |
| `items[]`            | array  | بيانات اتجاهات الأصول                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## ملخص نظرة عامة على الأصول

```http
GET /v1/private/user/asset/overview/summary
```

حقول الاستجابة هي نفسها حقول ملخص التبادل العام، باستثناء `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## نظرة عامة على الأصول الاتجاه

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

معايير الطلب:

| المعلمة | النوع   | مطلوب | الوصف                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | نعم      | نطاق الاتجاهات: `1D`، `1W`، `1M`، `3M`، `6M`، `1Y` |

حقول الاستجابة:

| الميدان                  | النوع   | الوصف                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | وقت اللقطة                   |
| `items[].balance`      | string | رصيد الحساب الجاري         |
| `items[].pnl`          | string | PnL للفترة الحالية      |
| `items[].pnlRate`      | string | معدل الأرباح الربحية للفترة الحالية |
| `items[].totalPnl`     | string | الرقم التراكمي لبيع الأرباح                  |
