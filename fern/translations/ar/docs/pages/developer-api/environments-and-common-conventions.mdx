<h2 id="service-endpoints">نقاط نهاية الخدمة</h2>

| النوع      | نقطة النهاية              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="time-and-numeric-values">الزمن والقيم الرقمية</h2>

* ما لم يذكر خلاف ذلك، فإن حقول الوقت هي طوابع زمنية بحجم مللي ثانية من يونكس.
* الإحصائيات اليومية، ولمحات الرزن، وإحصائيات حجم التداول تستخدم حدود UTC اليوم بشكل افتراضي.
* الحقول الحساسة للدقة مثل الكمية والسعر والكمية والمعدل تنقل كسلاسل نصية.
* يتم إرجاع معرفات الأعداد الصحيحة الكبيرة مثل `orderId`و `conditionId`و `strategyId` كسلاسل في JSON.

<h2 id="response-format">صيغة الاستجابة</h2>

استجابة ناجحة:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

استجابة خطأ:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

ملاحظات:

* عادة ما تعيد أخطاء الأعمال هيكل JSON الموحد. يجب على المدمجين التحقق من `code` أولا.
* قد تعيد حالات فشل المصادقة HTTP `401`؛ قد تعيد حدود المعدل HTTP `429`.
* يمكنك إرسال `X-Request-ID` في رأس الطلب. سيعيدها الخادم كما `requestId` في الرد.
