<h2 id="documentation-areas">مجالات التوثيق</h2>

| المنطقة | ما الذي يغطيه |
| --- | --- |
| إعداد التكامل | عناوين الخدمة، اتفاقيات الطلبات، شكل الاستجابة، وأنماط الوصول. |
| المصادقة والأمان | JWT، API Key الأذونات، توقيع HMAC ، حماية إعادة التشغيل، ومزامنة الوقت. |
| REST API | نقاط النهاية العامة، بيانات المستخدم/الحساب، الطلبات، المراكز، وبيانات السوق. |
| WebSocket | دورة حياة الاتصال، تدفقات السوق العامة، وتدفقات المستخدمين الخاصين. |
| المراجع وحل المشكلات | الرموز العشوائية، رموز الخطأ، وتوصيات عملية للتكامل. |

<h2 id="production-checklist">قائمة تحقق الإنتاج</h2>

- تخزين API الأسرار فقط في الخلفية.
- مزامنة وقت الخادم قبل الطلبات الموقعة.
- عامل جميع حقول الدقة العددية كسلاسل نصية ما لم تذكر الصفحة صراحة خلاف ذلك.
- استخدام الهواء، معرفات الطلبات، والسجلات المنظمة حول تدفقات الأوامر.
- الاشتراك في WebSocket تدفقات للحالة التي يجب أن تبقى محدثة في أنظمة التشغيل.
- مراجعة رموز الأخطاء وسلوك إعادة المحاولة قبل الإطلاق.
