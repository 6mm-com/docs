يستهدف هذا الدليل **Agent Java SDK `v0.3.0`**، Java 8+، والعقد العام الموسوم. يتم تشغيل الأمثلة في الواجهة الخلفية للشريك بعد تهيئة `client` في [بداية سريعة](/ar/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- ستة استعلامات دائمة: الطلبات الحالية، وسجل الطلبات، والتعبئة، والمواقف الحالية، وسجل المواقف، ودفتر الأستاذ للحساب.
- أرصدة التمويل والتحويلات واستعلامات الاسترداد وتحويلات التمويل/العقود.
- الإنتاج الصريح/الاختيار المحاكي لطلبات الأموال المدعومة.
- إعادة توجيه تداول الثواني وأدلة التضمين، ومرجع حقل الاستجابة، وتعليمات الترحيل.

Java SDK و Trading Widget SDK لديهما إصدارات مستقلة. القطعة `v1` URL ليست إصدار Java SDK `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## التكاملات القائمة

الحفاظ على تعيينات المستخدم والأوامر الأصلية وبيانات الاعتماد. تحتفظ حقول البيئة المحذوفة بسلوك الإنتاج الحالي. يتطلب التمويل والتمويل المحاكاة الصريحة وستة استعلامات دائمة النماذج والأساليب الجديدة المقابلة. مراجعة [دليل الترقية](/ar/sdk/agent-sdk/java/upgrade) قبل تغيير التكامل الحالي.
