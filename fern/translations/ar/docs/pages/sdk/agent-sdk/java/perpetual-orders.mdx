يستهدف هذا الدليل **Agent Java SDK `v0.3.0`**، Java 8+، والعقد العام الموسوم. يتم تشغيل الأمثلة في الواجهة الخلفية للشريك بعد تهيئة `client` في [بداية سريعة](/ar/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## مثال المتطلبات الأساسية

تشترك مقتطفات Java في هذه الواردات. قم بتهيئة `client` باستخدام البدء السريع واحصل على `platformUserId` من الرابط المحفوظ. يجب استبدال معرفات المستخدم/الطلب بالقيم الثابتة الخاصة بك.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

<span data-sixmm-canonical-anchor="listcurrentperpetualorders" aria-hidden="true"></span>

## `listCurrentPerpetualOrders`

نموذج الطلب: `CurrentPerpetualOrdersRequest`.

```java
import com.sixmm.agent.model.CurrentPerpetualOrdersRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

CurrentPerpetualOrdersRequest request = new CurrentPerpetualOrdersRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.orderCategory = "NORMAL";
request.symbol = "BTCUSDT";
PerpetualResponse response = client.listCurrentPerpetualOrders(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

<span id="request-fields" data-sixmm-canonical-anchor="request-fields" aria-hidden="true"></span>

### حقول الطلب

| مجال | Java النوع | مطلوب | معنى |
| --- | --- | --- | --- |
| `orderCategory` | `String` | نعم | NORMAL أو CONDITIONAL؛ تتطلب الاستعلامات الشرطية مستخدمين صريحين. |
| `platformUserIds` | `java.util.List<String>` | شرطي | 1–100 معرف عام فريد؛ مطلوب للتعبئة والأوامر المشروطة. حذف الاستعلامات المدعومة لنطاق اللاعب المباشر؛ [] غير صالح. |
| `symbol` | `String` | لا | مرشح اختياري لزوج التداول. |
| `limit` | `Integer` | لا | الافتراضي 500؛ 1-1000. |
| `cursor` | `String` | لا | استخدم nextCursor الذي تم إرجاعه مع المرشحات التي لم تتغير؛ توقف عندما يكون hasMore خطأ. |

المثال يقرأ صفحة واحدة. بالنسبة للحقول المطلوبة، ونطاق اللاعب، ودلالات التصفية، والحد، والمؤشر، وعمليات إعادة المحاولة المحدودة، اتبع ذلك [نظرة عامة على الاستعلام](/ar/sdk/agent-sdk/java/perpetual-queries). احتفظ بجميع المرشحات دون تغيير أثناء الترحيل؛ لا تفسر الخطأ كنتيجة فارغة.

## `listPerpetualOrderHistory`

نموذج الطلب: `PerpetualOrderHistoryRequest`.

```java
import com.sixmm.agent.model.PerpetualOrderHistoryRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

PerpetualOrderHistoryRequest request = new PerpetualOrderHistoryRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.orderCategory = "NORMAL";
request.symbol = "BTCUSDT";
request.endTime = System.currentTimeMillis();
request.startTime = request.endTime - 3_600_000L;
PerpetualResponse response = client.listPerpetualOrderHistory(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

### حقول الطلب

| مجال | Java النوع | مطلوب | معنى |
| --- | --- | --- | --- |
| `orderCategory` | `String` | نعم | NORMAL أو CONDITIONAL؛ تتطلب الاستعلامات الشرطية مستخدمين صريحين. |
| `platformUserIds` | `java.util.List<String>` | شرطي | 1–100 معرف عام فريد؛ مطلوب للتعبئة والأوامر المشروطة. حذف الاستعلامات المدعومة لنطاق اللاعب المباشر؛ [] غير صالح. |
| `symbol` | `String` | لا | مرشح اختياري لزوج التداول. |
| `orderId` | `String` | لا | معرف الطلب العادي؛ ليس رقم طلب نقل الشريك. |
| `conditionId` | `String` | لا | معرف الأمر المشروط؛ لا تخلط مع orderId. |
| `clientOrderId` | `String` | لا | مرجع أمر عميل التداول، وليس agentOrderNo. |
| `side` | `String` | لا | BUY / SELL مرشح. |
| `status` | `String` | لا | الحالة الخاصة بالموارد؛ راجع مرجع الحالة. |
| `startTime` | `Long` | لا | ميلي ثانية يونكس شاملة؛ استخدم نافذة سجل UTC ثابتة. |
| `endTime` | `Long` | لا | حصري يونكس ميلي ثانية. |
| `limit` | `Integer` | لا | الافتراضي 500؛ 1-1000. |
| `cursor` | `String` | لا | استخدم nextCursor الذي تم إرجاعه مع المرشحات التي لم تتغير؛ توقف عندما يكون hasMore خطأ. |

## الأوامر العادية: الحالية والتاريخ

الحالي: `orders/current` + `orderCategory=NORMAL`؛ التاريخ: `orders/history` + `orderCategory=NORMAL`.

| `data` الحقل | يكتب | معنى ونطاق التطبيق |
| --- | --- | --- |
| `symbol` | string | زوج التداول، مثل BTCUSDT |
| `orderId` | string | معرف النظام العادي للمنصة |
| `orderCategory` | string | ثابت NORMAL |
| `clientOrderId` | string | رقم طلب العميل المقدم من مصدر أمر المعاملة؛ ليس نفس حقل تحويل أموال التاجر agentOrderNo |
| `orderType` | string | نوع المفوض، مثل LIMIT، MARKET؛ يجب أن تسود قيمة التعداد الفعلي |
| `side` | string | اتجاه البيع والشراء BUY / SELL |
| `status` | string | حالة الطلب العادية، راجع نظرة عامة على الاستعلام |
| `timeInForce` | string | فترة الصلاحية/استراتيجية تنفيذ الصفقة، مثل GTC، IOC، FOK؛ يتم تفسيرها وفقا للقيم الفعلية |
| `price` | string | السعر المعتمد ويمكن حذفه عندما لا يتم تقديم أي سعر، ولن يتم استكمال سعر معاملة السوق من قبل الشخص نفسه. |
| `quantity` | string | كمية الطلب الأصلية |
| `filledQuantity` | string | كمية المعاملة |
| `remainingQuantity` | string | الكمية غير المتداولة؛ الاستعلام الحالي يأخذ الكمية - filledQuantity، والاستعلام التاريخي يأخذ قيمة السجل التاريخية |
| `avgFilledPrice` | string | متوسط ​​سعر الصفقة للجزء المكتمل؛ قد لا تكون هناك قيمة عندما لا تكتمل |
| `reduceOnly` | boolean | سواء لتقليل المواقف فقط |
| `closeOnly` | boolean | ما إذا كان يتم استخدامه فقط لإغلاق المراكز |
| `makerOnly` | boolean | ما إذا كان سيتم التنفيذ كصانع فقط |
| `leverage` | integer | الرافعة المالية المتعددة؛ **النظام العادي التاريخي** له مصدر، والنظام العادي الحالي لا ينشئ هذه القيمة |
| `marginMode` | string | وضع الهامش؛ **الترتيب العادي التاريخي** يُرجع حاليًا سلسلة تعداد رقمية، مثل "1" و"2"؛ لم يتم توفير النظام العادي الحالي |
| `createdAt` | integer | وقت إنشاء الطلب، بالمللي ثانية؛ استخدم هذا الحقل لتصفية وقت الطلب التاريخي |
| `updatedAt` | integer | تفويض وقت تحديث السجل، بالمللي ثانية |

يتضمن سجل الطلبات الأوامر العادية التي تم إنهاؤها. لا يمكن اعتبار كل سجل مكتملًا بالكامل استنادًا إلى اسم الواجهة وحده. صفحة الطلب الحالية هي استعلام عن الحالة الحالية، وليست تدفق حدث طلب.

## الأوامر المشروطة: الحالية والتاريخ

الحالي: `orders/current` + `orderCategory=CONDITIONAL`؛ التاريخ: `orders/history` + `orderCategory=CONDITIONAL`. كلاهما يتطلب platformUserIds صريحًا.

| `data` الحقل | يكتب | معنى |
| --- | --- | --- |
| `symbol` | string | زوج التداول |
| `conditionId` | string | معرف الأوامر المشروطة، مستقل عن العادي orderId |
| `orderCategory` | string | ثابت CONDITIONAL |
| `generatedOrderId` | string | معرف الطلب العادي الذي تم إنشاؤه بعد التشغيل؛ قد يتم حذفها إذا لم يتم إنشاؤها |
| `clientOrderId` | string | رقم أمر العميل للأوامر المشروطة، والإخراج عند وجوده |
| `side` | string | BUY / SELL |
| `orderType` | string | نوع الأمر اللاحق للتفعيل، ويتم تفسيره وفقًا للقيمة الفعلية |
| `triggerType` | string | نوع قاعدة التشغيل، موضح من خلال تعداد المصدر الفعلي |
| `workingType` | string | نوع الوظيفة/مصدر السعر الذي يؤدي إلى السعر، ويتم تفسيره على أنه التعداد الفعلي |
| `timeInForce` | string | فترة الصلاحية/استراتيجية تنفيذ الأمر بعد تفعيله |
| `price` | string | سعر الأمر بعد التحفيز، والإخراج عندما يكون للمصدر قيمة |
| `quantity` | string | كمية الطلب المشروطة |
| `triggerPrice` | string | سعر الزناد |
| `reduceOnly` | boolean | سواء لتقليل المواقف فقط |
| `closePosition` | boolean | ما إذا كان سيتم استخدام دلالات إغلاق الموضع الكامل، لا يمكن الخلط بينه وبين closeOnly باعتباره نفس الحقل |
| `leverage` | integer | الرافعة المالية المتعددة، والإخراج عندما يكون غير الصفر |
| `marginMode` | string | تُرجع هذه الفئة CROSS / ISOLATED، وهي سلسلة رقمية تختلف عن الأوامر/المواضع التاريخية العادية |
| `status` | string | حالة المشغل المفردة المشروطة، راجع نظرة عامة على الاستعلام |
| `triggerStatus` | string | يستخدم التنفيذ الحالي نفس قيمة الحالة الشرطية مثل الحالة |
| `createdAt` | integer | وقت إنشاء الأمر الشرطي، بالمللي ثانية؛ تتم تصفية الظروف التاريخية بحلول هذا الوقت |
| `updatedAt` | integer | تحديث الوقت، والإخراج عندما تكون هناك قيمة، ميلي ثانية |
| `deletedAt` | integer | حذف وقت العلامة، والإخراج عندما تكون هناك قيمة، بالمللي ثانية؛ فهو ليس حقل وقت موحد للمعاملة/الإلغاء |

لا توفر الأوامر المشروطة filledQuantity، remainingQuantity، avgFilledPrice للأوامر العادية. إذا كنت بحاجة إلى حالة المعاملة للأوامر العادية بعد التنشيط، فاستفسر عن الأوامر/المعاملات العادية من خلال generatedOrderId، ولا تستنتج حجم المعاملة من حالة الأمر المشروط.

## مثال على مظروف الاستجابة

هذه صفحة فارغة توضيحية، وليست عينة من صفقة مكتملة. تصف جداول الحقول الخاصة بالموارد أعلاه `items[].data` المأهولة.

```json
{"code":0,"message":"success","data":{"items":[],"nextCursor":"","hasMore":false}}
```
