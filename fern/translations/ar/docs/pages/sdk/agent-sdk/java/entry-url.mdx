يستهدف هذا الدليل **Agent Java SDK `v0.3.0`**، Java 8+، والعقد العام الموسوم. يتم تشغيل الأمثلة في الواجهة الخلفية للشريك بعد تهيئة `client` في [بداية سريعة](/ar/sdk/agent-sdk/java/quick-start).

## مثال المتطلبات الأساسية

تشترك مقتطفات Java في هذه الواردات. قم بتهيئة `client` باستخدام البدء السريع واحصل على `platformUserId` من الرابط المحفوظ. يجب استبدال معرفات المستخدم/الطلب بالقيم الثابتة الخاصة بك.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## الدخول المباشر URL

الإدخال المباشر URL مخصص لوضع إعادة التوجيه. ينقر مستخدم شريك على زر في
موقع الشريك، ويفتح الواجهة الأمامية 6MM، ويتم تسجيل الدخول تلقائيًا.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

القواعد الميدانية:

| مجال | وصف |
| --- | --- |
| `redirectPath` | 6MM المسار النسبي للواجهة الأمامية. يجب أن يبدأ بـ `/`، على سبيل المثال `/trade/BTCUSDT` |
| `returnUrl` | يُستخدم الشريك المطلق URL عندما يخرج المستخدم من الواجهة الأمامية 6MM. يُسمح فقط بـ `http` و`https` |
| `expireAt` | وقت انتهاء صلاحية تذكرة الدخول كطابع زمني لنظام Unix بالثواني |

متطلبات الأمان:

- `webUrl` يحتوي على تذكرة لمرة واحدة. استخدمه على الفور ولا تقم بتخزينه على المدى الطويل.
- إذا انتهت صلاحية الإدخال URL أو تم استخدامه، فقم بإنشاء إدخال جديد من موقع الشريك.
- `returnUrl` يجب ألا يكون `javascript:`، مسارًا نسبيًا، أو URL يتضمن معلومات المستخدم.

## اختيار المنتج والوضع

استخدم مسار الواجهة الأمامية الحالي الذي يوفره 6MM. على سبيل المثال `/zh-CN/up-down?tradingMode=demo`، أو `/zh-CN/high-low?tradingMode=real`، أو `/zh-CN/grid-prediction?tradingMode=real`، أو `/zh-CN/futures/BTCUSDT?tradingMode=real`. التذكرة تصادق المستخدم؛ ولا يختار بيئة التمويل أو ينقل الأموال.

يرى [تداول الثواني](/ar/sdk/agent-sdk/java/seconds-trading) لإعادة التوجيه والأمثلة المضمنة.
