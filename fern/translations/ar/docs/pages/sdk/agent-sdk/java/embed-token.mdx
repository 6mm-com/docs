## مثال المتطلبات الأساسية

تشترك مقتطفات Java في هذه الواردات. قم بتهيئة `client` باستخدام البدء السريع واحصل على `platformUserId` من الرابط المحفوظ. يجب استبدال معرفات المستخدم/الطلب بالقيم الثابتة الخاصة بك.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget تضمين الرمز المميز

رمز التضمين مخصص لوضع Trading Widget SDK `partner-token + tokenProvider`. ال
يستدعي المتصفح الواجهة الخلفية للشريك، وتستدعي الواجهة الخلفية للشريك هذا Java SDK
لإنشاء `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

متطلبات التكامل:

- يجب أن يستخدم `channelId` القيمة التي تم تمريرها بواسطة Trading Widget SDK.
- `symbol` اختياري، ولكن يوصى بتمرير الرمز الأولي الحالي.
- `embedToken` قصير العمر ولمرة واحدة. لا تضعه في سلاسل الاستعلام URL.
- يجب ألا تحتوي الواجهة الأمامية للشريك مطلقًا على `apiSecret`.
- `expireAt` هو طابع زمني لنظام Unix بالثواني، وليس TTL.

مثال على نقطة نهاية الواجهة الخلفية للشريك:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## عقد نقطة النهاية للشريك

قم بتوثيق جلسة الشريك واشتقاق `agentUserId` من جانب الخادم. قبول القطعة الحالية `channelId`؛ إرجاع المستوى الأعلى `embedToken`، `expireAt` (ثواني Unix)، ونفس `channelId`. لا توفر استجابات الوكيل `channelId`: الواجهة الخلفية لديك تكررها. جلب رمز مميز جديد عند التهيئة والتجديد؛ لا تعيد استخدامه أبدًا. لا يؤدي إنشاء الرمز المميز إلى تحويل الأموال أو اختيار بيئة المحفظة.

يرى [تداول الثواني](/ar/sdk/agent-sdk/java/seconds-trading) لتدفق الواجهة الأمامية/الخلفية الكامل.
