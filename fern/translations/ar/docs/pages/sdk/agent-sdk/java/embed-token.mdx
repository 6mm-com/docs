## SDK الاتصال

أنشئ رموز تضمين من الخلفية بعد التحقق من جلسة المستخدم الشريك. يجب أن يستدعي المتصفح نقطة النهاية الخاصة بك، ويجب أن تتصل 6MM عبر Agent SDK.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **شهادة لمرة واحدة**
>
> embedToken قصير العمر ويستخدم مرة واحدة. لا تضعه في سلسلة استعلام URL .

<span id="backend-endpoint-example" data-sixmm-canonical-anchor="backend-endpoint-example" aria-hidden="true"></span>

## مثال على نقطة نهاية خلفية

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

أعيد فقط الحقول التي يحتاجها مزود الرمز Trading Widget . لا تعيد apiSecretأو حقول التوقيع الخام أو تكوين الخدمة الداخلي.

## التعامل مع الأعطال

| الحالة | التعامل الموصى به |
| --- | --- |
| جلسة المستخدم مفقودة أو منتهية الصلاحية | أعد 401 من نقطة نهاية الشريك واطلب من المستخدم تسجيل الدخول مرة أخرى. |
| مستخدم الوكيل غير مقيد | قم بربط المستخدم أولا، ثم أعد محاولة إنشاء الرمز. |
| 6MM يعيد خطأ مؤقت | أعيد خطأ قابل للمحاولة إلى الواجهة الأمامية وسجل requestId للدعم. |
| channelId لا يتطابق مع نسخة الويدجت | ارفض الطلب وأعد إنشاء جلسة الويدجت. |
