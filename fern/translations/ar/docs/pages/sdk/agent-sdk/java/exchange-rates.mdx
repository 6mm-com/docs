يستهدف هذا الدليل **Agent Java SDK `v0.3.0`**، Java 8+، والعقد العام الموسوم. يتم تشغيل الأمثلة في الواجهة الخلفية للشريك بعد تهيئة `client` في [بداية سريعة](/ar/sdk/agent-sdk/java/quick-start).

## مثال المتطلبات الأساسية

تشترك مقتطفات Java في هذه الواردات. قم بتهيئة `client` باستخدام البدء السريع واحصل على `platformUserId` من الرابط المحفوظ. يجب استبدال معرفات المستخدم/الطلب بالقيم الثابتة الخاصة بك.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## أسعار العملات الأجنبية المرجعية

تستخدم كلتا طريقتي FX التدفق العادي للوكيل الموقع API. ابدأ باكتشاف
العملات المصدر المدعومة حاليًا:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

الاستعلام عن جميع الأسعار المرجعية المدعومة من العملات الورقية إلى USDT:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

الاستعلام عن العملات المحددة:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

يقوم مصنع الطلب بقص رموز العملات والأحرف الكبيرة وتسلسلها على أنها
القيمة المفصولة بفواصل `sourceCurrencies` المطلوبة بواسطة API. إغفال
طلب أو جميع قيم العملة الفعالة تستعلم عن كل عملة مدعومة.

| مجال الرد | يكتب | وصف |
| --- | --- | --- |
| `snapshotVersion` | string | نسخة لقطة مستقرة للتدقيق والمصالحة |
| `provider` | string | مزود المنبع، حاليا `ECB` |
| `sourceDate` | string | تاريخ مراقبة المنبع بتنسيق `yyyy-MM-dd`. |
| `fetchedAt` / `expiresAt` | int64 | الطوابع الزمنية لنظام التشغيل Unix بالمللي ثانية |
| `pricingPolicy` | string | حاليا `FIXED_PEG` |
| `usdtUsdRate` | string | USD المبلغ لكل 1 USDT، ثابت حاليًا عند `1` |
| `rateType` | string | حاليا `INDICATIVE_DAILY` |
| `usage` | string | حاليا `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT المبلغ المقابل لوحدة واحدة من المصدر القانوني |

هذه القيم هي مراجع لحساب المحفظة متعددة العملات الشريكة
تم إرسال المبلغ USDT إلى 6MM. فهي ليست أسعار قابلة للتنفيذ، أو عروض أسعار مقفلة، أو
أسعار السوق في الوقت الحقيقي USDT. استخدم `BigDecimal` والسلاسل للمبلغ
الحسابات؛ لا تستخدم `double` أو `float`.
