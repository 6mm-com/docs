يستهدف هذا الدليل **Agent Java SDK `v0.3.0`**، Java 8+، والعقد العام الموسوم. يتم تشغيل الأمثلة في الواجهة الخلفية للشريك بعد تهيئة `client` في [بداية سريعة](/ar/sdk/agent-sdk/java/quick-start).

## مثال المتطلبات الأساسية

تشترك مقتطفات Java في هذه الواردات. قم بتهيئة `client` باستخدام البدء السريع واحصل على `platformUserId` من الرابط المحفوظ. يجب استبدال معرفات المستخدم/الطلب بالقيم الثابتة الخاصة بك.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

<span data-sixmm-canonical-anchor="listcurrentperpetualpositions" aria-hidden="true"></span>

## `listCurrentPerpetualPositions`

نموذج الطلب: `CurrentPerpetualPositionsRequest`.

```java
import com.sixmm.agent.model.CurrentPerpetualPositionsRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

CurrentPerpetualPositionsRequest request = new CurrentPerpetualPositionsRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.symbol = "BTCUSDT";
PerpetualResponse response = client.listCurrentPerpetualPositions(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

<span id="request-fields" data-sixmm-canonical-anchor="request-fields" aria-hidden="true"></span>

### حقول الطلب

| مجال | Java النوع | مطلوب | معنى |
| --- | --- | --- | --- |
| `platformUserIds` | `java.util.List<String>` | شرطي | 1–100 معرف عام فريد؛ مطلوب للتعبئة والأوامر المشروطة. حذف الاستعلامات المدعومة لنطاق اللاعب المباشر؛ [] غير صالح. |
| `symbol` | `String` | لا | مرشح اختياري لزوج التداول. |
| `limit` | `Integer` | لا | الافتراضي 500؛ 1-1000. |
| `cursor` | `String` | لا | استخدم nextCursor الذي تم إرجاعه مع المرشحات التي لم تتغير؛ توقف عندما يكون hasMore خطأ. |

المثال يقرأ صفحة واحدة. بالنسبة للحقول المطلوبة، ونطاق اللاعب، ودلالات التصفية، والحد، والمؤشر، وعمليات إعادة المحاولة المحدودة، اتبع ذلك [نظرة عامة على الاستعلام](/ar/sdk/agent-sdk/java/perpetual-queries). احتفظ بجميع المرشحات دون تغيير أثناء الترحيل؛ لا تفسر الخطأ كنتيجة فارغة.

## `listPerpetualPositionHistory`

نموذج الطلب: `PerpetualPositionHistoryRequest`.

```java
import com.sixmm.agent.model.PerpetualPositionHistoryRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

PerpetualPositionHistoryRequest request = new PerpetualPositionHistoryRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.symbol = "BTCUSDT";
request.endTime = System.currentTimeMillis();
request.startTime = request.endTime - 3_600_000L;
PerpetualResponse response = client.listPerpetualPositionHistory(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

## المناصب: الحالية والتاريخية

| `data` الحقل | يكتب | الوضع الحالي | مواقف تاريخية | معنى |
| --- | --- | --- | --- | --- |
| `positionId` | string | إمداد | إمداد | معرف المنصب، المطابق لـ entityId |
| `symbol` | string | إمداد | إمداد | زوج التداول |
| `positionSide` | string | إمداد | إمداد | LONG / SHORT / BOTH واتجاهات الموضع الأخرى |
| `status` | string | إمداد | إمداد | سلسلة مع الحالة الرقمية للموضع، راجع نظرة عامة على الاستعلام |
| `leverage` | integer | إمداد | إمداد | الاستفادة المتعددة |
| `marginMode` | string | إمداد | إمداد | سلسلة التعداد الرقمية "1" للموضع الكامل، "2" للموضع المعزول |
| `quantity` | string | إمداد | غير متوفر | كمية الموقف الحالي |
| `entryPrice` | string | إمداد | إمداد | متوسط ​​سعر الافتتاح للصفقات المخزنة |
| `margin` | string | إمداد | غير متوفر | مبلغ هامش المركز الحالي، وليس رصيد محفظة العقد بالكامل للمستخدم |
| `maxQuantity` | string | غير متوفر | إمداد | الحد الأقصى لعدد المواقف المسجلة في هذا الموقف التاريخي |
| `closeQuantity` | string | غير متوفر | إمداد | العدد التراكمي للصفقات المغلقة خلال دورة حياة الصفقة التاريخية |
| `closePrice` | string | غير متوفر | إمداد | متوسط ​​سعر الإغلاق المخزن |
| `pnl` | string | غير متوفر | إمداد | الربح والخسارة للوضع التاريخي؛ لا تدمجها مع المعاملة realizedPnl للتكرار والتراكم ببساطة |
| `roe` | string | غير متوفر | إمداد | القيمة التناسبية لعائد المركز التاريخي، غير مضروبة في 100؛ على سبيل المثال، `"0.043"` يمثل `4.3%`، `"-0.05"` يمثل `-5%` |
| `fundingFeeAccum` | string | إمداد | إمداد | رسوم التمويل المتراكمة، مع الاحتفاظ برمز المصدر ودقته |
| `openedAt` | integer | إمداد | إمداد | وقت افتتاح المركز، بالمللي ثانية |
| `updatedAt` | integer | إمداد | غير متوفر | وقت تحديث الموقف الحالي، بالمللي ثانية |
| `closedAt` | integer | غير متوفر | إمداد | وقت الإغلاق، ميلي ثانية؛ استخدم هذا الحقل لتصفية وقت الموقع التاريخي |

عيار حساب التاريخ `roe` هو `pnl / (entryPrice × maxQuantity / leverage)`، وتقوم الواجهة مباشرة بإرجاع قيمة النسبة المحفوظة. عند عرض النسبة المئوية، استخدم العملية العشرية واضرب في 100، ثم أضف `%`؛ يستخدم المقام الهامش الاسمي لسجل المركز التاريخي، وليس رصيد محفظة الحساب. عندما يكون سعر الافتتاح أو الحد الأقصى لكمية المركز 0، تكون الرافعة المالية غير صالحة، وما إلى ذلك ولا يمكن حسابها، ويتم حفظ المصدر كـ 0. لذلك، لا يمكن استنتاج أن الربح أو الخسارة هي 0 بناءً على `roe=0`.

لا يحتوي المركز الحالي على سعر محدد في الوقت الفعلي، أو أرباح وخسائر عائمة في الوقت الفعلي، أو ROE في الوقت الفعلي، أو سعر تصفية في الوقت الفعلي. إنه يعكس حالة الموضع المخزن ولا يمكنه استخدام وقت التحديث وحقول الهامش للمطالبة بنتائج التحكم في المخاطر الحالية في الوقت الفعلي.

## مثال على مظروف الاستجابة

هذه صفحة فارغة توضيحية، وليست عينة من صفقة مكتملة. تصف جداول الحقول الخاصة بالموارد أعلاه `items[].data` المأهولة.

```json
{"code":0,"message":"success","data":{"items":[],"nextCursor":"","hasMore":false}}
```
