## ما يغطيه SDK

| فئة | سيناريو | SDK API | وصف |
| --- | --- | --- | --- |
| ملزمة المستخدم | ربط المستخدم | `bind` | قم بإنشاء أو جلب الارتباط بين مستخدم شريك ومستخدم النظام الأساسي 6MM |
| استعلامات الأصول | الاستعلام عن حساب الشريك | `queryAccount` | الاستعلام عن هامش الشريك أو حساب التمويل |
| استعلامات الأصول | الاستعلام عن أصول المستخدم | `queryUserAssets` | الاستعلام عن أصول العقد؛ استخدم `withFunding()` لتضمين أرصدة التمويل |
| التحويلات | تحويل مبلغ ثابت | `transfer` | تحويل الأموال إلى أو من 6MM |
| التحويلات | نقل كل شيء | `transferAllOut` | قم بنقل كافة أرصدة المستخدم القابلة للسحب مرة أخرى إلى النظام الأساسي الشريك |
| التحويلات | ترتيب عكسي | `reverse` | قم بعكس النقل الناجح عندما تدعم الواجهة الخلفية تدفق التعويض |
| التحويلات | ترتيب الاستعلام | `queryOrder` | الاستعلام عن أمر تحويل واحد عن طريق رقم أمر الشريك |
| التحويلات | قائمة الطلبات | `listOrders` | صفحة من خلال أوامر النقل للمصالحة |
| التحويلات | Webhook التحقق | `WebhookVerifier.verify` | التحقق من نقل عمليات رد الاتصال للحالة النهائية من 6MM |
| محفظة التمويل | تحويل التمويل | `walletTransfer` | الشريك ↔ التمويل أو التمويل ↔ العقد؛ تأكيد الحالة التي تم إرجاعها |
| محفظة التمويل | حالة تحويل التمويل | `queryWalletTransfer` | استرداد عملية التمويل باستخدام رقم طلب الشريك الأصلي الخاص بها |
| دخول التداول | الدخول المباشر URL | `createEntryUrl` | قم بإنشاء SSO URL مرة واحدة لوضع إعادة التوجيه |
| دخول التداول | تضمين الرمز المميز | `createEmbedToken` | قم بإنشاء رمز مميز قصير العمر لوضع Trading Widget `tokenProvider` |
| بيانات دائمة | الأوامر الدائمة الحالية | `listCurrentPerpetualOrders` | الاستعلام عن الطلبات الحالية NORMAL أو CONDITIONAL |
| بيانات دائمة | تاريخ النظام الدائم | `listPerpetualOrderHistory` | الاستعلام عن أوامر NORMAL أو CONDITIONAL |
| بيانات دائمة | الصفقات الدائمة | `listPerpetualTrades` | الاستعلام عن تعبئة قائمة اللاعبين العامة الصريحة |
| بيانات دائمة | المواقف الدائمة الحالية | `listCurrentPerpetualPositions` | الاستعلام عن المناصب الحالية |
| بيانات دائمة | تاريخ الموقف الدائم | `listPerpetualPositionHistory` | الاستعلام عن المراكز المغلقة |
| بيانات دائمة | دفتر الحسابات الدائم | `listPerpetualLedger` | الاستعلام عن سجلات تغيير رصيد العقد الفردي |
| الأسعار المرجعية لشركة فيات | قائمة العملات الورقية المدعومة | `listSupportedFiatCurrencies` | قائمة العملات الورقية القابلة للتحويل حاليًا إلى USDT |
| الأسعار المرجعية لشركة فيات | الاستعلام عن الأسعار المرجعية للعملات الأجنبية | `queryExchangeRates` | الاستعلام اليومي عن النسب المرجعية للعملات الورقية إلى USDT لجميع العملات أو العملات المحددة |
| معلومات الخدمة | نسخة الخدمة | `version` | معلومات إصدار خدمة وكيل الاستعلام |

## إعدادات

احصل على القيم التالية من 6MM من قبل
دمج.

| غرض | مثال | وصف |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | الوكيل API قاعدة URL، بدون شرطة مائلة زائدة |
| `agentCode` | `AGENT001` | رمز الشريك |
| `apiSecret` | `your-api-secret` | API سر التوقيع. احتفظ بها على الواجهة الخلفية فقط |
| `defaultCurrency` | `USDT` | العملة الافتراضية، عادة `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | نقطة نهاية الشريك لعمليات الاسترجاعات 6MM |

توصيات الإنتاج:

- استخدم HTTPS لنقاط النهاية للعامل API وwebhook.
- قم بتخزين `apiSecret` في مدير سري أو مركز تكوين أو متغير بيئة.
- حافظ على مزامنة وقت الخادم، ويفضل أن يكون ذلك مع NTP.
- الحفاظ على جميع أرقام طلبات الشركاء والاحتفاظ بها فريدة عالميًا.
- لا ترسل أبدًا `apiSecret` إلى المتصفحات أو التطبيقات أو البرامج الصغيرة أو كود مصدر الواجهة الأمامية.

## حقول التوقيع التلقائي

بالنسبة لمكالمات الوكيل الموقعة API، يقوم SDK بإدخال ما يلي تلقائيًا:

| مجال | مصدر | وصف |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | رمز الشريك |
| `timestamp` | الطابع الزمني الحالي UTC لنظام التشغيل Unix | ثواني |
| `nonce` | تأمين مولد عشوائي | إعادة الحماية |
| `sign` | HMAC-SHA256 | طلب التوقيع |
| `currency` | `defaultCurrency` | يتم ملؤها عند حذف طلبات التحويل/الحساب العملة |

قواعد التوقيع:

1. استبعاد `sign`.
2. استبعاد القيم الفارغة.
3. فرز المفاتيح حسب ترتيب ASCII.
4. انضم باسم `k=v&k2=v2`.
5. احسب الست عشري HMAC-SHA256 باستخدام `apiSecret`.

لا يجب أن يقوم رمز العمل العادي بحساب التوقيعات أو تعيينها يدويًا
`agentCode`، `timestamp`، `nonce`، أو `sign`.
