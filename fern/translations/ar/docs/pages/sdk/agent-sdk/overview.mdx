6MM Agent SDK مخصص لخدمات الواجهة الخلفية للشركاء التي تحتاج إلى استدعاء الوكيل المميز APIs دون تنفيذ التوقيع ومعالجة الطلب من البداية. يجب ألا يتم تشغيله في المتصفح أو الهاتف المحمول أو رمز سطح المكتب العام لأن التكامل يستخدم سر الشريك API.

<span id="when-to-use-the-agent-sdk" data-sixmm-canonical-anchor="when-to-use-the-agent-sdk" aria-hidden="true"></span>

## متى يتم استخدام Agent SDK

استخدم Agent SDK عندما يحتاج نظامك الخلفي إلى ربط مستخدم تابع للشريك، أو نقل الأصول عبر سير عمل معتمد، أو الاستعلام عن سجلات التداول، أو إنشاء عنوان URL للدخول إلى التداول المضمّن، أو التحقق من إشعارات Webhook. استخدم [Trading Widget SDK](/ar/sdk/trading-widget/overview) بشكل منفصل عندما تحتاج الواجهة الأمامية للشريك إلى عرض واجهة التداول.

## التكوين المشترك

| مفتاح | مثال | وصف |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | خدمة 6MM الوكيل API URL بدون شرطة مائلة زائدة. |
| agentCode | AGENT001 | رمز الوكيل الشريك. |
| apiSecret | your-api-secret | API سر التوقيع مخزّن فقط على الواجهة الخلفية. |
| defaultCurrency | USDT | العملة الافتراضية للتحويل والحساب APIs. |
| webhookUrl | https://partner.example.com/6mm/webhook | نقطة نهاية الشريك لإشعارات 6MM webhook. |

<span id="typical-integration-flow" data-sixmm-canonical-anchor="typical-integration-flow" aria-hidden="true"></span>

## تدفق التكامل النموذجي

1. تقوم الواجهة الأمامية للشريك بمصادقة المستخدم من خلال نظام الحساب الخاص بالشريك.
2. تقوم الواجهة الخلفية للشريك بتعيين المستخدم إلى معرف ثابت من جانب الشريك.
3. تستدعي الواجهة الخلفية Agent SDK مع `agentCode` والسر المحمي API.
4. يقوم SDK بالتوقيع وإرسال طلب الوكيل API.
5. يخزّن النظام الخلفي معرّف العملية المُعاد، ثم يعالج إشعارات Webhook اللاحقة بصورة تضمن عدم تكرار المعالجة.
6. تتلقى الواجهة الأمامية فقط النتيجة قصيرة الأجل أو بيانات اعتماد الدخول التي تحتاجها.

## قائمة مراجعة الإنتاج

- قم بتحميل `apiSecret` من مدير سري للواجهة الخلفية، وليس من كود المصدر.
- احتفظ ببيانات اعتماد التطوير والتشغيل والإنتاج منفصلة.
- استخدم تعيينًا ثابتًا لمستخدم الشريك ومعرفات أوامر العمل الفريدة.
- احتفظ بالمعرف الأصلي عند التحقق من حالة طلب انتهاء المهلة.
- التحقق من توقيعات webhook وتخزين معرفات الأحداث المعالجة.
- قم بتنقيح الأسرار والتوقيعات من السجلات مع الاحتفاظ بمعرفات الطلب للحصول على الدعم.
