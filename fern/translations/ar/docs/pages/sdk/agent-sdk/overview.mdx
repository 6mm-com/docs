6MM Agent SDK مخصص لخدمات الخلفية الشريكة التي تحتاج إلى استدعاء API الوكيل المميز دون تنفيذ معالجة التوقيع والطلبات من الصفر. يجب ألا تعمل في كود المتصفح أو الهاتف المحمول أو سطح المكتب العام لأن التكامل يستخدم سريا API الشريك.

<h2 id="when-to-use-the-agent-sdk">متى تستخدم Agent SDK</h2>

استخدم Agent SDK عندما يحتاج نظامك الخلفي إلى ربط مستخدم تابع للشريك، أو نقل الأصول عبر سير عمل معتمد، أو الاستعلام عن سجلات التداول، أو إنشاء عنوان URL للدخول إلى التداول المضمّن، أو التحقق من إشعارات Webhook. استخدم [Trading Widget SDK](/ar/sdk/trading-widget/overview) بشكل منفصل عندما تحتاج الواجهة الأمامية للشريك إلى عرض واجهة التداول.

<h2 id="common-configuration">التكوين المشترك</h2>

| مفتاح | مثال | الوصف |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM API خدمة URL دون تتبع أو شرط. |
| agentCode | AGENT001 | رمز وكيل الشريك. |
| apiSecret | سر واجهة المستخدم الخاص بك | API التوقيع السري المخزن فقط في الخلفية. |
| defaultCurrency | USDT | العملة الافتراضية للتحويل وحساب API. |
| webhookUrl | https://partner.example.com/6mm/webhook | نقطة نهاية الشريك لإشعارات الويب هوك 6MM . |

<h2 id="typical-integration-flow">تدفق التكامل النموذجي</h2>

1. تقوم واجهة الشريك بالتحقق من صحة المستخدم من خلال نظام حسابات الشريك الخاص.
2. يقوم الطرف الخلفي للشريك بتعيين المستخدم إلى معرف مستقر من جانب الشريك.
3. الواجهة الخلفية تتصل ب Agent SDK مع `agentCode` و API السر المحمي.
4. يوقع SDK ويرسل العميل API الطلب.
5. يخزّن النظام الخلفي معرّف العملية المُعاد، ثم يعالج إشعارات Webhook اللاحقة بصورة تضمن عدم تكرار المعالجة.
6. تحصل الواجهة الأمامية فقط على النتيجة القصيرة أو بطاقة الدخول التي تحتاجها.

<h2 id="production-checklist">قائمة تحقق الإنتاج</h2>

- تحميل `apiSecret` من مدير سري خلفي، وليس من الشيفرة المصدرية.
- إبقاء الاعتماد على التطوير والإخراج والإنتاج.
- استخدام خريطة مستخدم الشريك المستقرة ومعرفات أوامر الأعمال الفريدة.
- الحفاظ على المعرف الأصلي عند التحقق من حالة طلب انتهاء الوقت.
- التحقق من توقيعات webhook وتخزين معرفات الأحداث المعالجة.
- حذف الأسرار والتواقيع من السجلات مع الاحتفاظ بمعرفات الطلبات للدعم.
