<h2 id="install">التثبيت</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **وصول الحزمة**
>
يوفر > 6MM اسم حزمة المؤلف المعتمد، والمستودع، والإصدار أثناء انضمام الشركاء. لا ينبغي افتراض وجود الحزمة على Packagist العام.

<h2 id="before-you-start">قبل أن تبدأ</h2>

- أكد API العميل URL القاعدة مع 6MM.
- تحميل apiSecret من متغيرات البيئة أو إدارة سرية.
- احتفظ بالاستخدام SDK داخل خدمات الخلفية فقط.
- تحضير معالجة الإيديمبوتنت للتدفقات الانتقالية والبيبهوك.

<h2 id="initialize-client">تهيئة العميل</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **الواجهة الخلفية فقط**
>
> PHP SDK يوقع على API الوكيل ويجب ألا يتم كشفه من خلال الشيفرة المصدرية العامة أو بيئات التشغيل في الواجهة الأمامية.

<h2 id="example-transfer-funds-in">مثال: تحويل الأموال إلى</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

استخدم السلاسل العشرية للكميات واحتفظ agentOrderNo الأصلية عند إعادة المحاولة أو الاستعلام عن حالة النقل.
