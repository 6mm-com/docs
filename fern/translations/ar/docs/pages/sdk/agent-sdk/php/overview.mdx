## مدة العرض

| العنصر | القيمة |
| --- | --- |
| الحزمة | Sixmm/Agent-SDK |
| النسخة PHP الأدنى | PHP 7.4+ |
| النسخة PHP الموصى بها | PHP إصدار 8.1+ أو النسخ المدعومة حاليا |
| التمديدات المطلوبة | ext-json، ext-curl |

يتم توفير مصدر الحزمة PHP SDK والنسخة المعتمدة أثناء انضمام الشركاء. لا تفترض أن الحزمة متاحة من Packagist العام؛ قم بتكوين مستودع المؤلف المقدم لمؤسستك.

## السيناريوهات المدعومة

| السيناريو | طريقة SDK |
| --- | --- |
| مستخدم الربط | ربط |
| تحويل مبلغ ثابت | النقل |
| انقل كل شيء | transferAllOut |
| النقل العكسي | العكس |
| ترتيب الاستعلام | queryOrder |
| إنشاء URL | createEntryUrl |
| التحقق عبر Webhook | WebhookVerifier::verify |

## قواعد التكامل في الواجهة الخلفية

- تحميل `apiSecret` من مدير سري أو متغير بيئة محمية.
- إبقاء ربط المستخدم، والنقل، والتوقيع، ومنطق webhook خارج كود المتصفح.
- استخدام سلاسل عشرية لمبالغ الأصول لتجنب تقريب النقطة العائمة.
- إعادة استخدام `agentOrderNo` الأصلي عند الاستعلام عن نتيجة نقل غير مؤكدة.
- التحقق من توقيعات webhook مقابل جسم الطلب الخام قبل فك ترميزها أو تغييرها.
