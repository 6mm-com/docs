| مجال | يكتب | تقصير | ملحوظات |
| --- | --- | --- | --- |
| baseUrl | string | SDK أصل النص | نطاق iframe. تمرير صراحة في صفحات الشركاء. |
| رمز | string | BTCUSDT | تمت تطبيعه إلى أحرف كبيرة وشرائط - / _. |
| سمة | مظلم \| ضوء | مظلم | معلمة الموضوع الأولي |

| مصادقة | object | لا أحد | استخدم رمز الشريك لعمليات التكامل الجديدة SSO. |

## ضوابط العرض

يتحكم `display` في غلاف صفحة التداول المضمن والحاويات عالية المستوى. في عمليات تضمين الشريك، يتم إخفاء رأس جهاز الكمبيوتر ومؤشر السوق السفلي بشكل افتراضي.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| مجال | يكتب | تقصير | ملحوظات |
| --- | --- | --- | --- |
| showHeader | boolean | خطأ شنيع | ما إذا كان سيتم إظهار رأس تضمين الكمبيوتر داخل إطار iframe أم لا. |
| showTicker | boolean | خطأ شنيع | ما إذا كان سيتم إظهار مؤشر السوق السفلي في الغلاف المضمن أم لا. |
| مختفي | خيط[] | [] | إخفاء الحاويات عالية المستوى في صفحة التداول. |

القيم `display.hidden` المدعومة:

| قيمة | حاوية |
| --- | --- |
| جدول | حاوية الرسم البياني |
| orderBook | طلب حاوية الكتاب |
| orderForm | لوحة نموذج الطلب |
| المواقف | المراكز السفلية ولوحة الأوامر المفتوحة |
| حساب | حاوية أصول الحساب |

`display.hidden` يخفي الحاويات بأكملها فقط. ولا يخفي الأزرار أو الحقول أو الأدوات الفردية داخل الحاوية. يتم تجاهل القيم التي لا يتم تعيينها إلى إطار العرض الحالي.

## صفحات المنتج ووضع التداول

يتم إصدار Java Agent SDK والمتصفح Trading Widget SDK بشكل مستقل. بالنسبة للتداول بالثواني، استخدم إمكانيات الأداة الحالية وحدد كلاً من الصفحة ووضع التداول بشكل صريح.

| خيار | قيم | معنى |
| --- | --- | --- |
| `page` | `up-down`، `high-low`، `grid-prediction` | صفحة المنتج لتداول الثواني. |
| `tradingMode` | `real`، `demo` | الافتراضي هو `real`؛ تطابق بشكل واضح بيئة التمويل الخلفية. |

تحقق من `TradingWidget.capabilities.pages` و`TradingWidget.capabilities.tradingModes` و`TradingWidget.capabilities.partnerToken` قبل التهيئة. لا يؤدي إنشاء الرمز المميز إلى تحديد بيئة الأموال. لتغيير المستخدمين أو الوضع الحقيقي/التجريبي، قم بتدمير المثيل القديم وإنشاء مثيل جديد.

يرى [مثال تداول الثواني الكاملة](/ar/sdk/agent-sdk/java/seconds-trading) و [الإنتاج/التكوين المحاكى](/ar/sdk/agent-sdk/java/environments).

## أهداف وأحداث العرض الإضافية

يقبل وقت التشغيل الحالي أيضًا `symbolFavorites` و`symbolTicker` في `display.hidden`. تحقق دائمًا من `TradingWidget.capabilities.displayTargets`؛ يتحكم الهدف في حاوية عالية المستوى ولا يعد إعداد إذن على مستوى الحقل.

| حدث | معنى |
| --- | --- |
| `rendered` | يرسل iframe الإشعار المقدم الخاص به. |
| `theme_changed` | يُبلغ iframe عن موضوعه الفعلي. |
| `page_changed` | يُبلغ إطار iframe عن صفحة المنتج الفعلية الخاصة به. |

استخدم `onRendered` أو `widget.on('rendered', handler)` للتعامل مع العرض بشكل منفصل عن التهيئة. يتم نشر الصفحات المدعومة الحالية في `TradingWidget.capabilities.pages`؛ التحقق من صحة الصفحة المطلوبة بدلاً من تخمين المسار.
