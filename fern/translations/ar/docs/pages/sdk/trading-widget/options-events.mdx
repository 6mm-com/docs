| الميدان | النوع | الافتراضي | ملاحظات |
| --- | --- | --- | --- |
| baseUrl | string | SDK أصل النص | نطاق iframe. تمرير الملف بشكل صريح في صفحات الشركاء. |
| الرمز | string | BTCUSDT | تم تطبيعه إلى الأحرف الكبيرة والشرائط - / _. |
| الموضوع | دارك \| الضوء | مظلم | معامل الموضوع الأولي. |

## ضوابط العرض

`display` يتحكم في غلاف صفحة التداول المدمجة والحاويات عالية المستوى. في تضمين الشركاء، يكون رأس PC ومؤشر السوق السفلي مخفيا بشكل افتراضي.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| الميدان | النوع | الافتراضي | ملاحظات |
| --- | --- | --- | --- |
| showHeader | boolean | خطأ | هل يجب عرض رأس التضمين الخاص بالكمبيوتر داخل إطار iframe. |
| showTicker | boolean | خطأ | هل يجب عرض مؤشر السوق السفلي في غلاف التضمين. |
| مخفي | الوتر[] | [] | يخفي الحاويات عالية المستوى في صفحة التداول. |

قيم `display.hidden` المدعومة:

| القيمة | الحاوية |
| --- | --- |
| المخطط | حاوية الخريطة |
| orderBook | حاوية دفتر الطلبات |
| orderForm | لوحة نماذج الطلب |
| المناصب | لوحة المراكز السفلى والأوامر المفتوحة |
| الحساب | حاوية أصول الحساب |

`display.hidden` يخفي الحاويات الكاملة فقط. لا يخفي الأزرار أو الحقول أو الأدوات الفردية داخل الحاوية. القيم التي لا تتوافق مع نافذة العرض الحالية يتم تجاهلها.

## الفعاليات

| الحدث | الزناد |
| --- | --- |
| جاهز | تم الانتهاء من تهيئة iframe. |
| خطأ | SDK أو iframe أو خطأ في المصادقة. |
| state_changed | SDK حالة دورة الحياة تغيرت. |
| auth_state_changed | حالة مصادقة الشريك-رمز تغيرت. |
| symbol_changed | رمز iframe الفعلي تغير. |
| locale_changed | تم تغيير موقع iframe الفعلي. |
| order_created | أنشأ المستخدم طلبا داخل إطار iframe. |
| order_failed | فشل تقديم الطلب. |
| تم تدميرها | SDK الحادثة دمرت. |
