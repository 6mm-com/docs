| منطقة | مالك | ملحوظات |
| --- | --- | --- |
| إنشاء الحاوية | الواجهة الأمامية للشريك | قم بتوفير عنصر مرئي بعرض وارتفاع واضحين. |

## الإصدار

يظل مسار التكامل العام مستقرًا ضمن البرنامج النصي v1 URL. تشتمل مجموعة إمكانات الإصدار الأول الحالية على رمز الشريك، tokenProvider، entryUrlProvider، وعناصر التحكم في العرض، وأحداث دورة الحياة، وطرق المثيل، وأحداث الطلب.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

## متى تستخدم القطعة

اختر Trading Widget عندما يحتاج الشريك إلى واجهة تداول كاملة داخل منتج ويب موجود. استخدم وثائق REST API وWebSocket بدلاً من ذلك عند إنشاء واجهة تداول مخصصة بالكامل وصيانتها.

## مسار التنفيذ

1. اتبع [Trading Widget بداية سريعة](/ar/sdk/trading-widget/quick-start) لتحميل البرنامج النصي وإنشاء حاوية مرئية.
2. تكوين [مصادقة الرمز المميز للشريك](/ar/sdk/trading-widget/authentication) من خلال الواجهة الخلفية للشريك.
3. أضف المطلوب [الخيارات والأحداث](/ar/sdk/trading-widget/options-events).
4. يستخدم [طرق المثال](/ar/sdk/trading-widget/instance-methods) للتحكم في دورة الحياة ووقت التشغيل.

## تم التحقق من وقت التشغيل العام

يُبلغ البرنامج النصي العام `v1` عن الإصدار `1.8.0` اعتبارًا من 10-10-2026. هذه URL هي نقطة دخول ثابتة للإصدار الرئيسي، وليست بنية مثبتة. اقرأ `TradingWidget.version` و`TradingWidget.capabilities` في وقت التشغيل الذي تم تحميله قبل استخدام الميزات الاختيارية. Java Agent SDK `v0.3.0` هي حزمة خلفية منفصلة.

يدعم وقت التشغيل مثيلًا نشطًا واحدًا (`multiInstance=false`)؛ يؤدي إنشاء عنصر واجهة مستخدم آخر إلى تدمير المثيل السابق. لغاتها المدعومة هي `en`، `en-US`، و `zh-CN`، بشكل مستقل عن لغات التوثيق العشرين.
