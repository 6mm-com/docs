## تقسيم المسؤولية

| المنطقة | المالك | ملاحظات |
| --- | --- | --- |
| إنشاء الحاويات | واجهة الشريك الأمامية | وفر عنصرا مرئيا بعرض وارتفاع واضحين. |
| إنشاء iframe | Trading Widget SDK | يقوم SDK بإنشاء وإدارة الإطار الافتراضي. |
| واجهة التداول | 6MM iframe | خط K، دفتر الطلبات، نموذج الطلب، المراكز، الطلبات، وبيانات الحساب تعمل داخل إطار iframe. |
| ضوابط العرض | Trading Widget SDK + 6MM iframe | رأس التضمين في الحاسوب الشخصي ورمز الخصم السفلي مخفيان بشكل افتراضي. يمكن للشركاء استخدام `display` لإظهار مناطق القشرة أو إخفاء حاويات التداول عالية المستوى. |
| فحص تسجيل دخول الشريك | خلفية الشريك | تحقق من جلسة مستخدم الشريك قبل إصدار بيانات اعتماد المصادقة. |
| إصدار رمز التضمين | خلفية الشريك + وكيل API | موصى به لوضع الشريك الرمزي. |

## الإصدار

يبقى مسار التكامل العام مستقرا تحت URL السكريبت v1. تشمل مجموعة القدرات الحالية للإصدار 1 رموز الشريك، tokenProvider، entryUrlProvider، التحكم في العرض، أحداث دورة الحياة، طرق الحالات، وأحداث الأمر.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## متى تستخدم الأداة

اختر Trading Widget عندما يحتاج الشريك إلى واجهة تداول كاملة داخل منتج ويب موجود. استخدم وثائق REST API و WebSocket بدلا من ذلك عند بناء وصيانة واجهة تداول مخصصة بالكامل.

## مسار التنفيذ

1. اتبع [Trading Widget البداية السريعة](/ar/sdk/trading-widget/quick-start) لتحميل السكريبت وإنشاء حاوية مرئية.
2. التكوين [مصادقة الشركاء](/ar/sdk/trading-widget/authentication) من خلال خلفية شريك.
3. أضف المطلوب [الخيارات والفعاليات](/ar/sdk/trading-widget/options-events).
4. الاستخدام [طرق النسخة](/ar/sdk/trading-widget/instance-methods) لتحكم دورة الحياة ووقت التشغيل.
