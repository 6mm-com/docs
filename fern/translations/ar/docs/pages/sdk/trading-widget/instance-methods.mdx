## ملخص الطريقة

| طريقة | غاية |
| --- | --- |
| تدمير () | قم بإزالة إطار iframe وحرر مستمعي الأحداث. |
| getState() | اقرأ حالة دورة الحياة SDK الحالية. |
| whenReady() | انتظر حتى ينتهي iframe من التهيئة. |
| setSymbol(الرمز) | قم بتبديل زوج التداول داخل إطار iframe. |
| setTheme(الموضوع) | قم بتحديث معلمة سمة iframe. |
| setLocale(اللغة المحلية) | تبديل لغة iframe. |
| setSize(العرض، الارتفاع) | تحديث أبعاد iframe. |
| إعادة التحميل () | أعد تحميل إطار iframe الحالي. |
| refreshAuth(السبب) | قم بتشغيل تدفق تحديث مصادقة القطعة. |
| setTokenProvider(المزود) | استبدل الموفر الذي يستخدمه وضع الرمز المميز للشريك. |
| على (الحدث، المعالج) | اشترك في أحداث وقت التشغيل واحصل على وظيفة إلغاء الاشتراك. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## تدمير ()

قم بإزالة إطار iframe، ومسح المستمعين، ثم قم بتدمير الإصدار مرة واحدة للمثيل الحالي.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

اقرأ حالة دورة الحياة الحالية لمثيل عنصر واجهة المستخدم.

```js
const state = widget.getState()
```

تتضمن قيم الإرجاع التحميل والمصادقة والجاهزية والخطأ والتدمير.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

انتظر حتى ينتهي إطار iframe من التهيئة قبل تشغيل منطق واجهة المستخدم التابعة.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(الرمز)

قم بتبديل زوج التداول داخل إطار iframe. إذا كان iframe لا يزال قيد التهيئة، فإن SDK يضع الأمر في قائمة الانتظار ويرسله بعد أن يصبح جاهزًا.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(الموضوع)

قم بتحديث معلمة السمة المستخدمة بواسطة iframe للتداول المضمن.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(اللغة المحلية)

تبديل لغة iframe. القيم المدعومة هي en وen-US وzh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(العرض، الارتفاع)

قم بتحديث حجم iframe DOM وأبلغ iframe بالحجم الخارجي الجديد. يتم تحويل القيم الرقمية إلى بكسل.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## إعادة التحميل ()

أعد تحميل إطار iframe الحالي وانتظر حتى تتم تهيئته مرة أخرى.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(السبب)

اطلب من iframe تحديث تدفق المصادقة الحالي. تتم إعادة توجيه قيمة السبب الاختيارية للتسجيل والتحكم في التدفق.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(المزود)

استبدل tokenProvider المستخدم في وضع الرمز المميز للشريك. يستدعي SDK الموفر عندما يطلب إطار iframe رمزًا مميزًا جديدًا للتضمين.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

## على (الحدث، المعالج)

الاشتراك في حدث وقت التشغيل. تقوم الوظيفة التي تم إرجاعها بإزالة المستمع.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## طرق إضافية في وقت التشغيل v1 الحالي

| طريقة | غاية |
| --- | --- |
| `whenRendered()` | انتظر الإشعار المقدم لإطار iframe؛ هذا منفصل عن جاهز. |
| `setPage(page)` | اطلب صفحة منتج مدعومة في المثيل الحالي. لا يغير بيئة الصناديق. |
| `prepareForRecreate()` | اطلب iframe جاهزًا للتحضير للاستبدال؛ يُرجع وعدًا ويمكن رفضه إذا كان غير متاح أو مشغول أو انتهت مهلته. |
| `cancelRecreate()` | قم بإلغاء تدفق الاستبدال المعلق/المجهز. |
| `TradingWidget.validateOptions(options)` | التحقق من صحة خيارات التهيئة قبل إنشاء مثيل. |

بالنسبة لمستخدم أو تغيير البيئة الحقيقية/التجريبية، قم بتدمير المثيل القديم وإنشاء مثيل جديد باستخدام المصادقة والوضع المستهدفين. لا تستخدم `setPage` كمحول للبيئة. تحقق من القدرات قبل استخدام الطرق الاختيارية.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
