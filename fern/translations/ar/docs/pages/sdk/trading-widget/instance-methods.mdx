<h2 id="method-summary">ملخص الطريقة</h2>

| الطريقة | الغرض |
| --- | --- |
| ديسترو() | قم بإزالة iframe وأطلق مستمعي الحدث. |
| getState() | اقرأ حالة دورة الحياة الحالية SDK . |
| whenReady() | انتظر حتى ينتهي تهيئة iframe. |
| setSymbol(رمز) | بدل زوج التداول داخل إطار iframe. |
| setTheme(المقدمة) | قم بتحديث معامل قالب iframe. |
| setLocale(الموقع) | غير لغة iframe. |
| setSize(العرض، الارتفاع) | تحديث أبعاد iframe. |
| إعادة التحميل () | أعد تحميل الإطار الحالي. |
| refreshAuth(سبب) | فعل تدفق تحديث مصادقة الويدجت. |
| setTokenProvider(المزود) | استبدل المزود المستخدم في وضع الشريك-الرمز. |
| on(event، المسؤول) | اشترك في فعاليات وقت التشغيل واحصل على وظيفة إلغاء الاشتراك. |

<h2 id="destroy">ديسترو()</h2>

قم بإزالة iframe، ومسح المستمعين، وإرسال الملف الذي تم تدميره مرة واحدة في الحالة الحالية.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

اقرأ حالة دورة الحياة الحالية لنسخة الويدجت.

```js
const state = widget.getState()
```

تشمل قيم الإرجاع التحميل، المصادقة، الجاهز، الخطأ، والتدمير.

<h2 id="whenready">whenReady()</h2>

انتظر حتى ينتهي تهيئة iframe قبل تشغيل منطق واجهة المستخدم التابع.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(رمز)</h2>

بدل زوج التداول داخل إطار iframe. إذا كان iframe لا يزال في مرحلة التهيئة، يقوم SDK بإدخال الأمر وإرساله بعد "جاهز".

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(المقدمة)</h2>

قم بتحديث معاملة القالب المستخدمة في إطار التداول المدمج.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(الموقع)</h2>

بدل بلغة iframe. القيم المدعومة هي en، en-US، و zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(العرض، الارتفاع)</h2>

قم بتحديث حجم DOM الإطار وأبلغ الإطار بالحجم الخارجي الجديد. يتم تحويل القيم الرقمية إلى px.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">إعادة التحميل ()</h2>

أعد تحميل الإطار الحالي وانتظر حتى يتم تهيئة الجهاز مرة أخرى.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(سبب)</h2>

اطلب من iframe تحديث تدفق المصادقة الحالي. يتم تحويل قيمة السبب الاختياري للتسجيل والتحكم في التدفق.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(المزود)</h2>

استبدل tokenProvider المستخدم في وضع الشريك-الرمز. يتصل SDK بالمزود عندما يطلب iframe رمزا جديدا مدمجا.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">on(event، المسؤول)</h2>

اشترك في حدث وقت تشغيل. الوظيفة المعادة تزيل المستمع.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
