تدمج Trading Widget SDK واجهة التداول 6MM داخل صفحة ويب مملوكة للشركاء. أسرع تكامل يتطلب حاوية مرئية، وسكريبت SDK الإنتاج، واستدعاء إلى `TradingWidget.create()`.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## قبل أن تبدأ

- تشغيل المثال من صفحة ويب يمكنها تحميل الموارد من `https://app.6mm.com`.
- إعطاء حاوية الأداة عرضا وارتفاعا صريحين.
- حمل SDK قبل الاتصال `TradingWidget.create()`.
- تخطيط [تدفق المصادقة](/ar/sdk/trading-widget/authentication) قبل تمكين ميزات الحساب أو التداول في الإنتاج.

<span id="minimal-example" data-sixmm-canonical-anchor="minimal-example" aria-hidden="true"></span>

## مثال بسيط

```html
<div id="trading-widget" style="width: 100%; height: 720px"></div>

<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
<script>
  const widget = TradingWidget.create('#trading-widget', {
    baseUrl: 'https://app.6mm.com',
    symbol: 'BTCUSDT',
    theme: 'dark',
    locale: 'en',
    layout: 'default',
    display: {
      showHeader: false,
      showTicker: false,
      hidden: [],
    },
    onReady(event) {
      console.log('ready', event)
    },
    onError(error) {
      console.error('error', error)
    },
  })
</script>
```

عندما ينجح التكامل، ينشئ SDK إطار iframe داخل `#trading-widget` وينادي `onReady`. التقاط `onError` أثناء التطوير بحيث تكون إخفاقات التكوين والتحميل مرئية.

<span id="sdk-urls" data-sixmm-canonical-anchor="sdk-urls" aria-hidden="true"></span>

## SDK الروابط

| البيئة | URL النص |
| --- | --- |
| الإنتاج | https://app.6mm.com/sdk/trading-widget/v1/index.js |

> **اضبط baseUrl بشكل صريح**
>
> عند الاختبار من صفحات مملوكة للشركاء، امرر baseUrl بحيث يشير الiframe دائما إلى نطاق الويب 6MM .

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## ضوابط العرض

التضمين الشريكي يخفي رأس الحاسوب ومؤشر السوق السفلي بشكل افتراضي. استخدم `display` عندما تحتاج إلى إظهار مناطق الشل أو إخفاء الحاويات عالية المستوى في صفحة التداول المدمجة.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['account'],
}
```

<span id="container-size" data-sixmm-canonical-anchor="container-size" aria-hidden="true"></span>

## حجم الحاوية

| السطح | الحد الأدنى الموصى به |
| --- | --- |
| سطح المكتب | 1024 × 720 |
| موبايل | 390 × 700 |

للتخطيطات المستجيبة، حافظ على سلس العرض وحدد ارتفاعا أدنى مناسبا لكل نقطة توقف. الحاوية ذات الارتفاع الصفري يمكنها تحميل SDK بنجاح مع ترك واجهة التداول غير مرئية.

<span id="verify-the-integration" data-sixmm-canonical-anchor="verify-the-integration" aria-hidden="true"></span>

## تحقق من التكامل

1. تأكد من عودة سكريبت SDK بنجاح في لوحة شبكة المتصفح.
2. تأكيد `onReady` الإطلاق بمجرد تهيئة iframe.
3. اختبر `symbol`المكونة وال `locale`والموضوع والأقسام المخفية.
4. تغيير حجم الصفحة عبر نقاط توقف سطح المكتب والهواتف المحمولة.
5. أكمل اختبارا مصادقا مع مستخدم غير إنتاجي قبل الإطلاق.

<span id="common-issues" data-sixmm-canonical-anchor="common-issues" aria-hidden="true"></span>

## القضايا الشائعة

| عَرَض | ما يجب التحقق منه |
| --- | --- |
| منطقة الأداة الفارغة | تأكد من أن الحاوية تظهر عرضا وارتفاعا. |
| `TradingWidget` غير معرف | تأكد من تحميل السكريبت v1 قبل إنشاء المكالمة. |
| الصفحة أو البيئة الخاطئة | قم بتعيين `baseUrl` بشكل صريح وتحقق من البيئة المكونة. |
| حدث الاستعداد لا يطلق أبدا | التقاط `onError` وفحص طلبات iframe أو السكريبتات المحجوبة. |
| بيانات الحساب غير متوفرة | أكمل تدفق مصادقة الأداة المدعومة. |
