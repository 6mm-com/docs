يشرح دليل التداول كيف ينتقل المستخدمون من الوصول والتمويل إلى التداول الدائم في عقودهم، وكيف تؤثر قواعد التداول الأساسية على الأوامر والمراكز والرسوم ومخاطر التصفية.

هذا القسم مكتوب للمنتج والعمليات والدعم وتعليم المستخدم النهائي. لتفاصيل API الحقول والتوقيع وتكامل الخلفية، استخدم أقسام المطورين و SDK .

<h2 id="before-trading">قبل التداول</h2>

- تأكيد دخول المستخدم عبر شريك معتمد أو إدخال 6MM مدمج.
- التأكد من توفر الأموال في الحساب الصحيح قبل وضع الطلبات.
- فهم سلوك الرافعة المالية، والهامش، والتصفية، ورسوم التمويل.
- ابدأ بأحجام مراكز صغيرة عند تعلم سوق أو نمط تداول جديد.
- استخدام أوامر TP / SL وأوامر التقليل فقط عند الاقتضاء للسيطرة على المخاطر.
