## وحدة التحكم ودعم الزوار

| أعراض | تحقق أولا |
| --- | --- |
| القائمة مفقودة | دور الحساب وتوافر خدمة المستأجر |
| القطعة لا تفتح | البرنامج النصي الذي تم إنشاؤه URL، ومفتاح التطبيق، وأخطاء النطاق والمتصفح المسموح بها |
| لا يستخدم الروبوت النموذج الكبير | الخطوة المطابقة الفعلية ومفاتيح الخدمة الذكية والتكوين ذي الصلة |
| تستخدم الإجابة القواعد القديمة | المقالة المصدر، حالة النشر، FAQ النص، حالة الترجمة والاسترجاع |
| الترجمة غائبة | اللغة المستهدفة، وتبديل الترجمة، والترجمة المحفوظة، وتوافر الخدمة/الرصيد |
| فشل توليد المتجهات | توفر الخدمة وحالة الاسترجاع؛ تجنب إعادة البناء بشكل متكرر دون تحديد الفشل |
| حقل الاتصال فارغ | ما إذا كان هذا الحقل قد تم جمعه بالفعل؛ التمييز بين جهة الاتصال والبريد الإلكتروني للدخول |

## MCP الاتصال والمكالمات

| أعراض | الخطوة التالية |
| --- | --- |
| يؤدي فتح نقطة النهاية في المتصفح إلى إرجاع خطأ | إنها نقطة نهاية بروتوكول، وليست صفحة تسجيل دخول؛ قم بإضافته إلى عميل MCP متوافق |
| لا يمكن بدء التفويض | تحقق من نقطة النهاية الدقيقة ودعم العميل HTTP/OAuth وتدفق تسجيل الدخول للمتصفح |
| اتصال غير مصرح به أو منتهي الصلاحية | التحقق من الإلغاء وانتهاء الصلاحية؛ إعادة الاتصال من خلال التطبيق |
| الأداة مفقودة أو تم رفض الوصول إليها | التحقق من دور حساب التفويض ونطاق السجل؛ تحديث قائمة الأدوات |
| في انتظار الموافقة | افتح رابط الموافقة الذي تم إرجاعه وراجعه في الواجهة الخلفية |
| تم تغيير المحتوى | اقرأ أحدث سجل وقم بمعاينته مرة أخرى وأرسل عملية جديدة مقصودة |
| انتهت مهلة الطلب | الاستعلام عن حالة العملية قبل إعادة المحاولة أو افتراض الفشل |
| لا يوجد سجل الكتابة | تمييز القراءة، في انتظار الموافقة والكتابة المكتملة؛ تحقق من المرشحات في سجلات العملية |

<span id="before-contacting-support" data-sixmm-canonical-anchor="before-contacting-support" aria-hidden="true"></span>

## قبل الاتصال بالدعم

اجمع الوقت والمنطقة الزمنية والمستأجر/الحساب المتأثر واسم الصفحة أو الأداة ومعرف العملية حيثما كان ذلك متاحًا والخطأ الدقيق. قم بتضمين لقطة شاشة منقحة أو خطوات لإعادة إنتاجها. لا ترسل كلمات المرور أو رموز التحقق أو الرموز المميزة لحاملها أو أسرار التوقيع.

جرب سجل اختبار صغير عند تشخيص الكتابة. تحقق من النتيجة وقم بتنظيف بيانات الاختبار التي قمت بإنشائها فقط، باستخدام تدفق التأكيد العادي حيثما يكون ذلك مطلوبًا.
