## الأدوات المتاحة تتبع دورك

يصف الجدول الحد الأقصى للنطاق المدعوم. يتلقى تطبيق الذكاء الاصطناعي الخاص بك فقط الأدوات المسموح بها لحساب التفويض. استخدم قائمة الأدوات المباشرة ومخطط المعلمات الخاص بها كعقد؛ ميزة وحدة التحكم الجديدة لا تعتبر أداة MCP تلقائيًا.

| وحدة التحكم | العمليات المدعومة |
| --- | --- |
| المحادثات عبر الإنترنت | قراءة الجلسات والرسائل ومعلومات قائمة الانتظار؛ التعيين والانضمام والتولي والنقل؛ إرسال الرسائل؛ دعوة التقييمات؛ إدارة إذن التحميل؛ التعرف على/ترجمة الرسائل؛ تحميل الملفات المدعومة |
| التذاكر وردود الفعل | الاستعلام عن الحالة وتعيينها وتحديثها وحذف تذاكر المستخدم وملاحظاته؛ إنشاء وقراءة وتحديث وتعيين وحذف تذاكر الوكيل |
| تاريخ المحادثة | جلسات الاستعلام والرسائل. حذف جلسة واحدة أو جلسات متعددة |
| إدارة المحتوى | قراءة الفئات والمقالات والأسئلة الساخنة وفئات الأسئلة وبطاقات الميزات والإعلانات وإدخالات الخدمة الذاتية والاحتفاظ بها؛ نشر/إلغاء نشر المقالات |
| ترجمة اللغة | قراءة المصادر والترجمات وحالة الإكمال؛ حفظ أو مسح الترجمات المدعومة؛ استدعاء الترجمة الآلية؛ إدارة إعدادات اللغة المدعومة |
| تكوين بوت | اقرأ الإعدادات المدعومة والأسئلة الشائعة، وحافظ على الأسئلة المشابهة، واختبر الردود، وفحص حالة الاسترداد، وقم بتحديث الفهارس وإعادة بناء المتجهات |
| إدارة الوكيل | الحفاظ على الوكلاء والأدوار والردود السريعة المدعومة |
| إعدادات النظام | حقول القائمة المسموح بها للقراءة/الكتابة والمظهر والنسخ والمحادثة وإدخال الزائر والخدمة الذكية وموقع الويب |
| إحصائيات | نظرة عامة للقراءة فقط والاستعلامات الإحصائية المدعومة |
| الاستخدام والفواتير | رصيد القراءة فقط والاستخدام والمعاملات والأسعار |
| سجلات العملية | قائمة العمليات والتفاصيل للقراءة فقط |

## يكتب والتأكيد

يتطلب الحذف والنشر/إلغاء النشر وتحرير المقالات المنشورة وإرسال الرسائل وإدارة الدور/الحساب وتغييرات القائمة المسموح بها لموقع الويب وإعادة بناء المتجهات والترجمة التلقائية للنظام الأساسي تأكيدًا خلفيًا حيثما تحدده الأداة. لا يزال من الممكن أن تؤدي الكتابة دون تأكيد إلى تغيير البيانات على الفور؛ قم بمراجعة النطاق المقصود قبل مطالبة الذكاء الاصطناعي بتنفيذه.

MCP لا يوفر إدارة النظام الأساسي، أو إغلاق/حذف المستأجر، أو إعادة شحن الرصيد، أو تعديلات الفواتير، أو الوصول السري للمزود. تفرض أدوات الملفات عمليات فحص التنسيق والحد الأقصى للحجم المنشور؛ يدعم التنفيذ الحالي ملفًا واحدًا يصل حجمه إلى 10 ميجابايت عبر Base64. استخدم وحدة التحكم للملفات الأكبر حجمًا حيث تسمح الحدود الخاصة بها.

## المهام سبيل المثال

- قم بإدراج الترجمات المفقودة ومسودات الإصدارات اليابانية مع الحفاظ على الروابط والمبالغ.
- ابحث عن تذاكر المستخدم التي لم يتم حلها واقترح المهام دون تطبيقها بعد.
- قم بإنشاء مسودة مقالة معرفية في فئة موجودة، ثم قم بإظهار عنوانها ومعرفها.
- قم بتلخيص إحصائيات الدعم الأخيرة بنطاق زمني محدد.

يمكن أن يؤدي الذكاء الاصطناعي للمنصة والترجمة الآلية وعمليات المتجهات إلى فرض رسوم الخدمة الحالية. يعد الاستخدام الخاص لموفر الذكاء الاصطناعي المتصل منفصلاً.
