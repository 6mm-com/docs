<span id="partner-information" data-sixmm-canonical-anchor="partner-information" aria-hidden="true"></span>

## معلومات الشريك

| الميدان | الوصف |
| --- | --- |
| اسم الشريك | اسم قانوني أو اسم مشروع المستخدم في التكامل. |
| نوع المنتج | تطبيق، محفظة، بوابة وسطاء، بورصة بيضاء، منصة مؤسسية، أو غيرها. |
| الاتصالات الرئيسية | جهات اتصالات تجارية، تقنية، عملياتية، وطارئة. |
| مناطق الإطلاق | الدول أو المناطق التي سيكشف فيها التكامل. |

<span id="technical-information" data-sixmm-canonical-anchor="technical-information" aria-hidden="true"></span>

## معلومات تقنية

| الميدان | الوصف |
| --- | --- |
| نطاقات الواجهة الأمامية | النطاقات التي تقوم بتحميل الأداة أو صفحات الإدخال. |
| النطاقات الخلفية | نطاقات الخادم المستخدمة لاستدعاءات Agent SDK أو API . |
| URL الهوك | نقطة نهاية Webhook الإنتاج ومتطلبات قائمة IP المتوقعة. |
| نطاق التكامل | Trading Widget، Agent SDK، REST API، WebSocket، نظام العلامة البيضاء، أو دمج السيولة. |

<span id="operational-information" data-sixmm-canonical-anchor="operational-information" aria-hidden="true"></span>

## المعلومات التشغيلية

- تاريخ الإطلاق المتوقع.
- حركة المرور المتوقعة أو نطاق المستخدم النشط.
- ساعات الدعم ومالك التصعيد.
- مراقبة الاتصال بالمالك والحادث.

<span id="security-and-review-information" data-sixmm-canonical-anchor="security-and-review-information" aria-hidden="true"></span>

## معلومات الأمان والمراجعة

- طريقة المصادقة ونطاق الإذن API Key .
- التخزين السري، ومالك التناوب، وعناوين IP المصدر المعتمدة.
- التحقق من توقيع Webhook وتصميم الهوية.
- تسجيل التسجيل، المراقبة، المطابقة، التراجع، والاستجابة للحوادث.
- الأسواق المستهدفة، نوع المستخدم، نموذج الحيازة، والجهة المسؤولة عن الالتزامات الموجهة للمستخدم.

لا تدرج أسرار الإنتاج، أو رموز الوصول الكامل، أو المفاتيح الخاصة، أو بيانات المستخدمين غير المحجوبة في هذا القالب.

استخدم [قائمة التحقق لإطلاق الإنتاج](/ar/resources/production-launch-checklist) للموافقة النهائية ونموذج [طلب الدعم](/ar/resources/support-request-template) لتصعيد المشكلة.
