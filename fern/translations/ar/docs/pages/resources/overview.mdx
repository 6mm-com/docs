## متى يجب استخدام هذا القسم

| السيناريو | الصفحة الموصى بها |
| --- | --- |
| أضف صفحة تداول 6MM إلى تطبيق أو صفحة ويب | إرشادات الاستخدام |
| أحتاج إلى ملفات لإدخال الشعار، اللافتة، أو بطاقات البطاقات | تنزيلات الأصول |
| جهز إطلاق يحمل علامة شريك | دعم العلامة البيضاء |
| الانتقال من الاختبار إلى الإنتاج | قائمة التحقق لإطلاق الإنتاج |
| اطلب من الدعم 6MM للتحقيق في مشكلة ما | قالب طلب الدعم |
