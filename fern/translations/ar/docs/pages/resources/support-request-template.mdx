عند التواصل مع الدعم، يرجى تضمين المعلومات أدناه متى ما توفرت فيه.

<h2 id="required-context">السياق المطلوب</h2>

| الميدان | مثال |
| --- | --- |
| البيئة | الإنتاج أو التمثيل |
| الوحدة المتأثرة | Trading Widget، Agent SDK، REST API، WebSocket، webhook ، نظام العلامة البيضاء |
| النطاق الزمني | UTC نطاق الطابع الزمني عند حدوث المشكلة |
| معرف المستخدم الشريك | معرف المستخدم من جهة الشريك، إذا كان ذا صلة |
| معرف 6MM التعيين | agentUserIdأو معرف الطلب، أو معرف الطلب، أو معرف حدث webhook |
| تأثير الأعمال | عدد المستخدمين أو العمليات المتأثرة وما إذا كانت المشكلة مستمرة |

<h2 id="description-format">تنسيق الوصف</h2>

- ماذا حدث؟
- ماذا كنت تتوقع أن يحدث؟
- هل يمكن إعادة إنتاجه؟
- ما الذي تغير مؤخرا؟
- هل المشكلة ما زالت تحدث؟

<h2 id="attachments">الملحقات</h2>

- سجلات الطلبات والاستجابات ذات الصلة.
- لقطات شاشة أو تسجيلات شاشة.
- حمولة Webhook ورؤوس توقيع.
- أخطاء في وحدة التحكم في المتصفح لمشاكل Trading Widget .

<h2 id="copyable-template">قالب قابل للنسخ</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

أزل الحقول غير ذات الصلة، لكن احتفظ بنطاق UTC الزمني وعلى الأقل طلب أو معرف أعمال واحد قابل للبحث كلما أمكن.

<h2 id="redact-sensitive-data">حجب البيانات الحساسة</h2>

لا ترسل:

- كلمات المرور أو رموز الوصول الكامل
- API الأسرار، أو المفاتيح الخاصة، أو التوقيعات الكاملة
- ملفات تعريف الارتباط الخاصة بالجلسات
- الدفع الكامل أو الهوية أو بيانات شخصية غير ضرورية أخرى

احتفظ باسم الحقل وبادئة قصيرة أو لاحقة فقط عندما يحتاج الدعم إلى التمييز بين القيم المنقحة.

<h2 id="choose-the-right-channel">اختر القناة المناسبة</h2>
