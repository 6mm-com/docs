Khi liên hệ với bộ phận hỗ trợ, hãy cung cấp thông tin bên dưới khi có sẵn.

<h2 id="required-context">Bối cảnh bắt buộc</h2>

| Lĩnh vực | Ví dụ |
| --- | --- |
| Môi trường | Sản xuất hoặc dàn dựng |
| Mô-đun bị ảnh hưởng | Trading Widget, Agent SDK, REST API, WebSocket, webhook, hệ thống nhãn trắng |
| Khoảng thời gian | UTC phạm vi dấu thời gian khi sự cố xảy ra |
| ID người dùng đối tác | Định danh người dùng phía đối tác, nếu có liên quan |
| ID ánh xạ 6MM | agentUserId, ID đơn hàng, ID yêu cầu hoặc ID sự kiện webhook |
| Tác động kinh doanh | Số lượng người dùng hoặc hoạt động bị ảnh hưởng và liệu sự cố có đang diễn ra hay không |

<h2 id="description-format">Định dạng mô tả</h2>

- Chuyện gì đã xảy ra?
- Anh mong đợi chuyện gì sẽ xảy ra?
- Có thể tái tạo không?
- Gần đây có gì thay đổi?
- Vấn đề vẫn còn xảy ra chứ?

<h2 id="attachments">Tệp đính kèm</h2>

- Nhật ký yêu cầu và phản hồi liên quan.
- Ảnh chụp màn hình hoặc bản ghi màn hình.
- Payload và tiêu đề chữ ký Webhook.
- Lỗi bảng điều khiển trình duyệt do các sự cố Trading Widget .

<h2 id="copyable-template">Mẫu có thể sao chép</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Loại bỏ các trường không liên quan, nhưng giữ khoảng thời gian UTC và ít nhất một yêu cầu hoặc định danh doanh nghiệp có thể tìm kiếm khi có thể.

<h2 id="redact-sensitive-data">Ẩn dữ liệu nhạy cảm</h2>

Không gửi:

- Mật khẩu hoặc mã truy cập đầy đủ
- API bí mật, khóa riêng tư hoặc chữ ký hoàn chỉnh
- Cookie phiên
- Thanh toán đầy đủ, nhận dạng hoặc dữ liệu cá nhân không cần thiết khác

Chỉ giữ tên trường và một tiền tố hoặc hậu tố ngắn khi bộ phận hỗ trợ cần phân biệt giữa các giá trị đã được làm sạch.
