<h2 id="how-the-solutions-connect">Cách các giải pháp kết nối</h2>

Hầu hết các triển khai đối tác kết hợp nhiều hơn một 6MM năng. Sàn giao dịch nhãn trắng có thể sử dụng thanh khoản tổ chức, hỗ trợ tuân thủ và tích hợp API . Đối tác giao dịch nhúng có thể bắt đầu với Trading Widget SDK và sau đó thêm luồng Agent SDK backend, xử lý webhook và tài nguyên vận hành.
