Hệ thống Giao dịch Embedded API / SDK được thiết kế cho các đối tác đã sở hữu lưu lượng truy cập, người dùng hoặc quy trình làm việc kinh doanh và muốn thêm giao dịch mà không cần xây dựng sàn giao dịch hoàn chỉnh từ đầu.

<h2 id="what-it-provides">Những gì nó cung cấp</h2>

- Thiết bị giao dịch tích hợp qua Trading Widget SDK
- Tích hợp backend đối tác thông qua Agent SDKs
- Ràng buộc danh tính người dùng và luồng token nhập
- Chuyển tài sản, truy cập lệnh, vị thế và tài khoản API
- Tích hợp sự kiện, webhook và vòng đời cho các hệ thống vận hành

<h2 id="recommended-architecture">Kiến trúc được khuyến nghị</h2>

| Lớp | Trách nhiệm |
| --- | --- |
| Giao diện đối tác | Lưu trữ điểm vào và tích hợp giao diện giao dịch 6MM . |
| Backend đối tác | Giữ bí mật API , xác thực người dùng, phát hành token nhúng và xử lý webhook. |
| 6MM hạ tầng giao dịch | Xử lý giao diện giao dịch giao dịch, khớp, rủi ro, thanh khoản, trạng thái tài khoản và vòng đời giao dịch. |

<h2 id="choose-an-integration-path">Chọn đường dẫn tích hợp</h2>

| Yêu cầu | Lộ trình được đề xuất |
| --- | --- |
| Giao diện giao dịch hoàn chỉnh với tích hợp web nhanh nhất | Trading Widget |
| Xử lý liên kết người dùng backend, chuyển tải, URLnhập và webhook | Agent SDK |
| Quy trình sản phẩm và đơn hàng hoàn toàn tùy chỉnh | REST API + WebSocket |
| Kinh nghiệm trao đổi thương hiệu với phạm vi hoạt động rộng hơn | Trao đổi nhãn trắng |

Thiết kế cuối cùng có thể kết hợp các đường dẫn này. Xác nhận xác thực, quyền sở hữu tài sản, ranh giới trách nhiệm, giám sát và hỗ trợ sản xuất trước khi bắt đầu triển khai.
