Hướng dẫn này hướng tới **Agent Java SDK `v0.3.0`**, Java 8+ và hợp đồng công khai được gắn thẻ. Các ví dụ chạy trong phần phụ trợ của đối tác sau khi khởi tạo `client` trong [Bắt đầu nhanh](/vi/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## Điều kiện tiên quyết mẫu

Đoạn mã Java chia sẻ những nội dung nhập này. Khởi tạo `client` bằng cách sử dụng Bắt đầu nhanh và lấy `platformUserId` từ liên kết đã lưu. ID người dùng/đơn đặt hàng mẫu phải được thay thế bằng các giá trị cố định của riêng bạn.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## `listPerpetualLedger`

Mẫu yêu cầu: `PerpetualLedgerRequest`.

```java
import com.sixmm.agent.model.PerpetualLedgerRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

PerpetualLedgerRequest request = new PerpetualLedgerRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.endTime = System.currentTimeMillis();
request.startTime = request.endTime - 3_600_000L;
PerpetualResponse response = client.listPerpetualLedger(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

<span id="request-fields" data-sixmm-canonical-anchor="request-fields" aria-hidden="true"></span>

### Các trường yêu cầu

| Cánh đồng | Java loại | Yêu cầu | Nghĩa |
| --- | --- | --- | --- |
| `platformUserIds` | `java.util.List<String>` | có điều kiện | 1–100 ID công khai duy nhất; cần thiết cho việc điền và các đơn đặt hàng có điều kiện. Bỏ qua các truy vấn được hỗ trợ cho phạm vi trình phát trực tiếp; [] không hợp lệ. |
| `assetType` | `String` | KHÔNG | Phân loại tài sản theo sổ cái trả về; đừng cho rằng USDT. |
| `changeType` | `String` | KHÔNG | Sổ cái doanh nghiệp-loại thay đổi, bảo toàn giá trị nguồn. |
| `startTime` | `Long` | KHÔNG | Bao gồm Unix mili giây; sử dụng cửa sổ lịch sử UTC cố định. |
| `endTime` | `Long` | KHÔNG | Unix mili giây độc quyền. |
| `limit` | `Integer` | KHÔNG | Mặc định 500; 1–1000. |
| `cursor` | `String` | KHÔNG | Sử dụng nextCursor được trả về với các bộ lọc không thay đổi; dừng khi hasMore sai. |

Ví dụ đọc một trang. Đối với các trường bắt buộc, phạm vi trình phát, ngữ nghĩa bộ lọc, giới hạn, con trỏ và số lần thử giới hạn, hãy làm theo [Tổng quan về truy vấn](/vi/sdk/agent-sdk/java/perpetual-queries). Giữ tất cả các bộ lọc không thay đổi trong khi phân trang; không hiểu lỗi là kết quả trống.

## Sổ nhật ký hợp đồng

Giao diện: `account/ledger`. Dữ liệu trả về chỉ chứa 11 trường kinh doanh sau và không mang cờ boolean thứ tự.

| Trường `data` | kiểu | nghĩa |
| --- | --- | --- |
| `ledgerId` | string | Sổ cái nguồn ghi vào ID giao dịch; cùng một giao dịch có thể được chia thành nhiều chi tiết |
| `symbol` | string | Cặp giao dịch liên quan, có thể bỏ qua nếu không liên quan |
| `assetType` | string | Loại tài sản, được lưu theo giá trị nguồn; được sử dụng để phân loại tài sản, không được suy luận theo mặc định USDT |
| `changeType` | string | Tài khoản thay đổi loại hình kinh doanh, lưu theo giá trị nguồn, chẳng hạn như phí xử lý, lãi lỗ, chuyển khoản; có thể được lọc theo cùng một trường |
| `amount` | string | Mức độ thay đổi của chi tiết này, số dương biểu thị tăng, số âm biểu thị giảm; độ chính xác được giữ lại |
| `walletBalanceBefore` | string | Số dư ví trước khi thay đổi tài khoản được ghi ở chi tiết này |
| `walletBalanceAfter` | string | Số dư ví sau khi thay đổi tài khoản được ghi ở chi tiết này |
| `frozenBalanceBefore` | string | Số dư bị đóng băng trước khi thay đổi tài khoản được ghi vào chi tiết này |
| `frozenBalanceAfter` | string | Số dư bị đóng băng được ghi nhận ở chi tiết này sau khi thay đổi tài khoản |
| `referenceId` | string | Mã số doanh nghiệp liên kết; được hiểu là changeType và không thể được coi là thống nhất theo thứ tự orderId; "0" chỉ ra rằng nguồn không có số liên kết hợp lệ |
| `createdAt` | integer | Thời gian tạo chi tiết thay đổi tài khoản, mili giây; trường này được sử dụng để lọc thời gian trong giao diện này |

Sử dụng số dư trước và sau khi thay đổi tài khoản được giao diện trả về. changeType khác nhau có ngữ nghĩa khác nhau và không thể giả định rằng mỗi số tiền bằng walletBalanceAfter − walletBalanceBefore. Việc hiển thị/tóm tắt các bản ghi sổ cái phải giữ lại danh tính loại và chi tiết.

Dưới đây là ví dụ về định dạng sử dụng ID và số tiền giả:

```json
{

  "message": "success",
  "data": {
    "items": [

        "platformUserId": "1188041528",
        "entityType": "ACCOUNT_LEDGER",

        "data": {
          "ledgerId": "ledger-example-001",
          "symbol": "BTCUSDT",
          "assetType": "USDT",
          "changeType": "HANDLING_FEE",
          "amount": "-0.10000000",
          "walletBalanceBefore": "100.00000000",
```

## Ví dụ về phong bì phản hồi

Đây là trang trống minh họa, không phải mẫu giao dịch đã hoàn thành. Các bảng trường dành riêng cho tài nguyên ở trên mô tả `items[].data`.

```json
{"code":0,"message":"success","data":{"items":[],"nextCursor":"","hasMore":false}}
```
