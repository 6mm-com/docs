Hướng dẫn này hướng tới **Agent Java SDK `v0.3.0`**, Java 8+ và hợp đồng công khai được gắn thẻ. Các ví dụ chạy trong phần phụ trợ của đối tác sau khi khởi tạo `client` trong [Bắt đầu nhanh](/vi/sdk/agent-sdk/java/quick-start).

## Điều kiện tiên quyết mẫu

Đoạn mã Java chia sẻ những nội dung nhập này. Khởi tạo `client` bằng cách sử dụng Bắt đầu nhanh và lấy `platformUserId` từ liên kết đã lưu. ID người dùng/đơn đặt hàng mẫu phải được thay thế bằng các giá trị cố định của riêng bạn.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget Mã thông báo nhúng

Mã thông báo nhúng dành cho chế độ Trading Widget SDK `partner-token + tokenProvider`. các
trình duyệt gọi phần phụ trợ của đối tác và phần phụ trợ của đối tác gọi đây là Java SDK
để tạo một `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Yêu cầu tích hợp:

- `channelId` phải sử dụng giá trị được truyền bởi Trading Widget SDK.
- `symbol` là tùy chọn và có thể mang ký hiệu ban đầu hiện tại. Đây không phải là hạn chế về quyền đối với cặp giao dịch mã thông báo.
- `embedToken` chỉ tồn tại trong thời gian ngắn và một lần. Đừng đặt nó vào chuỗi truy vấn URL.
- Giao diện đối tác không bao giờ được giữ `apiSecret`.
- `expireAt` là dấu thời gian Unix tính bằng giây, không phải TTL.

Ví dụ về điểm cuối phụ trợ của đối tác:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Hợp đồng điểm cuối của đối tác

Xác thực phiên đối tác và lấy được `agentUserId` phía máy chủ. Chấp nhận Widget hiện tại `channelId`; trả về `embedToken`, `expireAt` (giây Unix) cấp cao nhất và `channelId`. Phản hồi của tác nhân không cung cấp `channelId`: chương trình phụ trợ của bạn phản ánh điều đó. Tìm nạp mã thông báo mới khi khởi tạo và gia hạn; không bao giờ sử dụng lại nó. Việc tạo mã thông báo không chuyển tiền hoặc chọn môi trường ví.

Nhìn thấy [Giao dịch giây](/vi/sdk/agent-sdk/java/seconds-trading) cho luồng giao diện người dùng/phụ trợ hoàn chỉnh.
