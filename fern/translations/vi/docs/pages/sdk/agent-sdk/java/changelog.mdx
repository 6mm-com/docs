Hướng dẫn này hướng tới **Agent Java SDK `v0.3.0`**, Java 8+ và hợp đồng công khai được gắn thẻ. Các ví dụ chạy trong phần phụ trợ của đối tác sau khi khởi tạo `client` trong [Bắt đầu nhanh](/vi/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Sáu truy vấn vĩnh viễn: đơn đặt hàng hiện tại, lịch sử đơn hàng, điền, vị trí hiện tại, lịch sử vị trí và sổ cái tài khoản.
- Số dư tài trợ, chuyển khoản, truy vấn khôi phục và chuyển khoản Tài trợ/Hợp đồng.
- Sản xuất rõ ràng/lựa chọn mô phỏng cho các yêu cầu kinh phí được hỗ trợ.
- Hướng dẫn nhúng và chuyển hướng giao dịch theo giây, tham chiếu trường phản hồi và hướng dẫn di chuyển.

Java SDK và Trading Widget SDK có các phiên bản độc lập. Tiện ích `v1` URL không phải là phiên bản Java SDK `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Tích hợp hiện có

Bảo toàn ánh xạ người dùng, đơn đặt hàng ban đầu và thông tin xác thực. Các trường môi trường bị bỏ qua sẽ giữ lại hành vi sản xuất hiện có. Việc cấp vốn, quỹ mô phỏng rõ ràng và sáu truy vấn vĩnh viễn yêu cầu các mô hình và phương pháp mới tương ứng. Ôn tập [Hướng dẫn nâng cấp](/vi/sdk/agent-sdk/java/upgrade) trước khi thay đổi tích hợp hiện có.
