Hướng dẫn này hướng tới **Agent Java SDK `v0.3.0`**, Java 8+ và hợp đồng công khai được gắn thẻ. Các ví dụ chạy trong phần phụ trợ của đối tác sau khi khởi tạo `client` trong [Bắt đầu nhanh](/vi/sdk/agent-sdk/java/quick-start).

## Phiên bản và cài đặt

| Mục | Giá trị |
| --- | --- |
| Thẻ nguồn ổn định | `v0.3.0` |
| Java | Java 8+ |
| Maven | Maven 3.9+ |
| tọa độ | `com.sixmm.exchange.sdk:agent:0.3.0` |

Nguồn máy chủ GitHub; nó không làm cho các tọa độ này có thể phân giải được từ Maven Central. Sử dụng cài đặt cục bộ được gắn thẻ hoặc kho lưu trữ tạo tác đã được phê duyệt của bạn.

## SDK bao gồm những gì

| Loại | Kịch bản | SDK API | Sự miêu tả |
| --- | --- | --- | --- |
| Ràng buộc người dùng | Ràng buộc người dùng | `bind` | Tạo hoặc tìm nạp liên kết giữa người dùng đối tác và người dùng nền tảng 6MM |
| Truy vấn nội dung | Truy vấn tài khoản đối tác | `queryAccount` | Truy vấn ký quỹ đối tác hoặc tài khoản cấp vốn |
| Truy vấn nội dung | Truy vấn nội dung người dùng | `queryUserAssets` | Truy vấn tài sản hợp đồng; sử dụng `withFunding()` để bao gồm số dư Kinh phí |
| chuyển nhượng | Chuyển số tiền cố định | `transfer` | Chuyển tiền vào hoặc ra khỏi 6MM |
| chuyển nhượng | Chuyển tất cả ra ngoài | `transferAllOut` | Di chuyển tất cả số dư người dùng có thể rút trở lại nền tảng đối tác |
| chuyển nhượng | Đảo ngược thứ tự | `reverse` | Đảo ngược quá trình chuyển thành công khi phần phụ trợ hỗ trợ luồng bù |
| chuyển nhượng | Thứ tự truy vấn | `queryOrder` | Truy vấn một lệnh chuyển theo mã số đơn hàng của đối tác |
| chuyển nhượng | Liệt kê đơn hàng | `listOrders` | Trang thông qua lệnh chuyển nhượng để đối chiếu |
| chuyển nhượng | Webhook xác minh | `WebhookVerifier.verify` | Xác minh chuyển lệnh gọi lại trạng thái cuối cùng từ 6MM |
| Ví tiền tài trợ | Chuyển tiền tài trợ | `walletTransfer` | Đối tác ↔ Tài trợ hoặc Tài trợ ↔ Hợp đồng; xác nhận trạng thái trả lại |
| Ví tiền tài trợ | Tình trạng chuyển tiền | `queryWalletTransfer` | Khôi phục hoạt động cấp vốn bằng cách sử dụng số đơn đặt hàng đối tác ban đầu của nó |
| Nhập giao dịch | Vào trực tiếp URL | `createEntryUrl` | Tạo SSO URL một lần cho chế độ chuyển hướng |
| Nhập giao dịch | Nhúng mã thông báo | `createEmbedToken` | Tạo mã thông báo tồn tại trong thời gian ngắn cho chế độ Trading Widget `tokenProvider` |
| Dữ liệu vĩnh viễn | Lệnh vĩnh viễn hiện tại | `listCurrentPerpetualOrders` | Truy vấn các đơn hàng NORMAL hoặc CONDITIONAL hiện tại |
| Dữ liệu vĩnh viễn | Lịch sử đặt hàng vĩnh viễn | `listPerpetualOrderHistory` | Thiết bị đầu cuối truy vấn NORMAL hoặc CONDITIONAL lệnh |
| Dữ liệu vĩnh viễn | Giao dịch vĩnh viễn | `listPerpetualTrades` | Truy vấn giao dịch điền vào danh sách người chơi công khai rõ ràng |
| Dữ liệu vĩnh viễn | Vị trí vĩnh viễn hiện tại | `listCurrentPerpetualPositions` | Truy vấn vị trí hiện tại |
| Dữ liệu vĩnh viễn | Lịch sử vị trí vĩnh viễn | `listPerpetualPositionHistory` | Truy vấn các vị trí đã đóng |
| Dữ liệu vĩnh viễn | Sổ cái tài khoản vĩnh viễn | `listPerpetualLedger` | Truy vấn hồ sơ thay đổi số dư hợp đồng cá nhân |
| Tỷ giá tham chiếu Fiat | Liệt kê các loại tiền tệ fiat được hỗ trợ | `listSupportedFiatCurrencies` | Liệt kê các loại tiền tệ pháp định hiện có thể chuyển đổi thành USDT |

| Thông tin dịch vụ | Phiên bản dịch vụ | `version` | Thông tin phiên bản dịch vụ của Tác nhân truy vấn |

## Cấu hình

Lấy các giá trị sau từ 6MM trước
tích hợp.

| Mục | Ví dụ | Sự miêu tả |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Tác nhân API cơ sở URL, không có dấu gạch chéo ở cuối |
| `agentCode` | `AGENT001` | Mã đối tác |
| `apiSecret` | `your-api-secret` | API ký bí mật. Chỉ giữ nó ở phần phụ trợ |
| `defaultCurrency` | `USDT` | Đơn vị tiền tệ mặc định, thường là `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Điểm cuối của đối tác cho lệnh gọi lại 6MM |

Khuyến nghị sản xuất:

- Sử dụng HTTPS cho điểm cuối Tác nhân API và webhook.
- Lưu trữ `apiSecret` trong trình quản lý bí mật, trung tâm cấu hình hoặc biến môi trường.
- Giữ thời gian của máy chủ được đồng bộ hóa, tốt nhất là với NTP.
- Duy trì tất cả số đơn đặt hàng của đối tác và giữ chúng duy nhất trên toàn cầu.
- Không bao giờ gửi `apiSecret` tới trình duyệt, ứng dụng, chương trình nhỏ hoặc mã nguồn giao diện người dùng.

## Trường ký tự động

Đối với các cuộc gọi Đại lý đã ký API, SDK sẽ tự động đưa vào:

| Cánh đồng | Nguồn | Sự miêu tả |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Mã đối tác |
| `timestamp` | Dấu thời gian Unix UTC hiện tại | Giây |
| `nonce` | Trình tạo ngẫu nhiên an toàn | Bảo vệ phát lại |
| `sign` | HMAC-SHA256 | Yêu cầu chữ ký |
| `currency` | `defaultCurrency` | Được điền khi yêu cầu chuyển khoản/tài khoản bỏ qua loại tiền tệ |

Nguyên tắc ký:

1. Loại trừ `sign`.
2. Loại trừ các giá trị trống.
3. Sắp xếp các khóa theo thứ tự ASCII.
4. Tham gia với tư cách `k=v&k2=v2`.
5. Tính toán hệ thập lục phân HMAC-SHA256 với `apiSecret`.

Mã doanh nghiệp thông thường không nên tính toán chữ ký hoặc đặt thủ công
`agentCode`, `timestamp`, `nonce` hoặc `sign`.
