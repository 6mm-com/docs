## Kho lưu trữ chính thức

Kho lưu trữ Java SDK là nguồn dữ liệu cho mã nguồn, ghi chú phát hành, ví dụ sử dụng và chi tiết triển khai SDK :

[6mm-com/agent-java-sdk](https://github.com/6mm-com/agent-java-sdk)

<span id="runtime" data-sixmm-canonical-anchor="runtime" aria-hidden="true"></span>

## Thời gian chạy

| Mục | Giá trị |
| --- | --- |
| Phiên bản Java tối thiểu | Java 8+ |
| Công cụ xây dựng được khuyến nghị | Maven 3.9+ |
| Nhóm Maven | `com.sixmm.exchange.sdk` |
| Hiện vật Maven | `agent` |
| Thẻ nguồn được tài liệu hóa | `v0.1.1` |

Kho lưu trữ GitHub công khai là lưu trữ nguồn, không phải kho lưu trữ phụ thuộc Maven. Xây dựng và cài đặt mã nguồn được gắn thẻ cục bộ hoặc xuất bản artifact đã được phê duyệt vào kho Maven riêng của tổ chức bạn trước khi sử dụng trong các nhóm build.

<span id="typical-backend-responsibilities" data-sixmm-canonical-anchor="typical-backend-responsibilities" aria-hidden="true"></span>

## Các trách nhiệm điển hình của backend

- Xác thực phiên người dùng đối tác.
- Ánh xạ người dùng đối tác với agentUserId.
- Bind Call trước khi giao dịch hoặc chuyển tiền lần đầu.
- Gọi createEntryUrl để được kiểm tra toàn SSOmột lần.
- Gọi createEmbedToken để Trading Widget chế độ token đối tác.
- Xác minh các webhook truyền và xử lý chúng một cách hiệu quả.

<span id="security-and-operational-rules" data-sixmm-canonical-anchor="security-and-operational-rules" aria-hidden="true"></span>

## Quy tắc an ninh và vận hành

- Lưu `apiSecret` chỉ trong một biến quản lý bí mật phía sau hoặc môi trường bảo vệ.
- Giữ thời gian máy chủ đồng bộ vì các yêu cầu đã ký có dấu thời gian.
- Xem `agentOrderNo` như một khóa idempotency bền vững và giữ cho nó duy nhất trên toàn cầu.
- Lưu `platformUserId` dưới dạng chuỗi và duy trì mối quan hệ với `agentUserId`.
- Truy vấn lần truyền gốc trước khi thử lại sau khi hết thời gian chờ hoặc kết quả mạng không chắc chắn.
