## Thời gian chạy

| Mục | Giá trị |
| --- | --- |
| Đóng gói | SixMM/Agent-SDK |
| Phiên bản PHP tối thiểu | PHP 7.4+ |
| Phiên bản PHP được đề xuất | PHP 8.1+ hoặc các phiên bản hiện được hỗ trợ |
| Các phần mở rộng bắt buộc | ext-json, ext-curl |

Nguồn gói PHP SDK và phiên bản được phê duyệt sẽ được cung cấp trong quá trình tiếp nhận đối tác. Không giả định rằng gói có sẵn từ Packagist công khai; hãy cấu hình kho Composer được cung cấp cho tổ chức của bạn.

<span id="supported-scenarios" data-sixmm-canonical-anchor="supported-scenarios" aria-hidden="true"></span>

## Các kịch bản được hỗ trợ

| Kịch bản | Phương pháp SDK |
| --- | --- |
| Liên kết người dùng | buộc |
| Chuyển khoản cố định | chuyển giao |
| Chuyển toàn bộ ra ngoài | transferAllOut |
| Chuyển ngược | mặt đảo ngược |
| Lệnh truy vấn | queryOrder |
| Tạo URL nhập | createEntryUrl |
| Xác minh Webhook | WebhookVerifier::verify |

<span id="backend-integration-rules" data-sixmm-canonical-anchor="backend-integration-rules" aria-hidden="true"></span>

## Quy tắc tích hợp backend

- Tải `apiSecret` từ một trình quản lý bí mật hoặc biến môi trường được bảo vệ.
- Giữ cho việc liên kết, truyền tải, ký và logic webhook của người dùng không xuất hiện trong mã duyệt.
- Sử dụng chuỗi thập phân cho số lượng tài sản để tránh làm tròn số thực.
- Tái sử dụng `agentOrderNo` gốc khi truy vấn kết quả truyền không chắc chắn.
- Xác minh chữ ký webhook với phần thân yêu cầu thô trước khi giải mã hoặc thay đổi nó.
