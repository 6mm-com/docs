## Phân chia trách nhiệm

| Khu vực | Chủ sở hữu | Ghi chú |
| --- | --- | --- |
| Tạo container | Giao diện đối tác | Cung cấp một phần tử hiển thị với chiều rộng và chiều cao rõ ràng. |
| Tạo iframe | Trading Widget SDK | SDK tạo và quản lý iframe. |
| Giao diện giao dịch | 6MM iframe | K-dòng, sổ lệnh, mẫu đơn đặt hàng, vị trí, lệnh và dữ liệu tài khoản đều chạy bên trong iframe. |
| Điều khiển hiển thị | Trading Widget SDK + 6MM iframe | Tiêu đề nhúng PC và mã giá dưới cùng được ẩn mặc định. Đối tác có thể sử dụng `display` để hiển thị khu vực shell hoặc ẩn các container giao dịch cấp cao. |
| Kiểm tra đăng nhập đối tác | Backend đối tác | Xác thực phiên người dùng đối tác trước khi cấp thông tin xác thực. |
| Phát hành token nhúng | Backend đối tác + API nhân viên | Khuyến nghị cho chế độ token đối tác. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Lập phiên bản

Đường dẫn tích hợp công khai vẫn ổn định dưới script v1 URL. Bộ khả năng v1 hiện tại bao gồm partner-token, tokenProvider, entryUrlProvider, điều khiển hiển thị, sự kiện vòng đời, phương thức thể hiện và sự kiện lệnh.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Khi nào nên sử dụng widget

Hãy chọn Trading Widget khi đối tác cần một giao diện giao dịch hoàn chỉnh bên trong một sản phẩm web hiện có. Thay vào đó, hãy sử dụng tài liệu REST API và WebSocket khi xây dựng và duy trì giao diện giao dịch hoàn toàn tùy chỉnh.

## Quá trình triển khai

1. Theo dõi [Trading Widget Khởi Đầu Nhanh](/vi/sdk/trading-widget/quick-start) để tải script và tạo một container hiển thị.
2. Cấu hình [xác thực token đối tác](/vi/sdk/trading-widget/authentication) thông qua backend đối tác.
3. Thêm những gì cần thiết [Tùy chọn và sự kiện](/vi/sdk/trading-widget/options-events).
4. Sử dụng [phương thức thể hiện](/vi/sdk/trading-widget/instance-methods) cho các điều khiển vòng đời và thời gian chạy.
