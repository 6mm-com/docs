## Tóm tắt phương pháp

| Phương pháp | Mục đích |
| --- | --- |
| hủy hoại() | Xóa iframe và giải phóng trình xử lý sự kiện. |
| getState() | Đọc trạng thái vòng đời SDK hiện tại. |
| whenReady() | Đợi cho đến khi iframe hoàn tất quá trình khởi tạo. |
| setSymbol(ký hiệu) | Chuyển đổi cặp giao dịch bên trong iframe. |
| setTheme(chủ đề) | Cập nhật tham số chủ đề iframe. |
| setLocale(ngôn ngữ) | Chuyển đổi ngôn ngữ iframe. |
| setSize(chiều rộng, chiều cao) | Cập nhật kích thước iframe. |
| tải lại() | Tải lại iframe hiện tại. |
| refreshAuth(lý do) | Kích hoạt luồng làm mới xác thực tiện ích. |
| setTokenProvider(nhà cung cấp) | Thay thế nhà cung cấp được sử dụng bởi chế độ mã thông báo đối tác. |
| on(sự kiện, trình xử lý) | Đăng ký các sự kiện thời gian chạy và nhận chức năng hủy đăng ký. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## hủy hoại()

Xóa iframe, xóa trình nghe và phát ra bị hủy một lần cho phiên bản hiện tại.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Đọc trạng thái vòng đời hiện tại của phiên bản widget.

```js
const state = widget.getState()
```

Các giá trị trả về bao gồm tải, xác thực, sẵn sàng, lỗi và bị hủy.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Đợi iframe hoàn tất quá trình khởi tạo trước khi chạy logic giao diện người dùng phụ thuộc.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(ký hiệu)

Chuyển đổi cặp giao dịch bên trong iframe. Nếu iframe vẫn đang khởi tạo, SDK sẽ xếp hàng lệnh và gửi nó sau khi sẵn sàng.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(chủ đề)

Cập nhật tham số chủ đề được sử dụng bởi iframe giao dịch được nhúng.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(ngôn ngữ)

Chuyển đổi ngôn ngữ iframe. Các giá trị được hỗ trợ là en, en-US và zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(chiều rộng, chiều cao)

Cập nhật kích thước iframe DOM và thông báo cho iframe về kích thước bên ngoài mới. Giá trị số được chuyển đổi thành px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## tải lại()

Tải lại iframe hiện tại và đợi nó khởi chạy lại.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(lý do)

Yêu cầu iframe làm mới luồng xác thực hiện tại. Giá trị lý do tùy chọn được chuyển tiếp để ghi nhật ký và kiểm soát luồng.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(nhà cung cấp)

Thay thế tokenProvider được sử dụng bởi chế độ mã thông báo đối tác. SDK gọi nhà cung cấp khi iframe yêu cầu mã thông báo nhúng mới.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(sự kiện, trình xử lý)

Đăng ký một sự kiện thời gian chạy. Hàm trả về sẽ loại bỏ trình nghe.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Các phương thức bổ sung trong thời gian chạy v1 hiện tại

| Phương pháp | Mục đích |
| --- | --- |
| `whenRendered()` | Đợi thông báo được hiển thị của iframe; cái này tách biệt với sẵn sàng. |
| `setPage(page)` | Yêu cầu trang sản phẩm được hỗ trợ trong phiên bản hiện tại. Nó không thay đổi môi trường quỹ. |
| `prepareForRecreate()` | Yêu cầu iframe sẵn sàng để chuẩn bị thay thế; trả lại một lời hứa và có thể từ chối nếu không có mặt, bận hoặc hết thời gian. |
| `cancelRecreate()` | Hủy luồng thay thế đang chờ xử lý/chuẩn bị. |
| `TradingWidget.validateOptions(options)` | Xác thực các tùy chọn khởi tạo trước khi tạo một phiên bản. |

Để thay đổi môi trường người dùng hoặc môi trường thực/demo, hãy hủy phiên bản cũ và tạo một phiên bản mới với chế độ và xác thực đích. Không sử dụng `setPage` làm công tắc môi trường. Kiểm tra khả năng trước khi sử dụng các phương pháp tùy chọn.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
