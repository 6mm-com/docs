<h2 id="service-endpoints">Điểm cuối dịch vụ</h2>

| Loại      | Điểm cuối              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="time-and-numeric-values">Thời gian và giá trị số</h2>

* Trừ khi được chỉ định khác, trường thời gian là dấu thời gian mili giây của Unix.
* Thống kê hàng ngày, tổng số dư và khối lượng giao dịch mặc định sử dụng ranh giới UTC ngày.
* Các trường nhạy độ chính xác như số lượng, giá cả, số lượng và tỷ lệ được truyền dưới dạng chuỗi.
* Các ID số nguyên lớn như `orderId`, `conditionId`, và `strategyId` được trả về dưới dạng chuỗi trong JSON.

<h2 id="response-format">Định dạng phản hồi</h2>

Phản hồi thành công:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Phản hồi lỗi:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Ghi chú:

* Lỗi kinh doanh thường vẫn trả về cấu trúc JSON thống nhất. Các nhà tích hợp nên kiểm tra `code` trước.
* Lỗi xác thực có thể trả về HTTP `401`; giới hạn tốc độ có thể trả về HTTP `429`.
* Bạn có thể gửi `X-Request-ID` trong phần đầu yêu cầu. Máy chủ sẽ trả về như `requestId` trong phản hồi.
