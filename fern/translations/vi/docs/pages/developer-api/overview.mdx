<h2 id="documentation-areas">Khu vực tài liệu</h2>

| Khu vực | Nội dung bao gồm |
| --- | --- |
| Thiết lập tích hợp | Địa chỉ dịch vụ, quy ước yêu cầu, hình dạng phản hồi và các chế độ truy cập. |
| Xác thực & bảo mật | JWT, quyền API Key , ký HMAC , bảo vệ phát lại và đồng bộ thời gian. |
| REST API | Các điểm cuối công khai, dữ liệu người dùng/tài khoản, lệnh, vị thế và dữ liệu thị trường. |
| WebSocket | Vòng đời kết nối, luồng thị trường công khai và luồng người dùng riêng tư. |
| Tham khảo & khắc phục sự cố | Enums, mã lỗi và các khuyến nghị tích hợp thực tế. |

<h2 id="production-checklist">Danh sách kiểm tra sản xuất</h2>

- Chỉ lưu trữ API bí mật ở phía sau.
- Đồng bộ thời gian máy chủ trước khi các yêu cầu đã ký.
- Coi tất cả các trường độ chính xác số học là chuỗi trừ khi trang có ghi rõ điều ngược lại.
- Sử dụng idempotency, ID yêu cầu và nhật ký có cấu trúc xoay quanh luồng lệnh.
- Đăng ký các luồng WebSocket cho trạng thái phải luôn cập nhật trong hệ thống vận hành.
- Xem lại mã lỗi và hành vi thử lại trước khi khởi động.
