> REST URL cơ bản: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Tài liệu này dành cho các hệ thống bên ngoài tích hợp với dịch vụ 6MM API . Nó bao gồm đăng nhập, xác thực JWT , quản lý API Key , ký API Key HMAC , truy vấn tài khoản, lệnh, vị thế, dữ liệu thị trường và luồng WebSocket .

Việc cấp phát tài khoản và chuẩn bị tài trợ được xử lý thông qua các quy trình phía nền tảng. Tài liệu này chỉ mô tả các điểm cuối API dịch vụ có thể gọi bên ngoài.

<span id="service-endpoints" data-sixmm-canonical-anchor="service-endpoints" aria-hidden="true"></span>

## Điểm cuối dịch vụ

| Loại      | Điểm cuối              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Quy trình tích hợp

Trình tự tích hợp được khuyến nghị:

1. Đăng nhập bằng tài khoản do nền tảng cung cấp và nhận `accessToken`.
2. Để truy cập lập trình phía máy chủ, tạo API Key với JWT trước, và lưu trữ an toàn `apiSecret`trả lại một lần.
3. Các truy vấn riêng tư, endpoint lệnh và endpoint vị thế có thể được gọi bằng `Authorization: Bearer <accessToken>` hoặc chữ ký API Key.
4. Đối với các luồng WebSocket riêng tư, tạo một `listenKey` trước, sau đó kết nối với `wss://ws.6mm.com/ws?listenKey=...`.
5. Dữ liệu thị trường REST các điểm cuối và kênh WebSocket công cộng không yêu cầu xác thực.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Lựa chọn xác thực

| Kịch bản                               | Phương pháp được khuyến nghị         |
| -------------------------------------- | -------------------------- |
| Hành động của người dùng frontend                  | JWT                        |
| Gọi chương trình phía máy chủ         | API Key + chữ ký HMAC   |
| API Key tạo, cập nhật và xóa | JWT                        |
| Thị trường công cộng REST / WebSocket công cộng  | Không cần xác thực |

## Phạm vi tài liệu
