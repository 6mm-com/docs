Tạo `listenKey` trước:

```http
POST /v1/private/user/listen-key
```

Ví dụ phản hồi:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "listenKey": "f57cb61ef604ce76be09e753a5dbdd8c",
    "expireAt": 1777539918867
  },
  "requestId": "req-listen-key"
}
```

`listenKey` mặc định có hiệu lực trong 60 phút. Khuyến nghị gia hạn mỗi 30 phút.

## Gia hạn

```http
PUT /v1/private/user/listen-key
Content-Type: application/json
```

```json
{ "listenKey": "f57cb61ef604ce76be09e753a5dbdd8c" }
```

<span id="close" data-sixmm-canonical-anchor="close" aria-hidden="true"></span>

## Đóng

```http
DELETE /v1/private/user/listen-key
Content-Type: application/json
```

```json
{ "listenKey": "f57cb61ef604ce76be09e753a5dbdd8c" }
```

## Kết nối với WebSocket riêng tư

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

Phương thức kết nối JWT tương thích:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Sau khi xác thực thành công, máy chủ sẽ tự động đăng ký kết nối đến kênh riêng tư của người dùng hiện tại. Không cần đăng ký thủ công.

Xác nhận xác thực thành công:

```json
{ "event": "auth", "success": true, "data": "1188041528" }
```

<span id="common-private-events" data-sixmm-canonical-anchor="common-private-events" aria-hidden="true"></span>

## Các sự kiện riêng tư phổ biến

| Sự kiện                | Mô tả                                                                   |
| -------------------- | ----------------------------------------------------------------------------- |
| `ORDER_TRADE_UPDATE` | Thay đổi trạng thái đơn hàng, bao gồm đơn hàng mới, sửa đổi, giao dịch và hủy bỏ |
| `ACCOUNT_UPDATE`     | Số dư tài khoản và thay đổi vị thế                                          |

Bao bọc tin nhắn đẩy riêng tư:

```json
{
  "topic": "user.5794",
  "ts": 1771047000000,
  "data": {
    "eventType": "ORDER_TRADE_UPDATE"
  }
}
```

REST đầu cuối truy vấn và luồng riêng tư WebSocket sử dụng các lược đồ riêng biệt. Khách hàng nên phân tích từng lược đồ độc lập và không nên giả định tên trường giống hệt nhau.

<span id="common-differences" data-sixmm-canonical-anchor="common-differences" aria-hidden="true"></span>

## Những điểm khác biệt chung

| Miền         | cánh đồng REST     | cánh đồng WebSocket                                             |
| -------------- | -------------- | ----------------------------------------------------------- |
| Tình trạng đơn hàng   | `status`       | `orderStatus`                                               |
| Số dư đóng băng | `frozenMargin` | `frozenBalance`                                             |
| Chế độ lề    | `marginMode`   | `marginMode`, trả về dưới dạng chuỗi ở vị trí và luồng |

<span id="recovery-and-reconciliation" data-sixmm-canonical-anchor="recovery-and-reconciliation" aria-hidden="true"></span>

## Phục hồi và hòa giải

- Gia hạn listenKey trước khi hết hạn và tạo  mới nếu gia hạn thất bại.
- Kết nối lại, xác thực lại và coi socket mới như một phiên sự kiện mới.
- Loại bỏ trùng lặp sự kiện trước khi thay đổi số dư đối tác hoặc bản ghi đơn hàng.
- Nếu có thể đã bỏ sót sự kiện, hãy truy vấn [orders](/vi/developer-api/rest-api/order), [positions](/vi/developer-api/rest-api/position), và [trạng thái tài khoản](/vi/developer-api/rest-api/user-and-account) qua REST.
- Làm theo [hướng dẫn kết nối và nhịp tim](/vi/developer-api/websocket/connection-subscription-and-heartbeat) để thử lại và xử lý kết nối bị trì hoãn.
