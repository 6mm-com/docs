> **Qeyd**
>
> Sifariş son nöqtələri ticarət icazəsi tələb edir.

<h2 id="place-order">Yer Sifarişi</h2>

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Parametrləri sorğu:**

| Parametr       | Tip   | Tələb olunur               | Təsvir                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Bəli                    | Simvol                                                                                                                        |
| `type`          | string | Bəli                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Bəli                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Xeyr                     | `BOTH` / `LONG` / `SHORT`, standart `BOTH`                                                                                     |
| `price`         | string | Şərti tələb olunur | Limit əmrləri üçün tələb olunur                                                                                                     |
| `quantity`      | string | Şərti tələb olunur | Kəmiyyət. `closePosition=true` zaman çıxarıla bilər                                                                            |
| `timeInForce`   | string | Xeyr                     | `GTC` / `IOC` / `FOK`, standart `GTC`                                                                                          |
| `reduceOnly`    | bool   | Xeyr                     | Yalnız azaldılmış, standart `false`                                                                                                  |
| `makerOnly`     | bool   | Xeyr                     | Yalnız Maker-də, standart `false`                                                                                                   |
| `closePosition` | bool   | Xeyr                     | Bütün mövqeyi bağla, standart `false`                                                                                    |
| `clientOrderId` | string | Xeyr                     | Müştəri tərəfindən təyin olunan sifariş ID-si                                                                                                       |
| `placeType`     | string | Xeyr                     | Sifariş yerləşdirmə tipli marker                                                                                                   |
| `priceType`     | int32  | Xeyr                     | BBO qiymət növü: `0` göstərilən qiymət, `1` rəqibin qiyməti 1, `2` rəqibin qiyməti 5, `3` eyni tərəfin qiyməti 1, `4` eyni tərəfin qiyməti 5 |

**Nümunə istəyi:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Cavab sahələri:**

| Sahə           | Tip   | Təsvir             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | Server sifariş ID-si         |
| `clientOrderId` | string | Müştəri tərəfindən təyin olunan sifariş ID-si |
| `status`        | string | Orden statusu            |
| `timestamp`     | int64  | Zaman möhürü               |

<h2 id="batch-place-orders">Toplu Yer Sifarişləri</h2>

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Tələb bədəni:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Cavab sahələri:**

| Sahə          | Tip  | Təsvir                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Uğurlu sifarişlərin sayı |
| `failedCount`  | int32 | Uğursuz əmrlərin sayı     |
| `results[]`    | array | Hər sifariş üçün nəticə       |

<h2 id="place-condition-order">Yer Şərti Sırası</h2>

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Parametrləri sorğu:**

| Parametr       | Tip   | Tələb olunur               | Təsvir                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Bəli                    | Simvol                                                                                      |
| `type`          | string | Bəli                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Bəli                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Xeyr                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Şərti tələb olunur | `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` üçün tələb olunur                                             |
| `quantity`      | string | Şərti tələb olunur | Kəmiyyət. `closePosition=true` zaman çıxarıla bilər                                          |
| `timeInForce`   | string | Xeyr                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Xeyr                     | Yalnız azaldılmış                                                                                 |
| `clientOrderId` | string | Xeyr                     | Müştəri tərəfindən təyin olunan sifariş ID-si                                                                     |
| `stopPrice`     | string | Şərti tələb olunur | Tetik qiyməti                                                                               |
| `workingType`   | string | Xeyr                     | `MARK_PRICE` / `CONTRACT_PRICE`, standart `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Xeyr                     | Qiymət qorunmasının aktiv olub-olmaması                                                         |
| `activatePrice` | string | Şərti tələb olunur | Trailing order aktivləşdirmə qiyməti                                                             |
| `callbackRate`  | string | Şərti tələb olunur | Trailing order geri çağırış sürəti                                                                |
| `closePosition` | bool   | Xeyr                     | Bütün mövqeyi bağla                                                                   |

**Cavab sahələri:**

| Sahə             | Tip   | Təsvir            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | Şərt sırası ID-si     |
| `conditionStatus` | string | Şərt sifarişi statusu |
| `timestamp`       | int64  | Zaman möhürü              |

<h2 id="place-strategy-order">Yerləşmə Strategiyası Sırası</h2>

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Parametrləri sorğu:**

| Parametr      | Tip   | Tələb olunur | Təsvir             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Bəli      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Bəli      | Alt-sıra siyahısı          |

`subOrderList[]`-də sahələr əsasən normal əmrlər və şərt sıraları ilə eynidir, əlavə asılılıq sahələri ilə:

| Parametr        | Tip   | Təsvir                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | Alt-sıra ID-si                                    |
| `firstDrivenId`  | int64  | Birinci sürücülük sifarişi ID. `0` o deməkdir ki, asılılıq yoxdur |
| `firstDrivenOn`  | string | Birinci tetik şərti                         |
| `firstTrigger`   | string | İlk tetik hərəkəti                            |
| `secondDrivenId` | int64  | İkinci sürücülük sifarişi ID-si                         |
| `secondDrivenOn` | string | İkinci tetik şərti                        |
| `secondTrigger`  | string | İkinci tətik hərəkəti                           |

**Cavab sahələri:**

| Sahə            | Tip   | Təsvir     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | Strategiya ID-si     |
| `strategyStatus` | string | Strategiya statusu |
| `timestamp`      | int64  | Zaman möhürü       |

<h2 id="query-single-order">Sorğu Tək Sıra</h2>

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Parametrləri sorğu:**

| Parametr       | Tip   | Tələb olunur | Təsvir             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Bəli      | Simvol                  |
| `orderId`       | string | Xeyr       | Server sifariş ID-si         |
| `clientOrderId` | string | Xeyr       | Müştəri tərəfindən təyin olunan sifariş ID-si |

Ən azı `orderId` və `clientOrderId` biri təmin edilməlidir. Əgər hər ikisi təmin olunubsa, server hər iki şərtdə dəqiq uyğunluq tətbiq edir.

<h2 id="cancel-order">Ləğv Sifarişi</h2>

<h2 id="cancel-all">Hamısını ləğv et</h2>

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Parametrləri sorğu:**

| Parametr    | Tip   | Tələb olunur | Təsvir                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Xeyr       | Simvol                                                                              |
| `cancelType` | int32  | Xeyr       | `0` bütün normal əmrlər `1` limit əmrləri `2` bütün şərt əmrləri. Standart `0` |

Normal sifarişlər üçün ləğv etmə asinxron şəkildə qəbul edilir. Son status WebSocket `ORDER_TRADE_UPDATE` və ya sorğu son nöqtələrinə görə müəyyən edilməlidir.
