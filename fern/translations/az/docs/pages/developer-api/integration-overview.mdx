> REST Baza URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Bu sənədləşmə 6MM API xidməti ilə inteqrasiya olunmuş xarici sistemlər üçün nəzərdə tutulub. Bu proqram giriş, JWT autentifikasiya, API Key idarəetmə, API Key HMAC imzalama, hesab sorğuları, sifarişlər, mövqelər, bazar məlumatları və WebSocket axınlarını əhatə edir.

Hesab təminatı və maliyyələşdirmənin hazırlanması platforma tərəfi prosesləri vasitəsilə həyata keçirilir. Bu sənədləşmə yalnız xaricdən çağırıla bilən API xidmət son nöqtələrini təsvir edir.

<h2 id="service-endpoints">Xidmət Son Nöqtələri</h2>

| Tip      | Son nöqtə              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="integration-flow">İnteqrasiya Axını</h2>

Tövsiyə olunan inteqrasiya ardıcıllığı:

1. Platformanın təqdim etdiyi hesabla daxil olun və `accessToken`alın.
2. Server tərəfi proqramatik giriş üçün JWT ilə API Key yaradın və bir dəfəlik qaytarılan `apiSecret`təhlükəsiz saxlayın.
3. Şəxsi sorğular, sifariş və mövqe endpoint-ləri ya `Authorization: Bearer <accessToken>`, ya da API Key imzası ilə çağırıla bilər.
4. Özəl WebSocket axınları üçün əvvəlcə `listenKey` yaradın, sonra `wss://ws.6mm.com/ws?listenKey=...`-ə qoşulun.
5. Bazar məlumatları REST son nöqtələr və ictimai WebSocket kanalları autentifikasiya tələb etmir.

<h2 id="authentication-choice">Autentifikasiya Seçimi</h2>

| Ssenari                               | Tövsiyə olunan üsul         |
| -------------------------------------- | -------------------------- |
| Ön tərəf istifadəçi əməliyyatları                  | JWT                        |
| Server tərəfi proqramatik çağırışlar         | API Key + HMAC imzası   |
| API Key yaradılması, yenilənməsi və silinməsi | JWT                        |
| İctimai bazar REST / ictimai WebSocket  | Autentifikasiya tələb olunmur |
