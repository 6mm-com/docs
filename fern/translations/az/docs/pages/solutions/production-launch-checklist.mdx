İstehsal istifadəçilərinə 6MMticarət axınlarını təqdim etməzdən əvvəl bu yoxlama siyahısından istifadə edin. Bu, məhsul, mühəndislik, əməliyyatlar, risk və dəstək komandalarının birlikdə nəzərdən keçirməsi üçün nəzərdə tutulub.

<h2 id="launch-checklist">Buraxılış siyahısı</h2>

| Ərazi | Yoxlama siyahısı |
| --- | --- |
| Məhsul | Giriş nöqtələri, istifadəçi mətni, risk sorğuları, dil əhatəsi və dəstək yolları hazırdır. |
| Backend | API etimadnamələr, imzalama, token buraxılışı, veb hooklar, təkrar qeydlər və qeydiyyat tətbiq olunur. |
| Ticarət | Sifariş, transfer, mövqe, marja, komissiya və likvidasiya davranışı nəzərdən keçirilib. |
| Təhlükəsizlik | Sirlər, giriş rolları, monitorinq, insidentlərə cavab və audit qeydləri hazırlanır. |
| Əməliyyatlar | Dəstək iş axınları, eskalasiya yolları, uzlaşdırma və gündəlik monitorinq təyin olunur. |

<h2 id="recommended-sequence">Tövsiyə olunan ardıcıllıq</h2>

1. Tam sandbox və ya daxili mühit təsdiqi.
2. Giriş, giriş, transfer, ticarət və dəstək üçün istifadəçi səyahətlərini başdan sona keçirin.
3. Monitorinq və insidentə cavab sahibliyini təsdiqləyin.
4. İctimai nüsxə, lokalizasiya olunmuş aktivlər və resurs yükləmələrini təsdiqləyin.
5. Geniş təbliğatdan əvvəl nəzarətli buraxılış pəncərəsi ilə başlayın.

<h2 id="after-launch">Buraxılışdan sonra</h2>

İlkin buraxılış dövründə hər gün fəaliyyəti nəzərdən keçirin. Giriş konversiyasını, token buraxılışında uğursuzluqları, sifariş səhvlərini, yayılma keyfiyyətini, transferin tamamlanmasını, webhook təkrarlarını və dəstək biletlərini birlikdə izləyin.
