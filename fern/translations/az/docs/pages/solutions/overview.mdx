<h2 id="core-solution-lines">Əsas həll xətləri</h2>

<CardGroup cols={2}>
<Card title="Embedded API / SDK Ticarət Sistemi" icon="fa-duotone fa-window" href="/az/solutions/embedded-trading">
Mövcud tətbiqə, cüzdana, brokerə, trafik platformasına və ya biznes sisteminə APIs və SDKsvasitəsilə daimi ticarət imkanları əlavə edin.
</Card>
<Card title="İnstitusional Likvidlik Həlləri" icon="fa-duotone fa-water" href="/az/solutions/institutional-liquidity">
Ticarət məkanlarını və tərəfdaş platformalarını daha dərin likvidlik, avtomatlaşdırılmış bazar yaradılması və riskə uyğun likvidlik əməliyyatları ilə birləşdirin.
</Card>
<Card title="Ağ Etiketli Mübadilə Sistemi" icon="fa-duotone fa-store" href="/az/solutions/white-label-exchange">

</Card>
<Card title="Uyğunluq Lisenziyalaşdırılması və Məsləhət" icon="fa-duotone fa-scale-balanced" href="/az/solutions/compliance-licensing">

</Card>
</CardGroup>

<h2 id="how-the-solutions-connect">Həllər necə birləşir</h2>

Əksər tərəfdaş tətbiqləri bir neçə 6MM qabiliyyətini birləşdirir. Ağ etiketli birja institusional likvidlik, uyğunluq dəstəyi və API inteqrasiyalarından istifadə edə bilər. Daxili ticarət tərəfdaşı Trading Widget SDK ilə başlaya bilər və sonradan backend Agent SDK axınları, webhook emalı və əməliyyat resursları əlavə edə bilər.
