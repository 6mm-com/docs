Tərəfdaş resursları mövcud məhsula 6MM ticarət imkanlarını inteqrasiya etmək, ağ etiketli mübadilə başlatmaq və ya əməliyyat materiallarını istehsal üçün hazırlayan komandalar üçün hazırlanır.

<h2 id="resource-areas">Resurs sahələri</h2>

<CardGroup cols={2}>
<Card title="Brend və Aktivlər" icon="fa-duotone fa-palette" href="/az/resources/brand-assets/usage-guidelines">
Təsdiqlənmiş 6MM vizual aktivlərdən, giriş bannerlərindən, kart aktivlərindən və ağ etiketli material tövsiyələrindən istifadə edin.
</Card>
<Card title="Buraxılış Materialları" icon="fa-duotone fa-rocket" href="/az/resources/production-launch-checklist">
İstehsalın işə salınma yoxlamalarını, inteqrasiya məlumatlarını və dəstək təhvil detalları hazırlamaq.
</Card>
<Card title="Aktiv Yükləmələri" icon="fa-duotone fa-folder-arrow-down" href="/az/resources/brand-assets/asset-downloads">
Loqo, banner, kart girişi və ağ etiketli aktiv paketlərini yükləyin.
</Card>
<Card title="Dəstək Sorğusu Şablonu" icon="fa-duotone fa-message-question" href="/az/resources/support-request-template">
İnteqrasiya, ticarət və ya istehsal problemlərini bildirərkən ardıcıl formatdan istifadə edin.
</Card>
</CardGroup>

<h2 id="when-to-use-this-section">Bu bölməni nə vaxt istifadə etmək lazımdır</h2>

| Ssenari | Tövsiyə olunan səhifə |
| --- | --- |
| Tətbiqə və ya veb səhifəyə 6MM ticarət girişi əlavə edin | İstifadə Qaydaları |
| Loqo, banner və ya kart giriş faylları lazımdır | Aktiv Yükləmələri |
| Tərəfdaş brendli buraxılışa hazırlaşın | Ağ etiketli dəstək |
| Testdən istehsala keçid | İstehsalın Başlanğıcı Yoxlama Siyahısı |
| Problemi araşdırmaq üçün 6MM dəstəyə müraciət edin | Dəstək Sorğusu Şablonu |
