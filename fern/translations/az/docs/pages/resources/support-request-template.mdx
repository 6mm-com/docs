Dəstəyə müraciət edərkən, mövcud olduqda aşağıdakı məlumatı daxil edin.

<h2 id="required-context">Tələb olunan kontekst</h2>

| Sahə | Nümunə |
| --- | --- |
| Ətraf mühit | İstehsal və ya səhnələşdirmə |
| Təsirlənmiş modul | Trading Widget, Agent SDK, REST API, WebSocket, webhook, ağ etiket sistemi |
| Zaman aralığı | UTC buraxılışın baş verdiyi zaman möhürü aralığı |
| Tərəfdaş istifadəçi ID-si | Əgər əlaqəlidirsə, tərəfdaş tərəfi istifadəçi identifikatoru |
| 6MM xəritələmə ID-si | agentUserId, sifariş ID, sorğu ID və ya webhook hadisə ID-si |
| Biznesə təsir | Təsirlənmiş istifadəçilərin və ya əməliyyatların sayı və problemin davam edib-etməməsi |

<h2 id="description-format">Təsvir formatı</h2>

-Nə baş verib?
- Nə olacağını gözləyirdin?
- Təkrarlana bilərmi?
- Son vaxtlar nə dəyişdi?
- Problem hələ də davam edir?

<h2 id="attachments">Əlavələr</h2>

- Müvafiq sorğu və cavab qeydləri.
- Ekran görüntüləri və ya ekran yazıları.
- Webhook yükü və imza başlıqları.
- Trading Widget problemlər üçün brauzer konsol xətaları.

<h2 id="copyable-template">Kopyalana bilən şablon</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Əlaqəsi olmayan sahələri silin, amma UTC zaman aralığını və mümkün olduqda ən azı bir axtarıla bilən sorğu və ya biznes identifikatorunu saxlayın.

<h2 id="redact-sensitive-data">Həssas məlumatları redaktə et</h2>

Göndərməyin:

- Şifrələr və ya tam giriş tokenləri
- API sirləri, şəxsi açarları və ya tam imzaları
- Sessiya kukiləri
- Tam ödəniş, şəxsiyyət və ya digər lazımsız şəxsi məlumatlar

Sahə adını və qısa prefiksi və ya sonluğu yalnız dəstək təmizlənmiş dəyərləri ayırd etməli olduqda saxlayın.
