Aydın məsuliyyət modeli əməliyyat riskini azaldır və dəstək komandalarının daha sürətli reaksiya verməsinə kömək edir.

<h2 id="responsibility-split">Məsuliyyətin bölüşdürülməsi</h2>

| Ərazi | 6MM | Tərəfdaş |
| --- | --- | --- |
| Ticarət infrastrukturu | Uyğunlaşdırma, risk, ticarət mühərriki, API və SDK imkanları | Düzgün inteqrasiya və istehsal monitorinqi |
| Son istifadəçi əlaqəsi | Birbaşa müştəri əlaqəsi yoxdur, yalnız ayrı-ayrılıqda razılaşdırılıbsa | İstifadəçi işə salınması, dəstək, açıqlamalar və hesabın həyat dövrü |
| Sirlər və sənədlər | Etimadnamə modeli və imzalama tələblərini təmin edir | Sirləri təhlükəsiz saxlayır və daxili girişi məhdudlaşdırır |
| Webhooks | İmzalanmış həyat dövrü hadisələri göndərir | İmzaları təsdiqləyir və hadisələri idempot şəkildə emal edir |
| Uyğunluq əməliyyatları | Uyğunluq yönümlü texnologiya və dəstək materialları təmin edir | Yerli öhdəlikləri və istifadəçiyə yönəlmiş tələbləri təsdiqləyir |
| İnteqrasiya buraxılışları | Sənədləşdirilmiş platforma və inteqrasiya imkanlarını saxlayır | Buraxılışdan əvvəl tərəfdaş kodu, konfiqurasiya və istifadəçi səyahətlərini test edir |
| Hadisələrin idarə olunması | Müvafiq 6MM infrastrukturunu araşdırır və tərəfdaş dəstək kanalları təqdim edir | İstifadəçiyə yönəlmiş təsiri aşkar edir, sübutları qoruyur, tərəfdaş sistemləri ehtiva edir və eskalasiya edir |

<h2 id="responsibilities-by-lifecycle">Həyat dövrü üzrə məsuliyyətlər</h2>

| Səhnə | Tərəfdaş fəaliyyəti |
| --- | --- |
| Dizayn | İstifadəçi mülkiyyətini, aktiv axını, məlumat axını, dəstək modelini və hədəf yurisdiksiyalarını müəyyən edin. |
| Tikinti | Arxa planda sirləri saxlayın, dəstəklənən autentifikasiyanı tətbiq edin və biznes identifikatorlarını qoruyun. |
| Test | Vaxt aşağı, təkrar cəhd, dublikat-webhook, müddəti bitmiş token və uğursuzluq ssenarilərini tətbiq edin. |
| Buraxılış | Hazırlıq yoxlamasını tamamla, monitorinq qur və dəstəyin eskalasiyasını sənədləşdir. |
| İşləmə | Xəbərdarlıqları nəzərdən keçirin, anormal əməliyyatları uzlaşdırın, etimadnamələri rotasiya edin və audit sübutlarını saxlayın. |
| Hadisə | Tərəfdaş tərəfindən idarə olunan sistemləri saxlayın, etimadnamələri qoruyun, UTC zaman cədvəllərini qoruyun və düzgün 6MM kanalı ilə əlaqə saxlayın. |

<h2 id="handoff-checklist">Əməliyyat təhvil siyahısı</h2>

- İnteqrasiya sağlamlığı, təhlükəsizlik, uyğunluq və son istifadəçi dəstəyi üçün sahibin adını çəkin.
- İstehsal bazası URL-lərini, etimadnamə sahiblərini və rotasiya prosedurlarını sənədləşdirin.
- Təsdiqləmə, sifariş, ötürmə və veb hook uğursuzluqları üçün panelləri və xəbərdarlıqları təsdiqləyin.
- Axtarıla bilən loglarda sorğu ID-lərini, tərəfdaş sifariş nömrələrini və tədbir ID-lərini saxlamaq.
- Hansı hadisələrin dərhal eskalasiya tələb etdiyini müəyyən edin.
- [Dəstək Sorğu Şablonu](/az/resources/support-request-template) əməliyyat komandası üçün əlçatan saxlayın.
