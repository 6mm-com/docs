Bu 6MM Agent SDK tərəfdaş arxa plan xidmətləri üçündür ki, onlar imtiyazlı Agent APIs çağırmalıdırlar, imzalama və sorğu idarəsini sıfırdan həyata keçirmədən. O, brauzer, mobil və ya ictimai masaüstü kodunda işləməməlidir, çünki inteqrasiya tərəfdaş API sirrindən istifadə edir.

<h2 id="when-to-use-the-agent-sdk">Nə vaxt istifadə Agent SDK</h2>

Backend-iniz tərəfdaş istifadəçini bağlamaq, aktivləri təsdiqlənmiş iş axınından keçirmək, ticarət qeydlərini sorğulamaq, daxili ticarət girişi yaratmaq URLvə ya webhook bildirişlərini yoxlamaq lazım olduqda Agent SDK istifadə edin. Tərəfdaş frontend-in ticarət interfeysini göstərməsi lazım olduqda [Trading Widget SDK](/az/sdk/trading-widget/overview) ayrıca istifadə edin.

<h2 id="common-configuration">Ümumi konfiqurasiya</h2>

| Açar | Nümunə | Təsvir |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Agent API xidmət URL slash izləmədən. |
| agentCode | AGENT001 | Tərəfdaş agent kodu. |
| apiSecret | sənin-api-sirrin | API imza sirri yalnız arxa planda saxlanılır. |
| defaultCurrency | USDT | Transfer və hesab üçün standart valyuta APIs. |
| webhookUrl | https://partner.example.com/6mm/webhook | Webhook bildirişləri 6MM tərəfdaş endpoint. |

<h2 id="typical-integration-flow">Tipik inteqrasiya axını</h2>

1. Tərəfdaş ön tərəf istifadəçini tərəfdaşın öz hesab sistemi vasitəsilə autentifikasiya edir.
2. Tərəfdaş backend istifadəçini sabit tərəfdaş tərəf identifikatoruna xəritələndirir.
3. Backend `agentCode` ilə Agent SDK və qorunan API sirrini çağırır.
4. SDK imzalayır və Agentə API xahişi göndərir.
5. Backend geri qaytarılan biznes identifikatorunu saxlayır və sonrakı vebhookları idempotent şəkildə işləyir.
6. Ön tərəf yalnız ehtiyac duyduğu qısa müddətli nəticə və ya giriş məlumatını alır.

<h2 id="production-checklist">İstehsal yoxlama siyahısı</h2>

- `apiSecret` arxa planda gizli menecerdən yüklən, mənbə kodundan yox.
- İnkişaf, səhnələşdirmə və istehsal keyfiyyətlərini ayrı saxlayın.
- Sabit tərəfdaş istifadəçi xəritələşdirməsi və unikal biznes sifariş identifikatorlarından istifadə etmək.
- Vaxtaşırı sorğunun statusunu yoxlayarkən orijinal identifikatoru qoruyun.
- Webhook imzalarını yoxlamaq və işlənmiş hadisə ID-lərini saxlamaq.
- Loglardan sirləri və imzaları redaktə etmək, dəstək üçün sorğu ID-lərini saxlamaq.
