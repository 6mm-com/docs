<h2 id="install">Quraşdırma</h2>

İctimai SDK mənbə hazırda `v0.1.1` bu Maven koordinatları ilə işarələyir:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

GitHub Maven asılılıq anbarı kimi fəaliyyət göstərmir. Asılılığı həll etməzdən əvvəl etiketlənmiş mənbəni lokal olaraq quraşdırın:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Komanda quruluşları**
>
> Təsdiqlənmiş artefaktı CI, test və istehsal quruluşları üçün təşkilatınızın Maven deposunda dərc edin. İstehsal yerləşdirilmədən əvvəl təsdiqlənmiş versiyanı 6MM ilə təsdiqləyin.

Mənbə kodu və istifadə nümunələri rəsmi Java SDK repozitoriyasında mövcuddur:

[6mm-com/agent-java-sdk](https://github.com/6mm-com/agent-java-sdk)

<h2 id="before-you-start">Başlamazdan əvvəl</h2>

- İstehsal agentini təsdiqlə, API baza URL 6MM komandası ilə.
- apiSecret yalnız arxa planda gizli idarəetmədə saxla.
- platformUserId ilə agentUserIdarasında sabit xəritələşdirmə hazırla.
- Bağlama, ötürmə, sifariş və webhook axınları ətrafında strukturlaşdırılmış logları aktiv etmək.

<h2 id="initialize-client">Müştərini başlat</h2>

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Yalnız backend**
>
> Brauzer, mobil və ya masaüstü müştəri kodundan Agent SDK başlatmayın. SDK imtiyazlı Agent API tələblərini imzalayır.

<h2 id="example-transfer-funds-in">Nümunə: vəsaitlərin köçürülməsi</h2>

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Hər transfer sorğusu üçün unikal tərəfdaş tərəfli sifariş nömrəsi istifadə edin. Əgər sorğu vaxt aşırsa, yeni sifariş yaratmadan əvvəl orijinal sifarişi sorğulayın.
