<h2 id="install">Quraşdırma</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Paketə giriş**
>
> 6MM tərəfdaşın işə salınması zamanı təsdiqlənmiş Composer paket adı, repozitoriyası və versiyasını təqdim edir. Paketin ictimai Packagist-də mövcud olduğu qəbul edilməməlidir.

<h2 id="before-you-start">Başlamazdan əvvəl</h2>

- Agent API baza URL 6MMilə təsdiqlə.
- Mühit dəyişənlərindən və ya gizli idarəetmədən apiSecret yükləmək.
- SDK istifadəni yalnız arxa xidmət daxilində saxlayın.
- Transfer və webhook axınları üçün idempotent idarəetməni hazırlamaq.

<h2 id="initialize-client">Müştərini başlat</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Yalnız backend**
>
> PHP SDK Agent API sorğularını imzalayır və ictimai mənbə kodu və ya frontend icra mühitləri vasitəsilə ifşa edilməməlidir.

<h2 id="example-transfer-funds-in">Nümunə: vəsaitlərin köçürülməsi</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Məbləğlər üçün onluq sətirlərdən istifadə edin və transfer statusunu yenidən yoxlayarkən və ya sorğu aparanda orijinal agentOrderNo saxlayın.
