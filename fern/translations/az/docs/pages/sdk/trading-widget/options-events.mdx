<h2 id="options">Seçimlər</h2>

| Sahə | Tip | Default | Qeydlər |
| --- | --- | --- | --- |
| baseUrl | string | SDK yazı mənşəyi | iframe domeni. Tərəfdaş səhifələrində açıq şəkildə ötür. |
| Simvol | string | BTCUSDT | Böyük hərflərə və zolaqlara normallaşdırılıb - / _. |
| Mövzu | qaranlıq \| İşıq | qaranlıq | İlkin tema parametri. |
| Məkan | en \| en-US \| zh-CN | Brauzer/standart | İngilis və Sadələşdirilmiş Çin dili dəstəklənir. |
| Düzülüş | default \| kompakt | Default | Rezerv edilmiş düzülüş seçimi. |
| Ekran | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Daxili qabıq sahələrini və yüksək səviyyəli ticarət konteynerlərini idarə edir. |
| Autentifikasiya | object | Heç biri | Yeni SSO inteqrasiyaları üçün partner-token-dən istifadə edin. |

<h2 id="display-controls">Ekran idarəetmələri</h2>

`display` yerləşdirilmiş ticarət səhifəsi qabığını və yüksək səviyyəli konteynerləri idarə edir. Tərəfdaş yerləşdirmələrdə PC başlığı və aşağı bazar tickeri standart olaraq gizlədilir.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Sahə | Tip | Default | Qeydlər |
| --- | --- | --- | --- |
| showHeader | boolean | yalançı | PC embed header-in iframe-in içində göstərilib-göstərilməməsi. |
| showTicker | boolean | yalançı | Aşağı bazar tickerini embed shell-də göstərmək lazımdırmı? |
| gizli | String[] | [] | Yüksək səviyyəli konteynerləri ticarət səhifəsində gizlədir. |

Dəstəklənən `display.hidden` dəyərləri:

| Dəyər | Konteyner |
| --- | --- |
| Çart | Xəritə konteyneri |
| orderBook | Sifariş kitabı konteyneri |
| orderForm | Sifariş forması paneli |
| Vəzifələr | Aşağı mövqelər və açıq sifarişlər paneli |
| Hesabat | Hesab aktivləri konteyneri |

`display.hidden` yalnız bütün konteynerləri gizlədir. O, fərdi düymələri, sahələri və ya alətləri konteynerin içində gizlətmir. Cari baxış pəncərəsinə uyğun gəlməyən dəyərlər nəzərə alınmır.

<h2 id="events">Tədbirlər</h2>

| Tədbir | Trigger |
| --- | --- |
| Hazır | iFrame ilkinləşdirməsi tamamlandı. |
| səhv | SDK, iframe və ya autentifikasiya xətası. |
| state_changed | SDK həyat dövrü vəziyyəti dəyişdi. |
| auth_state_changed | tərəfdaş-token autentifikasiya vəziyyəti dəyişdirildi. |
| symbol_changed | Əsl iframe simvolu dəyişdi. |
| locale_changed | Əsl iframe yeri dəyişdi. |
| order_created | İstifadəçi iframe daxilində bir sifariş yaratdı. |
| order_failed | Sifariş göndərilməsi uğursuz oldu. |
| Məhv edildi | SDK hadisə məhv edildi. |
