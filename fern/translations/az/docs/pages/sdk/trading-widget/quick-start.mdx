Trading Widget SDK 6MM ticarət interfeysini tərəfdaşın mülkiyyətində olan veb səhifəyə yerləşdirir. Ən sürətli inteqrasiya görünən konteyner, istehsal SDK skripti və `TradingWidget.create()`çağırışı tələb edir.

<h2 id="before-you-start">Başlamazdan əvvəl</h2>

- Nümunəni resursları yükləyə bilən veb səhifədən işə salın `https://app.6mm.com`.
- Widget konteynerinə açıq şəkildə en və hündürlük verin.
- Zəng etməzdən əvvəl SDK yüklə `TradingWidget.create()`.
- İstehsalda hesab və ya ticarət funksiyalarını aktivləşdirməzdən əvvəl [autentifikasiya axını](/az/sdk/trading-widget/authentication) planlamaq.

<h2 id="minimal-example">Minimal nümunə</h2>

```html
<div id="trading-widget" style="width: 100%; height: 720px"></div>

<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
<script>
  const widget = TradingWidget.create('#trading-widget', {
    baseUrl: 'https://app.6mm.com',
    symbol: 'BTCUSDT',
    theme: 'dark',
    locale: 'en',
    layout: 'default',
    display: {
      showHeader: false,
      showTicker: false,
      hidden: [],
    },
    onReady(event) {
      console.log('ready', event)
    },
    onError(error) {
      console.error('error', error)
    },
  })
</script>
```

İnteqrasiya uğurlu olduqda, SDK `#trading-widget` daxilində iframe yaradır və `onReady`çağırır. İnkişaf zamanı `onError` tutur ki, konfiqurasiya və yükləmə uğursuzluqları görünsün.

<h2 id="sdk-urls">SDK URL-lər</h2>

| Ətraf mühit | Ssenari URL |
| --- | --- |
| İstehsal | https://app.6mm.com/sdk/trading-widget/v1/index.js |

> **Açıq şəkildə baseUrl et**
>
> Tərəfdaşlara məxsus səhifələrdən test edərkən, iframe həmişə 6MM Web domeninə işarə etməsi üçün baseUrl ötürün.

<h2 id="display-controls">Ekran idarəetmələri</h2>

Tərəfdaş yerləşdirmələr standart olaraq PC başlığını və aşağı bazar tickerini gizlədir. Shell sahələrini göstərmək və ya yüksək səviyyəli konteynerləri yerləşdirilmiş ticarət səhifəsində gizlətmək lazım olduqda `display` istifadə edin.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['account'],
}
```

<h2 id="container-size">Konteyner ölçüsü</h2>

| Səth | Tövsiyə olunan minimum |
| --- | --- |
| Masaüstü | 1024 x 720 |
| Mobil | 390 x 700 |

Cavabdeh düzülüşlər üçün eni axıcı saxlayın və hər breakpoint üçün uyğun minimum hündürlük təyin edin. Sıfır hündürlüyə malik konteyner SDK uğurla yükləyə bilər və ticarət interfeysini görünməz saxlaya bilər.

<h2 id="verify-the-integration">İnteqrasiyanı yoxlayın</h2>

1. SDK skriptinin brauzer şəbəkə panelində uğurla qayıtdığını təsdiqləyin.
2. iframe işə düşdükdən sonra `onReady` atəş açdığını təsdiqləyin.
3. Konfiqurasiya olunmuş `symbol`, `locale`, mövzu və gizli bölmələri yoxlayın.
4. Səhifəni masaüstü və mobil fasilə nöqtələri arasında ölçüsünü dəyişin.
5. Buraxılışdan əvvəl istehsal olunmayan istifadəçi ilə autentifikasiya olunmuş testi tamamlayın.

<h2 id="common-issues">Ümumi problemlər</h2>

| Symptom | Nəyi yoxlamaq lazımdır |
| --- | --- |
| Boş vidjet sahəsi | Konteynerin görünən eni və hündürlüyü olduğunu təsdiqləyin. |
| `TradingWidget` müəyyən olunmayıb | Yaradılma çağırışından əvvəl v1 skriptinin yükləndiyini təsdiqləyin. |
| Yanlış səhifə və ya mühit | `baseUrl` açıq təyin edin və konfiqurasiya olunmuş mühiti yoxlayın. |
| Hazır hadisə heç vaxt atəş açmır | Bloklanmış iframe və ya skript sorğularını `onError` tutun və yoxlayın. |
| Hesab məlumatları mövcud deyil | Dəstəklənən vidjet autentifikasiya axınını tamamla. |
