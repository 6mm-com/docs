Agent SDK sorğular sirr API tərəfdaşla təsdiqlənir. Bu sirri etibarlı backend xidmətində saxlayın və imkan olduqca SDK imza sahələri yaratsın.

> **İki imzalama protokolu**
>
> Agent SDK imzalama çeşidlənmiş sorğu sahələri, saniyəyə əsaslanan zaman möhürü və nonce istifadə edir. Birbaşa İnkişaf etdirici API sorğuları [Request Signing](/az/developer-api/request-signing) bölməsində təsvir olunan ayrıca prosesdən istifadə edir. Bir yük formatını digərinə təkrar istifadə etməyin.

<h2 id="signing-rule">İmza qaydası</h2>

Agent SDK istəklər üçün:

1. `sign` sahəsini istisna edin.
2. Boş dəyərli sahələri çıxarın.
3. Qalan sahə adlarını ASCII ardıcıllıqla sıralayın.
4. Sahələri `k=v&k2=v2`kimi birləşdirin.
5. HMAC-SHA256 onaltılıq imzanı `apiSecret`ilə hesablayın.

SDK bu dəyəri göndərdiyi eyni məlumatlardan qurmalıdır. İmza yaradıldıqdan sonra imzalanmış sahənin dəyişdirilməsi doğrulamanın uğursuzluğuna səbəb olur.

<h2 id="sdk-managed-fields">SDK- idarə olunan sahələr</h2>

| Sahə | Mənbə | Təsvir |
| --- | --- | --- |
| agentCode | SDK konfiqurasiyası | Tərəfdaş agent kodu. |
| Zaman möhürü | Cari server vaxtı | Unix zaman möhürü saniyələrlə. |
| nonce | Təhlükəsiz təsadüfi dəyər | Replay-protection təsadüfi sətir. |
| İşarə | HMAC-SHA256 | İmza tələb olunur. |
| Valyuta | Standart valyuta | Köçürmə/hesab APIs valyutanı çıxaranda istifadə olunur. |

<h2 id="secret-storage">Gizli saxlama</h2>

- Backend gizli menecerindən və ya qorunan runtime konfiqurasiyasından `apiSecret` yükləmək.
- Sirri heç vaxt frontend paketlərində, mobil tətbiqlərdə, masaüstü müştərilərdə, ekran görüntülərində və ya dəstək biletlərində yerləşdirməyin.
- İnkişaf, səhnələşdirmə və istehsal üçün sertifikatları ayrı saxlayın.
- Tələb edən xidmətlərə və operatorlara girişi məhdudlaşdırmaq.
- Loglardan sorğu imzalarını, avtorizasiya dəyərlərini və sirrləri redaktə edin.
- Şübhəli olduqda etibarnamələri ləğv edib dəyişdirmək.

<h2 id="clock-and-replay-protection">Saat və təkrar baxış qoruması</h2>

Bu SDK təkrar baxış riskini azaltmaq üçün `timestamp` və `nonce` ehtiva edir. Backend saatlarını sinxronlaşdırın və əl ilə qurulmuş nonce-u təkrar istifadə etməyin. Əgər imza təsdiqi uğursuz olarsa, yenidən cəhd etməzdən əvvəl konfiqurasiya olunmuş sirri, server vaxtını, seriallaşdırılmış sahələri və mühiti təsdiqləyin.

| Yoxlama | Gözlənilən nəticə |

| Ətraf mühit | Əsas URL və sertifikat eyni mühitə aiddir. |

| Rotasiya | Sertifikat sahibi və dəyişdirmə prosesi sənədləşdirilib. |
