Ticarət Bələdçisi istifadəçilərin giriş və maliyyələşmədən daimi müqavilə ticarətinə necə keçdiyini və əsas ticarət qaydalarının əmrlərə, mövqelərə, komissiyalara və likvidasiya riskinə necə təsir etdiyini izah edir.

Bu bölmə məhsul, əməliyyatlar, dəstək və son istifadəçi təhsili üçün yazılıb. API sahələri, imzalama və backend inteqrasiya detalları üçün Developer və SDK bölmələrindən istifadə edin.

<h2 id="before-trading">Ticarətdən əvvəl</h2>

- İstifadəçinin icazəli tərəfdaş və ya daxili 6MM girişi vasitəsilə daxil olduğunu təsdiqləmək.
- Sifariş verməzdən əvvəl vəsaitin düzgün hesabda olduğuna əmin olun.
- Leverage, marja, likvidasiya və maliyyələşdirmə haqları davranışını başa düşmək.
- Yeni bazar və ya ticarət rejimini öyrənərkən kiçik mövqe ölçülərindən başlayın.
- TP / SL istifadə edin və risk idarəetməsi üçün uyğun olduqda yalnız azaldıcı sifarişlər verin.
