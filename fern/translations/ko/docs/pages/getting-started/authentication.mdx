6MM는 파트너 시스템과 화이트 라벨 플랫폼과의 통합이라는 두 가지 계정 액세스 모델을 지원합니다. 플랫폼에서 제공하는 항목을 사용하세요. 계정 생성, 인증 및 프로필 관리는 선택한 모델에 따라 다릅니다.

<h2 id="registration-model">계정 모델을 선택하세요</h2>

| 영역 | 파트너 통합 | 화이트 라벨 플랫폼 |
| --- | --- | --- |
| 계정 소스 | 사용자는 거래 사용자를 연결하거나 동기화하는 파트너 시스템에 계정을 가지고 있습니다. | 사용자는 화이트 라벨 플랫폼의 계정 시스템에 속합니다. |
| 액세스 항목 | 파트너의 앱, 웹사이트 또는 내장된 거래 항목입니다. | 화이트 라벨 플랫폼의 브랜드 도메인 및 로그인 페이지입니다. |
| 입증 | 파트너는 사용자와 해당 백엔드가 필요한 거래 액세스 자격 증명을 얻었는지 확인합니다. | 로그인, 확인 및 계정 보안은 플랫폼의 활성화된 구성을 따릅니다. |
| 계정 관리 | 파트너는 자신의 사용자 프로필을 관리합니다. 거래 시스템은 필요한 사용자 매핑 및 거래 기록을 유지합니다. | 화이트 라벨 계정 시스템과 승인된 관리자는 사용자 프로필, 계정 상태 및 보안 설정을 관리합니다. |

<h2 id="login-method-1-partner-embedded-access">파트너 통합</h2>

1. 파트너의 계정 시스템을 통해 로그인하세요.
2. 파트너 백엔드는 세션을 확인하고 해당 거래 사용자를 바인딩하거나 식별합니다.
3. 백엔드는 지원되는 통합을 통해 필요한 거래 액세스 자격 증명 또는 항목 URL 을 얻습니다.
4. 내장된 거래 인터페이스 또는 파트너가 제공한 승인된 거래 항목을 엽니다.

계정 액세스 자체만으로는 거래에 자금을 사용할 수 없습니다. 주문하기 전에 파트너의 자금 조달 프로세스를 따르고 사용 가능한 영구 계정 잔액을 확인하세요.

<h2 id="login-method-2-6mm-account-login-partner-issued-credentials">화이트 라벨 플랫폼 액세스</h2>

화이트 라벨 플랫폼에서 제공하는 브랜드 도메인 및 계정 항목을 사용하세요. 자가 등록 가능 여부, 계정 개설 방법, 활성화되는 로그인 또는 신원 확인 방법은 해당 플랫폼의 구성에 따라 다릅니다.

플랫폼의 계정 시스템과 승인된 관리자는 자신의 권한 내에서 프로필 관리, 계정 상태 및 보안 작업을 처리합니다. 비밀번호 복구, 연락처 정보 변경 또는 계정 제한에 대한 플랫폼의 확인 프로세스를 따르세요.

로그인 후 플랫폼에서 지원하는 펀딩 프로세스를 통해 자금을 준비하세요. 무기한 거래의 경우, 펀딩 계정에서 무기한 계정으로 필요한 결제 자산을 이체하고 이체 결과를 확인합니다.

<h2 id="user-ownership-and-data-responsibility">계정 및 데이터 책임</h2>

두 모델의 책임 경계는 서로 다릅니다. 파트너 통합은 거래에 필요한 사용자 매핑 및 기록을 유지하면서 파트너 측 계정 관리를 유지합니다. 화이트 라벨 플랫폼은 자체 계정 프로세스와 관리 권한을 사용하여 사용자를 관리합니다.

수집, 저장 또는 표시되는 정보, 신원 확인 요구 사항 및 지원 책임은 실제 배포에 대해 정의되어야 합니다. 한 모델의 계정 관리 가정을 모든 플랫폼에 적용하지 마십시오.

<h2 id="design-principles">거래에 들어가기 전에</h2>

- 올바른 플랫폼 도메인과 계정을 사용하고 있는지 확인하세요.
- 해당 플랫폼에 필요한 신원 확인 또는 보안 검사를 완료하세요.
- 해당 계좌에 거래 액세스 권한이 있는지 확인하고 제한 사항을 검토하세요.
- 영구 계정의 사용 가능한 잔액을 확인하세요. 로그인해도 자동으로 자금이 이체되지는 않습니다.
- 계정 액세스 또는 신원 확인에 주의가 필요한 경우 플랫폼 지원팀에 문의하세요.
