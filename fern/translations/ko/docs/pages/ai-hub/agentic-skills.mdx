> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


에이전트 스킬은 CLI 및 MCP 도구를 기반으로 구축된 상위 수준의 워크플로 템플릿입니다.

에이전트가 도구를 사용해야 하는 시기, 금지된 작업, 생성할 출력 형식, 필요한 위험 검사를 정의합니다.

## 추천 스킬

| 기능 | 목적 | 기본 모드 |
| --- | --- | --- |
| 6mm 시장 분석가 | 시장 상태, 유동성, 변동성, 자금 조달을 분석합니다. | 읽기 전용 |
| 6mm 포트폴리오 위험 관리자 | 계정 노출 및 위험 집중을 검토합니다. | 계정 읽기 |
| 6mm-펀딩-차익거래-연구원 | 자금 조달 요율과 연구 기회를 비교하십시오. | 읽기 전용 |
| 6mm-청산-보호-보조 | 청산 위험 및 위험 감소 옵션을 식별합니다. | 계정 읽기 |
| 6mm 주문 실행 플래너 | 계획 주문 매개변수 및 실행 접근 방식. | 미리보기만 가능 |
| 6mm-트레이딩-저널-애널리스트 | 채우기, 동작 및 위험 참고 사항을 요약합니다. | 계정 읽기 |

## 각 기술에 포함되어야 할 사항

- 의도된 사용자 시나리오.
- CLI 또는 MCP 도구가 필요합니다.
- 허용된 작업과 금지된 작업.
- 필수 권한 계층.
- 거래가 허용되는지 여부입니다.
- 미리보기가 필수인지 여부입니다.
- 출력 형식.
- 위험 경고 행동.
- 사용자 프롬프트의 예.
