> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


MCP 프롬프트는 MCP 서버에 의해 노출되는 재사용 가능한 워크플로입니다. 이는 사용자가 일관된 질문을 하고 AI 클라이언트가 올바른 도구를 사용하도록 돕습니다.

## 권장 프롬프트

| 즉각적인 | 목적 |
| --- | --- |
| 시장개요 | 선택한 기호에 대한 시장 상태를 요약합니다. |
| 시장_미시구조_분석 | 스프레드, 깊이, 최근 거래 및 유동성 상태를 분석합니다. |
| 포트폴리오_위험_평가 | 포지션, 노출, 증거금 및 청산 위험을 검토합니다. |
| 포지션_관리 | 사용자가 위치 상태와 가능한 조치를 이해하도록 돕습니다. |
| 청산_보호 | 청산 위험 및 위험 감소 옵션을 식별합니다. |
| 자금_비율_기회 | 자금 조달 요율과 가능한 기회를 비교하십시오. |
| create_optimal_order | 미리보기 전에 주문 매개변수를 계획하세요. |
| 헤징_전략 | 기존 노출에 대한 헤징 옵션을 살펴보세요. |
| 거래_상담 | 주문을 실행하지 않고도 구조화된 거래 분석을 생성합니다. |

<span id="prompt-safety-rules" data-sixmm-canonical-anchor="prompt-safety-rules" aria-hidden="true"></span>

## 신속한 안전수칙

- 즉각적인 결과를 재정적 조언으로 취급하지 마십시오.
- 사용자가 명시적으로 요청하지 않는 한 거래 도구를 실행하지 마십시오.
- 만들기 전에 미리보기를 사용하세요.
- 가정과 데이터 소스를 설명합니다.
- 공개 문서에 있는 테스트넷 예제를 선호하세요.
