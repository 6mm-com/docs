> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


MCP 리소스는 AI 클라이언트가 도구를 호출하기 전에 검사할 수 있는 읽기 전용 컨텍스트입니다.

리소스는 모델에 6MM에 대한 안정적이고 구조화된 정보를 제공하여 환각을 줄입니다.

<h2 id="recommended-resource-uris">권장 리소스 URI</h2>

| 의지 | 목적 |
| --- | --- |
| 6mm://시스템/구성 | 환경 및 기능 구성. |
| 6mm://시스템/상태 | 현재 시스템 및 시장 상황. |
| 6mm://시장 | 이용 가능한 시장. |
| 6mm://시장/{symbol} | 계약 사양 및 시장 수준 메타데이터. |
| 6mm://수수료 | 수수료 규정. |
| 6mm://위험/규칙 | 거래 및 위험 규칙 요약. |
| 6mm://리스크/마진 | 마진 및 청산 컨텍스트. |
| 6mm://펀딩/규칙 | 펀딩 요율 규칙. |
| 6mm://api/docs | API 참조 요약 또는 링크. |

<h2 id="resource-design-rules">리소스 디자인 규칙</h2>

- 리소스를 읽기 전용으로 유지하세요.
- 안정적인 스키마를 사용하세요.
- 타임스탬프와 환경 이름을 포함합니다.
- 비밀이 노출되지 않도록 하세요.
- 긴 산문보다 간결하고 구조화된 데이터를 선호하세요.
- 세부정보가 너무 길면 표준 문서에 연결하세요.
