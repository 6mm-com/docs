> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


MCP 도구는 AI 클라이언트가 호출할 수 있는 작업입니다. 각 도구에는 명확한 설명, JSON 스키마, 권한 요구 사항, 안정적인 응답 형식 및 오류 모델이 있어야 합니다.

<h2 id="phase-1-public-market-tools">1단계: 공개 시장 도구</h2>

| 도구 | 목적 |
| --- | --- |
| 6mm_시스템_상태 | 서비스 및 시장 가용성을 확인하세요. |
| 6mm_시장 | 사용 가능한 시장과 기본 메타데이터를 나열합니다. |
| 6mm_시장_요약 | 하나 이상의 기호에 대한 시장 상태를 요약합니다. |
| 6mm_티커 | 최신 티커 데이터를 반환합니다. |
| 6mm_주문장 | 반품 주문서 깊이. |
| 6mm_클라인 | 역사적인 양초를 반환하십시오. |
| 6mm_거래 | 최근 공개 거래를 반환합니다. |
| 6mm_펀딩_요율 | 현재 및 과거 자금 조달 요율을 반환합니다. |

<h2 id="phase-3-and-later-trading-tools">3단계 이상: 거래 도구</h2>

| 도구 | 목적 |
| --- | --- |
| 6mm_미리보기_주문 | 주문을 하지 않고 주문을 확인하세요. |

<h2 id="tool-requirements">도구 요구 사항</h2>

모든 도구는 다음을 정의해야 합니다.

- AI 모델에 대한 설명입니다.
- JSON 스키마를 입력합니다.
- 권한 범위.
- 환경 지원.
- 비율 제한 동작.
- 안정적인 응답 필드.
- 오류 코드.
- 감사 로그 필드.
