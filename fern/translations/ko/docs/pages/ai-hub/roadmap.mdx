> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


AI Hub는 민감한 거래 기능을 보호하면서 사용자가 조기에 가치를 받을 수 있도록 단계적으로 출시되어야 합니다.

<h2 id="phase-1-public-market-ai-access">1단계: 공개 시장 AI 액세스</h2>

목표: 지원되는 모든 AI 클라이언트가 공식 6MM 시장 데이터를 읽을 수 있도록 합니다.

결과물:

- SDK / API 클라이언트를 공유했습니다.
- CLI 공개 시장 명령.
- 지역 MCP 공개 시장 도구.
- MCP 공개 시장 도구를 호스팅했습니다.
- 시장, 수수료, 위험 규칙 및 시스템 상태에 대한 리소스입니다.
- 클라이언트 설치 가이드.

포함되지 않음:

- 계정 쿼리.
- 실제 거래.
- API 키 호스팅.

<h2 id="phase-2-account-read">2단계: 계정 읽기</h2>

목표: 사용자가 자신의 계정 컨텍스트를 안전하게 검사할 수 있도록 합니다.

결과물:

- 읽기 전용 API 키 범위입니다.
- 계정 요약.
- 잔액.
- 위치.
- 주문을 개시하세요.
- 채웁니다.
- 자금 지불.
- 포트폴리오 위험 프롬프트.

선호하는 배포:

- 로컬 MCP.
- CLI.
- 원격 MCP 자체 호스팅됩니다.

<h2 id="phase-3-trading-preview">3단계: 거래 미리보기</h2>

목표: AI가 주문을 실행하지 않고도 주문을 생성하도록 돕습니다.

결과물:

- `preview_order`.
- 위험 점검.
- 마진 영향.
- 수수료 견적.
- 청산 영향.
- 실행 계획 프롬프트.

<h2 id="phase-4-controlled-trading">4단계: 통제된 거래</h2>

목표: 강력한 가드레일로만 실제 거래를 지원합니다.

결과물:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- 멱등성.
- 최대 명목상 한도.
- 명시적인 확인.
- 감사 로그.

<h2 id="phase-5-agentic-skills">5단계: 에이전트 스킬</h2>

목표: 일반적인 시장 분석 및 위험 워크플로우를 제품화합니다.

결과물:

- 시장 분석가 기술.
- 포트폴리오 위험 기술.
- 자금 연구 기술.
- 청산 보호 스킬.
- 실행 계획 기술.
- 예제 작업 라이브러리.
