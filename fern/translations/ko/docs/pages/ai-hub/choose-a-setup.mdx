> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


두 가지 질문을 바탕으로 설정을 선택하세요.

1. 어떤 AI 클라이언트를 사용하시겠습니까?
2. 공개 데이터만 필요합니까, 개인 계정 액세스가 필요합니까, 아니면 거래 워크플로가 필요합니까?

확실하지 않은 경우 공개 데이터의 경우 호스팅된 MCP로 시작하고 개인 계정 워크플로의 경우 로컬 MCP로 시작하세요.

## 사용 사례별로 선택

<CardGroup cols={2}>
<Card title="공개 시장 데이터만 있으면 됩니다." icon="fa-duotone fa-cloud" href="/ko/ai-hub/hosted-mcp">
호스팅된 MCP을 사용합니다. 로컬 설치가 없고, 사용자 API 키가 없으며, 개인 계정 액세스가 없습니다.
</Card>
<Card title="내 AI 클라이언트가 내 계정을 읽을 수 있기를 원합니다." icon="fa-duotone fa-computer" href="/ko/ai-hub/local-mcp">
읽기 전용 자격 증명으로 로컬 MCP을 사용합니다. 테스트넷 또는 읽기 전용 모드에서 시작하세요.
</Card>
<Card title="내 에이전트가 터미널 명령을 실행할 수 있습니다." icon="fa-duotone fa-terminal" href="/ko/ai-hub/cli">
6MM CLI를 사용하세요. 이는 Codex, Claude Code, Gemini CLI, 스크립트 및 CI 작업에 대해 간단합니다.
</Card>
<Card title="우리 팀에는 관리형 엔드포인트가 필요합니다" icon="fa-duotone fa-server" href="/ko/ai-hub/remote-mcp">
원격 MCP을 사용합니다. 팀이 제어하는 ​​인프라에 서버를 배포합니다.
</Card>
</CardGroup>

## 빠른 의사결정 테이블

| 목표 | 권장 설정 | 왜 |
| --- | --- | --- |
| AI 클라이언트에게 공개 시장 데이터 요청 | 호스팅됨 MCP | 로컬 설치가 필요하지 않으며 API 키도 필요하지 않습니다. |
| Claude Desktop, Cursor 또는 ChatGPT Desktop에서 6MM 도구를 호출하도록 허용 | 지역 MCP | AI는 사용자가 제어하는 ​​로컬 서버를 통해 도구를 호출합니다. |
| Codex, Claude Code, Gemini CLI 또는 스크립트에서 6MM를 호출하도록 허용 | CLI | 명령 출력은 JSON일 수 있으며 에이전트가 쉽게 구문 분석할 수 있습니다. |
| 회사 관리 MCP 엔드포인트 제공 | 원격 MCP | 교육기관은 호스팅, 자격 증명, 액세스 및 로그를 제어합니다. |
| 반복 분석 또는 위험 워크플로 표준화 | 에이전트 스킬 | 템플릿은 도구 사용법, 가드레일 및 출력 형식을 정의합니다. |

## AI 클라이언트로 선택

| AI 클라이언트 | 호스팅됨 MCP | 지역 MCP | CLI | 메모 |
| --- | --- | --- | --- | --- |
| 클로드 데스크탑 | 가능한 | 추천 | 가능한 | 계정 컨텍스트가 필요한 경우 로컬 MCP을 사용하세요. |
| Claude.ai 웹 | 지원되는 경우 권장됨 | 해당 없음 | 해당 없음 | 공개 시장 데이터에만 적합합니다. |
| 채팅GPT 데스크톱 | 가능한 | 추천 | 가능한 | 개인 계정 도구에는 로컬 MCP이 선호됩니다. |
| 커서 | 가능한 | 추천 | 가능한 | 로컬 MCP은 코딩 작업 흐름에 잘 작동합니다. |
| 코덱스 CLI | 가능한 | 가능한 | 추천 | CLI는 일반적으로 가장 직접적인 경로입니다. |
| 클로드 코드 CLI | 가능한 | 가능한 | 추천 | 워크플로우에 따라 CLI 또는 로컬 MCP입니다. |
| VS 코드/부조종사 | 가능한 | 추천 | 가능한 | MCP 및 터미널 지원에 따라 다릅니다. |
| 쌍둥이자리 CLI | 가능한 | 가능한 | 추천 | CLI는 가장 간단한 첫 번째 설정입니다. |
| 윈드서핑 | 가능한 | 추천 | 가능한 | 로컬 MCP이 선호됩니다. |

## 설정 경로로 선택

| 설정 | 설치 | API 키 위치 | 최상의 초기 범위 | 계좌 및 거래 범위 |
| --- | --- | --- | --- | --- |
| 호스팅됨 MCP | 없음 | 공개 데이터에 대한 사용자 API 키가 없습니다. | 공개 시장 데이터 | 첫 번째 릴리스에는 권장되지 않음 |
| 지역 MCP | 사용자가 패키지를 설치합니다. | 사용자 기계 | 공개 데이터 및 계정 읽기 | 향후 거래를 위한 권장 경로 |
| CLI | 사용자가 패키지를 설치합니다. | 사용자 기계 | 공개 데이터 및 스크립트 | 미리보기 및 자동화에 유용합니다. |
| 원격 MCP | 사용자가 서버를 배포합니다. | 사용자 클라우드 또는 기관 클라우드 | 공개 데이터 또는 계정 읽기 | 사용자가 배포를 제어하는 ​​경우 가능 |
| 기술 | 문서 또는 설치 가능한 템플릿 | 기본 도구에 따라 다름 | 분석 워크플로 | 도구 권한을 따라야 합니다. |

## 경험에 의한 보안 규칙

작업을 지원하는 가장 위험도가 낮은 설정을 사용하십시오.

- 공개 시장 데이터: 호스팅된 MCP이면 충분합니다.
- 개인 계정 데이터: 로컬 MCP 또는 사용자 관리형 원격 MCP.
- 거래 미리보기: 로컬 MCP 또는 CLI, 테스트넷 먼저 하는 것이 좋습니다.
- 실제 거래: 명시적인 허가, 미리보기, 확인, 한도 및 감사 로그 이후에만 가능합니다.
