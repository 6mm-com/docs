> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


원격 MCP은 자체적으로 제어되는 장기 실행 MCP 엔드포인트를 원하는 사용자 또는 기관을 위한 것입니다.

호스팅된 MCP와 달리 원격 MCP은 사용자를 위해 6MM에 의해 작동되지 않습니다. 6MM은 코드, 이미지, 템플릿 및 문서를 제공합니다. 사용자는 호스팅 및 자격 증명을 제어합니다.

<h2 id="architecture">건축학</h2>

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<h2 id="deployment-targets">배포 대상</h2>

- 도커 또는 도커 작성.
- VPS 역방향 프록시를 사용합니다.
- 철도.
- 세우다.
- Fly.io.
- AWS ECS 또는 람다.
- 내부 쿠버네티스.

<h2 id="required-files">필수 파일</h2>

- Dockerfile.
- docker-compose.yml.
- .env.템플릿.
- HTTP 운송 모드.
- /mcp 엔드포인트.
- /health 끝점.
- 역방향 프록시 및 TLS 참고 사항.

<h2 id="credential-model">자격 증명 모델</h2>

자격 증명은 AI 클라이언트 프롬프트가 아닌 사용자 관리 환경에 저장되어야 합니다. 기관 관리 배포의 경우 승인된 클라이언트 및 네트워크에 대한 액세스를 제한합니다.

<h2 id="recommended-first-release">권장되는 첫 번째 릴리스</h2>

공개 시장 데이터로 시작하세요. 인증 후 계정 읽기만 추가, 키 범위 지정, 로그, 액세스 제어가 가능합니다. 통제된 거래 요건이 충족될 때까지 거래는 비활성화된 상태로 유지되어야 합니다.
