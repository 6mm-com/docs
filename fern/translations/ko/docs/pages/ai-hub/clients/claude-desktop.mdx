> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


Claude Desktop은 MCP-기반 조사, 계정 검토 및 운영 분석에 적합합니다.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## 권장 설정

| 필요 | 설정 |
| --- | --- |
| 공공 시장 조사 | 호스팅됨 MCP |
| 계정 인식 분석 | 지역 MCP |
| 내부 팀 엔드포인트 | 원격 MCP |

## 메모

MCP는 개인 계정 데이터가 포함될 때마다 선호됩니다. MCP 서버가 사용자 컴퓨터에서 실행되고 자격 증명을 6MM 호스팅 AI 엔드포인트로 보낼 필요가 없기 때문입니다.
