> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


ChatGPT Desktop은 자연어로 시장 질문을 하려는 사용자에게 친숙한 진입점입니다.

사용자가 공개 시장 데이터, 계정 요약, 포지션 설명 및 거래 규칙 컨텍스트에 대한 대화형 인터페이스를 원할 때 이 경로를 사용하십시오.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## 권장 설정

| 필요 | 설정 |
| --- | --- |
| 공개 시장 데이터 | 호스팅됨 MCP |
| 비공개 계정 컨텍스트 | 지역 MCP |
| 반복 가능한 분석 프롬프트 | 에이전트 스킬 |
| 터미널 기반 워크플로 | 6MM CLI |

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

## 안전 기본값

- 공개 시장 데이터로 시작하세요.
- 계정 자격 증명이 필요한 경우 로컬 MCP을 사용하십시오.
- 사용자 컴퓨터에 개인 API 키를 보관하세요.
- 향후 거래 조치를 취하기 전에 미리보기와 명시적인 확인이 필요합니다.
