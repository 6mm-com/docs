> **계획됨 — 아직 출시되지 않음**
> AI Hub는 계획된 기능입니다. 이 페이지의 기능, 엔드포인트, 명령 및 클라이언트 구성은 제안된 설계를 설명하지만 현재는 사용할 수 없습니다. 최종 가용성 및 설정 지침은 출시 시 발표됩니다.


Windsurf는 6MM 문서, CLI 출력 및 로컬 프로젝트 파일을 함께 고려해야 하는 코딩 에이전트 워크플로에 유용합니다.

<h2 id="recommended-setup">권장 설정</h2>

| 필요 | 설정 |
| --- | --- |
| 코딩 에이전트 통합 | 지역 MCP |
| 명령 실행 | 6MM CLI |
| 반복 가능한 검토 흐름 | 에이전트 스킬 |

<h2 id="example-prompts">예시 프롬프트</h2>

```text
Use 6MM to review this Agent SDK integration and identify missing production checks.
```

```text
Use 6MM to build a webhook verification checklist for this backend.
```
