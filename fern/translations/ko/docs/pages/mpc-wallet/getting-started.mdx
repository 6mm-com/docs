테스트 환경을 사용할 수 있게 되면 이 순서를 사용하십시오. 액세스 링크와 설치 패키지는 온보딩 담당자로부터 제공되어야 합니다. 이 가이드는 공개 가입 또는 다운로드 엔드포인트를 제공하지 않습니다.

<span id="prepare-your-workspace" data-sixmm-canonical-anchor="prepare-your-workspace" aria-hidden="true"></span>

## 작업 공간을 준비하세요

1. 평가할 제품과 해당 제품의 작업 공간을 소유한 계정 또는 조직을 확인하세요.
2. 제공된 액세스 경로를 사용하여 로그인하고 해당 버전에서 제공하는 계정 보안 단계를 완료하세요.
3. 원하는 작업공간을 선택하세요. 자산을 운영하기 전 해당 상품, 회원 권한, 초기화 상태를 확인하세요.
4. 보관권이 있는 제품의 경우, 확인하기 전에 참가자 및 복구 책임을 검토하세요.

로그인 계정, 작업공간, 온체인 지갑을 혼동하지 마세요. 하나의 계정은 다양한 작업 공간에 액세스할 수 있으며 각 작업 공간은 자체 제품 및 운영 컨텍스트를 결정합니다.

<span id="complete-initialization" data-sixmm-canonical-anchor="complete-initialization" aria-hidden="true"></span>

## 초기화 완료

제품에 따라 설정에는 장치 또는 노드 등록, 참가자 수락, 지갑 키 생성 및 백업 준비가 포함될 수 있습니다. 하나의 성공적인 단계를 전체 프로세스의 완료로 처리하는 대신 선택한 작업 영역의 설정 상태를 따르세요.

완전 관리형 환경에서는 고객이 공유하는 기업 지갑과 동일한 고객 노드 설정이 필요하지 않습니다. 개인 및 팀 장치에는 자체 등록 및 서명 흐름도 있습니다.

<span id="validate-a-small-test-flow" data-sixmm-canonical-anchor="validate-a-small-test-flow" aria-hidden="true"></span>

## 소규모 테스트 흐름 검증

1. 환경이 테스트 네트워크인지 여부를 포함하여 활성화된 네트워크 및 자산을 확인합니다.
2. 수신 주소와 필요한 메모 또는 태그를 얻습니다. 주소 확인이 제공되는 경우 주소를 배포하기 전에 완료하세요.
3. 소액의 테스트 금액을 받고 결과가 나올 때까지 입금 기록을 따르십시오.
4. 소규모 발신 전송을 준비합니다. 목적지, 수수료, 필수 승인 또는 장치 서명을 검토하세요.
5. 지갑 기록과 체인 결과, 자신의 사업 기록을 비교해 보세요.

테스트를 확장하기 전에 팀이 거부된 승인, 사용할 수 없는 서명자, 누락된 콜백 및 불확실한 거래 결과를 처리할 수 있는지 확인하십시오. 보다 [지갑 운영](/ko/mpc-wallet/wallet-operations) 그리고 [보안 및 복구](/ko/mpc-wallet/security-and-recovery).
