인출은 비동기식 비즈니스 작업입니다. 성공적인 HTTP 응답은 요청이 처리되었음을 의미합니다. 자금이 온체인에 도착했다는 사실은 입증되지 않습니다.

<span id="persist-one-business-identifier" data-sixmm-canonical-anchor="persist-one-business-identifier" aria-hidden="true"></span>

## 하나의 비즈니스 식별자 유지

출금을 보내기 전에 `client_request_id`을 생성하고 저장하세요. 프로세스를 다시 시작한 후를 포함하여 동일한 의도한 작업을 다시 시도하는 데 다시 사용하세요. 거래 필드를 일관되게 유지하세요. 현재 구현에서는 비즈니스 매개변수가 충돌하는 반복 식별자를 거부합니다.

`Idempotency-Key` 헤더에만 의존하지 마십시오. 제공된 SDK는 해당 헤더를 추가할 수 있지만 현재 출금 중복 제거 계약은 본문 필드 `client_request_id`를 기반으로 합니다.

<span id="understand-request-data" data-sixmm-canonical-anchor="understand-request-data" aria-hidden="true"></span>

## 요청 데이터 이해

| 필드 | 의미 |
| --- | --- |
| `chain_id`, `asset_id` | 합의된 환경의 식별자 |
| `to_address`, `amount` | 문자열로 표시되는 대상 및 양의 소수 금액 |
| `client_request_id` | 안정적인 비즈니스 요청 식별자 |
| `dest_memo_type`, `dest_memo` | 네트워크에서 요구하는 대상 메모 세부정보 |
| `client_authorization` | API 키로 시작된 출금에 대한 고객 거래 승인 |
| `end_user_id` | 엔터프라이즈 API 흐름의 선택적 비즈니스 사용자 식별자 |

이 표에는 전체 요청 스키마가 아닌 핵심 필드가 강조되어 있습니다. 통합 버전에 대한 미리보기, 수수료 확인 및 보관 관련 요구 사항을 확인하세요. 이진 부동 소수점 금액을 피하고 환경 간에 예제 체인 또는 자산 번호를 복사하지 마십시오.

## 결과를 따르세요

| 상태 예시 | 해석 |
| --- | --- |
| `pending_approval`, `pending_platform_review` | 비즈니스 승인 또는 검토가 완료되었습니다. |
| `approved`, `pending_sign` | 승인과 서명은 별도의 단계입니다. |
| `broadcasting`, `pending_chain` | 방송 또는 체인 확인이 진행 중입니다. |
| `broadcast_unverified`, `recovering` | 결과는 아직 불확실합니다. 다른 전송을 생성하지 마세요 |
| `awaiting_reauthorization` | 동일한 요청에 대해 새로운 고객 승인이 필요할 수 있습니다. |
| `confirmed` | 시스템에 체인 확인이 기록되었습니다. |

목록은 설명을 위한 것이며 변경될 수 있습니다. 알 수 없는 상태를 성공 또는 실패로 매핑하는 대신 조사를 위해 보존합니다. 실패하거나 거부된 라벨만으로는 서명되거나 방송되지 않았다는 증거가 충분하지 않습니다.

<span id="recover-after-a-timeout" data-sixmm-canonical-anchor="recover-after-a-timeout" aria-hidden="true"></span>

## 시간 초과 후 복구

원래 `client_request_id` 쿼리 매개변수를 사용하여 `GET /api/v1/withdrawals/by-request`를 쿼리합니다. 결과가 불확실할 때 원래 작업을 계속 폴링하거나 조정합니다. 승인 갱신이 필요한 경우 동일한 식별자와 합의된 갱신 절차를 사용하십시오.

취소 여부는 실제 서명 단계와 서버 확인에 따라 달라집니다. 원본이 양도불가, 양도불가로 확정된 후에만 대체사업을 개시합니다. 이벤트 수신을 통해 [webhooks](/ko/mpc-wallet/webhooks-and-sdks), API 쿼리를 조정 경로로 유지합니다.
