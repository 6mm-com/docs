잔액 보기를 사용하여 현재 자금 포지션과 거래 보기를 확인하고 어떻게 변경되었는지 설명하세요. Enterprise 작업 영역은 제품 및 역할에 따라 여러 보기를 노출할 수 있습니다.

<span id="use-the-right-record-for-each-question" data-sixmm-canonical-anchor="use-the-right-record-for-each-question" aria-hidden="true"></span>

## 각 질문에 올바른 기록을 사용하세요.

| 질문 | 어디를 볼 것인가 |
| --- | --- |
| 결제 시 사용할 수 있는 금액은 얼마인가요? | 해당 지갑과 자산의 사용 가능 잔액을 확인하세요. 보유 또는 동결된 금액을 별도로 검토합니다. |
| 입금이 크레딧을 받았나요? | 입금기록을 확인하고 네트워크, 자산, 금액, 수령내역을 일치시키세요. |
| 지급이 알려진 결과에 도달했습니까? | 가능한 경우 출금 기록과 체인 확인을 확인하세요. |
| 어떤 항목이 비즈니스 잔액에 영향을 미쳤습니까? | 작업공간에서 제공하는 경우 원장 보기를 사용하세요. 온체인 이동에 대한 체인 활동 보기를 확인하세요. |

<span id="reconcile-a-payment-period" data-sixmm-canonical-anchor="reconcile-a-payment-period" aria-hidden="true"></span>

## 지불 기간 조정

1. 확인하고 있는 업무 공간, 네트워크, 자산, 사업 기간을 확인하세요.
2. 입출금 기록을 귀하가 보관하고 있는 사업 주문 또는 지불 참조서와 일치시키십시오.
3. 수수료와 내부 징수는 별도로 계산하십시오. 완료된 이체와 별도로 보류 중인 요청에 대해 보유된 잔액을 기록합니다.
4. 거래 참조 및 최신 상태를 사용하여 일치하지 않는 항목을 조사합니다. 결과가 확정될 때까지 보류 중인 항목을 열어 두십시오.

예를 들어, 인출 기록이 아직 확인을 기다리는 동안 나가는 거래가 온체인에 나타나는 경우 원래 비즈니스 요청을 열어두고 해당 기록을 따르십시오. 최종 상태와 해당 금액을 사용하여 조정을 종료합니다.
