Embedded API / SDK 거래 시스템은 이미 트래픽, 사용자 또는 비즈니스 워크플로우를 소유하고 있으며, 완전한 거래소를 처음부터 구축하지 않고도 거래를 추가하고자 하는 파트너들을 위해 설계되었습니다.

<h2 id="what-it-provides">제공하는 것</h2>

- Trading Widget SDK를 통한 내장형 거래 터미널
- 파트너 백엔드 통합 Agent SDKs
- 사용자 신원 바인딩 및 진입 토큰 흐름
- 자산 이전, 주문, 포지션 및 계좌 API 접근
- 운영 시스템을 위한 이벤트, webhook, 라이프사이클 통합

<h2 id="recommended-architecture">추천 아키텍처</h2>

| 층 | 책임 |
| --- | --- |
| 파트너 프론트엔드 | 진입 지점을 호스팅하고 6MM 거래 인터페이스를 내장합니다. |
| 파트너 백엔드 | API 비밀을 유지하고, 사용자를 검증하며, 임베드 토큰을 발행하고, webhooks처리합니다. |
| 6MM 무역 인프라 | 거래 UI, 매칭, 위험, 유동성, 계좌 상태 및 거래 수명 주기를 처리합니다. |

<h2 id="choose-an-integration-path">통합 경로를 선택하세요</h2>

| 요구 사항 | 추천 경로 |
| --- | --- |
| 가장 빠른 웹 통합을 지원하는 완전한 거래 UI입니다 | Trading Widget |
| 백엔드 사용자 바인딩, 전송, 진입 URL 및 webhook 처리 | Agent SDK |
| 완전 맞춤형 제품 및 주문 워크플로우 | REST API + WebSocket |
| 더 넓은 운영 범위를 가진 브랜드 교환 경험 | 화이트라벨 교환 |

최종 설계에서는 이 경로를 결합할 수 있습니다. 구현 시작 전에 인증, 자산 소유권, 책임 경계, 모니터링 및 생산 지원을 확인하세요.
