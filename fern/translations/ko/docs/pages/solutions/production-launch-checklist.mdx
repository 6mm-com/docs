6MM기반 거래 흐름을 프로덕션 사용자에게 노출하기 전에 이 체크리스트를 사용하세요. 제품, 엔지니어링, 운영, 리스크 및 지원 팀이 함께 검토할 수 있도록 설계되었습니다.

<h2 id="launch-checklist">발사 체크리스트</h2>

| 면적 | 체크리스트 |
| --- | --- |
| 제품 | 진입 지점, 사용자 카피, 위험 프롬프트, 언어 범위, 지원 경로가 준비되어 있습니다. |
| 백엔드 | API 자격 증명, 서명, 토큰 발행, webhooks, 재시도, 그리고 로깅이 구현되어 있습니다. |
| 거래 | 주문, 이전, 포지션, 마진, 수수료, 청산 행위 등이 검토되었습니다. |
| 보안 | 비밀, 접근 역할, 모니터링, 사고 대응, 감사 로그가 준비됩니다. |
| 운영 | 지원 워크플로우, 에스컬레이션 경로, 조정, 일일 모니터링이 할당됩니다. |

<h2 id="recommended-sequence">추천 시퀀스</h2>

1. 완전한 샌드박스 또는 내부 환경 검증.
2. 로그인, 입력, 전송, 거래 및 지원을 위한 종단 간 사용자 여정을 운영합니다.
3. 모니터링 및 사고 대응 소유권 확인.
4. 공개 카피, 현지화된 자산, 리소스 다운로드를 승인합니다.
5. 광범위한 홍보 전에 통제된 발사 창을 설정하세요.

<h2 id="after-launch">출범 후</h2>

초기 출시 기간 동안 매일 활동을 점검하세요. 입력 변환, 토큰 발급 실패, 주문 오류, 스프레드 품질, 전송 완료, webhook 재시도, 지원 티켓 등을 함께 시청하세요.
