<h2 id="how-the-solutions-connect">솔루션들이 어떻게 연결되는가</h2>

대부분의 파트너 구현은 두 가지 이상의 6MM 기능을 결합합니다. 화이트라벨 거래소는 기관 유동성, 준수 지원, API 통합을 활용할 수 있습니다. 임베디드 트레이드 파트너는 Trading Widget SDK 에서 시작해 이후 백엔드 Agent SDK 흐름, webhook 처리, 운영 자원을 추가할 수 있습니다.
