깔끔한 내재 거래 시작은 명확한 책임 경계에 달려 있습니다. 파트너 시스템은 민감한 사업 소유권을 유지해야 하며, 6MM 는 거래 인프라와 수명 주기 역량을 제공합니다.

<h2 id="responsibility-model">책임 모델</h2>

| 면적 | 파트너 시스템 | 6MM 인프라 |
| --- | --- | --- |
| 사용자 관계 | 사용자 계정, 로그인 상태, 고객 지원 신원, 자격 심사를 소유합니다. | 검증된 거래 진입 컨텍스트를 받고 거래 측 상태를 유지합니다. |
| 비밀과 서명 | 저장소는 백엔드에서 API 키를 파트너로 관리하며 서버 측 요청을 서명합니다. | 서명된 요청을 검증하고 권한 있는 작업을 처리합니다. |
| 거래 경험 | 진입 지점, 내비게이션, 제품 맥락을 제공합니다. | 거래 UI, 주문 수명 주기, 시장 데이터, 포지션, 위험, 결제 동작을 제공합니다. |
| 운영 | 지원 워크플로우, 비즈니스 분석, 내부 에스컬레이션을 담당합니다. | 통합에 필요한 이벤트, webhooks, 상태 정보를 발산합니다. |

<h2 id="production-principles">제작 원칙</h2>

- 모든 파트너는 비밀로 하라.
- 임베드 토큰을 단명한 진입 자격 증명으로 간주합니다.
- 멩등성 webhooks 처리하고 이벤트 ID를 저장합니다.
- 토큰 발행, 전송 흐름, 주문 상태 변경 모니터링을 활용합니다.
- 고객 대상 카피를 입력, 거래 및 지원 페이지에서 일관되게 유지합니다.
