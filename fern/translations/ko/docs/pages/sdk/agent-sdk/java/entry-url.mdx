이 가이드는 **Agent Java SDK `v0.3.0`**, Java 8+ 및 태그된 공개 계약을 대상으로 합니다. 예제는 `client`를 초기화한 후 파트너 백엔드에서 실행됩니다. [빠른 시작](/ko/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## 예시 전제조건

Java 조각은 이러한 가져오기를 공유합니다. 빠른 시작을 사용하여 `client`를 초기화하고 저장된 바인딩에서 `platformUserId`를 가져옵니다. 예시 사용자/주문 ID는 고유한 지속 값으로 대체되어야 합니다.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## 직접 입력 URL

직접 입력 URL 은 리디렉션 모드용입니다. 파트너 사용자가
파트너 사이트에서 6MM 프런트엔드를 열고 자동으로 로그인됩니다.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/en/futures/BTCUSDT?tradingMode=real")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

필드 규칙:

| 필드 | 설명 |
| --- | --- |
| `redirectPath` | 6MM 프런트엔드 상대 경로입니다. `/`로 시작해야 합니다(예: `/en/futures/BTCUSDT?tradingMode=real`). |
| `returnUrl` | 사용자가 6MM 프런트엔드를 종료할 때 사용되는 파트너 절대값 URL 입니다. `http` 및 `https`만 허용됩니다. |
| `expireAt` | Unix 타임스탬프로 표시되는 입장권 만료 시간(초) |

이 예는 리얼 모드에서 영구 미래를 엽니다. 시뮬레이션 거래의 경우 프런트엔드에서 `tradingMode=demo`를 사용하고 해당 백엔드 지갑 요청에서 `environment=SIMULATED`를 명시적으로 전달합니다. 프론트엔드`tradingMode`와 백엔드 펀드`environment`는 별도로 구성됩니다. URL 항목을 생성하면 사용자가 인증됩니다. 자금을 이체하거나 지갑 환경을 선택하지 않습니다.

보안 요구사항:

- `webUrl`에는 일회성 티켓이 포함되어 있습니다. 즉시 사용하고 장기간 보관하지 마십시오.
- URL 항목이 만료되거나 사용된 경우 파트너 사이트에서 새 항목을 생성하세요.
- `returnUrl`는 `javascript:`, 상대 경로 또는 사용자 정보가 포함된 URL 일 수 없습니다.

## 제품 및 모드 선택

6MM에서 제공하는 현재 프런트엔드 경로를 사용합니다. 예를 들어 `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` 또는 `/zh-CN/futures/BTCUSDT?tradingMode=real`입니다. 티켓은 사용자를 인증합니다. 자금 환경을 선택하거나 자금을 이동하지 않습니다.

보다 [초 거래](/ko/sdk/agent-sdk/java/seconds-trading) 리디렉션 및 포함된 예제의 경우.
