이 가이드는 **Agent Java SDK `v0.3.0`**, Java 8+ 및 태그된 공개 계약을 대상으로 합니다. 예제는 `client`를 초기화한 후 파트너 백엔드에서 실행됩니다. [빠른 시작](/ko/sdk/agent-sdk/java/quick-start).

문서 기준: SDK `v0.3.0`, 커밋 `54aa3c1`.

## 구성

이전에 6MM에서 다음 값을 얻습니다.
통합.

| 목 | 예 | 설명 |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | 에이전트 API 기본 URL, 후행 슬래시 없음 |
| `agentCode` | `AGENT001` | 파트너 코드 |
| `apiSecret` | `your-api-secret` | API 서명 비밀입니다. 백엔드에만 유지 |
| `defaultCurrency` | `USDT` | 기본 통화, 일반적으로 `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | 6MM 콜백에 대한 파트너 엔드포인트 |

생산 권장사항:

- 에이전트 API 및 webhook 엔드포인트에는 HTTPS를 사용합니다.
- 비밀 관리자, 구성 센터 또는 환경 변수에 `apiSecret`를 저장합니다.
- 가급적이면 NTP을 사용하여 서버 시간을 동기화하세요.
- 모든 파트너 주문 번호를 유지하고 전 세계적으로 고유하게 유지하세요.
- 브라우저, 앱, 미니 프로그램 또는 프런트엔드 소스 코드에 `apiSecret`을 보내지 마세요.

## 자동 서명 필드

서명된 에이전트 API 호출의 경우 SDK는 자동으로 다음을 삽입합니다.

| 필드 | 원천 | 설명 |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | 파트너 코드 |
| `timestamp` | 현재 UTC Unix 타임스탬프 | 초 |
| `nonce` | 보안 난수 생성기 | 재생 보호 |
| `sign` | HMAC-SHA256 | 서명 요청 |
| `currency` | `defaultCurrency` | 이체/계좌 요청 시 작성 통화 생략 |

서명 규칙:

1. `sign`을 제외합니다.
2. 빈 값을 제외합니다.
3. ASCII 순서로 키를 정렬합니다.
4. `k=v&k2=v2`로 가입하세요.
5. HMAC-SHA256 16진수를 `apiSecret`로 계산합니다.

배열 값은 서명 페이로드에 합류하기 전에 압축된 JSON로 직렬화됩니다. 예를 들어, `platformUserIds`는 `["1188041528"]`로 서명되어 `k=v` 페이로드에 `platformUserIds=["1188041528"]`를 제공합니다. 배열 요소 순서, 큰따옴표 및 문자열 ID를 유지합니다. 서식 지정 공백을 삽입하거나 Java `List.toString()`(예: `[1188041528]`)를 사용하지 마세요. SDK는 이 직렬화를 자동으로 처리합니다.

일반 비즈니스 코드는 서명을 계산하거나 수동으로 설정해서는 안 됩니다.
`agentCode`, `timestamp`, `nonce` 또는 `sign`.
