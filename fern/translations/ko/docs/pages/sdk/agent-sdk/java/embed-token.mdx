이 가이드는 **Agent Java SDK `v0.3.0`**, Java 8+ 및 태그된 공개 계약을 대상으로 합니다. 예제는 `client`를 초기화한 후 파트너 백엔드에서 실행됩니다. [빠른 시작](/ko/sdk/agent-sdk/java/quick-start).

## 예시 전제조건

Java 조각은 이러한 가져오기를 공유합니다. 빠른 시작을 사용하여 `client`를 초기화하고 저장된 바인딩에서 `platformUserId`를 가져옵니다. 예시 사용자/주문 ID는 고유한 지속 값으로 대체되어야 합니다.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget 내장 토큰

포함 토큰은 Trading Widget SDK `partner-token + tokenProvider` 모드용입니다. 그만큼
브라우저는 파트너 백엔드를 호출하고, 파트너 백엔드는 이를 Java SDK라고 호출합니다.
`embedToken`을 생성합니다.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

통합 요구 사항:

- `channelId`은 Trading Widget SDK에 의해 전달된 값을 사용해야 합니다.
- `symbol`은 선택 사항이며 현재 초기 기호를 전달할 수 있습니다. 이는 토큰 거래 쌍 권한 제한이 아닙니다.
- `embedToken`는 수명이 짧고 일회성입니다. URL 쿼리 문자열에 넣지 마세요.
- 파트너 프런트엔드는 `apiSecret`를 보유하면 안 됩니다.
- `expireAt`는 TTL가 아니라 초 단위의 Unix 타임스탬프입니다.

파트너 백엔드 엔드포인트 예:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## 파트너 엔드포인트 계약

파트너 세션을 인증하고 `agentUserId` 서버 측을 파생시킵니다. 현재 위젯 `channelId`을 수락합니다. 최상위 수준 `embedToken`, `expireAt`(Unix 초) 및 동일한 `channelId`를 반환합니다. 에이전트 응답은 `channelId`를 제공하지 않습니다. 백엔드가 이를 에코합니다. 초기화 및 갱신 시 새로운 토큰을 가져옵니다. 절대로 재사용하지 마십시오. 토큰 생성은 자금을 이체하거나 지갑 환경을 선택하지 않습니다.

보다 [초 거래](/ko/sdk/agent-sdk/java/seconds-trading) 전체 프런트엔드/백엔드 흐름을 위해.
