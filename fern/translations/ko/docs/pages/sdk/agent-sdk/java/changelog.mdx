이 가이드는 **Agent Java SDK `v0.3.0`**, Java 8+ 및 태그된 공개 계약을 대상으로 합니다. 예제는 `client`를 초기화한 후 파트너 백엔드에서 실행됩니다. [빠른 시작](/ko/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- 6가지 영구 쿼리: 현재 주문, 주문 내역, 채우기, 현재 위치, 위치 내역 및 계정 원장.
- 자금 잔액, 이체, 복구 쿼리 및 자금/계약 이체.
- 지원 자금 요청에 대한 명시적 생산/시뮬레이션 선택.
- 초 거래 리디렉션 및 포함 가이드, 응답 필드 참조 및 마이그레이션 지침.

Java SDK 및 Trading Widget SDK에는 독립적인 버전이 있습니다. `v1` 위젯 URL 이 Java SDK 버전 `0.3.0`이 아닙니다.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## 기존 통합

사용자 매핑, 원래 주문 및 자격 증명을 보존합니다. 생략된 환경 필드는 기존 프로덕션 동작을 유지합니다. 자금 조달, 명시적 시뮬레이션 자금 및 6가지 영구 쿼리에는 해당하는 새로운 모델과 방법이 필요합니다. 검토 [업그레이드 가이드](/ko/sdk/agent-sdk/java/upgrade) 기존 통합을 변경하기 전에.
