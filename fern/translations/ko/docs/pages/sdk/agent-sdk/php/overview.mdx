<h2 id="runtime">런타임</h2>

| 항목 | 가치 |
| --- | --- |
| 패키지 | sixmm/agent-SDK |
| 최소 PHP 버전 | PHP 7.4+ |
| 추천 PHP 버전 | PHP 8.1+ 또는 현재 지원되는 버전 |
| 필요한 확장 | ext-json, ext-curl |

PHP SDK 패키지 소스와 승인된 버전은 파트너 온보딩 시 제공됩니다. 패키지가 공개 Packagist에서 구매할 수 있다고 가정하지 마세요; 귀사에 제공된 작곡가 저장소를 구성하세요.

<h2 id="supported-scenarios">지원되는 시나리오</h2>

| 시나리오 | SDK 방법 |
| --- | --- |
| 사용자 결속 | 결박 |
| 고정 금액 이체 | 이송 |
| 전부 전부 전해 | transferAllOut |
| 역전송 | 뒷면 |
| 쿼리 순서 | queryOrder |
| 진입 URL | createEntryUrl |
| Webhook 검증 | WebhookVerifier::verify |

<h2 id="backend-integration-rules">백엔드 통합 규칙</h2>

- 비밀 관리자나 보호 환경 변수에서 `apiSecret` 로드.
- 사용자의 바인딩, 전송, 서명 및 webhook 로직이 브라우저 코드에서 배제됩니다.
- 자산 금액을 소수점 문자열로 사용하여 부동소수점 반올림을 피하세요.
- 불확실한 전송 결과를 쿼리할 때 원래 `agentOrderNo` 을 재사용.
- webhook 서명을 원시 요청 본체와 대조하여 디코딩하거나 변경하기 전에 검증합니다.
