<h2 id="responsibility-split">책임 분담</h2>

| 면적 | 소유주 | 주석 |
| --- | --- | --- |
| 컨테이너 생성 | 파트너 프론트엔드 | 명확한 너비와 높이가 있는 가시 요소를 제공하세요. |
| iframe 생성 | Trading Widget SDK | SDK이 iframe을 생성하고 관리합니다. |
| 트레이딩 UI | 6MM iframe | K-라인, 주문장부, 주문서, 포지션, 주문, 계정 데이터가 iframe 내에서 실행됩니다. |
| 디스플레이 제어 | Trading Widget SDK + 6MM iframe | PC 임베드 헤더와 하단 티커는 기본적으로 숨겨져 있습니다. 파트너는 `display` 을 이용해 셸 지역을 보여주거나 고급 거래 컨테이너를 숨길 수 있습니다. |
| 파트너 로그인 확인 | 파트너 백엔드 | 인증 증명을 발급하기 전에 파트너 사용자 세션을 검증하세요. |
| 임베드 토큰 발행 | 파트너 백엔드 + 에이전트 API | 파트너-토큰 모드에 추천합니다. |

<h2 id="versioning">버전 관리</h2>

공개 통합 경로는 v1 스크립트 URL 하에서 안정적으로 유지됩니다. 현재 v1 기능 세트에는 파트너 토큰, tokenProvider, entryUrlProvider, 디스플레이 컨트롤, 라이프사이클 이벤트, 인스턴스 메서드, 명령 이벤트가 포함됩니다.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">위젯을 언제 사용해야 하는지에 대해</h2>

파트너가 기존 웹 제품 내에 완전한 거래 인터페이스가 필요할 때 Trading Widget 선택하세요. 완전 맞춤형 거래 인터페이스를 구축하고 유지할 때는 REST API 및 WebSocket 문서를 활용하세요.

<h2 id="implementation-path">구현 경로</h2>

1. 다음에 따라 [Trading Widget 퀵 스타트](/ko/sdk/trading-widget/quick-start) 스크립트를 불러와서 가시적인 컨테이너를 생성하는 것입니다.
2. 구성 [파트너 토큰 인증](/ko/sdk/trading-widget/authentication) 파트너 백엔드를 통해서요.
3. 필요한 추가 [옵션 및 이벤트](/ko/sdk/trading-widget/options-events).
4. 사용 [인스턴스 메서드](/ko/sdk/trading-widget/instance-methods) 라이프사이클 및 런타임 제어를 위한 것입니다.
