## 방법 요약

| 방법 | 목적 |
| --- | --- |
| 파괴하다() | iframe 및 릴리스 이벤트 리스너를 제거합니다. |
| getState() | 현재 SDK 수명 주기 상태를 읽습니다. |
| whenReady() | iframe 초기화가 완료될 때까지 기다리세요. |
| setSymbol(기호) | iframe 내에서 거래 쌍을 전환하세요. |
| setTheme(테마) | iframe 테마 매개변수를 업데이트합니다. |
| setLocale(로케일) | iframe 언어를 전환하세요. |
| setSize(너비, 높이) | iframe 크기를 업데이트하세요. |
| 다시 로드() | 현재 iframe을 다시 로드합니다. |
| refreshAuth(이유) | 위젯 인증 새로 고침 흐름을 트리거합니다. |
| setTokenProvider(공급자) | 파트너 토큰 모드에서 사용되는 공급자를 교체합니다. |
| on(이벤트, 핸들러) | 런타임 이벤트를 구독하고 구독 취소 기능을 받으세요. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## 파괴하다()

iframe을 제거하고, 리스너를 지우고, 현재 인스턴스에 대해 한 번 파괴된 항목을 내보냅니다.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

위젯 인스턴스의 현재 수명 주기 상태를 읽습니다.

```js
const state = widget.getState()
```

반환 값에는 로드, 인증, 준비, 오류 및 삭제가 포함됩니다.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

종속 UI 로직을 실행하기 전에 iframe이 초기화를 완료할 때까지 기다립니다.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(기호)

iframe 내에서 거래 쌍을 전환하세요. iframe이 아직 초기화 중인 경우 SDK는 명령을 대기열에 추가하고 준비된 후 전송합니다.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(테마)

포함된 거래 iframe에서 사용되는 테마 매개변수를 업데이트합니다.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(로케일)

iframe 언어를 전환하세요. 지원되는 값은 en, en-US 및 zh-CN입니다.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(너비, 높이)

iframe DOM 크기를 업데이트하고 iframe에 새로운 외부 크기를 알립니다. 숫자 값은 px로 변환됩니다.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## 다시 로드()

현재 iframe을 다시 로드하고 다시 초기화될 때까지 기다립니다.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(이유)

iframe에 현재 인증 흐름을 새로 고치도록 요청하세요. 선택적 이유 값은 로깅 및 흐름 제어를 위해 전달됩니다.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(공급자)

파트너 토큰 모드에서 사용되는 tokenProvider를 교체합니다. SDK는 iframe이 새로운 포함 토큰을 요청할 때 공급자를 호출합니다.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(이벤트, 핸들러)

런타임 이벤트를 구독합니다. 반환된 함수는 리스너를 제거합니다.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## 현재 v1 런타임의 추가 메서드

| 방법 | 목적 |
| --- | --- |
| `whenRendered()` | iframe의 렌더링된 알림을 기다립니다. 이것은 준비와 별개입니다. |
| `setPage(page)` | 현재 인스턴스에서 지원되는 제품 페이지를 요청하세요. 자금환경은 바뀌지 않습니다. |
| `prepareForRecreate()` | 교체 준비를 위해 준비된 iframe을 요청하세요. Promise를 반환하고 사용할 수 없거나 통화 중이거나 시간 초과된 경우 거부할 수 있습니다. |
| `cancelRecreate()` | 보류 중/준비된 교체 흐름을 취소합니다. |
| `TradingWidget.validateOptions(options)` | 인스턴스를 생성하기 전에 초기화 옵션을 검증하세요. |

사용자 또는 실제/데모 환경 변경의 경우 기존 인스턴스를 삭제하고 대상 인증 및 모드를 사용하여 새 인스턴스를 생성합니다. `setPage`을 환경 스위치로 사용하지 마십시오. 선택적 방법을 사용하기 전에 기능을 확인하십시오.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
