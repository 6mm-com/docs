방문자가 지원을 입력하는 방법, 방문자가 보는 내용, 사용 가능한 지능형 서비스를 설정하세요. 설정 변경을 작은 릴리스로 처리하십시오. 이를 저장하고 실제 항목을 테스트한 후 결과를 확인하십시오.

<div className="sixmm-support-flow">

1. **설정 선택** — 변경하려는 동작에 대한 탭을 찾습니다.
2. **변경 사항 저장** — 영향을 받은 항목이나 서비스를 검토합니다.
3. **방문자로 테스트** — 실제 웹사이트를 열고 결과를 확인하세요.

</div>


<span id="configure-the-visitor-experience" data-sixmm-canonical-anchor="configure-the-visitor-experience" aria-hidden="true"></span>

## 방문자 경험 구성

**시스템 설정**을 엽니다. 사용 가능한 제어는 역할과 활성화된 테넌트 서비스에 따라 다릅니다.

| 꼬리표 | 구성할 항목 |
| --- | --- |
| 외관 및 통합 | 사용 가능한 시각적 및 항목 설정 |
| 홈페이지 및 카피 | 고객용 홈페이지 텍스트 및 안내 |
| 대화 및 시간 초과 | 대화 동작 및 시간 초과 제어 |
| 방문자 대화 | 방문자 입장 시 수집된 정보 및 프롬프트 |
| 지능형 서비스 | 테넌트에게 공개되는 AI, 검색 및 번역 기능 |
| 웹사이트 통합 | 도메인 허용 목록, 삽입 코드, 서명된 ID 및 언어/테마 통합 |
| MCP 연결 | 서비스 주소, 승인된 신청 및 철회 |

설정을 저장한 다음 방문자 항목에서 확인하세요. 미리보기 또는 성공적인 저장은 별도로 포함된 웹사이트가 이미 최신 설정을 사용하고 있음을 입증하지 않습니다.

<span id="keep-boundaries-clear" data-sixmm-canonical-anchor="keep-boundaries-clear" aria-hidden="true"></span>

## 경계를 명확하게 유지하세요

테넌트 설정은 테넌트의 고객 지원을 구성합니다. 플랫폼 전체 공급자 키, 기타 테넌트, 재충전 작업 또는 교환 거래 계정에 대한 액세스 권한을 부여하지 않습니다. MCP 현재 역할에서 허용하는 지원되는 구성 필드만 노출합니다. MCP을(를) 통해 도메인 허용 목록을 변경하려면 확인이 필요합니다.


<span id="plan-the-initial-setup" data-sixmm-canonical-anchor="plan-the-initial-setup" aria-hidden="true"></span>

## 초기 설정 계획

1. **외형 및 카피:** 눈에 보이는 브랜드, 홈페이지 안내, 지원 문구를 확인하세요. 실제로 제공하는 교환 서비스와 설명을 일관되게 유지하세요.
2. **방문자 입력:** 수집할 정보를 결정하고 사용 가능한 프롬프트 동작을 검토합니다. 해당하는 경우 신규 방문과 재방문을 모두 테스트합니다.
3. **접수 동작:** 실시간 대화를 처리하는 팀과 함께 세션 및 시간 초과 제어를 검토합니다.
4. **지능형 서비스:** 활성화된 테넌트 기능을 확인한 다음 대표적인 질문이나 번역을 테스트합니다. 구성된 스위치만으로는 업스트림 요청의 성공을 증명할 수 없습니다.
5. **웹사이트 통합:** 허용된 웹사이트 도메인을 확인하고 삽입 코드, 로그인 ID, 언어 및 테마에 대한 통합 가이드를 사용하세요.
6. **MCP:** 인증 계정과 사용 가능한 권한을 확인한 후에만 외부 AI를 연결하세요.

<span id="example-a-saved-change-is-not-visible-on-your-website" data-sixmm-canonical-anchor="example-a-saved-change-is-not-visible-on-your-website" aria-hidden="true"></span>

### 예: 저장된 변경사항이 웹사이트에 표시되지 않습니다.

먼저 테스트 중인 테넌트 및 방문자 항목을 확인합니다. 해당 항목을 다시 로드하고, 포함된 웹 사이트가 자체 언어나 테마를 전달하는지 확인하고, 의도한 구성이 저장되었는지 확인하세요. 액세스 실패의 경우 관련 없는 설정을 반복적으로 변경하기 전에 허용된 도메인 및 통합 구성을 검토하세요.

## 일반적인 질문

<AccordionGroup>

<Accordion title="설정 탭이 표시되지 않는 이유는 무엇입니까?">
계정 권한과 활성화된 테넌트 서비스가 사용 가능한 항목을 결정합니다. 다른 테넌트나 계정을 변경하기보다는 테넌트 관리자에게 해당 접근권한을 확인해 달라고 요청하세요.
</Accordion>

<Accordion title="모델 자격 증명 및 충전은 어디에서 관리되나요?">
공급자 자격 증명 및 플랫폼 잔액 조정은 테넌트 설정 외부에 있습니다. 플랫폼 운영자와 합의한 서비스 약정을 사용하세요.
</Accordion>

</AccordionGroup>
