## 방문자 경험 구성

**시스템 설정**을 엽니다. 사용 가능한 제어는 역할과 활성화된 테넌트 서비스에 따라 다릅니다.

| 꼬리표 | 구성할 항목 |
| --- | --- |
| 외관 및 통합 | 사용 가능한 시각적 및 항목 설정 |
| 홈페이지 및 카피 | 고객용 홈페이지 텍스트 및 안내 |
| 대화 및 시간 초과 | 대화 동작 및 시간 초과 제어 |
| 방문자 대화 | 방문자 입장 시 수집된 정보 및 프롬프트 |
| 지능형 서비스 | 테넌트에게 공개되는 AI, 검색 및 번역 기능 |
| 웹사이트 통합 | 도메인 허용 목록, 삽입 코드, 서명된 ID 및 언어/테마 통합 |
| MCP 연결 | 서비스 주소, 승인된 신청 및 철회 |

설정을 저장한 다음 방문자 항목에서 확인하세요. 미리보기 또는 성공적인 저장은 별도로 포함된 웹사이트가 이미 최신 설정을 사용하고 있음을 입증하지 않습니다.

<span id="keep-boundaries-clear" data-sixmm-canonical-anchor="keep-boundaries-clear" aria-hidden="true"></span>

## 경계를 명확하게 유지하세요

테넌트 설정은 테넌트의 고객 지원을 구성합니다. 플랫폼 전체 공급자 키, 기타 테넌트, 재충전 작업 또는 교환 거래 계정에 대한 액세스 권한을 부여하지 않습니다. MCP 현재 역할에서 허용하는 지원되는 구성 필드만 노출합니다. MCP을(를) 통해 도메인 허용 목록을 변경하려면 확인이 필요합니다.
