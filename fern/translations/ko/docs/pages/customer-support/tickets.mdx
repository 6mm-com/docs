## 올바른 기록을 선택하세요

**티켓 관리**를 열고 해당 탭을 선택하세요.

| 기록 | 목적 |
| --- | --- |
| 에이전트 티켓 | 지원팀이 생성하고 유지 관리하는 작업 |
| 사용자 티켓 | 후속 조치를 위해 방문자가 제출한 질문 |
| 사용자 피드백 | 피드백 항목을 통해 제출된 제안 또는 문제 |

<span id="handle-a-case" data-sixmm-canonical-anchor="handle-a-case" aria-hidden="true"></span>

## 케이스 처리

기록에 있는 설명, 연락처 세부정보, 관련 대화 및 첨부 파일을 읽어보세요. 이를 적절한 처리기에 할당하고 작업이 진행됨에 따라 상태를 업데이트합니다. 상담원 티켓에 지원되는 편집 컨트롤을 사용하세요. 사용자 티켓과 피드백에는 고유한 사용 가능한 작업이 있습니다.

상태를 업데이트한다고 해서 방문자가 이메일이나 채팅 응답을 받았다는 사실이 입증되는 것은 아닙니다. 필요한 경우 사용 가능한 통신 채널을 통해 응답을 보내고 결과를 확인합니다. 승인된 테넌트 워크플로 내에서 개인 정보를 유지하세요.

<span id="use-mcp-for-triage" data-sixmm-canonical-anchor="use-mcp-for-triage" aria-hidden="true"></span>

## 분류에는 MCP를 사용하세요.

연결된 AI에게 해결되지 않은 사례를 나열하고 문제별로 그룹화하여 제안된 답변을 준비하도록 요청하세요. 할당 및 상태 변경 사항을 실제 사례에 적용하기 전에 검토하세요. 상담원 티켓 생성과 사용자 티켓 제출은 서로 다른 작업 흐름입니다. 하나의 도구가 다른 도구를 지원한다는 의미는 아닙니다. MCP을(를) 통해 티켓을 삭제하려면 확인이 필요합니다.
