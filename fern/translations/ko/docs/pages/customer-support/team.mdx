## 지원팀을 구성하세요

**상담원 관리**를 사용하여 상담원 계정, 역할, 빠른 답변을 유지하세요. 각 사람에게 실제로 필요한 모듈과 작업을 기반으로 역할을 할당합니다. 팀 전체에 하나의 관리자 로그인을 공유하는 대신 계정 자격 증명을 개인별로 유지하세요.

역할을 변경한 후 영향을 받는 계정으로 확인하세요. 표시되는 메뉴, 대화 모니터링, 콘텐츠 편집 및 설정 액세스가 다를 수 있습니다. 계정 상태, 세션 소유권 및 필드 수준 확인은 메뉴가 존재하는 것 이상으로 계속 적용됩니다.

## MCP는 동일한 ID를 상속받습니다.

MCP 연결은 승인하는 테넌트 및 에이전트 계정에 바인딩됩니다. AI는 별도의 관리자 역할을 받지 않습니다. 이 서비스는 통화에 대한 계정 권한을 재평가합니다. 사용할 수 없는 도구는 이름을 추측하거나 다른 테넌트 ID를 제공하여 활성화할 수 없습니다.

**시스템 설정 → MCP 연결**에서 연결된 애플리케이션을 관리하세요. 더 이상 필요하지 않은 연결을 취소합니다. 브라우저에서 로그아웃한다고 해서 외부 AI 애플리케이션의 인증이 자체적으로 취소되는 것은 아닙니다.

MCP을(를) 통해 역할 및 에이전트 계정을 변경하려면 확인이 필요합니다. MCP을 통해 에이전트 생성 시 초기 비밀번호는 AI에 반환되지 않고 백엔드 확인 페이지에서 사용자가 입력합니다.
