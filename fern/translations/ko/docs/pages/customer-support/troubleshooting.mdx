## 콘솔 및 방문자 지원

| 징후 | 먼저 확인하세요 |
| --- | --- |
| 메뉴가 없습니다 | 계정 역할 및 테넌트 서비스 가용성 |
| 위젯이 열리지 않습니다 | 생성된 스크립트 URL, 앱 키, 허용된 도메인 및 브라우저 오류 |
| 봇은 대형 모델을 사용하지 않습니다. | 실제 매칭 단계, 지능형 서비스 스위치 및 관련 구성 |
| 대답은 오래된 규칙을 사용합니다 | 원본 기사, 출판 상태, FAQ 텍스트, 번역 및 검색 상태 |
| 번역이 없습니다 | 대상 언어, 번역 전환, 저장된 번역 및 서비스/잔액 가용성 |
| 벡터 생성 실패 | 서비스 가용성 및 검색 상태 오류를 식별하지 않고 반복적으로 재구축하는 것을 방지합니다. |
| 연락처 필드가 비어 있습니다. | 해당 필드가 실제로 수집되었는지 여부 연락처와 입력 이메일을 구별하세요 |

## MCP 연결 및 통화

| 징후 | 다음 단계 |
| --- | --- |
| 브라우저에서 엔드포인트를 열면 오류가 반환됩니다. | 이는 로그인 페이지가 아닌 프로토콜 엔드포인트입니다. 호환되는 MCP 클라이언트에 추가하세요. |
| 승인을 시작할 수 없습니다. | 정확한 엔드포인트, 클라이언트의 스트리밍 가능 HTTP/OAuth 지원 및 브라우저 로그인 흐름을 확인하세요. |
| 승인되지 않았거나 만료된 연결 | 취소 및 만료를 확인하세요. 애플리케이션을 통해 다시 연결 |
| 도구가 없거나 액세스가 거부되었습니다. | 승인 계정 역할과 기록 범위를 확인하세요. 도구 목록 새로 고침 |
| 승인 대기 중 | 반환된 승인 링크를 열고 백엔드에서 검토하세요. |
| 내용이 변경됨 | 최신 기록을 읽고, 다시 미리 보고, 새로운 의도된 작업을 제출하세요. |
| 요청 시간이 초과되었습니다. | 재시도하거나 실패를 가정하기 전에 작업 상태 쿼리 |
| 쓰기 로그 없음 | 읽기, 승인 대기 중, 완료된 쓰기를 구별합니다. 작업 로그에서 필터를 확인하세요. |

## 지원팀에 문의하기 전에

시간 및 시간대, 영향을 받는 테넌트/계정, 페이지 또는 도구 이름, 사용 가능한 경우 작업 ID 및 정확한 오류를 수집합니다. 수정된 스크린샷이나 재현 단계를 포함하세요. 비밀번호, 인증 코드, 무기명 토큰 또는 서명 비밀을 보내지 마세요.

쓰기를 진단할 때 작은 테스트 기록을 시도해 보세요. 필요한 경우 일반적인 확인 흐름을 사용하여 결과를 확인하고 생성한 테스트 데이터만 정리합니다.
