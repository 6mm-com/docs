## 작업 공간을 준비하세요

열려 있는 [콘솔](https://csadmin.6mm.com/) 테넌트에게 제공된 계정으로. 로그인 화면에서 요청하는 로그인 및 보안 설정을 완료하세요. 메뉴에 접근할 수 없는 경우 테넌트 관리자에게 역할 확인을 요청하세요.

1. **팀을 설정합니다.** 상담원 관리에서 필요한 역할과 상담원 계정을 만듭니다. 대화를 보고, 콘텐츠를 편집하고, 설정을 관리할 수 있는 사람을 확인하세요.
2. **비즈니스 지식을 준비합니다.** 콘텐츠 관리에서 계정 액세스, 입출금 절차, 거래 규칙, 수수료 및 지원 에스컬레이션에 대한 카테고리와 기사를 만듭니다. 사용자가 봐야 할 자료를 검토하고 게시합니다.
3. **자동화를 구성합니다.** 시스템 설정에서 필요한 지능형 서비스를 활성화합니다. Bot 구성에서 FAQ, 벡터 일치, AI 응답 및 ID 응답을 검토합니다.
4. **언어를 준비하세요.** 기본 언어와 기본 언어를 선택하고, 도움말 콘텐츠를 번역하고, 용어, 숫자, 링크를 검토하세요.
5. **웹사이트를 연결합니다.** 웹사이트 통합에 사이트를 추가하고 테넌트가 생성한 포함 코드를 복사합니다. 자신의 앱 키를 사용하세요.
6. **실행 전 테스트.** Bot Configuration의 흐름 테스트를 사용한 다음 실제 방문자 항목을 사용합니다. 알려진 질문, 후속 조치, 다른 언어, 인력 지원 및 티켓 제출을 확인하세요.

## 출시 승인

| 시험 | 예상되는 결과 |
| --- | --- |
| 문서화된 거래 규칙 | 응답에는 조건, 숫자 및 예외가 유지됩니다. |
| 알 수 없는 계정 관련 문제 | 발명된 잔액이나 거래 결과가 없습니다. 사용자는 적절한 다음 단계를 얻습니다. |
| 외국어 질문 | 활성화된 언어로 적절한 답변 또는 상담원 번역 |
| 사람의 지원을 받을 수 없습니다. | 티켓 등 구성된 대안을 사용할 수 있습니다. |
| 제한된 에이전트 계정 | 허용된 메뉴와 기록만 접근 가능 |
| 서비스 이용 | 관련 통화가 사용량 및 청구에 표시됩니다. |

기본 워크플로가 작동한 후 MCP를 연결합니다. 비즈니스 콘텐츠에 쓰기를 사용하기 전에 읽기 전용 쿼리로 시작한 다음 테스트 초안을 작성하세요.
