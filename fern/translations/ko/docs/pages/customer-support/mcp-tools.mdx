## 귀하의 역할에 맞는 사용 가능한 도구

표에는 지원되는 최대 범위가 설명되어 있습니다. AI 애플리케이션은 인증 계정에 허용된 도구만 ​​수신합니다. 라이브 도구 목록과 해당 매개변수 스키마를 계약으로 사용합니다. 새로운 콘솔 기능은 자동으로 MCP 도구가 아닙니다.

| 콘솔 모듈 | 지원되는 작업 |
| --- | --- |
| 온라인 대화 | 세션, 메시지 및 대기열 정보를 읽습니다. 할당, 가입, 인수 및 양도; 메시지 보내기; 평가 초대; 업로드 권한을 관리합니다. 메시지 인식/번역 지원되는 파일 업로드 |
| 티켓 및 피드백 | 상태를 쿼리, 할당, 업데이트하고 사용자 티켓과 피드백을 삭제합니다. 상담원 티켓 생성, 읽기, 업데이트, 할당 및 삭제 |
| 대화 기록 | 세션 및 메시지 쿼리 단일 세션 또는 여러 세션 삭제 |
| 콘텐츠 관리 | 카테고리, 기사, 인기 질문, 질문 카테고리, 기능 카드, 공지 사항 및 셀프 서비스 항목을 읽고 유지합니다. 기사 게시/게시 취소 |
| 언어 번역 | 소스, 번역 및 완료 상태를 읽습니다. 지원되는 번역을 저장하거나 지웁니다. 자동 번역을 호출합니다. 지원되는 언어 설정 관리 |
| 봇 구성 | 지원되는 설정 및 FAQ 읽기, 유사한 질문 유지, 답변 테스트, 검색 상태 검사, 인덱스 업데이트 및 벡터 재구축 |
| 에이전트 관리 | 지원되는 상담원, 역할, 빠른 답변 유지 |
| 시스템 설정 | 읽기/쓰기 허용 모양, 복사, 대화, 방문자 입력, 지능형 서비스 및 웹 사이트 허용 목록 필드 |
| 통계 | 읽기 전용 개요 및 지원되는 통계 쿼리 |
| 사용량 및 청구 | 읽기 전용 잔액, 사용량, 거래 및 가격 |
| 작업 로그 | 읽기 전용 작업 목록 및 세부정보 |

## 쓰기 및 확인

삭제, 게시/게시 취소, 게시된 기사 편집, 메시지 보내기, 역할/계정 관리, 웹사이트 허용 목록 변경, 벡터 재구축 및 플랫폼 자동 번역에는 도구에 지정된 백엔드 확인이 필요합니다. 확인 없이 쓰기를 해도 데이터가 즉시 변경될 수 있습니다. AI에게 실행을 요청하기 전에 의도된 범위를 검토하세요.

MCP는 플랫폼 관리, 테넌트 폐쇄/삭제, 잔액 재충전, 청구서 편집 또는 공급자 비밀 액세스를 제공하지 않습니다. 파일 도구는 형식 확인과 배포된 크기 제한을 적용합니다. 현재 구현에서는 Base64를 통해 최대 10MB의 단일 파일을 지원합니다. 자체 제한이 허용하는 더 큰 파일에는 콘솔을 사용하십시오.

## 예시 작업

- 링크와 금액을 유지하면서 누락된 번역과 초안 일본어 버전을 나열합니다.
- 해결되지 않은 사용자 티켓을 찾고 아직 적용하지 않은 채 할당을 제안하세요.
- 기존 카테고리에 기술 자료 초안을 생성한 다음 해당 제목과 ID를 표시합니다.
- 정확한 날짜 범위로 최근 지원 통계를 요약합니다.

플랫폼 AI, 자동 번역, 벡터 연산에는 기존 서비스 요금이 발생할 수 있습니다. 연결된 AI 제공업체의 자체 사용법은 별개입니다.
