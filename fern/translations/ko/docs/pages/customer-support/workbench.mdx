첫 번째 검토부터 전달까지 들어오는 대화를 처리합니다. 이 작업 공간을 사용하여 질문을 이해하고, 인력 지원을 조정하고, 대화를 맥락에 맞게 유지하세요.

<div className="sixmm-support-flow">

1. **대화 읽기** — 질문과 최근 메시지를 검토하세요.
2. **핸들러 선택** — 가입 또는 이전하기 전에 소유권을 확인하세요.
3. **답장 및 후속 조치** — 답변하고 피드백을 요청하거나 티켓을 계속 진행하세요.

</div>


<span id="work-from-one-conversation-workspace" data-sixmm-canonical-anchor="work-from-one-conversation-workspace" aria-hidden="true"></span>

## 하나의 대화 작업 공간에서 작업

**온라인 대화**를 엽니다. 휴먼, 모니터링 및 봇 탭은 계정에 표시되는 대화를 구성합니다. 모니터링 액세스 및 대화 소유권은 계속 적용됩니다. 에이전트는 모든 테넌트 대화를 자동으로 보지 않습니다.

1. 대화를 선택하고 최근 메시지와 사용 가능한 방문자 정보를 읽어보세요.
2. 귀하의 역할이 허용하는 작업을 사용하여 가입, 인수, 할당 또는 이전하십시오.
3. 텍스트, 지원되는 첨부 파일 또는 빠른 답장으로 답장하세요. 필요한 경우 언어 인식 및 번역을 사용하십시오.
4. 방문자 업로드 권한을 관리하고 가능한 경우 평가를 초대합니다.
5. 추가 작업이 필요한 경우 대화를 완료하거나 티켓을 생성/후속 조치하세요.

<span id="understand-visitor-information" data-sixmm-canonical-anchor="understand-visitor-information" aria-hidden="true"></span>

## 방문자 정보 이해

읽을 수 있는 방문자 이름은 확인된 거래소 계정의 증거가 아닌 표시 라벨입니다. 로그인한 사용자 ID, 참가 이메일, 지원 시 제공된 연락처 이메일을 구별합니다. 사례를 이해하려면 사용 가능한 세션 세부정보를 사용하세요. 동일한 이메일을 가진 두 명의 방문자가 동일한 인증된 사용자라고 가정하지 마십시오.

보내기 전에 현재 대화를 확인하세요. AI-외부 MCP 클라이언트에서 생성된 텍스트는 단순히 AI 채팅에 표시된다는 이유만으로 전송되지 않습니다. MCP를 통해 전송하려면 플랫폼의 확인 흐름이 필요합니다.

## 사람의 지원이 불가능한 경우

방문자 항목은 구성된 가용성 및 대체 동작을 따릅니다. 티켓은 나중에 처리할 수 있도록 질문을 보존할 수 있습니다. 표시된 지침을 실제 인력 배치 및 대응 정책과 일치하게 유지하십시오. 지원되지 않는 응답 시간을 약속하지 마십시오.

## 어떤 작업 공간을 사용할지 파악

| 작업공간 | 여기서해야 할 일 |
| --- | --- |
| 인간 | 사용 가능한 대화를 검토하고 할당된 작업을 처리하세요. 답변하기 전에 현재 상담원을 확인하세요. |
| 모니터링 | 모니터링 권한 내에서 대화를 검토하세요. 세션을 보는 것과 인계받는 것은 다른 작업입니다. |
| 봇 | 사람이 직접 처리해야 하는지 결정하기 전에 질문과 봇의 응답을 검사하세요. |

<span id="example-a-user-asks-about-exchange-integration" data-sixmm-canonical-anchor="example-a-user-asks-about-exchange-integration" aria-hidden="true"></span>

### 예: 사용자가 Exchange 통합에 대해 문의합니다.

1. 문서 요청과 계정별 문제를 구별하려면 대화를 읽어보세요.
2. 검토된 지식 답변이나 적절한 빠른 답변을 사용하세요. 보내기 전에 플랫폼 이름, 링크, 금액을 확인하세요.
3. 다른 언어의 경우 사용 가능한 인식 및 번역 컨트롤을 사용하고 응답하기 전에 의미를 검토하세요.
4. 동료가 계속해야 하는 경우 권한 범위 내에서 이전하거나 할당하세요. 문제에 대해 나중에 조사가 필요한 경우 적절한 티켓 워크플로를 계속 진행하세요.

**종료 전:** 사용자가 응답을 받았는지 확인하고, 완료되지 않은 질문이 있는지 확인하고 후속 조치를 위해 관련 대화 번호를 보관하세요.
