## 올바른 콘텐츠 유형을 선택하세요

**콘텐츠 관리**를 엽니다. 지식 카테고리는 기사를 구성합니다. 다른 콘텐츠 유형은 간결한 답변, 탐색 및 서비스 진입점을 제공합니다.

| 콘텐츠 | 일반적인 사용 |
| --- | --- |
| 지식 문서 및 카테고리 | 온보딩, 전송, 거래 규칙 및 문제 해결에 대한 자세한 가이드 |
| 뜨거운 질문 | 자주 묻는 질문에 대한 짧은 답변 |
| 질문 카테고리 및 기능 카드 | 주제를 그룹화하고 사용자에게 관련 정보를 안내합니다. |
| 공지사항 | 고객 대상 공지 게시 |
| 셀프 서비스 항목 | 사용자에게 사용 가능한 지원 작업이나 리소스를 안내합니다. |

## 지식 창출 및 유지

1. 적절한 카테고리를 생성하거나 선택합니다. 기사 작성 시 카테고리를 포함한 필수 항목을 작성해 주세요.
2. 범위, 조건, 단계 및 예외를 포함하여 제목과 본문을 작성합니다. 가정된 교환 동작보다는 실제 비즈니스 규칙을 사용하십시오.
3. 초안을 저장하고 검토합니다. 사용자가 준비되면 게시하세요. 적절한 경우 오래된 자료의 게시를 취소합니다.
4. 변경 후 번역을 유지하고 검색/색인 상태를 확인하세요. 봇 흐름 및 방문자 채팅에서 질문을 테스트합니다.

예를 들어, 철회 안내서에는 사용자가 선택해야 하는 네트워크, 주소를 얻을 수 있는 위치, 적용 가능한 비즈니스 제한 사항 및 지원 문의 방법이 설명되어 있어야 합니다. 처리 시간이나 수수료를 고안하지 마십시오.

## 콘텐츠의 일관성 유지

소스를 업데이트한다고 해서 모든 번역이 최신임을 증명하는 것은 아닙니다. 영향을 받은 번역 및 관련 FAQ 답변을 검토하세요. 게시된 기사, 인기 질문 답변 및 발표에서는 호환되지 않는 규칙을 설명해서는 안 됩니다. 삭제하기 전에 해당 콘텐츠가 사용자 탐색이나 답변에 여전히 필요한지 확인하세요. MCP는 동일한 허용된 콘텐츠 작업을 지원합니다. 보다 [MCP 도구](/ko/customer-support/mcp-tools).
