## 사용 가능한 도구를 찾아보세요

OAuth 인증 후 스트리밍 가능한 HTTP가 있는 MCP 클라이언트를 사용하여 연결을 초기화하고 `tools/list`을 통해 도구를 얻습니다. Call tools through `tools/call`. REST URL 에서 매개변수를 파생시키는 대신 반환된 각 입력 스키마를 읽으십시오. 읽기에서 가져온 ID는 일반적으로 경로 인수에 대한 10진수 문자열입니다. 본문 내부의 숫자 필드는 스키마에서 요구하는 경우 숫자로 유지됩니다.

아래 예는 초기화 후의 JSON-RPC 도구 메시지이며 완전한 독립 실행형 HTTP 요청이 아닙니다. 클라이언트는 액세스 토큰과 프로토콜 헤더를 제공합니다. 예시 ID를 자신의 테넌트에 대해 반환된 레코드로 바꿉니다.

<span id="read-categories" data-sixmm-canonical-anchor="read-categories" aria-hidden="true"></span>

## 카테고리 읽기

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "knowledge_get_categories",
    "arguments": {}
  }
}
```

<span id="create-a-draft" data-sixmm-canonical-anchor="create-a-draft" aria-hidden="true"></span>

## 초안 만들기

읽기 결과에서 기존 카테고리를 선택하세요. The category is required. 게시하고 필요한 확인을 완료하려는 경우가 아니면 게시 상태를 설정하지 마세요.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "knowledge_create_article",
    "arguments": {
      "requestId": "support-demo-create-001",
      "body": {
        "title": "Withdrawal guide draft",
        "content": "Reviewed withdrawal instructions go here.",
        "categoryId": 12,
        "status": "draft"
      }
    }
  }
}
```

<span id="preview-an-update-or-deletion" data-sixmm-canonical-anchor="preview-an-update-or-deletion" aria-hidden="true"></span>

## 수정 또는 삭제 미리보기

기사를 먼저 읽어보세요. 새 요청 ID를 포함하여 의도된 정확한 쓰기를 미리 봅니다. 미리보기는 작업을 실행하지 않습니다.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "mcp_preview",
    "arguments": {
      "tool": "knowledge_delete_article",
      "arguments": {
        "id": "123",
        "requestId": "support-demo-delete-001"
      }
    }
  }
}
```

의도한 대상이나 매개변수를 변경하지 않고 반환된 `version`를 `expectedVersion`에 복사합니다.

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "knowledge_delete_article",
    "arguments": {
      "id": "123",
      "requestId": "support-demo-delete-001",
      "expectedVersion": "REPLACE_WITH_THE_64_CHARACTER_VERSION_FROM_PREVIEW"
    }
  }
}
```

The placeholder is not a valid version. 미리보기에서 반환된 실제 64자 값을 사용합니다.

## 확인 및 결과 조회

결과가 `awaiting_approval`로 보고되면 `approvalUrl`을 열고 인증 계정으로 로그인한 후 작업을 검토하세요. Only approving it runs the pending operation. 현재 확인은 15분 후에 만료됩니다. Rejection or expiry does not execute the write.

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "mcp_operation",
    "arguments": {
      "operationId": "REPLACE_WITH_RETURNED_OPERATION_ID"
    }
  }
}
```

도구 출력은 JSON를 포함하는 텍스트 콘텐츠로 전달됩니다. 그것과 `isError` 플래그를 검사하십시오. HTTP 응답이나 승인 링크만으로는 성공을 증명할 수 없습니다. 작업 상태를 읽고 유용할 경우 영향을 받은 레코드를 쿼리합니다.

## 안전하게 다시 시도하세요

동일한 쓰기의 네트워크 재시도에 대해 동일한 `requestId` 및 인수를 재사용합니다. 다른 작업에 재사용하지 마세요. 콘텐츠가 변경된 경우 다시 읽고 미리 본 다음 새 요청 ID로 새로운 의도된 작업을 제출하세요. 응답이 손실되거나 작업이 계속 실행 중인 경우 수행할 작업을 결정하기 전에 상태 및 비즈니스 기록을 쿼리하세요. 시간 초과가 아무 일도 일어나지 않았다는 것을 의미한다고 가정하지 마십시오.

AI 클라이언트는 일반적으로 사용자를 위해 이 프로토콜을 수행합니다. 이러한 세부 정보는 클라이언트 개발자 및 도구 워크플로 진단을 위한 것입니다.
