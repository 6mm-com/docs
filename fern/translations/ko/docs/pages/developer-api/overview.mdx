<h2 id="documentation-areas">문서 영역</h2>

| 면적 | 다루는 내용 |
| --- | --- |
| 통합 설정 | 서비스 주소, 요청 관습, 응답 형태, 접근 모드. |
| 인증 및 보안 | JWT, API Key 권한이 있고, HMAC 서명, 재생 보호, 시간 동기화가 포함됩니다. |
| REST API | 공개 엔드포인트, 사용자/계정 데이터, 주문, 포지션, 시장 데이터. |
| WebSocket | 연결 수명 주기, 공개 시장 스트림, 그리고 개인 사용자 스트림. |
| 참고 및 문제 해결 | 열거, 오류 코드, 그리고 실용적인 통합 권고사항. |

<h2 id="production-checklist">생산 체크리스트</h2>

- 비밀 API 백엔드에만 저장합니다.
- 서명 요청 전 서버 시간 동기화.
- 페이지에 명시적으로 달리 명시하지 않는 한 모든 수치 정밀도 필드를 문자열로 취급합니다.
- 멮등성, 요청 ID, 순서 흐름을 중심으로 구조화된 로그를 사용합니다.
- 운영 시스템에서 최신 상태를 유지해야 하는 WebSocket 스트림에 구독합니다.
- 실행 전에 오류 코드를 검토하고 동작을 재시도합니다.
