<h2 id="public-endpoints">공개 엔드포인트</h2>

| 종착점                   | 방법 | 경로                                        | 설명                                                    |
| -------------------------- | ------ | ------------------------------------------- | -------------------------------------------------------------- |
| 서비스 버전            | GET    | `/v1/version`                               | 서비스 버전 정보 받기                                |
| 서버 시간                | GET    | `/v1/time`                                  | 서버 시간을 쌓으세요                                                |
| 사용자 로그인                 | POST   | `/v1/public/user/login`                     | 사용자 이름과 비밀번호를 사용해 `accessToken`              |
| 새로고침 토큰              | POST   | `/v1/public/user/refresh-token`             | 쿠키를 통한 로그인 상태 새로고침                                 |
| 에이전트 티켓 교환      | POST   | `/v1/public/agent-sso/exchange-ticket`      | 에이전트 입장권을 로그인 상태로 교환하세요              |
| 에이전트 임베드 토큰 교환 | POST   | `/v1/public/agent-sso/exchange-embed-token` | 내장 거래 단기 토큰을 로그인 상태로 교환합니다 |
| 심볼 구성       | GET    | `/v1/public/market/symbols`                 | 심볼, 거래 규칙, 수수료 등급 구성을 확인하세요         |
| 자금 조달 요율 구성 | GET    | `/v1/public/market/funding-rate`            | 조회 자금 지원 요율 구성                               |
| 현재 자금 지원 비율       | GET    | `/v1/public/market/funding-rate/current`    | 페이지네이트 현재 자금 지원 요율                                 |
| 자금 지원 이력       | GET    | `/v1/public/market/funding-rate/history`    | 자금 조회 이력                                     |
| 클라인스                     | GET    | `/v1/public/market/klines`                  | 거래 가격, 지수 가격, 또는 마크 가격 Klines 조회           |
| PnL 리더보드            | GET    | `/v1/public/leaderboard/pnl`                | 쿼리 7 / 30 / 90일 PnL 리더보드                          |

<h2 id="private-user-endpoints">개인 사용자 엔드포인트</h2>

별도 명시가 없는 한, 다음 엔드포인트들은 JWT 또는 API Key 서명을 사용할 수 있습니다.

| 종착점                 | 방법 | 경로                                      | 허가   | 설명                                 |
| ------------------------ | ------ | ----------------------------------------- | ------------ | ------------------------------------------- |
| 사용자 정보                | GET    | `/v1/private/user/info`                   | 읽기         | 현재 사용자 프로필 조회                  |
| 사용자 자산              | GET    | `/v1/private/user/asset`                  | 읽기         | 지갑 잔액 및 마진 사용 조회       |
| listenKey 만들기         | POST   | `/v1/private/user/listen-key`             | 읽기         | 개인 WebSocket 인증 키 생성 |
| 갱신 listenKey          | PUT    | `/v1/private/user/listen-key`             | 읽기         | 타당성을 확장listenKey                   |
| 클로즈 listenKey          | DELETE | `/v1/private/user/listen-key`             | 읽기         | 클로즈 listenKey                             |
| 계정 변경 기록      | GET    | `/v1/private/user/account-change-log`     | 읽기         | 자금 이동 기록 조회                 |
| 30일 거래량 통계 | GET    | `/v1/private/user/volume-stats`           | 읽기         | 최근 30일 거래 거래량과 수수료 조회 |
| 밸런스 역사          | GET    | `/v1/private/user/balance-history`        | 읽기         | 쿼리 밸런스 이력                       |
| 무역 개요           | GET    | `/v1/private/user/trade-overview`         | 읽기         | PnL, 거래량, 자산 추세 조회          |
| 자산 개요 요약   | GET    | `/v1/private/user/asset/overview/summary` | 읽기         | 자산 요약 지표 조회                 |
| 자산 개요 추세     | GET    | `/v1/private/user/asset/overview/trend`   | 읽기         | 자산 추세 조회                           |
| 좋아하는 기호를 저장하세요    | POST   | `/v1/private/user/favorite-symbols`       | 읽기         | 좋아하는 기호를 덮어쓰기                  |
| 좋아하는 상징을 받아보세요     | GET    | `/v1/private/user/favorite-symbols`       | 읽기         | 즐겨찾기 기호 쿼리                      |
| 로그아웃                   | POST   | `/v1/private/user/logout`                 | JWT + 쿠키 | 로그인 상태 해제                           |

<h2 id="api-key-management-endpoints">API Key 관리 엔드포인트</h2>

API Key 관리 엔드포인트는 JWT만 받습니다.

| 종착점            | 방법 | 경로                                  | 설명                                         |
| ------------------- | ------ | ------------------------------------- | --------------------------------------------------- |
| API Key 만들기      | POST   | `/v1/private/user/api-key/create`     | API Key창조 ; `apiSecret` 한 번만 반환됩니다   |
| API Key 목록        | GET    | `/v1/private/user/api-key/list`       | 현재 사용자의 API 키를 조회                       |
| 업데이트 API Key      | PUT    | `/v1/private/user/api-key/update`     | 라벨, 권한을 업데이트하고, 화이트리스트 IP , 상태 |
| 삭제 API Key      | POST   | `/v1/private/user/api-key/delete`     | 지정된 API Key을 삭제하세요                          |
| 모든 API 키를 삭제하세요 | POST   | `/v1/private/user/api-key/delete-all` | 현재 사용자의 모든 API 키를 삭제하세요             |

<h2 id="order-endpoints">순서 종료점</h2>

주문 엔드포인트는 거래 허가가 필요합니다.

| 종착점                    | 방법 | 경로                                  | 설명                                                       |
| --------------------------- | ------ | ------------------------------------- | ----------------------------------------------------------------- |
| 단일 순서 쿼리          | GET    | `/v1/private/order`                   | 정확한 쿼리 `symbol + orderId/clientOrderId`                   |
| 주문하기                 | POST   | `/v1/private/order/place`             | 지정가 또는 시장가 주문                                             |
| 위치 조건 순서       | POST   | `/v1/private/order/place-condition`   | 손절매, 이익 실현, 트레일링 스톱 및 기타 조건 주문 |
| 전략 순서        | POST   | `/v1/private/order/place-strategy`    | OTO / OCO / OTOCO 전략 순서                                  |
| 배치 주문          | POST   | `/v1/private/order/batch-place`       | 여러 개의 일반 주문을 제출하세요                                     |
| 주문 취소                | POST   | `/v1/private/order/cancel`            | 지정된 정상 순서를 취소한다                                   |
| 명령 개정                 | POST   | `/v1/private/order/move`              | 일반 대기 주문 가격과 수량을 수정하세요                    |
| 배치 수정 명령          | POST   | `/v1/private/order/batch-move`        | 동일한 심볼에 대해 일반 대기 명령을 배치 수정합니다            |
| 주문 취소 배치         | POST   | `/v1/private/order/batch-cancel`      | 일반 주문 취소                                        |
| 모두 취소하세요                  | POST   | `/v1/private/order/batch-cancel-all`  | 유형별 주문 취소 배치                                       |
| 취소 조건 명령      | POST   | `/v1/private/order/cancel-condition`  | 지정된 조건 순서를 취소합니다                                |
| 현재 정상 순서       | GET    | `/v1/private/order/current`           | 현재 정상 대기 명령 조회                               |
| 현재 상태 명령    | GET    | `/v1/private/order/current-condition` | 현재 트리거되지 않은 상태 명령 조회                        |
| 역사적 정상 순서    | GET    | `/v1/private/order/history`           | 페이지네이트 역사적 정상 순서                                 |
| 역사적 상태 명령 | GET    | `/v1/private/order/history-condition` | 페이지네이트 역사적 상태 명령                              |
| 무역 기록               | GET    | `/v1/private/order/trades`            | 페이지네이트 무역 기록                                            |
| 전략 명령 세부 사항       | GET    | `/v1/private/order/strategy`          | 쿼리 전략 순서와 하위 순서                               |

<h2 id="position-endpoints">위치 종료점</h2>

포지션 엔드포인트는 거래 허가가 필요합니다.

| 종착점          | 방법 | 경로                               | 설명                                  |
| ----------------- | ------ | ---------------------------------- | -------------------------------------------- |
| 마진 모드 설정   | POST   | `/v1/private/position/margin-mode` | 스위치 분리 / 교차 마진               |
| 지렛대 설정      | POST   | `/v1/private/position/leverage`    | 심볼 레버리지 설정                          |
| 위치 설정 | GET    | `/v1/private/position/settings`    | 심볼에 대한 쿼리 레버리지 및 마진 모드  |
| 현재 직책 | GET    | `/v1/private/position/positions`   | 현재 위치 조회                      |
| 지위 역사  | GET    | `/v1/private/position/history`     | 과거 위치 및 근접 기록 조회 |
