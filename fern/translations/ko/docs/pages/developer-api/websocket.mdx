<h2 id="service-endpoint">서비스 엔드포인트</h2>

```
wss://ws.6mm.com/ws
```

WebSocket 채널은 공용 채널과 비공개 채널로 나뉩니다:

| 유형             | 인증              | 설명                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| 공영 채널  | 필수 사항                | 깊이, 거래, Klines, 티커 등 시장 데이터도 포함됩니다 |
| 사설 채널 | `listenKey` 또는 JWT 필수 | 사용자 순서, 계정 및 위치 스트림              |

<h2 id="public-channels">공영 채널</h2>

공 WebSocket 는 인증이 필요하지 않습니다. 연결 후에는 시장 채널 구독 요청을 `subscribe` 보내세요.

일반적인 채널:

| 채널                            | 설명                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | 주문 책 깊이. 먼저 스냅샷을 보내고, 그 다음 증분 업데이트를 보냅니다 |
| `market.trade.{symbol}`            | 최신 거래                                                      |
| `market.kline.{symbol}.{interval}` | 클라인스                                                             |
| `market.ticker.{symbol}`           | 단일 심볼 티커 요약                                       |
| `market.tickers`                   | 모든 심볼 티커 요약                                          |

<h2 id="private-channels">사설 채널</h2>

<h2 id="listenkey">listenKey</h2>
개인 WebSocket 스트림의 경우, 먼저 REST API를 통해 `listenKey`을 생성한 후 다음 링크에 연결하세요:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
호환 가능한 JWT 연결 방식:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

인증이 성공하면 서버는 현재 사용자의 개인 채널에 자동으로 연결을 구독합니다. 수동 구독은 필요하지 않습니다.
