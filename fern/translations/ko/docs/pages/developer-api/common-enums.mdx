<h2 id="orders">명령</h2>

| 열거                 | 가치                                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| 주문 측           | `BUY` / `SELL`                                                                                            |
| 포지션 사이드        | `BOTH` / `LONG` / `SHORT`                                                                                 |
| 정규 순서 유형    | `LIMIT` / `MARKET`                                                                                        |
| 조건 순서 유형 | `STOP_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_MARKET` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP`               |
| 유효 기간        | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                                         |
| 트리거 가격 유형   | `MARK_PRICE` / `CONTRACT_PRICE`                                                                           |
| 명령 현황         | `NEW` / `PENDING` / `PARTIALLY_FILLED` / `FILLED` / `CANCELED` / `REJECTED` / `PARTIALLY_FILLED_CANCELED` |

`NEW` 주문 요청이 수락되어 반환되었다는 뜻입니다. `PENDING` 명령이 보류 중이거나 열린 주문 상태에 들어갔다는 의미입니다.

<h2 id="positions">위치</h2>

| 열거                      | 가치                                                      |
| ------------------------- | ----------------------------------------------------------- |
| 마진 모드 요청 값 | `1` 십자가, `2` 고립                                     |
| 마진 모드 문자열        | `ISOLATED` / `CROSS`                                        |
| 클로즈 트리거 모드        | `1` 매뉴얼, 이익 실현, 손절매`3` 및 청산`4` `2` |

<h2 id="integration-rules">통합 규칙</h2>

- 열거 값을 대문자 구분 와이어 값으로 간주합니다.
- 알 수 없는 값을 로그에 보존하고 조용히 알려진 상태로 매핑하는 대신 안전하게 실패합니다.
- 모든 비최종 명령 상태가 다시 시도해도 안전하다고 추론하지 마십시오. 순서를 쿼리하거나 사적인 WebSocket 이벤트와 조화시키세요.
- 원본 API 값과 파트너 측 디스플레이 라벨을 모두 저장하여 과거 기록을 변경하지 않고도 새로운 값을 지원할 수 있도록 합니다.

<h2 id="order-state-handling">주문 상태 처리</h2>

| 국가 그룹 | 가치 | 권장 취급 방법 |
| --- | --- | --- |
| 수용 또는 개방 | `NEW`, `PENDING`, `PARTIALLY_FILLED` | 주문을 활성화하고 WebSocket 또는 REST 업데이트와 조율하세요. |
| 완성됨 | `FILLED` | 최종 채취된 수량과 실행 기록을 적용하세요. |
| 완전 채우지 않고 닫혔습니다 | `CANCELED`, `REJECTED`, `PARTIALLY_FILLED_CANCELED` | 활성 처리를 중단하고 이유와 실행 완료 수량을 보존하세요. |
