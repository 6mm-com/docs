<h2 id="documentation-map">문서 지도</h2>

| 면적 | 목적 |
| --- | --- |
| 보안 아키텍처 | 거래 인프라, API/SDK 접근, 파트너 운영이 어떻게 보호되는지 이해하세요. |
| API 및 webhook 보안 | 서명, 비밀 저장소, 멮등성 처리를 통해 백엔드 통합을 보호합니다. |
| 준수 준비 상태 | 라이선스 지원 맥락, 발사 점검, 파트너 측 운영 통제를 준비하세요. |
| 법적 문서 | 운영 시작 전에 약관, 개인정보 보호, 책임 경계를 검토하세요. |

<h2 id="recommended-reading-order">추천 읽기 순서</h2>

1. 보안 아키텍처와 파트너 책임 경계부터 시작한다.
2. 백엔드 통합 전에 API Key 관리, 요청 서명, 멩등성 Webhook 검토.
3. 지역 발사 준비 전에 준수 개요 및 라이선스 지원을 검토합니다.
4. 거래 기능을 사용자에게 공개하기 전에 법률 페이지와 출시 체크리스트를 검토하세요.
