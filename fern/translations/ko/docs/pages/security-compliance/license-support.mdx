면허 계획은 더 광범위한 출시 계획의 일부입니다. 올바른 경로는 목표 시장, 사용자 유형, 제품 범위, 보관 모델, 그리고 각 당사자의 운영 책임에 따라 달라집니다.

<h2 id="planning-inputs">계획 입력</h2>

| 입력 | 왜 중요한가 |
| --- | --- |
| 대상 관할권 | 규제 기대치와 필요한 지역 검토를 결정합니다. |
| 사용자 유형 | 소매, 전문직, 기관 또는 파트너 분산 사용자는 서로 다른 통제가 필요할 수 있습니다. |
| 제품 범위 | 현물, 파생상품, 지갑, 수탁, 중개 기능이 준수 모델을 바꿀 수 있습니다. |
| 운영 모델 | 화이트라벨, 임베디드, 브로커, 기관 모델은 서로 다른 책임 경계를 가지고 있습니다. |

<h2 id="how-to-use-this-documentation">이 문서의 사용 방법</h2>

법률 검토 전에 기술적·운영 요구사항을 조율하는 데 이 문서들을 활용하세요. 문서는 팀이 아키텍처, 데이터 흐름, 서명, 보안, 자산 이동, 거래 수명 주기 책임을 설명하는 데 도움을 줄 수 있습니다.

> **중요**
>
> 라이선스 결정은 해당 관할구역의 자격을 갖춘 법률 및 준수 자문가와 검토해야 합니다.
