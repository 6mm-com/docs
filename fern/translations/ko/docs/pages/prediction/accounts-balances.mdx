예측에서는 자금 조달 계정을 사용합니다. 보유 지분은 추가 독립 자산 계정이 아닌 해당 계정 내 예측 동결 자금으로 표시됩니다.

<span id="balance-components" data-sixmm-canonical-anchor="balance-components" aria-hidden="true"></span>

## 저울 구성요소

| 요소 | 의미 |
| --- | --- |
| 자금 잔액 | 이 모델에서 사용 가능한 자금과 예측 동결된 자금을 포함하는 계정 잔액 |
| 사용 가능한 잔액 | 현재 허용된 새로운 활동에 사용할 수 있는 자금 |
| 예측 동결 잔액 | 재정적 해결을 기다리는 예측 주문을 위해 예약된 자금 |
| 예상 지급액 | 잠재적인 결과 금액 현재 사용 가능한 자금이 아님 |

예측 잔액 모델 내에서 자금 잔액은 사용 가능한 잔액에 예측 동결 잔액을 더한 것과 같습니다. 기타 계정 제한사항은 표시되는 경우 별도로 확인해야 합니다.

<span id="reservation-example" data-sixmm-canonical-anchor="reservation-example" aria-hidden="true"></span>

## 예약 예

1,000개의 USDT를 사용할 수 있고 예측 예약이나 기타 움직임이 없다고 가정합니다. 100USDT 주문이 수락되고 예약되면 사용 가능한 자금은 900USDT가 되고 예측 동결 자금은 100USDT이 됩니다. 금액을 예약해도 100USDT 자산이 추가로 생성되지 않습니다.

최종 정산은 기록된 결과에 따라 계좌를 변경합니다. 보다 [지급 및 손익](/ko/prediction/returns-pnl) 결과 금액.

## 이중 계산 방지

이미 포함된 자금 잔액 위에 예측 동결 자금을 추가하지 마십시오. 마찬가지로 보류 중인 주문에서 예상되는 지불금을 실현 자산으로 계산하지 마십시오.

현물 또는 영구 계좌의 자금은 관련 지원 이체가 완료될 때까지 예측에 사용할 수 있다고 가정해서는 안 됩니다. 보다 [양도 및 거래](/ko/prediction/transfers-ledger).
