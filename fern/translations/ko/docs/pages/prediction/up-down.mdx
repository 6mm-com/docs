Up/Down 예측은 주문을 예정된 라운드로 그룹화합니다. 사용자는 정산 가격이 라운드 개시 가격보다 높거나 낮을지 여부를 선택합니다.

<span id="참여-방법" data-sixmm-anchor-target="how-to-participate" aria-hidden="true"></span>
<h2 id="how-to-participate">참여 방법</h2>

1. 활성화된 기호와 마침표를 선택하세요.
2. 라운드 수, 개시 가격, 배팅 창, 결과 평가 시간을 확인하세요.
3. 위 또는 아래를 선택하고 판돈을 입력하세요.
4. 제공된 확률과 예상 지불금을 검토한 후 베팅이 진행되는 동안 제출하세요.
5. 해당 라운드의 주문을 추적하고 최종 결과를 확인하고 반환합니다.

<span id="라운드-시간" data-sixmm-anchor-target="round-times" aria-hidden="true"></span>
<h2 id="round-times">라운드 시간</h2>

| 시간 | 의미 |
| --- | --- |
| 베팅 시작 | 라운드가 주문 접수를 시작합니다. |
| 베팅 종료 | 해당 라운드에 대한 새로운 베팅이 더 이상 허용되지 않습니다. |
| 결과평가 시간 | 예정된 결과 평가 시간 |
| 정산완료 | 결제 처리 완료 기록 |

라운드 기간과 베팅 기간은 서로 다른 설정입니다. 베팅이 전체 기간 동안 열려 있다고 가정하기보다는 표시된 타임스탬프를 사용하십시오.

<span id="방향-결과" data-sixmm-anchor-target="direction-result" aria-hidden="true"></span>
<h2 id="direction-result">방향 결과</h2>

| 가격 비교 | 방향 |
| --- | --- |
| 정산가가 시가보다 높음 | 위로 |
| 정산가가 시가보다 낮습니다. | 아래에 |

동일한 가격은 어느 방향도 설정하지 않습니다. 해당 라운드의 동일 가격 규칙을 확인하세요. 평등을 자동 손실 또는 환불로 간주하지 마십시오.

<span id="확률과-예" data-sixmm-anchor-target="odds-and-example" aria-hidden="true"></span>
<h2 id="odds-and-example">확률과 예</h2>

제안된 배당률은 구성된 한도에 따라 상향 및 하향 풀과 제안된 판돈에 따라 변경됩니다. 나중 풀 견적 자체는 이전 주문의 정산 조건을 식별하지 않습니다. 해당 명령에 기록된 조건을 사용하십시오.

예를 들어 시가가 65,000이고 정산가가 65,100이면 방향은 위쪽입니다. 기록된 지불 배율 1.85x에서 허용된 우승 판돈 100USDT은 별도로 공개된 수수료 전 총 지불금이 185USDT입니다. 이 숫자는 생산 견적이 아닌 계산을 나타냅니다.
