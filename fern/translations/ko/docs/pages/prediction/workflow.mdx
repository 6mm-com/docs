예측은 각 게임마다 다른 타이밍 규칙을 사용하여 일반적인 주문 및 자금 여정을 따릅니다.

<span id="order-lifecycle" data-sixmm-canonical-anchor="order-lifecycle" aria-hidden="true"></span>

## 주문 수명주기

| 단계 | 확인해야 할 사항 |
| --- | --- |
| 선택 및 견적 | 게임, 기호, 수량, 확률, 가격/시간 조건 |
| 수락 | 주문 번호, 기록된 조건 및 성공적인 수락 |
| 예약된 자금 | 자금 계좌의 주문 예약 |
| 결과를 기다리는 중 | 라운드 결과 평가, 독립적 만료 또는 그리드의 유효 기간 |
| 결과 처리 | 신뢰할 수 있는 가격 증거 및 주문에 적용되는 규칙 |
| 합의 | 최종현황, 실제 지급액, 정산거래 |
| 화해 | 주문 내역이 계정 이동과 일치합니다. |

<span id="timing-by-game" data-sixmm-canonical-anchor="timing-by-game" aria-hidden="true"></span>

## 게임별 타이밍

- **위/아래:** 주문은 예정된 라운드에 속합니다. 결과가 처리되기 전에 베팅이 종료됩니다.
- **맞춤형:** 각 주문에는 자체 개시 가격과 만료 기간이 있습니다. 다른 사용자의 주문은 타이밍이 다를 수 있습니다.
- **그리드:** 선택한 셀에 유효한 시작 및 종료 시간이 있습니다. 그 창 밖에서 터치하는 것은 자격이 없습니다.

<span id="if-processing-is-interrupted" data-sixmm-canonical-anchor="if-processing-is-interrupted" aria-hidden="true"></span>

## 처리가 중단된 경우

페이지 연결이 끊어지거나 잔액 새로고침이 지연되어 최종 결과를 추론하지 마세요. 주문 기록을 다시 열고 현재 상태를 확인한 후 관련 거래를 조정하세요. 가격증빙이나 정산처리에 이상이 있는 경우 [환불 및 예외](/ko/prediction/refunds-exceptions).

<span id="keep-a-traceable-record" data-sixmm-canonical-anchor="keep-a-traceable-record" aria-hidden="true"></span>

## 추적 가능한 기록을 유지하세요

지원을 위해 주문 번호, 게임, 기호, 주문 시간, 표시된 상태 및 결제 거래 번호(있는 경우)를 보관하세요. 어림수는 위/아래 주문을 식별하는 데 도움이 됩니다. 그리드 스크린샷만으로는 저장된 주문을 식별할 수 없습니다.
