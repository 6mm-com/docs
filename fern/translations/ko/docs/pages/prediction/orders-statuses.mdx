허용되는 각 예측 순서에는 고유한 순서 번호가 있습니다. Up/Down 주문도 라운드를 참조합니다. 맞춤형 및 그리드 주문에는 공유 라운드가 필요하지 않습니다.

<span id="current-and-historical-records" data-sixmm-canonical-anchor="current-and-historical-records" aria-hidden="true"></span>

## 현재 및 과거 기록

| 표시된 상태 | 읽는 방법 |
| --- | --- |
| 결과를 기다리는 중 | 아직 최종 결과가 기록되지 않았습니다. |
| 베팅 종료 | 표시된 베팅 단계가 닫힙니다. 이것은 승패 결과가 아닙니다. |
| 이겼다 | 해당 주문은 당첨결과로 기록됩니다. |
| 잃어버린 | 주문은 패배 결과로 기록됩니다. |
| 환불됨 | 환불 처리는 주문 상태에 반영됩니다. 실제 거래를 조정하다 |
| 무효화됨 | 주문이 무효화되었습니다. 사유 및 관련 자금 처리를 확인하세요. |

모든 게임이 모든 중간 상태를 동일한 방식으로 사용하는 것은 아닙니다. 상태 라벨만으로는 계정 크레딧이 완료되었음을 증명할 수 없습니다.

<span id="fields-to-check" data-sixmm-canonical-anchor="fields-to-check" aria-hidden="true"></span>

## 확인할 필드

모든 게임은 주문 번호, 사용자 소유권, 기호, 지분, 확률, 주문 시간 및 상태를 노출합니다. 이력기록에는 실제 지급액, 결과정보, 정산시간, 정산거래번호 등이 추가됩니다.

- 위/아래는 라운드 수와 예측/실제 방향을 추가합니다.
- 사용자 정의는 고정 배당률과 독립적인 만료를 추가합니다.
- 그리드는 선택한 셀과 가격 간격을 추가합니다. 시간 창 터치 규칙을 사용하여 결과 필드를 해석합니다.

## 변경사항 및 중복 제출

예측 주문이 영구 지정가 주문처럼 수정되거나 취소될 수 있다고 가정하지 마세요. 허용된 제품에 적용 가능한 작업과 규칙을 따르십시오. 제출 응답이 불확실한 경우 다른 지분을 배치하기 전에 원래 주문을 쿼리하십시오.
