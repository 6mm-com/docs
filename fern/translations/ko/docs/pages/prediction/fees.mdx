예측 수수료는 승인된 주문 확률 및 파트너 플랫폼에서 공개한 수수료 일정과 함께 읽어야 합니다. 본 가이드에서는 보편적 수수료율을 설정하지 않습니다.

## 금액을 구별하라

| 목 | 의미 |
| --- | --- |
| 확률 승수 | 주문 조건에 따라 총 승리 수익을 결정합니다. |
| 목표 수익률 매개변수 | 가격 책정 모델 입력 그 자체로 별도의 수수료 거래가 아닌 |
| 별도 공시되는 서비스 이용료 | 제품/주문에 적용되는 경우 조정 비용 |
| 파트너 수익 정산 | 자동으로 다른 사용자 주문 요금이 청구되지 않는 비즈니스 수준 할당 |

운영 모델에는 예측 플랫폼 서비스 수수료가 수수료 항목으로 포함되어 있습니다. 해당 카테고리가 존재한다고 해서 요율, 청구 시점 또는 특정 주문이 별도로 청구되는지 여부가 결정되지는 않습니다.

## 제출하기 전에 확인하세요

- 선택한 게임 및 계정에 수수료가 적용되는지 여부입니다.
- 수수료 기준과 금액, 청구 시기입니다.
- 표시된 반품 금액이 별도로 부과되는 수수료 이전인지 이후인지 여부입니다.
- 환불되거나 취소된 주문에 대한 수수료 처리 방법.

해당 조건이 불분명한 경우 다음을 통해 해당 일정을 얻으십시오. [파트너 지원](/ko/resources/contact/support) 거래하기 전에.

## 두 번 공제하지 않고 화해하다

확률 매개변수와 별도의 요금은 다른 기록입니다. 이미 허용된 확률을 반영하는 지불금에서 추론된 백분율을 공제하지 마십시오. 실제로 공개된 요금과 거래만 조정하세요.
