예외에는 가격 중단, 일관되지 않은 가격 증거, 승률 불일치 또는 결제 처리 실패가 포함될 수 있습니다. 예외에는 기록된 해결 방법이 필요합니다. 자동으로 패배하는 결과는 아닙니다.

<span id="common-situations" data-sixmm-canonical-anchor="common-situations" aria-hidden="true"></span>

## 일반적인 상황

| 상황 | 해야 할 일 |
| --- | --- |
| 유효한 기간 동안 그리드 피드가 누락되었습니다. | 예외/환불 처리를 확인하세요. 샘플이 없으면 누락을 증명할 수 없습니다. |
| 주문 응답 시간이 초과되었습니다. | 다시 제출하기 전에 원래 주문과 예약을 찾아보세요. |
| 표시와 기록 결과가 일치하지 않음 | 가격 소스, 타임스탬프, 허용된 조건 및 결과 증거를 비교하세요. |
| 결제가 지연된 것으로 보입니다 | 최종현황 및 거래별도 확인 |
| 환불 또는 무효화 기록 | 사유, 실제 자금 이동, 잔여 예약 등을 검토합니다. |

<span id="refund-and-void-are-distinct" data-sixmm-canonical-anchor="refund-and-void-are-distinct" aria-hidden="true"></span>

## 환불과 무효는 별개입니다

환불은 자금 처리를 설명합니다. 무효는 주문 무효화를 나타냅니다. 라벨만으로 정확한 환불 금액이나 처리 기한을 추론하지 마십시오. 기록된 해상도와 거래를 사용합니다.

환불 및 무효 주문은 보고 시 유효한 지분에서 제외됩니다. 게임 플레이 성능을 평가할 때 환불은 승리 수익으로 간주되어서는 안 됩니다.

## 증거를 뒷받침하다

주문 번호, 라운드 번호(해당하는 경우), 기호, 관련 타임스탬프, 기록된 지급 배율, 결과/상태 및 결제 거래 번호를 제공하세요. 그리드 분쟁의 경우 허용되는 가격 간격과 유효한 기간을 포함하세요. 비밀번호, API 비밀번호 또는 전체 액세스 토큰을 포함하지 마세요.

사용 [파트너 지원](/ko/resources/contact/support) 지원 경로 및 [양도 및 거래](/ko/prediction/transfers-ledger) 화해를 위해.
