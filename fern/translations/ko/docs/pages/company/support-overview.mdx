6MM 지원은 공식 파트너, 적극적인 통합 및 생산 운영을 위해 설계되었습니다. 최종 사용자 지원은 별도로 합의되지 않는 한 파트너 플랫폼의 책임으로 남아 있습니다.

<h2 id="choose-the-right-path">올바른 길을 선택하세요</h2>

| 상황 | 추천 경로 | 포함 |
| --- | --- | --- |
| 새로운 파트너십 또는 솔루션 평가 | 파트너 온보딩 경로 | 제품 유형, 타깃 지역, 출시 일정, 예상 통합 모델. |
| SDK, API, webhook또는 환경 관련 질문 | 기술 지원 경로 | 엔드포인트, SDK 버전, 요청 ID, 재생산 단계, 로그. |
| 생산 사고 또는 거래 흐름 저하 | 사건 에스컬레이션 경로 | 영향 범위, 시작 시간, 영향을 받은 사용자, 주문 ID, 현재 완화 조치 등. |
| 자산, 복사 또는 발사 자료 변경 | 작전 지원 경로 | 페이지, 언어, 요청된 변경 사항, 출시일, 승인 소유자. |
| 취약성 또는 의심되는 학대 | 보안 보고 경로 | 기술적 세부사항, 영향을 받은 엔드포인트, 증거, 긴급성, 이슈가 활성화되었는지 여부 등이 포함됩니다. |

<h2 id="severity-guide">심각도 가이드</h2>

| 심각도 | 예시 |
| --- | --- |
| 비평 | 생산 거래, 인증, 토큰 발행 또는 자금 관련 흐름은 불가능합니다. |
| 높게 | 주요 파트너 흐름이 저하되지만, 우회 방법이 존재합니다. |
| 정상 | 통합 질문, 구성 요청, 문서 문제 또는 예정된 런칭 지원. |

<h2 id="before-contacting-support">지원팀에 연락하기 전에</h2>

- 영향을 받는 제품 영역과 환경을 확인한다.
- 요청 ID, 주문 ID, 타임스탬프, 사용자 매핑 ID, webhook 이벤트 ID, 로그 수집.
- 운영 문제에 대해서는 지원 요청 템플릿을 사용하세요.
