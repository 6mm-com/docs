지원팀에 연락할 때는 아래 정보를 제공하면 포함하세요.

<h2 id="required-context">필수 맥락</h2>

| 필드 | 예시 |
| --- | --- |
| 환경 | 제작 또는 연출 |
| 영향을 받은 모듈 | Trading Widget, Agent SDK, REST API, WebSocket, webhook, 화이트라벨 시스템 |
| 시간 범위 | 문제가 발생한 UTC 타임스탬프 범위 |
| 파트너 사용자 ID | 파트너 측 사용자 식별자, 관련 시 |
| 6MM 매핑 ID | agentUserId, 주문 ID, 요청 ID, 또는 webhook 이벤트 ID |
| 비즈니스 영향 | 영향을 받은 사용자 수나 운영 수와 문제가 계속되고 있는지 여부 |

<h2 id="description-format">설명 형식</h2>

- 무슨 일이야?
- 뭘 기대했어?
- 재현할 수 있나요?
- 최근에 뭐가 바뀌었어?
- 문제 아직 진행 중인가요?

<h2 id="attachments">부속 자료</h2>

- 관련 요청 및 응답 로그.
- 스크린샷이나 화면 녹화.
- 페이로드 및 시그니처 헤더 Webhook .
- Trading Widget 문제에 대한 브라우저 콘솔 오류 발생.

<h2 id="copyable-template">복사 가능한 템플릿</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

관련 없는 필드는 제거하되, UTC 시간 범위와 가능한 한 최소 하나의 검색 가능한 요청 또는 사업자 식별 정보를 유지하세요.

<h2 id="redact-sensitive-data">민감한 데이터를 편집합니다</h2>

전송하지 마세요:

- 비밀번호 또는 전체 접근 토큰
- API 비밀, 개인 키, 또는 완전한 서명
- 세션 쿠키
- 전액 결제, 신원 또는 기타 불필요한 개인정보

필드 이름과 짧은 접두사 또는 접미사는 지원팀이 정제된 값을 구분할 때만 유지하세요.
