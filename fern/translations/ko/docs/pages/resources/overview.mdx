통합 및 지원 자원은 기존 제품에 6MM 거래 기능을 추가하거나, 화이트라벨 교환을 시작하거나, 생산 사용을 위한 운영 자료를 준비하는 팀을 위해 준비됩니다.

<h2 id="resource-areas">자원 지역</h2>

<CardGroup cols={2}>
<Card title="브랜드 및 자산" icon="fa-duotone fa-palette" href="/ko/resources/brand-assets/usage-guidelines">
승인된 6MM 시각 자료, 출품 배너, 카드 자료, 화이트라벨 자료 지침을 사용하세요.
</Card>
<Card title="발사 재료" icon="fa-duotone fa-rocket" href="/ko/resources/production-launch-checklist">
생산 실행 점검, 통합 정보, 지원 핸드오프 세부 사항을 준비하세요.
</Card>
<Card title="에셋 다운로드" icon="fa-duotone fa-folder-arrow-down" href="/ko/resources/brand-assets/asset-downloads">
로고, 배너, 카드 입력, 화이트라벨 자산 패키지를 다운로드하세요.
</Card>
<Card title="지원 요청 템플릿" icon="fa-duotone fa-message-question" href="/ko/resources/support-request-template">
통합, 거래 또는 생산 문제를 보고할 때 일관된 형식을 사용하세요.
</Card>
</CardGroup>

<h2 id="when-to-use-this-section">이 섹션을 언제 사용해야 하는지</h2>

| 시나리오 | 추천 페이지 |
| --- | --- |
| 앱이나 웹페이지에 6MM 거래 항목을 추가하세요 | 사용 지침 |
| 로고, 배너 또는 카드 입력 파일이 필요합니다 | 에셋 다운로드 |
| 파트너 브랜드 출시 준비 | 화이트라벨 지원 |
| 테스트에서 프로덕션으로 전환 | 생산 출시 체크리스트 |
| 6MM 지원팀에 문제를 조사해 달라고 요청하세요 | 지원 요청 템플릿 |
