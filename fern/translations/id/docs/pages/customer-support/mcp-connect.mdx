## Detail koneksi

| Barang | Nilai |
| --- | --- |
| Konsol penyewa | [Konsol penyewa](https://csadmin.6mm.com/) |
| Mengangkut | Dapat dialirkan HTTP |
| Otorisasi | OAuth kode otorisasi dengan PKCE; pendaftaran klien dinamis |
| Akun | Akun dukungan pelanggan Anda yang sudah ada |

Gunakan aplikasi AI yang mendukung aliran transportasi dan otorisasi jarak jauh ini. Tidak diperlukan penerapan server MCP khusus penyewa atau konfigurasi izin MCP terpisah yang diperlukan. Jangan menambahkan jalur SSE atau menggunakan Kunci Aplikasi sebagai token pembawa OAuth.

<span id="connect-step-by-step" data-sixmm-canonical-anchor="connect-step-by-step" aria-hidden="true"></span>

## Hubungkan langkah demi langkah

1. Masuk ke konsol dan buka **Pengaturan Sistem → MCP Koneksi**.
2. Salin titik akhir dan tambahkan sebagai server MCP jarak jauh di aplikasi AI Anda. Nama tampilan seperti 6MM Dukungan Pelanggan sudah cukup.
3. Biarkan aplikasi memulai otorisasi. Di browser, masuk dan selesaikan semua verifikasi yang diperlukan.
4. Periksa aplikasi, penyewa, akun, dan alamat pengirim sebelum mengizinkan koneksi. Nama aplikasi yang diberikan bukan merupakan tanda sertifikasi.
5. Kembali ke aplikasi AI dan segarkan alatnya jika perlu. Mintalah untuk mencantumkan kategori pengetahuan sebagai tes baca-saja yang pertama.
6. Periksa Aplikasi yang Terhubung di konsol. Cabut koneksi di sana bila tidak diperlukan lagi.

Jangan pernah memberikan kata sandi, kode verifikasi, atau rahasia penandatanganan identitas Anda kepada AI. Otorisasi hanya melalui halaman login dan persetujuan.

<span id="what-access-does-the-ai-receive" data-sixmm-canonical-anchor="what-access-does-the-ai-receive" aria-hidden="true"></span>

## Akses apa yang diterima AI?

Hanya alat dan data penyewa akun saat ini yang didukung. Izin diperiksa lagi selama panggilan; penangguhan akun, ketidaktersediaan penyewa, atau pencabutan otorisasi dapat memblokir akses. Keluar dari konsol tidak secara otomatis mencabut koneksi AI.

Implementasi saat ini menggunakan otorisasi koneksi 30 hari dan token akses berumur pendek dengan token penyegaran yang berputar. Ikuti masa berlaku yang ditunjukkan pada Aplikasi Terhubung dan sambungkan kembali bila diperlukan. Aplikasi AI menangani pertukaran dan pembaruan token; penyewa tidak menempelkan kata sandi secara manual ke panggilan alat.

MCP ini mengelola backend dukungan. Itu tidak memungkinkan bot pengunjung untuk mengoperasikan backend atau memberikan akses ke akun perdagangan.
