## Dukungan konsol dan pengunjung

| Gejala | Periksa dulu |
| --- | --- |
| Ada menu yang hilang | Peran akun dan ketersediaan layanan penyewa |
| Widget tidak terbuka | Skrip yang dihasilkan URL, Kunci Aplikasi, kesalahan domain dan browser yang diizinkan |
| Bot tidak menggunakan model besar | Langkah yang benar-benar cocok, sakelar layanan cerdas, dan konfigurasi yang relevan |
| Sebuah jawaban menggunakan aturan lama | Artikel sumber, status terbitan, FAQ teks, terjemahan dan status pengambilan |
| Terjemahan tidak ada | Bahasa target, peralihan terjemahan, terjemahan tersimpan, dan ketersediaan layanan/saldo |
| Pembuatan vektor gagal | Ketersediaan layanan dan status pengambilan; hindari membangun kembali berulang kali tanpa mengidentifikasi kegagalannya |
| Bidang kontak kosong | Apakah ladang tersebut benar-benar dikumpulkan; membedakan kontak dan email masuk |

## MCP koneksi dan panggilan

| Gejala | Langkah selanjutnya |
| --- | --- |
| Membuka titik akhir di browser akan mengembalikan kesalahan | Ini adalah titik akhir protokol, bukan halaman login; tambahkan ke klien MCP yang kompatibel |
| Otorisasi tidak dapat dimulai | Verifikasi titik akhir yang tepat, dukungan HTTP/OAuth Streamable klien, dan alur login browser |
| Koneksi tidak sah atau kedaluwarsa | Periksa pencabutan dan kadaluwarsa; terhubung kembali melalui aplikasi |
| Alat hilang atau akses ditolak | Periksa peran akun otorisasi dan cakupan rekaman; menyegarkan daftar alat |
| Menunggu persetujuan | Buka tautan persetujuan yang dikembalikan dan tinjau di backend |
| Konten berubah | Baca catatan terbaru, pratinjau lagi, dan kirimkan operasi baru yang diinginkan |
| Waktu permintaan habis | Kueri status operasi sebelum mencoba lagi atau berasumsi gagal |
| Tidak ada log tulis | Membedakan pembacaan, persetujuan tertunda, dan penulisan selesai; periksa filter di Log Operasi |

## Sebelum menghubungi dukungan

Kumpulkan waktu dan zona waktu, penyewa/akun yang terpengaruh, nama halaman atau alat, ID operasi jika tersedia, dan kesalahan sebenarnya. Sertakan tangkapan layar yang telah disunting atau langkah-langkah untuk mereproduksi. Jangan mengirimkan kata sandi, kode verifikasi, token pembawa, atau rahasia penandatanganan.

Cobalah catatan tes kecil saat mendiagnosis penulisan. Verifikasi hasilnya dan bersihkan hanya data pengujian yang Anda buat, menggunakan alur konfirmasi normal jika diperlukan.
