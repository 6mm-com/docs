## Kontrol tampilan

`display` mengontrol shell halaman perdagangan yang tertanam dan kontainer tingkat tinggi. Dalam penyematan mitra, header PC dan ticker pasar bawah disembunyikan secara default.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Bidang | Jenis | Bawaan | Catatan |
| --- | --- | --- | --- |
| showHeader | boolean | PALSU | Apakah akan menampilkan header penyematan PC di dalam iframe. |
| showTicker | boolean | PALSU | Apakah akan menampilkan ticker pasar terbawah di shell yang disematkan. |
| tersembunyi | rangkaian[] | [] | Menyembunyikan kontainer tingkat tinggi di halaman perdagangan. |

Nilai `display.hidden` yang didukung:

| Nilai | Wadah |
| --- | --- |
| bagan | Wadah bagan |
| orderBook | Wadah buku pesanan |
| orderForm | Panel formulir pemesanan |
| posisi | Posisi bawah dan panel pesanan terbuka |
| akun | Wadah aset akun |

`display.hidden` hanya menyembunyikan seluruh kontainer. Itu tidak menyembunyikan tombol, bidang, atau alat individual di dalam wadah. Nilai yang tidak dipetakan ke area pandang saat ini akan diabaikan.

## Halaman produk dan mode perdagangan

Java Agent SDK dan browser Trading Widget SDK dibuat versinya secara independen. Untuk perdagangan detik, gunakan kemampuan Widget saat ini dan pilih halaman dan mode perdagangan secara eksplisit.

| Pilihan | Nilai-nilai | Arti |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Halaman produk untuk perdagangan detik. |
| `tradingMode` | `real`, `demo` | Defaultnya adalah `real`; secara eksplisit cocok dengan lingkungan pendanaan backend. |

Periksa `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes`, dan `TradingWidget.capabilities.partnerToken` sebelum inisialisasi. Pembuatan token tidak memilih lingkungan dana. Untuk mengubah mode pengguna atau nyata/demo, hancurkan instance lama dan buat yang baru.

Melihat [contoh perdagangan detik lengkap](/id/sdk/agent-sdk/java/seconds-trading) Dan [konfigurasi produksi/simulasi](/id/sdk/agent-sdk/java/environments).

## Target tampilan dan acara tambahan

Runtime saat ini juga menerima `symbolFavorites` dan `symbolTicker` di `display.hidden`. Selalu centang `TradingWidget.capabilities.displayTargets`; target mengontrol kontainer tingkat tinggi dan bukan merupakan pengaturan izin tingkat bidang.

| Peristiwa | Arti |
| --- | --- |
| `rendered` | Iframe mengirimkan notifikasi yang diberikan. |
| `theme_changed` | Iframe melaporkan tema sebenarnya. |
| `page_changed` | Iframe melaporkan halaman produk sebenarnya. |

Gunakan `onRendered` atau `widget.on('rendered', handler)` untuk menangani rendering secara terpisah dari inisialisasi. Halaman yang didukung saat ini diterbitkan di `TradingWidget.capabilities.pages`; memvalidasi halaman yang diminta daripada menebak-nebak jalannya.
