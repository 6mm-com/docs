<h2 id="responsibility-split">Pembagian tanggung jawab</h2>

| Luas | Pemilik | Catatan |
| --- | --- | --- |
| Pembuatan kontainer | Frontend mitra | Berikan elemen yang terlihat dengan lebar dan tinggi yang eksplisit. |
| pembuatan iframe | Trading Widget SDK | SDK membuat dan mengelola iframe. |
| Antarmuka Perdagangan | 6MM iframe | K-line, buku pesanan, formulir pesanan, posisi, pesanan, dan data akun dijalankan di dalam iframe. |
| Kontrol tampilan | Trading Widget SDK + 6MM iframe | Header embed PC dan ticker bawah secara default tersembunyi. Mitra dapat menggunakan `display` untuk menampilkan area shell atau menyembunyikan kontainer trading tingkat tinggi. |
| Pemeriksaan login mitra | Backend mitra | Validasi sesi pengguna mitra sebelum mengeluarkan kredensial autentikasi. |
| Penerbitan token Embed | Backend mitra + Agent API | Direkomendasikan untuk mode token mitra. |

<h2 id="versioning">Versi</h2>

Jalur integrasi publik tetap stabil di bawah skrip v1 URL. Set kemampuan v1 saat ini mencakup token-partner, tokenProvider, entryUrlProvider, kontrol tampilan, event siklus hidup, metode instance, dan event order.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Kapan menggunakan widget</h2>

Pilih Trading Widget ketika mitra membutuhkan antarmuka trading lengkap di dalam produk web yang sudah ada. Gunakan dokumentasi REST API dan WebSocket saat membangun dan memelihara antarmuka trading yang sepenuhnya kustom.

<h2 id="implementation-path">Jalur implementasi</h2>

1. Ikuti [Trading Widget Mulai Cepat](/id/sdk/trading-widget/quick-start) untuk memuat skrip dan membuat wadah yang terlihat.
2. Konfigurasi [Otentikasi token mitra](/id/sdk/trading-widget/authentication) melalui backend mitra.
3. Tambahkan yang diperlukan [Opsi dan acara](/id/sdk/trading-widget/options-events).
4. Penggunaan [metode instance](/id/sdk/trading-widget/instance-methods) untuk kontrol siklus hidup dan runtime.
