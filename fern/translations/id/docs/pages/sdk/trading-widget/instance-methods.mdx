## Ringkasan Metode

| Metode | Tujuan |
| --- | --- |
| menghancurkan() | Hapus iframe dan lepaskan pendengar acara. |
| getState() | Baca status siklus hidup SDK saat ini. |
| whenReady() | Tunggu hingga iframe selesai inisialisasi. |
| setSymbol(simbol) | Ganti pasangan perdagangan di dalam iframe. |
| setTheme(tema) | Perbarui parameter tema iframe. |
| setLocale(lokal) | Ganti bahasa iframe. |
| setSize(lebar, tinggi) | Perbarui dimensi iframe. |
| memuat ulang() | Muat ulang iframe saat ini. |
| refreshAuth(alasan) | Memicu aliran penyegaran autentikasi widget. |
| setTokenProvider(penyedia) | Ganti penyedia yang digunakan dengan mode token mitra. |
| aktif (acara, pengendali) | Berlangganan acara runtime dan terima fungsi berhenti berlangganan. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## menghancurkan()

Hapus iframe, hapus pendengar, dan emit yang dimusnahkan satu kali untuk instance saat ini.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Baca status siklus hidup instance widget saat ini.

```js
const state = widget.getState()
```

Nilai yang dikembalikan mencakup memuat, mengautentikasi, siap, kesalahan, dan dimusnahkan.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Tunggu hingga iframe menyelesaikan inisialisasi sebelum menjalankan logika UI dependen.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(simbol)

Ganti pasangan perdagangan di dalam iframe. Jika iframe masih melakukan inisialisasi, SDK mengantri perintah dan mengirimkannya setelah siap.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(tema)

Perbarui parameter tema yang digunakan oleh iframe perdagangan yang disematkan.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(lokal)

Ganti bahasa iframe. Nilai yang didukung adalah en, en-US, dan zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(lebar, tinggi)

Perbarui ukuran iframe DOM dan beri tahu iframe tentang ukuran luar yang baru. Nilai numerik dikonversi ke px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## memuat ulang()

Muat ulang iframe saat ini dan tunggu hingga diinisialisasi lagi.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(alasan)

Minta iframe untuk menyegarkan alur autentikasi saat ini. Nilai alasan opsional diteruskan untuk logging dan kontrol aliran.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(penyedia)

Ganti tokenProvider yang digunakan oleh mode token mitra. SDK memanggil penyedia ketika iframe meminta token penyematan baru.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## aktif (acara, pengendali)

Berlangganan ke acara runtime. Fungsi yang dikembalikan menghapus pendengar.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Metode tambahan dalam runtime v1 saat ini

| Metode | Tujuan |
| --- | --- |
| `whenRendered()` | Tunggu notifikasi yang diberikan iframe; ini terpisah dari siap. |
| `setPage(page)` | Minta halaman produk yang didukung dalam contoh saat ini. Itu tidak mengubah lingkungan dana. |
| `prepareForRecreate()` | Minta iframe yang sudah siap untuk mempersiapkan penggantian; mengembalikan janji dan dapat menolak jika tidak tersedia, sibuk, atau waktu habis. |
| `cancelRecreate()` | Membatalkan aliran penggantian yang tertunda/disiapkan. |
| `TradingWidget.validateOptions(options)` | Validasi opsi inisialisasi sebelum membuat instance. |

Untuk perubahan lingkungan pengguna atau nyata/demo, hancurkan instance lama dan buat yang baru dengan otentikasi dan mode target. Jangan gunakan `setPage` sebagai pengalih lingkungan. Periksa kemampuan sebelum menggunakan metode opsional.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
