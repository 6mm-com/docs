## Ringkasan Metode

| Metode | Tujuan |
| --- | --- |
| hancurkan() | Lepaskan pendengar iframe dan rilis event. |
| getState() | Baca status siklus hidup SDK saat ini. |
| whenReady() | Tunggu sampai iframe selesai inisialisasi. |
| setSymbol(simbol) | Tukar pasangan trading di dalam iframe. |
| setTheme(tema) | Perbarui parameter tema iframe. |
| setLocale(lokasi) | Ganti bahasa iframe. |
| setSize(lebar, tinggi) | Perbarui dimensi iframe. |
| reload() | Muat ulang iframe saat ini. |
| refreshAuth(alasan) | Aktifkan alur pembaruan otentikasi widget. |
| setTokenProvider(penyedia) | Ganti penyedia yang digunakan oleh mode token mitra. |
| on(event, handler) | Berlangganan acara runtime dan terima fungsi berhenti berlangganan. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## hancurkan()

Lepaskan iframe, hapus listener, dan emit destroyed sekali untuk instance saat ini.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Baca status siklus hidup saat ini dari instance widget.

```js
const state = widget.getState()
```

Nilai pengembalian meliputi loading, authenticating, ready, error, dan destroyed.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Tunggu hingga iframe selesai inisialisasi sebelum menjalankan logika UI yang bergantung.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(simbol)

Alihkan pasangan trading di dalam iframe. Jika iframe masih dalam inisialisasi, SDK mengantrikan perintah dan mengirimkannya setelah siap.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(tema)

Perbarui parameter tema yang digunakan oleh iframe trading tertanam.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(lokasi)

Ganti bahasa iframe. Nilai yang didukung adalah en, en-US, dan zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(lebar, tinggi)

Perbarui ukuran DOM iframe dan beri tahu iframe tentang ukuran luar baru. Nilai numerik dikonversi ke px.

```js
widget.setSize('100%', 720)
```

<span data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## reload()

Muat ulang iframe saat ini dan tunggu hingga diinisialisasi lagi.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(alasan)

Minta iframe untuk menyegarkan alur autentikasi saat ini. Nilai alasan opsional diteruskan untuk logging dan kontrol aliran.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(penyedia)

Ganti tokenProvider yang digunakan oleh mode token mitra. SDK memanggil penyedia saat iframe meminta token embed baru.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(event, handler)

Berlangganan ke acara runtime. Fungsi yang dikembalikan akan menghapus listener.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
