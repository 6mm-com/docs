<h2 id="runtime">Durasi</h2>

| Item | Nilai |
| --- | --- |
| Paket | sixmm/agent-sdk |
| Versi PHP minimum | PHP 7.4+ |
| Versi PHP yang direkomendasikan | PHP versi 8.1+ atau yang saat ini didukung |
| Perpanjangan yang diperlukan | ext-json, ext-curl |

Sumber paket PHP SDK dan versi yang disetujui disediakan selama proses onboarding mitra. Jangan berasumsi bahwa paket tersedia dari Packagist publik; konfigurasikan repositori Composer yang disediakan untuk organisasi Anda.

<h2 id="supported-scenarios">Skenario yang didukung</h2>

| Skenario | metode SDK |
| --- | --- |
| Ikat pengguna | mengikat |
| Transfer jumlah tetap | transfer |
| Transfer semua | transferAllOut |
| Transfer balik | membalik |
| Urutan kueri | queryOrder |
| Buat entri URL | createEntryUrl |
| Verifikasi Webhook | WebhookVerifier::verifikasi |

<h2 id="backend-integration-rules">Aturan integrasi backend</h2>

- Muat `apiSecret` dari manajer rahasia atau variabel lingkungan yang dilindungi.
- Jauhkan logika pengikatan, transfer, penandatanganan, dan webhook pengguna dari kode browser.
- Gunakan string desimal untuk jumlah aset guna menghindari pembulatan floating-point.
- Gunakan kembali `agentOrderNo` asli saat melakukan query hasil transfer yang tidak pasti.
- Verifikasi tanda tangan webhook terhadap badan permintaan mentah sebelum mendekode atau mengubahnya.
