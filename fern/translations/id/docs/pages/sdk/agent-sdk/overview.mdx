6MM Agent SDK ini untuk layanan backend mitra yang perlu memanggil API Agen yang memiliki hak istimewa tanpa menerapkan penanganan penandatanganan dan permintaan dari awal. Integrasi tidak boleh berjalan di browser, mobile, atau kode desktop publik karena integrasi menggunakan rahasia mitra API.

<h2 id="when-to-use-the-agent-sdk">Kapan menggunakan Agent SDK</h2>

Gunakan Agent SDK saat backend Anda perlu menghubungkan pengguna mitra, memindahkan aset melalui alur kerja yang disetujui, membaca catatan perdagangan, membuat URL akses embedded trading, atau memverifikasi notifikasi webhook. Gunakan [Trading Widget SDK](/id/sdk/trading-widget/overview) secara terpisah saat frontend mitra perlu menampilkan antarmuka trading.

<h2 id="common-configuration">Konfigurasi umum</h2>

| Kunci | Contoh | Deskripsi |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Agen API layanan URL tanpa garis miring di belakang. |
| agentCode | AGENT001 | Kode agen mitra. |
| apiSecret | rahasia api Anda | API rahasia penandatanganan hanya disimpan di backend. |
| defaultCurrency | USDT | Mata uang default untuk transfer dan API akun. |
| webhookUrl | https://partner.example.com/6mm/webhook | Endpoint mitra untuk notifikasi webhook 6MM . |

<h2 id="typical-integration-flow">Alur integrasi yang khas</h2>

1. Frontend mitra mengautentikasi pengguna melalui sistem akun mitra sendiri.
2. Backend mitra memetakan pengguna ke pengenal sisi mitra yang stabil.
3. Backend memanggil Agent SDK dengan `agentCode` dan rahasia API yang dilindungi.
4. SDK menandatangani dan mengirimkan permintaan API kepada Agen.
5. Backend menyimpan identifikasi bisnis yang dikembalikan dan memproses webhook berikutnya secara identik.
6. Frontend hanya menerima hasil jangka pendek atau kredensial entri yang dibutuhkan.

<h2 id="production-checklist">Daftar periksa produksi</h2>

- Muat `apiSecret` dari manajer rahasia backend, bukan dari kode sumber.
- Pisahkan kredensial pengembangan, penataan, dan produksi.
- Gunakan pemetaan pengguna mitra yang stabil dan pengidentifikasi pesanan bisnis yang unik.
- Pertahankan pengenal asli saat memeriksa status permintaan yang sudah habis waktu.
- Verifikasi tanda tangan webhook dan simpan event ID yang telah diproses.
- Menyuntingkan rahasia dan tanda tangan dari log sambil mempertahankan ID permintaan untuk dukungan.
