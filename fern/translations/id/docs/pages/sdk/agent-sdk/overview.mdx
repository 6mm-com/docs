6MM Agent SDK ditujukan untuk layanan backend mitra yang perlu memanggil Agen dengan hak istimewa APIs tanpa menerapkan penandatanganan dan penanganan permintaan dari awal. Ini tidak boleh berjalan di browser, seluler, atau kode desktop publik karena integrasi menggunakan rahasia API mitra.

<span id="when-to-use-the-agent-sdk" data-sixmm-canonical-anchor="when-to-use-the-agent-sdk" aria-hidden="true"></span>

## Kapan menggunakan Agent SDK

Gunakan Agent SDK saat backend Anda perlu menghubungkan pengguna mitra, memindahkan aset melalui alur kerja yang disetujui, membaca catatan perdagangan, membuat URL akses embedded trading, atau memverifikasi notifikasi webhook. Gunakan [Trading Widget SDK](/id/sdk/trading-widget/overview) secara terpisah saat frontend mitra perlu menampilkan antarmuka trading.

## Konfigurasi umum

| Kunci | Contoh | Keterangan |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Agen API melayani URL tanpa garis miring. |
| agentCode | AGENT001 | Kode agen mitra. |
| apiSecret | rahasia-api-Anda | API rahasia penandatanganan hanya disimpan di backend. |
| defaultCurrency | USDT | Mata uang default untuk transfer dan rekening APIs. |
| webhookUrl | https://partner.example.com/6mm/webhook | Titik akhir mitra untuk notifikasi 6MM webhook. |

<span id="typical-integration-flow" data-sixmm-canonical-anchor="typical-integration-flow" aria-hidden="true"></span>

## Aliran integrasi yang khas

1. Frontend mitra mengautentikasi pengguna melalui sistem akun mitra sendiri.
2. Backend mitra memetakan pengguna ke pengidentifikasi sisi mitra yang stabil.
3. Backend memanggil Agent SDK dengan `agentCode` dan rahasia API yang dilindungi.
4. SDK menandatangani dan mengirimkan permintaan Agen API.
5. Backend menyimpan pengidentifikasi bisnis yang dikembalikan dan kemudian memproses webhooks secara idempoten.
6. Frontend hanya menerima hasil jangka pendek atau kredensial masuk yang diperlukan.

## Daftar periksa produksi

- Muat `apiSecret` dari pengelola rahasia backend, bukan kode sumber.
- Pisahkan kredensial pengembangan, pementasan, dan produksi.
- Gunakan pemetaan pengguna mitra yang stabil dan pengidentifikasi pesanan bisnis yang unik.
- Pertahankan pengidentifikasi asli saat memeriksa status permintaan yang waktunya habis.
- Verifikasi webhook tanda tangan dan simpan ID peristiwa yang diproses.
- Redaksi rahasia dan tanda tangan dari log sambil mempertahankan ID permintaan untuk dukungan.
