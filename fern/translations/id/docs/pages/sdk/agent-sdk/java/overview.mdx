## Konfigurasi

Dapatkan nilai berikut dari 6MM sebelumnya
mengintegrasikan.

| Barang | Contoh | Keterangan |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Agen API basis URL, tanpa garis miring |
| `agentCode` | `AGENT001` | Kode mitra |
| `apiSecret` | `your-api-secret` | API rahasia penandatanganan. Simpan di backend saja |
| `defaultCurrency` | `USDT` | Mata uang default, biasanya `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Titik akhir mitra untuk panggilan balik 6MM |

Rekomendasi produksi:

- Gunakan HTTPS untuk titik akhir Agen API dan webhook.
- Simpan `apiSecret` di manajer rahasia, pusat konfigurasi, atau variabel lingkungan.
- Jaga waktu server tetap tersinkronisasi, sebaiknya dengan NTP.
- Pertahankan semua nomor pesanan mitra dan jaga agar nomor tersebut unik secara global.
- Jangan pernah mengirim `apiSecret` ke browser, aplikasi, program mini, atau kode sumber frontend.


<span id="automatic-signing-fields" data-sixmm-canonical-anchor="automatic-signing-fields" aria-hidden="true"></span>

## Bidang Penandatanganan Otomatis

Untuk panggilan Agen API yang ditandatangani, SDK secara otomatis memasukkan:

| Bidang | Sumber | Keterangan |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Kode mitra |
| `timestamp` | Stempel waktu Unix UTC saat ini | Detik |
| `nonce` | Amankan generator acak | Perlindungan pemutaran ulang |
| `sign` | HMAC-SHA256 | Minta tanda tangan |
| `currency` | `defaultCurrency` | Diisi ketika permintaan transfer/rekening menghilangkan mata uang |

Aturan penandatanganan:

1. Kecualikan `sign`.
2. Kecualikan nilai kosong.
3. Urutkan kunci berdasarkan urutan ASCII.
4. Bergabunglah sebagai `k=v&k2=v2`.
5. Hitung HMAC-SHA256 hex dengan `apiSecret`.

Kode bisnis normal tidak boleh menghitung tanda tangan atau mengaturnya secara manual
`agentCode`, `timestamp`, `nonce`, atau `sign`.
