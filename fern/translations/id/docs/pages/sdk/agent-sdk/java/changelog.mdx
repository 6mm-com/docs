Panduan ini menargetkan **Agent Java SDK `v0.3.0`**, Java 8+, dan kontrak publik yang diberi tag. Contoh dijalankan di backend mitra setelah menginisialisasi `client` di [Mulai Cepat](/id/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Enam pertanyaan abadi: pesanan saat ini, riwayat pesanan, pengisian, posisi saat ini, riwayat posisi, dan buku besar akun.
- Saldo pendanaan, transfer, kueri pemulihan, dan transfer Pendanaan/Kontrak.
- Produksi eksplisit/pemilihan simulasi untuk permintaan dana yang didukung.
- Panduan pengalihan dan penyematan perdagangan detik, referensi bidang respons, dan instruksi migrasi.

Java SDK dan Trading Widget SDK memiliki versi independen. Widget `v1` URL bukan Java SDK versi `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Integrasi yang ada

Pertahankan pemetaan pengguna, pesanan asli, dan kredensial. Bidang lingkungan yang dihilangkan mempertahankan perilaku produksi yang ada. Pendanaan, dana simulasi eksplisit, dan enam kueri abadi memerlukan model dan metode baru yang sesuai. Tinjauan [Panduan peningkatan](/id/sdk/agent-sdk/java/upgrade) sebelum mengubah integrasi yang ada.
