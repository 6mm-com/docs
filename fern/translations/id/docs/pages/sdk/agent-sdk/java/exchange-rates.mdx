import com.sixmm.agent.*;

## Tarif Referensi FX

Kedua metode FX menggunakan aliran Agen API yang ditandatangani secara normal. Mulailah dengan menemukan
mata uang sumber yang saat ini didukung:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Kueri semua tarif referensi fiat-ke-USDT yang didukung:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Kueri mata uang yang dipilih:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

Permintaan pabrik memangkas dan huruf besar kode mata uang dan membuat serialisasinya sebagai
nilai `sourceCurrencies` yang dipisahkan koma yang diperlukan oleh API. Menghilangkan
permintaan atau semua nilai mata uang efektif menanyakan setiap mata uang yang didukung.

| Bidang respons | Jenis | Keterangan |
| --- | --- | --- |
| `snapshotVersion` | string | Versi snapshot yang stabil untuk audit dan rekonsiliasi |
| `provider` | string | Penyedia hulu, saat ini `ECB` |
| `sourceDate` | string | Tanggal observasi hulu dalam format `yyyy-MM-dd` |
| `fetchedAt` / `expiresAt` | int64 | Stempel waktu Unix dalam milidetik |
| `pricingPolicy` | string | Saat ini `FIXED_PEG` |
| `usdtUsdRate` | string | USD jumlah per 1 USDT, saat ini ditetapkan pada `1` |
| `rateType` | string | Saat ini `INDICATIVE_DAILY` |
| `usage` | string | Saat ini `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT jumlah yang sesuai dengan satu unit fiat sumber |

Nilai-nilai ini adalah referensi untuk dihitung oleh dompet multi-mata uang mitra
jumlah USDT yang dikirim ke 6MM. Itu bukan harga yang dapat dieksekusi, kuotasi terkunci, atau
harga pasar USDT waktu nyata. Gunakan `BigDecimal` dan string untuk jumlahnya
perhitungan; jangan gunakan `double` atau `float`.
