## SDK

Buat token embed dari backend Anda setelah memvalidasi sesi pengguna mitra. Browser harus memanggil endpoint Anda, dan endpoint Anda harus memanggil 6MM melalui Agent SDK.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Kredensial sekali pakai**
>
> embedToken bersifat singkat dan hanya digunakan sekali saja. Jangan menempatkannya dalam string kueri URL .

<span id="backend-endpoint-example" data-sixmm-canonical-anchor="backend-endpoint-example" aria-hidden="true"></span>

## Contoh endpoint backend

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Kembalikan hanya bidang yang dibutuhkan oleh penyedia token Trading Widget . Jangan kembalikan apiSecret, field penandatanganan mentah, atau konfigurasi layanan internal.

## Penanganan kegagalan

| Kondisi | Penanganan yang direkomendasikan |
| --- | --- |
| Sesi pengguna hilang atau kedaluwarsa | Kembalikan 401 dari endpoint mitra dan minta pengguna untuk masuk lagi. |
| Pengguna agen tidak terikat | Ikat pengguna terlebih dahulu, lalu coba ulang pembuatan token. |
| 6MM mengembalikan kesalahan sementara | Kembalikan error yang dapat dicoba ulang ke frontend dan catat requestId untuk dukungan. |
| channelId tidak cocok dengan instance widget | Tolak permintaan dan buat ulang sesi widget. |
