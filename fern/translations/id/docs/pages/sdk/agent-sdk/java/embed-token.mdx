## Trading Widget Sematkan Token

Token yang disematkan adalah untuk mode Trading Widget SDK `partner-token + tokenProvider`. Itu
browser memanggil backend mitra, dan backend mitra memanggil ini Java SDK
untuk membuat `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Persyaratan integrasi:

- `channelId` harus menggunakan nilai yang diteruskan oleh Trading Widget SDK.
- `symbol` bersifat opsional, tetapi disarankan untuk meneruskan simbol awal saat ini.
- `embedToken` berumur pendek dan hanya sekali. Jangan memasukkannya ke dalam string kueri URL.
- Frontend mitra tidak boleh menampung `apiSecret`.
- `expireAt` adalah stempel waktu Unix dalam hitungan detik, bukan TTL.

Contoh titik akhir backend mitra:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Kontrak titik akhir mitra

Otentikasi sesi mitra dan dapatkan `agentUserId` di sisi server. Terima Widget saat ini `channelId`; mengembalikan `embedToken`, `expireAt` (Unix detik), dan `channelId` tingkat atas. Respons agen tidak menyediakan `channelId`: backend Anda mengulanginya. Ambil token baru pada inisialisasi dan pembaruan; jangan pernah menggunakannya kembali. Pembuatan token tidak mentransfer dana atau memilih lingkungan dompet.

Melihat [Perdagangan detik](/id/sdk/agent-sdk/java/seconds-trading) untuk aliran frontend/backend lengkap.
