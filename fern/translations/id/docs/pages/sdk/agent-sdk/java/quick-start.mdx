## Instal

Sumber SDK publik saat ini mendokumentasikan tag `v0.1.1` dengan koordinat Maven berikut:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

GitHub tidak berfungsi sebagai repositori ketergantungan Maven. Instal sumber yang ditandai secara lokal sebelum menyelesaikan ketergantungan:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Membangun tim**
>
> Publikasikan artefak yang disetujui ke repositori Maven organisasi Anda untuk build CI, pengujian, dan produksi. Konfirmasi versi yang disetujui dengan 6MM sebelum penerapan produksi.

Kode sumber dan contoh penggunaan tersedia di repositori resmi Java SDK :

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

## Sebelum Anda mulai

- Konfirmasi Agen produksi Anda API URL markas dengan tim 6MM .
- Simpan apiSecret hanya di manajemen rahasia backend.
- Siapkan pemetaan stabil antara platformUserId dan agentUserId.
- Aktifkan log terstruktur di sekitar aliran bind, transfer, order, dan webhook.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Inisialisasi klien

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Hanya backend**
>
> Jangan inisialisasi Agent SDK dari kode klien browser, mobile, atau desktop. SDK menandatangani permintaan API Agen yang memiliki hak istimewa.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Contoh: transfer dana ke

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Gunakan nomor pesanan sisi mitra yang unik untuk setiap permintaan transfer. Jika permintaan habis waktu, kueri pesanan asli sebelum membuat yang baru.
