## Contoh prasyarat

## Masuk Langsung URL

Entri langsung URL adalah untuk mode pengalihan. Pengguna mitra mengklik tombol di
situs mitra, membuka frontend 6MM, dan masuk secara otomatis.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Aturan lapangan:

| Bidang | Keterangan |
| --- | --- |
| `redirectPath` | 6MM jalur relatif frontend. Harus dimulai dengan `/`, misalnya `/trade/BTCUSDT` |
| `returnUrl` | Mitra absolut URL digunakan saat pengguna keluar dari frontend 6MM. Hanya `http` dan `https` yang diperbolehkan |
| `expireAt` | Waktu kedaluwarsa tiket masuk sebagai stempel waktu Unix dalam hitungan detik |

Persyaratan keamanan:

- `webUrl` berisi tiket satu kali. Gunakan segera dan jangan disimpan dalam jangka waktu lama.
- Jika entri URL kedaluwarsa atau telah digunakan, buat entri baru dari situs mitra.
- `returnUrl` tidak boleh berupa `javascript:`, jalur relatif, atau URL dengan info pengguna.

## Pemilihan produk dan mode

Gunakan rute frontend saat ini yang disediakan oleh 6MM. Misalnya `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real`, atau `/zh-CN/futures/BTCUSDT?tradingMode=real`. Tiket mengautentikasi pengguna; ia tidak memilih lingkungan pendanaan atau memindahkan dana.

Melihat [Perdagangan detik](/id/sdk/agent-sdk/java/seconds-trading) untuk contoh pengalihan dan penyematan.
