Mulailah dengan lingkungan, stempel waktu, dan pengidentifikasi bisnis untuk operasi yang gagal. Pemeriksaan terstruktur biasanya memisahkan masalah konfigurasi dari masalah autentikasi, jaringan, dan pemrosesan asinkron.

<span id="diagnostic-order" data-sixmm-canonical-anchor="diagnostic-order" aria-hidden="true"></span>

## Urutan diagnostik yang direkomendasikan

1. Konfirmasikan lingkungan dan pangkalan yang terkena dampak URL.
2. Catat rentang waktu UTC dan permintaan pertama yang gagal.
3. Identifikasi modul: Trading Widget, Agent SDK, REST API, WebSocket, atau webhook.
4. Catat ID permintaan, ID pengguna mitra, `agentOrderNo`, ID pesanan, atau webhook ID peristiwa.
5. Periksa kode terbaru, kredensial, IP daftar putih, atau perubahan penerapan.
6. Reproduksi dengan test case terkecil yang aman.

<span id="trading-widget-issues" data-sixmm-canonical-anchor="trading-widget-issues" aria-hidden="true"></span>

## Trading Widget masalah

| Gejala | Kemungkinan penyebabnya | Memperbaiki |
| --- | --- | --- |
| iframe meminta domain lokal mitra | baseUrl tidak ada | Lulus baseUrl: 'https://app.6mm.com'. |
| iframe tidak terlihat atau sangat pendek | Wadah induk tidak memiliki ketinggian | Tetapkan tinggi wadah atau tinggi lintasan. |
| token_provider_missing | mode token mitra tidak memiliki penyedia | Tambahkan autentikasi.tokenProvider. |
| auth_exchange_failed | Token penyematan tidak valid, kedaluwarsa, atau tidak cocok | Periksa respons token backend dan channelId. |

<span id="agent-sdk-issues" data-sixmm-canonical-anchor="agent-sdk-issues" aria-hidden="true"></span>

## Agent SDK masalah

| Gejala | Kemungkinan penyebabnya | Memperbaiki |
| --- | --- | --- |
| Tanda tangan ditolak | Rahasia salah, jam melayang, atau bidang yang ditandatangani diubah secara manual | Biarkan SDK menghasilkan bidang penandatanganan dan menyinkronkan waktu server. |
| Risiko perpindahan dana duplikat | Nomor pesanan baru digunakan setelah batas waktu habis | Kueri berdasarkan agentOrderNo asli terlebih dahulu. |
| PROCESSING dianggap gagal | Status yang tertunda disalahpahami | Tunggu webhook atau hubungi queryOrder. |
| Webhook diproses beberapa kali | Coba lagi perilaku tanpa idempotensi | Tambahkan kunci idempotensi dan pemeriksaan keadaan akhir. |

<span id="evidence-to-capture" data-sixmm-canonical-anchor="evidence-to-capture" aria-hidden="true"></span>

## Bukti untuk ditangkap

| Integrasi | Bukti yang berguna |
| --- | --- |
| Trading Widget | Jalur versi halaman URL, SDK, konsol browser, permintaan jaringan yang gagal, `onError` payload, dan dimensi kontainer. |
| Agent SDK | SDK bahasa/versi, basis URL, UTC stempel waktu, ID permintaan, `agentOrderNo`, kode respons, dan log yang dibersihkan. |
| Webhook | Waktu pengiriman, peristiwa atau kunci bisnis, hasil validasi tanda tangan, status pemrosesan, dan hash tubuh mentah yang dibersihkan. |
| REST API | Metode, jalur, lingkungan, ID permintaan, kode respons, dan parameter yang dibersihkan. |

Jangan pernah menyertakan kata sandi, token akses, API rahasia, tanda tangan lengkap, kunci pribadi, atau data pribadi yang tidak disunting dalam diagnostik.

<span id="before-escalating" data-sixmm-canonical-anchor="before-escalating" aria-hidden="true"></span>

## Sebelum meningkat

- Coba lagi hanya ketika operasi didokumentasikan aman untuk dicoba lagi.
- Setelah waktu habis, tanyakan pengidentifikasi bisnis asli alih-alih membuat yang baru.
- Konfirmasikan jam sistem dan lingkungan kredensial untuk kesalahan tanda tangan.
- Pertahankan kegagalan pertama dan hasil percobaan ulang selanjutnya.
- Gunakan [Templat Permintaan Dukungan](/id/resources/support-request-template) untuk mengirimkan laporan yang lengkap dan telah disunting.

## Java diagnostik v0.3.0

| Gejala | Periksa dan pemulihan |
| --- | --- |
| Permintaan pendanaan memiliki hasil yang tidak diketahui | Simpan `agentOrderNo` yang asli; panggil `queryWalletTransfer` dengan lingkungan aslinya. Jangan gunakan `queryOrder`. |
| Simulasi UI menunjukkan dana tak terduga | Periksa frontend `tradingMode` secara terpisah dari backend `environment`; akun `isSimulatedUser` tidak merutekan permintaan. |
| Kesalahan kueri `6905` | Mundur menggunakan kuota mitra bersama, lalu coba lagi kursor yang sama dan filter melalui SDK. |
| Kesalahan kueri `6904` | Kurangi kueri bersamaan dan persempit jangka waktu; hubungi dukungan jika terus-menerus. |
| Kursor tidak valid atau kedaluwarsa | Mulai ulang jendela riwayat tetap yang sama dan hapus duplikat catatan yang disimpan. |
| Metode Java baru tidak ada | Periksa artefak Maven yang terselesaikan terhadap tag publik `v0.3.0`; hapus dependensi yang bertentangan sesuai dengan kebijakan artefak Anda. |
