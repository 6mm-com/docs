Bagian ini ditulis untuk edukasi produk, operasi, dukungan, dan pengguna akhir. Untuk API kolom, penandatanganan, dan detail integrasi backend, gunakan bagian Pengembang dan SDK .

<h2 id="before-trading">Sebelum trading</h2>

- Konfirmasi pengguna masuk melalui mitra yang berwenang atau entri 6MM tertanam.
- Pastikan dana tersedia di rekening yang benar sebelum melakukan pemesanan.
- Memahami perilaku leverage, margin, likuidasi, dan biaya pendanaan.
- Mulailah dengan ukuran posisi kecil saat mempelajari pasar atau mode trading baru.
- Gunakan TP / SL dan perintah pengurangan hanya jika sesuai untuk pengendalian risiko.
