## Waktu dan Nilai Numerik

* Kecuali ditentukan lain, kolom waktu adalah timestamp milidetik Unix.
* Statistik harian, snapshot saldo, dan statistik volume trading secara default menggunakan batas hari UTC .
* Bidang yang sensitif terhadap presisi seperti jumlah, harga, jumlah, dan tarif dikirimkan sebagai string.
* ID bilangan bulat besar seperti `orderId`, `conditionId`, dan `strategyId` dikembalikan sebagai string dalam JSON.

<span id="response-format" data-sixmm-canonical-anchor="response-format" aria-hidden="true"></span>

## Format Respons

Respon berhasil:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Respons kesalahan:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Catatan:

* Kesalahan bisnis biasanya masih mengembalikan struktur JSON yang terpadu. Integrator harus memeriksa `code` terlebih dahulu.
* Kegagalan autentikasi dapat mengembalikan HTTP `401`; Pembatasan laju dapat mengembalikan HTTP `429`.
* Anda dapat mengirim `X-Request-ID` di header permintaan. Server akan mengembalikannya sebagai `requestId` dalam respons.
