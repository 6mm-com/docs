> REST URL dasar : `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Dokumentasi ini ditujukan untuk sistem eksternal yang terintegrasi dengan layanan 6MM API . Dokumentasi ini mencakup login, autentikasi JWT , manajemen API Key , penandatanganan API Key HMAC , kueri akun, pesanan, posisi, data pasar, dan aliran WebSocket .

Penyediaan akun dan persiapan pendanaan ditangani melalui proses di sisi platform. Dokumentasi ini hanya menjelaskan endpoint layanan API yang dapat dipanggil secara eksternal.

| Tipe      | Titik Akhir              |

| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Alur Integrasi

Urutan integrasi yang direkomendasikan:

1. Masuk dengan akun yang disediakan oleh platform dan dapatkan `accessToken`.
2. Untuk akses programatik sisi server, buat API Key dengan JWT terlebih dahulu, dan simpan `apiSecret`yang dikembalikan sekali pakai dengan aman.
3. Kueri privat, endpoint pesanan, dan endpoint posisi dapat dipanggil dengan `Authorization: Bearer <accessToken>` atau penandatanganan API Key.
4. Untuk stream WebSocket privat, buat `listenKey` terlebih dahulu, lalu sambungkan ke `wss://ws.6mm.com/ws?listenKey=...`.
5. Data pasar REST endpoint dan saluran WebSocket publik tidak memerlukan autentikasi.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Pilihan Autentikasi

| Skenario                               | Metode yang direkomendasikan         |
| -------------------------------------- | -------------------------- |
| Tindakan pengguna frontend                  | JWT                        |
| Panggilan programatik di sisi server         | API Key + tanda tangan HMAC   |
| API Key pembuatan, pembaruan, dan penghapusan | JWT                        |
| REST pasar publik / WebSocket publik  | Tidak memerlukan otentikasi |
