## Endpoint Layanan

```
wss://ws.6mm.com/ws
```

WebSocket saluran dibagi menjadi saluran publik dan saluran privat:

| Tipe             | Autentikasi              | Deskripsi                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Saluran publik  | Tidak wajib                | Data pasar, seperti kedalaman, perdagangan, Klines, dan ticker |
| Saluran privat | `listenKey` atau JWT diperlukan | Urutan pengguna, akun, dan aliran posisi              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## Saluran Publik

WebSocket publik tidak memerlukan autentikasi. Setelah terhubung, kirim permintaan `subscribe` untuk berlangganan saluran pasar.

Saluran umum:

| Saluran                            | Deskripsi                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Kedalaman pesan buku. Mengirim snapshot terlebih dahulu, lalu pembaruan bertahap |
| `market.trade.{symbol}`            | Perdagangan terbaru                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Ringkasan ticker simbol tunggal                                       |
| `market.tickers`                   | Ringkasan ticker semua simbol                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## Saluran Pribadi

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
Untuk aliran WebSocket privat, buat `listenKey` melalui REST API terlebih dahulu, lalu hubungkan ke:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
Metode koneksi JWT yang kompatibel:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Setelah autentikasi berhasil, server secara otomatis berlangganan koneksi ke saluran privat pengguna saat ini. Tidak diperlukan langganan manual.
