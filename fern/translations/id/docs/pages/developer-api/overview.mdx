<h2 id="production-checklist">Daftar periksa produksi</h2>

- Simpan rahasia API hanya di backend.
- Sinkronkan waktu server sebelum permintaan yang ditandatangani.
- Perlakukan semua bidang presisi numerik sebagai string kecuali halaman secara eksplisit menyatakan sebaliknya.
- Gunakan idempotensi, ID permintaan, dan log terstruktur seputar alur pesanan.
- Berlangganan aliran WebSocket untuk status yang harus tetap terkini dalam sistem operasional.
- Tinjau kode kesalahan dan mencoba ulang perilaku sebelum peluncuran.
