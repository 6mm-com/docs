## Area dokumentasi

| Luas | Apa yang dibahas |
| --- | --- |
| Pengaturan integrasi | Alamat layanan, konvensi permintaan, bentuk respons, dan mode akses. |
| Autentikasi & keamanan | JWT, izin API Key , penandatanganan HMAC , perlindungan replay, dan sinkronisasi waktu. |
| REST API | Endpoint publik, data pengguna/akun, pesanan, posisi, dan data pasar. |
| WebSocket | Siklus hidup koneksi, aliran pasar publik, dan aliran pengguna pribadi. |
| Referensi & pemecahan masalah | Enum, kode kesalahan, dan rekomendasi integrasi praktis. |

## Daftar periksa produksi

- Simpan rahasia API hanya di backend.
- Sinkronkan waktu server sebelum permintaan yang ditandatangani.
- Perlakukan semua bidang presisi numerik sebagai string kecuali halaman secara eksplisit menyatakan sebaliknya.
- Gunakan idempotensi, ID permintaan, dan log terstruktur seputar alur pesanan.
- Berlangganan aliran WebSocket untuk status yang harus tetap terkini dalam sistem operasional.
- Tinjau kode kesalahan dan mencoba ulang perilaku sebelum peluncuran.
