> **Direncanakan — belum diluncurkan**
> AI Hub adalah fitur yang direncanakan. Kemampuan, titik akhir, perintah, dan konfigurasi klien di halaman ini menjelaskan desain yang diusulkan dan saat ini tidak tersedia. Ketersediaan akhir dan petunjuk pengaturan akan diumumkan saat peluncuran.


Pilih pengaturan berdasarkan dua pertanyaan:

1. Klien AI mana yang ingin Anda gunakan?
2. Apakah Anda hanya memerlukan data publik, akses akun pribadi, atau alur kerja perdagangan?

Jika Anda tidak yakin, mulailah dengan Hosted MCP untuk data publik atau Lokal MCP untuk alur kerja akun pribadi.

## Tabel keputusan cepat

| Sasaran | Pengaturan yang disarankan | Mengapa |
| --- | --- | --- |
| Mintalah klien AI untuk data pasar publik | Dihosting MCP | Tidak diperlukan instalasi lokal dan tidak diperlukan kunci API. |
| Biarkan Claude Desktop, Cursor, atau ChatGPT Desktop memanggil alat 6MM | Lokal MCP | AI memanggil alat melalui server lokal yang dikendalikan oleh pengguna. |
| Biarkan Codex, Claude Code, Gemini CLI, atau skrip memanggil 6MM | CLI | Output perintah dapat berupa JSON dan mudah diurai oleh agen. |
| Menyediakan titik akhir MCP yang dikelola perusahaan | Jarak jauh MCP | Institusi mengontrol hosting, kredensial, akses, dan log. |
| Standarisasi analisis berulang atau alur kerja risiko | Keterampilan Agenik | Templat menentukan penggunaan alat, pagar pembatas, dan format keluaran. |

## Pilih berdasarkan jalur pengaturan

| Pengaturan | Instalasi | API lokasi kunci | Cakupan awal terbaik | Ruang lingkup akun dan perdagangan |
| --- | --- | --- | --- | --- |
| Dihosting MCP | Tidak ada | Tidak ada kunci pengguna API untuk data publik | Data pasar publik | Tidak direkomendasikan untuk rilis pertama |
| Lokal MCP | Paket instalasi pengguna | Mesin pengguna | Data publik dan pembacaan akun | Jalur yang disarankan untuk perdagangan masa depan |
| CLI | Paket instalasi pengguna | Mesin pengguna | Data dan skrip publik | Berguna untuk pratinjau dan otomatisasi |
| Jarak jauh MCP | Pengguna menyebarkan server | Cloud pengguna atau cloud institusi | Data publik atau pembacaan akun | Mungkin ketika pengguna mengontrol penerapan |
| Keterampilan | Dokumen atau templat yang dapat diinstal | Tergantung pada alat yang mendasarinya | Alur kerja analisis | Harus mengikuti izin alat |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## Aturan praktis keamanan

Gunakan pengaturan dengan risiko paling rendah yang mendukung tugas tersebut:

- Data pasar publik: MCP yang dihosting sudah cukup.
- Data akun pribadi: Lokal MCP atau Remote yang dikelola pengguna MCP.
- Pratinjau perdagangan: Lokal MCP atau CLI, sebaiknya testnet terlebih dahulu.
- Perdagangan nyata: hanya setelah izin eksplisit, pratinjau, konfirmasi, batasan, dan log audit.
