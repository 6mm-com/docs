MCP lokal adalah pengaturan yang disarankan ketika klien AI memerlukan konteks akun pribadi atau alat perdagangan yang dikontrol di masa depan.

Server MCP berjalan di mesin pengguna. Klien AI memanggil alat 6MM lokal, dan server lokal berkomunikasi dengan 6MM APIs menggunakan kredensial yang dikonfigurasi oleh pengguna.

<span id="what-your-ai-client-can-do" data-sixmm-canonical-anchor="what-your-ai-client-can-do" aria-hidden="true"></span>

## Apa yang dapat dilakukan klien AI Anda

Dengan MCP Lokal, klien AI dapat menggunakan alat 6MM dengan cara yang terkendali:

- Ambil data pasar langsung dan historis.
- Baca saldo akun, posisi, pesanan terbuka, pengisian, dan catatan pendanaan ketika kredensial hanya-baca diaktifkan.
- Jelaskan eksposur portofolio, penggunaan margin, dan risiko likuidasi.
- Pratinjau pesanan sebelum pesanan sebenarnya dilakukan.
- Pada fase perdagangan terkontrol selanjutnya, buat atau batalkan pesanan hanya setelah izin eksplisit dan pemeriksaan risiko.

Gunakan Lokal MCP ketika kredensial harus tetap ada di mesin pengguna.

## Arsitektur

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

## Contoh konfigurasi

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

## Tingkat izin yang disarankan

| Tingkat | Peralatan | Catatan |
| --- | --- | --- |
| Data publik | Pasar, ticker, orderbook, klines, perdagangan, pendanaan | Tidak ada akses akun pribadi. |
| Akun dibaca | Saldo, posisi, pesanan terbuka, pengisian | Memerlukan cakupan kunci API yang hanya dapat dibaca. |
| Pratinjau perdagangan | Pratinjau pesanan, dampak margin, perkiraan biaya | Tidak memesan. |
| Perdagangan terkendali | Buat, batalkan, ubah pesanan | Memerlukan izin eksplisit, konfirmasi, dan pengendalian risiko. |

## Daftar periksa pengaturan pertama

1. Instal paket MCP.
2. Membuat atau mengonfigurasi kunci API hanya-baca.
3. Mulai di testnet.
4. Tambahkan server MCP ke konfigurasi klien AI.
5. Minta klien untuk membuat daftar 6MM alat yang tersedia.
6. Jalankan kueri data pasar publik.
7. Baru kemudian tambahkan kredensial baca akun jika diperlukan.

<span id="security-notes" data-sixmm-canonical-anchor="security-notes" aria-hidden="true"></span>

## Catatan keamanan

MCP lokal seharusnya bersifat read-only dan testnet secara default. Alat perdagangan harus memerlukan pratinjau, konfirmasi pengguna, kunci idempotensi, batasan nosional, dan pemeriksaan risiko sisi layanan.
