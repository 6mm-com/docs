> AI Hub adalah fitur yang direncanakan. Kemampuan, titik akhir, perintah, dan konfigurasi klien di halaman ini menjelaskan desain yang diusulkan dan saat ini tidak tersedia. Ketersediaan akhir dan petunjuk pengaturan akan diumumkan saat peluncuran.


Claude Desktop cocok untuk penelitian berbasis MCP-, tinjauan akun, dan analisis operasional.

<h2 id="recommended-setup">Pengaturan yang disarankan</h2>

| Membutuhkan | Pengaturan |
| --- | --- |
| Riset pasar publik | Dihosting MCP |
| Analisis sadar akun | Lokal MCP |
| Titik akhir tim internal | Jarak jauh MCP |

<h2 id="example-prompts">Contoh petunjuknya</h2>

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<h2 id="notes">Catatan</h2>

MCP lokal lebih disukai setiap kali data akun pribadi terlibat karena server MCP berjalan di mesin pengguna dan kredensial tidak perlu dikirim ke titik akhir AI yang dihosting 6MM.
