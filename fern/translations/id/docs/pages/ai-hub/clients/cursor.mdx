Kursor sangat cocok untuk pengembang mitra yang menginginkan konteks 6MM di dalam editor kode mereka.

<h2 id="recommended-setup">Pengaturan yang disarankan</h2>

| Membutuhkan | Pengaturan |
| --- | --- |
| Tanyakan tentang SDK dokumen saat membuat kode | Lokal MCP |
| Hasilkan perintah integrasi | 6MM CLI |
| Jaga agar perintah tim tetap konsisten | Keterampilan Agenik |
