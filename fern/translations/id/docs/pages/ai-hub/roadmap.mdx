> **Direncanakan — belum diluncurkan**
> AI Hub adalah fitur yang direncanakan. Kemampuan, titik akhir, perintah, dan konfigurasi klien di halaman ini menjelaskan desain yang diusulkan dan saat ini tidak tersedia. Ketersediaan akhir dan petunjuk pengaturan akan diumumkan saat peluncuran.


AI Hub harus dirilis secara bertahap sehingga pengguna menerima nilai lebih awal sementara kemampuan perdagangan sensitif tetap terlindungi.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## Fase 1: Akses AI Pasar Publik

Sasaran: memungkinkan klien AI yang didukung membaca data pasar resmi 6MM.

Kiriman:

- Klien SDK / API bersama.
- CLI perintah pasar publik.
- Alat pasar publik lokal MCP.
- Alat pasar publik MCP yang dihosting.
- Sumber daya untuk pasar, biaya, aturan risiko, dan status sistem.
- Panduan instalasi klien.

Tidak termasuk:

- Pertanyaan akun.
- Perdagangan nyata.
- API hosting kunci.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Tahap 2: Pembacaan Akun

Sasaran: memungkinkan pengguna memeriksa konteks akun mereka sendiri dengan aman.

Kiriman:

- Cakupan kunci API hanya baca.
- Ringkasan akun.
- Saldo.
- Posisi.
- Buka pesanan.
- Mengisi.
- Pembayaran pendanaan.
- Permintaan risiko portofolio.

Penerapan pilihan:

- Lokal MCP.
- CLI.
- MCP jarak jauh yang dihosting sendiri.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Fase 3: Pratinjau Perdagangan

Sasaran: biarkan AI membantu menghasilkan pesanan tanpa mengeksekusinya.

Kiriman:

- `preview_order`.
- Pemeriksaan risiko.
- Dampak margin.
- Perkiraan biaya.
- Dampak likuidasi.
- Perencanaan eksekusi cepat.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Fase 4: Perdagangan Terkendali

Sasaran: mendukung perdagangan nyata hanya dengan pagar pembatas yang kuat.

Kiriman:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- idempotensi.
- batas nosional maksimal.
- konfirmasi eksplisit.
- log audit.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Fase 5: Keterampilan Agenik

Sasaran: menghasilkan analisis pasar umum dan alur kerja risiko.

Kiriman:

- Keterampilan analis pasar.
- Keterampilan risiko portofolio.
- Mendanai keterampilan penelitian.
- Keterampilan perlindungan likuidasi.
- Keterampilan perencana eksekusi.
- Contoh perpustakaan tugas.
