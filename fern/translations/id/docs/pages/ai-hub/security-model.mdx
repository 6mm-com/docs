## Postur keselamatan default

- Defaultnya adalah hanya-baca.
- Bawaan ke testnet.
- Jangan memaparkan penarikan atau transfer melalui alat AI.
- Memerlukan pratinjau sebelum membuat.
- Memerlukan konfirmasi eksplisit sebelum perdagangan mainnet.
- Gunakan kunci idempotensi untuk tindakan perdagangan.
- Terapkan batas nosional dan leverage maksimal.
- Simpan log audit lengkap.

<span id="controlled-trading-flow" data-sixmm-canonical-anchor="controlled-trading-flow" aria-hidden="true"></span>

## Arus perdagangan terkendali

```text
User natural language intent
  -> AI maps intent to tool parameters
  -> 6mm_preview_order validates the order
  -> service returns risk checks and margin impact
  -> user explicitly confirms
  -> 6mm_create_order submits the order
  -> audit log records the full flow
```

## Perlindungan injeksi yang cepat

Klien AI dan server MCP harus memperlakukan konten eksternal sebagai tidak tepercaya. Halaman pasar, salinan teks, dokumen, dan konten web tidak boleh mengabaikan izin alat, aturan konfirmasi, atau batasan perdagangan.
