> **Direncanakan — belum diluncurkan**
> AI Hub adalah fitur yang direncanakan. Kemampuan, titik akhir, perintah, dan konfigurasi klien di halaman ini menjelaskan desain yang diusulkan dan saat ini tidak tersedia. Ketersediaan akhir dan petunjuk pengaturan akan diumumkan saat peluncuran.


MCP alat adalah tindakan yang dapat dipanggil oleh klien AI. Setiap alat harus memiliki deskripsi yang jelas, skema JSON, persyaratan izin, format respons stabil, dan model kesalahan.

<h2 id="phase-1-public-market-tools">Fase 1: alat pasar publik</h2>

| Alat | Tujuan |
| --- | --- |
| 6mm_system_status | Periksa layanan dan ketersediaan pasar. |
| 6mm_pasar | Buat daftar pasar yang tersedia dan metadata dasar. |
| 6mm_pasar_ringkasan | Ringkas keadaan pasar untuk satu atau lebih simbol. |
| 6mm_ticker | Kembalikan data ticker terbaru. |
| 6mm_buku pesanan | Kedalaman buku pesanan pengembalian. |
| 6mm_klines | Kembalikan lilin bersejarah. |
| 6mm_perdagangan | Kembalikan perdagangan publik terkini. |
| 6mm_dana_tarif | Kembalikan tingkat pendanaan saat ini dan historis. |

<h2 id="tool-requirements">Persyaratan alat</h2>

Setiap alat harus mendefinisikan:

- Deskripsi untuk model AI.
- Masukkan skema JSON.
- Ruang lingkup izin.
- Dukungan lingkungan.
- Perilaku batas nilai.
- Bidang respons yang stabil.
- Kode kesalahan.
- Bidang log audit.
