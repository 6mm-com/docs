## Perintah yang direkomendasikan

| Mengingatkan | Tujuan |
| --- | --- |
| pasar_ikhtisar | Ringkas keadaan pasar di seluruh simbol yang dipilih. |
| analisis_struktur_mikro pasar | Analisis spread, kedalaman, perdagangan terkini, dan kondisi likuiditas. |
| penilaian_risiko_portofolio | Tinjau posisi, eksposur, margin, dan risiko likuidasi. |
| posisi_manajemen | Bantu pengguna memahami status posisi dan kemungkinan tindakan. |
| likuidasi_perlindungan | Identifikasi risiko likuidasi dan opsi pengurangan risiko. |
| pendanaan_tingkat_peluang | Bandingkan tingkat pendanaan dan kemungkinan peluang. |
| buat_pesanan_optimal | Rencanakan parameter pesanan sebelum pratinjau. |
| lindung nilai_strategi | Jelajahi opsi lindung nilai untuk eksposur yang ada. |
| perdagangan_konsultasi | Menghasilkan analisis perdagangan terstruktur tanpa mengeksekusi pesanan. |

<span id="prompt-safety-rules" data-sixmm-canonical-anchor="prompt-safety-rules" aria-hidden="true"></span>

## Aturan keselamatan yang cepat

- Jangan menganggap hasil yang cepat sebagai nasihat keuangan.
- Jangan mengeksekusi alat perdagangan kecuali pengguna memintanya secara eksplisit.
- Gunakan pratinjau sebelum membuat.
- Menjelaskan asumsi dan sumber data.
- Lebih suka contoh testnet dalam dokumentasi publik.
