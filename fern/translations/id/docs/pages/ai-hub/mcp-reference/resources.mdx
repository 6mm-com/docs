> **Direncanakan — belum diluncurkan**
> AI Hub adalah fitur yang direncanakan. Kemampuan, titik akhir, perintah, dan konfigurasi klien di halaman ini menjelaskan desain yang diusulkan dan saat ini tidak tersedia. Ketersediaan akhir dan petunjuk pengaturan akan diumumkan saat peluncuran.


MCP sumber daya adalah konteks hanya-baca yang dapat diperiksa oleh klien AI sebelum memanggil alat.

Sumber daya mengurangi halusinasi dengan memberikan model informasi yang stabil dan terstruktur tentang 6MM.

<span id="recommended-resource-uris" data-sixmm-canonical-anchor="recommended-resource-uris" aria-hidden="true"></span>

## URI sumber daya yang direkomendasikan

| Sumber | Tujuan |
| --- | --- |
| 6mm://sistem/konfigurasi | Konfigurasi lingkungan dan kemampuan. |
| 6mm://sistem/status | Sistem saat ini dan status pasar. |
| 6mm://pasar | Pasar yang tersedia. |
| 6mm://pasar/{symbol} | Spesifikasi kontrak dan metadata tingkat pasar. |
| 6mm://biaya | Aturan biaya. |
| 6mm://risiko/aturan | Ringkasan aturan perdagangan dan risiko. |
| 6mm://risiko/margin | Konteks margin dan likuidasi. |
| 6mm://pendanaan/aturan | Aturan tingkat pendanaan. |
| 6mm://api/docs | API ringkasan referensi atau tautan. |

<span id="resource-design-rules" data-sixmm-canonical-anchor="resource-design-rules" aria-hidden="true"></span>

## Aturan desain sumber daya

- Jaga agar sumber daya hanya dapat dibaca.
- Gunakan skema yang stabil.
- Sertakan stempel waktu dan nama lingkungan.
- Hindari membeberkan rahasia.
- Lebih menyukai data terstruktur yang ringkas daripada prosa yang panjang.
- Tautan ke dokumentasi kanonik jika detailnya terlalu panjang.
