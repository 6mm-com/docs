> **Direncanakan — belum diluncurkan**
> AI Hub adalah fitur yang direncanakan. Kemampuan, titik akhir, perintah, dan konfigurasi klien di halaman ini menjelaskan desain yang diusulkan dan saat ini tidak tersedia. Ketersediaan akhir dan petunjuk pengaturan akan diumumkan saat peluncuran.


MCP jarak jauh ditujukan untuk pengguna atau institusi yang menginginkan titik akhir MCP yang berjalan lama di bawah kendali mereka sendiri.

Berbeda dengan MCP yang Dihosting, MCP jarak jauh tidak dioperasikan oleh 6MM untuk pengguna. 6MM menyediakan kode, gambar, templat, dan dokumentasi; pengguna mengontrol hosting dan kredensial.

<span id="architecture" data-sixmm-canonical-anchor="architecture" aria-hidden="true"></span>

## Arsitektur

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<span id="deployment-targets" data-sixmm-canonical-anchor="deployment-targets" aria-hidden="true"></span>

## Target penerapan

- Docker atau Docker Menulis.
- VPS dengan proksi terbalik.
- Kereta Api.
- Memberikan.
- Terbang.io.
- AWS ECS atau Lambda.
- Kubernet internal.

<span id="required-files" data-sixmm-canonical-anchor="required-files" aria-hidden="true"></span>

## File yang diperlukan

- file buruh pelabuhan.
- buruh pelabuhan-compose.yml.
- .env.template.
- HTTP mode transportasi.
- /mcp titik akhir.
- /titik akhir kesehatan.
- Proksi terbalik dan TLS catatan.

<span id="credential-model" data-sixmm-canonical-anchor="credential-model" aria-hidden="true"></span>

## Model kredensial

Kredensial harus disimpan di lingkungan yang dikelola pengguna, bukan di perintah klien AI. Untuk penerapan yang dikelola institusi, batasi akses ke klien dan jaringan yang disetujui.

<span id="recommended-first-release" data-sixmm-canonical-anchor="recommended-first-release" aria-hidden="true"></span>

## Rilis pertama yang direkomendasikan

Mulailah dengan data pasar publik. Tambahkan hanya baca akun setelah autentikasi, pelingkupan kunci, log, dan kontrol akses tersedia. Perdagangan harus tetap dinonaktifkan sampai persyaratan perdagangan yang terkendali terpenuhi.
