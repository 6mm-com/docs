<h2 id="how-the-solutions-connect">Bagaimana solusi terhubung</h2>

Sebagian besar implementasi mitra menggabungkan lebih dari satu kemampuan 6MM . Bursa white-label dapat menggunakan likuiditas institusional, dukungan kepatuhan, dan integrasi API . Mitra trading embedded dapat memulai dengan Trading Widget SDK dan kemudian menambahkan alur Agent SDK backend, pemrosesan webhook, dan sumber daya operasional.
