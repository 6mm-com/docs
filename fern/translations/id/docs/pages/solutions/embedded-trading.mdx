Sistem Trading Embedded API / SDK dirancang untuk mitra yang sudah memiliki lalu lintas, pengguna, atau alur kerja bisnis dan ingin menambahkan trading tanpa membangun bursa penuh dari awal.

<span id="what-it-provides" data-sixmm-canonical-anchor="what-it-provides" aria-hidden="true"></span>

## Apa yang disediakan

- Terminal trading tertanam melalui Trading Widget SDK
- Integrasi backend mitra melalui Agent SDK
- Pengikatan identitas pengguna dan alur token entri
- Transfer aset, pesanan, posisi, dan akses API akun
- Integrasi event, webhook, dan siklus hidup untuk sistem operasional

<span id="recommended-architecture" data-sixmm-canonical-anchor="recommended-architecture" aria-hidden="true"></span>

## Arsitektur yang direkomendasikan

| lapisan | Tanggung Jawab |
| --- | --- |
| Frontend mitra | Menjadi host titik masuk dan menyematkan antarmuka trading 6MM . |
| Backend mitra | Menjaga rahasia API , memvalidasi pengguna, mengeluarkan token yang disematkan, dan memproses webhook. |
| Infrastruktur perdagangan 6MM | Menangani UI trading, pencocokan, risiko, likuiditas, status akun, dan siklus hidup trading. |

## Pilih jalur integrasi

| Persyaratan | Jalur yang direkomendasikan |
| --- | --- |
| Antarmuka perdagangan lengkap dengan integrasi web tercepat | Trading Widget |
| Penanganan pengikatan pengguna backend, transfer, URL entri, dan webhook | Agent SDK |
| Alur kerja produk dan pesanan yang sepenuhnya disesuaikan | REST API + WebSocket |
| Pengalaman pertukaran bermerek dengan cakupan operasional yang lebih luas | Pertukaran label putih |

Desain akhir dapat menggabungkan jalur-jalur ini. Konfirmasi autentikasi, kepemilikan aset, batas tanggung jawab, pemantauan, dan dukungan produksi sebelum implementasi dimulai.
