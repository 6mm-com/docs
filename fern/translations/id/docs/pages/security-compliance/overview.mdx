<h2 id="documentation-map">Peta dokumentasi</h2>

| Luas | Tujuan |
| --- | --- |
| Arsitektur keamanan | Pahami bagaimana infrastruktur perdagangan, akses API/SDK , dan operasi mitra dilindungi. |
| Keamanan API dan Webhook | Lindungi integrasi backend melalui penandatanganan, penyimpanan rahasia, dan pemrosesan idempotent. |
| Kesiapan kepatuhan | Siapkan konteks dukungan lisensi, pemeriksaan peluncuran, dan kontrol operasional sisi mitra. |
| Dokumen hukum | Tinjau syarat, privasi, dan batas tanggung jawab sebelum peluncuran produksi. |

<h2 id="recommended-reading-order">Urutan bacaan yang direkomendasikan</h2>

1. Mulailah dengan Arsitektur Keamanan dan Batas Tanggung Jawab Mitra.
2. Tinjau API Key Management, Penandatanganan Permintaan, dan idempotensi Webhook sebelum integrasi backend.
3. Tinjau Tinjauan Kepatuhan dan Dukungan Lisensi sebelum persiapan peluncuran regional.
4. Tinjau halaman legal dan daftar periksa peluncuran sebelum memperkenalkan fungsi trading kepada pengguna.
