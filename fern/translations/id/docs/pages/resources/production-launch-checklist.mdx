Gunakan daftar periksa ini sebelum memperkenalkan kemampuan trading yang didukung 6MMkepada pengguna nyata.

<span id="integration-readiness" data-sixmm-canonical-anchor="integration-readiness" aria-hidden="true"></span>

## Kesiapan integrasi

- Domain produksi dan jalur pengalihan dikonfirmasi.
- Trading Widget, Agent SDK, API, atau aliran WebSocket telah diuji secara end-to-end.
- Backend mitra menyimpan semua rahasia di sisi server.
- Penerimaan Webhook, verifikasi tanda tangan, penanganan ulang, dan idempotensi diaktifkan.
- Log mencakup ID permintaan, ID pemetaan pengguna, ID pesanan, dan cap waktu.

<span id="product-and-resource-readiness" data-sixmm-canonical-anchor="product-and-resource-readiness" aria-hidden="true"></span>

## Kesiapan produk dan sumber daya

- Titik masuk, banner, dan aset kartu menggunakan versi bahasa yang disetujui.
- Aset white-label hanya digunakan ketika perjanjian kerja sama mengizinkannya.
- Prompt risiko yang ditujukan kepada pengguna dan salinan entri trading ditinjau oleh tim mitra.
- Pemilik dukungan dan eskalasi ditugaskan.

<span id="operational-readiness" data-sixmm-canonical-anchor="operational-readiness" aria-hidden="true"></span>

## Kesiapan operasional

- Pemantauan mencakup kesalahan API , penerbitan token, inisialisasi widget, kegagalan webhook, dan peristiwa siklus hidup pesanan.
- Jalur kontak darurat telah dikonfirmasi.
- Rencana rollback atau rencana discapacitasi sementara disiapkan untuk entri perdagangan.

<span id="security-and-compliance-readiness" data-sixmm-canonical-anchor="security-and-compliance-readiness" aria-hidden="true"></span>

## Kesiapan keamanan dan kepatuhan

- Kunci API menggunakan izin minimum dan pembatasan IP yang disetujui jika berlaku.
- Rotasi dan pencabutan kredensial telah diuji.
- Tanda tangan Webhook diverifikasi terhadap badan permintaan mentah.
- Pengungkapan pengguna, pemberitahuan risiko, batas tanggung jawab, dan tinjauan pasar sasaran telah selesai.
- Bukti insiden, rekonsiliasi, dan dukungan dapat diambil tanpa mengungkap rahasia.
