Sumber daya integrasi dan dukungan dipersiapkan untuk tim yang menambahkan kemampuan trading 6MM ke produk yang sudah ada, meluncurkan bursa white-label, atau mempersiapkan materi operasional untuk penggunaan produksi.

<h2 id="resource-areas">Area sumber daya</h2>

<CardGroup cols={2}>
<Card title="Merek & Aset" icon="fa-duotone fa-palette" href="/id/resources/brand-assets/usage-guidelines">
Gunakan aset visual 6MM yang telah disetujui, banner entri, aset kartu, dan panduan materi label putih.
</Card>
<Card title="Bahan Peluncuran" icon="fa-duotone fa-rocket" href="/id/resources/production-launch-checklist">
Siapkan pemeriksaan peluncuran produksi, informasi integrasi, dan detail serah terima dukungan.
</Card>
<Card title="Unduhan Aset" icon="fa-duotone fa-folder-arrow-down" href="/id/resources/brand-assets/asset-downloads">
Unduh paket logo, banner, entri kartu, dan aset label putih.
</Card>
<Card title="Template Permintaan Dukungan" icon="fa-duotone fa-message-question" href="/id/resources/support-request-template">
Gunakan format yang konsisten saat melaporkan masalah integrasi, perdagangan, atau produksi.
</Card>
</CardGroup>

<h2 id="when-to-use-this-section">Kapan menggunakan bagian ini</h2>

| Skenario | Halaman yang direkomendasikan |
| --- | --- |
| Tambahkan entri trading 6MM ke aplikasi atau halaman web | Pedoman Penggunaan |
| Perlu file logo, banner, atau entri kartu | Unduhan Aset |
| Siapkan peluncuran bermerek mitra | Dukungan White-label |
| Beralih dari pengujian ke produksi | Daftar Periksa Peluncuran Produksi |
| Minta dukungan 6MM untuk menyelidiki masalah | Template Permintaan Dukungan |
