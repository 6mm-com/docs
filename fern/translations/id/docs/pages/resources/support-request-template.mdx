Saat menghubungi dukungan, sertakan informasi di bawah ini jika tersedia.

<h2 id="required-context">Konteks yang diperlukan</h2>

| Lapangan | Contoh |
| --- | --- |
| Lingkungan | Produksi atau penataan |
| Modul yang terdampak | Trading Widget, Agent SDK, REST API, WebSocket, webhook, sistem white-label |
| Rentang waktu | UTC rentang timestamp saat masalah terjadi |
| ID pengguna mitra | Pengidentifikasi pengguna sisi mitra, jika relevan |
| ID pemetaan 6MM | agentUserId, ID pesanan, ID permintaan, atau ID event webhook |
| Dampak bisnis | Jumlah pengguna atau operasi yang terdampak dan apakah masalah masih berlangsung |

<h2 id="description-format">Format deskripsi</h2>

- Apa yang terjadi?
- Apa yang kamu harapkan terjadi?
- Bisa direproduksi?
- Apa yang berubah belakangan ini?
- Apakah masalahnya masih terjadi?

<h2 id="attachments">Lampiran</h2>

- Log permintaan dan respons yang relevan.
- Tangkapan layar atau rekaman layar.
- Payload Webhook dan header tanda tangan.
- Kesalahan konsol browser untuk masalah Trading Widget .

<h2 id="copyable-template">Template yang dapat disalin</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Hapus kolom yang tidak relevan, tetapi pertahankan rentang waktu UTC dan setidaknya satu permintaan yang dapat dicari atau pengidentifikasi bisnis jika memungkinkan.

<h2 id="redact-sensitive-data">Menyuntal data sensitif</h2>

Jangan kirim:

- Kata sandi atau token akses penuh
- API rahasia, kunci privat, atau tanda tangan lengkap
- Cookie sesi
- Pembayaran penuh, identitas, atau data pribadi lain yang tidak perlu

Pertahankan nama bidang dan awalan pendek atau akhiran hanya ketika dukungan perlu membedakan antara nilai yang telah disanitasi.
