Gunakan template ini saat menyiapkan integrasi baru atau memindahkan integrasi yang sudah ada ke dalam produksi.

<h2 id="partner-information">Informasi mitra</h2>

| Lapangan | Deskripsi |
| --- | --- |
| Nama mitra | Nama hukum atau proyek yang digunakan untuk integrasi. |
| Jenis produk | Aplikasi, dompet, portal broker, bursa white-label, platform institusional, atau lainnya. |
| Kontak utama | Kontak bisnis, teknis, operasional, dan darurat. |
| Wilayah peluncuran | Negara atau wilayah di mana integrasi akan terekspos. |

<h2 id="technical-information">Informasi teknis</h2>

| Lapangan | Deskripsi |
| --- | --- |
| Domain frontend | Domain yang akan memuat halaman widget atau entri. |
| Domain backend | Domain server yang digunakan untuk panggilan Agent SDK atau API . |
| Webhook URL | Endpoint webhook produksi dan persyaratan daftar izin IP yang diharapkan. |
| Ruang lingkup integrasi | Trading Widget, Agent SDK, REST API, WebSocket, sistem white-label, atau integrasi likuiditas. |

<h2 id="operational-information">Informasi operasional</h2>

- Tanggal peluncuran yang diharapkan.
- Lalu lintas yang diharapkan atau rentang pengguna aktif.
- Pemilik jam dukungan dan eskalasi.
- Memantau kontak pemilik dan insiden.

<h2 id="security-and-review-information">Informasi keamanan dan tinjauan</h2>

- Metode autentikasi dan cakupan izin API Key .
- Penyimpanan rahasia, pemilik rotasi, dan IP sumber yang disetujui.
- Verifikasi tanda tangan Webhook dan desain idempotensi.
- Pemilik pencatatan, pemantauan, rekonsiliasi, rollback, dan respons insiden.
- Pasar sasaran, jenis pengguna, model kustodi, dan entitas yang bertanggung jawab atas kewajiban yang berhadapan langsung dengan pengguna.

Jangan sertakan rahasia produksi, token akses penuh, kunci privat, atau data pengguna yang belum disensor dalam template ini.

Gunakan [daftar periksa peluncuran produksi](/id/resources/production-launch-checklist) untuk persetujuan akhir dan [template permintaan dukungan](/id/resources/support-request-template) untuk eskalasi isu.
