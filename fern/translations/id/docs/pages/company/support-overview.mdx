Dukungan 6MM dirancang untuk mitra yang berwenang, integrasi aktif, dan operasi produksi. Dukungan pengguna akhir tetap menjadi tanggung jawab platform mitra kecuali disepakati secara terpisah.

<h2 id="choose-the-right-path">Pilih jalur yang tepat</h2>

| Situasi | Jalur yang direkomendasikan | Termasuk |
| --- | --- | --- |
| Kemitraan baru atau evaluasi solusi | Jalur onboarding mitra | Jenis produk, wilayah target, jadwal peluncuran, model integrasi yang diharapkan. |
| SDK, API, webhook, atau pertanyaan lingkungan | Jalur dukungan teknis | Endpoint, versi SDK , ID permintaan, langkah reproduksi, log. |
| Insiden produksi atau penurunan aliran perdagangan | Jalur eskalasi insiden | Lingkup dampak, waktu mulai, pengguna yang terdampak, ID pesanan, mitigasi saat ini. |
| Perubahan materi aset, salinan, atau peluncuran | Jalur dukungan operasi | Halaman, bahasa, perubahan yang diminta, tanggal peluncuran, pemilik persetujuan. |
| Kerentanan atau dugaan penyalahgunaan | Jalur pelaporan keamanan | Detail teknis, titik akhir yang terpengaruh, bukti, urgensi, apakah masalah sedang aktif. |

<h2 id="severity-guide">Panduan tingkat keparahan</h2>

| Keparahan | Contoh |
| --- | --- |
| Kritikal | Perdagangan produksi, autentikasi, penerbitan token, atau aliran terkait dana tidak tersedia. |
| Tinggi | Aliran mitra utama menjadi terdegradasi, tetapi ada solusi sementara. |
| Normal | Pertanyaan integrasi, permintaan konfigurasi, masalah dokumentasi, atau dukungan peluncuran yang direncanakan. |

<h2 id="before-contacting-support">Sebelum menghubungi dukungan</h2>

- Konfirmasi area produk dan lingkungan yang terdampak.
- Kumpulkan ID permintaan, ID pesanan, timestamp, ID pemetaan pengguna, ID event webhook, dan log.
- Gunakan template permintaan dukungan untuk masalah produksi.
