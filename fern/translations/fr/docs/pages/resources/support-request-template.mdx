Lorsque vous contactez le support, incluez les informations ci-dessous dès que possible.

<h2 id="required-context">Contexte requis</h2>

| Terrain | Exemple |
| --- | --- |
| Environnement | Production ou mise en scène |
| Module affecté | Trading Widget, Agent SDK, REST API, WebSocket, webhook, système en marque blanche |
| Plage de temps | UTC plage d’horodatage au moment où le problème est survenu |
| Identifiant utilisateur partenaire | Identifiant utilisateur côté partenaire, si pertinent |
| ID de 6MM | agentUserId, ID de commande, ID de requête ou ID d’événement webhook |
| Impact sur les entreprises | Nombre d’utilisateurs ou d’opérations concernés et si le problème est en cours |

<h2 id="description-format">Format de la description</h2>

- Que s’est-il passé ?
- Qu’est-ce que tu t’attendais ?
- Peut-on le reproduire ?
- Qu’est-ce qui a changé récemment ?
- Le problème continue-t-il ?

<h2 id="attachments">Accessoires</h2>

- Journaux de demandes et de réponses pertinents.
- Captures d’écran ou enregistrements d’écran.
- En-têtes de charge utile et signature Webhook.
- Erreurs de console du navigateur pour Trading Widget problèmes.

<h2 id="copyable-template">Modèle copiable</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Supprimez les champs non pertinents, mais gardez la plage de temps UTC et au moins une requête ou identifiant métier consultable autant que possible.

<h2 id="redact-sensitive-data">Expurger les données sensibles</h2>

N’envoyez pas :

- Mots de passe ou jetons d’accès complet
- API des secrets, des clés privées ou des signatures complètes
- Cookies de session
- Paiement complet, identité ou autres données personnelles inutiles

Gardez le nom du champ et un préfixe ou un suffixe court uniquement lorsque le support doit distinguer les valeurs épurées.

<h2 id="choose-the-right-channel">Choisissez le bon canal</h2>

| Descendance | Page suivante |
| --- | --- |
| Problème d’intégration ou de production | [Soutien](/fr/resources/contact/support) |
| SDK problème qui nécessite encore un diagnostic | [ DépannageSDK Intégration](/fr/sdk/security/troubleshooting) |
| Vulnérabilité ou accès non autorisé suspecté | [Rapport de sécurité](/fr/resources/support/security-reporting) |
| Divulgation responsable de vulnérabilité | [Programme de prime d’insectes](/fr/security-compliance/bug-bounty-program) |
