6MM support est conçu pour les partenaires autorisés, les intégrations actives et les opérations de production. Le support utilisateur final reste la responsabilité de la plateforme partenaire, sauf convenance séparée.

<h2 id="choose-the-right-path">Choisissez le bon chemin</h2>

| Situation | Chemin recommandé | Incluez |
| --- | --- | --- |
| Nouvelle évaluation de partenariat ou de solution | Parcours d’intégration des partenaires | Type de produit, région cible, calendrier de lancement, modèle d’intégration attendu. |
| SDK, API, webhook ou question d’environnement | Parcours de support technique | Terminaison, SDK version, ID de requête, étapes de reproduction, journaux. |
| Incident de production ou flux commercial dégradé | Chemin d’escalade d’incident | Portée d’impact, heure de début, utilisateurs concernés, identifiants de commande, atténuation actuelle. |
| Changement d’atout, de copie ou de matériel de lancement | Chemin de soutien opérationnel | Page, langue, modification demandée, date de lancement, détenteur de l’approbation. |
| Vulnérabilité ou abus suspect | Chemin de rapport de sécurité | Détails techniques, point de départ concerné, preuves, urgence, si le problème est actif. |

<h2 id="severity-guide">Guide de la gravité</h2>

| Gravité | Exemple |
| --- | --- |
| Critique | Le trading en production, l’authentification, l’émission de jetons ou les flux liés aux fonds ne sont pas disponibles. |
| Haut | Un flux de partenaires majeur est dégradé, mais il existe une solution de contournement. |
| Normal | Question d’intégration, demande de configuration, problème de documentation ou support de lancement prévu. |

<h2 id="before-contacting-support">Avant de contacter le support</h2>

- Confirmer la zone de produit et l’environnement concernés.
- Collecter les identifiants de requête, les identifiants de commande, les horodatages, les identifiants de mappage utilisateur, les identifiants d’événements webhook et les journaux.
- Utiliser le modèle de demande de support pour les problèmes de production.
