<h2 id="production-checklist">Liste de contrôle de la production</h2>

- Stockez API secrets uniquement en arrière-plan.
- Synchroniser le temps serveur avant les requêtes signées.
- Traiter tous les champs de précision numérique comme des chaînes, sauf indication contraire explicite d’une page.
- Utiliser l’idempotence, les identifiants de requête et les journaux structurés autour des flux de commandes.
- S’abonner à WebSocket flux pour l’état qui doit rester à jour dans les systèmes opérationnels.
- Réexaminer les codes d’erreur et réessayer le comportement avant le lancement.
