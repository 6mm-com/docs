> REST Base URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Cette documentation est destinée aux systèmes externes s’intégrant au service 6MM API . Il couvre la connexion, l’authentification JWT , la gestion API Key , la signature API Key HMAC , les requêtes de compte, les ordres, les positions, les données de marché et les flux WebSocket .

La mise en vente des comptes et la préparation au financement sont gérées via des processus côté plateforme. Cette documentation ne décrit que les terminaux de service API appelables de l’extérieur.

<span id="service-endpoints" data-sixmm-canonical-anchor="service-endpoints" aria-hidden="true"></span>

## Points de terminaison de service

| Type      | Extrémité              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Flux d’intégration

Séquence d’intégration recommandée :

1. Connectez-vous avec le compte fourni par la plateforme et obtenez un `accessToken`.
2. Pour l’accès programmatique côté serveur, créer d’abord un API Key avec JWT , et stocker de manière sécurisée la `apiSecret`retournée à une seule fois.
3. Les requêtes privées ainsi que les endpoints d’ordre et de position peuvent être appelés avec `Authorization: Bearer <accessToken>` ou une signature API Key.
4. Pour les flux privés WebSocket , créez d’abord un `listenKey` , puis connectez-vous à `wss://ws.6mm.com/ws?listenKey=...`.
5. Les données de marché REST les points d’accès et les canaux de WebSocket publics ne nécessitent pas d’authentification.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Choix d’authentification

| Scénario                               | Méthode recommandée         |
| -------------------------------------- | -------------------------- |
| Actions de l’utilisateur frontend                  | JWT                        |
| Appels programmatiques côté serveur         | API Key + HMAC signature   |
| API Key création, mise à jour et suppression | JWT                        |
| REST de marché public / WebSocket publique  | Aucune authentification requise |
