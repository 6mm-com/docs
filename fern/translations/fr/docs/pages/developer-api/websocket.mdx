## Service Endpoint

```
wss://ws.6mm.com/ws
```

WebSocket chaînes sont divisées en chaînes publiques et chaînes privées :

| Type             | Authentification              | Description                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Chaînes publiques  | Pas obligatoire                | Données de marché, telles que la profondeur, les transactions, les Klines et le boursier |
| Chaînes privées | `listenKey` ou JWT requis | Ordre, flux de comptes et de position des utilisateurs              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## Chaînes publiques

Le WebSocket public ne nécessite pas d’authentification. Après la connexion, envoyez une demande de `subscribe` pour vous abonner aux canaux de marché.

Canaux courants :

| Chaîne                            | Description                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Profondeur de commande de livre. Envoie d’abord un instantané, puis des mises à jour incrémentales |
| `market.trade.{symbol}`            | Dernières transactions                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Résumé du ticker à symbole unique                                       |
| `market.tickers`                   | Résumé du ticker tous symboles                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## Chaînes privées

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
Pour les flux privés WebSocket , créez d’abord un `listenKey` via le REST API , puis connectez-vous à :

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
Méthode de connexion JWT compatible :

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Après réussite de l’authentification, le serveur s’abonne automatiquement à la connexion au canal privé de l’utilisateur actuel. Aucun abonnement manuel n’est requis.
