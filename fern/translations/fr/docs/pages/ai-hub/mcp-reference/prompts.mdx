Les invites MCP sont des flux de travail réutilisables exposés par le serveur MCP. Ils aident les utilisateurs à poser des questions cohérentes et aident les clients IA à utiliser les bons outils.

<span id="recommended-prompts" data-sixmm-canonical-anchor="recommended-prompts" aria-hidden="true"></span>

## Invites recommandées

| Rapide | But |
| --- | --- |
| market_overview | Résumez l’état du marché sur les symboles sélectionnés. |
| analyse_microstructure_marché | Analysez le spread, la profondeur, les transactions récentes et les conditions de liquidité. |
| portefeuille_risk_assessment | Examinez les positions, l’exposition, la marge et le risque de liquidation. |
| position_gestion | Aidez les utilisateurs à comprendre l’état de la position et les actions possibles. |
| liquidation_protection | Identifiez le risque de liquidation et les options de réduction des risques. |
| financement_taux_opportunité | Comparez les taux de financement et les opportunités possibles. |
| create_optimal_order | Planifiez les paramètres de commande avant l’aperçu. |
| stratégie_de couverture | Explorez les options de couverture pour l’exposition existante. |
| consultation_trading | Produisez une analyse de trading structurée sans exécuter d’ordres. |

<span id="prompt-safety-rules" data-sixmm-canonical-anchor="prompt-safety-rules" aria-hidden="true"></span>

## Règles de sécurité rapides

- Ne considérez pas une sortie rapide comme un conseil financier.
- N'exécutez pas d'outils de trading à moins que l'utilisateur ne le demande explicitement.
- Utilisez l'aperçu avant de créer.
- Expliquer les hypothèses et les sources de données.
- Préférez les exemples testnet dans la documentation publique.
