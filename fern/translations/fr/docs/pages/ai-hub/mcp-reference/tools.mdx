Les outils MCP sont des actions qu'un client IA peut appeler. Chaque outil doit avoir une description claire, un schéma JSON, des exigences d'autorisation, un format de réponse stable et un modèle d'erreur.

<h2 id="phase-1-public-market-tools">Phase 1 : outils du marché public</h2>

| Outil | But |
| --- | --- |
| 6mm_system_status | Vérifiez le service et la disponibilité du marché. |
| 6mm_marchés | Répertoriez les marchés disponibles et les métadonnées de base. |
| 6mm_market_summary | Résumez l’état du marché pour un ou plusieurs symboles. |
| 6mm_ticker | Renvoie les dernières données du téléscripteur. |
| 6mm_carnet de commande | Profondeur du carnet de commandes de retour. |
| 6mm_klines | Renvoyez les bougies historiques. |
| 6mm_trades | Renvoie les transactions publiques récentes. |
| 6mm_funding_rates | Renvoie les taux de financement actuels et historiques. |

<h2 id="tool-requirements">Exigences en matière d'outils</h2>

Chaque outil doit définir :

- Description du modèle IA.
- Saisissez le schéma JSON.
- Portée de l'autorisation.
- Prise en charge de l'environnement.
- Comportement de limite de débit.
- Champs de réponse stables.
- Codes d'erreur.
- Champs du journal d’audit.
