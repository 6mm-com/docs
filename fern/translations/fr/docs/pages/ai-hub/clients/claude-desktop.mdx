Claude Desktop convient parfaitement à la recherche basée sur MCP-, à l'examen des comptes et à l'analyse opérationnelle.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Configuration recommandée

| Besoin | Installation |
| --- | --- |
| Etude de marché publique | Hébergé MCP |
| Analyse tenant compte du compte | Local MCP |
| Point de terminaison de l’équipe interne | À distance MCP |

<span id="example-prompts" data-sixmm-canonical-anchor="example-prompts" aria-hidden="true"></span>

## Exemples d'invites

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<span id="notes" data-sixmm-canonical-anchor="notes" aria-hidden="true"></span>

## Remarques

Le MCP local est préféré chaque fois que des données de compte privé sont impliquées, car le serveur MCP s'exécute sur la machine de l'utilisateur et les informations d'identification n'ont pas besoin d'être envoyées à un point de terminaison IA hébergé par 6MM.
