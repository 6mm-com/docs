ChatGPT Desktop est un point d'entrée familier pour les utilisateurs qui souhaitent poser des questions sur le marché en langage naturel.

Utilisez ce chemin lorsque l'utilisateur souhaite une interface conversationnelle pour les données du marché public, les résumés de compte, les explications de position et le contexte des règles de trading.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Configuration recommandée

| Besoin | Installation |
| --- | --- |
| Données du marché public | Hébergé MCP |
| Contexte du compte privé | Local MCP |
| Invites d'analyse répétables | Compétences d'agent |
| Flux de travail basés sur un terminal | 6MM CLI |

<span id="what-users-can-ask" data-sixmm-canonical-anchor="what-users-can-ask" aria-hidden="true"></span>

## Ce que les utilisateurs peuvent demander

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<span id="safety-defaults" data-sixmm-canonical-anchor="safety-defaults" aria-hidden="true"></span>

## Paramètres de sécurité par défaut

- Commencez par les données du marché public.
- Utilisez Local MCP lorsque les informations d'identification du compte sont nécessaires.
- Conservez les clés privées API sur la machine de l'utilisateur.
- Exiger un aperçu et une confirmation explicite avant toute action commerciale future.
