Claude Code CLI est utile lorsque l'agent peut exécuter des commandes de terminal, inspecter la sortie JSON et mettre à jour le code d'intégration.

<h2 id="recommended-setup">Configuration recommandée</h2>

| Besoin | Installation |
| --- | --- |
| Vérifications rapides du marché | 6MM CLI |
| Contexte du compte local | Local MCP |
| Flux de travail de mise en œuvre reproductible | Compétences d'agent |

<h2 id="example-tasks">Exemples de tâches</h2>

```text
Use 6MM CLI to list available perpetual markets and return JSON.
```

```text
Use 6MM to inspect webhook event examples and generate an idempotent handler plan.
```

```text
Use 6MM testnet data to validate this Trading Widget integration. Do not place live orders.
```

<h2 id="best-practice">Meilleure pratique</h2>

Préférez la sortie JSON pour les flux de travail des agents. Il est plus facile d'analyser, de comparer et d'inclure dans les journaux d'implémentation.
