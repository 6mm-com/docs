## Commencez avec l'outil d'IA que les utilisateurs connaissent déjà

<Card title="Codex CLI" icon="fa-duotone fa-code" href="/fr/ai-hub/clients/codex-cli">

<Card title="Curseur" icon="fa-duotone fa-arrow-pointer" href="/fr/ai-hub/clients/cursor">

<span id="each-client-guide-should-include" data-sixmm-canonical-anchor="each-client-guide-should-include" aria-hidden="true"></span>

## Chaque guide client doit inclure

- Mode pris en charge : CLI, local MCP, hébergé MCP ou distant MCP.
- Commande d'installation.
- Chemin du fichier de configuration.
- Variables d'environnement.
- Exemple de testnet.
- Commande ou invite de vérification.
- Erreurs courantes.
- Notes de sécurité.

<span id="example-verification-prompts" data-sixmm-canonical-anchor="example-verification-prompts" aria-hidden="true"></span>

## Exemples d'invites de vérification

```text
Use 6MM to list available markets.
```

```text
Use 6MM to check BTC-USDT-PERP orderbook depth and summarize liquidity.
```

```text
Using 6MM testnet, preview a small BTC long order and explain the margin impact. Do not place the order.
```
