Choisissez une configuration en fonction de deux questions :

1. Quel client IA souhaitez-vous utiliser ?
2. Avez-vous besoin uniquement de données publiques, d'un accès à un compte privé ou de workflows de trading ?

Si vous n'êtes pas sûr, commencez par Hosted MCP pour les données publiques ou Local MCP pour les workflows de compte privé.

## Table de décision rapide

| But | Configuration recommandée | Pourquoi |
| --- | --- | --- |
| Demandez à un client IA des données sur le marché public | Hébergé MCP | Aucune installation locale et aucune clé API requise. |
| Laissez Claude Desktop, Cursor ou ChatGPT Desktop appeler les outils 6MM | Local MCP | L'IA appelle des outils via un serveur local contrôlé par l'utilisateur. |
| Laissez Codex, Claude Code, Gemini CLI ou les scripts appeler 6MM | CLI | Le résultat de la commande peut être JSON et facile à analyser pour les agents. |
| Fournir un point de terminaison MCP géré par l'entreprise | À distance MCP | L'institution contrôle l'hébergement, les informations d'identification, l'accès et les journaux. |
| Standardisez les analyses répétées ou les flux de travail liés aux risques | Compétences d'agent | Les modèles définissent l'utilisation des outils, les garde-fous et le format de sortie. |

## Choisir par chemin de configuration

| Installation | Installation | API emplacement clé | Meilleure portée initiale | Compte et périmètre de négociation |
| --- | --- | --- | --- | --- |
| Hébergé MCP | Aucun | Aucune clé utilisateur API pour les données publiques | Données du marché public | Non recommandé pour la première version |
| Local MCP | Package d'installation par l'utilisateur | Machine utilisateur | Données publiques et lecture de compte | Chemin recommandé pour les transactions futures |
| CLI | Package d'installation par l'utilisateur | Machine utilisateur | Données publiques et scripts | Utile pour la prévisualisation et l'automatisation |
| À distance MCP | L'utilisateur déploie le serveur | Cloud utilisateur ou cloud institution | Données publiques ou lecture de compte | Possible lorsque l'utilisateur contrôle le déploiement |
| Compétences | Documents ou modèles installables | Dépend des outils sous-jacents | Flux de travail d'analyse | Doit suivre les autorisations de l'outil |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## Règle générale de sécurité

Utilisez la configuration la moins risquée qui prend en charge la tâche :

- Données du marché public : MCP hébergés suffisent.
- Données du compte privé : local MCP ou distant géré par l'utilisateur MCP.
- Aperçu du trading : local MCP ou CLI, de préférence testnet en premier.
- Trading réel : uniquement après autorisation explicite, aperçu, confirmation, limites et journaux d'audit.
