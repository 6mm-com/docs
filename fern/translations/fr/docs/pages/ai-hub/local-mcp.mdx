Local MCP est la configuration recommandée lorsqu'un client AI a besoin d'un contexte de compte privé ou de futurs outils de trading contrôlés.

Le serveur MCP s'exécute sur la machine de l'utilisateur. Le client AI appelle les outils 6MM locaux et le serveur local communique avec 6MM APIs à l'aide des informations d'identification configurées par l'utilisateur.

<span id="what-your-ai-client-can-do" data-sixmm-canonical-anchor="what-your-ai-client-can-do" aria-hidden="true"></span>

## Ce que votre client IA peut faire

Avec Local MCP, un client IA peut utiliser les outils 6MM de manière contrôlée :

- Récupérez des données de marché en direct et historiques.
- Lisez les soldes des comptes, les positions, les commandes ouvertes, les exécutions et les enregistrements de financement lorsque les informations d'identification en lecture seule sont activées.
- Expliquer l'exposition du portefeuille, l'utilisation de la marge et le risque de liquidation.
- Prévisualisez les commandes avant qu’une commande réelle ne soit passée.
- Dans les phases ultérieures de négociation contrôlée, créez ou annulez des ordres uniquement après une autorisation explicite et une vérification des risques.

Utilisez Local MCP lorsque les informations d'identification doivent rester sur la machine de l'utilisateur.

## Architecture

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

## Exemple de configuration

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

<span id="recommended-permission-tiers" data-sixmm-canonical-anchor="recommended-permission-tiers" aria-hidden="true"></span>

## Niveaux d'autorisation recommandés

| Étage | Outils | Remarques |
| --- | --- | --- |
| Données publiques | Marchés, ticker, carnet d'ordres, klines, transactions, financement | Aucun accès au compte privé. |
| Compte lu | Soldes, positions, ordres ouverts, exécutions | Nécessite une portée de clé API en lecture seule. |
| Aperçu du trading | Aperçu de la commande, impact sur la marge, estimation des frais | Ne passe pas de commandes. |
| Négoce contrôlé | Créer, annuler, modifier des commandes | Nécessite une autorisation explicite, une confirmation et des contrôles des risques. |

<span id="first-setup-checklist" data-sixmm-canonical-anchor="first-setup-checklist" aria-hidden="true"></span>

## Liste de contrôle de première configuration

1. Installez le package MCP.
2. Créez ou configurez une clé API en lecture seule.
3. Commencez dans testnet.
4. Ajoutez le serveur MCP à la configuration du client AI.
5. Demandez au client de lister les outils 6MM disponibles.
6. Exécutez une requête de données sur le marché public.
7. Ajoutez ensuite les informations d'identification de lecture du compte si nécessaire.

<span id="security-notes" data-sixmm-canonical-anchor="security-notes" aria-hidden="true"></span>

## Notes de sécurité

Local MCP doit être par défaut en lecture seule et testnet. Les outils de trading doivent nécessiter un aperçu, une confirmation de l'utilisateur, des clés d'idempotence, des limites notionnelles et des contrôles de risque côté service.
