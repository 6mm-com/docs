## Support console et visiteur

| Symptôme | Vérifiez d'abord |
| --- | --- |
| Il manque un menu | Rôle du compte et disponibilité du service locataire |
| Le widget ne s'ouvre pas | Script généré URL, clé d'application, erreurs de domaine et de navigateur autorisées |
| Le bot n'utilise pas le grand modèle | Étape réelle correspondante, commutateurs de service intelligent et configuration pertinente |
| Une réponse utilise d'anciennes règles | Article source, statut de publication, texte FAQ, état de traduction et de récupération |
| La traduction est absente | Langue cible, changement de traduction, traduction enregistrée et disponibilité du service/solde |
| La génération de vecteurs échoue | Disponibilité du service et état de récupération ; éviter de reconstruire à plusieurs reprises sans identifier la panne |
| Un champ de contact est vide | Si ce champ a réellement été collecté ; distinguer l'e-mail de contact et l'e-mail d'entrée |

## MCP connexion et appels

| Symptôme | Étape suivante |
| --- | --- |
| L'ouverture du point de terminaison dans un navigateur renvoie une erreur | Il s'agit d'un point de terminaison de protocole, pas d'une page de connexion ; ajoutez-le à un client MCP compatible |
| L'autorisation ne peut pas démarrer | Vérifiez le point de terminaison exact, la prise en charge Streamable HTTP/OAuth du client et le flux de connexion du navigateur |
| Connexion non autorisée ou expirée | Vérifier la révocation et l'expiration ; se reconnecter via l'application |
| Un outil est manquant ou l'accès est refusé | Vérifiez le rôle du compte autorisant et la portée de l'enregistrement ; actualiser la liste des outils |
| En attente d'approbation | Ouvrez le lien d'approbation renvoyé et examinez-le dans le backend |
| Contenu modifié | Lisez le dernier enregistrement, prévisualisez-le à nouveau et soumettez une nouvelle opération prévue |
| La demande a expiré | Interrogez l'état de l'opération avant de réessayer ou de supposer un échec |
| Pas de journal d'écriture | Distinguer une lecture, une approbation en attente et une écriture terminée ; vérifier les filtres dans les journaux d'opérations |

<span id="before-contacting-support" data-sixmm-canonical-anchor="before-contacting-support" aria-hidden="true"></span>

## Avant de contacter le support

Collectez l'heure et le fuseau horaire, le locataire/compte concerné, le nom de la page ou de l'outil, l'ID de l'opération le cas échéant et l'erreur exacte. Incluez une capture d’écran expurgée ou les étapes à reproduire. N'envoyez pas de mots de passe, de codes de vérification, de jetons de porteur ou de secrets de signature.

Essayez un petit enregistrement de test lors du diagnostic des écritures. Vérifiez le résultat et nettoyez uniquement les données de test que vous avez créées, en utilisant le flux de confirmation normal si nécessaire.
