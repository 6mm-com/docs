## Préparez votre espace de travail

Ouvrir [la console](https://csadmin.6mm.com/) avec le compte fourni à votre locataire. Terminez la configuration de connexion et de sécurité demandée par l’écran de connexion. Si vous ne pouvez pas accéder à un menu, demandez à votre administrateur client de vérifier le rôle.

1. **Configurez l'équipe.** Dans Agent Management, créez les rôles et les comptes d'agent requis. Vérifiez qui peut consulter les conversations, modifier le contenu et gérer les paramètres.
2. **Préparer les connaissances commerciales.** Dans la gestion de contenu, créez des catégories et des articles pour l'accès au compte, les procédures de dépôt et de retrait, les règles de négociation, les frais et l'escalade du support. Examinez et publiez le matériel que les utilisateurs devraient voir.
3. **Configurez l'automatisation.** Activez les services intelligents requis dans les paramètres système. Dans Configuration du robot, examinez FAQ, la correspondance vectorielle, les réponses IA et les réponses d'identité.
4. **Préparez les langues.** Choisissez les langues principales et par défaut, traduisez le contenu de l'aide et révisez la terminologie, les chiffres et les liens.
5. **Connectez votre site Web.** Ajoutez le site à l'intégration de site Web et copiez le code d'intégration généré par le locataire. Utilisez votre propre clé d'application.
6. **Testez avant le lancement.** Utilisez le test de flux de Bot Configuration, puis l'entrée réelle du visiteur. Vérifiez les questions connues, les suivis, une autre langue, l'assistance humaine et la soumission des tickets.

## Acceptation du lancement

| Test | Résultat attendu |
| --- | --- |
| Une règle de trading documentée | La réponse préserve les conditions, les chiffres et les exceptions |
| Un problème inconnu spécifique au compte | Aucun solde ou résultat de transaction inventé ; l'utilisateur obtient une prochaine étape appropriée |
| Une question en langue étrangère | Une réponse appropriée ou une traduction d'agent dans la langue activée |
| Assistance humaine indisponible | L'alternative configurée, telle qu'un ticket, est disponible |
| Compte d'agent restreint | Seuls les menus et enregistrements autorisés sont accessibles |
| Utilisation des services | L'appel concerné apparaît dans Utilisation et facturation |

Connectez MCP après le fonctionnement du flux de travail de base. Commencez par une requête en lecture seule, puis un brouillon de test, avant d'utiliser les écritures sur le contenu métier.
