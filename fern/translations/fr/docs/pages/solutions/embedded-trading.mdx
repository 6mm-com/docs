Le système de trading Embedded API / SDK est conçu pour les partenaires qui possèdent déjà du trafic, des utilisateurs ou des flux de travail métier et souhaitent ajouter du trading sans construire une bourse complète à partir de zéro.

<h2 id="what-it-provides">Ce qu’il apporte</h2>

- Terminal de négociation intégré via le Trading Widget SDK
- Intégration backend par partenaires via Agent SDK
- Liaison d’identité utilisateur et flux de jetons d’entrée
- Transfert d’actifs, ordre, position et accès API compte
- Intégration d’événements, de webhooks et de cycles de vie pour les systèmes opérationnels

<h2 id="recommended-architecture">Architecture recommandée</h2>

| Couche | Responsabilité |
| --- | --- |
| Interface partenaire | Il héberge le point d’entrée et intègre l’interface de trading 6MM . |
| Backend partenaire | Garde API secrets, valide les utilisateurs, diffuse des tokens d’intégration et traite les webhooks. |
| 6MM Infrastructure commerciale | Prend en charge l’interface de trading, l’appariement, le risque, la liquidité, l’état du compte et le cycle de vie du trading. |

<h2 id="choose-an-integration-path">Choisir un chemin d’intégration</h2>

| Exigence | Chemin recommandé |
| --- | --- |
| Interface de trading complète avec l’intégration web la plus rapide | Trading Widget |
| Lien utilisateur backend, transfert, URL d’entrée et gestion du webhook | Agent SDK |
| Flux de travail entièrement personnalisés produits et commandes | REST API + WebSocket |
| Expérience en échange de marques avec un champ opérationnel plus large | Échange en marque blanche |

La conception finale peut combiner ces chemins. Confirmez l’authentification, la propriété des actifs, les limites de responsabilité, la surveillance et le support en production avant le début de la mise en œuvre.
