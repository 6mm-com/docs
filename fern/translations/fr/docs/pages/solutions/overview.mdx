<h2 id="how-the-solutions-connect">Comment les solutions se connectent</h2>

La plupart des implémentations partenaires combinent plus d’une capacité 6MM . Une plateforme d’échange en marque blanche peut utiliser la liquidité institutionnelle, le soutien à la conformité et des intégrations API . Un partenaire commercial embarqué peut commencer par le Trading Widget SDK puis ajouter les flux de Agent SDK backend, le traitement des webhooks et les ressources opérationnelles.
