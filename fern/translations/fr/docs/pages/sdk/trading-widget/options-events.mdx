## Possibilités

| Champ | Taper | Défaut | Remarques |
| --- | --- | --- | --- |
| baseUrl | string | SDK origine du script | domaine iframe. Transmettez explicitement dans les pages partenaires. |
| symbole | string | BTCUSDT | Normalisé en majuscules et en bandes - / _. |
| thème | sombre \| lumière | sombre | Paramètre de thème initial. |

| mise en page | défaut \| compact | défaut | Option de mise en page réservée. |
| afficher | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Les contrôles intègrent des zones d'obus et des conteneurs commerciaux de haut niveau. |
| authentification | object | aucun | Utilisez le jeton de partenaire pour les nouvelles intégrations SSO. |

## Afficher les commandes

`display` contrôle le shell de la page de trading intégré et les conteneurs de haut niveau. Dans les intégrations partenaires, l'en-tête PC et le ticker du marché inférieur sont masqués par défaut.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Champ | Taper | Défaut | Remarques |
| --- | --- | --- | --- |
| showHeader | boolean | FAUX | Indique s'il faut afficher l'en-tête d'intégration du PC dans l'iframe. |
| showTicker | boolean | FAUX | Indique s'il faut afficher le ticker du marché le plus bas dans le shell d'intégration. |
| caché | chaîne[] | [] | Masque les conteneurs de haut niveau dans la page de trading. |

Valeurs `display.hidden` prises en charge :

| Valeur | Récipient |
| --- | --- |
| graphique | Conteneur de graphiques |
| orderBook | Conteneur de carnet de commandes |
| orderForm | Panneau du formulaire de commande |
| positions | Positions inférieures et panneau de commandes ouvertes |
| compte | Conteneur d'actifs de compte |

`display.hidden` masque uniquement les conteneurs entiers. Il ne masque pas les boutons, champs ou outils individuels à l'intérieur d'un conteneur. Les valeurs qui ne correspondent pas à la fenêtre actuelle sont ignorées.

## Événements

| Événement | Déclenchement |
| --- | --- |
| prêt | L'initialisation de l'iframe est terminée. |
| erreur | SDK, iframe ou erreur d'authentification. |
| état_changé | L'état du cycle de vie de SDK a été modifié. |
| auth_state_changed | L’état d’authentification du jeton partenaire a changé. |
| symbole_changé | Le symbole iframe réel a changé. |
| locale_changed | Les paramètres régionaux iframe réels ont été modifiés. |
| commande_créée | L'utilisateur a créé une commande dans l'iframe. |
| commande_failed | La soumission de la commande a échoué. |
| détruit | Instance SDK détruite. |

## Pages produits et mode de trading

Java Agent SDK et le navigateur Trading Widget SDK sont versionnés indépendamment. Pour le trading de secondes, utilisez les capacités actuelles du widget et sélectionnez explicitement la page et le mode de trading.

| Option | Valeurs | Signification |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Page produit pour le trading de secondes. |
| `tradingMode` | `real`, `demo` | La valeur par défaut est `real` ; correspondre explicitement à l’environnement de financement backend. |

Vérifiez `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` et `TradingWidget.capabilities.partnerToken` avant l'initialisation. La création de jetons ne sélectionne pas un environnement de fonds. Pour changer d'utilisateur ou de mode réel/démo, détruisez l'ancienne instance et créez-en une nouvelle.

Voir [exemple complet de trading de secondes](/fr/sdk/agent-sdk/java/seconds-trading) et [configuration de production/simulée](/fr/sdk/agent-sdk/java/environments).

## Cibles et événements d'affichage supplémentaires

Le moteur d'exécution actuel accepte également `symbolFavorites` et `symbolTicker` dans `display.hidden`. Vérifiez toujours `TradingWidget.capabilities.displayTargets` ; une cible contrôle un conteneur de haut niveau et ne constitue pas un paramètre d'autorisation au niveau du champ.

| Événement | Signification |
| --- | --- |
| `rendered` | L'iframe envoie sa notification rendue. |
| `theme_changed` | L'iframe rapporte son thème réel. |
| `page_changed` | L'iframe rapporte sa page produit réelle. |

Utilisez `onRendered` ou `widget.on('rendered', handler)` pour gérer le rendu séparément de l'initialisation. Les pages actuellement prises en charge sont publiées dans `TradingWidget.capabilities.pages` ; validez la page demandée plutôt que de deviner un chemin.
