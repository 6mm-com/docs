<h2 id="responsibility-split">Répartition des responsabilités</h2>

| Superficie | Propriétaire | Notes |
| --- | --- | --- |
| Création de conteneurs | Interface partenaire | Fournir un élément visible avec une largeur et une hauteur explicites. |
| Création d’iFrame | Trading Widget SDK | Le SDK crée et gère l’iframe. |
| Interface de trading | 6MM iframe | K-line, carnet de commandes, formulaires de commande, positions, ordres et données de compte sont exécutés à l’intérieur de l’iframe. |
| Commandes d’affichage | Trading Widget SDK + 6MM iframe | L’en-tête et le ticker inférieur de l’embed PC sont cachés par défaut. Les partenaires peuvent utiliser `display` pour afficher les zones de coques ou cacher des conteneurs de trading de haut niveau. |
| Vérification de la connexion du partenaire | Backend partenaire | Validez la session utilisateur partenaire avant d’émettre les identifiants d’authentification. |
| Émission de jeton intégré | Backend partenaire + Agent API | Recommandé pour le mode jeton partenaire. |

<h2 id="versioning">Versionnement</h2>

Le chemin d’intégration public reste stable sous le script v1 URL. L’ensemble actuel de capacités v1 comprend partner-token, tokenProvider, entryUrlProvider, contrôles d’affichage, événements du cycle de vie, méthodes d’instance et événements d’ordre.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Quand utiliser le widget</h2>

Choisissez Trading Widget lorsqu’un partenaire a besoin d’une interface de trading complète à l’intérieur d’un produit web existant. Utilisez plutôt la documentation REST API et WebSocket lors de la création et du maintien d’une interface de trading entièrement personnalisée.

<h2 id="implementation-path">Chemin d’implémentation</h2>

1. Suivre le [Trading Widget Départ rapide](/fr/sdk/trading-widget/quick-start) pour charger le script et créer un conteneur visible.
2. Configurer [Authentification par jeton partenaire](/fr/sdk/trading-widget/authentication) via un backend partenaire.
3. Ajouter les éléments requis [Options et événements](/fr/sdk/trading-widget/options-events).
4. Utilisation [Méthodes d’instance](/fr/sdk/trading-widget/instance-methods) pour les contrôles du cycle de vie et de l’exécution.
