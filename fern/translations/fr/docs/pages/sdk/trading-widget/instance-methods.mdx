<h2 id="method-summary">Résumé de la méthode</h2>

| Méthode | Objectif |
| --- | --- |
| détruire() | Retirez l’iframe et libérez les auditeurs de l’événement. |
| getState() | Lisez l’état actuel du cycle de vie SDK . |
| whenReady() | Attendez que l’iframe termine son initialisation. |
| setSymbol(symbole) | Inversez la paire de trading à l’intérieur de l’iframe. |
| setTheme(thème) | Mettez à jour le paramètre thème de l’iframe. |
| setLocale(localisation) | Changez le langage de l’iframe. |
| setSize(largeur, hauteur) | Mettez à jour les dimensions de l’iframe. |
| recharge() | Rechargez l’iframe actuel. |
| refreshAuth(raison) | Déclenche le flux de rafraîchissement de l’authentification du widget. |
| setTokenProvider(fournisseur) | Remplacez le fournisseur utilisé par le mode partner-token. |
| On (événement, manipulateur) | Abonnez-vous aux événements d’exécution et recevez une fonction de désabonnement. |

<h2 id="destroy">détruire()</h2>

Retirez l’iframe, nettoyez les auditeurs, et envoyez détruit une fois pour l’instance actuelle.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Lisez l’état actuel du cycle de vie de l’instance du widget.

```js
const state = widget.getState()
```

Les valeurs de retour incluent chargement, authentification, prêt, erreur et destruction.

<h2 id="whenready">whenReady()</h2>

Attends que l’iframe termine son initialisation avant d’exécuter la logique d’interface dépendante.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(symbole)</h2>

Inversez la paire d’échanges à l’intérieur de l’iframe. Si l’iframe est encore en train d’initialiser, le SDK met la commande en file d’attente et l’envoie après ready.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(thème)</h2>

Mettez à jour le paramètre thème utilisé par l’iframe de trading intégré.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(localisation)</h2>

Changez le langage de l’iframe. Les valeurs prises en charge sont en, en-US et zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(largeur, hauteur)</h2>

Mettez à jour la taille DOM l’iframe et informez l’iframe de la nouvelle taille extérieure. Les valeurs numériques sont converties en px.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">recharge()</h2>

Rechargez l’iframe actuel et attendez qu’il s’initialise à nouveau.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(raison)</h2>

Demandez à l’iframe de rafraîchir le flux d’authentification actuel. La valeur de raison optionnelle est transmise pour la journalisation et le contrôle du flux.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(fournisseur)</h2>

Remplacez le tokenProvider utilisé par le mode partner-token. Le SDK appelle le fournisseur lorsque l’iframe demande un nouvel ajout.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">On (événement, manipulateur)</h2>

Abonnez-vous à un événement d’exécution. La fonction retournée supprime l’écouteur.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
