## Résumé de la méthode

| Méthode | But |
| --- | --- |
| détruire() | Supprimez l'iframe et libérez les écouteurs d'événements. |
| getState() | Lisez l'état actuel du cycle de vie de SDK. |
| whenReady() | Attendez que l'iframe termine son initialisation. |
| setSymbol(symbole) | Changez la paire de trading à l'intérieur de l'iframe. |
| setTheme(thème) | Mettez à jour le paramètre du thème iframe. |
| setLocale(paramètres régionaux) | Changez la langue iframe. |
| setSize(largeur, hauteur) | Mettez à jour les dimensions de l'iframe. |
| recharger() | Rechargez l'iframe actuelle. |
| refreshAuth(raison) | Déclenchez le flux d’actualisation d’authentification du widget. |
| setTokenProvider(fournisseur) | Remplacez le fournisseur utilisé par le mode jeton partenaire. |
| on (événement, gestionnaire) | Abonnez-vous aux événements d'exécution et recevez une fonction de désabonnement. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## détruire()

Supprimez l'iframe, effacez les écouteurs et émettez une fois détruite pour l'instance actuelle.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Lisez l'état actuel du cycle de vie de l'instance de widget.

```js
const state = widget.getState()
```

Les valeurs de retour incluent le chargement, l'authentification, le prêt, l'erreur et la destruction.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Attendez que l'iframe termine l'initialisation avant d'exécuter la logique d'interface utilisateur dépendante.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(symbole)

Changez la paire de trading à l'intérieur de l'iframe. Si l'iframe est encore en cours d'initialisation, le SDK met la commande en file d'attente et l'envoie une fois prête.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(thème)

Mettez à jour le paramètre de thème utilisé par l'iframe de trading intégré.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(paramètres régionaux)

Changez la langue iframe. Les valeurs prises en charge sont en, en-US et zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(largeur, hauteur)

Mettez à jour la taille de l'iframe DOM et informez l'iframe de la nouvelle taille extérieure. Les valeurs numériques sont converties en px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## recharger()

Rechargez l'iframe actuelle et attendez qu'elle s'initialise à nouveau.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(raison)

Demandez à l'iframe d'actualiser le flux d'authentification actuel. La valeur facultative du motif est transmise pour la journalisation et le contrôle de flux.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(fournisseur)

Remplacez le tokenProvider utilisé par le mode jeton partenaire. Le SDK appelle le fournisseur lorsque l'iframe demande un nouveau jeton d'intégration.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on (événement, gestionnaire)

Abonnez-vous à un événement d'exécution. La fonction renvoyée supprime l'écouteur.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Méthodes supplémentaires dans le runtime v1 actuel

| Méthode | But |
| --- | --- |
| `whenRendered()` | Attendez la notification rendue par l'iframe ; ceci est distinct du prêt. |
| `setPage(page)` | Demandez une page produit prise en charge dans l’instance actuelle. Cela ne change pas l’environnement des fonds. |
| `prepareForRecreate()` | Demandez une iframe prête pour préparer le remplacement ; renvoie une promesse et peut la rejeter si elle est indisponible, occupée ou expirée. |
| `cancelRecreate()` | Annulez un flux de remplacement en attente/préparé. |
| `TradingWidget.validateOptions(options)` | Validez les options d'initialisation avant de créer une instance. |

Pour un changement d'utilisateur ou d'environnement réel/de démonstration, détruisez l'ancienne instance et créez-en une nouvelle avec l'authentification et le mode cibles. N'utilisez pas `setPage` comme commutateur d'environnement. Vérifiez les fonctionnalités avant d’utiliser des méthodes facultatives.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
