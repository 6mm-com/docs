<h2 id="runtime">Durée d’exécution</h2>

| Objet | Valeur |
| --- | --- |
| Package | Sixmm/agent-SDK |
| Version PHP minimum | PHP 7,4+ |
| Version recommandée PHP | PHP 8.1+ ou versions actuellement prises en charge |
| Extensions obligatoires | ext-json, ext-curl |

La source du paquet PHP SDK et la version approuvée sont fournies lors de l’intégration du partenaire. Ne supposez pas que le package est disponible depuis le Packagist public ; configurez le dépôt Composer fourni pour votre organisation.

<h2 id="supported-scenarios">Scénarios pris en charge</h2>

| Scénario | SDK méthode |
| --- | --- |
| Lier l’utilisateur | lié |
| Transfert à montants fixes | Transfert |
| Transfert à tous | transferAllOut |
| Transfert inverse | À l’envers |
| Ordre des requêtes | queryOrder |
| Créer une entrée URL | createEntryUrl |
| Vérification Webhook | WebhookVerifier ::verify |

<h2 id="backend-integration-rules">Règles d’intégration backend</h2>

- Charger `apiSecret` depuis un gestionnaire secret ou une variable d’environnement protégé.
- Garder la liaison utilisateur, le transfert, la signature et la logique webhook hors du code du navigateur.
- Utiliser des chaînes décimales pour les montants des actifs afin d’éviter l’arrondi en virgule flottante.
- Réutiliser le `agentOrderNo` original lors de l’interrogation d’un résultat de transfert incertain.
- Vérifier les signatures webhook par rapport au corps brut de la requête avant de le décoder ou de le modifier.
