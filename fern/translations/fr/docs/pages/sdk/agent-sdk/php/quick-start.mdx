<h2 id="install">Installation</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Accès au forfait**
>
> 6MM fournit le nom du paquet Composer approuvé, le dépôt et la version lors de l’intégration du partenaire. Il ne faut pas supposer que le package existe sur Packagist public.

<h2 id="before-you-start">Avant que tu commences</h2>

- Confirmez l’Agent API URL base avec 6MM.
- Charger apiSecret à partir de variables d’environnement ou de gestion de secrets.
- Conserver SDK utilisation uniquement dans les services backend.
- Préparer la manipulation des idempotents pour les flux de transfert et de webhook.

<h2 id="initialize-client">Initialisation du client</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Uniquement en arrière-plan**
>
> Le PHP SDK signe les requêtes Agent API et ne doit pas être exposé via le code source public ou les environnements d’exécution frontend.

<h2 id="example-transfer-funds-in">Exemple : transférer des fonds dans</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Utilisez des chaînes décimales pour les montants et conservez le agentOrderNo d’origine lors de la réévaluation ou de la requête sur le statut du transfert.
