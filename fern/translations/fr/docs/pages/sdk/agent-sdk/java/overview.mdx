| Article | Valeur |
| --- | --- |
| Balise source stable | `v0.3.0` |
| Java | Java 8+ |
| Maven | Maven 3.9+ |
| Coordonnées | `com.sixmm.exchange.sdk:agent:0.3.0` |

GitHub héberge la source ; cela ne rend pas ces coordonnées résolubles à partir de Maven Central. Utilisez l'installation locale balisée ou votre référentiel d'artefacts approuvé.

## Ce que couvre le SDK

| Catégorie | Scénario | SDK API | Description |
| --- | --- | --- | --- |
| Liaison utilisateur | Lier l'utilisateur | `bind` | Créer ou récupérer la liaison entre un utilisateur partenaire et un utilisateur de la plateforme 6MM |
| Requêtes d'actifs | Compte partenaire de requête | `queryAccount` | Interroger la marge du partenaire ou le compte de financement |
| Requêtes d'actifs | Interroger les ressources utilisateur | `queryUserAssets` | Interroger les actifs du contrat ; utilisez `withFunding()` pour inclure les soldes de financement |
| Transferts | Virement à montant fixe | `transfer` | Transférer des fonds vers ou depuis 6MM |
| Transferts | Tout transférer | `transferAllOut` | Transférez tout le solde utilisateur retirable vers la plateforme partenaire |
| Transferts | Ordre inverse | `reverse` | Annuler un transfert réussi lorsque le backend prend en charge un flux de compensation |
| Transferts | Ordre de requête | `queryOrder` | Rechercher un ordre de transfert par numéro de commande partenaire |
| Transferts | Liste des commandes | `listOrders` | Feuilleter les ordres de transfert pour le rapprochement |
| Transferts | Webhook vérification | `WebhookVerifier.verify` | Vérifier le transfert des rappels de l'état final à partir de 6MM |
| Portefeuille de financement | Transfert de fonds | `walletTransfer` | Partenaire ↔ Financement ou Financement ↔ Contrat ; confirmer le statut renvoyé |
| Portefeuille de financement | Statut du transfert de fonds | `queryWalletTransfer` | Récupérer une opération de financement en utilisant son numéro de commande partenaire d'origine |
| Entrée en bourse | Entrée directe URL | `createEntryUrl` | Créez un SSO URL unique pour le mode de redirection. |
| Entrée en bourse | Intégrer le jeton | `createEmbedToken` | Créez un jeton de courte durée pour le mode Trading Widget `tokenProvider` |
| Données perpétuelles | Commandes perpétuelles actuelles | `listCurrentPerpetualOrders` | Interroger les commandes NORMAL ou CONDITIONAL en cours |
| Données perpétuelles | Historique des commandes perpétuel | `listPerpetualOrderHistory` | Interroger les commandes du terminal NORMAL ou CONDITIONAL |
| Données perpétuelles | Métiers perpétuels | `listPerpetualTrades` | Requête d'échange pour une liste de joueurs publique explicite |
| Données perpétuelles | Positions perpétuelles actuelles | `listCurrentPerpetualPositions` | Interroger les postes actuels |
| Données perpétuelles | Historique perpétuel des positions | `listPerpetualPositionHistory` | Interroger les positions fermées |
| Données perpétuelles | Grand livre de comptes perpétuel | `listPerpetualLedger` | Interroger les enregistrements individuels de modification du solde du contrat |

## Configuration

Obtenez les valeurs suivantes auprès de 6MM avant
intégrant.

| Article | Exemple | Description |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Agent API base URL, sans barre oblique finale |
| `agentCode` | `AGENT001` | Code partenaire |
| `apiSecret` | `your-api-secret` | API secret de signature. Gardez-le uniquement sur le backend |
| `defaultCurrency` | `USDT` | Devise par défaut, généralement `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Point de terminaison partenaire pour les rappels 6MM |

Recommandations de fabrication :

- Utilisez HTTPS pour les points de terminaison de l'agent API et webhook.
- Stockez `apiSecret` dans un gestionnaire de secrets, un centre de configuration ou une variable d'environnement.
- Gardez l'heure du serveur synchronisée, de préférence avec NTP.
- Conservez tous les numéros de commande des partenaires et conservez-les uniques au monde.
- N'envoyez jamais `apiSecret` aux navigateurs, applications, mini-programmes ou code source frontend.


<span id="automatic-signing-fields" data-sixmm-canonical-anchor="automatic-signing-fields" aria-hidden="true"></span>

## Champs de signature automatique

Pour les appels signés de l'agent API, le SDK injecte automatiquement :

| Champ | Source | Description |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Code partenaire |
| `timestamp` | Horodatage Unix actuel UTC | Secondes |
| `nonce` | Générateur aléatoire sécurisé | Protection contre la relecture |
| `sign` | HMAC-SHA256 | Demander une signature |
| `currency` | `defaultCurrency` | Rempli lorsque les demandes de transfert/compte omettent la devise |

Règles de signature :

1. Exclure `sign`.
2. Excluez les valeurs vides.
3. Triez les clés par ordre ASCII.
4. Rejoignez-nous en tant que `k=v&k2=v2`.
5. Calculez HMAC-SHA256 hexadécimal avec `apiSecret`.

Le code commercial normal ne doit pas calculer les signatures ni définir manuellement
`agentCode`, `timestamp`, `nonce` ou `sign`.
