Ce guide cible **Agent Java SDK `v0.3.0`**, Java 8+ et le contrat public étiqueté. Exemples exécutés dans un backend partenaire après l'initialisation de `client` dans [Démarrage rapide](/fr/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Six requêtes perpétuelles : commandes en cours, historique des commandes, exécutions, positions actuelles, historique des positions et grand livre des comptes.
- Soldes de financement, transferts, requêtes de recouvrement et transferts de financement/contrat.
- Production explicite/sélection simulée pour les demandes de fonds prises en charge.
- Guides de redirection et d'intégration du trading de secondes, référence du champ de réponse et instructions de migration.

Java SDK et Trading Widget SDK ont des versions indépendantes. Le widget `v1` Widget URL n'est pas la version Java SDK `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Intégrations existantes

Conservez les mappages d’utilisateurs, les commandes originales et les informations d’identification. Les champs d'environnement omis conservent le comportement de production existant. Le financement, les fonds simulés explicites et six requêtes perpétuelles nécessitent les nouveaux modèles et méthodes correspondants. Revoir [Guide de mise à niveau](/fr/sdk/agent-sdk/java/upgrade) avant de modifier une intégration existante.
