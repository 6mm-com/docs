## Taux de référence des changes

Les deux méthodes FX utilisent le flux d'agent signé normal API . Commencez par découvrir le
Devises sources actuellement prises en charge :

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Interrogez tous les taux de référence fiat-to-USDT pris en charge :

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Rechercher les devises sélectionnées :

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

L'usine de demande coupe et met en majuscules les codes de devise et les sérialise comme
la valeur `sourceCurrencies` séparée par des virgules requise par le API. En omettant le
request ou toutes les valeurs de devise effectives interroge chaque devise prise en charge.

| Champ de réponse | Taper | Description |
| --- | --- | --- |
| `snapshotVersion` | string | Version instantanée stable pour l'audit et le rapprochement |
| `provider` | string | Fournisseur en amont, actuellement `ECB` |
| `sourceDate` | string | Date d'observation amont au format `yyyy-MM-dd` |
| `fetchedAt` / `expiresAt` | int64 | Horodatages Unix en millisecondes |
| `pricingPolicy` | string | Actuellement `FIXED_PEG` |
| `usdtUsdRate` | string | Montant de USD par 1 USDT, actuellement fixé à `1` |
| `rateType` | string | Actuellement `INDICATIVE_DAILY` |
| `usage` | string | Actuellement `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT montant correspondant à une unité de source fiat |

Ces valeurs sont des références permettant à un portefeuille multi-devises partenaire de calculer
le montant de USDT envoyé à 6MM. Il ne s'agit pas de prix exécutables, de cotations verrouillées ou
en temps réel USDT prix du marché. Utiliser `BigDecimal` et des chaînes pour le montant
calculs; n'utilisez pas `double` ou `float`.
