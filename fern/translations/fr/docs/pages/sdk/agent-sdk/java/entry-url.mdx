## Entrée directe URL

L'entrée directe URL est destinée au mode de redirection. Un utilisateur partenaire clique sur un bouton du
site partenaire, ouvre l'interface 6MM et est automatiquement connecté.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Règles de terrain :

| Champ | Description |
| --- | --- |
| `redirectPath` | 6MM chemin relatif du frontend. Il doit commencer par `/`, par exemple `/trade/BTCUSDT` |
| `returnUrl` | Partenaire absolu URL utilisé lorsque l'utilisateur quitte l'interface 6MM. Seuls `http` et `https` sont autorisés |
| `expireAt` | Délai d'expiration du ticket d'entrée sous forme d'horodatage Unix en secondes |

Exigences de sécurité :

- `webUrl` contient un ticket unique. Utilisez-le immédiatement et ne le stockez pas à long terme.
- Si l'entrée URL expire ou a été utilisée, générez-en une nouvelle depuis le site partenaire.
- `returnUrl` ne doit pas être `javascript:`, un chemin relatif ou un URL avec les informations utilisateur.


<span id="product-and-mode-selection" data-sixmm-canonical-anchor="product-and-mode-selection" aria-hidden="true"></span>

## Sélection du produit et du mode

Utilisez la route frontale actuelle fournie par 6MM. Par exemple `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` ou `/zh-CN/futures/BTCUSDT?tradingMode=real`. Le ticket authentifie l'utilisateur ; il ne sélectionne pas un environnement de financement ni ne déplace de fonds.

Voir [Trading de secondes](/fr/sdk/agent-sdk/java/seconds-trading) pour les exemples de redirection et intégrés.
