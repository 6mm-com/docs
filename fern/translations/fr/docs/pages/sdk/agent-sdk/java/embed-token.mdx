## Trading Widget Intégrer le jeton

Le jeton intégré est destiné au mode Trading Widget SDK `partner-token + tokenProvider`. Le
le navigateur appelle le backend partenaire, et le backend partenaire appelle ceci Java SDK
pour créer un `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Exigences d'intégration :

- `channelId` doit utiliser la valeur transmise par le Trading Widget SDK.
- `symbol` est facultatif et peut porter le symbole initial actuel. Il ne s'agit pas d'une restriction d'autorisation de paire de trading de jetons.
- `embedToken` est de courte durée et ponctuel. Ne le placez pas dans les chaînes de requête URL.
- L'interface partenaire ne doit jamais contenir `apiSecret`.
- `expireAt` est un horodatage Unix en secondes, pas un TTL.

Exemple de point de terminaison backend partenaire :

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```


<span id="partner-endpoint-contract" data-sixmm-canonical-anchor="partner-endpoint-contract" aria-hidden="true"></span>

## Contrat de point de terminaison partenaire

Authentifiez la session partenaire et dérivez `agentUserId` côté serveur. Acceptez le widget actuel `channelId` ; renvoie `embedToken` de niveau supérieur, `expireAt` (secondes Unix) et le même `channelId`. Les réponses de l'agent ne fournissent pas `channelId` : votre backend le fait écho. Récupérez un nouveau jeton lors de l'initialisation et du renouvellement ; ne le réutilisez jamais. La création de jetons ne transfère pas de fonds et ne choisit pas l'environnement du portefeuille.

Voir [Trading de secondes](/fr/sdk/agent-sdk/java/seconds-trading) pour le flux frontend/backend complet.
