## SDK appelle

Créez des tokens d’intégration depuis votre backend après avoir validé la session utilisateur partenaire. Le navigateur doit appeler votre point de terminaison, et votre point de terminaison doit appeler 6MM via le Agent SDK.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Accréditation unique**
>
> embedToken est de courte durée et à usage unique. Ne le placez pas dans une chaîne de requête URL .

<span id="backend-endpoint-example" data-sixmm-canonical-anchor="backend-endpoint-example" aria-hidden="true"></span>

## Exemple de terminaison backend

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Retournez uniquement les champs nécessaires au fournisseur Trading Widget token. Ne retournez pas apiSecret, champs de signature bruts ou configuration interne du service.

<span id="failure-handling" data-sixmm-canonical-anchor="failure-handling" aria-hidden="true"></span>

## Gestion des pannes

| État | Manipulation recommandée |
| --- | --- |
| La session utilisateur est manquante ou expirée | Retournez le 401 depuis le point de terminaison partenaire et demandez à l’utilisateur de se reconnecter. |
| L’utilisateur agent n’est pas lié | Assignez d’abord l’utilisateur, puis réessayez la création du token. |
| 6MM renvoie une erreur temporaire | Retournez une erreur réessayable au frontend et enregistrez requestId pour le support. |
| channelId ne correspond pas à l’instance du widget | Rejetez la requête et recréez la session du widget. |
