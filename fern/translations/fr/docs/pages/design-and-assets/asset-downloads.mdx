Cette page fournit des directives unifiées pour les spécifications d’utilisation et les méthodes de téléchargement des actifs visuels 6MM Embedded Exchange, applicables aux partenaires intégrant 6MM des capacités de trading de contrats perpétuels via SDK / API.

Ce document combine les spécifications des assets (tailles / formats / règles d’utilisation) et les téléchargements d’assets (catégories / aperçus / ZIP packages), permettant aux partenaires de compléter ce qui suit en une seule page :

* Spécifications de revue
* Comparer les exemples
* Télécharger les packs d’assets correspondants

Toutes les spécifications sont conçues avec une intégration intégrée, une compatibilité multiplateforme et une maintenance à long terme comme objectifs fondamentaux.

<h2 id="2-entry-banners">2. Bannières d’entrée</h2>

Cas d’utilisation

* Bannières de la page d’accueil de l’application
* Bannières héroïques de la page d’accueil web
* Zones de recommandation ou d’entrée de campagne

Tailles recommandées (px)

| Taille       | Description d’utilisation              |
| ---------- | ------------------------------ |
| 750 × 300  | Norme mobile / H5           |
| 1125 × 450 | Télécommande mobile haute résolution         |
| 1200 × 480 | Bannière polyvalente         |
| 1440 × 480 | Section visuelle principale du web     |
| 1920 × 600 | Écran de bureau / grand écran |

Guidage du format d’image

* Disposition horizontale
* Ratios recommandés : 4:1, 5:2, 3:1

Règles d’utilisation

* Gardez le contenu principal centré
* Réserve ≥ marge de sécurité de 10 % des deux côtés
* Éviter la copie de longueur variable à l’intérieur de l’asset

<h2 id="3-card-module-entries">3. Entrées de cartes / modules</h2>

Cas d’utilisation

* Cartes caractéristiques de la page d’accueil de l’application
* Entrées fonctionnelles modulaires web
* Échanges de blocs de fonctionnalités dans les flux de contenu

Ratios communs et tailles recommandées (px)

| Type            | Ratio | Taille recommandée | Description d’utilisation            |
| --------------- | ----- | ---------------- | ---------------------------- |
| Carte horizontale | 16:9  | 640 × 360        | Flux / zones de recommandation |
| Carte horizontale | 16:9  | 1280 × 720       | Cartes web haute résolution    |
| Carte horizontale | 3:2   | 600 × 400        | Modules fonctionnels           |
| Carte verticale   | 4:5   | 600 × 750        | Entrées basées sur des listes           |
| Carte carrée     | 1:1   | 512 × 512        | Agencements en grille                 |
| Carte carrée     | 1:1   | 1024 × 1024      | Affichage haute résolution      |

Règles de conception

* Centrer la vision principale
* Les zones de texte doivent permettre le recadrage
* Maintenir ≥ marge de sécurité de 8 % de toutes parts
* Ne vous fiez pas aux coins arrondis ou aux effets d’ombre

* PNG

<h2 id="4-general-usage-rules">4. Règles d’usage générale</h2>

* Privilégier les actifs haute résolution ou vectoriels
* Éviter d’intégrer une logique métier fixe ou un texte marketing dans les actifs
* Les assets doivent prendre en charge les environnements en mode sombre
* Les actifs sont limités à l’entrée de trading et à l’assistance à l’interface

***

<h2 id="5-versioning-and-maintenance">5. Gestion des versions et maintenance</h2>

* Les tailles et spécifications des actifs peuvent être mises à jour en même temps que les mises à jour des produits
* Les partenaires sont invités à utiliser les derniers packs d’actifs
* Les anciennes versions de l’asset ne sont pas recommandées pour les nouvelles intégrations

Pour des exigences particulières concernant les spécifications ou téléchargements des assets, veuillez contacter 6MM support technique ou professionnel officiel.
