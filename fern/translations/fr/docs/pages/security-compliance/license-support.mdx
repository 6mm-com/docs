La planification des licences fait partie d’un plan de lancement plus large. La bonne voie dépend des marchés cibles, du type d’utilisateur, de l’étendue du produit, du modèle de garde et des responsabilités opérationnelles de chaque partie.

<span id="planning-inputs" data-sixmm-canonical-anchor="planning-inputs" aria-hidden="true"></span>

## Apports en planification

| Entrée | Pourquoi cela compte |
| --- | --- |
| Juridiction cible | Détermine les attentes réglementaires et la révision locale requise. |
| Type d’utilisateur | Les utilisateurs de détail, professionnels, institutionnels ou distribués par des partenaires peuvent nécessiter des contrôles différents. |
| Portée du produit | Les fonctionnalités au comptant, dérivés, portefeuille, garde et courtage peuvent modifier le modèle de conformité. |
| Modèle de fonctionnement | Les modèles white-label, embarqués, courtiers et institutionnels ont des limites de responsabilité différentes. |

<span id="how-to-use-this-documentation" data-sixmm-canonical-anchor="how-to-use-this-documentation" aria-hidden="true"></span>

## Comment utiliser cette documentation

Utilisez ces documents pour aligner les exigences techniques et opérationnelles avant un examen juridique. La documentation peut aider les équipes à décrire l’architecture, le flux de données, la signature, la sécurité, le mouvement d’actifs et les responsabilités du cycle de vie du trading.

> **Important**
>
> Les décisions de licence doivent être examinées par des conseillers juridiques et de conformité qualifiés pour la juridiction concernée.
