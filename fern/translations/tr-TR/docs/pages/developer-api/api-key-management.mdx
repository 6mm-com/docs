API Key idarəetmə son nöqtələri yalnız JWT autentifikasiya qəbul edir.

<h2 id="create-api-key">Yarat API Key</h2>

```http
POST /v1/private/user/api-key/create
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json
```

Sorğu parametrləri:

| Parametr     | Tip      | Tələb olunur | Təsvir                                                           |
| ------------- | --------- | -------- | --------------------------------------------------------------------- |
| `label`       | string    | Bəli      | API Key etiketi, uzunluq 1 - 64                                          |
| `permissions` | int       | Xeyr       | İcazə bitmaskası, standart `1`, aralıq `1` - `7`                      |
| `ipWhitelist` | String\[] | Xeyr       | IP ağ siyahı, 20-yə qədər giriş. Əgər çıxarılıbsa, mənbə IP məhdudiyyətsizdir |

Nümunə istəyi:

```bash
curl -X POST https://api.6mm.com/v1/private/user/api-key/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -d '{
    "label": "external-service-prod",
    "permissions": 3,
    "ipWhitelist": ["203.0.113.10"]
  }'
```

Cavab nümunəsi:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "apiKey": "fx_xxxxxxxxxxxxxxxxxxxxxxxx",
    "apiSecret": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  },
  "requestId": "req-api-key"
}
```

`apiSecret` API Key yaradıldıqda yalnız bir dəfə geri qaytarılır. Dərhal gizli idarəetmə sistemində saxlayın. Onu mənbə kodu anbarlarına və ya loglara yazmayın.

Hər istifadəçi 30-a qədər API Açar yarada bilər.

<h2 id="list-api-keys">Açarların API siyahısı</h2>

```http
GET /v1/private/user/api-key/list
Authorization: Bearer YOUR_ACCESS_TOKEN
```

Cavab sahələri:

| Sahə                | Tip      | Təsvir                       |
| -------------------- | --------- | --------------------------------- |
| `list[].id`          | string    | API Key ID                        |
| `list[].label`       | string    | Etiket                             |
| `list[].apiKey`      | string    | İctimai API Key identifikatoru         |
| `list[].permissions` | int       | İcazə bitmaskı                |
| `list[].ipWhitelist` | String\[] | IP ağ siyahı                      |
| `list[].status`      | int       | Status: `1` aktivdir, `0` deaktivdir |
| `list[].lastUsedAt`  | int64     | Son istifadə vaxtı                    |
| `list[].createdAt`   | int64     | Yaradılma vaxtı                     |

<h2 id="update-api-key">Yeniləmə API Key</h2>

```http
PUT /v1/private/user/api-key/update
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json
```

Sorğu parametrləri:

| Parametr     | Tip      | Tələb olunur | Təsvir               |
| ------------- | --------- | -------- | ------------------------- |
| `id`          | string    | Bəli      | API Key ID                |
| `label`       | string    | Xeyr       | Yeni etiket                 |
| `permissions` | int       | Xeyr       | Yeni icazə bitmaskı    |
| `ipWhitelist` | String\[] | Xeyr       | Yeni IP ağ siyahısı          |
| `status`      | int       | Xeyr       | `1` aktivdir, `0` deaktivdir |

<h2 id="delete-api-key">Sil API Key</h2>

```http
POST /v1/private/user/api-key/delete
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json
```

Tələb bədəni:

```json
{ "id": "1001" }
```

<h2 id="delete-all-api-keys">Bütün API Açarları Sil</h2>

```http
POST /v1/private/user/api-key/delete-all
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json
```

Cavab sahələri:

| Sahə     | Tip  | Təsvir                |
| --------- | ----- | -------------------------- |
| `deleted` | int64 | Silinmiş API Açarların sayı |
