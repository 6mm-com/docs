<h2 id="base-url">Baza URL</h2>

```
https://api.6mm.com
```

<h2 id="service-version">Xidmət Versiyası</h2>

```http
GET /v1/version
```

Xidmət versiyası məlumatını əldə edin.

<h2 id="server-time">Server Vaxtı</h2>

```http
GET /v1/time
```

Server vaxtı alın. Bu son nöqtə API Key imzalamadan əvvəl müştəri vaxtını kalibrləmək üçün istifadə oluna bilər.

<h2 id="user-login">İstifadəçi Girişi</h2>

```http
POST /v1/public/user/login
```

Sorğu parametrləri:

| Parametr    | Tip   | Tələb olunur | Təsvir                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | Bəli      | İstifadəçi adı, uzunluq 3 - 32                 |
| `password`   | string | Bəli      | Şifrə, uzunluq 1 - 64                 |
| `deviceId`   | string | Xeyr       | Cihaz barmaq izi, 64 simvola qədər |
| `deviceName` | string | Xeyr       | Cihaz adı, maksimum 128 simvol       |

Nümunə istəyi:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

Cavab nümunəsi:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<h2 id="refresh-token">Refresh Token</h2>

```http
POST /v1/public/user/refresh-token
```

Adi inteqrasiya hallarında giriş vəziyyəti Cookie vasitəsilə yenilənir. Cookie-ni giriş cavabında geri qaytarın.

Cavab sahələri:

| Sahə          | Tip   | Təsvir              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Yeni giriş tokeni         |
| `accessExpire` | int64  | Access Token-in bitmə müddəti |

<h2 id="agent-sso">Agent SSO</h2>

<h2 id="ticket-exchange">Bilet Mübadiləsi</h2>

```http
POST /v1/public/agent-sso/exchange-ticket
```

Sorğu parametrləri:

| Parametr  | Tip   | Tələb olunur | Təsvir                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | Bəli      | Agent xidməti tərəfindən verilən bir dəfəlik bilet |
| `deviceId` | string | Xeyr       | Cihaz barmaq izi, 64 simvola qədər     |

Cavab sahələri:

| Sahə          | Tip   | Təsvir              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Access Token             |
| `accessExpire` | int64  | Access Token-in bitmə müddəti |
| `redirectPath` | string | Təklif olunan yönləndirmə yolu  |

<h2 id="embed-token-exchange">Embed Token Exchange</h2>

```http
POST /v1/public/agent-sso/exchange-embed-token
```

Sorğu parametrləri:

| Parametr    | Tip   | Tələb olunur | Təsvir                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | Bəli      | Agent xidməti tərəfindən buraxılmış qısaömürlü gömülü ticarət tokeni |
| `channelId`  | string | Bəli      | Daxili iframe kanal ID, 128 simvola qədər               |
| `deviceId`   | string | Xeyr       | Cihaz barmaq izi, 64 simvola qədər                        |

Cavab sahələri:

| Sahə          | Tip   | Təsvir              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Access Token             |
| `accessExpire` | int64  | Access Token-in bitmə müddəti |

<h2 id="pnl-leaderboard">PnL Lider Cədvəli</h2>

```http
GET /v1/public/leaderboard/pnl?period=30d
```

Sorğu parametrləri:

| Parametr | Tip   | Tələb olunur | Təsvir          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | Bəli      | `7d` / `30d` / `90d` |

Cavab sahələri:

| Sahə              | Tip   | Təsvir                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | Rütbə                                                              |
| `list[].userId`    | string | Xarici istifadəçi ID-si                                                  |
| `list[].trader`    | string | Maskalı tacir adı                                                |
| `list[].volume`    | string | Pəncərədə ticarət həcmi                                      |
| `list[].pnlAmount` | string | Pəncərədə başa düşülmüş PnL                                        |
| `list[].pnlPct`    | string | PnL nisbəti, `0`-dən `1`-ə onluq                                |
| `myRank`           | int32  | Cari istifadəçinin reytinqi. Əgər təsdiqlənməyibsə və ya reytinqi yoxdursa, `0` qaytarılır |
