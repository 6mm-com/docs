<h2 id="service-endpoint">Xidmət Son Nöqtəsi</h2>

```
wss://ws.6mm.com/ws
```

WebSocket kanallar ictimai və özəl kanallara bölünür:

| Tip             | Autentifikasiya              | Təsvir                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| İctimai kanallar  | Tələb olunmur                | Bazar məlumatları, məsələn, dərinlik, ticarətlər, Klines və ticker |
| Özəl kanallar | `listenKey` və ya JWT tələb olunur | İstifadəçi sifarişi, hesab və mövqe axınları              |

<h2 id="public-channels">İctimai Kanallar</h2>

İctimai WebSocket autentifikasiya tələb etmir. Qoşulduqdan sonra bazar kanallarına abunə olmaq üçün `subscribe` sorğu göndərin.

Ümumi kanallar:

| Kanal                            | Təsvir                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Kitab dərinliyini sifariş edin. Əvvəlcə snapshot göndərir, sonra tədrici yeniləmələr |
| `market.trade.{symbol}`            | Son transferlər                                                      |
| `market.kline.{symbol}.{interval}` | Klines-lər                                                             |
| `market.ticker.{symbol}`           | Tək simvollu ticker xülasəsi                                       |
| `market.tickers`                   | Bütün simvollar üzrə ticker xülasəsi                                          |

<h2 id="private-channels">Özəl Kanallar</h2>

<h2 id="listenkey">listenKey</h2>
Özəl WebSocket axınları üçün əvvəlcə REST API vasitəsilə `listenKey` yaradın, sonra qoşulun:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
Uyğun JWT qoşulma üsulu:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Autentifikasiya uğurlu olduqdan sonra server avtomatik olaraq bağlantını cari istifadəçinin şəxsi kanalına abunə edir. Əl ilə abunə tələb olunmur.
