<h2 id="documentation-areas">Sənədləşdirmə sahələri</h2>

| Ərazi | Nələri əhatə edir |
| --- | --- |
| İnteqrasiya quruluşu | Xidmət ünvanları, sorğu konvensiyaları, cavab forması və giriş rejimləri. |
| Autentifikasiya və təhlükəsizlik | JWT, API Key icazələri, HMAC imzalama, təkrar baxış qorunması və zaman sinxronizasiyası. |
| REST API | İctimai son nöqtələr, istifadəçi/hesab məlumatları, sifarişlər, mövqelər və bazar məlumatları. |
| WebSocket | Bağlantı həyat dövrü, ictimai bazar axınları və özəl istifadəçi axınları. |
| İstinadlar və problemlərin həlli | Enumlar, səhv kodları və praktik inteqrasiya tövsiyələri. |

<h2 id="production-checklist">İstehsal yoxlama siyahısı</h2>

- API sirləri yalnız arxa planda saxla.
- İmzalanmış sorğulardan əvvəl server vaxtını sinxronlaşdırmaq.
- Bütün ədədi dəqiqlik sahələrini sətir kimi qəbul edin, əgər səhifədə açıq şəkildə başqa cür göstərilməyibsə.
- İdempotensiya, sorğu ID-ləri və sifariş axınları ətrafında strukturlaşdırılmış loglardan istifadə edin.
- Əməliyyat sistemlərində aktual qalmalı olan vəziyyət üçün WebSocket axınlarına abunə olun.
- Buraxılışdan əvvəl səhv kodlarını və davranışı yenidən yoxlayın.
