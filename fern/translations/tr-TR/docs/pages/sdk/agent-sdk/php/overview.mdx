<h2 id="runtime">İcra müddəti</h2>

| Maddə | Dəyər |
| --- | --- |
| Paket | Sixmm/Agent-SDK |
| Minimum PHP versiyası | PHP 7.4+ |
| Tövsiyə olunan PHP versiyası | PHP 8.1+ və ya hazırda dəstəklənən versiyalar |
| Tələb olunan uzadmalar | ext-json, ext-curl |

PHP SDK paket mənbəyi və təsdiqlənmiş versiya tərəfdaş onboarding zamanı təqdim olunur. Paketin ictimai Packagist-dən əlçatan olduğunu fərz etməyin; təşkilatınız üçün təqdim olunan Composer repozitoriyasını konfiqurasiya edin.

<h2 id="supported-scenarios">Dəstəklənən ssenarilər</h2>

| Ssenari | SDK metodu |
| --- | --- |
| İstifadəçini bağla | bağlama |
| Sabit məbləğli köçürmə | Transfer |
| Tam ötürmə | transferAllOut |
| Tərs ötürmə | Tərs |
| Sorğu sırası | queryOrder |
| Giriş yarat URL | createEntryUrl |
| Webhook yoxlaması | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Backend inteqrasiya qaydaları</h2>

- Gizli menecerdən və ya qorunan mühit dəyişənindən `apiSecret` yükləmək.
- İstifadəçi bağlama, ötürmə, imzalama və webhook loqikası brauzer kodundan kənarda saxlanmalıdır.
- Aktiv məbləğləri üçün onluq sətirlərdən istifadə edin ki, üzən nöqtə yuvarlaqlaşdırılmasının qarşısını alsın.
- Qeyri-müəyyən transfer nəticəsini sorğulayarkən orijinal `agentOrderNo` təkrar istifadə etmək.
- Webhook imzalarını xam sorğu bədəni ilə yoxlamaq, sonra onu deşifrə etmək və ya dəyişdirmək.
