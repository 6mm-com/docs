<h2 id="responsibility-split">Məsuliyyətin bölüşdürülməsi</h2>

| Ərazi | Sahibi | Qeydlər |
| --- | --- | --- |
| Konteyner yaradılması | Tərəfdaş ön tərəf | Açıq şəkildə eni və hündürlüyü olan görünən element təmin edin. |
| iframe yaradılması | Trading Widget SDK | SDK iframe-i yaradır və idarə edir. |
| Ticarət interfeysi | 6MM iframe | K-line, sifariş kitabı, sifariş forması, mövqelər, sifarişlər və hesab məlumatları iframe daxilində işləyir. |
| Ekran idarəetmələri | Trading Widget SDK + 6MM iframe | PC embed başlığı və alt ticker standart olaraq gizlidir. Tərəfdaşlar `display` istifadə edərək qabıq sahələrini göstərə və ya yüksək səviyyəli ticarət konteynerlərini gizlədə bilərlər. |
| Tərəfdaş giriş yoxlaması | Tərəfdaş backend | Auth etimadnaməsini verməzdən əvvəl tərəfdaş istifadəçi sessiyasını təsdiqləyin. |
| Embed token buraxılışı | Tərəfdaş backend + Agent API | Partnyor-token rejimi üçün tövsiyə olunur. |

<h2 id="versioning">Versiyalaşdırma</h2>

İctimai inteqrasiya yolu v1 skripti altında sabit qalır URL. Hazırkı v1 qabiliyyət dəsti tərəfdaş-token, tokenProvider, entryUrlProvider, ekran idarəetmələri, həyat dövrü hadisələri, instansiya metodları və sifariş hadisələrini əhatə edir.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Vidjetdən nə vaxt istifadə etmək lazımdır</h2>

Tərəfdaşın mövcud veb məhsul daxilində tam ticarət interfeysinə ehtiyacı olduqda Trading Widget seçin. Tam fərdi ticarət interfeysi qurarkən və saxlayarkən REST API və WebSocket sənədlərindən istifadə edin.

<h2 id="implementation-path">İcra yolu</h2>

1. Skripti yükləmək və görünən konteyner yaratmaq üçün [Trading Widget Quick Start](/tr-TR/sdk/trading-widget/quick-start) düyməsini izləyin.
2. [tərəfdaş-token autentifikasiyası](/tr-TR/sdk/trading-widget/authentication) tərəfdaş backend vasitəsilə konfiqurasiya edin.
3. Tələb olunan [seçimlər və hadisələr](/tr-TR/sdk/trading-widget/options-events) əlavə edin.
4. Həyat dövrü və işləmə idarəetmələri üçün [instance method](/tr-TR/sdk/trading-widget/instance-methods) istifadə edin.
