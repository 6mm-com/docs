Təhlükəsizlik hesabatları 6MM komandasının təsiri qiymətləndirməsi və problemi təhlükəsiz şəkildə təkrarlaması üçün kifayət qədər texniki kontekst ehtiva etməlidir.

<h2 id="reportable-issues">Hesabat verilə bilən məsələlər</h2>

- API, SDK, webhook, autentifikasiya və ya ticarət giriş axınlarında zəifliklər.
- Ticarətin bütövlüyünə və istifadəçi təhlükəsizliyinə təsir edə biləcək şübhəli istehsal davranışı.
- Giriş məlumatlarının sızması və ya şübhəli icazəsiz giriş.
- Sistem sabitliyinə təsir edə biləcək sui-istifadə nümunələri.

<h2 id="include-in-the-report">Hesabatda daxil edin</h2>

- Təsirlənmiş mühit və son nöqtə.
- Zaman aralığı və reproduksiya addımları.
- Qeydlər, sorğu ID-ləri, webhook hadisə ID-ləri və ya ekran görüntüləri.
- Problemin hazırda aktiv olub-olmaması.

<h2 id="safe-reporting-guidelines">Təhlükəsiz hesabat qaydaları</h2>

- Təmizlənməmiş zəifliyi ictimaiyyətə açıqlamayın.
- Problemi sübut etmək üçün tələb olunan məlumatlara daxil olmayın, yükləməyin, dəyişdirməyin və ya saxlamayın.
- Xidmətin rədd edilməsi, dağıdıcı, sosial mühəndislik və ya vəsait hərəkəti testləri aparmayın.
- Test hesablarından və ən kiçik təhlükəsiz konsept sübutundan istifadə edin.
- Əlavələrdən şifrələri, API sirləri, giriş tokenlərini, şəxsi açarları və əlaqəsiz şəxsi məlumatları silmək.

<h2 id="suggested-report-format">Təklif olunan hesabat formatı</h2>

```text
Title:
Affected component and environment:
First observed time (UTC):
Issue status:
Technical description:
Reproduction steps:
Expected security behavior:
Observed behavior:
Potential impact:
Sanitized evidence:
Researcher or partner contact:
```

<h2 id="security-contact">Təhlükəsizlik əlaqəsi</h2>

Zəiflik və təcili təhlükəsizlik hesabatlarını şəxsi olaraq aşağıdakı ünvanlara göndərin:

[security@6mm.com] (mailto:security@6mm.com)

Ümumi inteqrasiya problemləri [Dəstək Sorğusu](/tr-TR/resources/support-request-template) istifadə etməlidir. Tədqiqatçılar həmçinin [Bug Bounty Programı](/tr-TR/security-compliance/bug-bounty-program) miqyası və məsuliyyətli açıqlama gözləntiləri üçün nəzərdən keçirməlidirlər.
