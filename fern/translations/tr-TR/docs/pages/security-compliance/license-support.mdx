Lisenziya planlaşdırması daha geniş buraxılış planının bir hissəsidir. Düzgün yol hədəf bazarlardan, istifadəçi növündən, məhsulun əhatə dairəsindən, saxlanma modelindən və hər bir tərəfin əməliyyat məsuliyyətlərindən asılıdır.

<h2 id="planning-inputs">Planlaşdırma girişləri</h2>

| Giriş | Niyə önəmlidir |
| --- | --- |
| Hədəf yurisdiksiya | Tənzimləyici gözləntiləri və tələb olunan yerli yoxlamanı müəyyən edir. |
| İstifadəçi tipi | Pərakəndə satış, peşəkar, institusional və ya tərəfdaş tərəfindən paylanmış istifadəçilər fərqli nəzarətlərə ehtiyac duya bilərlər. |
| Məhsulun əhatə dairəsi | Spot, törəmə alətlər, cüzdan, saxlanma və brokerlik xüsusiyyətləri uyğunluq modelini dəyişə bilər. |
| İşləmə modeli | Ağ etiketli, embedded, broker və institusional modellərin məsuliyyət sərhədləri fərqlidir. |

<h2 id="how-to-use-this-documentation">Bu sənədləşmədən necə istifadə etmək olar</h2>

Bu sənədlərdən texniki və əməliyyat tələblərini hüquqi yoxlamadan əvvəl uyğunlaşdırmaq üçün istifadə edin. Sənədlər komandalara arxitektura, məlumat axını, imzalama, təhlükəsizlik, aktivlərin hərəkəti və ticarət həyat dövrü məsuliyyətlərini təsvir etməyə kömək edə bilər.

> **Vacib**
>
> Lisenziya qərarları müvafiq yurisdiksiya üzrə ixtisaslı hüquqi və uyğunluq məsləhətçiləri ilə birlikdə nəzərdən keçirilməlidir.
