Embedded API / SDK Ticarət Sistemi artıq trafikə, istifadəçilərə və ya biznes iş axınlarına sahib olan tərəfdaşlar üçün nəzərdə tutulub və tam birja sıfırdan qurmadan ticarət əlavə etmək istəyirlər.

<h2 id="what-it-provides">Nə təmin edir</h2>

- Daxili ticarət terminalı Trading Widget SDK
- Agent SDKs vasitəsilə tərəfdaş backend inteqrasiyası
- İstifadəçi şəxsiyyətinin bağlanması və giriş-token axınları
- Aktiv transferi, sifariş, mövqe və hesab API giriş
- Əməliyyat sistemləri üçün hadisə, vebhook və həyat dövrü inteqrasiyası

<h2 id="recommended-architecture">Tövsiyə olunan arxitektura</h2>

| Qat | Məsuliyyət |
| --- | --- |
| Tərəfdaş ön tərəf | Giriş nöqtəsini yerləşdirir və 6MM ticarət interfeysini yerləşdirir. |
| Tərəfdaş backend | API sirləri saxlayır, istifadəçiləri təsdiqləyir, embed tokenləri buraxır və webhook-ları işləyir. |
| 6MM ticarət infrastrukturu | Ticarət istifadəçi interfeysi, uyğunlaşdırma, risk, likvidlik, hesab vəziyyəti və ticarət həyat dövrünü idarə edir. |

<h2 id="choose-an-integration-path">İnteqrasiya yolunu seçin</h2>

| Tələb | Tövsiyə olunan yol |
| --- | --- |
| Ən sürətli veb inteqrasiyası ilə tam ticarət interfeysi | Trading Widget |
| Backend istifadəçi bağlaması, ötürmə, giriş URLvə webhook idarəetməsi | Agent SDK |
| Tam fərdi məhsul və sifariş iş axınları | REST API + WebSocket |
| Daha geniş əməliyyat sahəsində brendli mübadilə təcrübəsi | Ağ etiketli mübadilə |

Son dizayn bu yolları birləşdirə bilər. Tətbiqə başlamazdan əvvəl autentifikasiya, aktiv mülkiyyəti, məsuliyyət sərhədləri, monitorinq və istehsal dəstəyini təsdiqləyin.
