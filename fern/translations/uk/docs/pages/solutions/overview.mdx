<h2 id="how-the-solutions-connect">Як пов'язані рішення</h2>

Більшість партнерських реалізацій поєднують більше ніж одну 6MM можливість. Біржа з білою етикеткою може використовувати інституційну ліквідність, підтримку відповідності та інтеграції API . Вбудований торговий партнер може почати з Trading Widget SDK , а пізніше додати бекенд- Agent SDK потоки, вебхуки та операційні ресурси.
