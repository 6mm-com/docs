<h2 id="how-the-solutions-connect">Як пов'язані рішення</h2>

Більшість партнерських реалізацій поєднують більше ніж одну 6MM можливості. White-label біржа може використовувати інституційну ліквідність, підтримку відповідності та інтеграції API . Вбудований торговий партнер може починати з Trading Widget SDK , а пізніше додавати бекенд- Agent SDK потоки, обробку вебхуків та операційні ресурси.
