Система торгівлі Embedded API / SDK розроблена для партнерів, які вже володіють трафіком, користувачами або бізнес-робочими процесами і хочуть додати торгівлю без створення повноцінної біржі з нуля.

<span id="what-it-provides" data-sixmm-canonical-anchor="what-it-provides" aria-hidden="true"></span>

## Що вона дає

- Вбудований торговий термінал через Trading Widget SDK
- Інтеграція з партнерським бекендом через Agent SDK
- Пов'язування ідентифікації користувача та потоки токенів введення
- Доступ до передачі активів, порядку, позиції та API рахунку
- Інтеграція подій, вебхуків і життєвого циклу для операційних систем

<span id="recommended-architecture" data-sixmm-canonical-anchor="recommended-architecture" aria-hidden="true"></span>

## Рекомендована архітектура

| Шар | Відповідальність |
| --- | --- |
| Партнерський фронтенд | Хостить точку входу та вбудовує 6MM торговий інтерфейс. |
| Партнерський бекенд | Зберігає API таємниці, перевіряє користувачів, випускає embed токени та обробляє вебхуки. |
| 6MM торговельна інфраструктура | Відповідає за інтерфейс торгівлі, відповідність, ризики, ліквідність, стан рахунку та життєвий цикл торгівлі. |

## Виберіть шлях інтегрування

| Вимога | Рекомендований шлях |
| --- | --- |
| Повний торговий інтерфейс із найшвидшою вебінтеграцією | Trading Widget |
| Зв'язування бекенд-користувача, передача, URL входу та обробка вебхуків | Agent SDK |
| Повністю кастомні робочі процеси для товарів і замовлень | REST API + WebSocket |
| Досвід брендового обміну з ширшим операційним охопленням | White-label біржа |

Остаточний дизайн може поєднувати ці шляхи. Підтверджуйте автентифікацію, володіння активами, межі відповідальності, моніторинг і підтримку виробництва перед початком впровадження.
