Використовуйте цей чек-лист перед тим, як показувати 6MMторгові потоки, що базуються на виробництві, для користувачів виробництва. Він розроблений для спільного перегляду команд продуктів, інженерії, операцій, ризиків і підтримки.

<h2 id="launch-checklist">Чек-лист запуску</h2>

| Площа | Контрольний список |
| --- | --- |
| Продукт | Точки входу, тексти користувачів, підказки щодо ризику, мовне охоплення та шляхи підтримки готові. |
| Бекенд | API впроваджуються облікові дані, підписання, випуск токенів, вебхуки, повторення та ведення журналів. |
| Торгівля | Було переглянуто поведінку щодо замовлень, передачі, позиції, маржі, комісій та ліквідації. |
| Безпека | Готуються таємниці, ролі доступу, моніторинг, реагування на інциденти та журнали аудиту. |
| Експлуатація | Призначені робочі процеси підтримки, шляхи ескалації, звірка та щоденний моніторинг. |

<h2 id="recommended-sequence">Рекомендована послідовність</h2>

1. Повна перевірка «пісочниці» або внутрішнього середовища.
2. Запускати повні шляхи користувача для входу, входу, передачі, торгівлі та підтримки.
3. Підтвердити право власності на моніторинг і реагування на інциденти.
4. Затверджувати публічні копії, локалізовані ресурси та завантаження ресурсів.
5. Починайте з контрольованого вікна запуску перед широким просуванням.

<h2 id="after-launch">Після запуску</h2>

Щодня переглядати діяльність під час початкового періоду запуску. Слідкуйте за конверсіями записів, збоями з випуском токенів, помилками замовлень, якістю спреду, завершенням передачі, повтореннями webhook та заявками підтримки разом.
