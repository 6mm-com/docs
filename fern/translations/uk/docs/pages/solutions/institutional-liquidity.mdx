Рішення з інституційної ліквідності допомагають біржам, брокерам, DeFi-протоколам і кількісним командам підвищувати торговельність, глибину та надійність виконання.

<h2 id="core-capabilities">Основні можливості</h2>

- Безперервна підтримка ліквідності для підтримуваних ринків
- Покращення глибини ринку та оптимізація спреду
- Оцінка ризиків та автоматизовані операції з ліквідністю
- Підтримка волатильних ринкових умов
- Краща якість виконання для користувачів нижче рівня

<h2 id="suitable-for">Підходить для</h2>

| Тип партнера | Типова потреба |
| --- | --- |
| Біржі | Покращіть активність ринку, глибину та досвід торгівлі. |
| Брокери та платформи каналів | Пропонуйте торговельні ринки без створення команди маркетмейкерів. |
| DeFi та Web3-проєкти | Додайте глибину ринку для запуску активів або продуктів. |
| Кількісні команди | Поєднайте програмні стратегії зі структурованою торговою інфраструктурою. |

<h2 id="evaluation-metrics">Метрики оцінки</h2>

Оцінюйте ліквідність, що перевищує загальну суму. Відстежуйте спред за умовами ринку, виконуваною глибиною на кількох рівнях цін, впливом ціни за розміром замовлення, темпом виконання, коефіцієнтом відмови та часом відновлення після волатильності або перерв з'єднання.

Партнерські команди повинні погоджувати символи, вікна спостережень, розміри замовлень і пороги ескалації, які використовуються для перегляду. Послідовне вимірювання дозволяє відрізнити проблему ліквідності від проблеми валідації замовлень, рахунку чи користувацького досвіду.
