Кастомізація бренду має зробити біржу нативною для партнерського продукту, водночас зберігаючи інформацію про торгівлю чіткою, послідовною та відповідною вимогам.

<h2 id="customization-areas">Області налаштування</h2>

| Площа | Приклади |
| --- | --- |
| Візуальна ідентичність | Логотип, фавікон, акцентний колір, банери для входу та картки кампаній. |
| Розміщення учасників | Головна сторінка, сторінки активів, сторінки гаманця, центр облікових записів і ярлики для торгівлі. |
| Користувацька копія | Підказки щодо ризику, тексти для передачі, етикетки входу в торгівлю та повідомлення підтримки. |
| Пакети активів | Завантажувані партнерські ресурси для маркетингу, карток для входу та матеріалів білої етикетки. |

<h2 id="quality-checklist">Контрольний список якості</h2>

- Використовуйте правильну версію логотипу для світлого та темного фонів.
- Зробіть торгові дії візуально чіткими та легко відрізнятими від маркетингового контенту.
- Локалізувати скріншоти та завантаження окремо для китайських та англійських сторінок.
- Підтримувати підтримку та підказки щодо ризику узгоджені з реальним торговим процесом.

<h2 id="asset-and-content-checklist">Контрольний список активів і контенту</h2>

- Надавати варіанти світлого та темного логотипів з чіткими правилами мінімального розміру та безпечної зони.
- Підготувати локалізовані банери для входу, активи карток, альтернативний текст і описи для користувача.
- Підтвердити, які поверхні мають 6MM брендинг, а які — партнерські.
- Тестувати ресурси на комп'ютерних та мобільних версіях перед запуском.
- Зберігати імена файлів, версії, власників, дати затвердження та історію замін у реєстрі активів.

Використовуйте описовий альтернативний текст, який пояснює функцію кожного зображення в контексті його сторінки. Не використовуйте списки ключових слів і не повторюйте непов'язані пошукові терміни в описах зображень.
