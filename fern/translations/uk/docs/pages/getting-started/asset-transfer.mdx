У цьому посібнику пояснюється шлях фінансування для торгівлі безстроковими контрактами. На рахунку фінансування зберігаються кошти, доступні для розподілу; безстроковий рахунок зберігає контрактну маржу та розрахункові залишки. Для цього маршруту спотовий обліковий запис не потрібен.

<span id="partner-managed-deposits-and-withdrawals" data-sixmm-canonical-anchor="partner-managed-deposits-and-withdrawals" aria-hidden="true"></span>

## Фінансування через вашу платформу

Для партнерської інтеграції API / SDK дотримуйтеся процесу розподілу балансу та фінансування партнерської платформи. Для розгортання білої мітки депозити та зняття дотримуйтеся налаштованого процесу постачальника гаманця платформи; підтверджені депозити зараховуються на рахунок поповнення, а для зняття використовується цей рахунок.

Перевірте доступний спосіб фінансування на вашій платформі. Внутрішній переказ рахунку відокремлений від депозиту або зняття.

## Рахунки, які використовуються для постійної торгівлі

| Обліковий запис | призначення |
| --- | --- |
| <span style={{ whiteSpace: "nowrap" }}>Рахунок фінансування</span> | Зберігає кошти для розподілу та отримує кошти, перераховані назад з безстрокового рахунку. Використовуйте наявний баланс при підготовці переказу. |
| <span style={{ whiteSpace: "nowrap" }}>Безстроковий рахунок</span> | Зберігає кошти, які використовуються для контрактної маржі та розрахунків. Перевірте капітал рахунку, використання маржі та нереалізований прибуток і збиток перед торгівлею або переказом. |

## Підготуйте передачу

1. Підтвердьте користувача, актив і напрямок передачі.
2. Перевірте доступний баланс вихідного облікового запису та будь-які обмеження облікового запису.
3. Надішліть через підтримуваний запис передачі платформи або авторизовану інтеграцію.
4. Підтвердьте результат переказу та кінцевий баланс перед розміщенням замовлення.

## Переказ між фінансовим і безстроковим рахунками

- Перед торгівлею: перенесіть необхідний розрахунковий актив з рахунку поповнення на безстроковий рахунок.
- Після розрахунку: перерахуйте доступну для зняття суму з безстрокового рахунку назад на рахунок поповнення.
- Перекази рахунків — це внутрішні зміни балансу, а не транзакції в мережі.
- Використання маржі, відкриті замовлення, позиції та обмеження облікового запису можуть впливати на суму, доступну для переказу. Використовуйте суму та результат, показані платформою.

<span id="design-principles" data-sixmm-canonical-anchor="design-principles" aria-hidden="true"></span>

## Перевірити стан і звірити баланси

Поданий запит сам по собі не підтверджує виконання. Перевірте ідентифікатор переказу, статус, актив, суму, обліковий запис джерела та рахунок призначення. Якщо обробка не вдається або не вирішується, перевірте записи балансу та зв’яжіться зі службою підтримки платформи, перш ніж надсилати інший запит.

Не думайте, що всі баланси можна переказувати вільно або що кожен переказ є миттєвим або безкоштовним. Дотримуйтеся відображених умов платформи та остаточного результату обробки.
