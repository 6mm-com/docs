Звертаючись до служби підтримки, вказуйте інформацію нижче, якщо вона доступна.

<h2 id="required-context">Необхідний контекст</h2>

| Поле | Приклад |
| --- | --- |
| Навколишнє середовище | Виробництво або постановка |
| Уражений модуль | Trading Widget, Agent SDK, REST API, WebSocket, вебхук, система white-label |
| Часовий діапазон | UTC часовий діапазон на момент випуску |
| Ідентифікатор користувача партнера | Ідентифікатор користувача на стороні партнера, якщо це релевантно |
| 6MM ідентифікатор відображення | agentUserId, ID замовлення, запит ID або вебхук-подійний ID |
| Вплив на бізнес | Кількість постраждалих користувачів або операцій і чи триває проблема |

<h2 id="description-format">Формат опису</h2>

- Що сталося?
- Чого ти очікував?
- Чи можна відтворити?
- Що змінилося останнім часом?
- Проблема ще триває?

<h2 id="attachments">Додатки</h2>

- Відповідні журнали запитів і відповідей.
- Скріншоти або записи екранів.
- Заголовки корисного навантаження та підпису Webhook.
- Помилки консолі браузера для Trading Widget проблем.

<h2 id="copyable-template">Шаблон, який можна копіювати</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Видаляйте поля, які не є релевантними, але зберігайте UTC часовий діапазон і принаймні один пошуковий запит або бізнес-ідентифікатор, коли це можливо.

<h2 id="redact-sensitive-data">Редагувати чутливі дані</h2>

Не надсилати:

- Паролі або токени повного доступу
- API секрети, приватні ключі або повні підписи
- Сесійні файли cookie
- Повна оплата, особисті дані або інші непотрібні особисті дані

Залишайте назву поля та короткий префікс або суфікс лише тоді, коли підтримка має розрізняти очищені значення.

<h2 id="choose-the-right-channel">Виберіть правильний канал</h2>

| Діти | Наступна сторінка |
| --- | --- |
| Проблема інтеграції або виробництва | [Підтримка](/uk/resources/contact/support) |
| SDK проблема, яка ще потребує діагностики | [SDK Усунення несправностей інтеграції](/uk/sdk/security/troubleshooting) |
| Вразливість або підозра на несанкціонований доступ | [Репортаж безпеки](/uk/resources/support/security-reporting) |
| Відповідальне розкриття вразливості | [Програма нагороди за жуки](/uk/security-compliance/bug-bounty-program) |
