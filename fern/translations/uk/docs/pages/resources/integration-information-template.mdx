Використовуйте цей шаблон при підготовці нової інтеграції або переносі існуючої інтеграції у продакшн.

<span id="partner-information" data-sixmm-canonical-anchor="partner-information" aria-hidden="true"></span>

## Інформація про партнера

| Поле | Опис |
| --- | --- |
| Ім'я партнера | Юридична або назва проєкту, використана для інтеграції. |
| Тип продукту | Додаток, гаманець, брокерський портал, біржа білої етикетки, інституційна платформа чи інше. |
| Основні контакти | Ділові, технічні, операційні та екстрені контакти. |
| Регіони запуску | Країни або регіони, де інтеграція буде викритою. |

<span id="technical-information" data-sixmm-canonical-anchor="technical-information" aria-hidden="true"></span>

## Технічна інформація

| Поле | Опис |
| --- | --- |
| Фронтенд-домени | Домени, які завантажують віджет або сторінки входу. |
| Бекенд-домени | Серверні домени, що використовуються для Agent SDK або API дзвінків. |
| Webhook URL | Кінцева точка вебхука для виробництва та очікувані вимоги IP списку дозволів. |
| Обсяг інтеграції | Trading Widget, Agent SDK, REST API, WebSocket, система white-label або інтеграція ліквідності. |

<span id="operational-information" data-sixmm-canonical-anchor="operational-information" aria-hidden="true"></span>

## Оперативна інформація

- Очікувана дата запуску.
- Очікуваний трафік або активний діапазон користувачів.
- Власник години підтримки та ескалації.
- Моніторинг контактів власника та інциденту.

<span id="security-and-review-information" data-sixmm-canonical-anchor="security-and-review-information" aria-hidden="true"></span>

## Інформація про безпеку та огляд

- Метод автентифікації та область доступу API Key .
- Секретне зберігання, власник ротації та затверджені джерела IP.
- Верифікація підписів вебхуків та дизайн ідемпотентності.
- Власники логування, моніторингу, звірки, відкату та реагування на інциденти.
- Цільові ринки, тип користувача, модель зберігання та суб'єкт, відповідальний за зобов'язання, пов'язані з користувачами.

Не включайте у цей шаблон продакшн-секрети, токени повного доступу, приватні ключі чи невідредаговані дані користувачів.

Використовуйте [контрольний список запуску виробництва](/uk/resources/production-launch-checklist) для остаточного затвердження та [шаблон запиту підтримки](/uk/resources/support-request-template) для ескалації проблеми.
