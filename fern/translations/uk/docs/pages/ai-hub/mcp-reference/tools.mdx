> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Інструменти MCP — це дії, які клієнт ШІ може викликати. Кожен інструмент повинен мати чіткий опис, JSON схему, вимоги щодо дозволу, стабільний формат відповіді та модель помилки.

<h2 id="phase-1-public-market-tools">Фаза 1: інструменти публічного ринку</h2>

| Інструмент | призначення |
| --- | --- |
| 6mm_system_status | Перевірте наявність послуг і ринку. |
| 6mm_ринки | Перелік доступних ринків і основних метаданих. |
| 6mm_market_summary | Узагальніть стан ринку для одного або кількох символів. |
| 6mm_ticker | Повернути останні дані про тикер. |
| 6мм_замовлення | Глибина книги замовлень на повернення. |
| 6мм_клінів | Поверніть історичні свічки. |
| 6mm_trades | Повернути останні публічні торги. |
| 6mm_funding_rates | Повернути поточні та історичні ставки фінансування. |

<h2 id="phase-2-account-read-tools">Етап 2: інструменти читання облікових записів</h2>

| Інструмент | призначення |
| --- | --- |
| 6mm_account_summary | Підсумуйте стан рахунку. |
| 6мм_баланси | Читайте баланси. |
| 6mm_positions | Прочитайте позиції. |
| 6mm_open_orders | Читайте відкриті замовлення. |
| 6mm_order_history | Читати історичні порядки. |
| 6мм_заливки | Прочитайте заливки. |
| 6mm_funding_payments | Прочитайте фінансові платежі. |

<h2 id="phase-3-and-later-trading-tools">Фаза 3 і пізніше: торгові інструменти</h2>

| Інструмент | призначення |
| --- | --- |
| 6mm_preview_order | Перевірте замовлення, не розміщуючи його. |
| 6mm_create_order | Створіть замовлення після підтвердження та перевірки ризиків. |
| 6mm_cancel_order | Скасувати одне замовлення. |
| 6mm_cancel_all_orders | Скасувати всі відповідні відкриті замовлення. |
| 6mm_замовлення змін | Внести зміни в існуючий порядок. |
| 6mm_status_order | Читати статус для конкретного замовлення. |

<h2 id="tool-requirements">Вимоги до інструменту</h2>

Кожен інструмент повинен визначати:

- Опис моделі AI.
- Введіть схему JSON.
- Область дозволу.
- Екологічна підтримка.
- Поведінка обмеження швидкості.
- Стабільні поля відгуку.
- Коди помилок.
- Поля журналу аудиту.
