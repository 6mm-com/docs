> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Підказки MCP — це багаторазово використовувані робочі процеси, надані сервером MCP. Вони допомагають користувачам задавати послідовні запитання та допомагають клієнтам ШІ використовувати правильні інструменти.

<h2 id="recommended-prompts">Рекомендовані підказки</h2>

| Підкажіть | призначення |
| --- | --- |
| огляд ринку | Узагальніть стан ринку за вибраними символами. |
| аналіз_мікроструктури_ринку | Аналізуйте спред, глибину, останні угоди та умови ліквідності. |
| оцінка_ризику_портфеля | Перегляньте позиції, ризик ризику, маржу та ліквідацію. |
| посада_управління | Допоможіть користувачам зрозуміти стан позиції та можливі дії. |
| ліквідація_захист | Визначте ризик ліквідації та варіанти зменшення ризику. |
| funding_rate_opportunity | Порівняйте ставки фінансування та можливі можливості. |
| create_optimal_order | Плануйте параметри замовлення перед попереднім переглядом. |
| стратегія_хеджування | Вивчіть варіанти хеджування для наявних ризиків. |
| торгова_консультація | Зробіть структурований торговий аналіз без виконання ордерів. |

<h2 id="prompt-safety-rules">Підказка правил безпеки</h2>

- Не сприймайте швидкий вихід як фінансову пораду.
- Не використовуйте торгові інструменти, якщо користувач явно не попросить.
- Використовуйте попередній перегляд перед створенням.
- Поясніть припущення та джерела даних.
- Віддавайте перевагу прикладам testnet у публічній документації.
