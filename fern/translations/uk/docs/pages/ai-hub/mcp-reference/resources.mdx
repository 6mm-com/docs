> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Ресурси MCP — це контекст лише для читання, який клієнти ШІ можуть перевірити перед викликом інструментів.

Ресурси зменшують галюцинації, надаючи моделі стабільну, структуровану інформацію про 6MM.

<h2 id="recommended-resource-uris">Рекомендовані URI ресурсів</h2>

| Ресурс | призначення |
| --- | --- |
| 6mm://system/config | Конфігурація середовища та можливостей. |
| 6mm://system/status | Поточна система та стан ринку. |
| 6mm://ринки | Доступні ринки. |
| 6mm://ринок/{symbol} | Специфікації контракту та метадані на рівні ринку. |
| 6mm://плати | Правила оплати. |
| 6mm://ризик/правила | Короткий опис правил торгівлі та ризику. |
| 6 мм://ризик/маржа | Контекст маржі та ліквідації. |
| 6mm://фінансування/правила | Норми фінансування. |
| 6mm://api/docs | API резюме або посилання. |

<h2 id="resource-design-rules">Правила оформлення ресурсу</h2>

- Зберігайте ресурси лише для читання.
- Використовуйте стабільні схеми.
- Додайте мітки часу та назви середовища.
- Уникайте розкриття секретів.
- Віддавайте перевагу стислим структурованим даним над довгою прозою.
- Посилання на канонічну документацію, якщо деталі задовгі.
