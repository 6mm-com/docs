> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


6MM Agentic AI Hub — це AI-власний інтерфейс для 6MM ринкових даних, робочих процесів облікових записів і майбутніх контрольованих торгових операцій.

Замість перемикання між інформаційними панелями, API документами та сценаріями користувачі можуть попросити клієнт ШІ зробити запит 6MM, пояснити ринкові умови, переглянути ризики облікового запису або підготувати попередній перегляд замовлення. Клієнт AI не замінює модель безпеки 6MM API; він викликає структуровані 6MM інструменти через CLI, MCP або шаблони робочих процесів.

<h2 id="what-you-can-ask-an-ai-client">Що ви можете запитати у клієнта ШІ</h2>

Використовуйте AI Hub, коли ви хочете поставити такі запитання, як:

```text
Show me the BTC-USDT-PERP order book and explain current liquidity.
```

```text
Compare BTC and ETH funding rates over the last 24 hours.
```

```text
Check my testnet positions and explain liquidation risk. Do not place orders.
```

```text
Preview a small BTC long order and explain fees, margin impact, and risk checks.
```

<h2 id="why-ai-agents-need-a-dedicated-access-layer">Навіщо агентам ШІ потрібен виділений рівень доступу</h2>

Агенти ШІ працюють найкраще, коли мають структуровані інструменти замість необроблених веб-сторінок або неструктурованого скопійованого тексту. AI Hub надає їм:

| Вимога | 6MM підхід |
| --- | --- |
| Контекст живого ринку | Інструменти та ресурси загальнодоступних ринкових даних для символів, книг замовлень, угод, фінансування, комісій і правил. |
| Чіткі дозволи | Окремі публічні дані, читання облікового запису, попередній перегляд і контрольована торгівля. |
| Безпечніше виконання | Попередній перегляд потоку першого замовлення, явне підтвердження, ідемпотентність, обмеження та журнали аудиту. |
| Клієнтська гнучкість | Розміщені MCP, локальні MCP, CLI, віддалені MCP навички та навички агента для різних середовищ ШІ. |

<h2 id="setup-paths">Налаштування шляхів</h2>

| шлях | Найкраще для | Користувач повинен знати |
| --- | --- | --- |
| Розміщено MCP | Швидкий публічний доступ до ринкових даних | Немає інсталяції та ключа користувача API для загальнодоступних даних. Торгівля не є метою першого випуску. |
| Місцевий MCP | Клієнти ШІ, яким потрібен приватний контекст облікового запису | Сервер MCP працює локально, а облікові дані залишаються на комп’ютері користувача. |
| CLI | Агенти кодування, сценарії та користувачі терміналів | Видає зручні для агента вихідні дані команд і може використовуватися без сервера MCP. |
| Віддалений MCP | Інституції та команди, яким потрібна власна кінцева точка | Користувач або установа контролює хостинг, облікові дані, доступ до мережі та журнали. |
| Агентські навички | Повторювані робочі процеси | Навички направляють ШІ через кроки аналізу та ризиків за допомогою затверджених інструментів. |

<h2 id="what-is-available-first">Те, що доступно в першу чергу</h2>

Центр штучного інтелекту має початися з загальнодоступних ринкових даних і ресурсів торгових правил:

- Ринки.
- Тікери.
- Книги замовлень.
- Торги.
- Клайнс.
- Норми фінансування.
- Статус системи.
- Комісії, специфікації контрактів, правила маржі та ресурси щодо правил ризику.

Доступ до приватного рахунку та торгівля мають бути поетапними:

- Інструменти читання облікових записів вимагають явних облікових даних лише для читання.
- Попередній перегляд замовлення має відбуватися перед створенням справжнього замовлення.
- Для контрольованої торгівлі потрібні області дозволів, перевірка ризиків на стороні служби, підтвердження користувача, ідемпотентність і журнали аудиту.
