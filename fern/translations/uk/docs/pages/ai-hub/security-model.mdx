> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Доступ до торгівлі за допомогою ШІ має бути безпечнішим, ніж звичайна автоматизація, оскільки наміри користувача виражаються природною мовою.

## Необхідні діапазони дозволів

| Область застосування | Дозволяє |
| --- | --- |
| ринок: читати | Публічні ринкові дані та ресурси правил. |
| обліковий запис: читати | Баланси, позиції, відкриті замовлення, заповнення та підсумки рахунків. |
| замовлення: написати | Створення, зміна та скасування замовлення. |

<span id="default-safety-posture" data-sixmm-canonical-anchor="default-safety-posture" aria-hidden="true"></span>

## Стандартна безпечна поза

- За замовчуванням лише для читання.
- За замовчуванням тестова мережа.
- Не розкривайте зняття чи перекази через інструменти ШІ.
- Вимагати попереднього перегляду перед створенням.
- Вимагати явного підтвердження перед торгівлею в основній мережі.
- Використовуйте ключі ідемпотентності для торгових дій.
- Застосуйте максимальні умовні обмеження та ліміти кредитного плеча.
- Зберігайте повні журнали аудиту.

<span id="controlled-trading-flow" data-sixmm-canonical-anchor="controlled-trading-flow" aria-hidden="true"></span>

## Контрольований торговий потік

```text
User natural language intent
  -> AI maps intent to tool parameters
  -> 6mm_preview_order validates the order
  -> service returns risk checks and margin impact
  -> user explicitly confirms
  -> 6mm_create_order submits the order
  -> audit log records the full flow
```

<span id="prompt-injection-protection" data-sixmm-canonical-anchor="prompt-injection-protection" aria-hidden="true"></span>

## Швидкий захист від ін'єкції

Клієнти штучного інтелекту та MCP сервери повинні розглядати зовнішній вміст як ненадійний. Сторінки ринку, скопійований текст, документи та веб-контент не повинні перекривати дозволи інструментів, правила підтвердження чи обмеження торгівлі.
