> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


6MM CLI — це точка входу в командний рядок для користувачів, сценаріїв і агентів ШІ, які можуть виконувати команди оболонки.

Використовуйте CLI, якщо середовище ШІ може запускати команди терміналу безпосередньо. Це часто найпростіший шлях для агентів кодування, оскільки окремий MCP сервер не потрібен. CLI за умовчанням має повертати стабільний JSON, щоб агенти могли аналізувати результати, не покладаючись на форматування терміналу.

<span id="what-the-cli-is-good-for" data-sixmm-canonical-anchor="what-the-cli-is-good-for" aria-hidden="true"></span>

## Для чого корисний CLI.

- Швидкі запити ринкових даних із терміналу.
- Керований агентами аналіз у Codex, Claude Code, Gemini CLI або подібних інструментах.
- CI або заплановані сценарії, які потребують даних 6MM.
- Перевірки читання облікового запису, коли налаштовано локальні облікові дані.
- Потоки попереднього перегляду замовлення, коли агент готує параметри, але не розміщує замовлення.

<span id="example-commands" data-sixmm-canonical-anchor="example-commands" aria-hidden="true"></span>

## Приклади команд

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

<span id="output-modes" data-sixmm-canonical-anchor="output-modes" aria-hidden="true"></span>

## Режими виведення

| Режим | Випадок використання |
| --- | --- |
| JSON | За замовчуванням для агентів ШІ, сценаріїв і автоматизації. |
| Таблиця | Зрозумілий огляд терміналу. |
| Сирий | Тести налагодження та інтеграції. |

<span id="recommended-safety-defaults" data-sixmm-canonical-anchor="recommended-safety-defaults" aria-hidden="true"></span>

## Рекомендовані стандартні параметри безпеки

- Середовищем за замовчуванням є testnet.
- Вихід за замовчуванням JSON.
- Торгові команди вимагають явної згоди.
- Створення замовлення в мережі Mainnet вимагає підтвердження.
- Перед створенням доступний режим попереднього перегляду.
- Помилки включають стабільні коди та чіткі повідомлення.

<span id="agent-usage" data-sixmm-canonical-anchor="agent-usage" aria-hidden="true"></span>

## Використання агента

Агенти штучного інтелекту повинні віддавати перевагу командам лише для читання, якщо користувач явно не запитує попередній перегляд або торгові дії.

Приклад підказки:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
