> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Віддалена MCP призначена для користувачів або установ, яким потрібна довготривала кінцева точка MCP під їхнім власним контролем.

На відміну від розміщеного MCP, віддаленим MCP не керує 6MM для користувача. 6MM містить код, зображення, шаблони та документацію; користувач контролює хостинг і облікові дані.

<h2 id="architecture">Архітектура</h2>

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<h2 id="deployment-targets">Цілі розгортання</h2>

- Docker або Docker Compose.
- VPS зі зворотним проксі.
- Залізниця.
- Рендер.
- Fly.io.
- AWS ECS або Лямбда.
- Внутрішній Kubernetes.

<h2 id="required-files">Необхідні файли</h2>

- Dockerfile.
- docker-compose.yml.
- .env.template.
- HTTP режим транспортування.
- /mcp кінцева точка.
- /кінцева точка здоров'я.
- Зворотний проксі та TLS примітки.

<h2 id="credential-model">Модель облікових даних</h2>

Облікові дані слід зберігати в середовищі, керованому користувачем, а не в підказці клієнта ШІ. Для розгортань, керованих установами, обмежте доступ до затверджених клієнтів і мереж.

<h2 id="recommended-first-release">Рекомендований перший випуск</h2>

Почніть із загальнодоступних ринкових даних. Додайте обліковий запис лише для читання після автентифікації, визначення області ключа, журналів і контролю доступу. Торгівля має залишатися вимкненою, доки не будуть виконані вимоги до контрольованої торгівлі.
