> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Розміщений MCP — це найпростіший спосіб розпочати роботу з 6MM AI Hub.

Підключіть клієнт штучного інтелекту до 6MM кінцевої точки MCP і ставте запитання щодо загальнодоступних ринкових даних. Немає локального сервера, який потрібно встановлювати, немає хмарного розгортання, яке потрібно підтримувати, і немає ключа користувача API, потрібного для публічних даних.

<span id="what-you-can-do" data-sixmm-canonical-anchor="what-you-can-do" aria-hidden="true"></span>

## Що ви можете зробити

- Запитуйте поточні та історичні ринкові дані.
- Перегляньте доступні безстрокові ринки.
- Перевірте глибину книги ордерів і останні угоди.
- Порівняйте ставки фінансування.
- Прочитайте контекст комісій, контрактів, маржі та правил ризику.

Розміщений MCP найкраще підходить для досліджень, вивчення продукту та аналізу публічного ринку. Це не правильна перша настройка для доступу до приватного облікового запису або торгівлі.

<span id="endpoint" data-sixmm-canonical-anchor="endpoint" aria-hidden="true"></span>

## Кінцева точка

```text
https://mcp.6mm.com/mcp
```

Перевірка стану здоров'я:

```text
https://mcp.6mm.com/health
```

<span id="recommended-first-release-scope" data-sixmm-canonical-anchor="recommended-first-release-scope" aria-hidden="true"></span>

## Рекомендований обсяг першого випуску

Розміщений MCP має надавати лише загальнодоступну інформацію та інформацію лише для читання в першому випуску:

- Ринки.
- Тікери.
- Книги замовлень.
- Останні торги.
- Клайнс.
- Норми фінансування.
- Статус системи.
- Комісії за торгівлю.
- Технічні умови договору.
- Ресурси правил ризику та маржі.

<span id="not-supported-in-the-first-release" data-sixmm-canonical-anchor="not-supported-in-the-first-release" aria-hidden="true"></span>

## Не підтримується в першому випуску

Розміщений MCP не повинен бути першим місцем для розкриття:

- Залишки на рахунках.
- посади.
- Відкриті замовлення.
- Створення замовлення.
- Скасування замовлення.
- Перекази або зняття коштів.
- Користувач API сховище ключів.

<span id="why-public-data-first" data-sixmm-canonical-anchor="why-public-data-first" aria-hidden="true"></span>

## Чому насамперед публічні дані

Розміщений MCP керується 6MM і доступ до нього здійснюється через мережу. Це зручно, але воно не повинно ставати місцем за замовчуванням, де користувачі надсилають приватні ключі API. Конфіденційні облікові записи та робочі процеси для торгівлі мають починатися з локального MCP, CLI або керованого користувачем віддаленого MCP.

## Експлуатаційні вимоги

- TLS на всіх кінцевих точках.
- Обмеження швидкості запиту.
- Захист від зловживань.
- Структуровані журнали та метрики.
- Перевірки стану здоров'я.
- Чіткі описи та схеми інструментів.
- Стабільні відповіді на помилки для клієнтів ШІ.
