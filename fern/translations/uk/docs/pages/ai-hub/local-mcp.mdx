> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Локальний MCP — це рекомендоване налаштування, якщо клієнту штучного інтелекту потрібен контекст приватного облікового запису або майбутні контрольовані торгові інструменти.

Сервер MCP працює на комп’ютері користувача. Клієнт AI викликає локальні інструменти 6MM, а локальний сервер спілкується з 6MM APIs за допомогою облікових даних, налаштованих користувачем.

<h2 id="what-your-ai-client-can-do">Що може зробити ваш клієнт ШІ</h2>

За допомогою локального MCP клієнт ШІ може керовано використовувати інструменти 6MM:

- Отримайте поточні та історичні ринкові дані.
- Перечитування балансів рахунків, позицій, відкритих замовлень, заповнень і записів фінансування, коли ввімкнено облікові дані лише для читання.
- Поясніть ризик портфеля, використання маржі та ризик ліквідації.
- Попередній перегляд замовлень перед розміщенням справжнього замовлення.
- На наступних етапах контрольованої торгівлі створюйте або скасовуйте замовлення лише після чіткого дозволу та перевірки ризиків.

Використовуйте локальний MCP, коли облікові дані повинні залишатися на комп’ютері користувача.

<h2 id="architecture">Архітектура</h2>

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

<h2 id="example-configuration">Приклад конфігурації</h2>

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

<h2 id="recommended-permission-tiers">Рекомендовані рівні дозволів</h2>

| Рівень | Інструменти | Примітки |
| --- | --- | --- |
| Публічні дані | Ринки, тикер, ордербук, кліни, угоди, фінансування | Немає доступу до приватного облікового запису. |
| Обліковий запис прочитано | Баланси, позиції, відкриті ордери, заповнення | Потрібна область ключа API лише для читання. |
| Попередній перегляд торгівлі | Попередній перегляд замовлення, вплив маржі, оцінка комісії | Не розміщує замовлення. |
| Контрольована торгівля | Створювати, скасовувати, змінювати замовлення | Потрібен явний дозвіл, підтвердження та контроль ризиків. |

<h2 id="first-setup-checklist">Перший контрольний список налаштування</h2>

1. Встановіть пакет MCP.
2. Створіть або налаштуйте доступний лише для читання ключ API.
3. Почати в testnet.
4. Додайте сервер MCP до конфігурації клієнта ШІ.
5. Попросіть клієнта скласти список доступних 6MM інструментів.
6. Виконайте запит публічних ринкових даних.
7. Лише тоді додайте облікові дані для читання облікового запису, якщо це необхідно.

<h2 id="security-notes">Примітки безпеки</h2>

Локальний MCP має за замовчуванням лише для читання та тестової мережі. Торгові інструменти повинні вимагати попереднього перегляду, підтвердження користувача, ключів ідемпотентності, умовних лімітів і перевірки ризиків на стороні сервісу.
