> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Виберіть налаштування на основі двох запитань:

1. Який клієнт AI ви хочете використовувати?
2. Вам потрібні лише публічні дані, доступ до приватного облікового запису чи торгові робочі процеси?

Якщо ви не впевнені, почніть із розміщеного MCP для публічних даних або локального MCP для робочих процесів приватного облікового запису.

<h2 id="pick-by-setup-path">Виберіть шлях налаштування</h2>

| Налаштування | монтаж | API розташування ключа | Найкращий початковий приціл | Обліковий запис і сфера торгівлі |
| --- | --- | --- | --- | --- |
| Розміщено MCP | Жодного | Немає користувача API ключа для публічних даних | Дані публічного ринку | Не рекомендується для першого випуску |
| Місцевий MCP | Користувач встановлює пакет | Машина користувача | Загальнодоступні дані та читання облікових записів | Рекомендований шлях для майбутньої торгівлі |
| CLI | Користувач встановлює пакет | Машина користувача | Публічні дані та скрипти | Корисно для попереднього перегляду та автоматизації |
| Віддалений MCP | Користувач розгортає сервер | Хмара користувача або хмара установи | Публічні дані або читання облікового запису | Можливо, коли користувач керує розгортанням |
| Навички | Документи або шаблони, які можна встановити | Залежить від основних інструментів | Робочі процеси аналізу | Необхідно дотримуватися дозволів інструменту |

<h2 id="security-rule-of-thumb">Емпіричне правило безпеки</h2>

Використовуйте налаштування з найменшим ризиком, які підтримують це завдання:

- Публічні ринкові дані: достатньо розміщених MCP.
- Дані приватного облікового запису: локальний MCP або керований користувачем віддалений MCP.
- Попередній перегляд торгів: локальний MCP або CLI, бажано спочатку тестова мережа.
- Реальна торгівля: лише після явного дозволу, попереднього перегляду, підтвердження, лімітів і журналів аудиту.

<h2 id="next-step">Наступний крок</h2>

Вибравши шлях, відкрийте відповідний посібник і виконайте одну підказку підтвердження, перш ніж додавати конфіденційні облікові дані.
