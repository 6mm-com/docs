> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


VS Code та GitHub Copilot корисні для впровадження SDK, підписання API та інтеграції серверної частини партнера.

| Шаблони командного робочого процесу | Агентські навички |

## Примітки безпеки

Не розміщуйте секрети API у коді зовнішнього інтерфейсу, налаштуваннях розширення, призначених для керування джерелами, або спільних файлах робочої області.
