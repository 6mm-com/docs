> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Код Claude CLI корисний, коли агент може запускати команди терміналу, перевіряти вихідні дані JSON і оновлювати код інтеграції.

<h2 id="recommended-setup">Рекомендоване налаштування</h2>

| потреба | Налаштування |
| --- | --- |
| Швидкі перевірки ринку | 6MM CLI |
| Контекст локального облікового запису | Місцевий MCP |
| Робочий процес впровадження, що повторюється | Агентські навички |

<h2 id="example-tasks">Зразкові завдання</h2>

```text
Use 6MM CLI to list available perpetual markets and return JSON.
```

```text
Use 6MM to inspect webhook event examples and generate an idempotent handler plan.
```

```text
Use 6MM testnet data to validate this Trading Widget integration. Do not place live orders.
```

<h2 id="best-practice">Найкраща практика</h2>

Надавайте перевагу виводу JSON для робочих процесів агента. Його легше аналізувати, порівнювати та включати в журнали впровадження.
