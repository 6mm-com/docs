> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


ChatGPT Desktop — це знайома точка входу для користувачів, які хочуть ставити ринкові запитання природною мовою.

Використовуйте цей шлях, коли користувачеві потрібен діалоговий інтерфейс для загальнодоступних ринкових даних, підсумків облікового запису, пояснень позиції та контексту торгових правил.

<h2 id="recommended-setup">Рекомендоване налаштування</h2>

| потреба | Налаштування |
| --- | --- |
| Дані публічного ринку | Розміщено MCP |
| Контекст приватного облікового запису | Місцевий MCP |
| Повторювані підказки аналізу | Агентські навички |
| Робочі процеси на основі терміналу | 6MM CLI |

<h2 id="what-users-can-ask">Що користувачі можуть запитати</h2>

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<h2 id="safety-defaults">Стандартні параметри безпеки</h2>

- Почніть із загальнодоступних ринкових даних.
- Використовуйте локальний MCP, коли потрібні облікові дані облікового запису.
- Зберігайте особисті ключі API на машині користувача.
- Вимагати попереднього перегляду та явного підтвердження перед будь-якими майбутніми торговельними діями.
