> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Claude Desktop добре підходить для MCP-досліджень, перегляду облікових записів і операційного аналізу.

<h2 id="recommended-setup">Рекомендоване налаштування</h2>

| потреба | Налаштування |
| --- | --- |
| Дослідження публічного ринку | Розміщено MCP |
| Аналіз облікових записів | Місцевий MCP |
| Внутрішня кінцева точка команди | Віддалений MCP |

<h2 id="example-prompts">Приклад підказує</h2>

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<h2 id="notes">Примітки</h2>

Локальний MCP є кращим, якщо залучаються дані приватного облікового запису, оскільки сервер MCP працює на комп’ютері користувача, і облікові дані не потрібно надсилати до кінцевої точки AI, розміщеної на 6MM.
