> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


Gemini CLI найкраще працює з виводом командного рядка, який можна перевірити, узагальнити та передати в наступні завдання.

<h2 id="recommended-setup">Рекомендоване налаштування</h2>

| потреба | Налаштування |
| --- | --- |
| Державні ринкові перевірки | 6MM CLI |
| Сценарне дослідження | 6MM CLI |
| Контекст приватного облікового запису | Локальний MCP або CLI з локальними обліковими даними |

<h2 id="example-prompts">Приклад підказує</h2>

```text
Use 6MM CLI to fetch market metadata and summarize tradable pairs.
```

```text
Use 6MM to compare fee and margin rules for two symbols.
```

<h2 id="output-format">Вихідний формат</h2>

Віддавайте перевагу структурованому виводу, такому як JSON або таблиці Markdown, щоб клієнт ШІ міг міркувати над результатом без втрати точності.
