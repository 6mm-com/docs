> **Заплановано — ще не запущено**
> AI Hub є запланованою функцією. Можливості, кінцеві точки, команди та конфігурації клієнта на цій сторінці описують запропонований дизайн і наразі недоступні. Остаточна доступність та інструкції з налаштування будуть оголошені під час запуску.


AI Hub слід випускати поетапно, щоб користувачі отримували цінність завчасно, а чутливі можливості торгівлі залишалися захищеними.

## Етап 1: Доступ ШІ до публічного ринку

Мета: дозволити будь-якому підтримуваному клієнту ШІ читати офіційні 6MM ринкові дані.

Результати роботи:

- Спільний SDK / API клієнт.
- CLI команди публічного ринку.
- Місцеві MCP публічні інструменти ринку.
- Розміщені MCP публічні інструменти ринку.
- Ресурси для ринків, комісій, правил ризику та статусу системи.
- Керівництво по установці клієнта.

Не включено:

- Запити щодо облікового запису.
- Справжня торгівля.
- Хостинг ключів API.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Етап 2: читання облікового запису

Мета: дозволити користувачам безпечно перевіряти контекст свого облікового запису.

Результати роботи:

- Область ключа API лише для читання.
- Резюме облікового запису.
- Залишки.
- посади.
- Відкриті замовлення.
- Наповнює.
- Фінансування платежів.
- Підказка про портфельний ризик.

Бажане розгортання:

- Місцевий MCP.
- CLI.
- Віддалений MCP власний хостинг.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Етап 3: попередній перегляд торгівлі

Мета: дозволити ШІ генерувати замовлення, не виконуючи їх.

Результати роботи:

- `preview_order`.
- Перевірки ризиків.
- Вплив маржі.
- Оцінка гонорару.
- Ліквідаційний вплив.
- Підказка щодо планування виконання.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Етап 4: контрольована торгівля

Мета: підтримувати реальну торгівлю лише за допомогою міцних огорож.

Результати роботи:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- ідемпотентність.
- максимальні умовні обмеження.
- явне підтвердження.
- журнали аудиту.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Фаза 5: Агентські навички

Мета: створити спільний аналіз ринку та робочі процеси ризиків.

Результати роботи:

- Навички аналітика ринку.
- Навички портфельного ризику.
- Навички фінансування досліджень.
- Навичка захисту від ліквідації.
- Навички планування виконання.
- Бібліотека прикладів завдань.
