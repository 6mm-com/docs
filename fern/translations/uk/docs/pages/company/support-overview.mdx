6MM підтримка призначена для авторизованих партнерів, активних інтеграцій та виробничих операцій. Підтримка кінцевих користувачів залишається відповідальністю партнерської платформи, якщо це не було окремо погоджено.

<h2 id="choose-the-right-path">Обирайте правильний шлях</h2>

| Ситуація | Рекомендований шлях | Включайте |
| --- | --- | --- |
| Нове партнерство або оцінка рішення | Шлях адаптації партнерів | Тип продукту, цільовий регіон, терміни запуску, очікувана модель інтеграції. |
| SDK, API, вебхук або питання про середовище | Шлях технічної підтримки | Кінцева точка, SDK версія, ID запиту, кроки відтворення, журнали. |
| Інциденти з виробництвом або погіршення торгового потоку | Шлях ескалації інциденту | Обсяг впливу, час початку, потерпілі користувачі, ідентифікатори замовлень, поточні заходи пом'якшення. |
| Зміна матеріалу для активу, копіювання або запуску | Шлях підтримки операцій | Сторінка, мова, запитана зміна, дата запуску, власник затвердження. |
| Вразливість або підозра на зловживання | Шлях звітування про безпеку | Технічні деталі, уражений кінцевий пункт, докази, терміновість, чи є проблема активною. |

<h2 id="severity-guide">Гід з тяжкості</h2>

| Тяжкість | Приклад |
| --- | --- |
| Критично | Виробнича торгівля, автентифікація, випуск токенів або потоки, пов'язані з фондами, недоступні. |
| Високий | Основний партнерський потік деградує, але існує обхідний шлях. |
| Звичайна | Питання інтеграції, запит на конфігурацію, питання з документацією або підтримка запланованого запуску. |

<h2 id="before-contacting-support">Перед зверненням до служби підтримки</h2>

- Підтвердити уражену зону продукту та середовище.
- Збирати ідентифікатори запитів, ідентифікатори замовлень, часові позначки, ідентифікатори відображення користувачів, вебхуки події та журнали.
- Використовуйте шаблон запиту на підтримку для виробничих проблем.
