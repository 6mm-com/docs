Якщо не вказано інше, наступні кінцеві точки можуть використовувати JWT або API Key підписи.

<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Інформація про користувача

```http
GET /v1/private/user/info
```

Поля відповіді:

| Поле                  | Тип   | Опис      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | Зовнішній ідентифікатор користувача |
| `userInfo.username`    | string | Ім'я користувача         |
| `userInfo.agentId`     | int64  | Ідентифікатор агента         |
| `userInfo.vipLevel`    | int64  | VIP рівень        |
| `userInfo.lastLoginAt` | int64  | Останній час входу  |
| `userInfo.lastLoginIp` | string | Останній IP входу    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Користувацькі ресурси

```http
GET /v1/private/user/asset
```

Поля відповіді:

| Поле                     | Тип   | Опис                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | Зовнішній ідентифікатор користувача                |
| `userAsset.assetType`     | string | Тип активу                      |
| `userAsset.walletBalance` | string | Баланс гаманця                  |
| `userAsset.frozenMargin`  | string | Маржа заморожена через очікувані ордери |
| `userAsset.usedMargin`    | string | Маржа за позиціями        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Створіть listenKey

```http
POST /v1/private/user/listen-key
```

Створює ключ автентифікації для приватних WebSocket потоків.

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Оновити listenKey

```http
PUT /v1/private/user/listen-key
```

Розширює listenKey валідність.

<span data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Close listenKey

```http
DELETE /v1/private/user/listen-key
```

Закриває заданий listenKey.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Журнали змін облікового запису

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Параметри запиту:

| Параметр    | Тип   | Обов'язкове | Опис                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | Ні       | Тип активу, наприклад `USDT`   |
| `changeType` | string | Ні       | Тип зміни                  |
| `startTime`  | int64  | Ні       | Час початку                   |
| `endTime`    | int64  | Ні       | Кінець часу                     |
| `page`       | int32  | Ні       | Номер сторінки, стандартний `1`     |
| `pageSize`   | int32  | Ні       | Пункти на сторінку, стандартні `20` |

Поля відповіді:

| Поле                        | Тип   | Опис                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Тип активу                   |
| `list[].amount`              | string | Змінена сума               |
| `list[].walletBalanceBefore` | string | Баланс гаманця до зміни |
| `list[].walletBalanceAfter`  | string | Баланс гаманця після зміни  |
| `list[].frozenBalanceBefore` | string | Заморожений баланс перед змінами |
| `list[].frozenBalanceAfter`  | string | Заморожений баланс після зміни  |
| `list[].changeType`          | string | Тип зміни                  |
| `list[].referenceId`         | string | Пов'язаний бізнес-ідентифікатор          |
| `list[].createdAt`           | int64  | Час створення                |
| `total`                      | int64  | Загальна кількість                  |

## Статистика обсягів за 30 днів

```http
GET /v1/private/user/volume-stats
```

Поля відповіді:

| Поле         | Тип   | Опис                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Сукупний обсяг торгівлі за останні 30 днів |
| `feeTotal30d` | string | Накопичені комісії за останні 30 днів           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## Історія балансу

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Параметри запиту:

| Параметр | Тип   | Обов'язкове | Опис                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Так      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | Ні       | Кількість повернених товарів, за замовчуванням `30` |

Поля відповіді:

| Поле             | Тип   | Опис                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Дата агрегації            |
| `items[].balance` | string | Баланс гаманця              |
| `items[].pnl`     | string | Реалізований PnL за цей період |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Огляд торгівлі

```http
GET /v1/private/user/trade-overview?type=1M
```

Параметри запиту:

| Параметр | Тип   | Обов'язкове | Опис                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Так      | Діапазон трендів: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Поля відповіді:

| Поле                | Тип   | Опис                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | Сьогоднішній реалізований PnL                                                 |
| `todayVolume`        | string | Сьогоднішній обсяг торгів за контрактами                                      |
| `totalVolume`        | string | Кумулятивний обсяг торгів за контрактами                                   |
| `totalPnl`           | string | Кумулятивний реалізований PnL                                              |
| `maxDrawdown30d`     | string | Максимальна сума погашення за останні 30 днів                        |
| `maxDrawdown30dRate` | string | Максимальний темп пониження за останні 30 днів, десятковий від `0` до `1` |
| `transferIn`         | string | Кумулятивні переведені кошти                                      |
| `transferOut`        | string | Кумулятивні переведені кошти                                     |
| `items[]`            | array  | Дані про тенденції активів                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Огляд активів Огляд

```http
GET /v1/private/user/asset/overview/summary
```

Поля відповідей такі ж, як і поля огляду торгівлі, за винятком `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Огляд тенденції активів

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Параметри запиту:

| Параметр | Тип   | Обов'язкове | Опис                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Так      | Діапазон трендів: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Поля відповіді:

| Поле                  | Тип   | Опис                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Час знімка                   |
| `items[].balance`      | string | Баланс поточного рахунку         |
| `items[].pnl`          | string | PnL за поточний період      |
| `items[].pnlRate`      | string | Ставка PnL за поточний період |
| `items[].totalPnl`     | string | Кумулятивний PnL                  |
