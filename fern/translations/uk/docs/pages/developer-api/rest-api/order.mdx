> **Примітка**
>
> Кінцеві точки замовлення потребують дозволу на торгівлю.

<h2 id="place-order">Зробити замовлення</h2>

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Параметри запиту:**

| Параметр       | Тип   | Обов'язкове               | Опис                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Так                    | Символ                                                                                                                        |
| `type`          | string | Так                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Так                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Ні                     | `BOTH` / `LONG` / `SHORT`, за замовчуванням `BOTH`                                                                                     |
| `price`         | string | Умовно обов'язковий | Потрібні для лімітних ордерів                                                                                                     |
| `quantity`      | string | Умовно обов'язковий | Кількість. Можна опустити, коли `closePosition=true`                                                                            |
| `timeInForce`   | string | Ні                     | `GTC` / `IOC` / `FOK`, за замовчуванням `GTC`                                                                                          |
| `reduceOnly`    | bool   | Ні                     | Лише зменшення, стандартне `false`                                                                                                  |
| `makerOnly`     | bool   | Ні                     | Тільки для виробника, стандартний `false`                                                                                                   |
| `closePosition` | bool   | Ні                     | Закрити всю позицію за замовчуванням `false`                                                                                    |
| `clientOrderId` | string | Ні                     | Ідентифікатор замовлення, визначений клієнтом                                                                                                       |
| `placeType`     | string | Ні                     | Маркер типу розміщення замовлення                                                                                                   |
| `priceType`     | int32  | Ні                     | BBO тип ціни: `0` вказана ціна, `1` опонента ціна 1, `2` опонент ціна 5, `3` ціна на той самий бік 1, `4` ціна з того ж боку 5 |

**Приклад запиту:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Поля відповіді:**

| Поле           | Тип   | Опис             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | Ідентифікатор порядку сервера         |
| `clientOrderId` | string | Ідентифікатор замовлення, визначений клієнтом |
| `status`        | string | Статус ордену            |
| `timestamp`     | int64  | Часова мітка               |

<h2 id="batch-place-orders">Замовлення на розміщення пакетів</h2>

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Запитуйте тіло:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Поля відповіді:**

| Поле          | Тип  | Опис                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Кількість успішних замовлень |
| `failedCount`  | int32 | Кількість невдалих замовлень     |
| `results[]`    | array | Результат для кожного порядку       |

<h2 id="place-condition-order">Порядок умов розміщення</h2>

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Параметри запиту:**

| Параметр       | Тип   | Обов'язкове               | Опис                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Так                    | Символ                                                                                      |
| `type`          | string | Так                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Так                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Ні                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Умовно обов'язковий | Обов'язково для `STOP_LIMIT` / `TAKE_PROFIT_LIMIT`                                             |
| `quantity`      | string | Умовно обов'язковий | Кількість. Можна опустити, коли `closePosition=true`                                          |
| `timeInForce`   | string | Ні                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Ні                     | Лише редукція                                                                                 |
| `clientOrderId` | string | Ні                     | Ідентифікатор замовлення, визначений клієнтом                                                                     |
| `stopPrice`     | string | Умовно обов'язковий | Тригерна ціна                                                                               |
| `workingType`   | string | Ні                     | `MARK_PRICE` / `CONTRACT_PRICE`, за замовчуванням `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Ні                     | Чи увімкнено захист цін                                                         |
| `activatePrice` | string | Умовно обов'язковий | Ціна активації трейлінгового замовлення                                                             |
| `callbackRate`  | string | Умовно обов'язковий | Частота зворотного виклику за наказом                                                                |
| `closePosition` | bool   | Ні                     | Закрийте всю позицію                                                                   |

**Поля відповіді:**

| Поле             | Тип   | Опис            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | Ідентифікатор порядку стану     |
| `conditionStatus` | string | Стан порядку стану |
| `timestamp`       | int64  | Часова мітка              |

<h2 id="place-strategy-order">Порядок розміщення стратегії</h2>

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Параметри запиту:**

| Параметр      | Тип   | Обов'язкове | Опис             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Так      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Так      | Список підпорядків          |

Поля в `subOrderList[]` здебільшого збігаються з нормальними порядками та порядками умов, з додатковими полями залежностей:

| Параметр        | Тип   | Опис                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | Ідентифікатор підпорядку                                    |
| `firstDrivenId`  | int64  | Перше посвідчення наказу на водіння. `0` означає відсутність залежності |
| `firstDrivenOn`  | string | Перша умова тригера                         |
| `firstTrigger`   | string | Перша спускова дія                            |
| `secondDrivenId` | int64  | Другий ідентифікатор наказу водіння                         |
| `secondDrivenOn` | string | Друга умова тригера                        |
| `secondTrigger`  | string | Друга спускова дія                           |

**Поля відповіді:**

| Поле            | Тип   | Опис     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | Стратегічний ідентифікатор     |
| `strategyStatus` | string | Статус стратегії |
| `timestamp`      | int64  | Часова мітка       |

<h2 id="query-single-order">Одиничний порядок запиту</h2>

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Параметри запиту:**

| Параметр       | Тип   | Обов'язкове | Опис             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Так      | Символ                  |
| `orderId`       | string | Ні       | Ідентифікатор порядку сервера         |
| `clientOrderId` | string | Ні       | Ідентифікатор замовлення, визначений клієнтом |

Має бути надано принаймні один із `orderId` і `clientOrderId` . Якщо обидва надані, сервер виконує точне співпадіння за обох умов.

<h2 id="cancel-order">Скасування замовлення</h2>

```http
POST /v1/private/order/cancel
Content-Type: application/json
```

**Запитуйте тіло:**

```json
{
  "symbol": "BTCUSDT",
  "orderId": "2022543809547603968"
}
```

`clientOrderId` також можна використати для скасування замовлення.

<h2 id="amend-order">Наказ про внесення змін</h2>

```http
POST /v1/private/order/move
Content-Type: application/json
```

**Запитуйте тіло:**

```json
{
  "symbol": "BTCUSDT",
  "orderId": "2022543809547603968",
  "price": "85100",
  "quantity": "0.2"
}
```

`quantity` — це остаточна загальна кількість замовлення після внесення змін, а не залишкова величина.

<h2 id="cancel-all">Скасувати все</h2>

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Параметри запиту:**

| Параметр    | Тип   | Обов'язкове | Опис                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Ні       | Символ                                                                              |
| `cancelType` | int32  | Ні       | `0` всі звичайні ордери, `1` лише лімітні ордери, `2` всі умовні ордери. Стандартна `0` |

Скасування всіх для звичайних замовлень приймається асинхронно. Остаточний статус має визначатися WebSocket `ORDER_TRADE_UPDATE` або кінцевими точками запиту.
