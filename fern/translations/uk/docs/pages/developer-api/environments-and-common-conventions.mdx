## Кінцеві точки обслуговування

| Тип      | Кінцева точка              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="time-and-numeric-values" data-sixmm-canonical-anchor="time-and-numeric-values" aria-hidden="true"></span>

## Час і числові значення

* Якщо не вказано інше, часові поля є мілісекундними часовими мітками Unix.
* Щоденна статистика, балансові знімки та статистика обсягів торгівлі за замовчуванням використовують межі UTC дня.
* Поля, чутливі до точності, такі як кількість, ціна, кількість і швидкість, передаються у вигляді рядків.
* Великі цілочисельні ідентифікатори, такі як `orderId`, `conditionId`, і `strategyId` , повертаються як рядки у JSON.

<span id="response-format" data-sixmm-canonical-anchor="response-format" aria-hidden="true"></span>

## Формат відповіді

Успішна відповідь:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Відповідь на помилку:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Примітки:

* Бізнес-помилки зазвичай все одно повертають уніфіковану структуру JSON . Інтегратори повинні спочатку перевірити `code` .
* Невдачі автентифікації можуть повертати HTTP `401`; обмеження швидкості може повертати HTTP `429`.
* Ви можете надіслати `X-Request-ID` у заголовку запиту. Сервер поверне його як `requestId` у відповіді.
