<h2 id="documentation-areas">Області документації</h2>

| Площа | Що він охоплює |
| --- | --- |
| Налаштування інтеграції | Адреси сервісів, конвенції запитів, форма відповіді та режими доступу. |
| Автентифікація та безпека | JWT, API Key дозволи, HMAC підписи, захист від повторів і синхронізацію часу. |
| REST API | Публічні кінцеві точки, дані користувачів/акаунтів, замовлення, позиції та ринкові дані. |
| WebSocket | Життєвий цикл з'єднання, потоки публічного ринку та приватні користувацькі потоки. |
| Довідки та усунення несправностей | Enums, коди помилок і практичні рекомендації щодо інтеграції. |

<h2 id="production-checklist">Чек-лист виробництва</h2>

- Зберігайте API секрети лише на бекенді.
- Синхронізувати час сервера перед підписаними запитами.
- Розглядати всі поля числової точності як рядки, якщо на сторінці явно не зазначено інше.
- Використовувати ідемпотентність, ідентифікатори запитів і структуровані журнали навколо потоків замовлень.
- Підписатися на WebSocket потоки стану, які мають залишатися актуальними в операційних системах.
- Перегляд кодів помилок і повторна спроба поведінки перед запуском.
