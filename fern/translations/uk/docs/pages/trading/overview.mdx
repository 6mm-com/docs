Посібник з торгівлі пояснює, як користувачі переходять від доступу та фінансування до безперервної торгівлі за контрактами, а також як основні торгові правила впливають на ордери, позиції, комісії та ризики ліквідації.

Цей розділ написаний для навчання продукту, операцій, підтримки та кінцевих користувачів. Для API полів, підписування та деталей інтеграції бекенду використовуйте розділи Розробники та SDK .

<h2 id="before-trading">Перед торгівлею</h2>

- Підтвердити, що користувач увійшов через уповноваженого партнера або вбудований 6MM запис.
- Переконайтеся, що кошти доступні на правильному рахунку перед розміщенням замовлень.
- Розуміння поведінки щодо кредитного плеча, маржі, ліквідації та комісій за фінансування.
- Починайте з малих розмірів позицій при вивченні нового ринку або режиму торгівлі.
- Використовувати TP / SL і зменшувати лише накази для контролю ризиків.
