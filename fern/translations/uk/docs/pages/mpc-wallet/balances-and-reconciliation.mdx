Використовуйте перегляд балансу, щоб побачити поточну позицію коштів і перегляди транзакцій, щоб пояснити, як це змінилося. Корпоративні робочі області можуть відображати кілька переглядів залежно від продукту та ролі.

<span id="use-the-right-record-for-each-question" data-sixmm-canonical-anchor="use-the-right-record-for-each-question" aria-hidden="true"></span>

## Використовуйте правильний запис для кожного запитання

| Питання | Де шукати |
| --- | --- |
| Яка сума може бути використана для оплати? | Перевірте доступний баланс для передбаченого гаманця та активу. Перегляньте суми, які зберігаються або заморожені окремо. |
| Чи отримав кредит на вхідний платіж? | Перевірте запис депозиту та зіставте мережу, актив, суму та деталі отримання. |
| Вихідний платіж отримав відомий результат? | Перевірте запис про зняття коштів і його ланцюжкове підтвердження, якщо доступне. |
| Які записи вплинули на баланс підприємства? | Використовуйте подання бухгалтерської книги, якщо це передбачено робочою областю. Перевірте подання активності ланцюга для руху в ланцюзі. |

<span id="reconcile-a-payment-period" data-sixmm-canonical-anchor="reconcile-a-payment-period" aria-hidden="true"></span>

## Звірити платіжний період

1. Визначте робочу область, мережу, актив і бізнес-період, який ви перевіряєте.
2. Зіставте записи про внесення та зняття з бізнес-замовленням або платіжною довідкою, яку ви зберегли.
3. Облік комісій та внутрішнього збору окремо. Запишіть будь-який баланс, утриманий для очікуваного запиту, окремо від завершеного переказу.
4. Перевірте невідповідні записи, використовуючи посилання на транзакцію та останній статус. Тримайте незавершений елемент відкритим, доки не буде встановлено результат.

Наприклад, якщо вихідна транзакція з’являється в ланцюжку, а запис про зняття коштів все ще очікує на підтвердження, залиште оригінальний бізнес-запит відкритим і дотримуйтеся цього запису. Використовуйте кінцевий статус і відповідні суми для завершення звірки.
