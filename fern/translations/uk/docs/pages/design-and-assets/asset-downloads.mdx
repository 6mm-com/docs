Ця сторінка містить уніфіковані рекомендації щодо специфікацій використання та методів завантаження візуальних активів 6MM Embedded Exchange, які застосовуються до партнерів, які інтегрують 6MM можливості безперервної торгівлі контрактами через SDK / API.

Цей документ поєднує специфікації активів (розміри / формати / правила використання) та завантаження активів (категорії / прев'ю / пакети ZIP ), дозволяючи партнерам виконати наступне на одній сторінці:

* Огляд специфікацій
* Порівняйте приклади
* Завантажити відповідні пакети активів

Усі специфікації розроблені з урахуванням вбудованої інтеграції, кросплатформенної сумісності та довгострокового обслуговування як основних завдань.

<h2 id="2-entry-banners">2. Банери для входу</h2>

Випадки використання

* Банери на головній сторінці додатку
* Банери героїв на головній сторінці веб-сайту
* Рекомендації або зони участі в кампаніях

Рекомендовані розміри (px)

| Розмір       | Опис використання              |
| ---------- | ------------------------------ |
| 750 × 300  | Мобільний / стандарт H5           |
| 1125 × 450 | Високороздільний мобільний пристрій         |
| 1200 × 480 | Універсальний банер         |
| 1440 × 480 | Веб-первинний візуальний розділ     |
| 1920 × 600 | Настільний / великий екран |

Керівництво щодо співвідношення сторін

* Горизонтальне розташування
* Рекомендовані співвідношення: 4:1, 5:2, 3:1

Правила використання

* Тримайте основний контент у центрі
* Резерв ≥ 10% безпечної маржі з обох сторін
* Уникайте копіювання змінної довжини всередині активу

Формати

* PNG

<h2 id="3-card-module-entries">3. Записи карток / модулів</h2>

Випадки використання

* Картки функцій головної сторінки додатку
* Веб-модульні функціональні записи
* Блоки торгових функцій у стрічках контенту

Поширені співвідношення та рекомендовані розміри (px)

| Тип            | Співвідношення | Рекомендований розмір | Опис використання            |
| --------------- | ----- | ---------------- | ---------------------------- |
| Горизонтальна карта | 16:9  | 640 × 360        | Потоки / рекомендації |
| Горизонтальна карта | 16:9  | 1280 × 720       | Веб-карти високої роздільної здатності    |
| Горизонтальна карта | 3:2   | 600 × 400        | Функціональні модулі           |
| Вертикальна карта   | 4:5   | 600 × 750        | Записи на основі списків           |
| Квадратна карта     | 1:1   | 512 × 512        | Планування сітки                 |
| Квадратна карта     | 1:1   | 1024 × 1024      | Дисплей високої роздільної здатності      |

Правила проєктування

* Центруйте основний візуальний елемент
* Текстові області повинні дозволяти обрізання
* Підтримувати ≥ 8% безпечної маржі з усіх сторін
* Не покладайтеся на закруглені кути чи тіні

Формати

* PNG

<h2 id="4-general-usage-rules">4. Правила загального використання</h2>

* Віддайте перевагу високоякісним або векторним ресурсам
* Уникайте вбудовування фіксованої бізнес-логіки або маркетингового тексту в активи
* Ресурси повинні підтримувати середовище темного режиму
* Активи обмежені цілями входу в торгівлю та допомоги інтерфейсу

***

<h2 id="5-versioning-and-maintenance">5. Версування та обслуговування</h2>

* Розміри та характеристики активів можуть оновлюватися разом із оновленнями продукту
* Партнерам рекомендується використовувати найновіші пакети активів
* Старіші версії активів не рекомендуються для нових інтеграцій

Для особливих вимог щодо специфікацій або завантажень активів, будь ласка, звертайтеся 6MM офіційну технічну або бізнес-підтримку.
