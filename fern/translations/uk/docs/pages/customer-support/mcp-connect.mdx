## Деталі підключення

| Пункт | Значення |
| --- | --- |
| Консоль орендаря | [Консоль орендаря](https://csadmin.6mm.com/) |
| Транспорт | Потоковий HTTP |
| Авторизація | OAuth код авторизації з PKCE; динамічна реєстрація клієнтів |
| Обліковий запис | Ваш наявний обліковий запис служби підтримки клієнтів |

Використовуйте програму штучного інтелекту, яка підтримує цей віддалений транспорт і потік авторизації. Без особливостей орендаря MCP розгортання сервера або окремо MCP потрібна конфігурація дозволу. Не додавайте SSE шлях або використовуйте ключ програми як OAuth жетон на пред'явника.

<span id="connect-step-by-step" data-sixmm-canonical-anchor="connect-step-by-step" aria-hidden="true"></span>

## Підключайте крок за кроком

1. Увійдіть у консоль і відкрийте **Параметри системи → MCP Connection**.
2. Скопіюйте кінцеву точку та додайте її як віддалений сервер MCP у вашій програмі ШІ. Досить відображуваного імені, наприклад 6MM Служба підтримки клієнтів.
3. Дозвольте програмі почати авторизацію. Увійдіть у веб-переглядачі та завершіть необхідну перевірку.
4. Перш ніж дозволити підключення, перевірте програму, орендаря, обліковий запис і зворотню адресу. Надана назва програми не є знаком сертифікації.
5. Поверніться до програми ШІ та за потреби оновіть її інструменти. Попросіть його перерахувати категорії знань як перший тест лише для читання.
6. Перевірте «Підключені програми» на консолі. Скасуйте підключення там, коли більше не потрібне.

Ніколи не повідомляйте штучному інтелекту свій пароль, код підтвердження чи секрет підпису особи. Авторизуйтеся лише через сторінки входу та згоди.

<span id="what-access-does-the-ai-receive" data-sixmm-canonical-anchor="what-access-does-the-ai-receive" aria-hidden="true"></span>

## Який доступ отримує AI?

Лише підтримувані інструменти та дані клієнта поточного облікового запису. Дозволи перевіряються знову під час дзвінків; призупинення облікового запису, недоступність орендаря або скасування авторизації можуть блокувати доступ. Вихід із консолі не скасовує автоматично підключення AI.

Поточна реалізація використовує 30-денну авторизацію підключення та короткочасні маркери доступу з змінними маркерами оновлення. Дотримуйтеся терміну дії, зазначеного в підключених програмах, і повторно підключіться, коли це буде потрібно. Програми штучного інтелекту обслуговують обмін і оновлення токенів; орендарі не вставляють паролі вручну у виклики інструментів.

Цей MCP керує системою підтримки. Це не дозволяє боту відвідувача керувати серверною частиною або надавати доступ до торгових рахунків.
