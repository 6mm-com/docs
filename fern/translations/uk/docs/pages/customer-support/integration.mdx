## Скопіюйте код інтеграції клієнта

Відкрийте **Системні налаштування → Інтеграція веб-сайту**. Налаштуйте дозволені домени веб-сайту та скопіюйте згенерований код. Ключ програми ідентифікує вашого орендаря; це не пароль для входу чи секрет підпису особи. Віджет підтримки клієнтів окремий від Trading Widget SDK.

Нижче показано підтримувані атрибути сценарію. Замініть покажчик місця заповнення ключем програми вашого клієнта та скористайтеся сценарієм URL, створеним вашою консоллю.

```html
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"></script>
```

Для наявної кнопки:

```html
<button id="support-button">Contact support</button>
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"
        data-trigger="#support-button"></script>
```

## Ідентичність відвідувача

| Режим | Інтеграційна відповідальність |
| --- | --- |
| Анонімний відвідувач | Використовуйте налаштований відвідувачем запис; система ідентифікує відвідувача браузера |
| Увійшов користувач | Згенеруйте ідентифікаційний токен на сервері та передайте стабільний ідентифікатор користувача та підписаний токен за допомогою прикладу консолі |

Підтримувані атрибути входу: <code>data-user-id</code> і <code>data-user-token</code>. Зберігайте таємницю підпису на своєму сервері; не вставляйте його в HTML, мобільний код або підказку ШІ. Використовуйте точний формат маркера та час життя, показані на консолі.

Для програми або WebView використовуйте режим входу та інтеграції, наданий для вашого клієнта. Перевірити навігацію, автентифікацію, вибір файлів і поведінку вікна перегляду на реальному пристрої; один лише фрагмент веб-сайту не забезпечує власну підтримку SDK.

## Перевірте запис

Перевірте дозволені домени, мову, світлу/темну тему, відкриття та закриття, тестове повідомлення, підтримку персоналу та подання заявки. Під час зміни користувача веб-сайту переконайтеся, що ідентифікаційна інформація, передана віджету, належить поточному користувачеві. Якщо віджет не відкривається, перевірте ключ програми, завантаження сценарію, налаштування домену та доступність служби орендаря.
