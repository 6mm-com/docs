## Налаштуйте досвід відвідувачів

Відкрийте **Налаштування системи**. Доступні елементи керування залежать від вашої ролі та ввімкнених служб орендаря.

| вкладка | Що налаштувати |
| --- | --- |
| Зовнішній вигляд та інтеграція | Доступні візуальні та вхідні налаштування |
| Домашня сторінка та копія | Текст і вказівки на домашній сторінці для клієнтів |
| Розмова та тайм-аут | Поведінка розмови та контроль часу очікування |
| Діалоги відвідувачів | Інформація та підказки, що збираються під час входу відвідувача |
| Інтелектуальні послуги | ШІ, можливості пошуку та перекладу доступні для орендаря |
| Інтеграція сайту | Білий список доменів, код для вбудовування, підписаний ідентифікатор та інтеграція мови/теми |
| MCP підключення | Адреса служби, авторизовані заявки та відкликання |

Збережіть налаштування, а потім перевірте їх у записі відвідувача. Попередній перегляд або успішне збереження не означає, що окремо вбудований веб-сайт уже використовує останні налаштування.

## Тримайте кордони чіткими

Параметри клієнта налаштовують підтримку клієнтів клієнта. Вони не надають доступу до ключів постачальників на всій платформі, інших орендарів, операцій поповнення чи біржових торгових рахунків. MCP відкриває лише підтримувані поля конфігурації, дозволені поточною роллю. Зміни білого списку доменів через MCP потребують підтвердження.
