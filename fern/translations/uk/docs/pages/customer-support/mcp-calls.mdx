## Відкрийте для себе доступні інструменти

Після авторизації OAuth використовуйте клієнт MCP із Streamable HTTP, щоб ініціалізувати з’єднання та отримати інструменти через `tools/list`. Викликати інструменти через `tools/call`. Зчитувати кожну повернуту схему введення, а не отримувати параметри з REST URL-адрес. Ідентифікатори, взяті з читання, зазвичай є десятковими рядками для аргументів шляху; числове поле всередині тіла залишається числовим там, де цього вимагає схема.

Нижче наведено приклади повідомлень інструментів JSON-RPC після ініціалізації, а не завершених окремих запитів HTTP. Клієнт надає маркер доступу та заголовки протоколу. Замініть ілюстративні ідентифікатори на записи, повернуті для вашого власного орендаря.

<span id="read-categories" data-sixmm-canonical-anchor="read-categories" aria-hidden="true"></span>

## Читайте категорії

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "knowledge_get_categories",
    "arguments": {}
  }
}
```

<span id="create-a-draft" data-sixmm-canonical-anchor="create-a-draft" aria-hidden="true"></span>

## Створіть чернетку

Виберіть існуючу категорію з результатів читання. Категорія обов'язкова. Не встановлюйте статус опубліковано, якщо ви не збираєтеся опублікувати та завершити будь-яке необхідне підтвердження.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "knowledge_create_article",
    "arguments": {
      "requestId": "support-demo-create-001",
      "body": {
        "title": "Withdrawal guide draft",
        "content": "Reviewed withdrawal instructions go here.",
        "categoryId": 12,
        "status": "draft"
      }
    }
  }
}
```

## Попередній перегляд оновлення або видалення

Спочатку прочитайте статтю. Перегляньте точний запланований запис, включаючи новий ідентифікатор запиту. Попередній перегляд не виконує його.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "mcp_preview",
    "arguments": {
      "tool": "knowledge_delete_article",
      "arguments": {
        "id": "123",
        "requestId": "support-demo-delete-001"
      }
    }
  }
}
```

Скопіюйте повернутий `version` у `expectedVersion`, не змінюючи ціль або параметри:

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "knowledge_delete_article",
    "arguments": {
      "id": "123",
      "requestId": "support-demo-delete-001",
      "expectedVersion": "REPLACE_WITH_THE_64_CHARACTER_VERSION_FROM_PREVIEW"
    }
  }
}
```

Заповнювач не є дійсною версією. Використовуйте фактичне значення з 64 символів, яке повертає попередній перегляд.

<span id="confirm-and-check-the-result" data-sixmm-canonical-anchor="confirm-and-check-the-result" aria-hidden="true"></span>

## Підтвердіть і перевірте результат

Якщо результат повідомляє `awaiting_approval`, відкрийте `approvalUrl`, увійдіть як обліковий запис авторизації та перегляньте дію. Лише його схвалення запускає незавершену операцію. Термін дії підтвердження закінчується через 15 хвилин. Відмова або закінчення терміну дії не виконує запис.

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "mcp_operation",
    "arguments": {
      "operationId": "REPLACE_WITH_RETURNED_OPERATION_ID"
    }
  }
}
```

Вихід інструмента передається у текстовому вмісті, що містить JSON; перевірте його та будь-який прапор `isError`. Сама по собі відповідь HTTP або посилання на схвалення не є доказом успіху. Прочитайте статус операції та, якщо це буде корисно, запитайте відповідний запис.

## Спробуйте безпечно

Повторно використовуйте той самий `requestId` і аргументи для повторної мережевої спроби того самого запису. Не використовуйте його для іншої дії. Якщо вміст змінився, прочитайте та перегляньте ще раз, а потім надішліть нову заплановану операцію з новим ідентифікатором запиту. Якщо відповідь втрачена або операція продовжує виконуватися, запитайте її статус і бізнес-запис, перш ніж вирішити, що робити; ніколи не вважати тайм-ауту означає, що нічого не сталося.

Клієнт AI зазвичай виконує цей протокол для користувача. Ці відомості призначені для розробників клієнтів і для діагностики робочого процесу інструменту.
