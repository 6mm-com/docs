## Доступні інструменти відповідають вашій ролі

У таблиці описано максимальний підтримуваний обсяг. Ваша програма AI отримує лише інструменти, дозволені для облікового запису авторизації. Використовуйте список активних інструментів і його схему параметрів як договір; нова функція консолі не є автоматично інструментом MCP.

| Консольний модуль | Підтримувані операції |
| --- | --- |
| Онлайн розмови | Читати сесії, повідомлення та інформацію про чергу; призначати, приєднуватися, приймати та передавати; надсилати повідомлення; запрошувати рейтинги; керувати дозволом на завантаження; розпізнавати/перекладати повідомлення; завантажувати підтримувані файли |
| Квитки та відгуки | Запитувати, призначати, оновлювати статус і видаляти квитки та відгуки користувачів; створювати, читати, оновлювати, призначати та видаляти квитки агента |
| Історія розмов | Сеанси запитів і повідомлення; видалити один або кілька сеансів |
| Управління контентом | Читати та підтримувати категорії, статті, гарячі запитання, категорії питань, картки функцій, оголошення та записи самообслуговування; публікувати/скасувати публікацію статей |
| Мовний переклад | Читати джерела, переклади та статус завершення; зберегти або очистити підтримувані переклади; викликати автоматичний переклад; керувати підтримуваними налаштуваннями мови |
| Конфігурація бота | Читайте підтримувані налаштування та поширені запитання, ведіть подібні запитання, тестуйте відповіді, перевіряйте статус пошуку, оновлюйте індекси та перебудовуйте вектори |
| Агентське управління | Підтримуйте підтримуваних агентів, ролі та швидкі відповіді |
| Налаштування системи | Дозволений вигляд для читання/запису, копіювання, бесіда, запис відвідувача, інтелектуальна служба та білий список веб-сайтів |
| Статистика | Огляд лише для читання та підтримувані статистичні запити |
| Використання та виставлення рахунків | Баланс, використання, транзакції та ціни лише для читання |
| Журнали операцій | Перелік операцій лише для читання та деталі |

## Пише і підтвердження

Видалення, публікація/скасування публікації, редагування опублікованих статей, надсилання повідомлень, керування ролями/обліковими записами, зміни дозволеного списку веб-сайтів, перебудова векторів і автоматичний переклад платформи потребують підтвердження серверної частини, якщо це зазначено інструментом. Запис без підтвердження може негайно змінити дані; перевірте запланований обсяг, перш ніж просити ШІ виконати його.

MCP не забезпечує адміністрування платформи, закриття/видалення клієнта, поповнення балансу, редагування платежів або секретний доступ постачальника. Файлові інструменти примусово перевіряють формат і обмеження розгорнутого розміру; поточна реалізація підтримує один файл розміром до 10 Мб через Base64. Використовуйте консоль для більших файлів, де це дозволяють її власні обмеження.

## Зразкові завдання

- Перелічіть відсутні переклади та чернетки японських версій, зберігаючи посилання та суми.
- Знайдіть невирішені заявки користувачів і запропонуйте призначення, ще не застосовуючи їх.
- Створіть чернетку статті бази знань у наявній категорії, а потім покажіть її назву й ідентифікатор.
- Узагальніть останні статистичні дані підтримки з точним діапазоном дат.

Штучний інтелект платформи, автоматичний переклад і векторні операції можуть стягувати плату за обслуговування. Власне використання підключеного постачальника AI є окремим.
