## Виберіть правильний запис

Відкрийте **Керування квитками** та виберіть відповідну вкладку.

| запис | призначення |
| --- | --- |
| Агентський квиток | Робота створена та підтримується командою підтримки |
| Квиток користувача | Запитання, надіслане відвідувачем для доопрацювання |
| Відгуки користувачів | Пропозиція або проблема, надіслана через запис відгуку |

<span id="handle-a-case" data-sixmm-canonical-anchor="handle-a-case" aria-hidden="true"></span>

## Займатися справою

Прочитайте опис, контактні дані, пов’язану розмову та вкладення, наявні в записі. Призначте його відповідному обробнику та оновлюйте статус у міру просування роботи. Використовуйте підтримувані елементи керування для квитків агентів; квитки користувачів і відгуки мають власні доступні дії.

Оновлення статусу саме по собі не доводить, що відвідувач отримав відповідь електронною поштою чи чатом. За потреби надішліть відповідь через доступний канал зв’язку та перевірте результат. Зберігайте особисту інформацію в рамках авторизованого робочого процесу орендаря.

<span id="use-mcp-for-triage" data-sixmm-canonical-anchor="use-mcp-for-triage" aria-hidden="true"></span>

## Використовуйте MCP для сортування

Попросіть підключений ШІ скласти список невирішених випадків, згрупувати їх за проблемами та підготувати запропоновану відповідь. Перегляньте призначення та зміни статусу, перш ніж застосовувати їх до реальних випадків. Створення квитка агента та подання квитка користувача є різними робочими процесами; інструмент для одного не означає, що він підтримує інший. Видалення квитка через MCP вимагає підтвердження.
