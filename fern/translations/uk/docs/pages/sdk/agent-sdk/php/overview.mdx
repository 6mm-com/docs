<h2 id="runtime">Тривалість виконання</h2>

| Предмет | Вартість |
| --- | --- |
| Пакет | sixmm/agent-SDK |
| Мінімальна версія PHP | PHP 7.4+ |
| Рекомендована версія PHP | PHP версії 8.1+ або підтримувані наразі |
| Необхідні розширення | ext-json, ext-curl |

Джерело пакету PHP SDK та затверджена версія надаються під час адаптації партнерів. Не припускайте, що посилка доступна через публічний Packagist; налаштуйте репозиторій Composer, який надається вашій організації.

<h2 id="supported-scenarios">Підтримувані сценарії</h2>

| Сценарій | SDK метод |
| --- | --- |
| Прив'язати користувача | зв'язування |
| Фіксована сума переказу | Трансфер |
| Переведіть усе | transferAllOut |
| Зворотний трансфер | реверс |
| Порядок запитів | queryOrder |
| Створити запис URL | createEntryUrl |
| Верифікація за допомогою вебхука | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Правила інтеграції бекенду</h2>

- Завантаження `apiSecret` з секретного менеджера або захищеної змінної середовища.
- Тримати логіку зв'язування, передачу, підписування та вебхуків поза кодом браузера.
- Використовуйте десяткові рядки для визначення кількості активів, щоб уникнути округлення з плаваючою точкою.
- Повторне використання початкового `agentOrderNo` при запиті щодо невизначеного результату передачі.
- Перевірити сигнатури webhook за сирим запитом перед декодуванням або зміною.
