Цей посібник призначений для **Agent Java SDK `v0.3.0`**, Java 8+ і публічного контракту з тегами. Приклади виконуються в серверній частині партнера після ініціалізації `client` у [Швидкий старт](/uk/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Шість постійних запитів: поточні замовлення, історія замовлень, заповнення, поточні позиції, історія позицій і облікова книга.
- Залишки коштів, перекази, запити на відновлення та перекази фінансування/контракту.
- Явне виробництво/імітований вибір для підтримуваних запитів на фінансування.
- Посібники з перенаправлення та вбудовування Seconds Trading, посилання на поле відповіді та інструкції з міграції.

Java SDK і Trading Widget SDK мають незалежні версії. `v1` Віджет URL не є Java SDK версією `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Існуючі інтеграції

Зберігайте зіставлення користувачів, оригінальні замовлення та облікові дані. Пропущені поля середовища зберігають існуючу робочу поведінку. Фінансування, явно змодельовані кошти та шість постійних запитів вимагають відповідних нових моделей і методів. огляд [Посібник з оновлення](/uk/sdk/agent-sdk/java/upgrade) перед зміною існуючої інтеграції.
