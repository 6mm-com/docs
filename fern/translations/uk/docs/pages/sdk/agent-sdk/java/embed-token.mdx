Цей посібник призначений для **Agent Java SDK `v0.3.0`**, Java 8+ і публічного контракту з тегами. Приклади виконуються в серверній частині партнера після ініціалізації `client` у [Швидкий старт](/uk/sdk/agent-sdk/java/quick-start).

## Приклад передумов

Фрагменти Java поділяють ці імпортовані файли. Ініціалізуйте `client` за допомогою швидкого запуску та отримайте `platformUserId` із збереженого зв’язування. Приклади ідентифікаторів користувача/замовлення потрібно замінити вашими постійними значеннями.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget Вставити маркер

Вбудований маркер призначений для режиму Trading Widget SDK `partner-token + tokenProvider`. The
браузер викликає серверну частину партнера, а серверна частина партнера викликає це Java SDK
щоб створити `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Вимоги до інтеграції:

- `channelId` має використовувати значення, передане Trading Widget SDK.
- `symbol` необов’язковий, але рекомендується передавати поточний початковий символ.
- `embedToken` короткочасний і одноразовий. Не вводьте його в рядки запиту URL.
- Інтерфейс партнера ніколи не повинен містити `apiSecret`.
- `expireAt` — це позначка часу Unix у секундах, а не TTL.

Приклад серверної кінцевої точки партнера:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Контракт кінцевої точки партнера

Автентифікуйте сеанс партнера та виведіть `agentUserId` на стороні сервера. Прийняти поточний віджет `channelId`; повернути верхнього рівня `embedToken`, `expireAt` (секунди Unix) і те саме `channelId`. Відповіді агента не надають `channelId`: ваш сервер повторює це. Отримати новий маркер під час ініціалізації та оновлення; ніколи не використовуйте його повторно. Створення токена не переказує кошти та не вибирає середовище гаманця.
