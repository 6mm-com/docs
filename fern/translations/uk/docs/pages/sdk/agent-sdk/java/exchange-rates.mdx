Цей посібник призначений для **Agent Java SDK `v0.3.0`**, Java 8+ і публічного контракту з тегами. Приклади виконуються в серверній частині партнера після ініціалізації `client` у [Швидкий старт](/uk/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## Приклад передумов

Фрагменти Java поділяють ці імпортовані файли. Ініціалізуйте `client` за допомогою швидкого запуску та отримайте `platformUserId` із збереженого зв’язування. Приклади ідентифікаторів користувача/замовлення потрібно замінити вашими постійними значеннями.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Довідкові курси валют

Обидва методи FX використовують звичайний потік агента з підписом API. Почніть із відкриття
наразі підтримувані вихідні валюти:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Запитуйте всі підтримувані довідкові ставки fiat-to-USDT:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Запит вибраних валют:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

Фабрика запитів обрізає коди валют у верхньому регістрі та серіалізує їх як
розділене комами значення `sourceCurrencies`, яке вимагає API. Опускаючи
запит або всі значення ефективної валюти запитує кожну підтримувану валюту.

| Поле відповіді | Тип | опис |
| --- | --- | --- |
| `snapshotVersion` | string | Стабільна версія знімка для аудиту та звірки |
| `provider` | string | Вихідний постачальник, зараз `ECB` |
| `sourceDate` | string | Дата спостереження вгорі у форматі `yyyy-MM-dd`. |
| `fetchedAt` / `expiresAt` | int64 | Мітки часу Unix у мілісекундах |
| `pricingPolicy` | string | Зараз `FIXED_PEG` |
| `usdtUsdRate` | string | USD сума на 1 USDT, наразі зафіксована на `1` |
| `rateType` | string | Зараз `INDICATIVE_DAILY` |
| `usage` | string | Зараз `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT сума, що відповідає одній одиниці вихідного фіату |

Ці значення є довідковими для обчислення мультивалютного гаманця партнера
сума USDT, надіслана на 6MM. Вони не є доступними для виконання цінами, заблокованими котируваннями або
USDT ринкові ціни в реальному часі. Використовуйте `BigDecimal` і рядки для суми
розрахунки; не використовуйте `double` або `float`.
