Цей посібник призначений для **Agent Java SDK `v0.3.0`**, Java 8+ і публічного контракту з тегами. Приклади виконуються в серверній частині партнера після ініціалізації `client` у [Швидкий старт](/uk/sdk/agent-sdk/java/quick-start).

<span id="version-and-installation" data-sixmm-canonical-anchor="version-and-installation" aria-hidden="true"></span>

## Версія та установка

| Пункт | Значення |
| --- | --- |
| Тег стабільного джерела | `v0.3.0` |
| Java | Java 8+ |
| Мейвен | Maven 3.9+ |
| Координати | `com.sixmm.exchange.sdk:agent:0.3.0` |

Джерело хостів GitHub; це не робить ці координати розв’язними з Maven Central. Використовуйте локальну установку з тегами або затверджене сховище артефактів.

## Що охоплює SDK.

| Категорія | Сценарій | SDK API | опис |
| --- | --- | --- | --- |
| Прив'язка користувача | Прив’язати користувача | `bind` | Створення або отримання прив’язки між користувачем-партнером і користувачем платформи 6MM |
| Запити активів | Запит партнерського облікового запису | `queryAccount` | Запит партнерської маржі або рахунку фінансування |
| Запити активів | Запит ресурсів користувача | `queryUserAssets` | Активи Контракту запиту; використовуйте `withFunding()`, щоб включити залишки фінансування |
| Трансфери | Переказ фіксованої суми | `transfer` | Переказ коштів на або з 6MM |
| Трансфери | Перенести все назовні | `transferAllOut` | Перенесіть весь баланс користувача, який можна зняти, назад на партнерську платформу |
| Трансфери | Зворотній порядок | `reverse` | Скасувати успішну передачу, якщо серверна частина підтримує потік компенсації |
| Трансфери | Порядок запиту | `queryOrder` | Запитувати одне замовлення на переказ за номером замовлення партнера |
| Трансфери | Список замовлень | `listOrders` | Переглядайте переказні ордери для звірки |
| Трансфери | Webhook перевірка | `WebhookVerifier.verify` | Перевірити зворотні виклики кінцевого стану передачі від 6MM |
| Гаманець для фінансування | Переказ фінансування | `walletTransfer` | Партнер ↔ Фінансування або Фінансування ↔ Контракт; підтвердити повернутий статус |
| Гаманець для фінансування | Статус переказу коштів | `queryWalletTransfer` | Відновіть операцію фінансування, використовуючи вихідний номер замовлення партнера |
| Торговий запис | Прямий вхід URL | `createEntryUrl` | Створіть одноразовий SSO URL для режиму перенаправлення |
| Торговий запис | Вставити маркер | `createEmbedToken` | Створіть короткочасний маркер для режиму Trading Widget `tokenProvider` |
| Вічні дані | Поточні безстрокові замовлення | `listCurrentPerpetualOrders` | Запит поточних замовлень NORMAL або CONDITIONAL |
| Вічні дані | Безстрокова історія замовлень | `listPerpetualOrderHistory` | Запит терміналу NORMAL або CONDITIONAL замовлення |
| Вічні дані | Вічні торги | `listPerpetualTrades` | Запит торгівлі заповнює явний публічний список гравців |
| Вічні дані | Поточні безстрокові посади | `listCurrentPerpetualPositions` | Запит поточних позицій |
| Вічні дані | Безстрокова історія позицій | `listPerpetualPositionHistory` | Запит закритих позицій |
| Вічні дані | Безстрокова бухгалтерська книга | `listPerpetualLedger` | Запит окремих записів зміни балансу контракту |
| Довідкові ставки Fiat | Список підтримуваних фіатних валют | `listSupportedFiatCurrencies` | Список фіатних валют, які зараз конвертуються в USDT |
| Довідкові ставки Fiat | Запит довідкових ставок FX | `queryExchangeRates` | Запитуйте щоденні довідкові співвідношення фіат-USDT для всіх або вибраних валют |
| Сервісна інформація | Сервісна версія | `version` | Інформація про версію служби Query Agent |

## Конфігурація

Отримайте наступні значення з 6MM раніше
інтегруючий.

| Пункт | приклад | опис |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | База агента API URL, без косої риски в кінці |
| `agentCode` | `AGENT001` | Код партнера |
| `apiSecret` | `your-api-secret` | API секрет підпису. Зберігайте його лише на сервері |
| `defaultCurrency` | `USDT` | Валюта за умовчанням, зазвичай `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Кінцева точка партнера для зворотних викликів 6MM. |

Рекомендації по виготовленню:

- Використовуйте HTTPS для кінцевих точок агента API і webhook.
- Зберігайте `apiSecret` у секретному менеджері, центрі конфігурації або змінній середовища.
- Тримайте час сервера синхронізованим, бажано з NTP.
- Зберігайте всі номери замовлень партнерів і зберігайте їх глобально унікальними.
- Ніколи не надсилайте `apiSecret` у браузери, програми, міні-програми чи вихідний код інтерфейсу.

## Поля автоматичного підпису

Для викликів підписаного агента API SDK автоматично вводить:

| Поле | Джерело | опис |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Код партнера |
| `timestamp` | Поточна позначка часу UTC Unix | секунд |
| `nonce` | Безпечний генератор випадкових змін | Захист від повторів |
| `sign` | HMAC-SHA256 | Запит на підпис |
| `currency` | `defaultCurrency` | Заповнюється, якщо в запитах на переказ/рахунок не вказано валюту |

Правила підписання:

1. Виключити `sign`.
2. Виключити порожні значення.
3. Сортувати ключі за ASCII порядком.
4. Приєднатися як `k=v&k2=v2`.
5. Обчисліть HMAC-SHA256 шістнадцяткове за допомогою `apiSecret`.

Звичайний бізнес-код не повинен розраховувати підписи або встановлювати вручну
`agentCode`, `timestamp`, `nonce` або `sign`.
