## Резюме методу

| метод | призначення |
| --- | --- |
| знищити() | Видаліть iframe і звільніть прослуховувачі подій. |
| getState() | Прочитайте поточний стан життєвого циклу SDK. |
| whenReady() | Зачекайте, поки iframe завершить ініціалізацію. |
| setSymbol(символ) | Переключіть торгову пару в iframe. |
| setTheme(тема) | Оновіть параметр теми iframe. |
| setLocale(локаль) | Змініть мову iframe. |
| setSize(ширина, висота) | Оновіть розміри iframe. |
| перезавантажити() | Перезавантажте поточний iframe. |
| refreshAuth(причина) | Запустити процес оновлення авторизації віджета. |
| setTokenProvider(постачальник) | Замініть постачальника, який використовується в режимі маркера партнера. |
| on(подія, обробник) | Підпишіться на події виконання та отримайте функцію скасування підписки. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## знищити()

Видаліть iframe, очистіть прослуховувачі та видаліть один раз для поточного екземпляра.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Прочитайте поточний стан життєвого циклу примірника віджета.

```js
const state = widget.getState()
```

Повернуті значення включають завантаження, автентифікацію, готовність, помилку та знищено.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Зачекайте, поки iframe завершить ініціалізацію, перш ніж запускати залежну логіку інтерфейсу користувача.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(символ)

Переключіть торгову пару в iframe. Якщо iframe все ще ініціалізується, SDK ставить команду в чергу та надсилає її після завершення.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(тема)

Оновіть параметр теми, який використовується вбудованим торговим iframe.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(локаль)

Змініть мову iframe. Підтримувані значення: en, en-US і zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(ширина, висота)

Оновіть розмір iframe DOM і повідомте iframe про новий зовнішній розмір. Числові значення перетворюються на px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## перезавантажити()

Перезавантажте поточний iframe і зачекайте, доки він знову ініціалізується.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(причина)

Попросіть iframe оновити поточний потік автентифікації. Додаткове значення причини пересилається для журналювання та керування потоком.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(постачальник)

Замініть tokenProvider, який використовується режимом маркера партнера. SDK викликає постачальника, коли iframe запитує новий маркер вбудовування.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(подія, обробник)

Підпишіться на подію виконання. Повернена функція видаляє слухача.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Додаткові методи в поточній версії 1

| метод | призначення |
| --- | --- |
| `whenRendered()` | Зачекайте на відтворене сповіщення iframe; це окремо від готового. |
| `setPage(page)` | Запит на сторінку підтримуваного продукту в поточному екземплярі. Це не змінює середовище використання коштів. |
| `prepareForRecreate()` | Попросіть готовий iframe підготувати до заміни; повертає обіцянку та може відхилити, якщо недоступний, зайнятий або минув час очікування. |
| `cancelRecreate()` | Скасувати потік очікуваної/підготовленої заміни. |
| `TradingWidget.validateOptions(options)` | Перевірте параметри ініціалізації перед створенням екземпляра. |

Для зміни користувацького або реального/демонстраційного середовища знищіть старий екземпляр і створіть новий із цільовою автентифікацією та режимом. Не використовуйте `setPage` як перемикач середовища. Перевірте можливості перед використанням додаткових методів.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
