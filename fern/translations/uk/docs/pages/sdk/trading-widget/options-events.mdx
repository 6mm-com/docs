<h2 id="options">Опції</h2>

| Поле | Тип | За замовчуванням | Примітки |
| --- | --- | --- | --- |
| baseUrl | string | SDK походження писемності | Домен iframe. Передайте явно на сторінках партнерів. |
| Символ | string | BTCUSDT | Нормалізовано у великі літери та смужки - / _. |
| Тема | темний \| Світло | темний | Початковий параметр теми. |
| Локація | en \| en-US \| zh-CN | Браузер/за замовчуванням | Підтримуються англійська та спрощена китайська. |
| Планування | За замовчуванням \| компактний | За замовчуванням | Зарезервована опція планування. |
| Дисплей | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Керування вбудовує оболонкові зони та високорівневі торгові контейнери. |
| Автортифікація | object | жодних | Використовуйте partner-token для нових інтеграцій SSO . |

<h2 id="display-controls">Керування відображенням</h2>

`display` керує вбудованою оболонкою торгової сторінки та високорівневими контейнерами. У партнерських вбудованих заголовок PC і нижній ринковий тикер за замовчуванням приховані.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Поле | Тип | За замовчуванням | Примітки |
| --- | --- | --- | --- |
| showHeader | boolean | неправда | Чи показувати вбудований заголовок ПК всередину iframe. |
| showTicker | boolean | неправда | Чи варто показувати тікер нижнього ринку в оболонкі embed. |
| прихований | Струна[] | [] | Приховує високорівневі контейнери на сторінці обміну. |

Підтримувані `display.hidden` цінності:

| Вартість | Контейнер |
| --- | --- |
| Чарт | Контейнер для карт |
| orderBook | Контейнер для книги замовлень |
| orderForm | Панель форми замовлень |
| Посади | Нижні позиції та панель відкритих ордерів |
| Облік | Контейнер активів рахунку |

`display.hidden` приховує лише цілі контейнери. Він не приховує окремі кнопки, поля чи інструменти всередині контейнера. Значення, які не відповідають поточному порту перегляду, ігноруються.

<h2 id="events">Події</h2>

| Подія | Тригер |
| --- | --- |
| Готовий | Ініціалізація iFrame завершена. |
| Помилка | SDK, iframe або помилка автентифікації. |
| state_changed | SDK стан життєвого циклу змінився. |
| auth_state_changed | Статус автентифікації партнера-токена змінився. |
| symbol_changed | Фактичний символ iframe змінився. |
| locale_changed | Фактична локація iframe змінилася. |
| order_created | Користувач створив замовлення всередині iframe. |
| order_failed | Подання замовлення не вдалося. |
| знищено | SDK екземпляр знищено. |
