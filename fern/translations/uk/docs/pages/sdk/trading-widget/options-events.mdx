## Елементи керування дисплеєм

`display` контролює вбудовану оболонку торгової сторінки та контейнери високого рівня. У партнерських вставках заголовок ПК і нижній ринковий тикер приховані за умовчанням.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Поле | Тип | За замовчуванням | Примітки |
| --- | --- | --- | --- |
| showHeader | boolean | помилковий | Чи показувати заголовок вбудованого ПК усередині iframe. |
| showTicker | boolean | помилковий | Чи показувати нижній ринковий тікер у вставній оболонці. |
| прихований | рядок[] | [] | Приховує контейнери високого рівня на торговій сторінці. |

Підтримувані значення `display.hidden`:

| Значення | Контейнер |
| --- | --- |
| діаграма | Контейнер діаграми |
| orderBook | Контейнер для книги замовлень |
| orderForm | Панель форми замовлення |
| позиції | Нижні позиції та панель відкритих ордерів |
| рахунок | Контейнер активів облікового запису |

`display.hidden` приховує лише цілі контейнери. Він не приховує окремі кнопки, поля або інструменти всередині контейнера. Значення, які не відповідають поточному вікну перегляду, ігноруються.

## Події

| Подія | Тригер |
| --- | --- |
| готовий | ініціалізацію iframe завершено. |
| помилка | SDK, iframe або помилка автентифікації. |
| стан_змінено | SDK стан життєвого циклу змінено. |
| auth_state_changed | стан автентифікації маркера партнера змінено. |
| символ_змінено | Фактичний символ iframe змінено. |
| locale_changed | Фактична локаль iframe змінена. |
| order_created | Користувач створив замовлення всередині iframe. |
| order_failed | Не вдалося надіслати замовлення. |
| зруйновано | SDK екземпляр знищено. |

## Сторінки товарів і режим торгівлі

Версії Java Agent SDK і браузера Trading Widget SDK надаються незалежно. Для торгівлі секундами скористайтеся поточними можливостями віджета та явно виберіть сторінку та режим торгівлі.

| Варіант | Цінності | Значення |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Сторінка продукту для торгівлі секундами. |
| `tradingMode` | `real`, `demo` | За замовчуванням `real`; явно відповідати зовнішньому середовищу фінансування. |

Перевірте `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` і `TradingWidget.capabilities.partnerToken` перед ініціалізацією. Створення токена не вибирає середовище коштів. Щоб змінити користувачів або реальний/демо режим, знищіть старий екземпляр і створіть новий.

## Додаткові цілі відображення та події

Поточне середовище виконання також приймає `symbolFavorites` і `symbolTicker` у `display.hidden`. Завжди перевіряйте `TradingWidget.capabilities.displayTargets`; ціль керує контейнером високого рівня і не є параметром дозволу на рівні поля.

| Подія | Значення |
| --- | --- |
| `rendered` | iframe надсилає відтворене сповіщення. |
| `theme_changed` | iframe повідомляє про свою фактичну тему. |
| `page_changed` | iframe повідомляє про фактичну сторінку продукту. |

Використовуйте `onRendered` або `widget.on('rendered', handler)` для обробки візуалізації окремо від ініціалізації. Поточні підтримувані сторінки опубліковано в `TradingWidget.capabilities.pages`; перевіряти запитану сторінку, а не вгадувати шлях.
