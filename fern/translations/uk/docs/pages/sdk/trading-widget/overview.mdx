<h2 id="responsibility-split">Розподіл відповідальності</h2>

| Площа | Власник | Примітки |
| --- | --- | --- |
| Створення контейнерів | Партнерський фронтенд | Надайте видимий елемент з явною шириною та висотою. |
| Створення iFrame | Trading Widget SDK | SDK створює та керує iframe. |
| Торговий інтерфейс | 6MM iframe | K-line, книга замовлень, форма замовлень, позиції, замовлення та дані рахунку запускаються всередині iframe. |
| Керування відображенням | Trading Widget SDK + 6MM iframe | Заголовок вбудовування ПК і нижній тікер за замовчуванням приховані. Партнери можуть використовувати `display` для показу зон shell або приховування високорівневих торгових контейнерів. |
| Перевірка входу партнера | Партнерський бекенд | Перевірте сесію партнера користувача перед видачею облікових даних автентифікації. |
| Випуск вбудованих токенів | Партнерський бекенд + агент API | Рекомендую для режиму партнерського токена. |

<h2 id="versioning">Версування</h2>

Публічний шлях інтеграції залишається стабільним у скрипті v1 URL. Поточний набір можливостей v1 включає партнер-токен, tokenProvider, entryUrlProvider, керування відображенням, події життєвого циклу, методи екземплярів та події порядку.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Коли користуватися віджетом</h2>

Обирайте Trading Widget , коли партнеру потрібен повний торговий інтерфейс у межах існуючого веб-продукту. Використовуйте REST API та WebSocket документацію при створенні та підтримці повністю індивідуального торгового інтерфейсу.

<h2 id="implementation-path">Шлях реалізації</h2>

1. Слідуйте за [Trading Widget Quick Start](/uk/sdk/trading-widget/quick-start), щоб завантажити скрипт і створити видимий контейнер.
2. Налаштувати [автентифікацію партнера-токену](/uk/sdk/trading-widget/authentication) через партнерський бекенд.
3. Додайте необхідні [опції та події](/uk/sdk/trading-widget/options-events).
4. Використовуйте [методи екземплярів](/uk/sdk/trading-widget/instance-methods) для керування життєвим циклом і виконанням.
