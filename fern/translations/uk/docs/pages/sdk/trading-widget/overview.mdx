## Розподіл відповідальності

| Площа | Власник | Примітки |
| --- | --- | --- |
| Створення контейнера | Інтерфейс партнера | Надайте видимий елемент із явною шириною та висотою. |
| створення iframe | Trading Widget SDK | SDK створює iframe і керує ним. |
| Інтерфейс для торгівлі | 6MM iframe | K-line, книга замовлень, форма замовлення, позиції, замовлення та дані облікового запису запускаються в iframe. |
| Елементи керування дисплеєм | Trading Widget SDK + 6MM iframe | За замовчуванням заголовок і нижній тикер вбудованого ПК приховані. Партнери можуть використовувати `display`, щоб показати зони оболонки або приховати торгові контейнери високого рівня. |
| Перевірка входу партнера | Партнерський бекенд | Перевірте сеанс партнера перед видачею облікових даних авторизації. |
| Вбудований випуск токенів | Партнерська серверна частина + агент API | Рекомендовано для режиму партнерського маркера. |

## Керування версіями

Загальнодоступний шлях інтеграції залишається стабільним у сценарії v1 URL. Поточний набір можливостей v1 включає маркер партнера, tokenProvider, entryUrlProvider, елементи керування відображенням, події життєвого циклу, методи екземплярів і події замовлення.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

## Коли використовувати віджет

Виберіть Trading Widget, якщо партнеру потрібен повний торговий інтерфейс у наявному веб-продукті. Використовуйте натомість документацію REST API і WebSocket під час створення та підтримки повністю індивідуального торгового інтерфейсу.

## Шлях реалізації

1. Дотримуйтесь [Trading Widget Швидкий старт](/uk/sdk/trading-widget/quick-start) щоб завантажити сценарій і створити видимий контейнер.
2. Налаштувати [автентифікація маркера партнера](/uk/sdk/trading-widget/authentication) через серверний сервер партнера.
3. Додайте необхідне [параметри та події](/uk/sdk/trading-widget/options-events).
4. використання [методи екземпляра](/uk/sdk/trading-widget/instance-methods) для керування життєвим циклом і часом виконання.

## Перевірене публічне середовище виконання

Загальнодоступний сценарій `v1` повідомляє про версію `1.8.0` станом на 10.10.2026. Це URL є стабільною точкою входу основної версії, а не закріпленою збіркою. Прочитайте `TradingWidget.version` і `TradingWidget.capabilities` у вашому завантаженому середовищі виконання перед використанням додаткових функцій. Java Agent SDK `v0.3.0` є окремим серверним пакетом.

Середа виконання підтримує один активний екземпляр (`multiInstance=false`); створення іншого віджета знищує попередній екземпляр. Його підтримувані локалі `en`, `en-US` і `zh-CN`, незалежно від 20 мов документації.
