Планування ліцензій є частиною ширшого плану запуску. Правильний шлях залежить від цільових ринків, типу користувача, обсягу продукту, моделі зберігання та операційних обов'язків кожної сторони.

<h2 id="planning-inputs">Вхідні дані для планування</h2>

| Вхідні дані | Чому це важливо |
| --- | --- |
| Цільова юрисдикція | Визначає регуляторні очікування та необхідний місцевий перегляд. |
| Тип користувача | Роздрібні, професійні, інституційні або партнерські користувачі можуть потребувати різних режимів контролю. |
| Обсяг продукту | Функції спотових обліків, деривативів, гаманця, зберігання спостереження та брокерської діяльності можуть змінити модель відповідності. |
| Операційна модель | Моделі whitelabel, embedded, broker та інституційні моделі мають різні межі відповідальності. |

<h2 id="how-to-use-this-documentation">Як користуватися цією документацією</h2>

Використовуйте ці документи для узгодження технічних та операційних вимог перед юридичним розглядом. Документація допоможе командам описати архітектуру, потік даних, підписання, безпеку, переміщення активів і обов'язки за життєвий цикл торгівлі.

> **Важливо**
>
> Рішення щодо ліцензування мають розглядатися з кваліфікованими юридичними та комплаєнсними консультантами відповідної юрисдикції.
