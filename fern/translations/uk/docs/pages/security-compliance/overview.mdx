Документація з безпеки та відповідності пишеться для партнерських команд, які готують виробниче використання 6MM торгової інфраструктури. Вона об'єднує архітектуру безпеки, контроль API/SDK , підготовку відповідності, юридичні межі та готовність до запуску в один шлях перевірки.

<h2 id="documentation-map">Карта документації</h2>

| API та безпека вебхуків | Захищайте інтеграції бекенду через підписування, секретне зберігання та ідемпотентну обробку. |

<h2 id="recommended-reading-order">Рекомендований порядок читання</h2>

1. Почніть з архітектури безпеки та межі відповідальності партнера.
2. Перегляньте API Key управління, підписання запитів та ідемпотентність Webhook перед інтеграцією бекенду.
3. Перегляньте огляд відповідності та підтримку ліцензій перед підготовкою до регіонального запуску.
4. Перегляньте юридичні сторінки та чек-лист запуску перед тим, як розкривати торгові функції користувачам.
