Винятки можуть включати переривання ціни, суперечливі докази ціни, розбіжності коефіцієнтів або невдалу обробку розрахунків. Виняток вимагає записаної резолюції; це не автоматично програшний результат.

<span id="поширені-ситуації" data-sixmm-anchor-target="common-situations" aria-hidden="true"></span>
<h2 id="common-situations">Поширені ситуації</h2>

| Ситуація | Що робити |
| --- | --- |
| Під час дійсного вікна відсутній канал сітки | Перевірити виняток/обробку повернення коштів; відсутність зразка не може підтвердити промах |
| Час очікування відповіді на замовлення минув | Перегляньте оригінальне замовлення та бронювання перед повторним надсиланням |
| Дисплей і записаний результат не збігаються | Порівняйте джерело ціни, часові позначки, прийняті умови та докази результатів |
| Здається, що розрахунок затримується | Перевірте остаточний статус і транзакцію окремо |
| Повернено або анульовано запис | Перегляньте причину, фактичний рух коштів і резервування, що залишилося |

<span id="відшкодування-та-анулювання-відрізняються" data-sixmm-anchor-target="refund-and-void-are-distinct" aria-hidden="true"></span>
<h2 id="refund-and-void-are-distinct">Відшкодування та анулювання відрізняються</h2>

Відшкодування описує лікування коштів. Недійсність описує визнання замовлення недійсним. Не визначайте точну суму відшкодування або кінцевий термін обробки лише на етикетці; використовувати записані рішення та транзакції.

Повернені та анульовані замовлення виключаються з дійсної ставки у звітності. Відшкодування не слід вважати виграшними прибутками під час оцінки продуктивності ігрового процесу.

<span id="докази-підтримки" data-sixmm-anchor-target="support-evidence" aria-hidden="true"></span>
<h2 id="support-evidence">Докази підтримки</h2>

Укажіть номер замовлення, кругле число, якщо застосовно, символ, відповідні мітки часу, записаний множник виплати, результат/статус і номер розрахункової операції. Для суперечок щодо мережі вкажіть прийнятний ціновий інтервал і дійсне часове вікно. Ніколи не включайте паролі, API секрети або маркери повного доступу.

використання [Підтримка партнерів](/uk/resources/contact/support) для опорного шляху і [Перекази та транзакції](/uk/prediction/transfers-ledger) для примирення.
