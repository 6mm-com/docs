Кожен прийнятий порядок передбачення має власний номер замовлення. Ордери вгору/вниз також посилаються на раунд; Спеціальні та сіткові замовлення не вимагають спільного раунду.

<span id="current-and-historical-records" data-sixmm-canonical-anchor="current-and-historical-records" aria-hidden="true"></span>

## Поточні та історичні записи

| Відображений статус | Як це читати |
| --- | --- |
| Очікування результату | Остаточних результатів ще не зафіксовано |
| Ставки закриті | Відображений етап ставок закрито; це не результат виграшу/програшу |
| виграв | Замовлення реєструється як виграшний результат |
| Загублений | Замовлення реєструється як програшний результат |
| Повернено | Обробка відшкодування відображається в статусі замовлення; звірити фактичну операцію |
| Анульовано | Наказ визнано недійсним; перевірте причину та відповідне лікування фонду |

Не кожна гра використовує кожен проміжний статус однаково. Сама по собі мітка статусу не доводить, що кредит рахунку завершено.

<span id="fields-to-check" data-sixmm-canonical-anchor="fields-to-check" aria-hidden="true"></span>

## Поля для перевірки

Усі ігри містять номер замовлення, право власності користувача, символ, ставку, шанси, час замовлення та статус. Історичні записи додають фактичну виплату, інформацію про результат, час розрахунку та номер розрахункової операції.

- Вгору/Вниз додає кругле число та прогнозований/фактичний напрямок.
- Custom додає фіксовані коефіцієнти та незалежний термін дії.
- Сітка додає вибрану клітинку та ціновий інтервал; інтерпретувати поля результатів за допомогою правила дотику вікна часу.

<span id="changes-and-duplicate-submissions" data-sixmm-canonical-anchor="changes-and-duplicate-submissions" aria-hidden="true"></span>

## Зміни та дублікати подання

Не припускайте, що прогнозне замовлення може бути змінено або скасовано, як безстрокове лімітне замовлення. Дотримуйтеся дій і правил, доступних для прийнятого продукту. Якщо відповідь на подання невизначена, запитайте оригінальне замовлення, перш ніж робити іншу ставку.
