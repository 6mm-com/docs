Прогноз передбачає загальний шлях порядку та коштів із різними правилами часу для кожної гри.

## Життєвий цикл замовлення

| етап | Що перевірити |
| --- | --- |
| Вибір і цитата | Гра, символ, сума, шанси та умови ціни/часу |
| Прийняття | Номер замовлення, записані умови та успішне прийняття |
| Кошти зарезервовано | Резервування замовлення на рахунку поповнення |
| Очікування результату | Оцінка круглого результату, незалежне закінчення терміну дії або дійсне вікно сітки |
| Обробка результату | Достовірне підтвердження ціни та застосовні правила замовлення |
| Поселення | Остаточний статус, фактична виплата та розрахункова операція |
| Примирення | Історія замовлень відповідає руху по рахунку |

## Хронометраж по грі

- **Вгору/Вниз:** замовлення належать до запланованого раунду. Ставки закриваються до обробки результату.
- **Власний:** кожне замовлення має власну ціну відкриття та термін дії. Замовлення іншого користувача може мати інший час.
- **Сітка:** вибрана клітинка має дійсний час початку та закінчення. Дотик за межами цього вікна не кваліфікується.

## Якщо обробка перервана

Не виводьте остаточний результат на основі відключеної сторінки чи затримки оновлення балансу. Знову відкрийте запис замовлення, перевірте його поточний статус і звірте пов’язану транзакцію. Якщо підтвердження ціни або обробка розрахунків є ненормальною, дотримуйтесь [Відшкодування та винятки](/uk/prediction/refunds-exceptions).

## Ведіть відстежуваний облік

Для підтримки збережіть номер замовлення, гру, символ, час замовлення, відображений статус і номер розрахункової транзакції, якщо він є. Кругле число допомагає ідентифікувати ордери вгору/вниз; сам по собі знімок екрана сітки не ідентифікує збережений порядок.
