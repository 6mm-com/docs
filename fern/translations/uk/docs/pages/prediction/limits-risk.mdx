Запропонована гра чи пропозиція не гарантують, що кожне запропоноване замовлення може бути прийнято. На прийняття впливають доступні кошти, конфігурація продукту та контроль ризиків.

<span id="common-restrictions" data-sixmm-canonical-anchor="common-restrictions" aria-hidden="true"></span>

## Загальні обмеження

| обмеження | Ефект |
| --- | --- |
| Гра або символ вимкнено | Вибраний товар недоступний для нових замовлень |
| Період не ввімкнено | Цю тривалість не можна вибрати для символу |
| Одноразовий мінімум/максимум | Ставка має бути в межах відображеного дозволеного діапазону |
| Контроль сукупної ставки або експозиції | Подальші замовлення можуть бути обмежені, навіть якщо єдина ставка дійсна |
| Контроль відхилення коефіцієнтів | Цитата може вимагати перегляду або введення прогнозу може бути обмежено |
| Котирування сітки вище максимуму | Комірка недоступна за правилом ціноутворення сітки |
| Закрите вікно ставок | Нове замовлення не може бути прийнято в закрите вікно |

Модель керування включає сповіщення, перегляд, передбачені обмеження та відкладену обробку замовлень. Фактична відповідь залежить від запущеного правила; не припускайте, що кожне обмеження дає однаковий результат.

<span id="stake-and-model-risk" data-sixmm-canonical-anchor="stake-and-model-risk" aria-hidden="true"></span>

## Ставка і модельний ризик

Програшне замовлення без виплати втрачає свою частку. Вищі коефіцієнти не є доказом кращої можливості: вони можуть відображати нижчу оцінену ймовірність попадання. Параметр цільової прибутковості не гарантує доходності окремої особи.

<span id="configuration-changes" data-sixmm-canonical-anchor="configuration-changes" aria-hidden="true"></span>

## Зміни конфігурації

Перевірте поточні налаштування товару перед новим замовленням. Для прийнятих користувальницьких і сіткових замовлень збережені коефіцієнти та відповідні знімки замовлень запобігають перевизначенню цих прийнятих умов після оновлення екрана.

<span id="when-an-order-is-unavailable" data-sixmm-canonical-anchor="when-an-order-is-unavailable" aria-hidden="true"></span>

## Коли замовлення недоступне

Перевірте зміну продукту, доступний баланс, ліміти, котирування та час. Не надсилайте повторно, щоб обійти обмеження. Збережіть відповідь та ідентифікатор замовлення, якщо він був створений.
