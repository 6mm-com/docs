Зовнішні депозити та зняття коштів обробляються через авторизовану партнерську платформу. Прогнозне фінансування має відповідати включеному обліковому запису та потоку переказів цієї платформи.

<span id="before-a-transfer" data-sixmm-canonical-anchor="before-a-transfer" aria-hidden="true"></span>

## Перед пересадкою

Підтвердьте вихідний рахунок, цільовий рахунок фінансування, валюту, суму переказу та обмеження облікового запису. Загальна сума активів не означає, що всі активи доступні для передачі: незавершені замовлення або інша бізнес-діяльність можуть резервувати частину балансу.

Використовуйте підтримуваний запис переказу для облікового запису, який фактично є власником. Не копіюйте маршрут спот-до безстрокового довідника з безстрокової торгівлі як маршрут фінансування прогнозу.

<span id="reconcile-an-order" data-sixmm-canonical-anchor="reconcile-an-order" aria-hidden="true"></span>

## Узгодити замовлення

| запис | Перевірте |
| --- | --- |
| Перевести у фінансування | Ідентифікатор підприємства, валюта, сума та завершений статус |
| Бронювання прогнозу | Початковий порядок передбачення та зарезервована сума |
| Поселення | Кінцевий результат, фактична виплата та номер транзакції |
| Повернення або звільнення | Оригінальне замовлення, сума та остаточний баланс, яких це стосується |
| Окрема плата | Тип комісії, сума та пов’язане замовлення чи транзакція |

<span id="uncertain-transfer-responses" data-sixmm-canonical-anchor="uncertain-transfer-responses" aria-hidden="true"></span>

## Непевні відповіді на переказ

Перш ніж ініціювати заміну, запитайте оригінальний ідентифікатор передачі. Тайм-аут не доводить, що передавання не вдалося. Звірте остаточну операцію з балансом рахунку, враховуючи інші одночасні рухи рахунку.

<span id="partner-operations" data-sixmm-canonical-anchor="partner-operations" aria-hidden="true"></span>

## Партнерські операції

Звіти партнерів можуть узагальнювати прогнози за датою або місяцем, процесом гри, символом і результатом користувача. Зберігайте дійсні ставки, виплати, відшкодування та нестандартну компенсацію окремо. Конвенція про звітність визначає прогнозований чистий дохід як дійсну частку мінус виплату мінус ненормальну компенсацію; це не такий самий показник, як прибуток окремого користувача.
