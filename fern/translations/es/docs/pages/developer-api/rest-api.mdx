<h2 id="public-endpoints">Puntos finales públicos</h2>

| Punto final                   | Método | Camino                                        | Descripción                                                    |
| -------------------------- | ------ | ------------------------------------------- | -------------------------------------------------------------- |
| Versión de servicio            | GET    | `/v1/version`                               | Obtenga información sobre la versión del servicio                                |
| Tiempo de servidor                | GET    | `/v1/time`                                  | Consigue tiempo en el servidor                                                |
| Inicio de sesión de usuario                 | POST   | `/v1/public/user/login`                     | Usa el nombre de usuario y la contraseña para obtener `accessToken`              |
| Token de actualización              | POST   | `/v1/public/user/refresh-token`             | Actualizar estado de inicio de sesión mediante Cookie                                 |
| Intercambio de billetes de agente      | POST   | `/v1/public/agent-sso/exchange-ticket`      | Cambia un ticket de entrada de agente por el estado de inicio de sesión              |
| Intercambio de Token Embed de Agente | POST   | `/v1/public/agent-sso/exchange-embed-token` | Intercambia un token de trading embebido de corta duración por un estado de inicio de sesión |
| Configuración de símbolos       | GET    | `/v1/public/market/symbols`                 | Consigue símbolos, reglas de trading y configuración de niveles de comisiones         |
| Configuración de la tasa de financiación | GET    | `/v1/public/market/funding-rate`            | Consulta a la configuración de la tasa de financiación                               |
| Tasa actual de financiación       | GET    | `/v1/public/market/funding-rate/current`    | Paginar las tasas actuales de financiación                                 |
| Historial de tasas de financiación       | GET    | `/v1/public/market/funding-rate/history`    | Consulta historial de tasas de financiación                                     |
| Klines                     | GET    | `/v1/public/market/klines`                  | Consulta el precio de operación, el precio del índice o marca el precio Klines           |
| Clasificación de PnL            | GET    | `/v1/public/leaderboard/pnl`                | Consulta tabla de clasificación PnL de 7 / 30 / 90 días                          |

<h2 id="private-user-endpoints">Endpoints de usuarios privados</h2>

Salvo que se especifique lo contrario, los siguientes puntos finales pueden usar JWT o API Key firma.

| Punto final                 | Método | Camino                                      | Permiso   | Descripción                                 |
| ------------------------ | ------ | ----------------------------------------- | ------------ | ------------------------------------------- |
| Información del usuario                | GET    | `/v1/private/user/info`                   | Lee         | Consulta el perfil de usuario actual                  |
| Activos de usuario              | GET    | `/v1/private/user/asset`                  | Lee         | Consulta saldo de cartera y uso de márgenes       |
| Crea listenKey         | POST   | `/v1/private/user/listen-key`             | Lee         | Crear clave de autenticación WebSocket privada |
| Renovar listenKey          | PUT    | `/v1/private/user/listen-key`             | Lee         | Ampliar listenKey validez                   |
| Cierra listenKey          | DELETE | `/v1/private/user/listen-key`             | Lee         | Cierra listenKey                             |
| Registros de cambios de cuenta      | GET    | `/v1/private/user/account-change-log`     | Lee         | Consulta registros de movimiento de fondos                 |
| Estadísticas de volumen a 30 días | GET    | `/v1/private/user/volume-stats`           | Lee         | Consulta el volumen y las comisiones de operaciones recientes a 30 días |
| Historial de balance          | GET    | `/v1/private/user/balance-history`        | Lee         | Historial de balance de consultas                       |
| Resumen del sector           | GET    | `/v1/private/user/trade-overview`         | Lee         | Consulta PnL, volumen y tendencia de activos          |
| Resumen general de activos   | GET    | `/v1/private/user/asset/overview/summary` | Lee         | Consulta métricas resumen de activos                 |
| Tendencia general de activos     | GET    | `/v1/private/user/asset/overview/trend`   | Lee         | Consulta la tendencia del activo                           |
| Guardar símbolos favoritos    | POST   | `/v1/private/user/favorite-symbols`       | Lee         | Sobrescribir símbolos favoritos                  |
| Consigue símbolos favoritos     | GET    | `/v1/private/user/favorite-symbols`       | Lee         | Consulta símbolos favoritos                      |
| Cierre de sesión                   | POST   | `/v1/private/user/logout`                 | JWT + Cookie | Borrar estado de inicio de sesión                           |

<h2 id="api-key-management-endpoints">API Key Endpoints de gestión</h2>

API Key endpoints de gestión solo aceptan JWT.

| Punto final            | Método | Camino                                  | Descripción                                         |
| ------------------- | ------ | ------------------------------------- | --------------------------------------------------- |
| Crea API Key      | POST   | `/v1/private/user/api-key/create`     | Crea API Key; `apiSecret` solo se devuelve una vez   |
| API Key lista        | GET    | `/v1/private/user/api-key/list`       | Consulta las claves de API del usuario actual                       |
| Actualización API Key      | PUT    | `/v1/private/user/api-key/update`     | Etiqueta de actualización, permisos, lista blanca IP y estado |
| Elimina API Key      | POST   | `/v1/private/user/api-key/delete`     | Elimina un API Key especificado                          |
| Elimina todas las API Claves | POST   | `/v1/private/user/api-key/delete-all` | Eliminar todas las API Claves del usuario actual             |

<h2 id="order-endpoints">Órdenes finales</h2>

Los puntos finales de órdenes requieren permiso de intercambio.

| Punto final                    | Método | Camino                                  | Descripción                                                       |
| --------------------------- | ------ | ------------------------------------- | ----------------------------------------------------------------- |
| Consulta en un solo orden          | GET    | `/v1/private/order`                   | Consulta exacta por `symbol + orderId/clientOrderId`                   |
| Orden de colocación                 | POST   | `/v1/private/order/place`             | Límite u orden de mercado                                             |
| Orden de condición de lugar       | POST   | `/v1/private/order/place-condition`   | Stop loss, take profit, trailing stop y otras órdenes de condición |
| Colocar la estrategia en orden        | POST   | `/v1/private/order/place-strategy`    | OTO / OCO / OTOCO orden de estrategia                                  |
| Pedidos por lotes          | POST   | `/v1/private/order/batch-place`       | Envía varios pedidos normales                                     |
| Cancelar pedido                | POST   | `/v1/private/order/cancel`            | Cancelar un orden normal especificado                                   |
| Orden de enmienda                 | POST   | `/v1/private/order/move`              | Modificar el precio y la cantidad normales de las órdenes pendientes                    |
| Órdenes de enmienda por lotes          | POST   | `/v1/private/order/batch-move`        | Modificar por lotes órdenes normales pendientes para el mismo símbolo            |
| Cancelación por lote de pedidos         | POST   | `/v1/private/order/batch-cancel`      | Cancelar pedidos normales por lote                                        |
| Cancelar todo                  | POST   | `/v1/private/order/batch-cancel-all`  | Cancelación por lote de pedidos por tipo                                       |
| Orden de cancelación de condición      | POST   | `/v1/private/order/cancel-condition`  | Cancelar un orden de condición especificado                                |
| Órdenes normales actuales       | GET    | `/v1/private/order/current`           | Consulta órdenes normales pendientes actuales                               |
| Órdenes de estado actual    | GET    | `/v1/private/order/current-condition` | Consulta órdenes de condición no activadas actuales                        |
| Órdenes normales históricos    | GET    | `/v1/private/order/history`           | Paginar órdenes normales históricos                                 |
| Órdenes de condición histórica | GET    | `/v1/private/order/history-condition` | Paginar órdenes de condición histórica                              |
| Récords de traspasos               | GET    | `/v1/private/order/trades`            | Registros de intercambio de paginas                                            |
| Detalle del orden de la estrategia       | GET    | `/v1/private/order/strategy`          | Orden de la estrategia de consulta y subórdenes                               |

<h2 id="position-endpoints">Puntos finales de posición</h2>

Los puntos finales de posición requieren permiso de intercambio.

| Punto final          | Método | Camino                               | Descripción                                  |
| ----------------- | ------ | ---------------------------------- | -------------------------------------------- |
| Establecer el modo de margen   | POST   | `/v1/private/position/margin-mode` | Conmutador aislado / margen cruzado               |
| Palanca de establecimiento      | POST   | `/v1/private/position/leverage`    | Palanca de símbolo de establecimiento                          |
| Configuración de posición | GET    | `/v1/private/position/settings`    | Apalancamiento de consulta y modo de margen para un símbolo  |
| Cargos actuales | GET    | `/v1/private/position/positions`   | Consulta posiciones actuales                      |
| Historial de posiciones  | GET    | `/v1/private/position/history`     | Consulta posiciones históricas y registros cerrados |
