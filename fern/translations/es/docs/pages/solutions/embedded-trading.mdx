El Sistema de Trading Embedded API / SDK está diseñado para socios que ya poseen tráfico, usuarios o flujos de trabajo empresariales y que quieren añadir trading sin tener que construir un exchange completo desde cero.

<h2 id="what-it-provides">Lo que ofrece</h2>

- Terminal de negociación integrado a través de la Trading Widget SDK
- Integración backend de socios a través de Agent SDKs
- Enlaces de identidad del usuario y flujos de tokens de entrada
- Transferencia de activos, pedidos, posiciones y acceso API cuenta
- Integración de eventos, webhooks y ciclos de vida para sistemas operativos

<h2 id="recommended-architecture">Arquitectura recomendada</h2>

| Capa | Responsabilidad |
| --- | --- |
| Interfaz de socios | Aloja el punto de entrada e integra la interfaz de trading 6MM . |
| Backend del socio | Guarda API secretos, valida a los usuarios, emite tokens de incrustación y procesa webhooks. |
| 6MM infraestructura de negociación | Se encarga de la interfaz de trading, emparejamiento, riesgo, liquidez, estado de la cuenta y ciclo de vida del trading. |

<h2 id="choose-an-integration-path">Elige una ruta de integración</h2>

| Requisito | Ruta recomendada |
| --- | --- |
| Interfaz de trading completa con la integración web más rápida | Trading Widget |
| Vinculación de usuario backend, transferencia, URLde entrada y manejo de webhook | Agent SDK |
| Flujos de trabajo totalmente personalizados de productos y pedidos | REST API + WebSocket |
| Experiencia en intercambios de marca con un alcance operativo más amplio | Intercambio de marca blanca |

El diseño final puede combinar estos caminos. Confirma la autenticación, la propiedad de activos, los límites de responsabilidad, la monitorización y el soporte en producción antes de que comience la implementación.
