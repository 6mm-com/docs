<h2 id="runtime">Duración</h2>

| Punto | Valor |
| --- | --- |
| Paquete | Sixmm/agente-SDK |
| Versión mínima PHP | PHP 7,4+ |
| Versión PHP recomendada | PHP 8.1+ o versiones actualmente compatibles |
| Extensiones requeridas | ext-json, ext-curl |

El código fuente del paquete PHP SDK y la versión aprobada se proporcionan durante la incorporación del socio. No asumas que el paquete está disponible desde el Packagist público; configura el repositorio Composer proporcionado para tu organización.

<h2 id="supported-scenarios">Escenarios compatibles</h2>

| Escenario | SDK método |
| --- | --- |
| Vincular usuario | Atar |
| Transferencia de cantidad fija | Transferencia |
| Transfiere todo | transferAllOut |
| Transferencia inversa | Reversa |
| Orden de consulta | queryOrder |
| Crear URL | createEntryUrl |
| Verificación de Webhook | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Reglas de integración en el backend</h2>

- Cargar `apiSecret` desde un gestor secreto o una variable de entorno protegido.
- Mantener la lógica de enlace, transferencia, firma y webhook fuera del código del navegador.
- Utilizar cadenas decimales para los importes de activos para evitar redondeos en coma flotante.
- Reutilizar el `agentOrderNo` original al consultar un resultado de transferencia incierto.
- Verificar las firmas de webhook contra el cuerpo de la solicitud en bruto antes de decodificarlo o cambiarlo.
