<h2 id="install">Instalación</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Acceso al paquete**
>
> 6MM proporciona el nombre del paquete Composer aprobado, el repositorio y la versión durante la incorporación del socio. No se debe asumir que el paquete existe en Packagist público.

<h2 id="before-you-start">Antes de empezar</h2>

- Confirma que el Agente API base URL con 6MM.
- Cargar apiSecret desde variables de entorno o gestión de secretos.
- Mantener SDK uso solo dentro de los servicios backend.
- Preparar el manejo de idempotentes para transferencias y flujos de webhook.

<h2 id="initialize-client">Inicializar cliente</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Solo backend**
>
> El PHP SDK firma solicitudes de Agent API y no debe ser expuesto a través de código fuente público ni entornos de ejecución frontend.

<h2 id="example-transfer-funds-in">Ejemplo: transferir fondos en</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Usa cadenas decimales para las cantidades y conserva la agentOrderNo original al volver a intentar o consultar el estado de la transferencia.
