Utiliza esta plantilla al preparar una nueva integración o al trasladar una integración existente a producción.

<h2 id="partner-information">Información sobre socios</h2>

| Campo | Descripción |
| --- | --- |
| Nombre del socio | Se utilizó el nombre legal o del proyecto para la integración. |
| Tipo de producto | App, cartera, portal de corredores, exchange de marca blanca, plataforma institucional u otra. |
| Contactos principales | Contactos de negocios, técnicos, operaciones y emergencias. |
| Regiones de lanzamiento | Países o regiones donde se expondrá la integración. |

<h2 id="technical-information">Información técnica</h2>

| Campo | Descripción |
| --- | --- |
| Dominios frontend | Dominios que cargarán el widget o las páginas de entrada. |
| Dominios backend | Dominios de servidor usados para llamadas Agent SDK o API . |
| Webhook URL | Endpoint de webhook en producción y requisitos esperados de IP lista de permisos. |
| Alcance de integración | Trading Widget, Agent SDK, REST API, WebSocket, sistema de marca blanca o integración de liquidez. |

<h2 id="operational-information">Información operativa</h2>

- Fecha prevista de lanzamiento.
- Tráfico esperado o rango de usuarios activos.
- Propietario de horas de soporte y escalamiento.
- Monitorizar al propietario y al contacto con incidentes.

<h2 id="security-and-review-information">Información de seguridad y revisión</h2>

- Método de autenticación y API Key ámbito de permisos.
- Almacenamiento secreto, propietario de rotación e IPs de fuente aprobadas.
- Verificación de firma de webhook y diseño de idempotencia.
- Propietarios de registro, monitorización, conciliación, retroceso y respuesta a incidentes.
- Mercados objetivo, tipo de usuario, modelo de custodia y la entidad responsable de las obligaciones de cara al usuario.

No incluyas secretos de producción, tokens de acceso completo, claves privadas ni datos de usuario no censurados en esta plantilla.

Utiliza la [lista de verificación de lanzamiento de producción](/es/resources/production-launch-checklist) para la aprobación final y la [plantilla de solicitud de soporte](/es/resources/support-request-template) para la escalada de incidencias.
