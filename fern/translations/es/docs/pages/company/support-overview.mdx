6MM soporte está diseñado para socios autorizados, integraciones activas y operaciones de producción. El soporte para usuarios finales sigue siendo responsabilidad de la plataforma de socios salvo que se acuerde por separado.

<h2 id="choose-the-right-path">Elige el camino correcto</h2>

| Situación | Ruta recomendada | Incluye |
| --- | --- | --- |
| Nueva asociación o evaluación de soluciones | Vía de incorporación de socios | Tipo de producto, región objetivo, cronología de lanzamiento, modelo de integración esperado. |
| SDK, API, webhook o pregunta sobre el entorno | Camino de soporte técnico | Endpoint, versión SDK , ID de solicitud, pasos de reproducción, registros. |
| Incidente de producción o flujo comercial degradado | Ruta de escalada de incidentes | Alcance del impacto, hora de inicio, usuarios afectados, IDs de pedidos, mitigación actual. |
| Cambio de activos, copias o material de lanzamiento | Ruta de soporte operativo | Página, idioma, cambio solicitado, fecha de lanzamiento, propietario de la aprobación. |
| Vulnerabilidad o sospecha de abuso | Ruta de informes de seguridad | Detalles técnicos, punto final afectado, evidencia, urgencia, si el problema está activo. |

<h2 id="severity-guide">Guía de gravedad</h2>

| Gravedad | Ejemplo |
| --- | --- |
| Crítica | No están disponibles el trading de producción, la autenticación, la emisión de tokens o los flujos relacionados con fondos. |
| Alto | Un flujo principal de socios se degrada, pero existe una solución alternativa. |
| Normal | Pregunta de integración, solicitud de configuración, problema de documentación o soporte de lanzamiento planeado. |

<h2 id="before-contacting-support">Antes de contactar con el soporte</h2>

- Confirmar la zona de producto y el entorno afectados.
- Recopilar IDs de solicitud, IDs de pedido, marcas de tiempo, IDs de mapeo de usuarios, IDs de eventos de webhook y registros.
- Utilizar la plantilla de solicitud de soporte para problemas de producción.
