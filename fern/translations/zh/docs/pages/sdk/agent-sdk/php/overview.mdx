<h2 id="runtime">运行环境</h2>

| 项 | 值 |
| --- | --- |
| 包名 | sixmm/agent-sdk |
| 最低 PHP 版本 | PHP 7.4+ |
| 推荐 PHP 版本 | PHP 8.1+ 或当前仍受安全支持的版本 |
| 必需扩展 | ext-json、ext-curl |

PHP SDK 的包源和批准版本会在合作方接入阶段提供。不要假设该包已发布到公共 Packagist；请配置 6MM 为你所在组织提供的 Composer 仓库。

<h2 id="supported-scenarios">支持场景</h2>

| 场景 | SDK 方法 |
| --- | --- |
| 绑定用户 | bind |
| 固定金额划转 | transfer |
| 一键全部划出 | transferAllOut |
| 冲正 | reverse |
| 查询订单 | queryOrder |
| 创建入口 URL | createEntryUrl |
| Webhook 验签 | WebhookVerifier::verify |

<h2 id="backend-integration-rules">后端接入规则</h2>

- 从密钥管理系统或受保护的环境变量加载 `apiSecret`。
- 用户绑定、划转、签名和 Webhook 逻辑不得放入浏览器代码。
- 资产金额使用十进制字符串，避免浮点数舍入误差。
- 划转结果不确定时，使用原始 `agentOrderNo` 查询，不要生成新订单号重试。
- 解析或修改请求体之前，先使用原始请求体校验 Webhook 签名。
