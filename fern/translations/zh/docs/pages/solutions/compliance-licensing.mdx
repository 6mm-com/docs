合规牌照与交易技术方案将交易基础设施和合规规划支持结合起来，帮助合作伙伴准备合规化数字资产交易业务。

<h2 id="who-this-is-for">适用团队</h2>

本指南适用于正在评估嵌入式交易或白标交易所业务的产品、合规、安全、法务和研发团队，帮助各团队在针对具体司法辖区进行专业审查前，准备技术证据并明确责任划分。

<h2 id="what-this-covers">覆盖内容</h2>

- 面向合规运营的技术架构
- API、SDK 和白标部署路径
- 牌照和司法辖区规划支持
- 安全与密钥管理要求
- 事件响应和用户保护相关运营流程

<h2 id="planning-questions">需要确认的问题</h2>

| 范围 | 需要确认的问题 |
| --- | --- |
| 目标市场 | 业务涉及哪些司法辖区和用户类型？ |
| 产品范围 | 将提供哪些交易、资产、托管或经纪能力？ |
| 运营模式 | 使用嵌入式交易、白标界面、API，还是组合方案？ |
| 责任划分 | 哪一方负责用户准入、信息披露、客服、监控和事件升级？ |
| 数据与安全 | 凭证、用户数据、日志和运营证据保存在哪里？ |

<h2 id="recommended-workflow">建议工作流程</h2>

1. 明确目标市场、用户类型和计划提供的产品。
2. 记录技术架构和数据流。
3. 为每项运营流程分配合作方与 6MM 的责任。
4. 检查凭证存储、请求签名、Webhook 和事件响应控制。
5. 完成针对目标司法辖区的法律与合规审查。
6. 上线前使用生产检查清单收集相关证据。

<h2 id="important-note">重要说明</h2>

6MM 文档可以说明技术要求、运营流程和接入责任边界。法律、监管和牌照相关决策，应由合作方结合目标司法辖区咨询具备资质的专业顾问。
