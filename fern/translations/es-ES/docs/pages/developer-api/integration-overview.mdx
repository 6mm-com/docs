> REST Base URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Esta documentación está destinada a sistemas externos que se integran con el servicio 6MM API . Cubre inicio de sesión, autenticación JWT , gestión de API Key , firma de API Key HMAC , consultas de cuentas, órdenes, posiciones, datos de mercado y flujos de WebSocket .

La provisión de cuentas y la preparación de financiación se gestionan mediante procesos en el lado de la plataforma. Esta documentación solo describe los endpoints de servicio API llamables externamente.

<h2 id="service-endpoints">Puntos finales de servicio</h2>

| Tipo      | Punto final              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="integration-flow">Flujo de integración</h2>

Secuencia recomendada de integración:

1. Inicia sesión con la cuenta proporcionada por la plataforma y obtén un `accessToken`.
2. Para el acceso programático del lado del servidor, crear primero un API Key con JWT y almacenar de forma segura la `apiSecret`única devolvida de forma única.
3. Las consultas privadas y los endpoints de órdenes y posiciones pueden llamarse con `Authorization: Bearer <accessToken>` o mediante firma con API Key.
4. Para flujos de WebSocket privados, crea primero un `listenKey` y luego conéctate a `wss://ws.6mm.com/ws?listenKey=...`.
5. Los datos de mercado REST los puntos finales y los canales públicos de WebSocket no requieren autenticación.

<h2 id="authentication-choice">Elección de autenticación</h2>

| Escenario                               | Método recomendado         |
| -------------------------------------- | -------------------------- |
| Acciones del usuario frontal                  | JWT                        |
| Llamadas programáticas en el lado del servidor         | API Key + HMAC firma   |
| API Key creación, actualización y eliminación | JWT                        |
| REST de mercado público / WebSocket pública  | No se requiere autenticación |
