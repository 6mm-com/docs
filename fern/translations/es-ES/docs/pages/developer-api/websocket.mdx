## Punto final de servicio

```
wss://ws.6mm.com/ws
```

WebSocket canales se dividen en canales públicos y privados:

| Tipo             | Autenticación              | Descripción                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Canales públicos  | No es obligatorio                | Datos de mercado, como la profundidad, las operaciones, las Klines y el ticker |
| Canales privados | `listenKey` o JWT requerido | Órdenes, cuentas y flujos de posición de usuario              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## Canales públicos

La WebSocket pública no requiere autenticación. Después de conectarte, envía una solicitud de `subscribe` para suscribirte a los canales de mercado.

Canales comunes:

| Canal                            | Descripción                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Profundidad de libro de pedidos. Envía primero una instantánea y luego actualizaciones incrementales |
| `market.trade.{symbol}`            | Últimas operaciones                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Resumen del ticker de un solo símbolo                                       |
| `market.tickers`                   | Resumen del ticker de todos los símbolos                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## Canales privados

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
Para WebSocket privados de streams, crea primero una `listenKey` a través de la REST API y luego conéctate a:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
Método de conexión JWT compatible:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Tras el éxito de la autenticación, el servidor suscribe automáticamente la conexión al canal privado del usuario actual. No se requiere suscripción manual.
