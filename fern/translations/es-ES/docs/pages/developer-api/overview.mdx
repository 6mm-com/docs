<h2 id="production-checklist">Lista de verificación de producción</h2>

- Guardar API secretos solo en el backend.
- Sincronizar el tiempo del servidor antes de las solicitudes firmadas.
- Tratar todos los campos de precisión numérica como cadenas a menos que una página diga explícitamente lo contrario.
- Utilizar idempotencia, identificadores de petición y registros estructurados alrededor de los flujos de pedidos.
- Suscribirse a WebSocket flujos para estados que deben mantenerse actualizados en los sistemas operativos.
- Revisar los códigos de error y el comportamiento de reintentar antes del lanzamiento.
