Utilice la descripción general del saldo para una verificación rápida, los registros de uso para investigar las llamadas y el libro mayor para comprender los cambios del saldo. Lea la unidad y el tipo de servicio antes de comparar montos.

<div className="sixmm-support-flow">

1. **Consulte la descripción general**: revise el saldo y los gastos recientes.
2. **Encontrar el uso**: filtre el servicio y el rango de tiempo relevantes.
3. **Conciliar el saldo**: compare el cargo final con los cambios del libro mayor.

</div>


<span id="review-intelligent-service-usage" data-sixmm-canonical-anchor="review-intelligent-service-usage" aria-hidden="true"></span>

## Revisar el uso del servicio inteligente

Abra **Uso y facturación** para inspeccionar el saldo, los precios de los servicios disponibles, los registros de uso y los movimientos del saldo. Las respuestas de IA, la traducción y las operaciones vectoriales pueden consumir el saldo del servicio inteligente compartido según los servicios configurados del inquilino.

La ruta de respuesta de soporte es importante: una respuesta almacenada y una solicitud de modelo grande no son el mismo tipo de uso. La disponibilidad de modelos y precios puede cambiar; Utilice la consola actual en lugar de las cantidades fijas de esta guía.

<span id="understand-settlement" data-sixmm-canonical-anchor="understand-settlement" aria-hidden="true"></span>

## entender la liquidación

El servicio puede reservar una cantidad estimada antes de una solicitud medida. El uso confiable de aguas arriba se utiliza para la liquidación normal según las reglas existentes. Cuando se devuelve un resultado válido pero no hay un uso confiable disponible, el monto reservado se puede retener como cargo alternativo sin volver a aplicar el búfer. Las solicitudes fallidas o los resultados no válidos liberan el monto reservado según las reglas de falla.

Una reserva no supone un segundo cargo adicional. Compare el cargo final, la reserva original y cualquier ajuste de saldo antes de interpretar un registro. Las unidades estimadas de reserva no deben interpretarse como tokens medidos en sentido ascendente.

<span id="mcp-and-costs" data-sixmm-canonical-anchor="mcp-and-costs" aria-hidden="true"></span>

## MCP y costos

MCP no introduce una regla de facturación separada, pero las herramientas que invocan la plataforma AI, la traducción o los servicios vectoriales pueden incurrir en sus costos normales. Un proveedor externo de IA puede cobrar de forma independiente por su propio servicio. Las herramientas de facturación pueden leer saldos, uso, transacciones y precios; no pueden recargar saldos ni editar facturas.


<span id="use-the-right-billing-view" data-sixmm-canonical-anchor="use-the-right-billing-view" aria-hidden="true"></span>

## Utilice la vista de facturación correcta

| Vista | lo que responde |
| --- | --- |
| Uso | Cuando se llamó a un servicio, sus unidades de entrada/salida en su caso, cargo final y estado. |
| Libro mayor de saldos | El tipo y monto de cada saldo cambian, con el saldo antes y después. |
| Precios de servicio | El servicio actualmente disponible y su unidad de precio. Utilice la tarifa mostrada en lugar de un precio copiado de un documento antiguo. |

<span id="example-investigate-an-unexpected-balance-change" data-sixmm-canonical-anchor="example-investigate-an-unexpected-balance-change" aria-hidden="true"></span>

### Ejemplo: investigar un cambio de saldo inesperado

1. Anote el tiempo aproximado y seleccione el rango relevante. Utilice el filtro de servicio para separar la IA, la traducción, la detección de idioma y las incrustaciones.
2. Lea el estado de la llamada y el monto final cobrado. Un mensaje en pantalla no es en sí mismo un registro de facturación.
3. Revise los cambios en el libro mayor para el mismo período, incluidos el consumo, los reembolsos y otros ajustes mostrados.
4. Si las cifras aún necesitan explicación, conserve el rango de tiempo, el servicio y los detalles de registro relevantes para el operador de la plataforma. No vuelva a ejecutar repetidamente una operación facturable sólo para ver si el número cambia.

**Diferentes servicios utilizan diferentes unidades.** La generación de texto de IA puede tener precios de tokens de entrada y salida; El precio del servicio de incorporación se basa en el uso de insumos. Lea las unidades de traducción o detección de idioma tal como se muestran en lugar de tratar cada número como tokens.

## Preguntas comunes

<AccordionGroup>

<Accordion title="¿Una retención inicial es un segundo cargo?">
No. Es parte del proceso de liquidación descrito anteriormente. Revise el cargo final y los ajustes de saldo juntos en lugar de agregar la retención nuevamente.
</Accordion>

<Accordion title="¿Conectar MCP hace que todo el uso de IA sea gratuito?">
No. Los servicios de plataforma existentes aún pueden consumir el saldo compartido y la aplicación de IA externa puede tener sus propios cargos.
</Accordion>

</AccordionGroup>
