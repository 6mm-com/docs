## Consola y soporte para visitantes

| Síntoma | comprobar primero |
| --- | --- |
| falta un menú | Rol de cuenta y disponibilidad del servicio de inquilino |
| El widget no se abre | Script generado URL, clave de aplicación, dominio permitido y errores del navegador |
| Bot no usa el modelo grande. | Paso coincidente real, interruptores de servicio inteligentes y configuración relevante |
| Una respuesta utiliza reglas antiguas. | Artículo fuente, estado de publicación, FAQ texto, traducción y estado de recuperación |
| La traducción está ausente | Idioma de destino, cambio de traducción, traducción guardada y disponibilidad de servicio/saldo |
| La generación de vectores falla | Disponibilidad del servicio y estado de recuperación; Evite reconstruir repetidamente sin identificar la falla. |
| Un campo de contacto está vacío | Si ese campo fue realmente recopilado; distinguir correo electrónico de contacto y de entrada |

## MCP conexión y llamadas

| Síntoma | Siguiente paso |
| --- | --- |
| Abrir el punto final en un navegador devuelve un error | Es un punto final de protocolo, no una página de inicio de sesión; agréguelo a un cliente MCP compatible |
| La autorización no puede comenzar | Verifique el punto final exacto, la compatibilidad con Streamable HTTP/OAuth del cliente y el flujo de inicio de sesión del navegador |
| Conexión no autorizada o caducada | Cheque de revocación y caducidad; reconectarse a través de la aplicación |
| Falta una herramienta o se deniega el acceso | Verifique la función de la cuenta de autorización y el alcance del registro; actualizar la lista de herramientas |
| En espera de aprobación | Abra el enlace de aprobación devuelto y revíselo en el backend. |
| Contenido cambiado | Lea el registro más reciente, obtenga una vista previa nuevamente y envíe una nueva operación prevista |
| Solicitud agotada | Consultar el estado de la operación antes de volver a intentarlo o asumir un error. |
| Sin registro de escritura | Distinguir una lectura, pendiente de aprobación y escritura completada; comprobar filtros en registros de operación |

<span id="before-contacting-support" data-sixmm-canonical-anchor="before-contacting-support" aria-hidden="true"></span>

## Antes de contactar al soporte

Recopile la hora y la zona horaria, el inquilino/cuenta afectado, el nombre de la página o herramienta, el ID de la operación cuando esté disponible y el error exacto. Incluya una captura de pantalla redactada o pasos para reproducirla. No envíe contraseñas, códigos de verificación, tokens de portador ni secretos de firma.

Pruebe con un pequeño registro de prueba al diagnosticar escrituras. Verifique el resultado y limpie solo los datos de prueba que creó, utilizando el flujo de confirmación normal cuando sea necesario.
