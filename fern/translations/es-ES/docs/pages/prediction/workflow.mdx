La predicción sigue un proceso común de orden y fondos, con diferentes reglas de tiempo para cada juego.

## Ciclo de vida del pedido

| Escenario | Que comprobar |
| --- | --- |
| Selección y cotización | Condiciones de juego, símbolo, cantidad, probabilidades y precio/tiempo |
| Aceptación | Número de pedido, condiciones registradas y aceptación exitosa |
| Fondos reservados | La reserva del pedido en la cuenta de financiación. |
| Esperando resultado | Evaluación de resultados redondos, vencimiento independiente o ventana válida de la grilla |
| Procesamiento de resultados | Pruebas autorizadas de precios y reglas aplicables al pedido. |
| Asentamiento | Estado final, pago real y transacción de liquidación |
| Reconciliación | El historial de pedidos coincide con los movimientos de la cuenta |

## Cronometraje por juego

- **Arriba/Abajo:** las órdenes pertenecen a una ronda programada. Las apuestas se cierran antes de que se procese el resultado.
- **Personalizado:** cada pedido tiene su propio precio de apertura y vencimiento. El pedido de otro usuario puede tener tiempos diferentes.
- **Cuadrícula:** la celda seleccionada tiene una hora de inicio y finalización válida. Un toque fuera de esa ventana no califica.

## Si se interrumpe el procesamiento

No infiera un resultado final a partir de una página desconectada o una actualización retrasada del saldo. Vuelva a abrir el registro del pedido, verifique su estado actual y concilie la transacción asociada. Si la evidencia de precio o el procesamiento de liquidación son anormales, siga [Reembolsos y Excepciones](/es-ES/prediction/refunds-exceptions).

## Mantenga un registro rastreable

Para obtener asistencia, conserve el número de pedido, el juego, el símbolo, la hora del pedido, el estado mostrado y el número de transacción de liquidación, si está presente. Un número redondo ayuda a identificar órdenes arriba/abajo; una captura de pantalla de la cuadrícula por sí sola no identifica un pedido almacenado.
