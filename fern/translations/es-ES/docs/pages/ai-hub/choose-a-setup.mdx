> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


Elija una configuración basada en dos preguntas:

1. ¿Qué cliente de IA quieres usar?
2. ¿Necesita únicamente datos públicos, acceso a cuentas privadas o flujos de trabajo comerciales?

Si no está seguro, comience con MCP alojado para datos públicos o MCP local para flujos de trabajo de cuentas privadas.

## Elegir por caso de uso

<CardGroup cols={2}>
<Card title="Sólo necesito datos del mercado público." icon="fa-duotone fa-cloud" href="/es-ES/ai-hub/hosted-mcp">

<Card title="Quiero que mi cliente AI lea mi cuenta" icon="fa-duotone fa-computer" href="/es-ES/ai-hub/local-mcp">
Utilice Local MCP con credenciales de solo lectura. Inicie en testnet o modo de solo lectura.
</Card>
<Card title="Mi agente puede ejecutar comandos de terminal" icon="fa-duotone fa-terminal" href="/es-ES/ai-hub/cli">
Utilice 6MM CLI. Esto es sencillo para Codex, Claude Code, Gemini CLI, scripts y tareas de CI.
</Card>
<Card title="Mi equipo necesita un punto final administrado" icon="fa-duotone fa-server" href="/es-ES/ai-hub/remote-mcp">
Utilice el control remoto MCP. Implemente el servidor en una infraestructura controlada por su equipo.
</Card>
</CardGroup>

## tabla de decisión rápida

| Meta | Configuración recomendada | Por qué |
| --- | --- | --- |
| Solicite a un cliente de IA datos del mercado público | Alojado MCP | No se requiere instalación local ni clave API. |
| Deje que Claude Desktop, Cursor o ChatGPT Desktop llamen a las herramientas 6MM | Locales MCP | La IA llama a las herramientas a través de un servidor local controlado por el usuario. |
| Deje que Codex, Claude Code, Gemini CLI o scripts llamen a 6MM | CLI | La salida del comando puede ser JSON y fácil de analizar para los agentes. |
| Proporcionar un punto final MCP administrado por la empresa | Remoto MCP | La institución controla el alojamiento, las credenciales, el acceso y los registros. |
| Estandarice análisis repetidos o flujos de trabajo de riesgos | Habilidades de agente | Las plantillas definen el uso de herramientas, las barreras de seguridad y el formato de salida. |

## Elegir por ruta de configuración

| Configuración | Instalación | API ubicación de la clave | Mejor alcance inicial | Cuenta y alcance comercial |
| --- | --- | --- | --- | --- |
| Alojado MCP | Ninguno | Sin clave de usuario API para datos públicos | Datos del mercado público | No recomendado para el primer lanzamiento. |
| Locales MCP | Paquete de instalación del usuario | Máquina de usuario | Datos públicos y lectura de cuentas. | Ruta recomendada para operaciones futuras |
| CLI | Paquete de instalación del usuario | Máquina de usuario | Datos públicos y scripts | Útil para vista previa y automatización. |
| Remoto MCP | El usuario implementa el servidor | Nube de usuarios o nube de instituciones | Datos públicos o lectura de cuenta | Posible cuando el usuario controla la implementación. |
| Habilidades | Documentos o plantillas instalables | Depende de las herramientas subyacentes | Flujos de trabajo de análisis | Debe seguir los permisos de la herramienta. |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## Regla general de seguridad

Utilice la configuración de menor riesgo que admita la tarea:

- Datos del mercado público: MCP alojado es suficiente.
- Datos de cuenta privada: Local MCP o Remoto MCP administrado por el usuario.
- Vista previa de operaciones: MCP local o CLI local, preferiblemente testnet primero.
- Comercio real: solo después de permiso explícito, vista previa, confirmación, límites y registros de auditoría.
