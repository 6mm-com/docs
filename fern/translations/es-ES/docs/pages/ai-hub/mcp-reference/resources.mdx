> **Planificado, aún no lanzado**
> AI Hub es una característica planificada. Las capacidades, puntos finales, comandos y configuraciones de cliente en esta página describen el diseño propuesto y no están disponibles actualmente. La disponibilidad final y las instrucciones de configuración se anunciarán en el lanzamiento.


MCP los recursos son contexto de solo lectura que los clientes de IA pueden inspeccionar antes de llamar a las herramientas.

Los recursos reducen las alucinaciones al brindarle al modelo información estructurada y estable sobre 6MM.

<span id="recommended-resource-uris" data-sixmm-canonical-anchor="recommended-resource-uris" aria-hidden="true"></span>

## URI de recursos recomendados

| Recurso | Objetivo |
| --- | --- |
| 6mm://sistema/config | Configuración del entorno y capacidades. |
| 6mm://sistema/estado | Sistema actual y situación del mercado. |
| 6mm://mercados | Mercados disponibles. |
| 6mm://mercado/{symbol} | Especificaciones del contrato y metadatos a nivel de mercado. |
| 6mm://tarifas | Reglas de tarifas. |
| 6mm://riesgo/reglas | Resumen de reglas comerciales y de riesgo. |
| 6mm://riesgo/margen | Contexto de margen y liquidación. |
| 6mm://financiación/reglas | Reglas de tasa de financiación. |
| 6 mm://api/docs | API resumen de referencia o enlaces. |

<span id="resource-design-rules" data-sixmm-canonical-anchor="resource-design-rules" aria-hidden="true"></span>

## Reglas de diseño de recursos.

- Mantenga los recursos en modo de solo lectura.
- Utilice esquemas estables.
- Incluya marcas de tiempo y nombres de entornos.
- Evite exponer secretos.
- Prefiera datos estructurados concisos a prosa larga.
- Enlace a documentación canónica cuando los detalles sean demasiado largos.
