<h2 id="which-path-should-i-choose">¿Qué camino debería elegir?</h2>

| Objetivo empresarial | Solución recomendada | Médicos principales |
| --- | --- | --- |
| Añadir trading a un producto existente | Embedded API / SDK Sistema de Comercio | SDK, desarrolladores |
| Mejorar la profundidad del mercado y la calidad de la ejecución | Soluciones de liquidez institucional | Trading, Desarrolladores |
| Lanza un exchange de marca rápidamente | Sistema de intercambio de marca blanca | Soluciones, Recursos |
| Prepárense para operaciones reguladas | Licencias y Consultoría de Cumplimiento | Seguridad y cumplimiento |

<h2 id="how-the-solutions-connect">Cómo se conectan las soluciones</h2>

La mayoría de las implementaciones de socios combinan más de una capacidad 6MM . Un exchange de marca blanca puede utilizar liquidez institucional, soporte de cumplimiento y integraciones API . Un socio comercial embebido puede comenzar con el Trading Widget SDK y luego añadir flujos de Agent SDK backend, procesamiento de webhooks y recursos operativos.
