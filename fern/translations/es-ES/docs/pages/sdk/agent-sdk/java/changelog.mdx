Esta guía está dirigida a **Agent Java SDK `v0.3.0`**, Java 8+ y el contrato público etiquetado. Los ejemplos se ejecutan en un backend asociado después de inicializar `client` en [Inicio rápido](/es-ES/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Seis consultas perpetuas: pedidos actuales, historial de pedidos, despachos, posiciones actuales, historial de posiciones y libro mayor de cuentas.
- Saldos de financiación, transferencias, consultas de recuperación y transferencias de financiación/contratos.
- Producción explícita/selección simulada para solicitudes de fondos apoyados.
- Guías de incrustación y redireccionamiento comercial en segundos, referencia del campo de respuesta e instrucciones de migración.

Java SDK y Trading Widget SDK tienen versiones independientes. El widget `v1` URL no es la versión Java SDK `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Integraciones existentes

Conserve las asignaciones de usuarios, los pedidos originales y las credenciales. Los campos de entorno omitidos conservan el comportamiento de producción existente. La financiación, los fondos simulados explícitos y seis consultas perpetuas requieren los nuevos modelos y métodos correspondientes. Revisar [Guía de actualización](/es-ES/sdk/agent-sdk/java/upgrade) antes de cambiar una integración existente.
