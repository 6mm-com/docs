## Trading Widget Insertar token

El token de inserción es para el modo Trading Widget SDK `partner-token + tokenProvider`. El
el navegador llama al backend asociado y el backend asociado llama a esto Java SDK
para crear un `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Requisitos de integración:

- `channelId` debe usar el valor pasado por el Trading Widget SDK.
- `symbol` es opcional, pero se recomienda pasar el símbolo inicial actual.
- `embedToken` es de corta duración y único. No lo ponga en URL cadenas de consulta.
- La interfaz del socio nunca debe contener `apiSecret`.
- `expireAt` es una marca de tiempo de Unix en segundos, no un TTL.

Ejemplo de punto final de backend de socio:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Contrato de punto final de socio

Autenticar la sesión del socio y derivar `agentUserId` del lado del servidor. Aceptar el widget actual `channelId`; devuelve el nivel superior `embedToken`, `expireAt` (segundos de Unix) y el mismo `channelId`. Las respuestas del agente no proporcionan `channelId`: su backend lo repite. Obtenga un token nuevo durante la inicialización y renovación; nunca lo reutilices. La creación de tokens no transfiere fondos ni elige el entorno de la billetera.

Ver [Comercio de segundos](/es-ES/sdk/agent-sdk/java/seconds-trading) para el flujo completo de frontend/backend.
