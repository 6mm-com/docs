<h2 id="runtime">Duración</h2>

| Punto | Valor |
| --- | --- |
| Versión mínima Java | Java 8+ |
| Herramienta de construcción recomendada | Maven 3.9+ |
| Grupo Maven | `com.sixmm.exchange.sdk` |
| Artefacto de Maven | `agent` |
| Etiqueta de fuente documentada | `v0.1.1` |

El repositorio público de GitHub es alojamiento de fuentes, no un repositorio de dependencias de Maven. Compila e instala el código fuente etiquetado localmente o publica el artefacto aprobado en el repositorio privado de Maven de tu organización antes de usarlo en compilaciones de equipos.

<h2 id="typical-backend-responsibilities">Responsabilidades típicas en backend</h2>

- Validar la sesión de usuario asociada.
- Mapear al usuario socio a agentUserId.
- Vincular llamadas antes de los primeros flujos de negociación o transferencia.
- Llama createEntryUrl para una única vez en el SSOcompleto.
- Llamar createEmbedToken para Trading Widget modo de token de compañero.
- Verificar los webhooks de transferencia y procesarlos idempotentemente.

<h2 id="security-and-operational-rules">Normas de seguridad y operaciones</h2>

- Almacenar `apiSecret` solo en un gestor de secretos de backend o en una variable de entorno protegido.
- Mantener sincronizado el tiempo del servidor porque las solicitudes firmadas contienen marcas de tiempo.
- Tratar `agentOrderNo` como una clave de idempotencia duradera y mantenerla única a nivel global.
- Almacenar `platformUserId` como una cadena y persistir su relación con `agentUserId`.
- Consultar la transferencia original antes de volver a intentarlo tras un tiempo de espera o un resultado de red incierto.
