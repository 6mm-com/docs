Esta guía está dirigida a **Agent Java SDK `v0.3.0`**, Java 8+ y el contrato público etiquetado. Los ejemplos se ejecutan en un backend asociado después de inicializar `client` en [Inicio rápido](/es-ES/sdk/agent-sdk/java/quick-start).

Línea base de documentación: SDK `v0.3.0`, confirmar `54aa3c1`.

## Versión e instalación

| Artículo | Valor |
| --- | --- |
| Etiqueta de origen estable | `v0.3.0` |
| Java | Java 8+ |
| experto | Maven 3.9+ |
| Coordenadas | `com.sixmm.exchange.sdk:agent:0.3.0` |

Fuente de alojamiento de GitHub; no hace que estas coordenadas se puedan resolver desde Maven Central. Utilice la instalación local etiquetada o su repositorio de artefactos aprobado.

## Configuración

Obtenga los siguientes valores de 6MM antes
integrando.

| Artículo | Ejemplo | Descripción |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Agente API base URL, sin barra diagonal |
| `agentCode` | `AGENT001` | código de socio |
| `apiSecret` | `your-api-secret` | API secreto de firma. Manténgalo solo en el backend |
| `defaultCurrency` | `USDT` | Moneda predeterminada, normalmente `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Punto final de socio para devoluciones de llamadas 6MM |

Recomendaciones de producción:

- Utilice HTTPS para los puntos finales del Agente API y webhook.
- Almacene `apiSecret` en un administrador secreto, centro de configuración o variable de entorno.
- Mantenga la hora del servidor sincronizada, preferiblemente con NTP.
- Conserve todos los números de pedido de los socios y manténgalos únicos a nivel mundial.
- Nunca envíe `apiSecret` a navegadores, aplicaciones, miniprogramas o código fuente de interfaz.


<span id="automatic-signing-fields" data-sixmm-canonical-anchor="automatic-signing-fields" aria-hidden="true"></span>

## Campos de firma automática

Para llamadas firmadas del Agente API, el SDK inyecta automáticamente:

| Campo | Fuente | Descripción |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | código de socio |
| `timestamp` | Marca de tiempo Unix actual UTC | Artículos de segunda clase |
| `nonce` | Generador aleatorio seguro | Protección de repetición |
| `sign` | HMAC-SHA256 | Solicitar firma |
| `currency` | `defaultCurrency` | Se completa cuando las solicitudes de transferencia/cuenta omiten moneda |

Reglas de firma:

1. Excluir `sign`.
2. Excluir valores vacíos.
3. Ordenar claves por orden ASCII.
4. Únase como `k=v&k2=v2`.
5. Calcula HMAC-SHA256 hexadecimal con `apiSecret`.

Los valores de la matriz se serializan como JSON compacto antes de unirse a la carga útil de firma. Por ejemplo, `platformUserIds` firma como `["1188041528"]`, dando `platformUserIds=["1188041528"]` en la carga útil `k=v`. Preservar el orden de los elementos de la matriz, las comillas dobles y los ID de cadenas; no inserte espacios de formato ni utilice Java `List.toString()` (como `[1188041528]`). El SDK maneja esta serialización automáticamente.

El código comercial normal no debe calcular firmas ni configurarse manualmente
`agentCode`, `timestamp`, `nonce` o `sign`.
