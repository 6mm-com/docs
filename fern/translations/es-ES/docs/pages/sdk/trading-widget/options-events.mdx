## Opciones

| Campo | Tipo | Default | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origen de la escritura | Dominio iframe. Pasar explícitamente en las páginas asociadas. |
| Símbolo | string | BTCUSDT | Normalizado a mayúsculas y tiras - / _. |
| Tema | oscuro \| luz | oscuro | Parámetro inicial del tema. |
| Ubicación | en \| en-US \| zh-CN | Navegador/predeterminado | Se admiten inglés y chino simplificado. |
| Distribución | por defecto \| compacto | Por defecto | Opción de distribución reservada. |
| Pantalla | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Controla que incrustan áreas de concha y contenedores comerciales de alto nivel. |
| Auth | object | ninguno | Usa partner-token para nuevas integraciones SSO . |

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Controles de pantalla

`display` controla la shell de la página de trading incrustada y los contenedores de alto nivel. En los embebidos de socios, la cabecera PC y el ticker de mercado inferior están ocultos por defecto.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Default | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | falso | Si mostrar la cabecera embebided del PC dentro del iframe. |
| showTicker | boolean | falso | Si mostrar el ticker de mercado en la carcasa embebid. |
| oculto | cuerda[] | [] | Esconde contenedores de alto nivel en la página de intercambio. |

Valores `display.hidden` apoyados:

| Valor | Contenedor |
| --- | --- |
| Lista | Contenedor de cartas |
| orderBook | Contenedor de libros de pedidos |
| orderForm | Panel de formularios de pedido |
| Cargos | Posiciones inferiores y panel de órdenes abiertas |
| Cuenta | Contenedor de activos de la cuenta |

`display.hidden` oculta solo contenedores enteros. No oculta botones, campos o herramientas individuales dentro de un contenedor. Se ignoran los valores que no se asignan al viewport actual.

## Eventos

| Evento | Disparador |
| --- | --- |
| Listo | Inicialización del iframe finalizada. |
| Error | SDK, iframe o error de autenticación. |
| state_changed | SDK estado del ciclo de vida cambió. |
| auth_state_changed | El estado de autenticación del token de socio cambió. |
| symbol_changed | El símbolo real del iframe cambió. |
| locale_changed | La ubicación real del iframe cambió. |
| order_created | El usuario creó un pedido dentro del iframe. |
| order_failed | Envío de pedido fallido. |
| destruido | SDK instancia destruida. |
