## Resumen del método

| Método | Objetivo |
| --- | --- |
| destruir() | Elimine el iframe y libere los detectores de eventos. |
| getState() | Lea el estado actual del ciclo de vida SDK. |
| whenReady() | Espere hasta que el iframe finalice la inicialización. |
| setSymbol(símbolo) | Cambie el par comercial dentro del iframe. |
| setTheme(tema) | Actualice el parámetro del tema iframe. |
| setLocale(localización) | Cambie el idioma del iframe. |
| setSize(ancho, alto) | Actualizar las dimensiones del iframe. |
| recargar() | Vuelva a cargar el iframe actual. |
| refreshAuth(razón) | Activa el flujo de actualización de autenticación del widget. |
| setTokenProvider(proveedor) | Reemplace el proveedor utilizado por el modo de token de socio. |
| en (evento, controlador) | Suscríbase a eventos en tiempo de ejecución y reciba una función para cancelar la suscripción. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## destruir()

Elimine el iframe, borre los oyentes y emita destruido una vez para la instancia actual.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Lea el estado actual del ciclo de vida de la instancia del widget.

```js
const state = widget.getState()
```

Los valores de retorno incluyen carga, autenticación, listo, error y destruido.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Espere a que el iframe finalice la inicialización antes de ejecutar la lógica de UI dependiente.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(símbolo)

Cambie el par comercial dentro del iframe. Si el iframe aún se está inicializando, SDK pone en cola el comando y lo envía cuando esté listo.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(tema)

Actualice el parámetro de tema utilizado por el iframe comercial integrado.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(localización)

Cambie el idioma del iframe. Los valores admitidos son en, en-US y zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(ancho, alto)

Actualice el tamaño del iframe DOM y notifique al iframe sobre el nuevo tamaño exterior. Los valores numéricos se convierten a px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## recargar()

Vuelva a cargar el iframe actual y espere a que se inicialice nuevamente.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(razón)

Solicite al iframe que actualice el flujo de autenticación actual. El valor de motivo opcional se reenvía para el registro y el control de flujo.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(proveedor)

Reemplace el tokenProvider utilizado por el modo de token de socio. El SDK llama al proveedor cuando el iframe solicita un token de inserción nuevo.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## en (evento, controlador)

Suscríbete a un evento de tiempo de ejecución. La función devuelta elimina al oyente.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Métodos adicionales en el tiempo de ejecución v1 actual

| Método | Objetivo |
| --- | --- |
| `whenRendered()` | Espere la notificación renderizada del iframe; esto está separado de listo. |
| `setPage(page)` | Solicite una página de producto compatible en la instancia actual. No cambia el entorno de los fondos. |
| `prepareForRecreate()` | Solicite un iframe listo para prepararse para el reemplazo; devuelve una promesa y puede rechazarla si no está disponible, está ocupada o se agotó el tiempo de espera. |
| `cancelRecreate()` | Cancelar un flujo de reemplazo pendiente/preparado. |
| `TradingWidget.validateOptions(options)` | Valide las opciones de inicialización antes de crear una instancia. |

Para un cambio de usuario o de entorno real/de demostración, destruya la instancia anterior y cree una nueva con el modo y la autenticación de destino. No utilice `setPage` como conmutador de entorno. Verifique las capacidades antes de usar métodos opcionales.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
