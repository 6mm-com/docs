## División de responsabilidades

| Área | Propietario | Notas |
| --- | --- | --- |
| Creación de contenedores | Interfaz de socios | Proporciona un elemento visible con ancho y altura explícitos. |
| Creación de iFrame | Trading Widget SDK | El SDK crea y gestiona el iframe. |
| Interfaz de Comercio | 6MM iframe | K-line, libro de pedidos, formulario de pedido, posiciones, órdenes y datos de cuenta se ejecutan dentro del iframe. |
| Controles de pantalla | Trading Widget SDK + 6MM iframe | La cabecera y el ticker inferior de embed del PC están ocultos por defecto. Los socios pueden usar `display` para mostrar áreas de shell o ocultar contenedores de trading de alto nivel. |
| Comprobación de inicio de sesión del socio | Backend del socio | Valida la sesión de usuario del socio antes de emitir las credenciales de autenticación. |
| Emisión de tokens incrustados | Backend de socios + Agente API | Recomendado para el modo de fichas de socio. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Versión

La ruta de integración pública permanece estable bajo el script v1 URL. El conjunto actual de capacidades v1 incluye partner-token, tokenProvider, entryUrlProvider, controles de visualización, eventos del ciclo de vida, métodos de instancia y eventos de orden.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Cuándo usar el widget

Elige Trading Widget cuando un socio necesite una interfaz de trading completa dentro de un producto web existente. Utiliza la documentación de REST API y WebSocket al construir y mantener una interfaz de trading totalmente personalizada.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Ruta de implementación

1. Seguir el [Trading Widget Inicio rápido](/es-ES/sdk/trading-widget/quick-start) para cargar el script y crear un contenedor visible.
2. Configurar [Autenticación por token de socio](/es-ES/sdk/trading-widget/authentication) A través de un backend asociado.
3. Añadir lo requerido [Opciones y eventos](/es-ES/sdk/trading-widget/options-events).
4. Uso [Métodos de instancia](/es-ES/sdk/trading-widget/instance-methods) para los controles del ciclo de vida y de la ejecución.
