Ένα σαφές μοντέλο ευθύνης μειώνει τον λειτουργικό κίνδυνο και βοηθά τις ομάδες υποστήριξης να ανταποκρίνονται ταχύτερα.

<h2 id="responsibility-split">Καταμερισμός ευθυνών</h2>

| Περιοχή | 6MM | Εταίρος |
| --- | --- | --- |
| Εμπορική υποδομή | Δυνατότητες αντιστοίχισης, κινδύνου, μηχανής συναλλαγών, API και SDK | Σωστή ενσωμάτωση και παρακολούθηση παραγωγής |
| Σχέση τελικού χρήστη | Δεν υπάρχει άμεση σχέση με τον πελάτη, εκτός εάν συμφωνηθεί χωριστά | Ενσωμάτωση χρηστών, υποστήριξη, αποκαλύψεις και κύκλος ζωής λογαριασμού |
| Μυστικά και διαπιστευτήρια | Παρέχει μοντέλο διαπιστευτηρίων και απαιτήσεις υπογραφής | Αποθηκεύει μυστικά με ασφάλεια και περιορίζει την εσωτερική πρόσβαση |
| Webhooks | Αποστέλλει υπογεγραμμένα συμβάντα κύκλου ζωής | Επαληθεύει τις υπογραφές και επεξεργάζεται τα συμβάντα ανίκανα |
| Λειτουργίες συμμόρφωσης | Παρέχει τεχνολογία προσανατολισμένη στη συμμόρφωση και υποστηρικτικό υλικό | Επιβεβαιώνει τις τοπικές υποχρεώσεις και τις απαιτήσεις που αντιμετωπίζουν οι χρήστες |
| Εκδόσεις ενσωμάτωσης | Διατηρεί τεκμηριωμένη πλατφόρμα και δυνατότητες ενσωμάτωσης | Ελέγχει τον κώδικα συνεργάτη, τη ρύθμιση παραμέτρων και τις διαδρομές χρήστη πριν από την κυκλοφορία |
| Χειρισμός περιστατικών | Διερευνά τη σχετική υποδομή 6MM και παρέχει κανάλια υποστήριξης συνεργατών | Ανιχνεύει τον αντίκτυπο που αντιμετωπίζει ο χρήστης, διατηρεί αποδεικτικά στοιχεία, περιέχει συστήματα συνεργατών και κλιμακώνει |

<h2 id="responsibilities-by-lifecycle">Ευθύνες ανά κύκλο ζωής</h2>

| Στάδιο | Δράση εταίρου |
| --- | --- |
| Σχέδιο | Καθορίστε την ιδιοκτησία χρήστη, τη ροή πόρων, τη ροή δεδομένων, το μοντέλο υποστήριξης και τις δικαιοδοσίες-στόχους. |
| Κατασκευή | Διατηρήστε μυστικά στο backend, εφαρμόστε υποστηριζόμενο έλεγχο ταυτότητας και διατηρήστε τα αναγνωριστικά επιχείρησης. |
| Δοκιμή | Άσκηση χρονικού ορίου, επανάληψης, διπλότυπωνwebhook, ληγμένων διακριτικών και σεναρίων αποτυχίας. |
| Εκτόξευση | Ολοκληρώστε τον έλεγχο ετοιμότητας, καθιερώστε την παρακολούθηση και την κλιμάκωση της υποστήριξης εγγράφων. |
| Λειτουργία | Ελέγξτε τις ειδοποιήσεις, συμβιβάστε μη φυσιολογικές λειτουργίες, εναλλάσσετε διαπιστευτήρια και διατηρείτε αποδεικτικά στοιχεία ελέγχου. |
| Περιστατικό | Περιορίστε συστήματα που ελέγχονται από συνεργάτες, προστατέψτε τα διαπιστευτήρια, διατηρήστε UTC χρονοδιαγράμματα και επικοινωνήστε με το σωστό κανάλι 6MM . |

<h2 id="handoff-checklist">Λίστα ελέγχου λειτουργικής παράδοσης</h2>

- Ονομάστε τον κάτοχο για την εύρυθμη λειτουργία, την ασφάλεια, τη συμμόρφωση και την υποστήριξη τελικού χρήστη ενοποίησης.
- Διευθύνσεις URL βάσης παραγωγής εγγράφων, κάτοχοι διαπιστευτηρίων και διαδικασίες εναλλαγής.
- Επιβεβαιώστε τους πίνακες εργαλείων και τις ειδοποιήσεις για αποτυχίες ελέγχου ταυτότητας, παραγγελίας, μεταφοράς και webhook .
- Αποθηκεύστε αναγνωριστικά αιτημάτων, αριθμούς παραγγελιών συνεργατών και αναγνωριστικά συμβάντων σε αρχεία καταγραφής με δυνατότητα αναζήτησης.
- Καθορίστε ποια συμβάντα απαιτούν άμεση κλιμάκωση.
- Κρατήστε το [Πρότυπο αιτήματος υποστήριξης](/el/resources/support-request-template) στη διάθεση της επιχειρησιακής ομάδας.
