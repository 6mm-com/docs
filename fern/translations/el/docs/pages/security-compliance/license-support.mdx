Ο σχεδιασμός αδειών αποτελεί μέρος ενός ευρύτερου σχεδίου εκτόξευσης. Η σωστή διαδρομή εξαρτάται από τις αγορές-στόχους, τον τύπο χρήστη, το εύρος του προϊόντος, το μοντέλο θεματοφυλακής και τις λειτουργικές ευθύνες κάθε μέρους.

<span id="planning-inputs" data-sixmm-canonical-anchor="planning-inputs" aria-hidden="true"></span>

## Εισροές προγραμματισμού

| Εισαγωγή | Γιατί έχει σημασία |
| --- | --- |
| Δικαιοδοσία-στόχος | Καθορίζει τις ρυθμιστικές προσδοκίες και την απαιτούμενη τοπική αναθεώρηση. |
| Τύπος χρήστη | Οι χρήστες λιανικής, επαγγελματίες, θεσμικοί ή συνεργάτες ενδέχεται να απαιτούν διαφορετικούς ελέγχους. |
| Πεδίο εφαρμογής προϊόντος | Τα χαρακτηριστικά spot, παραγώγων, πορτοφολιού, φύλαξης και μεσιτείας μπορούν να αλλάξουν το μοντέλο συμμόρφωσης. |
| Μοντέλο λειτουργίας | Τα μοντέλα λευκής ετικέτας, ενσωματωμένα, μεσιτών και θεσμικών μοντέλων έχουν διαφορετικά όρια ευθύνης. |

<span id="how-to-use-this-documentation" data-sixmm-canonical-anchor="how-to-use-this-documentation" aria-hidden="true"></span>

## Πώς να χρησιμοποιήσετε αυτήν την τεκμηρίωση

Χρησιμοποιήστε αυτά τα έγγραφα για να ευθυγραμμίσετε τις τεχνικές και λειτουργικές απαιτήσεις πριν από τον νομικό έλεγχο. Η τεκμηρίωση μπορεί να βοηθήσει τις ομάδες να περιγράψουν την αρχιτεκτονική, τη ροή δεδομένων, την υπογραφή, την ασφάλεια, τη μετακίνηση περιουσιακών στοιχείων και τις ευθύνες του κύκλου ζωής των συναλλαγών.

> **Σημαντικό**
>
> Οι αποφάσεις αδειοδότησης πρέπει να επανεξετάζονται με ειδικευμένους νομικούς συμβούλους και συμβούλους συμμόρφωσης για τη σχετική δικαιοδοσία.
