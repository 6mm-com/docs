6MM τεκμηρίωση ασφαλείας εστιάζει στην ετοιμότητα παραγωγής συνεργατών. Ο στόχος είναι να διατηρηθεί σταθερή η υποδομή συναλλαγών, καθιστώντας παράλληλα σαφή τα όρια ευθύνης.

<h2 id="security-layers">Επίπεδα ασφαλείας</h2>

| Επίπεδο | Συγκεντρώνω |
| --- | --- |
| Υποδομή | Απομόνωση δικτύου, κρυπτογραφημένη επικοινωνία υπηρεσιών, παρακολούθηση και ανακατεύθυνση. |
| Συστήματα συναλλαγών | Ντετερμινιστική αντιστοίχιση, έλεγχοι περιθωρίου, έλεγχοι κινδύνου και πρόληψη κατάχρησης. |
| Ασφάλεια ενσωμάτωσης | API κλειδιά, HMAC υπογραφή, webhook υπογραφές, προστασία επανάληψης και μυστικά μόνο για backend. |
| Λειτουργίες συνεργατών | Επικύρωση περιόδου λειτουργίας χρήστη, φύλαξη περιουσιακών στοιχείων, υποστήριξη πελατών και τοπικοί έλεγχοι συμμόρφωσης. |

<h2 id="partner-responsibilities">Ευθύνες εταίρων</h2>

- Κρατήστε API μυστικά και τα κλειδιά υπογραφής από προγράμματα περιήγησης και εφαρμογές για κινητά.
- Επικυρώστε τις συνεδρίες χρηστών συνεργατών πριν από την έκδοση διαπιστευτηρίων καταχώρισης συναλλαγών.
- Εφαρμογή ελέγχων webhook ανικανότητας και κατάστασης τερματικού.
- Διατηρήστε λειτουργικά αρχεία καταγραφής για ροές λογαριασμού, παραγγελιών, μεταφοράς και webhook .

<h2 id="integration-trust-boundaries">Όρια εμπιστοσύνης ενσωμάτωσης</h2>

| Όριο | Απαιτούμενος έλεγχος |
| --- | --- |
| Πρόγραμμα περιήγησης ή εφαρμογή σε υποστήριξη συνεργάτη | Επικυρώστε τη συνεδρία συνεργάτη πριν από την έκδοση οποιουδήποτε διαπιστευτηρίου συναλλαγών. |
| Υποστήριξη συνεργάτη για 6MM API | Χρησιμοποιήστε διαπιστευτήρια εμβέλειας, υπογραφή αιτημάτων, συγχρονισμό ώρας και προστατευμένο μυστικό χώρο αποθήκευσης. |
| 6MM webhook στο τελικό σημείο συνεργάτη | Επαληθεύστε την υπογραφή σε σχέση με το ακατέργαστο σώμα αιτήματος, απορρίψτε μπαγιάτικα ή μη έγκυρα μηνύματα και καταργήστε τις διπλότυπες επαναλήψεις. |
| Αρχεία κατάστασης συναλλαγών προς εταίρο | Συμβιβάστε εντολές, θέσεις, υπόλοιπα και μεταφορές χρησιμοποιώντας ανθεκτικά αναγνωριστικά και ελέγχους κατάστασης τερματικού. |

<h2 id="production-verification">Επαλήθευση παραγωγής</h2>

- Η δοκιμή έληξε, ανακλήθηκε και εσφαλμένα διαπιστευτήρια.
- Δοκιμάστε τροποποιημένα σώματα webhook , διπλότυπες επανακλήσεις, καθυστερημένες επανακλήσεις και χρονικά όρια τελικού σημείου.
- Επιβεβαιώστε ότι τα αρχεία καταγραφής αποκρύπτουν μυστικά, διακριτικά πρόσβασης και ευαίσθητα φορτία αιτημάτων.
- Ειδοποίηση για επαναλαμβανόμενες αποτυχίες υπογραφής, μη φυσιολογική δραστηριότητα παραγγελιών, διαφορές συμφωνίας και αστάθεια σύνδεσης.
- Τεκμηριώστε τον κάτοχο και τη διαδρομή απόκρισης για έκθεση διαπιστευτηρίων, αποτυχία webhook και συμβάντα συναλλαγών.
