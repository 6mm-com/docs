Η τεκμηρίωση ασφάλειας και συμμόρφωσης έχει συνταχθεί για ομάδες συνεργατών που προετοιμάζουν την παραγωγική χρήση της υποδομής συναλλαγών 6MM . Συνδέει την αρχιτεκτονική ασφαλείας, τους ελέγχους API/SDK , την προετοιμασία συμμόρφωσης, τα νομικά όρια και την ετοιμότητα εκκίνησης σε μία διαδρομή αναθεώρησης.

<h2 id="documentation-map">Χάρτης τεκμηρίωσης</h2>

| Περιοχή | Σκοπός |
| --- | --- |
| Αρχιτεκτονική ασφαλείας | Κατανοήστε πώς προστατεύονται οι υποδομές συναλλαγών, η πρόσβαση API/SDK και οι λειτουργίες συνεργατών. |
| API και webhook ασφάλεια | Προστατέψτε τις ενοποιήσεις backend μέσω υπογραφής, μυστικής αποθήκευσης και ανίκανης επεξεργασίας. |
| Ετοιμότητα συμμόρφωσης | Προετοιμάστε το πλαίσιο υποστήριξης αδειών χρήσης, τους ελέγχους εκκίνησης και τους λειτουργικούς ελέγχους από την πλευρά του συνεργάτη. |
| Νομικά έγγραφα | Ελέγξτε τους όρους, το απόρρητο και τα όρια ευθύνης πριν από την έναρξη της παραγωγής. |

<h2 id="recommended-reading-order">Συνιστώμενη σειρά ανάγνωσης</h2>

1. Ξεκινήστε με την Αρχιτεκτονική Ασφάλειας και το Όριο Ευθύνης Συνεργατών.
2. Ελέγξτε τη διαχείριση API Key , την υπογραφή αιτημάτων και την Webhook idempotency πριν από την ενσωμάτωση του backend.
3. Ελέγξτε την Επισκόπηση Συμμόρφωσης και την Υποστήριξη Αδειών Χρήσης πριν από την προετοιμασία της περιφερειακής κυκλοφορίας.
4. Ελέγξτε τις νομικές σελίδες και τη λίστα ελέγχου εκκίνησης πριν εκθέσετε τη λειτουργία συναλλαγών στους χρήστες.
