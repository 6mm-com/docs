Χρησιμοποιήστε αρχεία καταγραφής λειτουργίας για να απαντήσετε ποιος άλλαξε τι και πότε. Συνδυάστε τη δράση, τον στόχο και την πηγή με την εγγραφή της επιχείρησης αντί να διαβάζετε την περιγραφή του αρχείου καταγραφής μεμονωμένα.

<div className="sixmm-support-flow">

1. **Εντοπισμός του συμβάντος** — Φιλτράρισμα ανά ώρα, λέξη-κλειδί και κατηγορία.
2. **Διαβάστε τις λεπτομέρειες** — Ελέγξτε τον ηθοποιό, τον στόχο, την πηγή και το αποτέλεσμα.
3. **Επαλήθευση του αποτελέσματος** — Ανοίξτε την επηρεαζόμενη εγγραφή πριν προσπαθήσετε ξανά.

</div>

## Παρακολούθηση μιας επέμβασης

Ανοίξτε τα **Μητρώα λειτουργίας**. Φιλτράρετε κατά λέξη-κλειδί, κατηγορία, ενέργεια, τύπο ηθοποιού, τύπο στόχου και ημερομηνία χρησιμοποιώντας τα διαθέσιμα στοιχεία ελέγχου. Διαβάστε τις λεπτομέρειες για να προσδιορίσετε ποιος έδρασε, ποιο αρχείο άλλαξε και το αποτέλεσμα.

Οι λειτουργίες MCP εμφανίζονται με την κατάσταση εφαρμογής/πηγής και εκτέλεσής τους. Ανάλογα με τη λειτουργία, μια αλλαγή επιχείρησης και η εγγραφή εκτέλεσής της MCP μπορούν να εμφανιστούν και οι δύο. δύο εγγραφές ελέγχου δεν σημαίνουν από μόνες τους ότι η ενέργεια εκτελέστηκε δύο φορές.

<span id="distinguish-authorization-from-execution" data-sixmm-canonical-anchor="distinguish-authorization-from-execution" aria-hidden="true"></span>

## Διαχωρίστε την εξουσιοδότηση από την εκτέλεση

Μια σύνδεση εφαρμογής αποδεικνύει μόνο εξουσιοδότηση. Μια προτεινόμενη εγγραφή, μια εκκρεμής έγκριση και μια ολοκληρωμένη εγγραφή είναι διαφορετικές καταστάσεις. Το αρχείο καταγραφής δεν είναι μια πλήρης μεταγραφή όλων όσων λέγονται στο εξωτερικό AI, και ένα ερώτημα μόνο για ανάγνωση δεν θα πρέπει να θεωρείται ότι δημιουργεί μια εγγραφή επιχειρηματικής εγγραφής.

Κατά τη διερεύνηση μιας αποτυχημένης κλήσης MCP, διατηρήστε το αναγνωριστικό λειτουργίας, την ώρα και το μήνυμα σφάλματος. Ζητήστε το αποτέλεσμα της λειτουργίας πριν προσπαθήσετε ξανά. Τα αρχεία καταγραφής λειτουργιών είναι μόνο για ανάγνωση μέσω MCP.

## Διαβάστε μια καταχώριση αρχείου καταγραφής

| Λεπτομέρεια | Γιατί έχει σημασία |
| --- | --- |
| Φορά | Τοποθετεί τη δράση στην ακολουθία γεγονότων που διερευνάτε. |
| Κατηγορία και δράση | Διακρίνετε μια ενημέρωση περιεχομένου, μια ενέργεια περιόδου σύνδεσης ή άλλη υποστηριζόμενη λειτουργία. |
| Ηθοποιός | Προσδιορίζει έναν λογαριασμό ή μια ενέργεια συστήματος. δεν είναι απαραίτητα ο επισκέπτης στη συζήτηση. |
| Πηγή | Βοηθά στη διάκριση της δραστηριότητας εφαρμογής MCP από άλλες λειτουργίες. |
| Στόχος | Προσδιορίζει το επιχειρηματικό αντικείμενο ή τη λειτουργία MCP που αναφέρεται από την εγγραφή. |
| Λεπτομέρειες και αποτέλεσμα | Δώστε τη διαθέσιμη εξήγηση και την κατάσταση εκτέλεσης. Διαβάστε το σφάλμα πριν αποφασίσετε να δοκιμάσετε ξανά. |

### Παράδειγμα: μια αλλαγή άρθρου MCP δεν εμφανίστηκε

1. Περιορίστε το εύρος ημερομηνιών και αναζητήστε την εφαρμογή ή τη σχετική λειτουργία.
2. Ελέγξτε εάν η λειτουργία περιμένει επιβεβαίωση, απέτυχε ή ολοκληρώθηκε. Η εξουσιοδότηση από μόνη της δεν σημαίνει την εκτέλεση της αλλαγής.
3. Ανοίξτε το άρθρο-στόχο και συγκρίνετε το τρέχον περιεχόμενό του. Εάν αναφέρεται διένεξη έκδοσης, διαβάστε την πιο πρόσφατη έκδοση και προετοιμάστε ένα νέο αίτημα αντί να επαναχρησιμοποιήσετε παλιό περιεχόμενο.
4. Διατηρήστε το αναγνωριστικό λειτουργίας και τα στοιχεία σφάλματος εάν απαιτείται περαιτέρω διερεύνηση. Μια σχετική εγγραφή επιχειρηματικού ελέγχου και εγγραφή εκτέλεσης MCP μπορεί να περιγράψει την ίδια αλλαγή.

Μια χρήσιμη μεταβίβαση περιέχει τον χρόνο, το αναγνωριστικό στόχου, το αναγνωριστικό λειτουργίας εάν υπάρχει και το παρατηρούμενο αποτέλεσμα. Δεν πρέπει να περιλαμβάνει κωδικούς πρόσβασης λογαριασμού ή API μυστικά.

## Συνήθεις ερωτήσεις

<AccordionGroup>

<Accordion title="Γιατί δεν υπάρχει εγγραφή για μια συνομιλία AI;">
Το αρχείο καταγραφής λειτουργίας δεν είναι μια μεταγραφή συνομιλιών σε μια εξωτερική εφαρμογή AI. Μια κλήση εργαλείου μόνο για ανάγνωση δεν δημιουργεί επίσης απαραίτητα ένα αρχείο καταγραφής αλλαγών επιχείρησης.
</Accordion>

<Accordion title="Πρέπει να επαναλάβω αμέσως μια αποτυχημένη λειτουργία;">

</Accordion>

</AccordionGroup>
