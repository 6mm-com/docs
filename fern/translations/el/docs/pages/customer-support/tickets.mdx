## Επιλέξτε τη σωστή εγγραφή

Ανοίξτε το **Ticket Management** και επιλέξτε την κατάλληλη καρτέλα.

| Ρεκόρ | Σκοπός |
| --- | --- |
| Εισιτήριο πράκτορα | Έργο που δημιουργείται και διατηρείται από την ομάδα υποστήριξης |
| Εισιτήριο χρήστη | Μια ερώτηση που υποβλήθηκε από έναν επισκέπτη για παρακολούθηση |
| Σχόλια χρηστών | Μια πρόταση ή ένα ζήτημα που υποβλήθηκε μέσω μιας καταχώρισης σχολίων |

## Χειριστείτε μια υπόθεση

Διαβάστε την περιγραφή, τα στοιχεία επικοινωνίας, τη σχετική συνομιλία και τα συνημμένα που είναι διαθέσιμα στο αρχείο. Αντιστοιχίστε το στον κατάλληλο χειριστή και ενημερώστε την κατάσταση καθώς προχωρά η εργασία. Χρησιμοποιήστε τα υποστηριζόμενα στοιχεία ελέγχου επεξεργασίας για εισιτήρια πρακτόρων. τα εισιτήρια των χρηστών και τα σχόλια έχουν τις δικές τους διαθέσιμες ενέργειες.

Η ενημέρωση μιας κατάστασης δεν αποδεικνύει από μόνη της ότι ο επισκέπτης έλαβε ένα email ή μια απάντηση συνομιλίας. Στείλτε μια απάντηση μέσω ενός διαθέσιμου καναλιού επικοινωνίας όταν απαιτείται και επαληθεύστε το αποτέλεσμα. Διατηρήστε τα προσωπικά στοιχεία εντός της ροής εργασιών του εξουσιοδοτημένου μισθωτή.

<span id="use-mcp-for-triage" data-sixmm-canonical-anchor="use-mcp-for-triage" aria-hidden="true"></span>

## Χρησιμοποιήστε το MCP για διαλογή

Ζητήστε από τη συνδεδεμένη τεχνητή νοημοσύνη να παραθέσει ανεπίλυτες υποθέσεις, να τις ομαδοποιήσει ανά ζήτημα και να προετοιμάσει μια προτεινόμενη απάντηση. Ελέγξτε τις αναθέσεις και τις αλλαγές κατάστασης πριν τις εφαρμόσετε σε πραγματικές περιπτώσεις. Η δημιουργία εισιτηρίου αντιπροσώπου και η υποβολή εισιτηρίου χρήστη είναι διαφορετικές ροές εργασίας. ένα εργαλείο για το ένα δεν σημαίνει ότι υποστηρίζει το άλλο. Η διαγραφή ενός εισιτηρίου μέσω MCP απαιτεί επιβεβαίωση.
