## Προετοιμάστε τον χώρο εργασίας σας

Ανοιχτό [την κονσόλα](https://csadmin.6mm.com/) με τον λογαριασμό που παρέχεται για τον ενοικιαστή σας. Ολοκληρώστε τη σύνδεση και τη ρύθμιση ασφαλείας που ζητούνται από την οθόνη σύνδεσης. Εάν δεν μπορείτε να αποκτήσετε πρόσβαση σε ένα μενού, ζητήστε από τον διαχειριστή ενοικιαστή να ελέγξει τον ρόλο.

1. **Ρυθμίστε την ομάδα.** Στη Διαχείριση πρακτόρων, δημιουργήστε τους απαιτούμενους ρόλους και λογαριασμούς πρακτόρων. Ελέγξτε ποιος μπορεί να βλέπει συνομιλίες, να επεξεργάζεται περιεχόμενο και να διαχειρίζεται ρυθμίσεις.
2. **Προετοιμάστε επιχειρηματικές γνώσεις.** Στη Διαχείριση περιεχομένου, δημιουργήστε κατηγορίες και άρθρα για πρόσβαση σε λογαριασμό, διαδικασίες κατάθεσης και ανάληψης, κανόνες συναλλαγών, χρεώσεις και κλιμάκωση υποστήριξης. Ελέγξτε και δημοσιεύστε το υλικό που πρέπει να δουν οι χρήστες.
3. **Διαμόρφωση αυτοματισμού.** Ενεργοποιήστε τις απαιτούμενες έξυπνες υπηρεσίες στις Ρυθμίσεις συστήματος. Στη Διαμόρφωση ρομπότ, ελέγξτε το FAQ, αντιστοίχιση διανυσμάτων, απαντήσεις τεχνητής νοημοσύνης και απαντήσεις ταυτότητας.
4. **Προετοιμάστε γλώσσες.** Επιλέξτε την κύρια και την προεπιλεγμένη γλώσσα, μεταφράστε το περιεχόμενο βοήθειας και ελέγξτε την ορολογία, τους αριθμούς και τους συνδέσμους.
5. **Συνδέστε τον ιστότοπό σας.** Προσθέστε τον ιστότοπο στην Ενοποίηση ιστότοπου και αντιγράψτε τον κώδικα ενσωμάτωσης που δημιουργήθηκε από τον ενοικιαστή. Χρησιμοποιήστε το δικό σας κλειδί εφαρμογής.
6. **Δοκιμή πριν από την εκκίνηση.** Χρησιμοποιήστε τη δοκιμή ροής του Bot Configuration και, στη συνέχεια, την καταχώριση πραγματικού επισκέπτη. Ελέγξτε γνωστές ερωτήσεις, συνέχεια, άλλη γλώσσα, ανθρώπινη υποστήριξη και υποβολή εισιτηρίου.

## Έναρξη αποδοχής

| Δοκιμή | Αναμενόμενο αποτέλεσμα |
| --- | --- |
| Ένας τεκμηριωμένος κανόνας συναλλαγών | Η απάντηση διατηρεί συνθήκες, αριθμούς και εξαιρέσεις |
| Ένα άγνωστο πρόβλημα που αφορά συγκεκριμένο λογαριασμό | Δεν επινοήθηκε υπόλοιπο ή αποτέλεσμα συναλλαγής. ο χρήστης λαμβάνει ένα κατάλληλο επόμενο βήμα |
| Μια ξενόγλωσση ερώτηση | Μια κατάλληλη απάντηση ή μετάφραση αντιπροσώπου στην ενεργοποιημένη γλώσσα |
| Η ανθρώπινη υποστήριξη δεν είναι διαθέσιμη | Η διαμορφωμένη εναλλακτική λύση, όπως ένα εισιτήριο, είναι διαθέσιμη |
| Λογαριασμός περιορισμένου πράκτορα | Μόνο τα επιτρεπόμενα μενού και εγγραφές είναι προσβάσιμα |
| Χρήση υπηρεσίας | Η σχετική κλήση εμφανίζεται στο Usage and Billing |

Συνδέστε το MCP αφού λειτουργήσει η βασική ροή εργασίας. Ξεκινήστε με ένα ερώτημα μόνο για ανάγνωση και μετά ένα δοκιμαστικό πρόχειρο, προτού χρησιμοποιήσετε εγγραφές σε επιχειρηματικό περιεχόμενο.
