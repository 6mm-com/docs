## Υποστήριξη κονσόλας και επισκεπτών

| Σύμπτωμα | Ελέγξτε πρώτα |
| --- | --- |
| Λείπει ένα μενού | Ρόλος λογαριασμού και διαθεσιμότητα υπηρεσιών μισθωτή |
| Το γραφικό στοιχείο δεν ανοίγει | Δημιουργήθηκε σενάριο URL, κλειδί εφαρμογής, επιτρεπόμενος τομέας και σφάλματα προγράμματος περιήγησης |
| Το bot δεν χρησιμοποιεί το μεγάλο μοντέλο | Πραγματικό αντιστοιχισμένο βήμα, διακόπτες έξυπνης υπηρεσίας και σχετική διαμόρφωση |
| Μια απάντηση χρησιμοποιεί παλιούς κανόνες | Πηγή άρθρου, δημοσιευμένη κατάσταση, FAQ κείμενο, μετάφραση και κατάσταση ανάκτησης |
| Η μετάφραση απουσιάζει | Γλώσσα προορισμού, διακόπτης μετάφρασης, αποθηκευμένη μετάφραση και διαθεσιμότητα υπηρεσίας/υπόλοιπου |
| Η δημιουργία διανύσματος αποτυγχάνει | Διαθεσιμότητα υπηρεσίας και κατάσταση ανάκτησης. αποφύγετε την επανειλημμένη ανακατασκευή χωρίς να εντοπίσετε την αποτυχία |
| Ένα πεδίο επαφής είναι κενό | Αν αυτό το πεδίο όντως συλλέχτηκε. διάκριση email επικοινωνίας και εισόδου |

## MCP σύνδεση και κλήσεις

| Σύμπτωμα | Επόμενο βήμα |
| --- | --- |
| Το άνοιγμα του τελικού σημείου σε ένα πρόγραμμα περιήγησης επιστρέφει ένα σφάλμα | Είναι ένα τελικό σημείο πρωτοκόλλου, όχι μια σελίδα σύνδεσης. προσθέστε το σε έναν συμβατό MCP πελάτη |
| Η εξουσιοδότηση δεν μπορεί να ξεκινήσει | Επαληθεύστε το ακριβές τελικό σημείο, την υποστήριξη ροής HTTP/OAuth του πελάτη και τη ροή σύνδεσης του προγράμματος περιήγησης |
| Μη εξουσιοδοτημένη ή ληγμένη σύνδεση | Έλεγχος ανάκλησης και λήξης. επανασυνδεθείτε μέσω της εφαρμογής |
| Λείπει ένα εργαλείο ή απαγορεύεται η πρόσβαση | Ελέγξτε τον ρόλο του λογαριασμού εξουσιοδότησης και το εύρος της εγγραφής. ανανεώστε τη λίστα εργαλείων |
| Εν αναμονή έγκρισης | Ανοίξτε τον σύνδεσμο επιστρεφόμενης έγκρισης και ελέγξτε τον στο backend |
| Το περιεχόμενο άλλαξε | Διαβάστε την πιο πρόσφατη εγγραφή, κάντε ξανά προεπισκόπηση και υποβάλετε μια νέα προβλεπόμενη λειτουργία |
| Το χρονικό όριο του αιτήματος έληξε | Ερώτηση για την κατάσταση λειτουργίας πριν προσπαθήσετε ξανά ή υποθέσετε αποτυχία |
| Δεν υπάρχει αρχείο καταγραφής εγγραφής | Διακρίνετε μια ανάγνωση, μια έγκριση που εκκρεμεί και μια ολοκληρωμένη εγγραφή. ελέγξτε τα φίλτρα στα αρχεία καταγραφής λειτουργίας |

## Πριν επικοινωνήσετε με την υποστήριξη

Συλλέξτε την ώρα και τη ζώνη ώρας, τον επηρεαζόμενο μισθωτή/λογαριασμό, το όνομα σελίδας ή εργαλείου, το αναγνωριστικό λειτουργίας όπου είναι διαθέσιμο και το ακριβές σφάλμα. Συμπεριλάβετε ένα ανανεωμένο στιγμιότυπο οθόνης ή βήματα για αναπαραγωγή. Μην στέλνετε κωδικούς πρόσβασης, κωδικούς επαλήθευσης, μάρκες κομιστή ή μυστικά υπογραφής.

Δοκιμάστε μια μικρή εγγραφή δοκιμής κατά τη διάγνωση εγγραφών. Επαληθεύστε το αποτέλεσμα και καθαρίστε μόνο τα δεδομένα δοκιμής που δημιουργήσατε, χρησιμοποιώντας την κανονική ροή επιβεβαίωσης όπου απαιτείται.
