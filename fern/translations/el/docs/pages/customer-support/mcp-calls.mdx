## Ανακαλύψτε διαθέσιμα εργαλεία

Μετά την εξουσιοδότηση OAuth, χρησιμοποιήστε έναν πελάτη MCP με Streamable HTTP για να αρχικοποιήσετε τη σύνδεση και να αποκτήσετε εργαλεία μέσω του `tools/list`. Κλήση εργαλείων μέσω `tools/call`. Διαβάστε κάθε επιστρεφόμενο σχήμα εισόδου αντί να αντλήσετε παραμέτρους από διευθύνσεις URL REST. Τα αναγνωριστικά που λαμβάνονται από τις αναγνώσεις είναι συνήθως δεκαδικές συμβολοσειρές για ορίσματα διαδρομής. ένα αριθμητικό πεδίο μέσα σε ένα σώμα παραμένει αριθμητικό όπου το απαιτεί το σχήμα.

Τα παρακάτω παραδείγματα είναι JSON-RPC μηνύματα εργαλείου μετά την προετοιμασία, όχι πλήρη αυτόνομα HTTP αιτήματα. Ο πελάτης παρέχει το διακριτικό πρόσβασης και τις κεφαλίδες πρωτοκόλλου. Αντικαταστήστε τα επεξηγηματικά αναγνωριστικά με αρχεία που επιστράφηκαν για τον ενοικιαστή σας.

## Διαβάστε κατηγορίες

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "knowledge_get_categories",
    "arguments": {}
  }
}
```

## Δημιουργήστε ένα προσχέδιο

Επιλέξτε μια υπάρχουσα κατηγορία από το αποτέλεσμα ανάγνωσης. Η κατηγορία είναι υποχρεωτική. Μην ορίσετε μια κατάσταση δημοσιότητας εκτός εάν σκοπεύετε να δημοσιεύσετε και να ολοκληρώσετε οποιαδήποτε απαιτούμενη επιβεβαίωση.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "knowledge_create_article",
    "arguments": {
      "requestId": "support-demo-create-001",
      "body": {
        "title": "Withdrawal guide draft",
        "content": "Reviewed withdrawal instructions go here.",
        "categoryId": 12,
        "status": "draft"
      }
    }
  }
}
```

## Προεπισκόπηση μιας ενημέρωσης ή διαγραφής

Διαβάστε πρώτα το άρθρο. Κάντε προεπισκόπηση της ακριβούς προβλεπόμενης εγγραφής, συμπεριλαμβανομένου ενός νέου αναγνωριστικού αιτήματος. Η προεπισκόπηση δεν την εκτελεί.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "mcp_preview",
    "arguments": {
      "tool": "knowledge_delete_article",
      "arguments": {
        "id": "123",
        "requestId": "support-demo-delete-001"
      }
    }
  }
}
```

Αντιγράψτε το επιστρεφόμενο `version` στο `expectedVersion` χωρίς να αλλάξετε τον επιδιωκόμενο στόχο ή τις παραμέτρους:

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "knowledge_delete_article",
    "arguments": {
      "id": "123",
      "requestId": "support-demo-delete-001",
      "expectedVersion": "REPLACE_WITH_THE_64_CHARACTER_VERSION_FROM_PREVIEW"
    }
  }
}
```

Το σύμβολο κράτησης θέσης δεν είναι έγκυρη έκδοση. Χρησιμοποιήστε την πραγματική τιμή των 64 χαρακτήρων που επιστρέφεται από την προεπισκόπηση.

## Επιβεβαιώστε και ελέγξτε το αποτέλεσμα

Εάν το αποτέλεσμα αναφέρει `awaiting_approval`, ανοίξτε το `approvalUrl`, συνδεθείτε ως λογαριασμός εξουσιοδότησης και ελέγξτε την ενέργεια. Μόνο η έγκρισή του εκτελεί την εκκρεμή λειτουργία. Η επιβεβαίωση αυτή τη στιγμή λήγει μετά από 15 λεπτά. Η απόρριψη ή η λήξη δεν εκτελεί την εγγραφή.

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "mcp_operation",
    "arguments": {
      "operationId": "REPLACE_WITH_RETURNED_OPERATION_ID"
    }
  }
}
```

Η έξοδος του εργαλείου μεταφέρεται σε περιεχόμενο κειμένου που περιέχει JSON. επιθεωρήστε το και οποιαδήποτε σημαία `isError`. Μια απάντηση HTTP ή ένας σύνδεσμος έγκρισης από μόνος του δεν αποδεικνύει επιτυχία. Διαβάστε την κατάσταση λειτουργίας και, όταν είναι χρήσιμο, υποβάλετε ερώτημα στην επηρεαζόμενη εγγραφή.

## Δοκιμάστε ξανά με ασφάλεια

Χρησιμοποιήστε ξανά το ίδιο `requestId` και τα ίδια ορίσματα για μια νέα προσπάθεια δικτύου της ίδιας εγγραφής. Μην το επαναχρησιμοποιήσετε για άλλη ενέργεια. Εάν το περιεχόμενο έχει αλλάξει, διαβάστε και κάντε ξανά προεπισκόπηση και, στη συνέχεια, υποβάλετε μια νέα προβλεπόμενη λειτουργία με νέο αναγνωριστικό αιτήματος. Εάν μια απόκριση χαθεί ή μια λειτουργία εξακολουθεί να εκτελείται, ρωτήστε την κατάστασή της και το ιστορικό της πριν αποφασίσετε τι να κάνετε. Ποτέ μην υποθέτετε ότι το τάιμ άουτ σημαίνει ότι δεν συνέβη τίποτα.

Ο πελάτης AI συνήθως εκτελεί αυτό το πρωτόκολλο για τον χρήστη. Αυτές οι λεπτομέρειες προορίζονται για προγραμματιστές-πελάτες και για τη διάγνωση μιας ροής εργασίας εργαλείου.
