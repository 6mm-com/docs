## Επιλέξτε τον σωστό τύπο περιεχομένου

Ανοίξτε τη **Διαχείριση περιεχομένου**. Οι κατηγορίες γνώσης οργανώνουν άρθρα. Οι άλλοι τύποι περιεχομένου παρέχουν συνοπτικές απαντήσεις, σημεία εισόδου πλοήγησης και υπηρεσίας.

| Περιεχόμενο | Τυπική χρήση |
| --- | --- |
| Γνωσιακά άρθρα και κατηγορίες | Λεπτομερείς οδηγοί για την επιβίβαση, τις μεταφορές, τους κανόνες συναλλαγών και την αντιμετώπιση προβλημάτων |
| Καυτές ερωτήσεις | Σύντομες απαντήσεις σε συχνές ερωτήσεις |
| Κατηγορίες ερωτήσεων και κάρτες χαρακτηριστικών | Ομαδοποιήστε θέματα και καθοδηγήστε τους χρήστες σε σχετικές πληροφορίες |
| Ανακοινώσεις | Δημοσίευση ειδοποιήσεων που απευθύνονται σε πελάτες |
| Εγγραφές αυτοεξυπηρέτησης | Κατευθύνετε τους χρήστες σε διαθέσιμες ενέργειες ή πόρους υποστήριξης |

## Δημιουργία και διατήρηση γνώσης

1. Δημιουργήστε ή επιλέξτε την κατάλληλη κατηγορία. Συμπληρώστε τα απαιτούμενα πεδία, συμπεριλαμβανομένης της κατηγορίας κατά τη δημιουργία ενός άρθρου.
2. Γράψτε τον τίτλο και το σώμα, συμπεριλαμβανομένων του πεδίου εφαρμογής, των συνθηκών, των βημάτων και των εξαιρέσεων. Χρησιμοποιήστε πραγματικούς επιχειρηματικούς κανόνες αντί για υποτιθέμενη συμπεριφορά ανταλλαγής.
3. Αποθηκεύστε και ελέγξτε το προσχέδιο. Δημοσίευση όταν είναι έτοιμη για χρήστες. καταργήστε τη δημοσίευση απαρχαιωμένου υλικού, όταν χρειάζεται.
4. Διατηρήστε τις μεταφράσεις και ελέγξτε την κατάσταση ανάκτησης/ευρετηρίου μετά από αλλαγές. Δοκιμάστε την ερώτηση στη ροή ρομπότ και στη συνομιλία επισκεπτών.

Για παράδειγμα, ένας οδηγός ανάληψης πρέπει να εξηγεί ποιο δίκτυο πρέπει να επιλέξει ο χρήστης, πού θα λάβει τη διεύθυνση, τυχόν ισχύοντες επιχειρηματικούς περιορισμούς και πώς να επικοινωνήσει με την υποστήριξη. Μην επινοείτε χρόνους επεξεργασίας ή χρεώσεις.

## Διατηρήστε το περιεχόμενο συνεπές

Η ενημέρωση της πηγής δεν αποδεικνύει ότι κάθε μετάφραση είναι τρέχουσα. Ελέγξτε τις επηρεαζόμενες μεταφράσεις και τις σχετικές FAQ απαντήσεις. Ένα δημοσιευμένο άρθρο, μια καυτή απάντηση και μια ανακοίνωση δεν πρέπει να περιγράφουν ασυμβίβαστους κανόνες. Πριν τη διαγραφή, ελέγξτε εάν το περιεχόμενο εξακολουθεί να απαιτείται για την πλοήγηση ή τις απαντήσεις των χρηστών. Το MCP υποστηρίζει τις ίδιες επιτρεπόμενες λειτουργίες περιεχομένου. βλέπω [MCP εργαλεία](/el/customer-support/mcp-tools).
