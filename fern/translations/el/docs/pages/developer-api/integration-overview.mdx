> REST Βάση URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Αυτή η τεκμηρίωση προορίζεται για εξωτερικά συστήματα που ενσωματώνονται στην υπηρεσία 6MM API . Καλύπτει τη σύνδεση, τον έλεγχο ταυτότητας JWT , τη διαχείριση API Key , την υπογραφή API Key HMAC , τα ερωτήματα λογαριασμού, τις παραγγελίες, τις θέσεις, τα δεδομένα αγοράς και τις ροές WebSocket .

Η παροχή λογαριασμού και η προετοιμασία χρηματοδότησης διεκπεραιώνονται μέσω διαδικασιών από την πλευρά της πλατφόρμας. Αυτή η τεκμηρίωση περιγράφει μόνο τα τελικά σημεία υπηρεσίας API με δυνατότητα εξωτερικής κλήσης.

## Τελικά σημεία υπηρεσίας

| Τύπος      | Τελικό σημείο              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Ροή ολοκλήρωσης

Προτεινόμενη ακολουθία ενσωμάτωσης:

1. Συνδεθείτε με τον λογαριασμό που παρέχεται από την πλατφόρμα και αποκτήστε ένα `accessToken`.
2. Για πρόσβαση μέσω προγραμματισμού από την πλευρά του διακομιστή, δημιουργήστε πρώτα ένα API Key με JWT και αποθηκεύστε με ασφάλεια το εφάπαξ επιστρεφόμενο `apiSecret`.
3. Τα ιδιωτικά ερωτήματα, τα τελικά σημεία παραγγελίας και τα τελικά σημεία θέσης μπορούν να κληθούν είτε με υπογραφή `Authorization: Bearer <accessToken>` είτε με API Key .
4. Για ιδιωτικές ροές WebSocket , δημιουργήστε πρώτα ένα `listenKey` και μετά συνδεθείτε στο `wss://ws.6mm.com/ws?listenKey=...`.
5. Τα δεδομένα της αγοράς REST τα τελικά σημεία και τα δημόσια κανάλια WebSocket δεν απαιτούν έλεγχο ταυτότητας.

## Επιλογή ελέγχου ταυτότητας

| Σενάριο                               | Συνιστώμενη μέθοδος         |
| -------------------------------------- | -------------------------- |
| Ενέργειες χρήστη frontend                  | JWT                        |
| Κλήσεις μέσω προγραμματισμού από την πλευρά του διακομιστή         | API Key + HMAC υπογραφή   |
| API Key δημιουργία, ενημέρωση και διαγραφή | JWT                        |
| Λαϊκή αγορά REST / δημόσια WebSocket  | Δεν απαιτείται έλεγχος ταυτότητας |
