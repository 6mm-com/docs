<h2 id="public-endpoints">Δημόσια τελικά σημεία</h2>

| Τελικό σημείο                   | Μέθοδος | Μονοπάτι                                        | Περιγραφή                                                    |
| -------------------------- | ------ | ------------------------------------------- | -------------------------------------------------------------- |
| Έκδοση υπηρεσίας            | GET    | `/v1/version`                               | Λήψη πληροφοριών έκδοσης υπηρεσίας                                |
| Ώρα διακομιστή                | GET    | `/v1/time`                                  | Λάβετε χρόνο διακομιστή                                                |
| Σύνδεση χρήστη                 | POST   | `/v1/public/user/login`                     | Χρησιμοποιήστε όνομα χρήστη και κωδικό πρόσβασης για να αποκτήσετε `accessToken`              |
| Διακριτικό ανανέωσης              | POST   | `/v1/public/user/refresh-token`             | Ανανέωση κατάστασης σύνδεσης μέσω Cookie                                 |
| Ανταλλαγή εισιτηρίων πράκτορα      | POST   | `/v1/public/agent-sso/exchange-ticket`      | Ανταλλάξτε ένα εισιτήριο εισόδου πράκτορα για την κατάσταση σύνδεσης              |
| Ανταλλαγή διακριτικών ενσωμάτωσης πράκτορα | POST   | `/v1/public/agent-sso/exchange-embed-token` | Ανταλλάξτε ένα ενσωματωμένο διακριτικό συναλλαγών μικρής διάρκειας για την κατάσταση σύνδεσης |
| Διαμόρφωση συμβόλων       | GET    | `/v1/public/market/symbols`                 | Λάβετε σύμβολα, κανόνες συναλλαγών και διαμόρφωση επιπέδου χρέωσης         |
| Διαμόρφωση ποσοστού χρηματοδότησης | GET    | `/v1/public/market/funding-rate`            | Διαμόρφωση ποσοστού χρηματοδότησης ερωτήματος                               |
| Τρέχον ποσοστό χρηματοδότησης       | GET    | `/v1/public/market/funding-rate/current`    | Σελιδοποίηση τρεχόντων ποσοστών χρηματοδότησης                                 |
| Ιστορικό ποσοστού χρηματοδότησης       | GET    | `/v1/public/market/funding-rate/history`    | Ιστορικό ποσοστού χρηματοδότησης ερωτήματος                                     |
| Κλάιν                     | GET    | `/v1/public/market/klines`                  | Ερώτηση τιμής συναλλαγής, τιμής δείκτη ή τιμής αναφοράς Klines           |
| Πίνακας κατάταξης PnL            | GET    | `/v1/public/leaderboard/pnl`                | Ερώτημα για τον πίνακα κατάταξης PnL 7 / 30 / 90 ημερών                          |

<h2 id="private-user-endpoints">Τελικά σημεία ιδιωτικού χρήστη</h2>

Εκτός εάν ορίζεται διαφορετικά, τα ακόλουθα τελικά σημεία μπορούν να χρησιμοποιούν JWT ή API Key υπογραφή.

| Τελικό σημείο                 | Μέθοδος | Μονοπάτι                                      | Αδεια   | Περιγραφή                                 |
| ------------------------ | ------ | ----------------------------------------- | ------------ | ------------------------------------------- |
| Πληροφορίες χρήστη                | GET    | `/v1/private/user/info`                   | Διαβάστε         | Ερώτημα τρέχοντος προφίλ χρήστη                  |
| Στοιχεία χρήστη              | GET    | `/v1/private/user/asset`                  | Διαβάστε         | Ερώτηση για το υπόλοιπο του πορτοφολιού και τη χρήση περιθωρίου       |
| Δημιουργήστε listenKey         | POST   | `/v1/private/user/listen-key`             | Διαβάστε         | Δημιουργία ιδιωτικού κλειδιού ελέγχου ταυτότητας WebSocket |
| Ανανέωση listenKey          | PUT    | `/v1/private/user/listen-key`             | Διαβάστε         | Παράταση ισχύος listenKey                   |
| Κλείσιμο listenKey          | DELETE | `/v1/private/user/listen-key`             | Διαβάστε         | Κλείσιμο listenKey                             |
| Αρχεία καταγραφής αλλαγών λογαριασμού      | GET    | `/v1/private/user/account-change-log`     | Διαβάστε         | Αναζήτηση αρχείων κίνησης κεφαλαίων                 |
| Στατιστικά όγκου 30 ημερών | GET    | `/v1/private/user/volume-stats`           | Διαβάστε         | Ερώτηση για τον πρόσφατο όγκο συναλλαγών 30 ημερών και τις χρεώσεις |
| Ιστορικό υπολοίπου          | GET    | `/v1/private/user/balance-history`        | Διαβάστε         | Ιστορικό υπολοίπου ερωτήματος                       |
| Επισκόπηση εμπορίου           | GET    | `/v1/private/user/trade-overview`         | Διαβάστε         | Ερώτημα PnL, όγκος και τάση περιουσιακών στοιχείων          |
| Σύνοψη επισκόπησης στοιχείων   | GET    | `/v1/private/user/asset/overview/summary` | Διαβάστε         | Μετρήσεις σύνοψης στοιχείων ερωτήματος                 |
| Τάση επισκόπησης στοιχείων     | GET    | `/v1/private/user/asset/overview/trend`   | Διαβάστε         | Τάση στοιχείων ερωτήματος                           |
| Αποθήκευση αγαπημένων συμβόλων    | POST   | `/v1/private/user/favorite-symbols`       | Διαβάστε         | Αντικατάσταση αγαπημένων συμβόλων                  |
| Λήψη αγαπημένων συμβόλων     | GET    | `/v1/private/user/favorite-symbols`       | Διαβάστε         | Αναζήτηση αγαπημένων συμβόλων                      |
| Αποσύνδεση                   | POST   | `/v1/private/user/logout`                 | JWT + Cookie | Εκκαθάριση κατάστασης σύνδεσης                           |

<h2 id="api-key-management-endpoints">Τελικά σημεία διαχείρισης API Key</h2>

API Key τα τελικά σημεία διαχείρισης δέχονται μόνο JWT.

| Τελικό σημείο            | Μέθοδος | Μονοπάτι                                  | Περιγραφή                                         |
| ------------------- | ------ | ------------------------------------- | --------------------------------------------------- |
| Δημιουργήστε API Key      | POST   | `/v1/private/user/api-key/create`     | Δημιουργήστε API Key; `apiSecret` επιστρέφεται μόνο μία φορά   |
| API Key λίστα        | GET    | `/v1/private/user/api-key/list`       | Υποβολή ερωτήματος στα κλειδιά API του τρέχοντος χρήστη                       |
| Ενημέρωση API Key      | PUT    | `/v1/private/user/api-key/update`     | Ενημερώστε την ετικέτα, τα δικαιώματα, τη λίστα επιτρεπόμενων IP και την κατάσταση |
| Διαγραφή API Key      | POST   | `/v1/private/user/api-key/delete`     | Διαγραφή καθορισμένου API Key                          |
| Διαγραφή όλων των πλήκτρων API | POST   | `/v1/private/user/api-key/delete-all` | Διαγράψτε όλα τα κλειδιά API του τρέχοντος χρήστη             |

<h2 id="order-endpoints">Τελικά σημεία παραγγελίας</h2>

Τα τελικά σημεία παραγγελίας απαιτούν άδεια συναλλαγής.

| Τελικό σημείο                    | Μέθοδος | Μονοπάτι                                  | Περιγραφή                                                       |
| --------------------------- | ------ | ------------------------------------- | ----------------------------------------------------------------- |
| Ερώτημα μεμονωμένης παραγγελίας          | GET    | `/v1/private/order`                   | Ακριβές ερώτημα από `symbol + orderId/clientOrderId`                   |
| Κάνω παραγγελία                 | POST   | `/v1/private/order/place`             | Όριο ή εντολή αγοράς                                             |
| Παραγγελία κατάστασης       | POST   | `/v1/private/order/place-condition`   | Stop loss, take profit, trailing stop και άλλες εντολές κατάστασης |
| Παραγγελία στρατηγικής        | POST   | `/v1/private/order/place-strategy`    | OTO / OCO / OTOCO σειρά στρατηγικής                                  |
| Παραγγελίες παρτίδας          | POST   | `/v1/private/order/batch-place`       | Υποβολή πολλαπλών κανονικών παραγγελιών                                     |
| Ακύρωση παραγγελίας                | POST   | `/v1/private/order/cancel`            | Ακύρωση καθορισμένης κανονικής παραγγελίας                                   |
| Τροποποίηση εντολής                 | POST   | `/v1/private/order/move`              | Τροποποιήστε την κανονική τιμή και ποσότητα παραγγελίας σε εκκρεμότητα                    |
| Εντολές τροποποίησης παρτίδας          | POST   | `/v1/private/order/batch-move`        | Μαζική τροποποίηση κανονικών εκκρεμών εντολών για το ίδιο σύμβολο            |
| Μαζική ακύρωση παραγγελιών         | POST   | `/v1/private/order/batch-cancel`      | Μαζική ακύρωση κανονικών παραγγελιών                                        |
| Ακύρωση όλων                  | POST   | `/v1/private/order/batch-cancel-all`  | Μαζική ακύρωση παραγγελιών ανά τύπο                                       |
| Ακύρωση εντολής κατάστασης      | POST   | `/v1/private/order/cancel-condition`  | Ακύρωση καθορισμένης εντολής συνθήκης                                |
| Τρέχουσες κανονικές παραγγελίες       | GET    | `/v1/private/order/current`           | Ερώτηση για τρέχουσες κανονικές εκκρεμείς εντολές                               |
| Εντολές τρέχουσας κατάστασης    | GET    | `/v1/private/order/current-condition` | Υποβολή ερωτήματος σε τρέχουσες μη ενεργοποιημένες εντολές συνθηκών                        |
| Ιστορικές κανονικές εντολές    | GET    | `/v1/private/order/history`           | Σελιδοποίηση ιστορικών κανονικών παραγγελιών                                 |
| Εντολές ιστορικών συνθηκών | GET    | `/v1/private/order/history-condition` | Σελιδοποίηση παραγγελιών ιστορικών συνθηκών                              |
| Εμπορικά αρχεία               | GET    | `/v1/private/order/trades`            | Σελιδοποιήστε τα εμπορικά αρχεία                                            |
| Λεπτομέρεια σειράς στρατηγικής       | GET    | `/v1/private/order/strategy`          | Σειρά και δευτερεύουσες παραγγελίες στρατηγικής ερωτημάτων                               |

<h2 id="position-endpoints">Τελικά σημεία θέσης</h2>

Τα τελικά σημεία θέσης απαιτούν άδεια συναλλαγής.

| Τελικό σημείο          | Μέθοδος | Μονοπάτι                               | Περιγραφή                                  |
| ----------------- | ------ | ---------------------------------- | -------------------------------------------- |
| Ορισμός λειτουργίας περιθωρίου   | POST   | `/v1/private/position/margin-mode` | Διακόπτης απομόνωσης / εγκάρσιου περιθωρίου               |
| Ορισμός μόχλευσης      | POST   | `/v1/private/position/leverage`    | Ορισμός μόχλευσης συμβόλων                          |
| Ρυθμίσεις θέσης | GET    | `/v1/private/position/settings`    | Ερώτηση για τη λειτουργία μόχλευσης και περιθωρίου για ένα σύμβολο  |
| Τρέχουσες θέσεις | GET    | `/v1/private/position/positions`   | Ερώτηση για τρέχουσες θέσεις                      |
| Ιστορικό θέσης  | GET    | `/v1/private/position/history`     | Αναζήτηση ιστορικών θέσεων και κλείσιμο εγγραφών |
