Χρησιμοποιήστε κανάλια δημόσιας αγοράς όταν μια εφαρμογή χρειάζεται συνεχώς ενημερωμένες τιμές, συναλλαγές, κηροπήγια ή βάθος βιβλίου παραγγελιών χωρίς επανειλημμένες δημοσκοπήσεις REST τελικά σημεία. Αυτές οι ροές μπορούν να υποστηρίξουν οθόνες συναλλαγών, εμφανίσεις τιμών, ειδοποιήσεις και παρακολούθηση της αγοράς.

<span id="connection-url" data-sixmm-canonical-anchor="connection-url" aria-hidden="true"></span>

## Σύνδεση URL

```
wss://ws.6mm.com/ws
```

Η δημόσια WebSocket δεν απαιτεί έλεγχο ταυτότητας.

Για τον κύκλο ζωής της σύνδεσης, τη συμπεριφορά κατάργησης εγγραφής, ping και επανασύνδεσης, ανατρέξτε στο θέμα [Σύνδεση, Συνδρομή & Καρδιακός Παλμός](/el/developer-api/websocket/connection-subscription-and-heartbeat).

<span id="common-channels" data-sixmm-canonical-anchor="common-channels" aria-hidden="true"></span>

## Κοινά κανάλια

| Κανάλι                            | Περιγραφή                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Βάθος βιβλίου παραγγελιών. Στέλνει πρώτα ένα στιγμιότυπο και μετά τμηματικές ενημερώσεις |
| `market.trade.{symbol}`            | Τελευταίες συναλλαγές                                                      |
| `market.kline.{symbol}.{interval}` | Κλάιν                                                             |
| `market.ticker.{symbol}`           | Σύνοψη μετοχής ενός συμβόλου                                       |
| `market.tickers`                   | Σύνοψη μετοχής όλων των συμβόλων                                          |

<span id="choose-a-channel" data-sixmm-canonical-anchor="choose-a-channel" aria-hidden="true"></span>

## Επιλέξτε ένα κανάλι

| Ανάγκη εφαρμογής | Κανάλι |
| --- | --- |
| Δημιουργία ή διατήρηση βιβλίου παραγγελιών | `market.depth.{symbol}` |
| Εμφάνιση ζωντανής ροής συναλλαγών | `market.trade.{symbol}` |
| Σχεδιάστε ένα γράφημα κηροπήγιο | `market.kline.{symbol}.{interval}` |
| Εμφάνιση μίας σύνοψης αγοράς | `market.ticker.{symbol}` |
| Διατηρήστε μια επισκόπηση της αγοράς | `market.tickers` |

<span id="subscription-example" data-sixmm-canonical-anchor="subscription-example" aria-hidden="true"></span>

## Παράδειγμα συνδρομής

```json
{ "id": "1772007814666", "op": "subscribe", "args": ["market.depth.BTCUSDT"] }
```

<span id="push-message-wrapper" data-sixmm-canonical-anchor="push-message-wrapper" aria-hidden="true"></span>

## Περιτύλιγμα μηνυμάτων Push

```json
{
  "topic": "market.depth.BTCUSDT",
  "event": "data",
  "ts": 1772007815000,
  "data": {}
}
```

Χρησιμοποιήστε `topic` για να δρομολογήσετε κάθε μήνυμα στον σωστό δείκτη χειρισμού και `ts` για να παρατηρήσετε το χρονοδιάγραμμα παράδοσης. Το αντικείμενο `data` περιέχει το φορτίο για το συνδρομητικό κανάλι.

<span id="order-book-handling" data-sixmm-canonical-anchor="order-book-handling" aria-hidden="true"></span>

## Χειρισμός βιβλίου παραγγελιών

Το κανάλι βάθους στέλνει πρώτα ένα στιγμιότυπο και μετά σταδιακές ενημερώσεις. Αρχικοποιήστε το τοπικό βιβλίο από το στιγμιότυπο πριν εφαρμόσετε ενημερώσεις. Μετά την επανασύνδεση, δημιουργήστε μια νέα περίοδο λειτουργίας, εγγραφείτε ξανά και δημιουργήστε ξανά το τοπικό βιβλίο από το επόμενο στιγμιότυπο αντί να συνεχίσετε από την κατάσταση μη ενημερωμένης μνήμης.

<span id="production-recommendations" data-sixmm-canonical-anchor="production-recommendations" aria-hidden="true"></span>

## Συστάσεις παραγωγής

- Δημιουργήστε μια μοναδική `id` για κάθε αίτημα εγγραφής, διαγραφής και ping.
- Επιβεβαιώστε τις επιβεβαιώσεις συνδρομής πριν αντιμετωπίσετε ένα κανάλι ως ενεργό.
- Εγγραφείτε ξανά σε κάθε απαιτούμενο θέμα μετά την επανασύνδεση.
- Διατηρήστε τις αναγνώσεις δικτύου ξεχωριστά από την πιο αργή επεξεργασία βάσης δεδομένων ή διεπαφής χρήστη.
- Παρακολουθήστε τη συχνότητα αποσύνδεσης, την καθυστέρηση επεξεργασίας μηνυμάτων και τα κακοσχηματισμένα ωφέλιμα φορτία.
- Χρήση [Ιδιωτικό κανάλι χρήστη](/el/developer-api/websocket/private-user-channel) για ενημερώσεις λογαριασμού και παραγγελιών με έλεγχο ταυτότητας.
