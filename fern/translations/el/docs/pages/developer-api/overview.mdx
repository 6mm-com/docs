<h2 id="documentation-areas">Τομείς τεκμηρίωσης</h2>

| Περιοχή | Τι καλύπτει |
| --- | --- |
| Ρύθμιση ενσωμάτωσης | Διευθύνσεις υπηρεσιών, συμβάσεις αιτημάτων, σχήμα απόκρισης και λειτουργίες πρόσβασης. |
| Έλεγχος ταυτότητας και ασφάλεια | JWT, API Key δικαιώματα, HMAC υπογραφή, προστασία επανάληψης και συγχρονισμός χρόνου. |
| REST API | Δημόσια τελικά σημεία, δεδομένα χρήστη/λογαριασμού, παραγγελίες, θέσεις και δεδομένα αγοράς. |
| WebSocket | Κύκλος ζωής σύνδεσης, ροές δημόσιας αγοράς και ροές ιδιωτικών χρηστών. |
| Αναφορά & αντιμετώπιση προβλημάτων | Enums, κωδικοί σφαλμάτων και πρακτικές προτάσεις ενσωμάτωσης. |

<h2 id="production-checklist">Λίστα ελέγχου παραγωγής</h2>

- Αποθηκεύστε API μυστικά μόνο στο backend.
- Συγχρονισμός χρόνου διακομιστή πριν από υπογεγραμμένα αιτήματα.
- Αντιμετωπίστε όλα τα πεδία αριθμητικής ακρίβειας ως συμβολοσειρές, εκτός εάν μια σελίδα λέει ρητά το αντίθετο.
- Χρησιμοποιήστε idempotency, αναγνωριστικά αιτήσεων και δομημένα αρχεία καταγραφής γύρω από τις ροές παραγγελιών.
- Εγγραφείτε σε ροές WebSocket για κατάσταση που πρέπει να παραμένει ενημερωμένη στα λειτουργικά συστήματα.
- Ελέγξτε τους κωδικούς σφάλματος και δοκιμάστε ξανά τη συμπεριφορά πριν από την εκκίνηση.
