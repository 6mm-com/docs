<h2 id="error-response-format">Μορφή απόκρισης σφάλματος</h2>

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Τα επιχειρηματικά σφάλματα συνήθως εξακολουθούν να επιστρέφουν την ενοποιημένη δομή JSON . Οι ολοκληρωτές θα πρέπει πρώτα να `code` ελέγξουν. Οι αποτυχίες ελέγχου ταυτότητας ενδέχεται να επιστρέψουν HTTP `401`; Ο περιορισμός του επιτοκίου μπορεί να επιστρέψει HTTP `429`.

<h2 id="common-error-codes">Κοινοί κωδικοί σφαλμάτων</h2>

| Κωδικός σφάλματος      | Περιγραφή                                  |
| --------------- | -------------------------------------------- |
| `0`             | Επιτυχία                                      |
| `1001`          | Δεν παρέχονται έγκυρες πληροφορίες ελέγχου ταυτότητας |
| `1002`          | Το διακριτικό έληξε                                |
| `1003`          | Μη έγκυρο διακριτικό, API Keyή υπογραφή         |
| `1004`          | Το διακριτικό ανακλήθηκε                                |
| `1006`          | Αναντιστοιχία IP πηγής                           |
| `2001`          | Λείπει η απαιτούμενη παράμετρος                   |
| `2002`          | Μη έγκυρη τιμή παραμέτρου                      |
| `2003`          | Παράμετρος εκτός εύρους                       |
| `3001`          | Ανεπαρκής ισορροπία                         |
| `3003`          | Η παραγγελία δεν βρέθηκε                              |
| `3004`          | Διπλότυπο αίτημα                            |
| `3005`          | Η παραγγελία δεν μπορεί να ακυρωθεί                     |
| `3006`          | Η άδεια απορρίφθηκε                            |
| `3100` - `3112` | Σφάλμα επικύρωσης παραμέτρου σειράς συνθήκης   |
| `5001`          | Εσωτερικό σφάλμα διακομιστή                        |
| `5002`          | Η υπηρεσία δεν είναι διαθέσιμη προσωρινά              |
| `5003`          | Ενεργοποίηση ορίου ρυθμού                         |

<h2 id="troubleshooting">Αντιμετώπιση προβλημάτων</h2>

| Πρόβλημα                                     | Σύσταση                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` Δεν υπάρχουν έγκυρες πληροφορίες ελέγχου ταυτότητας  | Ελέγξτε εάν περιλαμβάνεται `Authorization: Bearer <accessToken>` ή `X-API-KEY` .                  |
| `1002` Το διακριτικό έληξε                        | Ανανεώστε το διακριτικό ή συνδεθείτε ξανά πριν προσπαθήσετε ξανά.                                                   |
| `1003` μη έγκυρο διακριτικό, API Keyή υπογραφή | Ελέγξτε API Key, φορτίο υπογραφής, σώμα αιτήματος JSON συμβολοσειρά και σειρά παραμέτρων ερωτήματος.           |
| `1006` αναντιστοιχία IP πηγής                   | Ελέγξτε τη διαμόρφωση της λίστας επιτρεπόμενων API Key IP .                                                    |
| `3004` διπλότυπο αίτημα                    | Μην επαναχρησιμοποιείτε την ίδια υπογραφή για διαδρομές που σχετίζονται με παραγγελίες. Αναγεννήστε `timestamp` και `signature`. |
| `5003` ενεργοποιήθηκε το όριο ρυθμού                 | Μειώστε τη συχνότητα αιτημάτων και χρησιμοποιήστε εκθετική οπισθοδρόμηση εάν προσπαθήσετε ξανά.                                |
| `Timestamp outside of tolerance window`     | Καλέστε `/v1/time` για να βαθμονομήσετε τη χρονική μετατόπιση και να υπογράψετε ξανά το αίτημα.                             |
