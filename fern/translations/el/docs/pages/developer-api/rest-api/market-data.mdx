Τα δεδομένα αγοράς REST τα τελικά σημεία δεν απαιτούν έλεγχο ταυτότητας.

<span id="symbol-configuration" data-sixmm-canonical-anchor="symbol-configuration" aria-hidden="true"></span>

## Διαμόρφωση συμβόλου

```http
GET /v1/public/market/symbols
```

Κοινά πεδία απόκρισης:

| Πεδίο                      | Τύπος   | Περιγραφή                   |
| -------------------------- | ------ | ----------------------------- |
| `list[].symbol`            | string | Σύμβολο                        |
| `list[].baseAsset`         | string | Βασικό περιουσιακό στοιχείο                    |
| `list[].quoteAsset`        | string | Προσφορά στοιχείου                   |
| `list[].minQuantity`       | string | Ελάχιστη ποσότητα παραγγελίας        |
| `list[].minNotional`       | string | Ελάχιστη ονομαστική αξία        |
| `list[].tickSize`          | string | Μέγεθος τσιμπήματος τιμής               |
| `list[].stepSize`          | string | Μέγεθος βήματος ποσότητας            |
| `list[].pricePrecision`    | int64  | Ακρίβεια τιμής               |
| `list[].maxLimitOrderQty`  | string | Μέγιστο όριο ποσότητας εντολής  |
| `list[].maxMarketOrderQty` | string | Μέγιστη ποσότητα παραγγελίας αγοράς |
| `list[].maxOpenOrders`     | int64  | Μέγιστος αριθμός ανοικτών εντολών ανά χρήστη  |
| `list[].defaultLeverage`   | int64  | Προεπιλεγμένη μόχλευση              |
| `list[].defaultMarginMode` | int64  | Προεπιλεγμένη λειτουργία περιθωρίου           |
| `list[].leverageTiers[]`   | array  | Επίπεδα περιθωρίου μόχλευσης         |
| `handlingFeeLevelConfig[]` | array  | Διαμόρφωση βαθμίδας χρέωσης        |

<span id="funding-rate-configuration" data-sixmm-canonical-anchor="funding-rate-configuration" aria-hidden="true"></span>

## Διαμόρφωση ποσοστού χρηματοδότησης

```http
GET /v1/public/market/funding-rate?symbol=BTCUSDT
```

Παράμετροι αιτήματος:

| Παράμετρος | Τύπος   | Απαιτείται | Περιγραφή                     |
| --------- | ------ | -------- | ------------------------------- |
| `symbol`  | string | Όχι       | Εάν παραλειφθεί, επιστρέφει όλα τα σύμβολα |

<span id="current-funding-rate" data-sixmm-canonical-anchor="current-funding-rate" aria-hidden="true"></span>

## Τρέχον ποσοστό χρηματοδότησης

```http
GET /v1/public/market/funding-rate/current?symbol=BTCUSDT&page=1&pageSize=20
```

Παράμετροι αιτήματος:

| Παράμετρος  | Τύπος   | Απαιτείται | Περιγραφή                  |
| ---------- | ------ | -------- | ---------------------------- |
| `symbol`   | string | Όχι       | Σύμβολο                       |
| `page`     | int32  | Όχι       | Αριθμός σελίδας, προεπιλεγμένη `1`     |
| `pageSize` | int32  | Όχι       | Στοιχεία ανά σελίδα, προεπιλεγμένη `20` |

## Ιστορικό ποσοστού χρηματοδότησης

```http
GET /v1/public/market/funding-rate/history?symbol=BTCUSDT&page=1&pageSize=20
```

Παράμετροι αιτήματος:

| Παράμετρος   | Τύπος   | Απαιτείται | Περιγραφή                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Ναι      | Σύμβολο                       |
| `startTime` | int64  | Όχι       | Ώρα έναρξης                   |
| `endTime`   | int64  | Όχι       | Ώρα λήξης                     |
| `page`      | int32  | Όχι       | Αριθμός σελίδας, προεπιλεγμένη `1`     |
| `pageSize`  | int32  | Όχι       | Στοιχεία ανά σελίδα, προεπιλεγμένη `20` |

## Κλάιν

```http
GET /v1/public/market/klines?symbol=BTCUSDT&interval=1m&limit=500
```

Παράμετροι αιτήματος:

| Παράμετρος   | Τύπος   | Απαιτείται | Περιγραφή                                                              |
| ----------- | ------ | -------- | ------------------------------------------------------------------------ |
| `symbol`    | string | Ναι      | Σύμβολο                                                                   |
| `interval`  | string | Ναι      | Διάστημα, όπως `1m`, `5m`, `15m`, `30m`, `1h`, `4h`, `1d`, `1w`, `1M` |
| `priceType` | string | Όχι       | `indexPrice` / `markPrice`. Εάν παραλειφθεί, επιστρέφει την τιμή συναλλαγής Klines       |
| `startTime` | int64  | Όχι       | Ώρα έναρξης                                                               |
| `endTime`   | int64  | Όχι       | Ώρα λήξης                                                                 |
| `limit`     | int32  | Όχι       | Αριθμός επιστρεφόμενων ειδών, προεπιλεγμένη `500`, μέγιστη `1000`                  |

Πεδία απόκρισης:

| Πεδίο              | Τύπος   | Περιγραφή |
| ------------------ | ------ | ----------- |
| `list[].openTime`  | int64  | Ανοιχτός χρόνος   |
| `list[].open`      | string | Τιμή ανοίγματος  |
| `list[].high`      | string | Υψηλή τιμή  |
| `list[].low`       | string | Χαμηλή τιμή   |
| `list[].close`     | string | Κλείσιμο τιμής |
| `list[].volume`    | string | Ενταση ΗΧΟΥ      |
| `list[].closeTime` | int64  | Ώρα κλεισίματος  |
