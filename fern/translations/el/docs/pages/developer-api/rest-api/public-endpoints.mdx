<h2 id="base-url">Βάση URL</h2>

```
https://api.6mm.com
```

<h2 id="service-version">Έκδοση υπηρεσίας</h2>

```http
GET /v1/version
```

Λάβετε πληροφορίες για την έκδοση της υπηρεσίας.

<h2 id="server-time">Ώρα διακομιστή</h2>

```http
GET /v1/time
```

Λάβετε χρόνο διακομιστή. Αυτό το τελικό σημείο μπορεί να χρησιμοποιηθεί για τη βαθμονόμηση του χρόνου πελάτη πριν από την υπογραφή API Key .

<h2 id="user-login">Είσοδος χρήστη</h2>

```http
POST /v1/public/user/login
```

Παράμετροι αιτήματος:

| Παράμετρος    | Τύπος   | Απαιτείται | Περιγραφή                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | Ναι      | Όνομα χρήστη, μήκος 3 - 32                 |
| `password`   | string | Ναι      | Κωδικός πρόσβασης, μήκος 1 - 64                 |
| `deviceId`   | string | Όχι       | Δακτυλικό αποτύπωμα συσκευής, έως 64 χαρακτήρες |
| `deviceName` | string | Όχι       | Όνομα συσκευής, έως 128 χαρακτήρες       |

Παράδειγμα αιτήματος:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

Παράδειγμα απάντησης:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<h2 id="refresh-token">Διακριτικό ανανέωσης</h2>

```http
POST /v1/public/user/refresh-token
```

Σε κανονικά σενάρια ενοποίησης, η κατάσταση σύνδεσης ανανεώνεται μέσω cookie. Διατηρήστε το Cookie που επιστρέφεται από την απάντηση σύνδεσης.

Πεδία απόκρισης:

| Πεδίο          | Τύπος   | Περιγραφή              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Νέο διακριτικό πρόσβασης         |
| `accessExpire` | int64  | Χρόνος λήξης διακριτικού πρόσβασης |

<h2 id="agent-sso">Πράκτορας SSO</h2>

<h2 id="ticket-exchange">Ανταλλαγή εισιτηρίων</h2>

```http
POST /v1/public/agent-sso/exchange-ticket
```

Παράμετροι αιτήματος:

| Παράμετρος  | Τύπος   | Απαιτείται | Περιγραφή                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | Ναι      | Εφάπαξ εισιτήριο που εκδίδεται από την υπηρεσία πρακτόρων |
| `deviceId` | string | Όχι       | Δακτυλικό αποτύπωμα συσκευής, έως 64 χαρακτήρες     |

Πεδία απόκρισης:

| Πεδίο          | Τύπος   | Περιγραφή              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Διακριτικό πρόσβασης             |
| `accessExpire` | int64  | Χρόνος λήξης διακριτικού πρόσβασης |
| `redirectPath` | string | Προτεινόμενη διαδρομή ανακατεύθυνσης  |

<h2 id="embed-token-exchange">Ενσωματώστε το Token Exchange</h2>

```http
POST /v1/public/agent-sso/exchange-embed-token
```

Παράμετροι αιτήματος:

| Παράμετρος    | Τύπος   | Απαιτείται | Περιγραφή                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | Ναι      | Βραχύβιο ενσωματωμένο διακριτικό συναλλαγών που εκδίδεται από την υπηρεσία αντιπροσώπου |
| `channelId`  | string | Ναι      | Ενσωματωμένο αναγνωριστικό καναλιού iframe, έως 128 χαρακτήρες               |
| `deviceId`   | string | Όχι       | Δακτυλικό αποτύπωμα συσκευής, έως 64 χαρακτήρες                        |

Πεδία απόκρισης:

| Πεδίο          | Τύπος   | Περιγραφή              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Διακριτικό πρόσβασης             |
| `accessExpire` | int64  | Χρόνος λήξης διακριτικού πρόσβασης |

<h2 id="pnl-leaderboard">Πίνακας κατάταξης PnL</h2>

```http
GET /v1/public/leaderboard/pnl?period=30d
```

Παράμετροι αιτήματος:

| Παράμετρος | Τύπος   | Απαιτείται | Περιγραφή          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | Ναι      | `7d` / `30d` / `90d` |

Πεδία απόκρισης:

| Πεδίο              | Τύπος   | Περιγραφή                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | Κατάταξη                                                              |
| `list[].userId`    | string | Αναγνωριστικό εξωτερικού χρήστη                                                  |
| `list[].trader`    | string | Μασκοφόρο όνομα εμπόρου                                                |
| `list[].volume`    | string | Όγκος συναλλαγών στο παράθυρο                                      |
| `list[].pnlAmount` | string | Πραγματοποιημένο PnL στο παράθυρο                                        |
| `list[].pnlPct`    | string | Λόγος PnL, δεκαδικός από `0` έως `1`                                |
| `myRank`           | int32  | Κατάταξη του τρέχοντος χρήστη. Επιστρέφει `0` εάν δεν έχει γίνει έλεγχος ταυτότητας ή δεν έχει καταταχθεί |
