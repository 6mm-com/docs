Εκτός εάν ορίζεται διαφορετικά, τα ακόλουθα τελικά σημεία μπορούν να χρησιμοποιούν JWT ή API Key υπογραφή.

<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Πληροφορίες χρήστη

```http
GET /v1/private/user/info
```

Πεδία απόκρισης:

| Πεδίο                  | Τύπος   | Περιγραφή      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | Αναγνωριστικό εξωτερικού χρήστη |
| `userInfo.username`    | string | Όνομα χρήστη         |
| `userInfo.agentId`     | int64  | Αναγνωριστικό πράκτορα         |
| `userInfo.vipLevel`    | int64  | VIP επίπεδο        |
| `userInfo.lastLoginAt` | int64  | Τελευταίος χρόνος σύνδεσης  |
| `userInfo.lastLoginIp` | string | Τελευταία IP σύνδεσης    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Στοιχεία χρήστη

```http
GET /v1/private/user/asset
```

Πεδία απόκρισης:

| Πεδίο                     | Τύπος   | Περιγραφή                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | Αναγνωριστικό εξωτερικού χρήστη                |
| `userAsset.assetType`     | string | Τύπος περιουσιακού στοιχείου                      |
| `userAsset.walletBalance` | string | Υπόλοιπο πορτοφολιού                  |
| `userAsset.frozenMargin`  | string | Πάγωμα περιθωρίου από εκκρεμείς εντολές |
| `userAsset.usedMargin`    | string | Περιθώριο που χρησιμοποιείται από θέσεις        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Δημιουργήστε listenKey

```http
POST /v1/private/user/listen-key
```

Δημιουργεί ένα κλειδί ελέγχου ταυτότητας για ιδιωτικές ροές WebSocket .

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Ανανέωση listenKey

```http
PUT /v1/private/user/listen-key
```

Επεκτείνει listenKey ισχύ.

<span id="close-listenkey" data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Κλείσιμο listenKey

```http
DELETE /v1/private/user/listen-key
```

Κλείνει την καθορισμένη listenKey.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Αρχεία καταγραφής αλλαγών λογαριασμού

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Παράμετροι αιτήματος:

| Παράμετρος    | Τύπος   | Απαιτείται | Περιγραφή                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | Όχι       | Τύπος στοιχείου, όπως `USDT`   |
| `changeType` | string | Όχι       | Τύπος αλλαγής                  |
| `startTime`  | int64  | Όχι       | Ώρα έναρξης                   |
| `endTime`    | int64  | Όχι       | Ώρα λήξης                     |
| `page`       | int32  | Όχι       | Αριθμός σελίδας, προεπιλεγμένη `1`     |
| `pageSize`   | int32  | Όχι       | Στοιχεία ανά σελίδα, προεπιλεγμένη `20` |

Πεδία απόκρισης:

| Πεδίο                        | Τύπος   | Περιγραφή                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Τύπος περιουσιακού στοιχείου                   |
| `list[].amount`              | string | Αλλαγμένο ποσό               |
| `list[].walletBalanceBefore` | string | Υπόλοιπο πορτοφολιού πριν από την αλλαγή |
| `list[].walletBalanceAfter`  | string | Υπόλοιπο πορτοφολιού μετά την αλλαγή  |
| `list[].frozenBalanceBefore` | string | Παγωμένο υπόλοιπο πριν από την αλλαγή |
| `list[].frozenBalanceAfter`  | string | Παγωμένο υπόλοιπο μετά την αλλαγή  |
| `list[].changeType`          | string | Τύπος αλλαγής                  |
| `list[].referenceId`         | string | Αναγνωριστικό σχετικής επιχείρησης          |
| `list[].createdAt`           | int64  | Χρόνος δημιουργίας                |
| `total`                      | int64  | Συνολικός αριθμός                  |

GET /v1/private/user/volume-stats

| Πεδίο         | Τύπος   | Περιγραφή                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Αθροιστικός όγκος συναλλαγών τις τελευταίες 30 ημέρες |
| `feeTotal30d` | string | Σωρευτικές χρεώσεις τις τελευταίες 30 ημέρες           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## Ιστορικό υπολοίπου

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Παράμετροι αιτήματος:

| Παράμετρος | Τύπος   | Απαιτείται | Περιγραφή                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Ναι      | `1D` / `1W` / `1M`                     |
| `limit`   | Διεθνές    | Όχι       | Αριθμός στοιχείων που επιστράφηκαν, προεπιλεγμένη `30` |

Πεδία απόκρισης:

| Πεδίο             | Τύπος   | Περιγραφή                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Ημερομηνία συνάθροισης            |
| `items[].balance` | string | Υπόλοιπο πορτοφολιού              |
| `items[].pnl`     | string | Πραγματοποιηθέν PnL για την περίοδο |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Επισκόπηση Εμπορίου

```http
GET /v1/private/user/trade-overview?type=1M
```

Παράμετροι αιτήματος:

| Παράμετρος | Τύπος   | Απαιτείται | Περιγραφή                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Ναι      | Εύρος τάσεων: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Πεδία απόκρισης:

| Πεδίο                | Τύπος   | Περιγραφή                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | Το σημερινό υλοποιημένο PnL                                                 |
| `todayVolume`        | string | Ο σημερινός όγκος συναλλαγών συμβολαίων                                      |
| `totalVolume`        | string | Σωρευτικός όγκος συναλλαγών συμβολαίων                                   |
| `totalPnl`           | string | Σωρευτικό πραγματοποιηθέν PnL                                              |
| `maxDrawdown30d`     | string | Μέγιστο ποσό ανάληψης τις τελευταίες 30 ημέρες                        |
| `maxDrawdown30dRate` | string | Μέγιστο ποσοστό ανάληψης τις τελευταίες 30 ημέρες, δεκαδικό από `0` έως `1` |
| `transferIn`         | string | Σωρευτικά μεταφερόμενα κεφάλαια                                      |
| `transferOut`        | string | Σωρευτικά μεταφερόμενα κεφάλαια                                     |
| `items[]`            | array  | Δεδομένα τάσεων περιουσιακών στοιχείων                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Σύνοψη επισκόπησης περιουσιακών στοιχείων

```http
GET /v1/private/user/asset/overview/summary
```

Τα πεδία απόκρισης είναι τα ίδια με τα πεδία σύνοψης επισκόπησης συναλλαγών, εξαιρουμένων των `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Τάση επισκόπησης περιουσιακών στοιχείων

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Παράμετροι αιτήματος:

| Παράμετρος | Τύπος   | Απαιτείται | Περιγραφή                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Ναι      | Εύρος τάσεων: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Πεδία απόκρισης:

| Πεδίο                  | Τύπος   | Περιγραφή                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Χρόνος στιγμιότυπου                   |
| `items[].balance`      | string | Ισοζύγιο τρεχουσών συναλλαγών         |
| `items[].pnl`          | string | PnL για την τρέχουσα περίοδο      |
| `items[].pnlRate`      | string | Ποσοστό PnL για την τρέχουσα περίοδο |
| `items[].totalPnl`     | string | Αθροιστικό PnL                  |
