## Παραγγελίες

| Απαρίθμηση                 | Αξίες                                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| Πλευρά παραγγελίας           | `BUY` / `SELL`                                                                                            |
| Πλευρική θέση        | `BOTH` / `LONG` / `SHORT`                                                                                 |
| Κανονικός τύπος παραγγελίας    | `LIMIT` / `MARKET`                                                                                        |
| Τύπος εντολής κατάστασης | `STOP_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_MARKET` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP`               |
| Χρόνος ισχύος        | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                                         |
| Τύπος τιμής ενεργοποίησης   | `MARK_PRICE` / `CONTRACT_PRICE`                                                                           |
| Κατάσταση παραγγελίας         | `NEW` / `PENDING` / `PARTIALLY_FILLED` / `FILLED` / `CANCELED` / `REJECTED` / `PARTIALLY_FILLED_CANCELED` |

`NEW` σημαίνει ότι το αίτημα παραγγελίας έχει γίνει αποδεκτό και επιστραφεί. `PENDING` σημαίνει ότι η εντολή έχει εισέλθει σε κατάσταση εκκρεμούς ή ανοικτής εντολής.

## Θέσεις

| Απαρίθμηση                      | Αξίες                                                      |
| ------------------------- | ----------------------------------------------------------- |
| Τιμή αιτήματος λειτουργίας περιθωρίου | `1` σταυρός, `2` απομονωμένος                                     |
| Συμβολοσειρά λειτουργίας περιθωρίου        | `ISOLATED` / `CROSS`                                        |
| Κλείσιμο λειτουργίας σκανδάλης        | `1` εγχειρίδιο, `2` λήψη κέρδους, `3` stop loss `4` εκκαθάριση |

## Κανόνες ενσωμάτωσης

- Αντιμετωπίστε τις τιμές απαρίθμησης ως τιμές καλωδίων με διάκριση πεζών-κεφαλαίων.
- Διατηρήστε άγνωστες τιμές στα αρχεία καταγραφής και αποτύχετε με ασφάλεια αντί να τις αντιστοιχίσετε σιωπηλά σε μια γνωστή κατάσταση.
- Μην συμπεραίνετε ότι κάθε κατάσταση μη οριστικής παραγγελίας είναι ασφαλής για επανάληψη. Ζητήστε την παραγγελία ή συμβιβάστε την με μια ιδιωτική WebSocket εκδήλωση.
- Αποθηκεύστε τόσο την αρχική τιμή API όσο και την ετικέτα εμφάνισης που βλέπει προς τον συνεργάτη, ώστε να μπορούν να υποστηριχθούν νέες τιμές χωρίς αλλαγή ιστορικών εγγραφών.

## Χειρισμός κατάστασης παραγγελίας

| Κρατική ομάδα | Αξίες | Συνιστώμενος χειρισμός |
| --- | --- | --- |
| Αποδεκτό ή ανοιχτό | `NEW`, `PENDING`, `PARTIALLY_FILLED` | Διατηρήστε την παραγγελία ενεργή και συμβιβαστείτε με WebSocket ή REST ενημερώσεις. |
| Ολοκληρώθηκε | `FILLED` | Εφαρμόστε την τελική συμπληρωμένη ποσότητα και τις εγγραφές εκτέλεσης. |
| Κλειστό χωρίς πλήρες γέμισμα | `CANCELED`, `REJECTED`, `PARTIALLY_FILLED_CANCELED` | Σταματήστε την ενεργή επεξεργασία και διατηρήστε τον λόγο και τυχόν εκτελεσμένη ποσότητα. |
