<h2 id="service-endpoint">Τελικό σημείο υπηρεσίας</h2>

```
wss://ws.6mm.com/ws
```

WebSocket κανάλια χωρίζονται σε δημόσια και ιδιωτικά κανάλια:

| Τύπος             | Έλεγχος ταυτότητας              | Περιγραφή                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Δημόσια κανάλια  | Δεν απαιτείται                | Δεδομένα αγοράς, όπως βάθος, συναλλαγές, Klines και ticker |
| Ιδιωτικά κανάλια | `listenKey` ή JWT απαιτείται | Ροές σειράς χρήστη, λογαριασμού και θέσης              |

<h2 id="public-channels">Δημόσια κανάλια</h2>

Η δημόσια WebSocket δεν απαιτεί έλεγχο ταυτότητας. Μετά τη σύνδεση, στείλτε ένα αίτημα `subscribe` για εγγραφή σε κανάλια αγοράς.

Κοινά κανάλια:

| Κανάλι                            | Περιγραφή                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Βάθος βιβλίου παραγγελιών. Στέλνει πρώτα ένα στιγμιότυπο και μετά τμηματικές ενημερώσεις |
| `market.trade.{symbol}`            | Τελευταίες συναλλαγές                                                      |
| `market.kline.{symbol}.{interval}` | Κλάιν                                                             |
| `market.ticker.{symbol}`           | Σύνοψη μετοχής ενός συμβόλου                                       |
| `market.tickers`                   | Σύνοψη μετοχής όλων των συμβόλων                                          |

<h2 id="private-channels">Ιδιωτικά κανάλια</h2>

<h2 id="listenkey">listenKey</h2>
Για ιδιωτικές ροές WebSocket , δημιουργήστε πρώτα μια `listenKey` μέσω του REST API και, στη συνέχεια, συνδεθείτε σε:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
Συμβατή μέθοδος σύνδεσης JWT :

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Μετά την επιτυχία του ελέγχου ταυτότητας, ο διακομιστής εγγράφει αυτόματα τη σύνδεση στο ιδιωτικό κανάλι του τρέχοντος χρήστη. Δεν απαιτείται μη αυτόματη συνδρομή.
