<h2 id="service-endpoints">Τελικά σημεία υπηρεσίας</h2>

| Τύπος      | Τελικό σημείο              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="time-and-numeric-values">Χρόνος και αριθμητικές τιμές</h2>

* Εκτός εάν ορίζεται διαφορετικά, τα πεδία χρόνου είναι χρονικές σημάνσεις Unix χιλιοστών του δευτερολέπτου.
* Τα ημερήσια στατιστικά στοιχεία, τα στιγμιότυπα υπολοίπου και τα στατιστικά στοιχεία όγκου συναλλαγών χρησιμοποιούν UTC όρια ημέρας από προεπιλογή.
* Πεδία ευαίσθητα στην ακρίβεια, όπως το ποσό, η τιμή, η ποσότητα και ο ρυθμός μεταδίδονται ως συμβολοσειρές.
* Μεγάλα ακέραια αναγνωριστικά όπως `orderId`, `conditionId`και `strategyId` επιστρέφονται ως συμβολοσειρές στο JSON.

<h2 id="response-format">Μορφή απάντησης</h2>

Επιτυχής απάντηση:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Απόκριση σφάλματος:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Σημειώσεις:

* Τα επιχειρηματικά σφάλματα συνήθως εξακολουθούν να επιστρέφουν την ενοποιημένη δομή JSON . Οι ολοκληρωτές θα πρέπει πρώτα να `code` ελέγξουν.
* Οι αποτυχίες ελέγχου ταυτότητας ενδέχεται να επιστρέψουν HTTP `401`; Ο περιορισμός του ρυθμού μπορεί να επιστρέψει HTTP `429`.
* Μπορείτε να στείλετε `X-Request-ID` στην κεφαλίδα αιτήματος. Ο διακομιστής θα το επιστρέψει ως `requestId` στην απάντηση.
