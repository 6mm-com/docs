Όταν επικοινωνείτε με την υποστήριξη, συμπεριλάβετε τις παρακάτω πληροφορίες όποτε είναι διαθέσιμες.

<span id="required-context" data-sixmm-canonical-anchor="required-context" aria-hidden="true"></span>

## Απαιτούμενο πλαίσιο

| Πεδίο | Παράδειγμα |
| --- | --- |
| Περιβάλλον | Παραγωγή ή σταδιοποίηση |
| Επηρεαζόμενη ενότητα | Trading Widget, Agent SDK, REST API, WebSocket, webhook, σύστημα λευκής ετικέτας |
| Χρονικό εύρος | UTC εύρος χρονικής σήμανσης όταν παρουσιάστηκε το πρόβλημα |
| Αναγνωριστικό χρήστη συνεργάτη | Αναγνωριστικό χρήστη από την πλευρά του συνεργάτη, εάν υπάρχει |
| 6MM αναγνωριστικό αντιστοίχισης | agentUserId, αναγνωριστικό παραγγελίας, αναγνωριστικό αιτήματος ή webhook αναγνωριστικό συμβάντος |
| Επιχειρηματικός αντίκτυπος | Αριθμός χρηστών ή λειτουργιών που επηρεάζονται και αν το πρόβλημα βρίσκεται σε εξέλιξη |

<span id="description-format" data-sixmm-canonical-anchor="description-format" aria-hidden="true"></span>

## Μορφή περιγραφής

- Τι συνέβη?
- Τι περιμένατε να συμβεί;
- Μπορεί να αναπαραχθεί;
- Τι άλλαξε πρόσφατα;
- Το θέμα εξακολουθεί να συμβαίνει;

<span id="attachments" data-sixmm-canonical-anchor="attachments" aria-hidden="true"></span>

## Συνημμένα

- Σχετικά αρχεία καταγραφής αιτημάτων και απαντήσεων.
- Στιγμιότυπα οθόνης ή εγγραφές οθόνης.
- Webhook κεφαλίδες ωφέλιμου φορτίου και υπογραφής.
- Σφάλματα κονσόλας προγράμματος περιήγησης για Trading Widget προβλήματα.

## Πρότυπο με δυνατότητα αντιγραφής

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Καταργήστε τα πεδία που δεν είναι σχετικά, αλλά διατηρήστε το UTC χρονικό εύρος και τουλάχιστον ένα αίτημα με δυνατότητα αναζήτησης ή αναγνωριστικό επιχείρησης, όποτε είναι δυνατόν.

<span id="redact-sensitive-data" data-sixmm-canonical-anchor="redact-sensitive-data" aria-hidden="true"></span>

## Απόκρυψη ευαίσθητων δεδομένων

Να μην στέλνονται:

- Κωδικοί πρόσβασης ή διακριτικά πλήρους πρόσβασης
- API μυστικά, ιδιωτικά κλειδιά ή πλήρεις υπογραφές
- Cookies περιόδου λειτουργίας
- Πλήρης πληρωμή, ταυτότητα ή άλλα περιττά προσωπικά δεδομένα

Διατηρήστε το όνομα του πεδίου και ένα σύντομο πρόθεμα ή επίθημα μόνο όταν η υποστήριξη χρειάζεται να διακρίνει μεταξύ των καθαρισμένων τιμών.
