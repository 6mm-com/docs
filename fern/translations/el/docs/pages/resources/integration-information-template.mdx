Χρησιμοποιήστε αυτό το πρότυπο κατά την προετοιμασία μιας νέας ενσωμάτωσης ή τη μεταφορά μιας υπάρχουσας ενσωμάτωσης στην παραγωγή.

<h2 id="partner-information">Πληροφορίες συνεργάτη</h2>

| Πεδίο | Περιγραφή |
| --- | --- |
| Όνομα συνεργάτη | Νομικό όνομα ή όνομα έργου που χρησιμοποιείται για την ενσωμάτωση. |
| Τύπος προϊόντος | Εφαρμογή, πορτοφόλι, πύλη μεσίτη, ανταλλαγή λευκής ετικέτας, θεσμική πλατφόρμα ή άλλο. |
| Κύριες επαφές | Επιχειρηματικές, τεχνικές, επιχειρησιακές επαφές και επαφές έκτακτης ανάγκης. |
| Περιοχές εκκίνησης | Χώρες ή περιοχές όπου θα εκτεθεί η ενσωμάτωση. |

<h2 id="technical-information">Τεχνικές πληροφορίες</h2>

| Πεδίο | Περιγραφή |
| --- | --- |
| Τομείς Frontend | Τομείς που θα φορτώσουν το γραφικό στοιχείο ή τις σελίδες εισόδου. |
| Τομείς υποστήριξης | Τομείς διακομιστή που χρησιμοποιούνται για κλήσεις Agent SDK ή API . |
| Webhook URL | Παραγωγή webhook τελικό σημείο και αναμενόμενες απαιτήσεις IP λίστας επιτρεπόμενων. |
| Πεδίο εφαρμογής ενσωμάτωσης | Trading Widget, Agent SDK, REST API, WebSocket, σύστημα λευκής ετικέτας ή ενοποίηση ρευστότητας. |

<h2 id="operational-information">Επιχειρησιακές πληροφορίες</h2>

- Αναμενόμενη ημερομηνία κυκλοφορίας.
- Αναμενόμενη επισκεψιμότητα ή εύρος ενεργών χρηστών.
- Ώρες υποστήριξης και ιδιοκτήτης κλιμάκωσης.
- Παρακολούθηση επαφής ιδιοκτήτη και συμβάντος.

<h2 id="security-and-review-information">Πληροφορίες ασφάλειας και ελέγχου</h2>

- Μέθοδος ελέγχου ταυτότητας και εύρος δικαιωμάτων API Key .
- Μυστικός χώρος αποθήκευσης, κάτοχος εναλλαγής και εγκεκριμένες IP πηγής.
- Webhook επαλήθευση υπογραφής και σχεδιασμός idempotency.
- Κάτοχοι καταγραφής, παρακολούθησης, συμφωνίας, επαναφοράς και απόκρισης σε περιστατικά.
- Αγορές-στόχοι, τύπος χρήστη, μοντέλο θεματοφυλακής και η οντότητα που είναι υπεύθυνη για τις υποχρεώσεις που αντιμετωπίζουν οι χρήστες.

Μην συμπεριλάβετε μυστικά παραγωγής, διακριτικά πλήρους πρόσβασης, ιδιωτικά κλειδιά ή μη επεξεργασμένα δεδομένα χρήστη σε αυτό το πρότυπο.

Χρησιμοποιήστε το [Λίστα ελέγχου έναρξης παραγωγής](/el/resources/production-launch-checklist) για την τελική έγκριση και την [Πρότυπο αιτήματος υποστήριξης](/el/resources/support-request-template) για κλιμάκωση του ζητήματος.
