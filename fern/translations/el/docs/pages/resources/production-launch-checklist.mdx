Χρησιμοποιήστε αυτήν τη λίστα ελέγχου πριν εκθέσετε τις δυνατότητες συναλλαγών που υποστηρίζονται από 6MMσε πραγματικούς χρήστες.

<h2 id="integration-readiness">Ετοιμότητα ενσωμάτωσης</h2>

- Οι τομείς παραγωγής και οι διαδρομές ανακατεύθυνσης επιβεβαιώνονται.
- Trading Widget, Agent SDK, APIή WebSocket έχουν δοκιμαστεί από άκρο σε άκρο.
- Το backend συνεργάτη αποθηκεύει όλα τα μυστικά από την πλευρά του διακομιστή.
- Webhook είναι ενεργοποιημένη η λήψη, η επαλήθευση υπογραφής, ο χειρισμός επανάληψης και η idempotency.
- Τα αρχεία καταγραφής περιλαμβάνουν αναγνωριστικά αιτημάτων, αναγνωριστικά αντιστοίχισης χρηστών, αναγνωριστικά παραγγελιών και χρονικές σημάνσεις.

<h2 id="product-and-resource-readiness">Ετοιμότητα προϊόντων και πόρων</h2>

- Τα σημεία εισόδου, τα banner και τα στοιχεία της κάρτας χρησιμοποιούν την εγκεκριμένη γλωσσική έκδοση.
- Τα στοιχεία λευκής ετικέτας χρησιμοποιούνται μόνο όταν το επιτρέπει η συμφωνία συνεργασίας.
- Οι προτροπές κινδύνου που αντιμετωπίζουν οι χρήστες και το αντίγραφο καταχώρισης συναλλαγών εξετάζονται από την ομάδα συνεργατών.
- Εκχωρούνται ιδιοκτήτες υποστήριξης και κλιμάκωσης.

<h2 id="operational-readiness">Επιχειρησιακή ετοιμότητα</h2>

- Η παρακολούθηση καλύπτει σφάλματα API , έκδοση διακριτικών, προετοιμασία γραφικών στοιχείων, αποτυχίες webhook και συμβάντα κύκλου ζωής παραγγελιών.
- Οι διαδρομές επαφής έκτακτης ανάγκης επιβεβαιώνονται.
- Προετοιμάζεται σχέδιο επαναφοράς ή προσωρινής απενεργοποίησης για την καταχώριση συναλλαγών.

<h2 id="security-and-compliance-readiness">Ετοιμότητα ασφάλειας και συμμόρφωσης</h2>

- Τα κλειδιά API χρησιμοποιούν ελάχιστα δικαιώματα και εγκεκριμένους περιορισμούς IP , όπου ισχύουν.
- Η εναλλαγή και η ανάκληση διαπιστευτηρίων έχουν δοκιμαστεί.
- Webhook οι υπογραφές επαληθεύονται σε σχέση με τα ακατέργαστα σώματα αιτημάτων.
- Οι γνωστοποιήσεις χρηστών, οι ειδοποιήσεις κινδύνου, τα όρια ευθύνης και η ανασκόπηση της αγοράς-στόχου είναι πλήρεις.
- Τα στοιχεία περιστατικού, συμφιλίωσης και υποστήριξης μπορούν να ανακτηθούν χωρίς να αποκαλυφθούν μυστικά.
