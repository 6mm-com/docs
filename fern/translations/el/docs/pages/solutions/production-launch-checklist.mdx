Χρησιμοποιήστε αυτήν τη λίστα ελέγχου πριν εκθέσετε τις ροές συναλλαγών που τροφοδοτούνται από 6MMστους χρήστες παραγωγής. Έχει σχεδιαστεί για ομάδες προϊόντων, μηχανικής, λειτουργιών, κινδύνου και υποστήριξης να εξετάζουν από κοινού.

<span id="launch-checklist" data-sixmm-canonical-anchor="launch-checklist" aria-hidden="true"></span>

## Λίστα ελέγχου εκκίνησης

| Περιοχή | Υπόμνημα |
| --- | --- |
| Προϊόν | Τα σημεία εισόδου, το αντίγραφο χρήστη, οι προτροπές κινδύνου, η γλωσσική κάλυψη και οι διαδρομές υποστήριξης είναι έτοιμα. |
| Παρασκήνιο | API υλοποιούνται τα διαπιστευτήρια, η υπογραφή, η έκδοση διακριτικών, η webhooks, οι επαναλήψεις και η καταγραφή. |
| Συναλλαγές | Η συμπεριφορά παραγγελίας, μεταφοράς, θέσης, περιθωρίου, αμοιβής και ρευστοποίησης έχει αναθεωρηθεί. |
| Ασφάλεια | Προετοιμάζονται μυστικά, ρόλοι πρόσβασης, παρακολούθηση, απόκριση σε περιστατικά και αρχεία καταγραφής ελέγχου. |
| Λειτουργίες | Εκχωρούνται ροές εργασίας υποστήριξης, διαδρομές κλιμάκωσης, συμφωνία και καθημερινή παρακολούθηση. |

<span id="recommended-sequence" data-sixmm-canonical-anchor="recommended-sequence" aria-hidden="true"></span>

## Συνιστώμενη ακολουθία

1. Ολοκληρώστε την επικύρωση sandbox ή εσωτερικού περιβάλλοντος.
2. Εκτελέστε διαδρομές χρήστη από άκρο σε άκρο για σύνδεση, είσοδο, μεταφορά, συναλλαγές και υποστήριξη.
3. Επιβεβαιώστε την ιδιοκτησία παρακολούθησης και απόκρισης συμβάντων.
4. Εγκρίνετε δημόσιο αντίγραφο, τοπικά προσαρμοσμένα στοιχεία και λήψεις πόρων.
5. Ξεκινήστε με ένα ελεγχόμενο παράθυρο εκκίνησης πριν από την ευρεία προώθηση.

<span id="after-launch" data-sixmm-canonical-anchor="after-launch" aria-hidden="true"></span>

## Μετά την εκτόξευση

Ελέγξτε τη δραστηριότητα καθημερινά κατά την αρχική περίοδο κυκλοφορίας. Παρακολουθήστε τη μετατροπή καταχώρισης, τις αποτυχίες έκδοσης διακριτικών, τα σφάλματα παραγγελιών, την ποιότητα εξάπλωσης, την ολοκλήρωση μεταφοράς, τις επαναλήψεις webhook και τα εισιτήρια υποστήριξης μαζί.

<span id="implementation-resources" data-sixmm-canonical-anchor="implementation-resources" aria-hidden="true"></span>
