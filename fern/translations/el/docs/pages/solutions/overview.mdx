<h2 id="how-the-solutions-connect">Πώς συνδέονται οι λύσεις</h2>

Οι περισσότερες υλοποιήσεις συνεργατών συνδυάζουν περισσότερες από μία δυνατότητες 6MM . Ένα ανταλλακτήριο λευκής ετικέτας μπορεί να χρησιμοποιεί θεσμική ρευστότητα, υποστήριξη συμμόρφωσης και ενσωματώσεις API . Ένας ενσωματωμένος εμπορικός εταίρος μπορεί να ξεκινήσει με το Trading Widget SDK και αργότερα να προσθέσει ροές Agent SDK backend, webhook επεξεργασία και λειτουργικούς πόρους.
