Το Embedded API / SDK Trading System έχει σχεδιαστεί για συνεργάτες που κατέχουν ήδη επισκεψιμότητα, χρήστες ή επιχειρηματικές ροές εργασίας και θέλουν να προσθέσουν συναλλαγές χωρίς να δημιουργήσουν μια πλήρη ανταλλαγή από την αρχή.

<h2 id="what-it-provides">Τι παρέχει</h2>

- Ενσωματωμένο τερματικό συναλλαγών μέσω του Trading Widget SDK
- Ενσωμάτωση backend συνεργάτη μέσω Agent SDKs
- Ροές δέσμευσης ταυτότητας χρήστη και διακριτικού εισόδου
- Μεταφορά περιουσιακών στοιχείων, παραγγελία, θέση και πρόσβαση API λογαριασμού
- Ενοποίηση συμβάντων, webhookκαι κύκλου ζωής για λειτουργικά συστήματα

<h2 id="recommended-architecture">Προτεινόμενη αρχιτεκτονική</h2>

| Επίπεδο | Υπευθυνότητα |
| --- | --- |
| Frontend συνεργάτη | Φιλοξενεί το σημείο εισόδου και ενσωματώνει τη διεπαφή συναλλαγών 6MM . |
| Υποστήριξη συνεργάτη | Διατηρεί API μυστικά, επικυρώνει τους χρήστες, εκδίδει διακριτικά ενσωμάτωσης και επεξεργάζεται webhooks. |
| 6MM υποδομή συναλλαγών | Χειρίζεται τη διεπαφή χρήστη συναλλαγών, την αντιστοίχιση, τον κίνδυνο, τη ρευστότητα, την κατάσταση λογαριασμού και τον κύκλο ζωής συναλλαγών. |

<h2 id="choose-an-integration-path">Επιλέξτε μια διαδρομή ενσωμάτωσης</h2>

| Απαίτηση | Προτεινόμενη διαδρομή |
| --- | --- |
| Ολοκληρωμένη διεπαφή χρήστη συναλλαγών με την ταχύτερη ενσωμάτωση ιστού | Trading Widget |
| Σύνδεση χρήστη υποστήριξης, μεταφορά, URL εισόδου και χειρισμός webhook | Agent SDK |
| Πλήρως προσαρμοσμένες ροές εργασιών προϊόντων και παραγγελιών | REST API + WebSocket |
| Επώνυμη εμπειρία ανταλλαγής με ευρύτερο λειτουργικό πεδίο εφαρμογής | Ανταλλαγή λευκής ετικέτας |

Ο τελικός σχεδιασμός μπορεί να συνδυάζει αυτές τις διαδρομές. Επιβεβαιώστε τον έλεγχο ταυτότητας, την ιδιοκτησία περιουσιακών στοιχείων, τα όρια ευθύνης, την παρακολούθηση και την υποστήριξη παραγωγής πριν ξεκινήσει η υλοποίηση.
