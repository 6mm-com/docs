> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Το Hosted MCP είναι ο απλούστερος τρόπος για να ξεκινήσετε με το 6MM AI Hub.

Συνδέστε έναν πελάτη τεχνητής νοημοσύνης στο τελικό σημείο 6MM που φιλοξενείται MCP και κάντε ερωτήσεις σχετικά με δεδομένα δημόσιας αγοράς. Δεν υπάρχει τοπικός διακομιστής για εγκατάσταση, ανάπτυξη cloud για συντήρηση και κλειδί χρήστη API που απαιτείται για δημόσια δεδομένα.

<span id="what-you-can-do" data-sixmm-canonical-anchor="what-you-can-do" aria-hidden="true"></span>

## Τι μπορείτε να κάνετε

- Ζητήστε ζωντανά και ιστορικά δεδομένα αγοράς.
- Περιηγηθείτε στις διαθέσιμες αιώνιες αγορές.
- Ελέγξτε το βάθος του βιβλίου παραγγελιών και τις πρόσφατες συναλλαγές.
- Συγκρίνετε τα ποσοστά χρηματοδότησης.
- Διαβάστε το πλαίσιο αμοιβής, σύμβασης, περιθωρίου κέρδους και κανόνα κινδύνου.

Το φιλοξενούμενο MCP είναι το καλύτερο για έρευνα, εξερεύνηση προϊόντων και ανάλυση δημόσιας αγοράς. Δεν είναι η σωστή πρώτη ρύθμιση για πρόσβαση ή συναλλαγές σε ιδιωτικό λογαριασμό.

## Προτεινόμενο εύρος πρώτης κυκλοφορίας

Η φιλοξενούμενη MCP θα πρέπει να εκθέτει μόνο δημόσιες πληροφορίες και πληροφορίες μόνο για ανάγνωση στην πρώτη έκδοση:

- Αγορές.
- Tickers.
- Παραγγείλετε βιβλία.
- Πρόσφατες συναλλαγές.
- Klines.
- Ποσοστά χρηματοδότησης.
- Κατάσταση συστήματος.
- Προμήθειες συναλλαγών.
- Προδιαγραφές συμβολαίου.
- Πόροι κανόνων κινδύνου και περιθωρίου.

<span id="not-supported-in-the-first-release" data-sixmm-canonical-anchor="not-supported-in-the-first-release" aria-hidden="true"></span>

## Δεν υποστηρίζεται στην πρώτη έκδοση

Η φιλοξενούμενη MCP δεν θα πρέπει να είναι το πρώτο μέρος για την έκθεση:

- Υπόλοιπα λογαριασμών.
- Θέσεις.
- Ανοιχτές παραγγελίες.
- Δημιουργία παραγγελίας.
- Ακύρωση παραγγελίας.
- Μεταφορές ή αναλήψεις.
- Αποθηκευτικός χώρος κλειδιού χρήστη API.

<span id="why-public-data-first" data-sixmm-canonical-anchor="why-public-data-first" aria-hidden="true"></span>

## Γιατί πρώτα δημόσια δεδομένα

Το φιλοξενούμενο MCP λειτουργεί από τον 6MM και έχει πρόσβαση μέσω του δικτύου. Είναι βολικό, αλλά δεν θα πρέπει να γίνει το προεπιλεγμένο μέρος όπου οι χρήστες υποβάλλουν ιδιωτικά κλειδιά API. Οι ευαίσθητοι λογαριασμοί και οι ροές εργασιών συναλλαγών θα πρέπει να ξεκινούν με Τοπικό MCP, CLI ή απομακρυσμένο που διαχειρίζεται ο χρήστης MCP.

Use 6MM to check BTC-USDT-PERP orderbook depth and summarize liquidity.

## Λειτουργικές απαιτήσεις

- TLS σε όλα τα τελικά σημεία.
- Ζητήστε όρια ποσοστού.
- Προστασία από κατάχρηση.
- Δομημένα αρχεία καταγραφής και μετρήσεις.
- Έλεγχοι υγείας.
- Καθαρίστε τις περιγραφές και τα σχήματα εργαλείων.
- Σταθερές αποκρίσεις σφαλμάτων για πελάτες τεχνητής νοημοσύνης.
