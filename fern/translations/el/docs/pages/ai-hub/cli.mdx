> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


6MM CLI είναι το σημείο εισόδου της γραμμής εντολών για χρήστες, σενάρια και πράκτορες AI που μπορούν να εκτελούν εντολές φλοιού.

Χρησιμοποιήστε το CLI όταν το περιβάλλον AI μπορεί να εκτελεί απευθείας εντολές τερματικού. Αυτή είναι συχνά η απλούστερη διαδρομή για πράκτορες κωδικοποίησης, επειδή δεν απαιτείται ξεχωριστός διακομιστής MCP. Το CLI θα πρέπει να επιστρέψει σταθερό JSON από προεπιλογή, ώστε οι πράκτορες να μπορούν να αναλύουν τα αποτελέσματα χωρίς να βασίζονται στη μορφοποίηση τερματικού.

## Για ποιο λόγο είναι καλό το CLI

- Γρήγορα ερωτήματα για δεδομένα αγοράς από ένα τερματικό.
- Ανάλυση βασισμένη σε πράκτορες σε Codex, Claude Code, Gemini CLI ή παρόμοια εργαλεία.
- CI ή προγραμματισμένα σενάρια που χρειάζονται 6MM δεδομένα.
- Ελέγχει την ανάγνωση του λογαριασμού όταν διαμορφώνονται τα τοπικά διαπιστευτήρια.
- Η προεπισκόπηση παραγγελίας ρέει εκεί όπου ο πράκτορας προετοιμάζει παραμέτρους αλλά δεν υποβάλλει παραγγελία.

## Παραδείγματα εντολών

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

## Λειτουργίες εξόδου

| Τρόπος | Θήκη χρήσης |
| --- | --- |
| JSON | Προεπιλογή για πράκτορες AI, σενάρια και αυτοματισμό. |
| Τραπέζι | Ανασκόπηση τερματικού αναγνώσιμου από τον άνθρωπο. |
| Ακατέργαστος | Δοκιμές εντοπισμού σφαλμάτων και ενοποίησης. |

## Προτεινόμενες προεπιλογές ασφαλείας

- Το προεπιλεγμένο περιβάλλον είναι το testnet.
- Η προεπιλεγμένη έξοδος είναι JSON.
- Οι εντολές συναλλαγών απαιτούν ρητή συμμετοχή.
- Η δημιουργία παραγγελίας μέσω δικτύου απαιτεί επιβεβαίωση.
- Η λειτουργία προεπισκόπησης είναι διαθέσιμη πριν από τη δημιουργία.
- Τα σφάλματα περιλαμβάνουν σταθερούς κωδικούς και καθαρά μηνύματα.

## Χρήση πράκτορα

Οι πράκτορες AI θα πρέπει να προτιμούν εντολές μόνο για ανάγνωση, εκτός εάν ο χρήστης ζητήσει ρητά ενέργειες προεπισκόπησης ή συναλλαγών.

Παράδειγμα προτροπής:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
