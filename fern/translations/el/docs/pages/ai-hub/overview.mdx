> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


6MM Το Agentic AI Hub είναι η AI-εγγενής διεπαφή για 6MM δεδομένα αγοράς, ροές εργασίας λογαριασμού και μελλοντικές ελεγχόμενες συναλλαγές.

Αντί να κάνουν εναλλαγή μεταξύ πινάκων εργαλείων, API εγγράφων και σεναρίων, οι χρήστες μπορούν να ζητήσουν από έναν πελάτη τεχνητής νοημοσύνης να υποβάλει ερώτημα στο 6MM, να εξηγήσει τις συνθήκες της αγοράς, να ελέγξει τον κίνδυνο λογαριασμού ή να προετοιμάσει μια προεπισκόπηση παραγγελίας. Ο πελάτης AI δεν αντικαθιστά το μοντέλο ασφαλείας 6MM API. καλεί δομημένα 6MM εργαλεία μέσω CLI, MCP ή προτύπων ροής εργασίας.

<h2 id="what-you-can-ask-an-ai-client">Τι μπορείτε να ζητήσετε από έναν πελάτη AI</h2>

Χρησιμοποιήστε το AI Hub όταν θέλετε να κάνετε ερωτήσεις όπως:

```text
Show me the BTC-USDT-PERP order book and explain current liquidity.
```

```text
Compare BTC and ETH funding rates over the last 24 hours.
```

```text
Check my testnet positions and explain liquidation risk. Do not place orders.
```

```text
Preview a small BTC long order and explain fees, margin impact, and risk checks.
```

<h2 id="why-ai-agents-need-a-dedicated-access-layer">Γιατί οι πράκτορες AI χρειάζονται ένα αποκλειστικό επίπεδο πρόσβασης</h2>

Οι πράκτορες AI λειτουργούν καλύτερα όταν διαθέτουν δομημένα εργαλεία αντί για ακατέργαστες ιστοσελίδες ή μη δομημένο αντιγραμμένο κείμενο. Το AI Hub τους δίνει:

| Απαίτηση | 6MM προσέγγιση |
| --- | --- |
| Ζωντανό πλαίσιο αγοράς | Εργαλεία και πόροι δεδομένων δημόσιας αγοράς για σύμβολα, βιβλία παραγγελιών, συναλλαγές, χρηματοδότηση, χρεώσεις και κανόνες. |
| Εκκαθάριση αδειών | Διαχωρίστε δημόσια δεδομένα, ανάγνωση λογαριασμού, προεπισκόπηση και ελεγχόμενα πεδία συναλλαγών. |
| Ασφαλέστερη εκτέλεση | Προεπισκόπηση ροής πρώτης σειράς, ρητής επιβεβαίωσης, αδυναμίας, ορίων και αρχείων καταγραφής ελέγχου. |
| Ευελιξία πελάτη | Φιλοξενείται MCP, Τοπικό MCP, CLI, Απομακρυσμένο MCP και Agentic Skills για διαφορετικά περιβάλλοντα AI. |

<h2 id="setup-paths">Ρύθμιση μονοπατιών</h2>

| Μονοπάτι | Το καλύτερο για | Ο χρήστης πρέπει να γνωρίζει |
| --- | --- | --- |
| Φιλοξενείται MCP | Γρήγορη πρόσβαση σε δεδομένα δημόσιας αγοράς | Χωρίς εγκατάσταση και χωρίς κλειδί χρήστη API για δημόσια δεδομένα. Το εμπόριο δεν είναι ο στόχος της πρώτης κυκλοφορίας. |
| Τοπικό MCP | Πελάτες τεχνητής νοημοσύνης που χρειάζονται πλαίσιο ιδιωτικού λογαριασμού | Ο διακομιστής MCP εκτελείται τοπικά και τα διαπιστευτήρια παραμένουν στον υπολογιστή του χρήστη. |
| CLI | Πράκτορες κωδικοποίησης, σενάρια και χρήστες τερματικού | Παράγει εντολές φιλικές προς τον πράκτορα και μπορεί να χρησιμοποιηθεί χωρίς διακομιστή MCP. |
| Τηλεχειριστήριο MCP | Ιδρύματα και ομάδες που θέλουν το δικό τους τελικό σημείο | Ο χρήστης ή το ίδρυμα ελέγχει τη φιλοξενία, τα διαπιστευτήρια, την πρόσβαση στο δίκτυο και τα αρχεία καταγραφής. |
| Agentic Skills | Επαναλαμβανόμενες ροές εργασίας | Οι δεξιότητες καθοδηγούν την τεχνητή νοημοσύνη μέσω της ανάλυσης και των βημάτων κινδύνου χρησιμοποιώντας εγκεκριμένα εργαλεία. |

<h2 id="what-is-available-first">Τι είναι πρώτο διαθέσιμο</h2>

Το AI Hub θα πρέπει να ξεκινά με δεδομένα δημόσιας αγοράς και πόρους βάσει κανόνων συναλλαγών:

- Αγορές.
- Tickers.
- Παραγγείλετε βιβλία.
- Συναλλαγές.
- Klines.
- Ποσοστά χρηματοδότησης.
- Κατάσταση συστήματος.
- Προμήθειες, προδιαγραφές συμβολαίου, κανόνες περιθωρίου κέρδους και πόροι κανόνων κινδύνου.

Η πρόσβαση και οι συναλλαγές σε ιδιωτικό λογαριασμό θα πρέπει να είναι σταδιακά:

- Τα εργαλεία ανάγνωσης λογαριασμού απαιτούν ρητά διαπιστευτήρια μόνο για ανάγνωση.
- Η προεπισκόπηση παραγγελίας θα πρέπει να προηγείται της δημιουργίας πραγματικής παραγγελίας.
- Οι ελεγχόμενες συναλλαγές απαιτούν πεδία αδειών, ελέγχους κινδύνου από την πλευρά της υπηρεσίας, επιβεβαίωση χρήστη, ανικανότητα και αρχεία καταγραφής ελέγχου.
