> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Τα εργαλεία MCP είναι ενέργειες που μπορεί να καλέσει ένας πελάτης τεχνητής νοημοσύνης. Κάθε εργαλείο πρέπει να έχει μια σαφή περιγραφή, JSON σχήμα, απαίτηση άδειας, σταθερή μορφή απόκρισης και μοντέλο σφάλματος.

## Φάση 1: εργαλεία δημόσιας αγοράς

| Εργαλείο | Σκοπός |
| --- | --- |
| Κατάσταση_συστήματος 6mm | Ελέγξτε την υπηρεσία και τη διαθεσιμότητα της αγοράς. |
| 6mm_markets | Καταγράψτε τις διαθέσιμες αγορές και τα βασικά μεταδεδομένα. |
| 6mm_market_summary | Συνοψίστε την κατάσταση της αγοράς για ένα ή περισσότερα σύμβολα. |
| 6mm_ticker | Επιστρέψτε τα πιο πρόσφατα δεδομένα ticker. |
| 6mm_βιβλίο παραγγελιών | Βάθος βιβλίου παραγγελιών επιστροφής. |
| 6mm_klines | Επιστρέψτε ιστορικά κεριά. |
| 6mm_trades | Επιστρέψτε πρόσφατες δημόσιες συναλλαγές. |
| 6mm_rates_funding | Επιστροφή τρέχοντα και ιστορικά επιτόκια χρηματοδότησης. |

## Απαιτήσεις εργαλείου

Κάθε εργαλείο πρέπει να ορίζει:

- Περιγραφή για το μοντέλο AI.
- Εισαγωγή σχήματος JSON.
- Εύρος άδειας.
- Περιβαλλοντική υποστήριξη.
- Συμπεριφορά ορίου ρυθμού.
- Σταθερά πεδία απόκρισης.
- Κωδικοί σφαλμάτων.
- Πεδία καταγραφής ελέγχου.
