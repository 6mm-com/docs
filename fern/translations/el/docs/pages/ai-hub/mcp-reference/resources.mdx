> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Οι πόροι MCP είναι περιβάλλον μόνο για ανάγνωση που μπορούν να επιθεωρήσουν οι πελάτες τεχνητής νοημοσύνης πριν καλέσουν εργαλεία.

Οι πόροι μειώνουν τις παραισθήσεις δίνοντας στο μοντέλο σταθερές, δομημένες πληροφορίες για το 6MM.

<span id="recommended-resource-uris" data-sixmm-canonical-anchor="recommended-resource-uris" aria-hidden="true"></span>

## Προτεινόμενα URI πόρων

| Πόρος | Σκοπός |
| --- | --- |
| 6mm://system/config | Διαμόρφωση περιβάλλοντος και δυνατότητας. |
| 6mm://system/status | Τρέχον σύστημα και κατάσταση της αγοράς. |
| 6mm://markets | Διαθέσιμες αγορές. |
| 6mm://market/{symbol} | Προδιαγραφές συμβολαίου και μεταδεδομένα σε επίπεδο αγοράς. |
| 6mm://τέλες | Κανόνες χρέωσης. |
| 6mm://risk/rules | Σύνοψη κανόνων συναλλαγών και κινδύνου. |
| 6mm://risk/περιθώριο | Περιθώριο και πλαίσιο εκκαθάρισης. |
| 6mm://funding/rules | Κανόνες ποσοστού χρηματοδότησης. |
| 6mm://api/docs | API περίληψη ή σύνδεσμοι αναφοράς. |

<span id="resource-design-rules" data-sixmm-canonical-anchor="resource-design-rules" aria-hidden="true"></span>

## Κανόνες σχεδιασμού πόρων

- Διατηρήστε πόρους μόνο για ανάγνωση.
- Χρησιμοποιήστε σταθερά σχήματα.
- Συμπεριλάβετε χρονικές σημάνσεις και ονόματα περιβάλλοντος.
- Αποφύγετε την αποκάλυψη μυστικών.
- Προτιμήστε τα συνοπτικά δομημένα δεδομένα από τη μεγάλη πρόζα.
- Σύνδεση με κανονική τεκμηρίωση όταν οι λεπτομέρειες είναι πολύ μεγάλες.
