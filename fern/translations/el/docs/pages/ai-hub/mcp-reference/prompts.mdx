> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Οι προτροπές MCP είναι επαναχρησιμοποιήσιμες ροές εργασίας που εκτίθενται από τον διακομιστή MCP. Βοηθούν τους χρήστες να κάνουν συνεπείς ερωτήσεις και βοηθούν τους πελάτες τεχνητής νοημοσύνης να χρησιμοποιούν τα σωστά εργαλεία.

<h2 id="recommended-prompts">Προτεινόμενες προτροπές</h2>

| Ταχύς | Σκοπός |
| --- | --- |
| αγορά_επισκόπηση | Συνοψίστε την κατάσταση της αγοράς σε επιλεγμένα σύμβολα. |
| market_microstructure_analysis | Αναλύστε το spread, το βάθος, τις πρόσφατες συναλλαγές και τις συνθήκες ρευστότητας. |
| portfolio_risk_assessment | Ελέγξτε τις θέσεις, την έκθεση, το περιθώριο και τον κίνδυνο ρευστοποίησης. |
| θέση_διαχείριση | Βοηθήστε τους χρήστες να κατανοήσουν την κατάσταση της θέσης και τις πιθανές ενέργειες. |
| εκκαθάριση_προστασία | Προσδιορίστε τον κίνδυνο ρευστοποίησης και τις επιλογές μείωσης του κινδύνου. |
| χρηματοδότηση_ποσοστό_ευκαιρίας | Συγκρίνετε τα ποσοστά χρηματοδότησης και τις πιθανές ευκαιρίες. |
| create_optimal_order | Σχεδιάστε τις παραμέτρους παραγγελίας πριν από την προεπισκόπηση. |
| hedging_strategy | Εξερευνήστε επιλογές αντιστάθμισης κινδύνου για υφιστάμενα ανοίγματα. |
| trade_consultation | Δημιουργήστε μια δομημένη ανάλυση συναλλαγών χωρίς να εκτελείτε εντολές. |

<h2 id="prompt-safety-rules">Άμεσοι κανόνες ασφαλείας</h2>

- Μην αντιμετωπίζετε την άμεση απόδοση ως οικονομική συμβουλή.
- Μην εκτελείτε εργαλεία συναλλαγών εκτός εάν το ζητήσει ρητά ο χρήστης.
- Χρησιμοποιήστε την προεπισκόπηση πριν από τη δημιουργία.
- Εξηγήστε τις υποθέσεις και τις πηγές δεδομένων.
- Προτιμήστε παραδείγματα testnet σε δημόσια τεκμηρίωση.
