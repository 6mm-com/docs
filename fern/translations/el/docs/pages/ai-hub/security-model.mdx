> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Η εμπορική πρόσβαση που υποστηρίζεται από τεχνητή νοημοσύνη πρέπει να είναι ασφαλέστερη από την συνηθισμένη αυτοματοποίηση, επειδή η πρόθεση του χρήστη εκφράζεται σε φυσική γλώσσα.

## Απαιτούμενα πεδία άδειας

| Εκταση | επιτρέπει |
| --- | --- |
| αγορά: διαβάστε | Δεδομένα δημόσιας αγοράς και πόροι κανόνων. |
| λογαριασμός: διαβάστε | Υπόλοιπα, θέσεις, ανοιχτές εντολές, συμπληρώσεις και περιλήψεις λογαριασμών. |
| παραγγελία:γράψτε | Δημιουργία, τροποποίηση και ακύρωση παραγγελίας. |

## Προεπιλεγμένη στάση ασφαλείας

- Προεπιλογή μόνο για ανάγνωση.
- Προεπιλογή για το testnet.
- Μην εκθέτετε αναλήψεις ή μεταφορές μέσω εργαλείων AI.
- Απαιτείται προεπισκόπηση πριν από τη δημιουργία.
- Απαιτήστε ρητή επιβεβαίωση πριν από τις συναλλαγές στο κεντρικό δίκτυο.
- Χρησιμοποιήστε κλειδιά αδυναμίας για συναλλαγές.
- Εφαρμόστε μέγιστα πλασματικά όρια και όρια μόχλευσης.
- Διατηρήστε πλήρη αρχεία καταγραφής ελέγχου.

## Ελεγχόμενη ροή συναλλαγών

```text
User natural language intent
  -> AI maps intent to tool parameters
  -> 6mm_preview_order validates the order
  -> service returns risk checks and margin impact
  -> user explicitly confirms
  -> 6mm_create_order submits the order
  -> audit log records the full flow
```

## Προστασία έγκαιρης έγχυσης

Οι πελάτες τεχνητής νοημοσύνης και οι διακομιστές MCP θα πρέπει να αντιμετωπίζουν το εξωτερικό περιεχόμενο ως μη αξιόπιστο. Οι σελίδες της αγοράς, το αντιγραμμένο κείμενο, τα έγγραφα και το περιεχόμενο ιστού δεν πρέπει να παρακάμπτουν τα δικαιώματα εργαλείων, τους κανόνες επιβεβαίωσης ή τα όρια συναλλαγών.
