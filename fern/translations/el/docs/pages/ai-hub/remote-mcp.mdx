> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Το απομακρυσμένο MCP είναι για χρήστες ή ιδρύματα που θέλουν ένα μακροχρόνιο τελικό σημείο MCP υπό τον δικό τους έλεγχο.

Σε αντίθεση με το Hosted MCP, το Remote MCP δεν λειτουργεί από το 6MM για τον χρήστη. Το 6MM παρέχει κώδικα, εικόνες, πρότυπα και τεκμηρίωση. ο χρήστης ελέγχει τη φιλοξενία και τα διαπιστευτήρια.

<h2 id="architecture">Αρχιτεκτονική</h2>

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<h2 id="deployment-targets">Στόχοι ανάπτυξης</h2>

- Docker ή Docker Compose.
- VPS με αντίστροφο διακομιστή μεσολάβησης.
- Σιδηροδρομικός.
- Καθιστώ.
- Fly.io.
- AWS ECS ή Λάμδα.
- Εσωτερικά Kubernetes.

<h2 id="required-files">Απαιτούμενα αρχεία</h2>

- Dockerfile.
- docker-compose.yml.
- .env.πρότυπο.
- HTTP τρόπος μεταφοράς.
- τελικό σημείο /mcp.
- /τελικό σημείο υγείας.
- Αντίστροφος διακομιστής μεσολάβησης και TLS σημειώσεις.

<h2 id="credential-model">Μοντέλο διαπιστευτηρίων</h2>

Τα διαπιστευτήρια θα πρέπει να αποθηκεύονται στο περιβάλλον που διαχειρίζεται ο χρήστης και όχι στη γραμμή εντολών πελάτη AI. Για αναπτύξεις που διαχειρίζονται ιδρύματα, περιορίστε την πρόσβαση σε εγκεκριμένους πελάτες και δίκτυα.

<h2 id="recommended-first-release">Συνιστώμενη πρώτη έκδοση</h2>

Ξεκινήστε με δεδομένα δημόσιας αγοράς. Προσθήκη λογαριασμών για ανάγνωση μόνο μετά τον έλεγχο ταυτότητας, είναι διαθέσιμα η εμβέλεια κλειδιού, τα αρχεία καταγραφής και τα στοιχεία ελέγχου πρόσβασης. Η διαπραγμάτευση θα πρέπει να παραμείνει απενεργοποιημένη έως ότου ικανοποιηθούν οι ελεγχόμενες απαιτήσεις συναλλαγών.
