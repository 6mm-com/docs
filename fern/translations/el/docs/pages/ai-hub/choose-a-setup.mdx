> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Επιλέξτε μια ρύθμιση με βάση δύο ερωτήσεις:

1. Ποιο πρόγραμμα-πελάτη AI θέλετε να χρησιμοποιήσετε;
2. Χρειάζεστε μόνο δημόσια δεδομένα, πρόσβαση σε ιδιωτικό λογαριασμό ή ροές εργασιών συναλλαγών;

Εάν δεν είστε σίγουροι, ξεκινήστε με Φιλοξενούμενο MCP για δημόσια δεδομένα ή Τοπικό MCP για ροές εργασίας ιδιωτικού λογαριασμού.

## Πίνακας γρήγορης απόφασης

| Γκολ | Προτεινόμενη ρύθμιση | Γιατί |
| --- | --- | --- |
| Ρωτήστε έναν πελάτη τεχνητής νοημοσύνης για δεδομένα δημόσιας αγοράς | Φιλοξενείται MCP | Δεν απαιτείται τοπική εγκατάσταση και δεν απαιτείται κλειδί API. |
| Επιτρέψτε στον Claude Desktop, Cursor ή ChatGPT Desktop να καλέσει τα εργαλεία 6MM | Τοπικό MCP | Το AI καλεί εργαλεία μέσω ενός τοπικού διακομιστή που ελέγχεται από τον χρήστη. |
| Αφήστε Codex, Claude Code, Gemini CLI ή σενάρια να καλέσουν 6MM | CLI | Η έξοδος εντολών μπορεί να είναι JSON και είναι εύκολο να αναλύσουν οι πράκτορες. |
| Παρέχετε ένα τελικό σημείο MCP που διαχειρίζεται η εταιρεία | Τηλεχειριστήριο MCP | Το ίδρυμα ελέγχει τη φιλοξενία, τα διαπιστευτήρια, την πρόσβαση και τα αρχεία καταγραφής. |
| Τυποποιήστε επαναλαμβανόμενες αναλύσεις ή ροές εργασιών κινδύνου | Agentic Skills | Τα πρότυπα ορίζουν τη χρήση του εργαλείου, τα προστατευτικά κιγκλιδώματα και τη μορφή εξόδου. |

## Επιλογή ανά διαδρομή ρύθμισης

| Ρύθμιση | Εγκατάσταση | API θέση κλειδιού | Καλύτερο αρχικό εύρος | Λογαριασμός και πεδίο συναλλαγών |
| --- | --- | --- | --- | --- |
| Φιλοξενείται MCP | Κανένας | Δεν υπάρχει κλειδί χρήστη API για δημόσια δεδομένα | Στοιχεία δημόσιας αγοράς | Δεν συνιστάται για πρώτη κυκλοφορία |
| Τοπικό MCP | Πακέτο εγκαταστάσεων χρήστη | Μηχανή χρήστη | Δημόσια δεδομένα και ανάγνωση λογαριασμού | Προτεινόμενη διαδρομή για μελλοντικές συναλλαγές |
| CLI | Πακέτο εγκαταστάσεων χρήστη | Μηχανή χρήστη | Δημόσια δεδομένα και σενάρια | Χρήσιμο για προεπισκόπηση και αυτοματισμό |
| Τηλεχειριστήριο MCP | Ο χρήστης αναπτύσσει διακομιστή | Σύννεφο χρήστη ή σύννεφο ιδρύματος | Δημόσια δεδομένα ή ανάγνωση λογαριασμού | Δυνατότητα όταν ο χρήστης ελέγχει την ανάπτυξη |
| Δεξιότητες | Έγγραφα ή πρότυπα με δυνατότητα εγκατάστασης | Εξαρτάται από τα υποκείμενα εργαλεία | Ροές εργασιών ανάλυσης | Πρέπει να ακολουθείτε τα δικαιώματα του εργαλείου |

## Εμπειρικός κανόνας ασφαλείας

Χρησιμοποιήστε τη ρύθμιση χαμηλότερου κινδύνου που υποστηρίζει την εργασία:

- Δεδομένα δημόσιας αγοράς: Η φιλοξενούμενη MCP είναι αρκετά.
- Δεδομένα ιδιωτικού λογαριασμού: Τοπικό MCP ή απομακρυσμένη διαχείριση από χρήστη MCP.
- Προεπισκόπηση συναλλαγών: Τοπικό MCP ή CLI, κατά προτίμηση πρώτα το δοκιμαστικό δίκτυο.
- Πραγματικές συναλλαγές: μόνο μετά από ρητή άδεια, προεπισκόπηση, επιβεβαίωση, όρια και αρχεία καταγραφής ελέγχου.
