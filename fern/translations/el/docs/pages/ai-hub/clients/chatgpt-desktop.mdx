> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Το ChatGPT Desktop είναι ένα οικείο σημείο εισόδου για χρήστες που θέλουν να κάνουν ερωτήσεις αγοράς σε φυσική γλώσσα.

Χρησιμοποιήστε αυτήν τη διαδρομή όταν ο χρήστης θέλει μια διεπαφή συνομιλίας για δεδομένα δημόσιας αγοράς, περιλήψεις λογαριασμών, επεξηγήσεις θέσης και πλαίσιο κανόνων συναλλαγών.

<h2 id="recommended-setup">Προτεινόμενη ρύθμιση</h2>

| Ανάγκη | Ρύθμιση |
| --- | --- |
| Στοιχεία δημόσιας αγοράς | Φιλοξενείται MCP |
| Περιβάλλον ιδιωτικού λογαριασμού | Τοπικό MCP |
| Επαναλαμβανόμενες αναλύσεις | Agentic Skills |
| Ροές εργασιών που βασίζονται σε τερματικό | 6MM CLI |

<h2 id="what-users-can-ask">Τι μπορούν να ρωτήσουν οι χρήστες</h2>

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<h2 id="safety-defaults">Προεπιλογές ασφαλείας</h2>

- Ξεκινήστε με δεδομένα δημόσιας αγοράς.
- Χρησιμοποιήστε το Τοπικό MCP όταν χρειάζονται διαπιστευτήρια λογαριασμού.
- Διατηρήστε ιδιωτικά κλειδιά API στο μηχάνημα του χρήστη.
- Απαιτείται προεπισκόπηση και ρητή επιβεβαίωση πριν από οποιαδήποτε μελλοντική ενέργεια συναλλαγών.
