> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Το Claude Desktop είναι κατάλληλο για έρευνα που βασίζεται σε MCP-, έλεγχο λογαριασμού και λειτουργική ανάλυση.

<h2 id="recommended-setup">Προτεινόμενη ρύθμιση</h2>

| Ανάγκη | Ρύθμιση |
| --- | --- |
| Έρευνα δημόσιας αγοράς | Φιλοξενείται MCP |
| Ανάλυση λογαριασμών | Τοπικό MCP |
| Εσωτερικό τελικό σημείο ομάδας | Τηλεχειριστήριο MCP |

<h2 id="example-prompts">Παραδείγματα προτροπών</h2>

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<h2 id="notes">Σημειώσεις</h2>

Το τοπικό MCP προτιμάται κάθε φορά που εμπλέκονται δεδομένα ιδιωτικού λογαριασμού, επειδή ο διακομιστής MCP εκτελείται στο μηχάνημα του χρήστη και τα διαπιστευτήρια δεν χρειάζεται να σταλούν σε τελικό σημείο AI που φιλοξενείται από 6MM.
