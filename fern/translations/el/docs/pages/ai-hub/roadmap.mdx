> **Σχεδιασμένο — δεν έχει ακόμη ξεκινήσει **
> Το AI Hub είναι μια προγραμματισμένη λειτουργία. Οι δυνατότητες, τα τελικά σημεία, οι εντολές και οι διαμορφώσεις πελάτη σε αυτήν τη σελίδα περιγράφουν την προτεινόμενη σχεδίαση και δεν είναι προς το παρόν διαθέσιμα. Η τελική διαθεσιμότητα και οι οδηγίες εγκατάστασης θα ανακοινωθούν κατά την κυκλοφορία.


Το AI Hub θα πρέπει να κυκλοφορεί σταδιακά, ώστε οι χρήστες να λαμβάνουν αξία νωρίς, ενώ οι ευαίσθητες δυνατότητες συναλλαγών παραμένουν προστατευμένες.

## Φάση 1: Πρόσβαση τεχνητής νοημοσύνης στη δημόσια αγορά

Στόχος: αφήστε οποιονδήποτε υποστηριζόμενο πελάτη τεχνητής νοημοσύνης να διαβάσει επίσημα δεδομένα αγοράς 6MM.

Παραδοτέα:

- Κοινόχρηστος πελάτης SDK / API.
- CLI εντολές δημόσιας αγοράς.
- Εργαλεία τοπικής MCP δημόσιας αγοράς.
- Φιλοξενούνται MCP εργαλεία δημόσιας αγοράς.
- Πόροι για αγορές, αμοιβές, κανόνες κινδύνου και κατάσταση συστήματος.
- Οδηγοί εγκατάστασης πελάτη.

Δεν περιλαμβάνονται:

- Ερωτήματα λογαριασμού.
- Πραγματικό εμπόριο.
- API κλειδί φιλοξενίας.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Φάση 2: Ανάγνωση λογαριασμού

Στόχος: να επιτρέπεται στους χρήστες να επιθεωρούν με ασφάλεια το περιβάλλον του λογαριασμού τους.

Παραδοτέα:

- Εύρος κλειδιού μόνο για ανάγνωση API.
- Περίληψη λογαριασμού.
- Υπόλοιπα.
- Θέσεις.
- Ανοιχτές παραγγελίες.
- γεμίζει.
- Πληρωμές χρηματοδότησης.
- Προτροπή κινδύνου χαρτοφυλακίου.

Προτιμώμενη ανάπτυξη:

- Τοπικό MCP.
- CLI.
- Απομακρυσμένη MCP αυτο-φιλοξενούμενη.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Φάση 3: Προεπισκόπηση συναλλαγών

Στόχος: αφήστε την τεχνητή νοημοσύνη να βοηθήσει στη δημιουργία παραγγελιών χωρίς να τις εκτελείτε.

Παραδοτέα:

- `preview_order`.
- Έλεγχοι κινδύνου.
- Επίπτωση περιθωρίου.
- Εκτίμηση αμοιβής.
- Επίπτωση εκκαθάρισης.
- Προτροπή προγραμματισμού εκτέλεσης.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Φάση 4: Ελεγχόμενες συναλλαγές

Στόχος: υποστήριξη πραγματικών συναλλαγών μόνο με ισχυρά προστατευτικά κιγκλιδώματα.

Παραδοτέα:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- ανικανότητα.
- ανώτατα πλασματικά όρια.
- ρητή επιβεβαίωση.
- αρχεία καταγραφής ελέγχου.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Φάση 5: Agentic Skills

Στόχος: παραγωγή κοινής ανάλυσης αγοράς και ροών εργασιών κινδύνου.

Παραδοτέα:

- Ικανότητα αναλυτή αγοράς.
- Ικανότητα κινδύνου χαρτοφυλακίου.
- Ερευνητική ικανότητα χρηματοδότησης.
- Ικανότητα προστασίας από εκκαθάριση.
- Ικανότητα σχεδιαστή εκτέλεσης.
- Παράδειγμα βιβλιοθήκης εργασιών.
