Αυτή η σελίδα παρέχει ενοποιημένες οδηγίες για τις προδιαγραφές χρήσης και τις μεθόδους λήψης των οπτικών στοιχείων 6MM Embedded Exchange, που ισχύουν για συνεργάτες που ενσωματώνουν 6MM δυνατότητες διαπραγμάτευσης αορίστου συμβολαίου μέσω SDK / API.

Αυτό το έγγραφο συνδυάζει προδιαγραφές στοιχείων (μεγέθη / μορφές / κανόνες χρήσης) και λήψεις στοιχείων (κατηγορίες / προεπισκοπήσεις / ZIP πακέτα), επιτρέποντας στους συνεργάτες να ολοκληρώσουν τα ακόλουθα σε μία μόνο σελίδα:

* Ελέγξτε τις προδιαγραφές
* Συγκρίνετε παραδείγματα
* Λήψη αντίστοιχων πακέτων περιουσιακών στοιχείων

Όλες οι προδιαγραφές έχουν σχεδιαστεί με βασικούς στόχους την ενσωματωμένη ενοποίηση, τη συμβατότητα μεταξύ πλατφορμών και τη μακροχρόνια συντήρηση.

<h2 id="2-entry-banners">2. Πανό εισόδου</h2>

Χρήση περιπτώσεων

* Banner αρχικής σελίδας εφαρμογής
* Πανό ηρώων αρχικής σελίδας Ιστού
* Περιοχές σύστασης ή καταχώρισης καμπάνιας

Προτεινόμενα μεγέθη (px)

| Μέγεθος       | Περιγραφή χρήσης              |
| ---------- | ------------------------------ |
| 750 × 300  | Κινητό / Πρότυπο H5           |
| 1125 × 450 | Κινητό υψηλής ανάλυσης         |
| 1200 × 480 | Πανό γενικής χρήσης         |
| 1440 × 480 | Κύρια οπτική ενότητα Web     |
| 1920 × 600 | Επιφάνεια εργασίας / οθόνη μεγάλης οθόνης |

Καθοδήγηση αναλογίας διαστάσεων

* Οριζόντια διάταξη
* Προτεινόμενες αναλογίες: 4:1, 5:2, 3:1

Κανόνες Χρήσης

* Διατηρήστε το κύριο περιεχόμενο στο κέντρο
* Κρατήστε ≥ 10% ασφαλές περιθώριο και στις δύο πλευρές
* Αποφύγετε την αντιγραφή μεταβλητού μήκους εντός του στοιχείου

<h2 id="3-card-module-entries">3. Καταχωρήσεις καρτών / ενοτήτων</h2>

Χρήση περιπτώσεων

* Κάρτες χαρακτηριστικών αρχικής σελίδας εφαρμογής
* Αρθρωτές λειτουργικές καταχωρήσεις Ιστού
* Μπλοκ λειτουργιών συναλλαγών εντός ροών περιεχομένου

Κοινές αναλογίες & προτεινόμενα μεγέθη (px)

| Τύπος            | Αναλογία | Προτεινόμενο μέγεθος | Περιγραφή χρήσης            |
| --------------- | ----- | ---------------- | ---------------------------- |
| Οριζόντια κάρτα | 16:9  | 640 × 360        | Τροφοδοσίες / περιοχές συστάσεων |
| Οριζόντια κάρτα | 16:9  | 1280 × 720       | Κάρτες web υψηλής ανάλυσης    |
| Οριζόντια κάρτα | 3:2   | 600 × 400        | Λειτουργικές μονάδες           |
| Κάθετη κάρτα   | 4:5   | 600 × 750        | Καταχωρήσεις βάσει λίστας           |
| Τετράγωνη κάρτα     | 1:1   | 512 × 512        | Διατάξεις πλέγματος                 |
| Τετράγωνη κάρτα     | 1:1   | 1024 × 1024      | Οθόνη υψηλής ανάλυσης      |

Κανόνες σχεδίασης

* Κεντράρετε την κύρια απεικόνιση
* Οι περιοχές κειμένου πρέπει να επιτρέπουν την περικοπή
* Διατηρήστε ≥ ασφαλές περιθώριο 8% από όλες τις πλευρές
* Μην βασίζεστε σε στρογγυλεμένες γωνίες ή εφέ σκιάς

Μορφές

* PNG

<h2 id="4-general-usage-rules">4. Γενικοί κανόνες χρήσης</h2>

* Προτιμήστε στοιχεία υψηλής ανάλυσης ή διανυσματικά στοιχεία
* Αποφύγετε την ενσωμάτωση σταθερής επιχειρηματικής λογικής ή αντιγράφου μάρκετινγκ στα στοιχεία
* Τα στοιχεία θα πρέπει να υποστηρίζουν περιβάλλοντα σκοτεινής λειτουργίας
* Τα περιουσιακά στοιχεία περιορίζονται σε σκοπούς εισόδου συναλλαγών και βοήθειας διεπαφής

***

<h2 id="5-versioning-and-maintenance">5. Έκδοση & Συντήρηση</h2>

* Τα μεγέθη και οι προδιαγραφές των περιουσιακών στοιχείων ενδέχεται να ενημερώνονται παράλληλα με τις αναβαθμίσεις προϊόντων
* Συνιστάται στους συνεργάτες να χρησιμοποιούν τα πιο πρόσφατα πακέτα περιουσιακών στοιχείων
* Οι παλαιότερες εκδόσεις στοιχείων δεν συνιστώνται για νέες ενσωματώσεις

Για ειδικές απαιτήσεις σχετικά με τις προδιαγραφές στοιχείων ή τις λήψεις, επικοινωνήστε με την επίσημη τεχνική ή επιχειρηματική 6MM υποστήριξη.
