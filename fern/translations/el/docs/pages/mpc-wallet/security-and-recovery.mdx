Η προετοιμασία για την ασφάλεια ξεκινά με την επιλεγμένη ρύθμιση φύλαξης. Η προστασία λογαριασμού, η έγκριση συναλλαγής, η συμμετοχή και το υλικό ανάκτησης MPC εξυπηρετούν διαφορετικούς σκοπούς.

<span id="assign-responsibilities" data-sixmm-canonical-anchor="assign-responsibilities" aria-hidden="true"></span>

## Αναθέστε ευθύνες

Ξεχωριστή προβολή ρουτίνας, έναρξη μεταφοράς, έγκριση, διαχείριση μέλους και διαχείριση διαπιστευτηρίων προγραμματιστή όπου το επιτρέπει το προϊόν. Ελέγξτε τα δικαιώματα στον προβλεπόμενο χώρο εργασίας. Η πρόσβαση σε έναν χώρο εργασίας δεν δημιουργεί εξουσία σε έναν άλλο.

Για τις εταιρικές ροές εργασιών, συμφωνήστε ποιος εξετάζει τις αλλαγές προορισμού και τα εξερχόμενα αιτήματα. Για την υπογραφή συσκευής, ο συμμετέχων θα πρέπει να επιθεωρήσει το εμφανιζόμενο δίκτυο, το περιουσιακό στοιχείο, το ποσό, τον προορισμό και το πλαίσιο πριν από την αποδοχή. Η επιβεβαίωση συσκευής δεν θα πρέπει να αντιμετωπίζεται ως τυφλή προτροπή έγκρισης.

## Διατηρήστε τα διαπιστευτήρια διακριτά

| Υλικό | Σκοπός |
| --- | --- |
| Έλεγχος ταυτότητας λογαριασμού | Πρόσβαση στην εφαρμογή χρήστη |
| API κλειδί και μυστικό | Έλεγχος ταυτότητας αιτημάτων υποστήριξης API |
| Κλειδί εξουσιοδότησης πελάτη | Εξουσιοδοτήστε τα περιεχόμενα μιας ανάληψης API όπου απαιτείται |
| MPC μερίδιο κλειδιού | Συμμετέχετε στη διαδικασία κατανεμημένης υπογραφής του πορτοφολιού |
| Εφεδρικό υλικό και ανάκτηση υλικού | Επαναφέρετε τη συμμετοχή ή εκτελέστε την υποστηριζόμενη διαδικασία ανάκτησης |

Αποθηκεύστε τα σύμφωνα με τις δικές τους ευθύνες. Ένα κλειδί API δεν είναι κοινόχρηστο στοιχείο MPC. Η επαναφορά ενός κωδικού πρόσβασης λογαριασμού δεν είναι μια λειτουργία ανάκτησης πορτοφολιού. Μεταφορτώστε τα δημόσια κλειδιά μόνο μέσω της σχετικής ροής εγγραφής και ποτέ των αντίστοιχων ιδιωτικών κλειδιών τους.

## Προετοιμάστε την ανάκτηση πριν από τη χρήση

Καταγράψτε τους απαιτούμενους συμμετέχοντες, τους κατόχους αντιγράφων ασφαλείας και τα βήματα ανάκτησης κατά την ενσωμάτωση. Διατηρήστε αντίγραφα ασφαλείας σε ξεχωριστές κατάλληλες θέσεις και δοκιμάστε την υποστηριζόμενη διαδικασία ανάκτησης σε ελεγχόμενο περιβάλλον. Σκεφτείτε τόσο μια χαμένη συσκευή όσο και μια διακοπή της υπηρεσίας πλατφόρμας.

Η αυτοεπιμέλεια δεν επιτρέπει στην πλατφόρμα να δημιουργήσει εκ νέου μερίδια πελατών που λείπουν. Εάν απομένουν πολύ λίγοι χρησιμοποιήσιμοι συμμετέχοντες και αντίγραφα ασφαλείας για την ικανοποίηση των απαιτήσεων του πορτοφολιού, ενδέχεται να χαθεί η πρόσβαση στα στοιχεία. Η κοινή φύλαξη κλειδιών χρειάζεται επίσης μια τεκμηριωμένη συμφωνία ανάκτησης. μην υποθέσετε ότι η συμμετοχή στην πλατφόρμα εγγυάται την ανάκτηση.

## Χειριστείτε έναν μη διαθέσιμο συμμετέχοντα

Πρώτα διακρίνετε ένα προσωρινό πρόβλημα σύνδεσης, μια μη διαθέσιμη συσκευή και χαμένο υλικό υπογραφής. Ελέγξτε την κατάσταση της περιόδου λειτουργίας και της συσκευής και, στη συνέχεια, χρησιμοποιήστε την υποστηριζόμενη διαδικασία ανάκτησης ή αντικατάστασης. Μην διαγράψετε μια συσκευή, μην αλλάξετε την ταυτότητα υπογραφής της εφαρμογής της και μην υποθέσετε ότι τα κοινόχρηστα στοιχεία μπορούν να μετακινηθούν πριν ελέγξετε τις απαιτήσεις ανάκτησης.

Η διαθεσιμότητα αντιγράφων ασφαλείας δεν αποτελεί απόδειξη ολοκληρωμένης δοκιμής ανάκτησης. Επιβεβαιώστε ποιες διαδικασίες και εργαλεία περιλαμβάνονται στην κυκλοφορία σας προτού βασιστείτε σε αυτά.
