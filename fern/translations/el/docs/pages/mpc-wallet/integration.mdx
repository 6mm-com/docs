Οι οδηγοί προγραμματιστών περιγράφουν την τρέχουσα επιφάνεια ενοποίησης εταιρικού πορτοφολιού. MPC Το πορτοφόλι δεν έχει κυκλοφορήσει: τα παραδείγματα τελικού σημείου είναι αναφορές υλοποίησης, όχι υπόσχεση μιας δημόσιας διαθέσιμης υπηρεσίας ή παγωμένης σύμβασης API.

<span id="obtain-integration-information" data-sixmm-canonical-anchor="obtain-integration-information" aria-hidden="true"></span>

## Λάβετε πληροφορίες ολοκλήρωσης

Επιβεβαιώστε τη βάση δοκιμής URL, την έκδοση API, την ταυτότητα χώρου εργασίας, το μοντέλο φύλαξης, τα ενεργοποιημένα δίκτυα και τα στοιχεία, τα δικαιώματα API, τις απαιτήσεις εξουσιοδότησης πελάτη και τη ρύθμιση webhook. Τα αναγνωριστικά δικτύου και στοιχείων προέρχονται από το συμφωνημένο περιβάλλον. μην υποθέσετε ότι είναι ίσα με αναγνωριστικά δημόσιας αλυσίδας.

Διατηρήστε τα διαπιστευτήρια ενοποίησης πορτοφολιού χωριστά από τα διαπιστευτήρια συναλλαγών API. Ένας κοινόχρηστος ιστότοπος τεκμηρίωσης δεν κάνει τις υπηρεσίες ή τα μοντέλα λογαριασμών εναλλάξιμα.

<span id="connect-the-business-flow" data-sixmm-canonical-anchor="connect-the-business-flow" aria-hidden="true"></span>

## Συνδέστε την επιχειρηματική ροή

1. Δημιουργήστε ένα κλειδί ελάχιστων προνομίων API για τον προβλεπόμενο εταιρικό χώρο εργασίας και κρατήστε το μυστικό του στο backend σας.
2. Επικυρώστε ένα υπογεγραμμένο αίτημα μόνο για ανάγνωση και χειρισμό σφαλμάτων πριν από την εισαγωγή μεταφορών.
3. Εκχωρήστε μια διεύθυνση παραλαβής για ένα σταθερό αναγνωριστικό επαγγελματικού χρήστη και, στη συνέχεια, επαληθεύστε τη διεύθυνση που επιστράφηκε και οποιοδήποτε σημείωμα.
4. Λάβετε συμβάντα κατάθεσης και συμφιλιώστε τα με API ερωτήματα και τα δικά σας αρχεία.
5. Προσθέστε εξουσιοδότηση ανάληψης, σταθερά αναγνωριστικά επιχειρηματικών αιτημάτων και παρακολούθηση αποτελεσμάτων.

<span id="core-api-areas" data-sixmm-canonical-anchor="core-api-areas" aria-hidden="true"></span>

## Βασικές περιοχές API

| Εκταση | Παραδείγματα τρέχουσας διαδρομής | Σκοπός |
| --- | --- | --- |
| Λήψη διευθύνσεων | `POST /api/v1/addresses`, `GET /api/v1/addresses` | Κατανομή και αναζήτηση διευθύνσεων |
| Καταθέσεις | `GET /api/v1/deposits`, `GET /api/v1/deposits/{id}` | Ακολουθήστε τις εισερχόμενες μεταφορές |
| Αναλήψεις | `POST /api/v1/withdrawals`, `GET /api/v1/withdrawals/{id}` | Υποβάλετε ένα αίτημα και ρωτήστε το αποτέλεσμα του |
| Ζητήστε αναζήτηση | `GET /api/v1/withdrawals/by-request` | Συμφιλιώστε ένα αίτημα μετά από μια αβέβαιη απάντηση |
| Υπόλοιπα | `GET /api/v1/balances` | Ζητήστε επιχειρηματικά υπόλοιπα στο εξουσιοδοτημένο πεδίο |

Η εγγραφή διαδρομής δεν σημαίνει ότι κάθε πλήκτρο API μπορεί να καλέσει κάθε λειτουργία. Η πρόσβαση στο προϊόν, τα δικαιώματα χώρου εργασίας, η λειτουργία φύλαξης και η προετοιμασία μπορούν όλα να επηρεάσουν τη διαθεσιμότητα. Οι διοικητικές και προσωπικές διεπαφές συσκευών βρίσκονται εκτός αυτής της ροής γρήγορης εκκίνησης της επιχείρησης.

## Επαληθεύστε τις διευθύνσεις λήψης

Η παρεχόμενη εφαρμογή SDK υποστηρίζει υπογεγραμμένες βεβαιώσεις διευθύνσεων. Διαμορφώστε τα αξιόπιστα μέλη ή το υλικό αξιοπιστίας που καθορίζεται από το πακέτο ενοποίησης και παρέχετε ανεξάρτητα τον αναμενόμενο χώρο εργασίας, την αλυσίδα και τις πληροφορίες ομάδας κλειδιών όπου απαιτείται. Μην αντλείτε κάθε προσδοκία εμπιστοσύνης από την ίδια απάντηση που ελέγχετε.

Για τις πλήρως διαχειριζόμενες διευθύνσεις συγκέντρωσης, μια βεβαίωση μπορεί να προσδιορίσει μια διεύθυνση που ανήκει στην πλατφόρμα, ενώ η ανάθεσή της σε έναν πελάτη παραμένει δήλωση από την πλευρά του διακομιστή. Μην περιγράφετε αυτήν την εκχώρηση ως κρυπτογραφική απόδειξη ιδιοκτησίας πελάτη.

Συνεχίστε με [αίτηση υπογραφής](/el/mpc-wallet/request-signing), [συναλλαγές](/el/mpc-wallet/transactions) και [webhooks και SDKs](/el/mpc-wallet/webhooks-and-sdks).
