Webhooks ειδοποιήστε το backend σας για επαγγελματικές εκδηλώσεις. Χρησιμοποιήστε τα μαζί με API ερωτήματα, έτσι ώστε η καθυστέρηση ή η έλλειψη παράδοσης να μην αφήνει άλυτα τα αρχεία σας.

## Επαληθεύστε πριν από την επεξεργασία

Η τρέχουσα παράδοση περιλαμβάνει `X-Webhook-Signature` και `X-Webhook-Timestamp`. Η υπογραφή χρησιμοποιεί HMAC-SHA256 πάνω από το κείμενο της κεφαλίδας της χρονικής σφραγίδας, μια κουκκίδα και το ακριβές σώμα του πρωτογενούς αιτήματος. Η τιμή της κεφαλίδας του έχει τη μορφή `sha256=<HEX_SIGNATURE>`.

1. Διατηρήστε το ακατέργαστο σώμα πριν από την ανάλυση JSON.
2. Επικυρώστε τη χρονική σήμανση χρησιμοποιώντας τη συμφωνημένη ανοχή ρολογιού.
3. Επαληθεύστε την υπογραφή με το μυστικό webhook χρησιμοποιώντας μια σύγκριση σταθερού χρόνου.
4. Μόνο τότε ερμηνεύστε το ωφέλιμο φορτίο και ενημερώστε τα επιχειρηματικά αρχεία.

Η αναδιαμόρφωση του JSON πριν από την επαλήθευση αλλάζει τα υπογεγραμμένα byte. Η επαλήθευση Webhook χρησιμοποιεί το μυστικό webhook, όχι το μυστικό αίτημα API ή το κλειδί εξουσιοδότησης πελάτη.

## Αποθηκεύστε και αφαιρέστε τα αντίγραφα

Ο φάκελος περιλαμβάνει `event_id`, `event_type`, `created_at`, `tenant_id` και `data`. Για κανονικές παραδόσεις συμβάντων, χρησιμοποιήστε την επαληθευμένη ταυτότητα συμβάντος με το τελικό σημείο ή το περιβάλλον εργασίας σας για να αποτρέψετε την επαναλαμβανόμενη εφαρμογή. Επιμείνετε σε αυτήν την απόφαση ατομικά με την επιχειρηματική ενημέρωση που προκύπτει ή βάλτε στην ουρά το επαληθευμένο συμβάν προτού το αναγνωρίσετε.

Το `X-Webhook-Idempotency-Key` παρέχεται επίσης για κανονικές παραδόσεις εξερχόμενων. Είναι μεταδεδομένα παράδοσης, όχι ένα ανεξάρτητο υπογεγραμμένο πεδίο ωφέλιμου φορτίου. Μην αφήσετε μια αλλαγμένη κεφαλίδα να προκαλέσει το ίδιο επαληθευμένο συμβάν να μετακινήσει χρήματα δύο φορές. Οι δοκιμαστικές παραδόσεις και οι μη αυτόματες λειτουργίες μπορεί να έχουν διαφορετικά αναγνωριστικά ή να παραλείψουν αυτήν την κεφαλίδα.

Επιστρέψτε μια επιτυχημένη απάντηση αφού αποδεχτείτε το συμβάν μόνιμα. Σχεδιασμός για διπλότυπα και καθυστερημένα ή εκτός σειράς συμβάντα. Η χρονική σήμανση παράδοσης δεν είναι εγγυημένος χρόνος επαγγελματικής εμφάνισης. Αναζητήστε τον υποκείμενο πόρο όταν ένα συμβάν έρχεται σε διένεξη με ένα μεταγενέστερο γνωστό αποτέλεσμα.

## Επιλέξτε το πακέτο ενσωμάτωσης

| Οικογένεια πακέτων | Τρέχον πεδίο εφαρμογής |
| --- | --- |
| Go and Python API SDKs | Διεύθυνση, πόροι κατάθεσης και ανάληψης, υπογραφή αιτήματος και σχετικοί βοηθοί |
| Βοηθοί Go, Node.js και Python webhook | Webhook βοηθοί επαλήθευσης υπογραφής και ενοποίησης πλαισίου |

Αυτά είναι πεδία εφαρμογής πηγής, όχι επιβεβαίωση διαθεσιμότητας μητρώου πακέτων ή γενική έκδοση. Λάβετε ένα πακέτο που ταιριάζει με την έκδοση και τις οδηγίες εγκατάστασής του κατά την επιβίβαση. Άλλοι πόροι ενδέχεται να απαιτούν άμεσες κλήσεις API. μην συνάγετε έναν πλήρη πελάτη API από την παρουσία ενός πακέτου webhook.

## Δοκιμάστε τη διαδρομή λήψης

Δοκιμάστε μια έγκυρη παράδοση, τροποποιημένο σώμα, μη έγκυρη υπογραφή, παλαιωμένη χρονική σήμανση, διπλό συμβάν και επανεκκίνηση του δέκτη. Επιβεβαιώστε τις ρυθμίσεις επανάληψης και αναπαραγωγής με το περιβάλλον ενσωμάτωσης. Οι επανακλήσεις που λείπουν θα πρέπει να ενεργοποιούν τη συμφωνία και όχι ένα δεύτερο αίτημα ανάληψης.
