## Εγκαθιστώ

Η δημόσια πηγή SDK τεκμηριώνει επί του παρόντος την ετικέτα `v0.1.1` με αυτές τις συντεταγμένες Maven:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

Το GitHub δεν λειτουργεί ως αποθετήριο εξαρτήσεων Maven. Εγκαταστήστε την πηγή με ετικέτα τοπικά πριν επιλύσετε την εξάρτηση:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Κατασκευές ομάδας**
>
> Δημοσιεύστε το εγκεκριμένο τεχνούργημα στο αποθετήριο Maven του οργανισμού σας για δομές CI, δοκιμών και παραγωγής. Επιβεβαιώστε την εγκεκριμένη έκδοση με 6MM πριν από την ανάπτυξη της παραγωγής.

Ο πηγαίος κώδικας και τα παραδείγματα χρήσης είναι διαθέσιμα στο επίσημο αποθετήριο Java SDK :

[6mm-com/agent-java-sdk](https://github.com/6mm-com/agent-java-sdk)

## Πριν ξεκινήσετε

- Επιβεβαιώστε τον αντιπρόσωπο παραγωγής σας API URL βάσης με την ομάδα 6MM .
- Αποθηκεύστε apiSecret μόνο στη μυστική διαχείριση backend.
- Προετοιμάστε μια σταθερή αντιστοίχιση μεταξύ platformUserId και agentUserId.
- Ενεργοποιήστε τα δομημένα αρχεία καταγραφής γύρω από τις ροές δέσμευσης, μεταφοράς, παραγγελίας και webhook .

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Προετοιμασία προγράμματος-πελάτη

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Μόνο backend**
>
> Μην αρχικοποιείτε το Agent SDK από τον κώδικα προγράμματος-πελάτη του προγράμματος περιήγησης, του κινητού ή του επιτραπέζιου υπολογιστή. Το SDK υπογράφει προνομιακά αιτήματα API Agent.

## Παράδειγμα: μεταφορά χρημάτων σε

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Χρησιμοποιήστε έναν μοναδικό αριθμό παραγγελίας από την πλευρά του συνεργάτη για κάθε αίτημα μεταφοράς. Εάν λήξει το χρονικό όριο ενός αιτήματος, υποβάλετε ερώτημα στην αρχική παραγγελία πριν δημιουργήσετε μια νέα.
