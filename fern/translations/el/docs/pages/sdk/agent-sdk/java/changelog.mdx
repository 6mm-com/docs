Αυτός ο οδηγός στοχεύει **Agent Java SDK `v0.3.0`**, Java 8+ και τη δημόσια σύμβαση με ετικέτα. Τα παραδείγματα εκτελούνται σε ένα backend συνεργάτη μετά την προετοιμασία του `client` στο [Γρήγορη εκκίνηση](/el/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Έξι διαρκή ερωτήματα: τρέχουσες παραγγελίες, ιστορικό παραγγελιών, πληρώσεις, τρέχουσες θέσεις, ιστορικό θέσεων και καθολικό λογαριασμού.
- Υπόλοιπα χρηματοδότησης, μεταφορές, ερωτήματα ανάκτησης και μεταφορές χρηματοδότησης/συμβολαίου.
- Ρητή παραγωγή/προσομοιωμένη επιλογή για αιτήματα υποστηριζόμενων κεφαλαίων.
- Οδηγοί ανακατεύθυνσης και ενσωμάτωσης δευτερολέπτων συναλλαγών, αναφορά πεδίου απόκρισης και οδηγίες μετεγκατάστασης.

Java SDK και Trading Widget SDK έχουν ανεξάρτητες εκδόσεις. Το γραφικό στοιχείο `v1` URL δεν είναι Java SDK έκδοση `0.3.0`.

## Υπάρχουσες ενσωματώσεις

Διατηρήστε τις αντιστοιχίσεις χρηστών, τις αρχικές παραγγελίες και τα διαπιστευτήρια. Τα παραλειπόμενα πεδία περιβάλλοντος διατηρούν την υπάρχουσα παραγωγική συμπεριφορά. Η χρηματοδότηση, τα ρητά προσομοιωμένα κεφάλαια και τα έξι διαρκή ερωτήματα απαιτούν τα αντίστοιχα νέα μοντέλα και μεθόδους. Κριτική [Οδηγός αναβάθμισης](/el/sdk/agent-sdk/java/upgrade) πριν αλλάξετε μια υπάρχουσα ενοποίηση.
