Αυτός ο οδηγός στοχεύει **Agent Java SDK `v0.3.0`**, Java 8+ και τη δημόσια σύμβαση με ετικέτα. Τα παραδείγματα εκτελούνται σε ένα backend συνεργάτη μετά την προετοιμασία του `client` στο [Γρήγορη εκκίνηση](/el/sdk/agent-sdk/java/quick-start).

## Έκδοση και εγκατάσταση

| Είδος | Αξία |
| --- | --- |
| Σταθερή ετικέτα πηγής | `v0.3.0` |
| Java | Java 8+ |
| Maven | Maven 3,9+ |
| Συντεταγμένες | `com.sixmm.exchange.sdk:agent:0.3.0` |

Πηγή φιλοξενίας GitHub. δεν καθιστά αυτές τις συντεταγμένες επιλύσιμες από το Maven Central. Χρησιμοποιήστε την τοπική εγκατάσταση με ετικέτα ή τον εγκεκριμένο χώρο αποθήκευσης τεχνουργημάτων.

## Τι καλύπτει το SDK

| Κατηγορία | Σενάριο | SDK API | Περιγραφή |
| --- | --- | --- | --- |
| Δέσμευση χρήστη | Σύνδεση χρήστη | `bind` | Δημιουργήστε ή ανακτήστε τη σύνδεση μεταξύ ενός χρήστη συνεργάτη και ενός χρήστη πλατφόρμας 6MM |
| Ερωτήματα περιουσιακών στοιχείων | Ερώτημα λογαριασμού συνεργάτη | `queryAccount` | Ζητήστε ερώτημα για το περιθώριο ή τον λογαριασμό χρηματοδότησης συνεργάτη |
| Ερωτήματα περιουσιακών στοιχείων | Ερώτημα περιουσιακών στοιχείων χρήστη | `queryUserAssets` | Ερώτημα περιουσιακών στοιχείων συμβολαίου. χρησιμοποιήστε το `withFunding()` για να συμπεριλάβετε τα υπόλοιπα χρηματοδότησης |
| Μεταγραφές | Μεταφορά σταθερού ποσού | `transfer` | Μεταφορά χρημάτων προς ή από 6MM |
| Μεταγραφές | Μεταφέρετε όλα έξω | `transferAllOut` | Μεταφέρετε όλο το υπόλοιπο χρήστη που μπορεί να αναληφθεί πίσω στην πλατφόρμα συνεργατών |
| Μεταγραφές | Αντίστροφη σειρά | `reverse` | Αντιστρέψτε μια επιτυχημένη μεταφορά όταν το backend υποστηρίζει μια ροή αντιστάθμισης |
| Μεταγραφές | Σειρά ερωτήματος | `queryOrder` | Ζητήστε μια εντολή μεταφοράς ανά αριθμό παραγγελίας συνεργάτη |
| Μεταγραφές | Λίστα παραγγελιών | `listOrders` | Σελίδα μέσω εντολών μεταφοράς για συμφωνία |
| Μεταγραφές | Webhook επαλήθευση | `WebhookVerifier.verify` | Επαλήθευση μεταφοράς επανακλήσεων τελικής κατάστασης από 6MM |
| Πορτοφόλι χρηματοδότησης | Μεταφορά χρηματοδότησης | `walletTransfer` | Συνεργάτης ↔ Χρηματοδότηση ή Χρηματοδότηση ↔ Σύμβαση. επιβεβαιώστε την κατάσταση επιστροφής |
| Πορτοφόλι χρηματοδότησης | Κατάσταση μεταφοράς χρηματοδότησης | `queryWalletTransfer` | Ανακτήστε μια λειτουργία χρηματοδότησης χρησιμοποιώντας τον αρχικό αριθμό παραγγελίας συνεργάτη |
| Είσοδος συναλλαγών | Απευθείας είσοδος URL | `createEntryUrl` | Δημιουργήστε μια εφάπαξ SSO URL για λειτουργία ανακατεύθυνσης |
| Είσοδος συναλλαγών | Ενσωμάτωση διακριτικού | `createEmbedToken` | Δημιουργήστε ένα διακριτικό μικρής διάρκειας για τη λειτουργία Trading Widget `tokenProvider` |
| Αιώνια δεδομένα | Τρέχουσες αέναες εντολές | `listCurrentPerpetualOrders` | Ερώτημα τρέχουσες παραγγελίες NORMAL ή CONDITIONAL |
| Αιώνια δεδομένα | Ιστορικό διαρκούς παραγγελίας | `listPerpetualOrderHistory` | Ερώτημα τερματικού NORMAL ή CONDITIONAL παραγγελίες |
| Αιώνια δεδομένα | Αιώνιες συναλλαγές | `listPerpetualTrades` | Το εμπόριο ερωτημάτων συμπληρώνει μια ρητή δημόσια λίστα παικτών |
| Αιώνια δεδομένα | Τρέχουσες αέναες θέσεις | `listCurrentPerpetualPositions` | Ζητήστε τις τρέχουσες θέσεις |
| Αιώνια δεδομένα | Ιστορικό διαρκούς θέσης | `listPerpetualPositionHistory` | Ζητήστε κλειστές θέσεις |
| Αιώνια δεδομένα | Διαρκές βιβλίο λογαριασμού | `listPerpetualLedger` | Ερώτηση μεμονωμένων αρχείων υπολοίπου συμβολαίου-αλλαγής |
| Τιμές αναφοράς Fiat | Κατάλογος υποστηριζόμενων νομισμάτων fiat | `listSupportedFiatCurrencies` | Καταχωρίστε τα νομίσματα fiat που είναι επί του παρόντος μετατρέψιμα σε USDT |
| Τιμές αναφοράς Fiat | Ζητήστε τιμές αναφοράς FX | `queryExchangeRates` | Ζητήστε ημερήσιες αναλογίες αναφοράς fiat-to-USDT για όλα ή επιλεγμένα νομίσματα |
| Πληροφορίες σέρβις | Έκδοση υπηρεσίας | `version` | Πληροφορίες έκδοσης υπηρεσίας Query Agent |

## Διαμόρφωση

Λάβετε τις ακόλουθες τιμές από το 6MM πριν
ενσωμάτωση.

| Είδος | Παράδειγμα | Περιγραφή |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Πράκτορας API βάση URL, χωρίς τελική κάθετο |
| `agentCode` | `AGENT001` | Κωδικός συνεργάτη |
| `apiSecret` | `your-api-secret` | API μυστικό υπογραφής. Διατηρήστε το μόνο στο backend |
| `defaultCurrency` | `USDT` | Προεπιλεγμένο νόμισμα, συνήθως `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Τελικό σημείο συνεργάτη για 6MM επανακλήσεις |

Συστάσεις παραγωγής:

- Χρησιμοποιήστε το HTTPS για τα τελικά σημεία Agent API και webhook.
- Αποθηκεύστε το `apiSecret` σε έναν μυστικό διαχειριστή, κέντρο διαμόρφωσης ή μεταβλητή περιβάλλοντος.
- Διατηρήστε το χρόνο του διακομιστή συγχρονισμένο, κατά προτίμηση με NTP.
- Διατηρήστε όλους τους αριθμούς παραγγελιών συνεργατών και διατηρήστε τους μοναδικούς παγκοσμίως.
- Μην στέλνετε ποτέ `apiSecret` σε προγράμματα περιήγησης, εφαρμογές, μίνι προγράμματα ή πηγαίο κώδικα διεπαφής.

## Πεδία αυτόματης υπογραφής

Για υπογεγραμμένες κλήσεις αντιπροσώπου API, το SDK εγχέει αυτόματα:

| Πεδίο | Πηγή | Περιγραφή |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Κωδικός συνεργάτη |
| `timestamp` | Τρέχουσα χρονική σήμανση UTC Unix | Δευτερόλεπτα |
| `nonce` | Ασφαλής τυχαία γεννήτρια | Προστασία επανάληψης |
| `sign` | HMAC-SHA256 | Υπογραφή αιτήματος |
| `currency` | `defaultCurrency` | Συμπληρώνεται όταν τα αιτήματα μεταφοράς/λογαριασμού παραλείπουν το νόμισμα |

Κανόνες υπογραφής:

1. Εξαίρεση `sign`.
2. Εξαίρεση κενών τιμών.
3. Ταξινόμηση πλήκτρων κατά σειρά ASCII.
4. Εγγραφείτε ως `k=v&k2=v2`.
5. Υπολογίστε το HMAC-SHA256 εξάγωνο με `apiSecret`.

Ο κανονικός επιχειρηματικός κωδικός δεν πρέπει να υπολογίζει υπογραφές ή να ορίζεται χειροκίνητα
`agentCode`, `timestamp`, `nonce` ή `sign`.
