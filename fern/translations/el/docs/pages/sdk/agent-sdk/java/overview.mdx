<h2 id="official-repository">Επίσημο αποθετήριο</h2>

Το αποθετήριο Java SDK είναι η πηγή αλήθειας για SDK πηγαίο κώδικα, τις σημειώσεις έκδοσης, τα παραδείγματα χρήσης και τις λεπτομέρειες υλοποίησης:

[6mm-com/agent-java-sdk](https://github.com/6mm-com/agent-java-sdk)

<h2 id="runtime">Χρόνος εκτέλεσης</h2>

| Είδος | Αξία |
| --- | --- |
| Ελάχιστη έκδοση Java | Java 8+ |
| Προτεινόμενο εργαλείο κατασκευής | Maven 3.9+ |
| Ομάδα Maven | `com.sixmm.exchange.sdk` |
| Τεχνούργημα Maven | `agent` |
| Τεκμηριωμένη ετικέτα πηγής | `v0.1.1` |

Το δημόσιο αποθετήριο GitHub είναι φιλοξενία πηγαίου κώδικα και όχι αποθετήριο εξάρτησης Maven. Δημιουργήστε και εγκαταστήστε την προέλευση με ετικέτα τοπικά ή δημοσιεύστε το εγκεκριμένο τεχνούργημα στο ιδιωτικό αποθετήριο Maven του οργανισμού σας πριν το χρησιμοποιήσετε σε δομές ομάδας.

<h2 id="typical-backend-responsibilities">Τυπικές ευθύνες backend</h2>

- Επικυρώστε την περίοδο λειτουργίας χρήστη-συνεργάτη.
- Αντιστοιχίστε τον χρήστη-συνεργάτη στο agentUserId.
- Δέσμευση κλήσεων πριν από τις πρώτες ροές συναλλαγών ή μεταφοράς.
- Καλέστε createEntryUrl για εφάπαξ SSOπλήρους τοποθεσίας .
- Καλέστε createEmbedToken για Trading Widget λειτουργία partner-token.
- Επαληθεύστε webhooks μεταφοράς και επεξεργαστείτε τα ανίκανα.

<h2 id="security-and-operational-rules">Κανόνες ασφάλειας και λειτουργίας</h2>

- Αποθηκεύστε `apiSecret` μόνο σε μια μεταβλητή μυστικού διαχειριστή υποστήριξης ή προστατευμένου περιβάλλοντος.
- Διατηρήστε συγχρονισμένη την ώρα διακομιστή, επειδή οι υπογεγραμμένες αιτήσεις περιέχουν χρονικές σημάνσεις.
- Αντιμετωπίστε `agentOrderNo` ως ένα ανθεκτικό κλειδί ανικανότητας και διατηρήστε το παγκοσμίως μοναδικό.
- Αποθηκεύστε το `platformUserId` ως συμβολοσειρά και διατηρήστε τη σχέση του με `agentUserId`.
- Υποβάλετε ερώτημα για την αρχική μεταφορά πριν προσπαθήσετε ξανά μετά από λήξη χρονικού ορίου ή αβέβαιο αποτέλεσμα δικτύου.
