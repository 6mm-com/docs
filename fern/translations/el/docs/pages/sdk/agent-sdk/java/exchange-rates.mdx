Αυτός ο οδηγός στοχεύει **Agent Java SDK `v0.3.0`**, Java 8+ και τη δημόσια σύμβαση με ετικέτα. Τα παραδείγματα εκτελούνται σε ένα backend συνεργάτη μετά την προετοιμασία του `client` στο [Γρήγορη εκκίνηση](/el/sdk/agent-sdk/java/quick-start).

## Παράδειγμα προαπαιτούμενα

Τα αποσπάσματα Java μοιράζονται αυτές τις εισαγωγές. Αρχικοποιήστε το `client` χρησιμοποιώντας Γρήγορη εκκίνηση και αποκτήστε `platformUserId` από την αποθηκευμένη δέσμευση. Παραδείγματα αναγνωριστικών χρήστη/παραγγελιών πρέπει να αντικατασταθούν με τις δικές σας σταθερές τιμές.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Τιμές αναφοράς FX

Και οι δύο μέθοδοι FX χρησιμοποιούν την κανονική υπογεγραμμένη ροή Agent API. Ξεκινήστε ανακαλύπτοντας το
επί του παρόντος υποστηριζόμενα νομίσματα πηγής:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Ερώτημα όλων των υποστηριζόμενων ποσοστών αναφοράς fiat-to-USDT:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Ερώτημα για επιλεγμένα νομίσματα:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

Το εργοστασιακό αίτημα περικόπτει και κεφαλαία τους κωδικούς νομισμάτων και τους σειριοποιεί ως
την τιμή `sourceCurrencies` διαχωρισμένη με κόμματα που απαιτείται από το API. Παραλείποντας το
αίτημα ή όλες οι πραγματικές τιμές νομισμάτων ερωτά κάθε υποστηριζόμενο νόμισμα.

| Πεδίο απόκρισης | Τύπος | Περιγραφή |
| --- | --- | --- |
| `snapshotVersion` | string | Σταθερή έκδοση στιγμιότυπου για έλεγχο και συμφωνία |
| `provider` | string | Πάροχος ανάντη, επί του παρόντος `ECB` |
| `sourceDate` | string | Ημερομηνία παρατήρησης ανάντη σε μορφή `yyyy-MM-dd` |
| `fetchedAt` / `expiresAt` | int64 | Χρονικές σημάνσεις Unix σε χιλιοστά του δευτερολέπτου |
| `pricingPolicy` | string | Επί του παρόντος `FIXED_PEG` |
| `usdtUsdRate` | string | USD ποσό ανά 1 USDT, επί του παρόντος σταθερό σε `1` |
| `rateType` | string | Επί του παρόντος `INDICATIVE_DAILY` |
| `usage` | string | Επί του παρόντος `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT ποσό που αντιστοιχεί σε μία μονάδα τροφοδοσίας πηγής |

Αυτές οι τιμές είναι αναφορές για υπολογισμό ενός πορτοφολιού πολλαπλών νομισμάτων συνεργάτη
το USDT ποσό στάλθηκε στο 6MM. Δεν είναι εκτελέσιμες τιμές, κλειδωμένες τιμές ή
σε πραγματικό χρόνο USDT τιμές αγοράς. Χρησιμοποιήστε `BigDecimal` και συμβολοσειρές για το ποσό
υπολογισμοί? μην χρησιμοποιείτε `double` ή `float`.
