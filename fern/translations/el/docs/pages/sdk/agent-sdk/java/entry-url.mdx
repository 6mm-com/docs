Αυτός ο οδηγός στοχεύει **Agent Java SDK `v0.3.0`**, Java 8+ και τη δημόσια σύμβαση με ετικέτα. Τα παραδείγματα εκτελούνται σε ένα backend συνεργάτη μετά την προετοιμασία του `client` στο [Γρήγορη εκκίνηση](/el/sdk/agent-sdk/java/quick-start).

## Παράδειγμα προαπαιτούμενα

Τα αποσπάσματα Java μοιράζονται αυτές τις εισαγωγές. Αρχικοποιήστε το `client` χρησιμοποιώντας Γρήγορη εκκίνηση και αποκτήστε `platformUserId` από την αποθηκευμένη δέσμευση. Παραδείγματα αναγνωριστικών χρήστη/παραγγελιών πρέπει να αντικατασταθούν με τις δικές σας σταθερές τιμές.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Απευθείας είσοδος URL

Η άμεση καταχώρηση URL είναι για λειτουργία ανακατεύθυνσης. Ένας συνεργάτης χρήστης κάνει κλικ σε ένα κουμπί στο
συνεργαζόμενος ιστότοπος, ανοίγει το 6MM διεπαφή και συνδέεται αυτόματα.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/en/futures/BTCUSDT?tradingMode=real")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Κανόνες πεδίου:

| Πεδίο | Περιγραφή |
| --- | --- |
| `redirectPath` | 6MM σχετική διαδρομή διεπαφής. Πρέπει να ξεκινά με `/`, για παράδειγμα `/en/futures/BTCUSDT?tradingMode=real` |
| `returnUrl` | Απόλυτο συνεργάτη URL που χρησιμοποιείται όταν ο χρήστης εξέρχεται από το 6MM διεπαφή. Επιτρέπονται μόνο `http` και `https` |
| `expireAt` | Ο χρόνος λήξης του εισιτηρίου εισόδου ως χρονοσήμανση Unix σε δευτερόλεπτα |

Το παράδειγμα ανοίγει διαρκή συμβόλαια μελλοντικής εκπλήρωσης σε πραγματικό τρόπο. Για προσομοίωση συναλλαγών, χρησιμοποιήστε το `tradingMode=demo` στο frontend και περάστε ρητά το `environment=SIMULATED` στα αντίστοιχα αιτήματα πορτοφολιού υποστήριξης. Το Frontend `tradingMode` και το backend fund `environment` διαμορφώνονται ξεχωριστά. Η δημιουργία μιας καταχώρησης URL επαληθεύει την ταυτότητα του χρήστη. δεν μεταφέρει χρήματα ούτε επιλέγει περιβάλλον πορτοφολιού.

Απαιτήσεις ασφαλείας:

- Το `webUrl` περιέχει ένα εισιτήριο μίας χρήσης. Χρησιμοποιήστε το αμέσως και μην το αποθηκεύσετε για μεγάλο χρονικό διάστημα.
- Εάν η καταχώριση URL λήξει ή έχει χρησιμοποιηθεί, δημιουργήστε μια νέα από τον ιστότοπο συνεργάτη.
- Το `returnUrl` δεν πρέπει να είναι `javascript:`, σχετική διαδρομή ή URL με στοιχεία χρήστη.

## Επιλογή προϊόντος και τρόπου λειτουργίας

Χρησιμοποιήστε την τρέχουσα διεπαφή διαδρομή που παρέχεται από 6MM. Για παράδειγμα `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` ή `/zh-CN/futures/BTCUSDT?tradingMode=real`. Το εισιτήριο πιστοποιεί την ταυτότητα του χρήστη. δεν επιλέγει περιβάλλον χρηματοδότησης ούτε μετακινεί κεφάλαια.

Βλέπω [Συναλλαγές δευτερολέπτων](/el/sdk/agent-sdk/java/seconds-trading) για ανακατεύθυνση και ενσωματωμένα παραδείγματα.
