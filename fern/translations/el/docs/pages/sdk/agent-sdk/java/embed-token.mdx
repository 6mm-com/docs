## Παράδειγμα προαπαιτούμενα

Τα αποσπάσματα Java μοιράζονται αυτές τις εισαγωγές. Αρχικοποιήστε το `client` χρησιμοποιώντας Γρήγορη εκκίνηση και αποκτήστε `platformUserId` από την αποθηκευμένη δέσμευση. Παραδείγματα αναγνωριστικών χρήστη/παραγγελιών πρέπει να αντικατασταθούν με τις δικές σας σταθερές τιμές.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget Ενσωμάτωση διακριτικού

Το διακριτικό ενσωμάτωσης είναι για τη λειτουργία Trading Widget SDK `partner-token + tokenProvider`. Ο
Το πρόγραμμα περιήγησης καλεί το backend συνεργάτη και το backend συνεργάτη καλεί αυτό Java SDK
για να δημιουργήσετε ένα `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Απαιτήσεις ενσωμάτωσης:

- Το `channelId` πρέπει να χρησιμοποιεί την τιμή που πέρασε από το Trading Widget SDK.
- Το `symbol` είναι προαιρετικό, αλλά συνιστάται να περάσετε το τρέχον αρχικό σύμβολο.
- Το `embedToken` είναι βραχύβιο και εφάπαξ. Μην το βάζετε σε συμβολοσειρές ερωτήματος URL.
- Η διεπαφή συνεργάτη δεν πρέπει ποτέ να κρατά `apiSecret`.
- Το `expireAt` είναι μια χρονική σήμανση Unix σε δευτερόλεπτα, όχι ένα TTL.

Παράδειγμα τελικού σημείου υποστήριξης συνεργάτη:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Συμβόλαιο τελικού σημείου συνεργάτη

Έλεγχος ταυτότητας της συνεδρίας συνεργάτη και εξαγωγή `agentUserId` από την πλευρά του διακομιστή. Αποδοχή του τρέχοντος γραφικού στοιχείου `channelId`. επιστροφή ανώτατου επιπέδου `embedToken`, `expireAt` (δευτερόλεπτα Unix) και το ίδιο `channelId`. Οι αποκρίσεις πρακτόρων δεν παρέχουν `channelId`: το backend σας το επαναλαμβάνει. Λάβετε ένα νέο διακριτικό κατά την προετοιμασία και την ανανέωση. μην το ξαναχρησιμοποιήσετε ποτέ. Η δημιουργία διακριτικού δεν μεταφέρει χρήματα ούτε επιλέγει το περιβάλλον πορτοφολιού.

Βλέπω [Συναλλαγές δευτερολέπτων](/el/sdk/agent-sdk/java/seconds-trading) για την πλήρη ροή frontend/backend.
