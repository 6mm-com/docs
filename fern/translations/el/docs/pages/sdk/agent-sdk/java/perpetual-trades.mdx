## Παράδειγμα προαπαιτούμενα

Τα αποσπάσματα Java μοιράζονται αυτές τις εισαγωγές. Αρχικοποιήστε το `client` χρησιμοποιώντας Γρήγορη εκκίνηση και αποκτήστε `platformUserId` από την αποθηκευμένη δέσμευση. Παραδείγματα αναγνωριστικών χρήστη/παραγγελιών πρέπει να αντικατασταθούν με τις δικές σας σταθερές τιμές.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## `listPerpetualTrades`

Αίτημα μοντέλου: `PerpetualTradesRequest`.

```java
import com.sixmm.agent.model.PerpetualTradesRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

PerpetualTradesRequest request = new PerpetualTradesRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.symbol = "BTCUSDT";
request.endTime = System.currentTimeMillis();
request.startTime = request.endTime - 3_600_000L;
PerpetualResponse response = client.listPerpetualTrades(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

### Πεδία αιτήματος

| Πεδίο | Java τύπος | Υποχρεούμαι | Εννοια |
| --- | --- | --- | --- |
| `platformUserIds` | `java.util.List<String>` | Ναί | Παρέχετε ρητά 1–100 μοναδικά αναγνωριστικά χρήστη δημόσιας πλατφόρμας που ανήκουν στον τρέχοντα συνεργάτη. παράλειψη και ένας κενός πίνακας δεν είναι έγκυροι. |
| `symbol` | `String` | Οχι | Προαιρετικό φίλτρο ζεύγους συναλλαγών. |
| `orderId` | `String` | Οχι | Ταυτότητα παραγγελίας. δεν είναι αριθμός εντολής μεταφοράς συνεργάτη. |
| `startTime` | `Long` | Οχι | Συμπεριλαμβανόμενα χιλιοστά του δευτερολέπτου Unix. χρησιμοποιήστε ένα σταθερό παράθυρο ιστορικού UTC. |
| `endTime` | `Long` | Οχι | Αποκλειστικά Unix χιλιοστά του δευτερολέπτου. |
| `limit` | `Integer` | Οχι | Προεπιλογή 500; 1–1000. |
| `cursor` | `String` | Οχι | Χρησιμοποιήστε το επιστρεφόμενο nextCursor με αμετάβλητα φίλτρα. σταματήστε όταν το hasMore είναι ψευδές. |

Το παράδειγμα διαβάζει μια σελίδα. Για απαιτούμενα πεδία, εύρος προγράμματος αναπαραγωγής, σημασιολογία φίλτρου, όριο, δρομέα και περιορισμένες επαναλήψεις, ακολουθήστε [Επισκόπηση ερωτήματος](/el/sdk/agent-sdk/java/perpetual-queries). Διατηρήστε όλα τα φίλτρα αμετάβλητα κατά τη σελιδοποίηση. μην ερμηνεύσετε ένα σφάλμα ως κενό αποτέλεσμα.

## Στοιχεία πλήρωσης συναλλαγών

Διεπαφή: `trades`. Απαιτεί ρητή platformUserIds.

| πεδίο `data` | τύπος | έννοια |
| --- | --- | --- |
| `fillId` | string | Αναγνωριστικό στοιχείων συμπλήρωσης συναλλαγών, που αντιστοιχεί σε αυτήν την εγγραφή entityId |
| `tradeId` | string | Το αντίστοιχο αναγνωριστικό συναλλαγής που σχετίζεται με τη συναλλαγή. δεν αντικαθιστά το αναλυτικό αναγνωριστικό |
| `orderId` | string | Το γενικό αναγνωριστικό παραγγελίας στο οποίο ανήκει αυτό το στοιχείο |
| `positionId` | string | Αναγνωριστικό σχετιζόμενης θέσης |
| `symbol` | string | ζεύγος συναλλαγών |
| `side` | string | Κατεύθυνση αγοράς και πώλησης αυτού του παίκτη BUY / SELL |
| `roleType` | string | Ο χαρακτήρας συναλλαγής αυτού του παίκτη MAKER / TAKER |
| `positionSide` | string | Κατεύθυνση θέσης, επεξηγημένη σύμφωνα με την πραγματική τιμή LONG / SHORT / BOTH κ.λπ. |
| `price` | string | Αυτή η τιμή συναλλαγής |
| `quantity` | string | Η ποσότητα αυτής της συναλλαγής δεν είναι η συνολική ποσότητα της αρχικής παραγγελίας. |
| `tradeValue` | string | Η ονομαστική αξία αυτής της συναλλαγής προέρχεται από την πλασματική συναλλαγή |
| `handlingFee` | string | Η χρέωση συναλλαγής για αυτήν τη συναλλαγή διατηρεί το σύμβολο πηγής και την ακρίβεια και δεν παίρνει την απόλυτη τιμή από μόνη της. |
| `realizedPnl` | string | Τα πραγματοποιηθέντα κέρδη και ζημίες που αντιστοιχούν σε αυτή τη συναλλαγή. όχι τα κυμαινόμενα κέρδη και ζημίες σε πραγματικό χρόνο της τρέχουσας θέσης |
| `tradedAt` | integer | Χρόνος συναλλαγής, χιλιοστά του δευτερολέπτου. χρησιμοποιήστε αυτό το πεδίο για φιλτράρισμα χρόνου |

Μια παραγγελία μπορεί να έχει πολλαπλά συμπληρώματα, τα οποία θα πρέπει να αποθηκευτούν λεπτομερώς. Μην συγχωνεύετε εγγραφές διαφορετικών παικτών/συμπληρώστε ρόλους κατά tradeId και, στη συνέχεια, απορρίψτε τις ταυτότητες των αρχείων τους.

## Παράδειγμα φακέλου απάντησης

Αυτή είναι μια ενδεικτική κενή σελίδα, όχι ένα δείγμα ολοκληρωμένης συναλλαγής. Οι παραπάνω πίνακες πεδίων για συγκεκριμένους πόρους περιγράφουν το συμπληρωμένο `items[].data`.

```json
{"code":0,"message":"success","data":{"items":[],"nextCursor":"","hasMore":false}}
```
