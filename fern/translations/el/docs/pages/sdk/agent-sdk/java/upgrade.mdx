Αυτός ο οδηγός στοχεύει **Agent Java SDK `v0.3.0`** και Java 8+.

<span id="decide-what-needs-upgrading" data-sixmm-canonical-anchor="decide-what-needs-upgrading" aria-hidden="true"></span>

## Αποφασίστε τι χρειάζεται αναβάθμιση

| Υπάρχουσα ένταξη | Δράση |
| --- | --- |
| Υπάρχουσες συναρτήσεις παραγωγής με παραλειπόμενο περιβάλλον | Τα υπάρχοντα σχήματα απόκρισης παραμένουν συμβατά. τα νέα ερωτήματα δεν επιβάλλουν αναβάθμιση. |
| Υφιστάμενος γενικός έλεγχος ταυτότητας ενσωμάτωσης για συναλλαγές δευτερολέπτων | Επαναχρησιμοποίηση ελέγχου ταυτότητας και ανανέωσης. επιλέξτε την επιθυμητή σελίδα προϊόντος. |
| Υπόλοιπα χρηματοδότησης, μεταφορές και ανάκτηση | Χρησιμοποιήστε τα μοντέλα που περιέχουν `withFunding`, `walletTransfer` και `queryWalletTransfer`. |
| Ρητά προσομοιωμένα κεφάλαια | Χρησιμοποιήστε μοντέλα αιτήματος/απόκρισης που υποστηρίζουν `environment`. |
| Έξι ερωτήματα διαρκούς δεδομένων | Χρησιμοποιήστε το δημόσιο Java SDK `v0.3.0`, συμπεριλαμβανομένων των έξι μεθόδων και της υποστήριξης υπογραφής πίνακα. |

Διατηρήστε τις τρέχουσες `baseUrl`, `agentCode`, `apiSecret`, τις δεσμεύσεις χρήστη και τις αρχικές επιχειρηματικές παραγγελίες σας.

## Εγκαταστήστε τη σταθερή δημόσια ετικέτα

Πηγή φιλοξενίας GitHub. Η δημοσίευση μιας ετικέτας GitHub δεν δημοσιεύει τις συντεταγμένες Maven στο Maven Central. Εγκαταστήστε την πηγή με ετικέτα τοπικά ή δημοσιεύστε το επαληθευμένο JAR/POM στο αποθετήριο τεχνουργημάτων του οργανισμού σας.

```bash
git clone --branch v0.3.0 --single-branch https://github.com/6mm-com/agent-java-sdk.git agent-java-sdk-v0.3.0
cd agent-java-sdk-v0.3.0
git rev-parse HEAD
git rev-parse 'v0.3.0^{commit}'
mvn install
```

Τα δύο αναγνωριστικά δέσμευσης πρέπει να ταιριάζουν. Δηλώστε την εξάρτηση στο έργο συνεργάτη:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.3.0</version>
</dependency>
```

Επαληθεύστε την επιλυμένη εξάρτηση:

```bash
mvn dependency:tree -Dincludes=com.sixmm.exchange.sdk:agent
```

Μια τοπική εγκατάσταση καθιστά το τεχνούργημα διαθέσιμο μόνο σε αυτό το μηχάνημα. Το CI και άλλοι προγραμματιστές χρειάζονται την ίδια εγκατάσταση με ετικέτα ή το αποθετήριο επαληθευμένων τεχνουργημάτων. Εάν έχετε ήδη ένα ιδιωτικό τεχνούργημα με το όνομα `0.3.0`, επαληθεύστε την πηγή και τις μεθόδους του. μην αντικαθιστάτε σιωπηλά ένα κοινόχρηστο αντικείμενο.

## Απαιτούμενες αλλαγές ενσωμάτωσης

1. Ενημέρωση μοντέλων αιτήματος και απόκρισης για ρητά `environment`. Αυστηρά παλαιότερα μοντέλα απόκρισης ενδέχεται να απορρίψουν το πρόσθετο πεδίο.
2. Χρησιμοποιήστε το `withFunding()` πριν διαβάσετε το `funding`. Τα υπόλοιπα των συμβολαίων δεν είναι υπόλοιπα συναλλαγών δευτερολέπτων.
3. Χρησιμοποιήστε τα `/v1/agent/wallet-transfer` και `/v1/agent/wallet-transfer-status` για χρηματοδότηση. Το παλιό `queryOrder` δεν μπορεί να ανακτήσει μια λειτουργία χρηματοδότησης.
4. Τα έξι ερωτήματα χρησιμοποιούν το `platformUserIds` ως πίνακα συμβολοσειρών. Υπογράψτε τους πίνακες ως συμπαγείς JSON; Java `List.toString()` δεν είναι συμβατό.
5. Εντολές μεταφοράς καταστήματος, συνήθεις εντολές διαπραγμάτευσης, εντολές υπό όρους και πληρωμές ως διακριτές οντότητες. Ανάλυση `orderStatus` ή `status` σύμφωνα με τη λειτουργία.
6. Επαληθεύστε το αρχικό σώμα webhook πριν από την ανάλυση. Οι ρητές προσομοιωμένες ειδοποιήσεις περιλαμβάνουν `environment`. συγκρίνετε το με την αποθηκευμένη σειρά.
7. Διαχειριστείτε ανεξάρτητα τις εκδόσεις Java και Widget. Μια αναβάθμιση backend δεν αλλάζει τη σελίδα frontend ή τη λειτουργία συναλλαγών και η διαπραγμάτευση δευτερολέπτων δεν απαιτεί νέο τύπο διακριτικού.

## Επαληθεύστε την αναβάθμιση

Εκτελέστε το build του συνεργαζόμενου έργου και επιθεωρήστε το δέντρο εξάρτησής του. Δοκιμαστική δέσμευση, η αρχική ροή παραγωγής, ρητά προσομοιωμένα υπόλοιπα, ανάκτηση αποτελεσμάτων χρηματοδότησης, και τα έξι ερωτήματα, σελιδοποίηση σταθερού παραθύρου, χειρισμός σφαλμάτων και ανεπαρκείς επανακλήσεις.

Για έναν προσαρμοσμένο πελάτη HTTP, ακολουθήστε το αίτημα με ετικέτα και το συμβόλαιο υπογραφής αντί να υποθέσετε ότι τα παλιά μοντέλα καλύπτουν νέα πεδία. Βλέπω [Κανόνες υπογραφής πράκτορα](/el/sdk/security/secrets-signing#signing-rule), [Επισκόπηση ερωτήματος](/el/sdk/agent-sdk/java/perpetual-queries) και [Οδηγός περιβάλλοντος](/el/sdk/agent-sdk/java/environments).
