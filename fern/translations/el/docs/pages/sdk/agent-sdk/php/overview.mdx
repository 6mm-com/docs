<h2 id="runtime">Χρόνος εκτέλεσης</h2>

| Είδος | Αξία |
| --- | --- |
| Πακέτο | Sixmm/πράκτορας-SDK |
| Ελάχιστη έκδοση PHP | PHP 7.4+ |
| Προτεινόμενη έκδοση PHP | PHP 8.1+ ή υποστηριζόμενες εκδόσεις |
| Απαιτούμενες επεκτάσεις | ext-json, ext-curl |

Η πηγή του πακέτου PHP SDK και η εγκεκριμένη έκδοση παρέχονται κατά την ενσωμάτωση συνεργάτη. Μην υποθέτετε ότι το πακέτο είναι διαθέσιμο από το δημόσιο Packagist. ρυθμίστε τις παραμέτρους του αποθετηρίου του Composer που παρέχεται για τον οργανισμό σας.

<h2 id="supported-scenarios">Υποστηριζόμενα σενάρια</h2>

| Σενάριο | SDK μέθοδος |
| --- | --- |
| Δέσμευση χρήστη | δεσμεύω |
| Μεταφορά σταθερού ποσού | Μεταφορά |
| Μεταφορά όλων έξω | transferAllOut |
| Αντίστροφη μεταφορά | ΑΝΤΙΣΤΡΟΦΗ |
| Σειρά ερωτήματος | queryOrder |
| Δημιουργία URL καταχώρισης | createEntryUrl |
| Webhook επαλήθευση | WebhookVerifier::επαλήθευση |

<h2 id="backend-integration-rules">Κανόνες ενσωμάτωσης backend</h2>

- Φόρτωση `apiSecret` από μια μεταβλητή μυστικού διαχειριστή ή προστατευμένου περιβάλλοντος.
- Διατηρήστε τη δέσμευση χρήστη, τη μεταφορά, την υπογραφή και τη λογική webhook εκτός κώδικα προγράμματος περιήγησης.
- Χρησιμοποιήστε δεκαδικές συμβολοσειρές για ποσά περιουσιακών στοιχείων για να αποφύγετε τη στρογγυλοποίηση κινητής υποδιαστολής.
- Χρησιμοποιήστε ξανά την αρχική `agentOrderNo` όταν ρωτάτε ένα αβέβαιο αποτέλεσμα μεταφοράς.
- Επαληθεύστε τις υπογραφές webhook σε σχέση με το ακατέργαστο σώμα αιτήματος πριν το αποκωδικοποιήσετε ή το αλλάξετε.
