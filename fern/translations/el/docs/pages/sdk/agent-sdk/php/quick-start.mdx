## Εγκαθιστώ

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Πρόσβαση σε πακέτο**
>
> 6MM παρέχει το εγκεκριμένο όνομα πακέτου, το αποθετήριο και την έκδοση του Composer κατά την ενσωμάτωση του συνεργάτη. Το πακέτο δεν πρέπει να θεωρηθεί ότι υπάρχει στο δημόσιο Packagist.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Πριν ξεκινήσετε

- Επιβεβαιώστε ότι ο πράκτορας API βάση URL με 6MM.
- Φορτώστε apiSecret από μεταβλητές περιβάλλοντος ή μυστική διαχείριση.
- Διατηρήστε τη χρήση SDK μόνο εντός των υπηρεσιών υποστήριξης.
- Προετοιμάστε ανίκανους χειρισμούς για μεταφορά και webhook ροών.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Προετοιμασία προγράμματος-πελάτη

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Μόνο backend**
>
> Το PHP SDK υπογράφει αιτήματα API πράκτορα και δεν πρέπει να εκτίθεται μέσω δημόσιου πηγαίου κώδικα ή περιβάλλοντος χρόνου εκτέλεσης frontend.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Παράδειγμα: μεταφορά χρημάτων σε

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Χρησιμοποιήστε δεκαδικές συμβολοσειρές για ποσά και διατηρήστε την αρχική agentOrderNo κατά την επανάληψη ή την υποβολή ερωτήματος για την κατάσταση μεταφοράς.
