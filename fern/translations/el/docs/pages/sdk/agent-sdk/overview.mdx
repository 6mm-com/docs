Η 6MM Agent SDK αφορά υπηρεσίες υποστήριξης συνεργατών που πρέπει να καλούν προνομιακά APIs πρακτόρων χωρίς να εφαρμόζουν την υπογραφή και τον χειρισμό αιτημάτων από την αρχή. Δεν πρέπει να εκτελείται σε κώδικα προγράμματος περιήγησης, κινητού ή δημόσιου επιτραπέζιου υπολογιστή, επειδή η ενσωμάτωση χρησιμοποιεί έναν συνεργάτη API μυστικό.

<h2 id="when-to-use-the-agent-sdk">Πότε να χρησιμοποιήσετε το Agent SDK</h2>

Χρησιμοποιήστε ένα Agent SDK όταν το backend σας χρειάζεται να δεσμεύσει έναν χρήστη-συνεργάτη, να μετακινήσει στοιχεία μέσω μιας εγκεκριμένης ροής εργασιών, να υποβάλει ερωτήματα σε αρχεία συναλλαγών, να δημιουργήσει μια ενσωματωμένη URL καταχώρισης συναλλαγών ή να επαληθεύσει webhook ειδοποιήσεις. Χρησιμοποιήστε το [Trading Widget SDK](/el/sdk/trading-widget/overview) ξεχωριστά όταν το frontend συνεργάτη πρέπει να εμφανίσει τη διεπαφή συναλλαγών.

<h2 id="common-configuration">Κοινή διαμόρφωση</h2>

| Κλειδί | Παράδειγμα | Περιγραφή |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Ο πράκτορας API σέρβις URL χωρίς κάθετο. |
| agentCode | AGENT001 | Κωδικός συνεργάτη πράκτορα. |
| apiSecret | Το δικό σας-API-μυστικό | API μυστικό υπογραφής αποθηκευμένο μόνο στο backend. |
| defaultCurrency | USDT | Προεπιλεγμένο νόμισμα για μεταφορά και APIsλογαριασμού. |
| webhookUrl | https://partner.example.com/6mm/webhook | Τελικό σημείο συνεργάτη για ειδοποιήσεις 6MM webhook . |

<h2 id="typical-integration-flow">Τυπική ροή ολοκλήρωσης</h2>

1. Η διεπαφή συνεργάτη ελέγχει την ταυτότητα του χρήστη μέσω του συστήματος λογαριασμού του συνεργάτη.
2. Το backend συνεργάτη αντιστοιχίζει τον χρήστη σε ένα σταθερό αναγνωριστικό από την πλευρά του συνεργάτη.
3. Το backend καλεί το Agent SDK με `agentCode` και το προστατευμένο API μυστικό.
4. Ο SDK υπογράφει και αποστέλλει στον Πράκτορα API αίτημα.
5. Το backend αποθηκεύει το επιστρεφόμενο αναγνωριστικό επιχείρησης και επεξεργάζεται αργότερα webhooks ανίκανα.
6. Το frontend λαμβάνει μόνο το βραχύβιο αποτέλεσμα ή τα διαπιστευτήρια εισόδου που χρειάζεται.

<h2 id="production-checklist">Λίστα ελέγχου παραγωγής</h2>

- Φορτώστε `apiSecret` από έναν μυστικό διαχειριστή υποστήριξης, όχι από τον πηγαίο κώδικα.
- Διατηρήστε τα διαπιστευτήρια ανάπτυξης, σταδιοποίησης και παραγωγής ξεχωριστά.
- Χρησιμοποιήστε μια σταθερή αντιστοίχιση χρήστη συνεργάτη και μοναδικά αναγνωριστικά παραγγελιών επιχείρησης.
- Διατηρήστε το αρχικό αναγνωριστικό κατά τον έλεγχο της κατάστασης ενός αιτήματος που έχει λήξει.
- Επαληθεύστε τις υπογραφές webhook και αποθηκεύστε τα επεξεργασμένα αναγνωριστικά συμβάντων.
- Αποκρύψτε μυστικά και υπογραφές από αρχεία καταγραφής διατηρώντας παράλληλα αναγνωριστικά αιτημάτων για υποστήριξη.
