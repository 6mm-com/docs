Το 6MM Agent SDK είναι για υπηρεσίες υποστήριξης συνεργατών που πρέπει να καλούν τον προνομιακό Agent APIs χωρίς να εφαρμόζουν την υπογραφή και τον χειρισμό αιτημάτων από την αρχή. Δεν πρέπει να εκτελείται σε κώδικα προγράμματος περιήγησης, κινητού ή δημόσιου υπολογιστή, επειδή η ενοποίηση χρησιμοποιεί ένα μυστικό συνεργάτη API.

<span id="when-to-use-the-agent-sdk" data-sixmm-canonical-anchor="when-to-use-the-agent-sdk" aria-hidden="true"></span>

## Πότε να χρησιμοποιήσετε το Agent SDK

Χρησιμοποιήστε ένα Agent SDK όταν το backend σας χρειάζεται να δεσμεύσει έναν χρήστη συνεργάτη, να μετακινήσει στοιχεία μέσω εγκεκριμένης ροής εργασιών, να υποβάλει ερωτήματα σε αρχεία συναλλαγών, να δημιουργήσει μια ενσωματωμένη καταχώριση συναλλαγών URL ή να επαληθεύσει τις ειδοποιήσεις webhook. Χρησιμοποιήστε το [Trading Widget SDK](/el/sdk/trading-widget/overview) χωριστά όταν το frontend συνεργάτη χρειάζεται να εμφανίσει τη διεπαφή συναλλαγών.

## Κοινή διαμόρφωση

| Κλειδί | Παράδειγμα | Περιγραφή |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Υπηρεσία αντιπροσώπου API υπηρεσία URL χωρίς τελική κάθετο. |
| agentCode | AGENT001 | Κωδικός αντιπροσώπου συνεργάτη. |
| apiSecret | your-api-secret | API μυστικό υπογραφής αποθηκεύεται μόνο στο backend. |
| defaultCurrency | USDT | Προεπιλεγμένο νόμισμα για μεταφορά και λογαριασμό APIs. |
| webhookUrl | https://partner.example.com/6mm/webhook | Τελικό σημείο συνεργάτη για ειδοποιήσεις 6MM webhook. |

<span id="typical-integration-flow" data-sixmm-canonical-anchor="typical-integration-flow" aria-hidden="true"></span>

## Τυπική ροή ολοκλήρωσης

1. Η διεπαφή συνεργάτη ελέγχει την ταυτότητα του χρήστη μέσω του συστήματος λογαριασμού του συνεργάτη.
2. Το backend συνεργάτη αντιστοιχίζει τον χρήστη σε ένα σταθερό αναγνωριστικό από την πλευρά του συνεργάτη.
3. Το backend καλεί το Agent SDK με `agentCode` και το προστατευμένο API μυστικό.
4. Το SDK υπογράφει και στέλνει το αίτημα Agent API.
5. Το backend αποθηκεύει το αναγνωριστικό επιχείρησης που επιστράφηκε και επεξεργάζεται αργότερα webhooks ανεπαρκώς.
6. Το frontend λαμβάνει μόνο το βραχύβιο αποτέλεσμα ή το διαπιστευτήριο εισόδου που χρειάζεται.

## Λίστα ελέγχου παραγωγής

- Φόρτωση `apiSecret` από έναν διαχειριστή μυστικών υποστήριξης, όχι από τον πηγαίο κώδικα.
- Διατηρήστε χωριστά τα διαπιστευτήρια ανάπτυξης, σκηνοθεσίας και παραγωγής.
- Χρησιμοποιήστε μια σταθερή χαρτογράφηση χρήστη συνεργάτη και μοναδικά αναγνωριστικά παραγγελιών επιχείρησης.
- Διατηρήστε το αρχικό αναγνωριστικό κατά τον έλεγχο της κατάστασης ενός αιτήματος που έχει λήξει.
- Επαληθεύστε τις υπογραφές webhook και αποθηκεύστε τα επεξεργασμένα αναγνωριστικά συμβάντων.
- Διορθώστε μυστικά και υπογραφές από αρχεία καταγραφής διατηρώντας τα αναγνωριστικά αιτημάτων για υποστήριξη.
