<h2 id="recommended-combination">Προτεινόμενος συνδυασμός</h2>

| Στόχος συνεργάτη | Μπροστινό μέρος | Παρασκήνιο | Γιατί έχει σημασία |
| --- | --- | --- | --- |
| Προσθήκη ενσωματωμένου τερματικού συναλλαγών | Trading Widget SDK | Agent SDK | Το widget χειρίζεται τη διεπαφή χρήστη συναλλαγών, ενώ το backend του συνεργάτη εκδίδει διακριτικά και κρατά τα μυστικά ιδιωτικά. |
| Δημιουργία σημείου εισόδου εγγενούς εφαρμογής | Εγγενής καταχώρηση ή καταχώρηση H5 | Agent SDK | Η εφαρμογή ανοίγει μια καταχώρηση 6MM URL αφού ο συνεργάτης επικυρώσει την περίοδο λειτουργίας χρήστη. |
| Δημιουργήστε μια προσαρμοσμένη ροή συναλλαγών | Περιβάλλον εργασίας χρήστη συνεργάτη | Developer API + επιλεγμένες ροές SDK | Χρησιμοποιήστε APIs για δεδομένα λογαριασμού, παραγγελίας, θέσης και αγοράς, διατηρώντας παράλληλα τους λειτουργικούς ελέγχους από την πλευρά του διακομιστή. |

<h2 id="reference-architecture">Αρχιτεκτονική αναφοράς</h2>

```text
Partner Web App
  -> TradingWidget.create()
  -> tokenProvider()
  -> Partner Backend
  -> 6MM Agent SDK
  -> 6MM Agent API
  -> 6MM Trading iframe
```

> **Κρατήστε μυστικά από την πλευρά του διακομιστή**
>
> Ο κώδικας του προγράμματος περιήγησης θα πρέπει να καλεί μόνο τελικά σημεία που ανήκουν σε συνεργάτες. Το μυστικό API πράκτορα δεν πρέπει ποτέ να αποστέλλεται στον κώδικα διεπαφής.

<h2 id="production-checklist">Λίστα ελέγχου παραγωγής</h2>

- Αποθηκεύστε apiSecret μόνο σε υποδομή υποστήριξης.
- Χρησιμοποιήστε HTTPS για αιτήματα API εκπροσώπου και διευθύνσεις URL webhook .
- Διατήρηση αντιστοιχίσεων agentUserId, platformUserIdκαι agentOrderNo .
- Αναπαραστήστε τα χρηματικά ποσά ως δεκαδικές συμβολοσειρές αντί για τιμές κινητής υποδιαστολής.
- Χειριστείτε PROCESSING ως εκκρεμότητα, όχι ως επιτυχία ή αποτυχία.
- Επεξεργαστείτε webhooks ανίκανα επειδή αναμένονται επαναλήψεις.
