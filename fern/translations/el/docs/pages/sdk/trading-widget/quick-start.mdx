Το Trading Widget SDK ενσωματώνει τη διεπαφή συναλλαγών 6MM σε μια ιστοσελίδα που ανήκει σε συνεργάτη. Η ταχύτερη ενσωμάτωση απαιτεί ένα ορατό κοντέινερ, το σενάριο SDK παραγωγής και μια κλήση στο `TradingWidget.create()`.

<h2 id="before-you-start">Πριν ξεκινήσετε</h2>

- Εκτελέστε το παράδειγμα από μια ιστοσελίδα που μπορεί να φορτώσει πόρους από `https://app.6mm.com`.
- Δώστε στο κοντέινερ του γραφικού στοιχείου ένα σαφές πλάτος και ύψος.
- Φορτώστε το SDK πριν καλέσετε `TradingWidget.create()`.
- Σχεδιάστε το [Ροή ελέγχου ταυτότητας](/el/sdk/trading-widget/authentication) πριν ενεργοποιήσετε τις λειτουργίες λογαριασμού ή συναλλαγών στην παραγωγή.

<h2 id="minimal-example">Ελάχιστο παράδειγμα</h2>

```html
<div id="trading-widget" style="width: 100%; height: 720px"></div>

<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
<script>
  const widget = TradingWidget.create('#trading-widget', {
    baseUrl: 'https://app.6mm.com',
    symbol: 'BTCUSDT',
    theme: 'dark',
    locale: 'en',
    layout: 'default',
    display: {
      showHeader: false,
      showTicker: false,
      hidden: [],
    },
    onReady(event) {
      console.log('ready', event)
    },
    onError(error) {
      console.error('error', error)
    },
  })
</script>
```

Όταν η ενσωμάτωση είναι επιτυχής, το SDK δημιουργεί ένα iframe μέσα `#trading-widget` και καλεί `onReady`. Καταγράψτε `onError` κατά τη διάρκεια της ανάπτυξης, ώστε να είναι ορατές οι αποτυχίες διαμόρφωσης και φόρτωσης.

<h2 id="sdk-urls">SDK διευθύνσεις URL</h2>

| Περιβάλλον | Σενάριο URL |
| --- | --- |
| Παραγωγή | https://app.6mm.com/sdk/trading-widget/v1/index.js |

> **Ορίστε baseUrl ρητά**
>
> Κατά τη δοκιμή από σελίδες που ανήκουν σε συνεργάτες, περάστε baseUrl ώστε το iframe να οδηγεί πάντα στον 6MM τομέα Web.

<h2 id="display-controls">Στοιχεία ελέγχου οθόνης</h2>

Οι ενσωματώσεις συνεργατών αποκρύπτουν την κεφαλίδα του υπολογιστή και το ticker της κάτω αγοράς από προεπιλογή. Χρησιμοποιήστε `display` όταν πρέπει να εμφανίσετε αυτές τις περιοχές κελύφους ή να αποκρύψετε κοντέινερ υψηλού επιπέδου στην ενσωματωμένη σελίδα συναλλαγών.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['account'],
}
```

<h2 id="container-size">Μέγεθος δοχείου</h2>

| Εμβαδόν | Συνιστώμενο ελάχιστο |
| --- | --- |
| Επιφάνεια εργασίας | 1024 Χ 720 |
| Κινητό | 390 Χ 700 |

Για διατάξεις με απόκριση, διατηρήστε το πλάτος ρευστό και ορίστε ένα κατάλληλο ελάχιστο ύψος για κάθε σημείο διακοπής. Ένα κοντέινερ με μηδενικό ύψος μπορεί να φορτώσει το SDK με επιτυχία, αφήνοντας τη διεπαφή συναλλαγών αόρατη.

<h2 id="verify-the-integration">Επαληθεύστε την ενσωμάτωση</h2>

1. Επιβεβαιώστε ότι το σενάριο SDK επιστρέφει με επιτυχία στον πίνακα δικτύου του προγράμματος περιήγησης.
2. Επιβεβαιώστε `onReady` ενεργοποιείται μόλις αρχικοποιηθεί το iframe.
3. Δοκιμάστε τις διαμορφωμένες `symbol`, `locale`, θέμα και κρυφές ενότητες.
4. Αλλάξτε το μέγεθος της σελίδας σε σημεία διακοπής για υπολογιστές και κινητά.
5. Ολοκληρώστε μια δοκιμή με έλεγχο ταυτότητας με έναν χρήστη εκτός παραγωγής πριν από την κυκλοφορία.

<h2 id="common-issues">Κοινά προβλήματα</h2>

| Σύμπτωμα | Τι να ελέγξετε |
| --- | --- |
| Κενή περιοχή widget | Επιβεβαιώστε ότι το δοχείο έχει ορατό πλάτος και ύψος. |
| `TradingWidget` είναι απροσδιόριστο | Επιβεβαιώστε το σενάριο v1 που φορτώθηκε πριν από την κλήση δημιουργίας. |
| Λάθος σελίδα ή περιβάλλον | Ορίστε `baseUrl` ρητά και επαληθεύστε το διαμορφωμένο περιβάλλον. |
| Το έτοιμο συμβάν δεν ανάβει ποτέ | Καταγράψτε `onError` και επιθεωρήστε αποκλεισμένα αιτήματα iframe ή δέσμης ενεργειών. |
| Τα δεδομένα λογαριασμού δεν είναι διαθέσιμα | Ολοκληρώστε την υποστηριζόμενη ροή ελέγχου ταυτότητας γραφικών στοιχείων. |
