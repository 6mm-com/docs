<h2 id="options">Επιλογές</h2>

| Πεδίο | Τύπος | Προεπιλογή | Σημειώσεις |
| --- | --- | --- | --- |
| baseUrl | string | SDK προέλευση σεναρίου | iframe. Περάστε ρητά στις σελίδες συνεργατών. |
| σύμβολο | string | BTCUSDT | Κανονικοποιημένο σε κεφαλαία και λωρίδες - / _. |
| Θέμα | σκοτεινό \| φως | σκοτάδι | Αρχική παράμετρος θέματος. |
| τοπικές ρυθμίσεις | el \| en-US \| zh-ΣΟ | Πρόγραμμα περιήγησης/προεπιλογή | Υποστηρίζονται τα Αγγλικά και τα Απλοποιημένα Κινεζικά. |
| Διάταξη | προεπιλογή \| συμπαγής | Προεπιλογή | Επιλογή δεσμευμένης διάταξης. |
| Απεικόνιση | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Τα χειριστήρια ενσωματώνουν περιοχές κελύφους και εμπορευματοκιβώτια συναλλαγών υψηλού επιπέδου. |
| ΑΠΘ | object | Κανένας | Χρησιμοποιήστε το partner-token για νέες ενσωματώσεις SSO . |

<h2 id="display-controls">Στοιχεία ελέγχου οθόνης</h2>

`display` ελέγχει το ενσωματωμένο κέλυφος σελίδας συναλλαγών και τα κοντέινερ υψηλού επιπέδου. Στις ενσωματώσεις συνεργατών, η κεφαλίδα του υπολογιστή και το ticker της κάτω αγοράς είναι κρυφά από προεπιλογή.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Πεδίο | Τύπος | Προεπιλογή | Σημειώσεις |
| --- | --- | --- | --- |
| showHeader | boolean | ψευδής | Εάν θα εμφανίζεται η κεφαλίδα ενσωμάτωσης υπολογιστή μέσα στο iframe. |
| showTicker | boolean | ψευδής | Εάν θα εμφανίζεται το ticker της κάτω αγοράς στο κέλυφος ενσωμάτωσης. |
| κρυμμένος | συμβολοσειρά[] | [] | Αποκρύπτει κοντέινερ υψηλού επιπέδου στη σελίδα συναλλαγών. |

Υποστηριζόμενες τιμές `display.hidden` :

| Αξία | Δοχείο |
| --- | --- |
| διάγραμμα | Κοντέινερ γραφήματος |
| orderBook | Περιέκτης βιβλίου παραγγελιών |
| orderForm | Πίνακας φόρμας παραγγελίας |
| Θέσεις | Κάτω θέσεις και πίνακας ανοικτών εντολών |
| Λογαριασμός | Κοντέινερ στοιχείων λογαριασμού |

`display.hidden` κρύβει μόνο ολόκληρα δοχεία. Δεν κρύβει μεμονωμένα κουμπιά, πεδία ή εργαλεία μέσα σε ένα κοντέινερ. Οι τιμές που δεν αντιστοιχίζονται στην τρέχουσα θύρα προβολής αγνοούνται.

<h2 id="events">Εκδηλώσεις</h2>

| Εκδήλωση | Σκανδάλη |
| --- | --- |
| έτοιμο | Η προετοιμασία του iframe ολοκληρώθηκε. |
| Σφάλμα | SDK, iframe ή σφάλμα ελέγχου ταυτότητας. |
| state_changed | SDK κατάσταση του κύκλου ζωής άλλαξε. |
| auth_state_changed | partner-token auth state άλλαξε. |
| symbol_changed | Το πραγματικό σύμβολο iframe άλλαξε. |
| locale_changed | Οι πραγματικές τοπικές ρυθμίσεις iframe άλλαξαν. |
| order_created | Ο χρήστης δημιούργησε μια παραγγελία μέσα στο iframe. |
| order_failed | Η υποβολή της παραγγελίας απέτυχε. |
| καταστράφηκε | SDK περίπτωση καταστράφηκε. |
