## Χειριστήρια οθόνης

Το `display` ελέγχει το ενσωματωμένο κέλυφος της σελίδας συναλλαγών και τα κοντέινερ υψηλού επιπέδου. Στις ενσωματώσεις συνεργατών, η κεφαλίδα του υπολογιστή και η ένδειξη της κάτω αγοράς είναι κρυμμένα από προεπιλογή.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Πεδίο | Τύπος | Αθέτηση | Σημειώσεις |
| --- | --- | --- | --- |
| showHeader | boolean | ψευδής | Εάν θα εμφανίζεται η κεφαλίδα ενσωμάτωσης υπολογιστή μέσα στο iframe. |
| showTicker | boolean | ψευδής | Είτε θα εμφανιστεί ο δείκτης της κάτω αγοράς στο κέλυφος ενσωμάτωσης. |
| κεκρυμμένος | σειρά[] | [] | Αποκρύπτει κοντέινερ υψηλού επιπέδου στη σελίδα συναλλαγών. |

Υποστηριζόμενες τιμές `display.hidden`:

| Αξία | Δοχείο |
| --- | --- |
| διάγραμμα | Δοχείο γραφήματος |
| orderBook | Δοχείο βιβλίου παραγγελίας |
| orderForm | Πίνακας φόρμας παραγγελίας |
| θέσεις | Κάτω θέσεις και πίνακας ανοιχτών παραγγελιών |
| λογαριασμός | Δοχείο περιουσιακών στοιχείων λογαριασμού |

Το `display.hidden` κρύβει μόνο ολόκληρα δοχεία. Δεν κρύβει μεμονωμένα κουμπιά, πεδία ή εργαλεία μέσα σε ένα κοντέινερ. Οι τιμές που δεν αντιστοιχίζονται στην τρέχουσα θύρα προβολής αγνοούνται.

## Σελίδες προϊόντων και λειτουργία συναλλαγών

Java Agent SDK και το πρόγραμμα περιήγησης Trading Widget SDK έχουν εκδοθεί ανεξάρτητα. Για συναλλαγές σε δευτερόλεπτα, χρησιμοποιήστε τις τρέχουσες δυνατότητες του Widget και επιλέξτε ρητά τόσο τη σελίδα όσο και τη λειτουργία συναλλαγών.

| Επιλογή | Αξίες | Εννοια |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Σελίδα προϊόντος για συναλλαγές δευτερολέπτων. |
| `tradingMode` | `real`, `demo` | Προεπιλογές σε `real`; αντιστοιχούν ρητά στο περιβάλλον χρηματοδότησης backend. |

Ελέγξτε τα `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` και `TradingWidget.capabilities.partnerToken` πριν από την προετοιμασία. Η δημιουργία διακριτικού δεν επιλέγει περιβάλλον κεφαλαίων. Για να αλλάξετε τους χρήστες ή τη λειτουργία πραγματικής/επίδειξης, καταστρέψτε την παλιά παρουσία και δημιουργήστε μια νέα.

Βλέπω [Παράδειγμα συναλλαγών σε δευτερόλεπτα](/el/sdk/agent-sdk/java/seconds-trading) και [παραγωγή/προσομοίωση διαμόρφωσης](/el/sdk/agent-sdk/java/environments).

## Πρόσθετοι στόχοι εμφάνισης και συμβάντα

Ο τρέχων χρόνος εκτέλεσης δέχεται επίσης `symbolFavorites` και `symbolTicker` στο `display.hidden`. Να ελέγχετε πάντα το `TradingWidget.capabilities.displayTargets`; ένας στόχος ελέγχει ένα κοντέινερ υψηλού επιπέδου και δεν αποτελεί ρύθμιση δικαιωμάτων σε επίπεδο πεδίου.

| Συμβάν | Εννοια |
| --- | --- |
| `rendered` | Το iframe στέλνει την ειδοποίηση που έχει αποδοθεί. |
| `theme_changed` | Το iframe αναφέρει το πραγματικό του θέμα. |
| `page_changed` | Το iframe αναφέρει την πραγματική σελίδα προϊόντος του. |

Χρησιμοποιήστε το `onRendered` ή το `widget.on('rendered', handler)` για να χειριστείτε την απόδοση ξεχωριστά από την προετοιμασία. Οι τρέχουσες υποστηριζόμενες σελίδες δημοσιεύονται στο `TradingWidget.capabilities.pages`. επικυρώστε τη σελίδα που ζητήσατε αντί να μαντέψετε μια διαδρομή.
