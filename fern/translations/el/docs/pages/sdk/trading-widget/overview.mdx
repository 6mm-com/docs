<h2 id="responsibility-split">Καταμερισμός ευθυνών</h2>

| Περιοχή | Ιδιοκτήτης | Σημειώσεις |
| --- | --- | --- |
| Δημιουργία κοντέινερ | Frontend συνεργάτη | Παρέχετε ένα ορατό στοιχείο με σαφές πλάτος και ύψος. |
| Δημιουργία iframe | Trading Widget SDK | Ο SDK δημιουργεί και διαχειρίζεται το iframe. |
| Διεπαφή χρήστη συναλλαγών | 6MM iframe | Η γραμμή K, το βιβλίο παραγγελιών, η φόρμα παραγγελίας, οι θέσεις, οι εντολές και τα δεδομένα λογαριασμού εκτελούνται μέσα στο iframe. |
| Στοιχεία ελέγχου οθόνης | Trading Widget SDK + 6MM iframe | Η κεφαλίδα ενσωμάτωσης υπολογιστή και η κάτω στήλη ενημέρωσης είναι κρυφά από προεπιλογή. Οι συνεργάτες μπορούν να χρησιμοποιήσουν `display` για να εμφανίσουν περιοχές κελύφους ή να κρύψουν εμπορευματοκιβώτια συναλλαγών υψηλού επιπέδου. |
| Έλεγχος σύνδεσης συνεργάτη | Υποστήριξη συνεργάτη | Επικυρώστε τη συνεδρία χρήστη-συνεργάτη πριν από την έκδοση διαπιστευτηρίων ελέγχου ταυτότητας. |
| Ενσωμάτωση έκδοσης διακριτικού | Υποστήριξη συνεργάτη + Agent API | Συνιστάται για λειτουργία partner-token. |

<h2 id="versioning">Διαχείριση εκδόσεων</h2>

Η δημόσια διαδρομή ενσωμάτωσης παραμένει σταθερή κάτω από το σενάριο v1 URL. Το τρέχον σύνολο δυνατοτήτων v1 περιλαμβάνει partner-token, tokenProvider, entryUrlProvider, στοιχεία ελέγχου οθόνης, συμβάντα κύκλου ζωής, μεθόδους παρουσίας και συμβάντα παραγγελιών.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Πότε να χρησιμοποιήσετε το widget</h2>

Επιλέξτε Trading Widget όταν ένας συνεργάτης χρειάζεται μια πλήρη διεπαφή συναλλαγών μέσα σε ένα υπάρχον προϊόν Ιστού. Χρησιμοποιήστε την τεκμηρίωση REST API και WebSocket κατά τη δημιουργία και τη διατήρηση μιας πλήρως προσαρμοσμένης διεπαφής συναλλαγών.

<h2 id="implementation-path">Διαδρομή υλοποίησης</h2>

1. Ακολουθήστε το [Trading Widget Γρήγορη εκκίνηση](/el/sdk/trading-widget/quick-start) για να φορτώσετε το σενάριο και να δημιουργήσετε ένα ορατό κοντέινερ.
2. Διαμορφώστε [Έλεγχος ταυτότητας Partner-Token](/el/sdk/trading-widget/authentication) μέσω ενός backend συνεργάτη.
3. Προσθέστε τα απαιτούμενα [Επιλογές και συμβάντα](/el/sdk/trading-widget/options-events).
4. Χρήση [Μέθοδοι παρουσίας](/el/sdk/trading-widget/instance-methods) για ελέγχους κύκλου ζωής και χρόνου εκτέλεσης.
