## Κατανομή ευθυνών

| Εκταση | Ιδιοκτήτης | Σημειώσεις |
| --- | --- | --- |
| Δημιουργία κοντέινερ | Frontend συνεργάτη | Παρέχετε ένα ορατό στοιχείο με σαφές πλάτος και ύψος. |
| δημιουργία iframe | Trading Widget SDK | Το SDK δημιουργεί και διαχειρίζεται το iframe. |
| Διεπαφή χρήστη συναλλαγών | 6MM iframe | K-line, βιβλίο παραγγελιών, φόρμα παραγγελίας, θέσεις, παραγγελίες και δεδομένα λογαριασμού εκτελούνται μέσα στο iframe. |
| Χειριστήρια οθόνης | Trading Widget SDK + 6MM iframe | Η κεφαλίδα ενσωμάτωσης του υπολογιστή και το κάτω σημάδι είναι κρυφά από προεπιλογή. Οι συνεργάτες μπορούν να χρησιμοποιήσουν το `display` για να εμφανίσουν περιοχές κελύφους ή να αποκρύψουν κοντέινερ συναλλαγών υψηλού επιπέδου. |
| Έλεγχος σύνδεσης συνεργάτη | Backend συνεργάτη | Επικυρώστε την περίοδο σύνδεσης χρήστη συνεργάτη πριν από την έκδοση διαπιστευτηρίων ταυτότητας. |
| Ενσωμάτωση έκδοσης διακριτικού | Partner backend + Agent API | Συνιστάται για λειτουργία συνεργάτη. |

## Εκδόσεις

Η δημόσια διαδρομή ενοποίησης παραμένει σταθερή κάτω από το σενάριο v1 URL. Το τρέχον σύνολο δυνατοτήτων v1 περιλαμβάνει διακριτικό συνεργάτη, tokenProvider, entryUrlProvider, στοιχεία ελέγχου οθόνης, συμβάντα κύκλου ζωής, μεθόδους παρουσίας και συμβάντα παραγγελίας.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

## Πότε να χρησιμοποιήσετε το γραφικό στοιχείο

Επιλέξτε Trading Widget όταν ένας συνεργάτης χρειάζεται μια πλήρη διεπαφή συναλλαγών σε ένα υπάρχον προϊόν Ιστού. Χρησιμοποιήστε την τεκμηρίωση REST API και WebSocket κατά τη δημιουργία και τη διατήρηση μιας πλήρως προσαρμοσμένης διεπαφής συναλλαγών.

## Διαδρομή υλοποίησης

1. Ακολουθήστε το [Trading Widget Γρήγορη εκκίνηση](/el/sdk/trading-widget/quick-start) για να φορτώσετε το σενάριο και να δημιουργήσετε ένα ορατό κοντέινερ.
2. Διαμόρφωση [έλεγχος ταυτότητας με διακριτικό συνεργάτη](/el/sdk/trading-widget/authentication) μέσω ενός backend συνεργάτη.
3. Προσθέστε τα απαιτούμενα [επιλογές και εκδηλώσεις](/el/sdk/trading-widget/options-events).
4. Χρήση [μέθοδοι παραδείγματος](/el/sdk/trading-widget/instance-methods) για ελέγχους κύκλου ζωής και χρόνου εκτέλεσης.

## Επαληθευμένος χρόνος δημόσιας εκτέλεσης

Το δημόσιο σενάριο `v1` αναφέρει την έκδοση `1.8.0` από το 2026-10-10. Αυτό το URL είναι ένα σταθερό σημείο εισόδου της κύριας έκδοσης, όχι μια καρφιτσωμένη έκδοση. Διαβάστε τα `TradingWidget.version` και `TradingWidget.capabilities` στον φορτωμένο χρόνο εκτέλεσης πριν χρησιμοποιήσετε τις προαιρετικές δυνατότητες. Java Agent SDK `v0.3.0` είναι ένα ξεχωριστό πακέτο υποστήριξης.

Ο χρόνος εκτέλεσης υποστηρίζει μία μόνο ενεργή παρουσία (`multiInstance=false`). Η δημιουργία ενός άλλου γραφικού στοιχείου καταστρέφει το προηγούμενο παράδειγμα. Οι υποστηριζόμενες τοπικές ρυθμίσεις είναι `en`, `en-US` και `zh-CN`, ανεξάρτητα από τις 20 γλώσσες τεκμηρίωσης.
