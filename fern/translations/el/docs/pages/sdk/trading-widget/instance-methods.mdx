## Περίληψη μεθόδου

| Μέθοδος | Σκοπός |
| --- | --- |
| destroy() | Καταργήστε το iframe και αποδεσμεύστε τα προγράμματα ακρόασης συμβάντων. |
| getState() | Διαβάστε την τρέχουσα SDK κατάσταση του κύκλου ζωής. |
| whenReady() | Περιμένετε μέχρι να ολοκληρωθεί η προετοιμασία του iframe. |
| setSymbol(σύμβολο) | Αλλάξτε το ζεύγος συναλλαγών μέσα στο iframe. |
| setTheme(θέμα) | Ενημερώστε την παράμετρο θέματος iframe. |
| setLocale(τοπικές ρυθμίσεις) | Αλλάξτε τη γλώσσα iframe. |
| setSize(πλάτος, ύψος) | Ενημερώστε τις διαστάσεις του iframe. |
| reload() | Φορτώστε ξανά το τρέχον iframe. |
| refreshAuth(λόγος) | Ενεργοποιήστε τη ροή ανανέωσης ελέγχου ταυτότητας γραφικού στοιχείου. |
| setTokenProvider(πάροχος) | Αντικαταστήστε τον πάροχο που χρησιμοποιείται από τη λειτουργία διακριτικού συνεργάτη. |
| on(συμβάν, χειριστής) | Εγγραφείτε σε συμβάντα χρόνου εκτέλεσης και λάβετε μια λειτουργία κατάργησης εγγραφής. |

<span data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## destroy()

Αφαιρέστε το iframe, διαγράψτε τους ακροατές και εκπέμπετε κατεστραμμένο μία φορά για την τρέχουσα παρουσία.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Διαβάστε την τρέχουσα κατάσταση κύκλου ζωής της παρουσίας του γραφικού στοιχείου.

```js
const state = widget.getState()
```

Οι τιμές επιστροφής περιλαμβάνουν φόρτωση, έλεγχο ταυτότητας, έτοιμο, σφάλμα και καταστροφή.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Περιμένετε μέχρι να ολοκληρωθεί η προετοιμασία του iframe πριν εκτελέσετε την εξαρτώμενη λογική περιβάλλοντος εργασίας χρήστη.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(σύμβολο)

Αλλάξτε το ζεύγος συναλλαγών μέσα στο iframe. Εάν το iframe εξακολουθεί να προετοιμάζεται, το SDK τοποθετεί την εντολή στην ουρά και τη στέλνει αφού είναι έτοιμη.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(θέμα)

Ενημερώστε την παράμετρο θέματος που χρησιμοποιείται από το ενσωματωμένο iframe συναλλαγών.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(τοπικές ρυθμίσεις)

Αλλάξτε τη γλώσσα iframe. Οι υποστηριζόμενες τιμές είναι en, en-US και zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(πλάτος, ύψος)

Ενημερώστε το μέγεθος DOM iframe και ειδοποιήστε το iframe για το νέο εξωτερικό μέγεθος. Οι αριθμητικές τιμές μετατρέπονται σε px.

```js
widget.setSize('100%', 720)
```

<span data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## reload()

Φορτώστε ξανά το τρέχον iframe και περιμένετε να αρχικοποιηθεί ξανά.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(λόγος)

Ζητήστε από το iframe να ανανεώσει την τρέχουσα ροή ελέγχου ταυτότητας. Η προαιρετική τιμή αιτίας προωθείται για την καταγραφή και τον έλεγχο ροής.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(πάροχος)

Αντικαταστήστε το tokenProvider που χρησιμοποιείται από τη λειτουργία partner-token. Το SDK καλεί τον πάροχο όταν το iframe ζητά ένα νέο διακριτικό ενσωμάτωσης.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(συμβάν, χειριστής)

Εγγραφείτε σε ένα συμβάν χρόνου εκτέλεσης. Η επιστρεφόμενη λειτουργία αφαιρεί τον ακροατή.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
