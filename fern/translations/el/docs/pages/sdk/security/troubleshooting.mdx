Ξεκινήστε με το περιβάλλον, τη χρονική σήμανση και το αναγνωριστικό επιχείρησης για την αποτυχημένη λειτουργία. Ένας δομημένος έλεγχος συνήθως διαχωρίζει τα προβλήματα διαμόρφωσης από τα ζητήματα ελέγχου ταυτότητας, δικτύου και ασύγχρονης επεξεργασίας.

<span id="diagnostic-order" data-sixmm-canonical-anchor="diagnostic-order" aria-hidden="true"></span>

## Συνιστώμενη διαγνωστική εντολή

1. Επιβεβαιώστε το επηρεαζόμενο περιβάλλον και τη βάση URL.
2. Καταγράψτε το χρονικό εύρος UTC και το πρώτο αίτημα που αποτυγχάνει.
3. Προσδιορίστε τη λειτουργική μονάδα: Trading Widget, Agent SDK, REST API, WebSocket ή webhook.
4. Καταγράψτε το αναγνωριστικό αιτήματος, το αναγνωριστικό χρήστη συνεργάτη, το `agentOrderNo`, το αναγνωριστικό παραγγελίας ή το αναγνωριστικό συμβάντος webhook.
5. Ελέγξτε τον πρόσφατο κωδικό, τα διαπιστευτήρια, τη λίστα επιτρεπόμενων IP ή τις αλλαγές ανάπτυξης.
6. Αναπαράγετε με τη μικρότερη ασφαλή θήκη δοκιμής.

<span id="trading-widget-issues" data-sixmm-canonical-anchor="trading-widget-issues" aria-hidden="true"></span>

## Trading Widget ζητήματα

| Σύμπτωμα | Πιθανή αιτία | Διορθώνω |
| --- | --- | --- |
| Το iframe ζητά τοπικό τομέα συνεργάτη | Το baseUrl λείπει | Πάσο baseUrl: 'https://app.6mm.com'. |
| Το iframe είναι αόρατο ή πολύ σύντομο | Το μητρικό δοχείο δεν έχει ύψος | Ρυθμίστε το ύψος του δοχείου ή το ύψος διέλευσης. |
| token_provider_missing | Η λειτουργία συμβολικού συνεργάτη δεν έχει πάροχο | Προσθήκη ταυτότητας.tokenProvider. |
| auth_exchange_failed | Μη έγκυρο, ληγμένο ή αναντιστοιχία διακριτικό ενσωμάτωσης | Ελέγξτε την απόκριση διακριτικού υποστήριξης και channelId. |

<span id="agent-sdk-issues" data-sixmm-canonical-anchor="agent-sdk-issues" aria-hidden="true"></span>

## Agent SDK ζητήματα

| Σύμπτωμα | Πιθανή αιτία | Διορθώνω |
| --- | --- | --- |
| Η υπογραφή απορρίφθηκε | Λάθος μυστικό, μετατόπιση ρολογιού ή μη αυτόματα αλλαγμένα υπογεγραμμένα πεδία | Αφήστε το SDK να δημιουργήσει πεδία υπογραφής και να συγχρονίσει τον χρόνο διακομιστή. |
| Διπλότυπος κίνδυνος κίνησης κεφαλαίων | Ο νέος αριθμός παραγγελίας χρησιμοποιήθηκε μετά το χρονικό όριο | Ερώτημα από το αρχικό agentOrderNo πρώτα. |
| PROCESSING αντιμετωπίζεται ως αποτυχία | Η κατάσταση σε εκκρεμότητα παρεξηγήθηκε | Περιμένετε για webhook ή καλέστε queryOrder. |
| Webhook υποβλήθηκε σε επεξεργασία πολλές φορές | Δοκιμάστε ξανά συμπεριφορά χωρίς ανικανότητα | Προσθέστε κλειδί αδυναμίας και ελέγχους τελικής κατάστασης. |

## Αποδεικτικά στοιχεία προς σύλληψη

| Ολοκλήρωση | Χρήσιμα στοιχεία |
| --- | --- |
| Trading Widget | Σελίδα URL, διαδρομή έκδοσης SDK, κονσόλα προγράμματος περιήγησης, αποτυχημένα αιτήματα δικτύου, `onError` ωφέλιμο φορτίο και διαστάσεις κοντέινερ. |
| Agent SDK | SDK γλώσσα/έκδοση, βάση URL, UTC χρονική σήμανση, αναγνωριστικό αιτήματος, `agentOrderNo`, κωδικός απόκρισης και απολυμανμένα αρχεία καταγραφής. |
| Webhook | Χρόνος παράδοσης, κλειδί εκδήλωσης ή επιχείρησης, αποτέλεσμα επικύρωσης υπογραφής, κατάσταση επεξεργασίας και απολυμασμένος κατακερματισμός ακατέργαστου σώματος. |
| REST API | Μέθοδος, διαδρομή, περιβάλλον, αναγνωριστικό αιτήματος, κωδικός απόκρισης και απολυμανμένες παράμετροι. |

Ποτέ μην συμπεριλαμβάνετε κωδικούς πρόσβασης, διακριτικά πρόσβασης, API μυστικά, πλήρεις υπογραφές, ιδιωτικά κλειδιά ή προσωπικά δεδομένα που δεν έχουν διορθωθεί στα διαγνωστικά.

<span id="before-escalating" data-sixmm-canonical-anchor="before-escalating" aria-hidden="true"></span>

## Πριν κλιμακωθεί

- Δοκιμάστε ξανά μόνο όταν η λειτουργία τεκμηριώνεται ως ασφαλής για επανάληψη.
- Μετά από ένα χρονικό όριο, υποβάλετε ερώτημα στο αρχικό αναγνωριστικό επιχείρησης αντί να δημιουργήσετε ένα νέο.
- Επιβεβαιώστε το ρολόι του συστήματος και το περιβάλλον διαπιστευτηρίων για σφάλματα υπογραφής.
- Διατηρήστε την πρώτη αποτυχία και τυχόν μεταγενέστερα αποτελέσματα επανάληψης.
- Χρησιμοποιήστε το [Πρότυπο αιτήματος υποστήριξης](/el/resources/support-request-template) για να στείλετε μια πλήρη, ανανεωμένη αναφορά.

## Java διαγνωστικά v0.3.0

| Σύμπτωμα | Έλεγχος και ανάκτηση |
| --- | --- |
| Το αίτημα χρηματοδότησης έχει άγνωστο αποτέλεσμα | Διατηρήστε το πρωτότυπο `agentOrderNo`. καλέστε `queryWalletTransfer` με το αρχικό περιβάλλον. Μην χρησιμοποιείτε το `queryOrder`. |
| Η διεπαφή χρήστη προσομοίωσης εμφανίζει μη αναμενόμενα κεφάλαια | Ελέγξτε το frontend `tradingMode` ξεχωριστά από το backend `environment`. ο λογαριασμός `isSimulatedUser` δεν δρομολογεί αιτήματα. |
| Σφάλμα ερωτήματος `6905` | Υποχωρήστε χρησιμοποιώντας το κοινόχρηστο όριο συνεργατών και, στη συνέχεια, δοκιμάστε ξανά τον ίδιο δρομέα και φιλτράρετε μέσω του SDK. |
| Σφάλμα ερωτήματος `6904` | Μειώστε τα ταυτόχρονα ερωτήματα και περιορίστε το χρονικό παράθυρο. επικοινωνήστε με την υποστήριξη εάν είναι επίμονη. |
| Μη έγκυρος ή ληγμένος κέρσορας | Επανεκκινήστε το ίδιο σταθερό παράθυρο ιστορικού και αφαιρέστε τις αποθηκευμένες εγγραφές. |
| Λείπει η νέα μέθοδος Java | Ελέγξτε το επιλυμένο τεχνούργημα Maven έναντι της δημόσιας ετικέτας `v0.3.0`. καταργήστε τις αντικρουόμενες εξαρτήσεις σύμφωνα με την πολιτική σας για τα τεχνουργήματα. |
