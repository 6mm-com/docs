Webhooks ειδοποιήστε ένα backend συνεργάτη για ασύγχρονες αλλαγές κατάστασης επιχείρησης. Επειδή η παράδοση μπορεί να επαναληφθεί, κάθε παραλήπτης πρέπει να επαληθεύσει την υπογραφή πριν αναλύσει τα αξιόπιστα δεδομένα και πρέπει να επεξεργαστεί το συμβάν ανεπαρκώς.

<span id="webhook-headers" data-sixmm-canonical-anchor="webhook-headers" aria-hidden="true"></span>

## Webhook κεφαλίδες

| Επί κεφαλής | Περιγραφή |
| --- | --- |
| X-Agent-Timestamp | Unix timestamp σε δευτερόλεπτα. |
| X-Agent-Nonce | Προστασία επανάληψης καμία. |
| X-Agent-Υπογραφή | HMAC-SHA256 υπογραφή. |

```text
timestamp + nonce + rawBody
```

Χρησιμοποιήστε το ακριβές σώμα του πρωτογενούς αιτήματος που ελήφθη πάνω από HTTP κατά την ανακατασκευή της υπογεγραμμένης τιμής. Η ανάλυση και η επανασειριοποίηση του JSON πρώτα μπορεί να αλλάξει τα κενά διαστήματα ή τη σειρά πεδίων και να δημιουργήσει μια διαφορετική υπογραφή.

<span id="verification-flow" data-sixmm-canonical-anchor="verification-flow" aria-hidden="true"></span>

## Ροή επαλήθευσης

1. Διαβάστε τις κεφαλίδες χρονικής σήμανσης, nonce και υπογραφής.
2. Καταγράψτε το μη τροποποιημένο σώμα πρωτογενούς αιτήματος.
3. Κατασκευή `timestamp + nonce + rawBody`.
4. Υπολογίστε το HMAC-SHA256 με τον συνεργάτη API μυστικό.
5. Συγκρίνετε τις υπολογιζόμενες και τις ληφθείσες υπογραφές χρησιμοποιώντας σύγκριση σταθερού χρόνου.
6. Εφαρμόστε τους εγκεκριμένους ελέγχους χρονικής σφραγίδας-φρεσκάδας και μη επαναχρησιμοποίησης.
7. Ανάλυση και επεξεργασία του συμβάντος μόνο μετά την επιτυχία της επαλήθευσης.

Όταν είναι διαθέσιμος ένας επίσημος επαληθευτής Agent SDK, χρησιμοποιήστε τον αντί να διατηρείτε ανεξάρτητο κωδικό υπογραφής.

## Διαταγή ανικανότητας

| Περίπτωση | Χειριζόμενος |
| --- | --- |
| Αρχικό αίτημα μεταφοράς | Δημιουργήστε ένα παγκοσμίως μοναδικό agentOrderNo. |
| HTTP timeout | Ρωτήστε το πρωτότυπο agentOrderNo πριν δημιουργήσετε ένα νέο. |
| PROCESSING απάντηση | Περιμένετε για webhook ή ζητήστε την κατάσταση παραγγελίας. |
| Επαναλαμβανόμενο webhook | Κατάργηση αντιγράφων με κλειδί αδυναμίας και τελική κατάσταση. |

<span id="recommended-idempotency-record" data-sixmm-canonical-anchor="recommended-idempotency-record" aria-hidden="true"></span>

## Συνιστώμενο αρχείο ανικανότητας

Αποθηκεύστε αρκετές πληροφορίες για να αναγνωρίσετε μια επαναλαμβανόμενη παράδοση και να ανακτήσετε με ασφάλεια:

| Πεδίο | Σκοπός |
| --- | --- |
| Κλειδί εκδήλωσης ή επιχείρησης | Προσδιορίζει μοναδικά την ειδοποίηση ή τη λειτουργία. |
| Αριθμός παραγγελίας συνεργάτη | Συνδέει το συμβάν με το αρχικό αίτημα. |
| Κατακερματισμός ωφέλιμου φορτίου | Βοηθά στον εντοπισμό αντικρουόμενων επαναλαμβανόμενων ωφέλιμων φορτίων. |
| Τρέχουσα κατάσταση επεξεργασίας | Διακρίνει τη ληφθείσα, την επεξεργασία, την επιτυχημένη και την αποτυχημένη εργασία. |
| Τελική επιχειρηματική κατάσταση | Αποτρέπει την εφαρμογή μιας τερματικής ενέργειας δύο φορές. |
| Επεξεργασμένη χρονική σήμανση | Υποστηρίζει τις πολιτικές έρευνας και διατήρησης. |

Δεσμεύστε το αρχείο επιχειρηματικής αλλαγής και ανικανότητας στην ίδια συναλλαγή όπου είναι δυνατόν. Ένα επαναλαμβανόμενο συμβάν θα πρέπει να επιστρέψει το ήδη γνωστό αποτέλεσμα αντί να εφαρμόσει ξανά το υπόλοιπο, την παραγγελία ή την αλλαγή χρήστη.

## Κανόνας λήξης χρονικού ορίου και επανάληψης

Ένα χρονικό όριο HTTP δεν αποδεικνύει ότι το αρχικό αίτημα απέτυχε. Υποβάλετε ερώτημα για τη λειτουργία χρησιμοποιώντας το αρχικό `agentOrderNo` ή περιμένετε για το webhook, προτού αποφασίσετε εάν απαιτείται άλλη ενέργεια. Η δημιουργία ενός νέου αριθμού παραγγελίας επιχείρησης μετά από κάθε χρονικό όριο λήξης μπορεί να προκαλέσει διπλές κινήσεις κεφαλαίων.

<span id="production-checklist" data-sixmm-canonical-anchor="production-checklist" aria-hidden="true"></span>

## Λίστα ελέγχου παραγωγής

- Επαληθεύστε την υπογραφή πριν από την JSON ανάλυση ή επιχειρηματική επεξεργασία.
- Διατηρήστε το ακατέργαστο σώμα ανεξάρτητα από το αναλυόμενο ωφέλιμο φορτίο.
- Απόρριψη παλιών ή επαναλαμβανόμενων αιτημάτων σύμφωνα με την εγκεκριμένη πολιτική ενσωμάτωσης.
- Κάντε την επεξεργασία συμβάντων ασφαλή για επαναλαμβανόμενη και εκτός παραγγελίας παράδοση.
- Καταγραφή αναγνωριστικών συμβάντων, αριθμών παραγγελιών συνεργατών, αποτέλεσμα επεξεργασίας και χρόνος αιτήματος.
- Διορθώστε μυστικά και τιμές υπογραφής από αρχεία καταγραφής και υποστήριξη συνημμένων.

## Χρηματοδότηση και περιβαλλοντικά όρια

Η αρχική μεταφορά συμβολαίου webhook και η ροή `queryOrder` δεν ισχύουν αυτόματα για τη χρηματοδότηση. Επιβεβαιώστε τις λειτουργίες χρηματοδότησης χρησιμοποιώντας το `queryWalletTransfer` και το περιβάλλον αρχικής παραγγελίας. Χρήσεις χρηματοδότησης `status`; Οι αρχικές απαντήσεις μεταφοράς συμβολαίου χρησιμοποιήστε `orderStatus`. Μια επιτυχημένη απόκριση HTTP ή `code=0` δεν αποδεικνύει από μόνη της ότι μετακινήθηκαν χρήματα.

Οι ρητές προσομοιωμένες ειδοποιήσεις μεταφοράς συμβολαίου περιλαμβάνουν `environment=SIMULATED`. Επαληθεύστε πρώτα το μη επεξεργασμένο σώμα και, στη συνέχεια, ελέγξτε τον χρήστη, το ποσό, την ταυτότητα παραγγελίας και το περιβάλλον σε σχέση με την αποθηκευμένη τοπική επιχειρηματική παραγγελία.
