Οι εξαιρέσεις μπορεί να περιλαμβάνουν διακοπή τιμών, ασυνεπή στοιχεία τιμών, αποκλίσεις αποδόσεων ή αποτυχημένη επεξεργασία διακανονισμού. Μια εξαίρεση απαιτεί μια καταγεγραμμένη ανάλυση. δεν είναι αυτόματα ένα χαμένο αποτέλεσμα.

<span id="κοινές-καταστάσεις" data-sixmm-anchor-target="common-situations" aria-hidden="true"></span>
<h2 id="common-situations">Κοινές καταστάσεις</h2>

| Κατάσταση | Τι να κάνουμε |
| --- | --- |
| Λείπει η τροφοδοσία πλέγματος κατά το έγκυρο παράθυρο | Ελέγξτε την επεξεργασία εξαίρεσης/επιστροφής χρημάτων. ένα δείγμα που απουσιάζει δεν μπορεί να αποδείξει την έλλειψη |
| Λήξη χρόνου απόκρισης παραγγελίας | Αναζητήστε την αρχική παραγγελία και την κράτηση πριν την υποβάλετε ξανά |
| Η εμφάνιση και το καταγεγραμμένο αποτέλεσμα διαφωνούν | Συγκρίνετε την πηγή τιμής, τις χρονικές σημάνσεις, τους αποδεκτούς όρους και τα στοιχεία αποτελεσμάτων |
| Η διευθέτηση φαίνεται να καθυστερεί | Ελέγξτε την τελική κατάσταση και τη συναλλαγή ξεχωριστά |
| Εγγραφή που επιστράφηκε ή ακυρώθηκε | Ελέγξτε τον λόγο, την πραγματική κίνηση κεφαλαίων και την υπολειπόμενη κράτηση |

<span id="η-επιστροφή-χρημάτων-και-η-ακύρωση-είναι-διακριτά" data-sixmm-anchor-target="refund-and-void-are-distinct" aria-hidden="true"></span>
<h2 id="refund-and-void-are-distinct">Η επιστροφή χρημάτων και η ακύρωση είναι διακριτά</h2>

Η επιστροφή χρημάτων περιγράφει τη θεραπεία του ταμείου. Ένα κενό περιγράφει την ακύρωση μιας παραγγελίας. Μην συνάγετε το ακριβές ποσό επιστροφής χρημάτων ή την προθεσμία επεξεργασίας μόνο από την ετικέτα. χρησιμοποιήστε την καταγεγραμμένη ανάλυση και συναλλαγές.

Οι παραγγελίες που επιστρέφονται και ακυρώνονται εξαιρούνται από το έγκυρο ποντάρισμα στην αναφορά. Οι επιστροφές χρημάτων δεν θα πρέπει να υπολογίζονται ως κερδοφόρες επιστροφές κατά την αξιολόγηση της απόδοσης του παιχνιδιού.

<span id="υποστηρικτικά-στοιχεία" data-sixmm-anchor-target="support-evidence" aria-hidden="true"></span>
<h2 id="support-evidence">Υποστηρικτικά στοιχεία</h2>

Καταχωρίστε τον αριθμό παραγγελίας, τον στρογγυλό αριθμό εάν ισχύει, το σύμβολο, τις σχετικές χρονικές σημάνσεις, τον πολλαπλασιαστή καταγεγραμμένων πληρωμών, το αποτέλεσμα/κατάσταση και τον αριθμό συναλλαγής διακανονισμού. Για διαφωνίες δικτύου, συμπεριλάβετε το αποδεκτό διάστημα τιμών και το έγκυρο χρονικό διάστημα. Μην συμπεριλαμβάνετε ποτέ κωδικούς πρόσβασης, API μυστικά ή διακριτικά πλήρους πρόσβασης.

Χρήση [Υποστήριξη συνεργατών](/el/resources/contact/support) για τη διαδρομή υποστήριξης και [Μεταγραφές και Συναλλαγές](/el/prediction/transfers-ledger) για συμφιλίωση.
