> REST Base URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Ang dokumentasyon na ito ay inilaan para sa mga external system na nag-iintegrate sa 6MM API service. Saklaw nito ang login, JWT authentication, API Key management, API Key HMAC signing, account queries, orders, positions, market data, at WebSocket streams.

Ang pagbibigay ng account at paghahanda ng pondo ay pinangangasiwaan sa pamamagitan ng mga proseso sa tabi ng platform. Ang dokumentasyong ito ay naglalarawan lamang ng mga endpoint ng serbisyo na maaaring tawag API an sa labas.

<h2 id="service-endpoints">Mga Endpoint ng Serbisyo</h2>

| Uri      | Endpoint              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="integration-flow">Daloy ng Integrasyon</h2>

Inirerekomendang pagkakasunod-sunod ng integrasyon:

1. Mag-login gamit ang account na ibinigay ng platform at kumuha ng `accessToken`.
2. Para sa server-side programmatic access, gumawa muna ng API Key gamit ang JWT , at ligtas na itago ang one-time returned `apiSecret`.
3. Ang mga pribadong query, order endpoint, at position endpoint ay maaaring tawagin gamit ang alinman sa `Authorization: Bearer <accessToken>` o API Key signing.
4. Para sa mga private WebSocket stream, gumawa muna ng `listenKey` , pagkatapos ay kumonekta sa `wss://ws.6mm.com/ws?listenKey=...`.
5. Ang market data REST endpoints at public WebSocket channels ay hindi nangangailangan ng authentication.

<h2 id="authentication-choice">Pagpipilian sa Authentication</h2>

| Senaryo                               | Inirerekomendang paraan         |
| -------------------------------------- | -------------------------- |
| Mga aksyon ng frontend user                  | JWT                        |
| Server-side programmatic calls         | API Key + HMAC pirma   |
| API Key paglikha, pag-update, at pagtanggal | JWT                        |
| Pampublikong pamilihan REST / pampublikong WebSocket  | Hindi kailangan ng authentication |

<h2 id="documentation-scope">Saklaw ng Dokumentasyon</h2>

Saklaw ng dokumentasyong ito ang login, JWT authentication, API Key management, API Key HMAC signing, account queries, orders, positions, market data, at WebSocket streams.
