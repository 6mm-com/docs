<h2 id="service-endpoint">Endpoint ng Serbisyo</h2>

```
wss://ws.6mm.com/ws
```

WebSocket mga channel ay nahahati sa mga pampublikong channel at pribadong channel:

| Uri             | Pagpapatunay              | Paglalarawan                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Mga pampublikong channel  | Hindi kinakailangan                | Datos ng merkado, tulad ng depth, trades, Klines, at ticker |
| Pribadong mga channel | `listenKey` o JWT na kinakailangan | Mga daloy ng order ng user, account, at posisyon              |

<h2 id="public-channels">Mga Pampublikong Channel</h2>

Hindi nangangailangan ng authentication ang pampublikong WebSocket . Pagkatapos kumonekta, magpadala ng `subscribe` request para mag-subscribe sa market channels.

Karaniwang mga channel:

| Channel                            | Paglalarawan                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Lalim ng order book. Nagpapadala muna ng snapshot, pagkatapos ay incremental updates |
| `market.trade.{symbol}`            | Pinakabagong mga trade                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Buod ng ticker na may iisang simbolo                                       |
| `market.tickers`                   | Buod ng lahat ng simbolo ng ticker                                          |

<h2 id="private-channels">Mga Pribadong Channel</h2>

<h2 id="listenkey">listenKey</h2>
Para sa mga private WebSocket stream, gumawa muna ng `listenKey` sa REST API , pagkatapos ay kumonekta sa:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
Compatible na paraan ng JWT connection:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Kapag nagtagumpay ang authentication, awtomatikong nag-subscribe ang server sa pribadong channel ng kasalukuyang user. Hindi na kailangan ng manual subscription.
