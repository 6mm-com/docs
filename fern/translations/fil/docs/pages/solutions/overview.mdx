<h2 id="which-path-should-i-choose">Aling landas ang dapat kong piliin?</h2>

| Layunin sa negosyo | Inirerekomendang solusyon | Pangunahing dokumento |
| --- | --- | --- |
| Magdagdag ng trading sa isang umiiral na produkto | Embedded API / SDK Trading System | SDKs, Mga Developer |
| Pagbutihin ang lalim ng merkado at kalidad ng pagpapatupad | Mga Solusyon sa Likididad ng Institusyon | Trading, Mga Developer |

<h2 id="how-the-solutions-connect">Paano nagkakaugnay ang mga solusyon</h2>

Karamihan sa mga partner implementation ay pinagsasama ang higit sa isang 6MM capability. Maaaring gumamit ang white-label exchange ng institutional liquidity, compliance support, at API integrations. Maaaring magsimula ang isang embedded trading partner sa Trading Widget SDK at pagkatapos ay magdagdag ng backend Agent SDK flows, webhook processing, at operational resources.
