6MM suporta ay idinisenyo para sa mga awtorisadong kasosyo, aktibong integrasyon, at mga operasyon ng produksyon. Ang suporta para sa end-user ay nananatiling responsibilidad ng partner platform maliban kung hiwalay na napagkasunduan.

<h2 id="choose-the-right-path">Piliin ang tamang landas</h2>

| Sitwasyon | Inirerekomendang landas | Isama |
| --- | --- | --- |
| Pagsusuri ng bagong pakikipagsosyo o solusyon | Landas ng onboarding ng partner | Uri ng produkto, target na rehiyon, timeline ng paglulunsad, inaasahang integration model. |
| SDK, API, webhook, o tanong tungkol sa kapaligiran | Landas ng teknikal na suporta | Endpoint, SDK bersyon, request ID, mga hakbang sa reproduksyon, mga log. |
| Insidente sa produksyon o bumabagsak na daloy ng kalakalan | Landas ng pag-escalate ng insidente | Saklaw ng epekto, oras ng pagsisimula, mga apektadong user, order IDs, kasalukuyang mitigasyon. |
| Pagbabago ng asset, kopya, o launch material | Landas ng suporta sa operasyon | Pahina, wika, hinihiling na pagbabago, petsa ng paglulunsad, may-ari ng pag-apruba. |
| Kahinaan o pinaghihinalaang pang-aabuso | Landas ng pag-uulat sa seguridad | Teknikal na detalye, apektadong endpoint, ebidensya, agarang pangangailangan, kung aktibo ang isyu. |

<h2 id="severity-guide">Gabay sa tindi</h2>

| Tindi | Halimbawa |
| --- | --- |
| Kritikal | Hindi available ang production trading, authentication, token issuance, o mga daloy na may kaugnayan sa pondo. |
| Mataas | Ang malaking daloy ng partner ay bumababa, pero may paraan para makalusot. |
| Normal | Tanong tungkol sa integrasyon, kahilingan sa konfigurasyon, isyu sa dokumentasyon, o suporta sa planadong paglulunsad. |

<h2 id="before-contacting-support">Bago makipag-ugnayan sa suporta</h2>

- Kumpirmahin ang apektadong lugar ng produkto at kapaligiran.
- Kolektahin ang request IDs, order IDs, timestamps, user mapping IDs, webhook event IDs, at logs.
- Gamitin ang support request template para sa mga isyu sa produksyon.
