Dapat maglaman ang mga security report ng sapat na teknikal na konteksto para masuri ng 6MM team ang epekto at ligtas na maipakita ang isyu.

<h2 id="reportable-issues">Mga isyung maaaring iulat</h2>

- Mga kahinaan sa API, SDK, webhook, authentication, o trading entry flows.
- Kahina-hinalang pag-uugali sa produksyon na maaaring makaapekto sa integridad ng kalakalan o kaligtasan ng gumagamit.
- Pagtagas ng kredensyal o pinaghihinalaang hindi awtorisadong pag-access.
- Mga pattern ng pang-aabuso na maaaring makaapekto sa katatagan ng sistema.

<h2 id="include-in-the-report">Isama sa ulat</h2>

- Apektadong kapaligiran at endpoint.
- Saklaw ng oras at mga hakbang sa reproduksyon.
- Mga log, request IDs, webhook event IDs, o mga screenshot.
- Kung ang isyu ay kasalukuyang aktibo.

<h2 id="safe-reporting-guidelines">Mga patnubay sa ligtas na pag-uulat</h2>

- Huwag ibunyag sa publiko ang isang kahinaan na hindi pa naayos.
- Huwag i-access, i-download, baguhin, o itago ang data lampas sa kinakailangan upang ipakita ang isyu.
- Huwag magsagawa ng denial-of-service, destructive, social-engineering, o fund-movement testing.
- Gumamit ng test accounts at pinakamaliit na ligtas na proof of concept.
- Alisin ang mga password, API secret, access token, private key, at hindi kaugnay na personal na datos mula sa mga attachment.

<h2 id="suggested-report-format">Iminungkahing format ng ulat</h2>

```text
Title:
Affected component and environment:
First observed time (UTC):
Issue status:
Technical description:
Reproduction steps:
Expected security behavior:
Observed behavior:
Potential impact:
Sanitized evidence:
Researcher or partner contact:
```

<h2 id="security-contact">Kontak sa seguridad</h2>

Magpadala ng mga ulat sa kahinaan at agarang seguridad nang pribado sa:

[security@6mm.com] (mailto:security@6mm.com)

Ang mga pangkalahatang problema sa integrasyon ay dapat gumamit ng [Support Request Template](/fil/resources/support-request-template). Dapat ding suriin ng mga mananaliksik ang [Bug Bounty Program](/fil/security-compliance/bug-bounty-program) para sa saklaw at mga inaasahan sa responsableng pagsisiwalat.
