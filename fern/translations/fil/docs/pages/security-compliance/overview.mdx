Ang dokumentasyon sa seguridad at pagsunod ay isinulat para sa mga partner team na naghahanda ng produksyon gamit ang 6MM trading infrastructure. Pinag-uugnay nito ang security architecture, API/SDK controls, paghahanda sa pagsunod, legal na hangganan, at launch readiness sa isang review path.

<h2 id="documentation-map">Mapa ng dokumentasyon</h2>

| Lugar | Layunin |
| --- | --- |
| Arkitektura ng seguridad | Unawain kung paano pinoprotektahan ang trading infrastructure, API/SDK access, at mga operasyon ng partner. |
| Seguridad ng API at Webhook | Protektahan ang backend integrations sa pamamagitan ng signing, secret storage, at idempotent processing. |
| Kahandaan sa pagsunod | Ihanda ang konteksto ng suporta sa lisensya, mga pagsusuri sa paglulunsad, at mga kontrol sa operasyon sa panig ng partner. |
| Mga legal na dokumento | Suriin ang mga termino, privacy, at mga hangganan ng responsibilidad bago ilunsad ang produksyon. |

<h2 id="recommended-reading-order">Inirerekomendang pagkakasunod-sunod ng pagbabasa</h2>

1. Magsimula sa Security Architecture at Partner Responsibility Boundary.
2. Suriin ang API Key Management, Request Signing, at Webhook idempotency bago ang backend integration.
3. Suriin ang Compliance Overview at License Support bago maghanda sa regional launch.
4. Suriin ang mga legal na pahina at ang launch checklist bago ipakita ang trading functionality sa mga user.
