<h2 id="install">I-install</h2>

Sa kasalukuyan, ang pampublikong SDK source ay nagdodokumento ng tag `v0.1.1` ng mga coordinate ng Maven na ito:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

Hindi gumagana ang GitHub bilang Maven dependency repository. I-install ang tagged source nang lokal bago lutasin ang dependency:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Team builds**
>
> I-publish ang aprubadong artifact sa Maven repository ng iyong organisasyon para sa CI, testing, at production builds. Kumpirmahin ang aprubadong bersyon gamit ang 6MM bago ang deployment ng produksyon.

Ang mga halimbawa ng source code at paggamit ay makikita sa opisyal na Java SDK repository:

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

<h2 id="before-you-start">Bago ka magsimula</h2>

- Kumpirmahin ang iyong production Agent API base URL sa 6MM team.
- Itago ang apiSecret sa backend secret management lamang.
- Maghanda ng matatag na mapping sa pagitan ng platformUserId at agentUserId.
- I-enable ang structured logs sa bind, transfer, order, at webhook flows.

<h2 id="initialize-client">I-initialize ang kliyente</h2>

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Backend lamang**
>
> Huwag i-initialize ang Agent SDK mula sa browser, mobile, o desktop client code. Ang SDK ay pumirma ng pribilehiyadong Agent API requests.

<h2 id="example-transfer-funds-in">Halimbawa: maglipat ng pondo sa</h2>

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Gumamit ng natatanging partner-side order number para sa bawat transfer request. Kung mag-time out ang request, i-query ang orihinal na order bago gumawa ng bago.
