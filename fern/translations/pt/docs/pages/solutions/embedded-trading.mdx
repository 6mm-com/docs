O Embedded API / SDK Trading System foi concebido para parceiros que já possuem tráfego, utilizadores ou fluxos de trabalho empresariais e que pretendem adicionar trading sem construir uma exchange completa do zero.

<h2 id="what-it-provides">O que oferece</h2>

- Terminal de negociação embutido através do Trading Widget SDK
- Integração backend de parceiros através de Agent SDKs
- Ligação de identidade do utilizador e fluxos de tokens de entrada
- Transferência de ativos, ordens, posições e acesso API conta
- Integração de eventos, webhooks e ciclos de vida para sistemas operacionais

<h2 id="recommended-architecture">Arquitetura recomendada</h2>

| Camada | Responsabilidade |
| --- | --- |
| Frontend parceiro | Aloja o ponto de entrada e incorpora a interface de negociação 6MM . |
| Backend parceiro | Mantém API segredos, valida utilizadores, emite tokens de incorporação e processa webhooks. |
| 6MM infraestrutura de negociação | Trata da interface de negociação, emparelhamento, risco, liquidez, estado da conta e ciclo de vida da negociação. |

<h2 id="choose-an-integration-path">Escolha um caminho de integração</h2>

| Requisito | Percurso recomendado |
| --- | --- |
| Interface completa de negociação com a integração web mais rápida | Trading Widget |
| Ligação de utilizadores backend, transferência, URLde entrada e gestão de webhooks | Agent SDK |
| Fluxos de trabalho totalmente personalizados de produtos e encomendas | REST API + WebSocket |
| Experiência em trocas de marca com um âmbito operacional mais amplo | Troca de marca branca |

O design final pode combinar estes caminhos. Confirme autenticação, propriedade dos ativos, limites de responsabilidade, monitorização e suporte à produção antes do início da implementação.
