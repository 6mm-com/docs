<h2 id="responsibility-split">Divisão de responsabilidades</h2>

| Área | Proprietário | Notas |
| --- | --- | --- |
| Criação de contentores | Frontend parceiro | Fornecer um elemento visível com largura e altura explícitas. |
| Criação de iframe | Trading Widget SDK | O SDK cria e gere o iframe. |
| UI de Negociação | 6MM iframe | K-line, livro de encomendas, formulário de encomendas, posições, ordens e dados de conta são executados dentro do iframe. |
| Controlos de ecrã | Trading Widget SDK + 6MM iframe | O cabeçalho e o ticker inferior do PC embed estão ocultos por defeito. Os parceiros podem usar `display` para mostrar áreas de concha ou esconder contentores de troca de alto nível. |
| Verificação do login do parceiro | Backend parceiro | Valide a sessão do utilizador parceiro antes de emitir credenciais de autenticação. |
| Emissão de token embeded | Backend parceiro + Agente API | Recomendado para o modo de tokens de parceiro. |

<h2 id="versioning">Versionamento</h2>

O caminho de integração pública mantém-se estável sob o script v1 URL. O conjunto atual de capacidades v1 inclui partner-token, tokenProvider, entryUrlProvider, controlos de exibição, eventos do ciclo de vida, métodos de instância e eventos de ordem.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Quando usar o widget</h2>

Escolha Trading Widget quando um parceiro precisa de uma interface de negociação completa dentro de um produto web existente. Use antes a documentação REST API e WebSocket ao construir e manter uma interface de trading totalmente personalizada.

<h2 id="implementation-path">Caminho de implementação</h2>

1. Siga o [Trading Widget Quick Start](/pt/sdk/trading-widget/quick-start) para carregar o script e criar um contentor visível.
2. Configurar [autenticação de token de parceiro](/pt/sdk/trading-widget/authentication) através de um backend de parceiro.
3. Adicionar as [opções e eventos](/pt/sdk/trading-widget/options-events).
4. Utilizar [métodos de instância](/pt/sdk/trading-widget/instance-methods) para controlos do ciclo de vida e de execução.
