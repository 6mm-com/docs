<h2 id="options">Opções</h2>

| Campo | Tipo | Padrão | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origem da escrita | Domínio iFrame. Passe explicitamente nas páginas parceiras. |
| Símbolo | string | BTCUSDT | Normalizado para maiúsculas e tiras - / _. |
| Tema | escuro \| luz | escuro | Parâmetro inicial do tema. |
| Localização | en \| en-US \| zh-CN | Navegador/padrão | São suportados o inglês e o chinês simplificado. |
| Disposição | padrão \| compacto | Padrão | Opção de layout reservado. |
| Ecrã | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Os controlos incorporam áreas de concha e contentores de comércio de alto nível. |
| Auth | object | nenhum | Use partner-token para novas integrações SSO . |

<h2 id="display-controls">Controlos de ecrã</h2>

`display` controla a shell embutida da página de trading e os contentores de alto nível. Nos embeds parceiros, o cabeçalho do PC e o ticker de mercado inferior estão ocultos por defeito.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Padrão | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | falso | Se deve mostrar o cabeçalho embed do PC dentro do iframe. |
| showTicker | boolean | falso | Se deve mostrar o ticker inferior do mercado na concha embed. |
| Escondido | string[] | [] | Esconde contentores de alto nível na página de troca. |

Valores `display.hidden` apoiados:

| Valor | Contentor |
| --- | --- |
| Tabela | Contentor de cartas |
| orderBook | Recipiente do livro de encomendas |
| orderForm | Painel de formulários de encomenda |
| Posições | Posições mais baixas e painel de ordens abertas |
| Conta | Contentor de ativos da conta |

`display.hidden` esconde apenas recipientes inteiros. Não esconde botões, campos ou ferramentas individuais dentro de um contentor. Os valores que não correspondem à viewport atual são ignorados.

<h2 id="events">Eventos</h2>

| Evento | Gatilho |
| --- | --- |
| Pronto | Inicialização do iframe concluída. |
| erro | SDK, iframe ou erro de autenticação. |
| state_changed | SDK estado do ciclo de vida mudou. |
| auth_state_changed | O estado de autenticação do token parceiro mudou. |
| symbol_changed | O símbolo real do iframe mudou. |
| locale_changed | A localização real do iframe mudou. |
| order_created | O utilizador criou uma ordem dentro do iframe. |
| order_failed | Submissão da encomenda falhada. |
| destruído | SDK instância destruída. |
