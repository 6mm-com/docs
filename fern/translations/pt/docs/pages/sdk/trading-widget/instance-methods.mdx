<h2 id="method-summary">Resumo do Método</h2>

| Método | Finalidade |
| --- | --- |
| destruir() | Remova o iframe e liberte os ouvintes do evento. |
| getState() | Leia o estado atual do ciclo de vida SDK . |
| whenReady() | Espere até o iframe terminar a inicialização. |
| setSymbol(símbolo) | Troca o par de negociação dentro do iframe. |
| setTheme(tema) | Atualize o parâmetro do tema do iframe. |
| setLocale(local) | Muda a linguagem do iframe. |
| setSize(largura, altura) | Atualizar as dimensões do iframe. |
| reload() | Recarregue o iframe atual. |
| refreshAuth(razão) | Ativar o fluxo de atualização da autenticação do widget. |
| setTokenProvider(fornecedor) | Substitua o fornecedor usado pelo modo partner-token. |
| ligado (evento, handler) | Subscreva eventos em tempo de execução e receba uma função de cancelar subscrição. |

<h2 id="destroy">destruir()</h2>

Remove o iframe, limpa os ouvintes e emite destruído uma vez para a instância atual.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Leia o estado atual do ciclo de vida da instância do widget.

```js
const state = widget.getState()
```

Os valores de retorno incluem carregar, autenticar, preparar, erro e destruir.

<h2 id="whenready">whenReady()</h2>

Espera que o iframe termine a inicialização antes de executar a lógica dependente da interface.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(símbolo)</h2>

Troca o par de negociação dentro do iframe. Se o iframe ainda estiver a inicializar, o SDK coloca o comando em fila e envia-o depois de ready.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(tema)</h2>

Atualize o parâmetro de tema usado pelo iframe de negociação embutido.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(local)</h2>

Muda a linguagem do iframe. Os valores suportados são en, en-US e zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(largura, altura)</h2>

Atualiza o iframe DOM tamanho e notifica o iframe sobre o novo tamanho exterior. Os valores numéricos são convertidos para px.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">reload()</h2>

Recarrego o iframe atual e espera que ele se inicialize novamente.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(razão)</h2>

Pede ao iframe para atualizar o fluxo de autenticação atual. O valor opcional da razão é encaminhado para registo e controlo de fluxo.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(fornecedor)</h2>

Substitua a tokenProvider usada pelo modo partner-token. O SDK liga ao fornecedor quando o iframe solicita um token de embed novo.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">ligado (evento, handler)</h2>

Subscreva um evento em tempo real. A função devolvida remove o ouvinte.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
