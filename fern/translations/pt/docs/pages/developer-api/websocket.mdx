<h2 id="service-endpoint">Service Endpoint</h2>

```
wss://ws.6mm.com/ws
```

WebSocket canais dividem-se em canais públicos e canais privados:

| Tipo             | Autenticação              | Descrição                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Canais públicos  | Não é obrigatório                | Dados de mercado, como profundidade, transações, Klines e ticker |
| Canais privados | `listenKey` ou JWT obrigatório | Fluxos de ordem, conta e posição dos utilizadores              |

<h2 id="public-channels">Canais Públicos</h2>

A WebSocket pública não requer autenticação. Após a ligação, envie um pedido de `subscribe` para subscrever os canais de mercado.

Canais comuns:

| Canal                            | Descrição                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Profundidade do livro de encomendas. Envia primeiro um snapshot, depois atualizações incrementais |
| `market.trade.{symbol}`            | Últimas transações                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Resumo do ticker de símbolo único                                       |
| `market.tickers`                   | Resumo do ticker de todos os símbolos                                          |

<h2 id="private-channels">Canais Privados</h2>

<h2 id="listenkey">listenKey</h2>
Para streams de WebSocket privados, crie primeiro um `listenKey` através do REST API e depois ligue-se a:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
Método de ligação JWT compatível:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Após a autenticação bem-sucedida, o servidor subscreve automaticamente a ligação ao canal privado do utilizador atual. Não é necessária subscrição manual.
