When contacting support, include the information below whenever available.

<h2 id="required-context">Required context</h2>

| Field | Example |
| --- | --- |
| Environment | Production or staging |
| Affected module | Trading Widget, Agent SDK, REST API, WebSocket, webhook, white-label system |
| Time range | UTC timestamp range when the issue occurred |
| Partner user ID | Partner-side user identifier, if relevant |
| 6MM mapping ID | agentUserId, order ID, request ID, or webhook event ID |
| Business impact | Number of affected users or operations and whether the issue is ongoing |

<h2 id="description-format">Description format</h2>

- What happened?
- What did you expect to happen?
- Can it be reproduced?
- What changed recently?
- Is the issue still happening?

<h2 id="attachments">Attachments</h2>

- Relevant request and response logs.
- Screenshots or screen recordings.
- Webhook payload and signature headers.
- Browser console errors for Trading Widget issues.

<h2 id="copyable-template">Copyable template</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Remove fields that are not relevant, but keep the UTC time range and at least one searchable request or business identifier whenever possible.

<h2 id="redact-sensitive-data">Redact sensitive data</h2>

Do not send:

- Passwords or full access tokens
- API secrets, private keys, or complete signatures
- Session cookies
- Full payment, identity, or other unnecessary personal data

Keep the field name and a short prefix or suffix only when support needs to distinguish between sanitized values.

<h2 id="choose-the-right-channel">Choose the right channel</h2>

| Issue | Next page |
| --- | --- |
| Integration or production problem | [Support](/en-142/resources/contact/support) |
| SDK issue that still needs diagnosis | [SDK Integration Troubleshooting](/en-142/sdk/security/troubleshooting) |
| Vulnerability or suspected unauthorized access | [Security Reporting](/en-142/resources/support/security-reporting) |
| Responsible vulnerability disclosure | [Bug Bounty Program](/en-142/security-compliance/bug-bounty-program) |
