6MMticarət imkanlarını real istifadəçilərə təqdim etməzdən əvvəl bu yoxlama siyahısından istifadə edin.

<h2 id="integration-readiness">İnteqrasiya hazırlığı</h2>

- İstehsal domenləri və yönləndirmə yolları təsdiqləndi.
- Trading Widget, Agent SDK, APIvə ya WebSocket axınları başdan sona test olunub.
- Tərəfdaş backend bütün sirləri server tərəfində saxlayır.
- Webhook qəbulu, imza təsdiqi, təkrar cəhd idarəetməsi və idempotensiya aktivdir.
- Qeydlərə sorğu ID-ləri, istifadəçi xəritələşdirmə ID-ləri, sifariş ID-ləri və vaxt möhürləri daxildir.

<h2 id="product-and-resource-readiness">Məhsul və resurs hazırlığı</h2>

- Giriş nöqtələri, bannerlər və kart aktivləri təsdiqlənmiş dil versiyasından istifadə edir.
- Ağ etiketli aktivlər yalnız əməkdaşlıq razılaşması icazə verdikdə istifadə olunur.
- İstifadəçiyə yönəlmiş risk sorğuları və ticarət giriş nüsxələri tərəfdaş komanda tərəfindən nəzərdən keçirilir.
- Dəstək və eskalasiya sahibləri təyin olunur.

<h2 id="operational-readiness">Əməliyyat hazırlığı</h2>

- Monitorinq API səhvlərini, token buraxılışını, widget ilkinləşdirməsini, webhook uğursuzluqlarını və sifariş həyat dövrü hadisələrini əhatə edir.
- Təcili əlaqə yolları təsdiqləndi.
- Ticarət girişi üçün geri qaytarma və ya müvəqqəti əlillik planı hazırlanır.

<h2 id="security-and-compliance-readiness">Təhlükəsizlik və uyğunluq hazırlığı</h2>

- API açarlar minimum icazələrdən və təsdiqlənmiş IP məhdudiyyətlərindən istifadə edir.
- Sertifikat rotasiyası və ləğv edilməsi sınaqdan keçirilib.
- Webhook imzaları xam sorğu bədənlərinə qarşı yoxlanılır.
- İstifadəçi açıqlamaları, risk bildirişləri, məsuliyyət sərhədləri və hədəf bazar icmalı tamamlanıb.
- Hadisə, barışıq və dəstək sübutları sirləri ifşa etmədən əldə edilə bilər.
