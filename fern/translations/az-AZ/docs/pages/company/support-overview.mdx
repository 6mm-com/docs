6MM dəstəyi səlahiyyətli tərəfdaşlar, aktiv inteqrasiyalar və istehsal əməliyyatları üçün nəzərdə tutulub. Son istifadəçi dəstəyi tərəfdaş platformasının məsuliyyəti olaraq qalır, əgər ayrıca razılaşdırılmayıbsa.

<h2 id="choose-the-right-path">Düzgün yolu seçin</h2>

| Vəziyyət | Tövsiyə olunan yol | Daxil |
| --- | --- | --- |
| Yeni tərəfdaşlıq və ya həll qiymətləndirilməsi | Tərəfdaşın işə qəbul yolu | Məhsul növü, hədəf region, buraxılış vaxtı, gözlənilən inteqrasiya modeli. |
| SDK, API, webhook və ya mühit sualı | Texniki dəstək yolu | Son nöqtə, SDK versiyası, sorğu ID, reproduksiya addımları, loglar. |
| İstehsal hadisəsi və ya ticarət axının pisləşməsi | Hadisə eskalasiyası yolu | Təsir sahəsi, başlama vaxtı, təsirlənmiş istifadəçilər, sifariş ID-ləri, cari azaldılması. |
| Aktiv, surət və ya buraxılış materialının dəyişməsi | Əməliyyat dəstək yolu | Səhifə, dil, tələb olunan dəyişiklik, buraxılış tarixi, təsdiq sahibi. |
| Həssaslıq və ya şübhəli zorakılıq | Təhlükəsizlik hesabatı yolu | Texniki detallar, təsirlənmiş son nöqtə, sübutlar, təcililik, məsələnin aktiv olub-olmaması. |

<h2 id="severity-guide">Şiddət bələdçisi</h2>

| Şiddəti | Nümunə |
| --- | --- |
| Tənqidi | İstehsal ticarəti, autentifikasiya, token buraxılışı və ya fondlarla bağlı axınlar əlçatan deyil. |
| Yüksək | Əsas tərəfdaş axını zəifləyir, amma bir həll yolu mövcuddur. |
| Normal | İnteqrasiya sualı, konfiqurasiya sorğusu, sənədləşmə problemi və ya planlaşdırılmış buraxılış dəstəyi. |

<h2 id="before-contacting-support">Dəstəyə müraciət etməzdən əvvəl</h2>

- Təsirlənmiş məhsul sahəsi və mühitini təsdiqləyin.
- Sorğu ID-ləri, sifariş ID-ləri, vaxt möhürləri, istifadəçi xəritələşdirmə ID-ləri, webhook hadisə ID-ləri və logları toplayın.
- İstehsal problemləri üçün dəstək sorğusu şablonundan istifadə edin.
