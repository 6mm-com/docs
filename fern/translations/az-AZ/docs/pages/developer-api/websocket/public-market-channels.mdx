Tətbiqin davamlı yenilənən qiymətlərə, ticarətlərə, şamdanlara və ya sifariş kitabının dərinliyinə ehtiyacı olduqda, REST son nöqtələri təkrar-təkrar sorğu etmədən ictimai bazar kanallarından istifadə edin. Bu axınlar ticarət ekranlarını, qiymət göstəricilərini, xəbərdarlıqları və bazar monitorinqini dəstəkləyə bilər.

<h2 id="connection-url">Əlaqə URL</h2>

```
wss://ws.6mm.com/ws
```

İctimai WebSocket autentifikasiya tələb etmir.

Bağlantının həyat dövrü, abunəlikdən çıxma, ping və yenidən qoşulma davranışı üçün [Connection, Subscription & Heartbeat](/az-AZ/developer-api/websocket/connection-subscription-and-heartbeat) bölməsinə baxın.

<h2 id="common-channels">Ümumi Kanallar</h2>

| Kanal                            | Təsvir                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Kitab dərinliyini sifariş edin. Əvvəlcə snapshot göndərir, sonra tədricən yeniləmələr |
| `market.trade.{symbol}`            | Son transferlər                                                      |
| `market.kline.{symbol}.{interval}` | Klines-lər                                                             |
| `market.ticker.{symbol}`           | Tək simvollu ticker xülasəsi                                       |
| `market.tickers`                   | Bütün simvollar üzrə ticker xülasəsi                                          |

<h2 id="choose-a-channel">Kanal seçin</h2>

| Tətbiq ehtiyacı | Kanal |
| --- | --- |
| Sifariş kitabını yaratmaq və ya saxlamaq | `market.depth.{symbol}` |
| Canlı ticarət yayımını göstərin | `market.trade.{symbol}` |
| Şam cədvəli çək | `market.kline.{symbol}.{interval}` |
| Bir bazar xülasəsini göstər | `market.ticker.{symbol}` |
| Bazar icmalını saxlayın | `market.tickers` |

<h2 id="subscription-example">Abunə nümunəsi</h2>

```json
{ "id": "1772007814666", "op": "subscribe", "args": ["market.depth.BTCUSDT"] }
```

<h2 id="push-message-wrapper">Push Message Wrapper</h2>

```json
{
  "topic": "market.depth.BTCUSDT",
  "event": "data",
  "ts": 1772007815000,
  "data": {}
}
```

Hər mesajı düzgün idarəediciyə yönləndirmək üçün `topic` istifadə edin və çatdırılma vaxtını müşahidə `ts` . `data` obyekti abunə olmuş kanalın yükünü ehtiva edir.

<h2 id="order-book-handling">Sifariş kitabının idarə olunması</h2>

Dərinlik kanalı əvvəlcə snapshot göndərir, sonra isə tədrici yeniləmələr göndərir. Yeniləmələri tətbiq etməzdən əvvəl snapshot-dan lokal kitabı işə salın. Yenidən qoşulduqdan sonra yeni sessiya yaradın, yenidən abunə olun və yaddaşda köhnəlmiş vəziyyətdən davam etmək əvəzinə növbəti snapshot-dan yerli kitabı yenidən qurun.

<h2 id="production-recommendations">İstehsal tövsiyələri</h2>

- Hər abunəlik, abunəlikdən çıxma və ping sorğusu üçün unikal `id` yaradın.
- Kanalı aktiv hesab etməzdən əvvəl abunə təsdiqləməsini təsdiqləyin.
- Yenidən qoşulduqdan sonra bütün tələb olunan mövzulara yenidən abunə olun.
- Şəbəkə oxunuşlarını yavaş verilənlər bazası və ya UI emalından ayrı saxlamaq.
- Bağlantı kəsilmə tezliyini, mesaj işləmə gecikməsini və səhv formalaşdırılmış yükləri izləyin.
- Autentifikasiya olunmuş hesab və sifariş yeniləmələri üçün [Şəxsi İstifadəçi Kanalı](/az-AZ/developer-api/websocket/private-user-channel) istifadə edin.
