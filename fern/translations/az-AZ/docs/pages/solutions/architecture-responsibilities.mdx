Təmiz gömülü ticarət başlanğıcı aydın məsuliyyət sərhədlərinə əsaslanır. Tərəfdaş sistemlər həssas biznes mülkiyyətini saxlamalı, 6MM isə ticarət infrastrukturunu və həyat dövrü imkanlarını təmin etməlidir.

<h2 id="responsibility-model">Məsuliyyət modeli</h2>

| Ərazi | Tərəfdaş sistemi | 6MM infrastrukturu |
| --- | --- | --- |
| İstifadəçi əlaqəsi | İstifadəçi hesabına, giriş vəziyyətinə, müştəri dəstəyi şəxsiyyətinə və uyğunluq yoxlamalarına sahibdir. | Təsdiqlənmiş ticarət giriş kontekstini qəbul edir və ticarət tərəfi vəziyyətini saxlayır. |
| Sirlər və imzalama | Mağazalar backenddə API açarları tərəfdaş edir və server tərəfi sorğularını imzalayır. | İmzalanmış sorğuları yoxlayır və səlahiyyətli əməliyyatları emal edir. |
| Ticarət təcrübəsi | Giriş nöqtələri, naviqasiya və məhsul konteksti təqdim edir. | Ticarət istifadəçi interfeysi, sifariş həyat dövrü, bazar məlumatları, mövqelər, risk və hesablaşma davranışı təqdim edir. |
| Əməliyyatlar | Dəstək iş axınları, biznes analitikası və daxili eskalasiya işlərini idarə edir. | İnteqrasiya üçün lazım olan hadisələri, veb hookları və status məlumatlarını yayımlayır. |

<h2 id="production-principles">İstehsal prinsipləri</h2>

- Bütün tərəfdaş sirlərini arxa planda saxla.
- Embed tokenlərini qısaömürlü giriş etimadnamələri kimi qəbul edin.
- Webhook-ları idempotiv şəkildə emal etmək və hadisə ID-lərini saxlamaq.
- Token buraxılışı, transfer axınları və sifariş-vəziyyət dəyişiklikləri ətrafında monitorinqdən istifadə edin.
- Müştəriyə yönəlmiş mətnləri giriş, ticarət və dəstək səhifələrində ardıcıl saxlayın.
