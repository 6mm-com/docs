Embedded ticarət adətən mövcud məhsula daxil edilir, müstəqil bir təyinat kimi işə salınmır. Ən yaxşı inteqrasiya yolu istifadəçilərin artıq harada vaxt keçirdiyinə və hansı sistemin şəxsiyyətə, fondlara və əməliyyatlara sahib olduğuna bağlıdır.

<h2 id="common-scenarios">Ümumi ssenarilər</h2>

| Ssenari | Ən yaxşı başlanğıc nöqtəsi | Qeydlər |
| --- | --- | --- |
| Tətbiq və ya cüzdan ticarət girişi istəyir | Trading Widget SDK | İstifadəçi icazəsindən sonra yerli və ya H5 giriş nöqtəsi istifadə edin və daxili ticarət təcrübəsini açın. |
| Broker və ya kanal platforması törəmə alətlərə çıxış istəyir | Agent SDK + Trading Widget SDK | Müştəri əlaqələrini və arxa plan təsdiqini tərəfdaş sistemində saxlayın. |
| Platforma idarə olunan ticarət axını istəyir | API + seçilmiş SDK modulları | Hesab, ötürmə və sifariş iş axınları üçün backend APIs istifadə edin və yalnız lazım olan frontend girişini açıqlayın. |
| Mövcud birja əlavə bazarlar istəyir | Likvidlik + API inteqrasiyası | Bazar dərinliyini, hesab iş axınlarını və əməliyyat monitorinqini birləşdirin. |

<h2 id="product-decisions-before-integration">İnteqrasiyadan əvvəl məhsul qərarları</h2>

- İstifadəçilərin giriş üçün ana səhifə kartından, aktiv səhifəsindən, kampaniya səhifəsindən və ya hesab mərkəzindən daxil olub-olmadığını müəyyən etmək.
- Hansı sistemin giriş vəziyyətinə, istifadəçi uyğunluğuna və ölkə və ya regionun mövcudluğuna sahib olduğunu müəyyən etmək.
- Köçürmələrin, hesablaşma qeydlərinin və müştəri dəstəyi biletlərinin istifadəçilərə necə göstəriləcəyinə qərar vermək.
- Hansı hadisələrin daxili analitika, CRMvə ya risk əməliyyatlarına yönləndirilməli olduğuna qərar vermək.
