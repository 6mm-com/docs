<h2 id="method-summary">Metodun xülasəsi</h2>

| Metod | Məqsəd |
| --- | --- |
| məhv et() | iframe-i silin və tədbir dinləyicilərini buraxın. |
| getState() | Cari SDK həyat dövrü vəziyyətini oxuyun. |
| whenReady() | iframe ilkinləşdirməni bitirənə qədər gözləyin. |
| setSymbol(simvol) | iframe daxilində ticarət cütlüyünü dəyişin. |
| setTheme(mövzu) | iframe tema parametrini yeniləyin. |
| setLocale(məkan) | iframe dilini dəyişin. |
| setSize(en, hündürlük) | iframe ölçülərini yenilə. |
| reload() | Cari iframe-i yenidən yükləyin. |
| refreshAuth(səbəb) | Widget autentifikasiya yeniləmə axınını işə sal. |
| setTokenProvider(təminatçı) | Tərəfdaş-token rejimində istifadə olunan provayderi əvəz edin. |
| On(Event, Handler) | İcra tədbirlərinə abunə olun və abunəlikdən çıxma funksiyası alın. |

<h2 id="destroy">məhv et()</h2>

iframe-i çıxarın, dinləyiciləri təmizləyin və cari instansiya üçün bir dəfə məhv edilmiş emissiya.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Widget nümunəsinin cari həyat dövrü vəziyyətini oxuyun.

```js
const state = widget.getState()
```

Qaytarma dəyərlərinə loading, authentication, ready, error və destroy daxildir.

<h2 id="whenready">whenReady()</h2>

Dependent UI Logic-i işə salmazdan əvvəl iframe-in ilkinləşməsini bitirməsini gözləyin.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(simvol)</h2>

Ticarət cütünü iframe daxilində dəyişin. Əgər iframe hələ də işə düşürsə, SDK əmri növbəyə qoyur və hazır olduqdan sonra göndərir.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(mövzu)</h2>

Yerləşdirilmiş ticarət iframe üçün istifadə olunan tema parametrini yeniləyin.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(məkan)</h2>

iframe dilini dəyişin. Dəstəklənən dəyərlər en, en-US və zh-CN-dir.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(en, hündürlük)</h2>

iframe DOM ölçüsünü yeniləyin və iframe-ə yeni xarici ölçü barədə məlumat verin. Rəqəmsal dəyərlər px formatına çevrilir.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">reload()</h2>

Cari iframe-i yenidən yükləyin və yenidən işə düşməsini gözləyin.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(səbəb)</h2>

iframe-dən cari autentifikasiya axınını yeniləməsini xahiş edin. Əlavə səbəb dəyəri qeyd və axın idarəetməsi üçün yönləndirilir.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(təminatçı)</h2>

Tərəfdaş-token rejimində istifadə olunan tokenProvider əvəz edin. iframe yeni embed token tələb etdikdə SDK provayderə zəng edir.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">On(Event, Handler)</h2>

İcra hadisəsinə abunə olun. Qaytarılan funksiya dinləyicini çıxarır.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
