<h2 id="recommended-combination">Tövsiyə olunan kombinasiya</h2>

| Tərəfdaş məqsədi | Ön hissə | Backend | Niyə önəmlidir |
| --- | --- | --- | --- |
| Daxili ticarət terminalı əlavə edin | Trading Widget SDK | Agent SDK | Widget ticarət interfeysini idarə edir, tərəfdaş backend isə tokenlər buraxır və sirləri gizli saxlayır. |
| Yerli tətbiq giriş nöqtəsi yaradın | Native və ya H5 girişi | Agent SDK | Tətbiq tərəfdaş istifadəçi sessiyasını təsdiqlədikdən URL 6MM giriş açır. |
| Xüsusi ticarət axını yaradın | Tərəfdaş UI | İnkişaf etdirici API + seçilmiş SDK axınları | Hesab, sifariş, mövqe və bazar məlumatları üçün APIs istifadə edin, əməliyyat nəzarətlərini server tərəfində saxlayın. |

<h2 id="reference-architecture">İstinad arxitekturası</h2>

```text
Partner Web App
  -> TradingWidget.create()
  -> tokenProvider()
  -> Partner Backend
  -> 6MM Agent SDK
  -> 6MM Agent API
  -> 6MM Trading iframe
```

> **Server tərəfində sirləri saxla**
>
> Brauzer kodu yalnız tərəfdaşlara məxsus son nöqtələri çağırmalıdır. Agent API sirri heç vaxt frontend koduna göndərilməməlidir.

<h2 id="production-checklist">İstehsal yoxlama siyahısı</h2>

- apiSecret yalnız arxa plan infrastrukturunda saxlayın.
- Agent API sorğuları və webhook URL-ləri üçün HTTPS istifadə edin.
- Davamlı agentUserId, platformUserIdvə agentOrderNo xəritələmələri.
- Pul məbləğlərini onluq sətirlər şəklində göstərmək, üzən nöqtə dəyərləri əvəzinə.
- PROCESSING uğur və ya uğursuzluq kimi yox, gözləmədə kimi qəbul edin.
- Webhook-ları idempotiv şəkildə işləyin, çünki təkrar cəhdlər gözlənilir.
