<h2 id="recommended-reading-order">Tövsiyə olunan oxu ardıcıllığı</h2>

1. Təhlükəsizlik Arxitekturası və Tərəfdaş Məsuliyyəti Sərhədi ilə başlayın.
2. Backend inteqrasiyasından əvvəl API Key İdarəetmə, Sorğu İmzalanması və Webhook idempotensiyasını nəzərdən keçirin.
3. Regional buraxılışa hazırlıqdan əvvəl Uyğunluq İcmalı və Lisenziya Dəstəyini nəzərdən keçirin.
4. İstifadəçilərə ticarət funksionallığını təqdim etməzdən əvvəl hüquqi səhifələri və işə salma siyahısını nəzərdən keçirin.
