6MM səlahiyyətli tərəfdaşlar üçün texnoloji infrastruktur və uyğunluq yönümlü dəstək təmin edir. Uyğunluq tələbləri yurisdiksiya və biznes modelinə görə dəyişir, buna görə hər buraxılış tərəfdaşın öz öhdəlikləri ilə nəzərdən keçirilməlidir.

<h2 id="what-this-section-covers">Bu bölmə nələri əhatə edir</h2>

| Ərazi | Təsvir |
| --- | --- |
| Lisenziya dəstəyi | Dəstəklənən lisenziya yolları və tələb olunan hazırlıq materialları ilə bağlı təlimatlar. |
| Tərəfdaş öhdəlikləri | İstifadəçi onboarding, açıqlamalar, yerli uyğunluq nəzarətləri və müştəri əlaqələrinin idarə olunması. |
| Texniki idarəetmələr | İmzalama, qeydiyyat, giriş nəzarəti, veb hook yoxlaması və istehsalın monitorinqi. |
| Buraxılış icmalı | İstifadəçilərə ticarət funksionallığını təqdim etməzdən əvvəl yoxlama siyahısı əsaslı təsdiq. |

<h2 id="important-boundary">Əhəmiyyətli sərhəd</h2>

6MM sənədləri tərəfdaşlara texniki və əməliyyat nəzarətlərini hazırlamağa kömək edir. Bu, hüquqi məsləhət, yurisdiksiyaya xas uyğunluq yoxlaması və tərəfdaşın öz tənzimləyici öhdəliklərini əvəz etmir.

<h2 id="information-to-prepare">Hazırlamaq üçün məlumat</h2>

Uyğunluq və ya buraxılış yoxlamasından əvvəl sənədləri sənədləşdirin:

- Hədəf ölkələr və ya regionlar və giriş əldə edəcək istifadəçi növləri.
- Məhsul əhatə dairəsi, o cümlədən daxili ticarət, ağ etiketli çatdırılma, likvidlik, cüzdan, saxlanma və ya brokerlik xüsusiyyətləri.
- İstifadəçi qeydiyyatı, şəxsiyyət yoxlamaları, açıqlamalar, mühafizə, dəstək və hadisə ilə əlaqəyə cavabdeh olan qurum.
- Tərəfdaş frontend, tərəfdaş backend, 6MM APIs, SDKs, vebhooklar və əməliyyat sistemləri arasında məlumat axınları.
- Etimadnamələrin saxlanması, girişə nəzarət, audit qeydiyyatı, monitorinq və eskalasiya sahibləri.

<h2 id="recommended-review-path">Tövsiyə olunan rəy yolu</h2>

1. Mülkiyyəti təyin etmək üçün [tərəfdaş məsuliyyət matrisi](/az-AZ/security-compliance/partner-responsibilities) istifadə edin.
2. [lisenziya dəstəyi](/az-AZ/security-compliance/license-support) hədəf əməliyyat modelinə qarşı nəzərdən keçirin.
3. [təhlükəsizlik arxitekturası](/az-AZ/security-compliance/security-architecture) və API/Webhook idarəetmələrini təsdiqləyin.
4. [istehsalın işə salınma yoxlama siyahısı](/az-AZ/resources/production-launch-checklist) tamamlayın.

Hüquqi və uyğunluq nəticələri ixtisaslı məsləhətçilər və məsul tərəfdaş qurum tərəfindən təsdiqlənməlidir. Bu səhifələr inteqrasiya hazırlığı və məsuliyyət sərhədlərini təsvir edir, hüquqi rəy və ya müəyyən lisenziyanın mövcud olduğuna zəmanət vermir.
