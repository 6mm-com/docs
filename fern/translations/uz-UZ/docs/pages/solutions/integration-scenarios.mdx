O'rnatilgan savdo odatda mavjud mahsulotga kiritiladi, mustaqil manzil sifatida ishga tushirilmaydi. Eng yaxshi integratsiya yo'li foydalanuvchilar allaqachon qayerda vaqt o'tkazayotgani va qaysi tizim identifikatsiya, mablag'lar hamda operatsiyalarga egalik qilishiga bog'liq.

<h2 id="common-scenarios">Keng tarqalgan holatlar</h2>

| Ssenariy | Eng yaxshi boshlang'ich nuqta | Izohlar |
| --- | --- | --- |
| ilova yoki hamyon savdo yozuvini xohlaydi | Trading Widget SDK | Mahalliy yoki H5 kirish nuqtasidan foydalaning va foydalanuvchi avtorizatsiyasidan so'ng o'rnatilgan savdo tajribasini oching. |
| Broker yoki kanal platformasi derivativlarga kirishni xohlaydi | Agent SDK + Trading Widget SDK | Mijozlar bilan munosabatlar va orqa tizimni hamkor tizimida saqlang. |
| Platforma yo'naltirilgan savdo oqimini xohlaydi | API + tanlangan SDK modullar | Hisob, o'tkazish va buyurtma ish jarayonlari uchun backend APIs 'dan foydalaning, faqat zarur frontend yozuvlarini oching. |
| Mavjud birja qo'shimcha bozorlarni xohlaydi | Likvidlik + API integratsiyasi | Bozor chuqurligi, hisob jarayonlari va operatsion monitoringni birlashtiring. |

<h2 id="product-decisions-before-integration">Integratsiyadan oldingi mahsulot qarorlari</h2>

- Foydalanuvchilar bosh sahifa kartasi, aktiv sahifasi, kampaniya sahifasi yoki hisob markazidan kirishini hal qilish.
- Qaysi tizim tizimga kirish holati, foydalanuvchi huquqi va mamlakat yoki mintaqa mavjudligini aniqlash.
- O'tkazmalar, hisob-kitob yozuvlari va mijozlarni qo'llab-quvvatlash uchun chiptalar foydalanuvchilarga qanday ko'rsatilishini hal qilish.
- Qaysi voqealar ichki tahlil, CRMyoki xavf operatsiyalariga yo'naltirilishi kerakligini hal qilish.
