Embedded API / SDK Trading System allaqachon trafik, foydalanuvchilar yoki biznes ish jarayonlariga ega bo'lgan va to'liq birjani noldan qurmasdan savdoni qo'shishni istagan hamkorlar uchun mo'ljallangan.

<h2 id="what-it-provides">U nimani taqdim etadi</h2>

- O'rnatilgan savdo terminali Trading Widget SDK
- Hamkor orqa tizimini integratsiya qilish Agent SDKs
- Foydalanuvchi identifikatorini bog'lash va entry-token oqimlari
- Aktivlarni o'tkazish, buyurtma, pozitsiya va hisob API kirish
- Operatsion tizimlar uchun hodisa, veb xok va hayot siklini integratsiya qilish

<h2 id="recommended-architecture">Tavsiya etilgan arxitektura</h2>

| Qatlam | Mas'uliyat |
| --- | --- |
| Hamkor frontend | Kirish nuqtasini joylashtiradi va 6MM savdo interfeysini joylashtiradi. |
| Hamkor backend | API sirlarni saqlaydi, foydalanuvchilarni tasdiqlaydi, embed tokenlarini chiqaradi va webhooklarni qayta ishlaydi. |
| 6MM savdo infratuzilmasi | Savdo interfeysi, moslashtirish, xavf, likvidlik, hisob holati va savdo hayot aylanishini boshqaradi. |

<h2 id="choose-an-integration-path">Integratsiya yo'lini tanlang</h2>

| Talab | Tavsiya etilgan yo'l |
| --- | --- |
| Eng tez veb-integratsiya bilan to'liq savdo interfeysi | Trading Widget |
| Backend foydalanuvchi bog'lash, uzatish, kirish URLva webhook boshqaruvi | Agent SDK |
| To'liq maxsus mahsulot va buyurtma ish jarayonlari | REST API + WebSocket |
| Brendli almashinuv tajribasi va kengroq operatsion ko'lam | Oq yorliqli almashinuv |

Yakuniy dizayn ushbu yo'llarni birlashtirishi mumkin. Amalga oshirish boshlanishidan oldin autentifikatsiya, aktiv egaligi, mas'uliyat chegaralari, monitoring va ishlab chiqarishni qo'llab-quvvatlashni tasdiqlang.
