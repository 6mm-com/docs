6MM qo'llab-quvvatlash ruxsat etilgan hamkorlar, faol integratsiyalar va ishlab chiqarish operatsiyalari uchun mo'ljallangan. Yakuniy foydalanuvchini qo'llab-quvvatlash alohida kelishilgan bo'lsa, hamkor platformaning mas'uliyatida qoladi.

<h2 id="choose-the-right-path">To'g'ri yo'lni tanlang</h2>

| Vaziyat | Tavsiya etilgan yo'l | Quyidagilarni o'z ichiga oladi |
| --- | --- | --- |
| Yangi hamkorlik yoki yechim baholash | Hamkorlarni ishga tushirish yo'li | Mahsulot turi, maqsad mintaqasi, ishga tushirish jadvali, kutilayotgan integratsiya modeli. |
| SDK, API, webhook yoki muhit savoli | Texnik yordam yo'li | Endpoint, SDK versiya, so'rov ID, ko'paytirish bosqichlari, loglar. |
| Ishlab chiqarish hodisasi yoki savdo oqimining pasayishi | Hodisa eskalatsiyasi yo'li | Ta'sir doirasi, boshlanish vaqti, ta'sirlangan foydalanuvchilar, buyurtma identifikatorlari, joriy yengillashtirish. |
| Aktiv, nusxa yoki uchirish materiali o'zgarishi | Operatsiyalarni qo'llab-quvvatlash yo'li | Sahifa, til, so'ralgan o'zgartirish, ishga tushirish sanasi, tasdiqlash egasi. |
| Zaiflik yoki gumon qilingan suiiste'mol | Xavfsizlik hisobot yo'li | Texnik tafsilotlar, ta'sirlangan yakuniy nuqta, dalillar, shoshilinchlik, muammo faolmi. |

<h2 id="severity-guide">Og'irlik qo'llanmasi</h2>

| Og'irligi | Misol |
| --- | --- |
| Tanqidiy | Ishlab chiqarish savdosi, autentifikatsiya, token chiqarish yoki fondlar bilan bog'liq oqimlar mavjud emas. |
| Yuqori | Asosiy hamkor oqimi pasayadi, lekin bir yechim mavjud. |
| Normal | Integratsiya masalasi, konfiguratsiya so'rovi, hujjatlar muammosi yoki rejalashtirilgan uchirish qo'llab-quvvatlashi. |

<h2 id="before-contacting-support">Qo'llab-quvvatlashga murojaat qilishdan oldin</h2>

- Ta'sirlangan mahsulot hududi va atrof-muhitini tasdiqlang.
- So'rov IDlari, buyurtma IDlari, vaqt tamg'alar, foydalanuvchi xaritalash IDlari, webhook hodisa IDlari va loglarni yig'ish.
- Ishlab chiqarish muammolari uchun qo'llab-quvvatlash so'rovi shablonidan foydalaning.
