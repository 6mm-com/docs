<h2 id="responsibility-split">Mas'uliyatning taqsimlanishi</h2>

| Hudud | Egasi | Izohlar |
| --- | --- | --- |
| Konteyner yaratish | Hamkor frontend | Ko'rinadigan elementni aniq kenglik va balandlikda taqdim eting. |
| iframe yaratish | Trading Widget SDK | SDK iframe'ni yaratadi va boshqaradi. |
| Savdo interfeysi | 6MM iframe | K-line, buyurtma daftari, buyurtma shakli, pozitsiyalar, buyurtmalar va hisob ma'lumotlari iframe ichida ishlaydi. |
| Displey boshqaruvlari | Trading Widget SDK + 6MM iframe | PC embed sarlavhasi va pastki ticker standart holatda yashirilgan. Hamkorlar shell hududlarini ko'rsatish yoki yuqori darajadagi savdo konteynerlarini yashirish uchun `display` ishlatishlari mumkin. |
| Hamkor kirish tekshiruvi | Hamkor backend | Auth ma'lumotlarini berishdan oldin hamkor foydalanuvchi sessiyasini tasdiqlang. |
| Embed token chiqarish | Hamkor backend + Agent API | Hamkor-token rejimi uchun tavsiya etiladi. |

<h2 id="versioning">Versiyalar</h2>

Ommaviy integratsiya yo'li v1 skripti ostida barqaror URL. Hozirgi v1 imkoniyatlar to'plami partner-token, tokenProvider, entryUrlProvider, displey boshqaruvlari, hayot aylanishi hodisalari, instansiya metodlari va tartib hodisalarini o'z ichiga oladi.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Vidjetdan qachon foydalanish kerak</h2>

Hamkorga mavjud veb-mahsulot ichida to'liq savdo interfeysi kerak bo'lsa, Trading Widget tanlang. To'liq maxsus savdo interfeysini yaratish va saqlashda REST API va WebSocket hujjatlaridan foydalaning.

<h2 id="implementation-path">Amalga oshirish yo'li</h2>

1. [Trading Widget Quick Start](/uz-UZ/sdk/trading-widget/quick-start) ni kuzatib, skriptni yuklang va ko'rinadigan konteyner yarating.
2. [partner-token autentifikatsiyasi](/uz-UZ/sdk/trading-widget/authentication)ni hamkor backend orqali sozlang.
3. Kerakli [opsiyalar va voqealar](/uz-UZ/sdk/trading-widget/options-events) ni qo'shing.
4. Hayot sikl va ish vaqti boshqaruvlari uchun [instance method](/uz-UZ/sdk/trading-widget/instance-methods) dan foydalaning.
