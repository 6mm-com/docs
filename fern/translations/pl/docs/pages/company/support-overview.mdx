6MM wsparcie jest przeznaczone dla partnerów autoryzowanych, aktywnych integracji oraz operacji produkcyjnych. Wsparcie użytkownika końcowego pozostaje odpowiedzialnością platformy partnerskiej, chyba że zostanie to osobno uzgodnione.

<span id="choose-the-right-path" data-sixmm-canonical-anchor="choose-the-right-path" aria-hidden="true"></span>

## Wybierz właściwą drogę

| Sytuacja | Zalecana ścieżka | Zawiera |
| --- | --- | --- |
| Nowe partnerstwo lub ocena rozwiązań | Ścieżka wdrożenia partnera | Typ produktu, region docelowy, harmonogram startu, oczekiwany model integracji. |
| SDK, API, webhook lub pytanie środowiskowe | Ścieżka wsparcia technicznego | Endpoint, SDK wersji, ID żądania, kroki odtwarzania, logi. |
| Incydent produkcji lub pogorszenie przepływu handlowego | Ścieżka eskalacji incydentu | Zakres wpływu, czas rozpoczęcia, dotknięci użytkownicy, identyfikatory zamówień, aktualne środki łagodzące. |
| Zmiana materiału zasobowego, kopiowania lub startu | Ścieżka wsparcia operacyjnego | Strona, język, żądana zmiana, data premiery, właściciel zatwierdzenia. |
| Wrażliwość lub podejrzenie nadużycia | Ścieżka raportowania bezpieczeństwa | Szczegóły techniczne, dotknięty punkt końcowy, dowody, pilność, czy problem jest aktywny. |

<span id="severity-guide" data-sixmm-canonical-anchor="severity-guide" aria-hidden="true"></span>

## Przewodnik po nasileniu

| Nasilenie | Przykład |
| --- | --- |
| Krytyczne | Nie dostępne są przepływy związane z produkcją, uwierzytelnianiem, emisją tokenów ani przepływami związanymi z funduszami. |
| Wysoko | Przepływ głównych partnerów jest degradowany, ale istnieje obejście. |
| Normalne | Pytanie o integrację, prośba o konfigurację, problem z dokumentacją lub planowane wsparcie startowe. |

<span id="before-contacting-support" data-sixmm-canonical-anchor="before-contacting-support" aria-hidden="true"></span>

## Przed kontaktem z pomocą techniczną

- Potwierdź obszar i środowisko związane z produktem.
- Zbieranie identyfikatorów żądań, identyfikatorów zamówień, znaczników czasu, identyfikatorów mapowania użytkownika, identyfikatorów zdarzeń webhooków oraz logów.
- Używaj szablonu żądania wsparcia dla problemów produkcyjnych.
