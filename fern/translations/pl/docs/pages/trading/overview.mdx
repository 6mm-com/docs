Ta sekcja została napisana z myślą o produktach, operacjach, wsparciu oraz edukacji użytkowników końcowych. Dla API pól, podpisywania i integracji backendowej korzystaj z sekcji Deweloperzy i SDK .

<h2 id="before-trading">Przed handlem</h2>

- Potwierdzenie, że użytkownik wchodzi przez autoryzowanego partnera lub wbudowany 6MM wpis.
- Upewnij się, że środki są dostępne na właściwym koncie przed złożeniem zamówienia.
- Zrozumienie zachowania dźwigni, marży, likwidacji oraz opłat finansowych.
- Zaczynaj od małych pozycji podczas nauki nowego rynku lub trybu handlu.
- Używanie TP / SL oraz zamówienia tylko redukcyjne tam, gdzie to konieczne dla kontroli ryzyka.
