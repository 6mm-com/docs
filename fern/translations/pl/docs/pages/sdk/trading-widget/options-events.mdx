## Opcje

| Pole | Typ | Domyślny | Notatki |
| --- | --- | --- | --- |
| baseUrl | string | SDK pochodzenie skryptu | domena iframe. Przekaż jawnie na stronach partnerów. |
| symbol | string | BTCUSDT | Znormalizowany do wielkich liter i pasków - / _. |
| temat | ciemny \| światło | ciemny | Początkowy parametr motywu. |
| widownia | pl \| en-US \| zh-CN | Przeglądarka/domyślna | Obsługiwany jest język angielski i chiński uproszczony. |
| układ | domyślny \| kompaktowy | domyślny | Zarezerwowana opcja układu. |
| wyświetlacz | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Kontrole obejmują obszary powłoki i kontenery handlowe wysokiego poziomu. |
| autoryzacja | object | nic | Użyj tokena partnera dla nowych integracji SSO. |

## Elementy sterujące wyświetlacza

`display` kontroluje powłokę wbudowanej strony handlowej i kontenery wysokiego poziomu. W przypadku osadzania partnerów nagłówek komputera i dolny pasek rynku są domyślnie ukryte.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Pole | Typ | Domyślny | Notatki |
| --- | --- | --- | --- |
| showHeader | boolean | FAŁSZ | Określa, czy wyświetlać nagłówek osadzania komputera PC wewnątrz ramki iframe. |
| showTicker | boolean | FAŁSZ | Określa, czy wyświetlać dolny pasek rynku w powłoce osadzania. |
| ukryty | smyczkowy[] | [] | Ukrywa kontenery wysokiego poziomu na stronie handlu. |

Obsługiwane wartości `display.hidden`:

| Wartość | Pojemnik |
| --- | --- |
| wykres | Kontener wykresów |
| orderBook | Zamów pojemnik na książki |
| orderForm | Panel formularza zamówienia |
| pozycje | Dolne pozycje i otwarty panel zamówień |
| konto | Kontener zasobów konta |

`display.hidden` ukrywa tylko całe kontenery. Nie ukrywa poszczególnych przycisków, pól ani narzędzi w kontenerze. Wartości, które nie są odwzorowane na bieżącą rzutnię, są ignorowane.

## Wydarzenia

| Wydarzenie | Spust |
| --- | --- |
| gotowy | Zakończono inicjalizację elementu iframe. |
| błąd | SDK, element iframe lub błąd uwierzytelnienia. |
| stan_zmieniony | SDK stan cyklu życia uległ zmianie. |
| stan_auta_zmieniony | Stan uwierzytelnienia tokena partnera został zmieniony. |
| symbol_zmieniony | Rzeczywisty symbol iframe został zmieniony. |
| ustawienia_lokalne_zmienione | Rzeczywiste ustawienia regionalne elementu iframe zostały zmienione. |
| zamówienie_utworzone | Użytkownik utworzył zamówienie wewnątrz elementu iframe. |
| zamówienie_nie powiodło się | Złożenie zamówienia nie powiodło się. |
| zniszczony | SDK instancja zniszczona. |

## Strony produktów i tryb handlu

Java Agent SDK i przeglądarka Trading Widget SDK są wersjonowane niezależnie. Aby handlować sekundami, skorzystaj z bieżących możliwości widgetu i wyraźnie wybierz zarówno stronę, jak i tryb handlu.

| Opcja | Wartości | Oznaczający |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Strona produktu do handlu sekundami. |
| `tradingMode` | `real`, `demo` | Domyślnie `real`; wyraźnie pasują do środowiska finansowania zaplecza. |

Sprawdź `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` i `TradingWidget.capabilities.partnerToken` przed inicjalizacją. Tworzenie tokenu nie powoduje wyboru środowiska funduszy. Aby zmienić użytkowników lub tryb rzeczywisty/demo, zniszcz starą instancję i utwórz nową.

Widzieć [kompletny przykład handlu sekundami](/pl/sdk/agent-sdk/java/seconds-trading) I [konfiguracja produkcyjna/symulowana](/pl/sdk/agent-sdk/java/environments).

## Dodatkowe cele wyświetlania i zdarzenia

Bieżące środowisko wykonawcze akceptuje również `symbolFavorites` i `symbolTicker` w `display.hidden`. Zawsze sprawdzaj `TradingWidget.capabilities.displayTargets`; cel kontroluje kontener wysokiego poziomu i nie jest ustawieniem uprawnień na poziomie pola.

| Wydarzenie | Oznaczający |
| --- | --- |
| `rendered` | Element iframe wysyła wyrenderowane powiadomienie. |
| `theme_changed` | Element iframe zgłasza swój rzeczywisty motyw. |
| `page_changed` | Element iframe zgłasza rzeczywistą stronę produktu. |

Użyj `onRendered` lub `widget.on('rendered', handler)`, aby obsłużyć renderowanie oddzielnie od inicjalizacji. Aktualnie obsługiwane strony są publikowane w `TradingWidget.capabilities.pages`; zatwierdź żądaną stronę, zamiast zgadywać ścieżkę.
