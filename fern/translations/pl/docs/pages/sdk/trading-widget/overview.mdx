## Podział odpowiedzialności

| Obszar | Właściciel | Notatki |
| --- | --- | --- |
| Tworzenie kontenera | Interfejs partnera | Podaj widoczny element o wyraźnej szerokości i wysokości. |
| tworzenie ramki iframe | Trading Widget SDK | SDK tworzy ramkę iframe i zarządza nią. |
| Interfejs handlowy | 6MM iframe | Linia K, księga zamówień, formularz zamówienia, pozycje, zamówienia i dane konta działają wewnątrz ramki iframe. |
| Elementy sterujące wyświetlacza | Trading Widget SDK + 6MM iframe | Nagłówek i dolny pasek osadzania na komputerze są domyślnie ukryte. Partnerzy mogą używać `display`, aby pokazać obszary powłoki lub ukryć kontenery handlowe wysokiego poziomu. |
| Sprawdzenie logowania partnera | Zaplecze partnera | Przed wydaniem danych uwierzytelniających zweryfikuj sesję użytkownika partnera. |
| Wydanie tokena osadzania | Backend partnera + agent API | Zalecane w przypadku trybu tokenu partnera. |

## Wersjonowanie

Ścieżka integracji publicznej pozostaje stabilna pod skryptem v1 URL. Bieżący zestaw możliwości wersji 1 obejmuje token partnera, tokenProvider, entryUrlProvider, elementy sterujące wyświetlaniem, zdarzenia cyklu życia, metody instancji i zdarzenia zamówień.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Kiedy używać widgetu

Wybierz Trading Widget, jeśli partner potrzebuje kompletnego interfejsu handlowego w ramach istniejącego produktu internetowego. Zamiast tego korzystaj z dokumentacji REST API i WebSocket podczas tworzenia i utrzymywania w pełni niestandardowego interfejsu handlowego.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Ścieżka realizacji

1. Postępuj zgodnie z [Trading Widget Szybki start](/pl/sdk/trading-widget/quick-start) aby załadować skrypt i utworzyć widoczny kontener.
2. Skonfiguruj [uwierzytelnianie za pomocą tokena partnera](/pl/sdk/trading-widget/authentication) poprzez zaplecze partnera.
3. Dodaj wymagane [opcje i zdarzenia](/pl/sdk/trading-widget/options-events).
4. Używać [metody instancji](/pl/sdk/trading-widget/instance-methods) do kontroli cyklu życia i czasu działania.

## Zweryfikowane publiczne środowisko wykonawcze

Publiczny skrypt `v1` raportuje wersję `1.8.0` na dzień 10.10.2026. To URL to stabilny punkt wejścia do wersji głównej, a nie przypięta kompilacja. Przeczytaj `TradingWidget.version` i `TradingWidget.capabilities` w załadowanym środowisku wykonawczym przed użyciem funkcji opcjonalnych. Java Agent SDK `v0.3.0` to oddzielny pakiet backendowy.

Środowisko wykonawcze obsługuje pojedynczą aktywną instancję (`multiInstance=false`); utworzenie kolejnego widgetu niszczy poprzednią instancję. Obsługiwane lokalizacje to `en`, `en-US` i `zh-CN`, niezależnie od 20 języków dokumentacji.
