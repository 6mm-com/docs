## Podsumowanie metody

| Metoda | Zamiar |
| --- | --- |
| zniszczyć() | Usuń element iframe i zwolnij detektory zdarzeń. |
| getState() | Odczytaj bieżący stan cyklu życia SDK. |
| whenReady() | Poczekaj, aż element iframe zakończy inicjalizację. |
| setSymbol(symbol) | Zmień parę handlową wewnątrz ramki iframe. |
| setTheme(motyw) | Zaktualizuj parametr motywu iframe. |
| setLocale(lokalizacja) | Zmień język elementu iframe. |
| setSize(szerokość, wysokość) | Zaktualizuj wymiary elementu iframe. |
| przeładować() | Załaduj ponownie bieżącą ramkę iframe. |
| refreshAuth(powód) | Uruchom proces odświeżania uwierzytelniania widżetu. |
| setTokenProvider(dostawca) | Zastąp dostawcę używanego przez tryb tokenu partnera. |
| on(zdarzenie, procedura obsługi) | Subskrybuj zdarzenia wykonawcze i uzyskaj funkcję anulowania subskrypcji. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## zniszczyć()

Usuń ramkę iframe, wyczyść słuchacze i raz zniszczoną emisję dla bieżącej instancji.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Przeczytaj bieżący stan cyklu życia instancji widżetu.

```js
const state = widget.getState()
```

Zwracane wartości obejmują ładowanie, uwierzytelnianie, gotowość, błąd i zniszczenie.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Poczekaj, aż element iframe zakończy inicjalizację, zanim uruchomisz zależną logikę interfejsu użytkownika.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(symbol)

Zmień parę handlową wewnątrz ramki iframe. Jeśli element iframe nadal się inicjuje, SDK umieszcza polecenie w kolejce i wysyła je po przygotowaniu.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(motyw)

Zaktualizuj parametr motywu używany przez osadzoną ramkę iframe handlową.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(lokalizacja)

Zmień język elementu iframe. Obsługiwane wartości to en, en-US i zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(szerokość, wysokość)

Zaktualizuj rozmiar elementu iframe DOM i powiadom element iframe o nowym rozmiarze zewnętrznym. Wartości numeryczne są konwertowane na piksele.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## przeładować()

Załaduj ponownie bieżącą ramkę iframe i poczekaj, aż ponownie się zainicjuje.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(powód)

Poproś element iframe o odświeżenie bieżącego przepływu uwierzytelniania. Opcjonalna wartość przyczyny jest przekazywana w celu rejestrowania i kontroli przepływu.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(dostawca)

Zastąp tokenProvider używany przez tryb tokena partnera. SDK wywołuje dostawcę, gdy ramka iframe żąda nowego tokena do osadzenia.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(zdarzenie, procedura obsługi)

Subskrybuj wydarzenie wykonawcze. Zwrócona funkcja usuwa słuchacza.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Dodatkowe metody w bieżącym środowisku wykonawczym wersji 1

| Metoda | Zamiar |
| --- | --- |
| `whenRendered()` | Poczekaj na wyrenderowane powiadomienie elementu iframe; jest to oddzielne od gotowego. |
| `setPage(page)` | Poproś o obsługiwaną stronę produktu w bieżącej instancji. Nie zmienia to otoczenia funduszy. |
| `prepareForRecreate()` | Poproś gotową ramkę iframe o przygotowanie do wymiany; zwraca obietnicę i może ją odrzucić, jeśli jest niedostępna, zajęta lub przekroczono limit czasu. |
| `cancelRecreate()` | Anuluj oczekujący/przygotowany przepływ wymiany. |
| `TradingWidget.validateOptions(options)` | Przed utworzeniem instancji sprawdź opcje inicjalizacji. |

W przypadku zmiany środowiska użytkownika lub środowiska rzeczywistego/demo zniszcz starą instancję i utwórz nową z docelowym uwierzytelnianiem i trybem. Nie używaj `setPage` jako przełącznika środowiska. Sprawdź możliwości przed użyciem metod opcjonalnych.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
