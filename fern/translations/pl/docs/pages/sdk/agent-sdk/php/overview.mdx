## Czas trwania

| Przedmiot | Wartość |
| --- | --- |
| Pakiet | sixmm/agent-sdk |
| Wersja minimalna PHP | PHP 7.4+ |
| Zalecana wersja PHP | PHP wersje 8.1+ lub obecnie wspierane |
| Wymagane przedłużenia | ext-json, ext-curl |

Źródło PHP SDK pakietu i zatwierdzona wersja są udostępniane podczas onboardingu partnerów. Nie zakładaj, że pakiet jest dostępny w publicznym Packagist; skonfiguruj repozytorium Composer udostępnione dla Twojej organizacji.

<span id="supported-scenarios" data-sixmm-canonical-anchor="supported-scenarios" aria-hidden="true"></span>

## Wspierane scenariusze

| Scenariusz | SDK metoda |
| --- | --- |
| Użytkownik przypisania | Wiązanie |
| Transfer o stałej kwotie | Transfer |
| Przenieś wszystkich na zewnątrz | transferAllOut |
| Transfer wsteczny | Rewers |
| Kolejność zapytań | queryOrder |
| Utwórz URL | createEntryUrl |
| Weryfikacja Webhook | WebhookVerifier::verify |

<span id="backend-integration-rules" data-sixmm-canonical-anchor="backend-integration-rules" aria-hidden="true"></span>

## Reguły integracji backendowej

- Ładowanie `apiSecret` z menedżera tajemnic lub chronionej zmiennej środowiskowej.
- Utrzymanie logiki wiązania użytkownika, transferu, podpisywania i webhooków poza kodem przeglądarki.
- Używanie ciągów dziesiętnych dla wartości aktywów, aby uniknąć zaokrągleń zmiennoprzecinkowych.
- Ponownie użyć oryginalnego `agentOrderNo` podczas zapytania o niepewny wynik transferu.
- Weryfikacja sygnatur webhooków względem surowego ciała żądania przed jego dekodowaniem lub zmianą.
