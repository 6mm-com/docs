<h2 id="install">Instalacja</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Dostęp do pakietu**
>
> 6MM udostępnia zatwierdzoną nazwę pakietu, repozytorium oraz wersję podczas wdrażania partnerów. Nie należy zakładać, że pakiet istnieje na publicznym Packagist.

<h2 id="before-you-start">Zanim zaczniesz</h2>

- Potwierdź, że agent API bazie URL z 6MM.
- Ładowanie apiSecret ze zmiennych środowiskowych lub zarządzania tajemnicami.
- Zachowaj SDK użycie tylko w usługach backendowych.
- Przygotowanie obsługi idempotentów dla przepływów transferowych i webhooków.

<h2 id="initialize-client">Inicjalizuj klienta</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Tylko backend**
>
> PHP SDK podpisuje żądania Agenta API i nie może być ujawniany przez publiczny kod źródłowy ani środowiska frontendowe.

<h2 id="example-transfer-funds-in">Przykład: przelew środków do</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Używaj ciągów dziesiętnych dla wartości i zachowaj oryginalny agentOrderNo podczas ponownej próby lub zapytania o status transferu.
