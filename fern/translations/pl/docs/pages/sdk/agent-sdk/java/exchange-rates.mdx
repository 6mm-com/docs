Ten przewodnik jest przeznaczony dla **Agent Java SDK `v0.3.0`**, Java 8+ i oznaczonych zamówień publicznych. Przykłady działają w zapleczu partnera po inicjalizacji `client` w [Szybki start](/pl/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## Przykładowe wymagania wstępne

Fragmenty Java dzielą ten import. Zainicjuj `client` za pomocą Szybki start i uzyskaj `platformUserId` z zapisanego powiązania. Przykładowe identyfikatory użytkowników/zamówień należy zastąpić własnymi, utrwalonymi wartościami.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Kursy referencyjne walut

Obie metody FX wykorzystują normalny przepływ podpisanego agenta API. Zacznij od odkrycia
aktualnie obsługiwane waluty źródłowe:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Zapytaj o wszystkie obsługiwane stawki referencyjne fiat-to-USDT:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Zapytanie o wybrane waluty:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

Fabryka żądania przycina i pisze wielkimi literami kody walut oraz serializuje je jako
oddzielona przecinkami wartość `sourceCurrencies` wymagana przez API. Pominięcie
request lub wszystkie efektywne wartości walut wysyła zapytanie do każdej obsługiwanej waluty.

| Pole odpowiedzi | Typ | Opis |
| --- | --- | --- |
| `snapshotVersion` | string | Stabilna wersja migawki do celów audytu i uzgadniania |
| `provider` | string | Dostawca wyższego szczebla, obecnie `ECB` |
| `sourceDate` | string | Data obserwacji w górę rzeki w formacie `yyyy-MM-dd`. |
| `fetchedAt` / `expiresAt` | int64 | Unixowe znaczniki czasu w milisekundach |
| `pricingPolicy` | string | Obecnie `FIXED_PEG` |
| `usdtUsdRate` | string | USD kwota na 1 USDT, obecnie ustalona na `1` |
| `rateType` | string | Obecnie `INDICATIVE_DAILY` |
| `usage` | string | Obecnie `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT ilość odpowiadająca jednej jednostce źródła fiat |

Wartości te stanowią odniesienia do obliczenia dla partnerskiego portfela wielowalutowego
kwota USDT wysłana do 6MM. Nie są to ceny możliwe do wykonania, zablokowane notowania lub
ceny rynkowe USDT w czasie rzeczywistym. Użyj `BigDecimal` i ciągów znaków jako kwoty
obliczenia; nie używaj `double` ani `float`.
