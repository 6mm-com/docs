Ten przewodnik jest przeznaczony dla **Agent Java SDK `v0.3.0`**, Java 8+ i oznaczonych zamówień publicznych. Przykłady działają w zapleczu partnera po inicjalizacji `client` w [Szybki start](/pl/sdk/agent-sdk/java/quick-start).

<span id="v030" data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## wersja 0.3.0

- Sześć ciągłych zapytań: aktualne zamówienia, historia zamówień, wypełnienia, aktualne pozycje, historia pozycji i księga konta.
- Salda środków, transfery, zapytania dotyczące odzyskiwania środków i transfery środków/umów.
- Jawna produkcja/symulowany wybór wniosków o wsparcie finansowe.
- Przewodniki dotyczące przekierowania i osadzania handlu sekundami, informacje o polach odpowiedzi i instrukcje dotyczące migracji.

Java SDK i Trading Widget SDK mają niezależne wersje. `v1` Widget URL nie jest Java SDK wersją `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Istniejące integracje

Zachowaj mapowania użytkowników, oryginalne zamówienia i dane uwierzytelniające. Pominięte pola środowiska zachowują istniejące zachowanie produkcyjne. Finansowanie, jawne fundusze symulowane i sześć ciągłych zapytań wymagają odpowiednich nowych modeli i metod. Recenzja [Przewodnik po aktualizacji](/pl/sdk/agent-sdk/java/upgrade) przed zmianą istniejącej integracji.
