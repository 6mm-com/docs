Ten przewodnik jest przeznaczony dla **Agent Java SDK `v0.3.0`**, Java 8+ i oznaczonych zamówień publicznych. Przykłady działają w zapleczu partnera po inicjalizacji `client` w [Szybki start](/pl/sdk/agent-sdk/java/quick-start).

## Konfiguracja

Uzyskaj następujące wartości z 6MM wcześniej
integrowanie.

| Przedmiot | Przykład | Opis |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Agent API podstawa URL, bez końcowego ukośnika |
| `agentCode` | `AGENT001` | Kod partnera |
| `apiSecret` | `your-api-secret` | API tajemnica podpisywania. Trzymaj go tylko na zapleczu |
| `defaultCurrency` | `USDT` | Domyślna waluta, zwykle `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Punkt końcowy partnera dla wywołań zwrotnych 6MM. |

Zalecenia produkcyjne:

- Użyj HTTPS dla punktów końcowych agenta API i webhook.
- Przechowuj `apiSecret` w tajnym menedżerze, centrum konfiguracji lub zmiennej środowiskowej.
- Synchronizuj czas serwera, najlepiej z NTP.
- Zachowaj wszystkie numery zamówień partnerów i zachowaj je globalnie unikalne.
- Nigdy nie wysyłaj `apiSecret` do przeglądarek, aplikacji, miniprogramów lub kodu źródłowego frontendu.

## Automatyczne pola podpisywania

W przypadku wywołań podpisanego agenta API, SDK automatycznie dodaje:

| Pole | Źródło | Opis |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Kod partnera |
| `timestamp` | Bieżący UTC znacznik czasu Uniksa | Towary drugiej jakości |
| `nonce` | Bezpieczny generator losowy | Ochrona przed powtórkami |
| `sign` | HMAC-SHA256 | Poproś o podpis |
| `currency` | `defaultCurrency` | Wypełniane, gdy żądania przelewu/konta pomijają walutę |

Zasady podpisywania:

1. Wyklucz `sign`.
2. Wyklucz puste wartości.
3. Sortuj klucze według kolejności ASCII.
4. Dołącz jako `k=v&k2=v2`.
5. Oblicz HMAC-SHA256 szesnastkowo za pomocą `apiSecret`.

Wartości tablicy są serializowane jako kompaktowe JSON przed dołączeniem do ładunku podpisującego. Na przykład `platformUserIds` znakuje jako `["1188041528"]`, podając `platformUserIds=["1188041528"]` w ładunku `k=v`. Zachowaj kolejność elementów tablicy, podwójne cudzysłowy i identyfikatory ciągów; nie wstawiaj spacji formatujących ani nie używaj Java `List.toString()` (np. `[1188041528]`). SDK automatycznie obsługuje tę serializację.

Normalny kod biznesowy nie powinien obliczać podpisów ani ustawiać go ręcznie
`agentCode`, `timestamp`, `nonce` lub `sign`.
