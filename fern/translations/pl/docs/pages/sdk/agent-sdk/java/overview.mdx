## Czas trwania

| Przedmiot | Wartość |
| --- | --- |
| Wersja minimalna Java | Java 8+ |
| Polecane narzędzie do budowania | Maven 3.9+ |
| Grupa Maven | `com.sixmm.exchange.sdk` |
| Artefakt Maven | `agent` |
| Udokumentowany tag źródłowy | `v0.1.1` |

Publiczne repozytorium GitHub to hosting źródłowy, a nie repozytorium zależności Maven. Zbuduj i zainstaluj oznaczony kod lokalnie lub opublikuj zatwierdzony artefakt w prywatnym repozytorium Maven swojej organizacji, zanim użyjesz go w budowaniu zespołowym.

<span id="typical-backend-responsibilities" data-sixmm-canonical-anchor="typical-backend-responsibilities" aria-hidden="true"></span>

## Typowe obowiązki backendowe

- Walidacja sesji użytkownika partnera.
- Przypisuj użytkownika partnera na agentUserId.
- Wiązanie wywołań przed pierwszym handlem lub przepływem transferowym.
- Zadzwoń createEntryUrl w celu jednorazowego pełnego SSO.
- Zadzwoń createEmbedToken Trading Widget tryb tokenów partnera.
- Weryfikacja webhooków transferowych i ich prawidłowe przetwarzanie.

<span id="security-and-operational-rules" data-sixmm-canonical-anchor="security-and-operational-rules" aria-hidden="true"></span>

## Zasady bezpieczeństwa i działania

- Przechowywać `apiSecret` tylko w backendowym menedżerze sekretów lub chronionej zmiennej środowiskowej.
- Utrzymywanie synchronizacji czasu serwera, ponieważ podpisane żądania zawierają znaczniki czasowe.
- Traktuj `agentOrderNo` jako trwały klucz idempotencji i utrzymuj go globalnie unikalnym.
- Przechowuj `platformUserId` jako ciąg i utrzymuj jego relację do `agentUserId`.
- Zapytanie o oryginalny transfer przed ponowną próbą po przerwie czasu lub niepewnym wyniku sieci.
