<h2 id="install">Instalacja</h2>

Obecnie publiczne SDK źródła dokumentują tag `v0.1.1` tymi współrzędnymi Maven:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

GitHub nie działa jako repozytorium zależności Maven. Zainstaluj oznaczony kod lokalnie przed rozwiązaniem zależności:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Budowania drużyny**
>
> Publikuj zatwierdzony artefakt w repozytorium Maven w swojej organizacji do konfiguracji CI, testów i wersji produkcyjnych. Potwierdź zatwierdzoną wersję z 6MM przed wdrożeniem produkcyjnym.

Kod źródłowy i przykłady użycia są dostępne w oficjalnym repozytorium Java SDK :

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

<h2 id="before-you-start">Zanim zaczniesz</h2>

- Potwierdź, że twój agent produkcyjny API bazie URL z zespołem 6MM .
- Przechowywać apiSecret tylko w backendowym zarządzaniu tajemnicami.
- Przygotuj stabilne odwzorowanie między platformUserId a agentUserId.
- Umożliwienie uporządkowanych logów dotyczących przepływów bind, transfer, order i webhook.

<h2 id="initialize-client">Inicjalizuj klienta</h2>

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Tylko backend**
>
> Nie inicjalizuj Agent SDK z kodu klienta przeglądarki, telefonu mobilnego ani desktopowego. SDK podpisuje uprzywilejowane żądania API agenta.

<h2 id="example-transfer-funds-in">Przykład: przelew środków do</h2>

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Dla każdego żądania transferu używaj unikalnego numeru zlecenia po stronie partnera. Jeśli żądanie wygasa czasu, zapytaj oryginalne zamówienie przed utworzeniem nowego.
