## SDK telefon

Stwórz tokeny embed z backendu po zweryfikowaniu sesji użytkownika partnera. Przeglądarka powinna wywołać Twój punkt końcowy, a punkt końcowy powinien wywołać 6MM przez Agent SDK.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Jednorazowe uprawnienia**
>
> embedToken jest krótkotrwały i jednorazowy. Nie umieszczaj go w ciągu zapytania URL .

<span id="backend-endpoint-example" data-sixmm-canonical-anchor="backend-endpoint-example" aria-hidden="true"></span>

## Przykład endpointu backendowego

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Zwracaj tylko pola potrzebne dostawcy tokena Trading Widget . Nie zwracaj apiSecret, surowych pól podpisu ani wewnętrznej konfiguracji usługi.

## Obsługa awarii

| Stan | Zalecane prowadzenie |
| --- | --- |
| Sesja użytkownika jest brakująca lub wygasła | Zwróć 401 z punktu końcowego partnera i poproś użytkownika o ponowne zalogowanie. |
| Użytkownik agenta nie jest związany | Najpierw przypisz użytkownika, a potem spróbuj ponownie utworzyć token. |
| 6MM zwraca tymczasowy błąd | Zwróć błąd do ponownego spróbowania do frontendu i loguj requestId wsparcia. |
| channelId nie pasuje do instancji widżetu | Odrzuć żądanie i odtworzyć sesję widżetów. |
