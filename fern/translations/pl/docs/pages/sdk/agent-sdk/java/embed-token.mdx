Ten przewodnik jest przeznaczony dla **Agent Java SDK `v0.3.0`**, Java 8+ i oznaczonych zamówień publicznych. Przykłady działają w zapleczu partnera po inicjalizacji `client` w [Szybki start](/pl/sdk/agent-sdk/java/quick-start).

## Przykładowe wymagania wstępne

Fragmenty Java dzielą ten import. Zainicjuj `client` za pomocą Szybki start i uzyskaj `platformUserId` z zapisanego powiązania. Przykładowe identyfikatory użytkowników/zamówień należy zastąpić własnymi, utrwalonymi wartościami.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget Token osadzania

Token osadzania przeznaczony jest dla trybu Trading Widget SDK `partner-token + tokenProvider`. The
przeglądarka wywołuje backend partnera, a backend partnera wywołuje to Java SDK
aby utworzyć `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Wymagania dotyczące integracji:

- `channelId` musi używać wartości przekazanej przez Trading Widget SDK.
- `symbol` jest opcjonalne, ale zaleca się przekazanie bieżącego symbolu początkowego.
- `embedToken` jest krótkotrwałe i jednorazowe. Nie umieszczaj go w ciągach zapytania URL.
- Interfejs partnera nigdy nie może zawierać `apiSecret`.
- `expireAt` to uniksowy znacznik czasu w sekundach, a nie TTL.

Przykład punktu końcowego zaplecza partnera:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Umowa dotycząca punktu końcowego partnera

Uwierzytelnij sesję partnera i uzyskaj `agentUserId` po stronie serwera. Zaakceptuj bieżący widget `channelId`; zwróć najwyższy poziom `embedToken`, `expireAt` (sekundy Unixowe) i to samo `channelId`. Odpowiedzi agentów nie dostarczają `channelId`: Twój backend powtarza to. Pobierz nowy token podczas inicjalizacji i odnowienia; nigdy go nie używaj ponownie. Utworzenie tokena nie powoduje transferu środków ani wyboru środowiska portfela.

Widzieć [Handel sekundami](/pl/sdk/agent-sdk/java/seconds-trading) dla pełnego przepływu frontendu/backendu.
