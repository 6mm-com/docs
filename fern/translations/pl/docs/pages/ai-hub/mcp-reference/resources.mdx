> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Zasoby MCP to kontekst tylko do odczytu, który klienci AI mogą sprawdzić przed wywołaniem narzędzi.

Zasoby redukują halucynacje, dostarczając modelowi stabilnych, ustrukturyzowanych informacji o 6MM.

<span id="recommended-resource-uris" data-sixmm-canonical-anchor="recommended-resource-uris" aria-hidden="true"></span>

## Zalecane identyfikatory URI zasobów

| Ratunek | Zamiar |
| --- | --- |
| 6mm://system/config | Konfiguracja środowiska i możliwości. |
| 6mm://system/stan | Aktualny stan systemu i rynku. |
| 6mm://rynki | Dostępne rynki. |
| 6mm://rynek/{symbol} | Specyfikacje kontraktowe i metadane na poziomie rynku. |
| 6mm://opłaty | Zasady opłat. |
| 6mm://ryzyko/zasady | Podsumowanie zasad handlu i ryzyka. |
| 6mm://ryzyko/marża | Kontekst depozytu zabezpieczającego i likwidacji. |
| 6mm://finansowanie/zasady | Zasady stopy finansowania. |
| 6mm://api/docs | API podsumowanie lub linki referencyjne. |

<span id="resource-design-rules" data-sixmm-canonical-anchor="resource-design-rules" aria-hidden="true"></span>

## Zasady projektowania zasobów

- Zachowaj zasoby tylko do odczytu.
- Używaj stabilnych schematów.
- Dołącz znaczniki czasu i nazwy środowisk.
- Unikaj ujawniania tajemnic.
- Wolisz zwięzłe, uporządkowane dane od długiej prozy.
- Link do dokumentacji kanonicznej, gdy szczegóły są za długie.
