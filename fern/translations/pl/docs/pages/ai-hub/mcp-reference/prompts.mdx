> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Podpowiedzi MCP to przepływy pracy wielokrotnego użytku udostępniane przez serwer MCP. Pomagają użytkownikom zadawać spójne pytania i pomagają klientom AI korzystać z odpowiednich narzędzi.

<span id="recommended-prompts" data-sixmm-canonical-anchor="recommended-prompts" aria-hidden="true"></span>

## Polecane podpowiedzi

| Podpowiedź | Zamiar |
| --- | --- |
| przegląd_rynku | Podsumuj stan rynku za pomocą wybranych symboli. |
| analiza_mikrostruktury_rynku | Analizuj spread, głębokość, ostatnie transakcje i warunki płynności. |
| ocena_ryzyka portfela | Przejrzyj pozycje, ekspozycję, marżę i ryzyko likwidacji. |
| zarządzanie_pozycją | Pomóż użytkownikom zrozumieć stan pozycji i możliwe działania. |
| ochrona_likwidacyjna | Identyfikacja ryzyka likwidacji i możliwości jego ograniczenia. |
| finansowanie_rate_opportunity | Porównaj stawki finansowania i możliwe możliwości. |
| utwórz_optymalny_porządek | Zaplanuj parametry zamówienia przed podglądem. |
| strategia_zabezpieczenia | Przeglądaj opcje zabezpieczenia istniejącej ekspozycji. |
| trading_konsultacje | Przygotuj ustrukturyzowaną analizę handlową bez wykonywania zleceń. |

<span id="prompt-safety-rules" data-sixmm-canonical-anchor="prompt-safety-rules" aria-hidden="true"></span>

## Szybkie zasady bezpieczeństwa

- Nie traktuj szybkich wyników jako porady finansowej.
- Nie uruchamiaj narzędzi handlowych, chyba że użytkownik wyraźnie o to poprosi.
- Użyj podglądu przed utworzeniem.
- Wyjaśnij założenia i źródła danych.
- Preferuj przykłady sieci testowej w dokumentacji publicznej.
