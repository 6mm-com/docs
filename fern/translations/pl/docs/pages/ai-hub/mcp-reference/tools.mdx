> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Narzędzia MCP to działania, które może wywołać klient AI. Każde narzędzie powinno mieć przejrzysty opis, schemat JSON, wymagania dotyczące uprawnień, stabilny format odpowiedzi i model błędów.

## Wymagania dotyczące narzędzi

Każde narzędzie powinno definiować:

- Opis modelu AI.
- Wprowadź schemat JSON.
- Zakres uprawnień.
- Wsparcie środowiska.
- Zachowanie limitu szybkości.
- Stabilne pola odpowiedzi.
- Kody błędów.
- Pola dziennika audytu.
