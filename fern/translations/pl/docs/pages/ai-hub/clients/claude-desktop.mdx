> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Claude Desktop dobrze nadaje się do badań opartych na MCP-, przeglądach kont i analizach operacyjnych.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Zalecana konfiguracja

| Potrzebować | Organizować coś |
| --- | --- |
| Badania rynku publicznego | Hostowane MCP |
| Analiza uwzględniająca konto | Lokalny MCP |
| Wewnętrzny punkt końcowy zespołu | Zdalny MCP |

<span id="example-prompts" data-sixmm-canonical-anchor="example-prompts" aria-hidden="true"></span>

## Przykładowe podpowiedzi

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<span id="notes" data-sixmm-canonical-anchor="notes" aria-hidden="true"></span>

## Notatki

Lokalny MCP jest preferowany, gdy w grę wchodzą dane konta prywatnego, ponieważ serwer MCP działa na komputerze użytkownika i dane uwierzytelniające nie muszą być wysyłane do punktu końcowego AI hostowanego przez 6MM.
