> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Gemini CLI działa najlepiej z danymi wyjściowymi wiersza poleceń, które można sprawdzić, podsumować i przekazać do dalszych zadań.

<h2 id="recommended-setup">Zalecana konfiguracja</h2>

| Potrzebować | Organizować coś |
| --- | --- |
| Kontrole rynku publicznego | 6MM CLI |
| Badania skryptowe | 6MM CLI |
| Kontekst konta prywatnego | Lokalny MCP lub CLI z lokalnymi danymi uwierzytelniającymi |

<h2 id="example-prompts">Przykładowe podpowiedzi</h2>

```text
Use 6MM CLI to fetch market metadata and summarize tradable pairs.
```

```text
Use 6MM to compare fee and margin rules for two symbols.
```

<h2 id="output-format">Format wyjściowy</h2>

Preferuj ustrukturyzowane dane wyjściowe, takie jak JSON lub tabele Markdown, aby klient AI mógł przemyśleć wynik bez utraty precyzji.
