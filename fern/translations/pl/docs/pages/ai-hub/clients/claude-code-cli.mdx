> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Kod Claude CLI jest przydatny, gdy agent może uruchamiać polecenia terminala, sprawdzać dane wyjściowe JSON i aktualizować kod integracji.

<h2 id="recommended-setup">Zalecana konfiguracja</h2>

| Potrzebować | Organizować coś |
| --- | --- |
| Szybkie kontrole rynku | 6MM CLI |
| Kontekst konta lokalnego | Lokalny MCP |
| Powtarzalny przebieg realizacji | Umiejętności agenta |

<h2 id="example-tasks">Przykładowe zadania</h2>

```text
Use 6MM CLI to list available perpetual markets and return JSON.
```

```text
Use 6MM to inspect webhook event examples and generate an idempotent handler plan.
```

```text
Use 6MM testnet data to validate this Trading Widget integration. Do not place live orders.
```

<h2 id="best-practice">Najlepsza praktyka</h2>

Preferuj dane wyjściowe JSON dla przepływów pracy agenta. Łatwiej jest analizować, porównywać i uwzględniać w dziennikach implementacji.
