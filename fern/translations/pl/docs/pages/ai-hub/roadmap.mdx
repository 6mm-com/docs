> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


AI Hub powinien być udostępniany etapami, aby użytkownicy mogli wcześniej uzyskać wartość, a wrażliwe możliwości handlowe pozostały chronione.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## Faza 1: Dostęp do sztucznej inteligencji na rynku publicznym

Cel: pozwolić każdemu obsługiwanemu klientowi AI przeczytać oficjalne 6MM dane rynkowe.

Produkty dostarczane:

- Udostępniony klient SDK / API klienta.
- CLI polecenia rynku publicznego.
- Lokalne MCP narzędzia rynku publicznego.
- Hostowane MCP narzędzia rynku publicznego.
- Zasoby dotyczące rynków, opłat, zasad ryzyka i statusu systemu.
- Przewodniki instalacji klienta.

Nie obejmuje:

- Zapytania dotyczące konta.
- Prawdziwy handel.
- API hosting kluczy.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Faza 2: Przeczytanie konta

Cel: pozwolić użytkownikom bezpiecznie sprawdzać kontekst własnego konta.

Produkty dostarczane:

- Zakres klucza tylko do odczytu API.
- Podsumowanie konta.
- Salda.
- Pozycje.
- Otwórz zamówienia.
- Wypełnia.
- Płatności finansowe.
- Monit dotyczący ryzyka portfela.

Preferowane wdrożenie:

- Lokalny MCP.
- CLI.
- Zdalny MCP hostowany samodzielnie.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Faza 3: Podgląd handlu

Cel: pozwolić AI pomóc w generowaniu zamówień bez ich wykonywania.

Produkty dostarczane:

- `preview_order`.
- Kontrole ryzyka.
- Wpływ na marżę.
- Szacunkowa opłata.
- Wpływ likwidacji.
- Monit planowania wykonania.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Faza 4: Handel kontrolowany

Cel: wspieraj prawdziwy handel tylko mocnymi barierami.

Produkty dostarczane:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- idempotencja.
- maksymalne limity hipotetyczne.
- jednoznaczne potwierdzenie.
- dzienniki audytu.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Faza 5: Umiejętności agentyczne

Cel: stworzenie wspólnej analizy rynku i przepływów pracy w zakresie ryzyka.

Produkty dostarczane:

- Umiejętność analityka rynku.
- Umiejętność ryzyka portfela.
- Umiejętność prowadzenia badań w zakresie finansowania.
- Umiejętność ochrony przed likwidacją.
- Umiejętność planowania wykonania.
- Przykładowa biblioteka zadań.
