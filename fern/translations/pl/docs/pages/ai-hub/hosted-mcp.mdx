> **Planowane — jeszcze nie uruchomione**
> AI Hub to planowana funkcja. Możliwości, punkty końcowe, polecenia i konfiguracje klienta na tej stronie opisują proponowany projekt i nie są obecnie dostępne. Ostateczna dostępność i instrukcje konfiguracji zostaną ogłoszone w momencie premiery.


Hostowane MCP to najprostszy sposób na rozpoczęcie pracy z 6MM AI Hub.

Podłącz klienta AI do punktu końcowego 6MM hostowanego przez MCP i zadawaj pytania dotyczące publicznych danych rynkowych. Nie trzeba instalować lokalnego serwera, nie trzeba utrzymywać wdrożenia w chmurze ani nie jest wymagany klucz użytkownika API do danych publicznych.

<span id="what-you-can-do" data-sixmm-canonical-anchor="what-you-can-do" aria-hidden="true"></span>

## Co możesz zrobić

- Zapytaj o aktualne i historyczne dane rynkowe.
- Przeglądaj dostępne rynki wieczyste.
- Sprawdź głębokość księgi zamówień i ostatnie transakcje.
- Porównaj stawki finansowania.
- Przeczytaj kontekst dotyczący opłaty, umowy, marży i reguły ryzyka.

Hostowany MCP jest najlepszy do badań, eksploracji produktów i analiz rynku publicznego. Nie jest to właściwa pierwsza konfiguracja dostępu do konta prywatnego lub handlu.

<span id="recommended-first-release-scope" data-sixmm-canonical-anchor="recommended-first-release-scope" aria-hidden="true"></span>

## Zalecany zakres pierwszego wydania

Hostowane MCP powinno udostępniać tylko informacje publiczne i tylko do odczytu w pierwszej wersji:

- Rynki.
- Tikery.
- Zamów książki.
- Ostatnie transakcje.
- Klinesa.
- Stawki finansowania.
- Stan systemu.
- Opłaty handlowe.
- Specyfikacje kontraktowe.
- Zasoby dotyczące reguł ryzyka i marży.

<span id="not-supported-in-the-first-release" data-sixmm-canonical-anchor="not-supported-in-the-first-release" aria-hidden="true"></span>

## Nieobsługiwane w pierwszej wersji

Hostowane MCP nie powinno być pierwszym miejscem do ujawniania:

- Salda kont.
- Pozycje.
- Otwórz zamówienia.
- Tworzenie zamówienia.
- Anulowanie zamówienia.
- Przelewy lub wypłaty.
- Użytkownik API przechowywanie kluczy.

<span id="why-public-data-first" data-sixmm-canonical-anchor="why-public-data-first" aria-hidden="true"></span>

## Dlaczego najpierw dane publiczne

Hostowany MCP jest obsługiwany przez 6MM i jest dostępny przez sieć. Jest to wygodne, ale nie powinno stać się domyślnym miejscem, w którym użytkownicy przesyłają prywatne klucze API. Wrażliwe przepływy pracy związane z kontami i transakcjami powinny zaczynać się od lokalnego MCP, CLI lub zarządzanego przez użytkownika zdalnego MCP.

## Wymagania operacyjne

- TLS na wszystkich punktach końcowych.
- Żądaj limitów stawek.
- Ochrona przed nadużyciami.
- Ustrukturyzowane dzienniki i metryki.
- Kontrole stanu zdrowia.
- Przejrzyste opisy narzędzi i schematy.
- Stabilne reakcje na błędy dla klientów AI.
