Skorzystaj z tej listy kontrolnej, zanim udostępnisz użytkownikom produkcyjnym przepływy handlowe 6MMnapędzane. Jest ona zaprojektowana z myślą o tym, by zespoły produktowe, inżynieryjne, operacyjne, ryzykowne i wsparcie mogły je wspólnie przeglądać.

<h2 id="launch-checklist">Lista kontrolna startu</h2>

| Obszar | Lista kontrolna |
| --- | --- |
| Produkt | Punkty wejścia, teksty dla użytkownika, prompty ryzyka, pokrycie języka i ścieżki wsparcia są gotowe. |
| Zaplecze | API poświadczenia, podpisywanie, wydawanie tokenów, webhooki, próby i logowanie są zaimplementowane. |
| Handel | Przeglądano zachowania związane z zamówieniem, transferem, pozycją, marżą, opłatą oraz likwidacją. |
| Bezpieczeństwo | Przygotowywane są sekrety, role dostępu do informacji, monitoringu, reagowania na incydenty oraz rejestrów audytu. |
| Eksploatacja | Przypisane są procesy wsparcia, ścieżki eskalacji, uzgadnianie i codzienny monitoring. |

<h2 id="recommended-sequence">Zalecana kolejność</h2>

1. Kompletna walidacja piaskownicy lub środowiska wewnętrznego.
2. Przeprowadzaj kompleksowe ścieżki użytkownika dotyczące logowania, wprowadzania, transferu, handlu i wsparcia.
3. Potwierdzenie własności monitoringu i reagowania na incydenty.
4. Zatwierdzanie tekstów publicznych, lokalnych zasobów oraz pobierania zasobów.
5. Rozpocznij od kontrolowanego okna startowego przed szeroką promocją.

<h2 id="after-launch">Po wodowaniu</h2>

Codziennie przeglądaj aktywność podczas początkowego okresu uruchamiania. Obserwuj konwersję wpisów, niepowodzenia w emisji tokenów, błędy zamówień, jakość rozrzutu, zakończenie transferów, próby webhooków i zgłoszenia wsparcia razem.
