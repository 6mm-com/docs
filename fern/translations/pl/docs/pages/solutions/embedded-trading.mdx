System Embedded API / SDK Trading został zaprojektowany dla partnerów, którzy już posiadają ruch, użytkowników lub biznesowe workflowy i chcą dodać handel bez budowania pełnej giełdy od podstaw.

<h2 id="what-it-provides">Co zapewnia</h2>

- Wbudowany terminal handlowy przez Trading Widget SDK
- Integracja backendu partnerskiego poprzez Agent SDKs
- Wiązanie tożsamości użytkownika i przepływy tokenów entry
- Transfer aktywów, zlecenia, pozycja i dostęp do API konta
- Integracja zdarzeń, webhooków i cyklu życia systemów operacyjnych

<h2 id="recommended-architecture">Zalecana architektura</h2>

| Warstwa | Odpowiedzialność |
| --- | --- |
| Front partner | Hostuje punkt wejścia i osadza interfejs 6MM tradingu. |
| Backend partnera | Utrzymuje API sekrety, weryfikuje użytkowników, wydaje tokeny osadzające i przetwarza webhooki. |
| 6MM infrastruktura handlowa | Obsługuje interfejs handlowy, dopasowanie, ryzyko, płynność, stan konta oraz cykl życia transakcji. |

<h2 id="choose-an-integration-path">Wybierz ścieżkę integracji</h2>

| Wymagania | Zalecana ścieżka |
| --- | --- |
| Kompletny interfejs handlowy z najszybszą integracją z siecią | Trading Widget |
| Wiązanie użytkownika backendowego, transfer, URLwpisów oraz obsługa webhooków | Agent SDK |
| W pełni dostosowane do produktów i zamówień | REST API + WebSocket |
| Doświadczenie w wymianie markowej o szerszym zakresie operacyjnym | Wymiana białej etykiety |

Ostateczny projekt może łączyć te ścieżki. Potwierdź uwierzytelnianie, własność zasobów, granice odpowiedzialności, monitorowanie i wsparcie produkcyjne przed rozpoczęciem wdrożenia.
