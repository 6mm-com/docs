<h2 id="which-path-should-i-choose">Którą ścieżkę powinienem wybrać?</h2>

| Cel biznesowy | Zalecane rozwiązanie | Lekarze pierwotni |
| --- | --- | --- |
| Dodaj handel do istniejącego produktu | System handlowy Embedded API / SDK | SDK, Deweloperzy |
| Poprawa głębi rynku i jakości realizacji | Rozwiązania płynności instytucjonalnej | Handel, deweloperzy |
| Szybko uruchom markową giełdę | Platforma transakcyjna white-label | Rozwiązania, zasoby |
| Przygotowanie do operacji regulowanych | Licencjonowanie i doradztwo w zakresie zgodności | Bezpieczeństwo i zgodność |

<h2 id="how-the-solutions-connect">Jak rozwiązania się łączą</h2>

Większość implementacji partnerskich łączy więcej niż jedną 6MM zdolność. Giełda white-label może korzystać z płynności instytucjonalnej, wsparcia zgodności oraz integracji API . Partner handlowy wbudowany może zaczynać od Trading Widget SDK , a później dodawać przepływy Agent SDK backendu, przetwarzanie webhooków oraz zasoby operacyjne.
