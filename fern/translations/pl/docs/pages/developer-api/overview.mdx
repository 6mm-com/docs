## Lista kontrolna produkcji

- Przechowywanie API sekretów tylko na zapleczu.
- Synchronizacja czasu serwera przed podpisanymi żądaniami.
- Traktuj wszystkie pola precyzyjności liczbowej jako ciągi znaków, chyba że strona wyraźnie mówi inaczej.
- Używaj idempotencji, identyfikatorów żądań oraz ustrukturyzowanych logów wokół przepływów zamówień.
- Subskrybować WebSocket strumienie stanów, które muszą pozostać aktualne w systemach operacyjnych.
- Przegląd kodów błędów i zachowania ponownej próby przed uruchomieniem.
