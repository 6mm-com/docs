<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Informacje o użytkowniku

```http
GET /v1/private/user/info
```

Pola odpowiedzi:

| Pole                  | Typ   | Opis      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | Zewnętrzny identyfikator użytkownika |
| `userInfo.username`    | string | Nazwa użytkownika         |
| `userInfo.agentId`     | int64  | Identyfikator agenta         |
| `userInfo.vipLevel`    | int64  | VIP poziom        |
| `userInfo.lastLoginAt` | int64  | Ostatni czas logowania  |
| `userInfo.lastLoginIp` | string | Ostatnie IP logowania    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Zasoby użytkownika

```http
GET /v1/private/user/asset
```

Pola odpowiedzi:

| Pole                     | Typ   | Opis                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | Zewnętrzny identyfikator użytkownika                |
| `userAsset.assetType`     | string | Typ aktywów                      |
| `userAsset.walletBalance` | string | Saldo portfela                  |
| `userAsset.frozenMargin`  | string | Margines zamrożony przez oczekujące zamówienia |
| `userAsset.usedMargin`    | string | Margines używany według pozycji        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Stwórz listenKey

```http
POST /v1/private/user/listen-key
```

Tworzy klucz uwierzytelniający dla prywatnych strumieni WebSocket .

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Odnowić listenKey

```http
PUT /v1/private/user/listen-key
```

Rozszerza listenKey ważność.

<span data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Close listenKey

```http
DELETE /v1/private/user/listen-key
```

Zamyka określony listenKey.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Logi zmian konta

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Parametry żądania:

| Parametr    | Typ   | Wymagane | Opis                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | Nie       | Typ aktywa, taki jak `USDT`   |
| `changeType` | string | Nie       | Typ zmiany                  |
| `startTime`  | int64  | Nie       | Czas rozpoczęcia                   |
| `endTime`    | int64  | Nie       | Koniec czasu                     |
| `page`       | int32  | Nie       | Numer strony, domyślny `1`     |
| `pageSize`   | int32  | Nie       | Liczba elementów na stronę, domyślny `20` |

Pola odpowiedzi:

| Pole                        | Typ   | Opis                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Typ aktywów                   |
| `list[].amount`              | string | Zmieniona kwota               |
| `list[].walletBalanceBefore` | string | Saldo portfela przed zmianą |
| `list[].walletBalanceAfter`  | string | Saldo portfela po zmianie  |
| `list[].frozenBalanceBefore` | string | Zamrożona równowaga przed zmianą |
| `list[].frozenBalanceAfter`  | string | Zamrożone saldo po zmianie  |
| `list[].changeType`          | string | Typ zmiany                  |
| `list[].referenceId`         | string | Powiązany identyfikator firmy          |
| `list[].createdAt`           | int64  | Czas tworzenia                |
| `total`                      | int64  | Łączna liczba                  |

## Statystyki objętości za 30 dni

```http
GET /v1/private/user/volume-stats
```

Pola odpowiedzi:

| Pole         | Typ   | Opis                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Skumulowany wolumen handlu w ciągu ostatnich 30 dni |
| `feeTotal30d` | string | Skumulowane opłaty z ostatnich 30 dni           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## Historia balansu

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Parametry żądania:

| Parametr | Typ   | Wymagane | Opis                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Tak      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | Nie       | Liczba zwróconych przedmiotów, domyślna `30` |

Pola odpowiedzi:

| Pole             | Typ   | Opis                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Data agregacji            |
| `items[].balance` | string | Saldo portfela              |
| `items[].pnl`     | string | Zrealizowane PnL dla tego okresu |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Przegląd handlu

```http
GET /v1/private/user/trade-overview?type=1M
```

Parametry żądania:

| Parametr | Typ   | Wymagane | Opis                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Tak      | Zakres trendów: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Pola odpowiedzi:

| Pole                | Typ   | Opis                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | Dzisiejsze zrealizowane PnL                                                 |
| `todayVolume`        | string | Dzisiejszy wolumen handlu kontraktami                                      |
| `totalVolume`        | string | Skumulowany wolumen handlu kontraktami                                   |
| `totalPnl`           | string | Skumulowana zrealizowana PnL                                              |
| `maxDrawdown30d`     | string | Maksymalna kwota wypłaty w ciągu ostatnich 30 dni                        |
| `maxDrawdown30dRate` | string | Maksymalna stopa spadku w ciągu ostatnich 30 dni, dziesiętna od `0` do `1` |
| `transferIn`         | string | Skumulowane środki przetransferowane                                      |
| `transferOut`        | string | Skumulowane środki przeniesione                                     |
| `items[]`            | array  | Dane trendów aktywów                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Przegląd aktywów Podsumowanie

```http
GET /v1/private/user/asset/overview/summary
```

Pola odpowiedzi są takie same jak pola podsumowania transakcji, z wyjątkiem `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Przegląd aktywów Trend

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Parametry żądania:

| Parametr | Typ   | Wymagane | Opis                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Tak      | Zakres trendów: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Pola odpowiedzi:

| Pole                  | Typ   | Opis                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Czas migawki                   |
| `items[].balance`      | string | Saldo rachunku bieżącego         |
| `items[].pnl`          | string | PnL na obecny okres      |
| `items[].pnlRate`      | string | Stawka PnL na bieżący okres |
| `items[].totalPnl`     | string | Skumulowane PnL                  |

## Ulubione symbole

<span id="save" data-sixmm-canonical-anchor="save" aria-hidden="true"></span>

## Zapisz

```http
POST /v1/private/user/favorite-symbols
Content-Type: application/json
```

Główna część zgłoszenia:

```json
{
  "symbols": ["BTCUSDT", "ETHUSDT"]
}
```

## Zapytanie

```http
GET /v1/private/user/favorite-symbols
```

Pola odpowiedzi:

| Pole     | Typ      | Opis          |
| --------- | --------- | -------------------- |
| `symbols` | String\[] | Lista ulubionych symboli |
