## Kolejność miejsc

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Parametry żądania:**

| Parametr       | Typ   | Wymagane               | Opis                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Tak                    | Symbol                                                                                                                        |
| `type`          | string | Tak                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Tak                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Nie                     | `BOTH` / `LONG` / `SHORT`, domyślny `BOTH`                                                                                     |
| `price`         | string | Warunkowo wymagane | Wymagane dla zleceń limitujących                                                                                                     |
| `quantity`      | string | Warunkowo wymagane | Ilość. Można pominąć, gdy `closePosition=true`                                                                            |
| `timeInForce`   | string | Nie                     | `GTC` / `IOC` / `FOK`, domyślny `GTC`                                                                                          |
| `reduceOnly`    | bool   | Nie                     | Tylko redukcja, domyślny `false`                                                                                                  |
| `makerOnly`     | bool   | Nie                     | Tylko dla twórców, domyślny `false`                                                                                                   |
| `closePosition` | bool   | Nie                     | Zamykam całą pozycję, domyślnie `false`                                                                                    |
| `clientOrderId` | string | Nie                     | Identyfikator zamówienia definiowany przez klienta                                                                                                       |
| `placeType`     | string | Nie                     | Znacznik typu rozkazu                                                                                                   |
| `priceType`     | int32  | Nie                     | BBO typ ceny: `0` określoną cenę, `1`  przeciwnika 1, `2` przeciwnika 5, `3` cena tej samej strony 1 `4` cena tej samej strony 5 |

**Przykład prośby:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Pola odpowiedzi:**

| Pole           | Typ   | Opis             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | ID zamówienia serwera         |
| `clientOrderId` | string | Identyfikator zamówienia definiowany przez klienta |
| `status`        | string | Status zamówienia            |
| `timestamp`     | int64  | Znacznik czasu               |

## Zamówienia na składanie partii

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Ciało prośby:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Pola odpowiedzi:**

| Pole          | Typ  | Opis                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Liczba udanych zamówień |
| `failedCount`  | int32 | Liczba nieudanych zamówień     |
| `results[]`    | array | Wynik dla każdego zamówienia       |

## Kolejność warunków miejsca

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Parametry żądania:**

| Parametr       | Typ   | Wymagane               | Opis                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Tak                    | Symbol                                                                                      |
| `type`          | string | Tak                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Tak                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Nie                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Warunkowo wymagane | Wymagane dla `STOP_LIMIT` / `TAKE_PROFIT_LIMIT`                                             |
| `quantity`      | string | Warunkowo wymagane | Ilość. Można pominąć, gdy `closePosition=true`                                          |
| `timeInForce`   | string | Nie                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Nie                     | Redukująca tylko                                                                                 |
| `clientOrderId` | string | Nie                     | Identyfikator zamówienia definiowany przez klienta                                                                     |
| `stopPrice`     | string | Warunkowo wymagane | Cena wyzwalająca                                                                               |
| `workingType`   | string | Nie                     | `MARK_PRICE` / `CONTRACT_PRICE`, domyślny `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Nie                     | Czy ochrona cen jest możliwa                                                         |
| `activatePrice` | string | Warunkowo wymagane | Cena aktywacji kolejnych zamówień                                                             |
| `callbackRate`  | string | Warunkowo wymagane | Wskaźnik odwołań kolejnych zamówień                                                                |
| `closePosition` | bool   | Nie                     | Zamknąć całą pozycję                                                                   |

**Pola odpowiedzi:**

| Pole             | Typ   | Opis            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | Identyfikator kolejności warunków     |
| `conditionStatus` | string | Status kolejności warunków |
| `timestamp`       | int64  | Znacznik czasu              |

## Kolejność strategii placowania

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Parametry żądania:**

| Parametr      | Typ   | Wymagane | Opis             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Tak      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Tak      | Lista podporządkowań          |

Pola w `subOrderList[]` są w większości takie same jak porządki normalne i porządki warunkowe, z dodatkowymi polami zależności:

| Parametr        | Typ   | Opis                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | ID podrzędu                                    |
| `firstDrivenId`  | int64  | Pierwszy identyfikator z rozkazu jazdy. `0` oznacza brak zależności |
| `firstDrivenOn`  | string | Pierwszy warunek wyzwalacza                         |
| `firstTrigger`   | string | Pierwszy ruch spustu                            |
| `secondDrivenId` | int64  | Drugi identyfikator nakazu jazdy                         |
| `secondDrivenOn` | string | Drugi warunek wyzwalacza                        |
| `secondTrigger`  | string | Druga akcja spustu                           |

**Pola odpowiedzi:**

| Pole            | Typ   | Opis     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | ID strategii     |
| `strategyStatus` | string | Status strategii |
| `timestamp`      | int64  | Znacznik czasu       |

## Zapytanie o pojedynczy rząd

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Parametry żądania:**

| Parametr       | Typ   | Wymagane | Opis             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Tak      | Symbol                  |
| `orderId`       | string | Nie       | ID zamówienia serwera         |
| `clientOrderId` | string | Nie       | Identyfikator zamówienia definiowany przez klienta |

Należy podać co najmniej jeden z `orderId` i `clientOrderId` . Jeśli oba są dostępne, serwer wykonuje dokładne dopasowanie pod obiema warunkami.

## Anuluj wszystko

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Parametry żądania:**

| Parametr    | Typ   | Wymagane | Opis                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Nie       | Symbol                                                                              |
| `cancelType` | int32  | Nie       | `0` wszystkie normalne rozkazy, `1` tylko limit, `2` wszystkie porządki warunkowe. Domyślne `0` |

Anulowanie wszystkich dla zwykłych zamówień jest akceptowane asynchronicznie. Ostateczny status powinien być określany przez WebSocket `ORDER_TRADE_UPDATE` lub punkty końcowe zapytania.
