## Punkt końcowy usługi

```
wss://ws.6mm.com/ws
```

WebSocket kanały dzielą się na kanały publiczne i prywatne:

| Typ             | Uwierzytelnianie              | Opis                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Kanały publiczne  | Nie jest wymagane                | Dane rynkowe, takie jak głębokość, transakcje, Kliny i ticker |
| Kanały prywatne | `listenKey` lub JWT wymagane | Kolejność użytkowników, strumienie kont i pozycji              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## Kanały publiczne

Publiczne WebSocket nie wymagają uwierzytelniania. Po połączeniu wyślij `subscribe` zapytanie o subskrypcję kanałów rynkowych.

Wspólne kanały:

| Kanał                            | Opis                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Zamów książkę na głębokość. Najpierw wysyła migawkę, potem stopniowe aktualizacje |
| `market.trade.{symbol}`            | Najnowsze wydania                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Podsumowanie pojedynczego symbolu                                       |
| `market.tickers`                   | Podsumowanie wszystkich symbolicznych sercówek                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## Kanały prywatne

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
W przypadku prywatnych strumieni WebSocket najpierw stwórz `listenKey` przez REST API , a następnie połącz się z:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
Kompatybilna metoda JWT połączenia:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Po udanym uwierzytelnieniu serwer automatycznie subskrybuje połączenie z prywatnym kanałem obecnego użytkownika. Nie jest wymagana ręczna subskrypcja.
