Korzystaj z publicznych kanałów rynkowych, gdy aplikacja wymaga ciągłej aktualizacji cen, transakcji, świec lub głębokości księgi zamówień, bez ciągłego sprawdzania REST punktów końcowych. Strumienie te mogą obsługiwać ekrany handlowe, wyświetlanie cen, alerty oraz monitorowanie rynku.

<span id="connection-url" data-sixmm-canonical-anchor="connection-url" aria-hidden="true"></span>

## Połączenie URL

```
wss://ws.6mm.com/ws
```

Publiczne WebSocket nie wymagają uwierzytelniania.

O zachowaniu cyklu życia połączenia, wypisywania subskrypcji, pingu i ponownego połączenia zobacz [Połączenie, subskrypcję i bicie serca](/pl/developer-api/websocket/connection-subscription-and-heartbeat).

<span id="common-channels" data-sixmm-canonical-anchor="common-channels" aria-hidden="true"></span>

## Kanały wspólne

| Kanał                            | Opis                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Zamów książkę na głębokość. Najpierw wysyła migawkę, potem stopniowe aktualizacje |
| `market.trade.{symbol}`            | Najnowsze wydania                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Podsumowanie pojedynczego symbolu                                       |
| `market.tickers`                   | Podsumowanie wszystkich symbolicznych sercówek                                          |

<span id="choose-a-channel" data-sixmm-canonical-anchor="choose-a-channel" aria-hidden="true"></span>

## Wybierz kanał

| Potrzeba zastosowania | Kanał |
| --- | --- |
| Zbuduj lub utrzymuj księgę zamówień | `market.depth.{symbol}` |
| Wyświetlaj transmisję na żywo | `market.trade.{symbol}` |
| Narysuj wykres świecowy | `market.kline.{symbol}.{interval}` |
| Wyświetl jedno podsumowanie rynku | `market.ticker.{symbol}` |
| Utrzymuj przegląd rynku | `market.tickers` |

<span id="subscription-example" data-sixmm-canonical-anchor="subscription-example" aria-hidden="true"></span>

## Przykład subskrypcji

```json
{ "id": "1772007814666", "op": "subscribe", "args": ["market.depth.BTCUSDT"] }
```

<span id="push-message-wrapper" data-sixmm-canonical-anchor="push-message-wrapper" aria-hidden="true"></span>

## Opakowanie wiadomości push

```json
{
  "topic": "market.depth.BTCUSDT",
  "event": "data",
  "ts": 1772007815000,
  "data": {}
}
```

Użyj `topic` do kierowania każdej wiadomości do właściwego handlera oraz `ts` do obserwowania czasu dostawy. Obiekt `data` zawiera ładunek dla subskrybowanego kanału.

<span id="order-book-handling" data-sixmm-canonical-anchor="order-book-handling" aria-hidden="true"></span>

## Obsługa w księdze zamówień

Kanał głębi najpierw wysyła migawkę, a potem stopniowe aktualizacje. Zainicjalizuj lokalną księgę z migawki przed wprowadzeniem aktualizacji. Po ponownym połączeniu utwórz nową sesję, ponownie subskrybuj i odbuduj lokalną książkę z następnego snapshotu zamiast kontynuować od starego stanu w pamięci.

<span id="production-recommendations" data-sixmm-canonical-anchor="production-recommendations" aria-hidden="true"></span>

## Zalecenia produkcyjne

- Generuj unikalny `id` dla każdego zgłoszenia, wypisania i pingu.
- Potwierdzenie potwierdzenia subskrypcji przed uznaniem kanału za aktywny.
- Ponownie subskrybuj każdy wymagany temat po ponownym połączeniu.
- Trzymaj odczyty sieciowe oddzielnie od wolniejszego przetwarzania baz danych lub interfejsu użytkownika.
- Monitorować częstotliwość rozłączeń, opóźnienia przetwarzania wiadomości oraz nieprawidłowe ładunki.
- Użyj [Prywatnego Kanału Użytkownika](/pl/developer-api/websocket/private-user-channel) do uwierzytelnionych aktualizacji konta i zamówień.
