> REST Bazowy URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Ta dokumentacja jest przeznaczona dla zewnętrznych systemów integrujących się z usługą 6MM API . Obejmuje logowanie, uwierzytelnianie JWT , zarządzanie API Key , podpisywanie API Key HMAC , zapytania o konta, zlecenia, pozycje, dane rynkowe oraz strumienie WebSocket .

Tworzenie kont i przygotowanie finansowania realizowane są za pomocą procesów platformowych. Ta dokumentacja opisuje jedynie zewnętrzne końcowe API usługi.

## Punkty końcowe usług

| Typ      | Punkt końcowy              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Przepływ integracji

Zalecana sekwencja integracji:

1. Zaloguj się za pomocą konta udostępnionego przez platformę i pobierz `accessToken`.
2. Aby uzyskać dostęp programowy po stronie serwera, najpierw stwórz API Key z JWT i bezpiecznie przechowuj jednorazowy zwrot `apiSecret`.
3. Zapytania prywatne oraz punkty końcowe zleceń i pozycji można wywoływać za pomocą `Authorization: Bearer <accessToken>` albo podpisu API Key.
4. Dla prywatnych strumieni WebSocket najpierw utwórz `listenKey` , a następnie połącz się z `wss://ws.6mm.com/ws?listenKey=...`.
5. Dane rynkowe REST punktach końcowych i publicznych kanałach WebSocket nie wymagają uwierzytelniania.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Wybór uwierzytelniania

| Scenariusz                               | Zalecana metoda         |
| -------------------------------------- | -------------------------- |
| Działania użytkownika frontendu                  | JWT                        |
| Wywołania programowe po stronie serwera         | API Key + HMAC podpis   |
| API Key tworzenie, aktualizacja i usuwanie | JWT                        |
| REST na rynku publicznym / WebSocket  | Nie jest wymagane uwierzytelnianie |
