## Odkryj dostępne narzędzia

Po autoryzacji OAuth użyj klienta MCP z funkcją Streamable HTTP, aby zainicjować połączenie i uzyskać narzędzia poprzez `tools/list`. Wywołaj narzędzia poprzez `tools/call`. Przeczytaj każdy zwrócony schemat wejściowy, zamiast wyprowadzać parametry z adresów URL REST. Identyfikatory pobierane z odczytów to zazwyczaj ciągi dziesiętne dla argumentów ścieżki; pole numeryczne wewnątrz treści pozostaje numeryczne, jeśli schemat tego wymaga.

Poniższe przykłady to komunikaty narzędzia JSON-RPC po inicjalizacji, a nie kompletne, samodzielne żądania HTTP. Klient dostarcza token dostępu i nagłówki protokołu. Zastąp przykładowe identyfikatory dokumentami zwróconymi dla własnego najemcy.

<span id="read-categories" data-sixmm-canonical-anchor="read-categories" aria-hidden="true"></span>

## Czytaj kategorie

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "knowledge_get_categories",
    "arguments": {}
  }
}
```

<span id="create-a-draft" data-sixmm-canonical-anchor="create-a-draft" aria-hidden="true"></span>

## Utwórz wersję roboczą

Wybierz istniejącą kategorię z wyniku odczytu. Kategoria jest wymagana. Nie ustawiaj statusu opublikowanego, chyba że masz zamiar opublikować i wypełnić wymagane potwierdzenie.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "knowledge_create_article",
    "arguments": {
      "requestId": "support-demo-create-001",
      "body": {
        "title": "Withdrawal guide draft",
        "content": "Reviewed withdrawal instructions go here.",
        "categoryId": 12,
        "status": "draft"
      }
    }
  }
}
```

<span id="preview-an-update-or-deletion" data-sixmm-canonical-anchor="preview-an-update-or-deletion" aria-hidden="true"></span>

## Podgląd aktualizacji lub usunięcia

Najpierw przeczytaj artykuł. Wyświetl podgląd dokładnego zamierzonego zapisu, w tym nowego identyfikatora żądania. Podgląd nie wykonuje tego.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "mcp_preview",
    "arguments": {
      "tool": "knowledge_delete_article",
      "arguments": {
        "id": "123",
        "requestId": "support-demo-delete-001"
      }
    }
  }
}
```

Skopiuj zwrócone `version` do `expectedVersion` bez zmiany zamierzonego celu lub parametrów:

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "knowledge_delete_article",
    "arguments": {
      "id": "123",
      "requestId": "support-demo-delete-001",
      "expectedVersion": "REPLACE_WITH_THE_64_CHARACTER_VERSION_FROM_PREVIEW"
    }
  }
}
```

Symbol zastępczy nie jest prawidłową wersją. Użyj rzeczywistej wartości 64-znakowej zwróconej przez podgląd.

## Potwierdź i sprawdź wynik

Jeśli wynik zostanie zgłoszony `awaiting_approval`, otwórz `approvalUrl`, zaloguj się jako konto autoryzujące i przejrzyj akcję. Dopiero zatwierdzenie uruchamia oczekującą operację. Potwierdzenie wygasa obecnie po 15 minutach. Odrzucenie lub wygaśnięcie nie powoduje wykonania zapisu.

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "mcp_operation",
    "arguments": {
      "operationId": "REPLACE_WITH_RETURNED_OPERATION_ID"
    }
  }
}
```

Dane wyjściowe narzędzia są przesyłane w treści tekstowej zawierającej JSON; sprawdź to i dowolną flagę `isError`. Sama odpowiedź HTTP lub link zatwierdzający nie są gwarancją sukcesu. Przeczytaj status operacji i, jeśli to konieczne, prześlij zapytanie do rekordu, którego to dotyczy.

<span id="retry-safely" data-sixmm-canonical-anchor="retry-safely" aria-hidden="true"></span>

## Spróbuj ponownie bezpiecznie

Użyj ponownie tego samego `requestId` i argumentów, aby ponowić próbę sieciową tego samego zapisu. Nie używaj go ponownie do innego działania. Jeśli treść uległa zmianie, przeczytaj ponownie i wyświetl podgląd, a następnie prześlij nową zamierzoną operację z nowym identyfikatorem żądania. Jeśli odpowiedź zostanie utracona lub operacja będzie nadal wykonywana, przed podjęciem decyzji, co zrobić, sprawdź jej status i historię działalności; nigdy nie zakładaj, że przekroczenie limitu czasu oznacza, że ​​nic się nie wydarzyło.

Klient AI zwykle wykonuje ten protokół za użytkownika. Te szczegóły są przeznaczone dla programistów klientów i do diagnozowania przepływu pracy narzędzia.
