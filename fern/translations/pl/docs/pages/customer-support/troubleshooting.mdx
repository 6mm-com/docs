## Wsparcie konsoli i gości

| Objaw | Najpierw sprawdź |
| --- | --- |
| Brakuje menu | Rola konta i dostępność usług dzierżawcy |
| Widżet nie otwiera się | Wygenerowany skrypt URL, klucz aplikacji, dozwolone błędy domeny i przeglądarki |
| Bot nie używa dużego modelu | Rzeczywisty dopasowany krok, inteligentne przełączniki serwisowe i odpowiednia konfiguracja |
| Odpowiedź wykorzystuje stare zasady | Artykuł źródłowy, status publikacji, FAQ tekst, stan tłumaczenia i pobierania |
| Brakuje tłumaczenia | Język docelowy, zmiana tłumaczenia, zapisane tłumaczenie i dostępność usług/salda |
| Generowanie wektorów nie powiodło się | Dostępność i status usługi; unikaj wielokrotnego odbudowy bez zidentyfikowania awarii |
| Pole kontaktowe jest puste | Czy to pole zostało rzeczywiście zebrane; rozróżnij e-mail kontaktowy i wejściowy |

## MCP połączenie i połączenia

| Objaw | Następny krok |
| --- | --- |
| Otwarcie punktu końcowego w przeglądarce powoduje zwrócenie błędu | Jest to punkt końcowy protokołu, a nie strona logowania; dodaj go do kompatybilnego klienta MCP. |
| Nie można rozpocząć autoryzacji | Sprawdź dokładny punkt końcowy, obsługę Streamable HTTP/OAuth klienta i przebieg logowania do przeglądarki |
| Nieautoryzowane lub wygasłe połączenie | Sprawdź unieważnienie i wygaśnięcie; połącz się ponownie poprzez aplikację |
| Brak narzędzia lub odmowa dostępu | Sprawdź rolę konta autoryzującego i zakres rekordów; odśwież listę narzędzi |
| Oczekiwanie na zatwierdzenie | Otwórz zwrócony link do zatwierdzenia i przejrzyj go w zapleczu |
| Treść zmieniona | Przeczytaj najnowszy rekord, przejrzyj ponownie i prześlij nową zamierzoną operację |
| Upłynął limit czasu żądania | Zapytaj o stan operacji przed ponowną próbą lub założeniem niepowodzenia |
| Brak zapisu dziennika | Rozróżnij odczyt, oczekiwanie na zatwierdzenie i ukończony zapis; sprawdź filtry w dziennikach operacji |

## Przed skontaktowaniem się z pomocą techniczną

Zbierz godzinę i strefę czasową, dzierżawcę/konto, którego dotyczy problem, nazwę strony lub narzędzia, identyfikator operacji, jeśli jest dostępny, oraz dokładny błąd. Dołącz zredagowany zrzut ekranu lub kroki umożliwiające odtworzenie. Nie wysyłaj haseł, kodów weryfikacyjnych, tokenów na okaziciela ani tajemnic podpisywania.

Podczas diagnozowania zapisów wypróbuj mały rekord testowy. Sprawdź wynik i wyczyść tylko utworzone dane testowe, korzystając w razie potrzeby z normalnego procesu potwierdzania.
