Wyjątki mogą obejmować zakłócenia w kursie, niespójne dowody cenowe, rozbieżności kursów lub nieudane przetworzenie rozliczenia. Wyjątek wymaga zarejestrowanego rozwiązania; nie jest to automatycznie wynik przegrany.

<span id="typowe-sytuacje" data-sixmm-anchor-target="common-situations" aria-hidden="true"></span>
<h2 id="common-situations">Typowe sytuacje</h2>

| Sytuacja | Co robić |
| --- | --- |
| Brak zasilania sieciowego w prawidłowym oknie | Sprawdź przetwarzanie wyjątków/zwrotów; brak próbki nie może świadczyć o chybieniu |
| Upłynął limit czasu odpowiedzi na zamówienie | Przed ponownym przesłaniem sprawdź oryginalne zamówienie i rezerwację |
| Wynik wyświetlany i zarejestrowany nie zgadzają się | Porównaj źródło cen, znaczniki czasu, zaakceptowane warunki i dowody wyników |
| Rozliczenie wydaje się opóźnione | Sprawdź status końcowy i transakcję osobno |
| Dokument zwrócony lub unieważniony | Przejrzyj przyczynę, faktyczny ruch środków i pozostałą rezerwację |

<span id="zwrot-pieniędzy-i-unieważnienie-to-odrębne-kwestie" data-sixmm-anchor-target="refund-and-void-are-distinct" aria-hidden="true"></span>
<h2 id="refund-and-void-are-distinct">Zwrot pieniędzy i unieważnienie to odrębne kwestie</h2>

Zwrot opisuje sposób traktowania funduszu. Pustka oznacza unieważnienie zamówienia. Nie należy wyciągać dokładnej kwoty zwrotu ani terminu realizacji na podstawie samej etykiety; korzystać z zarejestrowanych uchwał i transakcji.

Zwrócone i unieważnione zamówienia są wyłączone z ważnego udziału w raportowaniu. Zwrotów pieniędzy nie należy liczyć jako wygranych przy ocenie wydajności rozgrywki.

<span id="dowody-potwierdzające" data-sixmm-anchor-target="support-evidence" aria-hidden="true"></span>
<h2 id="support-evidence">Dowody potwierdzające</h2>

Podaj numer zamówienia, okrągły numer, jeśli ma to zastosowanie, symbol, odpowiednie znaczniki czasu, zarejestrowany mnożnik wypłaty, wynik/status i numer transakcji rozliczeniowej. W przypadku sporów dotyczących sieci podaj zaakceptowany przedział cenowy i ważny przedział czasowy. Nigdy nie podawaj haseł, API sekretów ani tokenów pełnego dostępu.

Używać [Wsparcie partnera](/pl/resources/contact/support) dla ścieżki wsparcia i [Transfery i transakcje](/pl/prediction/transfers-ledger) dla pojednania.
