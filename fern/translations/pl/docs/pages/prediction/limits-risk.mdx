Oferowana gra lub wycena nie gwarantuje przyjęcia każdego zaproponowanego zamówienia. Dostępne fundusze, konfiguracja produktu i kontrola ryzyka wpływają na akceptację.

<span id="powszechne-ograniczenia" data-sixmm-anchor-target="common-restrictions" aria-hidden="true"></span>
<h2 id="common-restrictions">Powszechne ograniczenia</h2>

| Ograniczenie | Efekt |
| --- | --- |
| Gra lub symbol wyłączone | Wybrany produkt jest niedostępny dla nowych zamówień |
| Okres nie jest włączony | Nie można wybrać tego czasu trwania dla symbolu |
| Minimalne/maksimum pojedynczego zamówienia | Stawka musi mieścić się w wyświetlanym dozwolonym zakresie |
| Skumulowany udział lub kontrola ekspozycji | Dalsze zlecenia mogą zostać ograniczone nawet wtedy, gdy pojedyncza stawka jest ważna |
| Kontrola odchyleń kursów | Oferta może wymagać sprawdzenia lub wprowadzenie prognozy może zostać ograniczone |
| Cytat sieciowy powyżej maksimum | Komórka jest niedostępna w ramach reguły cenowej sieci |
| Zamknięte okno zakładów | Nowe zamówienie nie może zostać przyjęte do zamkniętego okna |

Model zarządzania obejmuje alerty, przeglądy, ograniczenia predykcji i obsługę opóźnionych zamówień. Rzeczywista odpowiedź zależy od uruchomionej reguły; nie zakładaj, że każde ograniczenie daje ten sam wynik.

<span id="ryzyko-stawki-i-modelu" data-sixmm-anchor-target="stake-and-model-risk" aria-hidden="true"></span>
<h2 id="stake-and-model-risk">Ryzyko stawki i modelu</h2>

Przegrane zlecenie bez wypłaty traci swoją stawkę. Większe kursy nie są dowodem na lepszą okazję: mogą odzwierciedlać niższe szacowane prawdopodobieństwo trafienia. Docelowy parametr zwrotu nie gwarantuje zwrotu indywidualnego.

<span id="zmiany-konfiguracji" data-sixmm-anchor-target="configuration-changes" aria-hidden="true"></span>
<h2 id="configuration-changes">Zmiany konfiguracji</h2>

Przed złożeniem nowego zamówienia sprawdź aktualne ustawienia produktu. W przypadku zaakceptowanych zamówień niestandardowych i siatkowych zachowane kursy i odpowiednie migawki zamówień uniemożliwiają ponowne zdefiniowanie zaakceptowanych warunków przy późniejszym odświeżeniu ekranu.

<span id="gdy-zamówienie-jest-niedostępne" data-sixmm-anchor-target="when-an-order-is-unavailable" aria-hidden="true"></span>
<h2 id="when-an-order-is-unavailable">Gdy zamówienie jest niedostępne</h2>

Sprawdź zmianę produktu, dostępne saldo, limity, wycenę i termin. Nie przesyłaj ponownie, aby ominąć ograniczenie. Zachowaj odpowiedź i identyfikator zamówienia, jeśli został utworzony.
