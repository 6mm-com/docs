Używaj tego szablonu podczas przygotowywania nowej integracji lub przenoszenia istniejącej integracji do produkcji.

<h2 id="partner-information">Informacje o partnerze</h2>

| Pole | Opis |
| --- | --- |
| Imię partnera | Nazwa prawna lub projekt użyta do integracji. |
| Typ produktu | Aplikacja, portfel, portal brokerski, giełda white-label, platforma instytucjonalna lub inny. |
| Główne kontakty | Kontakty biznesowe, techniczne, operacyjne i awaryjne. |
| Regiony startu | Kraje lub regiony, w których integracja zostanie ujawniona. |

<h2 id="technical-information">Informacje techniczne</h2>

| Pole | Opis |
| --- | --- |
| Domeny frontendowe | Domeny, które ładują widżet lub strony wejściowe. |
| Domeny backendowe | Domeny serwerów używane do wywołań Agent SDK lub API . |
| Webhook URL | Produkcyjny endpoint webhook oraz wymagania dotyczące listy dozwolonych IP oczekiwanych usług. |
| Zakres integracji | Trading Widget, Agent SDK, REST API, WebSocket, system white-label lub integracja płynności. |

<h2 id="operational-information">Informacje operacyjne</h2>

- Spodziewana data startu.
- Oczekiwany ruch lub zakres aktywnego użytkownika.
- Godziny wsparcia i właściciel eskalacji.
- Monitorowanie kontaktu właściciela i incydentu.

<h2 id="security-and-review-information">Informacje o bezpieczeństwie i przeglądzie</h2>

- Metoda uwierzytelniania i zakres API Key uprawnień.
- Tajne przechowywanie, właściciel rotacji oraz zatwierdzone adresy IP źródłowe.
- Weryfikacja podpisu webhooka i projektowanie idempotencji.
- Rejestrowanie, monitorowanie, uzgadnianie, cofanie i reagowanie na incydenty.
- Rynki docelowe, typ użytkownika, model opieki oraz podmiot odpowiedzialny za zobowiązania wobec użytkownika.

Nie uwzględniaj w tym szablonie sekretów produkcyjnych, tokenów pełnego dostępu, kluczy prywatnych ani niecenzurowanych danych użytkowników.

Użyj [lista kontrolna uruchomienia produkcji](/pl/resources/production-launch-checklist) do ostatecznej zgody oraz [szablon żądania wsparcia](/pl/resources/support-request-template) do eskalacji problemu.
