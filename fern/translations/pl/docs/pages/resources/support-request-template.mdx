Kontaktując się z pomocą techniczną, dołącz poniższe informacje, gdy tylko są dostępne.

<span id="required-context" data-sixmm-canonical-anchor="required-context" aria-hidden="true"></span>

## Wymagany kontekst

| Pole | Przykład |
| --- | --- |
| Środowisko | Produkcja lub inscenizacja |
| Dotknięty moduł | Trading Widget, Agent SDK, REST API, WebSocket, webhook, system white-label |
| Zakres czasowy | UTC zakres czasowy w momencie wystąpienia |
| Identyfikator użytkownika partnera | Identyfikator użytkownika po stronie partnera, jeśli jest istotny |
| 6MM ID mapowania | agentUserId, ID zamówienia, ID żądania lub identyfikator zdarzenia webhook |
| Wpływ na działalność biznesową | Liczba dotkniętych użytkowników lub operacji oraz czy problem trwa |

<span id="description-format" data-sixmm-canonical-anchor="description-format" aria-hidden="true"></span>

## Format opisu

- Co się stało?
- Czego się spodziewałeś?
- Czy można to odtworzyć?
- Co się ostatnio zmieniło?
- Czy problem nadal trwa?

<span id="attachments" data-sixmm-canonical-anchor="attachments" aria-hidden="true"></span>

## Załączniki

- Odpowiednie dzienniki żądań i odpowiedzi.
- Zrzuty ekranu lub nagrania ekranu.
- Ładunek Webhook i nagłówki podpisów.
- Błędy konsoli przeglądarki dla Trading Widget problemów.

<span id="copyable-template" data-sixmm-canonical-anchor="copyable-template" aria-hidden="true"></span>

## Szablon do kopiowania

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Usuń pola, które nie są istotne, ale zachowaj UTC przedział czasowy oraz przynajmniej jeden wyszukiwalny zapytanie lub identyfikator biznesowy, jeśli to możliwe.

<span id="redact-sensitive-data" data-sixmm-canonical-anchor="redact-sensitive-data" aria-hidden="true"></span>

## Zredaguj dane wrażliwe

Nie wysyłaj:

- Hasła lub tokeny pełnego dostępu
- API sekrety, klucze prywatne lub pełne podpisy
- Ciasteczka sesyjne
- Pełna płatność, tożsamość lub inne niepotrzebne dane osobowe

Zachowaj nazwę pola i krótki prefiks lub sufiks tylko wtedy, gdy wsparcie musi rozróżnić wartości oczyszczone.
