## 推荐接入方式

| 需求 | 方式 |
| --- | --- |
| 公开市场研究 | Hosted MCP |

| 团队内部统一端点 | Remote MCP |

## 示例提示词

```text
使用 6MM 对比 BTC 和 ETH 的市场深度，并说明哪里流动性更强。
```

```text
使用 6MM 检查我的账户风险。只读取数据，并输出摘要。
```

<span id="notes" data-sixmm-canonical-anchor="notes" aria-hidden="true"></span>

## 说明

只要涉及私有账户数据，优先使用 Local MCP。MCP 服务在用户本机运行，凭证不需要提交到 6MM 托管的 AI 端点。
