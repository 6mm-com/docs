> **规划中 · 尚未上线**
> AI Hub 为规划内容。本页中的功能、服务地址、命令及客户端配置用于说明拟定方案，目前尚未开放使用。实际开放范围与接入方式以上线公告为准。


Remote MCP 面向希望在自有基础设施中运行长期在线 MCP 端点的用户或机构。

与 Hosted MCP 不同，Remote MCP 不是 6MM 帮用户托管服务。6MM 提供代码、镜像、模板和文档，用户自己控制部署和凭证。

<span id="architecture" data-sixmm-canonical-anchor="architecture" aria-hidden="true"></span>

## 架构

```text
AI 客户端
  -> 用户自管 MCP HTTP 端点
  -> 6MM REST / WebSocket API
```

<span id="deployment-targets" data-sixmm-canonical-anchor="deployment-targets" aria-hidden="true"></span>

## 部署目标

- Docker 或 Docker Compose。
- VPS 加反向代理。
- Railway。
- Render。
- Fly.io。
- AWS ECS 或 Lambda。
- 内部 Kubernetes。

<span id="required-files" data-sixmm-canonical-anchor="required-files" aria-hidden="true"></span>

## 必需文件

- Dockerfile。
- docker-compose.yml。
- .env.template。
- HTTP transport 模式。
- /mcp 端点。
- /health 端点。
- 反向代理和 TLS 说明。

<span id="credential-model" data-sixmm-canonical-anchor="credential-model" aria-hidden="true"></span>

## 凭证模型

凭证应存储在用户自管环境中，不应写入 AI 客户端提示词。机构自管部署应限制允许访问的客户端和网络。

<span id="recommended-first-release" data-sixmm-canonical-anchor="recommended-first-release" aria-hidden="true"></span>

## 第一阶段建议

先支持公开市场数据。账户只读应在鉴权、key 权限范围、日志和访问控制到位后再开放。真实交易应在受控交易要求满足前保持关闭。
