## 准备租户后台

使用分配给本租户的账号进入[客服后台](https://csadmin.6mm.com/)，按登录页面要求完成安全设置。看不到某个菜单时，先让租户管理员检查角色权限。

1. **配置团队。** 在「客服管理」建立角色和客服账号，明确会话查看、内容编辑和设置管理权限。
2. **准备业务知识。** 在「内容管理」整理账户接入、充值提现流程、交易规则、费用和人工支持说明，创建分类与文章，审核并发布需要展示的内容。
3. **配置自动回复。** 在「系统设置」开启所需智能服务；在「机器配置」检查 FAQ、向量匹配、大模型回复和身份介绍。
4. **准备多语言。** 设置主语言和默认语言，翻译帮助内容，校对专业术语、金额、数字和链接。
5. **接入网站。** 在「网站接入」配置站点，复制本租户生成的接入代码，使用自己的 App Key。
6. **上线前测试。** 先使用「机器配置」中的流程测试，再从真实访客入口验证常见问题、连续追问、外语咨询、人工接待和工单提交。

## 上线验收

| 测试 | 预期结果 |
| --- | --- |
| 已有文档的交易规则 | 回复保留条件、数字和例外 |
| 无法确认的账户个案 | 不编造余额或交易结果，给出合适的后续处理方式 |
| 外语咨询 | 在已开启语言能力范围内回复，或帮助客服翻译消息 |
| 人工暂时不可用 | 展示已配置的替代入口，例如提交工单 |
| 普通客服账号 | 只能看到有权限的菜单和记录 |
| 服务用量 | 可以在用量账单中找到对应调用 |

基础流程通过后再连接 MCP。先查询，再创建测试草稿，最后用于正式业务写入。
