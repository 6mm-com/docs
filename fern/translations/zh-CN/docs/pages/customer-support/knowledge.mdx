## 选择合适的内容类型

进入 **内容管理**。知识分类用于组织文章，其他类型用于简短回答、主题导航和服务入口。

| 内容 | 典型用途 |
| --- | --- |
| 知识文章与分类 | 开户接入、资金划转、交易规则和故障排查的详细指南 |
| 热门问题 | 用户经常咨询的问题与简短答案 |
| 问题分类与功能卡片 | 按业务主题组织入口，引导用户查找信息 |
| 公告 | 向用户发布业务通知 |
| 自助服务 | 引导用户使用已有的支持功能或资源 |

<span id="create-and-maintain-knowledge" data-sixmm-canonical-anchor="create-and-maintain-knowledge" aria-hidden="true"></span>

## 创建与维护知识

1. 创建或选择适当分类，填写必填字段；创建文章时需要提供分类。
2. 编写标题和正文，包含适用范围、前提、步骤与例外，以真实业务规则为准。
3. 保存并审核草稿，准备好后发布；不再适用的内容及时下架。
4. 更新翻译，检查内容变更后的检索状态，再从流程测试和访客对话验证。

例如提现指南，应说明用户如何选择网络、获取地址、确认业务限制以及联系人工，不应自行补充未经确认的处理时间和费用。

<span id="keep-content-consistent" data-sixmm-canonical-anchor="keep-content-consistent" aria-hidden="true"></span>

## 保持内容一致

修改原文不代表所有译文已经同步。检查受影响的翻译和 FAQ，避免文章、热门问题与公告描述不同规则。删除前确认是否仍用于用户导航或客服回答。MCP 支持相应的授权内容操作，详见 [MCP 功能范围](/zh-CN/customer-support/mcp-tools)。
