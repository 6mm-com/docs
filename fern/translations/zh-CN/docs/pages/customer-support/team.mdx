## 组织客服团队

在 **客服管理** 维护客服账号、角色与快捷回复。根据岗位实际需要分配模块和操作权限，避免多人共享同一个管理员登录账号。

修改角色后，使用受影响的账号验证菜单、会话监控、内容编辑和设置权限。除了菜单权限，账号状态、会话归属和字段级校验也会继续生效。

<span id="mcp-inherits-the-same-identity" data-sixmm-canonical-anchor="mcp-inherits-the-same-identity" aria-hidden="true"></span>

## MCP 继承同一个账号身份

MCP 连接绑定授权的租户与客服账号，AI 不会额外获得管理员角色。服务在调用时重新检查权限，不能通过猜工具名或传入其他租户 ID 获得额外访问能力。

在 **系统设置 → MCP 连接** 管理已连接应用，不再使用时撤销连接。退出浏览器后台，不等于撤销外部 AI 应用的授权。

通过 MCP 管理角色与客服账号需要确认。通过 MCP 创建客服时，初始密码由用户在后台确认页填写，不返回给 AI。
