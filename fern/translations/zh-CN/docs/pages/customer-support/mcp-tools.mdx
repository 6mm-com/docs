## 工具范围跟随账号权限

下表说明系统支持的最大范围，AI 应用实际只获得授权账号有权限的工具。以实时工具清单和参数结构为准，后台新增功能不会自动变成 MCP 工具。

| 后台模块 | 可调用操作 |
| --- | --- |
| 在线会话 | 查询会话、消息和排队；分配、接入、接管、转接；发送消息、邀请评价、管理上传权限；识别与翻译消息；上传支持的文件 |
| 工单与反馈 | 查询、分配、更新状态和删除用户工单与反馈；新增、查询、修改、分配和删除客服工单 |
| 历史会话 | 查询会话及消息，单条或批量删除会话 |
| 内容管理 | 查询和维护分类、文章、热门问题、问题分类、功能卡片、公告与自助服务；发布、下架文章 |
| 语言翻译 | 读取原文、译文和完成情况；保存或清空支持的译文；调用自动翻译；管理开放的语言设置 |
| 机器配置 | 读取支持的配置与 FAQ、维护相似问题、测试回复、查看检索状态、更新数据与重建向量 |
| 客服管理 | 管理已开放的客服账号、角色和快捷回复 |
| 系统设置 | 读写有权限的外观、文案、会话、访客入口、智能服务及网站白名单字段 |
| 数据统计 | 只读查询概况及支持的统计数据 |
| 用量账单 | 只读查询余额、用量、流水和价格 |
| 操作日志 | 只读查询操作记录与详情 |

## 写入与确认

删除、发布或下架、修改已发布文章、发送消息、角色或账号管理、网站白名单变更、向量重建和平台自动翻译等操作，按工具规则在后台确认后执行。不需要确认的写入也可能立即改变数据，向 AI 下达执行任务前应明确范围。

MCP 不提供总平台管理、租户关闭或删除、余额充值、账单修改和供应商密钥访问。文件工具检查格式并执行已部署的大小限制，当前实现支持 Base64 上传单个最大 10 MB 的文件；更大文件可在后台自身限制允许时通过后台上传。

## 可以这样使用

- 列出缺失译文，起草日文翻译，保留链接和金额。
- 查询未解决的用户工单，先提出分配建议，不直接修改。
- 在已有分类中创建知识文章草稿，返回标题和 ID。
- 汇总近期客服统计，注明准确查询周期。

平台 AI、自动翻译和向量操作仍可能产生原有服务费用，连接的 AI 提供方用量另计。
