## 职责边界

| 范围 | 负责人 | 说明 |
| --- | --- | --- |
| 容器准备 | Partner 前端 | 提供有明确宽高的可见 DOM 容器。 |
| iframe 创建 | Trading Widget SDK | SDK 自动创建并管理 iframe。 |
| 交易 UI | 6MM iframe | K 线、订单簿、下单、持仓、订单和账户数据都在 iframe 内运行。 |
| 显示控制 | Trading Widget SDK + 6MM iframe | PC embed 顶部栏和底部行情跑马灯默认隐藏。Partner 可通过 `display` 开启 shell 区域，或隐藏交易页大容器。 |
| Partner 登录校验 | Partner 后端 | 签发鉴权凭据前，先校验 Partner 自己的用户登录态。 |
| embedToken 签发 | Partner 后端 + Agent API | 推荐用于 partner-token 模式。 |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## 版本说明

公开接入路径保持在 v1 脚本地址。当前 v1 能力包含 partner-token、tokenProvider、entryUrlProvider、display 显示控制、生命周期事件、实例方法和订单事件。

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## 什么时候使用 Widget

如果合作方需要在现有 Web 产品中嵌入完整交易界面，建议选择 Trading Widget。如果要自行开发并维护完整交易界面，则使用 REST API 和 WebSocket 文档。

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## 实施路径

1. 按 [Trading Widget 快速开始](/zh-CN/sdk/trading-widget/quick-start)加载脚本并创建可见容器。
2. 通过合作方后端配置 [partner-token 身份认证](/zh-CN/sdk/trading-widget/authentication)。
3. 添加所需的[参数与事件](/zh-CN/sdk/trading-widget/options-events)。
4. 使用[实例方法](/zh-CN/sdk/trading-widget/instance-methods)处理生命周期和运行时控制。

<span data-sixmm-canonical-anchor="已核对的公开运行版本" aria-hidden="true"></span>

## 已核对的公开运行版本

截至 2026-10-10，公开 `v1` 脚本返回版本 `1.8.0`。该 URL 是稳定主版本入口，不是固定构建。使用可选能力前，检查实际加载的 `TradingWidget.version` 与 `TradingWidget.capabilities`。Java Agent SDK `v0.3.0` 是独立的后端包。

运行时只支持一个活动实例（`multiInstance=false`），创建另一实例会销毁前一实例。支持语言为 `en`、`en-US`、`zh-CN`，与文档站的 20 种语言分别管理。
