本文对应 **Agent Java SDK `v0.3.0`**、Java 8+ 与该标签的公开契约。示例在合作方后端运行；先按[快速开始](/zh-CN/sdk/agent-sdk/java/quick-start)初始化 `client`。

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- 新增六类永续查询：当前委托、委托历史、成交、当前持仓、持仓历史、账变。
- 支持 Funding 余额、划转、结果恢复查单及 Funding/Contract 互转。
- 支持有环境字段的资金请求显式选择实盘或模拟盘。
- 补充秒合约跳转与内嵌、返回字段参考及旧项目升级说明。

Java SDK 与 Trading Widget SDK 分别管理版本。Widget 的 `v1` 地址不是 Java SDK 的 `0.3.0` 版本。

<span data-sixmm-canonical-anchor="已有项目" aria-hidden="true"></span>

## 已有项目

保留用户映射、原始订单和密钥配置。省略环境字段保持原实盘行为兼容。Funding、显式模拟资金和六类查询需要对应的新模型及方法。调整旧项目之前先阅读[升级指南](/zh-CN/sdk/agent-sdk/java/upgrade)。
