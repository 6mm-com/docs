取得测试环境后，可以按以下顺序准备。访问入口和安装包由接入联系人提供，本指南暂不提供公开注册或下载地址。

<span id="prepare-your-workspace" data-sixmm-canonical-anchor="prepare-your-workspace" aria-hidden="true"></span>

## 准备工作空间

1. 确认需要体验的产品，以及钱包空间所属的账户或组织。
2. 从提供的入口登录，完成该版本要求的账户安全设置。
3. 选择目标空间，核对产品类型、成员权限和初始化状态，再进行资产操作。
4. 对于需要选择保管方式的产品，先阅读参与方和恢复责任，再确认选择。

登录账户、工作空间与链上钱包是不同概念。一个账户可以访问不同空间，每个空间分别确定产品与操作上下文。

<span id="complete-initialization" data-sixmm-canonical-anchor="complete-initialization" aria-hidden="true"></span>

## 完成初始化

不同产品的初始化可能包含设备或节点录入、参与方确认、钱包建钥和备份准备。应按当前空间显示的初始化状态继续操作，不要把某一步成功当作整个流程已经完成。

全托管体验不要求客户完成与自持分片企业钱包相同的节点部署。个人与团队设备也有各自的录入和签名流程。

<span id="validate-a-small-test-flow" data-sixmm-canonical-anchor="validate-a-small-test-flow" aria-hidden="true"></span>

## 验证一笔小额测试

1. 确认已启用的网络和资产，特别注意当前是否为测试网络。
2. 获取收款地址及所需的备注或标签；如果提供地址验证，先完成验证再分发地址。
3. 接收一笔小额测试资金，跟踪充值记录，直到结果明确。
4. 准备小额转出，核对目标地址、手续费和所需的审批或设备签名。
5. 将钱包记录、链上结果与自己的业务记录进行对照。

扩大测试前，确认团队能够处理审批驳回、签名方离线、回调缺失和交易结果不确定等情况。继续阅读[钱包操作](/zh-CN/mpc-wallet/wallet-operations)与[安全和恢复](/zh-CN/mpc-wallet/security-and-recovery)。
