余额视图回答当前资金情况，交易视图帮助解释资金为什么变化。企业空间中实际可见的视图取决于产品和角色权限。

<span id="use-the-right-record-for-each-question" data-sixmm-canonical-anchor="use-the-right-record-for-each-question" aria-hidden="true"></span>

## 按问题选择对应的记录

| 需要核对的问题 | 查看哪里 |
| --- | --- |
| 现在有多少可以用来付款？ | 查看对应钱包和资产的可用余额，另行核对被冻结或暂时占用的金额。 |
| 客户的转入是否已经入账？ | 查看充值记录，核对网络、资产、金额和收款信息。 |
| 转出有明确结果了吗？ | 查看提现记录，并在链上结果可用时核对确认情况。 |
| 哪些记录影响业务余额？ | 空间提供资金流水时，查看账本分录。涉及实际链上转移时，再查看链上流水。 |

<span id="reconcile-a-payment-period" data-sixmm-canonical-anchor="reconcile-a-payment-period" aria-hidden="true"></span>

## 核对一个业务周期的资金

1. 先确定本次核对的空间、网络、资产和时间范围。
2. 将充值、提现记录与保存的业务订单或付款编号对应起来。
3. 单独记录手续费和内部归集，区分为待处理请求冻结的金额与已完成的转账。
4. 对没有对应上的记录，根据交易标识与最新状态继续核对，结果明确后再结账。

例如，链上已能看到一笔转出，但提现记录仍在等待确认。财务可以保留原业务请求继续跟踪，等状态和实际金额明确后完成对账。
