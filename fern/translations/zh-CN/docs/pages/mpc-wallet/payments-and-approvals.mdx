企业付款可以由不同角色协作完成。操作员准备转账，有权限的人员在需要时审批，再由签名参与方生成链上交易签名。

<span id="prepare-the-payment" data-sixmm-canonical-anchor="prepare-the-payment" aria-hidden="true"></span>

## 准备付款

选择来源钱包、网络和资产，填写收款地址、金额和必要的目标备注。提交前查看预览和费用。如果当前流程要求校验地址白名单，按授权的地址管理流程处理限制。

<span id="review-and-track-progress" data-sixmm-canonical-anchor="review-and-track-progress" aria-hidden="true"></span>

## 审批并跟踪进度

需要审批时，审批人可在企业待办中核对付款信息，并在权限范围内处理。要求平台风控复核的申请，可能在签名前暂停等待。审批完成后，继续用付款记录跟踪签名、广播和链上确认。

| 看到的进度 | 如何理解 |
| --- | --- |
| 等待审批或复核 | 仍有待处理的审核环节，可查看当前流程。 |
| 已审批或等待签名 | 申请可以继续进入签名流程，跟进原记录即可。 |
| 已广播或等待确认 | 链上结果仍在推进，有交易标识时可一并核对。 |
| 结果核对中 | 持续跟踪同一请求，直到结果明确。 |
| 已确认 | 记录已有链上确认结果，可进入对账。 |

如果结果延迟，先核对原申请，再决定后续动作。能否取消取决于实际签名阶段。系统对接可参阅[交易状态与重试](/zh-CN/mpc-wallet/transactions)。
