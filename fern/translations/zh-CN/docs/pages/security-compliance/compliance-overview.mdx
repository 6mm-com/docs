6MM 为授权合作方提供交易技术基础设施和合规导向的支持。合规要求会因司法辖区和业务模式不同而变化，因此每次上线都需要结合合作方自身义务进行确认。

<h2 id="what-this-section-covers">本栏目覆盖内容</h2>

| 领域 | 说明 |
| --- | --- |
| 牌照支持 | 支持路径和准备资料说明。 |
| 合作方义务 | 用户准入、信息披露、本地合规控制和客户关系管理。 |
| 技术控制 | 签名、日志、访问控制、Webhook 验证和生产监控。 |
| 上线审查 | 面向真实用户开放交易功能前的检查项。 |

<h2 id="important-boundary">重要边界</h2>

6MM 文档用于帮助合作方准备技术和运营控制，不替代法律意见、特定司法辖区合规审查，也不替代合作方自身监管义务。

<h2 id="information-to-prepare">需要准备的信息</h2>

开展合规或上线审查前，请整理：

- 目标国家或地区，以及将获得交易访问权限的用户类型。
- 产品范围，包括嵌入式交易、白标、流动性、钱包、托管或经纪业务功能。
- 用户准入、身份核验、信息披露、资产托管、客服和事件通知分别由哪个主体负责。
- 合作方前端、合作方后端、6MM API、SDK、Webhook 和运营系统之间的数据流。
- 凭据保存、访问控制、审计日志、监控和升级处理负责人。

<h2 id="recommended-review-path">建议评审路径</h2>

1. 使用[合作方责任矩阵](/zh-CN/security-compliance/partner-responsibilities)明确职责。
2. 按目标运营模式查看[牌照支持](/zh-CN/security-compliance/license-support)。
3. 确认[平台安全架构](/zh-CN/security-compliance/security-architecture)以及 API、Webhook 控制。
4. 完成[生产上线检查清单](/zh-CN/resources/production-launch-checklist)。

法律和合规结论必须由具备资质的顾问及合作方责任主体确认。本文档说明接入准备和责任边界，不构成法律意见，也不保证特定牌照可用。
