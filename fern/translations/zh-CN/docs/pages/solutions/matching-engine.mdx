白标交易所不只是一个前端外壳。交易、账户、风控和结算背后的核心模块，决定了最终用户体验是否可靠。

<h2 id="core-modules">核心模块</h2>

| 模块 | 作用 |
| --- | --- |
| 撮合与订单生命周期 | 处理下单、撮合状态、撤单和成交记录。 |
| 账户与仓位系统 | 维护余额、保证金状态、仓位和可交易状态。 |
| 风控能力 | 协调杠杆、保证金、清算和异常行情行为。 |
| 行情数据 | 向交易界面分发行情价格、深度、成交和 K 线数据。 |
| 结算与记录 | 对齐交易历史、余额变化和运营记录。 |

<h2 id="implementation-questions">实施问题</h2>

- 向用户开放哪些普通订单和条件单类型？
- 交易对规则、精度校验和可交易状态由哪个服务负责？
- 订单、成交、仓位、余额和结算记录如何对账？
- REST 响应、WebSocket 事件和合作方记录之间使用哪些稳定标识？
- 撮合、风控或行情服务不可用时，使用什么监控和回滚路径？

前端开发前应先回答这些问题，确保产品行为、接口处理、运营和客服使用同一套交易模型。
