6MM 支持**合作方系统接入**和**白标平台**两种账户访问模式。用户应通过所属平台提供的入口登录；账户创建、身份验证和资料管理方式取决于所采用的模式。

<h2 id="registration-model">确认账户所属模式</h2>

| 项目 | 合作方接入 | 白标平台 |
| --- | --- | --- |
| 账户来源 | 用户拥有合作方系统账户，由合作方绑定或同步交易用户。 | 用户使用白标平台的账户体系。 |
| 访问入口 | 合作方 App、网站或嵌入式交易入口。 | 白标平台的品牌域名和登录页面。 |
| 身份认证 | 合作方验证用户身份，由后端获取所需的交易访问凭证。 | 按平台开放的登录、验证和账户安全配置执行。 |
| 账户管理 | 合作方管理用户资料，交易系统维护必要的用户绑定关系和交易记录。 | 白标账户体系及经授权的后台人员管理用户资料、账户状态和安全设置。 |

<h2 id="login-method-1-partner-embedded-access">合作方系统接入</h2>

1. 用户先登录合作方自己的账户系统。
2. 合作方后端验证登录状态，绑定或识别对应的交易用户。
3. 后端通过支持的接入方式获取交易访问凭证或入口 URL。
4. 用户打开合作方提供的嵌入式交易界面或经授权的交易入口。

完成账户访问不代表已经具备交易资金。下单前，仍需按合作方的资金流程完成准备，并核对合约账户可用余额。

<h2 id="login-method-2-6mm-account-login-partner-issued-credentials">白标平台访问</h2>

用户通过白标平台提供的品牌域名和账户入口访问。是否开放自助注册、如何开通账户，以及支持哪些登录和身份验证方式，以该平台实际配置为准。

平台通过自身账户体系及经授权的后台人员，在权限范围内处理用户资料、账户状态和安全操作。找回密码、变更联系方式或处理账户限制时，按所属平台的验证流程办理。

登录后，通过平台支持的入金方式准备资金。进行永续合约交易前，将所需结算资产从资金账户转入合约账户，并确认划转结果。

<h2 id="user-ownership-and-data-responsibility">账户与数据责任</h2>

两种模式的责任边界不同。合作方接入保留合作方侧的账户管理，同时维护交易所需的用户绑定关系与记录；白标平台则通过自身账户流程和后台权限管理用户。

实际采集、保存或展示的信息范围、身份验证要求及客服责任，应按具体部署明确，不应将某一种模式的账户管理方式套用于所有平台。

<h2 id="design-principles">进入交易前确认</h2>

- 确认访问的是正确的平台域名，并使用对应账户。
- 完成所属平台要求的身份验证和安全检查。
- 确认账户已开通交易权限，并了解当前限制。
- 核对合约账户可用余额；登录成功不会自动完成资金划转。
- 遇到账户访问或身份验证问题时，联系所属平台客服。
