三种预测玩法统一以平台合约标记价作为价格依据。最新成交价、外部交易所报价或浏览器图表可能与该标记价不同。

<span id="evidence-by-game" data-sixmm-canonical-anchor="evidence-by-game" aria-hidden="true"></span>

## 各玩法需要的证据

| 玩法 | 相关证据 |
| --- | --- |
| 涨跌预测 | 场次开盘价、结算价和对应时间 |
| 自选预测 | 该笔订单的开盘价、到期时间和结算价 |
| 预测网格 | 已受理价格区间、有效时间窗及窗口内价格路径 |

<span id="why-a-screenshot-may-differ" data-sixmm-canonical-anchor="why-a-screenshot-may-differ" aria-hidden="true"></span>

## 为什么截图可能不同

页面可能存在延迟、显示舍入、采样间隔差异，或者展示了另一种价格。判断结果前，应先核对品种、价格来源、时间与精度。

对于网格，结束时的一个价格不能证明此前是否发生过触碰；需要查看有效时间内的价格证据，包括按玩法规则判定的价格穿越。

<span id="time-and-boundaries" data-sixmm-canonical-anchor="time-and-boundaries" aria-hidden="true"></span>

## 时间与边界

以订单记录中的时间为准。设备时钟和页面倒计时用于辅助显示，不作为接受迟到订单或改变有效窗口的依据。价格精度和边界包含规则必须与该产品适用规则一致。

<span id="when-data-is-abnormal" data-sixmm-canonical-anchor="when-data-is-abnormal" aria-hidden="true"></span>

## 数据异常时

保留订单号和受影响时间窗，查询处理状态。不要自行用外部交易所价格替代平台证据进行争议结算。详见[退款、作废与异常处理](/zh-CN/prediction/refunds-exceptions)。
