<span id="所有玩法都有场次吗" data-sixmm-anchor-target="do-all-games-use-rounds" aria-hidden="true"></span>
<h2 id="do-all-games-use-rounds">所有玩法都有场次吗？</h2>

不是。涨跌预测使用系统场次；自选订单有独立周期与到期时间；网格订单对应自己的格子和有效时间窗口。

<span id="网格结束时价格必须还在格子里吗" data-sixmm-anchor-target="must-the-price-finish-inside-my-grid-cell" aria-hidden="true"></span>
<h2 id="must-the-price-finish-inside-my-grid-cell">网格结束时价格必须还在格子里吗？</h2>

不需要。有效时间内发生符合规则的进入或穿越即可，时间窗结束后才触碰不算。详见[预测网格](/zh-CN/prediction/grid)。

<span id="网格移动会改变已下单条件吗" data-sixmm-anchor-target="does-a-moving-grid-change-my-accepted-order" aria-hidden="true"></span>
<h2 id="does-a-moving-grid-change-my-accepted-order">网格移动会改变已下单条件吗？</h2>

不会。实时网格重新居中或刷新时，已受理订单的价格区间、有效时间和赔率仍按保存的条件处理。

<span id="显示的返还全部是利润吗" data-sixmm-anchor-target="is-the-displayed-return-all-profit" aria-hidden="true"></span>
<h2 id="is-the-displayed-return-all-profit">显示的返还全部是利润吗？</h2>

不是。中奖总返还包含下注本金部分。下注 100 USDT、赔率 1.85x，未计单独费用的总返还是 185 USDT，净盈利为 85 USDT。详见[返还与盈亏计算](/zh-CN/prediction/returns-pnl)。

<span id="为什么可用余额小于资金账户余额" data-sixmm-anchor-target="why-is-my-available-balance-lower-than-my-funding-balance" aria-hidden="true"></span>
<h2 id="why-is-my-available-balance-lower-than-my-funding-balance">为什么可用余额小于资金账户余额？</h2>

待处理预测订单可能冻结部分资金。统计总资产时，不要把这部分冻结再加一次。详见[账户与余额](/zh-CN/prediction/accounts-balances)。

<span id="为什么高赔率格子不能下注" data-sixmm-anchor-target="why-is-a-high-odds-cell-unavailable" aria-hidden="true"></span>
<h2 id="why-is-a-high-odds-cell-unavailable">为什么高赔率格子不能下注？</h2>

网格规则会将计算赔率超过最高配置的格子设为不可下注。产品开关、限额、时间和账户限制也可能阻止下单。

<span id="目标返奖率-97-代表一定返还-97-吗" data-sixmm-anchor-target="does-a-97-target-return-guarantee-i-receive-97-back" aria-hidden="true"></span>
<h2 id="does-a-97-target-return-guarantee-i-receive-97-back">目标返奖率 97% 代表一定返还 97% 吗？</h2>

不代表。它是模型参数，不是单笔返还或长期结果保证。详见[赔率机制](/zh-CN/prediction/odds)。

<span id="结果延迟或请求超时怎么办" data-sixmm-anchor-target="what-if-the-result-is-delayed-or-my-request-times-out" aria-hidden="true"></span>
<h2 id="what-if-the-result-is-delayed-or-my-request-times-out">结果延迟或请求超时怎么办？</h2>

先查原订单与流水，不要直接重复提交。价格证据缺失或结果存在争议时，保留订单条件并联系支持。详见[退款、作废与异常处理](/zh-CN/prediction/refunds-exceptions)。

<span id="预测下注会计入合约成交额吗" data-sixmm-anchor-target="are-prediction-stakes-included-in-perpetual-trading-turnover" aria-hidden="true"></span>
<h2 id="are-prediction-stakes-included-in-perpetual-trading-turnover">预测下注会计入合约成交额吗？</h2>

两者是独立指标。预测报表分别统计有效下注、返还、用户盈亏、退款和作废，不应与现货或合约成交额混算。

<span id="可以直接使用合约-api-下单示例参与预测吗" data-sixmm-anchor-target="can-i-use-the-perpetual-api-order-examples-for-prediction" aria-hidden="true"></span>
<h2 id="can-i-use-the-perpetual-api-order-examples-for-prediction">可以直接使用合约 API 下单示例参与预测吗？</h2>

不能据此认定合约接口接受预测订单。应通过[合作伙伴支持](/zh-CN/resources/contact/support)确认当前接入已开通的预测接口与入口方式。
