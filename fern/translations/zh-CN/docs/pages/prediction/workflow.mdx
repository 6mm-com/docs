三种玩法共享订单与资金处理流程，但各自采用不同的时间规则。

<span id="订单生命周期" data-sixmm-anchor-target="order-lifecycle" aria-hidden="true"></span>
<h2 id="order-lifecycle">订单生命周期</h2>

| 阶段 | 需要核对的内容 |
| --- | --- |
| 选择与报价 | 玩法、品种、金额、赔率和价格／时间条件 |
| 订单受理 | 订单号、保存的条件和受理结果 |
| 资金冻结 | 资金账户中该笔订单对应的冻结 |
| 等待结果 | 场次开奖、独立订单到期或格子有效时间窗 |
| 结果处理 | 权威价格证据及订单适用规则 |
| 结算 | 最终状态、实际返还和结算流水 |
| 对账 | 历史订单与账户资金变动一致 |

<span id="各玩法的时间差异" data-sixmm-anchor-target="timing-by-game" aria-hidden="true"></span>
<h2 id="timing-by-game">各玩法的时间差异</h2>

- **涨跌预测**：订单归属系统场次，停止下注后等待结果处理。
- **自选预测**：每笔订单独立记录开盘价和到期时间，不同用户订单的时间可能不同。
- **预测网格**：格子有明确的有效开始与结束时间，时间窗之外的触碰不算命中。

<span id="处理中断时" data-sixmm-anchor-target="if-processing-is-interrupted" aria-hidden="true"></span>
<h2 id="if-processing-is-interrupted">处理中断时</h2>

不要根据页面断线或余额刷新延迟推断最终结果。重新打开订单，检查状态并核对关联流水。价格证据或结算处理异常时，参考[退款、作废与异常处理](/zh-CN/prediction/refunds-exceptions)。

<span id="保留可追溯记录" data-sixmm-anchor-target="keep-a-traceable-record" aria-hidden="true"></span>
<h2 id="keep-a-traceable-record">保留可追溯记录</h2>

联系支持时提供订单号、玩法、品种、下单时间、显示状态及已有的结算流水号。涨跌订单可以补充场次编号；网格截图本身不能替代已保存的订单记录。
