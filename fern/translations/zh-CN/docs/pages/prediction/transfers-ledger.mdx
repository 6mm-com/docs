外部充值和提现通过授权合作平台处理。预测资金应按照该平台已开通的账户与划转流程准备。

## 划转前检查

确认来源账户、目标资金账户、币种、可划转金额及账户限制。总资产不代表全部可以转出，待处理订单或其他业务可能占用部分余额。

使用当前账户实际支持的划转入口，不要把永续交易指南中的“现货转永续”直接作为预测入金路径。

## 核对订单资金

| 记录 | 核对内容 |
| --- | --- |
| 划入资金账户 | 业务标识、币种、金额及完成状态 |
| 预测冻结 | 原始预测订单与冻结金额 |
| 结算 | 最终结果、实际返还和流水号 |
| 退款或释放冻结 | 对应原订单、金额和最终余额 |
| 单独费用 | 费用类型、金额及关联订单或流水 |

## 划转结果不明确时

再次发起前，先查询原划转标识。超时不代表划转失败。核对最终流水与账户余额时，还应考虑同时发生的其他资金变动。

## 合作方运营核对

合作方报表可按日／月、玩法、品种和用户结果统计预测业务。有效下注、返还、退款和异常补偿应分别核对。报表中的预测净收入＝有效下注－返还－异常补偿，与单个用户的盈利不是同一个指标。
