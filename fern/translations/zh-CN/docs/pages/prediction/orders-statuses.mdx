每笔已受理预测订单都有独立订单号。涨跌预测还关联场次；自选预测和网格订单不依赖统一场次。

<span id="current-and-historical-records" data-sixmm-canonical-anchor="current-and-historical-records" aria-hidden="true"></span>

## 当前与历史记录

| 显示状态 | 如何理解 |
| --- | --- |
| 待开奖 | 尚未记录最终结果 |
| 已封盘 | 对应下注阶段已关闭，不表示中奖或未中奖 |
| 已中奖 | 订单记录为中奖结果 |
| 未中奖 | 订单记录为未中奖结果 |
| 已退款 | 订单状态反映退款处理，仍需核对实际流水 |
| 已作废 | 订单失效，应查看原因及对应资金处理 |

并非所有玩法都以同样方式使用每个中间状态。仅凭状态标签，不能证明账户入账已经完成。

<span id="fields-to-check" data-sixmm-canonical-anchor="fields-to-check" aria-hidden="true"></span>

## 需要核对的字段

各玩法都有订单号、用户归属、品种、下注金额、赔率、下单时间和状态。历史记录还包含实际返还、结果信息、结算时间与结算流水号。

- 涨跌预测额外关联场次编号、预测方向和实际方向。
- 自选预测记录固定赔率及独立到期时间。
- 网格记录选中格子与价格区间，结果字段应结合时间窗触碰规则理解。

<span id="changes-and-duplicate-submissions" data-sixmm-canonical-anchor="changes-and-duplicate-submissions" aria-hidden="true"></span>

## 修改与重复提交

不要假设预测订单可以像合约限价单一样改单或撤单，应按对应产品提供的操作和规则处理。提交结果不明确时，先查询原订单，再决定是否追加下注。
