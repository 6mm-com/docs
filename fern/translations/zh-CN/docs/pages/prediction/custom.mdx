自选预测允许用户选择上涨或下跌，以及当前可用的预测周期，随时发起独立订单，无需等待涨跌预测的下一场次。

<span id="how-to-participate" data-sixmm-canonical-anchor="how-to-participate" aria-hidden="true"></span>

## 如何参与

1. 选择品种及该品种已启用的周期。
2. 选择上涨或下跌，输入符合限制的金额。
3. 核对当前周期的固定赔率和预计返还。
4. 受理后查看订单保存的开盘价、下单时间、到期时间和赔率。
5. 到期后在历史订单中跟踪结算结果。

<span id="each-order-has-its-own-terms" data-sixmm-canonical-anchor="each-order-has-its-own-terms" aria-hidden="true"></span>

## 每笔订单独立记录条件

| 订单条件 | 用途 |
| --- | --- |
| 品种与方向 | 确定价格序列和预测选项 |
| 开盘价格 | 该笔订单的比较基准 |
| 周期与到期时间 | 确定该笔订单何时到期 |
| 下注金额与固定赔率 | 确定已受理金额与返还倍数 |
| 结算价格与结果 | 记录判定结果 |

同一周期配置的固定赔率适用于上涨和下跌两个方向。订单受理后保存赔率快照，后续配置变更不替换已有订单的赔率。

<span id="result-and-example" data-sixmm-canonical-anchor="result-and-example" aria-hidden="true"></span>

## 判定与示例

结算价高于开盘价为上涨，低于开盘价为下跌。价格相等时，需要按对应产品规则处理。

例如，一笔看跌订单开盘价为 3,000、结算价为 2,990，所选方向获胜。假设下注 100 USDT、锁定赔率 1.85x，未计单独披露费用的总返还为 185 USDT，其中包含下注本金，净盈利为 85 USDT。

<span id="things-to-check" data-sixmm-canonical-anchor="things-to-check" aria-hidden="true"></span>

## 注意事项

- 不同时间提交的订单，开盘价和结果可能不同。
- 核对结果时使用订单保存的到期时间，不以浏览器倒计时作为结算凭据。
- 一个品种支持的周期和固定赔率，不代表其他品种采用相同配置。
