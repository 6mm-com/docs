预测网格的纵轴是价格区间，横轴是未来时间窗口。选择一个格子，就创建一笔针对该价格区间和时间窗口的独立订单。

<span id="read-a-cell" data-sixmm-canonical-anchor="read-a-cell" aria-hidden="true"></span>

## 如何看懂格子

| 格子信息 | 含义 |
| --- | --- |
| 价格区间 | 格子的价格下限与上限 |
| 开始与结束时间 | 可以判定触碰命中的有效窗口 |
| 报价赔率 | 当前为该格子提供的返还倍数 |
| 下注金额 | 投入该笔订单的金额 |

例如，10 行、10 列且每列 2 秒的网格覆盖未来 20 秒。这是读图示例，实际应核对产品显示的网格尺寸和绝对时间。

<span id="what-counts-as-a-hit" data-sixmm-canonical-anchor="what-counts-as-a-hit" aria-hidden="true"></span>

## 什么算命中

在格子的有效时间内，平台标记价进入或穿过该价格区间即为命中。有效触碰一次即可，不要求价格一直停留到时间窗结束。

| 示例：65,010～65,020，10:00:04～10:00:06 | 结果解释 |
| --- | --- |
| 10:00:05 价格到达 65,015 | 有效时间内进入区间 |
| 有效时间内价格从 65,005 变为 65,025 | 穿过该价格区间 |
| 有效时间内始终未进入或穿过 | 没有符合条件的命中 |
| 时间窗结束后才首次触碰 | 不计入该笔订单 |

恰好位于价格边界或时间边界时，按订单适用规则判定。价格数据缺失并不等于从未触碰。

<span id="how-to-participate" data-sixmm-canonical-anchor="how-to-participate" aria-hidden="true"></span>

## 如何参与

1. 选择品种，核对页面价格轴和时间轴。
2. 选择可下注格子，输入符合限制的金额。
3. 确认价格上下界、有效时间、赔率和预计返还。
4. 检查已受理订单；即使实时网格移动，该笔订单的价格区间、有效时间和赔率也已锁定。
5. 在历史订单中跟踪最终结果和实际结算。

<span id="odds-and-unavailable-cells" data-sixmm-canonical-anchor="odds-and-unavailable-cells" aria-hidden="true"></span>

## 赔率与不可下注格子

定价模型根据标记价、波动率、价格边界和时间边界，估计有效时间内的触碰概率。模型报价以目标返奖率除以估计命中概率计算，并受到配置规则约束。

例如，97% 除以 20% 得到 4.85x。下注 100 USDT、锁定 4.85x 的中奖订单，总返还为 485 USDT。页面简化显示的小数位不应被当作改变订单已存倍数的依据。

按网格配置规则，计算报价超过最高赔率时，该格子不可下注，不会强制把报价压低到最高值。其他限制也可能阻止订单受理。

<span id="interrupted-price-evidence" data-sixmm-canonical-anchor="interrupted-price-evidence" aria-hidden="true"></span>

## 价格证据中断

有效时间内行情中断、无法确认命中时，订单进入异常处理或退款流程。不要根据图表中的空白片段直接认定未中奖。
