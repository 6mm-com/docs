涨跌预测由系统组织场次。用户选择该场次结算价格相对开盘价格是上涨还是下跌，同一场次可以包含多笔用户订单。

## 如何参与

1. 选择已启用的交易品种和周期。
2. 核对场次编号、开盘价格、下注窗口和开奖时间。
3. 选择上涨或下跌，并输入下注金额。
4. 核对当前赔率与预计返还，在开放下注期间提交。
5. 根据场次与订单记录查看最终结果和返还。

## 场次时间

| 时间 | 含义 |
| --- | --- |
| 开始下注时间 | 该场次开始受理订单 |
| 停止下注时间 | 不再接受该场次的新下注 |
| 开奖时间 | 计划进行结果判定的时间 |
| 结算完成时间 | 结算处理实际完成的记录时间 |

场次周期与下注开放时长是不同配置。应核对页面时间，不能认为整个周期内都可以下注。

## 方向判定

| 价格比较 | 方向 |
| --- | --- |
| 结算价格高于开盘价格 | 上涨 |
| 结算价格低于开盘价格 | 下跌 |

价格相等时并未形成上涨或下跌，应查看该场次适用的平价处理规则，不能自行认定一定判输或退款。

## 赔率与示例

报价随上涨池、下跌池及本次下注金额变化，并受到配置上下限约束。后续资金池报价本身不能说明此前订单的结算条件，应核对该笔订单保存的规则。

例如，开盘价为 65,000、结算价为 65,100，实际方向为上涨。假设一笔中奖订单的下注金额为 100 USDT、记录赔率为 1.85x，则未计单独披露费用的总返还为 185 USDT。这里的数字仅用于解释计算，不代表生产报价。
