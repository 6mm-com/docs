预测费用需要结合订单赔率及合作平台披露的费率规则理解。本页不规定所有合作方统一适用的费率。

<span id="区分不同金额" data-sixmm-anchor-target="distinguish-the-amounts" aria-hidden="true"></span>
<h2 id="distinguish-the-amounts">区分不同金额</h2>

| 项目 | 含义 |
| --- | --- |
| 赔率倍数 | 根据订单条件确定中奖总返还 |
| 目标返奖参数 | 定价模型输入，本身不等于一笔单独扣费流水 |
| 单独披露的平台服务费 | 该产品／订单适用时需要核对的收费 |
| 合作方营收结算 | 业务层面的分配，不自动等于用户订单再扣一次费用 |

运营模型包含预测平台服务费这一费用类别，但仅凭该类别无法确定费率、扣费时点，或某笔订单是否单独收费。

<span id="提交前确认" data-sixmm-anchor-target="check-before-submitting" aria-hidden="true"></span>
<h2 id="check-before-submitting">提交前确认</h2>

- 当前玩法和账户是否适用费用。
- 收费基数、金额及扣费时点。
- 显示返还是单独收费之前还是之后的金额。
- 退款、作废订单的费用如何处理。

如果这些条款不明确，请先通过[合作伙伴支持](/zh-CN/resources/contact/support)了解适用费率，再参与交易。

<span id="核对时避免重复扣减" data-sixmm-anchor-target="reconcile-without-deducting-twice" aria-hidden="true"></span>
<h2 id="reconcile-without-deducting-twice">核对时避免重复扣减</h2>

赔率参数和单独费用是不同记录。返还已按订单赔率计算时，不要再根据猜测的比例重复扣减；应核对实际披露的收费和流水。
