## 常见限制

| 限制 | 影响 |
| --- | --- |
| 玩法或品种关闭 | 不接受对应产品的新订单 |
| 周期未开通 | 该品种不能选择该周期 |
| 单笔最小额／最大额 | 下注金额必须在允许范围内 |
| 累计下注或敞口控制 | 即使单笔金额合规，继续下单也可能受限 |
| 赔率偏离控制 | 报价可能进入审核，或预测下单受限 |
| 网格报价超过最高值 | 按网格定价规则，该格子不可下注 |
| 下注窗口关闭 | 不接受进入已关闭窗口的新订单 |

管理模型包含告警、审核、限制预测及延迟下单等处置，实际响应取决于命中规则，不能认为所有限制产生相同结果。

<span id="stake-and-model-risk" data-sixmm-canonical-anchor="stake-and-model-risk" aria-hidden="true"></span>

## 本金与模型风险

未中奖且无返还的订单会损失下注金额。更高赔率不代表更好的机会，也可能意味着更低的估计命中概率。目标返奖参数不保证个人收益。

<span id="configuration-changes" data-sixmm-canonical-anchor="configuration-changes" aria-hidden="true"></span>

## 配置变更

新下单前应检查当前配置。已受理的自选和网格订单保存赔率及相关条件快照，后续页面刷新不会重新定义已经接受的条件。

<span id="when-an-order-is-unavailable" data-sixmm-canonical-anchor="when-an-order-is-unavailable" aria-hidden="true"></span>

## 无法下单时

依次核对产品开关、可用余额、限额、报价和时间。不要通过反复提交绕过限制；如果已经产生订单号，应保留订单号和响应信息。
