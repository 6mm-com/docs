首次下单前，确认账户已开通预测功能，并理解所选玩法如何判定结果。

## 准备账户

从合作平台进入预测页面，检查资金账户可用余额、结算币种及参与限制。其他账户中的余额不代表可以直接用于预测。

## 选择订单条件

| 玩法 | 输入金额前需要核对 |
| --- | --- |
| 涨跌预测 | 品种、场次编号、方向、停止下注时间和开奖时间 |
| 自选预测 | 品种、方向、所选周期及该笔订单的时间条件 |
| 预测网格 | 品种、价格上下界、有效开始时间和结束时间 |

## 确认并提交

1. 输入符合页面单笔限制的下注金额。
2. 核对当前报价和预计返还；订单受理前报价可能变化。
3. 阅读结果规则、费用说明及相关截止时间。
4. 提交一次，随后确认订单号和已受理的订单条件。

> **请求结果不明确，不等于下单失败。**
> 如果页面超时，先检查当前订单和账户流水，再决定是否重新提交。连续点击可能产生多笔独立订单。

## 查看结果

通过当前订单和历史订单跟踪处理进度。用实际返还与结算流水核对资金；结算前的预计返还不属于可用余额。
