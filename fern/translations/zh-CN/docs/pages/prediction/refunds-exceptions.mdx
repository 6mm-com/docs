异常可能涉及价格中断、价格证据不一致、赔率差异或结算处理失败。异常需要有可追溯的处理结果，不能自动等同于未中奖。

## 常见情况

| 情况 | 应如何处理 |
| --- | --- |
| 网格有效时间内行情缺失 | 查询异常或退款处理，缺少采样不能证明未命中 |
| 下单请求超时 | 先查原订单和冻结，再决定是否重新提交 |
| 页面显示与订单结果不同 | 核对价格来源、时间、已受理条件及判定证据 |
| 结算似乎延迟 | 分别检查最终状态与流水 |
| 订单已退款或作废 | 查看原因、实际资金变动及剩余冻结 |

## 退款与作废的区别

退款描述资金处理，作废描述订单失效。不要仅凭标签推断退款金额或到账时限，应核对记录中的处理结果和资金流水。

报表有效下注不包含已退款、已作废订单。分析玩法表现时，退款不应当作中奖返还统计。

## 联系支持时提供什么

提供订单号、适用的场次编号、品种、相关时间、记录赔率、结果／状态及结算流水号。网格争议还应附上已受理价格区间和有效时间窗。不要提供密码、API 密钥或完整访问令牌。

支持入口见[合作伙伴支持](/zh-CN/resources/contact/support)，资金核对见[资金划转与流水](/zh-CN/prediction/transfers-ledger)。
