## Copie o código de integração do locatário

Abra **Configurações do sistema → Integração de sites**. Configure os domínios de sites permitidos e copie o código gerado. A App Key identifica seu locatário; não é uma senha de login ou um segredo de assinatura de identidade. O widget de suporte ao cliente é separado do Trading Widget SDK.

A seguir ilustramos os atributos de script suportados. Substitua o espaço reservado pela App Key do seu locatário e use o script URL gerado pelo seu console.

```html
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"></script>
```

Para um botão existente:

```html
<button id="support-button">Contact support</button>
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"
        data-trigger="#support-button"></script>
```

## Identidade do visitante

| Modo | Responsabilidade de integração |
| --- | --- |
| Visitante anônimo | Use a entrada de visitante configurada pelo locatário; o sistema identifica o visitante do navegador |
| Usuário conectado | Gere o token de identidade em seu back-end e passe o ID de usuário estável e o token assinado usando o exemplo do console |

Os atributos de login suportados são <code>data-user-id</code> e <code>data-user-token</code>. Mantenha a assinatura em segredo no seu servidor; não o insira em HTML, código móvel ou prompt de IA. Use o formato exato do token e o tempo de vida mostrado no console.

Para um aplicativo ou WebView, use o modo de entrada e integração fornecido para seu locatário. Teste a navegação, autenticação, seleção de arquivos e comportamento da janela de visualização no dispositivo real; um snippet de site por si só não estabelece suporte nativo SDK.

<span id="verify-the-entry" data-sixmm-canonical-anchor="verify-the-entry" aria-hidden="true"></span>

## Verifique a entrada

Verifique domínios permitidos, idioma, tema claro/escuro, abertura e fechamento, mensagem de teste, suporte humano e envio de tickets. Ao trocar de usuário do site, verifique se a identidade transmitida ao widget pertence ao usuário atual. Se o widget não abrir, inspecione a chave do aplicativo, o carregamento do script, as configurações do domínio e a disponibilidade do serviço de locatário.
