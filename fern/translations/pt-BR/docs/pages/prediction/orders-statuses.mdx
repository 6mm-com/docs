Cada pedido de previsão aceito possui seu próprio número de pedido. As ordens para cima/para baixo também fazem referência a uma rodada; Pedidos personalizados e de grade não exigem uma rodada compartilhada.

<span id="current-and-historical-records" data-sixmm-canonical-anchor="current-and-historical-records" aria-hidden="true"></span>

## Registros atuais e históricos

| Status exibido | Como ler |
| --- | --- |
| Aguardando resultado | Nenhum resultado final foi registrado ainda |
| Apostas encerradas | A fase de apostas exibida é encerrada; este não é um resultado de vitória/derrota |
| Ganho | O pedido é registrado como um resultado vencedor |
| Perdido | A ordem é registrada como um resultado perdedor |
| Reembolsado | O processamento do reembolso é refletido no status do pedido; reconciliar a transação real |
| Anulado | O pedido é invalidado; verifique o motivo e o tratamento do fundo relacionado |

Nem todo jogo usa todos os status intermediários da mesma maneira. Uma etiqueta de status por si só não prova que o crédito da conta foi concluído.

<span id="fields-to-check" data-sixmm-canonical-anchor="fields-to-check" aria-hidden="true"></span>

## Campos para verificar

Todos os jogos expõem o número do pedido, propriedade do usuário, símbolo, aposta, probabilidades, horário do pedido e status. Os registros históricos adicionam pagamento real, informações de resultado, horário de liquidação e número da transação de liquidação.

- Para cima/para baixo adiciona o número redondo e a direção prevista/real.
- Custom adiciona probabilidades fixas e vencimento independente.
- Grid adiciona a célula selecionada e o intervalo de preço; interpretar campos de resultados usando a regra de toque da janela de tempo.

<span id="changes-and-duplicate-submissions" data-sixmm-canonical-anchor="changes-and-duplicate-submissions" aria-hidden="true"></span>

## Alterações e envios duplicados

Não presuma que uma ordem de previsão pode ser alterada ou cancelada como uma ordem com limite perpétuo. Siga as ações e regras disponíveis para o produto aceito. Quando a resposta do envio for incerta, consulte o pedido original antes de fazer outra aposta.
