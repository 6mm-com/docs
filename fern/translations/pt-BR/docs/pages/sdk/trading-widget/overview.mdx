## Divisão de responsabilidades

| Área | Proprietário | Notas |
| --- | --- | --- |
| Criação de contêiner | Front-end do parceiro | Forneça um elemento visível com largura e altura explícitas. |
| criação de iframe | Trading Widget SDK | O SDK cria e gerencia o iframe. |
| Interface de negociação | 6MM iframe | Linha K, livro de pedidos, formulário de pedido, posições, pedidos e dados de conta são executados dentro do iframe. |
| Controles de exibição | Trading Widget SDK + 6MM iframe | O cabeçalho incorporado e o ticker inferior do PC ficam ocultos por padrão. Os parceiros podem usar `display` para mostrar áreas de shell ou ocultar contêineres comerciais de alto nível. |
| Verificação de login do parceiro | Back-end do parceiro | Valide a sessão do usuário parceiro antes de emitir credenciais de autenticação. |
| Incorporar emissão de token | Back-end do parceiro + agente API | Recomendado para modo token de parceiro. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Versionamento

O caminho de integração pública permanece estável no script v1 URL. O conjunto atual de recursos v1 inclui token de parceiro, tokenProvider, entryUrlProvider, controles de exibição, eventos de ciclo de vida, métodos de instância e eventos de pedido.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Quando usar o widget

Escolha Trading Widget quando um parceiro precisar de uma interface comercial completa dentro de um produto web existente. Use a documentação REST API e WebSocket ao construir e manter uma interface de negociação totalmente personalizada.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Caminho de implementação

1. Siga o [Trading Widget Início rápido](/pt-BR/sdk/trading-widget/quick-start) para carregar o script e criar um contêiner visível.
2. Configurar [autenticação de token de parceiro](/pt-BR/sdk/trading-widget/authentication) por meio de um back-end de parceiro.
3. Adicione o necessário [opções e eventos](/pt-BR/sdk/trading-widget/options-events).
4. Usar [métodos de instância](/pt-BR/sdk/trading-widget/instance-methods) para controles de ciclo de vida e tempo de execução.

<span id="verified-public-runtime" data-sixmm-canonical-anchor="verified-public-runtime" aria-hidden="true"></span>

## Tempo de execução público verificado

O script público `v1` relata a versão `1.8.0` em 10/10/2026. Este URL é um ponto de entrada estável para a versão principal, não uma compilação fixada. Leia `TradingWidget.version` e `TradingWidget.capabilities` em seu tempo de execução carregado antes de usar recursos opcionais. Java Agent SDK `v0.3.0` é um pacote de back-end separado.

O tempo de execução oferece suporte a uma única instância ativa (`multiInstance=false`); criar outro widget destrói a instância anterior. Suas localidades suportadas são `en`, `en-US` e `zh-CN`, independentemente dos 20 idiomas de documentação.
