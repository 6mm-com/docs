## Divisão de responsabilidades

| Área | Proprietário | Notas |
| --- | --- | --- |
| Criação de contêineres | Interface parceira | Forneça um elemento visível com largura e altura explícitas. |
| Criação do iframe | Trading Widget SDK | O SDK cria e gerencia o iframe. |
| UI de Negociação | 6MM iframe | K-line, livro de pedidos, formulário de pedido, posições, ordens e dados de conta são executados dentro do iframe. |
| Controles de exibição | Trading Widget SDK + 6MM iframe | O cabeçalho embeded do PC e o ticker inferior são ocultos por padrão. Parceiros podem usar `display` para mostrar áreas de shell ou esconder contêineres de trading de alto nível. |
| Verificação de login do parceiro | Backend parceiro | Valide a sessão do usuário parceiro antes de emitir credenciais de autenticação. |
| Emissão de tokens incorporados | Backend parceiro + Agente API | Recomendado para o modo token-parceiro. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Versionamento

O caminho de integração pública permanece estável sob o script v1 URL. O conjunto atual de capacidades v1 inclui partner-token, tokenProvider, entryUrlProvider, controles de exibição, eventos do ciclo de vida, métodos de instância e eventos de ordem.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Quando usar o widget

Escolha Trading Widget quando um parceiro precisar de uma interface de negociação completa dentro de um produto web existente. Use a documentação REST API e WebSocket ao construir e manter uma interface de negociação totalmente personalizada.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Caminho de implementação

1. Siga o [Trading Widget Início Rápido](/pt-BR/sdk/trading-widget/quick-start) para carregar o script e criar um contêiner visível.
2. Configurar [Autenticação por token de parceiro](/pt-BR/sdk/trading-widget/authentication) através de um backend parceiro.
3. Adicionar o necessário [Opções e eventos](/pt-BR/sdk/trading-widget/options-events).
4. Uso [Métodos de instância](/pt-BR/sdk/trading-widget/instance-methods) para controles do ciclo de vida e do tempo de execução.
