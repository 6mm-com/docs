## Opções

| Campo | Tipo | Padrão | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origem do alfabeto | Domínio iframe. Passe explicitamente nas páginas parceiras. |
| Símbolo | string | BTCUSDT | Normalizado para maiúsculas e tiras - / _. |
| Tema | escuro \| luz | Escuro | Parâmetro inicial do tema. |
| Localização | en \| en-US \| zh-CN | Navegador/padrão | Inglês e chinês simplificado são suportados. |
| Layout | padrão \| compacto | Padrão | Opção de layout reservado. |
| Exibição | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Os controles embutim áreas de concha e contêineres de comércio de alto nível. |
| Auth | object | nenhum | Use o partner-token para novas integrações SSO . |

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Controles de exibição

`display` controla a shell da página de negociação embutida e os contêineres de alto nível. Em embeds de parceiros, o cabeçalho PC e o ticker do mercado inferior são ocultos por padrão.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Padrão | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | falso | Se mostrar o cabeçalho embed do PC dentro do iframe. |
| showTicker | boolean | falso | Se mostrar o ticker do mercado mais baixo na concha embed. |
| Escondido | String[] | [] | Esconde contêineres de alto nível na página de troca. |

Valores `display.hidden` suportados:

| Valor | Contêiner |
| --- | --- |
| Parada | Contêiner de cartas |
| orderBook | Recipiente do livro de pedidos |
| orderForm | Painel de formulários de pedidos |
| Posições | Posições inferiores e painel de ordens abertas |
| Conta | Contêiner de ativos da conta |

`display.hidden` esconde apenas contêineres inteiros. Não esconde botões, campos ou ferramentas individuais dentro de um contêiner. Valores que não se mapeiam para a viewport atual são ignorados.

## Eventos

| Evento | Gatilho |
| --- | --- |
| Pronto | Inicialização do iframe concluída. |
| Erro | SDK, iframe ou erro de autenticação. |
| state_changed | SDK estado do ciclo de vida mudou. |
| auth_state_changed | O estado de autenticação do token parceiro mudou. |
| symbol_changed | O símbolo real do iframe mudou. |
| locale_changed | A localização real do iframe mudou. |
| order_created | O usuário criou uma ordem dentro do iframe. |
| order_failed | A submissão do pedido foi falhada. |
| destruído | SDK instância destruída. |
