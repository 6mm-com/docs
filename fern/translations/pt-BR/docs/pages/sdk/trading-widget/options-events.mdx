## Opções

| Campo | Tipo | Padrão | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origem do script | domínio iframe. Passe explicitamente nas páginas dos parceiros. |
| símbolo | string | BTCUSDT | Normalizado para letras maiúsculas e faixas - / _. |
| tema | escuro \| luz | escuro | Parâmetro inicial do tema. |
| localidade | pt \| en-EUA \| zh-CN | Navegador/padrão | Inglês e chinês simplificado são suportados. |
| layout | padrão \| compactar | padrão | Opção de layout reservado. |
| mostrar | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Os controles incorporam áreas de shell e contêineres comerciais de alto nível. |
| autenticação | object | nenhum | Use token de parceiro para novas integrações SSO. |

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Controles de exibição

`display` controla o shell da página de negociação incorporada e os contêineres de alto nível. Nas incorporações de parceiros, o cabeçalho do PC e o ticker inferior do mercado ficam ocultos por padrão.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Padrão | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | falso | Se deve mostrar o cabeçalho incorporado do PC dentro do iframe. |
| showTicker | boolean | falso | Se deve mostrar o ticker inferior do mercado no shell incorporado. |
| escondido | corda[] | [] | Oculta contêineres de alto nível na página de negociação. |

Valores `display.hidden` suportados:

| Valor | Recipiente |
| --- | --- |
| gráfico | Contêiner de gráfico |
| orderBook | Recipiente de livro de pedidos |
| orderForm | Painel de formulário de pedido |
| posições | Posições inferiores e painel de pedidos abertos |
| conta | Contêiner de ativos da conta |

`display.hidden` oculta apenas contêineres inteiros. Ele não oculta botões, campos ou ferramentas individuais dentro de um contêiner. Os valores que não são mapeados para a viewport atual são ignorados.

## Eventos

| Evento | Acionar |
| --- | --- |
| preparar | inicialização do iframe concluída. |
| erro | SDK, iframe ou erro de autenticação. |
| estado_alterado | SDK estado do ciclo de vida alterado. |
| auth_state_changed | Estado de autenticação do token de parceiro alterado. |
| símbolo_alterado | O símbolo real do iframe foi alterado. |
| locale_changed | A localidade real do iframe foi alterada. |
| pedido_criado | O usuário criou um pedido dentro do iframe. |
| pedido_falhou | Falha no envio do pedido. |
| destruído | SDK instância destruída. |

## Páginas de produtos e modo de negociação

Java Agent SDK e o navegador Trading Widget SDK têm versão independente. Para negociação de segundos, use os recursos atuais do widget e selecione explicitamente a página e o modo de negociação.

| Opção | Valores | Significado |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Página do produto para negociação de segundos. |
| `tradingMode` | `real`, `demo` | O padrão é `real`; corresponder explicitamente ao ambiente de financiamento de back-end. |

Verifique `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` e `TradingWidget.capabilities.partnerToken` antes da inicialização. A criação de token não seleciona um ambiente de fundos. Para alterar os usuários ou o modo real/demo, destrua a instância antiga e crie uma nova.

Ver [exemplo completo de negociação de segundos](/pt-BR/sdk/agent-sdk/java/seconds-trading) e [configuração de produção/simulada](/pt-BR/sdk/agent-sdk/java/environments).

## Destinos e eventos de exibição adicionais

O tempo de execução atual também aceita `symbolFavorites` e `symbolTicker` em `display.hidden`. Sempre verifique `TradingWidget.capabilities.displayTargets`; um destino controla um contêiner de alto nível e não é uma configuração de permissão em nível de campo.

| Evento | Significado |
| --- | --- |
| `rendered` | O iframe envia sua notificação renderizada. |
| `theme_changed` | O iframe relata seu tema real. |
| `page_changed` | O iframe relata sua página real do produto. |

Use `onRendered` ou `widget.on('rendered', handler)` para lidar com a renderização separadamente da inicialização. As páginas atualmente suportadas são publicadas em `TradingWidget.capabilities.pages`; valide a página solicitada em vez de adivinhar um caminho.
