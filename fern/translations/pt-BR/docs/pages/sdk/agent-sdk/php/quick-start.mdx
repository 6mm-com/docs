## Instalação

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Acesso ao pacote**
>
> 6MM fornece o nome aprovado do pacote Composer, repositório e versão durante a integração do parceiro. O pacote não deve ser assumido como existindo no Packagist público.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Antes de começar

- Confirme o Agente API base URL com 6MM.
- Carregar apiSecret a partir de variáveis de ambiente ou gerenciamento de segredos.
- Mantenha SDK uso apenas dentro dos serviços backend.
- Preparar o manuseio de idempotentes para transferências e fluxos de webhook.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Inicializar cliente

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Apenas backend**
>
> O PHP SDK assina solicitações de API do Agente e não deve ser exposto por meio de código-fonte público ou ambientes de runtime frontend.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Exemplo: transferir fundos para

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Use cadeias decimais para os valores e preserve o agentOrderNo original ao tentar novamente ou consultar o status da transferência.
