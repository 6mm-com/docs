<h2 id="runtime">Duração</h2>

| Item | Valor |
| --- | --- |
| Pacote | Sixmm/agente-SDK |
| Versão mínima PHP | PHP 7,4+ |
| Versão recomendada PHP | PHP 8.1+ ou versões atualmente suportadas |
| Extensões obrigatórias | ext-json, ext-curl |

A fonte do pacote PHP SDK e a versão aprovada são fornecidas durante a integração do parceiro. Não presuma que o pacote está disponível pelo Packagist público; configure o repositório Composer fornecido para sua organização.

<h2 id="supported-scenarios">Cenários suportados</h2>

| Cenário | SDK método |
| --- | --- |
| Vincular usuário | Vincular |
| Transferência de valor fixo | Transferência |
| Transferir tudo para fora | transferAllOut |
| Transferência reversa | Reverso |
| Ordem da consulta | queryOrder |
| Criar URL de entrada | createEntryUrl |
| Verificação de Webhook | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Regras de integração backend</h2>

- Carregar `apiSecret` a partir de um gerenciador secreto ou variável de ambiente protegido.
- Mantenha a lógica de usuário, transferência, assinatura e webhook fora do código do navegador.
- Use cadeias decimais para os valores dos ativos para evitar arredondamento em ponto flutuante.
- Reutilizar o `agentOrderNo` original ao consultar um resultado de transferência incerto.
- Verificar as assinaturas do webhook contra o corpo bruto da requisição antes de decodificar ou alterá-lo.
