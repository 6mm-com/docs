Este guia é direcionado a **Agent Java SDK `v0.3.0`**, Java 8+ e ao contrato público marcado. Os exemplos são executados em um back-end de parceiro após a inicialização de `client` em [Início rápido](/pt-BR/sdk/agent-sdk/java/quick-start).

| Item | Valor |
| --- | --- |
| Tag de origem estável | `v0.3.0` |
| Java | Java 8+ |
| Maven | Maven 3.9+ |
| Coordenadas | `com.sixmm.exchange.sdk:agent:0.3.0` |

Fonte de hosts do GitHub; isso não torna essas coordenadas solucionáveis ​​no Maven Central. Use a instalação local marcada ou seu repositório de artefatos aprovado.

| Transferências | Transferência de valor fixo | `transfer` | Transferir fundos para ou de 6MM |

| Transferências | Ordem inversa | `reverse` | Reverter uma transferência bem-sucedida quando o back-end oferece suporte a um fluxo de compensação |
| Transferências | Ordem de consulta | `queryOrder` | Consultar uma ordem de transferência por número de ordem do parceiro |

| Transferências | Verificação Webhook | `WebhookVerifier.verify` | Verifique os retornos de chamada do estado final da transferência de 6MM |
| Carteira de financiamento | Transferência de financiamento | `walletTransfer` | Parceiro ↔ Financiamento ou Financiamento ↔ Contrato; confirme o status retornado |

## Configuração

Obtenha os seguintes valores de 6MM antes
integrando.

| Item | Exemplo | Descrição |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Agente API base URL, sem barra final |
| `agentCode` | `AGENT001` | Código de parceiro |
| `apiSecret` | `your-api-secret` | API segredo de assinatura. Mantenha-o apenas no back-end |
| `defaultCurrency` | `USDT` | Moeda padrão, geralmente `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Endpoint do parceiro para retornos de chamada 6MM |

Recomendações de produção:

- Use HTTPS para endpoints do agente API e webhook.
- Armazene `apiSecret` em um gerenciador secreto, centro de configuração ou variável de ambiente.
- Mantenha a hora do servidor sincronizada, de preferência com NTP.
- Mantenha todos os números de pedido de parceiros e mantenha-os globalmente exclusivos.
- Nunca envie `apiSecret` para navegadores, aplicativos, miniprogramas ou código-fonte de front-end.


<span id="automatic-signing-fields" data-sixmm-canonical-anchor="automatic-signing-fields" aria-hidden="true"></span>

## Campos de assinatura automática

Para chamadas assinadas do Agente API, o SDK injeta automaticamente:

| Campo | Fonte | Descrição |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Código de parceiro |
| `timestamp` | Carimbo de data/hora Unix atual UTC | Segundos |
| `nonce` | Gerador aleatório seguro | Proteção de repetição |
| `sign` | HMAC-SHA256 | Solicitar assinatura |
| `currency` | `defaultCurrency` | Preenchido quando solicitações de transferência/conta omitem moeda |

Regras de assinatura:

1. Excluir `sign`.
2. Exclua valores vazios.
3. Classifique as chaves por ordem ASCII.
4. Cadastre-se como `k=v&k2=v2`.
5. Calcule HMAC-SHA256 hexadecimal com `apiSecret`.

O código comercial normal não deve calcular assinaturas ou definir manualmente
`agentCode`, `timestamp`, `nonce`, ou `sign`.
