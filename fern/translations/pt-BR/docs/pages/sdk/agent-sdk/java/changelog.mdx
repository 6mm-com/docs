Este guia é direcionado a **Agent Java SDK `v0.3.0`**, Java 8+ e ao contrato público marcado. Os exemplos são executados em um back-end de parceiro após a inicialização de `client` em [Início rápido](/pt-BR/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Seis consultas perpétuas: pedidos atuais, histórico de pedidos, preenchimentos, posições atuais, histórico de posições e razão de contas.
- Saldos de financiamento, transferências, consultas de recuperação e transferências de financiamento/contrato.
- Produção explícita/seleção simulada para solicitações de fundos apoiados.
- Guias de redirecionamento e incorporação de negociação de segundos, referência de campo de resposta e instruções de migração.

Java SDK e Trading Widget SDK têm versões independentes. O widget `v1` URL não é Java SDK `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Integrações existentes

Preserve mapeamentos de usuários, pedidos originais e credenciais. Os campos de ambiente omitidos mantêm o comportamento de produção existente. Financiamento, fundos simulados explícitos e seis consultas perpétuas exigem os novos modelos e métodos correspondentes. Análise [Guia de atualização](/pt-BR/sdk/agent-sdk/java/upgrade) antes de alterar uma integração existente.
