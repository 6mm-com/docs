Este guia é direcionado a **Agent Java SDK `v0.3.0`**, Java 8+ e ao contrato público marcado. Os exemplos são executados em um back-end de parceiro após a inicialização de `client` em [Início rápido](/pt-BR/sdk/agent-sdk/java/quick-start).

## Entrada Direta URL

A entrada direta URL é para o modo de redirecionamento. Um usuário parceiro clica em um botão na
site do parceiro, abre o frontend 6MM e faz login automaticamente.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Regras de campo:

| Campo | Descrição |
| --- | --- |
| `redirectPath` | 6MM caminho relativo do frontend. Deve começar com `/`, por exemplo `/trade/BTCUSDT` |
| `returnUrl` | Parceiro absoluto URL usado quando o usuário sai do frontend 6MM. Somente `http` e `https` são permitidos |
| `expireAt` | Tempo de expiração do ticket de entrada como carimbo de data/hora Unix em segundos |

Requisitos de segurança:

- `webUrl` contém um ticket único. Use-o imediatamente e não guarde por muito tempo.
- Se a entrada URL expirar ou tiver sido usada, gere uma nova no site do parceiro.
- `returnUrl` não deve ser `javascript:`, um caminho relativo ou um URL com informações do usuário.

## Seleção de produto e modo

Use a rota de frontend atual fornecida por 6MM. Por exemplo `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` ou `/zh-CN/futures/BTCUSDT?tradingMode=real`. O ticket autentica o usuário; não seleciona um ambiente de financiamento nem movimenta fundos.

Ver [Negociação de segundos](/pt-BR/sdk/agent-sdk/java/seconds-trading) para exemplos de redirecionamento e incorporados.
