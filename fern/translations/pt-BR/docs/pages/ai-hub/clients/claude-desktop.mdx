Claude Desktop é uma boa opção para pesquisa baseada em MCP-, revisão de contas e análise operacional.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Configuração recomendada

| Precisar | Configurar |
| --- | --- |
| Pesquisa de mercado público | Hospedado MCP |
| Análise com reconhecimento de conta | Local MCP |
| Endpoint da equipe interna | Remoto MCP |

<span id="example-prompts" data-sixmm-canonical-anchor="example-prompts" aria-hidden="true"></span>

## Solicitações de exemplo

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<span id="notes" data-sixmm-canonical-anchor="notes" aria-hidden="true"></span>

## Notas

MCP local é preferido sempre que dados de contas privadas estão envolvidos porque o servidor MCP é executado na máquina do usuário e as credenciais não precisam ser enviadas para um endpoint de IA hospedado por 6MM.
