ChatGPT Desktop é um ponto de entrada familiar para usuários que desejam fazer perguntas de mercado em linguagem natural.

Use este caminho quando o usuário desejar uma interface de conversação para dados públicos de mercado, resumos de contas, explicações de posições e contexto de regras de negociação.

<h2 id="recommended-setup">Configuração recomendada</h2>

| Precisar | Configurar |
| --- | --- |
| Dados públicos do mercado | Hospedado MCP |
| Contexto da conta privada | Local MCP |
| Solicitações de análise repetíveis | Habilidades Agentes |
| Fluxos de trabalho baseados em terminal | 6MM CLI |

<h2 id="what-users-can-ask">O que os usuários podem perguntar</h2>

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<h2 id="safety-defaults">Padrões de segurança</h2>

- Comece com dados públicos de mercado.
- Use Local MCP quando as credenciais da conta forem necessárias.
- Mantenha as chaves privadas API na máquina do usuário.
- Exija visualização e confirmação explícita antes de qualquer ação comercial futura.
