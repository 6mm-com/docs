Gemini CLI funciona melhor com saída de linha de comando que pode ser inspecionada, resumida e passada para tarefas de acompanhamento.

<h2 id="recommended-setup">Configuração recomendada</h2>

| Precisar | Configurar |
| --- | --- |
| Verificações do mercado público | 6MM CLI |
| Pesquisa com script | 6MM CLI |
| Contexto da conta privada | Local MCP ou CLI com credenciais locais |

<h2 id="example-prompts">Solicitações de exemplo</h2>

```text

```

```text

```

<h2 id="output-format">Formato de saída</h2>

Prefira resultados estruturados, como JSON ou tabelas Markdown, para que o cliente de IA possa raciocinar sobre o resultado sem perder a precisão.
