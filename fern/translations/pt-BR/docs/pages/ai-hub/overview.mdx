> **Planejado – ainda não lançado**
> AI Hub é um recurso planejado. Recursos, terminais, comandos e configurações do cliente nesta página descrevem o design proposto e não estão disponíveis no momento. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


6MM Agentic AI Hub é a AI-interface nativa para 6MM dados de mercado, fluxos de trabalho de contas e futuras operações de negociação controladas.

Em vez de alternar entre painéis, API documentos e scripts, os usuários podem pedir a um cliente de IA para consultar 6MM, explicar as condições do mercado, revisar o risco da conta ou preparar uma visualização do pedido. O cliente AI não substitui o modelo de segurança 6MM API; ele chama ferramentas 6MM estruturadas por meio de CLI, MCP ou modelos de fluxo de trabalho.

<h2 id="what-you-can-ask-an-ai-client">O que você pode perguntar a um cliente de IA</h2>

Use o AI Hub quando quiser fazer perguntas como:

```text
Show me the BTC-USDT-PERP order book and explain current liquidity.
```

```text
Compare BTC and ETH funding rates over the last 24 hours.
```

```text
Check my testnet positions and explain liquidation risk. Do not place orders.
```

```text
Preview a small BTC long order and explain fees, margin impact, and risk checks.
```

<h2 id="why-ai-agents-need-a-dedicated-access-layer">Por que os agentes de IA precisam de uma camada de acesso dedicada</h2>

Os agentes de IA funcionam melhor quando possuem ferramentas estruturadas em vez de páginas da web brutas ou texto copiado não estruturado. O AI Hub oferece a eles:

| Exigência | Abordagem 6MM |
| --- | --- |
| Contexto do mercado ao vivo | Ferramentas e recursos de dados públicos de mercado para símbolos, carteiras de pedidos, negociações, financiamento, taxas e regras. |
| Limpar permissões | Dados públicos separados, leitura de conta, visualização e escopos de negociação controlados. |
| Execução mais segura | Visualização do fluxo do primeiro pedido, confirmação explícita, idempotência, limites e registros de auditoria. |
| Flexibilidade do cliente | Hospedado MCP, local MCP, CLI, remoto MCP e habilidades de agente para diferentes ambientes de IA. |

<h2 id="setup-paths">Caminhos de configuração</h2>

| Caminho | Melhor para | O usuário deve saber |
| --- | --- | --- |
| Hospedado MCP | Acesso rápido a dados públicos de mercado | Nenhuma instalação e nenhuma chave de usuário API para dados públicos. Negociar não é o objetivo do primeiro lançamento. |
| Local MCP | Clientes de IA que precisam de contexto de conta privada | O servidor MCP é executado localmente e as credenciais permanecem na máquina do usuário. |
| CLI | Agentes de codificação, scripts e usuários de terminal | Produz saída de comando amigável ao agente e pode ser usado sem um servidor MCP. |
| Remoto MCP | Instituições e equipes que desejam seu próprio endpoint | O usuário ou instituição controla hospedagem, credenciais, acesso à rede e registros. |
| Habilidades Agentes | Fluxos de trabalho repetíveis | As habilidades guiam a IA através de etapas de análise e risco usando ferramentas aprovadas. |

<h2 id="what-is-available-first">O que está disponível primeiro</h2>

O AI Hub deve começar com dados públicos de mercado e recursos de regras de negociação:

- Mercados.
- Relógios.
- Encomende livros.
- Negociações.
- Klines.
- Taxas de financiamento.
- Estado do sistema.
- Taxas, especificações de contrato, regras de margem e recursos de regras de risco.

O acesso à conta privada e a negociação devem ser realizados:

- As ferramentas de leitura de conta exigem credenciais explícitas somente leitura.
- A visualização do pedido deve vir antes de qualquer criação real de pedido.
- A negociação controlada requer escopos de permissão, verificações de risco do lado do serviço, confirmação do usuário, idempotência e registros de auditoria.
