> **Planejado – ainda não lançado**
> AI Hub é um recurso planejado. Recursos, terminais, comandos e configurações do cliente nesta página descrevem o design proposto e não estão disponíveis no momento. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


Escolha uma configuração com base em duas perguntas:

1. Qual cliente de IA você deseja usar?
2. Você precisa apenas de dados públicos, acesso a contas privadas ou fluxos de trabalho de negociação?

Se não tiver certeza, comece com MCP hospedado para dados públicos ou MCP local para fluxos de trabalho de contas privadas.

<h2 id="pick-by-use-case">Escolha por caso de uso</h2>

<CardGroup cols={2}>

<h2 id="quick-decision-table">Tabela de decisão rápida</h2>

| Meta | Configuração recomendada | Por que |
| --- | --- | --- |
| Peça a um cliente de IA dados públicos de mercado | Hospedado MCP | Nenhuma instalação local e nenhuma chave API necessária. |
| Deixe Claude Desktop, Cursor ou ChatGPT Desktop chamar ferramentas 6MM | Local MCP | A IA chama as ferramentas por meio de um servidor local controlado pelo usuário. |
| Deixe Codex, Claude Code, Gemini CLI, ou scripts chamarem 6MM | CLI | A saída do comando pode ser JSON e fácil de ser analisada pelos agentes. |
| Forneça um endpoint MCP gerenciado pela empresa | Remoto MCP | A instituição controla hospedagem, credenciais, acesso e logs. |
| Padronize análises repetidas ou fluxos de trabalho de risco | Habilidades Agentes | Os modelos definem o uso da ferramenta, as proteções e o formato de saída. |

<h2 id="pick-by-setup-path">Escolha por caminho de configuração</h2>

| Configurar | Instalação | API localização da chave | Melhor escopo inicial | Escopo de conta e negociação |
| --- | --- | --- | --- | --- |
| Hospedado MCP | Nenhum | Nenhuma chave de usuário API para dados públicos | Dados públicos do mercado | Não recomendado para primeiro lançamento |
| Local MCP | Pacote de instalação do usuário | Máquina do usuário | Dados públicos e leitura da conta | Caminho recomendado para negociações futuras |
| CLI | Pacote de instalação do usuário | Máquina do usuário | Dados públicos e scripts | Útil para visualização e automação |
| Remoto MCP | O usuário implanta o servidor | Nuvem de usuário ou nuvem institucional | Dados públicos ou leitura da conta | Possível quando o usuário controla a implantação |
| Habilidades | Documentos ou modelos instaláveis | Depende das ferramentas subjacentes | Fluxos de trabalho de análise | Deve seguir as permissões da ferramenta |

<h2 id="security-rule-of-thumb">Regra prática de segurança</h2>

Use a configuração de menor risco que suporta a tarefa:

- Dados públicos do mercado: MCP hospedado é suficiente.
- Dados da conta privada: Local MCP ou remoto gerenciado pelo usuário MCP.
- Visualização de negociação: Local MCP ou CLI, de preferência testnet primeiro.
- Negociação real: somente após permissão explícita, visualização, confirmação, limites e registros de auditoria.
