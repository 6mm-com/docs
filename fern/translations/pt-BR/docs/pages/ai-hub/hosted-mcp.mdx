> **Planejado – ainda não lançado**
> AI Hub é um recurso planejado. Recursos, terminais, comandos e configurações do cliente nesta página descrevem o design proposto e não estão disponíveis no momento. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


O MCP hospedado é a maneira mais simples de começar a usar o 6MM AI Hub.

Conecte um cliente de IA ao endpoint MCP hospedado por 6MM e faça perguntas sobre dados públicos de mercado. Não há servidor local para instalar, nenhuma implantação em nuvem para manter e nenhuma chave de usuário API necessária para dados públicos.

<h2 id="what-you-can-do">O que você pode fazer</h2>

- Consulte dados históricos e em tempo real do mercado.
- Navegue pelos mercados perpétuos disponíveis.
- Verifique a profundidade do livro de pedidos e as negociações recentes.
- Compare as taxas de financiamento.
- Leia o contexto de taxas, contratos, margens e regras de risco.

Hospedado MCP é melhor para pesquisa, exploração de produtos e análise de mercado público. Não é a primeira configuração correta para acesso ou negociação a contas privadas.

<h2 id="endpoint">Ponto final</h2>

```text
https://mcp.6mm.com/mcp
```

Verificação de saúde:

```text
https://mcp.6mm.com/health
```

<h2 id="recommended-first-release-scope">Escopo de primeiro lançamento recomendado</h2>

O MCP hospedado deve expor apenas informações públicas e somente leitura na primeira versão:

- Mercados.
- Relógios.
- Encomende livros.
- Negociações recentes.
- Klines.
- Taxas de financiamento.
- Estado do sistema.
- Taxas de negociação.
- Especificações do contrato.
- Recursos de regras de risco e margem.

<h2 id="not-supported-in-the-first-release">Não suportado na primeira versão</h2>

Hospedado MCP não deve ser o primeiro lugar a expor:

- Saldos de contas.
- Posições.
- Pedidos abertos.
- Criação de pedidos.
- Cancelamento de pedido.
- Transferências ou saques.
- Armazenamento de chave do usuário API.

<h2 id="why-public-data-first">Por que os dados públicos primeiro</h2>

Hospedado MCP é operado por 6MM e acessado pela rede. É conveniente, mas não deve se tornar o local padrão onde os usuários enviam chaves privadas API. Contas confidenciais e fluxos de trabalho de negociação devem começar com Local MCP, CLI ou Remoto gerenciado pelo usuário MCP.

<h2 id="example-user-prompt">Exemplo de prompt do usuário</h2>

```text

```

<h2 id="operational-requirements">Requisitos operacionais</h2>

- TLS em todos os terminais.
- Solicite limites de taxa.
- Proteção contra abuso.
- Logs e métricas estruturados.
- Verificações de saúde.
- Descrições e esquemas de ferramentas claros.
- Respostas de erro estáveis ​​para clientes de IA.
