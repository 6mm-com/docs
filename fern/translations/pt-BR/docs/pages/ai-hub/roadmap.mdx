> **Planejado – ainda não lançado**
> AI Hub é um recurso planejado. Recursos, terminais, comandos e configurações do cliente nesta página descrevem o design proposto e não estão disponíveis no momento. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


O AI Hub deve ser lançado em etapas para que os usuários recebam valor antecipadamente, enquanto os recursos comerciais confidenciais permanecem protegidos.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## Fase 1: Acesso à IA no mercado público

Objetivo: permitir que qualquer cliente de IA com suporte leia dados oficiais de mercado 6MM.

Entregáveis:

- Cliente SDK / API compartilhado.
- CLI comandos de mercado público.
- Ferramentas de mercado público local MCP.
- Ferramentas de mercado público MCP hospedadas.
- Recursos para mercados, taxas, regras de risco e status do sistema.
- Guias de instalação do cliente.

Não incluído:

- Consultas de conta.
- Negociação de verdade.
- API hospedagem principal.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Fase 2: leitura da conta

Objetivo: permitir que os usuários inspecionem com segurança o contexto de sua própria conta.

Entregáveis:

- Escopo da chave API somente leitura.
- Resumo da conta.
- Saldos.
- Posições.
- Pedidos abertos.
- Preenchimentos.
- Pagamentos de financiamento.
- Alerta de risco do portfólio.

Implantação preferencial:

- Local MCP.
- CLI.
- Remoto MCP auto-hospedado.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Fase 3: Pré-visualização da Negociação

Objetivo: permitir que a IA ajude a gerar pedidos sem executá-los.

Entregáveis:

- `preview_order`.
- Verificações de risco.
- Impacto na margem.
- Estimativa de taxas.
- Impacto da liquidação.
- Prompt de planejamento de execução.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Fase 4: Negociação Controlada

Objetivo: apoiar negociações reais apenas com barreiras de proteção fortes.

Entregáveis:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- idempotência.
- limites nocionais máximos.
- confirmação explícita.
- registros de auditoria.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Fase 5: Habilidades Agentes

Objetivo: produzir análises de mercado comuns e fluxos de trabalho de risco.

Entregáveis:

- Habilidade de analista de mercado.
- Habilidade de risco de portfólio.
- Habilidade de pesquisa de financiamento.
- Habilidade de proteção de liquidação.
- Habilidade de planejador de execução.
- Biblioteca de tarefas de exemplo.
