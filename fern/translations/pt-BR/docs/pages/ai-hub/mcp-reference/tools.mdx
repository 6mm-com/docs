Ferramentas MCP são ações que um cliente de IA pode chamar. Cada ferramenta deve ter uma descrição clara, esquema JSON, requisito de permissão, formato de resposta estável e modelo de erro.

<h2 id="phase-1-public-market-tools">Fase 1: ferramentas de mercado público</h2>

| Ferramenta | Propósito |
| --- | --- |
| 6mm_status_do_sistema | Verifique a disponibilidade do serviço e do mercado. |
| 6mm_mercados | Liste os mercados disponíveis e os metadados básicos. |
| 6mm_market_summary | Resuma o estado do mercado para um ou mais símbolos. |
| 6mm_ticker | Retorne os dados mais recentes do ticker. |
| 6mm_carteira de pedidos | Profundidade do livro de pedidos de devolução. |
| 6mm_klines | Devolva velas históricas. |
| 6mm_negociações | Retorne negociações públicas recentes. |
| 6 mm_taxas_de_financiamento | Retorne as taxas de financiamento atuais e históricas. |

| Ferramenta | Propósito |

| 6mm_balanças | Leia os saldos. |
| 6mm_posições | Leia as posições. |

<h2 id="phase-3-and-later-trading-tools">Fase 3 e posteriores: ferramentas de negociação</h2>

| Ferramenta | Propósito |
| --- | --- |
| 6mm_preview_order | Valide um pedido sem colocá-lo. |
| 6mm_create_order | Crie um pedido após confirmação e verificações de risco. |
| 6mm_cancel_order | Cancele um pedido. |
| 6mm_cancel_all_orders | Cancele todos os pedidos abertos qualificados. |
| 6mm_amend_order | Alterar um pedido existente. |
| 6mm_order_status | Leia o status de um pedido específico. |

<h2 id="tool-requirements">Requisitos de ferramenta</h2>

Cada ferramenta deve definir:

- Descrição do modelo de IA.
- Esquema de entrada JSON.
- Escopo de permissão.
- Apoio ambiental.
- Comportamento do limite de taxa.
- Campos de resposta estáveis.
- Códigos de erro.
- Campos de registro de auditoria.
