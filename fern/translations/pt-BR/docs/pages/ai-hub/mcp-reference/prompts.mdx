Os prompts MCP são fluxos de trabalho reutilizáveis ​​expostos pelo servidor MCP. Eles ajudam os usuários a fazer perguntas consistentes e ajudam os clientes de IA a usar as ferramentas certas.

<h2 id="recommended-prompts">Solicitações recomendadas</h2>

| Incitar | Propósito |
| --- | --- |
| visão geral_do mercado | Resuma o estado do mercado nos símbolos selecionados. |
| análise_de_microestrutura_de_mercado | Analise spread, profundidade, negociações recentes e condições de liquidez. |
| avaliação_de_risco_de_carteira | Revise posições, exposição, margem e risco de liquidação. |
| gerenciamento de posição | Ajude os usuários a compreender o estado da posição e as possíveis ações. |
| proteção_liquidação | Identifique o risco de liquidação e as opções de redução de risco. |
| taxa_de_financiamento_opportunity | Compare taxas de financiamento e possíveis oportunidades. |
| create_optimal_order | Planeje os parâmetros do pedido antes da visualização. |
| estratégia_de cobertura | Explore opções de cobertura para a exposição existente. |
| consulta_negociação | Produza uma análise comercial estruturada sem executar ordens. |

<h2 id="prompt-safety-rules">Alertar regras de segurança</h2>

- Não trate resultados imediatos como aconselhamento financeiro.
- Não execute ferramentas de negociação, a menos que o usuário solicite explicitamente.
- Use a visualização antes de criar.
- Explique suposições e fontes de dados.
- Prefira exemplos de testnet em documentação pública.
