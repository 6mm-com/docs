> **Planejado – ainda não lançado**
> AI Hub é um recurso planejado. Recursos, terminais, comandos e configurações do cliente nesta página descrevem o design proposto e não estão disponíveis no momento. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


Os recursos MCP são contextos somente leitura que os clientes de IA podem inspecionar antes de chamar as ferramentas.

Os recursos reduzem a alucinação, fornecendo ao modelo informações estruturadas e estáveis ​​sobre 6MM.

<h2 id="recommended-resource-uris">URIs de recursos recomendados</h2>

| Recurso | Propósito |
| --- | --- |
| 6mm://sistema/config | Configuração de ambiente e capacidade. |
| 6mm://sistema/status | Sistema atual e status do mercado. |
| 6mm://mercados | Mercados disponíveis. |
| 6mm://mercado/{symbol} | Especificações de contrato e metadados em nível de mercado. |
| 6mm://taxas | Regras de taxas. |
| 6mm://risco/regras | Resumo das regras de negociação e risco. |
| 6mm://risco/margem | Contexto de margem e liquidação. |
| 6mm://financiamento/regras | Regras de taxa de financiamento. |
| 6mm://api/docs | API resumo de referência ou links. |

<h2 id="resource-design-rules">Regras de design de recursos</h2>

- Mantenha os recursos somente leitura.
- Use esquemas estáveis.
- Inclua carimbos de data/hora e nomes de ambiente.
- Evite expor segredos.
- Prefira dados estruturados concisos em vez de prosa longa.
- Link para documentação canônica quando os detalhes forem muito longos.
