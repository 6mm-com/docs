Ao entrar em contato com o suporte, inclua as informações abaixo sempre que disponíveis.

<h2 id="required-context">Contexto necessário</h2>

| Campo | Exemplo |
| --- | --- |
| Meio ambiente | Produção ou encenação |
| Módulo afetado | Trading Widget, Agent SDK, REST API, WebSocket, webhook, sistema white-label |
| Intervalo de tempo | UTC faixa de data e hora em que o problema ocorreu |
| ID de usuário do parceiro | Identificador de usuário do lado do parceiro, se relevante |
| ID de mapeamento 6MM | agentUserId, ID de pedido, ID de requisição ou ID de evento de webhook |
| Impacto nos negócios | Número de usuários ou operações afetadas e se o problema está em andamento |

<h2 id="description-format">Formato da descrição</h2>

- O que aconteceu?
- O que você esperava que acontecesse?
- Pode ser reproduzido?
- O que mudou recentemente?
- O problema ainda está acontecendo?

<h2 id="attachments">Anexos</h2>

- Registros relevantes de solicitações e respostas.
- Capturas de tela ou gravações de tela.
- Cabeçalhos de carga útil e assinatura Webhook.
- Erros no console do navegador para Trading Widget problemas.

<h2 id="copyable-template">Modelo copiável</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Remova campos que não sejam relevantes, mas mantenha o intervalo de tempo UTC e pelo menos uma solicitação ou identificador de negócio pesquisável sempre que possível.

<h2 id="redact-sensitive-data">Redigir dados sensíveis</h2>

Não envie:

- Senhas ou tokens de acesso completo
- API segredos, chaves privadas ou assinaturas completas
- Cookies de sessão
- Pagamento integral, identidade ou outros dados pessoais desnecessários

Mantenha o nome do campo e um prefixo ou sufixo curto apenas quando o suporte precisar distinguir entre valores sanitizados.
