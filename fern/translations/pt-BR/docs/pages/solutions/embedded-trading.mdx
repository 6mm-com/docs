O Sistema de Negociação Embedded API / SDK foi projetado para parceiros que já possuem tráfego, usuários ou fluxos de trabalho de negócios e desejam adicionar negociações sem construir uma exchange completa do zero.

<span id="what-it-provides" data-sixmm-canonical-anchor="what-it-provides" aria-hidden="true"></span>

## O que ele oferece

- Terminal de negociação embarcado através do Trading Widget SDK
- Integração backend de parceiros por meio de Agent SDK
- Vinculação de identidade do usuário e fluxos de tokens de entrada
- Transferência de ativos, ordens, posições e acesso à conta API
- Integração de eventos, webhooks e ciclos de vida para sistemas operacionais

<span id="recommended-architecture" data-sixmm-canonical-anchor="recommended-architecture" aria-hidden="true"></span>

## Arquitetura recomendada

| Camada | Responsabilidade |
| --- | --- |
| Interface parceira | Hospeda o ponto de entrada e incorpora a interface de negociação 6MM . |
| Backend parceiro | Mantém API segredos, valida usuários, emite tokens incorporados e processa webhooks. |
| 6MM infraestrutura de comércio | Gerencia a interface de negociação, correspondência, risco, liquidez, estado da conta e ciclo de vida da negociação. |

## Escolha um caminho de integração

| Requisito | Caminho recomendado |
| --- | --- |
| Interface completa de negociação com a integração web mais rápida | Trading Widget |
| Vinculação de usuários backend, transferência, URL de entrada e manuseio de webhooks | Agent SDK |
| Fluxos de trabalho totalmente personalizados de produtos e pedidos | REST API + WebSocket |
| Experiência em trocas de marca com escopo operacional mais amplo | Bolsa de marca branca |

O design final pode combinar esses caminhos. Confirme autenticação, propriedade dos ativos, limites de responsabilidade, monitoramento e suporte à produção antes do início da implementação.
