## Endpoint de Serviço

```
wss://ws.6mm.com/ws
```

WebSocket canais são divididos em canais públicos e canais privados:

| Tipo             | Autenticação              | Descrição                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Canais públicos  | Não é obrigatório                | Dados de mercado, como profundidade, negociações, Klines e ticker |
| Canais privados | `listenKey` ou JWT necessário | Fluxos de ordem de usuários, contas e posições              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## Canais Públicos

A WebSocket pública não exige autenticação. Após a conexão, envie um pedido de `subscribe` para assinar os canais de mercado.

Canais comuns:

| Canal                            | Descrição                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Profundidade do livro de pedidos. Envia primeiro um snapshot, depois atualizações incrementais |
| `market.trade.{symbol}`            | Últimas negociações                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Resumo do ticker de símbolo único                                       |
| `market.tickers`                   | Resumo do ticker de todos os símbolos                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## Canais Privados

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
Para streams privados WebSocket , crie primeiro um `listenKey` pelo REST API e depois conecte-se a:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
Método de conexão JWT compatível:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Após o sucesso da autenticação, o servidor automaticamente assina a conexão no canal privado do usuário atual. Não é necessário assinar manualmente.
