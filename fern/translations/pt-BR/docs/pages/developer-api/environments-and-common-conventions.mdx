<h2 id="service-endpoints">Endpoints de Serviço</h2>

| Tipo      | Endpoint              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="time-and-numeric-values">Tempo e Valores Numéricos</h2>

* A menos que especificado de outra forma, os campos de tempo são carimbos de tempo de milissegundos do Unix.
* Estatísticas diárias, snapshots de saldo e estatísticas de volume de negociação usam limites UTC dias por padrão.
* Campos sensíveis à precisão, como quantidade, preço, quantidade e taxa, são transmitidos como cadeias.
* IDs inteiros grandes como `orderId`, `conditionId` `strategyId` e  são retornados como cadeias em JSON.

<h2 id="response-format">Formato de Resposta</h2>

Resposta bem-sucedida:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Resposta ao erro:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Notas:

* Erros de negócio geralmente ainda retornam a estrutura unificada de JSON . Integradores devem verificar `code` primeiro.
* Falhas de autenticação podem devolver HTTP `401`; limitação de taxa pode retornar HTTP `429`.
* Você pode enviar `X-Request-ID` no cabeçalho da solicitação. O servidor devolverá como `requestId` na resposta.
