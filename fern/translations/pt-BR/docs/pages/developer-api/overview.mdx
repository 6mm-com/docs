<h2 id="production-checklist">Checklist de produção</h2>

- Armazene API segredos apenas no backend.
- Sincronizar o tempo do servidor antes das solicitações assinadas.
- Tratar todos os campos de precisão numérica como strings, a menos que uma página diga explicitamente o contrário.
- Usar idempotência, IDs de requisição e logs estruturados ao redor dos fluxos de pedidos.
- Assinar WebSocket fluxos para estados que devem permanecer atualizados nos sistemas operacionais.
- Revise códigos de erro e comportamentos de tentativa antes do lançamento.
