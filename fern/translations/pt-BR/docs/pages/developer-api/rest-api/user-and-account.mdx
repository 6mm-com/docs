A menos que especificado de outra forma, os seguintes endpoints podem usar JWT ou API Key assinatura.

<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Informações do Usuário

```http
GET /v1/private/user/info
```

Campos de resposta:

| Campo                  | Tipo   | Descrição      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | ID de usuário externo |
| `userInfo.username`    | string | Nome de usuário         |
| `userInfo.agentId`     | int64  | ID do Agente         |
| `userInfo.vipLevel`    | int64  | VIP nível        |
| `userInfo.lastLoginAt` | int64  | Último tempo de login  |
| `userInfo.lastLoginIp` | string | Último login IP    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Recursos de Usuário

```http
GET /v1/private/user/asset
```

Campos de resposta:

| Campo                     | Tipo   | Descrição                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | ID de usuário externo                |
| `userAsset.assetType`     | string | Tipo de ativo                      |
| `userAsset.walletBalance` | string | Saldo da carteira                  |
| `userAsset.frozenMargin`  | string | Margem congelada por ordens pendentes |
| `userAsset.usedMargin`    | string | Margem usada pelas posições        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Crie listenKey

```http
POST /v1/private/user/listen-key
```

Cria uma chave de autenticação para fluxos privados WebSocket .

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Renovar listenKey

```http
PUT /v1/private/user/listen-key
```

Estende listenKey validade.

<span id="close-listenkey" data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Fechar listenKey

```http
DELETE /v1/private/user/listen-key
```

Fecha a listenKeyespecificada.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Registros de Alteração de Conta

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Parâmetros da solicitação:

| Parâmetro    | Tipo   | Obrigatório | Descrição                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | Não       | Tipo de ativo, como `USDT`   |
| `changeType` | string | Não       | Mudança de tipo                  |
| `startTime`  | int64  | Não       | Horário de início                   |
| `endTime`    | int64  | Não       | Fim dos tempos                     |
| `page`       | int32  | Não       | Número da página, `1` padrão     |
| `pageSize`   | int32  | Não       | Itens por página, padrão `20` |

Campos de resposta:

| Campo                        | Tipo   | Descrição                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Tipo de ativo                   |
| `list[].amount`              | string | Valor alterado               |
| `list[].walletBalanceBefore` | string | Saldo da carteira antes da troca |
| `list[].walletBalanceAfter`  | string | Saldo da carteira após a troca  |
| `list[].frozenBalanceBefore` | string | Saldo congelado antes da troca |
| `list[].frozenBalanceAfter`  | string | Saldo congelado após a troca  |
| `list[].changeType`          | string | Mudança de tipo                  |
| `list[].referenceId`         | string | ID de negócio relacionado          |
| `list[].createdAt`           | int64  | Tempo de criação                |
| `total`                      | int64  | Contagem total                  |

<span id="30-day-volume-statistics" data-sixmm-canonical-anchor="30-day-volume-statistics" aria-hidden="true"></span>

## Estatísticas de Volume de 30 Dias

```http
GET /v1/private/user/volume-stats
```

Campos de resposta:

| Campo         | Tipo   | Descrição                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Volume acumulado de negociação nos últimos 30 dias |
| `feeTotal30d` | string | Taxas acumuladas nos últimos 30 dias           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## Histórico de Balanço

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Parâmetros da solicitação:

| Parâmetro | Tipo   | Obrigatório | Descrição                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Sim      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | Não       | Número de itens devolvidos, padrão `30` |

Campos de resposta:

| Campo             | Tipo   | Descrição                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Data de agregação            |
| `items[].balance` | string | Saldo da carteira              |
| `items[].pnl`     | string | Realizou PnL para o período |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Visão Geral do Comércio

```http
GET /v1/private/user/trade-overview?type=1M
```

Parâmetros da solicitação:

| Parâmetro | Tipo   | Obrigatório | Descrição                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Sim      | Faixa de tendência: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Campos de resposta:

| Campo                | Tipo   | Descrição                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | O PnL realizado de hoje                                                 |
| `todayVolume`        | string | Volume de negociação de contratos de hoje                                      |
| `totalVolume`        | string | Volume acumulado de negociação de contratos                                   |
| `totalPnl`           | string | PnL realizado cumulativo                                              |
| `maxDrawdown30d`     | string | Valor máximo de redução nos últimos 30 dias                        |
| `maxDrawdown30dRate` | string | Taxa máxima de redução nos últimos 30 dias, decimal de `0` a `1` |
| `transferIn`         | string | Fundos transferidos cumulativos                                      |
| `transferOut`        | string | Fundos transferidos cumulativos para fora                                     |
| `items[]`            | array  | Dados de tendência de ativos                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Resumo da Visão Geral do Ativo

```http
GET /v1/private/user/asset/overview/summary
```

Os campos de resposta são os mesmos que os campos de resumo de visão geral do comércio, excluindo `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Tendência de Visão Geral dos Ativos

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Parâmetros da solicitação:

| Parâmetro | Tipo   | Obrigatório | Descrição                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Sim      | Faixa de tendência: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Campos de resposta:

| Campo                  | Tipo   | Descrição                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Tempo de snapshot                   |
| `items[].balance`      | string | Saldo da conta corrente         |
| `items[].pnl`          | string | PnL para o período atual      |
| `items[].pnlRate`      | string | Taxa PnL para o período atual |
| `items[].totalPnl`     | string | PnL Acumulado                  |
