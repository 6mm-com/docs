## Ordem de Colocação

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Parâmetros de solicitação:**

| Parâmetro       | Tipo   | Obrigatório               | Descrição                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Sim                    | Símbolo                                                                                                                        |
| `type`          | string | Sim                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Sim                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Não                     | `BOTH` / `LONG` / `SHORT`, `BOTH` padrão                                                                                     |
| `price`         | string | Exigido condicionalmente | Exigido para ordens limitadas                                                                                                     |
| `quantity`      | string | Exigido condicionalmente | Quantidade. Pode ser omitida quando `closePosition=true`                                                                            |
| `timeInForce`   | string | Não                     | `GTC` / `IOC` / `FOK`, `GTC` padrão                                                                                          |
| `reduceOnly`    | bool   | Não                     | Apenas reduzir, padrão `false`                                                                                                  |
| `makerOnly`     | bool   | Não                     | Apenas para o maker, `false` padrão                                                                                                   |
| `closePosition` | bool   | Não                     | Feche toda a posição, padrão `false`                                                                                    |
| `clientOrderId` | string | Não                     | ID de ordem definido pelo cliente                                                                                                       |
| `placeType`     | string | Não                     | Marcador de tipo de colocação de ordem                                                                                                   |
| `priceType`     | int32  | Não                     | BBO tipo de preço: `0` preço especificado, `1` preço do oponente 1, `2` preço do oponente 5, `3` preço do mesmo lado 1 `4` preço do mesmo lado 5 |

**Exemplo de solicitação:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Campos de resposta:**

| Campo           | Tipo   | Descrição             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | ID da ordem do servidor         |
| `clientOrderId` | string | ID de ordem definido pelo cliente |
| `status`        | string | Status da ordem            |
| `timestamp`     | int64  | Carimbo de data e hora               |

## Pedidos de Lote

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Solicitar corpo:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Campos de resposta:**

| Campo          | Tipo  | Descrição                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Número de ordens bem-sucedidas |
| `failedCount`  | int32 | Número de pedidos falhados     |
| `results[]`    | array | Resultado para cada ordem       |

## Ordem de Condição de Lugar

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Parâmetros de solicitação:**

| Parâmetro       | Tipo   | Obrigatório               | Descrição                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Sim                    | Símbolo                                                                                      |
| `type`          | string | Sim                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Sim                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Não                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Exigido condicionalmente | Obrigatório para `STOP_LIMIT` / `TAKE_PROFIT_LIMIT`                                             |
| `quantity`      | string | Exigido condicionalmente | Quantidade. Pode ser omitida quando `closePosition=true`                                          |
| `timeInForce`   | string | Não                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Não                     | Somente reduzir-se                                                                                 |
| `clientOrderId` | string | Não                     | ID de ordem definido pelo cliente                                                                     |
| `stopPrice`     | string | Exigido condicionalmente | Preço de gatilho                                                                               |
| `workingType`   | string | Não                     | `MARK_PRICE` / `CONTRACT_PRICE`, padrão `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Não                     | Se a proteção de preços é habilitada                                                         |
| `activatePrice` | string | Exigido condicionalmente | Preço de ativação da ordem móvel                                                             |
| `callbackRate`  | string | Exigido condicionalmente | Taxa de retorno de chamadas em ordem final                                                                |
| `closePosition` | bool   | Não                     | Feche toda a posição                                                                   |

**Campos de resposta:**

| Campo             | Tipo   | Descrição            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | ID de ordem de condição     |
| `conditionStatus` | string | Status da ordem de condição |
| `timestamp`       | int64  | Carimbo de data e hora              |

## Ordem de Estratégia de Colocação

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Parâmetros de solicitação:**

| Parâmetro      | Tipo   | Obrigatório | Descrição             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Sim      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Sim      | Lista de subordens          |

Campos em `subOrderList[]` são em sua maioria os mesmos que ordens normais e ordens de condição, com campos de dependência adicionais:

| Parâmetro        | Tipo   | Descrição                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | ID de subordem                                    |
| `firstDrivenId`  | int64  | Primeira identidade de ordem de trânsito. `0` significa sem dependência |
| `firstDrivenOn`  | string | Primeira condição gatilho                         |
| `firstTrigger`   | string | Primeira ação de gatilho                            |
| `secondDrivenId` | int64  | Segunda ordem de condução ID                         |
| `secondDrivenOn` | string | Segunda condição gatilho                        |
| `secondTrigger`  | string | Segunda ação de gatilho                           |

**Campos de resposta:**

| Campo            | Tipo   | Descrição     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | ID de Estratégia     |
| `strategyStatus` | string | Status da estratégia |
| `timestamp`      | int64  | Carimbo de data e hora       |

## Consulta de ordem única

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Parâmetros de solicitação:**

| Parâmetro       | Tipo   | Obrigatório | Descrição             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Sim      | Símbolo                  |
| `orderId`       | string | Não       | ID da ordem do servidor         |
| `clientOrderId` | string | Não       | ID de ordem definido pelo cliente |

Pelo menos um dos `orderId` e `clientOrderId` deve ser fornecido. Se ambos forem fornecidos, o servidor executa uma correspondência exata em ambas as condições.

## Recordes de troca

```http
GET /v1/private/order/trades?symbol=BTCUSDT&page=1&pageSize=20
```

**Parâmetros de solicitação:**

| Parâmetro   | Tipo   | Obrigatório | Descrição                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Não       | Símbolo                       |
| `orderId`   | string | Não       | Filtro de ID de ordem              |
| `startTime` | int64  | Não       | Horário de início                   |
| `endTime`   | int64  | Não       | Fim dos tempos                     |
| `page`      | int64  | Não       | Número da página, `1` padrão     |
| `pageSize`  | int64  | Não       | Itens por página, padrão `20` |

**Campos de resposta:**

| Campo                 | Tipo   | Descrição       |
| --------------------- | ------ | ----------------- |
| `list[].fillId`       | string | ID de detalhe de preenchimento    |
| `list[].tradeId`      | string | ID de registro comercial   |
| `list[].orderId`      | string | ID da Ordem          |
| `list[].symbol`       | string | Símbolo            |
| `list[].side`         | string | Side              |
| `list[].roleType`     | string | `maker` / `taker` |
| `list[].price`        | string | Preço preenchido      |
| `list[].quantity`     | string | Quantidade preenchida   |
| `list[].tradeValue`   | string | Valor comercial       |
| `list[].handlingFee`  | string | Taxa de manuseio      |
| `list[].realizedPnl`  | string | PnL realizado      |
| `list[].positionSide` | string | Lado da posição     |
| `list[].createdAt`    | int64  | Hora da troca        |

## Cancelar Pedido

```http
POST /v1/private/order/cancel

```

**Solicitar corpo:**

## Cancelar Tudo

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Parâmetros de solicitação:**

| Parâmetro    | Tipo   | Obrigatório | Descrição                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Não       | Símbolo                                                                              |
| `cancelType` | int32  | Não       | `0` todas as ordens normais, `1` apenas ordens de limite, `2` todas as ordens de condição. `0` padrão |

Cancelar tudo para ordens normais é aceito de forma assíncrona. O status final deve ser determinado por endpoints WebSocket `ORDER_TRADE_UPDATE` ou de consulta.
