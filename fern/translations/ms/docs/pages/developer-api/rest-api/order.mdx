> **Tala**
>
> Order endpoints ay nangangailangan ng trade permission.

<h2 id="place-order">Mag-order</h2>

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Mga parameter ng kahilingan:**

| Parameter       | Uri   | Kinakailangan               | Paglalarawan                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Oo                    | Simbolo                                                                                                                        |
| `type`          | string | Oo                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Oo                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Hindi                     | `BOTH` / `LONG` / `SHORT`, default `BOTH`                                                                                     |
| `price`         | string | Kondisyonal na kinakailangan | Kinakailangan para sa mga limit order                                                                                                     |
| `quantity`      | string | Kondisyonal na kinakailangan | Dami. Maaaring hindi isama kapag `closePosition=true`                                                                            |
| `timeInForce`   | string | Hindi                     | `GTC` / `IOC` / `FOK`, default `GTC`                                                                                          |
| `reduceOnly`    | bool   | Hindi                     | Reduce-only, default `false`                                                                                                  |
| `makerOnly`     | bool   | Hindi                     | Para lamang sa maker, default na `false`                                                                                                   |
| `closePosition` | bool   | Hindi                     | Isara ang buong posisyon, default `false`                                                                                    |
| `clientOrderId` | string | Hindi                     | Order ID na tinukoy ng kliyente                                                                                                       |
| `placeType`     | string | Hindi                     | Order placement type marker                                                                                                   |
| `priceType`     | int32  | Hindi                     | BBO uri ng presyo: `0` tinukoy na presyo, `1` presyo ng kalaban 1, `2` presyo ng kalaban 5, `3` presyo ng parehong panig 1, `4` presyo ng parehong panig 5 |

**Halimbawa ng kahilingan:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Mga patlang ng tugon:**

| Larangan           | Uri   | Paglalarawan             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | Server order ID         |
| `clientOrderId` | string | Order ID na tinukoy ng kliyente |
| `status`        | string | Katayuan ng Order            |
| `timestamp`     | int64  | Timestamp               |

<h2 id="batch-place-orders">Maglagay ng Batch ng Order</h2>

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Katawan ng kahilingan:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Mga patlang ng tugon:**

| Larangan          | Uri  | Paglalarawan                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Bilang ng mga matagumpay na order |
| `failedCount`  | int32 | Bilang ng mga nabigong order     |
| `results[]`    | array | Resulta para sa bawat order       |

<h2 id="place-condition-order">Maglagay ng Order ng Kondisyon</h2>

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Mga parameter ng kahilingan:**

| Parameter       | Uri   | Kinakailangan               | Paglalarawan                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Oo                    | Simbolo                                                                                      |
| `type`          | string | Oo                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Oo                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Hindi                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Kondisyonal na kinakailangan | Kinakailangan para sa `STOP_LIMIT` / `TAKE_PROFIT_LIMIT`                                             |
| `quantity`      | string | Kondisyonal na kinakailangan | Dami. Maaaring hindi isama kapag `closePosition=true`                                          |
| `timeInForce`   | string | Hindi                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Hindi                     | Reduce-only                                                                                 |
| `clientOrderId` | string | Hindi                     | Order ID na tinukoy ng kliyente                                                                     |
| `stopPrice`     | string | Kondisyonal na kinakailangan | Trigger price                                                                               |
| `workingType`   | string | Hindi                     | `MARK_PRICE` / `CONTRACT_PRICE`, default `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Hindi                     | Kung naka-enable ang proteksyon sa presyo                                                         |
| `activatePrice` | string | Kondisyonal na kinakailangan | Presyo ng pag-activate ng trailing order                                                             |
| `callbackRate`  | string | Kondisyonal na kinakailangan | Trailing order callback rate                                                                |
| `closePosition` | bool   | Hindi                     | Isara ang buong posisyon                                                                   |

**Mga patlang ng tugon:**

| Larangan             | Uri   | Paglalarawan            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | ID ng order ng kondisyon     |
| `conditionStatus` | string | Status ng order ng kondisyon |
| `timestamp`       | int64  | Timestamp              |

<h2 id="place-strategy-order">Maglagay ng Order ng Estratehiya</h2>

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Mga parameter ng kahilingan:**

| Parameter      | Uri   | Kinakailangan | Paglalarawan             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Oo      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Oo      | Listahan ng mga sub-order          |

Ang mga field sa `subOrderList[]` ay kadalasang pareho sa normal orders at condition orders, na may karagdagang dependency fields:

| Parameter        | Uri   | Paglalarawan                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | Sub-order ID                                    |
| `firstDrivenId`  | int64  | Unang driving order ID. `0` ibig sabihin walang dependency |
| `firstDrivenOn`  | string | Unang trigger condition                         |
| `firstTrigger`   | string | Unang aksyon ng trigger                            |
| `secondDrivenId` | int64  | Pangalawang driving order ID                         |
| `secondDrivenOn` | string | Pangalawang trigger condition                        |
| `secondTrigger`  | string | Ikalawang aksyon ng trigger                           |

**Mga patlang ng tugon:**

| Larangan            | Uri   | Paglalarawan     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | Strategy ID     |
| `strategyStatus` | string | Kalagayan ng estratehiya |
| `timestamp`      | int64  | Timestamp       |

<h2 id="query-single-order">Query Single Order</h2>

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Mga parameter ng kahilingan:**

| Parameter       | Uri   | Kinakailangan | Paglalarawan             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Oo      | Simbolo                  |
| `orderId`       | string | Hindi       | Server order ID         |
| `clientOrderId` | string | Hindi       | Order ID na tinukoy ng kliyente |

Dapat may hindi bababa sa isa sa `orderId` at `clientOrderId` na ibinigay. Kung parehong ibinigay, magsasagawa ang server ng eksaktong tugma sa parehong kondisyon.

<h2 id="cancel-order">Kanselahin ang Order</h2>


<h2 id="cancel-all">Kanselahin Lahat</h2>

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Mga parameter ng kahilingan:**

| Parameter    | Uri   | Kinakailangan | Paglalarawan                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Hindi       | Simbolo                                                                              |
| `cancelType` | int32  | Hindi       | `0` lahat ng normal na order, `1` limit orders lamang, `2` lahat ng condition orders. Default `0` |

Ang cancel-all para sa normal na order ay tinatanggap nang asynchronous. Ang panghuling status ay dapat matukoy ng WebSocket `ORDER_TRADE_UPDATE` o query endpoints.
