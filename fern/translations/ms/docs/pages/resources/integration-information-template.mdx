Gamitin ang template na ito kapag naghahanda ng bagong integration o kapag inilipat ang umiiral na integration sa production.

<h2 id="partner-information">Impormasyon tungkol sa Partner</h2>

| Larangan | Paglalarawan |
| --- | --- |
| Pangalan ng kasosyo | Legal o pangalan ng proyekto na ginagamit para sa integrasyon. |
| Uri ng produkto | App, wallet, broker portal, white-label exchange, institutional platform, o iba pa. |
| Pangunahing mga kontak | Mga kontak sa negosyo, teknikal, operasyon, at emergency. |
| Mga rehiyon ng paglulunsad | Mga bansa o rehiyon kung saan malalantad ang integrasyon. |

<h2 id="technical-information">Teknikal na impormasyon</h2>

| Larangan | Paglalarawan |
| --- | --- |
| Mga frontend domain | Mga domain na maglo-load ng widget o entry pages. |
| Mga backend domain | Mga server domain na ginagamit para sa Agent SDK o API calls. |
| Webhook URL | Production webhook endpoint at inaasahang mga kinakailangan sa IP allowlist. |
| Saklaw ng Integrasyon | Trading Widget, Agent SDK, REST API, WebSocket, white-label system, o liquidity integration. |

<h2 id="operational-information">Impormasyon sa operasyon</h2>

- Inaasahang petsa ng paglulunsad.
- Inaasahang trapiko o aktibong saklaw ng gumagamit.
- May-ari ng oras ng suporta at eskalasyon.
- Pagsubaybay sa may-ari at kontak sa insidente.

<h2 id="security-and-review-information">Impormasyon sa seguridad at pagsusuri</h2>

- Paraan ng pagpapatunay at saklaw ng pahintulot API Key .
- Lihim na imbakan, may-ari ng rotation, at mga aprubadong source IP.
- Beripikasyon ng Webhook signature at disenyo ng idempotency.
- Mga may-ari ng logging, monitoring, reconciliation, rollback, at incident-response.
- Target na merkado, uri ng gumagamit, modelo ng kustodiya, at ang entidad na responsable sa mga obligasyong nakaharap sa gumagamit.

Huwag isama ang production secrets, full access tokens, private keys, o unredacted user data sa template na ito.

Gamitin ang [production launch checklist](/ms/resources/production-launch-checklist) para sa final approval at ang [support request template](/ms/resources/support-request-template) para sa issue escalation.
