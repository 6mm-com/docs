## Конечная точка обслуживания

```
wss://ws.6mm.com/ws
```

WebSocket каналы делятся на публичные и частные каналы:

| Тип             | Аутентификация              | Описание                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Общественные каналы  | Не требуется                | Рыночные данные, такие как глубина, сделки, Клины и тикер |
| Частные каналы | `listenKey` или JWT обязательно | Потоки ордера, учетных записей и позиций пользователей              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## Общественные каналы

Публичный WebSocket не требует аутентификации. После подключения отправьте `subscribe` запрос на подписку на рыночные каналы.

Распространённые каналы:

| Канал                            | Описание                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Глубина книги заказов. Сначала отправляет снимок, затем постепенные обновления |
| `market.trade.{symbol}`            | Последние сделки                                                      |
| `market.kline.{symbol}.{interval}` | Клайнс                                                             |
| `market.ticker.{symbol}`           | Сводка тикеров по одному символу                                       |
| `market.tickers`                   | Сводка тикеров всех символов                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## Частные каналы

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
Для приватных WebSocket потоков сначала создайте `listenKey` через REST API , затем подключитесь к:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
Совместимый JWT способ подключения:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

После успешной аутентификации сервер автоматически подписывается на подключение к приватному каналу текущего пользователя. Ручная подписка не требуется.
