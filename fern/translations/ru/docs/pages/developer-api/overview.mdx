<h2 id="production-checklist">Чек-лист производства</h2>

- Храни API секреты только на бэкенде.
- Синхронизация времени сервера до подписанных запросов.
- Рассматривать все числовые поля как строки, если на странице явно не указано иное.
- Использовать идемпотентность, идентификаторы запросов и структурированные журналы вокруг потоков заказов.
- Подписываться на WebSocket потоки для состояния, которые должны оставаться актуальными в операционных системах.
- Проверять коды ошибок и повторять поведение перед запуском.
