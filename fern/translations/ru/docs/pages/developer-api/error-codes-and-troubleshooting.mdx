## Формат ответа на ошибки

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Бизнес-ошибки обычно всё равно возвращают унифицированную структуру JSON . Интеграторы должны сначала проверить `code` . Ошибки аутентификации могут вернуть HTTP `401`; ограничение скорости может вернуть HTTP `429`.

<span id="common-error-codes" data-sixmm-canonical-anchor="common-error-codes" aria-hidden="true"></span>

## Распространённые коды ошибок

| Код ошибки      | Описание                                  |
| --------------- | -------------------------------------------- |
| `0`             | Успех                                      |
| `1001`          | Достоверная информация об аутентификации не предоставлена |
| `1002`          | Токен истёк                                |
| `1003`          | Недействительный токен, API Keyили подпись         |
| `1004`          | Жетон аннулирован                                |
| `1006`          | Источник IP несоответствие                           |
| `2001`          | Отсутствует необходимый параметр                   |
| `2002`          | Недопустимое значение параметра                      |
| `2003`          | Параметр выходит за пределы зоны действия                       |
| `3001`          | Недостаток баланса                         |
| `3003`          | Порядок не найден                              |
| `3004`          | Дублирующий запрос                            |
| `3005`          | Заказ не может быть отменён                     |
| `3006`          | Разрешение отказано                            |
| `3100` - `3112` | Ошибка проверки параметров порядка условий   |
| `5001`          | Ошибка внутреннего сервера                        |
| `5002`          | Временно недоступно обслуживание              |
| `5003`          | Триггерный лимит ставки                         |

## Устранение неполадок

| Проблема                                     | Рекомендация                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` нет достоверной информации об аутентификации  | Проверьте, входит ли `Authorization: Bearer <accessToken>` или `X-API-KEY` .                  |
| `1002` Токен истёк                        | Обновите токен или войдите снова перед повторной попыткой.                                                   |
| `1003` недействительный токен, API Keyили подпись | Проверьте API Key, полезную нагрузку подписи, тело запроса JSON строку и порядок параметров запроса.           |
| `1006` источник IP несоответствия                   | Проверьте конфигурацию API Key IP белого списка.                                                    |
| `3004` дублирующий запрос                    | Не используйте одну и ту же подпись для путей, связанных с порядком. Регенерируйте `timestamp` и `signature`. |
| `5003` срабатывает лимит ставки                 | Уменьшайте частоту запросов и используйте экспоненциальный откат при повторных попытках.                                |
| `Timestamp outside of tolerance window`     | Вызовите `/v1/time` , чтобы откалибровать смещение времени и снова подпишите запрос.                             |
