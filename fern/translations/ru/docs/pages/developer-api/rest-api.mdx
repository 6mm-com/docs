<h2 id="public-endpoints">Публичные конечные точки</h2>

| Конечная точка                   | Метод | Путь                                        | Описание                                                    |
| -------------------------- | ------ | ------------------------------------------- | -------------------------------------------------------------- |
| Сервисная версия            | GET    | `/v1/version`                               | Получить информацию о версии сервиса                                |
| Время на сервере                | GET    | `/v1/time`                                  | Получите серверное время                                                |
| Вход пользователя                 | POST   | `/v1/public/user/login`                     | Используйте имя пользователя и пароль для получения `accessToken`              |
| Жетон обновления              | POST   | `/v1/public/user/refresh-token`             | Обновить состояние входа через Cookie                                 |
| Обмен билетов агента      | POST   | `/v1/public/agent-sso/exchange-ticket`      | Обменяйте билет для входа агента на состояние входа              |
| Обмен токенами Agent Embed | POST   | `/v1/public/agent-sso/exchange-embed-token` | Обменять встроенный токен для краткосрочного обмена на состояние входа |
| Конфигурация символов       | GET    | `/v1/public/market/symbols`                 | Получите символы, торговые правила и конфигурацию уровней комиссий         |
| Конфигурация ставки финансирования | GET    | `/v1/public/market/funding-rate`            | Конфигурация ставки финансирования запроса                               |
| Текущий уровень финансирования       | GET    | `/v1/public/market/funding-rate/current`    | Разделите текущие ставки финансирования                                 |
| История ставок финансирования       | GET    | `/v1/public/market/funding-rate/history`    | Запрос по истории ставок финансирования                                     |
| Клайнс                     | GET    | `/v1/public/market/klines`                  | Запросите торговую цену, индексную или марковую цену Клайнс           |
| Таблица лидеров PnL            | GET    | `/v1/public/leaderboard/pnl`                | Запрос 7 / 30 / 90 дней таблицы лидеров PnL                          |

<h2 id="private-user-endpoints">Частные пользовательские конечные точки</h2>

Если не указано иное, следующие конечные точки могут использовать JWT или API Key подписи.

| Конечная точка                 | Метод | Путь                                      | Разрешение   | Описание                                 |
| ------------------------ | ------ | ----------------------------------------- | ------------ | ------------------------------------------- |
| Информация пользователя                | GET    | `/v1/private/user/info`                   | Читать         | Запрос на текущий профиль пользователя                  |
| Пользовательские активы              | GET    | `/v1/private/user/asset`                  | Читать         | Запрос баланса кошелька и использование маржи       |
| Создайте listenKey         | POST   | `/v1/private/user/listen-key`             | Читать         | Создайте приватный WebSocket ключ аутентификации |
| Обновить listenKey          | PUT    | `/v1/private/user/listen-key`             | Читать         | Расширение listenKey действительности                   |
| Закрыть listenKey          | DELETE | `/v1/private/user/listen-key`             | Читать         | Закрыть listenKey                             |
| Журналы изменений аккаунта      | GET    | `/v1/private/user/account-change-log`     | Читать         | Запрос записей о перемещении фондов                 |
| Статистика объёма за 30 дней | GET    | `/v1/private/user/volume-stats`           | Читать         | Запросите недавний объём торгов за 30 дней и комиссии |
| История баланса          | GET    | `/v1/private/user/balance-history`        | Читать         | История баланса запросов                       |
| Обзор торговли           | GET    | `/v1/private/user/trade-overview`         | Читать         | Запрос PnL, объём и тренд активов          |
| Обзор активов   | GET    | `/v1/private/user/asset/overview/summary` | Читать         | Метрики сводки активов запроса                 |
| Обзор трендов активов     | GET    | `/v1/private/user/asset/overview/trend`   | Читать         | Тренд активов запросов                           |
| Сохранить любимые символы    | POST   | `/v1/private/user/favorite-symbols`       | Читать         | Перезаписывайте любимые символы                  |
| Получите любимые символы     | GET    | `/v1/private/user/favorite-symbols`       | Читать         | Запрос на избранные символы                      |
| Выход из системы                   | POST   | `/v1/private/user/logout`                 | JWT + Cookie | Очистить состояние входа                           |

<h2 id="api-key-management-endpoints">API Key Конечные точки управления</h2>

API Key управляющие конечные точки принимают только JWT.

| Конечная точка            | Метод | Путь                                  | Описание                                         |
| ------------------- | ------ | ------------------------------------- | --------------------------------------------------- |
| Создайте API Key      | POST   | `/v1/private/user/api-key/create`     | Создать API Key; `apiSecret` возвращается только один раз   |
| API Key список        | GET    | `/v1/private/user/api-key/list`       | Запрос API ключей текущего пользователя                       |
| Обновление API Key      | PUT    | `/v1/private/user/api-key/update`     | Обновить метку, разрешения, IP белый список и статус |
| Удалить API Key      | POST   | `/v1/private/user/api-key/delete`     | Удалить указанный API Key                          |
| Удалить все API Keys | POST   | `/v1/private/user/api-key/delete-all` | Удалить все API ключи текущего пользователя             |

<h2 id="order-endpoints">Конечные точки ордера</h2>

Конечные точки заказа требуют разрешения на торговлю.

| Конечная точка                    | Метод | Путь                                  | Описание                                                       |
| --------------------------- | ------ | ------------------------------------- | ----------------------------------------------------------------- |
| Запрос в одиночном ордере          | GET    | `/v1/private/order`                   | Точный запрос от `symbol + orderId/clientOrderId`                   |
| Оформить заказ                 | POST   | `/v1/private/order/place`             | Лимитный или рыночный ордер                                             |
| Ордер размещения условий       | POST   | `/v1/private/order/place-condition`   | Стоп-лосс, тейк-профит, трейлинг-стоп и другие условия |
| Ордер размещения стратегии        | POST   | `/v1/private/order/place-strategy`    | OTO / OCO / OTOCO ордер стратегии                                  |
| Заказы на размещение пакетов          | POST   | `/v1/private/order/batch-place`       | Подайте несколько обычных заказов                                     |
| Отменить заказ                | POST   | `/v1/private/order/cancel`            | Отменить заданный нормальный ордер                                   |
| Приказ о внесении изменений                 | POST   | `/v1/private/order/move`              | Измените обычную цену и количество ожидающих ордеров                    |
| Приказы о внесении изменений в партию          | POST   | `/v1/private/order/batch-move`        | Пакетная модификация обычных ожидающих заказов для того же символа            |
| Заказы на отмену пакета         | POST   | `/v1/private/order/batch-cancel`      | Пакетные отмены обычных заказов                                        |
| Отменить всё                  | POST   | `/v1/private/order/batch-cancel-all`  | Заказы на отмену пакетов по типу                                       |
| Ордер отмены условий      | POST   | `/v1/private/order/cancel-condition`  | Отменить заданный ордер условий                                |
| Текущие нормальные приказы       | GET    | `/v1/private/order/current`           | Запрос текущих нормальных ожидающих заказов                               |
| Текущие ордера в состоянии    | GET    | `/v1/private/order/current-condition` | Запрос на текущие ордера неактивированных условий                        |
| Исторические обычные ордера    | GET    | `/v1/private/order/history`           | Пагинуйте исторические нормальные ордера                                 |
| Исторические ордера условий | GET    | `/v1/private/order/history-condition` | Исторический ордер условий пагинатов                              |
| Торговые рекорды               | GET    | `/v1/private/order/trades`            | Торговые записи Пагинат                                            |
| Детализация ордера стратегии       | GET    | `/v1/private/order/strategy`          | Ордер и подордера стратегии запросов                               |

<h2 id="position-endpoints">Конечные точки позиции</h2>

Конечные точки позиции требуют разрешения на торговлю.

| Конечная точка          | Метод | Путь                               | Описание                                  |
| ----------------- | ------ | ---------------------------------- | -------------------------------------------- |
| Режим настройки поля   | POST   | `/v1/private/position/margin-mode` | Переключатель изолирован / перекрёстный маржа               |
| Рычаг установки      | POST   | `/v1/private/position/leverage`    | Рычаг символов множества                          |
| Настройки позиции | GET    | `/v1/private/position/settings`    | Рычаг запроса и режим поля для символа  |
| Текущие должности | GET    | `/v1/private/position/positions`   | Запрос текущих позиций                      |
| История позиции  | GET    | `/v1/private/position/history`     | Запрос исторических позиций и близких записей |
