Используйте публичные рыночные каналы, когда приложению нужны постоянно обновляемые цены, сделки, свечники или глубина ордер-книги без повторного опроса REST конечных точек. Эти потоки могут поддерживать торговые экраны, отображение цен, оповещения и мониторинг рынка.

<h2 id="connection-url">Связь URL</h2>

```
wss://ws.6mm.com/ws
```

Публичный WebSocket не требует аутентификации.

Для цикла подключения, отписки, пинга и повторного подключения см. в разделе [Подключение, подписка и сердцебиение](/ru/developer-api/websocket/connection-subscription-and-heartbeat).

<h2 id="common-channels">Общие каналы</h2>

| Канал                            | Описание                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Глубина книги заказов. Сначала отправляет снимок, затем постепенные обновления |
| `market.trade.{symbol}`            | Последние сделки                                                      |
| `market.kline.{symbol}.{interval}` | Клайнс                                                             |
| `market.ticker.{symbol}`           | Сводка тикеров по одному символу                                       |
| `market.tickers`                   | Сводка тикеров всех символов                                          |

<h2 id="choose-a-channel">Выберите канал</h2>

| Потребность в применении | Канал |
| --- | --- |
| Создайте или поддерживайте книгу заказов | `market.depth.{symbol}` |
| Отобразите прямую трансляцию обмена | `market.trade.{symbol}` |
| Нарисуйте диаграмму с подсвечниками | `market.kline.{symbol}.{interval}` |
| Отобразите один обзор рынка | `market.ticker.{symbol}` |
| Ведите обзор рынка | `market.tickers` |

<h2 id="subscription-example">Пример подписки</h2>

```json
{ "id": "1772007814666", "op": "subscribe", "args": ["market.depth.BTCUSDT"] }
```

<h2 id="push-message-wrapper">Обёртка push-сообщений</h2>

```json
{
  "topic": "market.depth.BTCUSDT",
  "event": "data",
  "ts": 1772007815000,
  "data": {}
}
```

Используйте `topic` для маршрутизации каждого сообщения к правильному обработчику и `ts` для наблюдения за временем доставки. Объект `data` содержит полезную нагрузку для подписанного канала.

<h2 id="order-book-handling">Обработка в книге заказов</h2>

Канал глубины сначала отправляет снимок, а затем инкрементальные обновления. Инициализируйте локальную книгу из снимка перед применением обновлений. После повторного подключения создайте новую сессию, снова подпишитесь и восстановите локальную книгу с следующего снимка, вместо того чтобы продолжать работу с устаревшим состоянием в памяти.

<h2 id="production-recommendations">Рекомендации по производству</h2>

- Генерировать уникальный `id` для каждого запроса подписки, отмены подписки и пинга.
- Подтвердить подтверждение подписки перед тем, как считать канал активным.
- Повторная подписка на все необходимые темы после повторного подключения.
- Держать сетевые чтения отдельно от медленной обработки баз данных или интерфейса.
- Мониторинг частоты отключения, задержки обработки сообщений и искажённых полезных нагрузок.
- Используйте [Private User Channel](/ru/developer-api/websocket/private-user-channel) для аутентифицированных обновлений аккаунтов и заказов.
