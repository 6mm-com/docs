> REST Базовый URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Эта документация предназначена для внешних систем, интегрирующихся с сервисом 6MM API . Он охватывает вход, JWT аутентификацию, управление API Key , подписание API Key HMAC , запросы к аккаунтам, ордеры, позиции, рыночные данные и WebSocket потоки.

Создание счетов и подготовка финансирования осуществляются через процессы на стороне платформы. В этой документации описываются только внешние вызовные API сервисные конечные точки.

## Конечные точки обслуживания

| Тип      | Конечная точка              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Процесс интеграции

Рекомендуемая последовательность интеграции:

1. Войдите в аккаунт, предоставленный платформой, и получите `accessToken`.
2. Для серверного программного доступа создайте API Key с JWT первым и безопасно храните одноразовый возврат `apiSecret`.
3. Частные запросы, а также конечные точки ордеров и позиций можно вызывать с помощью `Authorization: Bearer <accessToken>` или подписи API Key.
4. Для приватных WebSocket стримов сначала создайте `listenKey` , затем подключитесь к `wss://ws.6mm.com/ws?listenKey=...`.
5. Рыночные данные REST конечных и публичных WebSocket каналах не требуют аутентификации.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Выбор аутентификации

| Сценарий                               | Рекомендуемый метод         |
| -------------------------------------- | -------------------------- |
| Действия пользователей фронтенда                  | JWT                        |
| Серверные программные вызовы         | API Key + HMAC подпись   |
| API Key создание, обновление и удаление | JWT                        |
| Публичный рынок REST / общественный WebSocket  | Аутентификация не требуется |
