Рыночные данные REST конечные точки не требуют аутентификации.

<h2 id="symbol-configuration">Конфигурация символов</h2>

```http
GET /v1/public/market/symbols
```

Распространённые поля ответов:

| Поле                      | Тип   | Описание                   |
| -------------------------- | ------ | ----------------------------- |
| `list[].symbol`            | string | Символ                        |
| `list[].baseAsset`         | string | Базовый актив                    |
| `list[].quoteAsset`        | string | Актив котировки                   |
| `list[].minQuantity`       | string | Минимальное количество заказа        |
| `list[].minNotional`       | string | Минимальное номинальное значение        |
| `list[].tickSize`          | string | Размер тика цены               |
| `list[].stepSize`          | string | Размер шага количества            |
| `list[].pricePrecision`    | int64  | Точность цены               |
| `list[].maxLimitOrderQty`  | string | Максимальное количество лимитного заказа  |
| `list[].maxMarketOrderQty` | string | Максимальное количество рыночного ордера |
| `list[].maxOpenOrders`     | int64  | Максимальное количество открытых заказов на пользователя  |
| `list[].defaultLeverage`   | int64  | Кредитное плечо по умолчанию              |
| `list[].defaultMarginMode` | int64  | Стандартный режим margin           |
| `list[].leverageTiers[]`   | array  | Уровни маржи по кредитному плечу         |
| `handlingFeeLevelConfig[]` | array  | Конфигурация уровня оплаты        |

<h2 id="funding-rate-configuration">Конфигурация ставки финансирования</h2>

```http
GET /v1/public/market/funding-rate?symbol=BTCUSDT
```

Параметры запроса:

| Параметр | Тип   | Обязательно | Описание                     |
| --------- | ------ | -------- | ------------------------------- |
| `symbol`  | string | Нет       | Если опущено, возвращает все символы |

<h2 id="current-funding-rate">Текущий уровень финансирования</h2>

```http
GET /v1/public/market/funding-rate/current?symbol=BTCUSDT&page=1&pageSize=20
```

Параметры запроса:

| Параметр  | Тип   | Обязательно | Описание                  |
| ---------- | ------ | -------- | ---------------------------- |
| `symbol`   | string | Нет       | Символ                       |
| `page`     | int32  | Нет       | Номер страницы, по умолчанию `1`     |
| `pageSize` | int32  | Нет       | Пункты на странице, по умолчанию `20` |

<h2 id="funding-rate-history">История ставок финансирования</h2>

```http
GET /v1/public/market/funding-rate/history?symbol=BTCUSDT&page=1&pageSize=20
```

Параметры запроса:

| Параметр   | Тип   | Обязательно | Описание                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Да      | Символ                       |
| `startTime` | int64  | Нет       | Время начала                   |
| `endTime`   | int64  | Нет       | Конец                     |
| `page`      | int32  | Нет       | Номер страницы, по умолчанию `1`     |
| `pageSize`  | int32  | Нет       | Пункты на странице, по умолчанию `20` |

<h2 id="klines">Клайнс</h2>

```http
GET /v1/public/market/klines?symbol=BTCUSDT&interval=1m&limit=500
```

Параметры запроса:

| Параметр   | Тип   | Обязательно | Описание                                                              |
| ----------- | ------ | -------- | ------------------------------------------------------------------------ |
| `symbol`    | string | Да      | Символ                                                                   |
| `interval`  | string | Да      | Интервалы, такие как `1m`, `5m`, `15m`, `30m`, `1h`, `4h`, `1d`, `1w`, `1M` |
| `priceType` | string | Нет       | `indexPrice` / `markPrice`. Если это опущено, то возвращает цену по торговле Клины       |
| `startTime` | int64  | Нет       | Время начала                                                               |
| `endTime`   | int64  | Нет       | Конец                                                                 |
| `limit`     | int32  | Нет       | Количество возвращённых товаров, по умолчанию `500`, максимум `1000`                  |

Поля ответов:

| Поле              | Тип   | Описание |
| ------------------ | ------ | ----------- |
| `list[].openTime`  | int64  | Время открытия   |
| `list[].open`      | string | Открытая цена  |
| `list[].high`      | string | Высокая цена  |
| `list[].low`       | string | Низкая цена   |
| `list[].close`     | string | Цена закрытия |
| `list[].volume`    | string | Объём      |
| `list[].closeTime` | int64  | Время закрытия  |
