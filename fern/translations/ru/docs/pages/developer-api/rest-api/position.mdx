> **Примечание**
>
> Конечные точки позиции требуют разрешения на торговлю.

<span id="set-leverage" data-sixmm-canonical-anchor="set-leverage" aria-hidden="true"></span>

## Рычаг сета

```http
POST /v1/private/position/leverage
Content-Type: application/json
```

Запрос:

```json
{
  "symbol": "BTCUSDT",
  "leverage": 20
}
```

Поля ответов:

| Поле       | Тип   | Описание |
| ----------- | ------ | ----------- |
| `symbol`    | string | Символ      |
| `leverage`  | int32  | Кредитное плечо    |
| `timestamp` | int64  | Временная метка   |

<span id="set-margin-mode" data-sixmm-canonical-anchor="set-margin-mode" aria-hidden="true"></span>

## Режим настройки поля

```http
POST /v1/private/position/margin-mode
Content-Type: application/json
```

Запрос:

```json
{
  "symbol": "BTCUSDT",
  "marginMode": 1
}
```

`marginMode`: `1` скрест, `2` изолирован.

<span id="position-settings" data-sixmm-canonical-anchor="position-settings" aria-hidden="true"></span>

## Настройки позиции

```http
GET /v1/private/position/settings?symbol=BTCUSDT
```

Поля ответов:

| Поле        | Тип   | Описание             |
| ------------ | ------ | ----------------------- |
| `symbol`     | string | Символ                  |
| `marginMode` | int32  | `1` крест `2` изолирован |
| `leverage`   | int32  | Кредитное плечо                |

<span id="current-positions" data-sixmm-canonical-anchor="current-positions" aria-hidden="true"></span>

## Текущие должности

```http
GET /v1/private/position/positions?symbol=BTCUSDT
```

Параметры запроса:

| Параметр | Тип   | Обязательно | Описание |
| --------- | ------ | -------- | ----------- |
| `symbol`  | string | Нет       | Символ      |

Поля ответов:

| Поле                         | Тип   | Описание                |
| ----------------------------- | ------ | -------------------------- |
| `positions[].symbol`          | string | Символ                     |
| `positions[].marginMode`      | string | Режим margin                |
| `positions[].positionSide`    | string | Сторона позиции              |
| `positions[].leverage`        | int32  | Кредитное плечо                   |
| `positions[].quantity`        | string | Количество позиции          |
| `positions[].entryPrice`      | string | Входная цена                |
| `positions[].breakEvenPrice`  | string | Цена в безубыточности           |
| `positions[].liqPrice`        | string | Цена ликвидации          |
| `positions[].marginRatio`     | string | Коэффициент маржи               |
| `positions[].unrealizedPnl`   | string | Нереализованный PnL             |
| `positions[].roe`             | string | Доходность собственного капитала           |
| `positions[].nextFundingFee`  | string | Предполагаемая следующая плата за финансирование |
| `positions[].fundingFeeAccum` | string | Накопленная плата за финансирование    |
| `positions[].tpPrice`         | string | Цена тейк-профита          |
| `positions[].slPrice`         | string | Стоп-лосс цена            |

## История позиций

```http
GET /v1/private/position/history?symbol=BTCUSDT&page=1&pageSize=20
```

Параметры запроса:

| Параметр   | Тип   | Обязательно | Описание                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Нет       | Символ                       |
| `side`      | string | Нет       | `long` / `short`             |
| `startTime` | int64  | Нет       | Время начала                   |
| `endTime`   | int64  | Нет       | Конец                     |
| `page`      | int64  | Нет       | Номер страницы, по умолчанию `1`     |
| `pageSize`  | int64  | Нет       | Пункты на странице, по умолчанию `20` |

Поля ответов:

| Поле                    | Тип   | Описание               |
| ------------------------ | ------ | ------------------------- |
| `list[].symbol`          | string | Символ                    |
| `list[].positionSide`    | string | Сторона позиции             |
| `list[].leverage`        | int32  | Кредитное плечо                  |
| `list[].maxQuantity`     | string | Максимальное количество позиции |
| `list[].entryPrice`      | string | Входная цена               |
| `list[].closePrice`      | string | Цена закрытия               |
| `list[].pnl`             | string | Реализованный PnL              |
| `list[].roe`             | string | Доходность собственного капитала          |
| `list[].marginMode`      | string | Режим margin               |
| `list[].triggerMode`     | int32  | Режим закрытия спуска        |
| `list[].fundingFeeAccum` | string | Накопленная плата за финансирование   |
| `list[].openedAt`        | int64  | Время открытия                 |
| `list[].closedAt`        | int64  | Время закрытия                |
| `total`                  | int64  | Общее количество               |
