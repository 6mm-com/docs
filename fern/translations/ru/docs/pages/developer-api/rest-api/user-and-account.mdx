<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Информация о пользователях

```http
GET /v1/private/user/info
```

Поля ответов:

| Поле                  | Тип   | Описание      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | Внешний идентификатор пользователя |
| `userInfo.username`    | string | Имя пользователя         |
| `userInfo.agentId`     | int64  | Идентификатор агента         |
| `userInfo.vipLevel`    | int64  | VIP уровень        |
| `userInfo.lastLoginAt` | int64  | Последнее время входа  |
| `userInfo.lastLoginIp` | string | Последний вход IP    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Пользовательские активы

```http
GET /v1/private/user/asset
```

Поля ответов:

| Поле                     | Тип   | Описание                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | Внешний идентификатор пользователя                |
| `userAsset.assetType`     | string | Тип актива                      |
| `userAsset.walletBalance` | string | Баланс кошелька                  |
| `userAsset.frozenMargin`  | string | Маржа заморожена неожиданными ордерами |
| `userAsset.usedMargin`    | string | Маржа по позициям        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Создайте listenKey

```http
POST /v1/private/user/listen-key
```

Создаёт ключ аутентификации для приватных WebSocket потоков.

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Обновить listenKey

```http
PUT /v1/private/user/listen-key
```

Расширяет listenKey валидность.

<span id="close-listenkey" data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Закрыть listenKey

```http
DELETE /v1/private/user/listen-key
```

Закрывает указанный listenKey.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Журналы изменений аккаунта

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Параметры запроса:

| Параметр    | Тип   | Обязательно | Описание                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | Нет       | Тип актива, например, `USDT`   |
| `changeType` | string | Нет       | Тип изменения                  |
| `startTime`  | int64  | Нет       | Время начала                   |
| `endTime`    | int64  | Нет       | Конец                     |
| `page`       | int32  | Нет       | Номер страницы, по умолчанию `1`     |
| `pageSize`   | int32  | Нет       | Пункты на странице, по умолчанию `20` |

Поля ответов:

| Поле                        | Тип   | Описание                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Тип актива                   |
| `list[].amount`              | string | Изменённая сумма               |
| `list[].walletBalanceBefore` | string | Баланс кошелька до изменения |
| `list[].walletBalanceAfter`  | string | Баланс кошелька после смены  |
| `list[].frozenBalanceBefore` | string | Замороженный баланс до изменений |
| `list[].frozenBalanceAfter`  | string | Замороженный баланс после изменения  |
| `list[].changeType`          | string | Тип изменения                  |
| `list[].referenceId`         | string | Связанный бизнес-идентификатор          |
| `list[].createdAt`           | int64  | Время создания                |
| `total`                      | int64  | Общее количество                  |

## Статистика объёмов за 30 дней

```http
GET /v1/private/user/volume-stats
```

Поля ответов:

| Поле         | Тип   | Описание                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Совокупный объём торгов за последние 30 дней |
| `feeTotal30d` | string | Накопленные комиссии за последние 30 дней           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## История баланса

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Параметры запроса:

| Параметр | Тип   | Обязательно | Описание                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Да      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | Нет       | Количество возвращённых товаров, по умолчанию `30` |

Поля ответов:

| Поле             | Тип   | Описание                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Дата агрегации            |
| `items[].balance` | string | Баланс кошелька              |
| `items[].pnl`     | string | Реализовал PnL за этот период |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Обзор торговли

```http
GET /v1/private/user/trade-overview?type=1M
```

Параметры запроса:

| Параметр | Тип   | Обязательно | Описание                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Да      | Диапазон трендов: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Поля ответов:

| Поле                | Тип   | Описание                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | Сегодняшний реализованный PnL                                                 |
| `todayVolume`        | string | Сегодняшний объём торговли по контрактам                                      |
| `totalVolume`        | string | Накопленный объём торговли по контрактам                                   |
| `totalPnl`           | string | Кумулятивный реализованный PnL                                              |
| `maxDrawdown30d`     | string | Максимальная сумма понижения за последние 30 дней                        |
| `maxDrawdown30dRate` | string | Максимальный темп снижения за последние 30 дней, десятичный от `0` до `1` |
| `transferIn`         | string | Накопленные переводные средства                                      |
| `transferOut`        | string | Кумулятивные переводные средства                                     |
| `items[]`            | array  | Данные о тенденциях активов                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Обзор активов

```http
GET /v1/private/user/asset/overview/summary
```

Поля ответов совпадают с полями обзора торговли, за исключением `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Обзор трендов активов

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Параметры запроса:

| Параметр | Тип   | Обязательно | Описание                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Да      | Диапазон трендов: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Поля ответов:

| Поле                  | Тип   | Описание                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Время снимка                   |
| `items[].balance`      | string | Баланс текущего счета         |
| `items[].pnl`          | string | PnL за текущий период      |
| `items[].pnlRate`      | string | Ставка PnL за текущий период |
| `items[].totalPnl`     | string | Кумулятивный PnL                  |
