Это руководство предназначено для **Agent Java SDK `v0.3.0`** и Java 8+.

<span id="decide-what-needs-upgrading" data-sixmm-canonical-anchor="decide-what-needs-upgrading" aria-hidden="true"></span>

## Решите, что нуждается в обновлении

| Существующая интеграция | Действие |
| --- | --- |
| Существующие производственные функции с опущенным окружением | Существующие формы ответов остаются совместимыми; новые запросы не требуют обновления. |
| Существующая общая встроенная аутентификация для секундной торговли | Повторное использование аутентификации и обновления; выберите нужную страницу товара. |
| Остатки средств, переводы и возмещение | Используйте модели, содержащие `withFunding`, `walletTransfer` и `queryWalletTransfer`. |
| Явные имитированные фонды | Используйте модели запросов/ответов, поддерживающие `environment`. |
| Шесть запросов к постоянным данным | Используйте public Java SDK `v0.3.0`, включая шесть методов и поддержку подписи массива. |

Сохраните текущие `baseUrl`, `agentCode`, `apiSecret`, пользовательские привязки и исходные бизнес-заказы.

<span id="install-the-stable-public-tag" data-sixmm-canonical-anchor="install-the-stable-public-tag" aria-hidden="true"></span>

## Установите стабильный общедоступный тег

Исходный код хоста на GitHub. Публикация тега GitHub не публикует координаты Maven в Maven Central. Установите источник с тегами локально или опубликуйте его проверенный JAR/POM в хранилище артефактов вашей организации.

```bash
git clone --branch v0.3.0 --single-branch https://github.com/6mm-com/agent-java-sdk.git agent-java-sdk-v0.3.0
cd agent-java-sdk-v0.3.0
git rev-parse HEAD
git rev-parse 'v0.3.0^{commit}'
mvn install
```

Два идентификатора фиксации должны совпадать. Объявите зависимость в партнерском проекте:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.3.0</version>
</dependency>
```

Проверьте разрешенную зависимость:

```bash
mvn dependency:tree -Dincludes=com.sixmm.exchange.sdk:agent
```

Локальная установка делает артефакт доступным только на этом компьютере. CI и другим разработчикам нужна одна и та же установка с тегами или ваш проверенный репозиторий артефактов. Если у вас уже есть частный артефакт с именем `0.3.0`, проверьте его источник и методы; не перезаписывайте общий артефакт молча.

## Необходимые изменения интеграции

1. Обновите модели запросов и ответов для явного `environment`. Строгие старые модели ответов могут отклонять дополнительное поле.
2. Используйте `withFunding()` перед чтением `funding`. Балансы контрактов не являются балансами для секундной торговли.
3. Используйте `/v1/agent/wallet-transfer` и `/v1/agent/wallet-transfer-status` для финансирования. Старый `queryOrder` не может восстановить операцию финансирования.
4. Шесть запросов используют `platformUserIds` в качестве массива строк. Подписать массивы как компактные JSON; Java `List.toString()` несовместимо.
5. Заказы на передачу магазинов, обычные торговые заказы, условные заказы и исполнения как отдельные объекты. Разберите `orderStatus` или `status` в соответствии с операцией.
6. Перед анализом проверьте исходное тело webhook . К явным смоделированным уведомлениям относятся `environment`; сравните его с сохраненным заказом.
7. Управляйте версиями Java и виджета независимо. Обновление серверной части не меняет страницу интерфейса или режим торговли, а секундная торговля не требует нового типа токена.

## Подтвердить обновление

Запустите сборку партнерского проекта и проверьте его дерево зависимостей. Привязка тестов, исходный производственный процесс, явные моделируемые балансы, восстановление результатов финансирования, все шесть запросов, разбиение на страницы с фиксированным окном, обработка ошибок и идемпотентные обратные вызовы.

Для пользовательского клиента HTTP следуйте тегированному запросу и контракту подписи вместо того, чтобы предполагать, что старые модели охватывают новые поля. Видеть [Правила подписи агента](/ru/sdk/security/secrets-signing#signing-rule), [Обзор запроса](/ru/sdk/agent-sdk/java/perpetual-queries) и [Руководство по окружающей среде](/ru/sdk/agent-sdk/java/environments).
