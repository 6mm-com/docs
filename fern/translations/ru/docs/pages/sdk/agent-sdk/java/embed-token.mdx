Это руководство предназначено для **Agent Java SDK `v0.3.0`**, Java 8+ и помеченного публичного контракта. Примеры выполняются в серверной части партнера после инициализации `client` в [Быстрый старт](/ru/sdk/agent-sdk/java/quick-start).

## Пример предварительных условий

Фрагменты Java разделяют этот импорт. Инициализируйте `client` с помощью быстрого запуска и получите `platformUserId` из сохраненной привязки. Примеры идентификаторов пользователей/заказов необходимо заменить вашими собственными сохраненными значениями.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget Встроить токен

Токен для внедрения предназначен для режима Trading Widget SDK `partner-token + tokenProvider`.
браузер вызывает серверную часть партнера, а серверная часть партнера вызывает это Java SDK
чтобы создать `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Требования к интеграции:

- `channelId` должен использовать значение, переданное Trading Widget SDK.
- `symbol` не является обязательным, но рекомендуется передать текущий начальный символ.
- `embedToken` кратковременный и одноразовый. Не помещайте его в строки запроса URL.
- Партнерский интерфейс никогда не должен содержать `apiSecret`.
- `expireAt` — это временная метка Unix в секундах, а не TTL.

Пример конечной точки серверной части партнера:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Партнерский контракт на конечную точку

Аутентифицируйте партнерский сеанс и получите `agentUserId` на стороне сервера. Примите текущий виджет `channelId`; вернуть верхний уровень `embedToken`, `expireAt` (Unix-секунды) и то же самое `channelId`. Ответы агента не предоставляют `channelId`: ваш сервер повторяет это. Получить новый токен при инициализации и обновлении; никогда не используйте его повторно. Создание токена не переводит средства и не выбирает среду кошелька.

Видеть [Торговля секундами](/ru/sdk/agent-sdk/java/seconds-trading) для полного потока внешнего и внутреннего интерфейса.
