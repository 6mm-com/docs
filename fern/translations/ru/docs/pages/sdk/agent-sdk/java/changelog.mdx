Это руководство предназначено для **Agent Java SDK `v0.3.0`**, Java 8+ и помеченного публичного контракта. Примеры выполняются в серверной части партнера после инициализации `client` в [Быстрый старт](/ru/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Шесть постоянных запросов: текущие заказы, история заказов, исполнения, текущие позиции, история позиций и книга счетов.
- Остатки средств, переводы, запросы на восстановление и переводы финансирования/контракта.
- Явный производственный/моделированный выбор для поддерживаемых запросов на финансирование.
- Руководства по перенаправлению и внедрению Seconds Trading, справочник по полям ответа и инструкции по миграции.

Java SDK и Trading Widget SDK имеют независимые версии. Виджет `v1` URL не является Java SDK версии `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Существующие интеграции

Сохраните сопоставления пользователей, исходные заказы и учетные данные. Пропущенные поля среды сохраняют существующее производственное поведение. Финансирование, явные моделируемые фонды и шесть постоянных запросов требуют соответствующих новых моделей и методов. Обзор [Руководство по обновлению](/ru/sdk/agent-sdk/java/upgrade) перед изменением существующей интеграции.
