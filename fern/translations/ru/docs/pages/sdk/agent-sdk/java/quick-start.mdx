## Установка

Публичный SDK источник в настоящее время документирует тег `v0.1.1` с такими координатами Maven:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

GitHub не выполняет функции репозитория зависимостей Maven. Установите тегированный исходный код локально перед разрешением зависимости:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Командные сборки**
>
> Опубликуйте одобренный артефакт в репозитории Maven вашей организации для CI, тестирования и производственных сборок. Подтвердите одобренную версию с помощью 6MM до запуска в производство.

Исходный код и примеры использования доступны в официальном репозитории Java SDK :

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

## Прежде чем начать

- Подтвердите вашего производственного агента API базовой URL с командой 6MM .
- Store apiSecret только в бэкенд-менеджменте секретов.
- Подготовить стабильное отображение между platformUserId и agentUserId.
- Включить структурированные логи вокруг потоков связывания, передачи, порядка и вебхуков.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Инициализация клиента

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Только для бэкенда**
>
> Не инициализировать Agent SDK из кода браузера, мобильного устройства или настольного клиента. SDK подписывает привилегированные запросы API Агента.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Пример: перевод средств в

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Используйте уникальный номер заказа на стороне партнёра для каждого запроса на передачу. Если срок действия запроса истек, запросите исходный заказ перед созданием нового.
