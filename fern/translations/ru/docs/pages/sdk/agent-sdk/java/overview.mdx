Это руководство предназначено для **Agent Java SDK `v0.3.0`**, Java 8+ и помеченного публичного контракта. Примеры выполняются в серверной части партнера после инициализации `client` в [Быстрый старт](/ru/sdk/agent-sdk/java/quick-start).

Базовый уровень документации: SDK `v0.3.0`, фиксация `54aa3c1`.

## Конфигурация

Получите следующие значения из 6MM перед
интегрируя.

| Элемент | Пример | Описание |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Агент API база URL, без косой черты в конце |
| `agentCode` | `AGENT001` | Код партнера |
| `apiSecret` | `your-api-secret` | API секрет подписи. Держите его только на бэкэнде |
| `defaultCurrency` | `USDT` | Валюта по умолчанию, обычно `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | Конечная точка партнера для обратных вызовов 6MM |

Рекомендации по производству:

- Используйте HTTPS для конечных точек агента API и webhook.
- Сохраните `apiSecret` в секретном менеджере, центре конфигурации или переменной среды.
- Синхронизируйте время сервера, желательно с помощью NTP.
- Сохраните все номера заказов партнеров и сделайте их глобально уникальными.
- Никогда не отправляйте `apiSecret` в браузеры, приложения, мини-программы или исходный код внешнего интерфейса.

## Поля автоматической подписи

Для подписанных вызовов агента API SDK автоматически вставляет:

| Поле | Источник | Описание |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | Код партнера |
| `timestamp` | Текущая временная метка UTC Unix | Секунды |
| `nonce` | Безопасный генератор случайных чисел | Защита от повтора |
| `sign` | HMAC-SHA256 | Запросить подпись |
| `currency` | `defaultCurrency` | Заполняется, когда в запросах на перевод/счет не указана валюта. |

Правила подписания:

1. Исключить `sign`.
2. Исключить пустые значения.
3. Сортировать ключи по порядку ASCII.
4. Присоединяйтесь как `k=v&k2=v2`.
5. Вычислите HMAC-SHA256 шестнадцатеричный код с помощью `apiSecret`.

Значения массива сериализуются как компактные JSON перед присоединением к подписывающим полезным данным. Например, `platformUserIds` обозначается как `["1188041528"]`, что дает `platformUserIds=["1188041528"]` в полезных данных `k=v` . Сохранять порядок элементов массива, двойные кавычки и идентификаторы строк; не вставляйте пробелы форматирования и не используйте Java `List.toString()` (например, `[1188041528]`). SDK автоматически обрабатывает эту сериализацию.

Обычный бизнес-код не должен рассчитывать подписи или устанавливать вручную.
`agentCode`, `timestamp`, `nonce` или `sign`.
