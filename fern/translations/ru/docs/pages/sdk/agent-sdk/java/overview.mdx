<h2 id="official-repository">Официальное хранилище</h2>

Репозиторий Java SDK является источником достоверности SDK исходного кода, примечаний к релизам, примеров использования и деталей реализации:

[6mm-com/agent-java-sdk] (https://github.com/6mm-com/agent-java-sdk)

<h2 id="runtime">Продолжительность работы</h2>

| Предмет | Ценность |
| --- | --- |
| Минимальная версия Java | Java 8+ |
| Рекомендуемый инструмент сборки | Maven 3.9+ |
| Группа Maven | `com.sixmm.exchange.sdk` |
| Артефакт Maven | `agent` |
| Задокументированный источник | `v0.1.1` |

Публичный репозиторий GitHub — это хостинг исходного кода, а не репозиторий зависимостей Maven. Создайте и установите отмеченный исходный код локально или опубликуйте одобренный артефакт в приватном репозитории Maven вашей организации перед использованием в командных сборках.

<h2 id="typical-backend-responsibilities">Типичные обязанности бэкенда</h2>

- Проверить сессию партнёра.
- Сопоставить партнёра пользователя с agentUserId.
- Связывание коллов перед первыми торговыми или трансферными потоками.
- Позвоните createEntryUrl для одноразового полноценного SSO.
- Вызовите createEmbedToken для Trading Widget режима партнёра-токен.
- Проверять вебхуки передачи и обрабатывать их идемпотентно.

<h2 id="security-and-operational-rules">Правила безопасности и эксплуатации</h2>

- Хранить `apiSecret` только в серверном менеджере секретов или защищённой переменной среды.
- Синхронизировать серверное время, поскольку подписанные запросы содержат временные метки.
- Рассматривать `agentOrderNo` как надёжный ключ идемпотентности и сохранять его глобально уникальным.
- Хранить `platformUserId` в виде строки и сохранять его связь с `agentUserId`.
- Запросить исходную передачу перед повторной попыткой после тайм-аута или неопределённого результата сети.
