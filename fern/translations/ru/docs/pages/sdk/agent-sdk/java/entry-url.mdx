Это руководство предназначено для **Agent Java SDK `v0.3.0`**, Java 8+ и помеченного публичного контракта. Примеры выполняются в серверной части партнера после инициализации `client` в [Быстрый старт](/ru/sdk/agent-sdk/java/quick-start).

## Пример предварительных условий

Фрагменты Java разделяют этот импорт. Инициализируйте `client` с помощью быстрого запуска и получите `platformUserId` из сохраненной привязки. Примеры идентификаторов пользователей/заказов необходимо заменить вашими собственными сохраненными значениями.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Прямой вход URL

Прямая запись URL предназначена для режима перенаправления. Пользователь-партнер нажимает кнопку на
партнерский сайт, открывает интерфейс 6MM и автоматически входит в систему.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Правила поля:

| Поле | Описание |
| --- | --- |
| `redirectPath` | 6MM относительный путь интерфейса. Он должен начинаться с `/`, например `/trade/BTCUSDT` |
| `returnUrl` | Абсолютный партнер URL используется, когда пользователь выходит из 6MM интерфейса. Разрешены только `http` и `https` |
| `expireAt` | Срок действия входного билета в виде временной метки Unix в секундах. |

Требования безопасности:

- `webUrl` содержит одноразовый билет. Используйте его немедленно и не храните его в течение длительного времени.
- Если срок действия записи URL истек или она уже использовалась, создайте новую на партнерском сайте.
- `returnUrl` не должен быть `javascript:`, относительным путем или URL с информацией о пользователе.

## Выбор продукта и режима

Используйте текущий маршрут интерфейса, предоставленный 6MM. Например, `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` или `/zh-CN/futures/BTCUSDT?tradingMode=real`. Билет аутентифицирует пользователя; он не выбирает среду финансирования и не перемещает средства.

Видеть [Торговля секундами](/ru/sdk/agent-sdk/java/seconds-trading) для перенаправления и встроенных примеров.
