<h2 id="runtime">Продолжительность работы</h2>

| Предмет | Ценность |
| --- | --- |
| Пакет | sixmm/agent-SDK |
| Минимальная версия PHP | PHP 7.4+ |
| Рекомендуемая версия PHP | PHP версии 8.1+ или поддерживаемые в настоящее время |
| Обязательные продления | ext-json, ext-curl |

Исходный и одобренный вариант PHP SDK пакета предоставляются во время адаптации партнёров. Не предполагайте, что посылка доступна на публичном Packagist; настройте репозиторий Composer, предоставленный вашей организации.

<h2 id="supported-scenarios">Поддерживаемые сценарии</h2>

| Сценарий | SDK метод |
| --- | --- |
| Пользователь привязки | связывать |
| Перевод фиксированной суммы | Трансфер |
| Переведите всё | transferAllOut |
| Обратная передача | Реверс |
| Порядок запроса | queryOrder |
| Создать запись URL | createEntryUrl |
| Проверка с помощью вебхука | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Правила интеграции бэкенда</h2>

- Загрузить `apiSecret` из секретного менеджера или защищённой переменной среды.
- Сохранить логику привязки, передачи, подписи и webhook вне кода браузера.
- Используйте десятичные строки для суммы активов, чтобы избежать округления с плавающей точкой.
- Повторное использование исходного `agentOrderNo` при запросе неопределённого результата передачи.
- Проверять сигнатуры webhook по исходному запросу перед декодированием или изменением.
