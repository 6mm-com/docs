Trading Widget SDK встраивает торговый интерфейс 6MM внутри веб-страницы, принадлежащей партнёру. Самая быстрая интеграция требует видимого контейнера, скрипта SDK производства и вызова `TradingWidget.create()`.

<h2 id="before-you-start">Прежде чем начать</h2>

- Запустить пример с веб-страницы, которая может загружать ресурсы из `https://app.6mm.com`.
- Дайте контейнеру виджета явную ширину и высоту.
- Загрузи SDK перед звонком `TradingWidget.create()`.
- Планировать [процесс аутентификации](/ru/sdk/trading-widget/authentication) до включения функций аккаунта или торговли в продакшене.

<h2 id="minimal-example">Минимальный пример</h2>

```html
<div id="trading-widget" style="width: 100%; height: 720px"></div>

<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
<script>
  const widget = TradingWidget.create('#trading-widget', {
    baseUrl: 'https://app.6mm.com',
    symbol: 'BTCUSDT',
    theme: 'dark',
    locale: 'en',
    layout: 'default',
    display: {
      showHeader: false,
      showTicker: false,
      hidden: [],
    },
    onReady(event) {
      console.log('ready', event)
    },
    onError(error) {
      console.error('error', error)
    },
  })
</script>
```

Когда интеграция успешна, SDK создаёт iframe внутри `#trading-widget` и вызывает `onReady`. Захват `onError` во время разработки, чтобы сбои при конфигурации и нагрузке были видны.

<h2 id="sdk-urls">SDK URL</h2>

| Окружающая среда | Сценарий URL |
| --- | --- |
| Производство | https://app.6mm.com/sdk/trading-widget/v1/index.js |

> **Установить baseUrl явно**
>
> При тестировании со страниц, принадлежащих партнёрам, передайте baseUrl так, чтобы iframe всегда указывал на веб-домен 6MM .

<h2 id="display-controls">Управление дисплеем</h2>

Встроенные партнёры по умолчанию скрывают заголовок ПК и тикер нижнего рынка. Используйте `display` , когда нужно показать эти области оболочки или скрыть высокоуровневые контейнеры на странице встраиваемых торгов.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['account'],
}
```

<h2 id="container-size">Размер контейнера</h2>

| Поверхность | Рекомендуемый минимум |
| --- | --- |
| Настольный компьютер | 1024 x 720 |
| Мобильные | 390 x 700 |

Для адаптивных раскладок поддерживайте ширину плавной и устанавливайте соответствующую минимальную высоту для каждой точки тормоза. Контейнер с нулевой высотой может успешно загрузить SDK , оставляя торговый интерфейс невидимым.

<h2 id="verify-the-integration">Проверьте интеграцию</h2>

1. Подтвердите, что скрипт SDK успешно возвращается в сетевой панели браузера.
2. Подтвердите `onReady` срабатывает после инициализации iframe.
3. Проверьте настроенные `symbol`, `locale`, тему и скрытые разделы.
4. Измените размер страницы между точками остановки на компьютере и мобильных устройствах.
5. Пройти аутентифицированный тест с непроизводственным пользователем до запуска.

<h2 id="common-issues">Распространённые проблемы</h2>

| Симптом | Что проверить |
| --- | --- |
| Пустая область виджета | Убедитесь, что у контейнера видимая ширина и высота. |
| `TradingWidget` не определён | Подтвердите, что скрипт v1 загружен до создания вызова. |
| Неправильная страница или окружение | Установите `baseUrl` явно и проверьте настроенную среду. |
| Событие «Готовность» никогда не срабатывает | Захватывайте `onError` и проверяйте заблокированные iframe или скриптовые запросы. |
| Данные по аккаунту недоступны | Завершите поддерживаемый процесс аутентификации виджета. |
