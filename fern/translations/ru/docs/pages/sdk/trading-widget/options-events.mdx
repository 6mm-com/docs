<h2 id="options">Варианты</h2>

| Поле | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| baseUrl | string | SDK происхождение сценария | Домен iframe. Передайте явно на страницах партнёров. |
| Символ | string | BTCUSDT | Нормализовано в заглавные буквы и полоски - / _. |
| Тема | Тёмный \| Свет | тёмный | Начальный параметр темы. |
| Местоположение | en \| en-US \| zh-CN | Браузер/стандарт | Поддерживаются английский и упрощённый китайский. |
| Планировка | по умолчанию \| компактный | По умолчанию | Опция зарезервированной планировки. |
| Экспозиция | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Управление встраивает области оболочек и высокоуровневые торговые контейнеры. |
| Авторизация | object | нет | Используйте partner-token для новых интеграций SSO . |

<h2 id="display-controls">Управление дисплеем</h2>

`display` управляет встроенной оболочкой торговой страницы и высокоуровневыми контейнерами. В партнерских встроенных заголовок PC и нижний рыночный тикер по умолчанию скрыты.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Поле | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| showHeader | boolean | ложь | Стоит ли показывать встроенный заголовок ПК внутри iframe. |
| showTicker | boolean | ложь | Стоит ли показывать нижний рыночный тикер в встраиваемой оболочке. |
| Скрыто | Струна[] | [] | Скрывает высокоуровневые контейнеры на странице обмена. |

Поддерживаемые `display.hidden` ценности:

| Ценность | Контейнер |
| --- | --- |
| Чарт | Контейнер для карт |
| orderBook | Контейнер для книги заказов |
| orderForm | Панель формы заказов |
| Должности | Нижние позиции и панель открытых ордеров |
| Счёт | Контейнер активов счетов |

`display.hidden` скрывает только целые контейнеры. Он не скрывает отдельные кнопки, поля или инструменты внутри контейнера. Значения, не соответствующие текущему порту просмотра, игнорируются.

<h2 id="events">Мероприятия</h2>

| Событие | Триггер |
| --- | --- |
| Готовы | Инициализация iframe завершена. |
| Ошибка | SDK, iframe или ошибка аутентификации. |
| state_changed | SDK состояние жизненного цикла изменилось. |
| auth_state_changed | Состояние аутентификации партнёрского токена изменилось. |
| symbol_changed | Фактический символ iframe изменился. |
| locale_changed | Фактическое местоположение iframe изменилось. |
| order_created | Пользователь создал заказ внутри iframe. |
| order_failed | Подача приказа не была выполнена. |
| уничтожен | SDK экземпляр уничтожен. |
