## Параметры

| Поле | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| baseUrl | string | SDK происхождение скрипта | iframe-домен. Передавайте явно на партнерских страницах. |
| символ | string | BTCUSDT | Нормализовано к верхнему регистру и полосам - / _. |
| тема | темный \| свет | темный | Начальный параметр темы. |
| локаль | ru \| ru-US \| ж-CN | Браузер/по умолчанию | Поддерживаются английский и упрощенный китайский. |
| макет | по умолчанию \| компактный | по умолчанию | Зарезервированный вариант планировки. |
| отображать | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Управляет встраиванием областей оболочки и торговых контейнеров высокого уровня. |
| авторизация | object | никто | Используйте партнерский токен для новых интеграций SSO. |

## Элементы управления дисплеем

`display` управляет встроенной оболочкой торговой страницы и высокоуровневыми контейнерами. В партнерских вставках заголовок ПК и нижний рыночный тикер по умолчанию скрыты.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Поле | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| showHeader | boolean | ЛОЖЬ | Показывать ли заголовок встраивания ПК внутри iframe. |
| showTicker | boolean | ЛОЖЬ | Показывать ли нижний рыночный тикер во встраиваемой оболочке. |
| скрытый | нить[] | [] | Скрывает высокоуровневые контейнеры на торговой странице. |

Поддерживаемые значения `display.hidden`:

| Ценить | Контейнер |
| --- | --- |
| диаграмма | Контейнер диаграммы |
| orderBook | Контейнер для книги заказов |
| orderForm | Панель формы заказа |
| позиции | Нижние позиции и панель открытых ордеров |
| счет | Контейнер активов аккаунта |

`display.hidden` скрывает только целые контейнеры. Он не скрывает отдельные кнопки, поля или инструменты внутри контейнера. Значения, которые не соответствуют текущему экрану просмотра, игнорируются.

## События

| Событие | Курок |
| --- | --- |
| готовый | Инициализация iframe завершена. |
| ошибка | SDK, iframe или ошибка аутентификации. |
| состояние_изменено | SDK состояние жизненного цикла изменено. |
| auth_state_changed | Состояние аутентификации токена партнера изменено. |
| символ_изменен | Фактический символ iframe изменен. |
| locale_changed | Фактическая локаль iframe изменена. |
| заказ_создан | Пользователь создал заказ внутри iframe. |
| заказ_не выполнен | Отправка заказа не удалась. |
| уничтожен | Экземпляр SDK уничтожен. |

## Страницы продуктов и режим торговли

Java Agent SDK и браузер Trading Widget SDK имеют независимые версии. Для секундной торговли используйте текущие возможности виджета и явно выберите страницу и режим торговли.

| Вариант | Ценности | Значение |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Страница продукта для секундной торговли. |
| `tradingMode` | `real`, `demo` | По умолчанию `real`; явно соответствовать среде внутреннего финансирования. |

Проверьте `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` и `TradingWidget.capabilities.partnerToken` перед инициализацией. Создание токена не выбирает среду финансирования. Чтобы сменить пользователей или реальный/демо-режим, уничтожьте старый экземпляр и создайте новый.

Видеть [полный пример торговли секундами](/ru/sdk/agent-sdk/java/seconds-trading) и [производственная/моделированная конфигурация](/ru/sdk/agent-sdk/java/environments).

## Дополнительные цели и события отображения

Текущая среда выполнения также принимает `symbolFavorites` и `symbolTicker` в `display.hidden`. Всегда проверяйте `TradingWidget.capabilities.displayTargets`; цель управляет контейнером высокого уровня и не является настройкой разрешения на уровне поля.

| Событие | Значение |
| --- | --- |
| `rendered` | iframe отправляет отображаемое уведомление. |
| `theme_changed` | iframe сообщает о своей фактической теме. |
| `page_changed` | iframe сообщает о фактической странице продукта. |

Используйте `onRendered` или `widget.on('rendered', handler)` для обработки рендеринга отдельно от инициализации. Текущие поддерживаемые страницы опубликованы в `TradingWidget.capabilities.pages`; проверять запрошенную страницу, а не угадывать путь.
