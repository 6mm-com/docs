## Разделение ответственности

| Область | Владелец | Примечания |
| --- | --- | --- |
| Создание контейнера | Партнерский интерфейс | Предоставьте видимый элемент с явно заданной шириной и высотой. |
| создание iframe | Trading Widget SDK | SDK создает iframe и управляет им. |
| Торговый интерфейс | 6MM iframe | K-линия, книга заказов, форма заказа, позиции, заказы и данные счета выполняются внутри iframe. |
| Элементы управления дисплеем | Trading Widget SDK + 6MM iframe | Заголовок для встраивания ПК и нижний тикер по умолчанию скрыты. Партнеры могут использовать `display` для отображения областей оболочки или скрытия торговых контейнеров высокого уровня. |
| Проверка входа партнера | Серверная часть партнера | Подтвердите сеанс пользователя-партнера перед выдачей учетных данных для аутентификации. |
| Встроить выпуск токена | Серверная часть партнера + агент API | Рекомендуется для режима партнерского токена. |

## Управление версиями

Путь общедоступной интеграции остается стабильным в рамках сценария v1 URL. Текущий набор возможностей версии 1 включает в себя партнерский токен, tokenProvider, entryUrlProvider, элементы управления отображением, события жизненного цикла, методы экземпляра и события заказа.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Когда использовать виджет

Выберите Trading Widget, если партнеру нужен полноценный торговый интерфейс внутри существующего веб-продукта. Вместо этого используйте документацию REST API и WebSocket при создании и поддержке полностью настраиваемого торгового интерфейса.

## Путь реализации

1. Следуйте [Trading Widget Быстрый старт](/ru/sdk/trading-widget/quick-start) чтобы загрузить скрипт и создать видимый контейнер.
2. Настроить [аутентификация по партнерскому токену](/ru/sdk/trading-widget/authentication) через серверную часть партнера.
3. Добавьте необходимые [варианты и события](/ru/sdk/trading-widget/options-events).
4. Использовать [методы экземпляра](/ru/sdk/trading-widget/instance-methods) для управления жизненным циклом и временем выполнения.

## Проверенная общедоступная среда выполнения

Публичный скрипт `v1` сообщает о версии `1.8.0` по состоянию на 10 октября 2026 г. Это URL — это стабильная точка входа основной версии, а не закрепленная сборка. Прочтите `TradingWidget.version` и `TradingWidget.capabilities` в загруженной среде выполнения перед использованием дополнительных функций. Java Agent SDK `v0.3.0` — это отдельный серверный пакет.

Среда выполнения поддерживает один активный экземпляр (`multiInstance=false`); создание другого виджета уничтожает предыдущий экземпляр. Поддерживаемые локали: `en`, `en-US` и `zh-CN` независимо от 20 языков документации.
