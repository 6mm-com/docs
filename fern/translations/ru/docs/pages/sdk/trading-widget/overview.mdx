<h2 id="responsibility-split">Разделение ответственности</h2>

| Площадь | Владелец | Примечания |
| --- | --- | --- |
| Создание контейнеров | Партнёрский фронтенд | Обеспечьте видимый элемент с явной шириной и высотой. |
| Создание iframe | Trading Widget SDK | SDK создаёт и управляет iframe. |
| Торговый интерфейс | 6MM iframe | K-line, книга заказов, форма заказа, позиции, заказы и данные аккаунта запускаются внутри iframe. |
| Управление дисплеем | Trading Widget SDK + 6MM iframe | Заголовок встраивания ПК и нижний тикер по умолчанию скрыты. Партнёры могут использовать `display` для отображения зон оболочки или для скрытия высокоуровневых торговых контейнеров. |
| Проверка входа в партнёра | Партнёрский бэкенд | Проверьте сессию партнёра перед выдачей учетных данных аутентификации. |
| Выпуск токенов встраивания | Партнёрский бэкенд + агент API | Рекомендуется для режима партнёрского токена. |

<h2 id="versioning">Версионирование</h2>

Путь публичной интеграции остаётся стабильным под скриптом v1 URL. Текущий набор возможностей v1 включает партнёрский токен, tokenProvider, entryUrlProvider, управление отображением, события жизненного цикла, методы экземпляра и события порядка.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Когда использовать виджет</h2>

Выбирайте Trading Widget , когда партнёру нужен полный торговый интерфейс внутри существующего веб-продукта. Используйте документацию REST API и WebSocket при создании и поддержании полностью индивидуального торгового интерфейса.

<h2 id="implementation-path">Путь реализации</h2>

1. Следуйте за [Trading Widget Quick Start](/ru/sdk/trading-widget/quick-start), чтобы загрузить скрипт и создать видимый контейнер.
2. Настройте [аутентификация токеном партнёра](/ru/sdk/trading-widget/authentication) через партнёрский бэкенд.
3. Добавьте необходимые [опции и события](/ru/sdk/trading-widget/options-events).
4. Используйте [методы экземпляра](/ru/sdk/trading-widget/instance-methods) для управления жизненным циклом и выполнением.
