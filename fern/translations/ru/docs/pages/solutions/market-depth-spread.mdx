Качество ликвидности видно пользователям по глубине, спреду, скорости исполнения и надёжности заказов. Для партнёрских платформ эти индикаторы часто определяют, достаточно ли пользователи доверяют рынку для повторной торговли.

<h2 id="what-to-evaluate">Что оценивать</h2>

| Индикатор | Почему это важно |
| --- | --- |
| Глубина в книге заказов | Помогает выполнять крупные ордеры с меньшим влиянием на цену. |
| Спред между ставками и спросом | Влияет на видимую торговую стоимость до размещения ордера. |
| Надёжность заполнения | Определяет, выполняются ли пользовательские заказы предсказуемо во время активных рынков. |
| Обработка волатильности | Поддерживает стабильное торговое поведение во время быстрых движений рынка. |

<h2 id="how-6mm-supports-liquidity-quality">Как 6MM поддерживает качество ликвидности</h2>

- Агрегирует источники ликвидности и распределяет глубину рынка между партнёрами.
- Поддерживает автоматизированное предоставление ликвидности для поддерживаемых торговых рынков.
- Помогает снизить фрагментированное поведение рынка в периоды запуска, роста и высокого объема.
- Работает с контролем рисков, чтобы качество оценок не было за счёт операционной стабильности.

<h2 id="operational-focus">Оперативная деятельность</h2>

Отслеживайте качество ликвидности вместе с поведением пользователей. Большое количество просмотров страниц без ордеров может свидетельствовать о проблемах с доверием или спредом. Попытки с высоким уровнем заказов с низким уровнем выполнения могут указывать на глубину рынка, риск или проблемы с рабочим процессом счета.
