Используйте этот чек-лист перед тем, как показывать 6MMторговые потоки производственным пользователям. Он предназначен для совместного анализа продуктовых, инженерных, операционных, рисковых и вспомогательных команд.

<span id="launch-checklist" data-sixmm-canonical-anchor="launch-checklist" aria-hidden="true"></span>

## Чек-лист запуска

| Площадь | Чек-лист |
| --- | --- |
| Продукт | Точки входа, пользовательские тексты, подсказки по риску, языковое покрытие и пути поддержки готовы. |
| Бэкенд | API реализуются учетные данные, подписание, выпуск токенов, вебхуки, повторы и логирование. |
| Торговля | Были пересмотрены действия по заказам, переводу, позиции, марже, комиссии и ликвидации. |
| Безопасность | Складываются журналы секретов, ролей доступа, мониторинга, реагирования на инциденты и аудита. |
| Эксплуатация | Назначены рабочие процессы поддержки, пути эскалации, сверка и ежедневный мониторинг. |

<span id="recommended-sequence" data-sixmm-canonical-anchor="recommended-sequence" aria-hidden="true"></span>

## Рекомендуемая последовательность

1. Полная проверка песочницы или внутренней среды.
2. Проведите сквозные путь пользователей для входа, входа, передачи, торговли и поддержки.
3. Подтвердить принадлежность к мониторингу и реагированию на инциденты.
4. Одобрять публичные копии, локализованные ресурсы и загрузку ресурсов.
5. Начните с контролируемого окна запуска перед широким продвижением.

<span id="after-launch" data-sixmm-canonical-anchor="after-launch" aria-hidden="true"></span>

## После запуска

Ежедневно проверяйте активность в период первоначального запуска. Вместе следите за конвертацией записей, сбоями при выпуске токенов, ошибками заказов, качеством спредов, завершением передачи, повторениями webhook и заявками поддержки.
