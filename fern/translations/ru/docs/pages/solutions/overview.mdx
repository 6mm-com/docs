<h2 id="how-the-solutions-connect">Как взаимосвязаны решения</h2>

Большинство партнёрских реализаций сочетают более одной 6MM возможностей. Биржа с собственной маркой может использовать институциональную ликвидность, поддержку соответствия и интеграции API . Встроенный торговый партнёр может начать с Trading Widget SDK , а затем добавить бэкенд- Agent SDK потоки, обработку вебхуков и операционные ресурсы.
