Система торговли Embedded API / SDK разработана для партнёров, которые уже владеют трафиком, пользователями или бизнес-рабочими процессами и хотят добавить торговлю без создания полноценной биржи с нуля.

<span id="what-it-provides" data-sixmm-canonical-anchor="what-it-provides" aria-hidden="true"></span>

## Что она даёт

- Встроенный торговый терминал через Trading Widget SDK
- Интеграция с партнёрским бэкэндом через Agent SDK
- Привязка идентичности пользователя и потоки токенов входа
- Доступ к передаче активов, порядку, позиции и счету API
- Интеграция событий, вебхука и жизненного цикла для операционных систем

<span id="recommended-architecture" data-sixmm-canonical-anchor="recommended-architecture" aria-hidden="true"></span>

## Рекомендуемая архитектура

| Слой | Ответственность |
| --- | --- |
| Партнёрский фронтенд | Хостит точку входа и встраивает торговый интерфейс 6MM . |
| Партнёрский бэкенд | Хранит API секреты, проверяет пользователей, выпускает встраиваемые токены и обрабатывает вебхуки. |
| 6MM торговая инфраструктура | Отвечает за торговый интерфейс, сопоставление, риски, ликвидность, состояние счёта и жизненный цикл торговли. |

## Выберите путь интеграции

| Требования | Рекомендуемый путь |
| --- | --- |
| Полный торговый интерфейс с максимально быстрой веб-интеграцией | Trading Widget |
| Привязка пользователей, передача, URL входа и обработка вебхуков | Agent SDK |
| Полностью индивидуальные рабочие процессы по товарам и заказам | REST API + WebSocket |
| Опыт брендового обмена с более широким операционным охватом | Биржа белых лейблов |

Окончательный дизайн может сочетать эти пути. Подтвердить аутентификацию, владение активами, границы ответственности, мониторинг и поддержку производства до начала внедрения.
