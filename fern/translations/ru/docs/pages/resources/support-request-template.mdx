При обращении в службу поддержки включайте информацию ниже, когда она доступна.

<span id="required-context" data-sixmm-canonical-anchor="required-context" aria-hidden="true"></span>

## Необходимый контекст

| Поле | Пример |
| --- | --- |
| Окружающая среда | Постановка или постановка |
| Затронутый модуль | Trading Widget, Agent SDK, REST API, WebSocket, webhook, система white-label |
| Временной диапазон | UTC временной отметке, когда произошёл выпуск |
| Идентификатор пользователя партнёра | Идентификатор пользователя на стороне партнёра, если это важно |
| 6MM идентификатор отображения | agentUserId, ID заказа, запроса или webhook event ID |
| Влияние на бизнес | Количество затронутых пользователей или операций и продолжается ли проблема |

<span id="description-format" data-sixmm-canonical-anchor="description-format" aria-hidden="true"></span>

## Формат описания

- Что случилось?
- Чего ты ожидал?
- Можно ли воспроизведать?
- Что изменилось в последнее время?
- Проблема всё ещё актуальна?

<span id="attachments" data-sixmm-canonical-anchor="attachments" aria-hidden="true"></span>

## Вложения

- Соответствующие журналы запросов и ответов.
- Скриншоты или записи экрана.
- Заголовки полезной нагрузки и подписи Webhook.
- Ошибки консоли браузера по Trading Widget проблемам.

<span id="copyable-template" data-sixmm-canonical-anchor="copyable-template" aria-hidden="true"></span>

## Копиируемый шаблон

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Удаляйте поля, которые не имеют значения, но сохраняйте UTC временной диапазон и хотя бы один поисковый запрос или бизнес-идентификатор, когда это возможно.

<span id="redact-sensitive-data" data-sixmm-canonical-anchor="redact-sensitive-data" aria-hidden="true"></span>

## Редактировать чувствительные данные

Не отправляйте:

- Пароли или токены полного доступа
- API секреты, приватные ключи или полные подписи
- Сессионные cookie
- Полная оплата, удостоверение личности или другие ненужные персональные данные

Оставляйте имя поля и короткий префикс или суффикс только в тех случаях, когда поддержке нужно различать очищенные значения.
