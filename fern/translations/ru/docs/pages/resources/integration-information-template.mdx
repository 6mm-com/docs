Используйте этот шаблон при подготовке новой интеграции или переносе существующей интеграции в продакшн.

<h2 id="partner-information">Информация о партнёрах</h2>

| Поле | Описание |
| --- | --- |
| Имя партнёра | Юридический или проектный имя, используемый для интеграции. |
| Тип продукта | Приложение, кошелёк, брокерский портал, биржа whitelabel, институциональная платформа или что-то подобное. |
| Основные контакты | Бизнес, технические, операционные и экстренные контакты. |
| Регионы запуска | Страны или регионы, где интеграция будет раскрыта. |

<h2 id="technical-information">Техническая информация</h2>

| Поле | Описание |
| --- | --- |
| Фронтенд-домены | Домены, которые загружают виджет или страницы записей. |
| Бэкенд-домены | Серверные домены, используемые для Agent SDK или API вызовов. |
| Webhook URL | Требования к производственному вебхуку и ожидаемому IP списку разрешений. |
| Область интеграции | Trading Widget, Agent SDK, REST API, WebSocket, система white-label или интеграция ликвидности. |

<h2 id="operational-information">Оперативная информация</h2>

- Ожидаемая дата запуска.
- Ожидаемый трафик или активный диапазон пользователей.
- Владелец часов поддержки и эскалации.
- Мониторинг контактов владельцев и инцидентов.

<h2 id="security-and-review-information">Информация о безопасности и обзоре</h2>

- Метод аутентификации и область API Key разрешений.
- IP секретного хранилища, владельца ротации и утверждённых исходных IP.
- Проверка подписи Webhook и дизайн идемпотентности.
- Владельцы логирования, мониторинга, сверки, отката и реагирования на инциденты.
- Целевые рынки, тип пользователя, модель хранения и организация, ответственная за обязательства, связанные с пользователем.

Не включайте в этот шаблон производственные секреты, токены полного доступа, приватные ключи или неотредактированные пользовательские данные.

Используйте [чек-лист запуска производства](/ru/resources/production-launch-checklist) для окончательного одобрения и [шаблон запроса в поддержку](/ru/resources/support-request-template) для эскалации проблем.
