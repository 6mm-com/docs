> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Удаленный MCP предназначен для пользователей или учреждений, которым нужна долговременно работающая конечная точка MCP под собственным контролем.

В отличие от размещенного MCP, удаленный MCP не управляется пользователем 6MM. 6MM предоставляет код, изображения, шаблоны и документацию; пользователь контролирует хостинг и учетные данные.

## Архитектура

```text
AI client
  -> user-managed MCP HTTP endpoint
  -> 6MM REST / WebSocket API
```

<span id="deployment-targets" data-sixmm-canonical-anchor="deployment-targets" aria-hidden="true"></span>

## Цели развертывания

- Docker или Docker Compose.
- VPS с обратным прокси.
- Железная дорога.
- Оказывать.
- Fly.io.
- AWS ECS или лямбда.
- Внутренний Кубернетес.

<span id="required-files" data-sixmm-canonical-anchor="required-files" aria-hidden="true"></span>

## Необходимые файлы

- Докерфайл.
- docker-compose.yml.
- .env.шаблон.
- HTTP транспортный режим.
- /mcp конечная точка.
- / конечная точка здоровья.
- Обратный прокси и заметки TLS.

<span id="credential-model" data-sixmm-canonical-anchor="credential-model" aria-hidden="true"></span>

## Модель учетных данных

Учетные данные должны храниться в среде, управляемой пользователем, а не в командной строке AI-клиента. Для развертываний, управляемых учреждением, ограничьте доступ утвержденным клиентам и сетям.

<span id="recommended-first-release" data-sixmm-canonical-anchor="recommended-first-release" aria-hidden="true"></span>

## Рекомендуемый первый выпуск

Начните с публичных рыночных данных. Добавьте учетную запись только для чтения после аутентификации, доступны область действия ключей, журналы и элементы управления доступом. Торговля должна оставаться отключенной до тех пор, пока не будут выполнены требования по контролируемой торговле.
