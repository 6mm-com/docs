> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


6MM CLI — это точка входа в командную строку для пользователей, сценариев и агентов ИИ, которые могут выполнять команды оболочки.

Используйте CLI, если среда AI может напрямую запускать команды терминала. Часто это самый простой путь для агентов кодирования, поскольку отдельный сервер MCP не требуется. CLI должен возвращать стабильный JSON по умолчанию, чтобы агенты могли анализировать результаты, не полагаясь на форматирование терминала.

<span id="what-the-cli-is-good-for" data-sixmm-canonical-anchor="what-the-cli-is-good-for" aria-hidden="true"></span>

## Чем хорош CLI

- Быстрые запросы рыночных данных с терминала.
- Агентный анализ в Codex, Claude Code, Gemini CLI или аналогичных инструментах.
- CI или запланированные сценарии, которым необходимы данные 6MM.
- Проверка чтения учетной записи при настройке локальных учетных данных.
- Предварительный просмотр заказа происходит, когда агент подготавливает параметры, но не размещает заказ.

<span id="example-commands" data-sixmm-canonical-anchor="example-commands" aria-hidden="true"></span>

## Примеры команд

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

<span id="output-modes" data-sixmm-canonical-anchor="output-modes" aria-hidden="true"></span>

## Режимы вывода

| Режим | Вариант использования |
| --- | --- |
| JSON | По умолчанию для агентов AI, сценариев и автоматизации. |
| Стол | Удобочитаемый обзор терминала. |
| Сырой | Отладка и интеграционные тесты. |

<span id="recommended-safety-defaults" data-sixmm-canonical-anchor="recommended-safety-defaults" aria-hidden="true"></span>

## Рекомендуемые настройки безопасности по умолчанию

- Среда по умолчанию — testnet.
- Выход по умолчанию: JSON.
- Торговые команды требуют явного согласия.
- Создание заказа в основной сети требует подтверждения.
- Режим предварительного просмотра доступен перед созданием.
- Ошибки включают стабильные коды и четкие сообщения.

<span id="agent-usage" data-sixmm-canonical-anchor="agent-usage" aria-hidden="true"></span>

## Использование агента

Агентам ИИ следует отдавать предпочтение командам, доступным только для чтения, если только пользователь явно не запрашивает предварительный просмотр или торговые действия.

Пример приглашения:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
