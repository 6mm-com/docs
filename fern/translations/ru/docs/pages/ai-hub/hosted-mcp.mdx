> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Хостинг MCP — это самый простой способ начать работу с 6MM AI Hub.

Подключите AI-клиент к 6MM конечной точке MCP и задавайте вопросы об общедоступных рыночных данных. Не требуется устанавливать локальный сервер, не требуется развертывание в облаке и не требуется пользовательский ключ API для общедоступных данных.

<span id="what-you-can-do" data-sixmm-canonical-anchor="what-you-can-do" aria-hidden="true"></span>

## Что вы можете сделать

- Запрашивайте текущие и исторические рыночные данные.
- Просмотрите доступные бессрочные рынки.
- Проверьте глубину стакана заказов и последние сделки.
- Сравните ставки финансирования.
- Прочтите комиссию, контракт, маржу и контекст правил риска.

Хостинг MCP лучше всего подходит для исследований, изучения продуктов и анализа публичного рынка. Это неподходящая первая настройка для доступа к личному счету или торговли.

<span id="recommended-first-release-scope" data-sixmm-canonical-anchor="recommended-first-release-scope" aria-hidden="true"></span>

## Рекомендуемая область действия первого выпуска

Размещенный MCP в первом выпуске должен предоставлять только общедоступную информацию и информацию, доступную только для чтения:

- Рынки.
- Тикеры.
- Заказ книг.
- Последние сделки.
- Клайнс.
- Ставки финансирования.
- Статус системы.
- Торговые комиссии.
- Спецификации контракта.
- Ресурсы правил риска и маржи.

<span id="not-supported-in-the-first-release" data-sixmm-canonical-anchor="not-supported-in-the-first-release" aria-hidden="true"></span>

## Не поддерживается в первом выпуске

Хостинг MCP не должен быть первым местом для размещения:

- Остатки на счетах.
- Позиции.
- Открытые ордера.
- Создание заказа.
- Отмена заказа.
- Переводы или снятие средств.
- Хранилище ключей пользователя API.

<span id="why-public-data-first" data-sixmm-canonical-anchor="why-public-data-first" aria-hidden="true"></span>

## Почему общедоступные данные прежде всего

Размещенный MCP управляется 6MM и доступен по сети. Это удобно, но оно не должно становиться местом по умолчанию, куда пользователи отправляют личные ключи API. Рабочие процессы с конфиденциальными учетными записями и торговлей следует начинать с локального MCP, CLI или удаленного, управляемого пользователем MCP.

## Эксплуатационные требования

- TLS на всех конечных точках.
- Запросить ограничения скорости.
- Защита от злоупотреблений.
- Структурированные журналы и метрики.
- Проверка здоровья.
- Четкие описания и схемы инструментов.
- Стабильные ответы на ошибки для клиентов AI.
