> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


VS Code и GitHub Copilot полезны для реализации SDK, подписания API и интеграции партнерской серверной части.

<h2 id="security-notes">Примечания по безопасности</h2>

Не размещайте секреты API в коде внешнего интерфейса, настройках расширения, переданных в систему контроля версий, или в файлах общей рабочей области.
