> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Gemini CLI лучше всего работает с выводом командной строки, который можно просмотреть, обобщить и передать в последующие задачи.

<h2 id="recommended-setup">Рекомендуемая настройка</h2>

| Нуждаться | Настраивать |
| --- | --- |
| Чеки публичного рынка | 6MM CLI |
| Сценарное исследование | 6MM CLI |
| Контекст личного аккаунта | Локальный MCP или CLI с локальными учетными данными |

<h2 id="example-prompts">Примеры подсказок</h2>

```text
Use 6MM CLI to fetch market metadata and summarize tradable pairs.
```

```text
Use 6MM to compare fee and margin rules for two symbols.
```

<h2 id="output-format">Выходной формат</h2>

Отдавайте предпочтение структурированному выводу, такому как JSON или таблицам Markdown, чтобы AI-клиент мог анализировать результат без потери точности.
