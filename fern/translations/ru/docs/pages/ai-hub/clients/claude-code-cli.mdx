> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Код Клода CLI полезен, когда агент может запускать команды терминала, проверять выходные данные JSON и обновлять код интеграции.

<h2 id="recommended-setup">Рекомендуемая настройка</h2>

| Нуждаться | Настраивать |
| --- | --- |
| Быстрая проверка рынка | 6MM CLI |
| Контекст локальной учетной записи | Местный MCP |
| Повторяемый рабочий процесс реализации | Агентские навыки |

<h2 id="best-practice">Лучшая практика</h2>

Предпочитайте вывод JSON для рабочих процессов агента. Легче анализировать, сравнивать и включать в журналы реализации.
