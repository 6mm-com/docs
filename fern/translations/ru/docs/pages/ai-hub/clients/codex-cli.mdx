> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Кодекс CLI лучше всего подходит для сложных рабочих процессов: интеграция SDK, обработчики webhook, подписание API и контрольные списки запуска.

<h2 id="recommended-setup">Рекомендуемая настройка</h2>

| Нуждаться | Настраивать |
| --- | --- |

| Документированный рабочий процесс | Агентские навыки |
| Проверка локальных личных счетов | Местный MCP |

<h2 id="guardrails">Ограждения</h2>

В рабочих процессах Кодекса торговые действия должны рассматриваться как задачи реализации или тестовой сети, если только пользователь явно не включит производственную торговую область.
