> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


ChatGPT Desktop — это знакомая точка входа для пользователей, которые хотят задавать рыночные вопросы на естественном языке.

Используйте этот путь, если пользователю нужен диалоговый интерфейс для общедоступных рыночных данных, сводок по счетам, объяснений позиций и контекста торговых правил.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Рекомендуемая настройка

| Нуждаться | Настраивать |
| --- | --- |
| Данные публичного рынка | Хостинг MCP |
| Контекст личного аккаунта | Местный MCP |
| Повторяемые подсказки для анализа | Агентские навыки |
| Рабочие процессы на базе терминала | 6MM CLI |

<span id="what-users-can-ask" data-sixmm-canonical-anchor="what-users-can-ask" aria-hidden="true"></span>

## Что могут спросить пользователи

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<span id="safety-defaults" data-sixmm-canonical-anchor="safety-defaults" aria-hidden="true"></span>

## Параметры безопасности по умолчанию

- Начните с публичных рыночных данных.
- Используйте локальный MCP, если необходимы учетные данные учетной записи.
- Храните личные ключи API на компьютере пользователя.
- Требовать предварительного просмотра и явного подтверждения перед любыми будущими торговыми действиями.
