> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Claude Desktop хорошо подходит для исследований на основе MCP-, проверки учетных записей и оперативного анализа.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Рекомендуемая настройка

| Нуждаться | Настраивать |
| --- | --- |
| Исследование общественного рынка | Хостинг MCP |
| Анализ с учетом учетной записи | Местный MCP |
| Конечная точка внутренней группы | Удаленный MCP |

<span id="example-prompts" data-sixmm-canonical-anchor="example-prompts" aria-hidden="true"></span>

## Примеры подсказок

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<span id="notes" data-sixmm-canonical-anchor="notes" aria-hidden="true"></span>

## Примечания

Локальный MCP предпочтителен, когда задействованы данные частной учетной записи, поскольку сервер MCP работает на компьютере пользователя, и учетные данные не нужно отправлять в конечную точку AI, размещенную в 6MM .
