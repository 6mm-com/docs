> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


6MM Agentic AI Hub — это AI-родной интерфейс для 6MM рыночных данных, рабочих процессов по счетам и будущих контролируемых торговых операций.

Вместо переключения между панелями мониторинга, документами API и скриптами пользователи могут попросить AI-клиента запросить 6MM, объяснить рыночные условия, просмотреть риски по счету или подготовить предварительный просмотр заказа. Клиент AI не заменяет модель безопасности 6MM API; он вызывает структурированные инструменты 6MM через CLI, MCP или шаблоны рабочих процессов.

<span id="what-you-can-ask-an-ai-client" data-sixmm-canonical-anchor="what-you-can-ask-an-ai-client" aria-hidden="true"></span>

## Что можно спросить у AI-клиента

Используйте AI Hub, если хотите задать такие вопросы, как:

```text
Show me the BTC-USDT-PERP order book and explain current liquidity.
```

```text
Compare BTC and ETH funding rates over the last 24 hours.
```

```text
Check my testnet positions and explain liquidation risk. Do not place orders.
```

```text
Preview a small BTC long order and explain fees, margin impact, and risk checks.
```

## Почему ИИ-агентам нужен выделенный уровень доступа

Агенты ИИ работают лучше всего, когда у них есть структурированные инструменты вместо необработанных веб-страниц или неструктурированного скопированного текста. AI Hub дает им:

| Требование | 6MM подход |
| --- | --- |
| Контекст реального рынка | Инструменты и ресурсы общедоступных рыночных данных для символов, книг заказов, сделок, финансирования, комиссий и правил. |
| Очистить разрешения | Отдельные области общедоступных данных, чтения со счета, предварительного просмотра и контролируемой торговли. |
| Более безопасное исполнение | Поток заказов с предварительным просмотром, явное подтверждение, идемпотентность, ограничения и журналы аудита. |
| Гибкость клиента | Хостинг MCP, локальный MCP, CLI, удаленный MCP и агентские навыки для различных сред ИИ. |

## Пути установки

| Путь | Лучшее для | Пользователь должен знать |
| --- | --- | --- |
| Хостинг MCP | Быстрый доступ к публичным рыночным данным | Нет установки и нет пользовательского ключа API для общедоступных данных. Торговля не является целью первого выпуска. |
| Местный MCP | Клиенты ИИ, которым нужен контекст частной учетной записи | Сервер MCP работает локально, а учетные данные остаются на компьютере пользователя. |
| CLI | Агенты кодирования, сценарии и пользователи терминалов | Создает удобный для агента вывод команд и может использоваться без сервера MCP. |
| Удаленный MCP | Учреждения и команды, которым нужна собственная конечная точка | Пользователь или учреждение контролирует хостинг, учетные данные, доступ к сети и журналы. |
| Агентские навыки | Повторяемые рабочие процессы | Навыки помогают ИИ выполнять анализ и действия по управлению рисками с использованием утвержденных инструментов. |

## Что доступно в первую очередь

AI Hub должен начать с общедоступных рыночных данных и ресурсов по торговым правилам:

- Рынки.
- Тикеры.
- Заказ книг.
- Торги.
- Клайнс.
- Ставки финансирования.
- Статус системы.
- Комиссии, спецификации контрактов, правила маржи и ресурсы правил риска.

Доступ к личному счету и торговля должны быть организованы:

- Инструменты чтения учетной записи требуют явных учетных данных только для чтения.
- Предварительный просмотр заказа должен предшествовать созданию реального заказа.
- Для контролируемой торговли требуются области разрешений, проверки рисков на стороне службы, подтверждение пользователя, идемпотентность и журналы аудита.
