> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Руководства для клиентов помогают пользователям подключить 6MM AI Hub к инструментам, которые они уже используют.

<h2 id="start-with-the-ai-tool-users-already-know">Начните с инструмента искусственного интеллекта, который уже известен пользователям</h2>

<CardGroup cols={2}>
<Card title="ЧатGPT для рабочего стола" icon="fa-duotone fa-message-bot" href="/ru/ai-hub/clients/chatgpt-desktop">
Используйте диалоговые подсказки для получения общедоступных рыночных данных, сводок по счетам и контекста торговых правил.
</Card>
<Card title="Клод Рабочий стол" icon="fa-duotone fa-comments" href="/ru/ai-hub/clients/claude-desktop">
Подключайтесь через локальный MCP или хостинговый MCP для исследования и анализа с учетом учетной записи.
</Card>
<Card title="Код Клода CLI" icon="fa-duotone fa-terminal" href="/ru/ai-hub/clients/claude-code-cli">
Используйте CLI или локальный MCP, если агент может запускать команды и проверять выходные данные JSON.
</Card>
<Card title="Кодекс CLI" icon="fa-duotone fa-code" href="/ru/ai-hub/clients/codex-cli">
Используйте рабочие процессы, ориентированные на реализацию, для SDK, API, webhook и задач запуска.
</Card>
<Card title="Курсор" icon="fa-duotone fa-arrow-pointer" href="/ru/ai-hub/clients/cursor">
Включите контекст 6MM SDK и API в рабочие процессы кодирования.
</Card>
<Card title="Близнецы CLI" icon="fa-duotone fa-sparkles" href="/ru/ai-hub/clients/gemini-cli">
Используйте структурированный вывод CLI для исследования рынка и автоматизации с помощью терминала.
</Card>
<Card title="Код VS / второй пилот GitHub" icon="fa-duotone fa-laptop-code" href="/ru/ai-hub/clients/vscode-copilot">
Используйте рабочие процессы редактора и терминала для реализации серверной части партнера.
</Card>
<Card title="Виндсерфинг" icon="fa-duotone fa-wind" href="/ru/ai-hub/clients/windsurf">
Используйте локальный MCP или CLI в рабочих процессах агента кодирования, которые проверяют файлы проекта.
</Card>
</CardGroup>

<h2 id="each-client-guide-should-include">Каждое руководство для клиента должно включать</h2>

- Поддерживаемый режим: CLI, локальный MCP, размещенный MCP или удаленный MCP.
- Команда установки.
- Путь к файлу конфигурации.
- Переменные среды.
- Пример тестовой сети.
- Команда или подсказка проверки.
- Распространенные ошибки.
- Примечания по безопасности.

