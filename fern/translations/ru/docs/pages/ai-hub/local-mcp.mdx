> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Локальный MCP — это рекомендуемая настройка, когда ИИ-клиенту нужен контекст приватной учетной записи или будущие контролируемые торговые инструменты.

Сервер MCP работает на компьютере пользователя. Клиент AI вызывает локальные инструменты 6MM, а локальный сервер связывается с 6MM APIs с использованием учетных данных, настроенных пользователем.

<span id="what-your-ai-client-can-do" data-sixmm-canonical-anchor="what-your-ai-client-can-do" aria-hidden="true"></span>

## Что может ваш AI-клиент

С помощью Local MCP AI-клиент может использовать инструменты 6MM контролируемым образом:

- Получайте живые и исторические рыночные данные.
- Чтение остатков на счетах, позиций, открытых ордеров, исполнений и записей о финансировании, когда включены учетные данные только для чтения.
- Объясните риски портфеля, использование маржи и риск ликвидации.
- Предварительный просмотр заказов перед размещением реального заказа.
- На более поздних этапах контролируемой торговли создавайте или отменяйте ордера только после явного разрешения и проверки рисков.

Используйте локальный MCP, если учетные данные должны оставаться на компьютере пользователя.

## Рекомендуемые уровни разрешений

| Уровень | Инструменты | Примечания |
| --- | --- | --- |
| Публичные данные | Рынки, тикер, книга заказов, клайны, сделки, финансирование | Нет доступа к личному кабинету. |
| Аккаунт прочитан | Балансы, позиции, открытые ордера, исполнения | Требуется доступная только для чтения область ключа API. |
| Предварительный просмотр торговли | Порядок предварительного просмотра, влияние маржи, оценка комиссии | Не размещает заказы. |
| Контролируемая торговля | Создание, отмена, изменение заказов | Требуется явное разрешение, подтверждение и контроль рисков. |

## Контрольный список первой настройки

1. Установите пакет MCP.
2. Создайте или настройте ключ API только для чтения.
3. Запустите в тестовой сети.
4. Добавьте сервер MCP в конфигурацию AI-клиента.
5. Попросите клиента перечислить доступные инструменты 6MM.
6. Запустите запрос данных об общедоступном рынке.
7. Только после этого при необходимости добавьте учетные данные для чтения учетной записи.

<span id="security-notes" data-sixmm-canonical-anchor="security-notes" aria-hidden="true"></span>

## Примечания по безопасности

Локальный MCP по умолчанию должен быть доступен только для чтения и в тестовой сети. Торговые инструменты должны требовать предварительного просмотра, подтверждения пользователя, ключей идемпотентности, условных ограничений и проверок рисков на стороне сервиса.
