> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Приглашения MCP — это рабочие процессы многократного использования, предоставляемые сервером MCP. Они помогают пользователям задавать последовательные вопросы и помогают клиентам ИИ использовать правильные инструменты.

## Рекомендуемые подсказки

| Быстрый | Цель |
| --- | --- |
| обзор_рынка | Обобщите состояние рынка по выбранным символам. |
| market_microstructure_anaанализ | Анализируйте спред, глубину, последние сделки и условия ликвидности. |
| портфель_риск_оценка | Просмотрите позиции, риски, маржу и риск ликвидации. |
| позиция_управление | Помогите пользователям понять состояние позиции и возможные действия. |
| ликвидация_защита | Определить риск ликвидации и варианты снижения риска. |
| funding_rate_opportunity | Сравните ставки финансирования и возможные возможности. |
| create_optimal_order | Запланируйте параметры заказа перед предварительным просмотром. |
| хеджинг_стратегия | Изучите варианты хеджирования существующих рисков. |
| торговая_консультация | Произведите структурированный анализ торговли без исполнения ордеров. |

## Подскажите правила безопасности

- Не воспринимайте быстрые результаты как финансовый совет.
- Не используйте торговые инструменты, если пользователь явно не попросит об этом.
- Используйте предварительный просмотр перед созданием.
- Объясните предположения и источники данных.
- Предпочитайте примеры тестовых сетей в общедоступной документации.
