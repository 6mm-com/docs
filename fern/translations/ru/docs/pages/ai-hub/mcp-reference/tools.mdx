> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Инструменты MCP — это действия, которые может вызывать AI-клиент. Каждый инструмент должен иметь четкое описание, схему JSON, требования к разрешениям, стабильный формат ответа и модель ошибок.

## Этап 1: инструменты публичного рынка

| Инструмент | Цель |
| --- | --- |
| 6mm_system_status | Проверьте сервис и доступность на рынке. |
| 6mm_markets | Перечислите доступные рынки и основные метаданные. |
| 6mm_market_summary | Обобщите состояние рынка для одного или нескольких символов. |
| 6 мм_тикер | Возвращает последние данные тикера. |
| 6mm_orderbook | Глубина книги заказов на возврат. |
| 6mm_klines | Верните исторические свечи. |
| 6mm_trades | Возврат недавних публичных торгов. |
| 6mm_funding_rates | Возвращайте текущие и исторические ставки финансирования. |

## Этап 3 и последующие: торговые инструменты

| Инструмент | Цель |
| --- | --- |
| 6mm_preview_order | Подтвердите заказ, не размещая его. |
| 6mm_create_order | Создайте заказ после подтверждения и проверки рисков. |
| 6mm_cancel_order | Отменить один заказ. |
| 6mm_cancel_all_orders | Отменить все подходящие открытые ордера. |

## Требования к инструменту

Каждый инструмент должен определять:

- Описание модели ИИ.
- Введите схему JSON.
- Объем разрешений.
- Поддержка окружающей среды.
- Поведение ограничения скорости.
- Стабильные поля ответа.
- Коды ошибок.
- Поля журнала аудита.
