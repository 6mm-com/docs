> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Ресурсы MCP — это контекст, доступный только для чтения, который клиенты ИИ могут проверять перед вызовом инструментов.

Ресурсы уменьшают галлюцинации, предоставляя модели стабильную, структурированную информацию о 6MM.

<h2 id="recommended-resource-uris">Рекомендуемые URI ресурсов</h2>

| Ресурс | Цель |
| --- | --- |
| 6 мм://система/конфигурация | Конфигурация среды и возможностей. |
| 6 мм://система/статус | Текущая система и состояние рынка. |
| 6мм://рынки | Доступные рынки. |
| 6 мм://рынок/{symbol} | Спецификации контрактов и метаданные рыночного уровня. |
| 6мм://плата | Правила оплаты. |
| 6 мм://риск/правила | Краткое изложение правил торговли и риска. |
| 6 мм://риск/маржа | Контекст маржи и ликвидации. |
| 6 мм://финансирование/правила | Правила ставок финансирования. |
| 6 мм://api/документы | API сводка ссылок или ссылки. |

<h2 id="resource-design-rules">Правила оформления ресурсов</h2>

- Оставляйте ресурсы доступными только для чтения.
- Используйте стабильные схемы.
- Включите временные метки и имена сред.
- Избегайте раскрытия секретов.
- Предпочитайте краткие структурированные данные длинной прозе.
- Ссылка на каноническую документацию, если подробности слишком длинные.
