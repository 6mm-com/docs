> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


AI-торговый доступ с поддержкой должен быть безопаснее, чем обычная автоматизация, поскольку намерения пользователя выражаются на естественном языке.

## Требуемые области разрешений

| Объем | Позволяет |
| --- | --- |
| рынок:читать | Данные публичного рынка и ресурсы правил. |
| аккаунт:читать | Балансы, позиции, открытые ордера, исполнения и сводки по счетам. |
| заказ: напишите | Создание, изменение и отмена заказов. |

## Положение безопасности по умолчанию

- По умолчанию только для чтения.
- По умолчанию используется тестовая сеть.
- Не раскрывайте снятие средств или переводы с помощью инструментов ИИ.
- Требовать предварительный просмотр перед созданием.
- Требуйте явного подтверждения перед торговлей в основной сети.
- Используйте ключи идемпотентности для торговых действий.
- Применяйте максимальные условные лимиты и лимиты кредитного плеча.
- Ведите полные журналы аудита.

<span id="controlled-trading-flow" data-sixmm-canonical-anchor="controlled-trading-flow" aria-hidden="true"></span>

## Контролируемый торговый поток

```text
User natural language intent
  -> AI maps intent to tool parameters
  -> 6mm_preview_order validates the order
  -> service returns risk checks and margin impact
  -> user explicitly confirms
  -> 6mm_create_order submits the order
  -> audit log records the full flow
```

<span id="prompt-injection-protection" data-sixmm-canonical-anchor="prompt-injection-protection" aria-hidden="true"></span>

## Мгновенная защита от инъекций

Клиенты AI и серверы MCP должны рассматривать внешний контент как ненадежный. Страницы рынка, скопированный текст, документы и веб-контент не должны отменять разрешения инструментов, правила подтверждения или торговые ограничения.
