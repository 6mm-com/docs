> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


Выберите настройку, основываясь на двух вопросах:

1. Какой AI-клиент вы хотите использовать?
2. Вам нужны только общедоступные данные, доступ к личному счету или торговые процессы?

Если вы не уверены, начните с Hosted MCP для общедоступных данных или с Local MCP для рабочих процессов частной учетной записи.

## Выбирайте по варианту использования

<CardGroup cols={2}>
<Card title="Мне нужны только публичные рыночные данные" icon="fa-duotone fa-cloud" href="/ru/ai-hub/hosted-mcp">
Используйте хостинг MCP. Никакой локальной установки, никакого пользовательского ключа API и доступа к частной учетной записи.
</Card>
<Card title="Я хочу, чтобы мой AI-клиент читал мою учетную запись" icon="fa-duotone fa-computer" href="/ru/ai-hub/local-mcp">
Используйте локальный MCP с учетными данными только для чтения. Запустите в тестовой сети или в режиме только для чтения.
</Card>
<Card title="Мой агент может запускать команды терминала" icon="fa-duotone fa-terminal" href="/ru/ai-hub/cli">
Используйте 6MM CLI. Это просто для Codex, Claude Code, Gemini CLI, сценариев и задач CI.
</Card>
<Card title="Моей команде нужна управляемая конечная точка" icon="fa-duotone fa-server" href="/ru/ai-hub/remote-mcp">
Используйте удаленный MCP. Разверните сервер в инфраструктуре, контролируемой вашей командой.
</Card>
</CardGroup>

| Настраивать | Установка | API расположение ключа | Лучший начальный прицел | Счет и объем торговли |
| --- | --- | --- | --- | --- |

| Местный MCP | Пользователь устанавливает пакет | Пользовательская машина | Публичные данные и чтение учетной записи | Рекомендуемый путь для будущей торговли |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## Эмпирическое правило безопасности

Используйте настройку с наименьшим риском, которая поддерживает задачу:

- Данные публичного рынка: хостинга MCP достаточно.
- Данные частной учетной записи: локальная MCP или управляемая пользователем удаленная MCP.
- Предварительный просмотр торговли: локальный MCP или CLI, желательно сначала в тестовой сети.
- Реальная торговля: только после явного разрешения, предварительного просмотра, подтверждения, ограничений и журналов аудита.
