> **Запланировано — ещё не запущено**
> AI Hub — запланированная функция. Возможности, конечные точки, команды и конфигурации клиента на этой странице описывают предлагаемый дизайн и в настоящее время недоступны. Окончательные инструкции по доступности и настройке будут объявлены при запуске.


AI Hub следует выпускать поэтапно, чтобы пользователи получали выгоду как можно раньше, сохраняя при этом конфиденциальные торговые возможности.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## Этап 1: Доступ к искусственному интеллекту на публичном рынке

Цель: позволить любому поддерживаемому AI-клиенту читать официальные рыночные данные 6MM .

Результаты:

- Общий клиент SDK / API.
- CLI команды публичного рынка.
- Инструменты местного MCP публичного рынка.
- Размещены MCP инструменты публичного рынка.
- Ресурсы для рынков, комиссий, правил риска и статуса системы.
- Руководство по установке клиента.

Не включено:

- Запросы по аккаунту.
- Реальная торговля.
- Хостинг ключей API .

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Этап 2: Чтение учетной записи

Цель: позволить пользователям безопасно проверять контекст своей учетной записи.

Результаты:

- Область ключа API только для чтения.
- Сводка по счету.
- Балансы.
- Позиции.
- Открытые ордера.
- Заполняет.
- Финансирование платежей.
- Подсказка о рисках портфеля.

Предпочтительное развертывание:

- Местный MCP.
- CLI.
- Удаленный MCP автономный хостинг.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Этап 3: Предварительный просмотр торговли

Цель: позволить ИИ помогать генерировать заказы, не выполняя их.

Результаты:

- `preview_order`.
- Проверки рисков.
- Влияние маржи.
- Оценка гонорара.
- Последствия ликвидации.
- Подсказка по планированию выполнения.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Этап 4: Контролируемая торговля

Цель: поддерживать реальную торговлю только с помощью надежных ограждений.

Результаты:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- идемпотентность.
- максимальные условные пределы.
- явное подтверждение.
- журналы аудита.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Фаза 5: Агентские навыки

Цель: разработать общий анализ рынка и рабочие процессы по рискам.

Результаты:

- Навыки рыночного аналитика.
- Навыки портфельного риска.
- Навыки финансирования исследований.
- Навык защиты от ликвидации.
- Навыки планирования выполнения.
- Пример библиотеки задач.
