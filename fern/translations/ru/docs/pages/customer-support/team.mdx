Предоставьте каждому агенту отдельную учетную запись, выберите роль и подготовьте проверенные быстрые ответы. Организуйте доступ к работе, которую выполняет каждый человек, а затем подтвердите ее с помощью этой учетной записи.

<div className="sixmm-support-flow">

1. **Создайте учетную запись** — определите агента и состояние учетной записи.
2. **Назначить роль** — предоставить модули и действия, необходимые для задания.
3. **Проверьте рабочий процесс** – проверьте доступ и подготовьте быстрые ответы.

</div>

## Организуйте команду поддержки

Используйте **Управление агентами** для управления учетными записями агентов, ролями и быстрыми ответами. Распределяйте роли на основе модулей и действий, которые действительно нужны каждому человеку. Сохраняйте учетные данные личными, а не делитесь одним логином администратора со всей командой.

После изменения роли проверьте ее с помощью затронутой учетной записи: видимые меню, мониторинг разговоров, редактирование контента и доступ к настройкам могут отличаться. Состояние учетной записи, владение сеансом и проверки на уровне полей по-прежнему применяются помимо наличия меню.

<span id="mcp-inherits-the-same-identity" data-sixmm-canonical-anchor="mcp-inherits-the-same-identity" aria-hidden="true"></span>

## MCP наследует тот же идентификатор

Соединение MCP привязано к авторизующей учетной записи клиента и агента. ИИ не получает отдельной роли администратора. Служба пересматривает разрешения учетной записи для звонков; недоступный инструмент нельзя включить, угадав его имя или указав другой идентификатор клиента.

Управляйте подключенными приложениями в **Системные настройки → MCP Соединение**. Отмените соединения, которые больше не нужны. Выход из браузера сам по себе не отменяет авторизацию внешнего приложения AI.

Изменение роли и учетной записи агента через MCP требует подтверждения. При создании агента через MCP исходный пароль вводится пользователем на странице подтверждения серверной части, а не возвращается AI.

## Понимание трех областей управления

| Область | Что поддерживать |
| --- | --- |
| Аккаунты агентов | Имена, адреса электронной почты для входа, роли, включенное состояние и элементы управления приемом, представленные на странице. |
| Управление ролями | Разрешенные модули и действия для группы агентов. Прежде чем сохранять изменения, просмотрите их влияние на существующих участников. |
| Быстрые ответы | Многоразовые заголовки ответов, содержание, порядок и включенное состояние. Просмотрите переводы, в которых доступна эта функция. |

### Подготовить агента к первой смене

1. Подтвердите адрес электронной почты для входа и предполагаемую роль. Не рассматривайте доступность учетной записи, состояние входа и рабочий статус как одно и то же.
2. Проверьте доступ к мониторингу, приоритет приема и максимальное количество одновременных сеансов, если они настроены. Эти элементы управления дополняют разрешения ролей.
3. Попросите агента войти в систему и проверить меню и действия, необходимые для его работы.
4. Подготовьте быстрые ответы на распространенные вопросы, а затем убедитесь, что они содержат текущие ссылки и не содержат информации, специфичной для посетителей.

**Процедура передачи**: просмотрите открытые обязанности, прежде чем изменять доступ агента. После изменения роли или учетной записи проверьте действующие разрешения, а не полагайтесь только на имя роли.

## Общие вопросы

<AccordionGroup>

<Accordion title="Действует ли ИИ, уполномоченный администратором, как обычный агент?">
Нет. Соединение MCP использует учетную запись, которая его авторизовала. Подключитесь к учетной записи, доступ к которой соответствует предполагаемой работе.
</Accordion>

<Accordion title="При выходе из системы отключается внешний AI?">
Выход из консоли отличается от отмены соединения MCP. Используйте Системные настройки → Соединение MCP для отзыва приложения.
</Accordion>

</AccordionGroup>
