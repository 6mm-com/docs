## Детали подключения

| Элемент | Ценить |
| --- | --- |
| Консоль арендатора | [Консоль арендатора](https://csadmin.6mm.com/) |
| Транспорт | Потоковое HTTP |
| Авторизация | OAuth код авторизации с помощью PKCE; динамическая регистрация клиентов |
| Счет | Ваша существующая учетная запись службы поддержки клиентов |

Используйте приложение AI, которое поддерживает этот удаленный транспорт и поток авторизации. Никакого развертывания сервера MCP конкретного клиента или отдельной настройки разрешений MCP не требуется. Не добавляйте путь SSE и не используйте ключ приложения в качестве токена носителя OAuth.

<span id="connect-step-by-step" data-sixmm-canonical-anchor="connect-step-by-step" aria-hidden="true"></span>

## Подключайтесь шаг за шагом

1. Войдите в консоль и откройте **Настройки системы → Соединение MCP**.
2. Скопируйте конечную точку и добавьте ее в качестве удаленного сервера MCP в свое приложение AI. Достаточно отображаемого имени, например 6MM Служба поддержки клиентов.
3. Позвольте приложению начать авторизацию. В браузере войдите в систему и выполните необходимую проверку.
4. Прежде чем разрешить подключение, проверьте приложение, арендатора, учетную запись и обратный адрес. Предоставленное имя приложения не является сертификционным знаком.
5. Вернитесь в приложение ИИ и при необходимости обновите его инструменты. Попросите его перечислить категории знаний в качестве первого теста, доступного только для чтения.
6. Проверьте Подключенные приложения в консоли. Отмените соединение там, когда оно больше не нужно.

Никогда не сообщайте ИИ свой пароль, код подтверждения или секрет подписи личности. Авторизуйтесь только через страницы входа и согласия.

<span id="what-access-does-the-ai-receive" data-sixmm-canonical-anchor="what-access-does-the-ai-receive" aria-hidden="true"></span>

## Какой доступ получает ИИ?

Только инструменты и данные клиента, поддерживаемые текущей учетной записью. Разрешения проверяются еще раз во время звонков; Приостановка учетной записи, недоступность арендатора или отзыв авторизации могут заблокировать доступ. Выход из консоли не приводит к автоматическому разрыву соединения AI.

Текущая реализация использует 30-дневную авторизацию подключения и кратковременные токены доступа с чередующимися токенами обновления. Следуйте сроку действия, указанному в разделе «Подключенные приложения», и при необходимости повторно подключитесь. Приложения искусственного интеллекта обеспечивают обмен и обновление токенов; Арендаторы не вставляют пароли вручную в вызовы инструментов.

Этот MCP управляет серверной частью поддержки. Он не позволяет боту-посетителю управлять серверной частью или предоставлять доступ к торговым счетам.
