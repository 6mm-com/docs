## Доступные инструменты соответствуют вашей роли

В таблице описана максимальная поддерживаемая область действия. Ваше приложение AI получает только инструменты, разрешенные для авторизующей учетной записи. Используйте список действующих инструментов и схему его параметров в качестве контракта; новая функция консоли не является автоматически инструментом MCP.

| Консольный модуль | Поддерживаемые операции |
| --- | --- |
| Онлайн-беседы | Чтение сеансов, сообщений и информации об очереди; назначать, присоединяться, брать на себя управление и передавать; отправлять сообщения; приглашать рейтинги; управлять разрешением на загрузку; распознавать/переводить сообщения; загрузить поддерживаемые файлы |
| Билеты и обратная связь | Запрашивать, назначать, обновлять статус и удалять заявки пользователей и отзывы; создавать, читать, обновлять, назначать и удалять билеты агента |
| История разговоров | Сеансы запросов и сообщения; удалить один сеанс или несколько сеансов |
| Управление контентом | Читать и поддерживать категории, статьи, горячие вопросы, категории вопросов, карточки с описанием, объявления и записи самообслуживания; публиковать/отменять публикацию статей |
| Языковой перевод | Читать источники, переводы и статус завершения; сохранить или удалить поддерживаемые переводы; вызвать автоматический перевод; управлять настройками поддерживаемого языка |
| Конфигурация бота | Читайте поддерживаемые настройки и часто задаваемые вопросы, сохраняйте похожие вопросы, проверяйте ответы, проверяйте статус извлечения, обновляйте индексы и перестраивайте векторы. |
| Управление агентами | Поддержка поддерживаемых агентов, ролей и быстрых ответов |
| Системные настройки | Чтение/запись полей разрешенного внешнего вида, копирования, разговора, входа для посетителей, интеллектуальных услуг и разрешенного списка веб-сайтов. |
| Статистика | Доступный только для чтения обзор и поддерживаемые статистические запросы |
| Использование и выставление счетов | Доступный только для чтения баланс, использование, транзакции и цены |
| Журналы операций | Список и подробные сведения о операциях, доступных только для чтения. |

## Пишет и подтверждает

Удаление, публикация/отмена публикации, редактирование опубликованных статей, отправка сообщений, управление ролями/учетными записями, изменение белого списка веб-сайтов, векторная перестройка и автоматический перевод платформы требуют подтверждения со стороны серверной части, если это указано в инструменте. Запись без подтверждения все равно может немедленно изменить данные; просмотрите предполагаемую область действия, прежде чем просить ИИ выполнить ее.

MCP не обеспечивает администрирование платформы, закрытие/удаление арендатора, пополнение баланса, редактирование счетов или доступ к секрету провайдера. Файловые инструменты обеспечивают проверку формата и ограничение развернутого размера; текущая реализация поддерживает один файл размером до 10 МБ через Base64. Используйте консоль для файлов большего размера, если это позволяют ее собственные ограничения.

## Примеры задач

- Перечислите недостающие переводы и набросайте версии на японском языке, сохраняя при этом ссылки и объемы.
- Находите неразрешенные заявки пользователей и предлагайте задания, еще не применяя их.
- Создайте черновик статьи базы знаний в существующей категории, затем отобразите ее заголовок и идентификатор.
- Обобщите недавнюю статистику поддержки с указанием точного диапазона дат.

Платформа искусственного интеллекта, автоматический перевод и векторные операции могут потребовать существующей платы за обслуживание. Собственное использование подключенного поставщика искусственного интеллекта является отдельным.
