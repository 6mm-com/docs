## Выберите правильную запись

Откройте **Управление билетами** и выберите соответствующую вкладку.

| Записывать | Цель |
| --- | --- |
| Билет агента | Работа создается и поддерживается командой поддержки |
| Билет пользователя | Вопрос, отправленный посетителем для дальнейшего рассмотрения |
| Отзывы пользователей | Предложение или проблема, отправленная через запись отзыва. |

<span id="handle-a-case" data-sixmm-canonical-anchor="handle-a-case" aria-hidden="true"></span>

## Разобраться с делом

Прочтите описание, контактные данные, соответствующий разговор и вложения, доступные в записи. Назначьте его соответствующему обработчику и обновляйте статус по мере выполнения работы. Используйте поддерживаемые элементы управления редактированием билетов агентов; Заявки пользователей и отзывы имеют свои собственные доступные действия.

Обновление статуса само по себе не доказывает, что посетитель получил электронное письмо или ответ в чате. При необходимости отправьте ответ по доступному каналу связи и проверьте результат. Храните личную информацию в рамках авторизованного рабочего процесса арендатора.

<span id="use-mcp-for-triage" data-sixmm-canonical-anchor="use-mcp-for-triage" aria-hidden="true"></span>

## Используйте MCP для сортировки

Попросите подключенный ИИ составить список нерешенных случаев, сгруппировать их по проблемам и подготовить предлагаемый ответ. Просмотрите назначения и изменения статуса, прежде чем применять их к реальным делам. Создание билета агента и отправка билета пользователя — это разные рабочие процессы; инструмент для одного не означает, что он поддерживает другой. Удаление заявки через MCP требует подтверждения.
