## Скопируйте код интеграции клиента

Откройте **Настройки системы → Интеграция с веб-сайтом**. Настройте разрешенные домены веб-сайтов и скопируйте сгенерированный код. Ключ приложения идентифицирует вашего арендатора; это не пароль для входа или секрет подписи личности. Виджет поддержки клиентов отделен от Trading Widget SDK.

Ниже показаны поддерживаемые атрибуты сценария. Замените заполнитель ключом приложения вашего клиента и используйте сценарий URL, созданный вашей консолью.

```html
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"></script>
```

Для существующей кнопки:

```html
<button id="support-button">Contact support</button>
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"
        data-trigger="#support-button"></script>
```

## Личность посетителя

| Режим | Ответственность за интеграцию |
| --- | --- |
| Анонимный посетитель | Используйте настроенную запись посетителя арендатора; система идентифицирует посетителя браузера |
| Вошедший пользователь | Создайте токен удостоверения на своем сервере и передайте стабильный идентификатор пользователя и подписанный токен, используя пример консоли. |

Поддерживаемые атрибуты для входа в систему: <code>data-user-id</code> и <code>data-user-token</code>. Храните подпись в секрете на своем сервере; не вставляйте его в HTML, мобильный код или подсказку AI. Используйте точный формат токена и срок его действия, указанные в консоли.

Для приложения или WebView используйте режим входа и интеграции, предусмотренный для вашего клиента. Тестируйте навигацию, аутентификацию, выбор файлов и поведение области просмотра на реальном устройстве; фрагмент веб-сайта сам по себе не обеспечивает встроенную поддержку SDK.

## Подтвердить запись

Проверьте разрешенные домены, язык, светлую/темную тему, открытие и закрытие, тестовое сообщение, человеческую поддержку и отправку заявок. При переключении пользователей веб-сайта убедитесь, что идентификатор, переданный в виджет, принадлежит текущему пользователю. Если виджет не открывается, проверьте ключ приложения, загрузку скрипта, настройки домена и доступность службы клиента.
