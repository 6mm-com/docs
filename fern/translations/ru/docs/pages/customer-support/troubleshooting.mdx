## Поддержка консоли и посетителей

| Симптом | Сначала проверьте |
| --- | --- |
| Меню отсутствует | Роль учетной записи и доступность службы клиента |
| Виджет не открывается | Сгенерированный скрипт URL, ключ приложения, разрешенные ошибки домена и браузера. |
| Бот не использует большую модель | Фактический согласованный шаг, интеллектуальные сервисные переключатели и соответствующая конфигурация. |
| В ответе используются старые правила | Исходная статья, статус публикации, текст FAQ, состояние перевода и поиска. |
| Перевод отсутствует | Целевой язык, переключение перевода, сохраненный перевод и доступность услуги/баланса |
| Генерация вектора не удалась | Доступность услуги и статус получения; избегать повторного восстановления без выявления сбоя |
| Поле контакта пусто | Было ли это поле действительно собрано; различать контактный и входной адрес электронной почты |

## MCP соединение и звонки

| Симптом | Следующий шаг |
| --- | --- |
| Открытие конечной точки в браузере возвращает ошибку | Это конечная точка протокола, а не страница входа; добавьте его в совместимый клиент MCP |
| Авторизация не может начаться | Проверьте точную конечную точку, поддержку Streamable HTTP/OAuth клиента и процесс входа в браузер. |
| Несанкционированное или истекшее соединение | Проверьте отзыв и срок действия; переподключиться через приложение |
| Инструмент отсутствует или доступ запрещен | Проверьте роль авторизующей учетной записи и область записи; обновить список инструментов |
| Ожидает одобрения | Откройте возвращенную ссылку для утверждения и просмотрите ее в серверной части. |
| Содержание изменено | Прочтите последнюю запись, просмотрите еще раз и отправьте новую запланированную операцию. |
| Время запроса истекло | Запрашивайте статус операции перед повторной попыткой или предположением об ошибке |
| Нет журнала записи | Различайте чтение, ожидание утверждения и завершенную запись; проверьте фильтры в журналах операций |

## Прежде чем обращаться в службу поддержки

Соберите время и часовой пояс, затронутого клиента/учетную запись, имя страницы или инструмента, идентификатор операции, если он доступен, и точную ошибку. Включите отредактированный снимок экрана или инструкции по его воспроизведению. Не отправляйте пароли, коды подтверждения, токены на предъявителя или секреты подписи.

Попробуйте выполнить небольшую тестовую запись при диагностике записи. Проверьте результат и очистите только созданные вами тестовые данные, используя при необходимости обычный процесс подтверждения.
