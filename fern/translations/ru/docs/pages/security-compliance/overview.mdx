## Документационная карта

| Площадь | Назначение |
| --- | --- |
| Архитектура безопасности | Поймите, как защищены торговая инфраструктура, доступ к API/SDK и операции партнёров. |
| API и webhook безопасности | Защищайте интеграции с бэкендом с помощью подписи, секретного хранения и идемпотентной обработки. |

## Рекомендуемый порядок чтения

1. Начните с архитектуры безопасности и границы ответственности партнера.
2. Проверьте управление API Key , подписание запросов и идемпотентность вебхука перед интеграцией с бэкендом.
3. Проверьте обзор соответствия и лицензионную поддержку перед подготовкой к региональному запуску.
4. Ознакомьтесь с юридическими страницами и чек-листом запуска перед тем, как раскрывать возможности торговли пользователям.
