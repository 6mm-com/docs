Прогнозирование использует счет финансирования. Его зарезервированная доля представлена ​​в виде замороженных по прогнозу средств на этом счете, а не в виде дополнительного независимого счета активов.

<span id="balance-components" data-sixmm-canonical-anchor="balance-components" aria-hidden="true"></span>

## Компоненты баланса

| Компонент | Значение |
| --- | --- |
| Баланс финансирования | Баланс счета, содержащий доступные и замороженные по прогнозу средства в этой модели. |
| Доступный баланс | Средства, доступные в настоящее время для разрешенных новых действий |
| Прогнозирование замороженного баланса | Средства, зарезервированные для заказов на прогнозирование в ожидании финансового решения |
| Ожидаемая выплата | Потенциальная сумма результата; нет текущих свободных средств |

В рамках модели прогнозируемого баланса баланс финансирования равен доступному балансу плюс замороженному балансу прогнозирования. Другие ограничения учетной записи следует проверять отдельно там, где они отображаются.

<span id="reservation-example" data-sixmm-canonical-anchor="reservation-example" aria-hidden="true"></span>

## Пример резервирования

Предположим, что доступно 1000 USDT и нет резервирования прогнозирования или других перемещений. Если заказ на 100 USDT принят и зарезервирован, доступные средства станут 900 USDT, а замороженные прогнозом средства станут 100 USDT. Резервирование суммы не создает еще 100 USDT активов.

Окончательный расчет изменяет счет в соответствии с записанным результатом. Видеть [Выплаты и PnL](/ru/prediction/returns-pnl) для суммы результата.

<span id="avoid-double-counting" data-sixmm-canonical-anchor="avoid-double-counting" aria-hidden="true"></span>

## Избегайте двойного счета

Не добавляйте средства, замороженные по прогнозу, поверх баланса финансирования, который уже содержит их. Аналогично, не считайте ожидаемые выплаты по отложенным ордерам реализованными активами.

Средства на спотовых или бессрочных счетах не должны считаться доступными для прогнозирования до тех пор, пока не будет завершен соответствующий поддерживаемый перевод. Видеть [Переводы и транзакции](/ru/prediction/transfers-ledger).
