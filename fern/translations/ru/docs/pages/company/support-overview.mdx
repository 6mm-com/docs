6MM поддержка предназначена для авторизованных партнёров, активных интеграций и производственных операций. Поддержка конечных пользователей остаётся ответственностью партнёрской платформы, если это не согласовано отдельно.

<h2 id="choose-the-right-path">Выберите правильный путь</h2>

| Положение | Рекомендуемый путь | Включайте |
| --- | --- | --- |
| Оценка нового партнёрства или решения | Путь адаптации партнёров | Тип продукта, целевой регион, сроки запуска, ожидаемая модель интеграции. |
| SDK, API, вебхук или вопрос о окружении | Путь технической поддержки | Конечная точка, SDK версия, идентификатор запроса, шаги воспроизведения, логи. |
| Производственный инцидент или ухудшение торгового потока | Путь эскалации инцидента | Область воздействия, время начала, затронутые пользователи, идентификаторы заказов, текущие меры смягчения. |
| Изменение материала для актива, копирования или запуска | Путь поддержки операций | Страница, язык, запрошенные изменения, дата запуска, одобрение владельца. |
| Уязвимость или подозрение на насилие | Путь отчётности по безопасности | Технические детали, затронутая конечная точка, доказательства, срочность, актуальность вопроса. |

<h2 id="severity-guide">Руководство по тяжести</h2>

| Степень тяжести | Пример |
| --- | --- |
| Критическое | Производственная торговля, аутентификация, выпуск токенов или связанные потоки средств недоступны. |
| Высокий | Основной поток партнёров ухудшается, но существует обходной путь. |
| Нормальный | Вопрос интеграции, запрос на конфигурацию, проблема с документацией или поддержка запланированного запуска. |

<h2 id="before-contacting-support">Прежде чем обращаться в поддержку</h2>

- Подтвердить затронутую область продукта и окружающую среду.
- Собирать идентификаторы запросов, ID заказов, временные метки, идентификаторы сопоставления пользователей, идентификаторы событий webhook и журналы.
- Используйте шаблон запроса поддержки при решении производственных проблем.
