Yeni bir entegrasyon hazırlarken veya mevcut bir entegrasyonu üretime taşırken bu şablonu kullanın.

<h2 id="partner-information">Ortak bilgileri</h2>

| Saha | Tanım |
| --- | --- |
| Ortak adı | Entegrasyon için kullanılan yasal veya proje adı. |
| Ürün türü | Uygulama, cüzdan, broker portalı, beyaz etiketli borsa, kurumsal platform veya başka bir platform. |
| Birincil temaslar | İş, teknik, operasyon ve acil durum bağlantıları. |
| Fırlatma bölgeleri | Entegrasyonun ortaya çıkacağı ülkeler veya bölgeler. |

<h2 id="technical-information">Teknik bilgiler</h2>

| Saha | Tanım |
| --- | --- |
| Ön uç alanları | Widget veya giriş sayfalarını yükleyecek alan adları. |
| Arka uç alan alanları | Agent SDK veya API çağrıları için kullanılan sunucu alan adları. |
| Webhook URL | Üretim webhook uç noktası ve beklenen IP izin listesi gereksinimleri. |
| Entegrasyon kapsamı | Trading Widget, Agent SDK, REST API, WebSocket, beyaz etiket sistemi veya likidite entegrasyonu. |

<h2 id="operational-information">Operasyonel bilgiler</h2>

- Beklenen fırlatma tarihi.
- Beklenen trafik veya aktif kullanıcı aralığı.
- Destek saatleri ve yükseltme sahibi.
- Sahibi ve olay temasını izlemek.

<h2 id="security-and-review-information">Güvenlik ve inceleme bilgileri</h2>

- Kimlik doğrulama yöntemi ve API Key izin kapsamı.
- Gizli depolama, rotasyon sahibi ve onaylı kaynak IP'ler.
- Webhook imza doğrulama ve kimlik potansiyeli tasarımı.
- Kayıtlama, izleme, uzlaştırma, geri alma ve olay-müdahale sahipleri.
- Hedef pazarlar, kullanıcı türü, saklama modeli ve kullanıcıya yönelik yükümlülüklerden sorumlu kuruluş.

Bu şablona üretim sırları, tam erişim tokenları, özel anahtarlar veya sansürlenmemiş kullanıcı verileri dahil edilmesin.

Kullan [Üretim başlatma kontrol listesi](/tr/resources/production-launch-checklist) nihai onay ve [Destek Talebi Şablonu](/tr/resources/support-request-template) Sorun yükseltmesi için.
