Yangi integratsiyani tayyorlashda yoki mavjud integratsiyani ishlab chiqarishga ko'chirishda ushbu shablondan foydalaning.

<h2 id="partner-information">Hamkorlar haqida ma'lumot</h2>

| Maydon | Tavsif |
| --- | --- |
| Hamkor nomi | Integratsiya uchun ishlatiladigan huquqiy yoki loyiha nomi. |
| Mahsulot turi | Ilova, hamyon, broker portali, oq yorliqli birja, institutsional platforma yoki boshqalar. |
| Asosiy aloqalar | Biznes, texnik, operatsiyalar va favqulodda aloqalar. |
| Uchirish hududlari | Integratsiya fosh bo'ladigan mamlakatlar yoki mintaqalar. |

<h2 id="technical-information">Texnik ma'lumotlar</h2>

| Maydon | Tavsif |
| --- | --- |
| Frontend domenlari | Vidjet yoki kirish sahifalarini yuklaydigan domenlar. |
| Backend domenlari | Server domenlari Agent SDK yoki API qo'ng'iroqlar uchun ishlatiladi. |
| Webhook URL | Ishlab chiqarish webhook endpoint va kutilayotgan IP ruxsat ro'yxati talablari. |
| Integratsiya doirasi | Trading Widget, Agent SDK, REST API, WebSocket, oq yorliq tizimi yoki likvidlik integratsiyasi. |

<h2 id="operational-information">Operatsion ma'lumotlar</h2>

- Kutilayotgan uchish sanasi.
- Kutilayotgan trafik yoki faol foydalanuvchi diapazoni.
- Qo'llab-quvvatlash soatlari va eskalatsiya egasi.
- Egasi va hodisa bilan aloqani nazorat qilish.

<h2 id="security-and-review-information">Xavfsizlik va ko'rib chiqish ma'lumotlari</h2>

- Autentifikatsiya usuli va API Key ruxsat doirasi.
- Maxfiy saqlash, rotatsiya egasi va tasdiqlangan manba IP manzillari.
- Webhook imzosini tekshirish va idempotentlik dizayni.
- Loglar, monitoring, muvofiqlashtirish, orqaga qaytarish va hodisalarga javob berish egalari.
- Maqsadli bozorlar, foydalanuvchi turi, saqlash modeli va foydalanuvchiga qaragan majburiyatlar uchun mas'ul subyekt.

Ushbu shablga ishlab chiqarish sirlari, to'liq kirish tokenlari, shaxsiy kalitlar yoki tahrirlanmagan foydalanuvchi ma'lumotlarini kiritmang.

Yakuniy tasdiqlash uchun [ishlab chiqarish ishga tushirish ro'yxati](/tr/resources/production-launch-checklist) va muammolarni eskalatsiya qilish uchun [qo'llab-quvvatlash so'rovi shabloni](/tr/resources/support-request-template) dan foydalaning.
