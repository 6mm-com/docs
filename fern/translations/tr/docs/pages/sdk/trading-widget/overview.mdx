<h2 id="responsibility-split">Sorumluluk paylaşımı</h2>

| Alan | Sahibi | Notlar |
| --- | --- | --- |
| Konteyner oluşturma | Partner ön uç | Açıkça genişlik ve yükseklikle görünür bir eleman sağla. |
| iframe oluşturma | Trading Widget SDK | SDK iframe'i oluşturur ve yönetir. |
| Ticaret arayüzü | 6MM iframe | K-line, sipariş defteri, sipariş formu, pozisyonlar, siparişler ve hesap verileri iframe içinde çalışır. |
| Ekran kontrolleri | Trading Widget SDK + 6MM iframe | PC gömülü başlığı ve alt ticker varsayılan olarak gizlidir. Ortaklar, kabuk alanlarını göstermek veya üst düzey ticaret konteynerlerini saklamak için `display` kullanabilir. |
| Partner giriş kontrolü | Ortak backend | Kimlik doğrulama bilgileri vermeden önce ortak kullanıcı oturumunu doğrulayın. |
| Embed token ihrayı | Partner backend + Agent API | Partner-token modu için önerilir. |

<h2 id="versioning">Versiyon Düzenleme</h2>

Genel entegrasyon yolu, v1 betiği altında sabit kalır URL. Mevcut v1 yetenek seti partner-token, tokenProvider, entryUrlProvider, display kontrolleri, yaşam döngüsü olayları, örnek yöntemleri ve order olaylarını içermektedir.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Widget ne zaman kullanılmalıdır</h2>

Bir partnerin mevcut bir web ürününde tam bir işlem arayüzüne ihtiyacı olduğunda Trading Widget seçin. Tamamen özel bir işlem arayüzü oluştururken ve sürdürürken REST API ve WebSocket dokümantasyonlarını kullanın.

<h2 id="implementation-path">Uygulama yolu</h2>

1. Takip edin [Trading Widget Hızlı Başlangıç](/tr/sdk/trading-widget/quick-start) betiği yükleyip görünür bir konteyner oluşturmak için.
2. Yapılandır [partner-token doğrulama](/tr/sdk/trading-widget/authentication) Bir partner backend aracılığıyla.
3. Gereklileri ekleyin [Seçenekler ve etkinlikler](/tr/sdk/trading-widget/options-events).
4. Kullanım [örnek yöntemler](/tr/sdk/trading-widget/instance-methods) yaşam döngüsü ve çalışma zamanı kontrolleri için.
