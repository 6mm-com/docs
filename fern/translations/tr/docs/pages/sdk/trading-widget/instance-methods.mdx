## Yöntem Özeti

| Yöntem | Amaç |
| --- | --- |
| tahrip etmek() | iframe'i kaldırın ve olay dinleyicilerini serbest bırakın. |
| getState() | Geçerli SDK yaşam döngüsü durumunu okuyun. |
| whenReady() | iframe'in başlatılması bitene kadar bekleyin. |
| setSymbol(sembol) | İframe içindeki işlem çiftini değiştirin. |
| setTheme(tema) | iframe tema parametresini güncelleyin. |
| setLocale(yerel ayar) | iframe dilini değiştirin. |
| setSize(genişlik, yükseklik) | iframe boyutlarını güncelleyin. |
| yeniden yükle() | Geçerli iframe'i yeniden yükleyin. |
| refreshAuth(sebep) | Widget kimlik doğrulama yenileme akışını tetikleyin. |
| setTokenProvider(sağlayıcı) | İş ortağı belirteci modu tarafından kullanılan sağlayıcıyı değiştirin. |
| on(olay, işleyici) | Çalışma zamanı etkinliklerine abone olun ve abonelikten çıkma işlevi alın. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## tahrip etmek()

Geçerli örnek için iframe'i kaldırın, dinleyicileri temizleyin ve yayının bir kez yok edilmesini sağlayın.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Widget örneğinin mevcut yaşam döngüsü durumunu okuyun.

```js
const state = widget.getState()
```

Dönüş değerleri arasında yükleme, kimlik doğrulama, hazır, hata ve yok etme bulunur.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Bağımlı kullanıcı arayüzü mantığını çalıştırmadan önce iframe'in başlatma işlemini bitirmesini bekleyin.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(sembol)

İframe içindeki işlem çiftini değiştirin. iframe hala başlatılıyorsa, SDK komutu sıraya alır ve hazır olduktan sonra gönderir.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(tema)

Gömülü ticaret iframe'i tarafından kullanılan tema parametresini güncelleyin.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(yerel ayar)

iframe dilini değiştirin. Desteklenen değerler en, en-US ve zh-CN'dir.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(genişlik, yükseklik)

iframe DOM boyutunu güncelleyin ve iframe'i yeni dış boyut hakkında bilgilendirin. Sayısal değerler piksele dönüştürülür.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## yeniden yükle()

Geçerli iframe'i yeniden yükleyin ve yeniden başlatılmasını bekleyin.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(sebep)

iframe'den mevcut kimlik doğrulama akışını yenilemesini isteyin. İsteğe bağlı neden değeri, günlük kaydı ve akış kontrolü için iletilir.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(sağlayıcı)

Ortak belirteç modu tarafından kullanılan tokenProvider'yi değiştirin. iframe yeni bir yerleştirme belirteci istediğinde SDK sağlayıcıyı arar.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(olay, işleyici)

Bir çalışma zamanı etkinliğine abone olun. Döndürülen işlev dinleyiciyi kaldırır.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Geçerli v1 çalışma zamanındaki ek yöntemler

| Yöntem | Amaç |
| --- | --- |
| `whenRendered()` | iframe'in oluşturulan bildirimini bekleyin; bu hazırdan ayrı. |
| `setPage(page)` | Mevcut örnekte desteklenen bir ürün sayfası isteyin. Fon ortamını değiştirmez. |
| `prepareForRecreate()` | Değiştirmeye hazırlanmak için hazır bir iframe isteyin; bir söz verir ve müsait değilse, meşgulse veya zaman aşımına uğramışsa reddedebilir. |
| `cancelRecreate()` | Bekleyen/hazırlanan bir değiştirme akışını iptal edin. |
| `TradingWidget.validateOptions(options)` | Örnek oluşturmadan önce başlatma seçeneklerini doğrulayın. |

Bir kullanıcı veya gerçek/demo ortamı değişikliği için eski örneği yok edin ve hedef kimlik doğrulaması ve moduyla yeni bir tane oluşturun. Ortam anahtarı olarak `setPage` kullanmayın. İsteğe bağlı yöntemleri kullanmadan önce yetenekleri kontrol edin.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
