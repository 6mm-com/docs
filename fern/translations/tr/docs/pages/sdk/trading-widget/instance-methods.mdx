<h2 id="method-summary">Metod qisqacha mazmuni</h2>

| Usul | Maqsad |
| --- | --- |
| destroy() | iframe'ni olib tashlang va event tinglovchilarini ozod qiling. |
| getState() | Joriy SDK hayot sikl holatini o'qing. |
| whenReady() | iframe ishga tushirishni tugatguncha kuting. |
| setSymbol(ramz) | iframe ichidagi savdo juftligini almashtiring. |
| setTheme(mavzu) | iframe mavzu parametrini yangilang. |
| setLocale(joy) | iframe tilini o'zgartiring. |
| setSize(kenglik, balandlik) | iframe o'lchamlarini yangilash. |
| Reload() | Joriy iframeni qayta yuklang. |
| refreshAuth(sabab) | Widget autentifikatsiyasini yangilash jarayonini ishga tushiring. |
| setTokenProvider(provayder) | Partner-token rejimida ishlatiladigan provayderni almashtiring. |
| on(tadbir, boshqaruvchi) | Runtime tadbirlariga obuna bo'ling va obunani bekor qilish funksiyasini oling. |

<h2 id="destroy">destroy()</h2>

iframe'ni olib tashlang, tinglovchilarni tozalang va joriy instansiya uchun bir marta yo'q qilingan emissiyani chiqaring.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Vidjet instansiyasining hozirgi hayot sikl holatini o'qing.

```js
const state = widget.getState()
```

Qaytish qiymatlari yuklash, autentifikatsiya, tayyor, xato va yo'q qilish kabi qiymatlarni o'z ichiga oladi.

<h2 id="whenready">whenReady()</h2>

iframe ishga tushirish tugaguncha kuting, keyin bog'liq UI mantiqini ishga tushiring.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(ramz)</h2>

iframe ichidagi savdo juftligini almashtiring. Agar iframe hali ham ishga tushirilayotgan bo'lsa, SDK buyruqni navbatga qo'yadi va tayyor bo'lgandan keyin yuboradi.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(mavzu)</h2>

O'rnatilgan savdo iframe uchun ishlatiladigan tema parametrini yangilang.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(joy)</h2>

iframe tilini o'zgartiring. Qo'llab-quvvatlanadigan qiymatlar: en, en-US va zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(kenglik, balandlik)</h2>

iframe o' DOM o'lchamini yangilab, iframe'ga yangi tashqi o'lcham haqida xabar bering. Raqamli qiymatlar px ga aylantiriladi.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">Reload()</h2>

Joriy iframeni qayta yuklab, yana ishga tushishini kuting.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(sabab)</h2>

iframe'dan joriy autentifikatsiya oqimini yangilashni so'rang. Ixtiyoriy sabab qiymati log qilish va oqim boshqaruvi uchun uzatiladi.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(provayder)</h2>

Hamkor-token rejimida ishlatiladigan tokenProvider almashtiring. SDK iframe yangi embed tokenini so'raganda provayderga murojaat qiladi.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">on(tadbir, boshqaruvchi)</h2>

Doimiy tadbirga obuna bo'ling. Qaytarilgan funksiya tinglovchini olib tashlaydi.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
