<h2 id="method-summary">Yöntem Özeti</h2>

| Yöntem | Amaç |
| --- | --- |
| yok et() | iframe'i kaldır ve etkinlik dinleyicilerini serbest bırak. |
| getState() | Mevcut SDK yaşam döngüsü durumunu okuyun. |
| whenReady() | iframe başlatmayı tamamlayana kadar bekleyin. |
| setSymbol(sembol) | Ticaret çiftini iframe içinde değiştirin. |
| setTheme(tema) | iframe tema parametresini güncelleyin. |
| setLocale(bölge) | iframe dilini değiştirin. |
| setSize(genişlik, yükseklik) | iframe boyutlarını güncelleyin. |
| reload() | Mevcut iframe'i yeniden yükleyin. |
| refreshAuth(sebep) | Widget auth yenileme akışını tetikle. |
| setTokenProvider(sağlayıcı) | Partner-token modunda kullanılan sağlayıcıyı değiştirin. |
| On(etkinlik, yönetici) | Çalışma süresi etkinliklerine abone olun ve abonelikten çıkma fonksiyonu alın. |

<h2 id="destroy">yok et()</h2>

iframe'i kaldırın, dinleyicileri temizleyin ve mevcut örnek için bir kez yok edilmiş yayımlayın.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Widget örneğinin mevcut yaşam döngüsü durumunu okuyun.

```js
const state = widget.getState()
```

İade değerleri arasında yükleme, doğrulama, hazır, hata ve yok etme bulunur.

<h2 id="whenready">whenReady()</h2>

Bağımlı UI mantığı çalıştırmadan önce iframe'in başlatmayı tamamlamasını bekleyin.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(sembol)</h2>

Ticaret çiftini iframe içinde değiştirin. iframe hâlâ başlatılıyorsa, SDK komutu sıraya alır ve hazır olduğunuzda gönderir.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(tema)</h2>

Gömülü işlem iframe'i tarafından kullanılan tema parametresini güncelleyin.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(bölge)</h2>

iframe dilini değiştirin. Desteklenen değerler en, en-US ve zh-CN'dir.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(genişlik, yükseklik)</h2>

iframe'in DOM boyutunu güncelleyin ve iframe'e yeni dış boyut hakkında bilgi verin. Sayısal değerler px'e dönüştürülür.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">reload()</h2>

Mevcut iframe'i yeniden yükleyin ve tekrar başlatılmasını bekleyin.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(sebep)</h2>

iframe'den mevcut kimlik doğrulama akışını yenilemesini iste. Isteğe bağlı neden değeri ise logetme ve akış kontrolü için yönlendirilir.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(sağlayıcı)</h2>

Partner-token modunda kullanılan tokenProvider değiştirilir. SDK , iframe yeni bir gömme belirteçeği talep ettiğinde sağlayıcıyı arar.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">On(etkinlik, yönetici)</h2>

Bir süreli etkinlik etkinliğine abone olun. Geri dönen fonksiyon dinleyiciyi çıkarır.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
