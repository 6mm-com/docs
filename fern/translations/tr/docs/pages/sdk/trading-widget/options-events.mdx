## Ekran kontrolleri

`display` , gömülü ticaret sayfası kabuğunu ve üst düzey konteynerleri kontrol eder. Ortak gömülerde, PC başlığı ve alt pazar ticker'ı varsayılan olarak gizlidir.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Saha | Tip | Varsayılan | Notlar |
| --- | --- | --- | --- |
| showHeader | boolean | yanlış | PC gömülü başlığını iframe içinde gösterip göstermemediği. |
| showTicker | boolean | yanlış | Gömülü kabuğunda alt piyasa ticker'ını gösterip göstermememe. |
| gizli | String[] | [] | Yüksek seviyeli konteynerleri ticaret sayfasında saklar. |

Desteklenen `display.hidden` değerleri:

| Değer | Konteyner |
| --- | --- |
| Harita | Harita konteyneri |
| orderBook | Sipariş defteri konteyneri |
| orderForm | Sipariş formu paneli |
| Pozisyonlar | Alt pozisyonlar ve açık emirler paneli |
| hesap | Hesap varlıkları konteyneri |

`display.hidden` sadece tüm kapları saklar. Tek tek düğmeleri, alanları veya araçları bir konteyner içinde saklamaz. Mevcut görünüm penceresine eşlenmeyen değerler göz ardı edilir.

## Etkinlikler

| Etkinlik | Tetikleyici |
| --- | --- |
| Hazır | iframe başlatma tamamlandı. |
| hata | SDK, iframe veya kimlik doğrulama hatası. |
| state_changed | SDK yaşam döngüsü durumu değişti. |
| auth_state_changed | partner-token doğrulama durumu değiştirildi. |
| symbol_changed | Gerçek iframe sembolü değişti. |
| locale_changed | Gerçek iframe konumu değişti. |
| order_created | Kullanıcı iframe içinde bir sipariş oluşturdu. |
| order_failed | Sipariş gönderimi başarısız oldu. |
| yok edildi | SDK örnek yok edildi. |
