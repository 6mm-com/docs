<h2 id="display-controls">Displey boshqaruvlari</h2>

`display` o'rnatilgan savdo sahifasi qobig'i va yuqori darajadagi konteynerlarni boshqaradi. Hamkor joylashtirishlarda PC sarlavhasi va pastki bozor tickeri standart tarzda yashirilgan bo'ladi.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Maydon | Turi | Standart | Izohlar |
| --- | --- | --- | --- |
| showHeader | boolean | yolg'on | PC embed headerini iframe ichida ko'rsatish kerakmi, yoki yo'qmi. |
| showTicker | boolean | yolg'on | Pastki bozor tickerini embed shellda ko'rsatish kerakmi, yoki yo'qmi. |
| yashirin | String[] | [] | Savdo sahifasida yuqori darajadagi konteynerlarni yashiradi. |

Qo'llab-quvvatlanadigan `display.hidden` qiymatlari:

| Qiymat | Konteyner |
| --- | --- |
| Chart | Chart konteyneri |
| orderBook | Buyurtma kitobi konteyneri |
| orderForm | Buyurtma shakli paneli |
| Lavozimlar | Pastki pozitsiyalar va ochiq buyurtmalar paneli |
| hisob | Hisob aktivlari konteyneri |

`display.hidden` faqat butun konteynerlarni yashiradi. U konteyner ichidagi alohida tugmalar, maydonlar yoki vositalarni yashirmaydi. Joriy ko'rinish oynasiga mos kelmaydigan qiymatlar e'tiborga olinmaydi.

<h2 id="events">Tadbirlar</h2>

| Tadbir | Trigger |
| --- | --- |
| Tayyor | iFrame ishga tushirilishi yakunlandi. |
| xato | SDK, iframe yoki autentifikatsiya xatosi. |
| state_changed | SDK hayot aylanishi holati o'zgardi. |
| auth_state_changed | sherik-token autentifikatsiya holati o'zgartirildi. |
| symbol_changed | Haqiqiy iframe belgisi o'zgardi. |
| locale_changed | Haqiqiy iframe joyi o'zgardi. |
| order_created | Foydalanuvchi iframe ichida buyurtma yaratdi. |
| order_failed | Buyruq topshirilishi muvaffaqiyatsiz bo'ldi. |
| Yo'q qilingan | SDK holat yo'q qilindi. |
