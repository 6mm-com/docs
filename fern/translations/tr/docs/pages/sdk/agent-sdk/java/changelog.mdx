Bu kılavuz **Agent Java SDK `v0.3.0`**, Java 8+ ve etiketli kamu sözleşmesini hedefler. Örnekler, `client` başlatıldıktan sonra bir iş ortağı arka ucunda çalıştırılır. [Hızlı Başlangıç](/tr/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Altı sürekli sorgu: mevcut siparişler, sipariş geçmişi, dolumlar, mevcut pozisyonlar, pozisyon geçmişi ve hesap defteri.
- Finansman bakiyeleri, transferler, kurtarma sorguları ve Finansman/Sözleşme transferleri.
- Desteklenen fon talepleri için açık üretim/simüle edilmiş seçim.
- Saniyeler içinde ticaret yönlendirme ve yerleştirme kılavuzları, yanıt alanı referansı ve geçiş talimatları.

Java SDK ve Trading Widget SDK'in bağımsız sürümleri vardır. `v1` Widget'ı URL, Java SDK sürümü `0.3.0` değil.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Mevcut entegrasyonlar

Kullanıcı eşlemelerini, orijinal siparişlerini ve kimlik bilgilerini koruyun. Çıkarılan ortam alanları mevcut üretim davranışını korur. Finansman, açık simüle edilmiş fonlar ve altı sürekli sorgu, ilgili yeni modelleri ve yöntemleri gerektirir. Gözden geçirmek [Yükseltme kılavuzu](/tr/sdk/agent-sdk/java/upgrade) Mevcut bir entegrasyonu değiştirmeden önce.
