## Çalışma süresi

| Madde | Değer |
| --- | --- |
| Minimum Java versiyonu | Java 8+ |
| Önerilen derleme aracı | Maven 3.9+ |
| Maven grubu | `com.sixmm.exchange.sdk` |
| Maven eseri | `agent` |
| Belgelenmiş kaynak etiketi | `v0.1.1` |

Halka açık GitHub deposu kaynak barındırma yöntemidir, Maven bağımlılık deposu değil. Etiketlenmiş kaynağı yerel olarak oluşturup kurun veya onaylanmış eseri takım derlemelerinde kullanmadan önce kuruluşunuzun özel Maven deposunda yayınlayın.

## Tipik arka uç sorumlulukları

- Ortak kullanıcı oturumunu doğrulayın.
- Ortak kullanıcıyı agentUserIdile eşleyin.
- İlk işlem veya transfer akışlarından önce call bind.
- Tek seferlik tam saha SSOiçin createEntryUrl arayın.
- createEmbedToken Trading Widget partner token modu için çağrılın.
- Transfer webhooks doğrulayın ve onları aynı şekilde işleyin.

<span id="security-and-operational-rules" data-sixmm-canonical-anchor="security-and-operational-rules" aria-hidden="true"></span>

## Güvenlik ve operasyonel kurallar

- `apiSecret` yalnızca bir arka uç gizli yöneticisinde veya korunan ortam değişkeninde depolayın.
- Sunucu zamanını senkronize tutmak, çünkü imzalanan istekler zaman damgaları içerir.
- `agentOrderNo` dayanıklı bir ikamet anahtarı olarak ele alın ve küresel olarak benzersiz tutulur.
- `platformUserId` bir dizi olarak depolayıp `agentUserId`ile ilişkisini sürdürebilir.
- Zaman aşımından veya ağ sonucundan sonra tekrar denemeden önce orijinal transferi sorgulamak.
