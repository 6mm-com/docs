<h2 id="runtime">Davomiyligi</h2>

| Element | Qiymat |
| --- | --- |
| Minimal Java versiyasi | Java 8+ |
| Tavsiya etilgan qurilish vositasi | Maven 3.9+ |
| Maven guruhi | `com.sixmm.exchange.sdk` |
| Maven artefakti | `agent` |
| Hujjatlashtirilgan manba tegi | `v0.1.1` |

Ommaviy GitHub repozitoriyasi manba xostiri bo'lib, Maven bog'liqlik ombori emas. Teglangan manbani mahalliy ravishda quring va o'rnating yoki tasdiqlangan artefaktni jamoaviy qurilishlarda ishlatishdan oldin tashkilotingizning shaxsiy Maven omboriga chop eting.

<h2 id="typical-backend-responsibilities">Oddiy orqa tizim mas'uliyatlari</h2>

- Hamkor foydalanuvchi sessiyasini tasdiqlang.
- Hamkor foydalanuvchini agentUserIdbilan xaritalang.
- Call bind birinchi savdo yoki transfer oqimlaridan oldin.
- createEntryUrl bir martalik to'liq sayt uchun SSOqo'ng'iroq qiling.
- Hamkor-token rejimi uchun createEmbedTokenTrading Widget chaqiring.
- Transfer webhooklarini tekshirish va ularni idempotal tarzda qayta ishlash.

<h2 id="security-and-operational-rules">Xavfsizlik va operatsion qoidalar</h2>

- `apiSecret` faqat backend maxfiy menejeri yoki himoyalangan muhit o'zgaruvchisida saqlanadi.
- Server vaqtini sinxronlashtiring, chunki imzolangan so'rovlar vaqt tamg'alarini o'z ichiga oladi.
- `agentOrderNo` bardoshli idempotensiya kaliti sifatida qarash va uni global miqyosda noyob saqlash.
- `platformUserId` satr sifatida saqlang va uning `agentUserId`bilan munosabatini davom ettiring.
- Vaqt tugashi yoki tarmoq natijasi noaniq bo'lgandan so'ng asl uzatishni qayta urinishdan oldin so'rov qilish.
