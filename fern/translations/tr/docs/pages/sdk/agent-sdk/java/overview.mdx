Bu kılavuz **Agent Java SDK `v0.3.0`**, Java 8+ ve etiketli kamu sözleşmesini hedefler. Örnekler, `client` başlatıldıktan sonra bir iş ortağı arka ucunda çalıştırılır. [Hızlı Başlangıç](/tr/sdk/agent-sdk/java/quick-start).

## Yapılandırma

Aşağıdaki değerleri önce 6MM'den alın
entegre.

| Öğe | Örnek | Tanım |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | Ajan API tabanı URL, sonunda eğik çizgi olmadan |
| `agentCode` | `AGENT001` | İş ortağı kodu |
| `apiSecret` | `your-api-secret` | API imzalama sırrı. Yalnızca arka uçta tutun |
| `defaultCurrency` | `USDT` | Varsayılan para birimi, genellikle `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | 6MM geri aramaları için iş ortağı uç noktası |

Üretim önerileri:

- Aracı API ve webhook uç noktaları için HTTPS kullanın.
- `apiSecret`'ı bir gizli yöneticide, yapılandırma merkezinde veya ortam değişkeninde saklayın.
- Sunucu zamanını tercihen NTP ile senkronize tutun.
- Tüm iş ortağı sipariş numaralarını koruyun ve bunları dünya çapında benzersiz tutun.
- Tarayıcılara, uygulamalara, mini programlara veya ön uç kaynak koduna asla `apiSecret` göndermeyin.

## Otomatik İmzalama Alanları

İmzalı Temsilci API çağrıları için, SDK otomatik olarak şunu enjekte eder:

| Alan | Kaynak | Tanım |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | İş ortağı kodu |
| `timestamp` | Geçerli UTC Unix zaman damgası | Saniye |
| `nonce` | Güvenli rastgele oluşturucu | Tekrar koruması |
| `sign` | HMAC-SHA256 | İmza iste |
| `currency` | `defaultCurrency` | Transfer/hesap isteklerinde para birimi çıkarıldığında doldurulur |

İmza kuralları:

1. `sign`'ı hariç tut.
2. Boş değerleri hariç tutun.
3. Anahtarları ASCII sırasına göre sıralayın.
4. `k=v&k2=v2` olarak katılın.
5. HMAC-SHA256 hex'i `apiSecret` ile hesaplayın.

Dizi değerleri, imzalama yüküne katılmadan önce kompakt JSON olarak serileştirilir. Örneğin, `platformUserIds`, `["1188041528"]` olarak işaretler ve `k=v` yükünde `platformUserIds=["1188041528"]` verir. Dizi öğesi sırasını, çift tırnakları ve dize kimliklerini koruyun; biçimlendirme boşlukları eklemeyin veya Java `List.toString()` (`[1188041528]` gibi) kullanmayın. SDK bu serileştirmeyi otomatik olarak gerçekleştirir.

Normal iş kodu imzaları hesaplamamalı veya manuel olarak ayarlanmamalıdır
`agentCode`, `timestamp`, `nonce` veya `sign`.
