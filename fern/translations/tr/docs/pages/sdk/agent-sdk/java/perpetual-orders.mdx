## Örnek önkoşullar

Java parçacıkları bu içe aktarmaları paylaşır. Hızlı Başlangıç'ı kullanarak `client`'ı başlatın ve kaydedilen bağlamadan `platformUserId`'i edinin. Örnek kullanıcı/sipariş kimlikleri kendi kalıcı değerlerinizle değiştirilmelidir.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## `listCurrentPerpetualOrders`

Talep modeli: `CurrentPerpetualOrdersRequest`.

```java
import com.sixmm.agent.model.CurrentPerpetualOrdersRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

CurrentPerpetualOrdersRequest request = new CurrentPerpetualOrdersRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.orderCategory = "NORMAL";
request.symbol = "BTCUSDT";
PerpetualResponse response = client.listCurrentPerpetualOrders(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

<span id="request-fields" data-sixmm-canonical-anchor="request-fields" aria-hidden="true"></span>

### Talep alanları

| Alan | Java türü | Gerekli | Anlam |
| --- | --- | --- | --- |
| `orderCategory` | `String` | Evet | NORMAL veya CONDITIONAL; koşullu sorgular açık kullanıcılar gerektirir. |
| `platformUserIds` | `java.util.List<String>` | Koşullu | 1-100 benzersiz genel kimlik; Dolumlar ve koşullu siparişler için gereklidir. Doğrudan oynatıcı kapsamı için desteklenen sorguları hariç tutun; [] geçersiz. |
| `symbol` | `String` | HAYIR | İsteğe bağlı işlem çifti filtresi. |
| `limit` | `Integer` | HAYIR | Varsayılan 500; 1–1000. |
| `cursor` | `String` | HAYIR | Döndürülen nextCursor öğesini değişmemiş filtrelerle kullanın; hasMore yanlış olduğunda dur. |

Örnek bir sayfayı okuyor. Gerekli alanlar, oynatıcı kapsamı, filtre semantiği, limit, imleç ve sınırlı yeniden denemeler için aşağıdaki adımları izleyin [Sorguya genel bakış](/tr/sdk/agent-sdk/java/perpetual-queries). Sayfalama sırasında tüm filtreleri değiştirmeden tutun; Bir hatayı boş bir sonuç olarak yorumlamayın.

## `listPerpetualOrderHistory`

Talep modeli: `PerpetualOrderHistoryRequest`.

```java
import com.sixmm.agent.model.PerpetualOrderHistoryRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

PerpetualOrderHistoryRequest request = new PerpetualOrderHistoryRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.orderCategory = "NORMAL";
request.symbol = "BTCUSDT";
request.endTime = System.currentTimeMillis();
request.startTime = request.endTime - 3_600_000L;
PerpetualResponse response = client.listPerpetualOrderHistory(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

## Sıradan siparişler: mevcut ve geçmiş

Güncel: `orders/current` + `orderCategory=NORMAL`; Geçmiş: `orders/history` + `orderCategory=NORMAL`.

| `data` alanı | tip | Uygulamanın anlamı ve kapsamı |
| --- | --- | --- |
| `symbol` | string | Ticaret çifti, örneğin BTCUSDT |
| `orderId` | string | Platform olağan sipariş kimliği |
| `orderCategory` | string | Düzeltildi NORMAL |
| `clientOrderId` | string | İşlem emri kaynağı tarafından sağlanan müşteri sipariş numarası; ticari fon transferi ile aynı alan değildir agentOrderNo |
| `orderType` | string | Temsilci türü, örneğin LIMIT, MARKET; gerçek numaralandırma değeri geçerli olacaktır |
| `side` | string | Alış ve satış yönü BUY / SELL |
| `status` | string | Olağan sipariş durumu, sorguya genel bakışa bakın |
| `timeInForce` | string | Geçerlilik süresi/anlaşma yürütme stratejisi, örneğin GTC, IOC, FOK; gerçek değerlere göre yorumlanır |
| `price` | string | emanet edilen fiyat; Fiyat verilmediği ve piyasa işlem fiyatının kendisi tarafından tamamlanmayacağı durumlarda bu bilgi atlanabilir. |
| `quantity` | string | Orijinal sipariş miktarı |
| `filledQuantity` | string | İşlem miktarı |
| `remainingQuantity` | string | İşlem yapılmamış miktar; geçerli sorgu miktarı - filledQuantity alır ve geçmiş sorgu geçmiş kayıt değerini alır |
| `avgFilledPrice` | string | Tamamlanan parçanın ortalama işlem fiyatı; tamamlanmadığında hiçbir değeri olmayabilir |
| `reduceOnly` | boolean | Yalnızca pozisyonların azaltılıp azaltılmayacağı |
| `closeOnly` | boolean | Yalnızca pozisyon kapatmak için kullanılıp kullanılmadığı |
| `makerOnly` | boolean | Yalnızca Maker olarak yürütülüp yürütülmeyeceği |
| `leverage` | integer | Birden fazla yararlanın; **Geçmişteki olağan düzenin** bir kaynağı vardır ve mevcut olağan düzen bu değeri yaratmaz |
| `marginMode` | string | Marj modu; **Geçmişteki olağan sıralama** şu anda "1", "2" gibi sayısal bir numaralandırma dizesi döndürmektedir; mevcut olağan sipariş sağlanmıyor |
| `createdAt` | integer | Sipariş oluşturma süresi, milisaniye; geçmiş sipariş zamanını filtrelemek için bu alanı kullanın |
| `updatedAt` | integer | Delege kaydı güncelleme süresi, milisaniye |

Sipariş geçmişi, sonlandırılan olağan siparişleri içerir. Her kayıt, yalnızca arayüz adına dayalı olarak tam olarak tamamlanmış sayılamaz. Mevcut sipariş sayfası bir sipariş olayı akışı değil, mevcut bir durum sorgusudur.

## Koşullu emirler: güncel ve geçmiş

Güncel: `orders/current` + `orderCategory=CONDITIONAL`; Geçmiş: `orders/history` + `orderCategory=CONDITIONAL`. Her ikisi de açık platformUserIds gerektirir.

| `data` alanı | tip | Anlam |
| --- | --- | --- |
| `symbol` | string | ticaret çifti |
| `conditionId` | string | Sıradan orderId'dan bağımsız, koşullu sipariş kimliği |
| `orderCategory` | string | Düzeltildi CONDITIONAL |
| `generatedOrderId` | string | Tetiklemeden sonra oluşturulan sıradan sipariş kimliği; oluşturulmadıysa ihmal edilebilir |
| `clientOrderId` | string | Koşullu siparişlerin müşteri sipariş numarası, mevcut olduğunda çıktı |
| `side` | string | BUY / SELL |
| `orderType` | string | Tetikleme sonrası emir türü, gerçek değere göre yorumlanır |
| `triggerType` | string | Gerçek kaynak numaralandırmasıyla açıklanan tetikleyici kural türü |
| `workingType` | string | Fiyatı tetikleyen iş türü/fiyat kaynağı, gerçek numaralandırma olarak yorumlanır |
| `timeInForce` | string | Emrin tetiklendikten sonraki geçerlilik süresi/yürütme stratejisi |
| `price` | string | Tetiklendikten sonraki emir fiyatı, kaynak değere sahip olduğunda çıktı |
| `quantity` | string | Koşullu sipariş miktarı |
| `triggerPrice` | string | tetik fiyatı |
| `reduceOnly` | boolean | Yalnızca pozisyonların azaltılıp azaltılmayacağı |
| `closePosition` | boolean | Tam konum kapatma anlambiliminin kullanılıp kullanılmayacağı, aynı alan olarak closeOnly ile karıştırılamaz |
| `leverage` | integer | Birden fazla yararlanın, sıfır olmadığında çıktı alın |
| `marginMode` | string | Bu sınıf, sıradan tarihsel sıralardan/konumlardan farklı bir sayısal dize olan CROSS / ISOLATED değerini döndürür |
| `status` | string | Koşullu tek tetikleme durumu, sorguya genel bakışa bakın |
| `triggerStatus` | string | Mevcut uygulama durumla aynı koşullu durum değerini kullanıyor |
| `createdAt` | integer | Koşullu sipariş oluşturma süresi, milisaniye; tarihsel koşullar bu zamana göre filtrelenir |
| `updatedAt` | integer | Güncelleme süresi, bir değer olduğunda çıktı, milisaniye |
| `deletedAt` | integer | İşaret süresini sil, bir değer olduğunda çıktı, milisaniye; birleşik bir işlem/iptal zamanı alanı değildir |

Koşullu emirler, sıradan emirler için filledQuantity, remainingQuantity, avgFilledPrice sağlamaz. Tetikleme sonrasında olağan emirlerin işlem durumuna ihtiyacınız varsa, sıradan emirleri/işlemleri generatedOrderId aracılığıyla sorgulayın ve işlem hacmini koşullu emir durumundan çıkarmayın.
