## Doğrudan Giriş URL

Doğrudan giriş URL yönlendirme modu içindir. Bir iş ortağı kullanıcısı,
ortak sitesi, 6MM ön ucunu açar ve otomatik olarak oturum açılır.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Alan kuralları:

| Alan | Tanım |
| --- | --- |
| `redirectPath` | 6MM ön uç göreli yolu. `/` ile başlamalıdır, örneğin `/trade/BTCUSDT` |
| `returnUrl` | Kullanıcı 6MM ön uçtan çıktığında iş ortağı mutlak değeri URL kullanılır. Yalnızca `http` ve `https`'ye izin verilir |
| `expireAt` | Saniye cinsinden Unix zaman damgası olarak giriş bileti son kullanma süresi |

Güvenlik gereksinimleri:

- `webUrl` tek seferlik bir bilet içerir. Hemen kullanın ve uzun süre saklamayın.
- URL girişinin süresi dolarsa veya kullanılmışsa, ortak siteden yeni bir giriş oluşturun.
- `returnUrl`, `javascript:`, göreceli bir yol veya kullanıcı bilgisi içeren bir URL olmamalıdır.

## Ürün ve mod seçimi

6MM tarafından sağlanan mevcut ön uç rotasını kullanın. Örneğin `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` veya `/zh-CN/futures/BTCUSDT?tradingMode=real`. Bilet kullanıcının kimliğini doğrular; bir finansman ortamı seçmez veya fonları taşımaz.

Görmek [Saniye ticareti](/tr/sdk/agent-sdk/java/seconds-trading) yönlendirme ve gömülü örnekler için.
