<h2 id="sdk-call">SDK çağrısı</h2>

Ortak kullanıcı oturumunu doğruladıktan sonra arka uçunuzdan gömülü tokenlar oluşturun. Tarayıcı uç noktanızı çağırmalı ve uç noktanız 6MM üzerinden Agent SDKaramalıdır.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Tek seferlik sertifika**
>
> embedToken kısa ömürlü ve tek kullanımdır. Bunu URL sorgu dizisine koymayın.

<h2 id="backend-endpoint-example">Arka uç uç noktası örneği</h2>

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Yalnızca Trading Widget token sağlayıcısının ihtiyaç duyduğu alanları geri gönderin. apiSecret, ham imza alanlarını veya dahili hizmet yapılandırmasını geri göndermeyin.

<h2 id="failure-handling">Arıza yönetimi</h2>

| Durum | Önerilen kullanım |
| --- | --- |
| Kullanıcı oturumu eksik veya süresi dolmuş | Partner uç noktasından 401'i geri gönderin ve kullanıcıya tekrar giriş yapmasını isteyin. |
| Ajan kullanıcısı bağlı değildir | Önce kullanıcıyı bağlayın, sonra token oluşturmayı tekrar deneyin. |
| 6MM geçici bir hata döndürür | Ön yüze tekrar denenebilir bir hata gönderin ve destek için requestId kaydlayın. |
| channelId widget örneğiyle eşleşmiyor | İsteği reddedin ve widget oturumunu yeniden oluşturun. |
