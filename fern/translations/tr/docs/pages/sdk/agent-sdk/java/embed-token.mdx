## Trading Widget Yerleştirme Jetonu

Gömme jetonu Trading Widget SDK `partner-token + tokenProvider` modu içindir.
tarayıcı iş ortağı arka ucunu çağırır ve iş ortağı arka ucu bunu Java SDK olarak adlandırır
bir `embedToken` oluşturmak için.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Entegrasyon gereksinimleri:

- `channelId`, Trading Widget SDK tarafından iletilen değeri kullanmalıdır.
- `symbol` isteğe bağlıdır ve geçerli başlangıç ​​sembolünü taşıyabilir. Bu, token alım satım çifti izin kısıtlaması değildir.
- `embedToken` kısa ömürlü ve tek seferliktir. Bunu URL sorgu dizelerine koymayın.
- İş ortağı ön ucu hiçbir zaman `apiSecret` tutmamalıdır.
- `expireAt`, TTL değil, saniye cinsinden bir Unix zaman damgasıdır.

İş ortağı arka uç uç noktası örneği:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## İş ortağı uç noktası sözleşmesi

İş ortağı oturumunun kimliğini doğrulayın ve `agentUserId` sunucu tarafını türetin. Geçerli Widget'ı kabul edin `channelId`; üst düzey `embedToken`, `expireAt` (Unix saniye) ve aynı `channelId` değerini döndür. Temsilci yanıtları `channelId` sağlamaz: arka ucunuz bunu yansıtır. Başlatma ve yenilemede yeni bir jeton alın; asla tekrar kullanmayın. Token oluşturma, fon aktarmaz veya cüzdan ortamını seçmez.

Görmek [Saniye ticareti](/tr/sdk/agent-sdk/java/seconds-trading) ön uç/arka uç akışının tamamı için.
