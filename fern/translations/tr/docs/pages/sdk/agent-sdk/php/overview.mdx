<h2 id="runtime">Çalışma süresi</h2>

| Madde | Değer |
| --- | --- |
| Paket | Sixmm/Agent-SDK |
| Minimum PHP versiyonu | PHP 7.4+ |
| Önerilen PHP versiyonu | PHP 8.1+ veya şu anda desteklenen sürümler |
| Gerekli uzatmalar | ext-json, ext-curl |

PHP SDK paket kaynağı ve onaylı versiyon partner onboarding sırasında sağlanır. Paketin kamuya açık Packagist'ten erişilebilir olduğunu varsaymayın; organizasyonunuz için sağlanan Composer deposunu yapılandırın.

<h2 id="supported-scenarios">Desteklenen senaryolar</h2>

| Senaryo | SDK yöntemi |
| --- | --- |
| Kullanıcıyı bağla | bağlama |
| Sabit miktar transferi | Transfer |
| Tamamını transfer et | transferAllOut |
| Ters aktarım | Ters Tersi |
| Sorgu sırası | queryOrder |
| Giriş URL oluşturun | createEntryUrl |
| Webhook doğrulama | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Arka uç entegrasyon kuralları</h2>

- Gizli bir yöneticiden veya korunan bir ortam değişkeninden `apiSecret` yüklemek.
- Kullanıcı bağlama, transfer, imzalama ve webhook mantığını tarayıcı kodundan uzak tutmak.
- Varlık miktarları için ondalık dizileri kullanarak kayan nokta yuvarlamalarını önleyin.
- Belirsiz bir transfer sonucunu sorgularken orijinal `agentOrderNo` tekrar kullanın.
- webhook imzalarını ham istek gövdesine göre doğrulamak, sonra çözmeden veya değiştirmek.
