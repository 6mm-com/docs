6MM Agent SDK, imzalamayı ve sıfırdan istek işlemeyi uygulamadan ayrıcalıklı Aracıyı APIs araması gereken iş ortağı arka uç hizmetleri içindir. Entegrasyon bir iş ortağının API sırrını kullandığından tarayıcı, mobil veya genel masaüstü kodunda çalışmamalıdır.

<span id="when-to-use-the-agent-sdk" data-sixmm-canonical-anchor="when-to-use-the-agent-sdk" aria-hidden="true"></span>

## Agent SDK ne zaman kullanılmalı?

Arka ucunuzun bir iş ortağı kullanıcısını bağlaması, varlıkları onaylanmış bir iş akışı üzerinden taşıması, alım satım kayıtlarını sorgulaması, yerleşik bir alım satım girişi oluşturması URL veya webhook bildirimlerini doğrulaması gerektiğinde bir Agent SDK kullanın. Kullan [Trading Widget SDK](/tr/sdk/trading-widget/overview) iş ortağı ön ucunun ticaret arayüzünü görüntülemesi gerektiğinde ayrı olarak.

## Ortak yapılandırma

| Anahtar | Örnek | Tanım |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM Aracı API hizmeti URL sonunda eğik çizgi olmadan. |
| agentCode | AGENT001 | İş ortağı temsilcisi kodu. |
| apiSecret | API-sırrınız | API imzalama sırrı yalnızca arka uçta depolanır. |
| defaultCurrency | USDT | Transfer ve hesap için varsayılan para birimi APIs. |
| webhookUrl | https://partner.example.com/6mm/webhook | 6MM webhook bildirimleri için iş ortağı uç noktası. |

<span id="typical-integration-flow" data-sixmm-canonical-anchor="typical-integration-flow" aria-hidden="true"></span>

## Tipik entegrasyon akışı

1. İş ortağı ön ucu, kullanıcının kimliğini iş ortağının kendi hesap sistemi aracılığıyla doğrular.
2. İş ortağı arka ucu, kullanıcıyı kararlı bir iş ortağı tarafı tanımlayıcıyla eşleştirir.
3. Arka uç, `agentCode` ve korumalı API sırrıyla Agent SDK'i çağırır.
4. SDK, Temsilcinin API isteğini imzalar ve gönderir.
5. Arka uç, döndürülen iş tanımlayıcıyı saklar ve daha sonra webhooks işlemleri bağımsız olarak gerçekleştirir.
6. Ön uç yalnızca kısa ömürlü sonucu veya ihtiyaç duyduğu giriş kimlik bilgilerini alır.

## Üretim kontrol listesi

- Kaynak kodundan değil, arka uç gizli yöneticisinden `apiSecret` dosyasını yükleyin.
- Geliştirme, aşamalandırma ve üretim kimlik bilgilerini ayrı tutun.
- İstikrarlı bir iş ortağı kullanıcı eşlemesi ve benzersiz iş emri tanımlayıcıları kullanın.
- Zaman aşımına uğramış bir isteğin durumunu kontrol ederken orijinal tanımlayıcıyı koruyun.
- webhook imzalarını doğrulayın ve işlenen olay kimliklerini saklayın.
- Destek için istek kimliklerini korurken gizli bilgileri ve imzaları günlüklerden çıkarın.
