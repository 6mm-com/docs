## Önerilen kombinasyon

| Ortak hedefi | Ön uç | Arka plan | Neden önemli |
| --- | --- | --- | --- |
| Gömülü bir işlem terminali ekleyin | Trading Widget SDK | Agent SDK | Widget, işlem arayüzü ile ilgilenirken, ortak arka uç token çıkarır ve sırları gizli tutar. |
| Yerel bir uygulama giriş noktası oluşturun | Native veya H5 girişi | Agent SDK | Uygulama, partner kullanıcı oturumunu doğruladıktan URL 6MM girişi açıyor. |
| Özel bir ticaret akışı oluşturun | Partner UI | Developer API + seçilmiş SDK akışları | Hesap, emir, pozisyon ve piyasa verileri için APIs kullanın, ancak operasyonel kontroller sunucu tarafında tutulur. |

<span id="reference-architecture" data-sixmm-canonical-anchor="reference-architecture" aria-hidden="true"></span>

## Referans mimarisi

```text
Partner Web App
  -> TradingWidget.create()
  -> tokenProvider()
  -> Partner Backend
  -> 6MM Agent SDK
  -> 6MM Agent API
  -> 6MM Trading iframe
```

> **Sunucu tarafında sırları sakla**
>
> Tarayıcı kodu sadece ortaklara ait uç noktaları çağırmalıdır. Ajan API sırrı asla ön uç koduna gönderilmemelidir.

<span id="production-checklist" data-sixmm-canonical-anchor="production-checklist" aria-hidden="true"></span>

## Üretim kontrol listesi

- apiSecret yalnızca arka uç altyapısında depolayın.
- Agent API talepleri ve webhook URL'leri için HTTPS kullanın.
- Sürekli agentUserId, platformUserIdve agentOrderNo eşlemeleri.
- Parasal miktarları ondalık dizim olarak göstermek, kayan nokta değerleri yerine.
- PROCESSING başarı veya başarısızlık olarak değil, beklemede olarak ele alın.
- Tekrar denemeler beklendiği için webhooks ikametsiz şekilde işlemek.
