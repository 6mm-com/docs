Ilova doimiy ravishda yangilanadigan narxlar, savdolar, shamdonlar yoki buyurtma daftari chuqurligi kerak bo'lganda, REST nuqtalarini takroran so'rov qilmasdan ommaviy bozor kanallaridan foydalaning. Ushbu oqimlar savdo ekranlari, narx ko'rsatkichlari, ogohlantirishlar va bozor monitoringini qo'llab-quvvatlashi mumkin.

<h2 id="connection-url">Aloqa URL</h2>

```
wss://ws.6mm.com/ws
```

Ommaviy WebSocket autentifikatsiya talab qilinmaydi.

Ulanish hayotiy aylanishi, obunani bekor qilish, ping va qayta ulanish xatti-harakatlari uchun [Connection, Subscription & Heartbeat](/tr/developer-api/websocket/connection-subscription-and-heartbeat) ga qarang.

<h2 id="common-channels">Umumiy kanallar</h2>

| Kanal                            | Tavsif                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Kitob chuqurligini buyurtma qiling. Avval snapshot yuboradi, keyin bosqichma-bosqich yangilanishlar |
| `market.trade.{symbol}`            | So'nggi savdolar                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Yagona belgili ticker sharhi                                       |
| `market.tickers`                   | Barcha belgilar bilan bog'liq ticker qisqacha mazmuni                                          |

<h2 id="choose-a-channel">Kanal tanlang</h2>

| Ilova zarurati | Kanal |
| --- | --- |
| Buyurtmalar kitobini tuzish yoki saqlash | `market.depth.{symbol}` |
| Jonli savdo oqimini ko'rsating | `market.trade.{symbol}` |
| Shamdon jadvalini chizing | `market.kline.{symbol}.{interval}` |
| Bir bozor qisqacha ma'lumotini ko'rsating | `market.ticker.{symbol}` |
| Bozor ko'rinishini saqlash | `market.tickers` |

<h2 id="subscription-example">Obuna misoli</h2>

```json
{ "id": "1772007814666", "op": "subscribe", "args": ["market.depth.BTCUSDT"] }
```

<h2 id="push-message-wrapper">Push Message Wrapper</h2>

```json
{
  "topic": "market.depth.BTCUSDT",
  "event": "data",
  "ts": 1772007815000,
  "data": {}
}
```

Har bir xabarni to'g'ri handlerga yo'naltirish uchun `topic` va yetkazib berish vaqtini kuzatish uchun `ts` foydalaning. `data` obyekti obuna bo'lgan kanal uchun yukni o'z ichiga oladi.

<h2 id="order-book-handling">Buyurtmalar daftarini boshqarish</h2>

Chuqurlik kanali avval snapshot yuboradi, keyin esa bosqichma-bosqich yangilanishlarni yuboradi. Yangilanishlarni qo'llashdan oldin snapshotdan mahalliy kitobni ishga tushiring. Qayta ulanishdan so'ng, yangi sessiya yarating, yana obuna bo'ling va mahalliy kitobni keyingi snapshotdan qayta quring, eskirgan xotira holatidan davom ettirish o'rniga.

<h2 id="production-recommendations">Ishlab chiqarish tavsiyalari</h2>

- Har bir obuna bo'lish, obunani bekor qilish va ping so'rovi uchun noyob `id` yaratish.
- Kanalni faol deb hisoblashdan oldin obuna tasdiqlarini tasdiqlang.
- Qayta ulanishdan so'ng barcha kerakli mavzularga qayta obuna bo'ling.
- Tarmoq o'qishlarini sekinroq ma'lumotlar bazasi yoki UI ishlov berishdan alohida saqlash.
- Uzilish chastotasi, xabarlarni qayta ishlash kechikishi va noto'g'ri shakllangan yuklarni nazorat qilish.
- [Private User Channel](/tr/developer-api/websocket/private-user-channel) orqali autentifikatsiyalangan hisob va buyurtma yangilanishlaridan foydalaning.
