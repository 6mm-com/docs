> **Izoh**
>
> Pozitsiya nuqtalari savdo ruxsati talab qiladi.

<h2 id="set-leverage">Leverage o'rnatish</h2>

```http
POST /v1/private/position/leverage
Content-Type: application/json
```

So'rov tanasi:

```json
{
  "symbol": "BTCUSDT",
  "leverage": 20
}
```

Javob maydonlari:

| Maydon       | Turi   | Tavsif |
| ----------- | ------ | ----------- |
| `symbol`    | string | Ramz      |
| `leverage`  | int32  | Leverage    |
| `timestamp` | int64  | Vaqt tamg'asi   |

<h2 id="set-margin-mode">Margin rejimini sozlash</h2>

```http
POST /v1/private/position/margin-mode
Content-Type: application/json
```

So'rov tanasi:

```json
{
  "symbol": "BTCUSDT",
  "marginMode": 1
}
```

`marginMode`: `1` o'rtoq, `2` izolyatsiyada.

<h2 id="position-settings">Pozitsiya sozlamalari</h2>

```http
GET /v1/private/position/settings?symbol=BTCUSDT
```

Javob maydonlari:

| Maydon        | Turi   | Tavsif             |
| ------------ | ------ | ----------------------- |
| `symbol`     | string | Ramz                  |
| `marginMode` | int32  | `1` xoch, `2` yolg'iz |
| `leverage`   | int32  | Leverage                |

<h2 id="current-positions">Hozirgi lavozimlar</h2>

```http
GET /v1/private/position/positions?symbol=BTCUSDT
```

So'rov parametrlari:

| Parametr | Turi   | Majburiy | Tavsif |
| --------- | ------ | -------- | ----------- |
| `symbol`  | string | Yo'q       | Ramz      |

Javob maydonlari:

| Maydon                         | Turi   | Tavsif                |
| ----------------------------- | ------ | -------------------------- |
| `positions[].symbol`          | string | Ramz                     |
| `positions[].marginMode`      | string | Margin rejimi                |
| `positions[].positionSide`    | string | Pozitsiya tomoni              |
| `positions[].leverage`        | int32  | Leverage                   |
| `positions[].quantity`        | string | Pozitsiya miqdori          |
| `positions[].entryPrice`      | string | Kirish narxi                |
| `positions[].breakEvenPrice`  | string | Ajralib turadigan narx           |
| `positions[].liqPrice`        | string | Likvidatsiya narxi          |
| `positions[].marginRatio`     | string | Marja nisbati               |
| `positions[].unrealizedPnl`   | string | Amalga oshirilmagan PnL             |
| `positions[].roe`             | string | Kapital daromadi           |
| `positions[].nextFundingFee`  | string | Taxminiy keyingi moliyalashtirish to'lovi |
| `positions[].fundingFeeAccum` | string | Yig'ilgan moliyalashtirish to'lovi    |
| `positions[].tpPrice`         | string | Foyda narxi          |
| `positions[].slPrice`         | string | Stop-loss narxi            |

<h2 id="position-history">Pozitsiya tarixi</h2>

```http
GET /v1/private/position/history?symbol=BTCUSDT&page=1&pageSize=20
```

So'rov parametrlari:

| Parametr   | Turi   | Majburiy | Tavsif                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Yo'q       | Ramz                       |
| `side`      | string | Yo'q       | `long` / `short`             |
| `startTime` | int64  | Yo'q       | Boshlanish vaqti                   |
| `endTime`   | int64  | Yo'q       | Yakun vaqti                     |
| `page`      | int64  | Yo'q       | Sahifa raqami, standart `1`     |
| `pageSize`  | int64  | Yo'q       | Sahifa boshidagi elementlar, standart `20` |

Javob maydonlari:

| Maydon                    | Turi   | Tavsif               |
| ------------------------ | ------ | ------------------------- |
| `list[].symbol`          | string | Ramz                    |
| `list[].positionSide`    | string | Pozitsiya tomoni             |
| `list[].leverage`        | int32  | Leverage                  |
| `list[].maxQuantity`     | string | Maksimal pozitsiya miqdori |
| `list[].entryPrice`      | string | Kirish narxi               |
| `list[].closePrice`      | string | Yaqin narx               |
| `list[].pnl`             | string | PnLni amalga oshirish              |
| `list[].roe`             | string | Kapital daromadi          |
| `list[].marginMode`      | string | Margin rejimi               |
| `list[].triggerMode`     | int32  | Trigger rejimini yopish        |
| `list[].fundingFeeAccum` | string | Yig'ilgan moliyalashtirish to'lovi   |
| `list[].openedAt`        | int64  | Ochiq vaqt                 |
| `list[].closedAt`        | int64  | Yaqin vaqt                |
| `total`                  | int64  | Umumiy hisob               |
