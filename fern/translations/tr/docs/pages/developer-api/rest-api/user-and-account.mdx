Aksi belirtilmedikçe, aşağıdaki uç noktalar JWT veya API Key işaretleme kullanabilir.

<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Kullanıcı Bilgileri

```http
GET /v1/private/user/info
```

Yanıt alanları:

| Saha                  | Tip   | Tanım      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | Dış kullanıcı Kimliği |
| `userInfo.username`    | string | Kullanıcı adı         |
| `userInfo.agentId`     | int64  | Ajan Kimliği         |
| `userInfo.vipLevel`    | int64  | VIP seviyesi        |
| `userInfo.lastLoginAt` | int64  | Son giriş zamanı  |
| `userInfo.lastLoginIp` | string | Son giriş IP    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Kullanıcı Varlıkları

```http
GET /v1/private/user/asset
```

Yanıt alanları:

| Saha                     | Tip   | Tanım                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | Dış kullanıcı Kimliği                |
| `userAsset.assetType`     | string | Varlık türü                      |
| `userAsset.walletBalance` | string | Cüzdan bakiyesi                  |
| `userAsset.frozenMargin`  | string | Kayır, bekleyen emirler nedeniyle donduruldu |
| `userAsset.usedMargin`    | string | Pozisyonlar tarafından kullanılan marj        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Yarat listenKey

```http
POST /v1/private/user/listen-key
```

Özel WebSocket akışları için kimlik doğrulama anahtarı oluşturur.

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Yenileme listenKey

```http
PUT /v1/private/user/listen-key
```

Geçerliliğini listenKey genişletiyor.

<span id="close-listenkey" data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Yakın listenKey

```http
DELETE /v1/private/user/listen-key
```

Belirtilen listenKeykapatır.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Hesap Değişiklik Kayıtları

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

İstek parametreleri:

| Parametre    | Tip   | Gerekli | Tanım                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | Hayır       | Varlık türü, örneğin `USDT`   |
| `changeType` | string | Hayır       | Türü değiştir                  |
| `startTime`  | int64  | Hayır       | Başlama zamanı                   |
| `endTime`    | int64  | Hayır       | Son zaman                     |
| `page`       | int32  | Hayır       | Sayfa numarası, varsayılan `1`     |
| `pageSize`   | int32  | Hayır       | Sayfa başına öğeler, varsayılan `20` |

Yanıt alanları:

| Saha                        | Tip   | Tanım                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Varlık türü                   |
| `list[].amount`              | string | Değişen miktar               |
| `list[].walletBalanceBefore` | string | Değişimden önceki cüzdan bakiyesi |
| `list[].walletBalanceAfter`  | string | Para değişikliğinden sonra cüzdan bakiyesi  |
| `list[].frozenBalanceBefore` | string | Değişimden önce donmuş denge |
| `list[].frozenBalanceAfter`  | string | Değişim sonrası donmuş denge  |
| `list[].changeType`          | string | Türü değiştir                  |
| `list[].referenceId`         | string | İlgili İşletme Kimliği          |
| `list[].createdAt`           | int64  | Yaratım zamanı                |
| `total`                      | int64  | Toplam sayım                  |

<span id="30-day-volume-statistics" data-sixmm-canonical-anchor="30-day-volume-statistics" aria-hidden="true"></span>

## 30 Günlük Hacim İstatistikleri

```http
GET /v1/private/user/volume-stats
```

Yanıt alanları:

| Saha         | Tip   | Tanım                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Son 30 günün kümülatif işlem hacmi |
| `feeTotal30d` | string | Son 30 gündeki birikimli ücretler           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## Denge Tarihi

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

İstek parametreleri:

| Parametre | Tip   | Gerekli | Tanım                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Evet      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | Hayır       | Iade edilen eşya sayısı, varsayılan `30` |

Yanıt alanları:

| Saha             | Tip   | Tanım                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Toplanma tarihi            |
| `items[].balance` | string | Cüzdan bakiyesi              |
| `items[].pnl`     | string | Dönem için gerçekleşen PnL |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Ticaret Genel Özeti

```http
GET /v1/private/user/trade-overview?type=1M
```

İstek parametreleri:

| Parametre | Tip   | Gerekli | Tanım                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Evet      | Trend aralığı: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Yanıt alanları:

| Saha                | Tip   | Tanım                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | Bugünün gerçekleşen PnL                                                 |
| `todayVolume`        | string | Bugünün sözleşme işlem hacmi                                      |
| `totalVolume`        | string | Kümülatif sözleşme işlem hacmi                                   |
| `totalPnl`           | string | Kümülatif gerçekleşen PnL                                              |
| `maxDrawdown30d`     | string | Son 30 gündeki maksimum çekim miktarı                        |
| `maxDrawdown30dRate` | string | Son 30 gündeki maksimum azalma oranı, ondalık olarak `0` 'den `1` |
| `transferIn`         | string | Kümülatif transfer edilen fonlar                                      |
| `transferOut`        | string | Kümülatif aktarılan fonlar                                     |
| `items[]`            | array  | Varlık eğilimi verileri                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Varlık Genel Özeti

```http
GET /v1/private/user/asset/overview/summary
```

Yanıt alanları, ticaret genel özet alanlarıyla aynıdır, `items[]`hariç.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Varlık Genel Görünümü Trendi

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

İstek parametreleri:

| Parametre | Tip   | Gerekli | Tanım                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Evet      | Trend aralığı: `1D`, `1W`, `1M`, `3M`, `6M`, `1Y` |

Yanıt alanları:

| Saha                  | Tip   | Tanım                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Anlık Görüntü Zamanı                   |
| `items[].balance`      | string | Mevcut hesap bakiyesi         |
| `items[].pnl`          | string | Mevcut dönem için PnL      |
| `items[].pnlRate`      | string | Mevcut dönem için PnL oranı |
| `items[].totalPnl`     | string | Kümülatif PnL                  |

## Favori Semboller

```json
{
```


Yanıt alanları:

| Saha     | Tip      | Tanım          |
| --------- | --------- | -------------------- |
| `symbols` | String\[] | Favori sembol listesi |
