## Temel URL

```
https://api.6mm.com
```

<span id="service-version" data-sixmm-canonical-anchor="service-version" aria-hidden="true"></span>

## Hizmet Versiyonu

```http
GET /v1/version
```

Servis versiyon bilgisini alın.

<span id="server-time" data-sixmm-canonical-anchor="server-time" aria-hidden="true"></span>

## Server Zamanı

```http
GET /v1/time
```

Server zamanı alın. Bu uç nokta, API Key imzalamadan önce istemci zamanını kalibre etmek için kullanılabilir.

<span id="user-login" data-sixmm-canonical-anchor="user-login" aria-hidden="true"></span>

## Kullanıcı Girişi

```http
POST /v1/public/user/login
```

İstek parametreleri:

| Parametre    | Tip   | Gerekli | Tanım                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | Evet      | Kullanıcı adı, uzunluk 3 - 32                 |
| `password`   | string | Evet      | Şifre, uzunluk 1 - 64                 |
| `deviceId`   | string | Hayır       | Cihaz parmak izi, 64 karaktere kadar |
| `deviceName` | string | Hayır       | Cihaz adı, 128 karaktere kadar       |

Örnek istemek:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

Yanıt örneği:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<span id="refresh-token" data-sixmm-canonical-anchor="refresh-token" aria-hidden="true"></span>

## Yenileme Belirtonu

```http
POST /v1/public/user/refresh-token
```

Normal entegrasyon senaryolarında, giriş durumu Cookie ile yenilenir. Giriş yanıtında geri dönen çerezi tutun.

Yanıt alanları:

| Saha          | Tip   | Tanım              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Yeni erişim tokenı         |
| `accessExpire` | int64  | Access Token son kullanma süresi |

## Ajan SSO

<span id="ticket-exchange" data-sixmm-canonical-anchor="ticket-exchange" aria-hidden="true"></span>

## Bilet Değişimi

```http
POST /v1/public/agent-sso/exchange-ticket
```

İstek parametreleri:

| Parametre  | Tip   | Gerekli | Tanım                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | Evet      | Temsilci servisi tarafından verilen tek seferlik bilet |
| `deviceId` | string | Hayır       | Cihaz parmak izi, 64 karaktere kadar     |

Yanıt alanları:

| Saha          | Tip   | Tanım              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Erişim Tokenı             |
| `accessExpire` | int64  | Access Token son kullanma süresi |
| `redirectPath` | string | Önerilen yönlendirme yolu  |

<span data-sixmm-canonical-anchor="embed-token-exchange" aria-hidden="true"></span>

## Embed Token Exchange

```http
POST /v1/public/agent-sso/exchange-embed-token
```

İstek parametreleri:

| Parametre    | Tip   | Gerekli | Tanım                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | Evet      | Ajan hizmeti tarafından çıkarılan kısa ömürlü gömülü ticaret tokenı |
| `channelId`  | string | Evet      | Gömülü iframe kanal kimliği, 128 karaktere kadar               |
| `deviceId`   | string | Hayır       | Cihaz parmak izi, 64 karaktere kadar                        |

Yanıt alanları:

| Saha          | Tip   | Tanım              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Erişim Tokenı             |
| `accessExpire` | int64  | Access Token son kullanma süresi |

<span id="pnl-leaderboard" data-sixmm-canonical-anchor="pnl-leaderboard" aria-hidden="true"></span>

## PnL Liderlik Tablosu

```http
GET /v1/public/leaderboard/pnl?period=30d
```

İstek parametreleri:

| Parametre | Tip   | Gerekli | Tanım          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | Evet      | `7d` / `30d` / `90d` |

Yanıt alanları:

| Saha              | Tip   | Tanım                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | Rütbe                                                              |
| `list[].userId`    | string | Dış kullanıcı Kimliği                                                  |
| `list[].trader`    | string | Maskeli tüccar adı                                                |
| `list[].volume`    | string | Penceredeki işlem hacmi                                      |
| `list[].pnlAmount` | string | Pencerede gerçekleşen PnL                                        |
| `list[].pnlPct`    | string | PnL oranı, `0`'dan `1`'ye ondalık                                |
| `myRank`           | int32  | Mevcut kullanıcının sıralaması. Doğrulanmamış veya sıralanmamışsa `0` döner. |
