<h2 id="base-url">Baza URL</h2>

```
https://api.6mm.com
```

<h2 id="service-version">Xizmat versiyasi</h2>

```http
GET /v1/version
```

Xizmat versiyasi haqida ma'lumot oling.

<h2 id="server-time">Server vaqti</h2>

```http
GET /v1/time
```

Server vaqtini oling. Ushbu endpoint mijoz vaqtini imzolashdan oldin kalibrlash uchun API Key mumkin.

<h2 id="user-login">Foydalanuvchi Logini</h2>

```http
POST /v1/public/user/login
```

So'rov parametrlari:

| Parametr    | Turi   | Majburiy | Tavsif                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | Ha      | Foydalanuvchi nomi, uzunligi 3 - 32                 |
| `password`   | string | Ha      | Parol, uzunligi 1 - 64                 |
| `deviceId`   | string | Yo'q       | Qurilma barmoq izi, 64 ta belgigacha |
| `deviceName` | string | Yo'q       | Qurilma nomi, 128 ta belgigacha       |

Misol so'rovi:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

Javob misoli:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<h2 id="refresh-token">Yangilanish Tokeni</h2>

```http
POST /v1/public/user/refresh-token
```

Oddiy integratsiya holatlarida login holati Cookie orqali yangilanadi. Login javobida qaytarilgan Cookie'ni saqlang.

Javob maydonlari:

| Maydon          | Turi   | Tavsif              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Yangi kirish tokeni         |
| `accessExpire` | int64  | Access Tokenning amal qilish muddati |

<h2 id="agent-sso">Agent SSO</h2>

<h2 id="ticket-exchange">Chipta almashinuvi</h2>

```http
POST /v1/public/agent-sso/exchange-ticket
```

So'rov parametrlari:

| Parametr  | Turi   | Majburiy | Tavsif                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | Ha      | Agent xizmati tomonidan berilgan bir martalik chipta |
| `deviceId` | string | Yo'q       | Qurilma barmoq izi, 64 ta belgigacha     |

Javob maydonlari:

| Maydon          | Turi   | Tavsif              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Access Token             |
| `accessExpire` | int64  | Access Tokenning amal qilish muddati |
| `redirectPath` | string | Tavsiya etilgan yo'naltirish yo'li  |

<h2 id="embed-token-exchange">Embed Token Exchange</h2>

```http
POST /v1/public/agent-sso/exchange-embed-token
```

So'rov parametrlari:

| Parametr    | Turi   | Majburiy | Tavsif                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | Ha      | Agent xizmati tomonidan chiqarilgan qisqa muddatli o'rnatilgan savdo tokeni |
| `channelId`  | string | Ha      | Ichki iframe kanal ID, 128 ta belgigacha               |
| `deviceId`   | string | Yo'q       | Qurilma barmoq izi, 64 ta belgigacha                        |

Javob maydonlari:

| Maydon          | Turi   | Tavsif              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Access Token             |
| `accessExpire` | int64  | Access Tokenning amal qilish muddati |

<h2 id="pnl-leaderboard">PnL reytinglar jadvali</h2>

```http
GET /v1/public/leaderboard/pnl?period=30d
```

So'rov parametrlari:

| Parametr | Turi   | Majburiy | Tavsif          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | Ha      | `7d` / `30d` / `90d` |

Javob maydonlari:

| Maydon              | Turi   | Tavsif                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | Unvoni                                                              |
| `list[].userId`    | string | Tashqi foydalanuvchi identifikatori                                                  |
| `list[].trader`    | string | Maskali savdogar nomi                                                |
| `list[].volume`    | string | Oynadagi savdo hajmi                                      |
| `list[].pnlAmount` | string | Derazada PnL amalga oshdi                                        |
| `list[].pnlPct`    | string | PnL nisbati, `0` dan o'nlik `1`                                |
| `myRank`           | int32  | Hozirgi foydalanuvchining reytingi. Agar autentifikatsiya qilinmagan yoki reytinglanmagan bo'lsa, `0` natijalar |
