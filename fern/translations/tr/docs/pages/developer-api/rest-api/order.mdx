<h2 id="place-order">Yer Siparişi</h2>

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Talep parametreleri:**

| Parametre       | Tip   | Gerekli               | Tanım                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Evet                    | Sembol                                                                                                                        |
| `type`          | string | Evet                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Evet                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Hayır                     | `BOTH` / `LONG` / `SHORT`, varsayılan `BOTH`                                                                                     |
| `price`         | string | Koşullu olarak gereklidir | Limit emirleri için gerekli                                                                                                     |
| `quantity`      | string | Koşullu olarak gereklidir | Miktar. Atlandığında `closePosition=true`                                                                            |
| `timeInForce`   | string | Hayır                     | `GTC` / `IOC` / `FOK`, varsayılan `GTC`                                                                                          |
| `reduceOnly`    | bool   | Hayır                     | Sadece azalt, varsayılan `false`                                                                                                  |
| `makerOnly`     | bool   | Hayır                     | Sadece üretici için, varsayılan `false`                                                                                                   |
| `closePosition` | bool   | Hayır                     | Tüm pozisyonu kapat, varsayılan `false`                                                                                    |
| `clientOrderId` | string | Hayır                     | İstemci tarafından tanımlanan sipariş kimliği                                                                                                       |
| `placeType`     | string | Hayır                     | Sipariş yerleştirme tipi işaretleyici                                                                                                   |
| `priceType`     | int32  | Hayır                     | BBO fiyat türü: `0` fiyat, `1` rakip fiyat 1, `2` rakip fiyat 5, `3` aynı taraf fiyatı 1 `4` aynı taraf fiyatı 5 |

**Örnek iste:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Yanıt alanları:**

| Saha           | Tip   | Tanım             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | Sunucu sipariş kimliği         |
| `clientOrderId` | string | İstemci tarafından tanımlanan sipariş kimliği |
| `status`        | string | Sipariş durumu            |
| `timestamp`     | int64  | Zaman damgası               |

<h2 id="batch-place-orders">Toplu Siparişler</h2>

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**Talep bedeni:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Yanıt alanları:**

| Saha          | Tip  | Tanım                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Başarılı sipariş sayısı |
| `failedCount`  | int32 | Başarısız emir sayısı     |
| `results[]`    | array | Her sipariş için sonuç       |

<h2 id="place-condition-order">Yer Koşulu Sırası</h2>

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Talep parametreleri:**

| Parametre       | Tip   | Gerekli               | Tanım                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Evet                    | Sembol                                                                                      |
| `type`          | string | Evet                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Evet                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Hayır                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Koşullu olarak gereklidir | `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` için zorunlu                                             |
| `quantity`      | string | Koşullu olarak gereklidir | Miktar. Atlandığında `closePosition=true`                                          |
| `timeInForce`   | string | Hayır                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Hayır                     | Sadece azalt                                                                                 |
| `clientOrderId` | string | Hayır                     | İstemci tarafından tanımlanan sipariş kimliği                                                                     |
| `stopPrice`     | string | Koşullu olarak gereklidir | Tetikleyici fiyat                                                                               |
| `workingType`   | string | Hayır                     | `MARK_PRICE` / `CONTRACT_PRICE`, varsayılan `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Hayır                     | Fiyat korumasının mümkün olup olmadığı                                                         |
| `activatePrice` | string | Koşullu olarak gereklidir | Takip eden emir aktivasyon fiyatı                                                             |
| `callbackRate`  | string | Koşullu olarak gereklidir | Takip eden sipariş geri çağrı oranı                                                                |
| `closePosition` | bool   | Hayır                     | Tüm pozisyonu kapat                                                                   |

**Yanıt alanları:**

| Saha             | Tip   | Tanım            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | Durum Sırası Kimliği     |
| `conditionStatus` | string | Durum sırası durumu |
| `timestamp`       | int64  | Zaman damgası              |

<h2 id="place-strategy-order">Yerleştirme Stratejisi Sırası</h2>

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Talep parametreleri:**

| Parametre      | Tip   | Gerekli | Tanım             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Evet      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Evet      | Alt sıralar listesi          |

`subOrderList[]`'daki alanlar çoğunlukla normal mertebeler ve koşul sıralarıyla aynıdır, ek bağımlılık alanları içerir:

| Parametre        | Tip   | Tanım                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | Alt sıra ID'si                                    |
| `firstDrivenId`  | int64  | İlk sürüş emri kimliği. `0` bağımlılık yok demektir |
| `firstDrivenOn`  | string | İlk tetikleme durumu                         |
| `firstTrigger`   | string | İlk tetikleme eylemi                            |
| `secondDrivenId` | int64  | İkinci sürüş emri kimliği                         |
| `secondDrivenOn` | string | İkinci tetikleyici koşulu                        |
| `secondTrigger`  | string | İkinci tetikleme eylemi                           |

**Yanıt alanları:**

| Saha            | Tip   | Tanım     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | Strateji Kimliği     |
| `strategyStatus` | string | Strateji durumu |
| `timestamp`      | int64  | Zaman damgası       |

<h2 id="query-single-order">Tek Sıra Sorgu</h2>

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Talep parametreleri:**

| Parametre       | Tip   | Gerekli | Tanım             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Evet      | Sembol                  |
| `orderId`       | string | Hayır       | Sunucu sipariş kimliği         |
| `clientOrderId` | string | Hayır       | İstemci tarafından tanımlanan sipariş kimliği |

En az `orderId` ve `clientOrderId` biri sağlanmalıdır. Her ikisi de sağlanırsa, sunucu her iki koşulda da tam bir eşleşme gerçekleştirir.

<h2 id="cancel-all">Her Şeyi İptal Et</h2>

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Talep parametreleri:**

| Parametre    | Tip   | Gerekli | Tanım                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Hayır       | Sembol                                                                              |
| `cancelType` | int32  | Hayır       | `0` tüm normal emirler, `1` limit emirleri `2` tüm koşul emirleri. Varsayılan `0` |

Normal siparişler için iptal etme asenkron olarak kabul edilir. Nihai durum WebSocket `ORDER_TRADE_UPDATE` veya sorgu uç noktalarına göre belirlenmelidir.
