> **Izoh**
>
> Order endpointlari savdo ruxsati talab qiladi.

<h2 id="place-order">Joy tartibi</h2>

```http
POST /v1/private/order/place
Content-Type: application/json
```

**Parametrlarni so'rash:**

| Parametr       | Turi   | Majburiy               | Tavsif                                                                                                                   |
| --------------- | ------ | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `symbol`        | string | Ha                    | Ramz                                                                                                                        |
| `type`          | string | Ha                    | `LIMIT` / `MARKET`                                                                                                            |
| `side`          | string | Ha                    | `BUY` / `SELL`                                                                                                                |
| `positionSide`  | string | Yo'q                     | `BOTH` / `LONG` / `SHORT`, standart `BOTH`                                                                                     |
| `price`         | string | Shartli talab qilinadi | Limit orderlar uchun talab qilinadi                                                                                                     |
| `quantity`      | string | Shartli talab qilinadi | Miqdor. Agar o'sha paytda chiqarib tashlash mumkin `closePosition=true`                                                                            |
| `timeInForce`   | string | Yo'q                     | `GTC` / `IOC` / `FOK`, standart `GTC`                                                                                          |
| `reduceOnly`    | bool   | Yo'q                     | Faqat kamaytirish, standart `false`                                                                                                  |
| `makerOnly`     | bool   | Yo'q                     | Faqat maker uchun, standart `false`                                                                                                   |
| `closePosition` | bool   | Yo'q                     | Butun pozitsiyani yop, standart `false`                                                                                    |
| `clientOrderId` | string | Yo'q                     | Mijoz tomonidan belgilangan buyurtma identifikatori                                                                                                       |
| `placeType`     | string | Yo'q                     | Buyurtma joylashtirish turi belgisi                                                                                                   |
| `priceType`     | int32  | Yo'q                     | BBO narx turi: `0` belgilangan narx, `1` raqib narxi 1, `2` raqib narxi 5, `3` bir tomon narxi 1, `4` bir tomon narxi 5 |

**Misol so'rash:**

```json
{
  "symbol": "BTCUSDT",
  "type": "LIMIT",
  "side": "BUY",
  "price": "85000",
  "quantity": "0.1",
  "timeInForce": "GTC",
  "makerOnly": true,
  "clientOrderId": "ext-1772710377808-001"
}
```

**Javob maydonlari:**

| Maydon           | Turi   | Tavsif             |
| --------------- | ------ | ----------------------- |
| `orderId`       | string | Server buyurtmasi identifikatori         |
| `clientOrderId` | string | Mijoz tomonidan belgilangan buyurtma identifikatori |
| `status`        | string | Buyurtma holati            |
| `timestamp`     | int64  | Vaqt tamg'asi               |

<h2 id="batch-place-orders">Partiyaviy joylashuv buyurtmalari</h2>

```http
POST /v1/private/order/batch-place
Content-Type: application/json
```

**So'rov tanasi:**

```json
{
  "orders": [
    {
      "symbol": "BTCUSDT",
      "type": "LIMIT",
      "side": "BUY",
      "price": "85000",
      "quantity": "0.1",
      "clientOrderId": "ext-buy-001"
    }
  ]
}
```

**Javob maydonlari:**

| Maydon          | Turi  | Tavsif                 |
| -------------- | ----- | --------------------------- |
| `successCount` | int32 | Muvaffaqiyatli buyurtmalar soni |
| `failedCount`  | int32 | Bajarilmagan buyurtmalar soni     |
| `results[]`    | array | Har bir tartib uchun natija       |

<h2 id="place-condition-order">Joy Sharoitlari Tartibi</h2>

```http
POST /v1/private/order/place-condition
Content-Type: application/json
```

**Parametrlarni so'rash:**

| Parametr       | Turi   | Majburiy               | Tavsif                                                                                 |
| --------------- | ------ | ---------------------- | ------------------------------------------------------------------------------------------- |
| `symbol`        | string | Ha                    | Ramz                                                                                      |
| `type`          | string | Ha                    | `STOP_MARKET` / `TAKE_PROFIT_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP` |
| `side`          | string | Ha                    | `BUY` / `SELL`                                                                              |
| `positionSide`  | string | Yo'q                     | `BOTH` / `LONG` / `SHORT`                                                                   |
| `price`         | string | Shartli talab qilinadi | `STOP_LIMIT` / `TAKE_PROFIT_LIMIT` uchun talab qilinadi                                             |
| `quantity`      | string | Shartli talab qilinadi | Miqdor. Agar o'sha paytda chiqarib tashlash mumkin `closePosition=true`                                          |
| `timeInForce`   | string | Yo'q                     | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                           |
| `reduceOnly`    | bool   | Yo'q                     | Faqat qisqartirish                                                                                 |
| `clientOrderId` | string | Yo'q                     | Mijoz tomonidan belgilangan buyurtma identifikatori                                                                     |
| `stopPrice`     | string | Shartli talab qilinadi | Trigger narxi                                                                               |
| `workingType`   | string | Yo'q                     | `MARK_PRICE` / `CONTRACT_PRICE`, standart `CONTRACT_PRICE`                                   |
| `priceProtect`  | bool   | Yo'q                     | Narxlarni himoya qilish yo'qmi                                                         |
| `activatePrice` | string | Shartli talab qilinadi | Trailing order faollashtirish narxi                                                             |
| `callbackRate`  | string | Shartli talab qilinadi | Trailing order callback rate                                                                |
| `closePosition` | bool   | Yo'q                     | Butun pozitsiyani yoping                                                                   |

**Javob maydonlari:**

| Maydon             | Turi   | Tavsif            |
| ----------------- | ------ | ---------------------- |
| `conditionId`     | string | Shart tartibi identifikatori     |
| `conditionStatus` | string | Shart tartibi holati |
| `timestamp`       | int64  | Vaqt tamg'asi              |

<h2 id="place-strategy-order">Joylashtirish strategiyasi tartibi</h2>

```http
POST /v1/private/order/place-strategy
Content-Type: application/json
```

**Parametrlarni so'rash:**

| Parametr      | Turi   | Majburiy | Tavsif             |
| -------------- | ------ | -------- | ----------------------- |
| `strategyType` | string | Ha      | `OTOCO` / `OTO` / `OCO` |
| `subOrderList` | array  | Ha      | Kichik tartiblar ro'yxati          |

`subOrderList[]` dagi maydonlar asosan normal tartiblar va shart tartiblari bilan bir xil, qo'shimcha bog'liqlik maydonlari bilan:

| Parametr        | Turi   | Tavsif                                     |
| ---------------- | ------ | ----------------------------------------------- |
| `strategySubId`  | int64  | Sub-tartib identifikatori                                    |
| `firstDrivenId`  | int64  | Birinchi haydovchilik tartibi ID. `0` bog'liqlik yo'qligini anglatadi |
| `firstDrivenOn`  | string | Birinchi trigger sharti                         |
| `firstTrigger`   | string | Birinchi trigger harakati                            |
| `secondDrivenId` | int64  | Ikkinchi haydovchilik tartibi identifikatori                         |
| `secondDrivenOn` | string | Ikkinchi trigger sharti                        |
| `secondTrigger`  | string | Ikkinchi trigger harakati                           |

**Javob maydonlari:**

| Maydon            | Turi   | Tavsif     |
| ---------------- | ------ | --------------- |
| `strategyId`     | string | Strategiya identifikatori     |
| `strategyStatus` | string | Strategiya holati |
| `timestamp`      | int64  | Vaqt tamg'asi       |

<h2 id="query-single-order">Yagona tartibni so'rash</h2>

```http
GET /v1/private/order?symbol=BTCUSDT&orderId=2022543809547603968
```

**Parametrlarni so'rash:**

| Parametr       | Turi   | Majburiy | Tavsif             |
| --------------- | ------ | -------- | ----------------------- |
| `symbol`        | string | Ha      | Ramz                  |
| `orderId`       | string | Yo'q       | Server buyurtmasi identifikatori         |
| `clientOrderId` | string | Yo'q       | Mijoz tomonidan belgilangan buyurtma identifikatori |

Kamida `orderId` va `clientOrderId` bittasi taqdim etilishi shart. Agar ikkalasi ham mavjud bo'lsa, server har ikkala holatda aniq moslikni bajaradi.

<h2 id="cancel-all">Hammasini bekor qiling</h2>

```http
POST /v1/private/order/batch-cancel-all
Content-Type: application/json
```

**Parametrlarni so'rash:**

| Parametr    | Turi   | Majburiy | Tavsif                                                                         |
| ------------ | ------ | -------- | ----------------------------------------------------------------------------------- |
| `symbol`     | string | Yo'q       | Ramz                                                                              |
| `cancelType` | int32  | Yo'q       | `0` barcha normal tartiblar, faqat limit buyruqlari `1` barcha shart buyruqlari `2` . Standart `0` |

Oddiy buyurtmalar uchun cancel-all asinxron tarzda qabul qilinadi. Yakuniy holat WebSocket `ORDER_TRADE_UPDATE` yoki so'rov nuqtalari bo'yicha belgilanishi kerak.
