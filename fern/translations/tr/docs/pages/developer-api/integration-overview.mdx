> REST Temel URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Bu dokümantasyon, 6MM API hizmetiyle entegre olan harici sistemler için tasarlanmıştır. Giriş girişi, JWT kimlik doğrulama, API Key yönetimi, API Key HMAC imzalama, hesap sorguları, emirler, pozisyonlar, piyasa verileri ve WebSocket akışlarını kapsar.

Hesap düzenleme ve finansman hazırlığı platform tarafı süreçlerle yürütülür. Bu dokümantasyon yalnızca harici olarak çağrılanabilen API hizmet uç noktalarını tanımlar.

## Hizmet Uç Noktaları

| Tip      | Uç nokta              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Entegrasyon Akışı

Önerilen entegrasyon dizisi:

1. Platform tarafından sağlanan hesabla giriş yapın ve bir `accessToken`alın.
2. Sunucu tarafı programatik erişim için, önce JWT ile bir API Key oluşturun ve bir kez geri gönderilen `apiSecret`güvenli bir şekilde saklanın.
3. Özel sorgular, sıra uç noktaları ve konum uç noktaları `Authorization: Bearer <accessToken>` veya API Key işaretiyle çağrılabilir.
4. Özel WebSocket akışları için önce bir `listenKey` oluşturun, sonra `wss://ws.6mm.com/ws?listenKey=...`'ye bağlanın.
5. Piyasa verileri REST uç noktaları ve halka açık WebSocket kanalları kimlik doğrulama gerektirmez.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Kimlik Doğrulama Seçimi

| Senaryo                               | Önerilen yöntem         |
| -------------------------------------- | -------------------------- |
| Ön yüz kullanıcı eylemleri                  | JWT                        |
| Sunucu tarafı programatik çağrılar         | API Key + HMAC imzası   |
| API Key oluşturulma, güncelleme ve silme | JWT                        |
| Kamu piyasa REST / kamu WebSocket  | Kimlik doğrulama gerekmiyor |
