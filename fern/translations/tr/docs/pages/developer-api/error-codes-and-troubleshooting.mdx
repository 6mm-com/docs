<h2 id="error-response-format">Hata Yanıt Formatı</h2>

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

İş hataları genellikle yine de birleşik JSON yapısını geri döndürür. Entegratörler önce `code` kontrol etmeli. Kimlik doğrulama hataları HTTP `401`döndürebilir; Hız sınırı HTTP `429`geri getirebilir.

<h2 id="common-error-codes">Yaygın Hata Kodları</h2>

| Hata kodu      | Tanım                                  |
| --------------- | -------------------------------------------- |
| `0`             | Başarı                                      |
| `1001`          | Geçerli kimlik doğrulama bilgisi sağlanmadı |
| `1002`          | Token süresi doldu                                |
| `1003`          | Geçersiz Token, API Keyveya imza         |
| `1004`          | Token iptal edildi                                |
| `1006`          | Kaynak IP uyumsuzluğu                           |
| `2001`          | Eksik gereken parametre                   |
| `2002`          | Geçersiz parametre değeri                      |
| `2003`          | Aralık dışı parametre                       |
| `3001`          | Yetersiz denge                         |
| `3003`          | Emir bulunamadı                              |
| `3004`          | Tekrarlanan talep                            |
| `3005`          | Sipariş iptal edilemez                     |
| `3006`          | İzin reddedildi                            |
| `3100` - `3112` | Şart sırası parametre doğrulama hatası   |
| `5001`          | Dahili sunucu hatası                        |
| `5002`          | Hizmet geçici olarak kullanılamaz              |
| `5003`          | Hız sınırı tetiklendi                         |

<h2 id="troubleshooting">Sorun Giderme</h2>

| Sorun                                     | Tavsiye                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` geçerli kimlik doğrulama bilgisi yok  | `Authorization: Bearer <accessToken>` veya `X-API-KEY` dahil olup olmadığını kontrol edin.                  |
| `1002` Token süresi doldu                        | Token'ı yenile veya tekrar giriş yapmadan önce tekrar giriş yapın.                                                   |
| `1003` geçersiz Token, API Keyveya imza | API Key, imza yükü, istek gövdesi JSON dizisi ve sorgu parametre sırasını kontrol edin.           |
| `1006` kaynağı IP uyumsuzluk                   | API Key IP beyaz listesi yapılandırmasını kontrol edin.                                                    |
| `3004` tekrarlayıcı talebi                    | Aynı imzayı siparişle ilgili yollar için tekrar kullanmayın. `timestamp` yeniden yarat ve `signature`. |
| `5003` hız sınırı tetiklendi                 | Tekrar denerken istek sıklığını azaltın ve üstel geri çekme kullanın.                                |
| `Timestamp outside of tolerance window`     | Zaman ofsetini kalibre etmek ve talebi tekrar imzalamak için `/v1/time` 'yi arayın.                             |
