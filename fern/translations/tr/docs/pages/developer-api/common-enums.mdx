## Siparişler

| Enum                 | Değerler                                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| Düzen tarafı           | `BUY` / `SELL`                                                                                            |
| Pozisyon tarafı        | `BOTH` / `LONG` / `SHORT`                                                                                 |
| Normal sıra tipi    | `LIMIT` / `MARKET`                                                                                        |
| Koşul sırası tipi | `STOP_MARKET` / `STOP_LIMIT` / `TAKE_PROFIT_MARKET` / `TAKE_PROFIT_LIMIT` / `TRAILING_STOP`               |
| Sürenin yürürlüğü        | `GTC` / `IOC` / `FOK` / `GTE_GTC`                                                                         |
| Tetikleyici fiyat türü   | `MARK_PRICE` / `CONTRACT_PRICE`                                                                           |
| Sipariş durumu         | `NEW` / `PENDING` / `PARTIALLY_FILLED` / `FILLED` / `CANCELED` / `REJECTED` / `PARTIALLY_FILLED_CANCELED` |

`NEW` , sipariş talebinin kabul edildiği ve geri gönderildiği anlamına gelir. `PENDING` emrin beklemede veya açık emir durumuna girdiği anlamına gelir.

## Pozisyonlar

| Enum                      | Değerler                                                      |
| ------------------------- | ----------------------------------------------------------- |
| Marj modu isteği değeri | `1` haç `2` izole                                     |
| Kenar modu dizisi        | `ISOLATED` / `CROSS`                                        |
| Kapanış tetik modu        | `1` manuel `2` kâr almak, stop loss `3` `4` tasfiye |

<span id="integration-rules" data-sixmm-canonical-anchor="integration-rules" aria-hidden="true"></span>

## Entegrasyon kuralları

- Enum değerlerini büyük harf hassasiyetli tel değerleri olarak ele alın.
- Kayıtlarda bilinmeyen değerleri koruyup güvenli bir şekilde başarısız olmayı sessizce bilinen bir duruma eşlemeyi tercih et.
- Her nihai olmayan düzen durumun yeniden denemenin güvenli olduğunu çıkarmayın. Siparişi sorgulayın veya özel bir WebSocket etkinliğiyle uzlaştırın.
- Hem orijinal API değerini hem de partnere dönük gösteri etiketini saklayarak yeni değerlerin geçmiş kayıtları değiştirmeden desteklenebilmesi sağlanır.

<span id="order-state-handling" data-sixmm-canonical-anchor="order-state-handling" aria-hidden="true"></span>

## Sipariş durumu işlemesi

| Eyalet grubu | Değerler | Önerilen kullanım |
| --- | --- | --- |
| Kabul edilmiş veya açık | `NEW`, `PENDING`, `PARTIALLY_FILLED` | Siparişi aktif tutun ve WebSocket veya REST güncellemelerle uzlaşın. |
| Tamamlandı | `FILLED` | Son doldurulan miktar ve uygulama kayıtlarını uygulayın. |
| Tam dolum olmadan kapalı | `CANCELED`, `REJECTED`, `PARTIALLY_FILLED_CANCELED` | Aktif işlemeyi durdurun ve sebep ile uygulanan miktarı koruyun. |
