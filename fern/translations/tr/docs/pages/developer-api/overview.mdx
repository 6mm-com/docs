Dasturchilar bo'limi backend muhandislari va platforma jamoalari uchun mo'ljallangan bo'lib, ular to'g'ridan-to'g'ri 6MM APIsbilan integratsiyalashadi. U ishlab chiqarishdan oldin zarur bo'lgan konventsiyalar, xavfsizlik modeli, REST resurslari, oqim kanallari va operatsion tekshiruvlarni tushuntiradi.

<h2 id="documentation-areas">Hujjatlashtirish sohalari</h2>

| Hudud | Nimani qamrab oladi |
| --- | --- |
| Integratsiya o'rnatish | Xizmat manzillari, so'rov konventsiyalari, javob shakli va kirish rejimlari. |
| Autentifikatsiya va xavfsizlik | JWT, API Key ruxsatlari, HMAC imzolash, qayta ko'rishdan himoya va vaqt sinxronizatsiyasi. |
| REST API | Ommaviy nuqtalar, foydalanuvchi/hisob ma'lumotlari, buyurtmalar, pozitsiyalar va bozor ma'lumotlari. |
| WebSocket | Ulanish hayot aylanishi, ommaviy bozor oqimlari va xususiy foydalanuvchi oqimlari. |
| Ma'lumot va muammolarni hal qilish | Asosiy ko'rsatkichlar, xato kodlari va amaliy integratsiya tavsiyalari. |

<h2 id="production-checklist">Ishlab chiqarish ro'yxati</h2>

- API sirlarni faqat orqa tomonda saqlang.
- Imzolangan so'rovlardan oldin server vaqtini sinxronlashtirish.
- Barcha raqamli aniqlik maydonlarini satr sifatida ko'r, agar sahifada aniq boshqacha ko'rsatilmagan bo'lsa.
- Buyurtma oqimlari atrofida idempotentlik, so'rov IDlari va tuzilgan loglardan foydalanish.
- Operatsion tizimlarda doimiy holatda qolishi kerak bo'lgan holatlar uchun WebSocket oqimlariga obuna bo'lish.
- Ishga tushirishdan oldin xato kodlarini ko'rib chiqish va xatti-harakatlarni qayta sinab ko'rish.
