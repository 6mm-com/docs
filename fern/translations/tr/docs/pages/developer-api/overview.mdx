<h2 id="documentation-areas">Belgeleme alanları</h2>

| Alan | Kapsamı |
| --- | --- |
| Entegrasyon kurulumu | Hizmet adresleri, istek konvansiyonları, yanıt şekli ve erişim modları. |
| Kimlik doğrulama ve güvenlik | JWT, API Key izinleri, HMAC imzalama, tekrar izleme koruması ve zaman senkronizasyonu. |
| REST API | Açık uç noktalar, kullanıcı/hesap verileri, emirler, pozisyonlar ve piyasa verileri. |
| WebSocket | Bağlantı yaşam döngüsü, kamu piyasası akışları ve özel kullanıcı akışları. |
| Referans ve sorun giderme | Enumlar, hata kodları ve pratik entegrasyon önerileri. |

<h2 id="production-checklist">Üretim kontrol listesi</h2>

- API sırları sadece arka uçta sakla.
- İmzalanmış isteklerden önce sunucu zamanını senkronize edin.
- Tüm sayısal hassasiyet alanlarını bir sayfa açıkça aksi belirtmedikçe dizî olarak ele alın.
- Sipariş akışları etrafında idempotensi, istek kimlikleri ve yapılandırılmış loglar kullanın.
- Operasyonel sistemlerde güncel kalması gereken durum için WebSocket akışlarına abone olmak.
- Başlatmadan önce hata kodlarını gözden geçirin ve davranışı tekrar denedin.
