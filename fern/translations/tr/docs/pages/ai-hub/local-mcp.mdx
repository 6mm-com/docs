> **Planlandı — henüz başlatılmadı**
> AI Hub planlanmış bir özelliktir. Bu sayfadaki yetenekler, uç noktalar, komutlar ve istemci yapılandırmaları önerilen tasarımı açıklamaktadır ve şu anda mevcut değildir. Nihai kullanılabilirlik ve kurulum talimatları lansman sırasında duyurulacaktır.


Yerel MCP, bir AI istemcisinin özel hesap bağlamına veya gelecekteki kontrollü ticaret araçlarına ihtiyaç duyduğu durumlarda önerilen kurulumdur.

MCP sunucusu kullanıcının makinesinde çalışır. AI istemcisi yerel 6MM araçlarını çağırır ve yerel sunucu, kullanıcı tarafından yapılandırılan kimlik bilgilerini kullanarak 6MM APIs ile iletişim kurar.

<span id="what-your-ai-client-can-do" data-sixmm-canonical-anchor="what-your-ai-client-can-do" aria-hidden="true"></span>

## AI istemcinizin yapabilecekleri

Yerel MCP ile bir AI istemcisi, 6MM araçlarını kontrollü bir şekilde kullanabilir:

- Canlı ve geçmiş piyasa verilerini alın.
- Salt okunur kimlik bilgileri etkinleştirildiğinde hesap bakiyelerini, pozisyonları, açık emirleri, doldurmaları ve fonlama kayıtlarını okuyun.
- Portföy riskini, marj kullanımını ve tasfiye riskini açıklayın.
- Herhangi bir gerçek sipariş verilmeden önce siparişleri önizleyin.
- Daha sonraki kontrollü ticaret aşamalarında, emirleri yalnızca açık izin ve risk kontrollerinden sonra oluşturun veya iptal edin.

Kimlik bilgilerinin kullanıcının makinesinde kalması gerektiğinde Yerel MCP kullanın.

## Mimarlık

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

## Örnek konfigürasyon

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

## Önerilen izin katmanları

| Aşama | Aletler | Notlar |
| --- | --- | --- |
| Herkese açık veriler | Piyasalar, hisse senedi, sipariş defteri, klines, işlemler, fonlama | Özel hesaba erişim yok. |
| Hesap okundu | Bakiyeler, pozisyonlar, açık emirler, doldurmalar | Salt okunur API anahtar kapsamını gerektirir. |
| Ticaret önizlemesi | Önizleme siparişi, marj etkisi, ücret tahmini | Sipariş vermiyor. |
| Kontrollü ticaret | Sipariş oluşturma, iptal etme, değiştirme | Açık izin, onay ve risk kontrolleri gerektirir. |

<span id="first-setup-checklist" data-sixmm-canonical-anchor="first-setup-checklist" aria-hidden="true"></span>

## İlk kurulum kontrol listesi

1. MCP paketini yükleyin.
2. Salt okunur bir API anahtarı oluşturun veya yapılandırın.
3. Test ağında başlayın.
4. MCP sunucusunu AI istemci yapılandırmasına ekleyin.
5. Müşteriden mevcut 6MM araçları listelemesini isteyin.
6. Bir kamu piyasası veri sorgusu çalıştırın.
7. Ancak bundan sonra gerekirse hesap okuma kimlik bilgilerini ekleyin.

## Güvenlik notları

Yerel MCP varsayılan olarak salt okunur ve test ağına ayarlanmalıdır. Ticaret araçları önizleme, kullanıcı onayı, idempotency anahtarları, kavramsal limitler ve hizmet tarafı risk kontrollerini gerektirmelidir.
