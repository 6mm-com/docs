> **Planlandı — henüz başlatılmadı**
> AI Hub planlanmış bir özelliktir. Bu sayfadaki yetenekler, uç noktalar, komutlar ve istemci yapılandırmaları önerilen tasarımı açıklamaktadır ve şu anda mevcut değildir. Nihai kullanılabilirlik ve kurulum talimatları lansman sırasında duyurulacaktır.


6MM CLI, kabuk komutlarını yürütebilen kullanıcılar, komut dosyaları ve AI Aracıları için komut satırı giriş noktasıdır.

Yapay zeka ortamı terminal komutlarını doğrudan çalıştırabildiğinde CLI kullanın. Ayrı bir MCP sunucusu gerekmediğinden bu genellikle aracıları kodlamak için en basit yoldur. Aracıların terminal biçimlendirmesine bağlı kalmadan sonuçları ayrıştırabilmesi için CLI varsayılan olarak kararlı JSON döndürmelidir.

<span id="what-the-cli-is-good-for" data-sixmm-canonical-anchor="what-the-cli-is-good-for" aria-hidden="true"></span>

## CLI ne işe yarar

- Bir terminalden hızlı piyasa verileri sorguları.
- Codex, Claude Code, Gemini CLI veya benzer araçlarda aracı odaklı analiz.
- 6MM verisine ihtiyaç duyan CI veya zamanlanmış komut dosyaları.
- Yerel kimlik bilgileri yapılandırıldığında hesap okuma kontrolleri.
- Aracının parametreleri hazırladığı ancak sipariş vermediği sipariş önizleme akışları.

<span id="example-commands" data-sixmm-canonical-anchor="example-commands" aria-hidden="true"></span>

## Örnek komutlar

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

## Çıkış modları

| Mod | Kullanım örneği |
| --- | --- |
| JSON | AI Aracıları, komut dosyaları ve otomasyon için varsayılan. |
| Masa | İnsan tarafından okunabilen terminal incelemesi. |
| Çiğ | Hata ayıklama ve entegrasyon testleri. |

<span id="recommended-safety-defaults" data-sixmm-canonical-anchor="recommended-safety-defaults" aria-hidden="true"></span>

## Önerilen güvenlik varsayılanları

- Varsayılan ortam testnet'tir.
- Varsayılan çıkış JSON şeklindedir.
- Ticaret komutları açık bir katılım gerektirir.
- Ana ağ siparişinin oluşturulması onay gerektirir.
- Önizleme modu oluşturmadan önce kullanılabilir.
- Hatalar, kararlı kodları ve net mesajları içerir.

<span id="agent-usage" data-sixmm-canonical-anchor="agent-usage" aria-hidden="true"></span>

## Aracı kullanımı

Kullanıcı açıkça önizleme veya alım satım eylemleri istemediği sürece AI Aracıları salt okunur komutları tercih etmelidir.

Örnek istem:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
