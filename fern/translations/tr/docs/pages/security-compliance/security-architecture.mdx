6MM xavfsizlik hujjatlari hamkor ishlab chiqarishga tayyorgarlikka e'tibor qaratadi. Maqsad savdo infratuzilmasini barqaror saqlash va mas'uliyat chegaralarini aniq ko'rsatishdir.

<h2 id="security-layers">Xavfsizlik qatlamlari</h2>

| Qatlam | Diqqat markazi |
| --- | --- |
| Infratuzilma | Tarmoq izolyatsiyasi, shifrlangan xizmat aloqasi, monitoring va faollashtirish. |
| Savdo tizimlari | Deterministik moslashtirish, marja tekshiruvlari, xavf nazorati va suiiste'mollikning oldini olish. |
| Integratsiya xavfsizligi | API kalitlar, HMAC imzolash, webhook imzolari, qayta o'yin himoyasi va faqat backend sirlari. |
| Hamkor operatsiyalar | Foydalanuvchi sessiyasini tasdiqlash, aktivlarni saqlash, mijozlarni qo'llab-quvvatlash va mahalliy muvofiqlik nazorati. |

<h2 id="partner-responsibilities">Hamkorlik mas'uliyatlari</h2>

- API sirlarni saqlab, brauzerlar va mobil ilovalardan kirish kalitlarini olib chiqish.
- Hamkor foydalanuvchi sessiyalarini tasdiqlashdan oldin savdo kirish ma'lumotlarini berish.
- Webhook idempotentsiyasi va terminal holatini tekshirishni amalga oshirish.
- Hisob, buyurtma, uzatish va webhook oqimlari uchun operatsion loglarni yuritish.

<h2 id="integration-trust-boundaries">Integratsiya ishonch chegaralari</h2>

| Chegara | Zarur boshqaruv |
| --- | --- |
| Brauzer yoki ilovadan hamkor backendga | Har qanday savdo guvohnomasini berishdan oldin hamkor sessiyasini tasdiqlang. |
| Hamkor orqa tizimni 6MM API | Keng qamrovli ma'lumotlar, so'rovlarni imzolash, vaqt sinxronizatsiyasi va himoyalangan maxfiy xotiradan foydalaning. |
| 6MM hamkor endpointga webhook | Imzoni xom so'rov tanasi bilan solishtiring, eskirgan yoki noto'g'ri xabarlarni rad eting, va takrorlanishlarni deduplicate qiling. |
| Savdo shtatidan hamkor yozuvlarga | Buyruqlar, pozitsiyalar, balanslar va o'tkazmalarni barqaror identifikatorlar va terminal-holat tekshiruvlari yordamida muvofiqlashtirish. |

<h2 id="production-verification">Ishlab chiqarishni tekshirish</h2>

- Test muddati o'tgan, bekor qilingan va noto'g'ri ko'rsatilgan ma'lumotlar.
- O'zgartirilgan webhook tanalarini, takroriy callbacklarni, kechiktirilgan callbacklarni va endpoint timeoutlarni sinash.
- Jurnallar sirlarni, kirish tokenlarini va maxfiy so'rov yuklarini yashirishini tasdiqlash.
- Takroriy imzo nosozliklari, g'ayrioddiy tartib faolligi, muvofiqlashtirish farqlari va ulanish beqarorligi haqida ogohlantirish.
- Egasi va javob yo'lini hujjatlashtirish, veb-xek nosozligi va savdo hodisalari uchun hujjatlashtiring.
