Xavfsizlik va muvofiqlik hujjatlari hamkor jamoalar uchun ishlab chiqarishni tayyorlashda 6MM savdo infratuzilmasidan foydalanish uchun yoziladi. U xavfsizlik arxitekturasi, API/SDK nazoratlari, muvofiqlikka tayyorgarlik, huquqiy chegaralar va ishga tushirish tayyorligini bitta ko'rib chiqish yo'liga bog'laydi.

<h2 id="documentation-map">Hujjatlashtirish xaritasi</h2>

| Hudud | Maqsad |
| --- | --- |
| Xavfsizlik arxitekturasi | Savdo infratuzilmasi, API/SDK kirish va hamkor operatsiyalari qanday himoyalanishini tushuning. |

| Moslashuvga tayyorgarlik | Litsenziya qo'llab-quvvatlash kontekstini, uchirish tekshiruvlarini va hamkor tomonidagi operatsion nazoratlarni tayyorlash. |

<h2 id="recommended-reading-order">Tavsiya etilgan o'qish tartibi</h2>

1. Avval Xavfsizlik Arxitekturasi va Hamkorlar Mas'uliyati Chegarasidan boshlang.
2. Backend integratsiyasidan oldin API Key boshqaruvi, so'rovlarni imzolash va Webhook idempotentsiyasini ko'rib chiqing.
3. Mintaqaviy uchirishga tayyorgarlikdan oldin muvofiqlik ko'rinishi va litsenziya qo'llab-quvvatlashni ko'rib chiqish.
4. Savdo funksiyalarini foydalanuvchilarga taqdim etishdan oldin huquqiy sahifalar va ishga tushirish ro'yxatini ko'rib chiqing.
