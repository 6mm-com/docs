Güvenlik ve uyumluluk belgeleri, 6MM ticaret altyapısının üretim kullanımını hazırlayan ortak ekipler için yazılır. Güvenlik mimarisi, API/SDK kontrolleri, uyum hazırlığı, yasal sınırlar ve başlatma hazırlığını tek bir inceleme yolunda birleştirir.

## Dokümantasyon haritası

| Alan | Amaç |
| --- | --- |
| Güvenlik mimarisi | Ticaret altyapısının, API/SDK erişiminin ve ortak operasyonlarının nasıl korunduğunu anlayın. |
| API ve webhook güvenliği | Arka uç entegrasyonlarını imzalama, gizli depolama ve idempotent işleme yoluyla koruyun. |
| Uyum hazırlığı | Lisans destek bağlamı, fırlatma kontrolleri ve ortak tarafı operasyonel kontroller hazırla. |
| Hukuki belgeler | Üretim başlatmadan önce şartları, gizliliği ve sorumluluk sınırlarını gözden geçirin. |

<span id="recommended-reading-order" data-sixmm-canonical-anchor="recommended-reading-order" aria-hidden="true"></span>

## Önerilen okuma sırası

1. Güvenlik Mimarisi ve Ortak Sorumluluk Sınırı ile başlayın.
2. Backend entegrasyonundan önce API Key Yönetimi, İstek İmzalama ve Webhook idempotensi'yi gözden geçirin.
3. Bölgesel fırlatma hazırlığından önce Uyum Genel Görünümünü ve Lisans Desteğini gözden geçirin.
4. Kullanıcılara işlem işlevselliğini tanıtmadan önce yasal sayfaları ve başlatma kontrol listesini gözden geçirin.
