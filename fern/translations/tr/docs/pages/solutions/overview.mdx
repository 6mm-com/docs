<h2 id="how-the-solutions-connect">Çözümler nasıl bağlanır</h2>

Çoğu ortak uygulaması birden fazla 6MM yeteneği birleştirir. Beyaz etiketli borsa, kurumsal likidite, uyum desteği ve API entegrasyonları kullanabilir. Gömülü bir ticaret ortağı, Trading Widget SDK ile başlayıp daha sonra arka uç Agent SDK akışları, webhook işleme ve operasyonel kaynakları ekleyebilir.
