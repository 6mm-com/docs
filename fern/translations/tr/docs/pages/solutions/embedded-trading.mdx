Embedded API / SDK Ticaret Sistemi, zaten trafiğin, kullanıcıların veya iş akışlarının sahibi olan ve sıfırdan tam bir borsa kurmadan işlem eklemek isteyen ortaklar için tasarlanmıştır.

<span id="what-it-provides" data-sixmm-canonical-anchor="what-it-provides" aria-hidden="true"></span>

## Ne sağladığı

- Gömülü ticaret terminali Trading Widget SDK
- Agent SDKs üzerinden partner arka uç entegrasyonu
- Kullanıcı kimliği bağlaması ve giriş-token akışları
- Varlık transferi, emri, pozisyon ve hesap API erişimi
- Operasyonel sistemler için olay, webhookve yaşam döngüsü entegrasyonu

<span id="recommended-architecture" data-sixmm-canonical-anchor="recommended-architecture" aria-hidden="true"></span>

## Önerilen mimari

| Katman | Sorumluluk |
| --- | --- |
| Partner ön uç | Giriş noktasını barındırır ve 6MM ticaret arayüzünü gömyer. |
| Ortak backend | API sırları saklar, kullanıcıları doğrular, gömülü tokenlar çıkarır ve webhooksişler. |
| 6MM ticaret altyapısı | İşlem arayüzü, eşleştirme, risk, likidite, hesap durumu ve işlem yaşam döngüsü ile ilgilenir. |

## Bir entegrasyon yolu seçin

| Gereksinim | Önerilen rota |
| --- | --- |
| En hızlı web entegrasyonuyla tam işlem arayüzü | Trading Widget |
| Arka uç kullanıcı bağlaması, transfer, giriş URL ve webhook işleme | Agent SDK |
| Tamamen özel ürün ve sipariş iş akışları | REST API + WebSocket |
| Daha geniş operasyonel kapsama sahip markalı değişim deneyimi | Beyaz etiketli değişim |

Son tasarım bu yolları birleştirebilir. Uygulama başlamadan önce kimlik doğrulama, varlık sahipliği, sorumluluk sınırları, izleme ve üretim desteğini onaylayın.
