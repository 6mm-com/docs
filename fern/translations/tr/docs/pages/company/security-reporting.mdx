Xavfsizlik hisobotlari 6MM jamoasi ta'sirni baholash va muammoni xavfsiz takrorlash uchun yetarli texnik kontekstni o'z ichiga olishi kerak.

<h2 id="reportable-issues">Hisobot qilinadigan masalalar</h2>

- API, SDK, webhook, autentifikatsiya yoki savdo kirish oqimlaridagi zaifliklar.
- Savdo halolligi yoki foydalanuvchi xavfsizligiga ta'sir qilishi mumkin bo'lgan shubhali ishlab chiqarish xatti-harakati.
- Ma'lumotlar sizib chiqishi yoki ruxsatsiz kirish gumon qilinmoqda.
- Tizim barqarorligiga ta'sir qilishi mumkin bo'lgan suiiste'mol naqshlari.

<h2 id="include-in-the-report">Hisobotga kiriting</h2>

- Ta'sirlangan muhit va oxirgi nuqta.
- Vaqt oralig'i va ko'paytirish bosqichlari.
- Jurnallar, so'rov IDlari, webhook hodisa identifikatorlari yoki skrinshotlar.
- Muammo hozirda faol yoki yo'qmi.

<h2 id="safe-reporting-guidelines">Xavfsiz hisobot ko'rsatmalari</h2>

- Tuzatilmagan zaiflikni ommaga oshkor qilmang.
- Muammoni isbotlash uchun talab qilinadigan ma'lumotlarga kirish, yuklab olish, o'zgartirish yoki saqlash taqiqlanadi.
- Xizmatdan voz kechish, buzuvchi, ijtimoiy muhandislik yoki mablag' harakati testlarini o'tkazmang.
- Test hisoblari va eng kichik xavfsiz kontseptsiya isbotidan foydalaning.
- Parollar, API sirlar, kirish tokenlari, shaxsiy kalitlar va bog'liq bo'lmagan shaxsiy ma'lumotlarni ilovalardan olib tashlash.

<h2 id="suggested-report-format">Tavsiya etilgan hisobot formati</h2>

```text
Title:
Affected component and environment:
First observed time (UTC):
Issue status:
Technical description:
Reproduction steps:
Expected security behavior:
Observed behavior:
Potential impact:
Sanitized evidence:
Researcher or partner contact:
```

<h2 id="security-contact">Xavfsizlik aloqasi</h2>

Zaiflik va shoshilinch xavfsizlik hisobotlarini shaxsiy manzilga yuboring:

[security@6mm.com](mailto:security@6mm.com)

Umumiy integratsiya muammolari [Support Request Template](/tr/resources/support-request-template) dan foydalanishi kerak. Tadqiqotchilar, shuningdek, [Bug Bounty Program](/tr/security-compliance/bug-bounty-program) doirasi va mas'uliyatli oshkor qilish kutishlarini ko'rib chiqishlari kerak.
