<h2 id="service-endpoints">サービスエンドポイント</h2>

| 種類      | 終着点              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<h2 id="time-and-numeric-values">時間と数値</h2>

* 特に指定がない限り、タイムフィールドはUnixのミリ秒タイムスタンプです。
* 日々の統計、バランススナップショット、取引量統計はデフォルトで日 UTC 境界を使用しています。
* 量、価格、数量、レートなどの精度に敏感なフィールドは文字列として送信されます。
* `orderId`、 `conditionId`、 `strategyId` のような大きな整数IDは JSONの文字列として返されます。

<h2 id="response-format">応答フォーマット</h2>

成功した対応:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

エラー応答:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

注記:

* ビジネスエラーは通常、統一された JSON 構造を返します。インテグレーターはまずこの `code` を確認するべきです。
* 認証失敗は HTTP `401`を返すことがあります;レートリミットは HTTP `429`を返すことがあります。
* リクエストヘッダーで `X-Request-ID` を送信できます。サーバーは応答で `requestId` として返します。
