6MM は、パートナー システムとの統合とホワイトラベル プラットフォームという 2 つのアカウント アクセス モデルをサポートしています。プラットフォームによって提供されるエントリを使用します。アカウントの作成、認証、プロファイル管理は、選択したモデルによって異なります。

<h2 id="registration-model">アカウントモデルを選択してください</h2>

| エリア | パートナー統合 | ホワイトラベルプラットフォーム |
| --- | --- | --- |
| アカウントソース | ユーザーはパートナー システムにアカウントを持っており、取引ユーザーをバインドまたは同期します。 | ユーザーは、ホワイトラベル プラットフォームのアカウント システムに属します。 |
| アクセスエントリ | パートナーのアプリ、Web サイト、または埋め込み取引エントリ。 | ホワイトラベル プラットフォームのブランド ドメインとログイン ページ。 |
| 認証 | パートナーはユーザーを検証し、そのバックエンドが必要な取引アクセス資格情報を取得します。 | ログイン、検証、アカウントのセキュリティは、プラットフォームの有効な設定に従います。 |
| アカウント管理 | パートナーはユーザー プロファイルを管理します。取引システムは、必要なユーザー マッピングと取引記録を維持します。 | ホワイトラベル アカウント システムと権限のある管理者が、ユーザー プロファイル、アカウント ステータス、セキュリティ設定を管理します。 |

<h2 id="login-method-1-partner-embedded-access">パートナー統合</h2>

1. パートナーのアカウント システムを通じてサインインします。
2. パートナー バックエンドはセッションを検証し、対応する取引ユーザーをバインドまたは識別します。
3. バックエンドは、サポートされている統合を通じて、必要な取引アクセス資格情報またはエントリ URL を取得します。
4. 埋め込み取引インターフェイスまたはパートナーが提供する承認された取引エントリを開きます。

アカウントにアクセスしても、それ自体で資金が取引に利用できるようになるわけではありません。パートナーの資金調達プロセスに従って、注文する前に利用可能な永久アカウントの残高を確認してください。

<h2 id="login-method-2-6mm-account-login-partner-issued-credentials">ホワイトラベルのプラットフォームへのアクセス</h2>

ホワイトラベル プラットフォームによって提供されるブランド ドメインとアカウント エントリを使用します。自己登録が利用可能かどうか、アカウントの開設方法、および有効なログインまたは ID 検証方法は、そのプラットフォームの構成によって異なります。

プラットフォームのアカウント システムと権限のある管理者は、権限の範囲内でプロファイル管理、アカウント ステータス、セキュリティ操作を処理します。パスワードの回復、連絡先情報の変更、アカウント制限については、プラットフォームの検証プロセスに従ってください。

サインインした後、プラットフォームのサポートされている資金調達プロセスを通じて資金を準備します。無期限取引の場合、必要な決済資産をファンディング口座から無期限口座に移管し、移管結果を確認します。

<h2 id="user-ownership-and-data-responsibility">アカウントとデータの責任</h2>

2 つのモデルには異なる責任の境界があります。パートナー統合では、取引に必要なユーザー マッピングと記録を維持しながら、パートナー側のアカウント管理を維持します。ホワイトラベル プラットフォームは、独自のアカウント プロセスと管理権限を使用してユーザーを管理します。

収集、保存、または表示される情報、ID 検証要件、およびサポート責任は、実際の展開に合わせて定義する必要があります。 1 つのモデルのアカウント管理の前提条件をすべてのプラットフォームに適用しないでください。

<h2 id="design-principles">取引を開始する前に</h2>

- 正しいプラットフォーム ドメインとアカウントを使用していることを確認してください。
- そのプラットフォームで必要な ID チェックまたはセキュリティチェックを完了します。
- アカウントに取引アクセス権があることを確認し、制限がないか確認してください。
- 永久アカウントの利用可能な残高を確認します。サインインしても資金は自動的に転送されません。
- アカウントへのアクセスや本人確認に注意が必要な場合は、プラットフォームのサポート チームにお問い合わせください。
