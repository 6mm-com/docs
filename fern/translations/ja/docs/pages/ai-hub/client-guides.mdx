クライアント ガイドは、ユーザーが 6MM AI Hub をすでに使用しているツールに接続するのに役立ちます。

<h2 id="start-with-the-ai-tool-users-already-know">ユーザーがすでに知っている AI ツールから始める</h2>

<CardGroup cols={2}>
<Card title="ChatGPT デスクトップ" icon="fa-duotone fa-message-bot" href="/ja/ai-hub/clients/chatgpt-desktop">

</Card>
<Card title="クロードデスクトップ" icon="fa-duotone fa-comments" href="/ja/ai-hub/clients/claude-desktop">

</Card>
<Card title="クロード コード CLI" icon="fa-duotone fa-terminal" href="/ja/ai-hub/clients/claude-code-cli">
エージェントがコマンドを実行して JSON の出力を検査できる場合は、CLI またはローカル MCP を使用します。
</Card>
<Card title="コーデックス CLI" icon="fa-duotone fa-code" href="/ja/ai-hub/clients/codex-cli">
SDK、API、webhook の実装に重点を置いたワークフローを使用し、タスクを起動します。
</Card>
<Card title="カーソル" icon="fa-duotone fa-arrow-pointer" href="/ja/ai-hub/clients/cursor">

<Card title="ジェミニ CLI" icon="fa-duotone fa-sparkles" href="/ja/ai-hub/clients/gemini-cli">

<Card title="VS コード / GitHub コパイロット" icon="fa-duotone fa-laptop-code" href="/ja/ai-hub/clients/vscode-copilot">

<Card title="ウィンドサーフィン" icon="fa-duotone fa-wind" href="/ja/ai-hub/clients/windsurf">

</Card>

<h2 id="each-client-guide-should-include">各クライアント ガイドには次の内容が含まれている必要があります。</h2>

- サポートされているモード: CLI、ローカル MCP、ホスト型 MCP、またはリモート MCP。
- インストールコマンド。
- 設定ファイルのパス。
- 環境変数。
- テストネットの例。
- 検証コマンドまたはプロンプト。
- よくあるエラー。
- セキュリティに関するメモ。

<h2 id="example-verification-prompts">検証プロンプトの例</h2>

```text
Use 6MM to list available markets.
```

```text
Use 6MM to check BTC-USDT-PERP orderbook depth and summarize liquidity.
```

```text
Using 6MM testnet, preview a small BTC long order and explain the margin impact. Do not place the order.
```
