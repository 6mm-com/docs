> **計画中 – まだ開始されていません**
> AI Hub は計画中の機能です。このページの機能、エンドポイント、コマンド、およびクライアント構成は、提案された設計について説明したものであり、現在は利用できません。最終的な可用性とセットアップ手順は発売時に発表されます。


AI Hub は段階的にリリースされ、機密性の高い取引機能が保護されたままユーザーが早期に価値を享受できるようにする必要があります。

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## フェーズ 1: 公開市場 AI へのアクセス

目標: サポートされている AI クライアントが公式の 6MM 市場データを読み取れるようにします。

成果物：

- 共有 SDK / API クライアント。
- CLI 公開市場コマンド。
- ローカル MCP の公開市場ツール。
- MCP の公開市場ツールをホストしました。
- 市場、手数料、リスクルール、システムステータスに関するリソース。
- クライアントのインストール ガイド。

含まれないもの:

- アカウントのクエリ。
- リアルな取引。
- API キーのホスティング。

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## フェーズ 2: アカウントの読み取り

目標: ユーザーが自分のアカウントのコンテキストを安全に検査できるようにします。

成果物：

- 読み取り専用の API キー スコープ。
- アカウントの概要。
- バランス。
- ポジション。
- 注文をオープンします。
- 満たします。
- 資金の支払い。
- ポートフォリオのリスク プロンプト。

推奨される展開:

- ローカル MCP。
- CLI.
- リモート MCP は自己ホスト型です。

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## フェーズ 3: 取引プレビュー

目標: AI が注文を実行せずに生成できるようにします。

成果物：

- `preview_order`.
- リスクチェック。
- マージンの影響。
- 料金の見積もり。
- 清算の影響。
- 実行計画のプロンプト。

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## フェーズ 4: 管理された取引

目標: 強力なガードレールを使用してのみ実際の取引をサポートします。

成果物：

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- 冪等性。
- 最大の想定上の制限。
- 明示的な確認。
- 監査ログ。

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## フェーズ 5: エージェント スキル

目標: 共通の市場分析とリスク ワークフローを製品化します。

成果物：

- マーケットアナリストのスキル。
- ポートフォリオのリスクスキル。
- 研究スキルに資金を提供する。
- 清算保護スキル。
- 実行プランナーのスキル。
- タスクライブラリの例。
