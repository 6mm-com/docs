> AI Hub は計画中の機能です。このページの機能、エンドポイント、コマンド、およびクライアント構成は、提案された設計について説明したものであり、現在は利用できません。最終的な可用性とセットアップ手順は発売時に発表されます。


ChatGPT デスクトップは、自然言語で市場の質問をしたいユーザーにとって馴染みのあるエントリ ポイントです。

ユーザーが公開市場データ、口座概要、ポジションの説明、取引ルールのコンテキスト用の会話型インターフェイスを必要とする場合は、このパスを使用します。

<h2 id="recommended-setup">推奨セットアップ</h2>

| 必要 | 設定 |
| --- | --- |
| 公開市場データ | ホスト MCP |
| プライベートアカウントのコンテキスト | ローカル MCP |
| 再現可能な分析プロンプト | エージェントスキル |
| ターミナルベースのワークフロー | 6MM CLI |

<h2 id="what-users-can-ask">ユーザーが質問できること</h2>

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<h2 id="safety-defaults">安全性のデフォルト</h2>

- まずは公開市場データから始めます。
- アカウントの資格情報が必要な場合は、ローカル MCP を使用します。
- プライベート API キーをユーザーのマシン上に保持します。
- 今後の取引アクションの前に、プレビューと明示的な確認が必要です。
