MCP ツールは、AI クライアントが呼び出すことができるアクションです。各ツールには、明確な説明、JSON スキーマ、権限要件、安定した応答形式、およびエラー モデルが必要です。

<span id="phase-1-public-market-tools" data-sixmm-canonical-anchor="phase-1-public-market-tools" aria-hidden="true"></span>

## フェーズ 1: 公開市場ツール

| 道具 | 目的 |
| --- | --- |
| 6mm_システム_ステータス | サービスと市場の可用性を確認します。 |
| 6mm_マーケット | 利用可能なマーケットと基本的なメタデータをリストします。 |
| 6mm_マーケット_サマリー | 1 つ以上のシンボルの市場状態を要約します。 |
| 6mm_ティッカー | 最新のティッカー データを返します。 |
| 6mm_オーダーブック | 返品注文書の深さ。 |
| 6mm_klines | 歴史的なキャンドルを返します。 |
| 6mm_trades | 最近の公開取引を返します。 |
| 6mm_funding_rates | 現在および過去の資金調達率を返します。 |

## フェーズ 2: アカウント読み取りツール

| 道具 | 目的 |
| --- | --- |
| 6mm_アカウント_概要 | アカウントの状態を要約します。 |

## フェーズ 3 以降: 取引ツール

| 道具 | 目的 |
| --- | --- |
| 6mm_プレビュー_オーダー | 注文を発注せずに検証します。 |
| 6mm_create_order | 確認とリスクチェック後に注文を作成します。 |
| 6mm_注文キャンセル | 1 つの注文をキャンセルします。 |
| 6mm_すべての注文をキャンセル | 対象となるすべての未処理の注文をキャンセルします。 |
| 6mm_修正注文 | 既存の注文を修正します。 |
| 6mm_オーダー_ステータス | 特定の注文のステータスを読み取ります。 |

## ツールの要件

すべてのツールは以下を定義する必要があります。

- AI モデルの説明。
- JSON スキーマを入力します。
- 許可範囲。
- 環境サポート。
- レート制限の動作。
- 安定した応答フィールド。
- エラーコード。
- 監査ログフィールド。
