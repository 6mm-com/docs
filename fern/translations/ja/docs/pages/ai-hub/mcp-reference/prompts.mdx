MCP プロンプトは、MCP サーバーによって公開される再利用可能なワークフローです。これらは、ユーザーが一貫した質問をするのに役立ち、AI クライアントが適切なツールを使用できるようにします。

<h2 id="recommended-prompts">推奨されるプロンプト</h2>

| プロンプト | 目的 |
| --- | --- |
| 市場概要 | 選択したシンボル全体の市場状態を要約します。 |
| 市場_微細構造_分析 | スプレッド、深度、最近の取引、流動性の状況を分析します。 |
| ポートフォリオ_リスク_評価 | ポジション、エクスポージャー、マージン、清算リスクを確認します。 |
| ポジション管理 | ユーザーが位置の状態と可能なアクションを理解できるようにします。 |
| 清算_保護 | 清算リスクとリスク軽減オプションを特定します。 |
| 資金調達率_機会 | 資金調達率と可能性のある機会を比較します。 |
| create_optimal_order | プレビューの前に注文パラメータを計画します。 |
| ヘッジ戦略 | 既存のエクスポージャのヘッジ オプションを検討します。 |
| 取引_相談 | 注文を実行せずに構造化された取引分析を作成します。 |

<h2 id="prompt-safety-rules">迅速な安全ルール</h2>

- 即時出力を財務上のアドバイスとして扱わないでください。
- ユーザーが明示的に要求しない限り、取引ツールを実行しないでください。
- 作成前にプレビューを使用します。
- 仮定とデータソースについて説明します。
- 公開ドキュメントにあるテストネットの例を優先します。
