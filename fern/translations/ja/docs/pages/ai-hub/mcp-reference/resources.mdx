MCP リソースは、AI クライアントがツールを呼び出す前に検査できる読み取り専用コンテキストです。

リソースは、モデルに 6MM に関する安定した構造化された情報を与えることで幻覚を軽減します。

<h2 id="recommended-resource-uris">推奨されるリソース URI</h2>

| リソース | 目的 |
| --- | --- |
| 6mm://システム/config | 環境と機能の構成。 |
| 6mm://システム/ステータス | 現在のシステムと市場の状況。 |
| 6mm://マーケット | 利用可能な市場。 |
| 6mm://market/{symbol} | 契約仕様と市場レベルのメタデータ。 |
| 6mm://手数料 | 料金ルール。 |
| 6mm://リスク/ルール | 取引とリスクのルールの概要。 |
| 6mm://リスク/マージン | マージンと清算のコンテキスト。 |
| 6mm://資金提供/ルール | 資金調達率のルール。 |
| 6mm://api/docs | API リファレンスの概要またはリンク。 |

<h2 id="resource-design-rules">リソース設計ルール</h2>

- リソースを読み取り専用にしておきます。
- 安定したスキーマを使用します。
- タイムスタンプと環境名を含めます。
- 秘密を暴露することは避けてください。
- 長い散文よりも簡潔な構造化データを好みます。
- 詳細が長すぎる場合は、正規ドキュメントへのリンクを作成します。
