> AI Hub は計画中の機能です。このページの機能、エンドポイント、コマンド、およびクライアント構成は、提案された設計について説明したものであり、現在は利用できません。最終的な可用性とセットアップ手順は発売時に発表されます。


ホスト型 MCP は、6MM AI Hub を開始する最も簡単な方法です。

AI クライアントを 6MM がホストする MCP エンドポイントに接続し、公開市場データについて質問します。ローカル サーバーをインストールしたり、クラウド展開を維持したりする必要はなく、公開データに必要なユーザー API キーも必要ありません。

<span id="what-you-can-do" data-sixmm-canonical-anchor="what-you-can-do" aria-hidden="true"></span>

## できること

- ライブおよび過去の市場データをクエリします。
- 利用可能な永久マーケットを参照します。
- 注文書の深さと最近の取引を確認します。
- 資金調達率を比較します。
- 手数料、契約、証拠金、リスクルールのコンテキストを読みます。

ホストされた MCP は、リサーチ、製品探索、公開市場分析に最適です。これは、プライベートアカウントへのアクセスや取引を行うための最初の設定としては適切ではありません。

## 推奨される最初のリリースの範囲

ホストされた MCP は、最初のリリースでは公開情報と読み取り専用情報のみを公開する必要があります。

- 市場。
- ティッカー。
- 本を注文する。
- 最近の取引。
- クラインズ。
- 資金調達率。
- システムのステータス。
- 取引手数料。
- 契約仕様書。
- リスクとマージン ルールのリソース。

<span id="not-supported-in-the-first-release" data-sixmm-canonical-anchor="not-supported-in-the-first-release" aria-hidden="true"></span>

## 最初のリリースではサポートされていません

ホストされた MCP を最初に公開する場所であってはなりません:

- 口座残高。
- ポジション。
- 注文をオープンします。
- 注文の作成。
- 注文のキャンセル。
- 転送または引き出し。
- ユーザー API キーのストレージ。

<span id="why-public-data-first" data-sixmm-canonical-anchor="why-public-data-first" aria-hidden="true"></span>

## なぜ公開データが最初なのか

ホストされている MCP は 6MM によって操作され、ネットワーク経由でアクセスされます。これは便利ですが、ユーザーが秘密鍵 API を送信するデフォルトの場所になるべきではありません。機密性の高いアカウントと取引ワークフローは、ローカル MCP、CLI、またはユーザー管理のリモート MCP から開始する必要があります。

## 動作要件

- すべてのエンドポイントで TLS。
- レート制限をリクエストします。
- 虐待保護。
- 構造化されたログとメトリクス。
- 健康診断。
- ツールの説明とスキーマを明確にします。
- AI クライアントに対する安定したエラー応答。
