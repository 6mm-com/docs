ローカル MCP は、AI クライアントがプライベート アカウント コンテキストまたは将来の制御された取引ツールを必要とする場合に推奨される設定です。

MCP サーバーはユーザーのマシン上で実行されます。 AI クライアントはローカル 6MM ツールを呼び出し、ローカル サーバーはユーザーが構成した資格情報を使用して 6MM APIs と通信します。

<h2 id="what-your-ai-client-can-do">AI クライアントができること</h2>

ローカル MCP を使用すると、AI クライアントは制御された方法で 6MM ツールを使用できます。

- ライブおよび過去の市場データを取得します。
- 読み取り専用の認証情報が有効になっている場合は、口座残高、ポジション、オープン注文、約定、資金記録を読み取ります。
- ポートフォリオのエクスポージャー、証拠金の使用状況、清算リスクについて説明します。
- 実際の注文を行う前に注文をプレビューできます。
- その後の管理取引フェーズでは、明示的な許可とリスク チェックの後にのみ注文を作成またはキャンセルします。

資格情報をユーザーのマシン上に保持する必要がある場合は、ローカル MCP を使用します。

<h2 id="architecture">建築</h2>

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

<h2 id="example-configuration">構成例</h2>

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

<h2 id="recommended-permission-tiers">推奨される権限レベル</h2>

| 階層 | ツール | 注意事項 |
| --- | --- | --- |
| 公開データ | マーケット、ティッカー、オーダーブック、クライン、取引、資金調達 | プライベートアカウントへのアクセスはありません。 |
| アカウントの読み取り | 残高、ポジション、オープンオーダー、約定 | 読み取り専用の API キー スコープが必要です。 |
| 取引プレビュー | プレビュー注文、マージンの影響、手数料の見積もり | 注文はしません。 |
| 管理された取引 | 注文の作成、キャンセル、修正 | 明示的な許可、確認、リスク管理が必要です。 |

<h2 id="first-setup-checklist">最初のセットアップのチェックリスト</h2>

1. MCP パッケージをインストールします。
2. 読み取り専用の API キーを作成または構成します。
3. テストネットで開始します。
4. MCP サーバーを AI クライアント構成に追加します。
5. 利用可能な 6MM ツールのリストをクライアントに依頼します。
6. 公開市場データのクエリを実行します。
7. その後、必要に応じてアカウント読み取り資格情報を追加してください。

<h2 id="security-notes">セキュリティに関する注意事項</h2>

ローカル MCP はデフォルトで読み取り専用およびテストネットに設定する必要があります。取引ツールには、プレビュー、ユーザー確認、冪等性キー、概念的な制限、およびサービス側のリスク チェックが必要です。
