> **計画中 – まだ開始されていません**
> AI Hub は計画中の機能です。このページの機能、エンドポイント、コマンド、およびクライアント構成は、提案された設計について説明したものであり、現在は利用できません。最終的な可用性とセットアップ手順は発売時に発表されます。


6MM Agentic AI Hub は、6MM 市場データ、アカウント ワークフロー、将来の管理された取引操作のための AI- ネイティブ インターフェイスです。

ダッシュボード、API ドキュメント、スクリプトを切り替える代わりに、ユーザーは AI クライアントに 6MM のクエリ、市場状況の説明、アカウント リスクの確認、または注文プレビューの準備を依頼できます。 AI クライアントは、6MM API セキュリティ モデルを置き換えるものではありません。 CLI、MCP、またはワークフロー テンプレートを通じて、構造化された 6MM ツールを呼び出します。

<h2 id="what-you-can-ask-an-ai-client">AI クライアントに質問できること</h2>

次のような質問をする場合は、AI Hub を使用します。

```text
Show me the BTC-USDT-PERP order book and explain current liquidity.
```

```text
Compare BTC and ETH funding rates over the last 24 hours.
```

```text
Check my testnet positions and explain liquidation risk. Do not place orders.
```

```text
Preview a small BTC long order and explain fees, margin impact, and risk checks.
```

<h2 id="why-ai-agents-need-a-dedicated-access-layer">AI エージェントに専用のアクセス層が必要な理由</h2>

AI エージェントは、生の Web ページや構造化されていないコピーされたテキストではなく、構造化されたツールを使用する場合に最適に機能します。 AI Hub は以下を提供します。

| 要件 | 6MM アプローチ |
| --- | --- |
| ライブ市場のコンテキスト | シンボル、オーダーブック、取引、資金調達、手数料、ルールのための公開市場データ ツールとリソース。 |
| 権限のクリア | 公開データ、アカウント読み取り、プレビュー、および制御された取引範囲を分離します。 |
| より安全な実行 | プレビューファーストオーダーフロー、明示的な確認、冪等性、制限、および監査ログ。 |
| クライアントの柔軟性 | さまざまな AI 環境のホスト MCP、ローカル MCP、CLI、リモート MCP、およびエージェント スキル。 |

<h2 id="setup-paths">セットアップパス</h2>

| パス | こんな方に最適 | ユーザーが知っておくべきこと |
| --- | --- | --- |
| ホスト MCP | 公開市場データへの迅速なアクセス | インストールも公開データのユーザー API キーもありません。トレーディングは最初のリリースの目標ではありません。 |
| ローカル MCP | プライベート アカウント コンテキストが必要な AI クライアント | MCP サーバーはローカルで実行され、資格情報はユーザーのマシンに残ります。 |
| CLI | コーディングエージェント、スクリプト、および端末ユーザー | エージェントフレンドリーなコマンド出力を生成し、MCP サーバーなしで使用できます。 |
| リモート MCP | 独自のエンドポイントを必要とする機関やチーム | ユーザーまたは機関は、ホスティング、資格情報、ネットワーク アクセス、およびログを制御します。 |
| エージェントスキル | 反復可能なワークフロー | スキルは、承認されたツールを使用した分析とリスクのステップを通じて AI をガイドします。 |

<h2 id="what-is-available-first">最初に利用できるもの</h2>

AI Hub は、公開市場データと取引ルールのリソースから始める必要があります。

- 市場。
- ティッカー。
- 本を注文する。
- 取引。
- クラインズ。
- 資金調達率。
- システムのステータス。
- 手数料、契約仕様、証拠金ルール、リスク ルールのリソース。

プライベートアカウントへのアクセスと取引は段階的に行う必要があります。

- アカウント読み取りツールには、明示的な読み取り専用資格情報が必要です。
- 注文のプレビューは、実際の注文を作成する前に行う必要があります。
- 制御された取引には、権限スコープ、サービス側のリスク チェック、ユーザー確認、冪等性、および監査ログが必要です。
