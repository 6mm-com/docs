次の 2 つの質問に基づいてセットアップを選択してください。

1. どの AI クライアントを使用したいですか?
2. パブリック データのみが必要ですか、プライベート アカウント アクセスが必要ですか、それとも取引ワークフローが必要ですか?

よくわからない場合は、パブリック データの場合はホスト MCP、プライベート アカウントのワークフローの場合はローカル MCP から始めてください。

## ユースケース別に選ぶ

<CardGroup cols={2}>
<Card title="公開市場データのみが必要です" icon="fa-duotone fa-cloud" href="/ja/ai-hub/hosted-mcp">
ホスト型 MCP を使用します。ローカル インストール、ユーザー API キー、プライベート アカウント アクセスはありません。
</Card>
<Card title="AI クライアントに私のアカウントを読んでもらいたい" icon="fa-duotone fa-computer" href="/ja/ai-hub/local-mcp">
読み取り専用資格情報でローカル MCP を使用します。テストネットまたは読み取り専用モードで開始します。
</Card>
<Card title="私のエージェントは端末コマンドを実行できます" icon="fa-duotone fa-terminal" href="/ja/ai-hub/cli">
6MM CLI を使用します。これは、Codex、Claude Code、Gemini CLI、スクリプト、CI タスクでは簡単です。
</Card>
<Card title="私のチームにはマネージド エンドポイントが必要です" icon="fa-duotone fa-server" href="/ja/ai-hub/remote-mcp">
リモート MCP を使用します。チームが管理するインフラストラクチャにサーバーを展開します。
</Card>
</CardGroup>

## クイックデシジョンテーブル

| ゴール | 推奨セットアップ | なぜ |
| --- | --- | --- |
| AI クライアントに公開市場データを要求する | ホスト MCP | ローカルインストールや API キーは必要ありません。 |
| Claude Desktop、Cursor、または ChatGPT Desktop で 6MM ツールを呼び出します | ローカル MCP | AI は、ユーザーが制御するローカル サーバーを介してツールを呼び出します。 |
| Codex、Claude Code、Gemini CLI、またはスクリプトで 6MM を呼び出します | CLI | コマンド出力は JSON になるため、エージェントは簡単に解析できます。 |
| 会社管理の MCP エンドポイントを提供します | リモート MCP | この機関は、ホスティング、資格情報、アクセス、ログを管理します。 |
| 繰り返される分析またはリスクのワークフローを標準化する | エージェントスキル | テンプレートは、ツールの使用法、ガードレール、出力形式を定義します。 |

## AIクライアントによる選択

| AIクライアント | ホスト MCP | ローカル MCP | CLI | 注意事項 |
| --- | --- | --- | --- | --- |
| クロードデスクトップ | 可能 | 推奨 | 可能 | アカウントコンテキストが必要な場合は、ローカル MCP を使用してください。 |
| クロード.ai ウェブ | サポートされている場合に推奨 | 適用できない | 適用できない | 公開市場データのみに最適です。 |
| ChatGPT デスクトップ | 可能 | 推奨 | 可能 | プライベート アカウント ツールにはローカル MCP が優先されます。 |
| カーソル | 可能 | 推奨 | 可能 | ローカル MCP はコーディング ワークフローとうまく連携します。 |
| コーデックス CLI | 可能 | 可能 | 推奨 | 通常、CLI が最も直接的なパスです。 |
| クロード コード CLI | 可能 | 可能 | 推奨 | ワークフローに応じて CLI またはローカル MCP。 |
| VS コード / 副操縦士 | 可能 | 推奨 | 可能 | MCP と端末のサポートに依存します。 |
| ジェミニ CLI | 可能 | 可能 | 推奨 | CLI は、最も単純な最初のセットアップです。 |
| ウィンドサーフィン | 可能 | 推奨 | 可能 | ローカル MCP が優先されます。 |

## セットアップパスで選択

| 設定 | インストール | API キーの場所 | 最適な初期スコープ | 口座と取引範囲 |
| --- | --- | --- | --- | --- |
| ホスト MCP | なし | 公開データにはユーザー API キーがありません | 公開市場データ | 最初のリリースには推奨されません |
| ローカル MCP | ユーザーがパッケージをインストールする | ユーザーマシン | 公開データとアカウント読み取り | 今後の取引に推奨されるパス |
| CLI | ユーザーがパッケージをインストールする | ユーザーマシン | 公開データとスクリプト | プレビューや自動化に便利 |
| リモート MCP | ユーザーがサーバーをデプロイする | ユーザークラウドまたは機関クラウド | 公開データまたはアカウント読み取り | ユーザーが展開を制御する場合に可能 |
| スキル | ドキュメントまたはインストール可能なテンプレート | 基盤となるツールに依存する | 分析ワークフロー | ツールの権限に従う必要があります |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## セキュリティの経験則

タスクをサポートする最もリスクの低いセットアップを使用します。

- 公開市場データ: ホストされている MCP で十分です。
- プライベートアカウントデータ: ローカル MCP またはユーザー管理のリモート MCP。
- 取引プレビュー: ローカル MCP または CLI、できれば最初にテストネット。
- 実際の取引: 明示的な許可、プレビュー、確認、制限、および監査ログの後にのみ。
