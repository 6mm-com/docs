エージェントティック スキルは、CLI および MCP ツールの上に構築された高レベルのワークフロー テンプレートです。

これらは、エージェントがいつツールを使用する必要があるか、どのようなアクションが禁止されているか、どのような出力形式を生成するか、どのリスク チェックが必要であるかを定義します。

## おすすめスキル

| スキル | 目的 | デフォルトモード |
| --- | --- | --- |
| 6mm-マーケットアナリスト | 市場の状態、流動性、ボラティリティ、資金調達を分析します。 | 読み取り専用 |
| 6mm ポートフォリオ リスク マネージャー | アカウントのエクスポージャとリスク集中を確認します。 | アカウント読み取り |
| 6mm 資金調達アービトラージ研究者 | 資金提供率と研究の機会を比較します。 | 読み取り専用 |
| 6mm-流動性保護-アシスタント | 清算リスクとリスク軽減オプションを特定します。 | アカウント読み取り |
| 6mmオーダー実行プランナー | 順序パラメータと実行アプローチを計画します。 | プレビューのみ |
| 6mmトレーディングジャーナルアナリスト | 約定、動作、リスクノートを要約します。 | アカウント読み取り |

<span id="what-each-skill-should-include" data-sixmm-canonical-anchor="what-each-skill-should-include" aria-hidden="true"></span>

## 各スキルに含めるべき内容

- 対象となるユーザーシナリオ。
- 必要な CLI または MCP ツール。
- 許可されるアクションと禁止されるアクション。
- 必要な権限層。
- 取引が許可されているかどうか。
- プレビューが必須かどうか。
- 出力形式。
- 危険を警告する行動。
- ユーザープロンプトの例。
