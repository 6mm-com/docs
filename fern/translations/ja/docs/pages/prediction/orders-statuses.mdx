受け入れられた予測注文にはそれぞれ独自の注文番号があります。アップ/ダウン注文もラウンドを参照します。カスタム注文とグリッド注文には共有ラウンドは必要ありません。

<span id="現在および過去の記録" data-sixmm-anchor-target="current-and-historical-records" aria-hidden="true"></span>
<h2 id="current-and-historical-records">現在および過去の記録</h2>

| 表示状態 | 読み方 |
| --- | --- |
| 結果待ち | 最終的な結果はまだ記録されていません |
| 賭けは終了しました | 表示されているベッティング ステージは閉じられています。これは勝ち負けの結果ではありません |
| 勝利した | 注文は勝利結果として記録されます |
| 失った | 注文は負けの結果として記録されます |
| 返金されました | 返金処理は注文ステータスに反映されます。実際の取引を調整する |
| 無効化されました | 注文は無効になります。理由と関連する資金の扱いを確認する |

すべてのゲームがすべての中間ステータスを同じ方法で使用するわけではありません。ステータス ラベルだけでは、アカウントへのクレジットが完了したことを証明するものではありません。

<span id="チェックするフィールド" data-sixmm-anchor-target="fields-to-check" aria-hidden="true"></span>
<h2 id="fields-to-check">チェックするフィールド</h2>

すべてのゲームでは、注文番号、ユーザーの所有権、シンボル、賭け金、オッズ、注文時間、ステータスが公開されます。履歴記録には、実際の支払い、結果情報、決済時間、決済取引番号が追加されます。

- Up/Down はラウンド数と予測/実際の方向を追加します。
- カスタムでは、固定オッズと独立した有効期限が追加されます。
- グリッドは選択したセルと価格間隔を追加します。タイムウィンドウタッチルールを使用して結果フィールドを解釈します。

<span id="変更と重複した送信" data-sixmm-anchor-target="changes-and-duplicate-submissions" aria-hidden="true"></span>
<h2 id="changes-and-duplicate-submissions">変更と重複した送信</h2>

予測注文は永久指値注文のように修正またはキャンセルできると想定しないでください。承認された製品に利用可能なアクションとルールに従ってください。送信の応答が不確かな場合は、別のステークを置く前に元の注文を問い合わせてください。
