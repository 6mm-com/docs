注文する前に、アカウントで予測が有効になっていて、ゲームの結果条件を識別できることを確認してください。

<span id="prepare-your-account" data-sixmm-canonical-anchor="prepare-your-account" aria-hidden="true"></span>

## アカウントを準備する

パートナー プラットフォームを通じて予測にアクセスします。資金調達アカウントの利用可能残高、決済通貨、および参加制限を確認してください。別のアカウントに保持されている残高は、自動的には予測に利用できません。

<span id="select-an-order" data-sixmm-canonical-anchor="select-an-order" aria-hidden="true"></span>

## 注文を選択してください

| ゲーム | 金額を入力する前に確認してください |
| --- | --- |
| 上下予測 | シンボル、ラウンド番号、方向、賭け終了時間、結果評価時間 |
| カスタム予測 | シンボル、方向、選択された期間、および注文の時間条件 |
| 予測グリッド | シンボル、価格の下限と上限、および有効な開始時間と終了時間 |

<span id="review-and-submit" data-sixmm-canonical-anchor="review-and-submit" aria-hidden="true"></span>

## 確認して送信する

1. 表示された 1 回あたりの注文限度額の範囲内で金額を入力します。
2. 現在の見積もりと予想される支払い額を確認します。見積もりは受諾前に変更される場合があります。
3. 結果ルール、料金開示、および関連する締め切り時間を読みます。
4. 一度送信してから、注文番号と同意された条件が利用可能であることを確認します。

> **不確実な応答は注文が失敗したわけではありません。**
> ページがタイムアウトした場合は、再送信する前に現在の注文とアカウントの取引を確認してください。クリックを繰り返すと、別々の注文を作成できます。

<span id="check-the-result" data-sixmm-canonical-anchor="check-the-result" aria-hidden="true"></span>

## 結果を確認する

現在および過去の記録を通じて順序をたどります。実際の支払いおよび決済トランザクションを使用して資金を調整します。決済前に表示される予想支払額は利用可能な残高ではありません。
