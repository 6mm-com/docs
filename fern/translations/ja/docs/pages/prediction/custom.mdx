カスタム予測を使用すると、ユーザーは上または下と利用可能な期間を選択して独立した注文を開始できます。次に予定されている Up/Down ラウンドに参加する必要はありません。

## 参加方法

1. シンボルとその有効期間の 1 つを選択します。
2. [上へ] または [下へ] を選択し、許可される賭け金を入力します。
3. その期間の固定オッズと予想される配当を確認します。
4. 承認後、記録された始値、注文時間、有効期限、オッズを確認します。
5. 有効期限が切れたら、注文履歴で決済結果を追跡します。

## 各注文には独自の条件があります

| 収録期間 | 目的 |
| --- | --- |
| 記号と方向 | 価格シリーズと選択された結果を識別します |
| オープン価格 | この注文の比較ベースライン |
| 期間と有効期限 | この注文の期限を定義します |
| 賭け金と固定オッズ | 受け入れられる金額と払戻金の乗数を定義します |
| 決済価格と結果 | 結果を記録します |

期間に対して設定された固定オッズは両方向に適用されます。注文が受け入れられると、オッズのスナップショットが保存されます。後で構成を変更しても、それは置き換えられません。

## 結果と例

決済価格が高いほど上昇、決済価格が低いほど下落に相当します。同一価格の取り扱いは、該当する商品ルールに従う必要があります。

始値が 3,000、清算値が 2,990 のダウン注文の例では、選択した方向が勝ちます。 1.85 倍のロックされたオッズで 100 USDT の賭け金は、賭け金を含む別途開示される手数料を除くと 185 USDT を返します。純総利益は 85 USDT です。

## 確認事項

- 異なる時間に行われた 2 つの注文は、開始価格と結果が異なる場合があります。
- 結果を確認するときは、ブラウザのカウントダウンではなく、許容された有効期限を使用します。
- あるシンボルで有効になっている期間または固定オッズ値を別のシンボルに適用する必要はありません。
