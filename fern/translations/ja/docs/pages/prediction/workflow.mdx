予測は、ゲームごとに異なるタイミング ルールを使用して、一般的な注文と資金の流れに従います。

<span id="注文のライフサイクル" data-sixmm-anchor-target="order-lifecycle" aria-hidden="true"></span>
<h2 id="order-lifecycle">注文のライフサイクル</h2>

| ステージ | 何を確認するか |
| --- | --- |
| 選定とお見積り | ゲーム、シンボル、金額、オッズ、価格/時間条件 |
| 承諾 | 注文番号、記録された条件、および正常な受領 |
| 予約された資金 | 資金口座内の注文の予約 |
| 結果待ち | ラウンド結果の評価、独立した有効期限、またはグリッドの有効期間 |
| 結果処理 | 信頼できる価格証拠と注文に適用されるルール |
| 決済 | 最終ステータス、実際の支払い、決済トランザクション |
| 和解 | 注文履歴がアカウントの動きと一致する |

<span id="ゲームごとのタイミング" data-sixmm-anchor-target="timing-by-game" aria-hidden="true"></span>
<h2 id="timing-by-game">ゲームごとのタイミング</h2>

- **上/下:** 注文はスケジュールされたラウンドに属します。賭けは結果が処理される前に終了します。
- **カスタム:** 各注文には独自の始値と有効期限があります。別のユーザーの注文は異なるタイミングで行われる可能性があります。
- **グリッド:** 選択したセルには有効な開始時刻と終了時刻があります。その窓の外に触れても資格はありません。

<span id="処理が中断された場合" data-sixmm-anchor-target="if-processing-is-interrupted" aria-hidden="true"></span>
<h2 id="if-processing-is-interrupted">処理が中断された場合</h2>

切断されたページや遅延した残高更新から最終結果を推測しないでください。注文レコードを再度開き、現在のステータスを確認し、関連するトランザクションを調整します。価格証拠や決済処理に異常がある場合は、 [払い戻しと例外](/ja/prediction/refunds-exceptions).

<span id="追跡可能な記録を保持する" data-sixmm-anchor-target="keep-a-traceable-record" aria-hidden="true"></span>
<h2 id="keep-a-traceable-record">追跡可能な記録を保持する</h2>

サポートのために、注文番号、ゲーム、シンボル、注文時刻、表示されたステータス、および決済トランザクション番号 (存在する場合) を保持してください。概数は、上昇注文と下降注文を識別するのに役立ちます。グリッドのスクリーンショットだけでは、保存された注文を特定することはできません。
