Up/Down Prediction は、注文をスケジュールされたラウンドにグループ化します。ユーザーは、決済価格がラウンドの開始価格よりも高いか低いかを選択します。

<span id="how-to-participate" data-sixmm-canonical-anchor="how-to-participate" aria-hidden="true"></span>

## 参加方法

1. 有効な記号とピリオドを選択します。
2. ラウンド数、始値、ベッティングウィンドウ、および結果評価時間を確認します。
3. 「上」または「下」を選択し、賭け金を入力します。
4. 提示されたオッズと予想される配当を確認し、賭けが開始されている間に送信します。
5. ラウンド中の注文を追跡し、最終結果を確認して返します。

<span id="round-times" data-sixmm-canonical-anchor="round-times" aria-hidden="true"></span>

## ラウンド時間

| 時間 | 意味 |
| --- | --- |
| ベッティングスタート | ラウンドで注文の受付が開始されます |
| ベッティングクローズ | そのラウンドの新しいベットは受け付けられなくなります |
| 結果評価時間 | 予定された結果評価時間 |
| 決済完了 | 決済処理完了の記録 |

ラウンドの期間とそのベッティングウィンドウは異なる設定です。期間全体にわたって賭けが行われていると仮定するのではなく、表示されたタイムスタンプを使用してください。

<span id="direction-result" data-sixmm-canonical-anchor="direction-result" aria-hidden="true"></span>

## 方向の結果

| 価格比較 | 方向 |
| --- | --- |
| 決済価格が始値よりも高い | 上 |
| 決済価格は始値よりも低い | 下 |

等しい価格ではどちらの方向も確立されません。該当するラウンドの等価ルールを確認してください。平等を自動的な損失または返金として扱わないでください。

<span id="odds-and-example" data-sixmm-canonical-anchor="odds-and-example" aria-hidden="true"></span>

## オッズと例

提供されるオッズは、構成された制限に従って、アッププールとダウンプール、および提案された賭け金によって変化します。後のプール見積自体は、以前の注文の決済条件を特定するものではありません。その注文に記録された条件を使用します。

たとえば、始値が 65,000、清算値が 65,100 の場合、方向は上です。記録された配当倍率 1.85 倍で承認された勝ち賭け金 100 USDT の場合、別途開示される手数料を除く総配当は 185 USDT となります。これらの数値は計算を示すものであり、生産見積りではありません。
