3 つの予測ゲームはすべて、価格ベースとしてプラットフォームの無期限契約マーク価格を使用します。最後の取引、外部為替相場、またはブラウザのチャートは、そのマーク価格と異なる場合があります。

<span id="ゲームによる証拠" data-sixmm-anchor-target="evidence-by-game" aria-hidden="true"></span>
<h2 id="evidence-by-game">ゲームによる証拠</h2>

| ゲーム | 関連する証拠 |
| --- | --- |
| 上下予測 | ラウンドの始値、清算値、予定されたタイムスタンプ |
| カスタム予測 | 注文の始値、有効期限、決済価格 |
| 予測グリッド | 受け入れられる間隔、有効な時間ウィンドウ、およびそのウィンドウ内の価格パス |

<span id="スクリーンショットが異なる場合がある理由" data-sixmm-anchor-target="why-a-screenshot-may-differ" aria-hidden="true"></span>
<h2 id="why-a-screenshot-may-differ">スクリーンショットが異なる場合がある理由</h2>

表示を遅らせたり、四捨五入したり、異なる間隔でサンプリングしたり、別の価格タイプを表示したりすることができます。結果が間違っていると結論付ける前に、シンボル、価格ソース、タイムスタンプ、精度を比較してください。

グリッド注文の場合、最終価格だけでは以前のタッチがあったかどうかを証明できません。ゲームのルールに基づいて観察された価格間のクロスを含む、有効なウィンドウ価格の証拠が重要です。

<span id="時間と限界" data-sixmm-anchor-target="time-and-boundaries" aria-hidden="true"></span>
<h2 id="time-and-boundaries">時間と限界</h2>

注文とともに保存されたタイムスタンプを使用します。デバイスの時計やカウントダウンは表示を補助するものであり、遅れた注文を受け入れたり、ウィンドウを変更したりするための権限ではありません。境界の包含と価格の精度は、該当する商品ルールと一致する必要があります。

<span id="データ異常時" data-sixmm-anchor-target="when-data-is-abnormal" aria-hidden="true"></span>
<h2 id="when-data-is-abnormal">データ異常時</h2>

注文番号と影響を受ける時間帯を記録してから、注文の処理ステータスを確認してください。係争中の注文を自分で決済するために、他の取引所の価格を代用しないでください。見る [払い戻しと例外](/ja/prediction/refunds-exceptions).
