提供されたゲームや見積もりは、提案されたすべての注文が受け入れられることを保証するものではありません。利用可能な資金、製品構成、リスク管理はすべて、承認に影響します。

<span id="一般的な制限事項" data-sixmm-anchor-target="common-restrictions" aria-hidden="true"></span>
<h2 id="common-restrictions">一般的な制限事項</h2>

| 制限 | 効果 |
| --- | --- |
| ゲームまたはシンボルが無効になっています | 選択された商品は新規注文できません |
| 期間が有効になっていません | その期間はシンボルに対して選択できません |
| 単一オーダーの最小値/最大値 | 賭け金は表示された許容範囲内に収まらなければなりません |
| 累積賭け金またはエクスポージャ制御 | 単一ステークが有効な場合でも、追加注文は制限される可能性があります |
| オッズ偏差制御 | 見積もりにはレビューが必要な場合や、予測の入力が制限される場合があります |
| 最大値を超えるグリッド見積もり | セルはグリッド価格設定ルールでは使用できません |
| クローズされたベッティングウィンドウ | 閉じたウィンドウでは新しい注文を受け付けることはできません |

管理モデルには、アラート、レビュー、予測制限、遅延注文処理が含まれます。実際の応答は、トリガーされたルールによって異なります。すべての制限が同じ結果をもたらすとは考えないでください。

<span id="ステークとモデルのリスク" data-sixmm-anchor-target="stake-and-model-risk" aria-hidden="true"></span>
<h2 id="stake-and-model-risk">ステークとモデルのリスク</h2>

支払いのない負けた注文は賭け金を失います。オッズが大きいことは、より良い機会があるという証拠ではありません。オッズは、より低い推定ヒット確率を反映している可能性があります。目標リターンパラメータは個人のリターンを保証するものではありません。

<span id="構成の変更" data-sixmm-anchor-target="configuration-changes" aria-hidden="true"></span>
<h2 id="configuration-changes">構成の変更</h2>

新たに注文する前に、現在の製品設定を確認してください。受け入れられたカスタムおよびグリッド注文の場合、オッズと関連する注文のスナップショットが保持されるため、後で画面を更新してもこれらの受け入れられた条件が再定義されるのを防ぎます。

<span id="注文できない場合" data-sixmm-anchor-target="when-an-order-is-unavailable" aria-hidden="true"></span>
<h2 id="when-an-order-is-unavailable">注文できない場合</h2>

商品の切り替え、利用可能残高、限度額、見積もり、タイミングを確認してください。制限を回避するために繰り返し再送信しないでください。応答と注文識別子が作成されている場合は、それを保存します。
