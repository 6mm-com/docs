外部からの入出金は、認定パートナーのプラットフォームを通じて処理されます。予測資金は、そのプラットフォームの有効なアカウントと送金フローに従う必要があります。

## 転送前

送金元口座、送金先口座、通貨、送金可能金額、口座制限を確認します。資産全体の合計は、すべての資産が譲渡可能であることを意味するものではありません。保留中の注文やその他の事業活動により、残高の一部が留保される可能性があります。

実際に保有しているアカウントに対してサポートされている転送エントリを使用してください。無期限契約取引ガイドのスポットから永久へのルートを予測資金調達ルートとしてコピーしないでください。

## 注文を調整する

| 記録 | チェック |
| --- | --- |
| ファンディングへの移管 | ビジネス識別子、通貨、金額、完了ステータス |
| 予測予約 | 元の予測順序と予約金額 |
| 決済 | 最終結果、実際の支払い、取引番号 |
| 払い戻しまたはリリース | 影響を受ける元の注文、金額、最終残高 |
| 別途料金 | 料金の種類、金額、および関連する注文または取引 |

## 不確実な転送応答

置換を開始する前に、元の転送識別子を照会します。タイムアウトは転送が失敗したことを証明するものではありません。他の同時口座の移動を考慮して、最終トランザクションを口座残高と調整します。

## パートナーのオペレーション

パートナー レポートでは、日付または月、ゲームプレイ、シンボル、ユーザーの結果ごとに予測を集計できます。有効な賭け金、支払い、払い戻し、異常な報酬は分けて保管してください。報告慣例では、予測純収益は有効賭け金から配当金を差し引いた異常な報酬として定義されています。それは個々のユーザーの利益と同じ尺度ではありません。

見る [口座と残高](/ja/prediction/accounts-balances) そして [払い戻しと例外](/ja/prediction/refunds-exceptions).
