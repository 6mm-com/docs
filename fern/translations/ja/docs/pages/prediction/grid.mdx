予測グリッドは、垂直方向に価格間隔を表示し、水平方向に将来の時間枠を表示します。 1 つのセルを選択すると、その価格間隔と時間枠に対して 1 つの独立した注文が作成されます。

## セルを読み取る

| グリッドセルの詳細 | 意味 |
| --- | --- |
| 価格間隔 | 価格の下限と上限 |
| 開始時間と終了時間 | タッチが有効になるまでの時間枠 |
| 提示されたペイアウト乗数 | そのセルに提供されるリターン乗数 |
| 賭け金 | その注文に約定した金額 |

10 行 10 列のグリッドで 1 列あたり 2 秒の場合、20 秒をカバーします。これは読み取りの例です。アクティブなプロダクトに表示されている寸法と絶対時間を使用します。

## 何がヒットとみなされるのでしょうか?

セルの有効な時間ウィンドウ中、プラットフォーム マーク価格はその価格区間に入るか、その価格区間を越える必要があります。適格なタッチをするだけで十分です。価格は最後まで維持される必要はありません。

| 例: 10:00:04 ～ 10:00:06 の間の 65,010 ～ 65,020 | 結果の解釈 |
| --- | --- |
| 10:00:05 に価格は 65,015 に達します | ウィンドウ中にインターバルを入力します |
| ウィンドウ内で、価格は 65,005 から 65,025 に移動します。 | 間隔を越える |
| 有効時間内に価格が区間外にとどまり、区間を横切らない | 有効なタッチなし |
| 最初のタッチはウィンドウ終了後に発生します | この注文には遅すぎます |

正確な境界価格とタイムスタンプは、受け入れられたルールに従います。価格フィードが欠落していても、価格がセルに一度も触れられていないという証拠にはなりません。

## 参加方法

1. シンボルを選択し、表示された時間軸と価格軸を調べます。
2. 利用可能なセルとその制限内の金額を選択します。
3. セル境界、有効ウィンドウ、オッズ、および予想される支払いを確認します。
4. 受け付けた注文を確認します。ライブグリッドが移動しても、価格間隔、有効ウィンドウ、オッズはロックされたままになります。
5. 注文履歴で結果と実際の決済を追跡します。

## オッズと使用できないセル

価格設定モデルは、マーク価格、ボラティリティ、および価格と時間の境界からウィンドウ内の間隔に達する確率を推定します。モデルの見積もりは、設定されたルールに従って、目標収益率を推定ヒット確率で割った値に基づいています。

たとえば、97% を 20% で割ると 4.85 倍になります。 4.85 倍でロックされた 賭け金 100 USDT の勝ち注文 の総支払額は 485 USDT です。丸められたラベルは、保存されている乗数の変更を正当化するものではありません。

構成されたグリッド ルールでは、計算された見積もりが最大値を超えると、その見積もりが最大値まで減らされるのではなく、セルが使用不可になります。その他の制限によっても受け入れが妨げられる場合があります。

## 価格証拠の中断

有効期間中にフィードが中断され、ヒットを確立できない場合、注文は例外処理または返金処理に入ります。空のチャートセグメントから損失を推測しないでください。
