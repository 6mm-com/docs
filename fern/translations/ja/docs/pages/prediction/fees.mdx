予測手数料は、受け付けられた注文のオッズおよびパートナー プラットフォームによって開示されている手数料スケジュールと併せて参照する必要があります。このガイドは、普遍的な手数料率を設定するものではありません。

<span id="distinguish-the-amounts" data-sixmm-canonical-anchor="distinguish-the-amounts" aria-hidden="true"></span>

## 金額を区別する

| アイテム | 意味 |
| --- | --- |
| オッズ乗数 | 注文条件に基づいて総獲得利益を決定します |
| ターゲットの戻りパラメータ | 価格設定モデルの入力。それ自体は別個の手数料トランザクションではありません |
| 別途開示するサービス料金 | 製品/注文に適用される場合の調整料金 |
| パートナー収益決済 | ビジネスレベルの割り当て。自動的に別のユーザー注文料金が発生するわけではありません。 |

運用モデルには、料金カテゴリーとして予測プラットフォームのサービス料金が含まれます。そのカテゴリの存在は、料金、請求時期、または特定の注文が個別に請求されるかどうかを確立するものではありません。

<span id="check-before-submitting" data-sixmm-canonical-anchor="check-before-submitting" aria-hidden="true"></span>

## 送信する前に確認してください

- 選択したゲームとアカウントに料金が適用されるかどうか。
- 料金の基準と金額、および請求される時期。
・表示された払戻金が別途料金発生前か後か。
- 注文が返金または無効になった場合の手数料の取り扱い方法。

これらの条件が不明瞭な場合は、次のサイトから該当するスケジュールを入手してください。 [パートナーサポート](/ja/resources/contact/support) 取引する前に。

<span id="reconcile-without-deducting-twice" data-sixmm-canonical-anchor="reconcile-without-deducting-twice" aria-hidden="true"></span>

## 2 回減算せずに調整する

オッズパラメーターと個別の料金は別の記録です。すでに受け入れられているオッズを反映しているペイアウトから、推定パーセンテージを差し引かないでください。実際に開示された料金と取引のみを照合してください。

見る [支払いと損益](/ja/prediction/returns-pnl) そして [転送と取引](/ja/prediction/transfers-ledger).
