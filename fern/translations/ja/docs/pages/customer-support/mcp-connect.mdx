## 接続の詳細

| アイテム | 価値 |
| --- | --- |
| テナントコンソール | [テナントコンソール](https://csadmin.6mm.com/) |
| 輸送 | ストリーミング可能 HTTP |
| 認可 | OAuth 認証コードと PKCE;動的クライアント登録 |
| アカウント | 既存のカスタマー サポート アカウント |

このリモート転送と認証フローをサポートする AI アプリケーションを使用します。テナント固有の MCP サーバーの展開や個別の MCP 権限の構成は必要ありません。 SSE パスを追加したり、アプリ キーを OAuth ベアラー トークンとして使用したりしないでください。

<span id="connect-step-by-step" data-sixmm-canonical-anchor="connect-step-by-step" aria-hidden="true"></span>

## 段階的に接続してください

1. コンソールにサインインし、**システム設定 → MCP 接続**を開きます。
2. エンドポイントをコピーし、AI アプリケーションのリモート MCP サーバーとして追加します。 6MM カスタマーサポートなどの表示名で十分です。
3. アプリケーションに認証を開始させます。ブラウザでサインインし、必要な検証をすべて完了します。
4. 接続を許可する前に、アプリケーション、テナント、アカウント、返信先アドレスを確認してください。指定されたアプリケーション名は認証マークではありません。
5. AI アプリケーションに戻り、必要に応じてツールを更新します。最初の読み取り専用テストとして、知識カテゴリをリストするように依頼します。
6. コンソールで接続されているアプリケーションを確認します。必要がなくなったら、そこでの接続を取り消します。

AI にパスワード、確認コード、または ID 署名の秘密を決して与えないでください。ログイン ページと同意ページを通じてのみ承認します。

<span id="what-access-does-the-ai-receive" data-sixmm-canonical-anchor="what-access-does-the-ai-receive" aria-hidden="true"></span>

## AIはどのようなアクセスを受け取りますか?

現在のアカウントでサポートされているツールとテナント データのみ。通話中に権限が再度チェックされます。アカウントの停止、テナントの利用不可、または承認の取り消しにより、アクセスがブロックされる可能性があります。コンソールからサインアウトしても、AI 接続は自動的に取り消されません。

現在の実装では、30 日間の接続認証と、更新トークンが循環する短期間のアクセス トークンが使用されます。 「接続されているアプリケーション」に表示されている有効期限に従い、必要に応じて再接続します。 AI アプリケーションはトークンの交換と更新を処理します。テナントはツール呼び出しにパスワードを手動で貼り付ける必要はありません。

この MCP はサポート バックエンドを管理します。訪問者ボットがバックエンドを操作したり、取引口座へのアクセスを許可したりすることはできません。
