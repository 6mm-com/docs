## コンソールと訪問者のサポート

| 症状 | まず確認してください |
| --- | --- |
| メニューがありません | アカウントの役割とテナントサービスの可用性 |
| ウィジェットが開かない | 生成されたスクリプト URL、アプリキー、許可されたドメインおよびブラウザーのエラー |
| ボットは大きなモデルを使用しません | 実際に一致したステップ、インテリジェント サービス スイッチ、および関連する構成 |
| 回答には古いルールが使用されます | ソース記事、公開ステータス、FAQ テキスト、翻訳および検索状態 |
| 翻訳はありません | ターゲット言語、翻訳スイッチ、保存された翻訳、サービス/残高の利用可能性 |
| ベクトルの生成に失敗する | サービスの可用性と取得ステータス。障害を特定せずに再構築を繰り返すことを避ける |
| 連絡先フィールドが空です | そのフィールドが実際に収集されたかどうか。連絡先と入力メールを区別する |

## MCP 接続と通話

| 症状 | 次のステップ |
| --- | --- |
| ブラウザでエンドポイントを開くとエラーが返される | これはプロトコル エンドポイントであり、ログイン ページではありません。互換性のある MCP クライアントに追加します |
| 認証を開始できません | 正確なエンドポイント、クライアントの Streamable HTTP/OAuth のサポート、ブラウザーのログイン フローを確認します。 |
| 不正な接続または期限切れの接続 | 失効と有効期限を確認します。アプリケーションを通じて再接続する |
| ツールが見つからないか、アクセスが拒否されました | 承認アカウントの役割とレコードの範囲を確認してください。ツールリストを更新する |
| 承認待ち | 返された承認リンクを開いてバックエンドで確認します。 |
| 内容変更 | 最新のレコードを読み取り、再度プレビューして、新しい目的の操作を送信します |
| リクエストがタイムアウトしました | 再試行するか失敗を想定する前に、操作ステータスをクエリします。 |
| 書き込みログがありません | 読み取り、承認待ち、完了した書き込みを区別します。操作ログのフィルターを確認する |

## サポートに問い合わせる前に

時刻とタイムゾーン、影響を受けるテナント/アカウント、ページまたはツール名、利用可能な場合は操作 ID、および正確なエラーを収集します。編集されたスクリーンショットまたは再現手順を含めます。パスワード、検証コード、ベアラー トークン、または署名シークレットを送信しないでください。

書き込みを診断するときは、小さなテスト レコードを試してください。結果を検証し、必要に応じて通常の確認フローを使用して、作成したテスト データのみをクリーンアップします。
