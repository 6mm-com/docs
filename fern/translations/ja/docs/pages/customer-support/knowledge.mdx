## 適切なコンテンツ タイプを選択する

**コンテンツ管理**を開きます。ナレッジ カテゴリによって記事が整理されます。他のコンテンツ タイプは、簡潔な回答、ナビゲーション、サービス エントリ ポイントを提供します。

| コンテンツ | 一般的な使用方法 |
| --- | --- |
| ナレッジ記事とカテゴリ | オンボーディング、転送、取引ルール、トラブルシューティングに関する詳細なガイド |
| よくある質問 | よくある質問への短い回答 |
| 質問のカテゴリと特徴カード | トピックをグループ化し、ユーザーを関連情報に誘導します |
| お知らせ | 顧客向けの通知を発行する |
| セルフサービスエントリー | 利用可能なサポート アクションまたはリソースにユーザーを誘導します |

<span id="create-and-maintain-knowledge" data-sixmm-canonical-anchor="create-and-maintain-knowledge" aria-hidden="true"></span>

## 知識の創造と維持

1. 適切なカテゴリを作成または選択します。記事作成時にカテゴリなど必須項目をご入力ください。
2. 範囲、条件、手順、例外を含むタイトルと本文を書きます。想定される交換動作ではなく、実際のビジネス ルールを使用します。
3. 下書きを保存して確認します。ユーザーの準備ができたら公開します。必要に応じて、古い資料を非公開にします。
4. 翻訳を維持し、変更後の検索/インデックスのステータスを確認します。ボット フローと訪問者チャットで質問をテストします。

たとえば、引き出しガイドでは、ユーザーがどのネットワークを選択する必要があるか、アドレスをどこで取得するか、適用されるビジネス制限、サポートへの連絡方法について説明する必要があります。処理時間や手数料をでっち上げないでください。

<span id="keep-content-consistent" data-sixmm-canonical-anchor="keep-content-consistent" aria-hidden="true"></span>

## コンテンツの一貫性を保つ

ソースを更新しても、すべての翻訳が最新であることが証明されるわけではありません。影響を受ける翻訳と関連する FAQ の回答を確認します。公開された記事、よくある質問の回答、および発表では、互換性のないルールについて説明してはなりません。削除する前に、そのコンテンツがユーザーのナビゲーションや回答にまだ必要かどうかを確認してください。 MCP は、許可された同じコンテンツ操作をサポートします。見る [MCP ツール](/ja/customer-support/mcp-tools).
