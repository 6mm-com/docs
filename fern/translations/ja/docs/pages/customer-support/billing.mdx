残高の概要を使用して簡単に確認し、使用状況記録を使用して通話を調査し、台帳を使用して残高の変更を把握します。金額を比較する前に、単位とサービスの種類をお読みください。

<div className="sixmm-support-flow">

1. **概要を確認してください** — 残高と最近の支出を確認します。
2. **使用状況を検索** — 関連するサービスと時間範囲をフィルターします。
3. **残高を調整します** — 最終請求額を元帳の変更と比較します。

</div>

## インテリジェントサービスの使用状況を確認する

[**使用状況と請求**] を開いて、残高、利用可能なサービス価格、使用記録、残高の移動を確認します。 AI 応答、翻訳、ベクトル操作は、テナントの構成されたサービスに応じて、共有インテリジェント サービス バランスを消費する可能性があります。

サポート応答パスは重要です。保存された応答と大規模モデルの要求は、同じタイプの使用法ではありません。入手可能なモデルと価格は変更される可能性があります。このガイドでは、固定量ではなく現在のコンソールを使用します。

<span id="understand-settlement" data-sixmm-canonical-anchor="understand-settlement" aria-hidden="true"></span>

## 決済を理解する

サービスは、従量制リクエストの前に推定量を予約する場合があります。信頼性の高い上流利用は、既存のルールに基づく通常の決済に使用されます。有効な結果が返されたが、信頼できる使用法が利用できない場合、バッファを再度適用することなく、予約された金額をフォールバック料金として保持できます。失敗したリクエストまたは無効な結果により、失敗ルールに基づいて予約された量が解放されます。

予約には2回目の追加料金はかかりません。記録を解釈する前に、最終的な料金、元の予約、および残高調整を比較します。フォールバック推定ユニットを上流で測定されたトークンとして解釈してはなりません。

<span id="mcp-and-costs" data-sixmm-canonical-anchor="mcp-and-costs" aria-hidden="true"></span>

## MCP と費用

MCP では個別の請求ルールは導入されていませんが、プラットフォーム AI、翻訳、またはベクター サービスを呼び出すツールには通常のコストが発生する可能性があります。外部の AI プロバイダーは、独自のサービスに対して独自に料金を請求する場合があります。請求ツールは残高、使用量、取引、価格を読み取ることができます。残高をリチャージしたり、請求書を編集したりすることはできません。

## 適切な請求ビューを使用する

| ビュー | 答えは何ですか |
| --- | --- |
| 使用法 | サービスが呼び出されたとき、その入出力ユニット (該当する場合)、最終的な料金およびステータス。 |
| 残高台帳 | 前後の残高により、それぞれの残高の種類と金額が変わります。 |
| サービス価格 | 現在利用可能なサービスとその価格単位。古い文書からコピーした価格ではなく、表示されたレートを使用してください。 |

<span id="example-investigate-an-unexpected-balance-change" data-sixmm-canonical-anchor="example-investigate-an-unexpected-balance-change" aria-hidden="true"></span>

### 例: 予期しないバランスの変化を調査する

1. おおよその時間をメモし、関連する範囲を選択します。サービス フィルターを使用して、AI、翻訳、言語検出、埋め込みを分離します。
2. 通話ステータスと最終請求金額を読み取ります。画面上のメッセージ自体は請求記録ではありません。
3. 消費、払い戻し、その他の表示された調整を含む、同じ期間の元帳の変更を確認します。
4. 数値にまだ説明が必要な場合は、時間範囲、サービス、および関連する記録の詳細をプラットフォーム オペレーターのために保管してください。数値が変化するかどうかを確認するためだけに、請求可能な操作を繰り返し再実行しないでください。

**異なるサービスは異なる単位を使用します。** AI テキスト生成には入力トークン価格と出力トークン価格を含めることができます。埋め込みサービスの価格は入力使用量に基づいて決定されます。すべての数値をトークンとして扱うのではなく、表示されたとおりに翻訳または言語検出単位を読み取ります。
