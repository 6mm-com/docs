## ワークスペースを準備する

開ける [コンソール](https://csadmin.6mm.com/) テナントに提供されたアカウントを使用して。ログイン画面で要求されたサインインとセキュリティ設定を完了します。メニューにアクセスできない場合は、テナント管理者にロールを確認するよう依頼してください。

1. **チームをセットアップします。** エージェント管理で、必要なロールとエージェント アカウントを作成します。誰が会話を閲覧できるか、コンテンツを編集できるか、設定を管理できるかを確認します。
2. **ビジネス知識を準備します。** コンテンツ管理で、アカウントへのアクセス、入出金手順、取引ルール、手数料、サポートエスカレーションに関するカテゴリと記事を作成します。ユーザーが見るべき資料をレビューして公開します。
3. **自動化を構成します。** システム設定で必要なインテリジェント サービスを有効にします。ボット構成で、FAQ、ベクトル マッチング、AI 応答、ID 応答を確認します。
4. **言語を準備します。** メイン言語とデフォルト言語を選択し、ヘルプ コンテンツを翻訳し、用語、番号、リンクを確認します。
5. **Web サイトを接続します。** サイトを Web サイト統合に追加し、テナントが生成した埋め込みコードをコピーします。独自のアプリキーを使用してください。
6. **起動前にテストします。** ボット構成のフロー テストを使用してから、実際の訪問者のエントリを使用します。既知の質問、フォローアップ、別の言語、人間によるサポート、チケットの送信を確認してください。

## 打ち上げ受付

| テスト | 期待される結果 |
| --- | --- |
| 文書化された取引ルール | 応答では条件、数値、例外が保持されます。 |
| 不明なアカウント固有の問題 | 残高や取引結果をでっち上げたものではありません。ユーザーは適切な次のステップを得ることができます |
| 外国語の質問 | 有効な言語での適切な返信またはエージェントの翻訳 |
| 人間によるサポートは利用できません | チケットなどの設定された代替手段が利用可能です |
| 制限付きエージェントアカウント | 許可されたメニューとレコードのみにアクセスできます |
| サービスの利用状況 | 関連する通話が「使用状況と請求」に表示されます。 |

接続する MCP 基本的なワークフローが機能した後。ビジネス コンテンツに対する書き込みを使用する前に、読み取り専用クエリから始めて、次にテスト ドラフトを作成します。
