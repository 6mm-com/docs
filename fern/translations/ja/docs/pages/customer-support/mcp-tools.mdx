## 利用可能なツールはあなたの役割に従います

この表は、サポートされる最大スコープを示しています。 AI アプリケーションは、認証アカウントに許可されたツールのみを受け取ります。ライブ ツール リストとそのパラメーター スキーマをコントラクトとして使用します。新しいコンソール機能は、自動的に MCP ツールになるわけではありません。

| コンソールモジュール | サポートされている操作 |
| --- | --- |
| オンラインでの会話 | セッション、メッセージ、キュー情報を読み取ります。割り当てる、参加する、引き継ぐ、譲渡する。メッセージを送信する。評価を募集します。アップロード許可を管理します。メッセージを認識/翻訳する。サポートされているファイルをアップロードする |
| チケットとフィードバック | ステータスのクエリ、割り当て、更新、およびユーザー チケットとフィードバックの削除。エージェントチケットの作成、読み取り、更新、割り当て、削除 |
| 会話履歴 | セッションとメッセージをクエリします。単一セッションまたは複数セッションを削除する |
| コンテンツ管理 | カテゴリ、記事、注目の質問、質問カテゴリ、特集カード、お知らせ、セルフサービス エントリを読んで管理します。記事の公開/非公開 |
| 言語翻訳 | ソース、翻訳、完了ステータスを読む。サポートされている翻訳を保存またはクリアします。自動翻訳を呼び出します。サポートされている言語設定を管理する |
| ボットの構成 | サポートされている設定と FAQ を読み、同様の質問を管理し、返信をテストし、取得ステータスを検査し、インデックスを更新し、ベクトルを再構築します。 |
| エージェント管理 | サポートされているエージェント、役割、クイック応答を維持する |
| システム設定 | 読み取り/書き込みが許可されている外観、コピー、会話、訪問者エントリ、インテリジェント サービス、および Web サイト許可リストのフィールド |
| 統計 | 読み取り専用の概要とサポートされている統計クエリ |
| 使用量と請求 | 読み取り専用の残高、使用量、トランザクション、価格 |
| 操作ログ | 読み取り専用操作のリストと詳細 |

## 書き込みと確認

削除、公開/非公開、公開記事の編集、メッセージの送信、ロール/アカウントの管理、Web サイトの許可リストの変更、ベクターの再構築、プラットフォームの自動翻訳には、ツールで指定されているバックエンドの確認が必要です。確認なしで書き込みを行っても、データがすぐに変更される可能性があります。 AI に実行を依頼する前に、意図したスコープを確認してください。

MCP は、プラットフォームの管理、テナントの閉鎖/削除、残高の再チャージ、請求の編集、またはプロバイダーの秘密へのアクセスを提供しません。ファイル ツールは、形式チェックとデプロ​​イされたサイズ制限を強制します。現在の実装では、Base64 経由で最大 10 MB の単一ファイルがサポートされています。独自の制限が許す限り、大きなファイルにはコンソールを使用してください。

## タスクの例

- リンクと金額を維持しながら、欠落している翻訳と草稿の日本語版をリストします。
- 未解決のユーザー チケットを見つけて、まだ適用せずに割り当てを提案します。
- 既存のカテゴリでナレッジ記事のドラフトを作成し、そのタイトルと ID を表示します。
- 最近のサポート統計を正確な日付範囲で要約します。

プラットフォーム AI、自動翻訳、ベクトル操作には既存のサービス料金が発生する可能性があります。接続された AI プロバイダー自身の使用法は別です。
