6MM サポートは、認可されたパートナー、アクティブな統合、本番運用向けに設計されています。エンドユーザーサポートは、別途合意されない限りパートナープラットフォームの責任となります。

<h2 id="choose-the-right-path">正しい道を選んでください</h2>

| 状況 | 推奨ルート | 含める |
| --- | --- | --- |
| 新しいパートナーシップまたはソリューションの評価 | パートナーオンボーディングパス | 製品タイプ、ターゲット地域、発売スケジュール、予想される統合モデル。 |
| SDK、 API、ウェブフック、または環境に関する質問 | 技術サポートパス | エンドポイント、 SDK バージョン、リクエストID、再現ステップ、ログ。 |
| 生産インシデントまたは取引フローの劣化 | インシデントのエスカレーション経路 | 影響範囲、開始時間、影響を受けたユーザー、注文ID、現在の緩和策などです。 |
| 資産、コピー、または発射素材の変更 | 作戦支援経路 | ページ、言語、リクエスト変更、ローンチ日、承認所有者。 |
| 脆弱性や虐待の疑い | セキュリティ報告経路 | 技術的な詳細、影響を受けたエンドポイント、証拠、緊急性、問題がアクティブかどうかなどです。 |

<h2 id="severity-guide">重症度ガイド</h2>

| 重症度 | 例 |
| --- | --- |
| 重要な点 | プロダクション取引、認証、トークン発行、ファンド関連のフローは利用できません。 |
| ハイ | 主要なパートナーフローは劣化しますが、回避策は存在します。 |
| ノーマル | 統合に関する質問、設定要望、ドキュメントの問題、または予定されているローンチサポート。 |

<h2 id="before-contacting-support">サポートに連絡する前に</h2>

- 影響を受ける製品エリアと環境を確認する。
- リクエストID、注文ID、タイムスタンプ、ユーザーマッピングID、ウェブフックイベントID、ログの収集。
- 本番の問題にはサポートリクエストテンプレートを使用。
