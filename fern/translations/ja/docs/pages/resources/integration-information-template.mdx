新しい統合の準備や既存の統合を本番環境に移行する際に、このテンプレートを活用してください。

<span id="partner-information" data-sixmm-canonical-anchor="partner-information" aria-hidden="true"></span>

## パートナー情報

| フィールド | 概要 |
| --- | --- |
| パートナー名 | 統合に使われる法的またはプロジェクト名。 |
| 製品タイプ | アプリ、ウォレット、ブローカーポータル、ホワイトラベル取引所、機関プラットフォーム、その他。 |
| 主な接触点 | ビジネス、技術、オペレーション、緊急連絡先。 |
| 発射地域 | 統合が露呈する国や地域。 |

<span id="technical-information" data-sixmm-canonical-anchor="technical-information" aria-hidden="true"></span>

## 技術情報

| フィールド | 概要 |
| --- | --- |
| フロントエンドドメイン | ウィジェットやエントリーページを読み込むドメイン。 |
| バックエンドドメイン | Agent SDK 通話またはAPI 通話に使用されるサーバードメイン。 |
| ウェブフック URL | 本番環境のWebhookエンドポイントと期待される IP 許可リスト要件。 |
| 統合範囲 | Trading Widget、 Agent SDK、 REST API、 WebSocket、ホワイトラベルシステム、または流動性統合。 |

<span id="operational-information" data-sixmm-canonical-anchor="operational-information" aria-hidden="true"></span>

## 運用情報

- 打ち上げ予定日。
- 予想されるトラフィックまたはアクティブユーザー範囲。
- サポート時間とエスカレーションのオーナー。
- 所有者と事故担当者の監視。

<span id="security-and-review-information" data-sixmm-canonical-anchor="security-and-review-information" aria-hidden="true"></span>

## セキュリティおよびレビュー情報

- 認証方法および権限範囲API Key
- 秘密のストレージ、ローテーションオーナー、承認済みのソースIP。
- Webhook署名検証および冪等設計。
- ログ記録、監視、照合、ロールバック、インシデント対応の所有者。
- ターゲット市場、ユーザータイプ、保管モデル、およびユーザー対応の義務を担う主体。

このテンプレートには、本番シークレット、完全なアクセストークン、秘密鍵、または未編集のユーザーデータを含まないでください。

以下の [生産開始チェックリスト](/ja/resources/production-launch-checklist) 最終承認および [サポートリクエストテンプレート](/ja/resources/support-request-template) 問題のエスカレーションのために。
