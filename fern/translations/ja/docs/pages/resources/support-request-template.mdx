サポートに連絡する際は、利用可能な情報を可能な限り含めてください。

<h2 id="required-context">必要な文脈</h2>

| フィールド | 例 |
| --- | --- |
| 環境 | 制作または演出 |
| 影響を受けたモジュール | Trading Widget、 Agent SDK、 REST API、 WebSocket、ウェブフック、ホワイトラベルシステム |
| 時間範囲 | 問題が発生したタイムスタンプ範囲UTC |
| パートナーユーザーID | パートナー側のユーザー識別子(該当する場合) |
| 6MM マッピングID | agentUserId、注文ID、リクエストID、またはウェブフックイベントID |
| ビジネスへの影響 | 影響を受けたユーザー数や運用数、そして問題が継続しているかどうか |

<h2 id="description-format">説明フォーマット</h2>

- 何があったの?
- 何が起こると思ってたんだ?
- 再現できますか?
- 最近何が変わったの?
- まだ問題は続いているのか?

<h2 id="attachments">付属施設</h2>

- 関連するリクエストおよび応答ログ。
- スクリーンショットや画面録画。
- Webhookペイロードおよびシグネチャヘッダー。
- Trading Widget 問題に関するブラウザコンソールエラー。

<h2 id="copyable-template">コピー可能なテンプレート</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

関連のないフィールドは削除しつつ、 UTC の時間範囲と可能な限り少なくとも1つの検索可能なリクエストまたは事業識別子を保持してください。

<h2 id="redact-sensitive-data">機密データの編集</h2>

送信しないでください:

- パスワードまたはフルアクセストークン
- API 秘密、秘密鍵、または完全な署名
- セッションクッキー
- 全額支払い、身元、その他の不要な個人データ

フィールド名と短い接頭辞や接尾辞は、サポートがサニティ化された値を区別する必要がある場合にのみ残してください。
