統合およびサポートリソースは、既存製品に 6MM 取引機能を追加したり、ホワイトラベル取引所を立ち上げたり、生産用の運用資料を準備したりするためのチーム向けに準備されます。

<h2 id="resource-areas">資源エリア</h2>

<CardGroup cols={2}>
<Card title="ブランドと資産" icon="fa-duotone fa-palette" href="/ja/resources/brand-assets/usage-guidelines">
承認された 6MM 視覚素材、エントリーバナー、カード素材、ホワイトラベル素材のガイドを使用してください。
</Card>
<Card title="打ち上げ材料" icon="fa-duotone fa-rocket" href="/ja/resources/production-launch-checklist">
本番のローンチチェック、統合情報、サポートの引き継ぎの詳細を準備します。
</Card>
<Card title="アセットダウンロード" icon="fa-duotone fa-folder-arrow-down" href="/ja/resources/brand-assets/asset-downloads">
ロゴ、バナー、カードエントリー、ホワイトラベルアセットパッケージをダウンロードできます。
</Card>
<Card title="サポートリクエストテンプレート" icon="fa-duotone fa-message-question" href="/ja/resources/support-request-template">
統合、取引、生産上の問題を報告する際は一貫したフォーマットを使用してください。
</Card>
</CardGroup>

<h2 id="when-to-use-this-section">このセクションの使用時期</h2>

| シナリオ | おすすめページ |
| --- | --- |
| アプリやウェブページに 6MM 取引エントリーを追加してください | 使用ガイドライン |
| ロゴ、バナー、カード入力ファイルが必要です | アセットダウンロード |
| パートナーブランドのローンチを準備しましょう | ホワイトラベルサポート |
| テストから本番環境への移行 | 生産開始チェックリスト |
| 問題 6MM 調査を依頼してください | サポートリクエストテンプレート |
