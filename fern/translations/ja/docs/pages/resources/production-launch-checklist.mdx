6MM搭載の取引機能を実際のユーザーに公開する前に、このチェックリストを活用してください。

<span id="integration-readiness" data-sixmm-canonical-anchor="integration-readiness" aria-hidden="true"></span>

## 統合準備度

- 本番ドメインとリダイレクト経路が確認されます。
- Trading Widget、 Agent SDK、 API、または WebSocket フローがエンドツーエンドでテストされています。
- パートナーバックエンドはすべての秘密をサーバー側に保存します。
- ウェブフック受信、署名検証、再試行処理、冪等性が有効化されます。
- ログにはリクエストID、ユーザーマッピングID、注文ID、タイムスタンプが含まれます。

<span id="product-and-resource-readiness" data-sixmm-canonical-anchor="product-and-resource-readiness" aria-hidden="true"></span>

## 製品および資源準備状況

- エントリーポイント、バナー、カードアセットは承認された言語版を使用します。
- ホワイトラベル資産は協力契約で許可されている場合のみ使用されます。
- ユーザー向けのリスクプロンプトや取引エントリーのコピーは、パートナーチームによってレビューされます。
- サポートおよびエスカレーションの所有者が割り当てられます。

<span id="operational-readiness" data-sixmm-canonical-anchor="operational-readiness" aria-hidden="true"></span>

## 作戦準備態勢

- 監視は API エラー、トークン発行、ウィジェット初期化、ウェブフックの失敗、注文ライフサイクルイベントをカバーします。
- 緊急接触経路が確認されました。
- 取引エントリーのためにロールバックまたは一時的な障害プランが作成されます。

<span id="security-and-compliance-readiness" data-sixmm-canonical-anchor="security-and-compliance-readiness" aria-hidden="true"></span>

## セキュリティおよびコンプライアンス準備

- API キーは最小権限を使用し、該当する場合は承認された IP 制限を使用します。
- 資格のローテーションと取り消しはテスト済みです。
- Webhookの署名は生のリクエストボディと照合されます。
- ユーザー開示、リスク通知、責任範囲、ターゲットマーケットレビューが完了しています。
- 事故、和解、支援証拠は秘密を漏らさずに取得可能です。
