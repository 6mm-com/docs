## 責任分担

| エリア | 所有者 | 注意事項 |
| --- | --- | --- |
| コンテナの作成 | パートナーフロントエンド | 可視要素に明示的な幅と高さを指定します。 |
| iframeの作成 | Trading Widget SDK | SDK は iframe を作成および管理します。 |
| 取引UI | 6MM iframe | K ライン、オーダーブック、オーダーフォーム、ポジション、オーダー、アカウントデータは iframe 内で実行されます。 |
| 表示コントロール | Trading Widget SDK + 6MM iframe | PC 埋め込みヘッダーと下部ティッカーはデフォルトでは非表示になっています。パートナーは `display` を使用してシェル領域を表示したり、高レベルの取引コンテナを非表示にしたりできます。 |
| パートナーログインチェック | パートナーバックエンド | 認証資格情報を発行する前に、パートナー ユーザー セッションを検証します。 |
| 埋め込みトークン発行 | パートナー バックエンド + エージェント API | パートナートークンモードに推奨されます。 |

## バージョン管理

パブリック統合パスは、v1 スクリプト URL で安定したままです。現在の v1 機能セットには、パートナー トークン、tokenProvider、entryUrlProvider、表示コントロール、ライフサイクル イベント、インスタンス メソッド、および注文イベントが含まれています。

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## ウィジェットを使用する場合

パートナーが既存の Web 製品内に完全な取引インターフェイスを必要とする場合は、Trading Widget を選択してください。完全にカスタムの取引インターフェイスを構築および維持する場合は、代わりに REST API および WebSocket のドキュメントを使用してください。

## 実装パス

1. フォローしてください [Trading Widget クイックスタート](/ja/sdk/trading-widget/quick-start) スクリプトをロードして、表示可能なコンテナを作成します。
2. 設定する [パートナートークン認証](/ja/sdk/trading-widget/authentication) パートナーのバックエンド経由。
3. 必要な項目を追加します [オプションとイベント](/ja/sdk/trading-widget/options-events).
4. 使用 [インスタンスメソッド](/ja/sdk/trading-widget/instance-methods) ライフサイクルとランタイムの制御用。

## 検証済みのパブリック ランタイム

パブリック `v1` スクリプトは、2026 年 10 月 10 日時点のバージョン `1.8.0` を報告します。この URL は、固定されたビルドではなく、安定したメジャー バージョンのエントリ ポイントです。オプション機能を使用する前に、ロードされたランタイムで `TradingWidget.version` と `TradingWidget.capabilities` を読み取ります。 Java Agent SDK `v0.3.0` は別個のバックエンド パッケージです。

ランタイムは、単一のアクティブなインスタンス (`multiInstance=false`) をサポートします。別のウィジェットを作成すると、前のインスタンスが破棄されます。サポートされているロケールは、20 のドキュメント言語とは関係なく、`en`、`en-US`、および `zh-CN` です。
