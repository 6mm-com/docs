このガイドは、**Agent Java SDK `v0.3.0`**、Java 8 以降、およびタグ付けされたパブリック コントラクトを対象としています。例は `client` を初期化した後にパートナー バックエンドで実行されます。 [クイックスタート](/ja/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- 6 つの永続クエリ: 現在の注文、注文履歴、約定、現在ポジション、ポジション履歴、口座元帳。
- 資金残高、転送、回収クエリ、および資金/契約転送。
- サポートされている資金リクエストの明示的な生成/シミュレートされた選択。
- 秒取引のリダイレクトと埋め込みガイド、応答フィールドのリファレンス、および移行手順。

Java SDK と Trading Widget SDK には独立したバージョンがあります。 `v1` ウィジェット URL は Java SDK バージョン `0.3.0` ではありません。

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## 既存の統合

ユーザー マッピング、元の注文、資格情報を保持します。省略された環境フィールドは、既存の運用動作を保持します。資金調達、明示的にシミュレートされた資金、および 6 つの永続クエリには、対応する新しいモデルとメソッドが必要です。レビュー [アップグレードガイド](/ja/sdk/agent-sdk/java/upgrade) 既存の統合を変更する前に。
