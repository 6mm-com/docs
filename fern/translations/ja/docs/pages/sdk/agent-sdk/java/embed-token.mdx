## 前提条件の例

Java スニペットはこれらのインポートを共有します。クイック スタートを使用して `client` を初期化し、保存されたバインディングから `platformUserId` を取得します。ユーザー/オーダー ID の例は、独自の永続化された値に置き換える必要があります。

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Trading Widget 埋め込みトークン

埋め込みトークンは Trading Widget SDK `partner-token + tokenProvider` モード用です。の
ブラウザーがパートナー バックエンドを呼び出し、パートナー バックエンドがこれを呼び出します Java SDK
`embedToken` を作成します。

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

統合要件:

- `channelId` は、Trading Widget SDK によって渡された値を使用する必要があります。
- `symbol` はオプションですが、現在の初期シンボルを渡すことをお勧めします。
- `embedToken` は短命かつ 1 回限りです。 URL クエリ文字列には入れないでください。
- パートナーのフロントエンドは `apiSecret` を保持してはなりません。
- `expireAt` は、TTL ではなく、秒単位の Unix タイムスタンプです。

パートナー バックエンド エンドポイントの例:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## パートナーエンドポイント契約

パートナーセッションを認証し、サーバー側で `agentUserId` を取得します。現在のウィジェット `channelId` を受け入れます。最上位の `embedToken`、`expireAt` (Unix 秒)、および同じ `channelId` を返します。エージェントの応答は `channelId` を提供しません。バックエンドはそれをエコーし​​ます。初期化および更新時に新しいトークンを取得します。決して再利用しないでください。トークンの作成では、資金を転送したり、ウォレット環境を選択したりしません。
