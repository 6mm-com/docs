このガイドは、**Agent Java SDK `v0.3.0`**、Java 8 以降、およびタグ付けされたパブリック コントラクトを対象としています。例は `client` を初期化した後にパートナー バックエンドで実行されます。 [クイックスタート](/ja/sdk/agent-sdk/java/quick-start).

## 前提条件の例

Java スニペットはこれらのインポートを共有します。クイック スタートを使用して `client` を初期化し、保存されたバインディングから `platformUserId` を取得します。ユーザー/オーダー ID の例は、独自の永続化された値に置き換える必要があります。

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## 直接入力 URL

直接入力 URL はリダイレクト モード用です。パートナー ユーザーがボタンをクリックすると、
パートナー サイトにアクセスすると、6MM フロントエンドが開き、自動的にログインされます。

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

フィールドのルール:

| 分野 | 説明 |
| --- | --- |
| `redirectPath` | 6MM フロントエンドの相対パス。 `/` で始まる必要があります (例: `/trade/BTCUSDT`) |
| `returnUrl` | ユーザーが 6MM フロントエンドを終了するときに使用される絶対パートナー URL。 `http` と `https` のみが許可されます |
| `expireAt` | エントリーチケットの有効期限 (秒単位の Unix タイムスタンプ) |

セキュリティ要件:

- `webUrl` には 1 回限りのチケットが含まれています。すぐに使用し、長期間保管しないでください。
- エントリ URL の有効期限が切れているか、使用されている場合は、パートナー サイトから新しいエントリを生成します。
- `returnUrl` は、`javascript:`、相対パス、またはユーザー情報を含む URL であってはなりません。

## 製品とモードの選択

6MM によって提供される現在のフロントエンド ルートを使用します。たとえば、`/zh-CN/up-down?tradingMode=demo`、`/zh-CN/high-low?tradingMode=real`、`/zh-CN/grid-prediction?tradingMode=real`、または `/zh-CN/futures/BTCUSDT?tradingMode=real` などです。チケットはユーザーを認証します。資金調達環境を選択したり、資金を移動したりするものではありません。

見る [秒取引](/ja/sdk/agent-sdk/java/seconds-trading) リダイレクトと埋め込みの例については。
