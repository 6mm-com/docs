企業の支払いには、さまざまな役割を持つ人々が関与する場合があります。オペレーターが転送を準備し、権限のあるレビュー担当者が必要に応じて承認を処理し、署名参加者がトランザクション署名を作成します。

<span id="prepare-the-payment" data-sixmm-canonical-anchor="prepare-the-payment" aria-hidden="true"></span>

## 支払いの準備をする

ソースウォレット、ネットワーク、アセットを選択します。受取人の住所、金額、必要な宛先メモを入力します。プレビューと料金を確認してください。選択したワークフローが宛先を許可リストと照合する場合は、許可されたアドレス管理プロセスを使用して制限を解決します。

<span id="review-and-track-progress" data-sixmm-canonical-anchor="review-and-track-progress" aria-hidden="true"></span>

## 進捗状況を確認して追跡する

承認が必要な場合、レビュー担当者はエンタープライズ タスク リストで支払いの詳細を確認し、権限の範囲内で行動できます。プラットフォームのリスクレビューが必要なリクエストは、署名する前にそこで待機する場合があります。承認後、支払い記録の署名、ブロードキャスト、チェーン確認を確認します。

| あなたが見るもの | それをどう解釈するか |
| --- | --- |
| 承認またはレビューを待っています | レビューステップはまだ残っています。割り当てられたプロセスを確認してください。 |
| 承認済み、または署名待ち | リクエストは署名ワークフローに沿って移動できます。既存の記録に従ってください。 |
| ブロードキャストまたは確認待ち | 連鎖的な結果はまだ進行中です。利用可能な場合はトランザクション参照を使用します。 |
| 検証中の結果 | 結果が判明するまで、同じリクエストを監視し続けます。 |
| 確認済み | この記録には、調整可能な連鎖的な結果が含まれています。 |

結果が遅れる場合は、別のアクションを実行する前に元のリクエストを確認してください。キャンセルの資格は、実際の署名段階によって異なります。システム統合については、以下を参照してください。 [トランザクションと再試行](/ja/mpc-wallet/transactions).
