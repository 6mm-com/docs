bitMPC ウォレットは、個人、チーム、企業向けのデジタル資産ウォレットです。個人は自分の資産を管理し、デバイスを使用して取引に署名できます。家族やチームはウォレットに対する責任を共有できます。企業は、許可、承認ルール、取引記録を使用して、入金、資金移動、出金を管理できます。

<Note>
MPC ウォレットは一般公開に先立って開発中です。ここで説明する製品の機能は、現在の実装を反映しています。利用可能なプラン、ネットワーク、運用ルールは開通時に確認いたします。
</Note>

## 誰のためのものなのか

| 財布 | 何に使えるのか |
| --- | --- |
| [個人ウォレット](/ja/mpc-wallet/personal-wallet) | 1 つのワークスペースでアセットと受信の詳細を表示し、参加デバイスを管理し、転送の進行状況を確認します。 |
| [家族やチームのウォレット](/ja/mpc-wallet/family-team-wallet) | 共通のワークスペースで共有資産を管理し、責任を割り当て、指定された参加者にトランザクションに署名してもらいます。 |
| [顧客が操作するノードを備えたエンタープライズウォレット](/ja/mpc-wallet/enterprise-wallet) | 署名ノードを操作し、受信アドレスを管理し、ウォレットの役割全体で資金を整理し、チームと一緒に送金を確認します。 |
| [フルマネージドのエンタープライズウォレット](/ja/mpc-wallet/managed-wallet) | チームが残高、支払いリクエスト、承認タスク、調整を処理している間、プラットフォームで署名インフラストラクチャを運用できるようにします。 |

利用可能な画面とアクションは、ウォレット製品とメンバーの権限によって異なります。個人およびチームのウォレットには、デバイス署名の進行状況が表示されます。エンタープライズ ワークスペースは、出金の確認をロールで許可されているメンバー向けのタスク リストも提供します。

## MPC の変更内容

マルチパーティ計算 (MPC) により、参加しているデバイスまたはノードが一緒にトランザクションに署名できます。各参加者は、署名キーの独自の部分を使用します。通常の署名では、参加者は秘密鍵全体をまとめなくても有効な署名を生成できます。署名のしきい値によって、ウォレットの構成に必要な参加者の数が決まります。

エンタープライズ支払いでは、金融オペレーターがリクエストを送信し、承認されたレビュー担当者がワークスペース ポリシーに基づいてリクエストを承認できます。次に、署名参加者はブロックチェーン署名を作成します。ビジネスの承認と署名には別個の責任があり、チェーンの確認によってトランザクションの結果が確立されます。

## 署名キーの保持方法を選択する

- **フルマネージド。** プラットフォームは署名インフラストラクチャを運用します。企業は、ワークスペースを通じて従業員と支払いワークフローを管理します。
- **共同保管。** 顧客とプラットフォームはそれぞれ署名に必要な鍵データの一部を保持します。誰が参加する必要があるか、および選択したウォレットのバックアップを誰が処理するかを確認します。
- **セルフカストディ。** 顧客はウォレットの署名キーの各部分を保持し、継続的なアクセスに必要なデバイス、バックアップ、回復プロセスを準備します。

カストディの選択はウォレット製品によって異なります。セットアップを完了する前に、参加者の構成とウォレットの回復責任を確認してください。見る [保管モデル](/ja/mpc-wallet/custody-models).

## ウォレットでできること

- **資産を受け取り、預金を追跡します。** 選択したネットワークの受け取り詳細を取得します。企業アドレスを割り当てる場合は、アドレスをビジネス ユーザー ID に関連付けます。住所を記載した必要なメモを保管し、それらの詳細を支払者に送信した後、入金を追跡します。
- **企業資金を整理します。** 入金の受け取り、日々の支払い、内部の動きや準備のために、さまざまな役割を持つウォレットを使用します。コレクションでは、該当するポリシーに基づいて、受信アドレスから指定されたウォレットに資金が送られます。
- **送金を確認してフォローしてください。** 送信する前に、ネットワーク、資産、金額、宛先、手数料を確認してください。関連する権限があれば、レビュー担当者はエンタープライズ タスク リストを使用して承認を処理できます。転送記録には、署名、ブロードキャスト、チェーン確認によるその後の進捗状況が示されます。
- **リスクを管理し、記録を調整します。** エンタープライズ ワークスペースは、役割に応じたアドレス リスト、承認ルール、監査ログを提供します。残高、入金、出金、およびチェーンの記録は、財務チームがウォレットのアクティビティを自分の記録と照合するのに役立ちます。
- **署名デバイスを管理し、回復を準備します。** 参加者を操作する場合は、デバイス ビューまたはノード ビューを使用して参加者を管理します。参加できる人を記録し、オンボーディング プランが選択した保管体制のバックアップとリカバリをカバーしていることを確認します。

## 例: 企業向け支払い

財務チームは、顧客から受け取った残高を回収し、サプライヤーに支払いたいと考えています。預金記録を業務記録と照合し、ウォレットの仕組みを利用して資金を支払いに利用できるようにします。オペレーターはサプライヤーの住所に転送を送信します。承認が必要な場合、レビュー担当者はリクエストを承認する前に宛先、資産、金額を確認します。署名参加者が署名を作成した後、チームは転送を追跡してチェーン確認を行い、トランザクション記録を使用して調整を終了します。

ブロードキャスト結果がまだ検証中の場合、チームは結果が判明するまで元の記録をチェックします。これにより、サプライヤーの支払いは 1 つのビジネス要求に関連付けられます。
