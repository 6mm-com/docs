残高ビューを使用して現在の資金ポジションを確認し、トランザクション ビューを使用してそれがどのように変化したかを説明します。エンタープライズ ワークスペースでは、製品と役割に応じて複数のビューを公開できます。

<span id="use-the-right-record-for-each-question" data-sixmm-canonical-anchor="use-the-right-record-for-each-question" aria-hidden="true"></span>

## 各質問に適切な記録を使用する

| 質問 | どこを見るべきか |
| --- | --- |
| 支払いに利用できる金額はいくらですか? | 対象のウォレットと資産の利用可能な残高を確認してください。保有または凍結された金額を個別に確認します。 |
| 入金された支払いはクレジットを受け取りましたか? | 入金記録を確認し、ネットワーク、資産、金額、受け取りの詳細を照合します。 |
| 支払いは既知の結果に達しましたか? | 可能な場合は、出金記録とそのチェーン確認を確認してください。 |
| どの項目が事業収支に影響を与えましたか? | ワークスペースが提供する場合は、レジャー ビューを使用します。チェーン上の動きについては、チェーン アクティビティ ビューを確認してください。 |

<span id="reconcile-a-payment-period" data-sixmm-canonical-anchor="reconcile-a-payment-period" aria-hidden="true"></span>

## 支払い期間を調整する

1. チェックしているワークスペース、ネットワーク、資産、営業期間を特定します。
2. 入金および出金の記録を、保管した業務命令または支払い参照と照合します。
3. 料金と内部徴収は別々に計算してください。完了した送金とは別に、保留中のリクエストに対して保持されている残高を記録します。
4. トランザクション参照と最新ステータスを使用して、一致しないエントリを調査します。結果が確定するまで保留中のアイテムを開いたままにしておきます。

たとえば、出金レコードがまだ確認を待っている間に発信トランザクションがオンチェーンに表示された場合は、元のビジネスリクエストを開いたままにし、そのレコードに従います。最終ステータスと対応する金額を使用して調整を完了します。
