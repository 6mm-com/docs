フルマネージド ウォレットは、署名インフラストラクチャを運用するプラットフォームを必要とする企業向けです。企業は、ワークスペースを使用して日々の資金を処理し、活動を確認し、ビジネス上の責任を割り当てます。

<span id="divide-operational-responsibilities" data-sixmm-canonical-anchor="divide-operational-responsibilities" aria-hidden="true"></span>

## 運用上の責任を分割する

| パーティー | 一般的な責任 |
| --- | --- |
| プラットフォーム | 署名インフラストラクチャを運用し、該当するプラットフォームのリスク レビューを処理します。 |
| 企業 | ワークスペースの権限と承認ルールを設定し、支払いを準備し、残高を確認し、取引とビジネス記録を照合します。 |

使用可能なツールは、ワークスペースと権限によって異なります。資金ビューではウォレット残高がグループ化され、トランザクションビューでは個別の元帳エントリ、チェーンアクティビティ、入出金が表示されます。

<span id="work-with-your-payment-team" data-sixmm-canonical-anchor="work-with-your-payment-team" aria-hidden="true"></span>

## 支払いチームと協力する

権限のあるオペレーターが引き出しを準備します。プレビューを使用して、資金、宛先、および適用される手数料を確認します。レビュー担当者は、承認ポリシーで必要な場合にタスクを処理します。一部のリクエストはプラットフォームのリスクレビューに入る可能性もあります。出金記録に従って署名とチェーン確認を進めてください。

<span id="example-of-a-merchant-payout" data-sixmm-canonical-anchor="example-of-a-merchant-payout" aria-hidden="true"></span>

## 加盟店の支払いの例

販売者は顧客の入金を記録と照合し、利用可能な残高から支払いを準備します。必要に応じて、認可されたレビュー担当者がリクエストを処理します。次に、財務部門は、最終的な引き出し記録とチェーン トランザクションを販売者の支払い参照と比較します。

このフローで使用される日々の記録については、次を参照してください。 [バランスと調整](/ja/mpc-wallet/balances-and-reconciliation).
