テスト環境が利用可能になった場合は、このシーケンスを使用します。アクセス リンクとインストール パッケージは、オンボーディング担当者から提供される必要があります。このガイドでは、パブリック サインアップやダウンロード エンドポイントは提供しません。

<span id="prepare-your-workspace" data-sixmm-canonical-anchor="prepare-your-workspace" aria-hidden="true"></span>

## ワークスペースを準備する

1. 評価する製品と、そのワークスペースを所有するアカウントまたは組織を確認します。
2. 提供されたアクセス ルートを使用してサインインし、そのバージョンで提供されるアカウント セキュリティ手順を完了します。
3. 目的のワークスペースを選択します。資産を操作する前に、製品、メンバー権限、初期化状態を確認してください。
4. 保管の選択がある製品の場合は、確認する前に参加者と回収の責任を確認してください。

ログインアカウント、ワークスペース、オンチェーンウォレットを混同しないでください。 1 つのアカウントは異なるワークスペースにアクセスできますが、各ワークスペースは独自の製品と操作コンテキストを決定します。

<span id="complete-initialization" data-sixmm-canonical-anchor="complete-initialization" aria-hidden="true"></span>

## 初期化を完了する

製品に応じて、セットアップにはデバイスまたはノードの登録、参加者の受け入れ、ウォレット キーの作成、バックアップの準備が含まれる場合があります。 1 つの成功したステップをプロセス全体の完了として扱うのではなく、選択したワークスペースのセットアップ ステータスに従ってください。

フルマネージド エクスペリエンスでは、顧客が保有する暗号鍵のシェアを使用するエンタープライズ ウォレットと同じ顧客ノードのセットアップは必要ありません。個人およびチームのデバイスにも、独自の登録および署名フローがあります。

<span id="validate-a-small-test-flow" data-sixmm-canonical-anchor="validate-a-small-test-flow" aria-hidden="true"></span>

## 小規模なテストフローを検証する

1. 環境がテスト ネットワークであるかどうかを含め、有効なネットワークと資産を確認します。
2. 受信アドレスと必要なメモまたはタグを取得します。住所確認が提供されている場合は、住所を配布する前に確認を完了してください。
3. 少額のテスト金額を受け取り、結果が判明するまで入金記録を追跡します。
4. 少額の送信転送を準備します。宛先、料金、必要な承認またはデバイスの署名を確認してください。
5. ウォレットの記録をチェーン結果および自分のビジネス記録と比較します。

テストを拡張する前に、拒否された承認、利用できない署名者、欠落したコールバック、および不確実なトランザクション結果をチームが処理できることを確認してください。見る [ウォレットの操作](/ja/mpc-wallet/wallet-operations) そして [セキュリティとリカバリ](/ja/mpc-wallet/security-and-recovery).
