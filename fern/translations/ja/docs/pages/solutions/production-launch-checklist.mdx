6MM駆動の取引フローを本番ユーザーに公開する前に、このチェックリストを使用してください。これは製品、エンジニアリング、オペレーション、リスク、サポートチームが一緒にレビューできるように設計されています。

<span id="launch-checklist" data-sixmm-canonical-anchor="launch-checklist" aria-hidden="true"></span>

## 打ち上げチェックリスト

| 面積 | チェックリスト |
| --- | --- |
| 製品 | エントリーポイント、ユーザーコピー、リスクプロンプト、言語カバレッジ、サポートパスが準備完了です。 |
| バックエンド | API 認証情報、署名、トークン発行、ウェブフック、リトライ、ログ記録が実装されています。 |
| 取引 | 注文、移転、ポジション、マージン、手数料、清算の行動は見直されました。 |
| セキュリティ | シークレット、アクセスロール、監視、インシデント対応、監査ログが作成されます。 |
| 運用 | サポートワークフロー、エスカレーション経路、照合、日々の監視が割り当てられています。 |

<span id="recommended-sequence" data-sixmm-canonical-anchor="recommended-sequence" aria-hidden="true"></span>

## 推奨順番

1. 完全なサンドボックスまたは内部環境の検証。
2. ログイン、入力、転送、取引、サポートのためのエンドツーエンドユーザージャーニーを実行します。
3. 監視およびインシデント対応の所有権を確認する。
4. 公開コピー、ローカライズされた資産、リソースダウンロードを承認します。
5. 大規模プロモーションの前に管理されたローンチウィンドウから始めること。

<span id="after-launch" data-sixmm-canonical-anchor="after-launch" aria-hidden="true"></span>

## 打ち上げ後

初期ローンチ期間中は毎日活動を確認しましょう。エントリー変換、トークン発行の失敗、注文エラー、スプレッド品質、転送完了、ウェブフックの再試行、サポートチケットを一緒に監視します。
