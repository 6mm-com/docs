ブランドカスタマイズは、取引情報を明確で一貫性があり、コンプライアンスを保ちつつ、取引所をパートナー製品にネイティブに感じさせるべきです。

<h2 id="customization-areas">カスタマイズエリア</h2>

| 面積 | 例 |
| --- | --- |
| 視覚的アイデンティティ | ロゴ、ファビコン、アクセントカラー、エントリーバナー、キャンペーンカード。 |
| エントリー配置 | ホームページモジュール、資産ページ、ウォレットページ、アカウントセンター、取引ショートカットなどがあります。 |
| ユーザーコピー | リスクプロンプト、トランスファーコピー、取引エントリーラベル、サポートメッセージング。 |
| アセットパッケージ | マーケティング用のダウンロード可能なパートナー資産、エントリーカード、ホワイトラベル資料。 |

<h2 id="quality-checklist">品質チェックリスト</h2>

- 明るい背景と暗い背景に正しいロゴバージョンを使用すること。
- 取引の行動を視覚的に明確にし、マーケティングコンテンツと区別しやすくすること。
- 中国語と英語ページごとに別々にスクリーンショットとダウンロードをローカライズすること。
- サポートやリスクの提示を実際の取引ワークフローと整合させる。

<h2 id="asset-and-content-checklist">アセットおよびコンテンツチェックリスト</h2>

- 明確な最小サイズおよび安全エリアルールのある明暗のロゴバリエーションを提供すること。
- ローカライズされたエントリーバナー、カードアセット、代替テキスト、ユーザー向けの説明を準備します。
- どの表面に 6MM ブランドが表示され、どの表面がパートナーブランドかを確認する。
- リリース前にデスクトップおよびモバイルのレイアウトでアセットをテストすること。
- ファイル名、バージョン、所有者、承認日、置換履歴をアセットレジスタに保持する。

各画像のページの文脈における機能を説明する説明的な代替テキストを使用してください。キーワードリストの使用や、画像説明に無関係な検索語を繰り返し使用しないでください。
