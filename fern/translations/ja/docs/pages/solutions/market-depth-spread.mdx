流動性の質は、深さ、スプレッド、実行速度、注文の信頼性を通じてユーザーに明確に示されます。パートナープラットフォームでは、これらの指標がユーザーが市場を繰り返し取引できるかどうかを決定づけます。

<h2 id="what-to-evaluate">評価すべき点</h2>

| インジケーター | なぜ重要なのか |
| --- | --- |
| 注文簿の深さ | 価格への影響を抑えつつ、大きな注文を成立させるのに役立ちます。 |
| ビッドアスクスプレッド | 注文が出される前の目に見える取引コストに影響します。 |
| 充填信頼性 | 活発な市場中にユーザーの注文が予測可能に完了するかどうかを判断します。 |
| ボラティリティ処理 | 市場の急動時にも取引行動を安定させます。 |

<h2 id="how-6mm-supports-liquidity-quality">流動性の質を 6MM 支える方法</h2>

- 流動性の集約と市場の深さをパートナーシナリオに分配する。
- 対応する取引市場向けの自動流動性提供をサポートします。
- ローンチ、成長、大量生産期における市場の断片化行動を軽減する助けとなります。
- リスク管理に取り組み、品質の見積もりが業務の安定性を犠牲にしないよう。

<h2 id="operational-focus">作戦の重点</h2>

流動性の質とユーザーの行動を追跡しましょう。注文なしでページビューが多いのは信頼やスプレッドの問題を示唆します。注文の試みが多いものの完了が少ないと、市場の深さやリスク、アカウントのワークフローの問題を示唆します。
