Embedded API / SDK トレーディングシステムは、すでにトラフィックやユーザー、ビジネスワークフローを所有しているパートナー向けに設計されており、完全な取引所を一から構築せずに取引を追加したいと考えています。

<h2 id="what-it-provides">提供するもの</h2>

- Trading Widget SDK を通じた組み込み取引端末
- パートナーのバックエンド統合 Agent SDK
- ユーザーアイデンティティバインディングおよびエントリートークンフロー
- 資産移転、注文、ポジション、口座 API アクセス
- 運用システム向けのイベント、ウェブフック、ライフサイクル統合

<h2 id="recommended-architecture">推奨アーキテクチャ</h2>

| 層 | 責任 |
| --- | --- |
| パートナーフロントエンド | エントリーポイントをホストし、 6MM 取引インターフェースを埋め込む。 |
| パートナーバックエンド | API 秘密を保持し、ユーザーの検証を行い、埋め込みトークンを発行し、ウェブフックを処理します。 |
| 6MM 取引インフラ | 取引のUI、マッチング、リスク、流動性、アカウント状態、取引ライフサイクルを管理します。 |

<h2 id="choose-an-integration-path">統合経路を選択する</h2>

| 要件 | 推奨ルート |
| --- | --- |
| 最高速のウェブ連携を備えた完全なトレーディングUIです | Trading Widget |
| バックエンドユーザーのバインディング、転送、エントリー URL、ウェブフックの処理 | Agent SDK |
| 完全カスタムの製品および注文ワークフロー | REST API + WebSocket |
| より広範な運用範囲を持つブランド交換の経験 | ホワイトラベル・エクスチェンジ |

最終設計ではこれらの経路を組み合わせることもあります。実装開始前に認証、資産所有権、責任範囲、監視、生産支援を確認しましょう。
