<h2 id="which-path-should-i-choose">どの道を選ぶべきでしょうか?</h2>

| 事業目標 | 推奨される解決策 | 主治医 |
| --- | --- | --- |
| 既存の製品に取引を追加する | Embedded API / SDK 取引システム | SDK、開発者 |
| 市場の深さと実行の質を向上させる | 機関投資家向け流動性ソリューション | 取引、開発者 |
| ブランド取引所を迅速に立ち上げましょう | ホワイトラベル交換システム | ソリューション、リソース |
| 規制された作戦に備えろ | コンプライアンス・ライセンス・コンサルティング | セキュリティとコンプライアンス |

<h2 id="how-the-solutions-connect">解決策のつながり</h2>

ほとんどのパートナー実装は複数の 6MM 機能を組み合わせています。ホワイトラベル取引所は機関投資家の流動性、コンプライアンスサポート、 API 統合を利用することがあります。組み込み取引パートナーは Trading Widget SDK から始め、後にバックエンド Agent SDK フロー、ウェブフック処理、運用リソースを追加していくことがあります。
