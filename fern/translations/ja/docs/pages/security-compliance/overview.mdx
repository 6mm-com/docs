<h2 id="documentation-map">ドキュメントマップ</h2>

| 面積 | 目的 |
| --- | --- |
| セキュリティアーキテクチャ | 取引インフラ、 API・SDK アクセス、パートナー運営がどのように保護されているかを理解しましょう。 |
| API およびウェブフックのセキュリティ | 署名、シークレットストレージ、冪等処理を通じてバックエンド統合を保護します。 |
| コンプライアンス準備 | ライセンスサポートコンテキスト、発射チェック、パートナー側の運用管理を準備します。 |
| 法的文書 | 本番開始前に利用規約、プライバシー、責任の範囲を確認しましょう。 |

<h2 id="recommended-reading-order">おすすめ読書順</h2>

1. まずセキュリティアーキテクチャとパートナー責任境界から始めます。
2. バックエンド統合前に API Key 管理、リクエスト署名、Webhookの冪等性を確認する。
3. 地域ローンチ準備前にコンプライアンスの概要とライセンスサポートを確認しましょう。
4. 取引機能をユーザーに公開する前に、法務ページとローンチチェックリストを必ず確認してください。
