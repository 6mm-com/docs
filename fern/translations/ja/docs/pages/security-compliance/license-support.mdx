ライセンス計画はより広範なローンチ計画の一部です。適切な進路はターゲット市場、ユーザータイプ、製品範囲、管理モデル、各関係者の運営責任によって異なります。

<h2 id="planning-inputs">計画の入力</h2>

| 入力 | なぜ重要なのか |
| --- | --- |
| 対象管轄区域 | 規制の期待値と必要な地域審査を決定します。 |
| ユーザータイプ | 小売、専門、機関、またはパートナー分散のユーザーによって異なる管理が必要になる場合があります。 |
| 製品範囲 | スポット、デリバティブ、ウォレット、カストディ、ブローカーレッジの機能がコンプライアンスモデルを変える可能性があります。 |
| 運用モデル | ホワイトラベル、組み込み、ブローカー、機関モデルは異なる責任範囲を持っています。 |

<h2 id="how-to-use-this-documentation">このドキュメントの使い方</h2>

これらの文書を使って、法的審査前に技術的かつ運用上の要件を一致させましょう。これらのドキュメントは、チームがアーキテクチャ、データフロー、署名、セキュリティ、資産移動、取引ライフサイクルの責任を説明するのに役立ちます。

> **重要**
>
> ライセンスの決定は、該当法域の資格を持つ法務およびコンプライアンスアドバイザーと審査する必要があります。
