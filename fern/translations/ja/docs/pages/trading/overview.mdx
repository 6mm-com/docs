このセクションは製品、運用、サポート、エンドユーザー教育のために作成されています。 API 分野、署名、バックエンド統合の詳細については、開発者および SDK セクションをご利用ください。

<h2 id="before-trading">取引前</h2>

- ユーザーが認可されたパートナーまたは埋め込み 6MM エントリーを通じて入っていることを確認します。
- 注文をする前に、正しい口座に資金が入っているか確認してください。
- レバレッジ、マージン、清算、資金調達手数料の行動を理解すること。
- 新しい市場や取引モードを学ぶ際は、まず小さなポジションサイズから始めましょう。
- リスク管理のために適切な場合はTP/SLおよび削減のみの命令を使用すること。
