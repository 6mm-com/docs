## Tempo e Valores Numéricos

* Salvo indicação em contrário, os campos de tempo são carimbos de tempo de milissegundos do Unix.
* Estatísticas diárias, instantâneos de saldo e estatísticas de volume de negociação utilizam os limites UTC dias por defeito.
* Campos sensíveis à precisão, como quantidade, preço, quantidade e taxa, são transmitidos como cadeias.
* IDs inteiros grandes como `orderId`, `conditionId` `strategyId` são devolvidos como cadeias em JSON.

<span id="response-format" data-sixmm-canonical-anchor="response-format" aria-hidden="true"></span>

## Formato de Resposta

Resposta bem-sucedida:

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "requestId": "req-12345678"
}
```

Resposta ao erro:

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Notas:

* Erros de negócio normalmente ainda retornam a estrutura unificada de JSON . Os integradores devem verificar `code` primeiro.
* Falhas de autenticação podem devolver HTTP `401`; A limitação de taxa pode devolver HTTP `429`.
* Pode enviar `X-Request-ID` no cabeçalho do pedido. O empregado irá devolve-lo como `requestId` na resposta.
