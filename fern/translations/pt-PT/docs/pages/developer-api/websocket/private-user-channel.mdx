Crie primeiro um `listenKey` :

```http
POST /v1/private/user/listen-key
```

Exemplo de resposta:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "listenKey": "f57cb61ef604ce76be09e753a5dbdd8c",
    "expireAt": 1777539918867
  },
  "requestId": "req-listen-key"
}
```

`listenKey` é válida por 60 minutos por defeito. Recomenda-se renovar a cada 30 minutos.

<h2 id="renew">Renovar</h2>

```http
PUT /v1/private/user/listen-key
Content-Type: application/json
```

```json
{ "listenKey": "f57cb61ef604ce76be09e753a5dbdd8c" }
```

<h2 id="close">Fechar</h2>

```http
DELETE /v1/private/user/listen-key
Content-Type: application/json
```

```json
{ "listenKey": "f57cb61ef604ce76be09e753a5dbdd8c" }
```

<h2 id="connect-to-private-websocket">Liga-te a WebSocket privado</h2>

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

Método de ligação JWT compatível:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Após a autenticação bem-sucedida, o servidor subscreve automaticamente a ligação ao canal privado do utilizador atual. Não é necessária subscrição manual.

Confirmação de autenticação bem-sucedida:

```json
{ "event": "auth", "success": true, "data": "1188041528" }
```

<h2 id="common-private-events">Eventos privados comuns</h2>

| Evento                | Descrição                                                                   |
| -------------------- | ----------------------------------------------------------------------------- |
| `ORDER_TRADE_UPDATE` | Alterações no estado da encomenda, incluindo nova ordem, alteração, troca e cancelamento |
| `ACCOUNT_UPDATE`     | Alterações no saldo da conta e na posição                                          |

Embalagem de mensagens push privadas:

```json
{
  "topic": "user.5794",
  "ts": 1771047000000,
  "data": {
    "eventType": "ORDER_TRADE_UPDATE"
  }
}
```

REST consultar endpoints e WebSocket streams privados usam esquemas separados. Os clientes devem analisar cada esquema independentemente e não devem assumir que os nomes dos campos são idênticos.

<h2 id="common-differences">Diferenças comuns</h2>

| Domínio         | REST campo     | WebSocket campo                                             |
| -------------- | -------------- | ----------------------------------------------------------- |
| Estado da ordem   | `status`       | `orderStatus`                                               |
| Saldo congelado | `frozenMargin` | `frozenBalance`                                             |
| Modo de margem    | `marginMode`   | `marginMode`, devolvido como uma cadeia em posições e fluxos |

<h2 id="recovery-and-reconciliation">Recuperação e reconciliação</h2>

- Renovar a listenKey antes do vencimento e criar uma nova se a renovação falhar.
- Reconectar, autenticar novamente e tratar o novo socket como uma nova sessão de eventos.
- Desduplicar eventos antes de alterar saldos de parceiros ou registos de encomendas.
- Se eventos puderem ter sido ignorados, consultar [ordens](/pt-PT/developer-api/rest-api/order), [posições](/pt-PT/developer-api/rest-api/position) e [estado da conta](/pt-PT/developer-api/rest-api/user-and-account) através de REST.
- Siga o [guia de ligação e batimento cardíaco](/pt-PT/developer-api/websocket/connection-subscription-and-heartbeat) para retentar e lidar com ligações obsoletas.
