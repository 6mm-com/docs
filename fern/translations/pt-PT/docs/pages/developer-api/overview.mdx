## Lista de verificação de produção

- Guardar API segredos apenas no backend.
- Sincronizar o tempo do servidor antes dos pedidos assinados.
- Tratar todos os campos de precisão numérica como cadeias, a menos que uma página diga explicitamente o contrário.
- Utilizar idempotência, IDs de pedidos e registos estruturados em torno dos fluxos de encomendas.
- Subscrever WebSocket fluxos para estados que devem manter-se atualizados nos sistemas operacionais.
- Rever códigos de erro e comportamento de retentativas antes do lançamento.
