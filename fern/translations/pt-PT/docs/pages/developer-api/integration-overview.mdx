> REST Base URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Esta documentação destina-se a sistemas externos que se integram com o serviço 6MM API . Abrange login, autenticação JWT , gestão de API Key , assinatura de API Key HMAC , consultas de contas, ordens, posições, dados de mercado e fluxos de WebSocket .

O fornecimento de contas e a preparação do financiamento são tratados através de processos na plataforma. Esta documentação descreve apenas endpoints de serviço API chamáveis externamente.

## Pontos Finais de Serviço

| Tipo      | Ponto final              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Fluxo de Integração

Sequência recomendada de integração:

1. Iniciar sessão com a conta fornecida pela plataforma e obter um `accessToken`.
2. Para acesso programático do lado do servidor, crie primeiro um API Key com JWT e armazene de forma segura o `apiSecret`devolvido único.
3. As consultas privadas e os endpoints de ordens e posições podem ser chamados com `Authorization: Bearer <accessToken>` ou com uma assinatura API Key.
4. Para fluxos de WebSocket privados, crie primeiro um `listenKey` e depois ligue-se ao `wss://ws.6mm.com/ws?listenKey=...`.
5. Dados de mercado REST endpoints e canais públicos de WebSocket não requerem autenticação.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Escolha de Autenticação

| Cenário                               | Método recomendado         |
| -------------------------------------- | -------------------------- |
| Ações do utilizador frontend                  | JWT                        |
| Chamadas programáticas do lado do servidor         | API Key + HMAC assinatura   |
| API Key criação, atualização e eliminação | JWT                        |
| REST de mercado público / WebSocket pública  | Não é necessária autenticação |
