## Versão de Serviço

```http
GET /v1/version
```

Obtenha informações sobre a versão do serviço.

<span id="server-time" data-sixmm-canonical-anchor="server-time" aria-hidden="true"></span>

## Tempo de Servidor

```http
GET /v1/time
```

Aproveita o tempo para o servidor. Este endpoint pode ser usado para calibrar o tempo do cliente antes API Key assinar.

<span id="user-login" data-sixmm-canonical-anchor="user-login" aria-hidden="true"></span>

## Login do Utilizador

```http
POST /v1/public/user/login
```

Parâmetros do pedido:

| Parâmetro    | Tipo   | Obrigatório | Descrição                             |
| ------------ | ------ | -------- | --------------------------------------- |
| `username`   | string | Sim      | Nome de utilizador, comprimento 3 - 32                 |
| `password`   | string | Sim      | Palavra-passe, comprimento 1 - 64                 |
| `deviceId`   | string | Não       | Impressão digital do dispositivo, até 64 caracteres |
| `deviceName` | string | Não       | Nome do dispositivo, até 128 caracteres       |

Exemplo de pedido:

```bash
curl -X POST https://api.6mm.com/v1/public/user/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "alice",
    "password": "yourPassword",
    "deviceId": "device-001",
    "deviceName": "server-001"
  }'
```

Exemplo de resposta:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "YOUR_ACCESS_TOKEN",
    "accessExpire": 1769676656
  },
  "requestId": "req-login"
}
```

<span id="refresh-token" data-sixmm-canonical-anchor="refresh-token" aria-hidden="true"></span>

## Token de Atualização

```http
POST /v1/public/user/refresh-token
```

Em cenários normais de integração, o estado de login é atualizado através de Cookie. Mantém o Cookie devolvido pela resposta de login.

Campos de resposta:

| Campo          | Tipo   | Descrição              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Novo Token de acesso         |
| `accessExpire` | int64  | Tempo de expiração do Access Token |

## Agente SSO

<span id="ticket-exchange" data-sixmm-canonical-anchor="ticket-exchange" aria-hidden="true"></span>

## Troca de Bilhetes

```http
POST /v1/public/agent-sso/exchange-ticket
```

Parâmetros do pedido:

| Parâmetro  | Tipo   | Obrigatório | Descrição                                 |
| ---------- | ------ | -------- | ------------------------------------------- |
| `ticket`   | string | Sim      | Multa única emitida pelo serviço de agentes |
| `deviceId` | string | Não       | Impressão digital do dispositivo, até 64 caracteres     |

Campos de resposta:

| Campo          | Tipo   | Descrição              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Token de Acesso             |
| `accessExpire` | int64  | Tempo de expiração do Access Token |
| `redirectPath` | string | Caminho de redirecionamento sugerido  |

<span data-sixmm-canonical-anchor="embed-token-exchange" aria-hidden="true"></span>

## Embed Token Exchange

```http
POST /v1/public/agent-sso/exchange-embed-token
```

Parâmetros do pedido:

| Parâmetro    | Tipo   | Obrigatório | Descrição                                                    |
| ------------ | ------ | -------- | -------------------------------------------------------------- |
| `embedToken` | string | Sim      | Token de negociação embutido de curta duração emitido pelo serviço de agentes |
| `channelId`  | string | Sim      | ID de canal iframe incorporado, até 128 caracteres               |
| `deviceId`   | string | Não       | Impressão digital do dispositivo, até 64 caracteres                        |

Campos de resposta:

| Campo          | Tipo   | Descrição              |
| -------------- | ------ | ------------------------ |
| `accessToken`  | string | Token de Acesso             |
| `accessExpire` | int64  | Tempo de expiração do Access Token |

<span id="pnl-leaderboard" data-sixmm-canonical-anchor="pnl-leaderboard" aria-hidden="true"></span>

## Tabela de Líderes PnL

```http
GET /v1/public/leaderboard/pnl?period=30d
```

Parâmetros do pedido:

| Parâmetro | Tipo   | Obrigatório | Descrição          |
| --------- | ------ | -------- | -------------------- |
| `period`  | string | Sim      | `7d` / `30d` / `90d` |

Campos de resposta:

| Campo              | Tipo   | Descrição                                                       |
| ------------------ | ------ | ----------------------------------------------------------------- |
| `list[].rank`      | int32  | Posto                                                              |
| `list[].userId`    | string | ID de utilizador externo                                                  |
| `list[].trader`    | string | Nome de comerciante mascarado                                                |
| `list[].volume`    | string | Volume de negociação na janela                                      |
| `list[].pnlAmount` | string | Percebi PnL na janela                                        |
| `list[].pnlPct`    | string | Razão PnL, decimal de `0` para `1`                                |
| `myRank`           | int32  | Classificação do utilizador atual. Devolve `0` se não for autenticado ou não classificado |
