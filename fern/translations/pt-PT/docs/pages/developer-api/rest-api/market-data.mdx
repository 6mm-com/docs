Os dados de mercado REST endpoints não requerem autenticação.

<span id="symbol-configuration" data-sixmm-canonical-anchor="symbol-configuration" aria-hidden="true"></span>

## Configuração de símbolos

```http
GET /v1/public/market/symbols
```

Campos de resposta comuns:

| Campo                      | Tipo   | Descrição                   |
| -------------------------- | ------ | ----------------------------- |
| `list[].symbol`            | string | Símbolo                        |
| `list[].baseAsset`         | string | Ativo base                    |
| `list[].quoteAsset`        | string | Ativo de cotação                   |
| `list[].minQuantity`       | string | Quantidade mínima encomendada        |
| `list[].minNotional`       | string | Valor nocional mínimo        |
| `list[].tickSize`          | string | Tamanho do tick de preço               |
| `list[].stepSize`          | string | Tamanho do passo em quantidade            |
| `list[].pricePrecision`    | int64  | Precisão do preço               |
| `list[].maxLimitOrderQty`  | string | Quantidade máxima de ordem limite  |
| `list[].maxMarketOrderQty` | string | Quantidade máxima de encomenda de mercado |
| `list[].maxOpenOrders`     | int64  | Ordens abertas máximas por utilizador  |
| `list[].defaultLeverage`   | int64  | Alavancagem padrão              |
| `list[].defaultMarginMode` | int64  | Modo de margem por defeito           |
| `list[].leverageTiers[]`   | array  | Níveis de margem de alavancagem         |
| `handlingFeeLevelConfig[]` | array  | Configuração por escalão de honorários        |

<span id="funding-rate-configuration" data-sixmm-canonical-anchor="funding-rate-configuration" aria-hidden="true"></span>

## Configuração da Taxa de Financiamento

```http
GET /v1/public/market/funding-rate?symbol=BTCUSDT
```

Parâmetros do pedido:

| Parâmetro | Tipo   | Obrigatório | Descrição                     |
| --------- | ------ | -------- | ------------------------------- |
| `symbol`  | string | Não       | Se omitido, devolve todos os símbolos |

<span id="current-funding-rate" data-sixmm-canonical-anchor="current-funding-rate" aria-hidden="true"></span>

## Taxa de Financiamento Atual

```http
GET /v1/public/market/funding-rate/current?symbol=BTCUSDT&page=1&pageSize=20
```

Parâmetros do pedido:

| Parâmetro  | Tipo   | Obrigatório | Descrição                  |
| ---------- | ------ | -------- | ---------------------------- |
| `symbol`   | string | Não       | Símbolo                       |
| `page`     | int32  | Não       | Número de página, `1` padrão     |
| `pageSize` | int32  | Não       | Itens por página, `20` padrão |

## Histórico das Taxas de Financiamento

```http
GET /v1/public/market/funding-rate/history?symbol=BTCUSDT&page=1&pageSize=20
```

Parâmetros do pedido:

| Parâmetro   | Tipo   | Obrigatório | Descrição                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Sim      | Símbolo                       |
| `startTime` | int64  | Não       | Hora de início                   |
| `endTime`   | int64  | Não       | Fim dos tempos                     |
| `page`      | int32  | Não       | Número de página, `1` padrão     |
| `pageSize`  | int32  | Não       | Itens por página, `20` padrão |

## Klines

```http
GET /v1/public/market/klines?symbol=BTCUSDT&interval=1m&limit=500
```

Parâmetros do pedido:

| Parâmetro   | Tipo   | Obrigatório | Descrição                                                              |
| ----------- | ------ | -------- | ------------------------------------------------------------------------ |
| `symbol`    | string | Sim      | Símbolo                                                                   |
| `interval`  | string | Sim      | Intervalo, como `1m`, `5m`, `15m`, `30m`, `1h`, `4h`, `1d`, `1w`, `1M` |
| `priceType` | string | Não       | `indexPrice` / `markPrice`. Se omitido, devolve o preço de troca Klines       |
| `startTime` | int64  | Não       | Hora de início                                                               |
| `endTime`   | int64  | Não       | Fim dos tempos                                                                 |
| `limit`     | int32  | Não       | Número de itens devolvidos, `500`padrão, máximo `1000`                  |

Campos de resposta:

| Campo              | Tipo   | Descrição |
| ------------------ | ------ | ----------- |
| `list[].openTime`  | int64  | Horário aberto   |
| `list[].open`      | string | Preço de abertura  |
| `list[].high`      | string | Preço elevado  |
| `list[].low`       | string | Preço baixo   |
| `list[].close`     | string | Preço próximo |
| `list[].volume`    | string | Volume      |
| `list[].closeTime` | int64  | Tempo de fechamento  |
