## Formato de Resposta ao Erro

```json
{
  "code": 1003,
  "message": "Invalid token",
  "requestId": "req-12345678"
}
```

Os erros de negócio geralmente continuam a devolver a estrutura unificada de JSON . Os integradores devem verificar `code` primeiro. Falhas de autenticação podem devolver HTTP `401`; a limitação de taxa pode devolver HTTP `429`.

<span id="common-error-codes" data-sixmm-canonical-anchor="common-error-codes" aria-hidden="true"></span>

## Códigos de Erro Comuns

| Código de erro      | Descrição                                  |
| --------------- | -------------------------------------------- |
| `0`             | Sucesso                                      |
| `1001`          | Não fornecida qualquer informação válida de autenticação |
| `1002`          | Token expirado                                |
| `1003`          | Token inválido, API Keyou assinatura         |
| `1004`          | Token revogado                                |
| `1006`          | Fonte IP incompatibilidade                           |
| `2001`          | Parâmetro obrigatório em falta                   |
| `2002`          | Valor inválido do parâmetro                      |
| `2003`          | Parâmetro fora do alcance                       |
| `3001`          | Equilíbrio insuficiente                         |
| `3003`          | Ordem não encontrada                              |
| `3004`          | Pedido duplicado                            |
| `3005`          | A encomenda não pode ser cancelada                     |
| `3006`          | Permissão negada                            |
| `3100` - `3112` | Erro de validação do parâmetro de ordem de condição   |
| `5001`          | Erro interno do servidor                        |
| `5002`          | Serviço temporariamente indisponível              |
| `5003`          | Limite de taxa acionado                         |

<span id="troubleshooting" data-sixmm-canonical-anchor="troubleshooting" aria-hidden="true"></span>

## Resolução de problemas

| Problema                                     | Recomendação                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `1001` nenhuma informação de autenticação válida  | Verifica se `Authorization: Bearer <accessToken>` ou `X-API-KEY` está incluído.                  |
| `1002` Token expirado                        | Atualize o Token ou faça login novamente antes de tentar novamente.                                                   |
| `1003` Token, API Keyou assinatura inválida | Verifique API Key, carga útil de assinatura, corpo JSON string de pedido e ordem dos parâmetros de consulta.           |
| `1006` fonte IP incompatibilidade                   | Verifique a configuração API Key IP whitelist.                                                    |
| `3004` pedido de duplicação                    | Não reutilize a mesma assinatura para caminhos relacionados com a ordem. Regenerar `timestamp` e `signature`. |
| `5003` limite de taxa ativado                 | Reduza a frequência dos pedidos e use um recuo exponencial se tentar novamente.                                |
| `Timestamp outside of tolerance window`     | Ligue `/v1/time` para calibrar o desfasamento temporal e assine o pedido novamente.                             |
