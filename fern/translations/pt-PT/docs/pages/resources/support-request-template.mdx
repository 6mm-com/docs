Ao contactar o suporte, inclua a informação abaixo sempre que disponível.

<span id="required-context" data-sixmm-canonical-anchor="required-context" aria-hidden="true"></span>

## Contexto necessário

| Campo | Exemplo |
| --- | --- |
| Ambiente | Produção ou encenação |
| Módulo afetado | Trading Widget, Agent SDK, REST API, WebSocket, webhook, sistema white-label |
| Intervalo temporal | UTC intervalo de carimbo temporal quando o problema ocorreu |
| ID de utilizador do parceiro | Identificador de utilizador do lado do parceiro, se relevante |
| ID de mapeamento 6MM | agentUserId, ID da encomenda, ID do pedido ou ID do evento webhook |
| Impacto no negócio | Número de utilizadores ou operações afetadas e se o problema está em curso |

<span id="description-format" data-sixmm-canonical-anchor="description-format" aria-hidden="true"></span>

## Formato da descrição

- O que aconteceu?
- O que esperavas que acontecesse?
- Pode ser reproduzido?
- O que mudou recentemente?
- O problema ainda está a acontecer?

<span id="attachments" data-sixmm-canonical-anchor="attachments" aria-hidden="true"></span>

## Anexos

- Registos relevantes de pedidos e respostas.
- Capturas de ecrã ou gravações de ecrã.
- Cabeçalhos de carga útil e assinatura Webhook.
- Erros na consola do navegador para Trading Widget problemas.

<span id="copyable-template" data-sixmm-canonical-anchor="copyable-template" aria-hidden="true"></span>

## Modelo copiável

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Remova campos que não sejam relevantes, mas mantenha o intervalo de tempo UTC e pelo menos um pedido pesquisável ou identificador de negócio sempre que possível.

<span id="redact-sensitive-data" data-sixmm-canonical-anchor="redact-sensitive-data" aria-hidden="true"></span>

## Rediga dados sensíveis

Não envie:

- Palavras-passe ou tokens de acesso completo
- API segredos, chaves privadas ou assinaturas completas
- Cookies de sessão
- Pagamento integral, identidade ou outros dados pessoais desnecessários

Mantenha o nome do campo e um prefixo ou sufixo curto apenas quando o suporte precisar de distinguir entre valores sanitizados.
