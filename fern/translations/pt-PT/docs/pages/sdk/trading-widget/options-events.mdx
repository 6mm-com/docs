## Opções

| Campo | Tipo | Predefinição | Notas |
| --- | --- | --- | --- |
| baseUrl | string | SDK origem do script | domínio iframe. Passe explicitamente nas páginas dos parceiros. |
| símbolo | string | BTCUSDT | Normalizado para letras maiúsculas e faixas - /_. |
| tema | escuro \| luz | escuro | Parâmetro inicial do tema. |
| localidade | pt \| pt-EUA \| zh-CN | Navegador/padrão | Inglês e chinês simplificado são suportados. |
| esquema | predefinição \| compactar | predefinição | Opção de layout reservado. |
| ecrã | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Os controlos incorporam áreas de shell e contentores comerciais de alto nível. |
| autenticação | object | nenhum | Utilize o token de parceiro para novas integrações SSO. |

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Controles de exibição

`display` controla o shell da página de negociação incorporada e os contentores de alto nível. Nas incorporações de parceiros, o cabeçalho do PC e o ticker inferior do mercado estão ocultos por defeito.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Predefinição | Notas |
| --- | --- | --- | --- |
| showHeader | boolean | FALSO | Se deve mostrar o cabeçalho incorporado do PC dentro do iframe. |
| showTicker | boolean | FALSO | Se deve mostrar o ticker inferior do mercado na concha incorporada. |
| oculto | fio[] | [] | Oculta os contentores de alto nível na página de negociação. |

Valores `display.hidden` suportados:

| Valor | Recipiente |
| --- | --- |
| gráfico | Contentor de gráfico |
| orderBook | Recipiente de livro de encomendas |
| orderForm | Painel de formulário de encomenda |
| posições | Posições inferiores e painel de encomendas aberto |
| conta | Contentor de ativos da conta |

`display.hidden` oculta apenas contentores inteiros. Não oculta botões, campos ou ferramentas individuais dentro de um contentor. Os valores que não são mapeados para a janela de visualização atual são ignorados.

## Eventos

| Evento | Gatilho |
| --- | --- |
| pronto | inicialização do iframe concluída. |
| erro | SDK, iframe ou erro de autenticação. |
| estado_alterado | SDK estado do ciclo de vida alterado. |
| auth_state_changed | Estado de autenticação do token de parceiro alterado. |
| símbolo_alterado | O símbolo real do iframe foi alterado. |
| locale_alterado | A localidade real do iframe foi alterada. |
| pedido_criado | O utilizador criou um pedido dentro do iframe. |
| pedido_falhou | Falha no envio do pedido. |
| destruído | SDK instância destruída. |

## Páginas de produtos e modo de negociação

Java Agent SDK e o browser Trading Widget SDK têm uma versão independente. Para a negociação de segundos, utilize as funcionalidades atuais do widget e selecione explicitamente a página e o modo de negociação.

| Opção | Valores | Significado |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Página do produto para negociação de segundos. |
| `tradingMode` | `real`, `demo` | O predefinido é `real`; corresponder explicitamente ao ambiente de financiamento de back-end. |

Verifique `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` e `TradingWidget.capabilities.partnerToken` antes do arranque. A criação de tokens não seleciona um ambiente de fundos. Para alterar os utilizadores ou o modo real/demo, destrua a instância antiga e crie uma nova.

Ver [exemplo completo de negociação de segundos](/pt-PT/sdk/agent-sdk/java/seconds-trading) e [configuração de produção/simulada](/pt-PT/sdk/agent-sdk/java/environments).

## Destinos e eventos de visualização adicionais

O tempo de execução atual também aceita `symbolFavorites` e `symbolTicker` em `display.hidden`. Verifique sempre `TradingWidget.capabilities.displayTargets`; um destino controla um contentor de alto nível e não é uma configuração de permissões ao nível do campo.

| Evento | Significado |
| --- | --- |
| `rendered` | O iframe envia a sua notificação renderizada. |
| `theme_changed` | O iframe reporta o seu tema real. |
| `page_changed` | O iframe reporta a sua página real do produto. |

Utilize `onRendered` ou `widget.on('rendered', handler)` para tratar a renderização separadamente da inicialização. As páginas atualmente suportadas são publicadas em `TradingWidget.capabilities.pages`; valide a página solicitada em vez de adivinhar um caminho.
