## Resumo do método

| Método | Finalidade |
| --- | --- |
| destruir() | Remova o iframe e liberte os ouvintes de eventos. |
| getState() | Leia o estado atual do ciclo de vida SDK. |
| whenReady() | Aguarde até que o iframe termine o arranque. |
| setSymbol(símbolo) | Troque o par de negociação dentro do iframe. |
| setTheme(tema) | Atualize o parâmetro do tema iframe. |
| setLocale(localidade) | Altere o idioma do iframe. |
| setSize(largura, altura) | Atualize as dimensões do iframe. |
| recarregar() | Recarregue o iframe atual. |
| refreshAuth(motivo) | Acione o fluxo de atualização de autenticação do widget. |
| setTokenProvider(fornecedor) | Substitua o fornecedor utilizado pelo modo token de parceiro. |
| on(evento, manipulador) | Subscreva eventos de tempo de execução e receba uma função de cancelamento de subscrição. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## destruir()

Remova o iframe, limpe os listeners e emita destruído uma vez para a instância atual.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Leia o estado atual do ciclo de vida da instância do widget.

```js
const state = widget.getState()
```

Os valores de retorno incluem carregamento, autenticação, pronto, erro e destruído.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Aguarde até que o iframe termine a inicialização antes de executar a lógica da UI dependente.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(símbolo)

Troque o par de negociação dentro do iframe. Se o iframe ainda estiver a arrancar, o SDK coloca o comando na fila e envia-o depois de estar pronto.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(tema)

Atualize o parâmetro do tema utilizado pelo iframe de negociação incorporado.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(localidade)

Altere o idioma do iframe. Os valores suportados são en, en-US e zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(largura, altura)

Atualize o tamanho do iframe DOM e notifique o iframe sobre o novo tamanho externo. Os valores numéricos são convertidos em px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## recarregar()

Recarregue o iframe atual e aguarde que seja novamente inicializado.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(motivo)

Peça ao iframe para atualizar o fluxo de autenticação atual. O valor de motivo opcional é encaminhado para o registo e controlo de fluxo.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(fornecedor)

Substitua o tokenProvider utilizado pelo modo token de parceiro. O SDK chama o fornecedor quando o iframe solicita um novo token incorporado.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(evento, manipulador)

Inscreva-se num evento de tempo de execução. A função devolvida remove o listener.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Métodos adicionais no tempo de execução v1 atual

| Método | Finalidade |
| --- | --- |
| `whenRendered()` | Aguarde a notificação renderizada do iframe; este é separado do pronto. |
| `setPage(page)` | Solicite uma página de produto compatível na instância atual. Não altera o ambiente dos fundos. |
| `prepareForRecreate()` | Peça um iframe pronto para se preparar para a substituição; devolve uma promessa e pode rejeitar se estiver indisponível, ocupado ou expirado. |
| `cancelRecreate()` | Cancele um fluxo de substituição pendente/preparado. |
| `TradingWidget.validateOptions(options)` | Valide as opções de arranque antes de criar uma instância. |

Para uma alteração de utilizador ou de ambiente real/de demonstração, destrua a instância antiga e crie uma nova com a autenticação e o modo de destino. Não utilize `setPage` como opção de ambiente. Verifique as características antes de utilizar métodos opcionais.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
