## Divisão de responsabilidades

| Área | Proprietário | Notas |
| --- | --- | --- |
| Criação de contentores | Frontend parceiro | Fornecer um elemento visível com largura e altura explícitas. |
| Criação de iframe | Trading Widget SDK | O SDK cria e gere o iframe. |
| UI de Negociação | 6MM iframe | K-line, livro de encomendas, formulário de encomendas, posições, ordens e dados de conta são executados dentro do iframe. |
| Controlos de ecrã | Trading Widget SDK + 6MM iframe | O cabeçalho e o ticker inferior do PC embed estão ocultos por defeito. Os parceiros podem usar `display` para mostrar áreas de shell ou esconder contentores de trading de alto nível. |
| Verificação do login do parceiro | Backend parceiro | Valide a sessão do utilizador parceiro antes de emitir credenciais de autenticação. |
| Emissão de token embeded | Backend parceiro + Agente API | Recomendado para o modo de tokens de parceiro. |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## Versionamento

O caminho de integração pública mantém-se estável sob o script v1 URL. O conjunto atual de capacidades v1 inclui partner-token, tokenProvider, entryUrlProvider, controlos de visualização, eventos do ciclo de vida, métodos de instância e eventos de ordem.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## Quando usar o widget

Escolha Trading Widget quando um parceiro precisa de uma interface de negociação completa dentro de um produto web já existente. Use a documentação REST API e WebSocket ao construir e manter uma interface de trading totalmente personalizada.

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## Caminho de implementação

1. Seguir o [Trading Widget Início Rápido](/pt-PT/sdk/trading-widget/quick-start) para carregar o script e criar um contentor visível.
2. Configurar [Autenticação por token de parceiro](/pt-PT/sdk/trading-widget/authentication) através de um backend parceiro.
3. Adicionar o necessário [Opções e eventos](/pt-PT/sdk/trading-widget/options-events).
4. Utilização [Métodos de instância](/pt-PT/sdk/trading-widget/instance-methods) para controlos do ciclo de vida e do tempo de execução.
