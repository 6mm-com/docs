## Entrada Direta URL

A entrada direta URL é para o modo de redireccionamento. Um utilizador parceiro clica num botão na
site do parceiro, abre o frontend 6MM e faz login automaticamente.

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/trade/BTCUSDT")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

Regras de campo:

| Campo | Descrição |
| --- | --- |
| `redirectPath` | 6MM caminho relativo do frontend. Deve começar por `/`, por exemplo `/trade/BTCUSDT` |
| `returnUrl` | Parceiro absoluto URL utilizado quando o utilizador sai do frontend 6MM. Apenas `http` e `https` são permitidos |
| `expireAt` | Tempo de expiração do ticket de entrada como carimbo de data/hora Unix em segundos |

Requisitos de segurança:

- `webUrl` contém um ticket único. Utilize-o imediatamente e não o guarde por muito tempo.
- Se a entrada URL expirar ou tiver sido utilizada, gere uma nova no site do parceiro.
- `returnUrl` não deve ser `javascript:`, um caminho relativo ou um URL com informação do utilizador.

## Seleção do produto e modo

Utilize a rota de frontend atual fornecida por 6MM. Por exemplo `/zh-CN/up-down?tradingMode=demo`, `/zh-CN/high-low?tradingMode=real`, `/zh-CN/grid-prediction?tradingMode=real` ou `/zh-CN/futures/BTCUSDT?tradingMode=real`. O ticket autentica o utilizador; não seleciona um ambiente de financiamento nem movimenta fundos.

Ver [Negociação de segundos](/pt-PT/sdk/agent-sdk/java/seconds-trading) para exemplos de redireccionamento e incorporados.
