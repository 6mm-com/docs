Este guia é dirigido a **Agent Java SDK `v0.3.0`**, Java 8+ e ao contrato público assinalado. Os exemplos são executados num back-end de parceiro após a inicialização de `client` em [Início rápido](/pt-PT/sdk/agent-sdk/java/quick-start).

## Pré-requisitos de exemplo

Os trechos Java partilham estas importações. Inicialize `client` utilizando o Quick Start e obtenha `platformUserId` a partir da ligação guardada. Os exemplos de IDs de utilizador/encomenda devem ser substituídos pelos seus próprios valores persistentes.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Taxas de referência de câmbio

Ambos os métodos FX utilizam o fluxo normal do Agente assinado API. Comece por descobrir o
moedas de origem atualmente suportadas:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Consulte todas as taxas de referência fiat-to-USDT suportadas:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Consultar moedas selecionadas:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

A fábrica de solicitações corta e coloca em maiúsculas os códigos de moeda e serializa-os como
o valor `sourceCurrencies` separado por vírgulas exigido pelo API. Omitindo o
request ou todos os valores de moeda efetivos consultam todas as moedas suportadas.

| Campo de resposta | Tipo | Descrição |
| --- | --- | --- |
| `snapshotVersion` | string | Versão instantânea estável para auditoria e reconciliação |
| `provider` | string | Fornecedor upstream, atualmente `ECB` |
| `sourceDate` | string | Data de observação a montante no formato `yyyy-MM-dd` |
| `fetchedAt` / `expiresAt` | int64 | Carimbos de data e hora Unix em milissegundos |
| `pricingPolicy` | string | Atualmente `FIXED_PEG` |
| `usdtUsdRate` | string | USD valor por 1 USDT, atualmente fixado em `1` |
| `rateType` | string | Atualmente `INDICATIVE_DAILY` |
| `usage` | string | Atualmente `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT valor correspondente a uma unidade de moeda fiduciária de origem |

Estes valores são referências para uma carteira multimoeda parceira calcular
o valor USDT enviado para 6MM. Não são preços executáveis, cotações bloqueadas ou
preços de mercado em tempo real USDT. Use `BigDecimal` e strings para o valor
cálculos; não utilize `double` ou `float`.
