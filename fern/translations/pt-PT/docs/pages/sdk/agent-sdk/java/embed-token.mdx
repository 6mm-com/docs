## Trading Widget Incorporar token

O token incorporado é para o modo Trading Widget SDK `partner-token + tokenProvider`. O
o browser chama o back-end do parceiro, e o back-end do parceiro chama isto Java SDK
para criar um `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Requisitos de integração:

- `channelId` deve utilizar o valor passado por Trading Widget SDK.
- `symbol` é opcional e pode conter o símbolo inicial atual. Não é uma restrição de permissão de pares de negociação de tokens.
- `embedToken` tem uma vida curta e é único. Não o coloque em strings de consulta URL.
- O front-end do parceiro nunca deve conter `apiSecret`.
- `expireAt` é um carimbo de data/hora Unix em segundos, e não um TTL.

Exemplo de endpoint de back-end do parceiro:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```


<span id="partner-endpoint-contract" data-sixmm-canonical-anchor="partner-endpoint-contract" aria-hidden="true"></span>

## Contrato de endpoint do parceiro

Autentique a sessão do parceiro e derive `agentUserId` do lado do servidor. Aceite o widget atual `channelId`; return `embedToken` de nível superior, `expireAt` (segundos Unix) e o mesmo `channelId`. As respostas do agente não fornecem `channelId`: o seu back-end faz eco. Obtenha um novo token no arranque e na renovação; nunca o reutilize. A criação de tokens não transfere fundos nem escolhe o ambiente da carteira.

Ver [Negociação de segundos](/pt-PT/sdk/agent-sdk/java/seconds-trading) para o fluxo completo de frontend/backend.
