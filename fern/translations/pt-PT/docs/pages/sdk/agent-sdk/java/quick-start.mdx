## Instalação

A fonte pública SDK documenta atualmente a etiqueta `v0.1.1` com estas coordenadas Maven:

```xml
<dependency>
    <groupId>com.sixmm.exchange.sdk</groupId>
    <artifactId>agent</artifactId>
    <version>0.1.1</version>
</dependency>
```

O GitHub não funciona como repositório de dependências do Maven. Instale o código-fonte marcado localmente antes de resolver a dependência:

```bash
git clone https://github.com/6mm-com/agent-java-sdk.git
cd agent-java-sdk
git checkout v0.1.1
mvn install
```

> **Construção de equipas**
>
> Publique o artefacto aprovado no repositório Maven da sua organização para CI, testes e builds de produção. Confirme a versão aprovada com 6MM antes da implementação em produção.

Exemplos de código-fonte e utilização estão disponíveis no repositório oficial de Java SDK :

[6mm-com/agent-java-sdk](https://github.com/6mm-com/agent-java-sdk)

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Antes de começares

- Confirma o teu agente de produção API URL base com a equipa 6MM .
- Armazenar apiSecret apenas na gestão de segredos do backend.
- Preparar um mapeamento estável entre platformUserId e agentUserId.
- Permitir registos estruturados em torno dos fluxos de ligação, transferência, ordem e webhook.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Inicializar cliente

```java
import com.sixmm.agent.AgentClient;
import com.sixmm.agent.AgentClientConfig;

AgentClient client = new AgentClient(AgentClientConfig.builder()
        .baseUrl("https://agent-api.6mm.com")
        .agentCode("AGENT001")
        .apiSecret("your-api-secret")
        .defaultCurrency("USDT")
        .build());
```

> **Apenas backend**
>
> Não inicialize o Agent SDK a partir do código do cliente do navegador, móvel ou ambiente de trabalho. O SDK assina pedidos privilegiados de Agente API .

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Exemplo: transferir fundos em

```java
TransferResponse resp = client.transfer(TransferRequest.fixed(
        "AGT-ORDER-1001",
        "agent-user-001",
        Direction.IN,
        "USDT",
        "10.00"));
```

Use um número de pedido único do lado do parceiro para cada pedido de transferência. Se um pedido expirar, consulta a ordem original antes de criar uma nova.
