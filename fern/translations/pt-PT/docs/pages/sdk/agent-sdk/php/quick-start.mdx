## Instalação

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Acesso ao pacote**
>
> 6MM fornece o nome do pacote Composer aprovado, repositório e versão durante a integração do parceiro. Não se deve assumir que o pacote existe no Packagist público.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Antes de começares

- Confirma o Agente API base URL com 6MM.
- Carregar apiSecret a partir de variáveis de ambiente ou gestão de segredos.
- Manter SDK utilização apenas dentro dos serviços backend.
- Preparar o manuseamento de idempotentes para transferências e fluxos de webhook.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Inicializar cliente

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Apenas backend**
>
> O PHP SDK assina pedidos de Agente API e não deve ser exposto através de código-fonte público ou ambientes de execução frontend.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Exemplo: transferir fundos em

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Use cadeias decimais para os valores e preserve o agentOrderNo original ao tentar novamente ou consultar o estado da transferência.
