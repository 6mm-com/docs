## Duração

| Item | Valor |
| --- | --- |
| Pacote | Sixmm/agente-SDK |
| Versão mínima PHP | PHP 7,4+ |
| Versão PHP recomendada | PHP 8.1+ ou versões atualmente suportadas |
| Extensões obrigatórias | ext-json, ext-curl |

A fonte do pacote PHP SDK e a versão aprovada são fornecidas durante a integração do parceiro. Não presuma que o pacote está disponível na Packagist pública; Configure o repositório Composer fornecido para a sua organização.

<span id="supported-scenarios" data-sixmm-canonical-anchor="supported-scenarios" aria-hidden="true"></span>

## Cenários suportados

| Cenário | SDK método |
| --- | --- |
| Associar utilizador | Vincular |
| Transferência de montante fixo | Transferência |
| Transferir tudo para fora | transferAllOut |
| Transferência inversa | Reverso |
| Ordem da consulta | queryOrder |
| Criar entrada URL | createEntryUrl |
| Verificação por Webhook | WebhookVerifier::verify |

<span id="backend-integration-rules" data-sixmm-canonical-anchor="backend-integration-rules" aria-hidden="true"></span>

## Regras de integração backend

- Carregar `apiSecret` a partir de um gestor secreto ou variável de ambiente protegido.
- Manter a ligação do utilizador, transferência, assinatura e lógica de webhook fora do código do navegador.
- Utilizar cadeias decimais para os montantes dos ativos para evitar arredondamento em ponto flutuante.
- Reutilizar o `agentOrderNo` original ao consultar um resultado de transferência incerto.
- Verificar as assinaturas do webhook em relação ao corpo bruto do pedido antes de o descodificar ou alterar.
