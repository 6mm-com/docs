## Copiar o código de integração do locatário

Abra **Configurações do sistema → Integração de sites**. Configure os domínios de sites permitidos e copie o código gerado. A App Key identifica o seu locatário; não é uma palavra-passe de login ou um segredo de assinatura de identidade. O widget de suporte ao cliente é separado do Trading Widget SDK.

 URL gerado pela sua consola.

```html
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"></script>
```

Para um botão existente:

```html
<button id="support-button">Contact support</button>
<script src="https://cs.6mm.com/widget/widget.js"
        data-app-key="YOUR_TENANT_APP_KEY"
        data-trigger="#support-button"></script>
```

## Identidade do visitante

| Modo | Responsabilidade de integração |
| --- | --- |
| Visitante anónimo | Use a entrada de visitante configurada pelo locatário; o sistema identifica o visitante do browser |
| Utilizador conectado |  |

Os atributos de login suportados são <code>ID do utilizador de dados</code> e <code>token de utilizador de dados</code>. Mantenha a assinatura em segredo no seu servidor; não o insira HTML, código móvel ou um aviso de IA. Utilize o formato exato do token e o tempo de vida apresentado na consola.

Para um aplicativo ou WebView, use o modo de entrada e integração fornecido para seu locatário. Teste a navegação, autenticação, seleção de arquivos e comportamento da janela de visualização no dispositivo real; um snippet de um site por si só não estabelece SDK apoio.
