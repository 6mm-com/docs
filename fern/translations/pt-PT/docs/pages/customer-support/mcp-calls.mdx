## Conheça as ferramentas disponíveis

Após a autorização de OAuth, utilize um cliente MCP com Streamable HTTP para inicializar a ligação e obter ferramentas através de `tools/list`. Chamar ferramentas através de `tools/call`. Leia cada esquema de entrada devolvido em vez de derivar parâmetros a partir de URLs REST. Os IDs obtidos a partir de leituras são normalmente strings decimais para argumentos de caminho; um campo numérico dentro de um corpo permanece numérico onde o esquema o exige.

Os exemplos abaixo são mensagens da ferramenta JSON-RPC após a inicialização, e não pedidos HTTP independentes completos. O cliente fornece o token de acesso e os cabeçalhos do protocolo. Substitua os IDs ilustrativos por registos devolvidos ao seu próprio locatário.

<span id="read-categories" data-sixmm-canonical-anchor="read-categories" aria-hidden="true"></span>

## Ler categorias

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "knowledge_get_categories",
    "arguments": {}
  }
}
```

<span id="create-a-draft" data-sixmm-canonical-anchor="create-a-draft" aria-hidden="true"></span>

## Crie um rascunho

Escolha uma categoria existente no resultado da leitura. A categoria é obrigatória. Não defina um estado de publicado, a menos que pretenda publicar e preencher qualquer confirmação necessária.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "knowledge_create_article",
    "arguments": {
      "requestId": "support-demo-create-001",
      "body": {
        "title": "Withdrawal guide draft",
        "content": "Reviewed withdrawal instructions go here.",
        "categoryId": 12,
        "status": "draft"
      }
    }
  }
}
```

<span id="preview-an-update-or-deletion" data-sixmm-canonical-anchor="preview-an-update-or-deletion" aria-hidden="true"></span>

## Visualizar uma atualização ou eliminação

Leia primeiro o artigo. Visualize a gravação exata pretendida, incluindo um novo ID de pedido. A visualização não a executa.

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "mcp_preview",
    "arguments": {
      "tool": "knowledge_delete_article",
      "arguments": {
        "id": "123",
        "requestId": "support-demo-delete-001"
      }
    }
  }
}
```

Copie o `version` devolvido em `expectedVersion` sem alterar o destino ou os parâmetros pretendidos:

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "knowledge_delete_article",
    "arguments": {
      "id": "123",
      "requestId": "support-demo-delete-001",
      "expectedVersion": "REPLACE_WITH_THE_64_CHARACTER_VERSION_FROM_PREVIEW"
    }
  }
}
```

O espaço reservado não é uma versão válida. Utilize o valor real de 64 caracteres devolvido pela visualização.

<span id="confirm-and-check-the-result" data-sixmm-canonical-anchor="confirm-and-check-the-result" aria-hidden="true"></span>

## Confirme e confira o resultado

Se o resultado for `awaiting_approval`, abra `approvalUrl`, inicie sessão como conta de autorização e reveja a ação. Só aprová-lo executa a operação pendente. A confirmação expira atualmente após 15 minutos. A rejeição ou expiração não executa a gravação.

```json
{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "mcp_operation",
    "arguments": {
      "operationId": "REPLACE_WITH_RETURNED_OPERATION_ID"
    }
  }
}
```

A saída da ferramenta é transportada em conteúdo de texto contendo JSON; inspecione-o e qualquer sinalizador `isError`. Uma resposta HTTP ou um link de aprovação por si só não provam sucesso. Leia o estado da operação e, quando útil, consulte o registo afetado.

<span id="retry-safely" data-sixmm-canonical-anchor="retry-safely" aria-hidden="true"></span>

## Tente novamente em segurança

Reutilize os mesmos `requestId` e argumentos para uma nova tentativa de rede da mesma escrita. Não o reutilize para outra ação. Se o conteúdo tiver sido alterado, leia e visualize novamente e, em seguida, envie uma nova operação pretendida com um novo ID de pedido. Se uma resposta for perdida ou uma operação continuar a ser executada, consulte o seu estado e registo comercial antes de decidir o que fazer; nunca presuma que um tempo limite significa que nada aconteceu.

O cliente AI geralmente executa este protocolo para o utilizador. Estes detalhes são para os programadores de clientes e para diagnosticar o fluxo de trabalho de uma ferramenta.
