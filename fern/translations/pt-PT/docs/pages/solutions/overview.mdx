<h2 id="how-the-solutions-connect">Como as soluções se conectam</h2>

A maioria das implementações de parceiros combina mais do que uma capacidade de 6MM . Uma bolsa de marca branca pode usar liquidez institucional, suporte de conformidade e integrações API . Um parceiro comercial embutido pode começar com o Trading Widget SDK e depois adicionar fluxos de Agent SDK backend, processamento de webhooks e recursos operacionais.
