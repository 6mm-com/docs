<h2 id="which-path-should-i-choose">Qual caminho devo escolher?</h2>

| Objetivo empresarial | Solução recomendada | Médicos primários |
| --- | --- | --- |
| Adicionar trading a um produto existente | Embedded API / SDK Sistema de Negociação | SDKs, Desenvolvedores |
| Melhorar a profundidade do mercado e a qualidade da execução | Soluções Institucionais de Liquidez | Comércio, Desenvolvedores |
| Lance rapidamente uma bolsa de marca | Sistema de Troca de Marca Branca | Soluções, Recursos |
| Preparar-se para operações reguladas | Licenciamento de Conformidade e Consultoria | Segurança e Conformidade |

<h2 id="how-the-solutions-connect">Como as soluções se conectam</h2>

A maioria das implementações de parceiros combina mais do que uma capacidade 6MM . Uma bolsa white label pode utilizar liquidez institucional, apoio à conformidade e integrações API . Um parceiro comercial embutido pode começar pelo Trading Widget SDK e depois adicionar fluxos de Agent SDK backend, processamento de webhooks e recursos operacionais.
