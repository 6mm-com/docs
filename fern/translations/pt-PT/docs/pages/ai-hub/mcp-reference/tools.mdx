> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


As ferramentas MCP são ações que um cliente de IA pode chamar. Cada ferramenta deve ter uma descrição clara, esquema JSON, requisito de permissão, formato de resposta estável e modelo de erro.

<span id="phase-1-public-market-tools" data-sixmm-canonical-anchor="phase-1-public-market-tools" aria-hidden="true"></span>

## Fase 1: ferramentas de mercado público

| Ferramenta | Finalidade |
| --- | --- |
| 6mm_estado_do_sistema | Verifique a disponibilidade do serviço e do mercado. |
| 6mm_mercados | Enumere os mercados disponíveis e os metadados básicos. |
| 6mm_market_summary | Resuma o estado do mercado para um ou mais símbolos. |
| 6mm_ticker | Devolver os dados mais recentes do ticker. |
| 6mm_carteira de encomendas | Profundidade do livro de pedidos de devolução. |
| 6mm_klines | Devolva velas históricas. |
| 6mm_negociações | Devolver negociações públicas recentes. |
| 6 mm_taxas_de_financiamento | Devolver as taxas de financiamento atuais e históricas. |

## Fase 3 e seguintes: ferramentas de negociação

| Ferramenta | Finalidade |
| --- | --- |
| 6mm_preview_order | Valide um pedido sem o colocar. |
| 6mm_create_order | Crie um pedido após confirmação e verificações de risco. |
| 6mm_cancelar_encomenda | Cancele um pedido. |
| 6mm_cancelar_todas_encomendas | Cancele todos os pedidos abertos elegíveis. |
| 6mm_amend_order | Alterar um pedido existente. |
| 6mm_order_status | Leia o estado de um pedido específico. |

<span id="tool-requirements" data-sixmm-canonical-anchor="tool-requirements" aria-hidden="true"></span>

## Requisitos da ferramenta

Cada ferramenta deve definir:

- Descrição do modelo de IA.
- Esquema de entrada JSON.
- Âmbito de permissão.
- Apoio ambiental.
- Comportamento do limite de taxa.
- Campos de resposta estáveis.
- Códigos de erro.
- Campos de registo de auditoria.
