> **Planeado – ainda não lançado**
> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


Os recursos MCP são contextos de leitura apenas que os clientes de IA podem inspecionar antes de chamar as ferramentas.

As características reduzem a alucinação, fornecendo ao modelo informações estruturadas e estáveis ​​sobre 6MM.

<h2 id="recommended-resource-uris">URIs de recursos recomendados</h2>

| Recurso | Finalidade |
| --- | --- |
| 6mm://sistema/config | Configuração do ambiente e capacidade. |
| 6mm://sistema/estado | Sistema atual e estado do mercado. |
| 6mm://mercados | Mercados disponíveis. |
| 6mm://mercado/{symbol} | Especificações de contratos e metadados ao nível de mercado. |
| 6mm://taxas | Regras de taxas. |
| 6mm://risco/regras | Resumo das regras de negociação e de risco. |
| 6mm://risco/margem | Contexto de margem e liquidação. |
| 6mm://financiamento/regras | Regras de taxa de financiamento. |
| 6mm://api/docs | API resumo de referência ou ligações. |

<h2 id="resource-design-rules">Regras de design de recursos</h2>

- Mantenha os recursos de leitura apenas.
- Utilize esquemas estáveis.
- Inclua carimbos de data/hora e nomes de ambiente.
- Evite expor segredos.
- Prefira dados estruturados concisos em vez de prosa longa.
- Ligação para documentação canónica quando os detalhes são demasiado longos.
