> **Planeado – ainda não lançado**
> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


Escolha uma configuração com base em duas questões:

1. Qual o cliente de IA que pretende usar?
2. Necessita apenas de dados públicos, acesso a contas privadas ou fluxos de trabalho de negociação?

Se não tiver a certeza, comece com MCP alojado para dados públicos ou MCP local para fluxos de trabalho de contas privadas.

## Tabela de decisão rápida

| Objetivo | Configuração recomendada | Porquê |
| --- | --- | --- |
| Peça a um cliente de IA dados públicos de mercado | Alojado MCP | Não é necessária instalação local e nenhuma chave API necessária. |
| Deixe o Claude Desktop, Cursor ou ChatGPT Desktop chamar ferramentas 6MM | Localização MCP | A IA chama as ferramentas através de um servidor local controlado pelo utilizador. |
| Sejam Codex, Claude Code, Gemini CLI, ou scripts a chamar 6MM | CLI | A saída do comando pode ser JSON e fácil de ser analisada pelos agentes. |
| Forneça um endpoint MCP gerido pela empresa | Remoto MCP | A instituição controla o alojamento, as credenciais, o acesso e os logs. |
| Estandardize análises repetidas ou fluxos de trabalho de risco | Habilidades Agentes | Os modelos definem a utilização da ferramenta, as proteções e o formato de saída. |

## Escolha por caminho de configuração

| Configurar | Instalação | API localização da chave | Melhor âmbito inicial | Âmbito da conta e negociação |
| --- | --- | --- | --- | --- |
| Alojado MCP | Nenhum | Sem chave de utilizador API para dados públicos | Dados públicos do mercado | Não recomendado para primeiro lançamento |
| Localização MCP | Pacote de instalação do utilizador | Máquina do utilizador | Dados públicos e leitura da conta | Caminho recomendado para futuras negociações |
| CLI | Pacote de instalação do utilizador | Máquina do utilizador | Dados públicos e scripts | Útil para visualização e automação |
| Remoto MCP | O utilizador implanta o servidor | Nuvem de utilizador ou nuvem institucional | Dados públicos ou leitura da conta | Possível quando o utilizador controla a implementação |
| Competências | Documentos ou modelos instaláveis | Depende das ferramentas subjacentes | Fluxos de trabalho de análise | Deve seguir as permissões da ferramenta |

<span id="security-rule-of-thumb" data-sixmm-canonical-anchor="security-rule-of-thumb" aria-hidden="true"></span>

## Regra prática de segurança

Utilize a definição de menor risco que suporta a tarefa:

- Dados públicos do mercado: MCP alojados é suficiente.
- Dados da conta privada: Local MCP ou remoto gerido pelo utilizador MCP.
- Vista de negociação: Local MCP ou CLI, de preferência testnet first.
- Negociação real: apenas após permissão explícita, visualização, confirmação, limites e registos de auditoria.
