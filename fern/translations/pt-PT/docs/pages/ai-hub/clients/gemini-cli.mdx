> **Planeado – ainda não lançado**
> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


O Gemini CLI funciona melhor com a saída de linha de comandos que pode ser inspecionada, resumida e passada para tarefas de acompanhamento.

<h2 id="recommended-setup">Configuração recomendada</h2>

| Necessidade | Configurar |
| --- | --- |
| Verificações do mercado público | 6MM CLI |
| Pesquisa com script | 6MM CLI |
| Contexto da conta privada | Local MCP ou CLI com credenciais locais |

<h2 id="example-prompts">Solicitações de exemplo</h2>

```text
Use 6MM CLI to fetch market metadata and summarize tradable pairs.
```

```text
Use 6MM to compare fee and margin rules for two symbols.
```

<h2 id="output-format">Formato de saída</h2>

Prefira resultados estruturados, como JSON ou tabelas Markdown, para que o cliente de IA possa raciocinar sobre o resultado sem perder a precisão.
