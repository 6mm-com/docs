> **Planeado – ainda não lançado**
> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


O ChatGPT Desktop é um ponto de entrada familiar para utilizadores que desejam fazer perguntas de mercado em linguagem natural.

Utilize este caminho quando o utilizador pretende uma interface de conversação para dados públicos de mercado, resumos de contas, explicações de posições e contexto de regras de negociação.

<h2 id="recommended-setup">Configuração recomendada</h2>

| Necessidade | Configurar |
| --- | --- |
| Dados públicos do mercado | Alojado MCP |
| Contexto da conta privada | Localização MCP |
| Pedidos de análise repetíveis | Habilidades Agentes |
| Fluxos de trabalho baseados em terminal | 6MM CLI |

<h2 id="what-users-can-ask">O que os utilizadores podem perguntar</h2>

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<h2 id="safety-defaults">Padrões de segurança</h2>

- Comece pelos dados públicos de mercado.
- Utilize Local MCP quando as credenciais da conta forem necessárias.
- Mantenha as chaves privadas API na máquina do utilizador.
- Exija visualização e confirmação explícita antes de qualquer ação comercial futura.
