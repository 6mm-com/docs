> **Planeado – ainda não lançado**
> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


O Claude Desktop é uma boa opção para pesquisa baseada em MCP-, revisão de contas e análise operacional.

<h2 id="recommended-setup">Configuração recomendada</h2>

| Necessidade | Configurar |
| --- | --- |
| Pesquisa de mercado público | Alojado MCP |
| Análise com reconhecimento de conta | Localização MCP |
| Endpoint da equipa interna | Remoto MCP |

<h2 id="example-prompts">Solicitações de exemplo</h2>

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<h2 id="notes">Notas</h2>

MCP local é preferido sempre que estão envolvidos dados de contas privadas porque o servidor MCP é executado na máquina do utilizador e as credenciais não precisam de ser enviadas para um endpoint de IA alojado por 6MM.
