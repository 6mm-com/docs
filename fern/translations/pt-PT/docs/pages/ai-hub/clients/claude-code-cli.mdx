> **Planeado – ainda não lançado**
> O AI Hub é um recurso planeado. As características, terminais, comandos e definições do cliente nesta página descrevem o design proposto e não estão atualmente disponíveis. A disponibilidade final e as instruções de configuração serão anunciadas no lançamento.


O Código Claude CLI é útil quando o agente pode executar comandos de terminal, inspecionar a saída JSON e atualizar o código de integração.

<h2 id="recommended-setup">Configuração recomendada</h2>

| Necessidade | Configurar |
| --- | --- |
| Verificações rápidas de mercado | 6MM CLI |
| Contexto da conta local | Localização MCP |
| Fluxo de trabalho de implementação repetível | Habilidades Agentes |

<h2 id="example-tasks">Tarefas de exemplo</h2>

```text
Use 6MM CLI to list available perpetual markets and return JSON.
```

```text
Use 6MM to inspect webhook event examples and generate an idempotent handler plan.
```

```text
Use 6MM testnet data to validate this Trading Widget integration. Do not place live orders.
```

<h2 id="best-practice">Melhores práticas</h2>

Prefira a saída JSON para os fluxos de trabalho do agente. É mais fácil analisar, comparar e incluir nos registos de implementação.
