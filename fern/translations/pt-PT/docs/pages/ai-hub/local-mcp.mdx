Local MCP é a configuração recomendada quando um cliente de IA necessita de contexto de conta privada ou de ferramentas de negociação controladas no futuro.

O servidor MCP é executado na máquina do utilizador. O cliente AI chama ferramentas locais 6MM e o servidor local comunica com 6MM APIs utilizando credenciais configuradas pelo utilizador.

<span id="what-your-ai-client-can-do" data-sixmm-canonical-anchor="what-your-ai-client-can-do" aria-hidden="true"></span>

## O que o seu cliente de IA pode fazer

Com Local MCP, um cliente de IA pode utilizar ferramentas 6MM de forma controlada:

- Obtenha dados históricos e em direto do mercado.
- Leia os saldos de contas, posições, pedidos abertos, preenchimentos e registos de financiamento quando as credenciais de leitura apenas estão ativadas.
- Explique a exposição do portefólio, a utilização de margem e o risco de liquidação.
- Visualize os pedidos antes de qualquer pedido real ser feito.
- Nas fases posteriores de negociação controlada, crie ou cancele encomendas apenas após permissão explícita e verificações de risco.

Utilize Local MCP quando as credenciais devem permanecer na máquina do utilizador.

## Arquitetura

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

<span id="example-configuration" data-sixmm-canonical-anchor="example-configuration" aria-hidden="true"></span>

## Configuração de exemplo

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

<span id="recommended-permission-tiers" data-sixmm-canonical-anchor="recommended-permission-tiers" aria-hidden="true"></span>

## Níveis de permissão recomendados

| Nível | Ferramentas | Notas |
| --- | --- | --- |
| Dados públicos | Mercados, ticker, carteira de ordens, klines, negociações, financiamento | Sem acesso à conta privada. |
| Leitura da conta | Saldos, posições, ordens abertas, preenchimentos | Requer o âmbito de chave API de leitura apenas. |
| Antevisão da negociação | Pedido de visualização, impacto na margem, estimativa de taxas | Não faz encomendas. |
| Negociação controlada | Criar, cancelar, alterar encomendas | Requer permissão explícita, confirmação e controlos de risco. |

<span id="first-setup-checklist" data-sixmm-canonical-anchor="first-setup-checklist" aria-hidden="true"></span>

## Lista de verificação da primeira configuração

1. Instale o pacote MCP.
2. Crie ou configure uma chave API de leitura apenas.
3. Comece na rede de teste.
4. Adicione o servidor MCP à configuração do cliente AI.
5. Peça ao cliente para listar as ferramentas 6MM disponíveis.
6. Execute uma consulta de dados de mercado público.
7. Só depois adicione as credenciais de leitura da conta, se necessário.

<span id="security-notes" data-sixmm-canonical-anchor="security-notes" aria-hidden="true"></span>

## Notas de segurança

O local MCP deve ser padronizado como de leitura apenas e testnet. As ferramentas de negociação devem exigir visualização, confirmação do utilizador, chaves de idempotência, limites nocionais e verificações de risco do lado do serviço.
