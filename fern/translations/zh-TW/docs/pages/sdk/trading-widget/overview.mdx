<h2 id="responsibility-split">責任分工</h2>

| 面積 | 擁有者 | 註釋 |
| --- | --- | --- |
| 容器建立 | 合作夥伴前端 | 提供一個明顯且寬度與高度的可見元素。 |
| iframe 創建 | Trading Widget SDK | SDK負責建立並管理 iframe。 |
| 交易使用者介面 | 6MM iframe | K-line、訂單簿、訂單表、持倉、訂單及帳戶資料皆在 iframe 內運行。 |
| 顯示控制 | Trading Widget SDK + 6MM iframe | PC 嵌入標頭和底部的行情條預設是隱藏的。夥伴可以用 `display` 顯示貝殼區域或隱藏高階交易容器。 |
| 合作夥伴登入檢查 | 合作夥伴後端 | 在發出認證憑證前，請驗證合作夥伴使用者會話。 |
| 嵌入代幣發行 | 合作夥伴後端 + 代理 API | 推薦用於夥伴代幣模式。 |

<h2 id="versioning">版本控制</h2>

公開整合路徑在 v1 腳本下保持穩定 URL。目前的 v1 能力集包含夥伴標記、 tokenProvider、 entryUrlProvider、顯示控制項、生命週期事件、實例方法與訂單事件。

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">何時使用小工具</h2>

當合作夥伴需要在現有產品中建立完整的交易介面時，請選擇 Trading Widget 。建立和維護完全自訂的交易介面時，請使用 REST API 和 WebSocket 文件。

<h2 id="implementation-path">實作路徑</h2>

1. 依照 [Trading Widget 快速啟動]（/sdk/trading-widget/quick-start） 載入腳本並建立可見容器。
2. 透過合作夥伴後端配置[夥伴令牌認證]（/sdk/trading-widget/authentication）。
3. 新增所需的[選項與事件]（/sdk/trading-widget/options-events）。
4. 使用[實例方法]（/sdk/trading-widget/instance-methods）來控制生命週期與執行時。
