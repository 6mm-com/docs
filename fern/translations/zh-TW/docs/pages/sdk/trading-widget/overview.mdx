## 責任劃分

| 區域 | 所有者 | 筆記 |
| --- | --- | --- |
| 容器創建 | 合作伙伴前端 | 提供具有明確寬度和高度的可見元素。 |
| iframe 創建 | Trading Widget SDK | SDK 創建並管理 iframe。 |
| 交易界面 | 6MM iframe | K線、訂單簿、訂單表格、倉位、訂單和賬戶數據在iframe內部運行。 |
| 顯示控制 | Trading Widget SDK + 6MM iframe | 默認情況下，PC 嵌入標題和底部代碼是隱藏的。合作伙伴可以使用`display`顯示外殼區域或隱藏高級交易容器。 |
| 合作伙伴登錄檢查 | 合作伙伴後臺 | 在發出身份驗證憑據之前驗證合作伙伴用戶會話。 |
| 嵌入代幣發行 | 合作伙伴後端+代理API | 推薦用於合作伙伴令牌模式。 |

<span id="versioning" data-sixmm-canonical-anchor="versioning" aria-hidden="true"></span>

## 版本控制

公共集成路徑在 v1 腳本 URL 下保持穩定。當前的 v1 功能集包括合作伙伴令牌、tokenProvider、entryUrlProvider、顯示控件、生命週期事件、實例方法和訂單事件。

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<span id="when-to-use-the-widget" data-sixmm-canonical-anchor="when-to-use-the-widget" aria-hidden="true"></span>

## 何時使用小部件

當合作夥伴需要在現有網絡產品中提供完整的交易界面時，請選擇 Trading Widget。在構建和維護完全自定義的交易界面時，請使用 REST API 和 WebSocket 文檔。

<span id="implementation-path" data-sixmm-canonical-anchor="implementation-path" aria-hidden="true"></span>

## 實施路徑

1. 遵循 [Trading Widget 快速入門](/zh-TW/sdk/trading-widget/quick-start) 加載腳本並創建可見容器。
2. 配置 [合作伙伴令牌身份驗證](/zh-TW/sdk/trading-widget/authentication) 通過合作伙伴後端。
3. 添加所需的 [選項和事件](/zh-TW/sdk/trading-widget/options-events).
4. 使用 [實例方法](/zh-TW/sdk/trading-widget/instance-methods) 用於生命週期和運行時控制。

<span id="verified-public-runtime" data-sixmm-canonical-anchor="verified-public-runtime" aria-hidden="true"></span>

## 經過驗證的公共運行時

截至 2026 年 10 月 10 日，公共 `v1` 腳本報告版本 `1.8.0`。此 URL 是一個穩定的主要版本入口點，而不是固定版本。在使用可選功能之前，請在加載的運行時中讀取 `TradingWidget.version` 和 `TradingWidget.capabilities`。 Java Agent SDK `v0.3.0` 是一個單獨的後端包。

運行時支持單個活動實例（`multiInstance=false`）；創建另一個小部件會破壞前一個實例。其支持的區域設置為 `en`、`en-US` 和 `zh-CN`，獨立於 20 種文檔語言。
