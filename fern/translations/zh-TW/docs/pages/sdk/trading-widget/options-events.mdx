| 場地 | 類型 | 默認 | 筆記 |
| --- | --- | --- | --- |
| baseUrl | string | SDK 腳本來源 | iframe 域。在合作伙伴頁面中明確傳遞。 |

## 顯示控制

`display` 控制嵌入式交易頁面 shell 和高級容器。在合作伙伴嵌入中，PC 標題和底部市場代碼默認隱藏。

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| 場地 | 類型 | 默認 | 筆記 |
| --- | --- | --- | --- |
| showHeader | boolean | 錯誤的 | 是否在 iframe 內顯示 PC 嵌入標頭。 |
| showTicker | boolean | 錯誤的 | 是否在嵌入外殼中顯示底部市場行情。 |
| 隱 | 細繩[] | [] | 隱藏交易頁面中的高級容器。 |

支持的 `display.hidden` 值：

| 價值 | 容器 |
| --- | --- |
| 圖表 | 圖表容器 |
| orderBook | 訂單簿容器 |
| orderForm | 訂單面板 |
| 職位 | 底部倉位和未平倉訂單面板 |
| 帳戶 | 賬戶資產容器 |

`display.hidden` 僅隱藏整個容器。它不會隱藏容器內的各個按鈕、字段或工具。未映射到當前視口的值將被忽略。

## 活動

| 事件 | 扳機 |
| --- | --- |
| 準備好 | iframe初始化完成。 |
| 錯誤 | SDK、iframe 或身份驗證錯誤。 |
| 狀態改變 | SDK 生命週期狀態已更改。 |
| auth_state_changed | 合作伙伴令牌身份驗證狀態已更改。 |
| 符號_更改 | 實際的 iframe 符號已更改。 |
| 語言環境已更改 | 實際 iframe 區域設置已更改。 |
| 訂單創建 | 用戶在 iframe 內創建了訂單。 |
| 訂單失敗 | 訂單提交失敗。 |
| 被摧毀 | SDK實例被摧毀。 |

## 產品頁面及交易模式

Java Agent SDK 和瀏覽器 Trading Widget SDK 版本獨立。對於秒交易，請使用當前的 Widget 功能並明確選擇頁面和交易模式。

| 選項 | 價值觀 | 意義 |
| --- | --- | --- |
| `page` | `up-down`，`high-low`，`grid-prediction` | 秒交易產品頁面。 |
| `tradingMode` | `real`，`demo` | 默認為`real`；明確匹配後端融資環境。 |

初始化前檢查`TradingWidget.capabilities.pages`、`TradingWidget.capabilities.tradingModes`和`TradingWidget.capabilities.partnerToken`。代幣創建不選擇資金環境。要更改用戶或真實/演示模式，請銷燬舊實例並創建一個新實例。

看 [完整的秒交易示例](/zh-TW/sdk/agent-sdk/java/seconds-trading) 和 [生產/模擬配置](/zh-TW/sdk/agent-sdk/java/environments).

## 附加顯示目標和事件

當前運行時還接受 `display.hidden` 中的 `symbolFavorites` 和 `symbolTicker`。始終檢查`TradingWidget.capabilities.displayTargets`；目標控制高級容器，而不是字段級權限設置。

| 事件 | 意義 |
| --- | --- |
| `rendered` | iframe 發送其渲染的通知。 |
| `theme_changed` | iframe 報告其實際主題。 |
| `page_changed` | iframe 報告其實際產品頁面。 |

使用 `onRendered` 或 `widget.on('rendered', handler)` 與初始化分開處理渲染。當前支持的頁面發佈在`TradingWidget.capabilities.pages`中；驗證請求的頁面而不是猜測路徑。
