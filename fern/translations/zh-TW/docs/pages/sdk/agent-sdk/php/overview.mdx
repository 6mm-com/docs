## 運行時間

| 項目 | 價值 |
| --- | --- |
| 包裝 | SixMM/agent-SDK |
| 最低 PHP 版本 | PHP 7.4+ |
| 推薦 PHP 版本 | PHP 8.1+ 或目前支援的版本 |
| 必要延期 | ext-json， ext-curl |

PHP SDK 套件來源及核准版本會在合作夥伴入職時提供。不要以為該套件是公開 Packagist 提供的;配置為你公司提供的 Composer 資料庫。

## 後端整合規則

- 從秘密管理器或受保護環境變數載入 `apiSecret` 。
- 避免使用者綁定、傳輸、簽署及 webhook 邏輯進入瀏覽器程式碼。
- 使用十進位字串表示資產數量，以避免浮點數四捨五入。
- 查詢不確定傳輸結果時，重用原始 `agentOrderNo` 。
- 在解碼或更改原始請求主體前，先驗證 webhook 簽章是否符合原始請求內容。
