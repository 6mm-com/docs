本指南針對 **Agent Java SDK `v0.3.0`**、Java 8+ 以及標記的公共合約。初始化 `client` 後在合作伙伴後端運行示例 [快速入門](/zh-TW/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- 六個永久查詢：當前訂單、訂單歷史、成交、當前持倉、持倉歷史和賬戶分類賬。
- 資金餘額、轉賬、回收查詢和資金/合同轉賬。
- 針對支持的資金請求的顯式生產/模擬選擇。
- 秒交易重定向和嵌入指南、響應字段參考和遷移說明。

Java SDK 和 Trading Widget SDK 具有獨立版本。 `v1` 小部件 URL 不是 Java SDK 版本 `0.3.0`。

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## 現有集成

保留用戶映射、原始訂單和憑據。省略的環境字段保留現有的生產行為。資金、顯式模擬資金、六項永續查詢都需要相應的新模型和方法。審查 [升級指南](/zh-TW/sdk/agent-sdk/java/upgrade) 在更改現有集成之前。
