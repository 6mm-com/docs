## 先決條件示例

Java 片段共享這些導入。使用快速啟動初始化 `client` 並從保存的綁定中獲取 `platformUserId`。示例用戶/訂單 ID 必須替換為您自己的持久值。

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## 直接輸入URL

直接輸入 URL 用於重定向模式。合作伙伴用戶單擊
合作伙伴站點，打開 6MM 前端，並自動登錄。

```java
import com.sixmm.agent.model.CreateEntryUrlRequest;
import com.sixmm.agent.model.CreateEntryUrlResponse;

CreateEntryUrlResponse resp = client.createEntryUrl(
        CreateEntryUrlRequest.of("agent-user-001")
                .withRedirectPath("/en/futures/BTCUSDT?tradingMode=real")
                .withReturnUrl("https://partner.example.com/return#markets"));

System.out.println(resp.webUrl);
System.out.println(resp.expireAt);
```

字段規則：

| 場地 | 描述 |
| --- | --- |
| `redirectPath` | 6MM 前端相對路徑。它必須以 `/` 開頭，例如 `/en/futures/BTCUSDT?tradingMode=real` |
| `returnUrl` | 當用戶退出 6MM 前端時使用合作伙伴絕對 URL。僅允許 `http` 和 `https` |
| `expireAt` | 入場券過期時間為 Unix 時間戳（以秒為單位） |

該示例在實模式下開啟永續期貨。對於模擬交易，在前端使用 `tradingMode=demo` 並在相應的後端錢包請求中顯式傳遞 `environment=SIMULATED`。前端`tradingMode`和後端資金`environment`分別配置。創建條目 URL 對用戶進行身份驗證；它不轉移資金或選擇錢包環境。

安全要求：

- `webUrl` 包含一張一次性門票。立即使用，不要長期存放。
- 如果條目 URL 過期或已被使用，請從合作伙伴網站生成一個新條目。
- `returnUrl` 不能是 `javascript:`、相對路徑或帶有用戶信息的 URL。

## 產品及模式選擇

使用 6MM 提供的當前前端路由。例如 `/zh-CN/up-down?tradingMode=demo`、`/zh-CN/high-low?tradingMode=real`、`/zh-CN/grid-prediction?tradingMode=real` 或 `/zh-CN/futures/BTCUSDT?tradingMode=real`。票據對用戶進行身份驗證；它不選擇融資環境或轉移資金。

看 [秒交易](/zh-TW/sdk/agent-sdk/java/seconds-trading) 用於重定向和嵌入示例。
