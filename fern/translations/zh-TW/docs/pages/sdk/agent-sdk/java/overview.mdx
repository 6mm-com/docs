## SDK 涵蓋什麼

| 類別 | 設想 | SDK API | 描述 |
| --- | --- | --- | --- |

| 接送服務 | 顛倒順序 | `reverse` | 當後端支持補償流時反轉成功的傳輸 |

## 配置

之前從6MM獲取以下值
整合。

| 物品 | 例子 | 描述 |
| --- | --- | --- |
| `baseUrl` | `https://agent-api.6mm.com` | 代理 API 基礎 URL，不帶尾部斜槓 |
| `agentCode` | `AGENT001` | 合作伙伴代碼 |
| `apiSecret` | `your-api-secret` | API簽名秘密。僅將其保留在後端 |
| `defaultCurrency` | `USDT` | 默認貨幣，通常為 `USDT` |
| `webhookUrl` | `https://partner.example.com/6mm/webhook` | 6MM 回調的合作伙伴端點 |

製作建議：

- 對代理 API 和 webhook 端點使用 HTTPS。
- 將 `apiSecret` 存儲在秘密管理器、配置中心或環境變量中。
- 保持服務器時間同步，最好與 NTP 同步。
- 保留所有合作伙伴訂單號並保持其全球唯一性。
- 切勿將 `apiSecret` 發送到瀏覽器、應用程序、小程序或前端源代碼。

## 自動簽名字段

對於簽名代理 API 調用，SDK 自動注入：

| 場地 | 來源 | 描述 |
| --- | --- | --- |
| `agentCode` | `AgentClientConfig.agentCode` | 合作伙伴代碼 |
| `timestamp` | 當前 UTC Unix 時間戳 | 秒數 |
| `nonce` | 安全隨機生成器 | 重放保護 |
| `sign` | HMAC-SHA256 | 請求籤名 |
| `currency` | `defaultCurrency` | 當轉賬/賬戶請求省略貨幣時填寫 |

簽名規則：

1. 排除`sign`。
2. 排除空值。
3. 按 ASCII 順序對鍵進行排序。
4. 作為 `k=v&k2=v2` 加入。
5. 使用 `apiSecret` 計算 HMAC-SHA256 十六進制。

正常的業務代碼不應該計算簽名或者手動設置
`agentCode`、`timestamp`、`nonce` 或 `sign`。
