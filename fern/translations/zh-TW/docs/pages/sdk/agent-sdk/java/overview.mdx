<h2 id="runtime">運行時間</h2>

| 項目 | 價值 |
| --- | --- |
| 最低 Java 版本 | Java 8+ |
| 推薦的建構工具 | Maven 3.9+ |
| Maven 群 | `com.sixmm.exchange.sdk` |
| Maven 神器 | `agent` |
| 文件來源標籤 | `v0.1.1` |

公開的 GitHub 倉庫是原始碼主機，不是 Maven 相依套件庫。在團隊建置前，請先在本地建置並安裝已標記的原始碼，或將核准的產物發佈到組織的私人 Maven 倉庫。

<h2 id="typical-backend-responsibilities">典型後端職責</h2>

- 驗證合作夥伴使用者會話。
- 將合作夥伴使用者映射到 agentUserId。
- 在首次交易或轉帳流前進行買權綁定。
- 致電 createEntryUrl 申請一次性全站 SSO。
- 呼叫createEmbedTokenTrading Widget夥伴標記模式。
- 驗證傳輸 webhook 並以冪零方式處理。

<h2 id="security-and-operational-rules">安全與操作規則</h2>

- 僅將 `apiSecret` 儲存在後端秘密管理器或受保護的環境變數中。
- 保持伺服器時間同步，因為簽署請求包含時間戳記。
- 將 `agentOrderNo` 視為持久的冪性密鑰，並保持其全域唯一性。
- 將 `platformUserId` 儲存為字串，並持續維持其與 `agentUserId`的關係。
- 在逾時或網路結果不確定後，先查詢原始傳輸。
