6MM Agent SDK 用於需要調用特權代理 APIs 的合作伙伴後端服務，而無需從頭開始實施簽名和請求處理。它不得在瀏覽器、移動設備或公共桌面代碼中運行，因為集成使用合作伙伴 API 機密。

<span id="when-to-use-the-agent-sdk" data-sixmm-canonical-anchor="when-to-use-the-agent-sdk" aria-hidden="true"></span>

## 何時使用 Agent SDK

當您的後端需要綁定合作伙伴用戶、通過批准的工作流移動資產、查詢交易記錄、創建嵌入式交易條目URL或驗證webhook通知時，請使用Agent SDK。使用 [Trading Widget SDK](/zh-TW/sdk/trading-widget/overview) 當合作夥伴前端需要顯示交易界面時單獨進行。

## 常用配置

| 鑰匙 | 例子 | 描述 |
| --- | --- | --- |
| baseUrl | `https://agent-api.6mm.com` | 6MM 代理 API 服務 URL 不帶尾部斜槓。 |
| agentCode | AGENT001 | 合作伙伴代理代碼。 |
| apiSecret | 你的 api 秘密 | API 簽名秘密僅存儲在後端。 |
| defaultCurrency | USDT | 轉賬和賬戶的默認貨幣APIs。 |
| webhookUrl | https://partner.example.com/6mm/webhook | 6MM webhook 通知的合作伙伴端點。 |

<span id="typical-integration-flow" data-sixmm-canonical-anchor="typical-integration-flow" aria-hidden="true"></span>

## 典型集成流程

1. 合作伙伴前端通過合作伙伴自己的賬戶系統對用戶進行身份驗證。
2. 合作伙伴後端將用戶映射到穩定的合作伙伴端標識符。
3. 後端使用 `agentCode` 和受保護的 API 秘密調用 Agent SDK。
4. SDK 簽署併發送代理 API 請求。
5. 後端存儲返回的業務標識符並稍後進行冪等處理webhooks。
6. 前端僅接收其所需的短暫結果或進入憑證。

## 生產清單

- 從後端秘密管理器加載 `apiSecret`，而不是源代碼。
- 將開發、登臺和生產憑證分開。
- 使用穩定的合作伙伴用戶映射和唯一的業務訂單標識符。
- 檢查超時請求的狀態時保留原始標識符。
- 驗證 webhook 簽名並存儲已處理的事件 ID。
- 編輯日誌中的機密和簽名，同時保留請求 ID 以獲取支持。
