自選預測允許用戶選擇上漲或下跌，以及當前可用的預測週期，隨時發起獨立訂單，無需等待漲跌預測的下一場次。

<span id="如何參與" data-sixmm-anchor-target="how-to-participate" aria-hidden="true"></span>
<h2 id="how-to-participate">如何參與</h2>

1. 選擇品種及該品種已啟用的週期。
2. 選擇上漲或下跌，輸入符合限制的金額。
3. 核對當前週期的固定賠率和預計返還。
4. 受理後查看訂單保存的開盤價、下單時間、到期時間和賠率。
5. 到期後在歷史訂單中跟蹤結算結果。

<span id="每筆訂單獨立記錄條件" data-sixmm-anchor-target="each-order-has-its-own-terms" aria-hidden="true"></span>
<h2 id="each-order-has-its-own-terms">每筆訂單獨立記錄條件</h2>

| 訂單條件 | 用途 |
| --- | --- |
| 品種與方向 | 確定價格序列和預測選項 |
| 開盤價格 | 該筆訂單的比較基準 |
| 週期與到期時間 | 確定該筆訂單何時到期 |
| 下注金額與固定賠率 | 確定已受理金額與返還倍數 |
| 結算價格與結果 | 記錄判定結果 |

同一週期配置的固定賠率適用於上漲和下跌兩個方向。訂單受理後保存賠率快照，後續配置變更不替換已有訂單的賠率。

<span id="判定與示例" data-sixmm-anchor-target="result-and-example" aria-hidden="true"></span>
<h2 id="result-and-example">判定與示例</h2>

結算價高於開盤價為上漲，低於開盤價為下跌。價格相等時，需要按對應產品規則處理。

例如，一筆看跌訂單開盤價為 3,000、結算價為 2,990，所選方向獲勝。假設下注 100 USDT、鎖定賠率 1.85x，未計單獨披露費用的總返還為 185 USDT，其中包含下注本金，淨盈利為 85 USDT。

<span id="注意事項" data-sixmm-anchor-target="things-to-check" aria-hidden="true"></span>
<h2 id="things-to-check">注意事項</h2>

- 不同時間提交的訂單，開盤價和結果可能不同。
- 核對結果時使用訂單保存的到期時間，不以瀏覽器倒計時作為結算憑據。
- 一個品種支持的週期和固定賠率，不代表其他品種採用相同配置。
