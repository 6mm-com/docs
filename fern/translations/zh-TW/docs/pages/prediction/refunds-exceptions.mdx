異常可能涉及價格中斷、價格證據不一致、賠率差異或結算處理失敗。異常需要有可追溯的處理結果，不能自動等同於未中獎。

<span id="common-situations" data-sixmm-canonical-anchor="common-situations" aria-hidden="true"></span>

## 常見情況

| 情況 | 應如何處理 |
| --- | --- |
| 網格有效時間內行情缺失 | 查詢異常或退款處理，缺少採樣不能證明未命中 |
| 下單請求超時 | 先查原訂單和凍結，再決定是否重新提交 |
| 頁面顯示與訂單結果不同 | 核對價格來源、時間、已受理條件及判定證據 |
| 結算似乎延遲 | 分別檢查最終狀態與流水 |
| 訂單已退款或作廢 | 查看原因、實際資金變動及剩餘凍結 |

<span id="refund-and-void-are-distinct" data-sixmm-canonical-anchor="refund-and-void-are-distinct" aria-hidden="true"></span>

## 退款與作廢的區別

退款描述資金處理，作廢描述訂單失效。不要僅憑標籤推斷退款金額或到賬時限，應核對記錄中的處理結果和資金流水。

報表有效下注不包含已退款、已作廢訂單。分析玩法表現時，退款不應當作中獎返還統計。

<span id="support-evidence" data-sixmm-canonical-anchor="support-evidence" aria-hidden="true"></span>

## 聯繫支持時提供什麼

提供訂單號、適用的場次編號、品種、相關時間、記錄賠率、結果／狀態及結算流水號。網格爭議還應附上已受理價格區間和有效時間窗。不要提供密碼、API 密鑰或完整訪問令牌。

支持入口見[合作伙伴支持](/zh-TW/resources/contact/support)，資金核對見[資金劃轉與流水](/zh-TW/prediction/transfers-ledger)。
