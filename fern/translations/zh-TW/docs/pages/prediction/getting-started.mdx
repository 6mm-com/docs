首次下單前，確認賬戶已開通預測功能，並理解所選玩法如何判定結果。

<span id="prepare-your-account" data-sixmm-canonical-anchor="prepare-your-account" aria-hidden="true"></span>

## 準備賬戶

從合作平臺進入預測頁面，檢查資金賬戶可用餘額、結算幣種及參與限制。其他賬戶中的餘額不代表可以直接用於預測。

<span id="select-an-order" data-sixmm-canonical-anchor="select-an-order" aria-hidden="true"></span>

## 選擇訂單條件

| 玩法 | 輸入金額前需要核對 |
| --- | --- |
| 漲跌預測 | 品種、場次編號、方向、停止下注時間和開獎時間 |
| 自選預測 | 品種、方向、所選週期及該筆訂單的時間條件 |
| 預測網格 | 品種、價格上下界、有效開始時間和結束時間 |

<span id="review-and-submit" data-sixmm-canonical-anchor="review-and-submit" aria-hidden="true"></span>

## 確認並提交

1. 輸入符合頁面單筆限制的下注金額。
2. 核對當前報價和預計返還；訂單受理前報價可能變化。
3. 閱讀結果規則、費用說明及相關截止時間。
4. 提交一次，隨後確認訂單號和已受理的訂單條件。

> **請求結果不明確，不等於下單失敗。**
> 如果頁面超時，先檢查當前訂單和賬戶流水，再決定是否重新提交。連續點擊可能產生多筆獨立訂單。

<span id="check-the-result" data-sixmm-canonical-anchor="check-the-result" aria-hidden="true"></span>

## 查看結果

通過當前訂單和歷史訂單跟蹤處理進度。用實際返還與結算流水核對資金；結算前的預計返還不屬於可用餘額。
