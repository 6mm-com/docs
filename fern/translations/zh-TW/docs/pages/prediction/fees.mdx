預測費用需要結合訂單賠率及合作平臺披露的費率規則理解。本頁不規定所有合作方統一適用的費率。

## 區分不同金額

| 項目 | 含義 |
| --- | --- |
| 賠率倍數 | 根據訂單條件確定中獎總返還 |
| 目標返獎參數 | 定價模型輸入，本身不等於一筆單獨扣費流水 |
| 單獨披露的平臺服務費 | 該產品／訂單適用時需要核對的收費 |
| 合作方營收結算 | 業務層面的分配，不自動等於用戶訂單再扣一次費用 |

運營模型包含預測平臺服務費這一費用類別，但僅憑該類別無法確定費率、扣費時點，或某筆訂單是否單獨收費。

## 提交前確認

- 當前玩法和賬戶是否適用費用。
- 收費基數、金額及扣費時點。
- 顯示返還是單獨收費之前還是之後的金額。
- 退款、作廢訂單的費用如何處理。

如果這些條款不明確，請先通過[合作伙伴支持](/zh-TW/resources/contact/support)瞭解適用費率，再參與交易。

## 核對時避免重複扣減

賠率參數和單獨費用是不同記錄。返還已按訂單賠率計算時，不要再根據猜測的比例重複扣減；應核對實際披露的收費和流水。
