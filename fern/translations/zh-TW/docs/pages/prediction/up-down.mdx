漲跌預測由系統組織場次。用戶選擇該場次結算價格相對開盤價格是上漲還是下跌，同一場次可以包含多筆用戶訂單。

<span id="如何參與" data-sixmm-anchor-target="how-to-participate" aria-hidden="true"></span>
<h2 id="how-to-participate">如何參與</h2>

1. 選擇已啟用的交易品種和週期。
2. 核對場次編號、開盤價格、下注窗口和開獎時間。
3. 選擇上漲或下跌，並輸入下注金額。
4. 核對當前賠率與預計返還，在開放下注期間提交。
5. 根據場次與訂單記錄查看最終結果和返還。

<span id="場次時間" data-sixmm-anchor-target="round-times" aria-hidden="true"></span>
<h2 id="round-times">場次時間</h2>

| 時間 | 含義 |
| --- | --- |
| 開始下注時間 | 該場次開始受理訂單 |
| 停止下注時間 | 不再接受該場次的新下注 |
| 開獎時間 | 計劃進行結果判定的時間 |
| 結算完成時間 | 結算處理實際完成的記錄時間 |

場次週期與下注開放時長是不同配置。應核對頁面時間，不能認為整個週期內都可以下注。

<span id="方向判定" data-sixmm-anchor-target="direction-result" aria-hidden="true"></span>
<h2 id="direction-result">方向判定</h2>

| 價格比較 | 方向 |
| --- | --- |
| 結算價格高於開盤價格 | 上漲 |
| 結算價格低於開盤價格 | 下跌 |

價格相等時並未形成上漲或下跌，應查看該場次適用的平價處理規則，不能自行認定一定判輸或退款。

<span id="賠率與示例" data-sixmm-anchor-target="odds-and-example" aria-hidden="true"></span>
<h2 id="odds-and-example">賠率與示例</h2>

報價隨上漲池、下跌池及本次下注金額變化，並受到配置上下限約束。後續資金池報價本身不能說明此前訂單的結算條件，應核對該筆訂單保存的規則。

例如，開盤價為 65,000、結算價為 65,100，實際方向為上漲。假設一筆中獎訂單的下注金額為 100 USDT、記錄賠率為 1.85x，則未計單獨披露費用的總返還為 185 USDT。這裡的數字僅用於解釋計算，不代表生產報價。
