<span id="所有玩法都有場次嗎" data-sixmm-anchor-target="do-all-games-use-rounds" aria-hidden="true"></span>
<h2 id="do-all-games-use-rounds">所有玩法都有場次嗎？</h2>

不是。漲跌預測使用系統場次；自選訂單有獨立週期與到期時間；網格訂單對應自己的格子和有效時間窗口。

<span id="網格結束時價格必須還在格子裡嗎" data-sixmm-anchor-target="must-the-price-finish-inside-my-grid-cell" aria-hidden="true"></span>
<h2 id="must-the-price-finish-inside-my-grid-cell">網格結束時價格必須還在格子裡嗎？</h2>

不需要。有效時間內發生符合規則的進入或穿越即可，時間窗結束後才觸碰不算。詳見[預測網格](/zh-TW/prediction/grid)。

<span id="網格移動會改變已下單條件嗎" data-sixmm-anchor-target="does-a-moving-grid-change-my-accepted-order" aria-hidden="true"></span>
<h2 id="does-a-moving-grid-change-my-accepted-order">網格移動會改變已下單條件嗎？</h2>

不會。實時網格重新居中或刷新時，已受理訂單的價格區間、有效時間和賠率仍按保存的條件處理。

<span id="顯示的返還全部是利潤嗎" data-sixmm-anchor-target="is-the-displayed-return-all-profit" aria-hidden="true"></span>
<h2 id="is-the-displayed-return-all-profit">顯示的返還全部是利潤嗎？</h2>

不是。中獎總返還包含下注本金部分。下注 100 USDT、賠率 1.85x，未計單獨費用的總返還是 185 USDT，淨盈利為 85 USDT。詳見[返還與盈虧計算](/zh-TW/prediction/returns-pnl)。

<span id="為什麼可用餘額小於資金賬戶餘額" data-sixmm-anchor-target="why-is-my-available-balance-lower-than-my-funding-balance" aria-hidden="true"></span>
<h2 id="why-is-my-available-balance-lower-than-my-funding-balance">為什麼可用餘額小於資金賬戶餘額？</h2>

待處理預測訂單可能凍結部分資金。統計總資產時，不要把這部分凍結再加一次。詳見[賬戶與餘額](/zh-TW/prediction/accounts-balances)。

<span id="為什麼高賠率格子不能下注" data-sixmm-anchor-target="why-is-a-high-odds-cell-unavailable" aria-hidden="true"></span>
<h2 id="why-is-a-high-odds-cell-unavailable">為什麼高賠率格子不能下注？</h2>

網格規則會將計算賠率超過最高配置的格子設為不可下注。產品開關、限額、時間和賬戶限制也可能阻止下單。

<span id="目標返獎率-97-代表一定返還-97-嗎" data-sixmm-anchor-target="does-a-97-target-return-guarantee-i-receive-97-back" aria-hidden="true"></span>
<h2 id="does-a-97-target-return-guarantee-i-receive-97-back">目標返獎率 97% 代表一定返還 97% 嗎？</h2>

不代表。它是模型參數，不是單筆返還或長期結果保證。詳見[賠率機制](/zh-TW/prediction/odds)。

<span id="結果延遲或請求超時怎麼辦" data-sixmm-anchor-target="what-if-the-result-is-delayed-or-my-request-times-out" aria-hidden="true"></span>
<h2 id="what-if-the-result-is-delayed-or-my-request-times-out">結果延遲或請求超時怎麼辦？</h2>

先查原訂單與流水，不要直接重複提交。價格證據缺失或結果存在爭議時，保留訂單條件並聯系支持。詳見[退款、作廢與異常處理](/zh-TW/prediction/refunds-exceptions)。

<span id="預測下注會計入合約成交額嗎" data-sixmm-anchor-target="are-prediction-stakes-included-in-perpetual-trading-turnover" aria-hidden="true"></span>
<h2 id="are-prediction-stakes-included-in-perpetual-trading-turnover">預測下注會計入合約成交額嗎？</h2>

兩者是獨立指標。預測報表分別統計有效下注、返還、用戶盈虧、退款和作廢，不應與現貨或合約成交額混算。

<span id="可以直接使用合約-api-下單示例參與預測嗎" data-sixmm-anchor-target="can-i-use-the-perpetual-api-order-examples-for-prediction" aria-hidden="true"></span>
<h2 id="can-i-use-the-perpetual-api-order-examples-for-prediction">可以直接使用合約 API 下單示例參與預測嗎？</h2>

不能據此認定合約接口接受預測訂單。應通過[合作伙伴支持](/zh-TW/resources/contact/support)確認當前接入已開通的預測接口與入口方式。
