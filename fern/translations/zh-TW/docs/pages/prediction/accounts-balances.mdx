預測使用資金賬戶。訂單佔用的下注資金以該賬戶內的“預測凍結”體現，不另外增加獨立的預測資產賬戶。

<span id="balance-components" data-sixmm-canonical-anchor="balance-components" aria-hidden="true"></span>

## 餘額組成

| 項目 | 含義 |
| --- | --- |
| 資金賬戶餘額 | 此模型中包含可用餘額和預測凍結的賬戶餘額 |
| 可用餘額 | 當前可用於允許操作的資金 |
| 預測凍結 | 為尚待資金處理的預測訂單保留的金額 |
| 預計返還 | 可能的結果金額，不是當前可用資金 |

在預測餘額模型中，資金賬戶餘額＝可用餘額＋預測凍結。頁面若顯示其他賬戶限制，還應分別檢查。

## 凍結示例

假設可用餘額為 1,000 USDT，沒有預測凍結和其他資金變動。受理並凍結一筆 100 USDT 訂單後，可用餘額變為 900 USDT，預測凍結為 100 USDT。凍結不會額外產生 100 USDT 資產。

最終結算按照記錄結果改變賬戶金額，結果計算見[返還與盈虧計算](/zh-TW/prediction/returns-pnl)。

## 避免重複計算

資金賬戶餘額已經包含預測凍結時，不要再次把凍結金額加到總資產裡。待結算訂單的預計返還也不能計為已實現資產。

現貨或永續賬戶中的餘額，不能在相應支持的劃轉完成前直接視為預測可用資金。詳見[資金劃轉與流水](/zh-TW/prediction/transfers-ledger)。
