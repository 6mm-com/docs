三種玩法共享訂單與資金處理流程，但各自採用不同的時間規則。

<span id="訂單生命週期" data-sixmm-anchor-target="order-lifecycle" aria-hidden="true"></span>
<h2 id="order-lifecycle">訂單生命週期</h2>

| 階段 | 需要核對的內容 |
| --- | --- |
| 選擇與報價 | 玩法、品種、金額、賠率和價格／時間條件 |
| 訂單受理 | 訂單號、保存的條件和受理結果 |
| 資金凍結 | 資金賬戶中該筆訂單對應的凍結 |
| 等待結果 | 場次開獎、獨立訂單到期或格子有效時間窗 |
| 結果處理 | 權威價格證據及訂單適用規則 |
| 結算 | 最終狀態、實際返還和結算流水 |
| 對賬 | 歷史訂單與賬戶資金變動一致 |

<span id="各玩法的時間差異" data-sixmm-anchor-target="timing-by-game" aria-hidden="true"></span>
<h2 id="timing-by-game">各玩法的時間差異</h2>

- **漲跌預測**：訂單歸屬系統場次，停止下注後等待結果處理。
- **自選預測**：每筆訂單獨立記錄開盤價和到期時間，不同用戶訂單的時間可能不同。
- **預測網格**：格子有明確的有效開始與結束時間，時間窗之外的觸碰不算命中。

<span id="處理中斷時" data-sixmm-anchor-target="if-processing-is-interrupted" aria-hidden="true"></span>
<h2 id="if-processing-is-interrupted">處理中斷時</h2>

不要根據頁面斷線或餘額刷新延遲推斷最終結果。重新打開訂單，檢查狀態並核對關聯流水。價格證據或結算處理異常時，參考[退款、作廢與異常處理](/zh-TW/prediction/refunds-exceptions)。

<span id="保留可追溯記錄" data-sixmm-anchor-target="keep-a-traceable-record" aria-hidden="true"></span>
<h2 id="keep-a-traceable-record">保留可追溯記錄</h2>

聯繫支持時提供訂單號、玩法、品種、下單時間、顯示狀態及已有的結算流水號。漲跌訂單可以補充場次編號；網格截圖本身不能替代已保存的訂單記錄。
