每筆已受理預測訂單都有獨立訂單號。漲跌預測還關聯場次；自選預測和網格訂單不依賴統一場次。

<span id="當前與歷史記錄" data-sixmm-anchor-target="current-and-historical-records" aria-hidden="true"></span>
<h2 id="current-and-historical-records">當前與歷史記錄</h2>

| 顯示狀態 | 如何理解 |
| --- | --- |
| 待開獎 | 尚未記錄最終結果 |
| 已封盤 | 對應下注階段已關閉，不表示中獎或未中獎 |
| 已中獎 | 訂單記錄為中獎結果 |
| 未中獎 | 訂單記錄為未中獎結果 |
| 已退款 | 訂單狀態反映退款處理，仍需核對實際流水 |
| 已作廢 | 訂單失效，應查看原因及對應資金處理 |

並非所有玩法都以同樣方式使用每個中間狀態。僅憑狀態標籤，不能證明賬戶入賬已經完成。

<span id="需要核對的字段" data-sixmm-anchor-target="fields-to-check" aria-hidden="true"></span>
<h2 id="fields-to-check">需要核對的字段</h2>

各玩法都有訂單號、用戶歸屬、品種、下注金額、賠率、下單時間和狀態。歷史記錄還包含實際返還、結果信息、結算時間與結算流水號。

- 漲跌預測額外關聯場次編號、預測方向和實際方向。
- 自選預測記錄固定賠率及獨立到期時間。
- 網格記錄選中格子與價格區間，結果字段應結合時間窗觸碰規則理解。

<span id="修改與重複提交" data-sixmm-anchor-target="changes-and-duplicate-submissions" aria-hidden="true"></span>
<h2 id="changes-and-duplicate-submissions">修改與重複提交</h2>

不要假設預測訂單可以像合約限價單一樣改單或撤單，應按對應產品提供的操作和規則處理。提交結果不明確時，先查詢原訂單，再決定是否追加下注。
