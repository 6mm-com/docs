結果判定用於確認訂單條件是否滿足，結算用於記錄最終資金處理。計劃開獎或到期時間，不一定等於所有關聯流水處理完成的時間。

## 按玩法判定

| 玩法 | 判定方式 |
| --- | --- |
| 漲跌預測 | 比較場次開盤價與結算價 |
| 自選預測 | 比較該筆訂單開盤價與到期結算價 |
| 預測網格 | 檢查已受理時間窗內是否有效觸碰或穿過區間 |

方向玩法中的價格相等，以及恰好位於價格或時間邊界的情況，需要按適用規則處理。網格命中本身也不代表資金立即可用，應繼續檢查結算進度。

## 結算依據

保留訂單號、已記錄條件、價格證據、最終狀態、實際返還、結算時間與流水號。漲跌場次記錄還包含開獎信息及場次下注、返還彙總。

## 如何核對

1. 確認記錄對應正確的訂單和賬戶。
2. 按正確的價格與時間條件檢查結果。
3. 根據訂單賠率、適用費用和舍入規則核對實際返還。
4. 將結算流水與資金賬戶變動對應起來。

## 延遲與異常

結果延遲不應被理解為未中獎；結果已顯示但餘額尚未刷新時，不應重複提交請求。先檢查訂單與流水狀態，持續不一致時攜帶證據聯繫支持。
