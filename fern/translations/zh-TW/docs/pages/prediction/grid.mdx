預測網格的縱軸是價格區間，橫軸是未來時間窗口。選擇一個格子，就創建一筆針對該價格區間和時間窗口的獨立訂單。

## 如何看懂格子

| 格子信息 | 含義 |
| --- | --- |
| 價格區間 | 格子的價格下限與上限 |
| 開始與結束時間 | 可以判定觸碰命中的有效窗口 |
| 報價賠率 | 當前為該格子提供的返還倍數 |
| 下注金額 | 投入該筆訂單的金額 |

例如，10 行、10 列且每列 2 秒的網格覆蓋未來 20 秒。這是讀圖示例，實際應核對產品顯示的網格尺寸和絕對時間。

## 什麼算命中

在格子的有效時間內，平臺標記價進入或穿過該價格區間即為命中。有效觸碰一次即可，不要求價格一直停留到時間窗結束。

| 示例：65,010～65,020，10:00:04～10:00:06 | 結果解釋 |
| --- | --- |
| 10:00:05 價格到達 65,015 | 有效時間內進入區間 |
| 有效時間內價格從 65,005 變為 65,025 | 穿過該價格區間 |
| 有效時間內始終未進入或穿過 | 沒有符合條件的命中 |
| 時間窗結束後才首次觸碰 | 不計入該筆訂單 |

恰好位於價格邊界或時間邊界時，按訂單適用規則判定。價格數據缺失並不等於從未觸碰。

## 如何參與

1. 選擇品種，核對頁面價格軸和時間軸。
2. 選擇可下注格子，輸入符合限制的金額。
3. 確認價格上下界、有效時間、賠率和預計返還。
4. 檢查已受理訂單；即使實時網格移動，該筆訂單的價格區間、有效時間和賠率也已鎖定。
5. 在歷史訂單中跟蹤最終結果和實際結算。

## 賠率與不可下注格子

定價模型根據標記價、波動率、價格邊界和時間邊界，估計有效時間內的觸碰概率。模型報價以目標返獎率除以估計命中概率計算，並受到配置規則約束。

例如，97% 除以 20% 得到 4.85x。下注 100 USDT、鎖定 4.85x 的中獎訂單，總返還為 485 USDT。頁面簡化顯示的小數位不應被當作改變訂單已存倍數的依據。

按網格配置規則，計算報價超過最高賠率時，該格子不可下注，不會強制把報價壓低到最高值。其他限制也可能阻止訂單受理。

## 價格證據中斷

有效時間內行情中斷、無法確認命中時，訂單進入異常處理或退款流程。不要根據圖表中的空白片段直接認定未中獎。
