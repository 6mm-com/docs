頁面提供某個玩法或報價，不代表所有訂單都會受理。可用資金、產品配置和風控規則都會影響下單結果。

## 常見限制

| 限制 | 影響 |
| --- | --- |
| 玩法或品種關閉 | 不接受對應產品的新訂單 |
| 週期未開通 | 該品種不能選擇該週期 |
| 單筆最小額／最大額 | 下注金額必須在允許範圍內 |
| 累計下注或敞口控制 | 即使單筆金額合規，繼續下單也可能受限 |
| 賠率偏離控制 | 報價可能進入審核，或預測下單受限 |
| 網格報價超過最高值 | 按網格定價規則，該格子不可下注 |
| 下注窗口關閉 | 不接受進入已關閉窗口的新訂單 |

管理模型包含告警、審核、限制預測及延遲下單等處置，實際響應取決於命中規則，不能認為所有限制產生相同結果。

## 本金與模型風險

未中獎且無返還的訂單會損失下注金額。更高賠率不代表更好的機會，也可能意味著更低的估計命中概率。目標返獎參數不保證個人收益。

## 配置變更

新下單前應檢查當前配置。已受理的自選和網格訂單保存賠率及相關條件快照，後續頁面刷新不會重新定義已經接受的條件。

## 無法下單時

依次核對產品開關、可用餘額、限額、報價和時間。不要通過反覆提交繞過限制；如果已經產生訂單號，應保留訂單號和響應信息。
