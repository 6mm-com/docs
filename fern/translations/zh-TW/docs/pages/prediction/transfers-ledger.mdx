外部充值和提現通過授權合作平臺處理。預測資金應按照該平臺已開通的賬戶與劃轉流程準備。

## 劃轉前檢查

確認來源賬戶、目標資金賬戶、幣種、可劃轉金額及賬戶限制。總資產不代表全部可以轉出，待處理訂單或其他業務可能佔用部分餘額。

使用當前賬戶實際支持的劃轉入口，不要把永續交易指南中的“現貨轉永續”直接作為預測入金路徑。

## 核對訂單資金

| 記錄 | 核對內容 |
| --- | --- |
| 劃入資金賬戶 | 業務標識、幣種、金額及完成狀態 |
| 預測凍結 | 原始預測訂單與凍結金額 |
| 結算 | 最終結果、實際返還和流水號 |
| 退款或釋放凍結 | 對應原訂單、金額和最終餘額 |
| 單獨費用 | 費用類型、金額及關聯訂單或流水 |

## 劃轉結果不明確時

再次發起前，先查詢原劃轉標識。超時不代表劃轉失敗。核對最終流水與賬戶餘額時，還應考慮同時發生的其他資金變動。

## 合作方運營核對

合作方報表可按日／月、玩法、品種和用戶結果統計預測業務。有效下注、返還、退款和異常補償應分別核對。報表中的預測淨收入＝有效下注－返還－異常補償，與單個用戶的盈利不是同一個指標。
