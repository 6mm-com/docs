三種預測玩法統一以平臺合約標記價作為價格依據。最新成交價、外部交易所報價或瀏覽器圖表可能與該標記價不同。

<span id="evidence-by-game" data-sixmm-canonical-anchor="evidence-by-game" aria-hidden="true"></span>

## 各玩法需要的證據

| 玩法 | 相關證據 |
| --- | --- |
| 漲跌預測 | 場次開盤價、結算價和對應時間 |
| 自選預測 | 該筆訂單的開盤價、到期時間和結算價 |
| 預測網格 | 已受理價格區間、有效時間窗及窗口內價格路徑 |

<span id="why-a-screenshot-may-differ" data-sixmm-canonical-anchor="why-a-screenshot-may-differ" aria-hidden="true"></span>

## 為什麼截圖可能不同

頁面可能存在延遲、顯示舍入、採樣間隔差異，或者展示了另一種價格。判斷結果前，應先核對品種、價格來源、時間與精度。

對於網格，結束時的一個價格不能證明此前是否發生過觸碰；需要查看有效時間內的價格證據，包括按玩法規則判定的價格穿越。

<span id="time-and-boundaries" data-sixmm-canonical-anchor="time-and-boundaries" aria-hidden="true"></span>

## 時間與邊界

以訂單記錄中的時間為準。設備時鐘和頁面倒計時用於輔助顯示，不作為接受遲到訂單或改變有效窗口的依據。價格精度和邊界包含規則必須與該產品適用規則一致。

<span id="when-data-is-abnormal" data-sixmm-canonical-anchor="when-data-is-abnormal" aria-hidden="true"></span>

## 數據異常時

保留訂單號和受影響時間窗，查詢處理狀態。不要自行用外部交易所價格替代平臺證據進行爭議結算。詳見[退款、作廢與異常處理](/zh-TW/prediction/refunds-exceptions)。
