合規授權與交易技術結合交易基礎設施與合規規劃支援，協助準備受規範的數位資產營運夥伴。

<span id="who-this-is-for" data-sixmm-canonical-anchor="who-this-is-for" aria-hidden="true"></span>

## 這是給誰的

本指南適用於產品、合規、安全、法律及工程團隊，評估嵌入式交易或白標交易所啟動。它幫助這些團隊辨識技術證據與責任決策，並準備接受司法管轄區專業審查。

<span id="what-this-covers" data-sixmm-canonical-anchor="what-this-covers" aria-hidden="true"></span>

## 涵蓋的內容

- 合規交易操作的技術架構
- API、 SDK 及白標部署路徑
- 執照與管轄區規劃支援
- 安全性與金鑰管理需求
- 事件應變與使用者保護的營運流程

<span id="planning-questions" data-sixmm-canonical-anchor="planning-questions" aria-hidden="true"></span>

## 規劃問題

| 面積 | 待解決的問題 |
| --- | --- |
| 目標市場 | 哪些司法管轄區和使用者類型在管轄範圍內？ |
| 產品 | 會提供哪些交易、資產、託管或經紀服務？ |
| 營運模式 | 產品會使用嵌入式交易、白標介面、 API，還是兩者結合？ |
| 責任 | 哪一方負責入職、揭露、支援、監控及事件升級？ |
| 資料與安全 | 憑證、使用者資料、日誌和操作證據都存放在哪裡？ |

<span id="recommended-workflow" data-sixmm-canonical-anchor="recommended-workflow" aria-hidden="true"></span>

## 推薦工作流程

1. 定義目標市場、用戶類型及擬議產品範圍。
2. 記錄技術架構與資料流。
3. 指派合作夥伴與 6MM 負責每個營運流程。
4. 檢視憑證儲存、請求簽署、webhook 及事件回應控制。
5. 完成針對特定司法管轄區的法律及合規審查。
6. 在發布前使用生產啟動清單收集證據。

<span id="important-note" data-sixmm-canonical-anchor="important-note" aria-hidden="true"></span>

## 重要說明

6MM 文件可描述技術需求、作業流程及整合責任。法律、監管及執照決策應由相關司法管轄區合格的專業顧問審查。
