在將 6MM驅動的交易流程暴露給生產用戶之前，請先使用此清單。它設計讓產品、工程、營運、風險及支援團隊能夠共同檢視。

<h2 id="launch-checklist">發射清單</h2>

| 面積 | 檢查清單 |
| --- | --- |
| 產品 | 入口、用戶文案、風險提示、語言覆蓋與支援路徑皆已準備就緒。 |
| 後端 | API 憑證、簽署、令牌發行、webhooks、重試及日誌記錄皆已實作。 |
| 交易 | 訂單、轉讓、持倉、保證金、費用及清算行為均已檢視。 |
| 安全性 | 機密、存取角色、監控、事件回應及稽核日誌皆已準備。 |
| 營運 | 支援工作流程、升級路徑、對帳及每日監控皆被指派。 |

<h2 id="recommended-sequence">推薦劇情</h2>

1. 完整的沙盒或內部環境驗證。
2. 執行端到端的使用者旅程，涵蓋登入、登入、轉移、交易及支援。
3. 確認監控與事件應變所有權。
4. 核准公開文案、在地化資產及資源下載。
5. 在廣泛推廣前，先從受控的啟動窗口開始。

<h2 id="after-launch">發射後</h2>

在初期啟動期間，每天檢視活動。同時觀看進入轉換、令牌發行失敗、訂單錯誤、散布品質、傳輸完成、網路鉤子重試及支援工單。
