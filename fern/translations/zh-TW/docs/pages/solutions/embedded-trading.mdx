Embedded API / SDK 交易系統專為已擁有流量、用戶或商業工作流程的合作夥伴設計，這些合作夥伴希望加入交易功能，而不必從零建立完整的交易所。

<h2 id="what-it-provides">它所提供的是什麼</h2>

- 透過Trading Widget SDK 內嵌交易終端
- 合作夥伴後端整合，透過 Agent SDK
- 使用者身份綁定與入口令牌流程
- 資產轉移、訂單、持倉及帳戶存取API
- 營運系統的事件、webhook 與生命週期整合

<h2 id="recommended-architecture">推薦架構</h2>

| 層 | 責任 |
| --- | --- |
| 合作夥伴前端 | 主機入口並嵌入 6MM 交易介面。 |
| 合作夥伴後端 | 保護 API 秘密、驗證使用者、發行嵌入令牌，並處理 webhook。 |
| 6MM 貿易基礎設施 | 處理交易介面、配對、風險、流動性、帳戶狀態及交易生命週期。 |

<h2 id="choose-an-integration-path">選擇整合路徑</h2>

| 需求 | 推薦路徑 |
| --- | --- |
| 完整的交易介面與最快的網頁整合 | Trading Widget |
| 後端使用者綁定、傳輸、進入 URL與網頁鉤子處理 | Agent SDK |
| 完全客製化的產品與訂單工作流程 | REST API + WebSocket |
| 品牌交流體驗，涵蓋更廣泛的營運範圍 | 白標交易所 |

最終設計可能會結合這些路徑。在實施前，確認認證、資產所有權、責任界限、監控及生產支援。
