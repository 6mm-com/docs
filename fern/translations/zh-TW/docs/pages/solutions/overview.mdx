<h2 id="which-path-should-i-choose">我該選擇哪條路？</h2>

| 商業目標 | 推薦解決方案 | 主要醫師 |
| --- | --- | --- |
| 將交易加入現有產品 | Embedded API / SDK 交易系統 | SDK，開發者 |
| 提升市場深度與執行品質 | 機構流動性解決方案 | 交易，開發者 |
| 快速推出品牌交易所 | 白標交易所系統 | 解決方案與資源 |
| 準備受管制的作業 | 合規授權與顧問 | 安全性與合規 |

<h2 id="how-the-solutions-connect">解決方案之間的連結</h2>

大多數合作夥伴實作結合多項 6MM 能力。白標交易所可能使用機構流動性、合規支援及 API 整合。嵌入式交易夥伴可能從 Trading Widget SDK 開始，後續加入後端 Agent SDK 流程、Webhook子處理及營運資源。
