品牌客製化應讓交易所感覺與合作夥伴產品貼合，同時保持交易資訊清晰、一致且合規。

<h2 id="customization-areas">自訂區域</h2>

| 面積 | 範例 |
| --- | --- |
| 視覺識別 | 標誌、旗幟、點綴色、入場橫幅及競選卡。 |
| 報名分班 | 首頁模組、資產頁面、錢包頁面、帳戶中心和交易捷徑。 |
| 使用者文字 | 風險提示、轉帳文、交易輸入標籤及支援訊息。 |
| 資產套件 | 可下載的合作夥伴資產，用於行銷、入場卡及白標資料。 |

<h2 id="quality-checklist">品質檢查清單</h2>

- 使用正確的標誌版本來呈現淺色與深色背景。
- 保持交易行為視覺清晰，易於與行銷內容區分。
- 將截圖與下載分開本地化，分別用於中文與英文頁面。
- 讓支撐與風險提示與實際交易流程保持一致。

<h2 id="asset-and-content-checklist">資產與內容清單</h2>

- 提供淺色與深色標誌的變體，並明確標示最小尺寸及安全區域規則。
- 準備在地化的參賽橫幅、卡片素材、替代文字及面向使用者的描述。
- 確認哪些表面顯示 6MM 品牌，哪些是合作夥伴品牌。
- 在上線前測試桌面與行動裝置版面的資產。
- 將檔名、版本、擁有者、核准日期及替換歷史記錄保存在資產登記冊中。

使用描述性替代文字，說明每張圖片在頁面上下文中的功能。請勿使用關鍵字列表或在圖片描述中重複無關的搜尋詞。
