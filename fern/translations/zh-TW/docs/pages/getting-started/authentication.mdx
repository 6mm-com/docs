6MM 支持**合作方系統接入**和**白標平臺**兩種賬戶訪問模式。用戶應通過所屬平臺提供的入口登錄；賬戶創建、身份驗證和資料管理方式取決於所採用的模式。

<h2 id="registration-model">確認賬戶所屬模式</h2>

| 項目 | 合作方接入 | 白標平臺 |
| --- | --- | --- |
| 賬戶來源 | 用戶擁有合作方系統賬戶，由合作方綁定或同步交易用戶。 | 用戶使用白標平臺的賬戶體系。 |
| 訪問入口 | 合作方 App、網站或嵌入式交易入口。 | 白標平臺的品牌域名和登錄頁面。 |
| 身份認證 | 合作方驗證用戶身份，由後端獲取所需的交易訪問憑證。 | 按平臺開放的登錄、驗證和賬戶安全配置執行。 |
| 賬戶管理 | 合作方管理用戶資料，交易系統維護必要的用戶綁定關係和交易記錄。 | 白標賬戶體系及經授權的後臺人員管理用戶資料、賬戶狀態和安全設置。 |

<h2 id="login-method-1-partner-embedded-access">合作方系統接入</h2>

1. 用戶先登錄合作方自己的賬戶系統。
2. 合作方後端驗證登錄狀態，綁定或識別對應的交易用戶。
3. 後端通過支持的接入方式獲取交易訪問憑證或入口 URL。
4. 用戶打開合作方提供的嵌入式交易界面或經授權的交易入口。

完成賬戶訪問不代表已經具備交易資金。下單前，仍需按合作方的資金流程完成準備，並核對合約賬戶可用餘額。

<h2 id="login-method-2-6mm-account-login-partner-issued-credentials">白標平臺訪問</h2>

用戶通過白標平臺提供的品牌域名和賬戶入口訪問。是否開放自助註冊、如何開通賬戶，以及支持哪些登錄和身份驗證方式，以該平臺實際配置為準。

平臺通過自身賬戶體系及經授權的後臺人員，在權限範圍內處理用戶資料、賬戶狀態和安全操作。找回密碼、變更聯繫方式或處理賬戶限制時，按所屬平臺的驗證流程辦理。

登錄後，通過平臺支持的入金方式準備資金。進行永續合約交易前，將所需結算資產從資金賬戶轉入合約賬戶，並確認劃轉結果。

<h2 id="user-ownership-and-data-responsibility">賬戶與數據責任</h2>

兩種模式的責任邊界不同。合作方接入保留合作方側的賬戶管理，同時維護交易所需的用戶綁定關係與記錄；白標平臺則通過自身賬戶流程和後臺權限管理用戶。

實際採集、保存或展示的信息範圍、身份驗證要求及客服責任，應按具體部署明確，不應將某一種模式的賬戶管理方式套用於所有平臺。

<h2 id="design-principles">進入交易前確認</h2>

- 確認訪問的是正確的平臺域名，並使用對應賬戶。
- 完成所屬平臺要求的身份驗證和安全檢查。
- 確認賬戶已開通交易權限，並瞭解當前限制。
- 核對合約賬戶可用餘額；登錄成功不會自動完成資金劃轉。
- 遇到賬戶訪問或身份驗證問題時，聯繫所屬平臺客服。
