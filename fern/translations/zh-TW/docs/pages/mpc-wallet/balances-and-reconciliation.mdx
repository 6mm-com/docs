餘額視圖回答當前資金情況，交易視圖幫助解釋資金為什麼變化。企業空間中實際可見的視圖取決於產品和角色權限。

## 按問題選擇對應的記錄

| 需要核對的問題 | 查看哪裡 |
| --- | --- |
| 現在有多少可以用來付款？ | 查看對應錢包和資產的可用餘額，另行核對被凍結或暫時佔用的金額。 |
| 客戶的轉入是否已經入賬？ | 查看充值記錄，核對網絡、資產、金額和收款信息。 |
| 轉出有明確結果了嗎？ | 查看提現記錄，並在鏈上結果可用時核對確認情況。 |
| 哪些記錄影響業務餘額？ | 空間提供資金流水時，查看賬本分錄。涉及實際鏈上轉移時，再查看鏈上流水。 |

## 核對一個業務週期的資金

1. 先確定本次核對的空間、網絡、資產和時間範圍。
2. 將充值、提現記錄與保存的業務訂單或付款編號對應起來。
3. 單獨記錄手續費和內部歸集，區分為待處理請求凍結的金額與已完成的轉賬。
4. 對沒有對應上的記錄，根據交易標識與最新狀態繼續核對，結果明確後再結賬。

例如，鏈上已能看到一筆轉出，但提現記錄仍在等待確認。財務可以保留原業務請求繼續跟蹤，等狀態和實際金額明確後完成對賬。
