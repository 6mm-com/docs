企業全託管錢包適合希望由平臺運行簽名基礎設施的企業。企業在工作空間中管理日常資金、查看交易，併為操作和審批分配職責。

<span id="divide-operational-responsibilities" data-sixmm-canonical-anchor="divide-operational-responsibilities" aria-hidden="true"></span>

## 明確平臺與企業的職責

| 參與方 | 主要職責 |
| --- | --- |
| 平臺 | 運行簽名基礎設施，按適用規則處理平臺風控複核。 |
| 企業 | 設置空間權限和審批規則，準備付款、查看餘額，並與自身業務記錄對賬。 |

可以使用的工具由空間和權限決定。資金管理視圖可以查看錢包餘額，流水頁面分別展示賬本分錄、鏈上流水、充值記錄和提現記錄。

<span id="work-with-your-payment-team" data-sixmm-canonical-anchor="work-with-your-payment-team" aria-hidden="true"></span>

## 與付款團隊協作

具備權限的操作員準備提現，通過預覽核對資金、收款地址及相關手續費。適用審批規則時，由審批人在待辦中處理申請。部分申請還可能進入平臺風控複核。隨後可以在提現記錄中跟蹤簽名與鏈上確認。

<span id="example-of-a-merchant-payout" data-sixmm-canonical-anchor="example-of-a-merchant-payout" aria-hidden="true"></span>

## 場景示例：商戶向外付款

商戶先把客戶充值與自己的業務記錄核對，然後從可用餘額中準備一筆付款。需要審批時，由對應人員處理。最終，財務將提現記錄、鏈上交易與商戶的付款編號對應起來。

有關日常資金檢查所需的視圖，參閱[餘額與對賬](/zh-TW/mpc-wallet/balances-and-reconciliation)。
