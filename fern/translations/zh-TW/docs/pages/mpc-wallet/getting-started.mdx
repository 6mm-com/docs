取得測試環境後，可以按以下順序準備。訪問入口和安裝包由接入聯繫人提供，本指南暫不提供公開註冊或下載地址。

<span id="prepare-your-workspace" data-sixmm-canonical-anchor="prepare-your-workspace" aria-hidden="true"></span>

## 準備工作空間

1. 確認需要體驗的產品，以及錢包空間所屬的賬戶或組織。
2. 從提供的入口登錄，完成該版本要求的賬戶安全設置。
3. 選擇目標空間，核對產品類型、成員權限和初始化狀態，再進行資產操作。
4. 對於需要選擇保管方式的產品，先閱讀參與方和恢復責任，再確認選擇。

登錄賬戶、工作空間與鏈上錢包是不同概念。一個賬戶可以訪問不同空間，每個空間分別確定產品與操作上下文。

<span id="complete-initialization" data-sixmm-canonical-anchor="complete-initialization" aria-hidden="true"></span>

## 完成初始化

不同產品的初始化可能包含設備或節點錄入、參與方確認、錢包建鑰和備份準備。應按當前空間顯示的初始化狀態繼續操作，不要把某一步成功當作整個流程已經完成。

全託管體驗不要求客戶完成與自持分片企業錢包相同的節點部署。個人與團隊設備也有各自的錄入和簽名流程。

<span id="validate-a-small-test-flow" data-sixmm-canonical-anchor="validate-a-small-test-flow" aria-hidden="true"></span>

## 驗證一筆小額測試

1. 確認已啟用的網絡和資產，特別注意當前是否為測試網絡。
2. 獲取收款地址及所需的備註或標籤；如果提供地址驗證，先完成驗證再分發地址。
3. 接收一筆小額測試資金，跟蹤充值記錄，直到結果明確。
4. 準備小額轉出，核對目標地址、手續費和所需的審批或設備簽名。
5. 將錢包記錄、鏈上結果與自己的業務記錄進行對照。

擴大測試前，確認團隊能夠處理審批駁回、簽名方離線、回調缺失和交易結果不確定等情況。繼續閱讀[錢包操作](/zh-TW/mpc-wallet/wallet-operations)與[安全和恢復](/zh-TW/mpc-wallet/security-and-recovery)。
