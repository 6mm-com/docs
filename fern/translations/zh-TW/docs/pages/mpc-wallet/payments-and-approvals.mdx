企業付款可以由不同角色協作完成。操作員準備轉賬，有權限的人員在需要時審批，再由簽名參與方生成鏈上交易簽名。

<span id="prepare-the-payment" data-sixmm-canonical-anchor="prepare-the-payment" aria-hidden="true"></span>

## 準備付款

選擇來源錢包、網絡和資產，填寫收款地址、金額和必要的目標備註。提交前查看預覽和費用。如果當前流程要求校驗地址白名單，按授權的地址管理流程處理限制。

<span id="review-and-track-progress" data-sixmm-canonical-anchor="review-and-track-progress" aria-hidden="true"></span>

## 審批並跟蹤進度

需要審批時，審批人可在企業待辦中核對付款信息，並在權限範圍內處理。要求平臺風控複核的申請，可能在簽名前暫停等待。審批完成後，繼續用付款記錄跟蹤簽名、廣播和鏈上確認。

| 看到的進度 | 如何理解 |
| --- | --- |
| 等待審批或複核 | 仍有待處理的審核環節，可查看當前流程。 |
| 已審批或等待簽名 | 申請可以繼續進入簽名流程，跟進原記錄即可。 |
| 已廣播或等待確認 | 鏈上結果仍在推進，有交易標識時可一併核對。 |
| 結果核對中 | 持續跟蹤同一請求，直到結果明確。 |
| 已確認 | 記錄已有鏈上確認結果，可進入對賬。 |

如果結果延遲，先核對原申請，再決定後續動作。能否取消取決於實際簽名階段。系統對接可參閱[交易狀態與重試](/zh-TW/mpc-wallet/transactions)。
