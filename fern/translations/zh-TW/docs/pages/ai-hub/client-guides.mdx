> AI Hub 為規劃內容。本頁中的功能、服務地址、命令及客戶端配置用於說明擬定方案，目前尚未開放使用。實際開放範圍與接入方式以上線公告為準。


客戶端接入指南用於幫助用戶把 6MM AI Hub 接入他們已經使用的 AI 工具。

## 從用戶已經認識的 AI 工具開始

<CardGroup cols={2}>
<Card title="ChatGPT Desktop" icon="fa-duotone fa-message-bot" href="/zh-TW/ai-hub/clients/chatgpt-desktop">

<Card title="Claude Desktop" icon="fa-duotone fa-comments" href="/zh-TW/ai-hub/clients/claude-desktop">

</Card>
<Card title="Claude Code CLI" icon="fa-duotone fa-terminal" href="/zh-TW/ai-hub/clients/claude-code-cli">

</Card>
<Card title="Codex CLI" icon="fa-duotone fa-code" href="/zh-TW/ai-hub/clients/codex-cli">

</Card>
<Card title="Cursor" icon="fa-duotone fa-arrow-pointer" href="/zh-TW/ai-hub/clients/cursor">

</Card>
<Card title="Gemini CLI" icon="fa-duotone fa-sparkles" href="/zh-TW/ai-hub/clients/gemini-cli">

</Card>
<Card title="VS Code / GitHub Copilot" icon="fa-duotone fa-laptop-code" href="/zh-TW/ai-hub/clients/vscode-copilot">

</Card>
<Card title="Windsurf" icon="fa-duotone fa-wind" href="/zh-TW/ai-hub/clients/windsurf">

## 每篇客戶端指南應包含

- 支持模式：CLI、Local MCP、Hosted MCP 或 Remote MCP。
- 安裝命令。
- 配置文件位置。
- 環境變量。
- Testnet 示例。
- 驗證命令或提示詞。
- 常見錯誤。
- 安全說明。

<span id="example-verification-prompts" data-sixmm-canonical-anchor="example-verification-prompts" aria-hidden="true"></span>

## 驗證提示詞 示例

```text
Use 6MM to list available markets.
```

```text
Use 6MM to check BTC-USDT-PERP orderbook depth and summarize liquidity.
```

```text
Using 6MM testnet, preview a small BTC long order and explain the margin impact. Do not place the order.
```
