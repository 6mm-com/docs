Agentic Skills 是構建在 CLI 和 MCP 工具 之上的更高層工作流模板。

它們定義 agent 什麼時候應該使用工具、哪些動作被禁止、輸出格式是什麼，以及必須執行哪些風險檢查。

<span id="recommended-skills" data-sixmm-canonical-anchor="recommended-skills" aria-hidden="true"></span>

## 推薦 skills

| Skill | 用途 | 默認模式 |
| --- | --- | --- |
| 6mm-market-analyst | 分析市場狀態、流動性、波動和資金費。 | 只讀 |
| 6mm-portfolio-risk-manager | 審查賬戶敞口和風險集中度。 | 賬戶只讀 |
| 6mm-funding-arbitrage-researcher | 對比資金費率並研究機會。 | 只讀 |
| 6mm-liquidation-protection-assistant | 識別清算風險和降風險方案。 | 賬戶只讀 |
| 6mm-order-execution-planner | 規劃訂單參數和執行方式。 | 僅預覽 |
| 6mm-trading-journal-analyst | 彙總成交、行為和風險記錄。 | 賬戶只讀 |

<span id="what-each-skill-should-include" data-sixmm-canonical-anchor="what-each-skill-should-include" aria-hidden="true"></span>

## 每個 skill 應包含

- 適用用戶場景。
- 需要的 CLI 或 MCP 工具。
- 允許和禁止的動作。
- 所需權限層級。
- 是否允許交易。
- 是否必須預覽。
- 輸出格式。
- 風險提示行為。
- 示例用戶提示詞。

<span id="recommended-first-release" data-sixmm-canonical-anchor="recommended-first-release" aria-hidden="true"></span>

## 第一階段建議

先把 skills 發佈為文檔模板。等底層工具和權限範圍 穩定後，再做成可安裝包。
