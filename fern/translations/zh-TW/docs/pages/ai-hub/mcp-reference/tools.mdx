MCP 工具 是 AI 客戶端可以主動調用的動作。每個 tool 都應包含清晰描述、JSON schema、權限要求、穩定返回格式和錯誤模型。

## Phase 1：公開市場工具

| Tool | 用途 |
| --- | --- |
| 6mm_system_status | 檢查服務和市場可用性。 |
| 6mm_markets | 列出可交易市場和基礎元數據。 |
| 6mm_market_summary | 彙總一個或多個交易對的市場狀態。 |
| 6mm_ticker | 返回最新 ticker。 |
| 6mm_orderbook | 返回盤口深度。 |
| 6mm_klines | 返回歷史 K 線。 |
| 6mm_trades | 返回最近公開成交。 |
| 6mm_funding_rates | 返回當前和歷史資金費率。 |

## Phase 2：賬戶只讀工具

| Tool | 用途 |
| --- | --- |
| 6mm_account_summary | 彙總賬戶狀態。 |

## Phase 3 及之後：交易工具

| Tool | 用途 |
| --- | --- |
| 6mm_preview_order | 校驗訂單但不下單。 |
| 6mm_create_order | 在確認和風控檢查後創建訂單。 |
| 6mm_cancel_order | 撤銷單個訂單。 |
| 6mm_cancel_all_orders | 撤銷所有符合條件的當前委託。 |
| 6mm_amend_order | 修改已有訂單。 |
| 6mm_order_status | 查詢指定訂單狀態。 |

<span id="tool-requirements" data-sixmm-canonical-anchor="tool-requirements" aria-hidden="true"></span>

## Tool 要求

每個 tool 都應定義：

- 給 AI model 看的描述。
- 輸入 JSON schema。
- 權限範圍。
- 支持環境。
- 限流行為。
- 穩定返回字段。
- 錯誤碼。
- 審計日誌字段。
