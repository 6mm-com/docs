MCP resources 是 AI 客戶端在調用工具前可以讀取的只讀上下文。

Resources 能減少 AI 胡亂猜測，因為模型可以讀取穩定、結構化的 6MM 信息。

<span id="recommended-resource-uris" data-sixmm-canonical-anchor="recommended-resource-uris" aria-hidden="true"></span>

## 推薦 resource URI

| Resource | 用途 |
| --- | --- |
| 6mm://system/config | 環境和能力配置。 |
| 6mm://system/status | 當前系統和市場狀態。 |
| 6mm://markets | 可交易市場。 |
| 6mm://market/{symbol} | 合約規格和市場級元數據。 |
| 6mm://fees | 費用規則。 |
| 6mm://risk/rules | 交易和風險規則摘要。 |
| 6mm://risk/margin | 保證金和清算上下文。 |
| 6mm://funding/rules | 資金費率規則。 |
| 6mm://api/docs | API 參考摘要或鏈接。 |

<span id="resource-design-rules" data-sixmm-canonical-anchor="resource-design-rules" aria-hidden="true"></span>

## Resource 設計規則

- 保持只讀。
- 使用穩定 schema。
- 包含時間戳和環境名稱。
- 不暴露密鑰。
- 優先使用簡潔結構化數據，而不是長篇文本。
- 細節過長時鏈接到權威文檔。
