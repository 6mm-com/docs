> **規劃中 · 尚未上線**
> AI Hub 為規劃內容。本頁中的功能、服務地址、命令及客戶端配置用於說明擬定方案，目前尚未開放使用。實際開放範圍與接入方式以上線公告為準。


AI Hub 應分階段上線，讓用戶儘早獲得價值，同時保護敏感交易能力。

<h2 id="phase-1-public-market-ai-access">Phase 1：公開市場 AI 接入</h2>

目標：讓任何支持的 AI 客戶端讀取 6MM 官方市場數據。

交付：

- 共享 SDK / API 客戶端。
- CLI 公開市場命令。
- Local MCP 公開市場工具。
- Hosted MCP 公開市場工具。
- 市場列表、費用規則、風控規則和系統狀態資源。
- 客戶端安裝指南。

不包含：

- 賬戶查詢。
- 真實交易。
- API key 託管。

<h2 id="phase-2-account-read">Phase 2：賬戶只讀</h2>

目標：讓用戶安全讀取自己的賬戶上下文。

交付：

- 只讀 API key 權限範圍。
- 賬戶摘要。
- 餘額。
- 倉位。
- 當前委託。
- 成交。
- 資金費記錄。
- 組合風險提示詞。

推薦部署：

- Local MCP。
- CLI。
- 自託管 Remote MCP。

<h2 id="phase-3-trading-preview">Phase 3：交易預覽</h2>

目標：讓 AI 輔助生成訂單，但不執行。

交付：

- `preview_order`.
- 風險檢查。
- 保證金影響。
- 費用估算。
- 清算影響。
- 執行規劃提示詞。

<h2 id="phase-4-controlled-trading">Phase 4：受控交易</h2>

目標：只在強風控下支持真實交易。

交付：

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- 冪等鍵。
- 最大訂單金額限制。
- 明確確認。
- 審計日誌。

<h2 id="phase-5-agentic-skills">Phase 5：Agentic Skills 智能工作流</h2>

目標：產品化常見市場分析和風險工作流。

交付：

- 市場分析 Skill。
- 組合風險 Skill。
- 資金費研究 Skill。
- 清算保護 Skill。
- 執行規劃 Skill。
- 示例任務庫。
