在向真實用戶展示 6MM驅動的交易能力之前，請先使用這份清單。

<h2 id="integration-readiness">整合準備度</h2>

- 確認生產域與重定向路徑。
- Trading Widget、 Agent SDK、 API或 WebSocket 流已從端到端進行測試。
- 合作夥伴後端將所有秘密儲存在伺服器端。
- 啟用 Webhook 接收、簽章驗證、重試處理及冪性。
- 日誌包含請求 ID、使用者映射 ID、訂單 ID 及時間戳記。

<h2 id="product-and-resource-readiness">產品與資源準備度</h2>

- 入口點、橫幅及卡片素材使用核准的語言版本。
- 白標資產僅在合作協議允許時使用。
- 面向用戶的風險提示與交易條目文案由合作夥伴團隊審核。
- 指派支援與升級負責人。

<h2 id="operational-readiness">作戰準備</h2>

- 監控涵蓋 API 錯誤、令牌發行、元件初始化、網路鉤子失敗及訂單生命週期事件。
- 緊急聯絡路徑已確認。
- 為交易輸入準備回滾或暫時停用計畫。

<h2 id="security-and-compliance-readiness">安全與合規準備</h2>

- API 鍵使用最低權限，並在適用時核准 IP 限制。
- 證件輪換與撤銷已測試。
- Webhook 簽章會與原始請求實體進行驗證。
- 用戶揭露、風險通知、責任界限及目標市場審查均已完成。
- 事件、和解及支持證據可在不暴露秘密的情況下取得。
