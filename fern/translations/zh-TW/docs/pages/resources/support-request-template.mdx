聯絡客服時，請盡可能提供以下資訊。

<h2 id="required-context">必要背景說明</h2>

| 場地 | 範例 |
| --- | --- |
| 環境 | 製作或舞台設計 |
| 受影響模組 | Trading Widget、 Agent SDK、 REST API、 WebSocket、webhook、白標系統 |
| 時間範圍 | UTC 問題發生的時間範圍 |
| 合作夥伴使用者識別碼 | 合作夥伴端使用者識別碼（如有關聯） |
| 6MM 映射識別碼 | agentUserId、訂單ID、請求ID，或webhook事件ID |
| 商業影響 | 受影響的使用者或營運人數，以及問題是否持續存在 |

<h2 id="description-format">說明格式</h2>

- 發生什麼事了？
- 你以為會發生什麼？
- 能複製嗎？
- 最近發生了什麼變化？
- 問題還在發生嗎？

<h2 id="attachments">附屬設施</h2>

- 相關的請求與回應紀錄。
- 截圖或螢幕錄影。
- Webhook 有效載荷與簽章標頭。
- 瀏覽器主控台錯誤， Trading Widget 問題。

<h2 id="copyable-template">可複製範本</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

移除不相關的欄位，但盡可能保留 UTC 時間範圍，並至少保留一個可搜尋的請求或商業識別碼。

<h2 id="redact-sensitive-data">刪除敏感資料</h2>

請勿發送：

- 密碼或完整存取權杖
- API 秘密、私鑰或完整簽章
- 會話 Cookie
- 全額付款、身份或其他不必要的個人資料

只有在支援需要區分消毒過的數值時，才保留欄位名稱和簡短的前綴或後綴。

<h2 id="choose-the-right-channel">選擇正確的頻道</h2>

| 子嗣 | 下一頁 |
| --- | --- |
| 整合或生產問題 | [支援]（/resources/contact/support） |
| SDK 還需要診斷的問題 | [SDK 整合故障排除 ]（/sdk/security/troubleshooting） |
