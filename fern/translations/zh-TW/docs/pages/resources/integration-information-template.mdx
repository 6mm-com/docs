準備新整合或將現有整合移入生產環境時，請使用此範本。

<h2 id="partner-information">合作夥伴資訊</h2>

| 場地 | 描述 |
| --- | --- |
| 合作夥伴名稱 | 整合時使用法定名稱或專案名稱。 |
| 產品類型 | 應用程式、錢包、經紀入口網站、白標交易所、機構平台或其他。 |
| 主要聯絡人 | 商業、技術、營運及緊急聯絡人。 |
| 發射區域 | 整合將暴露的國家或地區。 |

<h2 id="technical-information">技術資訊</h2>

| 場地 | 描述 |
| --- | --- |
| 前端網域 | 這些網域會載入小工具或入口頁面。 |
| 後端網域 | 用於 Agent SDK 或 API 通話的伺服器域。 |
| Webhook URL | 生產環境的 webhook 端點以及預期 IP 允許清單的要求。 |
| 整合範圍 | Trading Widget、 Agent SDK、 REST API、 WebSocket、白標系統或流動性整合。 |

<h2 id="operational-information">營運資訊</h2>

- 預計發射日期。
- 預期流量或活躍使用者範圍。
- 支援時數與升級負責人。
- 監控車主與事故聯絡人。

<h2 id="security-and-review-information">安全與審查資訊</h2>

- 認證方法與 API Key 權限範圍。
- 秘密儲存、輪替擁有者及核准的來源 IP。
- Webhook 簽名驗證與冪등性設計。
- 日誌記錄、監控、對帳、回滾及事件回應擁有者。
- 目標市場、使用者類型、託管模式，以及負責面向使用者義務的實體。

此範本中不得包含生產機密、完整存取權杖、私鑰或未塗黑的使用者資料。

使用[生產啟動檢查清單]（/resources/production-launch-checklist）進行最終核准，[支援請求模板]（/resources/support-request-template）用於問題升級。
