## 服務端點

```
wss://ws.6mm.com/ws
```

WebSocket 頻道分為公共頻道與私人頻道：

| 類型             | 認證              | 描述                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| 公共頻道  | 非必要條件                | 市場數據，例如深度、交易量、Klines 和股票代價 |
| 私人頻道 | `listenKey`或JWT | 使用者順序、帳戶與倉位串流              |

<span id="public-channels" data-sixmm-canonical-anchor="public-channels" aria-hidden="true"></span>

## 公共頻道

公開 WebSocket 不需要驗證。連線後，發送 `subscribe` 訂閱市場頻道的請求。

常見頻道：

| 頻道                            | 描述                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | 訂單簿深度。先傳送快照，再發送增量更新 |
| `market.trade.{symbol}`            | 最新交易                                                      |
| `market.kline.{symbol}.{interval}` | 克萊恩                                                             |
| `market.ticker.{symbol}`           | 單符號行情摘要                                       |
| `market.tickers`                   | 全符號行情條摘要                                          |

<span id="private-channels" data-sixmm-canonical-anchor="private-channels" aria-hidden="true"></span>

## 私人頻道

<span data-sixmm-canonical-anchor="listenkey" aria-hidden="true"></span>

## listenKey
對於私人WebSocket串流，先透過REST API 建立一個`listenKey`，然後連接到：

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<span data-sixmm-canonical-anchor="jwt" aria-hidden="true"></span>

## JWT
相容 JWT 連接方式：

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

認證成功後，伺服器會自動訂閱目前使用者的私人通道連線。不需要手動訂閱。
