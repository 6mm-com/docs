<h2 id="production-checklist">製作檢查清單</h2>

- API 秘密僅儲存在後端。
- 同步伺服器時間，先於簽署請求。
- 除非頁面明確說明，否則所有數值精度欄位都視為字串。
- 利用冪等性、請求 ID 及圍繞順序流程的結構化日誌。
- 訂閱 WebSocket 流，以取得必須在運作系統中保持狀態的最新狀態。
- 在啟動前檢視錯誤代碼並重試行為。
