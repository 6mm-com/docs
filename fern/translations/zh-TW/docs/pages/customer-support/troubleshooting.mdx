## 控制台和訪客支持

| 症狀 | 先檢查一下 |
| --- | --- |
| 缺少菜單 |  |
| 小部件未打開 | 產生的腳本 URL、應用程式金鑰、允許的網域和瀏覽器錯誤 |
| Bot不使用大模型 | 實際匹配的步驟、智慧服務開關及相關配置 |
| 答案使用舊規則 | 來源文章、發表狀態、FAQ文字、翻譯與檢索狀態 |
| 翻譯缺 | 目標語言、翻譯切換、已儲存的翻譯和服務/餘額可用性 |
| 向量生成失敗 | 服務可用性和檢索狀態；避免在未識別故障的情況下重複重建 |
| 聯絡方式欄位為空 | 該欄位是否確實被收集；區分聯絡人和輸入郵箱 |

## 聯繫支援人員之前

收集時間和時區、受影響的租戶/帳戶、頁面或工具名稱、可用的操作 ID 以及確切的錯誤。包括經過編輯的螢幕截圖或重現步驟。不要發送密碼、驗證碼、不記名令牌或簽名秘密。

诊断写入时尝试一个小测试记录。驗證結果並僅清理您建立的測試數據，根據需要使用正常確認流程。
