## 可用工具跟隨您的角色

該表描述了最大支持範圍。您的 AI 應用程式僅接收授權帳戶允許使用的工具。使用動力工具清單及其參數模式作為契約；新的控制台功能並不會自動成為 MCP 工具。

| 控制台模組 | 支援的操作 |
| --- | --- |
| 線上對話 | 讀取會話、訊息和佇列資訊；指派、加入、接管和轉讓；傳送訊息；邀請評分；管理上傳權限；識別/翻譯訊息；上傳支援的文件 |
| 門票和回饋 | 查詢、分配、更新狀態和刪除用戶工單和回饋；建立、讀取、更新、分配和刪除代理票證 |
| 對話歷史記錄 | 查詢會話和訊息；刪除單一會話或多個會話 |
| 內容管理 | 閱讀和維護類別、文章、熱門議題、問題類別、專題卡、公告和自助條目；發布/取消發布文章 |
| 語言翻譯 | 閱讀來源、翻譯和完成狀態；儲存或清除支援的翻譯；呼叫自動翻譯；管理支援的語言設定 |
| 機器人配置 | 閱讀支援的設定和常見問題解答，維護類似問題，測試回复，檢查檢索狀態，更新索引和重建向量 |
| 代理管理 | 維護支援的代理、角色和快速回复 |
| 系統設定 | 讀取/寫入允許的外觀、複製、對話、訪客條目、智慧服務和網站白名單字段 |
| 統計數據 | 只讀概述和支援的統計查詢 |
| 使用和計費 | 只讀餘額、使用情況、交易和價格 |
| 操作日誌 | 只讀操作列表和詳細信息 |

## 寫入並確認

刪除、發布/取消發布、編輯已發布的文章、發送訊息、角色/帳戶管理、網站白名單更改、向量重建和平台自動翻譯需要後端確認（如果工具指定）。未經確認的寫入仍然可以立即更改資料；在要求人工智慧執行之前檢查預期範圍。

MCP 不提供平台管理、租戶關閉/刪除、餘額充值、帳單編輯或提供者秘密存取。檔案工具強制執行格式檢查和部署的大小限制；目前的實作透過 Base64 支援最大 10 MB 的單一檔案。在其自身限制允許的情況下，使用控制台處理較大的檔案。

## 範例任務

- 列出缺少的翻譯和日文草案，同時保留連結和數量。
- 尋找未解決的用戶票證並提出分配（無需應用）。
- 在現有類別中建立知識文章草稿，然後顯示其標題和 ID。
- 總結最近的支援統計數據以及確切的日期範圍。

平台人工智慧、自動翻譯和向量操作可能會產生現有服務費用。互聯人工智慧提供者本身的使用是獨立的。
