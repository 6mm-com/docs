## 連線詳情

| 物品 | 價值 |
| --- | --- |
| 租戶控制台 | [租戶控制台](https://csadmin.6mm.com/) |
| 運輸 | 可串流傳輸 HTTP |
| 授權 | OAuth授權碼帶有PKCE；動態用戶端註冊 |
| 帳戶 | 您現有的客戶支援帳戶 |

使用支援此遠端傳輸和授權流程的 AI 應用程式。不需要特定於租用戶的 MCP 伺服器部署或單獨的 MCP 權限配置。請勿附加 SSE 路徑或使用應用程式密鑰作為 OAuth 不記名令牌。

<span id="connect-step-by-step" data-sixmm-canonical-anchor="connect-step-by-step" aria-hidden="true"></span>

## 一步步連接

1. 登入控制台並開啟 **系統設定 → MCP 連線**。
2. 複製端點並將其新增為 AI 應用程式中的遠端 MCP 伺服器。顯示名稱（例如 6MM 客戶支援）就足夠了。
3. 讓應用程式開始授權。在瀏覽器中，登入並完成任何所需的驗證。
4. 在允許連接之前檢查應用程式、租戶、帳戶和返回地址。提供的應用程式名稱不是認證標誌。
5. 返回 AI 應用程式並在必要時刷新其工具。要求它列出知識類別作為第一個只讀測驗。
6. 在控制台中檢查連接的應用程式。當不再需要時撤銷那裡的連線。

切勿向人工智慧提供您的密碼、驗證碼或身分簽名秘密。僅透過登入和同意頁面進行授權。

<span id="what-access-does-the-ai-receive" data-sixmm-canonical-anchor="what-access-does-the-ai-receive" aria-hidden="true"></span>

## AI 取得什麼存取權限？

僅當前帳戶支援的工具和租戶資料。通話時再次檢查權限；帳戶暫停、租戶不可用或授權撤銷可能會阻止存取。登出控制台不會自動撤銷 AI 連線。

目前的實作使用 30 天的連線授權和帶有輪換刷新令牌的短期存取令牌。請依照連接的應用程式中顯示的到期時間進行操作，並在需要時重新連線。人工智慧應用程式處理代幣交換和更新；租戶不會手動將密碼貼到工具呼叫中。

此 MCP 管理支援後端。它不允許訪客機器人操作後端或授予對交易帳戶的存取權限。
