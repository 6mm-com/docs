## 為跨語言使用者提供服務

6MM人工智慧客戶支援結合了多語言人工智慧回應、對話翻譯和翻譯的幫助內容。這些是具有自己設定的獨立功能；切換控制台語言並不能翻譯每篇文章或訊息。

| 能力 | 有什麼變化 |
| --- | --- |
| 控制台語言 | 您的客服人員看到的菜單和介面文本 |
| 幫助內容翻譯 | 在地化的文章、問題和其他支援的內容 |
| AI回覆語言 | 模型針對訪客問題所使用的語言 |
| 對話翻譯 | 翻譯後的訊息可協助客服人員跨語言理解和回應 |

內容語言代碼目前包括英語和地區英語；簡體中文和繁體中文；日本人;俄語;西班牙語和地區變體；意大利語；法語;德語;葡萄牙語和地區變體；印度尼西亞;拋光;越南語；烏克蘭;烏茲別克語；阿拉伯;菲律賓人；和阿塞拜疆語。確切的可選清單取決於功能。文件站點語言和支援產品語言並不相同。

## 管理翻譯內容

打開**語言翻譯**。選擇來源內容和目標語言，查看現有翻譯和完成狀態，然後翻譯或編輯並儲存。在可用設定中配置主要語言和預設語言。在發布面向客戶的文字之前，請檢查數字、貨幣、網路名稱、連結和例外情況。

自動翻譯需要可用的服務，並且可能會產生使用費。翻譯缺失並不意味著來源缺失；分別檢查目標語言和後備行為。

## 使用連接的人工智慧進行翻譯

和 [MCP](/zh-TW/customer-support/mcp-connect)，外部人工智慧可以讀取原始碼、建立或潤飾翻譯並使用允許的寫入工具來保存它們。或者，它可以呼叫平台的自動翻譯工具。第一個使用連接的人工智慧進行翻譯；第二個使用平台翻譯服務及其計費規則。兩者都保留帳戶權限和任何所需的確認。

範例請求：將提款指南翻譯成日語，保留 URL 和數字限制，並在儲存前顯示建議的翻譯。在工具報告完成前，請勿聲明已儲存成功。
