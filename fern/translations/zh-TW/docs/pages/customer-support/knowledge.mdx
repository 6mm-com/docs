## 選擇正確的內容類型

開啟**內容管理**。知識類別整理文章；其他內容類型提供簡潔的答案、導覽和服務入口點。

| 內容 | 典型用途 |
| --- | --- |
| 知識文章和類別 | 關於入職、轉帳、交易規則和故障排除的詳細指南 |
| 熱點問題 | 常見問題的簡短回答 |
| 問題類別和功能卡 | 將主題分組並引導使用者獲取相關信息 |
| 公告 | 發布面向客戶的通知 |
| 自助條目 | 引導使用者取得可用的支援操作或資源 |

<span id="create-and-maintain-knowledge" data-sixmm-canonical-anchor="create-and-maintain-knowledge" aria-hidden="true"></span>

## 創建和維護知識

1. 建立或選擇適當的類別。填寫必填字段，包括建立文章時的類別。
2. 寫下標題和正文，包括範圍、條件、步驟和例外情況。使用實際的業務規則而不是假設的交換行為。
3. 儲存並審閱草稿。準備好供用戶使用後發布；在適當的時候取消發布過時的材料。
4. 維護翻譯並檢查更改後的檢索/索引狀態。在機器人流程和訪客聊天中測試問題。

例如，提款指南應解釋使用者必須選擇哪個網路、從哪裡取得位址、任何適用的業務限制以及如何聯絡支援人員。不要發明處理時間或費用。

<span id="keep-content-consistent" data-sixmm-canonical-anchor="keep-content-consistent" aria-hidden="true"></span>

## 保持內容一致

更新源並不能證明每個翻譯都是最新的。查看受影響的翻譯和相關的 FAQ 答案。發表的文章、熱門問題和公告不應描述不相容的規則。刪除之前，請檢查該內容是否仍需要用於使用者導航或答案。 MCP支援相同允許的內容操作；看 [MCP 工具](/zh-TW/customer-support/mcp-tools).
