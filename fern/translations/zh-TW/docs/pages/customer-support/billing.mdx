## 查看智慧服務的使用情況

開啟**使用和計費**檢查餘額、可用服務價格、使用記錄和餘額變更。 AI回覆、翻譯和開機操作可能會根據租戶配置的服務消耗共享智慧服務餘額。

支援回應路徑很重要：儲存的答案和大模型請求不是同一類型的使用。型號和價格可能會發生變化；使用當前控制台而不是本指南中的固定金額。

<span id="understand-settlement" data-sixmm-canonical-anchor="understand-settlement" aria-hidden="true"></span>

## 了解結算

該服務可能會在計量請求之前保留估計的金額。可靠的上游用量用於現有規則下的正常結算。當返回有效結果但無法可靠使用時，可以保留預留金額作為後備費用，而無需再次應用緩衝區。失敗的請求或無效的結果將釋放失敗規則下的預留金額。

預訂不是額外的第二次費用。在解釋記錄之前，比較最終費用、原始預訂和任何餘額調整。回退估計單位不得解釋為上游測量的令牌。

<span id="mcp-and-costs" data-sixmm-canonical-anchor="mcp-and-costs" aria-hidden="true"></span>

## MCP 和成本

MCP沒有引入單獨的計費規則，但呼叫平台人工智慧、翻譯或向量服務的工具可能會產生正常費用。外部人工智慧提供者可以對其自己的服務獨立收費。計費工具可以讀取餘額、使用情況、交易和價格；他們無法充值餘額或編輯帳單。


<span id="use-the-right-billing-view" data-sixmm-canonical-anchor="use-the-right-billing-view" aria-hidden="true"></span>

## 使用正確的帳單視圖

| 看法 | 它回答什麼 |
| --- | --- |
| 用法 | 呼叫服務時，其輸入/輸出單位（如果適用）、最終費用和狀態。 |
| 餘額帳本 | 每個餘額的類型和金額隨著之前和之後的餘額而變化。 |
| 服務價格 | 目前可用的服務及其定價單位。使用顯示的匯率而不是從舊文件複製的價格。 |

<span id="example-investigate-an-unexpected-balance-change" data-sixmm-canonical-anchor="example-investigate-an-unexpected-balance-change" aria-hidden="true"></span>

### 例：調查意外的餘額變化

1. 記下大致時間並選擇相關範圍。使用服務過濾器來分離人工智慧、翻譯、語言檢測和嵌入。
2. 查看通話狀態和最終收費金額。螢幕上的訊息本身並不是計費記錄。
3. 查看同期帳本變化，包括消費、退款和其他顯示的調整。
4. 如果數字仍需要解釋，請為平台業者保留時間範圍、服務和相關記錄詳細資訊。不要只是為了查看數量是否有變化而重複重新運行計費操作。

**不同的服務使用不同的單位。 ** AI文字產生可以有輸入和輸出代幣價格；嵌入服務定價基於輸入使用。讀取顯示的翻譯或語言偵測單元，而不是將每個數字視為標記。

## 常見問題

<AccordionGroup>

<Accordion title="第一次扣押是否需要第二次扣費？">
不。這是上述結算流程的一部分。一起查看最終費用和餘額調整，而不是再次添加保留。
</Accordion>

<Accordion title="連線 MCP 是否可以免費使用所有 AI？">
不會。現有的平台服務仍然可以消耗共享餘額，外部AI應用程式可能會產生自己的費用。
</Accordion>
