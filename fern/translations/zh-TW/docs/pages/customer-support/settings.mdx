## 配置訪客體驗

開啟**系統設定**。可用的控制取決於您的角色和啟用的租用戶服務。

| 選項卡 | 需要配置什麼 |
| --- | --- |
| 外觀與集成 | 可用的視覺和入口設置 |
| 主頁及副本 | 面向客戶的主頁文字和指導 |
| 會話和超時 | 對話行為與超時控制 |
| 訪客對話 | 訪客進入時收集的資訊和提示 |
| 智慧服務 | 向租戶開放的人工智慧、檢索和翻譯功能 |
| 網站整合 | 域白名單、嵌入程式碼、簽名身分和語言/主題集成 |
| MCP 連接 | 服務地址、授權申請及撤銷 |

保存設置，然後從訪客條目中驗證它們。預覽或成功儲存並不能確定單獨嵌入的網站已在使用最新設定。

<span id="keep-boundaries-clear" data-sixmm-canonical-anchor="keep-boundaries-clear" aria-hidden="true"></span>

## 保持界線清晰

租戶設定配置租戶的客戶支援。他們不授予對平台範圍內的提供者金鑰、其他租戶、儲值操作或交易所交易帳戶的存取權限。 MCP 僅公開目前角色允許的支援組態欄位。透過 MCP 進行的域白名單變更需要確認。
