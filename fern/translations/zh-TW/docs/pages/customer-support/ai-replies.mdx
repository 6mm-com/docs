## 為 AI 提供可靠的業務背景

使用**系統設定→智慧服務**進行服務切換，使用**機器人設定**進行回覆行為。選單可用性和啟用的功能取決於您的租用戶配置和帳戶權限。

回覆管道首先處理特殊意圖，然後評估啟用的配對階段。 FAQ 或向量匹配可以在大模型階段之前回答。不會為每條訊息呼叫該模型。使用流測試來查看哪條路徑得到了回應。

| 配置 | 目的 |
| --- | --- |
| 基本設定 | 使用可用控製配置機器人的一般行為 |
| FAQ 回复 | 維護合格的問題來源和類似的措辭 |
| AI向量回覆 | 匹配語義相關的問題；審查閾值和指數準備情況 |
| AI大模回復 | 使用檢索到的業務知識和對話上下文來撰寫答案 |
| 身份和能力回复 | 保留問題的批准答案，例如助理是誰以及它可以做什麼 |
| 回覆按鈕 | 為建議的後續按鈕選擇符合條件的內容來源 |

<span id="improve-answer-quality" data-sixmm-canonical-anchor="improve-answer-quality" aria-hidden="true"></span>

## 提高答案品質

撰寫具有明確問題、適用受眾、先決條件、步驟、例外情況和升級路徑的文章。保持費用、限制和時間戳明確。刪除相互衝突的過時規則。一起提供相關事實，特別是存款網路、轉帳條件和帳戶驗證要求。

在訪客聊天中提出記錄的問題、後續問題和模糊的問題。檢查答案是否保留了您的實際規則，並在資訊不足時要求澄清。請勿將密碼、簽名機密或內部操作說明放在面向客戶的知識中。

## 診斷弱回覆

匹配的 FAQ 可以返回其配置的文本，而無需使用大模型。當內容有誤時更新該內容。如果沒有使用該型號，請檢查實際匹配的步驟和服務開關。對於向量故障，請​​在重建之前檢查檢索狀態和服務可用性。索引更新和重建可能會消耗配置的計費規則下的智慧服務餘額。
