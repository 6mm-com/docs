授權規劃是更廣泛啟動計畫的一部分。正確的路徑取決於目標市場、用戶類型、產品範圍、保管模式，以及各方的營運責任。

<h2 id="planning-inputs">規劃投入</h2>

| 輸入 | 為什麼重要 |
| --- | --- |
| 目標管轄區 | 確定法規期望及需接受地方審查。 |
| 使用者類型 | 零售、專業、機構或合作夥伴分散用戶可能需要不同的控制措施。 |
| 產品範圍 | 現貨、衍生性商品、錢包、託管及券商功能都能改變合規模式。 |
| 營運模式 | 白標、嵌入式、經紀人及機構模式的責任界限各異。 |

<h2 id="how-to-use-this-documentation">如何使用這些文件</h2>

利用這些文件在法律審查前，對齊技術與營運需求。這些文件能協助團隊描述架構、資料流、簽署、安全、資產流動及交易生命週期責任。

> **重要**
>
> 執照決定必須與相關司法管轄區合格的法律及合規顧問審查。
