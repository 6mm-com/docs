6MM 為授權合作夥伴提供技術基礎建設及合規支援。合規要求因司法管轄區及商業模式而異，因此每次啟動都應與合作夥伴自身義務進行審查。

<h2 id="what-this-section-covers">本節涵蓋的內容</h2>

| 面積 | 描述 |
| --- | --- |
| 授權支援 | 提供有關支援執照路徑及所需準備資料的指引。 |
| 合作夥伴義務 | 使用者入職、揭露、地方合規控管及客戶關係管理。 |
| 技術控制 | 簽名、日誌記錄、存取控制、webhook 驗證及生產監控。 |
| 發射回顧 | 在向用戶開放交易功能前，先進行核對清單確認。 |

<h2 id="important-boundary">重要邊界</h2>

6MM 文件協助合作夥伴準備技術與營運控制。它不能取代法律建議、司法管轄區特定合規審查或合作夥伴自身的監管義務。

<h2 id="information-to-prepare">需準備的資訊</h2>

在合規或上市審查前，請記錄：

- 目標國家或地區及將獲得存取權限的使用者類型。
- 產品範圍，包括嵌入式交易、白標交付、流動性、錢包、託管或經紀功能。
- 負責使用者入職、身份檢查、揭露、保管、支援及事件溝通的實體。
- 合作夥伴前端、後端、 6MM APIs、 SDKs、webhook 及營運系統之間的資料流動。
- 憑證儲存、存取控制、稽核記錄、監控及升級擁有者。

<h2 id="recommended-review-path">推薦的審查路徑</h2>

1. 使用[夥伴責任矩陣]（/security-compliance/partner-responsibilities）來分配所有權。
2. 與目標作業系統模型進行檢視[授權支援]（/security-compliance/license-support）。
3. 確認[安全架構]（/security-compliance/security-architecture）及 API/webhook控制項。
4. 完成[生產啟動清單]（/resources/production-launch-checklist）。

法律與合規結論必須經合格顧問及負責合作夥伴實體批准。本頁面描述整合準備及責任邊界，非法律意見或保證特定授權可得。
