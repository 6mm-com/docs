<h2 id="documentation-map">文件地圖</h2>

| 面積 | 目的 |
| --- | --- |
| 安全架構 | 了解交易基礎設施、 API/SDK 存取及合作夥伴營運如何受到保護。 |
| API 與Webhook子安全性 | 透過簽名、秘密儲存及冪等處理保護後端整合。 |
| 合規準備度 | 準備授權支援情境、發射檢查及合作夥伴方操作控制。 |
| 法律文件 | 在製作開始前，請檢視條款、隱私與責任界限。 |

<h2 id="recommended-reading-order">推薦閱讀順序</h2>

1. 從安全架構與合作夥伴責任邊界開始。
2. 在後端整合前，檢視 API Key 管理、請求簽署及 Webhook 冪等性。
3. 在區域發射準備前，檢視合規概覽與授權支援。
4. 在向用戶開放交易功能前，務必先檢視法律頁面及上市清單。
