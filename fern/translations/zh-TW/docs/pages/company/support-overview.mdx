6MM 支援設計用於授權合作夥伴、主動整合及生產作業。除非另有協議，最終用戶支援仍由合作夥伴平台負責。

<h2 id="choose-the-right-path">選擇正確的道路</h2>

| 地理位置 | 推薦路徑 | 包括 |
| --- | --- | --- |
| 新的合作夥伴關係或解決方案評估 | 合作夥伴入職路徑 | 產品類型、目標區域、上市時程、預期整合模式。 |
| SDK、 API、webhook 或環境問題 | 技術支援路徑 | 端點、 SDK 版本、請求 ID、重現步驟、日誌。 |
| 生產事件或貿易流下降 | 事件升級路徑 | 影響範圍、開始時間、受影響使用者、訂單 ID、目前緩解措施。 |
| 資產、複製或發射材料變更 | 作戰支援路徑 | 頁面、語言、請求變更、上線日期、核准擁有者。 |
| 脆弱或疑似虐待 | 安全報告路徑 | 技術細節、受影響的端點、證據、緊急程度、問題是否仍在運作。 |

<h2 id="severity-guide">嚴重程度指南</h2>

| 嚴重程度 | 範例 |
| --- | --- |
| 批判 | 無法進行生產交易、認證、代幣發行或資金相關資金流動。 |
| 高 | 主要的夥伴流量會被削弱，但有解決方法。 |
| 正常 | 整合問題、設定請求、文件問題或計畫中的啟動支援。 |

<h2 id="before-contacting-support">在聯絡客服之前</h2>

- 確認受影響的產品區域與環境。
- 收集請求 ID、訂單 ID、時間戳、使用者映射 ID、webhook 事件 ID 及日誌。
- 使用支援請求範本處理生產問題。
