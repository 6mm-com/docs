6MM 合作夥伴的入職流程圍繞著選擇合適的基礎設施路徑、驗證技術整合，以及在啟動前準備營運交接來來組織。

<h2 id="onboarding-stages">入職階段</h2>

| 舞台 | 焦點 | 產出 |
| --- | --- | --- |
| 1. 商業契合度 | 產品型號、目標市場、用戶流程及上市時程。 | 建議的解決方案路徑與範圍。 |
| 2. 解決方案設計 | 內嵌交易、流動性、白標交易或合規支援。 | 整合架構與責任分工。 |
| 3. 技術整合 | SDK、 API、webhook、認證、環境和監控設定。 | 在約定的環境中測試整合。 |
| 4. 發射準備 | 資產、風險提示、支援擁有者、事件路徑與生產檢查清單。 | 生產準備審查。 |
| 5. 持續進行的作業 | 監控、問題升級、產品變更及區域擴展。 | 穩定的夥伴運作節奏。 |

<h2 id="information-to-prepare">需準備的資訊</h2>

- 產品類型與預期使用者旅程。
- 目標地區、語言及發射時程。
- 首選整合模式：內嵌 SDK/API、白標交換、流動性支援或合規支援。
- 現有的後端、錢包、 KYC、風險及支援系統。
- 生產域、回調路徑及技術擁有者聯絡。
