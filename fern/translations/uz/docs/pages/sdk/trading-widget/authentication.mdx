<h2 id="recommended-mode-partner-token">Tavsiya etilgan rejim: partner-token</h2>

partner-token qisqa tokenlarni URL larga qo'ymaslik va apiSecret partner backendda ushlab turadi.

```js
const widget = TradingWidget.create('#trading-widget', {
  baseUrl: 'https://app.6mm.com',
  auth: {
    mode: 'partner-token',
    tokenProvider: async ({ channelId, symbol, reason }) => {
      const resp = await fetch('/api/trading/embed-token', {
        method: 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ channelId, symbol, reason }),
      })

      if (!resp.ok) {
        throw new Error('Failed to request embed token')
      }

      return resp.json()
    },
  },
})
```

<h2 id="backend-flow">Orqa tizim oqimi</h2>

```text
1. Partner frontend receives auth_request from the iframe.
2. SDK calls tokenProvider.
3. Partner frontend calls its own backend.
4. Partner backend validates the partner session.
5. Partner backend calls 6MM Agent API or Java SDK createEmbedToken.
6. SDK sends embedToken to the iframe through postMessage.
7. iframe exchanges embedToken for a 6MM access token.
8. iframe continues initialization and emits ready.
```

<h2 id="tokenprovider-contract">tokenProvider shartnomasi</h2>

| Maydon | Rejissyorlik | Tavsif |
| --- | --- | --- |
| channelId | SDK -> Hamkor backend | Noyob vidjet sessiya identifikatori. Orqa tomon uni createEmbedTokenga uzatishi kerak. |
| ramz | SDK -> Hamkor backend | Joriy so'ralgan savdo belgisi. Kerak bo'lganda tokenni scope qilish uchun undan foydalaning. |
| Sabab | SDK -> Hamkor backend | Nega SDK token so'rayapti, masalan, dastlabki yuklash yoki yangilanish. |
| embedToken | Hamkor backend -> SDK | Agent SDK yoki Agent tomonidan yaratilgan qisqa muddatli token API. |
| expireAt | Hamkor backend -> SDK | Token amal qilish muddati tamg'asi 6MMtomonidan qaytarildi. |

<h2 id="failure-handling">Nosozliklarni boshqarish</h2>

| Holati | Tavsiya etilgan boshqaruv |
| --- | --- |
| Hamkorlik sessiyasi muddati tugadi | Hamkor nuqtadan 401 ni qaytaring va foydalanuvchidan yana tizimga kirishni so'rang. |
| Token yaratish vaqtincha muvaffaqiyatsiz bo'ldi | tokenProvider ichiga xato kiriting va vidjetga autentifikatsiya xatosi paydo bo'lishiga ruxsat bering. |
| channelId mos kelmaydi | So'rovni rad eting va vidjet nusxasini qayta yarating. |
| Foydalanuvchiga savdo qilishga ruxsat berilmaydi | Hamkor boshqaruvidagi xatoni qaytaring va embed token yaratmang. |

<h2 id="compatibility-mode-agent-sso">Moslik rejimi: agent-sso</h2>

Agent-SSO eski /agent-entry chipta oqimini saqlab qoladi. Yangi integratsiyalar uchun partner-tokenni afzal ko'ring.

```js
const widget = TradingWidget.create('#trading-widget', {
  baseUrl: 'https://app.6mm.com',
  auth: {
    mode: 'agent-sso',
    entryUrlProvider: async ({ redirectPath }) => {
      const resp = await fetch('/api/trading-entry', {
        method: 'POST',
        credentials: 'include',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ redirectPath }),
      })
      const data = await resp.json()
      return data.webUrl
    },
  },
})
```
