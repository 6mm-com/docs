<h2 id="install">O'rnatish</h2>

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Paketga kirish**
>
> 6MM hamkor onboarding paytida tasdiqlangan Composer paket nomi, ombor va versiyasini taqdim etadi. Paket ommaviy Packagistda mavjud deb hisoblanmasligi kerak.

<h2 id="before-you-start">Boshlashdan oldin</h2>

- Agent API baza URL 6MMbilan tasdiqlang.
- Muhit o'zgaruvchilari yoki maxfiy boshqaruvdan apiSecret yuklash.
- Faqat orqa SDK xizmatlarida foydalanishni saqlang.
- Transfer va webhook oqimlari uchun idempotent boshqaruvni tayyorlash.

<h2 id="initialize-client">Mijozni ishga tushirish</h2>

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Faqat backend**
>
> PHP SDK Agent API so'rovlarini imzolaydi va ommaviy manba kodi yoki frontend ish muhitlari orqali oshkor qilinmasligi kerak.

<h2 id="example-transfer-funds-in">Misol: mablag'larni o'tkazish</h2>

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Miqdorlar uchun o'nlik satrlardan foydalaning va qayta urinishda yoki transfer holatini so'rashda asl agentOrderNo saqlang.
