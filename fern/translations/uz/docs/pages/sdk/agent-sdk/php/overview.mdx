<h2 id="runtime">Davomiyligi</h2>

| Element | Qiymat |
| --- | --- |
| Paket | Sixmm/Agent-SDK |
| Minimal PHP versiyasi | PHP 7.4+ |
| Tavsiya etilgan PHP versiyasi | PHP 8.1+ yoki hozirda qo'llab-quvvatlanadigan versiyalar |
| Talab qilinadigan kengaytmalar | ext-json, ext-curl |

PHP SDK paket manbasi va tasdiqlangan versiyasi hamkorlarni ishga tushirish jarayonida taqdim etiladi. Paket ommaviy Packagist'dan mavjud deb hisoblamang; tashkilotingiz uchun taqdim etilgan Composer repozitoriyasini sozlash.

<h2 id="supported-scenarios">Qo'llab-quvvatlanadigan ssenariylar</h2>

| Ssenariy | SDK usuli |
| --- | --- |
| Foydalanuvchini bog'lash | Bog'lash |
| Belgilangan miqdorda o'tkazish | O'tkazish |
| Hammasini uzatish | transferAllOut |
| Teskari uzatish | Orqa tomoni |
| So'rov tartibi | queryOrder |
| Kirishni yarat URL | createEntryUrl |
| Webhook tekshiruvi | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Backend integratsiya qoidalari</h2>

- Maxfiy menejer yoki himoyalangan muhit o'zgaruvchisidan `apiSecret` yuklash.
- Foydalanuvchi bog'lash, uzatish, imzolash va webhook mantiqini brauzer kodidan chiqarib tashlash.
- Aktiv miqdorlari uchun o'nlik satrlardan foydalaning, suzuvchi nuqtali yaxlitlashni oldini olish uchun.
- Noaniq uzatish natijasini so'rashda asl `agentOrderNo` ni qayta ishlatish.
- Webhook imzolarini xom so'rov tanasi bilan solishtirib, uni dekodlash yoki o'zgartirishdan oldin tekshirish.
