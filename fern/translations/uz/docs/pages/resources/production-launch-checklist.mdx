Haqiqiy foydalanuvchilarga 6MMquvvatli savdo imkoniyatlarini taqdim etishdan oldin ushbu ro'yxatdan foydalaning.

<h2 id="integration-readiness">Integratsiyaga tayyorgarlik</h2>

- Ishlab chiqarish domenlari va yo'naltirish yo'llari tasdiqlandi.
- Trading Widget, Agent SDK, APIyoki WebSocket oqimlari boshidan oxirigacha sinovdan o'tkazilgan.
- Hamkor backend server tomonidagi barcha sirlarni saqlaydi.
- Webhook qabul qilish, imzoni tekshirish, qayta urinish va idempotency yoqilgan.
- Jurnallar so'rov IDlari, foydalanuvchi xaritalash IDlari, buyurtma identifikatorlari va vaqt tamg'alarini o'z ichiga oladi.

<h2 id="product-and-resource-readiness">Mahsulot va resurslarga tayyorgarlik</h2>

- Kirish nuqtalari, bannerlar va karta aktivlari tasdiqlangan til versiyasidan foydalanadi.
- Oq yorliqli aktivlar faqat hamkorlik kelishuvi ruxsat berganda ishlatiladi.
- Foydalanuvchiga mo'ljallangan xavf so'rovlari va savdo yozuvi nusxalari hamkor jamoa tomonidan ko'rib chiqiladi.
- Qo'llab-quvvatlash va eskalatsiya egalari tayinlanadi.

<h2 id="operational-readiness">Operatsion tayyorgarlik</h2>

- Monitoring API xatolari, token chiqarish, vidjetlarni ishga tushirish, webhook nosozliklari va buyurtma hayotiy sikl hodisalarini qamrab oladi.
- Favqulodda aloqa yo'llari tasdiqlandi.
- Savdo yozuvi uchun orqaga qaytarish yoki vaqtinchalik nogiron reja tayyorlanadi.

<h2 id="security-and-compliance-readiness">Xavfsizlik va muvofiqlik tayyorligi</h2>

- API kalitlar minimal ruxsatlar va tasdiqlangan IP cheklovlaridan foydalanadi.
- Sertifikatlarni almashtirish va bekor qilish sinovdan o'tkazilgan.
- Webhook imzolari xom so'rov tanalariga qarshi tekshiriladi.
- Foydalanuvchi ma'lumotlari, xavf bildirishnomalari, mas'uliyat chegaralari va maqsadli bozor ko'rib chiqishi yakunlandi.
- Hodisa, yarashuv va qo'llab-quvvatlovchi dalillar sirlarni oshkor qilmasdan topilishi mumkin.
