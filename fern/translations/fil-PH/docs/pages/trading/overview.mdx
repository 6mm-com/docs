<h2 id="before-trading">Bago mag-trade</h2>

- Kumpirmahin na ang user ay pumapasok sa pamamagitan ng awtorisadong partner o embedded 6MM entry.
- Siguraduhing nasa tamang account ang pondo bago mag-order.
- Unawain ang leverage, margin, liquidation, at funding fee na pag-uugali.
- Magsimula sa maliliit na posisyon kapag natututo ng bagong merkado o mode ng pangangalakal.
- Gamitin ang TP / SL at bawasan lamang ang mga order kung kinakailangan para sa kontrol ng panganib.
