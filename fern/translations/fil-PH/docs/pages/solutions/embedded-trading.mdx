Ang Embedded API / SDK Trading System ay idinisenyo para sa mga partner na may hawak na ng traffic, users, o business workflows at nais magdagdag ng trading nang hindi gumagawa ng buong exchange mula sa simula.

<h2 id="what-it-provides">Ano ang ibinibigay nito</h2>

- Embedded trading terminal sa pamamagitan ng Trading Widget SDK
- Integrasyon ng partner backend sa pamamagitan ng Agent SDKs
- User identity binding at entry-token flows
- Paglipat ng ari-arian, order, posisyon, at access sa account API
- Integrasyon ng event, webhook, at lifecycle para sa mga operational system

<h2 id="recommended-architecture">Inirerekomendang arkitektura</h2>

| Layer | Responsibilidad |
| --- | --- |
| Frontend ng partner | Nagho-host ng entry point at ini-embed ang 6MM trading interface. |
| Partner backend | Pinananatiling API lihim, pinapatunayan ang mga gumagamit, naglalabas ng embed tokens, at nagpoproseso ng webhooks. |
| 6MM imprastraktura ng kalakalan | Pinangangasiwaan ang trading UI, matching, risk, liquidity, account state, at trading lifecycle. |

<h2 id="choose-an-integration-path">Pumili ng integration path</h2>

| Kinakailangan | Inirerekomendang landas |
| --- | --- |
| Kumpletong trading UI na may pinakamabilis na web integration | Trading Widget |
| Backend user binding, transfer, entry URL, at webhook handling | Agent SDK |
| Ganap na pasadyang workflow ng produkto at order | REST API + WebSocket |
| Karanasan sa branded exchange na may mas malawak na saklaw ng operasyon | White-label Exchange |

Maaaring pagsamahin ng panghuling disenyo ang mga landas na ito. Kumpirmahin ang authentication, pagmamay-ari ng asset, mga hangganan ng responsibilidad, monitoring, at suporta sa produksyon bago magsimula ang implementasyon.
