> **Tala**
>
> Ang mga endpoint ng posisyon ay nangangailangan ng trade permission.

<h2 id="set-leverage">Itakda ang Leverage</h2>

```http
POST /v1/private/position/leverage
Content-Type: application/json
```

Katawan ng kahilingan:

```json
{
  "symbol": "BTCUSDT",
  "leverage": 20
}
```

Mga field ng tugon:

| Larangan       | Uri   | Paglalarawan |
| ----------- | ------ | ----------- |
| `symbol`    | string | Simbolo      |
| `leverage`  | int32  | Leverage    |
| `timestamp` | int64  | Timestamp   |

<h2 id="set-margin-mode">Itakda ang Margin Mode</h2>

```http
POST /v1/private/position/margin-mode
Content-Type: application/json
```

Katawan ng kahilingan:

```json
{
  "symbol": "BTCUSDT",
  "marginMode": 1
}
```

`marginMode`: `1` cross, `2` hiwalay.

<h2 id="position-settings">Mga Setting ng Posisyon</h2>

```http
GET /v1/private/position/settings?symbol=BTCUSDT
```

Mga field ng tugon:

| Larangan        | Uri   | Paglalarawan             |
| ------------ | ------ | ----------------------- |
| `symbol`     | string | Simbolo                  |
| `marginMode` | int32  | `1` krus, `2` hiwalay |
| `leverage`   | int32  | Leverage                |

<h2 id="current-positions">Kasalukuyang mga Posisyon</h2>

```http
GET /v1/private/position/positions?symbol=BTCUSDT
```

Mga parameter ng kahilingan:

| Parameter | Uri   | Kinakailangan | Paglalarawan |
| --------- | ------ | -------- | ----------- |
| `symbol`  | string | Hindi       | Simbolo      |

Mga field ng tugon:

| Larangan                         | Uri   | Paglalarawan                |
| ----------------------------- | ------ | -------------------------- |
| `positions[].symbol`          | string | Simbolo                     |
| `positions[].marginMode`      | string | Margin mode                |
| `positions[].positionSide`    | string | Panig ng posisyon              |
| `positions[].leverage`        | int32  | Leverage                   |
| `positions[].quantity`        | string | Dami ng posisyon          |
| `positions[].entryPrice`      | string | Presyo ng pagpasok                |
| `positions[].breakEvenPrice`  | string | Break-even na presyo           |
| `positions[].liqPrice`        | string | Presyo ng likwidasyon          |
| `positions[].marginRatio`     | string | Ratio ng margin               |
| `positions[].unrealizedPnl`   | string | Hindi Natupad na PnL             |
| `positions[].roe`             | string | Balik sa equity           |
| `positions[].nextFundingFee`  | string | Tinatayang susunod na bayad sa pondo |
| `positions[].fundingFeeAccum` | string | Naipong bayad sa pondo    |
| `positions[].tpPrice`         | string | Presyo ng take-profit          |
| `positions[].slPrice`         | string | Presyo ng stop-loss            |

<h2 id="position-history">Kasaysayan ng Posisyon</h2>

```http
GET /v1/private/position/history?symbol=BTCUSDT&page=1&pageSize=20
```

Mga parameter ng kahilingan:

| Parameter   | Uri   | Kinakailangan | Paglalarawan                  |
| ----------- | ------ | -------- | ---------------------------- |
| `symbol`    | string | Hindi       | Simbolo                       |
| `side`      | string | Hindi       | `long` / `short`             |
| `startTime` | int64  | Hindi       | Oras ng pagsisimula                   |
| `endTime`   | int64  | Hindi       | Oras ng Pagtatapos                     |
| `page`      | int64  | Hindi       | Numero ng pahina, default na `1`     |
| `pageSize`  | int64  | Hindi       | Mga item kada pahina, default na `20` |

Mga field ng tugon:

| Larangan                    | Uri   | Paglalarawan               |
| ------------------------ | ------ | ------------------------- |
| `list[].symbol`          | string | Simbolo                    |
| `list[].positionSide`    | string | Panig ng posisyon             |
| `list[].leverage`        | int32  | Leverage                  |
| `list[].maxQuantity`     | string | Pinakamataas na dami ng posisyon |
| `list[].entryPrice`      | string | Presyo ng pagpasok               |
| `list[].closePrice`      | string | Presyo ng pagsasara               |
| `list[].pnl`             | string | Naisakatuparan na PnL              |
| `list[].roe`             | string | Balik sa equity          |
| `list[].marginMode`      | string | Margin mode               |
| `list[].triggerMode`     | int32  | Isara ang trigger mode        |
| `list[].fundingFeeAccum` | string | Naipong bayad sa pondo   |
| `list[].openedAt`        | int64  | Oras ng bukas                 |
| `list[].closedAt`        | int64  | Oras ng pagsasara                |
| `total`                  | int64  | Kabuuang bilang               |
