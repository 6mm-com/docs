<h2 id="runtime">Haba ng Takbo</h2>

| Item | Halaga |
| --- | --- |
| Pakete | sixmm/agent-sdk |
| Minimum na bersyon ng PHP | PHP 7.4+ |
| Inirerekomendang PHP bersyon | PHP 8.1+ o kasalukuyang suportadong mga bersyon |
| Mga kinakailangang extension | ext-json, ext-curl |

Ang pinagmulan ng PHP SDK package at aprubadong bersyon ay ibinibigay sa panahon ng partner onboarding. Huwag ipalagay na ang package ay available mula sa public Packagist; i-configure ang Composer repository na ibinigay para sa iyong organisasyon.

<h2 id="supported-scenarios">Mga suportadong senaryo</h2>

| Senaryo | SDK paraan |
| --- | --- |
| I-bind ang user | itali |
| Fixed amount transfer | paglilipat |
| Ilipat lahat | transferAllOut |
| Reverse transfer | baliktad |
| Pagkakasunod-sunod ng query | queryOrder |
| Gumawa ng entry URL | createEntryUrl |
| Beripikasyon ng Webhook | WebhookVerifier::verify |

<h2 id="backend-integration-rules">Mga patakaran sa backend integration</h2>

- Mag-load ng `apiSecret` mula sa secret manager o protected environment variable.
- Iwasan ang user binding, transfer, signing, at webhook logic sa browser code.
- Gumamit ng decimal strings para sa halaga ng asset upang maiwasan ang floating-point rounding.
- Gamitin muli ang orihinal na `agentOrderNo` kapag nag-query ng hindi tiyak na resulta ng paglilipat.
- I-verify ang webhook signatures laban sa raw request body bago ito i-decode o baguhin.
