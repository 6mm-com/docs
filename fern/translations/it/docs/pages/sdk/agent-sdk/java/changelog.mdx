Questa guida è rivolta a **Agent Java SDK `v0.3.0`**, Java 8+ e agli appalti pubblici contrassegnati. Gli esempi vengono eseguiti nel backend di un partner dopo aver inizializzato `client` in [Avvio rapido](/it/sdk/agent-sdk/java/quick-start).

<span data-sixmm-canonical-anchor="v030" aria-hidden="true"></span>

## v0.3.0

- Sei query perpetue: ordini correnti, cronologia degli ordini, esecuzioni, posizioni correnti, cronologia delle posizioni e registro dei conti.
- Saldi di finanziamento, trasferimenti, richieste di recupero e trasferimenti di finanziamenti/contratti.
- Selezione esplicita della produzione/simulata per le richieste di fondi supportati.
- Guide di reindirizzamento e incorporamento del trading di secondi, riferimento ai campi di risposta e istruzioni sulla migrazione.

Java SDK e Trading Widget SDK hanno versioni indipendenti. Il `v1` Widget URL non è la versione Java SDK `0.3.0`.

<span id="existing-integrations" data-sixmm-canonical-anchor="existing-integrations" aria-hidden="true"></span>

## Integrazioni esistenti

Conserva le mappature degli utenti, gli ordini originali e le credenziali. I campi ambientali omessi mantengono il comportamento di produzione esistente. Il finanziamento, i fondi simulati espliciti e le sei query perpetue richiedono i nuovi modelli e metodi corrispondenti. Revisione [Guida all'aggiornamento](/it/sdk/agent-sdk/java/upgrade) prima di modificare un'integrazione esistente.
