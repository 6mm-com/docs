## SDK chiamata

Crea token embed dal tuo backend dopo aver validato la sessione utente partner. Il browser dovrebbe chiamare il tuo endpoint, e il tuo endpoint dovrebbe chiamare 6MM tramite il Agent SDK.

```java
CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

> **Accreditazione una tantum**
>
> embedToken è di breve durata e usa una tantum. Non inserirlo in una stringa di query URL .

<span id="backend-endpoint-example" data-sixmm-canonical-anchor="backend-endpoint-example" aria-hidden="true"></span>

## Esempio di endpoint backend

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

Restituisci solo i campi necessari al fornitore Trading Widget token. Non restituire apiSecret, campi di firma grezzi o configurazione interna del servizio.

<span id="failure-handling" data-sixmm-canonical-anchor="failure-handling" aria-hidden="true"></span>

## Gestione dei guasti

| Condizioni | Manipolazione consigliata |
| --- | --- |
| La sessione utente è mancante o scaduta | Restituisci il 401 dall'endpoint partner e chiedi all'utente di accedere di nuovo. |
| L'utente agente non è vincolato | Assegna prima l'utente, poi riprova a creare il token. |
| 6MM restituisce un errore temporaneo | Restituisci un errore riprovabile al frontend e registra requestId per il supporto. |
| channelId non corrisponde all'istanza del widget | Rifiuta la richiesta e ricrea la sessione del widget. |
