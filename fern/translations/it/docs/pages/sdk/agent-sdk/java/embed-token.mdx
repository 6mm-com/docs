## Trading Widget Incorpora token

Il token incorporato è per la modalità Trading Widget SDK `partner-token + tokenProvider`. IL
il browser chiama il backend del partner e il backend del partner chiama questo Java SDK
per creare un `embedToken`.

```java
import com.sixmm.agent.model.CreateEmbedTokenRequest;
import com.sixmm.agent.model.CreateEmbedTokenResponse;

CreateEmbedTokenResponse resp = client.createEmbedToken(
        CreateEmbedTokenRequest.of("agent-user-001", "tw_abc123")
                .withSymbol("ETHUSDT"));

System.out.println(resp.embedToken);
System.out.println(resp.expireAt);
```

Requisiti di integrazione:

- `channelId` deve utilizzare il valore passato da Trading Widget SDK.
- `symbol` è facoltativo, ma si consiglia di passare il simbolo iniziale corrente.
- `embedToken` è di breve durata e si verifica una sola volta. Non inserirlo nelle stringhe di query URL.
- Il frontend del partner non deve mai contenere `apiSecret`.
- `expireAt` è un timestamp Unix in secondi, non un TTL.

Esempio di endpoint backend del partner:

```java
@PostMapping("/api/trading/embed-token")
public EmbedTokenView createEmbedToken(@RequestBody EmbedTokenRequest request,
                                       PartnerSession session) {
    String agentUserId = session.getAgentUserId();
    CreateEmbedTokenResponse resp = agentClient.createEmbedToken(
            CreateEmbedTokenRequest.of(agentUserId, request.getChannelId())
                    .withSymbol(request.getSymbol()));

    return new EmbedTokenView(resp.embedToken, resp.expireAt, request.getChannelId());
}
```

## Contratto endpoint partner

Autenticare la sessione partner e derivare `agentUserId` lato server. Accetta il Widget corrente `channelId`; restituisce il livello superiore `embedToken`, `expireAt` (secondi Unix) e lo stesso `channelId`. Le risposte dell'agente non forniscono `channelId`: il tuo backend lo fa eco. Recupera un nuovo token all'inizializzazione e al rinnovo; non riutilizzarlo mai. La creazione di token non trasferisce fondi né sceglie l'ambiente del portafoglio.

Vedere [Scambio di secondi](/it/sdk/agent-sdk/java/seconds-trading) per il flusso frontend/backend completo.
