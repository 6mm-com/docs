Questa guida è rivolta a **Agent Java SDK `v0.3.0`**, Java 8+ e agli appalti pubblici contrassegnati. Gli esempi vengono eseguiti nel backend di un partner dopo aver inizializzato `client` in [Avvio rapido](/it/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## Prerequisiti di esempio

Gli snippet Java condividono queste importazioni. Inizializza `client` utilizzando Quick Start e ottieni `platformUserId` dall'associazione salvata. Gli ID utente/ordine di esempio devono essere sostituiti con i tuoi valori persistenti.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

<span data-sixmm-canonical-anchor="listperpetualtrades" aria-hidden="true"></span>

## `listPerpetualTrades`

Modello richiesto: `PerpetualTradesRequest`.

```java
import com.sixmm.agent.model.PerpetualTradesRequest;
import com.sixmm.agent.model.PerpetualResponse;
import java.util.Collections;

PerpetualTradesRequest request = new PerpetualTradesRequest();
request.platformUserIds = Collections.singletonList("1188041528");
request.limit = 100;
request.symbol = "BTCUSDT";
request.endTime = System.currentTimeMillis();
request.startTime = request.endTime - 3_600_000L;
PerpetualResponse response = client.listPerpetualTrades(request);
System.out.println(response.data.items.size());
System.out.println(response.data.hasMore);
System.out.println(response.data.nextCursor);
```

<span id="request-fields" data-sixmm-canonical-anchor="request-fields" aria-hidden="true"></span>

### Campi richiesta

| Campo | Tipo Java | Necessario | Senso |
| --- | --- | --- | --- |
| `platformUserIds` | `java.util.List<String>` | Condizionale | Da 1 a 100 ID pubblici univoci; richiesto per esecuzioni e ordini condizionati. Omettere le query supportate per l'ambito del player diretto; [] non è valido. |
| `symbol` | `String` | NO | Filtro opzionale per le coppie di scambio. |
| `orderId` | `String` | NO | ID dell'ordine ordinario; non un numero di ordine di trasferimento del partner. |
| `startTime` | `Long` | NO | Millisecondi Unix inclusi; utilizzare una finestra della cronologia UTC fissa. |
| `endTime` | `Long` | NO | Millisecondi Unix esclusivi. |
| `limit` | `Integer` | NO | Predefinito 500; 1–1000. |
| `cursor` | `String` | NO | Utilizza il nextCursor restituito con i filtri invariati; interrompere quando hasMore è falso. |

L'esempio legge una pagina. Per i campi obbligatori, ambito del giocatore, semantica del filtro, limite, cursore e tentativi limitati, seguire [Panoramica delle query](/it/sdk/agent-sdk/java/perpetual-queries). Mantieni invariati tutti i filtri durante la paginazione; non interpretare un errore come un risultato vuoto.

## Dettagli di riempimento commerciale

Interfaccia: `trades`. Richiede platformUserIds esplicito.

| campo `data`. | tipo | Senso |
| --- | --- | --- |
| `fillId` | string | ID dettagli trade fill, corrispondente a questo record entityId |
| `tradeId` | string | L'ID transazione corrispondente associato alla transazione; non sostituisce l'ID dettagliato |
| `orderId` | string | L'ID ordine generale a cui appartiene questo dettaglio |
| `positionId` | string | ID posizione associata |
| `symbol` | string | coppia commerciale |
| `side` | string | La direzione di acquisto e vendita di questo giocatore BUY / SELL |
| `roleType` | string | Il carattere della transazione di questo giocatore MAKER / TAKER |
| `positionSide` | string | Direzione della posizione, spiegata in base al valore effettivo LONG / SHORT / BOTH ecc. |
| `price` | string | Questo prezzo di transazione |
| `quantity` | string | La quantità di questa transazione non è la quantità totale dell'ordine originale. |
| `tradeValue` | string | Il valore nominale di questa transazione deriva dal nozionale della transazione |
| `handlingFee` | string | La commissione per questa transazione mantiene il simbolo e l'accuratezza della fonte e non assume da sola il valore assoluto. |
| `realizedPnl` | string | Il profitto e la perdita realizzati corrispondenti a questa transazione; non i profitti e le perdite fluttuanti in tempo reale della posizione corrente |
| `tradedAt` | integer | Tempo di transazione, millisecondi; utilizzare questo campo per il filtraggio temporale |

Un ordine può avere più esecuzioni, che dovrebbero essere salvate in dettaglio. Non unire i record di giocatori diversi/riempire ruoli tramite tradeId per poi eliminare le loro identità record.
