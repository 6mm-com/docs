Questa guida è rivolta a **Agent Java SDK `v0.3.0`**, Java 8+ e agli appalti pubblici contrassegnati. Gli esempi vengono eseguiti nel backend di un partner dopo aver inizializzato `client` in [Avvio rapido](/it/sdk/agent-sdk/java/quick-start).

<span id="example-prerequisites" data-sixmm-canonical-anchor="example-prerequisites" aria-hidden="true"></span>

## Prerequisiti di esempio

Gli snippet Java condividono queste importazioni. Inizializza `client` utilizzando Quick Start e ottieni `platformUserId` dall'associazione salvata. Gli ID utente/ordine di esempio devono essere sostituiti con i tuoi valori persistenti.

```java
import com.sixmm.agent.*;
import com.sixmm.agent.model.*;
import java.util.*;
```

## Tassi di riferimento FX

Entrambi i metodi FX utilizzano il normale flusso dell'agente firmato API. Inizia scoprendo il
valute di origine attualmente supportate:

```java
import com.sixmm.agent.model.ListSupportedFiatCurrenciesResponse;

ListSupportedFiatCurrenciesResponse supported = client.listSupportedFiatCurrencies();
System.out.println(supported.targetCurrency);     // USDT
System.out.println(supported.sourceCurrencies);  // AUD, BRL, CNY, EUR, USD, ...
```

Richiedi tutti i tassi di riferimento fiat-to-USDT supportati:

```java
import com.sixmm.agent.model.ExchangeRateItem;
import com.sixmm.agent.model.QueryExchangeRatesResponse;

QueryExchangeRatesResponse rates = client.queryExchangeRates();
for (ExchangeRateItem item : rates.rates) {
    System.out.println("1 " + item.sourceCurrency + " = " + item.rate + " " + item.targetCurrency);
}
```

Interroga le valute selezionate:

```java
import com.sixmm.agent.model.QueryExchangeRatesRequest;

QueryExchangeRatesResponse rates = client.queryExchangeRates(
        QueryExchangeRatesRequest.of("CNY", "EUR", "USD"));
```

La fabbrica della richiesta ritaglia e mette in maiuscolo i codici valuta e li serializza come
il valore `sourceCurrencies` separato da virgole richiesto da API. Omettendo il
request o tutti i valori di valuta effettivi interroga ogni valuta supportata.

| Campo di risposta | Tipo | Descrizione |
| --- | --- | --- |
| `snapshotVersion` | string | Versione snapshot stabile per controllo e riconciliazione |
| `provider` | string | Fornitore upstream, attualmente `ECB` |
| `sourceDate` | string | Data di osservazione a monte nel formato `yyyy-MM-dd`. |
| `fetchedAt` / `expiresAt` | int64 | Timestamp Unix in millisecondi |
| `pricingPolicy` | string | Attualmente `FIXED_PEG` |
| `usdtUsdRate` | string | Importo USD per 1 USDT, attualmente fissato a `1` |
| `rateType` | string | Attualmente `INDICATIVE_DAILY` |
| `usage` | string | Attualmente `REFERENCE_ONLY` |
| `rateMeaning` | string | `1 sourceCurrency = rate USDT` |
| `rates[].rate` | string | USDT importo corrispondente ad una unità di fonte fiat |

Questi valori sono riferimenti da calcolare per un portafoglio multivaluta del partner
l'importo USDT inviato a 6MM. Non sono prezzi eseguibili, quotazioni bloccate o
prezzi di mercato USDT in tempo reale. Utilizzare `BigDecimal` e stringhe per l'importo
calcoli; non utilizzare `double` o `float`.
