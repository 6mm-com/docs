## Installazione

```json
{
  "require": {
    "sixmm/agent-sdk": "VERSION_PROVIDED_BY_6MM"
  }
}
```

> **Accesso al pacchetto**
>
> 6MM fornisce il nome del pacchetto Composer approvato, il repository e la versione durante l'onboarding del partner. Il pacchetto non dovrebbe essere presumibilmente esista su Packagist pubblico.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Prima che iniziate

- Conferma che l'Agente API base URL con 6MM.
- Carica apiSecret dalle variabili ambientali o dalla gestione dei segreti.
- Mantenere SDK utilizzo solo all'interno dei servizi backend.
- Preparare la gestione degli idempotenti per i flussi di trasferimento e webhook.

<span id="initialize-client" data-sixmm-canonical-anchor="initialize-client" aria-hidden="true"></span>

## Inizializzare client

```php
<?php

use Sixmm\Agent\AgentClient;
use Sixmm\Agent\AgentConfig;

$client = new AgentClient(new AgentConfig(
    'https://agent-api.6mm.com',
    'AGENT001',
    getenv('AGENT_API_SECRET') ?: '',
    'USDT'
));
```

> **Solo backend**
>
> Il PHP SDK firma le richieste dell'Agent API e non deve essere esposto tramite codice sorgente pubblico o ambienti frontend.

<span id="example-transfer-funds-in" data-sixmm-canonical-anchor="example-transfer-funds-in" aria-hidden="true"></span>

## Esempio: trasferire fondi in

```php
$response = $client->transfer([
    'agentOrderNo' => 'AGT-ORDER-1001',
    'agentUserId' => 'agent-user-001',
    'direction' => 'IN',
    'currency' => 'USDT',
    'amount' => '10.00',
]);
```

Usa stringhe decimali per gli importi e conserva il agentOrderNo originale quando riprovi o interroghi lo stato del trasferimento.
