## Durata

| Voce | Valore |
| --- | --- |
| Pacchetto | Sixmm/agente-SDK |
| Versione PHP minima | PHP 7.4+ |
| Versione PHP consigliata | PHP 8.1+ o versioni attualmente supportate |
| Estensioni richieste | ext-json, ext-curl |

La fonte del pacchetto PHP SDK e la versione approvata sono fornite durante l'onboarding del partner. Non presumere che il pacchetto sia disponibile tramite Packagist pubblico; configura il repository Composer fornito per la tua organizzazione.

<span id="supported-scenarios" data-sixmm-canonical-anchor="supported-scenarios" aria-hidden="true"></span>

## Scenari supportati

| Scenario | SDK metodo |
| --- | --- |
| Associare l'utente | Bindare |
| Trasferimento a importo fisso | Trasferimento |
| Trasferisci tutto fuori | transferAllOut |
| Trasferimento inverso | Retromarcia |
| Ordine delle query | queryOrder |
| Crea URL | createEntryUrl |
| Verifica Webhook | WebhookVerifier::verify |

<span id="backend-integration-rules" data-sixmm-canonical-anchor="backend-integration-rules" aria-hidden="true"></span>

## Regole di integrazione backend

- Carica `apiSecret` da un gestore segreto o da una variabile dell'ambiente protetto.
- Tenere la logica di link utente, trasferimento, firma e webhook fuori dal codice del browser.
- Utilizzare stringhe decimali per gli importi degli asset per evitare l'arrotondamento in virgola mobile.
- Riutilizzare il `agentOrderNo` originale quando si interroga un risultato di trasferimento incerto.
- Verificare le firme dei webhook rispetto al corpo grezzo della richiesta prima di decodificarlo o modificarlo.
