<h2 id="responsibility-split">Divisione delle responsabilità</h2>

| Area | Proprietario | Note |
| --- | --- | --- |
| Creazione di contenitori | Frontend partner | Fornire un elemento visibile con larghezza e altezza esplicite. |
| Creazione iframe | Trading Widget SDK | Il SDK crea e gestisce l'iframe. |
| Interfaccia di Trading | 6MM iframe | K-line, libretto ordini, modulo d'ordine, posizioni, ordini e dati del conto vengono eseguiti all'interno dell'iframe. |
| Controlli di visualizzazione | Trading Widget SDK + 6MM iframe | L'intestazione e il ticker inferiore del PC embed sono nascosti di default. I partner possono usare `display` per mostrare le aree delle shell o nascondere container di trading di alto livello. |
| Controllo login partner | Backend partner | Valida la sessione utente partner prima di rilasciare le credenziali di autenticazione. |
| Emissione di token di incorporamento | Backend partner + Agente API | Consigliato per la modalità partner-token. |

<h2 id="versioning">Versioning</h2>

Il percorso di integrazione pubblica rimane stabile sotto lo script v1 URL. L'attuale set di capacità v1 include partner-token, tokenProvider, entryUrlProvider, controlli di visualizzazione, eventi del ciclo di vita, metodi di istanza ed eventi di ordine.

```html
<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
```

<h2 id="when-to-use-the-widget">Quando usare il widget</h2>

Scegli Trading Widget quando un partner ha bisogno di un'interfaccia di trading completa all'interno di un prodotto web esistente. Usa invece la documentazione REST API e WebSocket quando costruisci e mantieni un'interfaccia di trading completamente personalizzata.

<h2 id="implementation-path">Percorso di implementazione</h2>

1. Segui il [Trading Widget Quick Start](/it/sdk/trading-widget/quick-start) per caricare lo script e creare un contenitore visibile.
2. Configurare [autenticazione partner-token](/it/sdk/trading-widget/authentication) tramite un backend partner.
3. Aggiungere le [opzioni ed eventi] necessarie(/sdk/trading-widget/options-events).
4. Utilizzare [metodi di istanza](/it/sdk/trading-widget/instance-methods) per i controlli del ciclo di vita e dell'esecuzione.
