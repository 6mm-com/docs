Il Trading Widget SDK incorpora l'interfaccia di trading 6MM all'interno di una pagina web di proprietà del partner. L'integrazione più rapida richiede un container visibile, lo script di produzione SDK e una chiamata al `TradingWidget.create()`.

<span id="before-you-start" data-sixmm-canonical-anchor="before-you-start" aria-hidden="true"></span>

## Prima che iniziate

- Eseguire l'esempio da una pagina web che può caricare risorse da `https://app.6mm.com`.
- Assegnare al contenitore del widget una larghezza e un'altezza esplicite.
- Carica il SDK prima di chiamare `TradingWidget.create()`.
- Pianificare il [flusso di autenticazione](/it/sdk/trading-widget/authentication) prima di abilitare funzionalità di conto o trading in produzione.

<span id="minimal-example" data-sixmm-canonical-anchor="minimal-example" aria-hidden="true"></span>

## Esempio minimo

```html
<div id="trading-widget" style="width: 100%; height: 720px"></div>

<script src="https://app.6mm.com/sdk/trading-widget/v1/index.js"></script>
<script>
  const widget = TradingWidget.create('#trading-widget', {
    baseUrl: 'https://app.6mm.com',
    symbol: 'BTCUSDT',
    theme: 'dark',
    locale: 'en',
    layout: 'default',
    display: {
      showHeader: false,
      showTicker: false,
      hidden: [],
    },
    onReady(event) {
      console.log('ready', event)
    },
    onError(error) {
      console.error('error', error)
    },
  })
</script>
```

Quando l'integrazione ha successo, il SDK crea un iframe all'interno di `#trading-widget` e chiama `onReady`. Cattura `onError` durante lo sviluppo in modo che i fallimenti di configurazione e caricamento siano visibili.

<span id="sdk-urls" data-sixmm-canonical-anchor="sdk-urls" aria-hidden="true"></span>

## SDK URL

| Ambiente | Copione URL |
| --- | --- |
| Produzione | https://app.6mm.com/sdk/trading-widget/v1/index.js |

> **Impostato esplicitamente baseUrl **
>
> Quando test da pagine di proprietà partner, passa baseUrl così l'iframe punta sempre al dominio web 6MM .

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Controlli di visualizzazione

Gli embedded partner nascondono di default l'intestazione PC e il ticker di mercato inferiore. Usa `display` quando devi mostrare quelle aree di shell o nascondere container di alto livello nella pagina di trading incorporata.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['account'],
}
```

<span id="container-size" data-sixmm-canonical-anchor="container-size" aria-hidden="true"></span>

## Dimensione del contenitore

| Superficie | Minimo raccomandato |
| --- | --- |
| Desktop | 1024 x 720 |
| Mobile | 390 x 700 |

Per layout responsive, mantenere la larghezza fluida e impostare un'altezza minima appropriata per ogni punto di rottura. Un contenitore con altezza zero può caricare il SDK con successo lasciando invisibile l'interfaccia di trading.

<span id="verify-the-integration" data-sixmm-canonical-anchor="verify-the-integration" aria-hidden="true"></span>

## Verifica l'integrazione

1. Conferma che lo script SDK ritorni con successo nel pannello di rete del browser.
2. Conferma `onReady` spara una volta che l'iframe è stato inizializzato.
3. Testare le `symbol`configurate, `locale`, tema e sezioni nascoste.
4. Ridimensionare la pagina tra i punti di interruzione desktop e mobile.
5. Completare un test autenticato con un utente non in produzione prima del lancio.

<span id="common-issues" data-sixmm-canonical-anchor="common-issues" aria-hidden="true"></span>

## Problemi comuni

| Sintomo | Cosa controllare |
| --- | --- |
| Area widget vuota | Conferma che il contenitore abbia larghezza e altezza visibili. |
| `TradingWidget` è indefinito | Conferma che lo script v1 sia stato caricato prima della chiamata create. |
| Pagina o ambiente sbagliato | Imposta `baseUrl` esplicitamente e verifica l'ambiente configurato. |
| L'evento pronto non si attiva mai | Cattura `onError` e ispeziona le richieste iframe o script bloccate. |
| I dati dell'account non sono disponibili | Completa il flusso di autenticazione dei widget supportato. |
