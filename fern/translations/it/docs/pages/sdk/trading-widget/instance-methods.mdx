<h2 id="method-summary">Riassunto del metodo</h2>

| Metodo | Scopo |
| --- | --- |
| distruggere() | Rimuovi l'iframe e rilascia gli ascoltatori dell'evento. |
| getState() | Leggi lo stato attuale del ciclo di vita SDK . |
| whenReady() | Aspetta che l'iframe finisca di inizializzare. |
| setSymbol(simbolo) | Scambia la coppia di trading all'interno dell'iframe. |
| setTheme(tema) | Aggiorna il parametro tema iframe. |
| setLocale(località) | Cambia il linguaggio dell'iframe. |
| setSize(larghezza, altezza) | Aggiorna le dimensioni dell'iframe. |
| ricarica() | Ricarica l'iframe attuale. |
| refreshAuth(motivo) | Attiva il flusso di aggiornamento dell'autenticazione del widget. |
| setTokenProvider(fornitore) | Sostituisci il provider usato dalla modalità partner-token. |
| ON(evento, gestore) | Iscriviti agli eventi di esecuzione e ricevi una funzione di disiscrizione. |

<h2 id="destroy">distruggere()</h2>

Rimuovi l'iframe, libera gli ascoltatori e emiti distrutto una volta per l'istanza attuale.

```js
widget.destroy()
```

<h2 id="getstate">getState()</h2>

Leggi lo stato attuale del ciclo di vita dell'istanza del widget.

```js
const state = widget.getState()
```

I valori di ritorno includono caricamento, autenticazione, pronto, errore e distrutto.

<h2 id="whenready">whenReady()</h2>

Aspetta che l'iframe finisca l'inizializzazione prima di eseguire la logica UI dipendente.

```js
await widget.whenReady()
```

<h2 id="setsymbol-symbol">setSymbol(simbolo)</h2>

Cambia la coppia di scambio all'interno dell'iframe. Se l'iframe sta ancora inizializzando, il SDK mette in coda il comando e lo invia dopo ready.

```js
widget.setSymbol('ETHUSDT')
```

<h2 id="settheme-theme">setTheme(tema)</h2>

Aggiorna il parametro tema usato dall'iframe di trading incorporato.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<h2 id="setlocale-locale">setLocale(località)</h2>

Cambia il linguaggio iframe. I valori supportati sono en, en-US e zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<h2 id="setsize-width-height">setSize(larghezza, altezza)</h2>

Aggiorna la dimensione dell'iframe DOM e avvisa l'iframe della nuova dimensione esterna. I valori numerici vengono convertiti in px.

```js
widget.setSize('100%', 720)
```

<h2 id="reload">ricarica()</h2>

Ricarica l'iframe attuale e aspetta che si inizializzi di nuovo.

```js
widget.reload()
```

<h2 id="refreshauth-reason">refreshAuth(motivo)</h2>

Chiedi all'iframe di aggiornare il flusso di autenticazione corrente. Il valore del motivo opzionale viene inoltrato per la registrazione e il controllo del flusso.

```js
widget.refreshAuth('manual')
```

<h2 id="settokenprovider-provider">setTokenProvider(fornitore)</h2>

Sostituire la tokenProvider usata dalla modalità partner-token. Il SDK chiama il provider quando l'iframe richiede un token di incorporamento fresco.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<h2 id="on-event-handler">ON(evento, gestore)</h2>

Iscriviti a un evento runtime. La funzione restituita rimuove l'ascoltatore.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```
