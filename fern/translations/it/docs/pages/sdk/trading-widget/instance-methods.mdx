## Riepilogo del metodo

| Metodo | Scopo |
| --- | --- |
| distruggere() | Rimuovi l'iframe e rilascia i listener di eventi. |
| getState() | Leggi lo stato attuale del ciclo di vita SDK |
| whenReady() | Attendi fino al completamento dell'inizializzazione dell'iframe. |
| setSymbol(simbolo) | Cambia la coppia di trading all'interno dell'iframe. |
| setTheme(tema) | Aggiorna il parametro del tema iframe. |
| setLocale(locale) | Cambia la lingua dell'iframe. |
| setSize(larghezza, altezza) | Aggiorna le dimensioni dell'iframe. |
| ricaricare() | Ricarica l'iframe corrente. |
| refreshAuth(motivo) | Attiva il flusso di aggiornamento dell'autenticazione del widget. |
| setTokenProvider(fornitore) | Sostituisci il provider utilizzato dalla modalità token partner. |
| on(evento, gestore) | Iscriviti agli eventi runtime e ricevi una funzione di annullamento dell'iscrizione. |

<span id="destroy" data-sixmm-canonical-anchor="destroy" aria-hidden="true"></span>

## distruggere()

Rimuovi l'iframe, cancella i listener ed emetti distrutti una volta per l'istanza corrente.

```js
widget.destroy()
```

<span data-sixmm-canonical-anchor="getstate" aria-hidden="true"></span>

## getState()

Leggere lo stato corrente del ciclo di vita dell'istanza del widget.

```js
const state = widget.getState()
```

I valori restituiti includono caricamento, autenticazione, pronto, errore e distrutto.

<span data-sixmm-canonical-anchor="whenready" aria-hidden="true"></span>

## whenReady()

Attendi che l'iframe termini l'inizializzazione prima di eseguire la logica dell'interfaccia utente dipendente.

```js
await widget.whenReady()
```

<span id="setsymbol-symbol" data-sixmm-canonical-anchor="setsymbol-symbol" aria-hidden="true"></span>

## setSymbol(simbolo)

Cambia la coppia di trading all'interno dell'iframe. Se l'iframe è ancora in fase di inizializzazione, SDK mette in coda il comando e lo invia dopo essere pronto.

```js
widget.setSymbol('ETHUSDT')
```

<span id="settheme-theme" data-sixmm-canonical-anchor="settheme-theme" aria-hidden="true"></span>

## setTheme(tema)

Aggiorna il parametro del tema utilizzato dall'iframe di trading incorporato.

```js
widget.setTheme('dark')
widget.setTheme('light')
```

<span id="setlocale-locale" data-sixmm-canonical-anchor="setlocale-locale" aria-hidden="true"></span>

## setLocale(locale)

Cambia la lingua dell'iframe. I valori supportati sono en, en-US e zh-CN.

```js
widget.setLocale('en')
widget.setLocale('en-US')
widget.setLocale('zh-CN')
```

<span id="setsize-width-height" data-sixmm-canonical-anchor="setsize-width-height" aria-hidden="true"></span>

## setSize(larghezza, altezza)

Aggiorna la dimensione dell'iframe DOM e notifica all'iframe la nuova dimensione esterna. I valori numerici vengono convertiti in px.

```js
widget.setSize('100%', 720)
```

<span id="reload" data-sixmm-canonical-anchor="reload" aria-hidden="true"></span>

## ricaricare()

Ricarica l'iframe corrente e attendi che venga inizializzato nuovamente.

```js
widget.reload()
```

<span id="refreshauth-reason" data-sixmm-canonical-anchor="refreshauth-reason" aria-hidden="true"></span>

## refreshAuth(motivo)

Chiedi all'iframe di aggiornare il flusso di autenticazione corrente. Il valore del motivo facoltativo viene inoltrato per la registrazione e il controllo del flusso.

```js
widget.refreshAuth('manual')
```

<span id="settokenprovider-provider" data-sixmm-canonical-anchor="settokenprovider-provider" aria-hidden="true"></span>

## setTokenProvider(fornitore)

Sostituisci il tokenProvider utilizzato dalla modalità partner-token. Il SDK chiama il provider quando l'iframe richiede un nuovo token di incorporamento.

```js
widget.setTokenProvider(async ({ channelId, symbol, reason }) => {
  const resp = await fetch('/api/trading/embed-token', {
    method: 'POST',
    credentials: 'include',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ channelId, symbol, reason }),
  })

  return resp.json()
})
```

<span id="on-event-handler" data-sixmm-canonical-anchor="on-event-handler" aria-hidden="true"></span>

## on(evento, gestore)

Sottoscrivere un evento di runtime. La funzione restituita rimuove il listener.

```js
const off = widget.on('order_created', (event) => {
  console.log(event)
})

off()
```

## Metodi aggiuntivi nel runtime v1 corrente

| Metodo | Scopo |
| --- | --- |
| `whenRendered()` | Attendi la notifica di rendering dell'iframe; questo è separato da pronto. |
| `setPage(page)` | Richiedi una pagina di prodotto supportato nell'istanza corrente. Non cambia l’ambiente dei fondi. |
| `prepareForRecreate()` | Richiedi un iframe pronto per prepararsi alla sostituzione; restituisce una promessa e può rifiutarla se non disponibile, occupato o in timeout. |
| `cancelRecreate()` | Annulla un flusso di sostituzione in sospeso/preparato. |
| `TradingWidget.validateOptions(options)` | Convalida le opzioni di inizializzazione prima di creare un'istanza. |

Per modificare un utente o un ambiente reale/demo, distruggi la vecchia istanza e creane una nuova con l'autenticazione e la modalità di destinazione. Non utilizzare `setPage` come interruttore ambientale. Verificare le funzionalità prima di utilizzare metodi opzionali.

```js
if (TradingWidget.capabilities.methods.includes('whenRendered')) {
  await widget.whenRendered();
}
if (TradingWidget.capabilities.pages.includes('up-down')) {
  widget.setPage('up-down');
}
```
