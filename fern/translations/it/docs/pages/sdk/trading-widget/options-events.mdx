## Opzioni

| Campo | Tipo | Predefinito | Note |
| --- | --- | --- | --- |
| baseUrl | string | SDK origine dello script | dominio iframe. Passa esplicitamente nelle pagine dei partner. |
| simbolo | string | BTCUSDT | Normalizzato in maiuscolo e strisce - / _. |
| tema | buio \| leggero | buio | Parametro del tema iniziale. |
| locale | it \| it-USA \| zh-CN | Browser/predefinito | Sono supportati l'inglese e il cinese semplificato. |
| disposizione | predefinito \| compatto | predefinito | Opzione di layout riservata. |
| display | object | `showHeader: false`, `showTicker: false`, `hidden: []` | Controlla le aree di incorporamento della shell e i contenitori di scambio di alto livello. |
| aut | object | nessuno | Utilizza il token partner per le nuove integrazioni SSO. |

<span id="display-controls" data-sixmm-canonical-anchor="display-controls" aria-hidden="true"></span>

## Visualizza i controlli

`display` controlla la shell della pagina di trading incorporata e i contenitori di alto livello. Negli incorporamenti dei partner, l'intestazione del PC e il ticker del mercato più basso sono nascosti per impostazione predefinita.

```js
display: {
  showHeader: false,
  showTicker: false,
  hidden: ['chart', 'orderBook'],
}
```

| Campo | Tipo | Predefinito | Note |
| --- | --- | --- | --- |
| showHeader | boolean | falso | Indica se mostrare l'intestazione incorporata del PC all'interno dell'iframe. |
| showTicker | boolean | falso | Se mostrare il ticker del mercato più basso nella shell di incorporamento. |
| nascosto | corda[] | [] | Nasconde i contenitori di alto livello nella pagina di scambio. |

Valori `display.hidden` supportati:

| Valore | Contenitore |
| --- | --- |
| grafico | Contenitore grafico |
| orderBook | Contenitore per libri degli ordini |
| orderForm | Pannello del modulo d'ordine |
| posizioni | Posizioni inferiori e pannello degli ordini aperti |
| account | Contenitore delle risorse dell'account |

`display.hidden` nasconde solo interi contenitori. Non nasconde singoli pulsanti, campi o strumenti all'interno di un contenitore. I valori che non vengono mappati alla finestra corrente vengono ignorati.

## Eventi

| Evento | Grilletto |
| --- | --- |
| pronto | Inizializzazione iframe terminata. |
| errore | SDK, iframe o errore di autenticazione. |
| stato_cambiato | SDK stato del ciclo di vita modificato. |
| auth_state_changed | Lo stato di autenticazione del token partner è cambiato. |
| simbolo_cambiato | Il simbolo iframe effettivo è stato modificato. |
| locale_modificato | La locale effettiva dell'iframe è cambiata. |
| ordine_creato | L'utente ha creato un ordine all'interno dell'iframe. |
| ordine_fallito | L'invio dell'ordine non è riuscito. |
| distrutto | SDK istanza distrutta. |

## Pagine dei prodotti e modalità di trading

Java Agent SDK e il browser Trading Widget SDK hanno versioni indipendenti. Per il trading di secondi, utilizza le funzionalità attuali del widget e seleziona esplicitamente sia la pagina che la modalità di trading.

| Opzione | Valori | Senso |
| --- | --- | --- |
| `page` | `up-down`, `high-low`, `grid-prediction` | Pagina del prodotto per il trading dei secondi. |
| `tradingMode` | `real`, `demo` | Il valore predefinito è `real`; corrispondere esplicitamente all'ambiente di finanziamento back-end. |

Controllare `TradingWidget.capabilities.pages`, `TradingWidget.capabilities.tradingModes` e `TradingWidget.capabilities.partnerToken` prima dell'inizializzazione. La creazione del token non seleziona un ambiente di fondi. Per cambiare utente o modalità reale/demo, distruggi la vecchia istanza e creane una nuova.

Vedere [esempio completo di trading dei secondi](/it/sdk/agent-sdk/java/seconds-trading) E [configurazione di produzione/simulata](/it/sdk/agent-sdk/java/environments).

## Target ed eventi di visualizzazione aggiuntivi

Il runtime corrente accetta anche `symbolFavorites` e `symbolTicker` in `display.hidden`. Controlla sempre `TradingWidget.capabilities.displayTargets`; una destinazione controlla un contenitore di alto livello e non è un'impostazione di autorizzazione a livello di campo.

| Evento | Senso |
| --- | --- |
| `rendered` | L'iframe invia la notifica renderizzata. |
| `theme_changed` | L'iframe riporta il suo tema attuale. |
| `page_changed` | L'iframe riporta la sua pagina di prodotto effettiva. |

Utilizzare `onRendered` o `widget.on('rendered', handler)` per gestire il rendering separatamente dall'inizializzazione. Le pagine attualmente supportate sono pubblicate in `TradingWidget.capabilities.pages`; convalidare la pagina richiesta anziché indovinare un percorso.
