<h2 id="production-checklist">Elenco di controllo della produzione</h2>

- Conserva API segreti solo nel backend.
- Sincronizzare il tempo del server prima delle richieste firmate.
- Trattare tutti i campi di precisione numerica come stringhe, a meno che una pagina non dica esplicitamente il contrario.
- Utilizzare idempotenza, ID delle richieste e log strutturati attorno ai flussi degli ordini.
- Sottoscrivere WebSocket flussi per lo stato che deve rimanere aggiornato nei sistemi operativi.
- Rivedere i codici di errore e il comportamento dei ritenti prima del lancio.
