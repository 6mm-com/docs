Salvo diversa specificazione, i seguenti endpoint possono utilizzare JWT o API Key firming.

<span id="user-info" data-sixmm-canonical-anchor="user-info" aria-hidden="true"></span>

## Informazioni utente

```http
GET /v1/private/user/info
```

Campi di risposta:

| Campo                  | Tipo   | Descrizione      |
| ---------------------- | ------ | ---------------- |
| `userInfo.userId`      | string | ID utente esterno |
| `userInfo.username`    | string | Nome utente         |
| `userInfo.agentId`     | int64  | ID agente         |
| `userInfo.vipLevel`    | int64  | VIP livello        |
| `userInfo.lastLoginAt` | int64  | Ultimo tempo di accesso  |
| `userInfo.lastLoginIp` | string | Ultimo accesso IP    |

<span id="user-assets" data-sixmm-canonical-anchor="user-assets" aria-hidden="true"></span>

## Risorse utente

```http
GET /v1/private/user/asset
```

Campi di risposta:

| Campo                     | Tipo   | Descrizione                     |
| ------------------------- | ------ | ------------------------------- |
| `userAsset.userId`        | string | ID utente esterno                |
| `userAsset.assetType`     | string | Tipo di asset                      |
| `userAsset.walletBalance` | string | Bilanciamento portafoglio                  |
| `userAsset.frozenMargin`  | string | Margine congelato da ordini in sospeso |
| `userAsset.usedMargin`    | string | Margine utilizzato dalle posizioni        |

<span id="create-listenkey" data-sixmm-canonical-anchor="create-listenkey" aria-hidden="true"></span>

## Crea listenKey

```http
POST /v1/private/user/listen-key
```

Crea una chiave di autenticazione per flussi privati WebSocket .

<span id="renew-listenkey" data-sixmm-canonical-anchor="renew-listenkey" aria-hidden="true"></span>

## Rinnovare listenKey

```http
PUT /v1/private/user/listen-key
```

Estende listenKey validità.

<span data-sixmm-canonical-anchor="close-listenkey" aria-hidden="true"></span>

## Close listenKey

```http
DELETE /v1/private/user/listen-key
```

Chiude il listenKeyspecificato.

<span id="account-change-logs" data-sixmm-canonical-anchor="account-change-logs" aria-hidden="true"></span>

## Registro delle modifiche degli account

```http
GET /v1/private/user/account-change-log?assetType=USDT&page=1&pageSize=20
```

Parametri della richiesta:

| Parametro    | Tipo   | Richiesto | Descrizione                  |
| ------------ | ------ | -------- | ---------------------------- |
| `assetType`  | string | No       | Tipo di asset, come `USDT`   |
| `changeType` | string | No       | Cambio di tipo                  |
| `startTime`  | int64  | No       | Orario di inizio                   |
| `endTime`    | int64  | No       | Fine dei tempi                     |
| `page`       | int32  | No       | Numero di pagina, `1` predefinito     |
| `pageSize`   | int32  | No       | Elementi per pagina, `20` predefinita |

Campi di risposta:

| Campo                        | Tipo   | Descrizione                  |
| ---------------------------- | ------ | ---------------------------- |
| `list[].assetType`           | string | Tipo di asset                   |
| `list[].amount`              | string | Importo modificato               |
| `list[].walletBalanceBefore` | string | Saldo del portafoglio prima del cambio |
| `list[].walletBalanceAfter`  | string | Saldo del portafoglio dopo il cambio  |
| `list[].frozenBalanceBefore` | string | Saldo congelato prima del cambiamento |
| `list[].frozenBalanceAfter`  | string | Saldo congelato dopo il cambio  |
| `list[].changeType`          | string | Cambio di tipo                  |
| `list[].referenceId`         | string | ID aziendale correlato          |
| `list[].createdAt`           | int64  | Tempo di creazione                |
| `total`                      | int64  | Conteggio totale                  |

## Statistiche del volume a 30 giorni

```http
GET /v1/private/user/volume-stats
```

Campi di risposta:

| Campo         | Tipo   | Descrizione                                     |
| ------------- | ------ | ----------------------------------------------- |
| `volume30d`   | string | Volume cumulativo di trading negli ultimi 30 giorni |
| `feeTotal30d` | string | Tariffe cumulative negli ultimi 30 giorni           |

<span id="balance-history" data-sixmm-canonical-anchor="balance-history" aria-hidden="true"></span>

## Storia del bilanciamento

```http
GET /v1/private/user/balance-history?period=1D&limit=30
```

Parametri della richiesta:

| Parametro | Tipo   | Richiesto | Descrizione                            |
| --------- | ------ | -------- | -------------------------------------- |
| `period`  | string | Sì      | `1D` / `1W` / `1M`                     |
| `limit`   | int    | No       | Numero di oggetti restituiti, predefinito `30` |

Campi di risposta:

| Campo             | Tipo   | Descrizione                 |
| ----------------- | ------ | --------------------------- |
| `items[].date`    | string | Data di aggregazione            |
| `items[].balance` | string | Bilanciamento portafoglio              |
| `items[].pnl`     | string | PnL realizzato per il periodo |

<span id="trade-overview" data-sixmm-canonical-anchor="trade-overview" aria-hidden="true"></span>

## Panoramica del settore

```http
GET /v1/private/user/trade-overview?type=1M
```

Parametri della richiesta:

| Parametro | Tipo   | Richiesto | Descrizione                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Sì      | Intervallo di tendenza: `1D`, `1W`, `1M`, `3M`, `6M` `1Y` |

Campi di risposta:

| Campo                | Tipo   | Descrizione                                                          |
| -------------------- | ------ | -------------------------------------------------------------------- |
| `todayPnl`           | string | Il PnL realizzato di oggi                                                 |
| `todayVolume`        | string | Volume di contratti di oggi                                      |
| `totalVolume`        | string | Volume cumulativo di contratti                                   |
| `totalPnl`           | string | PnL realizzato cumulativo                                              |
| `maxDrawdown30d`     | string | Importo massimo di ritiro negli ultimi 30 giorni                        |
| `maxDrawdown30dRate` | string | Tasso massimo di riduzione degli ultimi 30 giorni, decimale da `0` a `1` |
| `transferIn`         | string | Fondi trasferiti cumulativi                                      |
| `transferOut`        | string | Fondi trasferiti cumulativi                                     |
| `items[]`            | array  | Dati sulle tendenze degli asset                                                     |

<span id="asset-overview-summary" data-sixmm-canonical-anchor="asset-overview-summary" aria-hidden="true"></span>

## Riepilogo dell'Asset

```http
GET /v1/private/user/asset/overview/summary
```

I campi di risposta sono gli stessi dei campi di riepilogo della panoramica commerciale, escludendo `items[]`.

<span id="asset-overview-trend" data-sixmm-canonical-anchor="asset-overview-trend" aria-hidden="true"></span>

## Tendenza panoramica degli asset

```http
GET /v1/private/user/asset/overview/trend?type=1M
```

Parametri della richiesta:

| Parametro | Tipo   | Richiesto | Descrizione                                     |
| --------- | ------ | -------- | ----------------------------------------------- |
| `type`    | string | Sì      | Intervallo di tendenza: `1D`, `1W`, `1M`, `3M`, `6M` `1Y` |

Campi di risposta:

| Campo                  | Tipo   | Descrizione                     |
| ---------------------- | ------ | ------------------------------- |
| `items[].snapshotTime` | int64  | Tempo di istantanea                   |
| `items[].balance`      | string | Saldo del conto corrente         |
| `items[].pnl`          | string | PnL per il periodo attuale      |
| `items[].pnlRate`      | string | Tasso PnL per il periodo corrente |
| `items[].totalPnl`     | string | PnL cumulativo                  |

## Simboli preferiti

| --------- | --------- | -------------------- |
