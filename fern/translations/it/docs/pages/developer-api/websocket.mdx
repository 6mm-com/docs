<h2 id="service-endpoint">Endpoint di servizio</h2>

```
wss://ws.6mm.com/ws
```

WebSocket canali sono suddivisi in canali pubblici e canali privati:

| Tipo             | Autenticazione              | Descrizione                                            |
| ---------------- | --------------------------- | ------------------------------------------------------ |
| Canali pubblici  | Non è necessario                | Dati di mercato, come profondità, transazioni, Klines e ticker |
| Canali privati | `listenKey` o JWT richiesto | Flussi di ordine, account e posizione degli utenti              |

<h2 id="public-channels">Canali pubblici</h2>

La WebSocket pubblica non richiede autenticazione. Dopo esserti connesso, invia una richiesta di `subscribe` per abbonarti ai canali di mercato.

Canali comuni:

| Canale                            | Descrizione                                                        |
| ---------------------------------- | ------------------------------------------------------------------ |
| `market.depth.{symbol}`            | Ordine di profondità del libro. Invia prima uno snapshot, poi aggiornamenti incrementali |
| `market.trade.{symbol}`            | Ultime operazioni                                                      |
| `market.kline.{symbol}.{interval}` | Klines                                                             |
| `market.ticker.{symbol}`           | Riepilogo del ticker a singolo simbolo                                       |
| `market.tickers`                   | Riepilogo del ticker di tutti i simboli                                          |

<h2 id="private-channels">Canali privati</h2>

<h2 id="listenkey">listenKey</h2>
Per i flussi privati WebSocket , crea prima un `listenKey` attraverso il REST API , poi connettiti a:

```
wss://ws.6mm.com/ws?listenKey=YOUR_LISTEN_KEY
```

<h2 id="jwt">JWT</h2>
Metodo di connessione JWT compatibile:

```
wss://ws.6mm.com/ws?token=YOUR_ACCESS_TOKEN
```

Dopo il successo dell'autenticazione, il server sottoscrive automaticamente la connessione al canale privato dell'utente corrente. Non è richiesto alcun abbonamento manuale.
