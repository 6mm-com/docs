> REST Base URL: `https://api.6mm.com`\
> WebSocket URL: `wss://ws.6mm.com/ws`

Questa documentazione è destinata a sistemi esterni che si integrano con il servizio 6MM API . Copre login, autenticazione JWT , gestione API Key , firma API Key HMAC , query di conto, ordini, posizioni, dati di mercato e flussi WebSocket .

Il provisioning degli account e la preparazione dei fondi sono gestiti tramite processi lato piattaforma. Questa documentazione descrive solo endpoint di servizio API chiamabili esternamente.

<span id="service-endpoints" data-sixmm-canonical-anchor="service-endpoints" aria-hidden="true"></span>

## Endpoint di servizio

| Tipo      | Punto finale              |
| --------- | --------------------- |
| REST API  | `https://api.6mm.com` |
| WebSocket | `wss://ws.6mm.com/ws`    |

<span id="integration-flow" data-sixmm-canonical-anchor="integration-flow" aria-hidden="true"></span>

## Flusso di integrazione

Sequenza di integrazione consigliata:

1. Accedi con l'account fornito dalla piattaforma e ottieni un `accessToken`.
2. Per l'accesso programmatico lato server, creare prima un API Key con JWT e memorizzare in modo sicuro il `apiSecret`restituito una tantum.
3. Le query private e gli endpoint di ordine e posizione possono essere chiamati con `Authorization: Bearer <accessToken>` o con firma API Key.
4. Per i flussi privati WebSocket , crea prima un `listenKey` , poi collegati a `wss://ws.6mm.com/ws?listenKey=...`.
5. I dati di mercato REST endpoint e i canali pubblici di WebSocket non richiedono autenticazione.

<span id="authentication-choice" data-sixmm-canonical-anchor="authentication-choice" aria-hidden="true"></span>

## Scelta dell'autenticazione

| Scenario                               | Metodo consigliato         |
| -------------------------------------- | -------------------------- |
| Azioni dell'utente frontend                  | JWT                        |
| Chiamate programmatiche lato server         | API Key + HMAC firma   |
| API Key creazione, aggiornamento e cancellazione | JWT                        |
| REST di mercato pubblico / WebSocket pubblici  | Nessuna autenticazione richiesta |
