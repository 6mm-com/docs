## Console e supporto ai visitatori

| Sintomo | Controlla prima |
| --- | --- |
| Manca un menù | Ruolo dell'account e disponibilità del servizio tenant |
| Il widget non si apre | Script generato URL, chiave app, dominio consentito ed errori del browser |
| Bot non utilizza il modello grande | Passaggio effettivo corrispondente, switch di servizio intelligente e relativa configurazione |
| Una risposta utilizza vecchie regole | Articolo di origine, stato di pubblicazione, testo FAQ, stato di traduzione e recupero |
| La traduzione è assente | Lingua di destinazione, cambio di traduzione, traduzione salvata e disponibilità di servizio/saldo |
| La generazione del vettore fallisce | Disponibilità del servizio e stato di recupero; evitare di ricostruire ripetutamente senza identificare l'errore |
| Un campo di contatto è vuoto | Se quel campo è stato effettivamente raccolto; distinguere l'e-mail di contatto dall'e-mail di ingresso |

## MCP connessione e chiamate

| Sintomo | Prossimo passo |
| --- | --- |
| L'apertura dell'endpoint in un browser restituisce un errore | È un endpoint del protocollo, non una pagina di accesso; aggiungilo a un client MCP compatibile |
| Impossibile avviare l'autorizzazione | Verificare l'endpoint esatto, il supporto Streamable HTTP/OAuth del client e il flusso di accesso al browser |
| Connessione non autorizzata o scaduta | Verifica revoca e scadenza; riconnettersi tramite l'applicazione |
| Manca uno strumento o l'accesso è negato | Controllare il ruolo dell'account di autorizzazione e l'ambito del record; aggiornare l'elenco degli strumenti |
| In attesa di approvazione | Apri il collegamento di approvazione restituito e rivedilo nel backend |
| Il contenuto è cambiato | Leggere l'ultimo record, visualizzare nuovamente l'anteprima e inviare una nuova operazione prevista |
| Richiesta scaduta | Interrogare lo stato dell'operazione prima di riprovare o presumere un errore |
| Nessun registro di scrittura | Distinguere una lettura, in attesa di approvazione e una scrittura completata; controllare i filtri nei registri delle operazioni |

<span id="before-contacting-support" data-sixmm-canonical-anchor="before-contacting-support" aria-hidden="true"></span>

## Prima di contattare l'assistenza

Raccogli l'ora e il fuso orario, il tenant/account interessato, il nome della pagina o dello strumento, l'ID operazione ove disponibile e l'errore esatto. Includi uno screenshot oscurato o i passaggi da riprodurre. Non inviare password, codici di verifica, token al portatore o segreti di firma.

Prova un piccolo record di prova durante la diagnosi delle scritture. Verifica il risultato e pulisci solo i dati del test creati, utilizzando il normale flusso di conferma dove richiesto.
