6MM supporto è progettato per partner autorizzati, integrazioni attive e operazioni di produzione. Il supporto per l'utente finale rimane responsabilità della piattaforma partner salvo accordo separato.

<span id="choose-the-right-path" data-sixmm-canonical-anchor="choose-the-right-path" aria-hidden="true"></span>

## Scegli la strada giusta

| Situazione | Percorso consigliato | Include |
| --- | --- | --- |
| Valutazione di nuove partnership o soluzioni | Percorso di onboarding dei partner | Tipo di prodotto, regione target, tempistica di lancio, modello di integrazione atteso. |
| SDK, API, webhook o domanda sull'ambiente | Percorso di supporto tecnico | Endpoint, versione SDK , ID richiesta, passaggi di riproduzione, log. |
| Incidente produttivo o flusso commerciale degradato | Percorso di escalation degli incidenti | Ambito dell'impatto, orario di inizio, utenti interessati, ID ordini, mitigazione attuale. |
| Modifica di asset, copia o materiale di lancio | Percorso di supporto operativo | Pagina, lingua, modifica richiesta, data di lancio, proprietario dell'approvazione. |
| Vulnerabilità o sospetto abuso | Percorso di reportistica sulla sicurezza | Dettagli tecnici, endpoint interessato, evidenze, urgenza, se il problema è attivo. |

<span id="severity-guide" data-sixmm-canonical-anchor="severity-guide" aria-hidden="true"></span>

## Guida alla gravità

| Gravità | Esempio |
| --- | --- |
| Critica | Il trading in produzione, l'autenticazione, l'emissione di token o i flussi correlati ai fondi non sono disponibili. |
| Alto | Un flusso di partner importante si degrada, ma esiste una soluzione alternativa. |
| Normale | Domanda sull'integrazione, richiesta di configurazione, problema di documentazione o supporto al lancio pianificato. |

<span id="before-contacting-support" data-sixmm-canonical-anchor="before-contacting-support" aria-hidden="true"></span>

## Prima di contattare l'assistenza

- Confermare l'area del prodotto e l'ambiente interessati.
- Raccogliere ID richieste, ID ordini, timestamp, ID di mappatura utente, ID eventi webhook e log.
- Utilizzare il template di richiesta di supporto per problemi di produzione.
