Quando contatti l'assistenza, includi le informazioni qui sotto ogni volta che disponibili.

<h2 id="required-context">Contesto richiesto</h2>

| Campo | Esempio |
| --- | --- |
| Ambiente | Produzione o messa in scena |
| Modulo interessato | Trading Widget, Agent SDK, REST API, WebSocket, webhook, sistema white-label |
| Intervallo temporale | UTC intervallo di timestamp quando è avvenuto il problema |
| ID utente partner | Identificatore utente lato partner, se rilevante |
| ID di mappatura 6MM | agentUserId, ID ordine, ID richiesta o ID evento webhook |
| Impatto sul business | Numero di utenti o operazioni coinvolte e se il problema è ancora in corso |

<h2 id="description-format">Formato della descrizione</h2>

- Cosa è successo?
- Cosa ti aspettavi che succedesse?
- Si può riprodurre?
- Cosa è cambiato di recente?
- Il problema è ancora in corso?

<h2 id="attachments">Allegati</h2>

- Registri rilevanti di richieste e risposte.
- Screenshot o registrazioni dello schermo.
- Intestazione di payload e firma Webhook.
- Errori nella console del browser per Trading Widget problemi.

<h2 id="copyable-template">Modello copiabile</h2>

```text
Subject:
[Environment] [Module] Short issue summary

Environment:
Affected module:
First observed time (UTC):
Last observed time (UTC):
Is the issue ongoing:
Business impact:

Expected behavior:
Actual behavior:
Reproduction steps:
Recent changes:

Partner user ID:
agentUserId:
agentOrderNo or order ID:
requestId:
Webhook event ID:

Response code or error:
Attachments:
```

Rimuovi i campi non rilevanti, ma mantieni l'intervallo di tempo UTC e almeno una richiesta o un identificatore aziendale ricercabile ogni volta che è possibile.

<h2 id="redact-sensitive-data">Redattura dei dati sensibili</h2>

Non inviare:

- Password o token di accesso completo
- API segreti, chiavi private o firme complete
- Cookie di sessione
- Pagamento completo, identità o altri dati personali non necessari

Mantenere il nome del campo e un prefisso o suffisso breve solo quando il supporto deve distinguere tra valori sanificati.
