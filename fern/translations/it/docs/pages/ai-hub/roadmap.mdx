> **Pianificato – non ancora lanciato**
> AI Hub è una funzionalità pianificata. Funzionalità, endpoint, comandi e configurazioni client in questa pagina descrivono la progettazione proposta e non sono attualmente disponibili. La disponibilità finale e le istruzioni di configurazione saranno annunciate al momento del lancio.


AI Hub dovrebbe essere rilasciato in più fasi in modo che gli utenti ricevano valore in anticipo mentre le funzionalità di trading sensibili rimangono protette.

<span id="phase-1-public-market-ai-access" data-sixmm-canonical-anchor="phase-1-public-market-ai-access" aria-hidden="true"></span>

## Fase 1: accesso all’IA al mercato pubblico

Obiettivo: consentire a qualsiasi client AI supportato di leggere i dati di mercato ufficiali 6MM.

Risultati finali:

- Client SDK / API condiviso.
- CLI comanda il mercato pubblico.
- Strumenti del mercato pubblico locale MCP
- Strumenti del mercato pubblico ospitati MCP
- Risorse per mercati, commissioni, regole di rischio e stato del sistema.
- Guide all'installazione del client.

Non incluso:

- Domande sull'account.
- Commercio reale.
- API hosting chiave.

<span id="phase-2-account-read" data-sixmm-canonical-anchor="phase-2-account-read" aria-hidden="true"></span>

## Fase 2: lettura dell'account

Obiettivo: consentire agli utenti di ispezionare in sicurezza il contesto del proprio account.

Risultati finali:

- Ambito chiave API di sola lettura.
- Riepilogo del conto.
- Saldi.
- Posizioni.
- Ordini aperti.
- Riempimenti.
- Pagamenti di finanziamento.
- Richiesta di rischio del portafoglio.

Distribuzione preferita:

- Locale MCP.
- CLI.
- Remoto MCP ospitato autonomamente.

<span id="phase-3-trading-preview" data-sixmm-canonical-anchor="phase-3-trading-preview" aria-hidden="true"></span>

## Fase 3: Anteprima del trading

Obiettivo: lasciare che l'IA aiuti a generare ordini senza eseguirli.

Risultati finali:

- `preview_order`.
- Controlli del rischio.
- Impatto sul margine.
- Stima della tariffa.
- Impatto della liquidazione.
- Richiesta di pianificazione dell'esecuzione.

<span id="phase-4-controlled-trading" data-sixmm-canonical-anchor="phase-4-controlled-trading" aria-hidden="true"></span>

## Fase 4: Trading Controllato

Obiettivo: supportare il trading reale solo con forti guardrail.

Risultati finali:

- `create_order`.
- `cancel_order`.
- `amend_order`.
- `cancel_all_orders`.
- `order_status`.
- idempotenza.
- limiti nozionali massimi.
- conferma esplicita.
- registri di controllo.

<span id="phase-5-agentic-skills" data-sixmm-canonical-anchor="phase-5-agentic-skills" aria-hidden="true"></span>

## Fase 5: Abilità Agentiche

Obiettivo: produrre analisi di mercato comuni e flussi di lavoro relativi al rischio.

Risultati finali:

- Abilità di analista di mercato.
- Abilità nel rischio di portafoglio.
- Finanziare le capacità di ricerca.
- Competenza nella protezione dalla liquidazione.
- Abilità nel pianificare l'esecuzione.
- Libreria di attività di esempio.
