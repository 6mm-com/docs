Claude Desktop è una buona soluzione per la ricerca basata su MCP-, la revisione degli account e l'analisi operativa.

<h2 id="recommended-setup">Configurazione consigliata</h2>

| Bisogno | Impostare |
| --- | --- |
| Ricerche di mercato pubbliche | Ospitato MCP |
| Analisi consapevole dell'account | Locale MCP |
| Endpoint interno del team | Telecomando MCP |

<h2 id="example-prompts">Suggerimenti di esempio</h2>

```text
Use 6MM to compare BTC and ETH market depth and explain where liquidity is stronger.
```

```text
Use 6MM to review my account risk. Only read data and produce a summary.
```

<h2 id="notes">Note</h2>

Il MCP locale è preferito ogni volta che sono coinvolti i dati di un account privato perché il server MCP viene eseguito sul computer dell'utente e non è necessario inviare le credenziali a un endpoint AI ospitato da 6MM.
