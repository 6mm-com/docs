Gemini CLI funziona meglio con l'output della riga di comando che può essere ispezionato, riepilogato e passato ad attività di follow-up.

<h2 id="recommended-setup">Configurazione consigliata</h2>

| Bisogno | Impostare |
| --- | --- |
| Controlli del mercato pubblico | 6MM CLI |
| Ricerca scritta | 6MM CLI |
| Contesto del conto privato | Locale MCP o CLI con credenziali locali |

<h2 id="example-prompts">Suggerimenti di esempio</h2>

```text
Use 6MM CLI to fetch market metadata and summarize tradable pairs.
```

```text
Use 6MM to compare fee and margin rules for two symbols.
```

<h2 id="output-format">Formato di uscita</h2>

Preferisci output strutturati come JSON o tabelle Markdown in modo che il client AI possa ragionare sul risultato senza perdere la precisione.
