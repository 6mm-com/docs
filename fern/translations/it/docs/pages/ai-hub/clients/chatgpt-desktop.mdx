> AI Hub è una funzionalità pianificata. Funzionalità, endpoint, comandi e configurazioni client in questa pagina descrivono la progettazione proposta e non sono attualmente disponibili. La disponibilità finale e le istruzioni di configurazione saranno annunciate al momento del lancio.


ChatGPT Desktop è un punto di ingresso familiare per gli utenti che desiderano porre domande sul mercato in linguaggio naturale.

Utilizza questo percorso quando l'utente desidera un'interfaccia conversazionale per dati di mercato pubblici, riepiloghi dei conti, spiegazioni delle posizioni e contesto delle regole di trading.

<span id="recommended-setup" data-sixmm-canonical-anchor="recommended-setup" aria-hidden="true"></span>

## Configurazione consigliata

| Bisogno | Impostare |
| --- | --- |
| Dati del mercato pubblico | Ospitato MCP |
| Contesto del conto privato | Locale MCP |
| Richieste di analisi ripetibili | Abilità agentiche |
| Flussi di lavoro basati su terminale | 6MM CLI |

<span id="what-users-can-ask" data-sixmm-canonical-anchor="what-users-can-ask" aria-hidden="true"></span>

## Cosa possono chiedere gli utenti

```text
Use 6MM to summarize BTC-USDT-PERP liquidity and funding context.
```

```text
Use 6MM to explain my current open positions. Do not place or cancel orders.
```

```text
Use 6MM testnet to preview the margin impact of a small ETH long. Do not submit the order.
```

<span id="safety-defaults" data-sixmm-canonical-anchor="safety-defaults" aria-hidden="true"></span>

## Impostazioni predefinite di sicurezza

- Iniziamo con i dati del mercato pubblico.
- Utilizza Locale MCP quando sono necessarie le credenziali dell'account.
- Conserva le chiavi private API sul computer dell'utente.
- Richiedi un'anteprima e una conferma esplicita prima di qualsiasi futura azione commerciale.
