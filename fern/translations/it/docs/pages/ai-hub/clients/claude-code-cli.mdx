Il codice Claude CLI è utile quando l'agente può eseguire comandi del terminale, ispezionare l'output JSON e aggiornare il codice di integrazione.

<h2 id="recommended-setup">Configurazione consigliata</h2>

| Bisogno | Impostare |
| --- | --- |
| Controlli rapidi del mercato | 6MM CLI |
| Contesto dell'account locale | Locale MCP |
| Flusso di lavoro di implementazione ripetibile | Abilità agentiche |

<h2 id="example-tasks">Compiti di esempio</h2>

```text
Use 6MM CLI to list available perpetual markets and return JSON.
```

```text
Use 6MM to inspect webhook event examples and generate an idempotent handler plan.
```

```text
Use 6MM testnet data to validate this Trading Widget integration. Do not place live orders.
```

<h2 id="best-practice">Migliori pratiche</h2>

Preferisci l'output JSON per i flussi di lavoro degli agenti. È più semplice analizzare, confrontare e includere nei log di implementazione.
