> **Pianificato – non ancora lanciato**
> AI Hub è una funzionalità pianificata. Funzionalità, endpoint, comandi e configurazioni client in questa pagina descrivono la progettazione proposta e non sono attualmente disponibili. La disponibilità finale e le istruzioni di configurazione saranno annunciate al momento del lancio.


Le risorse MCP sono un contesto di sola lettura che i client AI possono ispezionare prima di chiamare gli strumenti.

Le risorse riducono le allucinazioni fornendo al modello informazioni stabili e strutturate su 6MM.

<h2 id="recommended-resource-uris">URI delle risorse consigliate</h2>

| Risorsa | Scopo |
| --- | --- |
| 6mm://sistema/config | Configurazione dell'ambiente e delle capacità. |
| 6mm://sistema/stato | Sistema attuale e situazione del mercato. |
| 6mm://mercati | Mercati disponibili. |
| 6mm://mercato/{symbol} | Specifiche contrattuali e metadati a livello di mercato. |
| 6mm://commissioni | Regole tariffarie. |
| 6mm://rischio/regole | Riepilogo delle regole di trading e rischio. |
| 6mm://rischio/margine | Margine e contesto di liquidazione. |
| 6mm://finanziamenti/regole | Regole sul tasso di finanziamento. |
| 6mm://api/docs | API riepilogo o collegamenti di riferimento. |

<h2 id="resource-design-rules">Regole di progettazione delle risorse</h2>

- Mantieni le risorse di sola lettura.
- Utilizza schemi stabili.
- Includi timestamp e nomi di ambiente.
- Evita di svelare i segreti.
- Preferisci dati strutturati concisi alla prosa lunga.
- Collegamento alla documentazione canonica quando i dettagli sono troppo lunghi.
