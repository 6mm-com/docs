## Suggerimenti consigliati

| Richiesta | Scopo |
| --- | --- |
| panoramica_del mercato | Riassumi lo stato del mercato attraverso i simboli selezionati. |
| mercato_analisi_microstruttura | Analizza spread, profondità, operazioni recenti e condizioni di liquidità. |
| portafoglio_rischio_valutazione | Esaminare le posizioni, l'esposizione, il margine e il rischio di liquidazione. |
| posizione_gestione | Aiuta gli utenti a comprendere lo stato della posizione e le possibili azioni. |
| liquidazione_protezione | Identificare il rischio di liquidazione e le opzioni di riduzione del rischio. |
| tasso_finanziamento_opportunità | Confronta i tassi di finanziamento e le possibili opportunità. |
| crea_ordine_ottimale | Pianifica i parametri dell'ordine prima dell'anteprima. |
| strategia_di_hedging | Esplora le opzioni di copertura per l'esposizione esistente. |
| trading_consultazione | Produrre un'analisi di trading strutturata senza eseguire ordini. |

<span id="prompt-safety-rules" data-sixmm-canonical-anchor="prompt-safety-rules" aria-hidden="true"></span>

## Norme di sicurezza tempestive

- Non considerare i risultati immediati come una consulenza finanziaria.
- Non eseguire strumenti di trading a meno che l'utente non lo chieda esplicitamente.
- Utilizza l'anteprima prima di creare.
- Spiegare le ipotesi e le fonti dei dati.
- Preferisci esempi di testnet nella documentazione pubblica.
