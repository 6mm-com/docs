La MCP locale è la configurazione consigliata quando un cliente AI necessita di un contesto di conto privato o di futuri strumenti di trading controllati.

Il server MCP viene eseguito sul computer dell'utente. Il client AI chiama gli strumenti 6MM locali e il server locale comunica con 6MM APIs utilizzando le credenziali configurate dall'utente.

<span id="what-your-ai-client-can-do" data-sixmm-canonical-anchor="what-your-ai-client-can-do" aria-hidden="true"></span>

## Cosa può fare il tuo client AI

Con Locale MCP, un client AI può utilizzare gli strumenti 6MM in modo controllato:

- Recupera dati di mercato in tempo reale e storici.
- Leggere i saldi dei conti, le posizioni, gli ordini aperti, le esecuzioni e i record di finanziamento quando le credenziali di sola lettura sono abilitate.
- Spiegare l'esposizione del portafoglio, l'utilizzo dei margini e il rischio di liquidazione.
- Visualizza l'anteprima degli ordini prima che venga effettuato qualsiasi ordine reale.
- Nelle fasi successive di negoziazione controllata, creare o annullare gli ordini solo dopo l'autorizzazione esplicita e il controllo dei rischi.

Utilizza Locale MCP quando le credenziali devono rimanere sul computer dell'utente.

## Architettura

```text
AI client
  -> local 6mm-mcp process
  -> 6MM REST / WebSocket API
```

<span id="example-configuration" data-sixmm-canonical-anchor="example-configuration" aria-hidden="true"></span>

## Configurazione di esempio

```json
{
  "mcpServers": {
    "6mm": {
      "command": "uvx",
      "args": ["6mm-mcp"],
      "env": {
        "SIXMM_ENVIRONMENT": "testnet",
        "SIXMM_API_KEY": "your_api_key",
        "SIXMM_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

<span id="recommended-permission-tiers" data-sixmm-canonical-anchor="recommended-permission-tiers" aria-hidden="true"></span>

## Livelli di autorizzazione consigliati

| Livello | Utensili | Note |
| --- | --- | --- |
| Dati pubblici | Mercati, ticker, orderbook, kline, operazioni, finanziamenti | Nessun accesso ad account privato. |
| Conto letto | Saldi, posizioni, ordini aperti, riempimenti | Richiede l'ambito della chiave API di sola lettura. |
| Anteprima del trading | Ordine in anteprima, impatto sul margine, stima delle commissioni | Non effettua ordini. |
| Commercio controllato | Crea, annulla, modifica ordini | Richiede autorizzazione esplicita, conferma e controlli dei rischi. |

<span id="first-setup-checklist" data-sixmm-canonical-anchor="first-setup-checklist" aria-hidden="true"></span>

## Prima lista di controllo della configurazione

1. Installa il pacchetto MCP.
2. Crea o configura una chiave API di sola lettura.
3. Inizia in testnet.
4. Aggiungi il server MCP alla configurazione del client AI.
5. Chiedi al cliente di elencare gli strumenti 6MM disponibili.
6. Esegui una query sui dati di mercato pubblici.
7. Solo allora aggiungi le credenziali di lettura dell'account, se necessario.

<span id="security-notes" data-sixmm-canonical-anchor="security-notes" aria-hidden="true"></span>

## Note di sicurezza

Il MCP locale dovrebbe essere di sola lettura e testnet per impostazione predefinita. Gli strumenti di trading dovrebbero richiedere anteprima, conferma dell'utente, chiavi di idempotenza, limiti nozionali e controlli del rischio sul lato del servizio.
