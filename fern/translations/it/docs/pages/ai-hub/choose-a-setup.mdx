> **Pianificato – non ancora lanciato**
> AI Hub è una funzionalità pianificata. Funzionalità, endpoint, comandi e configurazioni client in questa pagina descrivono la progettazione proposta e non sono attualmente disponibili. La disponibilità finale e le istruzioni di configurazione saranno annunciate al momento del lancio.


Scegli una configurazione in base a due domande:

1. Quale client AI vuoi utilizzare?
2. Hai bisogno solo di dati pubblici, accesso a conti privati ​​o flussi di lavoro di trading?

Se non sei sicuro, inizia con Ospitato MCP per i dati pubblici o Locale MCP per i flussi di lavoro di account privati.

<h2 id="quick-decision-table">Tabella decisionale rapida</h2>

| Obiettivo | Configurazione consigliata | Perché |

| Consenti a Claude Desktop, Cursor o ChatGPT Desktop di chiamare gli strumenti 6MM | Locale MCP | L'intelligenza artificiale richiama gli strumenti tramite un server locale controllato dall'utente. |

<h2 id="pick-by-setup-path">Scegli per percorso di installazione</h2>

| Impostare | Installazione | API posizione della chiave | Miglior ambito iniziale | Conto e ambito di negoziazione |
| --- | --- | --- | --- | --- |
| Ospitato MCP | Nessuno | Nessuna chiave utente API per i dati pubblici | Dati del mercato pubblico | Non consigliato per la prima versione |
| Locale MCP | L'utente installa il pacchetto | Macchina utente | Dati pubblici e lettura degli account | Percorso consigliato per il trading futuro |
| CLI | L'utente installa il pacchetto | Macchina utente | Dati pubblici e script | Utile per l'anteprima e l'automazione |
| Telecomando MCP | L'utente distribuisce il server | Cloud utente o cloud istituzionale | Dati pubblici o lettura dell'account | Possibile quando l'utente controlla la distribuzione |
| Competenze | Documenti o modelli installabili | Dipende dagli strumenti sottostanti | Flussi di lavoro di analisi | Deve seguire le autorizzazioni dello strumento |

<h2 id="security-rule-of-thumb">Regola pratica di sicurezza</h2>

Utilizza la configurazione a rischio più basso che supporta l'attività:

- Dati del mercato pubblico: l'hosted MCP è sufficiente.
- Dati dell'account privato: locale MCP o remoto gestito dall'utente MCP.
- Anteprima di trading: locale MCP o CLI, preferibilmente prima testnet.
- Trading reale: solo dopo autorizzazione esplicita, anteprima, conferma, limiti e registri di controllo.
