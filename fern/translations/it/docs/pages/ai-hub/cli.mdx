6MM CLI è il punto di ingresso della riga di comando per utenti, script e agenti AI che possono eseguire comandi shell.

Utilizzare CLI quando l'ambiente AI può eseguire direttamente i comandi del terminale. Questo è spesso il percorso più semplice per gli agenti di codifica perché non è richiesto un server MCP separato. Il CLI dovrebbe restituire stable JSON per impostazione predefinita in modo che gli agenti possano analizzare i risultati senza fare affidamento sulla formattazione del terminale.

<span id="what-the-cli-is-good-for" data-sixmm-canonical-anchor="what-the-cli-is-good-for" aria-hidden="true"></span>

## A cosa serve il CLI

- Interrogazioni rapide sui dati di mercato da un terminale.
- Analisi guidata dagli agenti in Codex, Claude Code, Gemini CLI o strumenti simili.
- CI o script pianificati che necessitano di dati 6MM.
- Controlli di lettura dell'account quando sono configurate le credenziali locali.
- Flussi di anteprima dell'ordine in cui l'agente prepara i parametri ma non effettua un ordine.

<span id="example-commands" data-sixmm-canonical-anchor="example-commands" aria-hidden="true"></span>

## Comandi di esempio

```bash
6mm markets
6mm ticker BTC-USDT-PERP
6mm orderbook BTC-USDT-PERP --depth 20
6mm klines BTC-USDT-PERP --interval 1h --limit 100
6mm account summary
6mm positions
6mm orders open
6mm order preview --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order create --symbol BTC-USDT-PERP --side buy --type limit --price 65000 --size 0.01
6mm order cancel --order-id xxx
```

<span id="output-modes" data-sixmm-canonical-anchor="output-modes" aria-hidden="true"></span>

## Modalità di uscita

| Modalità | Caso d'uso |
| --- | --- |
| JSON | Predefinito per agenti AI, script e automazione. |
| Tavolo | Revisione del terminale leggibile dall'uomo. |
| Crudo | Debug e test di integrazione. |

<span id="recommended-safety-defaults" data-sixmm-canonical-anchor="recommended-safety-defaults" aria-hidden="true"></span>

## Impostazioni predefinite di sicurezza consigliate

- L'ambiente predefinito è testnet.
- L'output predefinito è JSON.
- I comandi di trading richiedono un consenso esplicito.
- La creazione dell'ordine Mainnet richiede conferma.
- La modalità di anteprima è disponibile prima della creazione.
- Gli errori includono codici stabili e messaggi chiari.

<span id="agent-usage" data-sixmm-canonical-anchor="agent-usage" aria-hidden="true"></span>

## Utilizzo dell'agente

Gli agenti AI dovrebbero preferire comandi di sola lettura a meno che l'utente non richieda esplicitamente azioni di anteprima o di scambio.

Richiesta di esempio:

```text
Use the 6MM CLI to fetch BTC-USDT-PERP orderbook depth and return a short liquidity summary.
```
