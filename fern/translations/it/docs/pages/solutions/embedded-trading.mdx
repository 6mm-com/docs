Il Embedded API / SDK Trading System è progettato per partner che già possiedono traffico, utenti o flussi di lavoro aziendali e vogliono aggiungere trading senza costruire un exchange completo da zero.

<span id="what-it-provides" data-sixmm-canonical-anchor="what-it-provides" aria-hidden="true"></span>

## Cosa offre

- Terminale di trading integrato attraverso il Trading Widget SDK
- Integrazione backend partner tramite Agent SDK
- Binding dell'identità utente e flussi di token di ingresso
- Trasferimento di beni, ordini, posizioni e accesso API conto
- Integrazione di eventi, webhook e ciclo di vita per sistemi operativi

<span id="recommended-architecture" data-sixmm-canonical-anchor="recommended-architecture" aria-hidden="true"></span>

## Architettura consigliata

| Strato | Responsabilità |
| --- | --- |
| Frontend partner | Ospita il punto di ingresso e incorpora l'interfaccia di trading 6MM . |
| Backend partner | Mantiene i API segreti, valida gli utenti, emette token incorporati e processa webhook. |
| 6MM infrastruttura commerciale | Si occupa dell'interfaccia di trading, dell'abbinamento, del rischio, della liquidità, dello stato del conto e del ciclo di vita del trading. |

## Scegli un percorso di integrazione

| Requisito | Percorso consigliato |
| --- | --- |
| Interfaccia di trading completa con la più rapida integrazione web | Trading Widget |
| Binding backend utente, trasferimento, URL di voce e gestione del webhook | Agent SDK |
| Flussi di lavoro completamente personalizzati di prodotti e ordini | REST API + WebSocket |
| Esperienza in borsa di brand con un ambito operativo più ampio | Borsa white-label |

Il progetto finale può combinare questi percorsi. Confermare autenticazione, proprietà degli asset, limiti di responsabilità, monitoraggio e supporto alla produzione prima che inizi l'implementazione.
