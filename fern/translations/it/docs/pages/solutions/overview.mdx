<h2 id="how-the-solutions-connect">Come si collegano le soluzioni</h2>

La maggior parte delle implementazioni partner combina più di una capacità 6MM . Un exchange white-label può utilizzare liquidità istituzionale, supporto alla conformità e integrazioni API . Un partner commerciale embedded può iniziare con il Trading Widget SDK e successivamente aggiungere flussi di Agent SDK backend, elaborazione webhook e risorse operative.
